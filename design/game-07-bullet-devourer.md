## 一、世界观与叙事

### 1.1 世界背景

**"吞噬纪元"——新历2147年。**

人类发现了"虚空能量"——一种可以吞噬一切物质并转化为武器能源的奇异力量。但虚空能量有副作用：接触过的人会逐渐失去人性，变成只会攻击的"虚空傀儡"。

**"吞噬者"（Devourer）**应运而生—— 驾驶特制机甲的战士，机甲核心可以安全地吸收虚空能量，并将其转化为武器。吞噬者是人类最后的防线。

**玩家是"代号：零"**—— 最新型的吞噬者原型机驾驶员。你的机甲核心与其他不同：它不仅能吸收虚空能量，还能**吸收敌人的攻击**，将其反弹。这个能力被视为禁忌，因为历史上所有尝试过的驾驶员都疯了——他们的意识被吸收的虚空能量侵蚀。

**深层冲突**：随着战斗深入，你发现虚空傀儡其实是上一代的吞噬者。他们没有被侵蚀——他们是自愿放弃的，因为发现了某个真相：虚空能量不是外来入侵，是地球本身的免疫系统。人类过度开发资源，地球在"排毒"。而你的机甲核心，可能是唯一能与地球"沟通"的媒介。

### 1.2 叙事方式

**碎片叙事**：
- 每击败一个Boss，获得一段"记忆碎片"——上一代吞噬者的临终记录
- 碎片拼凑出真相：他们不是被侵蚀的，是选择了"融合"
- 最终选择：关闭虚空裂缝（拯救人类但毁灭地球）或成为新的"虚空意识"（毁灭人类但拯救地球）

**机甲日志**：
- 战斗间隙，机甲AI会播报分析（"检测到高浓度虚空能量，建议开启吞噬模式"）
- 随着剧情推进，AI的语气逐渐变化——从机械变得...有感情？

## 三、核心玩法

### 3.1 基础操作

**移动**：虚拟摇杆控制机甲移动

**射击**：按住射击按钮，机甲朝面向方向自动射击（移动时可射击，但精度下降20%）

**吞噬**：点击吞噬按钮，展开持续1秒的虚空护盾
- 护盾范围内，所有敌方弹幕被**吸收**（不是抵消）
- 吸收后，弹幕转化为"吞噬储备"
- 护盾冷却3秒，期间无法移动或移动速度-50%

**反射**：再次点击吞噬按钮（或有储备时自动），释放所有吞噬储备
- 储备的弹幕以2倍速、1.5倍伤害反射回去
- 反射弹幕保留原轨迹模式，但方向反转
- 反射弹幕数量=吞噬储备数量

### 3.2 虚空能量系统

| 状态 | 能量值 | 效果 |
|------|--------|------|
| 枯竭 | <20% | 伤害-30%，吞噬护盾持续时间-50% |
| 正常 | 20-79% | 正常战斗 |
| 充盈 | 80-99% | 攻击速度+20%，吞噬护盾范围+30% |
| **超载** | **100%** | **可激活超载模式**：伤害×2，吞噬储备上限翻倍，持续8秒 |

**能量变化**：
- 击杀敌人：+5%
- 吸收弹幕：+3%/发
- 反射命中：+2%/发
- 被击中：-8%
- 持续不操作（>5秒）：-3%/秒

### 3.3 弹幕吞噬机制（核心创新）

**风险-回报设计**：
- 开盾时机对 = 清屏+反杀+能量暴涨
- 开盾时机错 = 站着挨打+能量暴跌

**Build联动方向**：
- **护盾流**：延长护盾时间（1→2秒）、缩短冷却（3→1.5秒）、护盾期间回血
- **反射流**：反射伤害×3、反射弹幕穿透、反射弹幕分裂
- **贪婪流**：不开盾也能缓慢吸收附近弹幕（半径50px，-30%效率）
- **超载流**：超载持续时间+5秒、超载期间无敌、超载后不虚弱

### 3.4 卡牌构筑系统

**卡组系统**：
- 每局开始前，玩家从已解锁的卡牌中组建"卡组"（8张卡）
- 战斗中升级时，从卡组中随机抽取3张可选
- 卡牌分3种类型：攻击（红）、防御（蓝）、特殊（紫）

**卡牌示例**：

| 卡牌 | 类型 | 效果 | 稀有度 |
|------|------|------|--------|
| 弹幕风暴 | 攻击 | 反射弹幕数量×2 | 稀有 |
| 虚空护甲 | 防御 | 护盾期间受到伤害-50% | 普通 |
| 能量虹吸 | 特殊 | 击杀敌人回复10%能量 | 稀有 |
| 时间扭曲 | 特殊 | 反射弹幕速度×3 | 传说 |
| 连锁反应 | 攻击 | 反射命中后产生二次爆炸 | 史诗 |

**卡牌联动**：
- 弹幕风暴 + 连锁反应 = 反射弹幕分裂后每个都产生爆炸
- 虚空护甲 + 能量虹吸 = 护盾期间击杀回复双倍能量
- 时间扭曲 + 弹幕风暴 = 超高速弹幕风暴

### 3.5 核心循环（单局内）

```
Step 1: 进入区域，小波次敌人（5-8个），熟悉build
Step 2: 首次升级，从卡组抽3选1
Step 3: 敌人波次加密，需要走位+输出
Step 4: 首次使用吞噬，吸收弹幕+反射清屏
Step 5: 精英敌人出现（10倍血量，复杂弹幕），考验策略
Step 6: Build成型，卡牌联动激活，爽感爆发
Step 7: 区域Boss战，多阶段，弹幕密度峰值
Step 8: 击败Boss，结算（击杀数、吞噬数、build总览）
```

## 七、技术实现评估

| 项目 | 选择 | 理由 |
|------|------|------|
| 渲染 | Canvas 2D + 离屏缓存 | 弹幕为简单几何，批量绘制 |
| 碰撞 | Spatial Grid（空间网格） | 100+实体，O(n)检测 |
| 对象管理 | Object Pool（对象池） | 避免GC，预创建500对象 |
| 输入 | 虚拟摇杆 + 按钮 | 移动端标准 |

**AI开发难度：3/5** — 核心挑战是性能（对象池+空间网格必须到位），其他为标准游戏开发。
