# 策划文档：彩棱碰碰核心玩法设计

> 文档角色：策划（Planner）  
> 版本：v0.1（阶段性结论）  
> 日期：2026-08-15

---

## 一、核心玩法总结（一句话版本）

**玩家控制光点在网格上移动，留下光轨。当光轨围成闭环时，圈内的宝石被收集。如果圈内宝石满足组合条件（如3个同色），会合并成更高级的宝石。**

---

## 二、核心循环（简化版）

```
画圈（留下光轨）
  ↓
圈闭合 → 宝石引爆收集
  ↓
检查组合条件 → 满足则合并成新宝石
  ↓
光轨清空 → 重新开始画圈
```

**玩家理解成本：** 一句话能解释清楚——"画圈收宝石，同色组合变高级"。

---

## 三、关键机制定义

### 3.1 基础操作

| 操作 | 说明 |
|------|------|
| 移动 | 上下左右四向滑动，每次移动一格 |
| 留轨 | 每经过一格，留下光轨（占格子，不可重复经过） |
| 闭环 | 光轨首尾相连形成封闭区域 |
| 引爆 | 闭环形成后，圈内宝石全部收集 |

### 3.2 宝石系统

#### 基础宝石（5种颜色）

| 颜色 | 说明 |
|------|------|
| 红色 | 基础色，可参与组合 |
| 蓝色 | 基础色，可参与组合 |
| 绿色 | 基础色，可参与组合 |
| 黄色 | 基础色，可参与组合 |
| 紫色 | 基础色，可参与组合 |

#### 组合宝石（通过闭环组合产生）

| 组合条件 | 产物 | 效果（初步设计） |
|---------|------|----------------|
| 3个同色 | 强化宝石（同色） | 下次被圈中时，触发范围消除（周围8格） |
| 4个同色 | 超级宝石（同色） | 触发十字线消除（整行+整列） |
| 5个同色 | 终极宝石（同色） | 触发全屏消除（同色全部消失） |
| 红+蓝+绿 | 彩虹宝石 | 清屏，消除所有宝石 |

#### 组合规则说明

- **最少3个宝石**才能触发组合
- **杂色宝石**（如2红1蓝）不触发组合，普通收集
- **组合宝石**落在棋盘随机空位，可以被再次圈中
- **连锁反应**：MVP版本不做，后续版本考虑

### 3.3 步数限制系统

#### 核心概念

玩家每次画圈有**步数上限**，而不是时间限制。

| 参数 | 初始值 | 说明 |
|------|--------|------|
| 基础步数 | 30步 | 每次画圈最多走30格 |
| 步数恢复 | 引爆后重置 | 每次引爆成功，步数重置为基础值 |

#### 行动力宝石（特殊宝石）

| 宝石类型 | 效果 |
|---------|------|
| 闪电宝石 | 圈中后，本局基础步数+10（永久生效） |
| 时钟宝石 | 圈中后，本次画圈步数+20（临时生效） |

**设计目的：** 给玩家提供"行动力管理"的策略维度——是立即引爆，还是继续积累步数？

### 3.4 光轨管理

#### 原设计（已废弃）

- **虹化状态**：引爆后3步不留光轨，可穿越光轨
- **问题**：理解成本高，技术复杂度高（8字形路径、自相交等边界case）

#### 新设计（采用）

- **引爆后清空光轨**：每次引爆成功，所有光轨立即消失
- **优点**：
  - 玩家一看就懂（引爆=清空）
  - 技术实现简单（无需处理路径交叉）
  - 节奏感清晰（紧张→释放→重新开始）

## 四、关卡目标

### 4.1 基础目标

| 目标类型 | 说明 |
|---------|------|
| 收集所有宝石 | 最基础的目标，圈中所有宝石即过关 |
| 达到分数 | 通过组合宝石获得高分 |
| 收集特定组合 | 如"本关需要凑出2个彩虹宝石" |

### 4.2 关卡难度曲线

| 关卡段 | 引入机制 | 目标 |
|--------|---------|------|
| 1-5关 | 基础画圈+收集 | 教会玩家"画圈收宝石" |
| 6-10关 | 同色组合（3个） | 教会玩家"同色组合变高级" |
| 11-15关 | 混色组合（红蓝绿→彩虹） | 教会玩家"混色组合" |
| 16-20关 | 行动力宝石 | 引入"步数管理"策略 |
| 21+关 | 高级组合（4-5同色） | 深度策略 |

## 五、已废弃的设计

### 5.1 虹化机制（已移除）

**原设计：**
- 引爆后进入虹化状态，持续3步
- 虹化状态下不留光轨，可穿越已有光轨

**移除原因：**
1. **理解成本高**：玩家不知道"变成彩虹色"意味着"可以穿越光轨"，需要教程解释
2. **技术复杂度高**：8字形路径会形成多个闭环，边界case难以处理
3. **违背设计原则**：游戏应该"一看就会"，不需要解释

**替代方案：**
- 引爆后直接清空所有光轨
- 玩家理解：引爆成功=棋盘清空=重新开始

### 5.2 时间限制（已移除）

**原设计：**
- 光轨90秒后自动消失

**移除原因：**
- 时间限制对休闲游戏来说压力太大
- 步数限制更符合"思考型"玩法

## 六、核心策略维度

玩家在每一关需要平衡三条线：

1. **空间线**：光轨占格子，步数有限，如何高效利用？
2. **组合线**：如何凑出特定组合（3同色、红蓝绿等）？
3. **行动力线**：何时引爆？何时继续积累步数？

**核心抉择：**
> "我现在引爆一个小圈收集普通宝石，还是继续画圈凑出彩虹组合？"

## 七、待确认的问题

| 问题 | 选项 | 建议 |
|------|------|------|
| 组合宝石落在哪？ | A. 圈内中心<br>B. 棋盘随机空位 | B（视觉表现更好） |
| 杂色宝石圈中了怎么办？ | A. 直接消失<br>B. 算分数但不触发组合 | B（鼓励"清场"策略） |
| 高级宝石的效果？ | A. 范围消除<br>B. 十字线消除<br>C. 全屏消除 | 分级设计（3同色→范围，4同色→十字，5同色→全屏） |
| 行动力宝石的出现频率？ | A. 每关固定1-2个<br>B. 随机出现 | A（可控性更强） |
