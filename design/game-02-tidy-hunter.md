## 一、世界观与叙事

### 1.1 世界背景

**"记忆收藏家"的时代。**

在一个被遗忘的维度，存在着无数"记忆房间"——每个房间都是一个逝去灵魂的人生片段。这些房间被"混沌"侵蚀，物品散落、时间错乱、记忆模糊。

**玩家是"整理猎人"**—— 拥有"秩序之眼"的特殊能力者。你的使命：进入记忆房间，找到关键物品，恢复秩序，收集记忆碎片，拼凑出房间主人的故事。

**深层冲突**：每个房间主人都有未完成的遗憾。恢复秩序后，你会面临选择：让记忆保持完整（获得完整故事），还是提取稀有物品（获得强力道具）？

### 1.2 叙事方式

**玩法中叙事**：
- **房间环境**：每个房间的风格暗示主人身份（儿童房=早逝的孩子，书房=老学者，战场=士兵）
- **物品描述**：点击物品时显示一行文字（"这是一枚生锈的婚戒，内侧刻着'永远'"）
- **记忆碎片**：每关收集的3个关键物品拼凑成一段回忆（语音+画面）
- **房间解锁顺序**：按主题分类（童年→青春→中年→老年→战争→和平），形成叙事弧线

## 三、核心玩法

### 3.1 基础循环

**寻物+三消**：在杂乱场景中找到目标物品，放入收集栏，3个相同消除。

**操作**：
- 点击场景中的物品 → 高亮+飞入收集栏（0.3秒）
- 收集栏满5格且无法消除 → 游戏失败
- 3个相同物品自动消除 → 更新目标进度

### 3.2 物品系统（3A级详细）

| 类型 | 特征 | 分值 | 出现频率 |
|------|------|------|---------|
| 普通 | 明显可见 | 10分 | 70% |
| 隐藏 | 需缩放/移动视角 | 30分 | 20% |
| 干扰 | 点击扣分 | -20分 | 10% |
| 关键 | 过关必需 | 50分 | 每关1-3个 |
| 记忆 | 解锁故事片段 | 100分 | 每关1个 |

### 3.3 连击与评分

| 连击 | 倍率 | 条件 |
|------|------|------|
| 1 | ×1.0 | 无 |

## 增强设计 v2.1 — 互喂循环重构

> **重构目标**：打破寻物→三消→剧情的串联排队结构，让寻物与三消形成实时互喂的双核循环，产生 1+1>2 的化学反应。

---

### 1. 核心循环重构：混乱 ↔ 净化 双通道

#### 1.1 旧循环的问题

```
寻物找到物品 → 攒能量 → 能量满才能进三消 → 三消得分推进剧情
     ↑___________________________________________________↓
                        (单向、割裂、排队)
```

**问题诊断**：
- 寻物和三消是两个独立小游戏，只在"能量"处产生弱连接
- 玩家在三消时完全忘记寻物场景长什么样
- 三消的产出（分数）只服务于剧情进度，不反哺寻物过程
- 整体节奏是"做完A才能做B"，而非"A和B同时进行"

#### 1.2 新循环：互喂双通道

```
┌─────────────────────────────────────────────────────────────┐
│                        寻物场景                               │
│  ┌─────────────┐    混乱元素溢出    ┌─────────────┐         │
│  │   灰尘/杂物  │ ────────────────→ │ 三消棋盘障碍 │         │
│  │   幽灵污染   │    (实时污染)      │   块/特殊块   │         │
│  └─────────────┘                   └─────────────┘         │
│         ↑                                    │              │
│         │         ┌──────────────┐          │              │
│         │         │   连携评分    │          │              │
│         │         │   实时增益    │          │              │
│         │         └──────────────┘          │              │
│         │                                    ↓              │
│  ┌─────────────┐    净化完成返回    ┌─────────────┐         │
│  │   隐藏区域   │ ←──────────────── │  特定消除组合  │         │
│  │   揭示解锁   │    (区域净化)      │   触发净化    │         │
│  └─────────────┘                   └─────────────┘         │
│                                                             │
│  [时间压力] ← 倒计时同时作用于两个系统，玩家需在两者间权衡      │
└─────────────────────────────────────────────────────────────┘
```

**核心设计原则**：
- **污染通道**：寻物场景中的混乱状态实时映射到三消棋盘
- **净化通道**：三消的特定消除直接改变寻物场景的状态
- **时间共享**：两个系统共用同一个倒计时，操作任一系统都消耗时间
- **实时增益**：两个系统的优秀表现互相给对方提供 buff

---

### 2. 场景-棋盘映射系统

#### 2.1 设计理念

每个寻物场景不再只是"一张背景图"，而是与一个特定的三消棋盘形成**主题映射关系**。场景中的物品、区域、混乱元素都在棋盘上有对应表现。

**类比**：就像《马里奥赛车》的赛道与道具箱的关系——你在赛道上的表现决定了你能拿到什么道具，而道具又帮助你在赛道上跑得更好。

#### 2.2 映射规则（以"老书房"为例）

| 寻物场景元素 | 三消棋盘映射 | 互喂机制 |
|-------------|-------------|---------|
| 散落的书本 ×5 | 棋盘出现「书本块」 | 消除3个书本块 → 书房中1个书架区域被整理，隐藏抽屉解锁 |
| 灰尘覆盖区域 ×3 | 对应棋盘位置出现「灰尘障碍块」（不可移动/需相邻消除才能清除） | 清除灰尘障碍 → 寻物场景中该区域灰尘消散，露出下方隐藏物品 |
| 幽灵（干扰元素）×2 | 棋盘出现「幽灵块」（每3回合随机移动位置） | 将幽灵块消除或困在角落 → 寻物场景中对应幽灵消失，不再遮挡物品 |
| 钢笔/墨水 | 普通消除块 | 无特殊映射，正常消除得分 |
| 关键物品：放大镜 | 棋盘底部生成「放大镜特殊块」（类似炸弹，消除整行） | 使用放大镜特殊块 → 寻物场景中自动高亮一个隐藏物品3秒 |

#### 2.3 棋盘布局映射（老书房示例）

```
寻物场景布局（8×6网格）          三消棋盘布局（8×8网格）
┌────────────────────────┐      ┌────────────────────────┐
│ [书架][灰尘][书桌][窗户] │      │ 📕 │ 📕 │ 🕸️ │ ✒️ │ 📕 │ 🕸️ │ 📖 │ ✒️ │
│ [灰尘][地毯][抽屉][灰尘] │  →   │────┼────┼────┼────┼────┼────┼────┼────│
│ [门]  [幽灵][台灯][书架] │      │ ✒️ │ 🕸️ │ 👻 │ 📕 │ ✒️ │ 🕸️ │ 📖 │ 📕 │
│ [壁炉][画作][幽灵][灰尘] │      │────┼────┼────┼────┼────┼────┼────┼────│
│ [书桌][窗户][书架][灰尘] │      │ 📖 │ 👻 │ 📕 │ 🕸️ │ ✒️ │ 📕 │ 🕸️ │ ✒️ │
│ [抽屉][灰尘][地毯][门]  │      │────┼────┼────┼────┼────┼────┼────┼────│
└────────────────────────┘      │ ...（继续8行）              │
                                └────────────────────────┘

图例：📕书本块  🕸️灰尘障碍块  👻幽灵块  ✒️普通块  📖普通块
```

**关键规则**：
1. 寻物场景中每存在1个未清理的混乱元素（灰尘/幽灵），三消棋盘上就有1个对应的障碍块
2. 障碍块被消除后，寻物场景中对应区域立即净化（0.5秒动画反馈）
3. 三消棋盘上的普通块类型由寻物场景中的普通物品决定（书房=书本/钢笔/墨水/纸张四种普通块）
4. 每个场景有独特的棋盘主题颜色和方块样式

#### 2.4 场景主题列表（示例）

| 场景 | 主题色 | 普通块 | 特殊障碍 | 特殊机制 |
|------|--------|--------|---------|---------|
| 老书房 | 暖棕色 | 书本/钢笔/墨水/纸张 | 灰尘/幽灵 | 消除书本解锁隐藏抽屉 |
| 儿童房 | 明黄色 | 玩具/积木/蜡笔/糖果 | 污渍/玩具风暴 | 消除积木搭建玩具塔 |
| 战场掩体 | 灰绿色 | 弹药/绷带/水壶/钢盔 | 烟雾/弹坑 | 消除弹药补充"火力槽" |
| 老厨房 | 米白色 | 锅具/食材/餐具/调料 | 油污/蟑螂 | 消除食材完成食谱 |
| 花园温室 | 翠绿色 | 花盆/水壶/种子/剪刀 | 杂草/害虫 | 消除种子开花解锁区域 |

### 3. 时间压力系统（替代能量门）

#### 3.1 旧机制：能量门

```
寻物找到物品 → +10能量 → 能量满100 → 解锁三消 → 三消消耗能量 → 能量耗尽回寻物
```

**问题**：
- 人为制造等待，打断心流
- 两个玩法被迫交替，不能同时进行
- 能量不足时玩家只能干等或看广告

#### 3.2 新机制：统一倒计时

```
┌─────────────────────────────────────────────────────┐
│  房间进入 → 倒计时开始（例如：90秒）                    │
│                                                      │
│  ┌──────────────┐         ┌──────────────┐          │
│  │   寻物操作    │ ←─────→ │   三消操作    │          │
│  │   点击物品    │  随时   │   交换方块    │          │
│  │   -2秒/次    │  切换   │   -3秒/次    │          │
│  └──────────────┘         └──────────────┘          │
│         │                        │                  │
│         └────────┬───────────────┘                  │
│                  ↓                                   │
│           共用倒计时                                  │
│                                                      │
│  时间耗尽 → 房间评级（根据完成度）→ 奖励结算            │
└─────────────────────────────────────────────────────┘
```

**时间消耗规则**：

| 操作 | 时间消耗 | 说明 |
|------|---------|------|
| 点击寻物（正确） | -2秒 | 基础消耗 |
| 点击寻物（错误/干扰） | -5秒 | 惩罚 |
| 三消交换一次 | -3秒 | 比寻物略高，鼓励优先寻物 |
| 触发连消（3连） | -1秒 | 奖励，净消耗更低 |
| 触发连消（4连+） | +2秒 | 大奖励，时间回涨 |
| 消除障碍块（灰尘/幽灵） | +5秒 | 重要奖励 |
| 找到关键物品 | +10秒 | 重大奖励 |

**设计意图**：
- 玩家需要权衡：花3秒做一次三消是否值得？也许用这3秒在寻物中找更多物品更好？
- 高手可以通过连消和净化障碍来"赚时间"，形成正反馈循环
- 没有硬墙（能量耗尽强制停止），只有软压力（时间紧迫但始终可操作）

#### 3.3 界面表现

```
┌────────────────────────────────────────┐
│ ⏱️ 剩余时间: 47秒  [████████░░░░░░░░░░] │  ← 顶部倒计时条
│                                         │
│  ┌────────────────────────────────┐    │
│  │      寻物场景（上半屏）           │    │
│  │   [可点击区域，直接交互]          │    │
│  └────────────────────────────────┘    │
│                                         │
│  [🔄 切换] ← 中间快速切换按钮            │
│                                         │
│  ┌────────────────────────────────┐    │
│  │      三消棋盘（下半屏）           │    │
│  │   [可交换方块，直接交互]          │    │
│  └────────────────────────────────┘    │
│                                         │
│  当前目标: 找出3本书（1/3）解锁隐藏抽屉   │
│  棋盘状态: 2个灰尘障碍待清除             │
└────────────────────────────────────────┘
```

**双屏同显模式**（平板/大屏手机）：
- 寻物场景占上40%，三消棋盘占下40%
- 中间20%显示目标提示和切换按钮
- 两个界面同时可见，玩家一眼就能判断该做什么

**单屏切换模式**（小屏手机）：
- 通过中间的「🔄 切换」按钮快速在两个视图间切换
- 切换耗时0.3秒，不打断节奏
- 切换时保留两个界面的状态，不重置

### 4. 连携评分系统

#### 4.1 设计理念

**不是"寻物做完做三消"，而是"寻物中触发三消buff，三消中触发寻物hint"**。两个系统实时互相增益，优秀玩家在两边都能获得超额回报。

#### 4.2 寻物 → 三消 增益通道

| 寻物行为 | 三消增益 | 持续时间 |
|---------|---------|---------|
| 找到关键物品 | 生成1个「彩虹块」（可匹配任意颜色） | 立即生成，直到使用 |
| 连续找到3个正确物品（<5秒） | 下一次三消交换必定触发连消 | 1次交换 |
| 找到隐藏物品（无提示） | 三消棋盘所有障碍块高亮闪烁3秒 | 3秒 |
| 完成一个收集目标（如3/3书本） | 三消棋盘上对应书本块全部变成「超级书本块」（消除时清除整行+整列） | 直到被消除 |
| 净化一个区域（消除所有灰尘） | 三消获得「时间回溯」：下一次交换不消耗时间 | 1次交换 |
| 发现秘密物品（超出目标列表） | 生成1个「炸弹块」（3×3范围爆炸） | 立即生成，直到使用 |

#### 4.3 三消 → 寻物 增益通道

| 三消行为 | 寻物增益 | 持续时间 |
|---------|---------|---------|
| 达成3连消 | 寻物场景中下一个目标物品高亮闪烁 | 5秒 |
| 达成4连消 | 显示一个隐藏物品的位置（半透明白色轮廓） | 3秒 |
| 达成5连消（T型/L型） | 寻物场景缩放拉近，显示一个未净化区域的全貌 | 5秒 |
| 消除一组障碍块（3个灰尘） | 对应寻物区域净化，露出所有该区域的隐藏物品 | 永久 |
| 使用彩虹块 | 寻物场景中玩家可以点击任意物品（即使不在目标列表），点击正确+5秒 | 1次点击 |
| 触发全屏清屏（超级组合） | 寻物场景中所有干扰物（幽灵/误导物品）暂时消失 | 10秒 |
| 在时间<10秒时完成一次4连消 | 「肾上腺素」：寻物点击不再消耗时间，持续5秒 | 5秒 |

#### 4.4 连携评分计算

```
单次操作得分 = 基础分 × 连携倍率 × 时间倍率

连携倍率：
- 无连携：×1.0
- 单方向连携（寻物→三消 或 三消→寻物）：×1.5
- 双向连携（先寻物增益三消，再三消增益寻物）：×2.0
- 三连携（双向+限时内再次触发）：×3.0

时间倍率：
- 时间>60秒：×1.0
- 时间30-60秒：×1.2（紧张加成）
- 时间<30秒：×1.5（极限加成）
- 时间<10秒：×2.0（肾上腺素）

示例：
玩家在寻物中找到关键物品（生成彩虹块）→ 立即切换到三消，使用彩虹块触发4连消 → 
4连消触发寻物高亮 → 切回寻物找到高亮物品 → 完成一次「双向连携」
得分 = 100 × 2.0 × 1.2 = 240分（vs 无连携的100分）
```

#### 4.5 连携评级动画

| 评级 | 条件 | 动画效果 |
|------|------|---------|
| Good | 单方向连携 | 屏幕边缘闪过对应颜色光效 |
| Great | 双向连携 | 屏幕中央出现"⚡ 互喂 ⚡"字样，轻微震动 |
| Excellent | 三连携 | 全屏粒子爆发，时间暂停0.5秒展示得分 |
| Perfect | 四连携+时间<10秒 | 特殊动画：场景+棋盘同时发光，解锁"净化模式"（5秒内所有操作不消耗时间） |

### 6. Meta Game 调整

#### 6.1 移除/调整的旧系统

| 旧系统 | 处理方式 | 原因 |
|--------|---------|------|
| 能量门 | **完全移除** | 与新时间压力系统冲突 |
| 收集栏满5格失败 | **改为软惩罚** | 收集栏满时仍可操作，但寻物点击消耗时间+50% |
| 纯三消得分 | **改为连携分** | 单独三消得分效率低，鼓励互喂 |

#### 6.2 新增 Meta 要素

**净化评级系统**：
- 每关根据完成度（目标完成数/净化区域数/剩余时间）评级 ★~★★★
- ★★★通关解锁"净化模式"：该关卡可在无时间限制下自由探索
- 全关卡★★★解锁"鉴赏模式"：查看所有剧情碎片和隐藏设定

**连携大师等级**：
- 统计历史最高连携评级（Good/Great/Excellent/Perfect）
- 连续5关达成Excellent+解锁"互喂大师"称号
- 称号效果：初始时间+10秒

**房间真结局**：
- 每关有"标准净化"（完成目标）和"完美净化"（清除所有混乱+找到所有秘密物品）
- 完美净化解锁该房间的"真结局"剧情（比标准结局更完整的记忆故事）

### 8. 技术实现要点

#### 8.1 状态同步

```typescript
// 核心状态机
interface RoomState {
  // 寻物场景状态
  scene: {
    items: Item[];           // 所有物品（可见/隐藏/被遮挡）
    pollution: Pollution[];  // 混乱元素（灰尘/幽灵）
    purifiedAreas: string[]; // 已净化区域ID
  };
  
  // 三消棋盘状态
  board: {
    grid: (Block | null)[][];  // 8×8格子
    obstacles: Obstacle[];     // 障碍块映射
    specialBlocks: Special[];  // 特殊块（彩虹/炸弹/超级）
  };
  
  // 共享状态
  shared: {
    timeRemaining: number;     // 剩余时间（秒）
    chainMultiplier: number;   // 当前连携倍率
    lastActionSource: 'scene' | 'board'; // 上次操作来源
  };
}

// 关键同步规则：
// 1. pollution[i].cleared → board.obstacles[i] 在下一帧消失
// 2. board.obstacles[i].matched → pollution[i] 播放净化动画
// 3. scene.items[keyItem].found → board.generateSpecial('rainbow')
// 4. board.combo >= 4 → scene.highlightNextTarget(5秒)
```

#### 8.2 性能考虑

- 寻物场景和三消棋盘**不同时全屏渲染**（小屏切换模式）
- 切换时保留Canvas离屏缓冲区，避免重新绘制
- 互喂反馈使用轻量级动画（CSS transform / Canvas 2D），不使用粒子系统
- 连携评级动画使用预渲染的精灵图，避免实时计算

### 9. 对比总结

| 维度 | v3.0（旧） | v2.1（新） |
|------|-----------|-----------|
| 核心循环 | 寻物→三消→剧情（串联） | 寻物↔三消实时互喂（并联） |
| 连接方式 | 能量门（弱连接） | 污染/净化双向映射（强连接） |
| 限制机制 | 能量耗尽硬停止 | 统一倒计时软压力 |
| 玩家体验 | "做完A才能做B" | "A和B同时做，互相帮忙" |
| 心流状态 | 频繁打断 | 持续沉浸 |
| 高手天花板 | 三消技术 | 连携时序把控 |
| 重玩价值 | 刷分 | 优化连携路线 |
| 叙事融合 | 过关后解锁 | 净化过程中逐步揭示 |

---

> **设计判定**：此增强版本将「寻物+三消」从"两个拼在一起的小游戏"转变为"一个有机整体"。寻物中的混乱就是三消的障碍，三消的净化就是寻物的进度。时间压力让玩家必须在两个系统间做实时决策，连携评分奖励那些在两边都表现优秀的玩家。这是一个值得团队做3个月的核心循环。
