## 一、世界观与叙事

### 1.1 世界背景

**"第零号实验"——被时间遗忘的囚笼。**

你醒来时，躺在一座荒岛的海滩上。手腕上有一个发光的金属环——"时环"。时环的倒计时显示："30天"。

每到第30天，世界会崩解，一切归零。但你的记忆、知识、已解锁的蓝图会被时环保留。你被困在一个**30天为周期的时空牢笼**中。

**岛屿的真相**：这里是一座被遗弃的实验室遗址。曾经的研究者试图用时间循环技术实现永生，结果导致整个岛屿被困在了时间裂缝中。你是第427个被困者——前426个要么疯了，要么放弃了。

**你的任务**：
- 在30天内尽可能收集知识（蓝图、配方、信息碎片）
- 建造越来越高效的庇护所
- 找到打破循环的方法——或者，选择接受永恒的轮回

### 1.2 核心叙事机制

**知识传承**：
- 每次循环保留：蓝图、配方、技能等级、剧情碎片
- 每次循环重置：地图、资源分布、敌人、基地建筑
- 每发现一个新蓝图，时环会记录——下次循环可直接使用

**剧情碎片系统**：
- 岛上散落着前426个被困者留下的日志、实验记录、疯狂涂鸦
- 收集足够碎片后，拼出完整故事：为什么实验会失败？有没有逃脱方法？
- 某些碎片只在特定循环条件出现（如"第10次循环后才能在雪山顶找到第17号日志"）

**三种结局**：
1. **打破循环**（收集全部关键碎片，建造时间机器）——回到现实世界，但失去所有记忆
2. **接受轮回**（选择不打破循环）——成为新的"岛屿管理员"，帮助后续被困者
3. **疯狂**（循环超过50次仍没找到出路）——角色精神崩溃，解锁隐藏剧情线

## 三、核心玩法

### 3.1 基础操作

**移动与采集**：
- 虚拟摇杆控制移动
- 靠近资源自动采集（范围拾取，参考Forager）
- 点击敌人自动锁定攻击

**建造**：
- 打开建造菜单，选择蓝图
- 点击放置（自动对齐网格）
- 长按可批量放置

**合成**：
- 打开背包→合成界面
- 拖拽材料到合成格
- 长按制作按钮连续制作

### 3.2 时间循环机制（核心创新）

**循环规则**：
| 保留 | 重置 |
|------|------|
| 已解锁蓝图 | 地图地形 |
| 技能等级 | 资源分布 |
| 剧情碎片 | 敌人位置 |
| 配方知识 | 基地建筑 |
| 属性成长 | 背包物品 |

**循环倒计时**：
- 30游戏天为一个循环（约现实时间2-3小时）
- 最后5天，时环闪烁警告
- 第30天，世界崩解动画→传承报告→新循环加载

**传承报告**：
- 本轮存活天数
- 解锁新蓝图数量
- 最高成就（击杀最多敌人/建造最大基地等）
- 与历史最佳对比

**特殊循环条件**：
- 每5次循环，地图会出现"异常区域"（高难度但高奖励）
- 第10次循环后，解锁"速通模式"（挑战10天内完成特定目标）

### 3.3 程序化地图生成

**岛屿生成（Simplex噪声+水文模拟）**：
```
Step 1: Simplex噪声生成高度图（256×256）
Step 2: 径向梯度遮罩→中心高、边缘低（岛屿塑形）
Step 3: 高度梯度→生物群系（沙滩→草地→森林→山地→雪线）
Step 4: 内容填充（洞穴、资源点、敌人营地）
```

**生物群系**：
| 类型 | 特征 | 资源 | 危险 |
|------|------|------|------|
| 沙滩 | 出生点，安全 | 贝壳、椰子 | 低 |
| 草地 | 开阔，易建造 | 木材、浆果 | 低 |
| 森林 | 树木密集 | 大量木材、蘑菇 | 中（狼群）|
| 山地 | 矿石丰富 | 铁矿、石矿 | 高（落石）|
| 雪线 | 极端环境 | 稀有矿石 | 极高（暴风雪）|

**洞穴系统**：
- 随机房间+走廊算法（BSP树）
- 每层向下难度递增
- 深层有稀有蓝图和剧情碎片

### 3.4 核心循环（单局内）

```
Step 1: 苏醒·查看本轮地图特征（30秒）
Step 2: 紧急采集·直奔已知高价值资源（5分钟）
Step 3: 基地选址·靠近水源？矿点？（2分钟）
Step 4: 快速建造·使用传承蓝图一键建造核心设施（5分钟）
Step 5: 向外探索·进入Roguelike区域寻找新蓝图（10分钟）
Step 6: 危机应对·野兽袭击/资源枯萎/Boss战（5分钟）
Step 7: 深度优化·解锁更多蓝图，为循环结束做准备（剩余时间）
Step 8: 循环重置·世界崩解，传承报告，新循环开始
```

## 七、技术实现评估

| 项目 | 选择 | 理由 |
|------|------|------|
| 渲染 | Canvas 2D原生 | 2D俯视角足够，无需引擎 |
| 地图生成 | Simplex噪声+元胞自动机 | 轻量可控 |
| AI | FSM + A*寻路 | 昼夜行为切换简单高效 |
| 状态管理 | 集中式Store | 资源/建造/地图强关联 |
| 存储 | IndexedDB | 地图数据大 |

**AI开发难度：3/5** — 核心挑战是内容量（配方、敌人、事件）和地图生成趣味性。

### 一、循环结构重构：7天一周目

#### 1.1 时间粒度

| 层级 | 时长 | 说明 |
|------|------|------|
| **一局（周目）** | 7天 | 每周末强制重置 |
| **一天** | 4个阶段 | 早晨/中午/黄昏/夜晚 |
| **一个阶段** | 5–10分钟 | 白天阶段偏采集建造，夜晚偏战斗防守 |
| **单周目总时长** | **30–60分钟** | 新手约60分钟，熟练后约30分钟 |

#### 1.2 四阶段设计

每个阶段有明确的玩法重心和视觉氛围，玩家可以据此规划行动：

| 阶段 | 时长 | 玩法重心 | 环境变化 | 风险等级 |
|------|------|---------|---------|---------|
| **🌅 早晨** | ~5分钟 | 外出采集、探索新区域 | 视野最佳，敌人活跃度低 | ⭐ |
| **☀️ 中午** | ~5分钟 | 建造、合成、整理基地 | 光照最强，部分敌人回避阳光 | ⭐⭐ |
| **🌇 黄昏** | ~5分钟 | 紧急收尾、回防基地 | 光线渐暗，敌人开始活跃 | ⭐⭐⭐ |
| **🌙 夜晚** | ~10分钟 | 基地防守、洞穴探索 | 视野受限，夜间敌人出没 | ⭐⭐⭐⭐⭐ |

> **设计意图**：白天节奏快、偏规划，夜晚压力大、偏执行。黄昏作为"最后的安全窗口"制造紧迫感，逼迫玩家做取舍——再多挖两块矿，还是立刻回防？

#### 1.3 阶段切换动画

- 过渡动画约3秒：天色渐变 + 环境音效过渡（虫鸣→狼嚎）
- 玩家可随时暂停，但阶段内时间不会倒流
- 第7天夜晚结束即触发**强制循环重置**（世界崩解），不可跳过

### 二、周目递进机制

#### 2.1 核心概念：不是重复，是升级

每次重置不是"回到原点"，而是进入**下一个周目**。周目数永久累计，岛屿的时间裂缝越来越不稳定，但也暴露出更多秘密。

| 周目 | 新机制 | 敌人变化 | 资源变化 | 解锁内容 |
|------|--------|---------|---------|---------|
| **第1周目** | 基础生存教学 | 白天无主动敌人，夜晚只有狼 | 正常分布 | 基础蓝图（T1-T2） |
| **第2周目** | **幻影**夜间出没 | 夜晚新增"幻影"（半透明、高移速、穿墙） | 正常分布 | 幻影相关防御蓝图 |
| **第3周目** | **资源稀缺**+新区域 | 幻影数量增加，白天出现"腐化生物" | 木材/石头减少40%，稀有资源增加 | 深海区域开放 |
| **第4周目+** | 每周目随机叠加2个异常 | 异常池轮换：狂暴化/寄生/极寒/酸雨 | 随机波动 | 高级剧情碎片 |

#### 2.2 异常池（第4周目起每周目随机抽取2个）

| 异常名 | 效果 | 应对策略 |
|--------|------|---------|
| **狂暴化** | 所有敌人攻速+50%，血量-25% | 风筝打法，利用陷阱 |
| **寄生** | 击杀敌人后3秒内未远离，尸体复活 | 控制击杀位置，远程优先 |
| **极寒** | 夜晚体温下降速度翻倍 | 优先建造壁炉/保温建筑 |
| **酸雨** | 黄昏和夜晚户外持续掉血 | 提前储备室内活动资源 |
| **时间裂隙** | 随机出现传送门，进入=高难度奖励房 | 可选挑战，非强制 |
| **寂静** | 夜晚无环境音效，敌人无声接近 | 依赖视觉，建造探照灯 |

### 三、时间锚点系统

#### 3.1 核心概念：跳过重复劳动

玩家可以在循环中设置**最多3个时间锚点**。下次新周目开始时，可选择从任一锚点直接进入，跳过前期已知、枯燥的重复阶段。

#### 3.2 锚点设置规则

| 属性 | 说明 |
|------|------|
| **数量上限** | 3个（不可叠加） |
| **消耗** | 每个锚点消耗 **1个时间碎片**（稀有资源，每周目最多获得1-2个） |
| **设置时机** | 只能在"阶段结束"时设置（早晨→中午、中午→黄昏、黄昏→夜晚） |
| **保存内容** | 当前阶段 + 玩家背包状态 + 已建造建筑快照 + 已探索地图区域 |
| **重置丢失** | 锚点仅在当周目有效，周目重置后锚点清零（未使用的锚点不返还碎片） |

#### 3.3 锚点使用示例

```
玩家在第3周目的流程：

第1天早晨：砍树、采石头 → 设置锚点A（"第1天·早晨"）
第2天黄昏：基地初具规模 → 设置锚点B（"第2天·黄昏"）
第3天夜晚：击败幻影Boss，拿到关键蓝图 → 设置锚点C（"第3天·夜晚"）
第7天夜晚：循环重置

第4周目开始：
- 选项1：从头开始（第1天早晨）
- 选项2：从锚点A开始（第1天早晨，背包+基地已起步）
- 选项3：从锚点B开始（第2天黄昏，基地成型，跳过前两天）
- 选项4：从锚点C开始（第3天夜晚，直接Boss战后状态，但夜晚压力大）
```

#### 3.4 锚点策略深度

- **激进玩家**：锚点全部设在后期（第5-6天），追求速通高难度阶段
- **稳健玩家**：锚点均匀分布（第2/4/6天），每次从安全位置推进
- **尝鲜玩家**：每周目用不同锚点，体验同一周目的不同节奏

> **关键设计**：锚点不是"存档"，而是**策略资源**。什么时候设、设在哪儿，本身就是决策。

#### 3.5 时间碎片获取

| 来源 | 数量 | 说明 |
|------|------|------|
| 首次击败周目Boss | 1个 | 每周目首次 |
| 完成隐藏挑战 | 1个 | 如无伤过夜、单阶段采集100+资源 |
| 传承奖励（每3周目） | 1个 | 鼓励长期游玩 |
| 发现剧情碎片 | 0-1个 | 稀有碎片附带 |

### 四、循环加速：时间加速器

#### 4.1 解锁条件

- 时环等级达到 **Lv.20**
- 已解锁蓝图"时间加速器"（T3蓝图，需击败第2周目幻影Boss后获得）

#### 4.2 功能说明

建造并激活"时间加速器"后：

| 模式 | 效果 | 适用场景 |
|------|------|---------|
| **正常** | 1倍速，全天手动操作 | 新周目、高难度异常周目 |
| **加速** | 白天阶段（早晨/中午/黄昏）自动2倍速 | 已知套路、资源充足 |

- **夜晚阶段不可加速**——保留核心压力和决策时刻
- 加速时玩家仍可干预：手动暂停、下达建造指令、调整策略
- 加速期间资源自动采集（基于当前工具等级和技能等级自动计算）

#### 4.3 建造需求

| 材料 | 数量 |
|------|------|
| 铁矿 | 20 |
| 电子元件 | 5 |
| 古文明碎片 | 2 |
| 能量核心 | 1（击败幻影Boss掉落） |

> **设计意图**：时间加速器是"后期爽感"装置。当玩家已经熟悉前期套路、想要压缩重复时间时使用。它不是开局就能用的外挂，而是对熟练玩家的奖励。

### 五、传承机制重构

#### 5.1 保留项（跨周目永久继承）

| 类别 | 保留内容 | 说明 |
|------|---------|------|
| **蓝图** | 全部已解锁蓝图 | 核心传承，每次新周目可直接使用 |
| **技能等级** | 5种技能等级 | 永久成长，每级+5%效率 |
| **剧情碎片** | 已收集碎片 | 逐步拼凑完整故事 |
| **时环等级** | 累计经验等级 | 解锁新功能（地图预览、时间裂隙等） |

#### 5.2 新增：建筑模板系统

**核心痛点**：每次新周目都要从零建基地，挫败感强。
**解决方案**：玩家可以保存一套基地布局为"模板"，新周目一键重建。

##### 模板机制

| 属性 | 说明 |
|------|------|
| **保存上限** | 3套模板（可用时间碎片扩展至5套） |
| **保存内容** | 建筑类型 + 位置布局（不保存材料） |
| **重建消耗** | 所需材料的 **80%**（比从零建省20%，因为"有图纸了"） |
| **重建时机** | 新周目开始后任意时间，约10秒动画 |
| **模板编辑** | 可随时覆盖保存、命名、删除 |

##### 模板示例

```
模板名称：【速攻型·前哨站】
布局：
  - 中心：熔炉 ×1
  - 四角：箭塔 ×4
  - 外围：木墙 ×12段
  - 侧翼：农田 ×2
重建消耗（第1天即可建）：
  - 木材：120（原需150）
  - 石头：60（原需75）
  - 铁矿：20（原需25）
```

> **设计意图**："建筑模板"不是免费午餐——你仍然需要采集资源，但省去了"设计布局"的认知负担。玩家可以把心思花在策略上，而不是重复摆放木屋。

#### 5.3 重置项（每周末清零）

| 类别 | 重置内容 | 说明 |
|------|---------|------|
| **地图** | 全部地形、资源分布、敌人位置 | 保持Roguelike新鲜感 |
| **背包** | 所有物品 | 每周目从零开始积累 |
| **建筑** | 基地全部设施 | 可用模板快速重建 |
| **临时Buff** | 药水、食物效果 | 不跨周目 |
| **锚点** | 所有未使用锚点 | 不返还碎片 |
