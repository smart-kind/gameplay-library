## 一、世界观与叙事

### 1.1 世界背景

**"永恒熔炉"——诸神的斗兽场。**

你死了。但死亡不是终点。

你醒来时，发现自己站在一个巨大的圆形竞技场中央。天空是熔岩色的，四周漂浮着无数破碎的肢体——手臂、腿、头颅，它们在空中缓慢旋转，像是一座怪诞的雕塑。

一个声音在你脑海中响起："欢迎来到熔炉。在这里，你的身体是耗材，你的灵魂是货币。击败对手，夺取他们的肢体，组装成更强的自己。活到最后的，将获得向诸神挑战的资格。"

**你是第10,847个被投入熔炉的灵魂。** 前10,846个，都已经变成了漂浮在空中的零件。

### 1.2 核心叙事机制

**身体即进度**：
- 每次死亡，失去一个随机部位，但获得该部位的"记忆"
- 记忆积累后，该部位在后续掉落中概率+20%
- 某些稀有部位需要特定组合的记忆才能解锁

**灵魂等级**：
- 每次战斗获得"灵魂余烬"
- 余烬用于解锁新的斗魂（全局被动技能）
- 斗魂改变核心玩法（如"暴击时回复1%血量"）

**NPC故事线**：
- 竞技场中有"固定居民"——铁匠、商人、神秘人
- 与他们对话解锁背景故事
- 某些居民曾是前10,846个灵魂中的强者

**三种结局**：
1. **挑战诸神**：收集全部神级部位，击败最终Boss
2. **成为熔炉之主**：放弃挑战，留在竞技场帮助后续灵魂
3. **彻底消散**：连续死亡50次，灵魂耗尽，游戏结束（真结局解锁隐藏剧情）

## 三、核心玩法

### 3.1 基础操作

**移动**：
- 虚拟摇杆控制移动（支持8方向）
- 双击方向=冲刺
- 向上滑动=跳跃

**攻击**：
- 点击攻击键=轻攻击
- 长按攻击键=蓄力重攻击
- 滑动+攻击=方向技（滑向敌人+攻击=突进技）

**技能**：
- 技能按钮释放特殊技能（消耗能量）
- 必杀按钮（能量满时可用）

**防御/闪避**：
- 向反方向滑动=防御
- 快速双击=闪避（有无敌帧）

### 3.2 部位系统（核心创新）

**四个部位**：
| 部位 | 影响 | 示例 |
|------|------|------|
| 头部 | 视野范围、特殊感知、暴击率 | 鹰眼头=看破敌人攻击前兆 |
| 躯干 | 血量、防御、霸体 | 钢铁躯=防御+30%，移动-10% |
| 手臂 | 攻击速度、连招长度、武器类型 | 螳螂臂=攻速+25%，范围+20% |
| 腿部 | 移动速度、闪避方式、跳跃 | 弹簧腿=跳跃+50%，可二段跳 |

**部位稀有度**：
| 稀有度 | 颜色 | 掉率 | 特点 |
|--------|------|------|------|
| 普通 | 白色 | 60% | 基础属性 |
| 优秀 | 绿色 | 25% | 1条额外属性 |
| 稀有 | 蓝色 | 10% | 2条额外属性+特效 |
| 史诗 | 紫色 | 4% | 改变动作模组 |
| 传说 | 橙色 | 1% | 独特技能+外观 |

**部位协同**：
- 特定部位组合触发协同效果
- 示例：
  - 螳螂臂 + 蜘蛛腿 = 空中连击延长
  - 钢铁躯 + 铁拳头 = 霸体+重击强化
  - 鹰眼头 + 弓箭手臂 = 远程暴击率+50%

### 3.3 战斗系统

**帧级碰撞**：
- 每帧检测 hitbox（攻击盒）vs hurtbox（受击盒）
- 命中时触发 hitstop（双方冻结3-8帧）
- 根据攻击力度产生 knockback（击退）

**硬直系统**：
- 受击方进入固定帧数的不可操作状态
- 命中方根据招式类型获得不同优势帧
- 可连招的窗口期明确显示

**能量系统**：
- 攻击命中/被击积攒能量
- 能量满时释放必杀技
- 必杀技有无敌帧，可打断敌人攻击

### 3.4 核心循环（单局内）

```
Step 1: 熔炉重生（开局选择）- 从部位库选初始组合，选择斗魂
Step 2: 热身战（第1关小兵）- 3-4波低级敌人，熟悉手感，掉落白色部位
Step 3: 首次组装（战后奖励）- 3选1：新部位/升级/斗魂强化
Step 4: 精英战（第2关）- 带名字的精英敌人，击败掉落其特色部位
Step 5: 连招发现（中期成长）- 2-3个部位触发协同，解锁隐藏连招
Step 6: Boss战前准备（商店/事件）- 消耗灵魂余烬购买或交易部位
Step 7: Boss战（阶段式）- 3阶段Boss，死亡保留记忆（下次显示攻击预警）
Step 8: 死亡/通关 → 熔炉重铸 - 失去1个部位但获得记忆，或通关解锁新斗魂
```

## 四、局内成长系统

### 4.1 部位收集

**总部位数**：60个（15个头+15个躯干+15个手臂+15个腿）

**部位图鉴**：
- 收集部位解锁图鉴条目
- 完整收集一套系列（如"昆虫系"）解锁特殊斗魂
- 图鉴可查看部位的完整属性和协同组合

### 4.2 斗魂系统

| 斗魂 | 效果 | 解锁条件 |
|------|------|---------|
| 嗜血 | 暴击时回复1%血量 | 初始 |
| 铁壁 | 防御时伤害-50% | 收集5个钢铁系部位 |
| 风行者 | 移动时攻击力+20% | 收集5个速度系部位 |
| 时间行者 | 闪避时时间缓速1秒 | 击败时间Boss |
| 熔炉之主 | 每次死亡保留2个部位 | 通关5次 |

### 4.3 灵魂余烬

**获取**：
- 击败敌人掉落
- 连击奖励
- 无伤通关奖励

**用途**：
- 商店购买部位
- 移除负面部位
- 复活（保留当前进度）

### 4.4 难度系统

**熔炉热度**：
- 每次通关后热度+1
- 热度影响：敌人血量+10%/级、攻击力+5%/级、掉率+2%/级
- 热度无上限，挑战极限

## 七、技术实现评估

| 项目 | 选择 | 理由 |
|------|------|------|
| 渲染 | Canvas 2D + Spine骨骼动画 | 2D格斗，骨骼动画控制hitbox精确 |
| 动画 | Spine/DragonBones | 帧级控制，事件轨道触发碰撞 |
| 碰撞 | 自定义AABB + 空间哈希 | 格斗游戏需精确帧级碰撞 |
| AI | 行为树 + 条件评估器 | 敌人攻防节奏可配置 |
| 状态管理 | 分层状态机(HFSM) | 角色状态复杂，需分层管理 |

**AI开发难度：4/5** — 帧数据配置工作量大，手感调试周期长。
