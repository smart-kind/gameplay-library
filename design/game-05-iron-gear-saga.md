> 核心组合：蒸汽朋克机甲组装 + Roguelike动作 + 开放世界探索  
> 预估总分：**4.65**

## 一、世界观与叙事

### 1.1 世界背景

**时代**："大蒸汽纪元"第237年。人类文明在"灰烬战争"中毁灭，幸存者依靠巨型蒸汽机甲"铁巨人"（Iron Giant）在废土中重建文明。

**核心冲突**：世界被"锈蚀风暴"（Rust Storm）侵蚀——一种由战争遗留的纳米机械病毒，能将一切金属化为锈粉。玩家是"齿轮之城"（Gear City）的年轻机甲工程师，继承了祖父遗留的古老机甲图纸。为了寻找治愈锈蚀风暴的方法，玩家驾驶自制的蒸汽机甲深入风暴中心，探索战争前的遗迹。

**叙事节奏**：不是通过过场动画，而是**玩法中叙事**：
- 每个区域的环境叙事（废墟中的日记、全息影像）
- NPC的异步对话（通过无线电，玩家可随时收听）
- 机甲部件的"记忆"（装备特定部件时触发回忆片段）

### 1.2 角色设定

| 角色 | 身份 | 动机 | 与玩家关系 |
|------|------|------|-----------|
| 玩家 | 年轻机甲工程师 | 寻找治愈锈蚀风暴的方法，继承祖父遗志 | 主角 |
| 艾达 | 齿轮之城的首席机械师 | 保护城市，研究古代科技 | 导师，提供升级服务 |
| 锈鸦 | 神秘流浪者，全身机械化 | 寻找战争的真相 | 亦敌亦友，后期可招募 |
| 风暴核心 | 锈蚀风暴的源头AI | 执行战争遗留的"净化协议" | 最终Boss |

### 1.3 世界架构

| 区域 | 特征 | 敌人 | 资源 |
|------|------|------|------|
| 齿轮之城（安全区） | 蒸汽朋克风格城市，NPC聚集地 | 无 | 任务、交易、升级 |
| 锈蚀荒原（1-10级） | 红色沙漠，间歇性锈蚀风暴 | 锈狼、机械秃鹫 | 铁矿、基础零件 |
| 沉没工厂（10-25级） | 水下废墟，需氧气管理 | 深海机甲、漏电无人机 | 精密齿轮、蒸汽核心 |
| 天空遗迹（25-40级） | 浮空岛屿，重力异常 | 飞行机甲、风暴核心守卫 | 古代芯片、反重力石 |
| 风暴核心（40级+） | 最终区域，持续锈蚀伤害 | 风暴核心AI、精英守卫 | 终极材料 |

## 三、核心玩法

### 3.1 机甲组装系统（核心创新）

**部件类型**：

| 部位 | 功能 | 影响属性 | 示例 |
|------|------|---------|------|
| 躯干 | 决定基础生命、装甲 | 生命上限、装甲值 | 轻型躯干（生命+500，装甲+50） |
| 手臂 | 决定武器类型和攻击力 | 攻击力、攻击速度 | 重型手臂（攻击+30%，攻速-10%） |
| 腿部 | 决定移动方式和速度 | 移速、转向速度、可穿越地形 | 履带腿（移速-20%，可穿越沙漠） |
| 核心 | 决定能量上限和回复 | 能量上限、能量回复、技能强度 | 蒸汽核心（能量+50，回复+2/s） |
| 头部 | 决定视野和探测 | 视野范围、敌人探测距离 | 雷达头（视野+30%，探测隐形） |

**组装规则**：
- 每个部位有"重量"，总重量不能超过腿部"承重上限"
- 部件有"蒸汽兼容性"，不兼容的部件同时装备会降低效率（-20%属性）
- 部件位置影响重心：重型部件装在一侧会导致转向偏移

**协同效果（Synergy）**：

| 组合 | 效果 | 说明 |
|------|------|------|
| 火焰核心 + 火焰喷射臂 | 火焰伤害+50%，范围+20% | 专精火焰流 |
| 重型躯干 + 重型手臂×2 | 攻击力+30%，但移速-30% | 坦克流 |
| 轻型躯干 + 涡轮腿 + 雷达头 | 移速+50%，闪避+20% | 侦察流 |
| 古代核心 + 任何古代部件 | 激活古代科技，随机额外效果 | 考古流 |

### 3.2 战斗系统

**战斗方式**：俯视角动作，虚拟摇杆移动，技能按钮释放。

**战斗循环**：
```
Step 1: 探索区域，发现敌人（雷达头提前预警）
Step 2: 选择战斗或回避（根据机甲配置判断）
Step 3: 进入战斗，使用虚拟摇杆走位
Step 4: 点击技能按钮释放技能（消耗能量）
Step 5: 技能命中敌人，造成伤害（计算攻击力-敌人装甲）
Step 6: 敌人攻击，计算伤害（敌人攻击-玩家装甲）
Step 7: 能量自动回复（核心决定回复速度）
Step 8: 击败敌人，掉落材料和装备
```

**伤害计算**：
```
实际伤害 = (玩家攻击力 × 技能倍率 - 敌人装甲) × 协同加成 × 暴击倍率

暴击判定：随机数 < 暴击率（头部部件决定）
暴击倍率：1.5-3.0（根据部件）
```

### 3.3 探索系统

**开放世界设计**：
- 区域制开放世界，每个区域约500×500像素
- 无缝连接（过渡区域加载）
- 环境危害：锈蚀风暴（持续掉血）、高温区域（能量消耗翻倍）、辐射区（装甲快速损耗）

**资源采集**：
| 资源 | 用途 | 分布 |
|------|------|------|
| 铁矿 | 基础升级、修理 | 锈蚀荒原 |
| 精密齿轮 | 高级部件制作 | 沉没工厂 |
| 蒸汽核心 | 能量系统升级 | 天空遗迹 |
| 古代芯片 | 解锁古代科技 | 所有区域（稀有） |

**制作系统**：
- 收集材料 → 在齿轮之城的工作台制作部件
- 配方解锁：通过探索获得蓝图
- 制作成功率：基础80%，可用额外材料提升到100%

### 3.4 敌人设计

| 敌人类型 | 特征 | 弱点 | 掉落 |
|---------|------|------|------|
| 锈狼 | 快速近战，群体出没 | 火焰伤害（锈蚀金属怕热） | 铁矿、锈狼牙 |
| 机械秃鹫 | 飞行，远程攻击 | 电磁脉冲（干扰飞行） | 齿轮、羽毛合金 |
| 深海机甲 | 高装甲，近战重击 | 穿甲攻击（破甲后脆弱） | 精密齿轮、深海合金 |
| 风暴守卫 | 精英敌人，有护盾 | 持续伤害（护盾回复有间隔） | 古代芯片、核心碎片 |
| 风暴核心AI | Boss，多阶段 | 阶段转换时脆弱 | 终极核心、传说图纸 |

## 五、Meta Game

### 5.1 公会系统（社交核心）

**公会功能**：
- 公会基地：共享资源仓库、公会工坊（制作效率+20%）
- 公会任务：每日/每周公会目标，完成后全员奖励
- 公会战：每周与其他公会竞争，争夺"资源矿区"
- 公会科技：全员贡献升级，共享被动效果

**公会战规则**：
- 每周六20:00开启，持续1小时
- 公会成员驾驶机甲进入"矿区战场"
- 占领据点获取积分，积分最高公会获得该周矿区开采权
- 矿区产出稀有资源，仅该公会成员可采集

### 5.2 交易系统

**玩家交易**：
- 齿轮之城拍卖行：玩家出售多余材料和部件
- 交易税：10%（系统回收）
- 稀有部件可设置"一口价"或"竞拍"

### 5.3 赛季系统（长期运营）

**赛季周期**：每3个月一个赛季

**赛季内容**：
| 内容 | 说明 |
|------|------|
| 新赛季区域 | 全新探索区域（约2-3个） |
| 新赛季部件 | 20+新部件，新协同效果 |
| 赛季通行证 | 免费线+付费线，含限定外观和部件 |
| 赛季Boss | 限时世界Boss，全服协作击败 |
| 排位赛季 | PvP排位重置，新奖励 |

**赛季主题示例**：
- 第1赛季："锈蚀觉醒" — 基础内容
- 第2赛季："深海迷航" — 水下区域扩展
- 第3赛季："天空之城" — 浮空区域扩展
- 第4赛季："古代觉醒" — 古代科技全面解锁

## 六、商业化设计

### 6.1 变现模式：免费下载 + 赛季通行证 + 部件抽卡

**为什么不是纯付费**：移动端免费下载门槛最低，能快速积累用户基数。Roguelike+动作的核心玩家愿意为核心内容付费。

### 6.2 IAP设计

| 商品 | 价格 | 内容 | 设计理由 |
|------|------|------|---------|
| 赛季通行证 | $9.99/赛季 | 付费线奖励：限定外观×5、传说部件×2、资源×10000 | 主力营收，参考《堡垒之夜》 |
| 部件补给箱 | $2.99/抽 | 随机部件（概率：普通60%、稀有30%、传说10%） | 类似《原神》角色池，但有保底 |
| 资源礼包 | $4.99 | 铁矿×5000+齿轮×1000+合金×500 | 加速成长，非必须 |
| 外观套装 | $1.99-$9.99 | 机甲涂装、特效、头像框 | 纯装饰，零平衡影响 |
| 月卡 | $4.99/月 | 每日登录送资源+制作成功率+10% | 提高留存和付费率 |

**保底机制**：
- 连续30抽未出传说 → 第31抽必出传说
- 每10抽至少1个稀有

### 6.3 广告设计

| 场景 | 类型 | 奖励 |
|------|------|------|
| 死亡复活 | 激励视频 | 原地复活，恢复50%生命 |
| 资源加倍 | 激励视频 | 本次探索资源获取×2 |
| 快速制作 | 激励视频 | 跳过制作等待时间 |
| 每日奖励 | 激励视频 | 每日登录奖励×2 |

**禁止**：探索过程中插屏广告（破坏沉浸感）

### 6.4 LTV预估

| 用户类型 | 占比 | 月均付费 | LTV（12个月） |
|---------|------|---------|--------------|
| 免费用户 | 70% | $0 | $0（但提供广告收入和社交环境） |
| 小额付费 | 20% | $5 | $60（月卡+偶尔抽卡） |
| 中额付费 | 8% | $30 | $360（赛季通行证+定期抽卡） |
| 大额付费 | 2% | $150 | $1800（追求全收集） |

**综合LTV**：$0×70% + $60×20% + $360×8% + $1800×2% = $0 + $12 + $28.8 + $36 = **$76.8/用户**

## 七、技术实现评估

### 7.1 技术栈

| 项目 | 选择 | 理由 |
|------|------|------|
| 渲染 | Canvas 2D + WebGL（混合） | 2D俯视视角用Canvas，特效用WebGL |
| 物理 | Matter.js（轻量物理） | 机甲碰撞、子弹弹道、爆炸效果 |
| 输入 | 虚拟摇杆 + 手势 | 移动端标准方案 |
| 状态管理 | Redux + 自研ECS | Redux管理UI状态，ECS管理游戏实体 |
| 网络 | WebSocket | 实时PvP、公会战、聊天 |
| 存储 | IndexedDB + 服务器 | 本地缓存+云端存档 |

### 7.2 架构设计（可扩展性）

**部件系统（组件化）**：
```typescript
// 部件配置表（JSON，新增部件只需加配置）
interface PartConfig {
  id: string;
  name: string;
  slot: 'torso' | 'arm' | 'leg' | 'core' | 'head';
  weight: number;
  stats: {
    hp?: number;
    attack?: number;
    armor?: number;
    speed?: number;
    energy?: number;
  };
  synergy: string[]; // 触发协同效果的部件ID列表
  skill?: string; // 绑定的技能ID
}

// 部件管理器（运行时动态加载）
class PartManager {
  private parts: Map<string, PartConfig>;
  
  loadPart(config: PartConfig): void {
    this.parts.set(config.id, config);
  }
  
  getSynergy(partIds: string[]): SynergyEffect[] {
    // 自动计算当前装备的协同效果
  }
}
```

**为什么这样设计**：新增部件只需添加JSON配置，不需要改代码。策划可以自行配置新部件，程序只需审核配置。
