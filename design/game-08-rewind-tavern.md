## 一、世界观与叙事

### 1.1 世界背景

**"裂隙历"——没有时间的世界。**

你的酒馆坐落在时间的裂缝之中。门外不是街道，是无数个平行时间线的交汇点。顾客不是普通人——他们是来自不同时间线的灵魂，带着遗憾而来，寻求一杯能让他们暂时忘记的酒。

**你是"调酒师兼时间看守者"。** 你的酒不仅能醉人，还能让人看到"如果当初做了不同选择"的幻象。但这份能力有代价：每改变一次过去，现实就会产生裂缝。

**酒馆的规矩**：
- 只接待有"未了心愿"的灵魂
- 不干涉时间线（但你总是忍不住）
- 每天打烊时必须"清算因果"

**深层真相**：酒馆本身是一个囚笼——你是被时间法则囚禁的"修正者"，你的任务是修正时间线的错误。但你发现，真正需要修正的不是时间线，是时间法则本身。

### 1.2 核心叙事机制

**因果回溯**：
- 每天营业结束后，玩家获得"因果点"
- 可花费因果点回溯到任意之前的决策点，改变选择
- 改变过去会产生"时间悖论"：顾客消失、新事件出现、物价变动
- 某些灵魂只在特定"悖论级别"出现

**叙事碎片**：
- 每个灵魂都有自己的故事线（5-8段对话）
- 故事线之间有关联：A灵魂的故事会揭示B灵魂的真相
- 故事线有分支：玩家的选择决定灵魂的命运（留下/离开/消失）

**最终选择**：
- 收集足够多的"时间碎片"后，玩家发现酒馆的真相
- 选择1：关闭酒馆（释放所有灵魂，但自己永远留在时间裂缝）
- 选择2：成为新的时间法则（获得永恒但失去人性）
- 选择3：打破时间法则（世界混乱，但灵魂自由）

## 三、核心玩法

### 3.1 基础操作

**开店准备**：
- 拖拽安排今日菜单（3-5个菜位）
- 检查库存，补充食材
- 布置桌椅（位置影响顾客满意度）

**迎宾入座**：
- 顾客进门时，拖拽他们到合适座位
- 老人→安静角落，冒险者→热闹中央
- 连续正确匹配触发"连锁满意"倍率加成

**点单与上菜**：
- 顾客举手→点击接单→厨房自动制作→菜品完成后闪烁→拖拽上菜
- 上菜速度影响小费，超时顾客会离开并留下差评

**事件处理**：
- 随机事件弹出叙事卡片，左右滑动/点击选项选择
- 选择结果即时显现（接受诅咒酒桶→金币+50，但10分钟后卫兵搜查）

### 3.2 因果回溯系统（核心创新）

**因果点获取**：
- 每天营业结束获得1-3个因果点
- 达成特殊成就额外获得

**回溯操作**：
- 时间线可视化界面，看到今日所有决策节点
- 点击"回溯"→画面倒放特效→回到该节点→重新选择→快进到现在
- 观察变化：顾客消失/出现、物价变动、新事件触发

**悖论级别**：
| 级别 | 条件 | 效果 |
|------|------|------|
| 0 | 无回溯 | 正常世界 |
| 1 | 回溯1次 | 轻微变化，1-2个新事件 |
| 2 | 回溯2次 | 明显变化，顾客性格改变 |
| 3 | 回溯3次+ | 严重悖论，某些灵魂只能在悖论级别≥3时出现 |

**时间崩塌**：
- 每局最多回溯3次
- 过度回溯触发"时间崩塌"：本局提前结束，但保留发现的新信息
- 时间崩塌不是惩罚，是发现隐藏内容的手段

### 3.3 NPC AI系统

**行为树驱动**：

```
[Selector: 用餐流程]
├── [Sequence: 入座阶段]
│   ├── 寻找空座位（偏好：安静/热闹/靠窗）
│   ├── 移动到座位
│   └── 浏览菜单（黑板写入：意愿菜品列表）
├── [Sequence: 点餐阶段]
│   ├── 等待服务员
│   ├── 发出订单
│   └── 等待上菜（黑板：耐心值递减）
├── [Sequence: 用餐阶段]
│   ├── 等待食物到达
│   ├── 用餐（黑板：满意度动态计算）
│   └── 请求结账
└── [Sequence: 离开阶段]
    ├── 支付（小费=满意度×10%）
    ├── 留下评价（影响声誉）
    └── 离开（释放座位）
```

**情绪系统**：
- 每个NPC有情绪状态（开心/不满/愤怒/悲伤）
- 情绪影响行为：愤怒的NPC会大声抱怨影响其他顾客
- 情绪可通过"特殊调酒"改变

### 3.4 核心循环（单局内）

```
Step 1: 开店准备（2分钟）- 安排菜单、检查库存、布置桌椅
Step 2: 迎宾入座（动态）- 拖拽顾客到座位，匹配偏好
Step 3: 点单与上菜（主要阶段）- 接单→制作→上菜，管理多个顾客
Step 4: 随机事件插入（每局3-5次）- 叙事卡片选择，影响经营
Step 5: 特殊顾客剧情（每局0-2次）- 多段对话，影响关系值
Step 6: 打烊结算（1分钟）- 收入、满意度、解锁提示
Step 7: 因果回溯（可选）- 花费因果点改变过去决策
Step 8: 跨局成长 - 永久解锁新菜谱、顾客关系、剧情章节
```

## 增强设计 v2.1

> **设计修正目标**：消除"经营 or 视觉小说"的身份模糊，明确"经营为主、叙事为辅"的主次关系，让叙事成为经营表现的奖励层，而非并行的第二核心循环。

---

### v2.1-1 主次关系重构：经营为主，叙事为辅

#### 原问题
v1.0 设计中，因果回溯与叙事碎片、灵魂图鉴、4章主线剧情构成了一个与经营系统几乎平行的"叙事核心循环"，导致游戏身份模糊——玩家不知道该把时间花在调酒上，还是花在读故事上。

#### 修正方案

**"叙事 = 经营的奖励层"**

| 层级 | 内容 | 获取方式 |
|------|------|---------|
| 核心循环 | 酒馆经营（菜单/库存/员工/事件） | 玩家主动操作，Roguelike随机 |
| 奖励层 | 灵魂叙事片段 | 经营表现达标后自动解锁 |
| 终极目标 | 完整灵魂故事 + 主线真相 | 长期经营积累的成果 |

**每日结算流程（v2.1）**：
```
Step 1: 打烊 → 计算今日经营评分（S/A/B/C）
Step 2: 评分决定"叙事解锁额度"
        S = 解锁 3 个灵魂片段 + 1 个A级菜谱碎片
        A = 解锁 2 个灵魂片段
        B = 解锁 1 个灵魂片段
        C = 只解锁片段预览（无法阅读完整内容）
Step 3: 在已达好感度阈值的灵魂中，按优先级解锁
Step 4: 玩家进入"休息室"阅读已解锁的叙事内容
        （休息室是可选进入的，不强制打断经营节奏）
```

**关键原则**：
- 经营阶段 **绝不插入** 强制叙事（v1.0 的"特殊顾客剧情"改为非强制的"灵魂事件"）
- 叙事阅读发生在 **打烊后**，玩家可选择跳过，不影响次日经营
- 叙事解锁是 **经营的结果**，不是并行的目标

### v2.1-2 因果回溯重构：从"改变过去"到"经营纠错"

#### 原问题
v1.0 的因果回溯允许玩家改变任意过去决策，甚至影响叙事走向，导致：
- 叙事碎片化、非线性，玩家难以建立情感连接
- 悖论级别机制过于复杂（"某些灵魂只在悖论≥3时出现"）
- 经营和叙事的耦合过深，一个系统的操作会不可预测地影响另一个系统

#### 修正方案

**"回溯 = 经营纠错工具，不影响叙事"**

| 维度 | v1.0 | v2.1 |
|------|------|------|
| 回溯对象 | 任意过去决策 + 叙事选择 | 仅限经营决策（采购/装修/菜单/员工） |
| 对叙事的影响 | 改变灵魂命运、剧情分支 | **无影响**，叙事是线性解锁的 |
| 使用时机 | 任意时刻 | 仅每日打烊后，进入"复盘模式" |
| 资源消耗 | 因果点（每天1-3个） | 每日免费1次，额外次数用金币购买 |
| 核心目的 | 探索隐藏内容、改变故事 | 优化经营策略、学习机制 |

**"复盘模式"操作流程**：
```
Step 1: 打烊后，进入"今日复盘"界面
Step 2: 时间线可视化展示今日所有经营决策节点
        （如：09:15 购买诅咒酒桶 → 09:45 卫兵搜查事件）
Step 3: 玩家选择任意节点，点击"假设我当时..."
Step 4: 系统快进模拟：展示如果选择不同，今日营收会怎样变化
Step 5: 玩家可选择"采纳此策略"（明日生效）或"仅查看"
Step 6: 退出复盘，进入叙事解锁环节
```

**关键原则**：
- 回溯是 **"模拟推演"**，不是真正改变过去
- 推演结果只影响 **明日及以后的经营策略**，不修改已发生的叙事
- 叙事是 **单向线性推进的**，确保故事的情感累积和完整性

### v2.1-3 灵魂满意度系统：好感度驱动叙事解锁

#### 原问题
v1.0 的灵魂故事线解锁条件过于复杂（"关系值达标、特定事件触发、悖论级别要求"），玩家难以理解和规划。

#### 修正方案

**每个灵魂的统一解锁规则**：

| 属性 | 说明 |
|------|------|
| 灵魂好感度 | 0-100，通过经营行为提升 |
| 叙事片段数 | 每个灵魂 3-5 段 |
| 解锁阈值 | 好感度每达 25/50/75/100 解锁对应片段 |

**好感度获取途径（全部来自经营）**：

| 行为 | 好感度变化 | 说明 |
|------|-----------|------|
| 正确上菜（匹配偏好） | +5~10 | 灵魂有偏好的菜品/座位/氛围 |
| 满足特殊需求 | +10~15 | 如：安静座位、快速上菜、特定酒水 |
| 超时/上错菜 | -5~-10 | 失误会损害关系 |
| 每日首次接待 | +2 | 持续光顾累积好感 |
| 完美服务（无失误） | +5 | 单日该灵魂无负面事件 |

**灵魂偏好示例**：
```
灵魂"遗忘的骑士"：
- 偏好菜品：烈酒、烤肉
- 偏好座位：吧台（喜欢和其他顾客交谈）
- 特殊需求：上菜时陪他聊两句（点击触发简短对话）
- 厌恶：被安排在角落、酒水太淡
```

**叙事解锁与经营评分的挂钩**：
```
假设玩家今日经营评分 = A（可解锁2个片段）
假设今日好感度达标的灵魂有：
  - 遗忘的骑士（好感度 50 → 解锁第2段）
  - 哭泣的诗人（好感度 75 → 解锁第3段）
  - 迷失的商人（好感度 30 → 未达阈值）

则今日解锁：
  - 遗忘的骑士 第2段
  - 哭泣的诗人 第3段
  （2个片段，刚好用完A评分的额度）
```

### v2.1-4 评分系统简化：移除"悖论级别"，引入"每日经营评分"

#### 原问题
v1.0 的"悖论级别"机制复杂且与叙事系统深度耦合：
- 悖论级别 0-3，影响顾客性格、物价、灵魂出现条件
- 某些灵魂"只能在悖论级别≥3时出现"
- 过度回溯触发"时间崩塌"，提前结束本局

这导致系统过于复杂，玩家难以建立心智模型。

#### 修正方案

**简化为单一维度："每日经营评分"（S/A/B/C）**

| 评分 | 营收要求 | 顾客满意度 | 解锁奖励 |
|------|---------|-----------|---------|
| **S** | 达到日目标 120%+ | ≥90% | 3个灵魂片段 + 1个A级菜谱碎片 + 额外金币 |
| **A** | 达到日目标 100-119% | ≥80% | 2个灵魂片段 |
| **B** | 达到日目标 80-99% | ≥60% | 1个灵魂片段 |
| **C** | 低于日目标 80% 或满意度 <60% | — | 仅解锁片段预览（灰色，不可阅读） |

**评分计算方式**：
```
日目标营收 = 基础值 × 天数系数 × 难度系数
  - 基础值：第1天 500💰，每天递增 10%
  - 天数系数：连续经营天数加成（最多+30%）
  - 难度系数：根据玩家历史评分动态调整

顾客满意度 = Σ(单个顾客满意度) / 顾客总数
  - 单个顾客满意度 = 入座匹配(20%) + 上菜速度(30%) + 菜品质量(30%) + 特殊需求(20%)
```

**评分的作用范围**：
- 评分只影响 **当日的叙事解锁额度**
- 评分不影响 **次日经营**（无惩罚机制，鼓励继续尝试）
- 连续3天 S 评分触发 **"完美经营"奖励**：解锁一个隐藏灵魂
