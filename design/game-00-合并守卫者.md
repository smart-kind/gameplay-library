## 一、世界观与叙事

### 1.1 世界背景

**"元素纪元"第847年。**

世界由"元素大陆"构成——大地不是泥土，是凝固的元素能量。人类发现：通过特定的手势滑动，可以唤醒沉睡的元素方块，让它们合并升华为更强大的形态。

**"虚空裂隙"**打开了。来自次元之外的"侵蚀者"涌入大陆，它们吞噬元素能量，所到之处化为虚无。传统的军队无法抵抗——侵蚀者免疫物理攻击，只有纯粹元素能量才能伤害它们。

**玩家是"编织者"（Weaver）**—— rare bloodline 的后裔，天生拥有与元素方块共鸣的能力。你的使命：滑动合并元素方块，召唤元素守卫，抵御侵蚀者的入侵。

### 1.2 核心冲突

- **玩家**：编织者，守护元素大陆的最后希望
- **敌人**：虚空侵蚀者（分7种类型，各有特性）
- **深层冲突**：侵蚀者其实是上个纪元的编织者所化——他们过度追求元素力量，最终被反噬。玩家面临的诱惑是：要不要使用"禁忌合并"（ powerful but corrupting）？

### 1.3 叙事方式

**无过场动画，玩法中叙事**：
- **元素方块升级时的记忆碎片**：每次合并到Lv.4+，方块发光并播放一段"纪元记忆"（语音+画面）
- **敌人图鉴**：击败新类型侵蚀者后，解锁其背景故事（它们曾经是什么）
- **关卡环境变化**：前期是翠绿森林，中期是焦土废墟，后期是虚空裂隙边缘

## 三、核心玩法

### 3.1 基础循环（2048合并+塔防）

**合并规则**：
- 滑动屏幕，所有方块向该方向移动
- 相同数字方块碰撞时合并，数字×2，攻击力大幅跃升
- 每次滑动后，随机空位生成一个新的Lv.1方块

**塔防规则**：
- 每个方块是一个"元素守卫"，自动攻击路径上的敌人
- 攻击范围：以方块为中心的正方形区域（Lv.1=1.5格，Lv.4=3格）
- 攻击方式：发射元素弹（直线飞行，命中即伤害）

### 3.2 英雄系统（新增3A级系统）

**英雄选择**：

| 英雄 | 主动技能 | 被动技能 | 专属增益 |
|------|---------|---------|---------|
| 艾拉（火法师） | 陨石术：对全屏造成300%攻击力的伤害 | 火元素塔攻击力+20% | 合并时有10%概率触发额外爆炸 |
| 索林（冰战士） | 冰冻领域：冻结所有敌人3秒 | 冰元素塔攻击附带减速30% | 敌人移动速度-15% |
| 露娜（自然德鲁伊） | 生命之种：恢复2点生命，生成2个Lv.2方块 | 自然元素塔攻击时恢复生命 | 每波结束额外获得1张增益卡 |

**英雄升级**：
- 通过战斗获得英雄经验
- 升级解锁：新技能形态、被动增强、专属塔皮肤
- 最高等级：30级

### 3.3 符文系统（新增3A级系统）

**符文镶嵌**：
- 每个方块有1个符文槽（Lv.3+解锁）
- 符文提供额外效果：暴击、溅射、吸血、穿透等

| 符文 | 效果 | 稀有度 |
|------|------|--------|
| 烈焰符文 | 攻击时有20%概率触发爆炸（范围伤害） | 稀有 |
| 寒冰符文 | 攻击附带冰冻1秒 | 稀有 |
| 雷电符文 | 攻击弹射到附近2个敌人 | 史诗 |
| 虚空符文 | 攻击无视敌人50%防御 | 传说 |
| 生命符文 | 每次攻击恢复造成伤害10%的生命 | 稀有 |

**符文合成**：
- 3个同级符文可合成更高级符文
- 高级符文效果更强，附加属性更多

### 3.4 宠物系统（新增3A级系统）

**宠物助战**：

| 宠物 | 效果 | 获取方式 |
|------|------|---------|
| 小火龙 | 每5秒对随机敌人喷火（攻击力50%） | 新手赠送 |
| 冰晶蝶 | 每10秒冰冻最前方的敌人2秒 | 第10关解锁 |
| 雷鹰 | 每8秒对全屏敌人造成麻痹（攻击暂停1秒） | 抽卡获得 |
| 虚空兽 | 吞噬即将到达防御线的1个敌人（每波1次） | 赛季奖励 |

**宠物升级**：
- 喂食元素精华升级
- 升级提升效果频率和强度
- 宠物有亲密度系统，亲密度高时触发"共鸣"（效果增强50%）

### 3.5 敌人系统（7种侵蚀者）

| 敌人类型 | 特性 | 弱点 | 首次出现 |
|---------|------|------|---------|
| 虚空行者 | 基础敌人，血量低速度快 | 无 | 第1关 |
| 虚空护甲 | 高血量，物理减伤50% | 元素穿透 | 第3关 |
| 虚空飞翼 | 飞行单位，走空中路径 | 对空塔（Lv.4+自动对空） | 第5关 |
| 虚空治疗 | 为周围敌人恢复生命 | 优先击杀 | 第7关 |
| 虚空分裂 | 死亡时分裂为2个小怪 | 范围伤害 | 第10关 |
| 虚空隐形 | 隐形，只有Lv.5+塔能看见 | 高等级塔/侦查符文 | 第15关 |
| 虚空领主 | Boss，血量极高，有技能 | 集中火力+英雄技能 | 每5关 |

## 七、技术实现评估

| 项目 | 选择 | 理由 |
|------|------|------|
| 渲染 | Canvas 2D | 2D网格+简单特效 |
| 物理 | 无（自定义） | 敌人直线移动，弹道直线 |
| 状态管理 | Redux | 多系统（英雄+符文+宠物）需要结构化 |
| 网络 | REST API + WebSocket | 排行榜实时更新，公会战需要 |
| 存储 | IndexedDB | 大量关卡进度、英雄数据 |

**AI开发难度：4/5** — 多系统交织+网络同步，但核心逻辑清晰。

### v2.1-1 分屏双盘布局方案

#### 1.1 界面分区定义

| 区域 | 屏幕占比 | 尺寸（720×1280基准） | 功能 |
|------|---------|---------------------|------|
| **塔防战场** | 40% | 720×512 | 3条路径+防御线，纯展示+自动战斗 |
| **信息/技能栏** | 15% | 720×192 | 波次信息、英雄技能、召唤按钮、倍速控制 |
| **合并棋盘** | 45% | 720×576 | 4×4独立棋盘，玩家手动操作合并 |

```
┌─────────────────────────────────┐
│  塔防战场 (40%)                  │
│  ┌─────┐  ┌─────┐  ┌─────┐     │
│  │路径1│  │路径2│  │路径3│     │
│  │ →→→ │  │ →→→ │  │ →→→ │     │
│  │ 塔  │  │ 塔  │  │ 塔  │     │
│  │ →→→ │  │ →→→ │  │ →→→ │     │
│  └─────┘  └─────┘  └─────┘     │
│  ═══════════════════ 防御线     │
├─────────────────────────────────┤
│  信息/技能栏 (15%)               │
│  [波次3/10] [⚡召唤] [🔥技能] [⏩2x]│
├─────────────────────────────────┤
│  合并棋盘 (45%)                  │
│  ┌──┬──┬──┬──┐                  │
│  │ 1│ 2│  │  │  ← 玩家滑动操作   │
│  ├──┼──┼──┼──┤                  │
│  │  │ 4│  │  │                  │
│  ├──┼──┼──┼──┤                  │
│  │  │  │ 8│  │                  │
│  ├──┼──┼──┼──┤                  │
│  │  │  │  │  │                  │
│  └──┴──┴──┴──┘                  │
└─────────────────────────────────┘
```

#### 1.2 空间解耦原则

**合并棋盘与战场完全独立**：
- 合并棋盘上的方块**不直接等于**战场上的塔
- 合并棋盘是"资源池"，战场上的塔是"已部署单位"
- 玩家在合并盘上滑动合并，生成的方块暂存于"召唤队列"
- 点击"召唤"按钮后，将最高级方块转换为战场上的塔

**部署规则**：
- 每次召唤消耗1个合并盘上的方块（从队列中移除）
- 召唤时玩家点击战场上的空位（或已有塔的位置进行替换/升级）
- Lv.1方块不能直接召唤——必须至少合并到Lv.2才能召唤为有效战力

---

### v2.1-2 主次关系：资源决策层 vs 表现释放层

#### 2.1 合并盘 = 资源决策层

**核心决策**：
1. **何时召唤？** 现在召唤一个Lv.4，还是继续合并赌Lv.5？
2. **召唤哪个？** 队列中有Lv.3、Lv.4、Lv.5，优先召唤哪个？
3. **部署在哪？** 3条路径，哪条压力最大？哪里需要补伤害？

**合并盘操作流**：
```
滑动合并 → 生成高级方块 → 进入召唤队列 → 等待玩家决策 → 点击召唤 → 选择战场位置 → 部署为塔
```

#### 2.2 战场 = 表现释放层

**纯自动战斗**：
- 塔自动索敌、自动攻击
- 敌人沿固定路径移动
- 玩家无法直接操控塔（只能通过合并盘间接影响）

**战场信息反馈**：
- 实时显示3条路径的敌人密度（热力图或数字）
- 防御线血量实时变化
- 塔的DPS统计（帮助玩家决策下一波召唤什么）

#### 2.3 交互隔离设计

| 场景 | 合并盘 | 战场 |
|------|--------|------|
| 玩家滑动合并时 | ✅ 正常响应 | ✅ 战斗继续，不受影响 |
| 敌人进攻波次中 | ✅ 仍可操作 | ✅ 不暂停 |
| 波次间隙 | ✅ 操作时间充裕 | ⏸️ 自动暂停 |
| 召唤按钮点击 | 弹出队列选择 | 高亮可部署位置 |

### v2.1-3 数值框架重校准

#### 3.1 核心矛盾分析

**旧问题**：合并盘是指数增长（2^n），战场敌人HP是线性增长 → 后期Lv.6+方块碾压，前期Lv.1-2毫无用处。

**新方案**：引入"合并效率"机制，让高等级方块的"战力性价比"递减，迫使玩家在"赌大"和"实用"之间做选择。

#### 3.2 合并效率机制

**召唤冷却表**（每次召唤后的全局冷却）：

| 召唤方块等级 | 攻击力 | 召唤冷却时间 | DPS/冷却比 |
|-------------|--------|-------------|-----------|
| Lv.2 | 40 | 0秒 | 基准 |
| Lv.3 | 100 | 2秒 | 效率125% |
| Lv.4 | 280 | 5秒 | 效率112% |
| Lv.5 | 800 | 12秒 | 效率83% |
| Lv.6 | 2400 | 30秒 | 效率67% |
| Lv.7 | 8000 | 75秒 | 效率53% |

**设计意图**：
- Lv.3-4是"甜点区"——召唤快、伤害足、性价比高
- Lv.5+是"决战武器"——伤害爆炸但召唤慢，不能依赖
- 玩家需要在"频繁召唤Lv.4稳定输出"和"憋Lv.6一波爆发"之间权衡

#### 3.3 敌人HP曲线重调

```
敌人HP = 基础HP × 波次系数 × 路径系数

基础HP（虚空行者）: 50
波次系数: 1.15^波次数（指数增长，但温和）
路径系数: 路径1=1.0, 路径2=1.2, 路径3=0.9（诱导玩家分散注意力）
```

**示例数值**：

| 波次 | 路径1敌人HP | 路径2敌人HP | 路径3敌人HP | 推荐应对 |
|------|------------|------------|------------|---------|
| 1 | 58 | 69 | 52 | 1个Lv.2塔 |
| 5 | 101 | 121 | 91 | 2个Lv.3塔 |
| 10 | 202 | 243 | 182 | 3个Lv.4塔+英雄技能 |
| 20 | 818 | 982 | 736 | 混合部署+符文配合 |
| 50 | 5418 | 6501 | 4876 | 需要Lv.6+精准部署 |

#### 3.4 棋盘容量与敌人数量匹配

**关键设计**：合并盘的4×4=16格，最多同时存在16个方块。每次滑动生成1个新方块，召唤消耗1个方块。

**经济平衡**：
- 平均3-4次滑动可以生成1个Lv.3方块（可召唤）
- 单次滑动耗时约2秒（思考+操作）
- 因此**自然产出速率**：约1个Lv.3/8秒
- 波次间隙通常为15-30秒 → 玩家可以合成1-3个Lv.3+方块用于下一波

### v2.1-4 战术暂停系统

#### 4.1 自动暂停触发条件

| 触发条件 | 行为 | 玩家可做的事 |
|---------|------|------------|
| 一波敌人全部被消灭 | 战场暂停，合并盘继续可用 | 疯狂合并，为下一波做准备 |
| 波次间隙倒计时 | 显示"下一波将在X秒后到来" | 召唤、调整部署、思考策略 |
| 玩家手动点击暂停 | 全部暂停（包括合并盘） | 查看战场信息、规划 |

#### 4.2 波次进行中 = 不暂停（多任务考验）

**设计理念**：
- 合并盘始终可操作，但玩家注意力被分流
- 高手可以在敌人进攻时继续合并，菜鸟可以专注看战场
- "操作上限"由玩家的多任务能力决定，而非系统设计

**压力递增**：
- 前期波次（1-10）：敌人少、走得慢，合并时间充裕
- 中期波次（11-30）：敌人密度增加，需要边合并边看战场
- 后期波次（31+）：多条路径同时高压，必须提前在间隙准备好

#### 4.3 手动召唤 vs 自动召唤

**默认模式**：手动召唤（玩家控制节奏）

**可选解锁**：
- 编织者等级15解锁"自动召唤"——当召唤队列中有Lv.3+方块时，自动部署到压力最大的路径
- 自动召唤有5秒延迟，给手动玩家反应时间
- 自动召唤优先级：路径压力 > 空位数量 > 方块等级

### v2.1-5 增强后的核心循环

```
【波次间隙 - 准备阶段】
   ↓ 战场暂停，合并盘可用
玩家滑动合并方块 → 生成Lv.3+方块 → 进入召唤队列
   ↓
点击"召唤" → 选择战场位置 → 部署为塔
   ↓
【波次进行 - 战斗阶段】
   ↓ 战场不暂停，合并盘仍可用
敌人沿3条路径进攻 ← 塔自动攻击 → 玩家可继续合并补充
   ↓
敌人全灭 → 自动触发间隙暂停 → 回到准备阶段
   ↓
每5波 → Boss战 → 需要预留高等级方块+英雄技能
```
