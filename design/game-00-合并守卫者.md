## 一、世界观与叙事

### 1.1 世界背景

**"元素纪元"第847年。**

世界由"元素大陆"构成——大地不是泥土，是凝固的元素能量。人类发现：通过特定的手势滑动，可以唤醒沉睡的元素方块，让它们合并升华为更强大的形态。

**"虚空裂隙"**打开了。来自次元之外的"侵蚀者"涌入大陆，它们吞噬元素能量，所到之处化为虚无。传统的军队无法抵抗——侵蚀者免疫物理攻击，只有纯粹元素能量才能伤害它们。

**玩家是"编织者"（Weaver）**—— rare bloodline 的后裔，天生拥有与元素方块共鸣的能力。你的使命：滑动合并元素方块，召唤元素守卫，抵御侵蚀者的入侵。

### 1.2 核心冲突

- **玩家**：编织者，守护元素大陆的最后希望
- **敌人**：虚空侵蚀者（分7种类型，各有特性）
- **深层冲突**：侵蚀者其实是上个纪元的编织者所化——他们过度追求元素力量，最终被反噬。玩家面临的诱惑是：要不要使用"禁忌合并"（ powerful but corrupting）？

### 1.3 叙事方式

**无过场动画，玩法中叙事**：
- **元素方块升级时的记忆碎片**：每次合并到Lv.4+，方块发光并播放一段"纪元记忆"（语音+画面）
- **敌人图鉴**：击败新类型侵蚀者后，解锁其背景故事（它们曾经是什么）
- **关卡环境变化**：前期是翠绿森林，中期是焦土废墟，后期是虚空裂隙边缘

## 三、核心玩法

### 3.1 基础循环（2048合并+塔防）

**合并规则**：
- 滑动屏幕，所有方块向该方向移动
- 相同数字方块碰撞时合并，数字×2，攻击力大幅跃升
- 每次滑动后，随机空位生成一个新的Lv.1方块

**塔防规则**：
- 每个方块是一个"元素守卫"，自动攻击路径上的敌人
- 攻击范围：以方块为中心的正方形区域（Lv.1=1.5格，Lv.4=3格）
- 攻击方式：发射元素弹（直线飞行，命中即伤害）

### 3.2 英雄系统（新增3A级系统）

**英雄选择**：

| 英雄 | 主动技能 | 被动技能 | 专属增益 |
|------|---------|---------|---------|
| 艾拉（火法师） | 陨石术：对全屏造成300%攻击力的伤害 | 火元素塔攻击力+20% | 合并时有10%概率触发额外爆炸 |
| 索林（冰战士） | 冰冻领域：冻结所有敌人3秒 | 冰元素塔攻击附带减速30% | 敌人移动速度-15% |
| 露娜（自然德鲁伊） | 生命之种：恢复2点生命，生成2个Lv.2方块 | 自然元素塔攻击时恢复生命 | 每波结束额外获得1张增益卡 |

**英雄升级**：
- 通过战斗获得英雄经验
- 升级解锁：新技能形态、被动增强、专属塔皮肤
- 最高等级：30级

### 3.3 符文系统（新增3A级系统）

**符文镶嵌**：
- 每个方块有1个符文槽（Lv.3+解锁）
- 符文提供额外效果：暴击、溅射、吸血、穿透等

| 符文 | 效果 | 稀有度 |
|------|------|--------|
| 烈焰符文 | 攻击时有20%概率触发爆炸（范围伤害） | 稀有 |
| 寒冰符文 | 攻击附带冰冻1秒 | 稀有 |
| 雷电符文 | 攻击弹射到附近2个敌人 | 史诗 |
| 虚空符文 | 攻击无视敌人50%防御 | 传说 |
| 生命符文 | 每次攻击恢复造成伤害10%的生命 | 稀有 |

**符文合成**：
- 3个同级符文可合成更高级符文
- 高级符文效果更强，附加属性更多

### 3.4 宠物系统（新增3A级系统）

**宠物助战**：

| 宠物 | 效果 | 获取方式 |
|------|------|---------|
| 小火龙 | 每5秒对随机敌人喷火（攻击力50%） | 新手赠送 |
| 冰晶蝶 | 每10秒冰冻最前方的敌人2秒 | 第10关解锁 |
| 雷鹰 | 每8秒对全屏敌人造成麻痹（攻击暂停1秒） | 抽卡获得 |
| 虚空兽 | 吞噬即将到达防御线的1个敌人（每波1次） | 赛季奖励 |

**宠物升级**：
- 喂食元素精华升级
- 升级提升效果频率和强度
- 宠物有亲密度系统，亲密度高时触发"共鸣"（效果增强50%）

### 3.5 敌人系统（7种侵蚀者）

| 敌人类型 | 特性 | 弱点 | 首次出现 |
|---------|------|------|---------|
| 虚空行者 | 基础敌人，血量低速度快 | 无 | 第1关 |
| 虚空护甲 | 高血量，物理减伤50% | 元素穿透 | 第3关 |
| 虚空飞翼 | 飞行单位，走空中路径 | 对空塔（Lv.4+自动对空） | 第5关 |
| 虚空治疗 | 为周围敌人恢复生命 | 优先击杀 | 第7关 |
| 虚空分裂 | 死亡时分裂为2个小怪 | 范围伤害 | 第10关 |
| 虚空隐形 | 隐形，只有Lv.5+塔能看见 | 高等级塔/侦查符文 | 第15关 |
| 虚空领主 | Boss，血量极高，有技能 | 集中火力+英雄技能 | 每5关 |

## 七、技术实现评估

| 项目 | 选择 | 理由 |
|------|------|------|
| 渲染 | Canvas 2D | 2D网格+简单特效 |
| 物理 | 无（自定义） | 敌人直线移动，弹道直线 |
| 状态管理 | Redux | 多系统（英雄+符文+宠物）需要结构化 |
| 网络 | REST API + WebSocket | 排行榜实时更新，公会战需要 |
| 存储 | IndexedDB | 大量关卡进度、英雄数据 |

**AI开发难度：4/5** — 多系统交织+网络同步，但核心逻辑清晰。
