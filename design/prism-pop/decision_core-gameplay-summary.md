# 彩棱碰碰 (Prism Pop) - 核心玩法总结

**文档角色**：决策  
**日期**：2026-08-15  
**阶段**：核心玩法确认（阶段性成果）

---

## 一、游戏概述

**一句话说明**：用画圈的方式玩三消——圈中宝石让它们组合成更强大的新宝石。

**核心创新**：将King.com验证十年的三消组合机制，嫁接到"画圈收集"的操作方式上。

---

## 二、核心玩法

### 2.1 基础操作

| 步骤 | 玩家操作 | 结果 |
|------|---------|------|
| 1 | 在网格上画路径（上下左右） | 留下光轨 |
| 2 | 路径闭合形成圈 | 圈中宝石被收集 |
| 3 | 宝石组合判定 | 根据颜色组合产生新宝石 |
| 4 | 新宝石飞到棋盘空位 | 可以被再次圈中 |
| 5 | 引爆成功后清空光轨 | 棋盘清空，重新开始 |

### 2.2 组合规则（借鉴King.com三消模式）

| 圈中的宝石 | 产生的结果 | 效果 |
|-----------|-----------|------|
| 3个同色（如3红） | 高级红宝石 | 下次圈中时触发特殊效果（如范围消除） |
| 4个同色 | 超级红宝石 | 更强的效果 |
| 5个同色 | 终极红宝石 | 最强效果 |
| 红+绿+蓝（混色） | 彩虹宝石 | 特殊能力（如清屏） |
| 其他杂色（不足3个同色） | 普通收集 | 分数较少，相当于"清场" |

**关键设计**：
- 组合产生**新宝石**（飞到棋盘新位置），不是道具
- 新宝石可以被再次圈中，形成"组合→新宝石→再组合"的循环
- 玩家可以主动"清场"（圈杂色宝石），为后续组合做准备

### 2.3 行动力系统

| 机制 | 说明 |
|------|------|
| **基础行动力** | 一次绘制路径最多30格 |
| **行动力宝石** | 圈中闪电宝石等特殊宝石，增加行动力（如+20格） |
| **策略变化** | 玩家可以选择"快速清场"或"积攒行动力后画大圈" |

**设计原则**：
- 不按时间算，按步数算（避免时间压力导致新手流失）
- 行动力可以通过特殊宝石增加（提供策略深度）
- 行动力用完后，当前回合结束，光轨清空

## 三、关键决策：去掉虹化机制

### 3.1 原设计

画圈成功后进入"虹化状态"（3步自由移动，可以穿越光轨）。

### 3.2 问题

| 问题 | 影响 |
|------|------|
| 理解成本高 | 玩家不知道"变成彩虹色"意味着"可以穿越光轨"，需要教程解释 |
| 技术复杂度高 | 8字形路径、自相交、多闭环判断，都是计算几何难题 |
| 违背设计原则 | 游戏应该"一看就会"，不需要解释 |

### 3.3 决策

**去掉虹化，用"引爆后清空光轨"替代。**

**理由**：
- 最简单 — 引爆成功 = 清空棋盘 = 重新开始
- 最直观 — 玩家一看就懂，不需要解释
- 节奏感强 — 紧张（画圈）→ 释放（引爆+清空）→ 新的紧张

---

## 四、核心循环

**画圈（紧张）→ 引爆（释放）→ 清空（喘息）→ 重新画圈（新的紧张）**

这个节奏让游戏有张有弛，但所有概念都"一看就会"。

## 六、设计原则

1. **一看就会** — 不需要教程，玩家凭直觉就能玩
2. **策略深度** — 简单规则下产生复杂的策略选择
3. **视觉爽感** — 组合动画是核心体验，要足够炫
4. **渐进式学习** — 前10关只教基础组合，后续逐步加新规则
