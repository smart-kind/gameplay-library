## 一、世界观与叙事

### 1.1 世界背景

**"音律纪元"——共振历第847年。**

世界不是由物质构成的，是由"频率"构成的。每个人、每个物体、每座山都有自己独特的共振频率。当频率同步时，万物和谐；当频率冲突时，混沌入侵。

**"失调者"（Dissonant）**出现了——他们是频率被扭曲的存在，会吞噬周围的和谐，将一切拖入寂静的深渊。传统的武器对它们无效——只有与自己的频率完美共振，才能造成伤害。

**玩家是"调音师"（Tuner）**—— 拥有感知万物频率的 rare 能力者。你的使命：跟随音乐的节拍战斗，维持自己的共振，击败失调者，找到"原初频率"——那个能修复世界的终极音符。

### 1.2 核心冲突

- **玩家**：调音师，频率的守护者
- **敌人**：失调者，被扭曲的频率实体
- **深层冲突**：失调者其实是上一个纪元的调音师——他们过度追求力量，强行改变自身频率，最终被反噬。玩家面临的诱惑是：要不要使用"禁忌调音"（瞬间变强但永久失调）？

### 1.3 叙事方式

**玩法即叙事**：
- **共振槽的光芒**：槽满时角色发光，暗示"你正在成为你曾经对抗的东西"
- **敌人外形**：失调者的形态暗示它们曾经是什么（曾经的小提琴手→弦状的怪物）
- **关卡音乐**：每个关卡的音乐风格暗示场景背景（古典乐=古老的殿堂，电子乐=未来的废墟）
- **Boss战**：Boss的攻击模式与它的"生前"有关（钢琴家Boss用琴键般的攻击节奏）

## 三、核心玩法

### 3.1 基础操作

**移动**：虚拟摇杆控制角色移动（不绑定节拍，自由移动）

**攻击**：点击攻击按钮，角色朝面向方向攻击
- **在节拍上攻击**：伤害×2，共鸣槽+5%
- **偏离节拍攻击**：基础伤害，不增加共鸣槽

**闪避**：滑动屏幕或点击闪避按钮
- **在敌人攻击前一拍闪避**：完美闪避，时间微缓0.2秒，共鸣槽+10%
- **普通闪避**：无额外收益

**技能**：共鸣槽>50%时可释放，必须在节拍上释放

### 3.2 共鸣槽系统（核心创新）

| 状态 | 共鸣槽值 | 效果 |
|------|---------|------|
| 失调 | <20% | 伤害-30%，移动速度-20%，屏幕边缘发红警告 |
| 正常 | 20-79% | 正常战斗 |
| 共振 | 80-99% | 攻击附带雷电链，判定窗口+20% |
| **共鸣** | **100%** | **可激活共鸣状态**：无敌帧延长，BGM加入额外音轨，持续10秒 |

**共鸣槽变化规则**：
- 节拍上攻击：+5%
- 完美闪避：+10%
- 击杀敌人：+15%
- 偏离节拍攻击：-3%
- 被击中：-10%
- 持续不操作（>3秒）：-2%/秒

**共鸣状态（激活后）**：
- 共鸣槽以-5%/秒衰减
- 衰减至0时状态结束
- 状态期间：攻击附带雷电链、闪避产生残影、BGM加入电吉他solo

### 3.3 战斗系统

**攻击类型**：

| 武器 | 攻击方式 | 节拍加成 |
|------|---------|---------|
| 音刃（剑） | 近战斩击，范围1格 | 节拍上：斩击轨迹延长，伤害×2 |
| 韵律弓 | 远程射击，自动瞄准最近敌人 | 节拍上：箭矢穿透，伤害×2 |
| 节拍锤 | 近战重击，范围2格，攻速慢 | 节拍上：冲击波，伤害×2 |

**敌人类型**：

| 敌人 | 攻击节奏 | 弱点 |
|------|---------|------|
| 失调行者 | 每2拍攻击一次 | 连续节拍攻击可打断 |
| 失调射手 | 每4拍射击一次 | 射击前有明显蓄力音 |
| 失调骑士 | 每3拍冲锋一次 | 冲锋方向固定，可预判闪避 |
| 钢琴家Boss | 攻击对应琴键音，玩家可"听"出攻击模式 | 副歌阶段攻击加快 |

**Boss战设计**：
- 每个Boss对应一种音乐风格（古典/电子/摇滚/爵士）
- 战斗分阶段：前奏→主歌→副歌→桥段
- 副歌阶段BPM加快，攻击频率提升，但共鸣槽积累速度也提升
- 桥段阶段可能切换拍号（4/4→3/4），改变节奏模式

### 3.4 核心循环（单局内）

```
Step 1: 进入关卡，前4拍只有节拍器，建立BPM感知
Step 2: 遭遇第一批敌人（失调行者），练习节拍攻击
Step 3: 引入失调射手，需要边移动边攻击边闪避
Step 4: 多敌人群战，管理多个敌人的攻击节奏
Step 5: 共鸣槽积累至80%，准备进入共振状态
Step 6: 激活共鸣状态，高强度输出窗口
Step 7: Boss战，分阶段对应歌曲段落
Step 8: 击败Boss，结算（节拍准确率、连击数、共鸣维持时长）
```

## 七、技术实现评估

| 项目 | 选择 | 理由 |
|------|------|------|
| 渲染 | Canvas 2D + WebGL特效 | 2D俯视角+粒子特效 |
| 音频 | Web Audio API | 精确节拍检测+低延迟 |
| 输入 | Pointer Events + 时间戳优化 | 毫秒级判定 |
| 状态管理 | ECS架构 | 大量实体高效处理 |
| 节拍检测 | 离线预处理 + 现成库 | 运行时O(1)查询 |

**AI开发难度：4/5** — 核心难点是音频-渲染-输入三时间域同步，但技术方案已明确。
