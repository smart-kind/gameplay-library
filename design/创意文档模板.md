# 游戏创意文档模板 v1.0

> 每个游戏创意必须包含以下全部字段，缺一不可。字段内容决定评分是否有依据。

---

## 一、基础信息

| 字段 | 说明 |
|------|------|
| **游戏名称** | 中文名 + 英文名 |
| **核心组合** | 两个（或三个）机制的融合，如「2048合并 + 塔防」 |
| **一句话描述** | 30字以内，说清玩家做什么 |
| **目标平台** | Mobile (iOS+Android) / Web / PC |
| **预估单局时长** | 2-5分钟 / 5-10分钟 / 10分钟+ |
| **预估开发周期** | AI构建需要几天 / 几周 |

---

## 二、视觉与布局（必须描述）

### 2.1 屏幕分区
用文字描述整个游戏画面怎么分区的。例如：

```
┌─────────────────────────────┐
│  顶部状态栏：波次 3/5 | 金币 120 | 生命 ❤❤❤   │
├─────────────────────────────┤
│                             │
│      主游戏区（4×4网格）      │
│      数字方块在这里滑动合并      │
│                             │
├─────────────────────────────┤
│  底部战斗区：防御线 | 敌人进攻路径 │
└─────────────────────────────┘
```

### 2.2 关键视觉元素
- 玩家控制什么？长什么样？
- 敌人在哪里出现？怎么移动？长什么样？
- 背景是什么？动态还是静态？

---

## 三、核心玩法（必须详细）

### 3.1 玩家输入
- 玩家能做什么操作？（点击/滑动/长按/拖拽/输入文字）
- 操作区域在哪里？
- 操作反馈是什么？（音效/震动/粒子效果）

### 3.2 游戏实体
- 有哪些实体？（玩家角色/敌人/道具/方块/卡牌）
- 每个实体的属性？（血量/攻击力/速度/等级）
- 实体之间怎么互动？

### 3.3 胜负条件
- 怎么算赢？（到达出口/消灭所有敌人/存活N波/达到目标分数）
- 怎么算输？（血量归零/时间耗尽/敌人到达底线）
- 有没有三星/评分系统？

### 3.4 核心循环（单局内）
用步骤描述玩家一局内的体验：

```
Step 1: 观察当前盘面/局势
Step 2: 执行核心操作（滑动/点击/选择）
Step 3: 系统反馈（合并成功/消除/召唤/战斗结算）
Step 4: 敌人行动/环境变化
Step 5: 评估结果，进入下一轮
```

---

## 四、局内成长系统（必须描述）

### 4.1 单局内玩家如何变强
- 成长载体是什么？（数字升级/卡牌选择/装备购买/技能解锁）
- 成长节奏？（每波结束后？每回合？连续消除触发？）
- 成长感知？（数值可见提升？新能力解锁？视觉效果变化？）

### 4.2 难度递进
- 分几个阶段？（教学期 / 成长期 / 挑战期 / Boss期）
- 每个阶段的新变量？（新敌人类型 / 新机制 / 限制条件）
- 难度曲线？（线性递增 / 阶梯式 / 波峰波谷）

---

## 五、Meta Game（必须详细）

### 5.1 局外持久成长
- 玩家跨局保留什么？（金币 / 经验 / 解锁内容 / 收集品）
- 成长线有几条？（角色等级 / 建筑升级 / 卡牌收集 / 成就）
- 每日/周期内容？（每日挑战 / 赛季 / 限时活动）

### 5.2 解锁系统
- 解锁什么？（新角色 / 新皮肤 / 新模式 / 新难度）
- 解锁条件？（达到等级 / 完成成就 / 收集碎片 / 付费）

### 5.3 社交/竞技
- 有没有排行榜？（全球 / 好友 / 周榜）
- 有没有分享机制？（战绩分享 / 求助 / 邀请）
- 有没有对战？（异步 / 实时）

---

## 六、广告变现设计（必须描述）

### 6.1 广告插入点
列出所有广告插入时机：

| 时机 | 广告类型 | 玩家情绪 | 是否打断核心玩法 |
|------|---------|---------|----------------|
| 关卡完成 | 插屏 | 成就感，正向 | 否（自然断点） |
| 关卡失败 | 激励视频（复活） | 遗憾，渴望继续 | 否（提供选择） |
| 每X波结束 | 插屏/横幅 | 短暂休息 | 否（自然断点） |
| 商店/升级 | 激励视频（双倍） | 期待收益 | 否（Meta界面） |

### 6.2 激励视频场景
- 复活继续（失败后看广告，保持当前进度）
- 双倍奖励（关卡结束后金币×2）
- 免费抽奖（看广告获得一次抽卡/开宝箱）
- 加速解锁（看广告跳过等待时间）
- 每日奖励翻倍（看广告领双倍每日登录奖励）

### 6.3 付费点（IAP，可选）
- 去广告（一次性购买，移除所有插屏）
- 月卡（每日额外金币/体力）
- 礼包（限时优惠，含大量资源）

---

## 七、技术实现评估

### 7.1 技术栈
- 2D / 3D？
- 是否需要物理引擎？（Box2D / 自研简化 / 不需要）
- 是否需要网络？（纯单机 / 排行榜同步 / 实时对战）
- 数据存储？（本地localStorage / 云端存档）

### 7.2 AI开发难度判断
- 核心逻辑复杂度？（简单状态机 / 中等算法 / 复杂AI）
- 是否有现成的开源参考？（类似游戏的开源代码）
- 预估AI生成后需要多少人工调整？

## 使用说明

1. **先生成完整描述，再评分**。没有描述的维度，评分为空或标为"N/A"。
2. **评分必须引用上文具体描述**。例如："受众广度=5，因为目标平台为全平台Mobile，核心操作为单指点击，与愤怒的小鸟一致（知识库degree=4808）"。
3. **Meta Game不可省略**。即使简单也要写清楚："目前仅设计单局，无局外系统"也是一种描述。
4. **广告插入点必须具体到秒**。例如："每波结束（约90秒）弹插屏"，而非"关卡结束插广告"。
