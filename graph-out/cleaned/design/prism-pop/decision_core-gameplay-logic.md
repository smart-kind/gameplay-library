# 彩棱碰碰 (Prism Pop) - 核心玩法逻辑

**文档角色**：决策（策划）  
**日期**：2026-08-15  
**阶段**：核心玩法确认（阶段性成果）

---

## 一、游戏目标

**一句话**：用画圈的方式玩三消——圈中宝石让它们组合成更强大的新宝石。

**核心创新**：将King.com验证十年的三消组合机制，嫁接到"画圈收集"的操作方式上。

---

## 二、核心机制

### 2.1 画圈操作

**玩家操作**：
1. 在网格上移动（上下左右）
2. 经过的格子留下光轨
3. 路径闭合形成圈 → 触发引爆

**关键规则**：
- 路径不能交叉（碰到光轨就停止）
- 一次绘制最多30格（基础行动力）
- 引爆成功后，所有光轨清空

### 2.2 宝石系统

**基础宝石**（5种颜色）：
| 颜色 | 视觉 | 说明 |
|------|------|------|
| 红色 | 红宝石 | 基础宝石 |
| 蓝色 | 蓝宝石 | 基础宝石 |
| 绿色 | 绿宝石 | 基础宝石 |
| 黄色 | 黄宝石 | 基础宝石 |
| 紫色 | 紫宝石 | 基础宝石 |

**特殊宝石**：
| 类型 | 视觉 | 效果 |
|------|------|------|
| 闪电宝石 | 带闪电标志 | 圈中后+20行动力 |
| 炸弹宝石 | 带爆炸标志 | 圈中后消除周围8格 |
| 彩虹宝石 | 全彩旋转光晕 | 圈中后清屏 |

### 2.3 组合规则

**核心逻辑**：圈中宝石后，根据颜色组合产生新宝石。

| 圈中的宝石 | 产生的结果 | 效果 |
|-----------|-----------|------|
| 3个同色（如3红） | 高级红宝石 | 下次圈中时，范围消除（3×3） |
| 4个同色 | 超级红宝石 | 下次圈中时，十字消除（整行+整列） |
| 5个同色 | 终极红宝石 | 下次圈中时，全屏消除同色 |
| 红+绿+蓝（混色） | 彩虹宝石 | 下次圈中时，清屏 |
| 其他杂色（不足3个同色） | 普通收集 | 分数较少，不触发组合 |

**组合流程**：
1. 玩家画圈闭合
2. 系统检查圈内宝石的颜色组合
3. 如果匹配组合规则 → 产生新宝石
4. 新宝石飞到棋盘随机空位
5. 新宝石可以被再次圈中（触发特殊效果）

### 2.4 行动力系统

**基础规则**：
- 一次绘制路径最多30格（基础行动力）
- 行动力用完后，当前回合结束，光轨清空

**行动力宝石**：
- 圈中闪电宝石 → +20行动力
- 可以叠加（如圈中2个闪电宝石 → +40行动力）

**策略选择**：
- 快速清场：用小圈快速收集宝石
- 积攒行动力：先圈闪电宝石，再画大圈凑组合

---

## 三、游戏节奏

**核心循环**：
```
画圈（紧张）→ 引爆（释放）→ 清空（喘息）→ 重新画圈（新的紧张）
```

**节奏设计**：
- 每个回合有明确的开始和结束
- 引爆成功 = 奖励 = 清空棋盘
- 玩家不需要等待，可以立即开始下一回合

---

## 四、关卡设计原则

### 4.1 宝石分布

**必须保证**：
- 每关至少有2-3组"可凑成的组合"
- 同色宝石不能被围墙完全隔开
- 特殊宝石（闪电、炸弹）随机分布，提供策略选择

**难度曲线**：
| 关卡 | 宝石种类 | 组合规则 | 目标 |
|------|---------|---------|------|
| 1-5 | 2种（红+蓝） | 3同色→高级 | 教学关，让玩家熟悉画圈 |
| 6-10 | 3种（红+蓝+绿） | 3同色→高级 | 引入组合概念 |
| 11-15 | 4种（红+蓝+绿+黄） | 3同色+4同色 | 引入高级组合 |
| 16-20 | 5种（全色） | 3同色+4同色+混色 | 引入彩虹组合 |
| 21+ | 5种+特殊宝石 | 全部组合规则 | 完整玩法 |

### 4.2 关卡目标

**目标类型**：
1. **收集目标**：收集X个红色宝石
2. **分数目标**：达到X分
3. **组合目标**：凑出X个高级宝石

**关卡结束条件**：
- 达成目标 → 过关
- 行动力用完且无法达成目标 → 失败

## 五、关键决策记录

### 5.1 去掉虹化机制

**原设计**：画圈成功后进入"虹化状态"（3步自由移动，可以穿越光轨）。

**问题**：
- 理解成本高（需要解释"可以穿越光轨"）
- 技术复杂度高（8字形路径、自相交等边界case）
- 违背"一看就会"的设计原则

**决策**：去掉虹化，用"引爆后清空光轨"替代。

**理由**：
- 最简单 — 引爆成功 = 清空棋盘 = 重新开始
- 最直观 — 玩家一看就懂，不需要解释
- 节奏感强 — 紧张（画圈）→ 释放（引爆+清空）→ 新的紧张

### 5.2 行动力按步数算，不按时间算

**原设计**：光轨按时间衰减（90秒后消失）。

**问题**：
- 时间压力导致新手流失
- 无法体现策略深度

**决策**：行动力按步数算（基础30格），可通过特殊宝石增加。

**理由**：
- 没有时间压力，新手友好
- 可以通过闪电宝石增加行动力，提供策略选择
- 玩家可以"慢思考"，规划最优路径

### 5.3 组合产生新宝石，不是道具

**决策**：组合产生新宝石（飞到棋盘新位置），不是立即使用的道具。

**理由**：
- 新宝石有视觉反馈（"带亮光的红宝石"），道具只是功能
- 新宝石可以再次被圈中，形成"组合→新宝石→再组合"的循环
- 新宝石的稀有度可以驱动收集欲（"我要收集所有类型的组合宝石"）

---

## 六、设计原则

1. **一看就会** — 不需要教程，玩家凭直觉就能玩
2. **策略深度** — 简单规则下产生复杂的策略选择
3. **视觉爽感** — 组合动画是核心体验，要足够炫
4. **渐进式学习** — 前10关只教基础组合，后续逐步加新规则
