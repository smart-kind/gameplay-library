# 幽光海途 (Luminous Trail)

> 引导发光生物在深海中穿行——你留下的光迹既是护盾也是牢笼。

## 画面与场景

游戏发生在一个**深海洞穴**中。俯视角，网格化的海底地形——深靛蓝色的背景上散布着岩石暗柱（不可通过），微小的浮游粒子在黑暗中缓缓飘动，营造出神秘而压抑的海底氛围。

玩家控制的是一只**幽光水母**——一枚拳头大小的青绿色发光体，像深海中一盏孤独的灯。它经过的每一格都会在海底留下**生物荧光轨迹**——半透明的青绿色光带，缓慢明灭，像呼吸一样。这条光迹是活的，是美的，同时也是你的困境。

海底散布着**金色浮游生物**——小而密的光点，像沉入深海的星屑。它们是唯一的资源来源。

两种掠食者在黑暗中巡游：
- **深海鳗鱼**：暗红色的流线形体，移动缓慢但路径可预测，像巡逻的潜艇。
- **暗影章鱼**：深紫色的团状体，移动更快，会主动追踪玩家，触手在身后拖出暗紫色的残影。

当"脉冲"爆发时，以玩家为圆心扩散出一圈青白色的冲击波，所到之处光迹蒸发、敌人碎裂为金色光点。当"绽放"激活时，整个幽光水母变为炽白色，光迹同步转为金色——整个画面从暗色调瞬间亮起，像深海中被点燃了一盏太阳。

整体美术风格：**极简+发光粒子**。不需要写实的海洋，只需要"黑暗中的一点光"。

## 操作方式

**方向键四向移动**（手机为单指滑动）。每次输入移动一格。

- 每移动一步，当前格留下永久荧光轨迹
- 无法走回已有轨迹的格子（除非轨迹已衰减消失）
- **一个额外按键**：脉冲爆发（消耗光能，清除周围区域）

一手操作，无需精确点击，无需快速反应。玩家随时可以停下来思考。

> 这是思考游戏，不是反应游戏。

## 核心规则

**规则一：移动即留痕。** 幽光水母每经过一格，该格变为荧光轨迹。轨迹不可再次踏入——它是海底的永久光墙。你走过的路，变成了你未来的障碍。

**规则二：光迹驱敌。** 荧光轨迹会排斥掠食者——深海鳗鱼和暗影章鱼都无法穿越光迹。这意味着你的轨迹既是保护自己的屏障，也是压缩自己活动空间的牢笼。

**规则三：脉冲清场。** 消耗光能，在当前位置释放脉冲波——清除3×3范围内的荧光轨迹和掠食者。被清除的轨迹变为可通行空间，被消灭的掠食者碎裂为浮游生物。这是你唯一的主动操作，也是最关键的战略决策。

**规则四：光能衰减。** 光能随时间自然流失。不持续收集浮游生物，光能归零即游戏结束。绽放状态加速消耗。这迫使玩家不能龟缩在安全区域——你必须走出去觅食。

**规则五：绽放反转。** 光能蓄满阈值时，自动进入"绽放"状态：所有掠食者开始逃离你，你可以直接触碰消灭它们获取大量光能。但绽放持续消耗光能，窗口期有限。猎物变猎手——但猎手的弹药也在倒计时。

> **五条规则，一个核心矛盾：你越安全，空间越小；空间越小，你越危险。**

## 资源与制约系统

这款游戏的本质是一个**深海能量生态**——五种资源互相转化，玩家在生存的压力下不断做出取舍。

### 资源一览

| 资源 | 产生方式 | 消耗方式 | 双重角色 |
|------|----------|----------|----------|
| 开放空间 | 脉冲清场 / 轨迹衰减 | 每步移动消耗一格 | 自由度的基础，但开放=暴露在掠食者面前 |
| 光能 | 收集浮游生物 / 绽放吞噬敌人 | 自然衰减 / 脉冲消耗 / 绽放持续消耗 | 既是生命条又是弹药，唯一的核心资源 |
| 荧光轨迹 | 移动自动产生 | 脉冲清除 / 自然衰减（90秒） | 阻挡掠食者=安全；压缩空间=危险 |
| 掠食者 | 随时间在地图边缘刷新 | 脉冲消灭 / 绽放吞噬 | 威胁；也是潜在的光能来源 |
| 浮游生物 | 在开放空间持续刷新 | 被玩家收集 | 生存必需品；引诱玩家冒险离开安全区 |

### 资源流动全景

```
开放空间 ──移动──→ 荧光轨迹（保护/束缚）
                        │
                    衰减 / 脉冲
                        │
                        ↓
    浮游生物 ←── 开放空间重新释放 ←──┘
        │
        ↓ 收集
      光能 ──脉冲──→ 清除轨迹 + 消灭敌人
        │                 │
        │            敌人→浮游生物（转化）
        ↓ 蓄满
      绽放 ──吞噬敌人──→ 大量光能回流
```

### 核心矛盾：生长悖论

这是从贪吃蛇提取的核心体验，但用全新的方式表达：

- 你的轨迹越长，能抵挡掠食者的屏障就越多 → **你越安全**
- 但轨迹占据的空间越大，你能走的路就越少 → **你越受限**
- 最终你会被困在自己的光迹迷宫里，无法触及新区域的浮游生物 → **光能耗尽**

唯一的出路是**脉冲爆发**——用宝贵的光能炸开自己的轨迹，重新释放空间。但这意味着你花掉了收集来的光能，而且清掉轨迹也意味着清掉了自己的防御屏障。

> "我花光能脉冲清场，释放空间、消灭敌人——但我也同时拆掉了自己的护盾。"

这是每时每刻都在发生的决策。没有一步是"无脑"的。

### 玩家的三道平衡绳

1. **空间线**：别让轨迹把自己封死——但轨迹是唯一的防御
2. **能量线**：别把光能花在脉冲上导致不够绽放——但没有脉冲可能根本活不到绽放
3. **探索线**：别在安全区龟缩——浮游生物只在开放空间刷新，你必须冒险

三条线在每一步操作中互相拉扯。这就是游戏性的来源。

### 涌现策略（非显式设计，从规则中自然产生）

- **面包屑陷阱**：故意走一段短折线引诱敌人跟入，再绕回来用轨迹将其封堵在死角
- **脉冲钓鱼**：在敌人聚集区附近释放脉冲——敌人死亡转化为浮游生物，脉冲本身消耗的光能被"赚回"
- **自困求生**：盘绕式走位创建一个被轨迹包围的安全核心，在里面等待浮游生物刷新——但空间有限，食物可能不够
- **断尾脱身**：被自己的轨迹围困时，精确计算脉冲位置，炸开一条逃生通道——代价大但能救命
- **绽放冲锋**：蓄满光能后主动冲入敌群，在绽放窗口期内吞噬尽可能多的敌人——高风险高回报

## 为什么好玩

### 1. 轨迹的矛盾感——PopCap式"甜蜜的痛苦"

PopCap游戏的精髓是"每个操作都让你同时开心和焦虑"。在这个设计里，移动一步的效果是双面的：你留下了一段美丽的光迹（视觉满足感），同时永久失去了一格活动空间（焦虑感）。

这种"每步都有代价"的设计让玩家永远不会无脑移动。每一步都是一次微型决策。但因为操作极其简单（只是方向键），决策的速度可以很快——形成了King式"快速决策循环"的变体。

### 2. 护盾与牢笼的一体两面

"你的轨迹保护你"这件事本身就是有趣的。当你被深海鳗鱼追赶，拐进一条自己之前留下的光迹走廊，看到鳗鱼在光迹外徘徊无法进入——那一刻的安心感是独特的。

但紧接着你意识到：这条走廊是死胡同，你把自己封住了。安心感瞬间变成了空间焦虑。

这种**安全感与危机感的快速交替**是情绪钩子的核心。

### 3. 脉冲——"深呼吸后的爆破"

整个游戏大部分时间是安静的、策略性的：你在黑暗中缓缓移动，规划路线，收集浮游生物。然后在一个关键时刻，你按下脉冲键——

一圈光波扩散，轨迹蒸发，敌人碎裂成金色光点纷纷落下。深海重新亮了起来。

这个从"安静紧张"到"爆发释放"的节奏，是PopCap游戏最擅长的**"释放时刻"**设计——就像Zuma里三个球同时消除，就像Plants vs. Zombies里一排豌豆同时开火。

### 4. 绽放——掠食者变猎物的狂喜

绽放状态是整局游戏的情绪高点。当光能蓄满，水母变为炽白色，深海鳗鱼和暗影章鱼开始转身逃窜——角色互换了。

你从"被追的猎物"瞬间变成"追猎者"，冲向刚才还让你提心吊胆的敌人，一口一个吞下去，金色光能在身上炸开。

但绽放有时限。光能在倒计时。你必须抓紧每一秒——这种"有限时间内的权力幻想"创造了极强的满足感。当绽放结束，你回到正常状态，敌人重新逼近——从巅峰跌落回紧张，但这个落差反而让你更想再来一次。

### 5. 每局都是独特的迷宫

没有两局游戏的轨迹图案是一样的。你的轨迹是独一无二的——它记录了你这一局所有的决策路径。看着满屏的荧光轨迹网络，有的地方密不透风，有的地方豁然开朗——这是一幅**玩家自己画出来的画**。

这种"每一局都是独一无二的艺术品"的感觉，是PopCap游戏重玩价值的重要来源。

### 6. "差一点就活下来"的死亡体验

死亡几乎总是可以归因的：是不是脉冲用早了？是不是那条轨迹不该走？是不是绽放时贪了？

好的休闲游戏让玩家在死亡时想的不是"这不公平"，而是"下次我知道该怎么做了"。

## 一局游戏的节奏

```
开局（0-30秒）
│  深海洞穴开阔，浮游生物充沛，没有掠食者
│  快速探索收集，光迹开始蔓延
│  感觉：自由、好奇、轻松
│  核心行为：广域探索，积累光能储备
│
├─ 第一个威胁（30秒-1分钟）
│  第一条深海鳗鱼从边缘出现，缓慢巡逻
│  玩家第一次体验到被追逐的紧张
│  发现：光迹可以阻挡鳗鱼！
│  开始有意识地用轨迹建造防御走廊
│  感觉：紧张但可控，学会利用轨迹保护自己
│
├─ 空间压力（1-2分钟）
│  轨迹网络开始密集，开放空间收缩
│  第二条鳗鱼出现，暗影章鱼加入追踪
│  第一次需要脉冲爆发——炸开一条关键通道
│  💥 满足感：清场时刻，敌人化为浮游生物
│  但代价是光能下降，需要更积极觅食
│  感觉：紧张升级，开始感受到轨迹的束缚
│
├─ 战略深化（2-3分钟）
│  玩家开始有选择地走位——不是乱跑，而是
│  故意用轨迹构建"陷阱"引诱敌人
│  绽放第一次激活！追猎敌人的狂喜时刻
│  ✨ 情绪高点：吞噬敌人，大量光能回流
│  绽放结束后回到紧张节奏
│  感觉：紧张-释放-紧张的交替循环建立
│
├─ 生存冲刺（3-5分钟）
│  屏幕被轨迹和残存洞穴分割成迷宫般的碎片
│  多个掠食者在各个空间出没
│  每次脉冲都像是在拆自己的救命绳
│  绽放成为关键续命手段——但需要精准 timing
│  感觉：高压、高密度、每个决策都生死攸关
│
└─ 终局（5分钟+）
   空间极度压缩。浮游生物刷新在危险的开放区域
   暗影章鱼封堵退路，鳗鱼巡逻线交叉
   最后的绽放冲刺 or 脉冲断尾脱身
   光能耗尽——游戏结束
   感觉：壮烈的终结。满屏的光迹网络是这一局的"签名"
```

**节奏曲线**：轻松 → 小紧张 → 释放 → 更紧张 → 大释放 → 持续高压 → 终结

关键设计点：绽放状态是节奏中的**"呼吸高峰"**——在持续紧张中给玩家一次权力的释放，然后重新跌回紧张。这个循环让玩家永远想"再来一局"。

## 参数清单

| # | 参数 | 初始值 | 说明 |
|---|------|--------|------|
| 1 | **光能衰减速率** | 1/3秒 | 基础生存压力。过快→玩家永远在找食物无暇思考；过慢→没有觅食动力。这是难度调节的主轴 |
| 2 | **脉冲消耗** | 20光能 | 主动操作的成本。与脉冲范围联动——范围越大消耗应越高，保持"区域清除"的战略分量 |
| 3 | **脉冲范围** | 3×3 | 单次脉冲的影响面积。唯一可调的"清场规模"参数。扩大一格都显著改变策略空间 |
| 4 | **绽放阈值** | 80光能 | 进入猎杀模式的门槛。蓄满的过程本身就是"忍耐-期待"的情绪弧线 |
| 5 | **绽放持续** | 12秒 | 猎杀窗口。配合绽放消耗速率，决定玩家能吞噬多少敌人。这是"权力幻想"的时长 |
| 6 | **轨迹衰减时间** | 90秒 | 轨迹从产生到自然消散的时间。这是"生长悖论"的释放阀——太短则轨迹不构成威胁，太长则空间锁死无法逆转 |

> 6个参数。增减任意一个，游戏节奏都会明显改变——说明每个参数都在"承重"，没有冗余。
>
> 注意：敌人速度、刷新频率、地图尺寸等属于**关卡设计参数**，随游戏进程动态调整，不计入核心参数。核心参数定义的是"游戏的物理定律"——它们不变，关卡在它们之上创造变化。
