# 美术方向文档

> 作者：美术  
> 状态：✅ 已完成  
> 最后更新：2026-08-15

---

## 视觉定位

**核心美学：深色棱镜底板 + 彩虹光轨 + 聚焦光束引爆**

- **深色背景**：移动端休闲游戏的保护色，不管低端机还是高端机都有足够对比度
- **彩虹光轨**：半透明果冻状条纹，带有发光效果
- **引爆光效**：圈内区域瞬间被彩虹光束填满、粒子四散

## 宝石视觉设计

### 基础宝石（5色）

| 颜色 | 名称 | 外观描述 | 透明度 |
|------|------|---------|--------|
| 🟡 金色 | 普通宝石 | 平涂色，无明显光效 | 70% |
| 🔴 红色 | 烈焰宝石 | 红色基底 + 火焰纹路 | 80% |
| 🔵 蓝色 | 冰霜宝石 | 蓝色基底 + 冰晶纹路 | 80% |
| 🟢 绿色 | 藤蔓宝石 | 绿色基底 + 藤蔓纹路 | 80% |
| 🟣 紫色 | 紫晶宝石 | 紫色基底 + 晶格纹路 | 80% |

### 组合宝石（视觉层级）

| 类型 | 视觉特征 | 发光强度 |
|------|---------|---------|
| 强化宝石（3合） | 同色基底 + 该色纹路 + 轻微光晕环 | 中等 |
| 超级宝石（4合） | 强化宝石 + 外发光环 + 脉动更强 | 中高 |
| 终极宝石（5合） | 超级宝石 + 双光环 + 粒子环绕 | 高 |
| 彩虹宝石（红+绿+蓝） | 全光谱旋转光晕 + 环绕粒子 | 最高 |

### 特殊宝石

| 宝石 | 外观 | 作用 |
|------|------|------|
| 冻结宝石（冰蓝） | 表面有冰晶纹理，比普通蓝色宝石更亮 | 必须通过引爆收集 |
| 行动力宝石（闪电） | 带闪电标志，黄色基底 + 闪电纹路 | 圈中后增加行动力 |
| 时间宝石（时钟） | 带时钟标志，蓝色基底 + 时钟纹路 | 圈中后增加行动力 |

## 棋盘视觉

### 底色

- **深蓝黑色**：#0a0e1a（近似）
- 深色底板确保所有宝石和光轨清晰可读
- 不会出现"脏"的问题（相比暗色调海途）

### 网格

- 6×6 起步，最大 12×12
- 格子线微弱可见（10% 透明度），确保玩家有空间感
- 围墙用灰色石块纹理，与宝石颜色拉开差异

### 光轨

- **正常状态**：玩家颜色的半透明果冻状条纹
- **虹化状态**：❌ 已否决，不需要
- **发光效果**：Canvas glow 滤镜，强度随组合等级递增

## 动画设计

### 引爆动画

| 阶段 | 时长 | 描述 |
|------|------|------|
| 圈闭合瞬间 | 0.1s | 光轨闪烁 |
| 光芒爆发 | 0.3s | 圈内区域被彩虹光束填满 |
| 粒子四散 | 0.5s | 宝石碎片向四周飞散 |
| 光轨清空 | 0.2s | 所有光轨"蒸发"消失 |
| **总计** | **~1.1s** | 保持流畅不拖沓 |

### 合并动画（组合触发）

| 阶段 | 时长 | 描述 |
|------|------|------|
| 螺旋汇聚 | 0.3s | 3颗宝石沿螺旋轨迹向中心旋转汇聚 |
| 光芒爆发 | 0.5s | 接触瞬间闪光，颜色决定爆发色调 |
| 新宝石成型 | 0.2s | 从光中浮现，降落到棋盘新位置 |
| **总计** | **~1.0s** | 这是游戏核心"截图时刻" |

### 落地脉冲

新宝石降落后产生一圈扩散光波，强化"落地感"。

## 视觉层次控制

**核心原则**：普通宝石低调，组合宝石中等，彩虹宝石最炫

| 元素 | 透明度/发光 | 说明 |
|------|-----------|------|
| 背景 | 100% 不透明 | 深色保护色 |
| 网格线 | 10% 透明度 | 微弱可见 |
| 普通宝石 | 70% 透明度 + 无光效 | 低调 |
| 强化宝石 | 85% 透明度 + 中等光晕 | 有辨识度 |
| 超级宝石 | 90% 透明度 + 强光晕 + 脉动 | 醒目 |
| 彩虹宝石 | 100% 透明度 + 旋转光晕 + 环绕粒子 | 顶级视觉焦点 |
| 光轨 | 60% 透明度 | 不影响宝石可读性 |

## 已否决的美术方向

### ❌ 虹化状态特效

**原设计**：彩虹色光环 + 粒子环绕 + 全屏色调偏移  
**否决理由**：
- 美术工作量减少（不需要做虹化状态特效）
- 视觉设计更简洁
- 合并动画可以承担视觉爽感
