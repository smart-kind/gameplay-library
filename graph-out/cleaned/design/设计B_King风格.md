# 彩棱碰碰 (Prism Pop)

> 滑动留下光轨，画圈引爆宝石——空间越紧，闭环越爽。

## 画面与场景

棋盘是一块深色棱镜底板，上面散布着彩色宝石和少量灰色围墙。玩家控制一颗发光的"棱光"——一颗会在格子间滚动的小光球。

棱光每经过一格，就在该格留下一道彩色光轨（彩虹色，每步渐变）。光轨是半透明的果冻状条纹，堆叠在底板上，视觉上极其清晰——哪些格子走过了，一目了然。

当光轨首尾相连形成闭环时，圈内区域瞬间被"聚焦光束"填满：宝石碎裂、围墙崩塌、光轨蒸发——整个区域爆发出连锁的光粒子特效，伴随清脆的音效连击。这是游戏最核心的爽感时刻。

引爆后，棱光进入"虹化"状态：身体变为全彩光环，持续3步不留光轨，可以自由穿越棋盘重新布局。

关卡场景从简单的6×6棱镜板开始，逐步扩大到12×12，围墙布局越来越复杂，形成精密的迷宫。

## 操作方式

**单指滑动**。上下左右四向滑动，棱光移动一格。每滑一次，移动一格，留下一格光轨。

无需点击特定目标，无需拖动，无需组合操作。一只手的拇指即可完成所有操作。

玩家可以在任意时刻停下来观察棋盘——这不是反应游戏，是思考游戏。

## 核心规则

**规则一：移动即留轨。** 棱光每经过一格，该格变为光轨。光轨不可再次经过——它是棋盘上的新障碍。

**规则二：宝石分两种。** 普通宝石（彩色）可以直接经过收集；冻结宝石（被冰晶包裹）只能通过在闭环引爆中才能解放收集。

**规则三：闭环即引爆。** 当棱光移动到与自身光轨相邻的格子，且此操作形成了一个封闭区域时——引爆！圈内所有冻结宝石自动收集，普通宝石自动收集，围墙全部摧毁，边界光轨全部消散。

**规则四：引爆即虹化。** 闭环引爆后，棱光进入虹化状态：接下来3步不留光轨，且可以穿越已有光轨。这是奖励窗口——自由重新定位，为下一轮布局。

**规则五：全收即通关。** 收集本关所有宝石（普通+冻结）即过关。

> **五条规则，一个核心抉择：这颗宝石我直接吃，还是绕一圈把整片区域引爆？**

## 资源与制约系统

这款游戏的本质是一个**资源转化系统**，玩家在五个资源维度之间做平衡：

### 资源流动

```
格子空间（充裕）
    ↓ 移动消耗
光轨（增长 = 约束增长）
    ↓ 闭环触发转化
引爆（空间回收 + 宝石收集 + 得分）
    ↓ 引爆后转化
虹化状态（短暂的自由 = 零约束移动）
    ↓ 虹化结束
回到正常状态（光轨重新积累）
```

### 核心矛盾

**光轨既是武器也是枷锁。** 光轨越长，能围出的闭环越大，得分越高——但可用空间越小，自我困死的风险越大。玩家必须回答一个持续的问题：

> "我现在引爆一个小圈拿到安全空间，还是继续积累光轨赌一个大闭环？"

这个矛盾贯穿每一局。它不是反应，是策略。

### 资源转化表

| 资源 | 产生方式 | 消耗方式 | 冲突关系 |
|------|----------|----------|----------|
| 格子空间 | 引爆/虹化释放 | 每步移动消耗一格 | 光轨越多，空间越少 |
| 光轨 | 移动产生 | 闭环引爆时消散 | 封锁路径，但构成引爆边界 |
| 普通宝石 | 关卡初始 | 直接经过 / 闭环引爆 | 直接吃=安全但低分；圈住=高分但需更多步数 |
| 冻结宝石 | 关卡初始 | 仅闭环引爆 | 强制玩家必须使用闭环机制 |
| 虹化步数 | 引爆后获得3步 | 每步消耗1步 | 自由移动但浪费空间积累机会 |

### 玩家的平衡术

玩家同时管理三条线：

1. **空间线**：别把自己困死——留够退路
2. **收集线**：冻结宝石需要精确的闭环设计——它们不能直接吃
3. **得分线**：闭环面积越大分越高——鼓励冒险

三条线在每一步操作中互相拉扯。这就是游戏性的来源。

## 为什么好玩

### 1. "AHA时刻"是核心体验

每一关都有这样的瞬间：玩家盯着棋盘，看到散布的宝石和蔓延的光轨，突然脑中闪过——"如果我从这里绕到那里，再折回来……就能圈住这整片！"

这个"看到解法"的瞬间就是King式设计的灵魂。它和Candy Crush里"看到一步触发三个特殊糖果连锁"的快感同源——都是**模式识别带来的顿悟**。

### 2. 约束即策略

光轨不能重复经过，这看似是限制，实际上创造了深度。玩家不是在"自由地"移动，而是在**有限的选项中寻找最优解**。好的约束创造好的谜题。

冻结宝石的存在确保了闭环机制不可绕过——你不能只靠直接吃宝石通关。你**必须**学会画圈，**必须**学会利用约束。

### 3. 连锁反应的多巴胺

闭环引爆不只是"收集了几个宝石"。它是一个视觉、听觉、得分的三重爆发：

- **视觉**：圈内区域被彩虹光束吞没，粒子四散
- **听觉**：宝石碎裂声层层叠加，像多米诺骨牌
- **得分**：面积越大，倍率越高，数字飞速滚动

当玩家用一个大闭环圈住了半个棋盘，那种爽感和Candy Crush里触发彩色炸弹是同一种情绪——"我做到了！太漂亮了！"

### 4. 虹化——呼吸的节奏

持续紧张会导致疲劳。虹化状态是设计的"呼吸"——引爆之后，3步的自由移动让玩家放松、重新观察、规划下一步。

节奏感：**紧张（光轨积累）→ 释放（引爆）→ 自由（虹化）→ 新的紧张**。

这个节奏让玩家始终处于"心流"状态。

### 5. 一关一分钟

每关设计在1-3分钟内可完成。操作简单到不需要教程——看到棋盘就想试。但每一关的围墙布局和宝石位置都是精心设计的小谜题，让玩家觉得自己很聪明。

## 一局游戏的节奏

```
开局（10秒）
│  观察棋盘：宝石在哪？围墙什么形状？冻结宝石分布？
│  脑中开始规划路线……
│
├─ 第一阶段：试探布局（20-40秒）
│  移动棱光，光轨开始蔓延
│  顺路收集容易够到的普通宝石
│  为冻结宝石规划闭环路径
│  空间开始收缩，紧张感上升
│
├─ 第二阶段：第一个闭环（15-30秒）
│  看准时机，完成第一个闭环
│  💥 引爆！冻结宝石解放，空间释放
│  虹化状态启动，自由移动3步
│  重新定位到下一个目标区域
│
├─ 第三阶段：连锁规划（20-40秒）
│  利用虹化重新定位后，开始布局更大的闭环
│  高级玩家会设计"套娃闭环"——
│  先走一条看起来奇怪的路，但其实是在为后续大圈做准备
│  AHA时刻在这里爆发："原来他之前那步是伏笔！"
│
├─ 第四阶段：收官（10-20秒）
│  剩余宝石不多，但空间也紧
│  最后一步的精准闭环 = 完美通关
│  或：差一步没圈住，勉强直接吃 = 险胜
│
└─ 结算（5秒）
   得分展示，星级评价，"下一关！"的冲动
```

## 参数清单

| # | 参数 | 初始值 | 终局值 | 说明 |
|---|------|--------|--------|------|
| 1 | **网格尺寸** | 6×6 | 12×12 | 关卡难度主轴。越大，闭环机会越多但规划越难 |
| 2 | **每关宝石总数** | 5 | 30 | 决定关卡长度和闭环次数 |
| 3 | **冻结宝石比例** | 20% | 50% | 冻结宝石越多，越强制使用闭环机制。低于20%玩家可能只靠直接收集通关 |
| 4 | **虹化持续步数** | 3 | 3 | 固定为3步。这是"呼吸节奏"的核心参数，改动需极度谨慎 |
| 5 | **闭环得分系数** | 面积×10 | 面积×15 | 面积=闭环围住的格子数。系数越高，越鼓励冒险做大圈 |
| 6 | **围墙密度** | 5% | 20% | 围墙占棋盘比例。围墙增加路径规划的复杂度，同时为闭环提供天然边界 |

> 6个参数，足以支撑从新手到高手的完整体验曲线。没有第7个参数的空间——如果有，说明核心规则没设计好。
