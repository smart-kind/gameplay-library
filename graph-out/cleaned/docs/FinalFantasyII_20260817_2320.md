# 最终幻想II（Final Fantasy II）

- **类型**: 角色扮演
- **平台**: Mobile (iOS+Android) / NES / PSP
- **开发商**: Square Enix (原Square)
- **首次发布**: 1988
- **一句话描述**: 经典日式RPG的移植版，讲述一群反抗帝国暴政的年轻人的冒险故事，以独特的熟练度系统著称。

## 玩法规则

游戏采用经典的2D俯视视角探索地图和城镇，遭遇敌人后切换到第一人称回合制战斗画面。
探索模式：玩家在世界地图上行走（遇敌概率随机），进入城镇与NPC对话获取情报，购买装备和道具，在旅馆恢复体力。
战斗模式：回合制，队伍成员轮流行动。每个角色可以选择攻击、使用魔法、使用物品、逃跑。战斗胜利后获得金钱（Gil）。
独特的熟练度系统：没有传统的等级概念。角色通过使用某种武器来提升该武器的熟练度，通过施放魔法来提升该魔法的等级，通过承受攻击来提升HP上限。角色的成长方向完全由玩家的操作决定。
玩家可以随时更换队伍成员，不同的角色擅长不同的武器和魔法类型。装备不同的武器、防具改变角色属性。
游戏目标是收集反抗军的情报，寻找关键人物和道具，最终击败帕拉美琪亚帝国及其背后的黑暗力量。

## 核心循环

城镇探索获取情报 → 世界地图行进遇敌 → 回合制战斗获取资源 → 购买装备提升战力 → 推进剧情进入新区域

## 核心机制

- 熟练度成长系统：角色的成长方向由实际使用决定——多用剑就成为剑士，多施法就成为法师，没有预设职业限制。这让玩家可以自由实验各种角色构建方案
- 回合制策略战斗：需要根据敌人弱点和队伍配置选择行动顺序，魔法消耗HP或MP增加了资源管理维度。不同敌人有不同的防御倾向，需要针对性选择攻击方式
- 剧情驱动的探索：主线任务引导玩家探索不同地区，NPC对话和事件触发推进故事发展。角色牺牲的情感冲击在JRPG历史上也是里程碑级的

## 为什么好玩

没有固定职业系统的自由度让人想尝试各种成长路线——让法师去练剑、让战士去学魔法都有可能性。
剧情中角色牺牲的情感冲击在JRPG历史上也是里程碑级的，让人产生强烈的情感共鸣。
探索未知大陆、发现隐藏城镇和道具的经典JRPG乐趣。

## 粘性来源

角色成长的数值积累（'再升一级就好'）、未探索区域的未知感、以及经典JRPG的'我要看到结局'的故事驱动力。

## Meta 系统

无复杂外围系统，装备系统、道具收集、城镇设施构成核心RPG循环。

## 实现难度

中 — 需要实现2D地图渲染、回合制战斗系统、熟练度成长系统、NPC对话树和事件触发。主要技术难点在于多系统耦合的数据平衡和熟练度系统的数值曲线设计。

游戏还包含一些隐藏要素：隐藏武器、隐藏城镇和隐藏Boss。某些武器需要特定方式获取（如击败特定敌人掉落）。游戏的剧情包含角色牺牲的感人桥段，在JRPG历史上影响深远。
