# Canabalt

- **类型**: 跑酷 / 无尽奔跑 / 街机
- **平台**: Web / Mobile (iOS + Android) / PC / 多平台
- **开发商**: Adam Saltsman (Finji)
- **首次发布**: 2009
- **一句话描述**: 单键控制角色在城市屋顶上奔跑跳跃，逃离神秘破坏，尽可能跑得更远。

## 玩法规则

游戏画面为黑白风格的横向卷轴城市天际线，角色自动从左向右奔跑，速度逐渐加快。

操作方式：
- **单键/单击/触碰**：唯一的操作就是"跳跃"。按下任何键（空格、鼠标点击、触摸屏幕）角色就会跳跃。
- 角色奔跑速度会随时间逐渐增加，后期速度非常快。
- 角色自动跑向当前屋顶的边缘，玩家需要在到达边缘前按下跳跃键。
- 跳跃距离是固定的，取决于按下跳跃键时角色离屋顶边缘的距离——离边缘越近跳跃越远，但太近可能来不及起跳。

游戏场景由高低不一的屋顶组成，之间有宽窄不同的间隙。部分屋顶上有可拾取物品（钻石/宝石），收集可以增加分数。

如果角色没能跳到下一个屋顶（掉入间隙、撞到墙壁、被障碍物击中），游戏结束。游戏没有终点——目标是尽可能跑得更远，打破个人最高纪录。

背景中有神秘的建筑被破坏、飞行的不明物体等叙事元素，暗示世界末日主题。

## 核心循环

奔跑 → 看准时机跳跃 → 收集物品 → 速度越来越快 → 最终失误死亡 → 挑战更高分数

## 核心机制

- **单键操作**：游戏只有一个操作——跳跃。这种极简设计让任何人都能立刻上手，但"什么时候跳"的判断随速度增加而变得越来越难。
- **速度递增**：奔跑速度随时间持续增加，这是游戏难度曲线的唯一来源。后期需要极快的反应速度。
- **屋顶生成算法**：屋顶的宽度和间隙由算法随机生成（但遵循一定规则），保证既有挑战性又可完成。
- **距离/分数系统**：分数基于奔跑距离，收集物品额外加分。高分驱动反复挑战。

## 为什么好玩

Canabalt 是无尽跑酷类型的鼻祖，它的伟大之处在于极简——一个按键，一种操作，但创造了极致的紧张感。随着速度越来越快，玩家的反应时间被压缩到极限，"再跳一次就结束"的刺激感让人欲罢不能。黑白艺术风格、紧张的配乐和末日主题叙事共同营造了一种独特的氛围。

## 粘性来源

- **分数驱动**：无尽跑酷的核心驱动力是"比上次跑得更远"。
- **速度带来的肾上腺素**：后期的高速奔跑带来纯粹的刺激感。
- **极简上瘾**：单键操作降低了门槛，任何人都能"再来一局"。

## Meta 系统

无 — 纯街机体验，无长期成长系统。

## 实现难度

**低** — 单键跑酷的核心机制实现简单：自动奔跑+跳跃判定+随机场景生成。最大技术难点在于场景生成的算法——需要保证每次生成的场景既有挑战性又理论上可完成。
