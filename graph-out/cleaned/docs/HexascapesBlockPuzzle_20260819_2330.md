# Hexascapes - Block Puzzle

- **类型**: 益智解谜 / 空间逻辑 / 方块消除
- **平台**: Mobile (iOS+Android)
- **开发商**: EASY PLAY GAME TECHNOLOGY LIMITED
- **首次发布**: 2026
- **一句话描述**: 一款基于六边形网格的方块益智游戏，玩家通过旋转和放置六边形方块来填充空间并消除完成的行

## 玩法规则

游戏画面展示一个由六边形格子组成的棋盘（通常是六边形或菱形的整体轮廓），棋盘上部分格子已被填充。屏幕下方会出现即将放置的六边形方块（通常是3个候选方块，玩家可以选择放置顺序）。

每个候选方块由多个相连的六边形小格组成，形状各异（直线形、三角形、L形、T形等）。玩家的核心操作是选择一个方块，点击棋盘上的目标位置将其放置上去。放置后，如果某一行/列/对角线上的六边形格子全部被填满，这些格子会被消除并获得分数。

画面布局：上方是当前分数和目标进度，中央是六边形棋盘，下方是3个候选方块。棋盘上已有填充的格子显示不同的颜色，消除时会有动画效果。

玩家需要在每个回合选择放置哪个方块、放在什么位置。放置策略直接影响后续可用空间——好的放置可以创造出多行同时消除的机会，差的放置可能导致棋盘快速被填满而无处可放新方块。当棋盘被填满且剩余的方块无法放置时，游戏结束。

部分关卡模式有特定目标（如"在X步内达到Y分"或"消除Z个红色格子"），完成后解锁新关卡。无尽模式则以最高分为目标持续进行。

## 核心循环

观察棋盘和候选方块 -> 选择方块并放置到最优位置 -> 触发消除获得分数 -> 获取新候选方块继续

## 核心机制

- **六边形网格系统**: 与传统方块游戏的正方形网格不同，六边形网格有6个相邻方向而非4个，这创造了独特的空间逻辑。玩家需要适应六边形的"行"和"列"概念（实际上是6个方向的直线），增加了空间思维的挑战
- **三选一放置策略**: 每回合展示3个候选方块，玩家可以自主选择放置哪个。这引入了策略层——不仅要考虑"这个方块放哪"，还要考虑"先放哪个方块、把哪个方块留给后面"。选择顺序直接影响后续操作空间
- **多行同时消除奖励**: 当玩家的一次放置同时触发多行消除时，会获得额外分数奖励（类似"连击"）。这一机制鼓励玩家追求"一石多鸟"的精妙放置，增加了策略深度和成就感

## 为什么好玩

六边形网格带来的空间新鲜感是核心吸引力——习惯了正方形网格的玩家会发现六边形的排列方式完全不同，需要重新思考"什么是行/列"。同时，一次放置触发多行消除的视觉效果和分数反馈非常爽快

## 粘性来源

具体来说：1）"差一点就消除"的不甘心——棋盘上就差一个格子就能消除，促使玩家规划下一步；2）高分追求——每次放置都影响最终得分，玩家会反复挑战以突破记录；3）关卡目标多样化——不同关卡有不同条件（限时、限步、特定消除目标），保持新鲜感；4）简洁优雅的视觉风格配合流畅的消除动画，带来舒适的视觉体验

## Meta 系统

关卡进度系统：通过完成关卡获得星星，星星解锁新关卡章节。部分版本包含每日挑战和排行榜。方块主题/皮肤系统提供视觉个性化

## 实现难度

中等。核心难点是六边形网格的渲染和碰撞检测——需要处理六边形坐标系统（通常使用轴向坐标或立方体坐标）以及消除判断逻辑。最大技术难点是动画流畅性和触摸响应的精确度

## 关卡设计趋势

游戏关卡遵循由浅入深的设计原则：前期关卡元素简单，帮助玩家掌握核心机制；中期逐步引入复杂元素（如多种障碍物、多重目标）；后期关卡需要玩家综合运用已掌握的所有技巧。这种递进式难度曲线确保了持续的'略有挑战但可克服'的心流体验。
