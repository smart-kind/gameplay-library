# 细菌大作战：放置游戏（Bacterial Takeover - Idle Game）

- **类型**: 放置 / 策略 / 模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: Fufla SIA
- **首次发布**: 2017
- **一句话描述**: 以细菌进化为主题的放置游戏，通过不断升级菌群来征服世界。

## 玩法规则

游戏以培养细菌为核心玩法。玩家进入后看到一片微观世界的培养皿场景，中央有一个初始菌落。

玩家通过点击菌落产生能量点数，能量用于升级细菌的各项属性——繁殖速度、感染范围、抗药性等。每个属性升级后都有可见的数值反馈。

随着细菌数量增长，画面中会出现新的细菌个体自动繁殖。游戏设计了多个"感染阶段"，从单一培养皿逐步扩展到整个实验室、城市、全球。每个阶段都有新的细菌类型和升级选项解锁。

玩家还可以进化出特殊能力的细菌变种——比如产生毒素的菌株、能抵抗高温的嗜热菌、或者可以寄生在宿主体内的共生菌。每种变种都有独特的加成效果和视觉外观。

游戏没有失败条件，但有明确的进度目标：完成所有阶段的感染，解锁全部细菌类型图鉴。
## 核心循环

点击获取能量 → 升级细菌属性 → 自动繁殖 → 感染新区域 → 解锁新菌种

## 核心机制

- **细菌繁殖自动化**：购买基础繁殖升级后，细菌自动分裂产生新个体，数量呈指数增长，是放置类标准设计。
- **多维升级树**：细菌有繁殖速度、感染范围、抗药性、特殊能力四条升级线，玩家需要在有限资源下做出优先级选择。
- **阶段解锁机制**：感染区域从培养皿到全球分多个阶段，每个阶段带来新细菌类型和新升级选项，提供持续的进度感。

## 为什么好玩

将微观世界的细菌放大到可见尺度，让玩家体验'从一滴培养液到征服世界'的夸张成长过程。看着满屏的细菌自动增殖，满足感极强。

## 粘性来源

指数级增长的数值快感是核心粘性。每次升级后看到产出翻倍的效果立竿见影。多阶段目标（感染全球）提供长期追求。收集全部细菌图鉴的欲望驱动持续游玩。

## Meta 系统

细菌图鉴收集系统。每次解锁新菌种会记录在图鉴中，包含名称、特性描述和稀有度。图鉴完成度成为额外的长期目标。

## 实现难度

低 — 放置类核心逻辑简单。技术难点在于大量单位同时渲染时的性能优化，以及数值爆炸时的精度处理。

## 同类游戏

与此游戏类似的推荐：放置类可参考 Clicker Heroes 和 Idle Slayer；肉鸽类可参考 Slay the Spire 和 Vampire Survivors。
