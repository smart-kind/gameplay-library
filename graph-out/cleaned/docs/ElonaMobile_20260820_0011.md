# 伊洛纳移动版（Elona Mobile）

- **类型**: Roguelike RPG / 开放世界
- **平台**: Mobile (iOS+Android)
- **开发商**: LTGAMES GLOBAL
- **首次发布**: 2021
- **一句话描述**: 经典日式 Roguelike RPG 的移动版，以沉船事故为起点，在充满突变和未知危险的北提里斯大陆上探索、生存和成长的开放世界RPG。

## 玩法规则

故事从一场沉船事故开始：你乘坐一艘船逃离以太风造成的突变区，却遭遇风暴，醒来时发现自己身处陌生而危险的北提里斯大陆。

游戏采用俯视角 2D 画面，世界由多个城镇、地牢、野外区域组成。玩家可以在世界中自由移动，与 NPC 对话、接任务、战斗、采集、制作等。

战斗采用回合制，玩家和敌人轮流行动。游戏没有自动战斗，也没有重复刷怪的无聊设计——每次冒险都是全新的挑战。

游戏系统极其丰富：角色可以学习各种技能，从魔法到制作到驯兽；可以建造房屋、种植作物、经营商店；可以与NPC建立关系甚至结婚；可以在地牢中探索未知的宝藏。

## 核心循环

探索世界 → 战斗+收集 → 学习技能+成长 → 发现新区域 → 继续探索

## 核心机制

- **开放世界探索**：没有固定的主线流程，玩家可以自由决定做什么
- **深度技能系统**：大量技能可以自由学习，从战斗技能到生活技能
- **房屋建造**：可以建造和装饰自己的房屋
- **NPC 关系**：与 NPC 建立深厚关系，甚至可以结婚
- **无自动战斗**：手动回合制战斗，强调策略思考
- **以太风突变**：独特的世界观设定，增加沉浸感

## 为什么好玩

Elona 的魅力在于其"什么都可以做"的自由度。你可以是一个冒险家、一个商人、一个农夫、一个魔法师——或者全部。每个系统都足够深，让你总有新的目标去追求。没有自动战斗意味着你需要真正思考每场战斗的策略。

## 粘性来源

- **极致自由度**：没有"正确"的玩法，每个人可以创造自己的故事
- **系统深度**：技能、建造、关系、制作等系统层层叠加，总有新东西可探索
- **意外事件**：随机事件和突变让世界充满惊喜
- **无重复感**：手动战斗+开放世界+随机事件，不会感到枯燥

## Meta 系统

- **角色成长**：技能和属性永久提升
- **房屋系统**：建造和装饰属于自己的家
- **NPC 关系网**：与多个NPC建立关系
- **地牢探索**：随机生成的地牢提供持续的挑战

## 实现难度

高。开放世界+大量独立系统+回合制战斗AI+NPC关系系统。最大技术难点是各系统之间的耦合度和平衡性。
