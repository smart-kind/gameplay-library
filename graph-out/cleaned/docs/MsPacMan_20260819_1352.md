# 吃豆小姐（Ms. Pac-Man）

- **类型**: 街机/迷宫追逐
- **平台**: 街机 / Mobile (iOS+Android) / PC / 多平台复刻
- **开发商**: Midway / General Computer Corporation
- **首次发布**: 1982
- **一句话描述**: 经典迷宫追逐游戏，控制吃豆小姐在迷宫中吃豆子并躲避四个行为各异的幽灵

## 玩法规则

游戏画面是一个封闭的迷宫，迷宫中布满小豆子。玩家控制吃豆小姐（一个黄色的圆形角色，带有红色蝴蝶结和口红标记），通过方向键控制上下左右移动。目标是吃掉迷宫中所有小豆子以过关。

迷宫中有四个不同颜色的幽灵追逐玩家：红色幽灵Blinky（直接追踪玩家当前位置）、粉色幽灵Pinky（预判玩家前进方向并提前拦截）、浅蓝色幽灵Inky（行为最不可预测，基于Blinky和玩家位置计算目标）、橙色幽灵Sue（大部分时间远离玩家，但在特定条件下会突然接近）。

迷宫的四个角落各有一个大能量豆（Power Pellet）。吃掉能量豆后，所有幽灵变成蓝色并可以被反向吃掉。此时玩家可以追逐幽灵获得额外分数（200-1600分，连续吃掉分数递增）。能量效果是暂时的，蓝色幽灵会闪烁提示即将恢复，恢复后幽灵会从迷宫中央的'幽灵之家'重生。

迷宫左右两侧各有一个'传送隧道'——从左侧进入会瞬间从右侧出现，反之亦然。这是逃脱幽灵的重要策略工具。部分迷宫中还会出现水果奖励，吃掉获得额外分数。

## 核心循环

吃迷宫中的小豆子 → 躲避四个幽灵的追逐 → 吃能量豆反杀幽灵 → 清空所有豆子过关

## 核心机制

- **差异化幽灵AI**：四个幽灵各有独特的行为模式和算法，形成复杂而有趣的追逐动态。Blinky紧追不舍、Pinky设下陷阱、Inky难以预测、Sue时远时近。四种AI的组合让每次追逐都有不同体验
- **风险/回报系统**：吃能量豆可以反杀幽灵获得高分（200-1600递增），但能量效果有限且幽灵会快速恢复。选择何时吃能量豆、先追哪个幽灵、是否冒险吃多个，都是策略决策
- **传送隧道机制**：两侧通道的快速传送提供了关键的逃脱和策略选择空间。利用传送隧道可以摆脱紧追的Blinky，或者绕到幽灵后方进行反杀

## 为什么好玩

简单直接的操作配合复杂的幽灵AI，每次追逐都充满紧张感。从被追到反杀的转换带来巨大爽快感——当能量豆吃下、幽灵变蓝的瞬间，攻守易位的体验令人兴奋。四个幽灵不同的行为模式让游戏充满了可学习性和策略深度。

## 粘性来源

紧张刺激的追逐体验提供肾上腺素快感、高分挑战的驱动力（吃掉连续多个幽灵的分数递增）、幽灵行为模式的学习乐趣（掌握每个幽灵的规律后产生掌控感）、经典IP的怀旧情怀、以及简单规则下的无限可玩性

## Meta 系统

分数排行榜系统——追求高分是核心长期目标，吃掉连续幽灵的分数递增（200-400-800-1600）鼓励冒险；关卡速度随进度递增提供持续挑战；水果收集增加额外分数目标

## 实现难度

低 — 操作极简（仅方向键），上手零门槛。最大的技术难点在于四种幽灵AI的行为模式设计和平衡——既要让追逐有挑战性，又要给玩家学习和反制的空间
