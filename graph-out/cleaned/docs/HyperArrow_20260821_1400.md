# Hyper Arrow

- **类型**: 休闲跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: Thu Nguyen Thi
- **首次发布**: 2026
- **一句话描述**: 霓虹风格的极简跑酷，左右滑动躲避障碍挑战最高分

## 玩法规则

游戏采用竖屏操作。角色自动在霓虹赛道上向前奔跑，玩家通过左右滑动控制角色切换跑道。

赛道上布满各种障碍物，需要及时躲避。障碍物类型包括固定障碍、移动障碍、突然出现的陷阱等，需要不同的应对策略。

赛道有霓虹灯风格的视觉效果，配合快节奏的背景音乐。视觉和听觉的配合营造出紧张刺激的氛围。

游戏采用无尽模式，没有终点。跑得越远分数越高，速度会逐渐加快增加难度。每局通常几十秒到几分钟，取决于玩家反应速度。

## 核心循环

左右滑动切换跑道 → 躲避障碍 → 跑得越远分数越高 → 挑战个人最高分

## 核心机制

- **跑道切换系统**: 多条跑道并行，玩家通过滑动在跑道间切换。不同跑道上的障碍物分布不同，需要在极短时间内判断最佳跑道。反应速度和判断力是核心。
  （快速决策）
- **障碍物多样性**: 固定障碍、移动障碍、突发陷阱等多种类型，需要不同的应对方式。障碍物的组合和排列每局都不同。
  （反应挑战）
- **无尽模式递进**: 没有终点，目标是不断打破自己的最高分记录。速度会逐渐加快，障碍物密度也会增加，难度自然递进。
  （自我挑战）

## 为什么好玩

霓虹视觉效果配合快节奏音乐，操作感极佳。无尽模式让人不断挑战自我极限，每次破纪录都有成就感。

## 粘性来源

打破个人最高分的竞争欲、'差一点就破纪录'的不甘心、视觉和音乐的氛围沉浸。无尽模式的'再试一次'心理极强。

## Meta 系统

解锁新角色外观和赛道主题，无深度数值成长。核心驱动力是破纪录。

## 实现难度

低 — 无尽跑酷是成熟的游戏类型，技术实现简单。主要是美术和音效的质量要求。
