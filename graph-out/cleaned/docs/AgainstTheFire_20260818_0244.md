# Against the Fire（Against the Fire）

- **类型**: 双摇杆射击/动作
- **平台**: Mobile (iOS)
- **开发商**: Meridian
- **首次发布**: 2010
- **一句话描述**: 玩家扮演消防员冲进燃烧的摩天大楼营救被困人员

## 玩法规则

游戏采用俯视视角，画面展示燃烧中的摩天大楼内部。玩家扮演消防员手持水枪在各楼层间穿梭。

**操作方式**：
- 左侧虚拟摇杆控制消防员移动方向
- 右侧虚拟摇杆控制水枪喷射方向
- 点击屏幕拾取道具和氧气瓶
- 滑动在不同楼层间移动

**核心玩法**：
- 探索燃烧的摩天大楼，在迷宫般的楼层中寻找被困平民
- 用水枪射击火焰将其熄灭，火焰有不同大小和愤怒表情
- 找到被困平民后，平民会跟随玩家移动
- 将平民带回安全区域即可完成营救
- 收集氧气瓶延长探索时间
- 50层摩天大楼，每层都是不同的迷宫布局

**胜利/结束条件**：
- 关卡成功：营救所有被困平民并安全撤离
- 关卡失败：消防员被火焰吞噬或氧气耗尽

## 核心循环

探索楼层 → 熄灭火焰 → 寻找平民 → 带回安全区 → 进入下一层

## 核心机制

- **双摇杆射击**：左摇杆移动右摇杆喷水，经典双摇杆操作
- **迷宫探索**：每层楼都是迷宫，狭窄走廊和死路增加紧张感
- **跟随系统**：被救平民跟随玩家，需要保护他们安全
- **氧气系统**：收集氧气瓶延长探索时间，增加紧迫感
- **火焰AI**：火焰有大小之分，会主动向玩家移动
- **箭头指引**：屏幕上的箭头指向目标但可能误导进入死路

## 为什么好玩

将射击游戏的水枪换成消防水龙，把僵尸换成火焰，这种角色转换让游戏有了独特的体验。火焰在迷宫中追逐玩家的紧张感，加上营救平民的使命感，创造出与众不同的动作游戏。50层摩天大楼的规模提供了充足的挑战。

## 粘性来源

- **关卡推进**：50层楼的巨大规模提供持久挑战
- **紧张感**：火焰在狭窄走廊中追逐的压迫感
- **营救使命感**：拯救被困平民的道德驱动
- **道具收集**：氧气瓶和强化道具的收集乐趣

## Meta 系统

无 — 游戏以关卡推进为主，无外围成长系统。

## 实现难度

低 — 双摇杆射击框架成熟，主要技术难点在于迷宫生成算法和火焰AI的行为设计。
