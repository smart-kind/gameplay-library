# 文明工匠（CivCrafter）

- **类型**: 放置 / 策略 / 点击
- **平台**: Mobile (iOS+Android)
- **开发商**: Naquatic LLC
- **首次发布**: 2015
- **一句话描述**: 用一根手指打造整个文明——收集资源、建造军队、与其他氏族争夺世界霸权

## 玩法规则

CivCrafter 是一款经典的放置点击策略游戏。玩家通过点击屏幕收集资源（木材、石材、食物、黄金等），用这些资源建造各种建筑和设施，逐步发展自己的文明。

游戏界面分为几个主要区域：顶部显示当前资源数量，中部是建筑列表和升级按钮，底部是战斗和外交功能入口。玩家通过不断点击收集资源，然后用资源建造伐木场、采石场、兵营、农田等建筑。

每个建筑都有多个升级等级，升级后产出效率成倍增长。当建筑达到一定等级后，可以解锁新的建筑类型和功能。比如伐木场达到5级后可以建造锯木厂，进一步提升木材产量。

玩家可以训练军队，与其他玩家或AI对手进行战斗。战斗结果取决于军队数量、兵种搭配和科技等级。加入氏族后，可以参与大规模的氏族对战，争夺世界排行榜排名。

游戏的核心目标是通过资源积累、军事力量和科技升级来建立最强大的文明。整个过程从原始部落逐步发展到现代化帝国，每个阶段都有全新的建筑、兵种和战略选择。

## 核心循环

点击收集资源 → 建造和升级建筑 → 训练军队 → 参与战斗 → 获得更多资源 → 循环

## 核心机制

- 放置自动化机制：建筑会持续产出资源，即使离线也在增长，形成正反馈循环。这是放置游戏的核心，让玩家在碎片时间也能获得进度
- 指数级升级系统：每次升级成本递增但产出也成倍增长，创造'永远差一点就更好'的驱动力。这种数值设计是放置游戏上瘾的根源
- 氏族战斗系统：加入氏族后参与大规模PVP对战，社交竞争大大延长游戏寿命。与朋友一起进步和竞争是核心粘性

## 为什么好玩

CivCrafter 把复杂的文明建设简化成点击操作，但保留了策略深度。看着自己的文明从原始部落一步步发展到强大帝国，满足感极强。战斗系统为纯放置游戏增加了竞争维度，让游戏不仅仅是看数字增长。氏族合作和对抗增加了社交乐趣。

## 粘性来源

指数级增长的数值系统——每次升级都感觉'再升一级就更快了'。氏族系统提供社交压力和归属感，不想落后于朋友。离线收益机制让玩家即使不在线也在进步，打开App总有新收获。战斗系统提供了放置之外的主动参与感。

## Meta 系统

氏族系统：玩家加入氏族，共享资源信息，参与氏族排名战。氏族成员可以互相援助，加速建筑和训练。对核心玩法的影响是增加社交维度和集体目标，让游戏从个人成长扩展到团队协作。

## 实现难度

低 — 核心机制是资源收集和建筑升级，数学模型清晰。最大技术难点是数值平衡，确保升级曲线既有挑战感又不让玩家感到挫败。需要大量的数值测试和调优。
