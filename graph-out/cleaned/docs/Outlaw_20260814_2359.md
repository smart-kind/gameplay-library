# Outlaw

- **类型**: 动作/射击
- **平台**: Mobile (iOS)
- **开发商**: Muhammad Zeeshan
- **首次发布**: 2024
- **一句话描述**: 一款西部题材的动作射击手游

## 玩法规则

玩家扮演西部牛仔，在关卡中面对各种敌人。通过虚拟摇杆控制移动，点击屏幕射击。不同武器有不同的射速和伤害。

关卡中包含掩体系统，玩家可以躲在掩体后避免被击中。敌人会从多个方向出现，需要快速反应。Boss 关卡中，Boss 有特殊攻击模式。

画面采用西部风格，场景包括荒漠小镇、峡谷等。界面左侧为移动控制，右侧为射击和武器切换按钮。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

战斗获取金币 → 购买新武器和升级 → 挑战更难关卡

## 核心机制

- 掩体系统：利用掩体躲避敌人攻击，增加策略维度
- 武器升级：消耗金币提升武器伤害、射速和弹夹容量
- 波次敌人：敌人分多波出现，数量和强度递增

## 为什么好玩

西部题材搭配爽快的射击手感，掩体系统增加了战术思考。

## 粘性来源

武器升级的数值成长和关卡推进的目标驱动。

## Meta 系统

- 武器商店系统：消耗金币购买和升级武器
- 角色皮肤解锁：通过成就或付费解锁不同牛仔外观

## 实现难度

中等 — 射击手感和 AI 敌人行为需要精细调优，最大的技术难点是移动端射击操作的手感优化。
