# Colin McRae: Dirt

- **类型**: 竞速 / 拉力赛
- **平台**: Mobile (iOS)
- **开发商**: Codemasters
- **首次发布**: 2008
- **一句话描述**: 一款拟真风格的拉力赛赛车游戏，玩家驾驶赛车在泥泞的越野赛道上飞驰。

## 玩法规则

游戏画面呈现真实的越野拉力赛道场景——泥泞道路、砂石路面、草地和森林等自然环境。玩家驾驶拉力赛车在赛道上行驶，路面状况直接影响车辆的抓地力和操控性。

操控方式包括：倾斜设备控制转向、触摸加速/刹车/手刹。游戏中最关键的操控是手刹——在弯道中拉手刹可以让车辆漂移过弯，但过度漂移会导致车辆失控甚至翻滚。

赛道上分布着检查点（checkpoint），玩家需要在规定时间内通过所有检查点。碰撞树木、岩石等障碍物会减速甚至损坏车辆。不同路面（泥地、砂石、柏油）有不同的摩擦系数，需要调整驾驶策略。

## 核心循环

驾驶赛车通过赛道 → 漂移过弯/调整路线 → 通过检查点到达终点 → 获得排名解锁新车辆

## 核心机制

- **拉力赛路面物理**：不同路面类型（泥地、砂石、柏油、草地）有不同的抓地力和滑行系数，玩家需要根据实时路况调整速度和转向角度。泥地最容易打滑但漂移也最容易控制。
- **漂移操控**：手刹漂移是核心技巧——在入弯前拉手刹让车尾甩出，利用惯性过弯。漂移时机和力度决定了过弯速度和安全性。
- **车辆损坏系统**：碰撞障碍物会导致车辆性能下降（引擎动力降低、转向不灵敏），严重碰撞会导致车辆翻覆需要重新起步，增加了风险管理的维度。

## 为什么好玩

拉力赛的精髓在于"在失控边缘找控制"——既要利用漂移获得更快的过弯速度，又要避免真正失控翻车。这种在危险和精准之间走钢丝的体验非常刺激。加上真实的路面反馈音效，沉浸感很强。

## 粘性来源

- **技术进步感**：每次失败后玩家能更清楚哪个弯道该提前刹车、哪个弯道可以全速漂移，技术进步的反馈非常直观。
- **圈速挑战**：不断刷新自己的最快时间，追求完美跑法的动力持续存在。
- **车辆收集**：解锁不同性能的拉力赛车（不同品牌、马力、重量），给每种车找到最佳驾驶风格是一种乐趣。

## Meta 系统

- **车辆解锁**：赢得比赛或完成挑战解锁更多真实拉力赛车。
- **赛事模式**：包含锦标赛模式，多场比赛累积积分争夺总冠军，增加了长线目标。

## 实现难度

高。最大技术难点是拉力赛物理的模拟——需要精确计算不同路面的摩擦力、车辆的重量转移、以及漂移时的动态物理响应。另外，赛道的环境渲染（泥土飞溅、车辙痕迹）也需要较高的图形处理能力。

## 变体设计

可以加入"天气系统"——同一赛道在晴天、雨天、雪天的摩擦力完全不同，大幅增加策略深度。也可以加入"多人分屏对战"，让朋友之间直接比拼谁更会漂移。
