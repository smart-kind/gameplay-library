# Angry Birds Friends（愤怒的小鸟：好友）

- **类型**: 物理弹射 / 解谜 / 社交竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: Rovio Entertainment Oyj
- **首次发布**: 2013
- **一句话描述**: Angry Birds的多人竞技版本——每周更新35+新关卡，与全球玩家比拼分数的弹射解谜游戏。

## 玩法规则

游戏采用经典的Angry Birds弹弓机制。屏幕左侧有一个弹弓，上面放着一只或多只小鸟。屏幕右侧是用各种材料（木头、玻璃、石头、冰块）搭建的结构，结构中藏着绿猪敌人。

玩家操作：用手指拖拽弹弓上的小鸟调整发射角度和力度，松手后小鸟沿抛物线飞出，命中建筑物后产生破坏效果。不同小鸟有特殊能力：红色小鸟无特殊能力，黄色小鸟在空中点击会加速冲刺，蓝色小鸟会分裂成三只，黑色小鸟点击后爆炸，白色小鸟会产下爆炸蛋。

游戏目标是消灭结构中所有的绿猪。消灭方式包括直接撞击、被倒塌的建筑压扁、或被爆炸波及。部分关卡有特殊机制，如TNT炸药箱（被撞击后爆炸）、气球（携带物体升空）、弹簧（弹射物体）等。

## 核心循环

选择小鸟并弹射 → 利用小鸟特殊能力和物理破坏消灭绿猪 → 获得分数 → 与全球玩家排名比较 → 参加新锦标赛

## 核心机制

- **弹弓弹射系统**：拖拽调整角度和力度，松手发射。这是整个系列的核心操作，简洁直观但有深度——角度、力度、释放时机的微小差异会导致完全不同的结果。
- **小鸟特殊能力**：每只小鸟在空中时可以激活一次特殊能力，增加了操作的策略维度。玩家需要判断何时激活能力以获得最大效果——过早或过晚都可能浪费能力。
- **锦标赛竞争系统**：每周更新35+全新关卡，玩家在同一套关卡中竞争。排名基于每关的最高分数总和。每周主题不同，关卡设计围绕主题展开。这个机制创造了公平竞争环境——所有人面对相同的关卡。

## 为什么好玩

经典Angry Birds玩法的竞技化升级。每周新关卡保持了内容的新鲜感，与全球玩家竞争排名增加了紧迫感。熟悉的弹弓操作+新关卡=低门槛高挑战。

## 粘性来源

核心是"每周锦标赛"的竞争机制。限定时间的锦标赛创造了稀缺感——错过一周就错过了。排行榜驱动玩家反复尝试同一关卡以获得更高分。主题变化（节日、季节、特殊事件）让每次更新都有新鲜感。好友系统让竞争更具社交性——与认识的人比拼比分陌生人的排行榜更有动力。

## Meta 系统

锦标赛系统：每周4次新锦标赛（周一、周三、周四、周六开始），每次35+关卡。星级杯（Star Cup）是1v1对战模式。好友排行榜和全球排行榜提供多层竞争目标。

## 实现难度

中。2D物理引擎（Box2D）是核心，小鸟飞行轨迹、建筑破坏、碰撞检测都需要精确模拟。最大技术难点在于多人公平性——确保所有玩家的物理模拟完全一致，以及每周新关卡的设计质量和测试。
