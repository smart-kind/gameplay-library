# 细菌占领 - 放置游戏（Bacterial Takeover - Idle game）

- **类型**: 放置/模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2017
- **一句话描述**: 细菌繁殖扩张的放置游戏

## 玩法规则

玩家培养细菌菌落，细菌自动繁殖和扩张。通过点击或升级加速细菌生长。细菌可感染新的区域，扩大领地。解锁不同类型的细菌，各有特殊能力。升级提升繁殖速度、感染范围和抵抗力。游戏以指数增长为核心体验，数值增长带来强烈满足感。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

培养细菌 → 感染新区域 → 解锁新菌种 → 加速繁殖 → 继续扩张

## 核心机制

- **指数增长**:  细菌数量呈指数级增长
- **区域扩张**:  感染新领地扩大版图
- **菌种解锁**:  不同类型细菌有特殊能力

## 为什么好玩

指数增长的震撼感，从小菌落到全球覆盖的成就感

## 粘性来源

数值增长的快感；新区域和菌种解锁的期待

## Meta 系统

菌种收集和升级系统

## 实现难度

低 - 核心是数值增长模型 - 大规模数值计算的性能优化
