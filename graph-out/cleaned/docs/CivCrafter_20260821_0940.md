# CivCrafter

- **类型**: 放置 / 策略 / 模拟经营
- **平台**: Mobile (iOS)
- **开发商**: Naquatic
- **首次发布**: 2015
- **评分**: ⭐ 4.6/5 (5,968 评价)
- **价格**: Free
- **一句话描述**: 用一根手指打造整个文明！被称为"点击游戏的母亲"和"最上瘾的手机游戏"。

## 玩法规则

游戏开始时玩家只有一个原始人。通过点击屏幕收集资源（食物、木材、石头等）。用资源建造建筑：住房、农田、工作坊等。每种建筑自动产出特定资源或解锁新功能。随着文明发展，解锁新科技、新建筑类型、新资源。游戏界面以文明发展进度为核心：从原始部落到现代文明。玩家可以看到文明在屏幕上逐步扩展——建筑增多、人口增长、科技树扩展。

## 核心循环

点击收集资源 → 建造/升级建筑 → 解锁科技 → 文明进步 → 继续扩展

## 核心机制

- 文明进化：从原始部落到现代文明的完整进化链
- 自动生产：建筑自动产出资源，放置玩法
- 科技树：解锁新建筑和功能的渐进系统

## 为什么好玩

看着文明从无到有逐步壮大，这种"创造"的满足感极强。点击游戏的鼻祖级体验。

## 粘性来源

文明进化的宏大叙事、数值增长的满足感、解锁新科技的期待

## Meta 系统

完整的放置经济+科技树系统。核心玩法就是meta。

## 实现难度

低——点击游戏模板成熟，数值平衡和科技树设计是关键
