# Hyperball

- **类型**: 街机 / 体育竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: AI Games FZ
- **首次发布**: 2018
- **评分**: ⭐ 4.6/5 (84,222 评价)
- **价格**: Free
- **一句话描述**: 一款快节奏的街机式足球游戏，玩家控制车辆带球射门，目标是在时间结束前比对手进更多球。

## 玩法规则

游戏在一个小型封闭场地中进行（俯视角）。玩家控制一辆带球的汽车，通过虚拟摇杆或滑动控制方向和速度。目标是把球撞进对方球门。场地中有墙壁可以反弹球和车辆。游戏节奏极快，一局通常1-2分钟。操作只有方向控制——车辆自动前进，玩家只需转向。球有物理惯性，需要预判反弹路线。双方同时操作，没有回合制。界面简洁：场地中央、双方球门、比分和时间显示在顶部。

## 核心循环

进入匹配 → 快节奏对战 → 进球得分 → 赢得比赛 → 下一局

## 核心机制

- 极简控制：只需控制方向，自动前进，降低上手门槛
- 物理反弹：墙壁反弹增加策略深度——可以故意反弹球改变路线
- 快速一局：1-2分钟一局，节奏紧凑

## 为什么好玩

把足球和赛车结合，控制简单但物理反弹带来丰富的策略可能。快节奏对战让人停不下来。

## 粘性来源

快速一局的"再来一局"效应、物理反弹的不可预测性、PvP竞技

## Meta 系统

车辆/球皮肤解锁、段位系统。不影响核心玩法。

## 实现难度

中——物理引擎和实时多人同步是技术难点
