# 连接字母拼单词的文字解谜游戏（Word Connect）

- **类型**: 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Zentertain
- **首次发布**: 2016
- **一句话描述**: 连接字母拼单词的文字解谜游戏

## 玩法规则

屏幕上一圈字母，玩家需要滑动连接相邻字母组成有效的英文单词。每个关卡有特定的单词列表需要全部找出。找出的单词填充到网格中。随着关卡推进，字母数量和单词难度增加。

## 核心循环

观察字母 → 滑动连接拼词 → 找出所有单词 → 过关 → 下一关

## 核心机制

- 字母环连接：滑动连接相邻字母组成单词
- 单词网格：找出所有单词填充网格
- 关卡递增：字母数量和单词难度逐渐增加
- 提示系统：可以用硬币获取提示

## 为什么好玩

简单的文字游戏但有深度，找到所有隐藏单词的成就感很强。同时扩展词汇量。

## 粘性来源

词汇挑战；关卡驱动；学习新单词。

## Meta 系统

关卡解锁。

## 实现难度

低。字母连线简单。最大技术难点：词库和关卡生成。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
