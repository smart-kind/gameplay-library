# Gravity Mike（Gravity Mike）

- **类型**: 物理弹射 / 平台跳跃
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer收录
- **首次发布**: 2015
- **一句话描述**: 一款利用重力反转机制的物理平台跳跃游戏，玩家通过切换重力方向来控制角色穿越充满障碍的关卡。

## 玩法规则

游戏画面是一个横版平台场景，角色Mike默认站在平台表面受重力影响向下。屏幕上有多个平台、障碍物分布在上下两侧，形成对称或不对称的布局。

核心操作只有一个：点击屏幕切换重力方向。正常重力时角色站在下方平台向上受重力牵引，切换后角色会翻转掉到上方的天花板上继续自动向前移动。

玩家需要根据场景中障碍物的位置，选择合适时机切换重力，让角色从安全的一侧通过障碍。有些关卡在上下两侧都设置了陷阱，需要精确判断切换时机，早一秒晚一秒都会撞上障碍。

游戏目标是从起点到达终点，收集沿途的金币和星星。碰到障碍物则失去生命或重新开始当前检查点。部分关卡设有关卡内隐藏收集品，需要冒险走危险路线才能获取。

## 核心循环

观察障碍物分布 → 切换重力方向绕过障碍 → 收集金币 → 推进到下一关

## 核心机制

- **机制1**：重力反转机制：核心玩法围绕单一操作即点击切换重力方向。这种极简控制让游戏易于上手，但障碍物的复杂布局要求精准判断切换时机。随着关卡推进，障碍物的排列越来越精巧，需要连续多次切换才能通过。
- **机制2**：惯性物理机制：角色在重力切换后有真实的掉落动画和惯性滑行，增加了物理真实感和可预测性。玩家需要预判掉落轨迹来精确导航，而不是瞬间传送式的移动。
- **机制3**：收集品布局机制：金币和星星通常放置在危险位置如两个障碍之间或陷阱附近，引导玩家冒险以获取额外奖励。这增加了策略层次，让玩家在安全路线和高分路线之间权衡。

## 为什么好玩

重力反转带来的空间感知错乱感非常有新鲜感，每次切换都像在挑战自己对上下方向的本能认知。通过一个精心设计的复杂关卡的成就感很强，让人想要分享自己的通关方法。

## 粘性来源

空间认知挑战带来的再来一次就能过的冲动加上精确操作带来的成就感加上关卡设计逐步引入新元素保持新鲜感，三因素叠加让人欲罢不能。

## Meta 系统

关卡解锁系统加收集品累计，完成特定条件如收集所有星星可解锁新关卡区域和特殊主题。有隐藏关卡等待玩家发现。

## 实现难度

中 -- 需要物理引擎支持重力切换和惯性运动，关卡编辑器是主要技术投入。最大难点是设计既有趣又公平的关卡，让玩家觉得失败是自己的问题而非游戏设计不公平。

## 关卡设计示例

- **第1-5关**：基础教学，障碍物简单分布，只有一侧有陷阱，让玩家理解重力切换
- **第6-15关**：上下两侧都有障碍，需要连续切换2-3次
- **第16-30关**：引入移动障碍和隐藏通道，需要探索才能发现最佳路线
- **第31关+**：复杂障碍组合，重力切换时机窗口极小，需要精确操作
