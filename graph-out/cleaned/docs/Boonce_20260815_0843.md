# 弹球收集（Boonce (Bounce and Collect)）

- **类型**: 益智 / 物理弹射
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2021
- **一句话描述**: 一款基于物理弹跳的益智游戏，控制小球在平台上弹跳，通过倍增器最大化球的数量和得分。

## 玩法规则

游戏画面为竖屏，球从屏幕顶部落下，下方有各种平台、倍增器和障碍物。玩家需要在球掉落前调整接球位置或发射角度。

玩家通过滑动屏幕调整弹射方向和力度，点击发射。球在平台上弹跳时经过倍增器会分裂成更多球。目标是在有限的弹跳次数内收集尽可能多的球。

游戏中有各种特殊平台：倍增器（×2、×3）、障碍物（消除球）、传送门（改变弹道）。合理利用倍增器可以指数级增长球的数量。

每关有目标球数，达到即可过关。球全部消除或弹跳次数用尽则关卡结束。

## 核心循环

玩什么 → 得到什么 → 用来做什么：瞄准弹射让球倍增收集更多球，解锁新关卡来挑战更高目标

## 核心机制

- **物理倍增系统**：球经过倍增器时数量翻倍，合理规划路径可以实现指数级增长。一个球变几百个的满足感极强，视觉反馈非常到位
- **路径选择策略**：每个关卡有固定的平台布局，玩家需要在发射前仔细规划弹道路径，优先经过高倍率倍增器。最佳路径往往需要多次尝试
- **动态弹跳反馈**：球之间的碰撞和弹跳动画非常流畅，看着球越来越多极具视觉冲击力。物理模拟让每次弹跳都有微妙的不同

## 为什么好玩

从一颗球弹到几百颗球的视觉冲击极其满足。物理弹跳的随机性和策略规划的确定性形成有趣对比。每次找到最优路径时的顿悟感很棒。

## 粘性来源

物理弹跳的爽感反馈（看着球越来越多）+ 策略挑战（找到最优倍增路径）+ 关卡解锁。每一关都是新的物理谜题。

## Meta 系统

- **关卡推进**：完成当前关卡解锁下一关，难度逐步增加。关卡设计从简单倍增到复杂路径规划
- **球皮肤解锁**：达成条件解锁不同外观的球，仅为装饰用途
- **对核心玩法影响**：无，纯关卡制，皮肤仅为外观装饰，不影响 gameplay

## 实现难度

低 — 滑动瞄准加发射操作简单直观，策略深度体现在路径规划而非操作。最大技术难点在于物理引擎中大量球的碰撞计算优化。需要确保几百个球同时弹跳时仍保持流畅帧率。
