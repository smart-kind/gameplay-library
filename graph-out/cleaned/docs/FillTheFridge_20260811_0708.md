# Fill The Fridge（Fill The Fridge）

- **类型**: 休闲 / 益智 / 整理 / ASMR
- **平台**: Mobile (iOS+Android)
- **开发商**: Rollic
- **首次发布**: 2022
- **一句话描述**: 将各种食物和物品整齐地放入冰箱的收纳游戏中

## 玩法规则

画面展示一个空的（或部分填充的）冰箱内部，有若干层架子和门上的储物格。屏幕下方或侧面有一组需要放入冰箱的物品——包括饮料瓶、食物盒、水果、调料罐等，形状和大小各异。

玩家通过拖拽操作将物品从供应区移动到冰箱内的空格中。每个物品占据一定空间，玩家需要合理安排位置才能让所有物品都放得下。

物品可以旋转（通过双击或长按旋转手势），以便更好地适应空间。某些关卡有额外的约束——比如"饮料必须在门格上"、"水果必须在最上层"等规则。

如果所有物品都成功放入冰箱，关卡完成。如果空间不够或违反了特定规则，需要重新调整布局。

## 核心循环

观察物品 → 拖拽放入冰箱 → 旋转调整 → 填满冰箱 → 过关

## 核心机制

- **空间整理**: 核心玩法是空间管理——在有限的冰箱空间中合理安排各种形状和大小的物品。类似俄罗斯方块但更自由（物品可以任意位置放置，不只有底部支撑）。
- **拖拽+旋转**: 直观的手势操作让游戏极易上手。旋转功能增加了策略维度。
- **规则约束**: 后期关卡引入额外规则（物品必须在特定位置、某些物品不能相邻等），增加了解谜深度。
- **TikTok趋势改编**: 基于社交媒体上流行的"整理冰箱"视频趋势，天然具有熟悉感和共鸣。

## 为什么好玩

将日常家务变成有趣的挑战——"把冰箱塞满"本身就是一种满足感。看着杂乱的物品变得井井有条，有极强的整理成就感。

## 粘性来源

- **整理满足感**: 看着杂乱物品变得有序，有极强的心理满足感
- **ASMR元素**: 物品放入冰箱时的音效和视觉效果有放松作用
- **关卡多样性**: 不同冰箱布局、不同物品组合保持新鲜感
- **社交共鸣**: 源自TikTok热门趋势，玩家天然有认同感

## Meta 系统

关卡推进系统——完成关卡解锁新冰箱类型和新物品。无消耗系统。

## 实现难度

低。核心是2D/3D拖拽 + 碰撞检测 + 空间验证。最大难点在于关卡设计——需要确保每个关卡都有可行的解法，同时难度递增自然。
