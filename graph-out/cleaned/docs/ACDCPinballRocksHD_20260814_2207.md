# AC/DC弹珠台（AC/DC Pinball Rocks HD）

- **类型**: 弹珠台 / 街机
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发者
- **首次发布**: 2012
- **一句话描述**: 以AC/DC摇滚乐队为主题的3D弹珠台游戏，在经典弹珠玩法中融入摇滚音乐和视觉元素

## 玩法规则

游戏呈现一个精细的3D弹珠台画面，包含左右两个弹射挡板、顶部的弹珠发射器、台面上各种得分目标和机关。台面设计以AC/DC乐队的摇滚主题为核心，有乐队标志、专辑封面和相关视觉元素。

玩家从底部发射弹珠进入台面，通过点击屏幕左右两侧控制对应挡板，将弹珠反弹到各种得分区域。台面上有多种得分目标：旋转靶（击中多次得分递增）、坡道（引导弹珠到上方得分区）、弹出孔（弹珠落入后从另一位置弹出并触发特殊事件）、滚动球道（弹珠穿过时计分）。

操作方式：按住发射器蓄力松开弹射弹珠、点击左/右屏幕控制左/右挡板。玩家需要精准判断弹珠的弹道和落点，在弹珠即将掉落时及时弹起。

游戏目标是在有限弹珠数量内获得最高分数，触发特殊模式和连击奖励。弹珠掉落一次失去一颗，通常每局有3颗弹珠。

## 核心循环

弹射弹珠 → 控制挡板反弹 → 击中得分目标 → 触发特殊模式 → 获得高分

## 核心机制

- **弹道物理**：弹珠的运动遵循物理规律，包括重力、碰撞反弹和摩擦力，需要玩家预判弹道走向
- **多连击系统**：连续击中同一类目标触发连击倍率，奖励精准操作
- **模式触发**：特定目标组合可激活限时特殊模式，期间得分倍率大幅提升
- **摇滚主题集成**：AC/DC经典音乐作为背景音效，击中特定目标时播放对应乐段，增强沉浸感

## 为什么好玩

弹珠台游戏的魅力在于物理弹射的随机性与精准控制的结合——每次弹击结果都不可完全预测，但高手能通过挡板控制将弹珠引导到高分区域。摇滚主题让经典玩法焕发新意。

## 粘性来源

高分追逐（"差5000分就破纪录"）、模式触发概率的随机性、不同弹道组合的实验乐趣。物理引擎保证每局都是独特体验，不会因重复而失去新鲜感。

## Meta 系统

无。纯街机游戏，无外围成长系统。

## 实现难度

中等。弹珠物理模拟需要精确的碰撞检测和重力计算，3D台面渲染也需要一定技术投入。最大难点是弹道物理的真实感和挡板控制的响应速度优化。
