# Brain It On!（Brain It On!）

- **类型**: 物理绘图解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Orbital Nine Games
- **首次发布**: 2016
- **一句话描述**: 通过手绘形状来解物理谜题的益智游戏，玩家用画笔在屏幕上画出各种形状来完成特定目标。

## 玩法规则

游戏界面简洁——一个2D物理场景中包含若干固定障碍物、需要移动的目标物体和一个目标区域。玩家在屏幕上用手指画出各种形状（线条、圆形、方形、任意曲线等），这些画出的形状会立即获得物理属性并参与物理模拟。

每个关卡都有一个明确目标：让红球落入指定区域、击碎特定物体、将某个物品推到目标位置等。玩家画出的形状会受重力影响掉落，同时与场景中其他物体发生碰撞。玩家可以用线条搭建斜坡让球滚动，画圆形作为轮子，画不规则形状作为杠杆或配重。

关卡没有任何操作次数限制，但提供了"最佳解"参考。玩家可以反复尝试不同的画法，直到找到能让目标完成的形状。游戏没有"失败"状态——只有完成或未完成的区分。

## 核心循环

观察场景 → 手绘解决方案 → 观察物理模拟 → 调整画法重复尝试

## 核心机制

- **自由绘图机制**：玩家可以画出任意形状，没有预设模板或固定答案。系统会自动识别闭合区域为实体形状，线条为刚性物体。这种完全自由的方式让每个关卡都有无数种可能的解决方案，鼓励创造性思维。
- **2D物理模拟**：游戏内置完整的2D刚体物理引擎，所有物体都受重力、摩擦力、碰撞力影响。玩家画出的形状会按照真实物理规律运动，使得解题过程既直观又有深度——需要理解重心、杠杆原理、动量传递等概念。
- **无惩罚试错**：没有步数限制或失败惩罚，玩家可以无限次重画。这种设计降低了入门门槛，让玩家专注于"寻找答案"而非"避免失败"。
- **多解奖励**：同一关卡可以用多种完全不同的方式完成，鼓励玩家分享自己的创意解法并与他人比较。

## 为什么好玩

"我画个东西就能解决物理谜题"——这种从纯消费者变成创造者的体验非常独特。当玩家画出一个歪歪扭扭的形状，看着它按照物理规律完美完成任务时，会有一种"我自己发明了答案"的成就感。不同玩家的画法差异极大，有人画出精密的机械结构，有人用几根线条就搞定，这种多样性本身就是乐趣。

- **多解可能性**：每道关卡没有唯一正确答案。玩家可以用完全不同的方式解决同一问题——有人画出精密的机械装置，有人只用一根斜线就让球自然滚落。这种开放性鼓励实验和探索。
- **物理直觉的培养**：游玩过程中玩家会潜移默化地学习到物理概念——重心、杠杆、动量、摩擦力。当玩家画出"正确的形状"时，实际上是在运用这些物理直觉。

## 粘性来源

- **创造性表达的满足感**：每一道关卡都是一道开放性难题，用自己的方式解决带来的成就感远超"按提示操作"的游戏
- **"差一点就对了"的持续动力**：物理模拟的精确性意味着玩家常常离成功只差微调——角度差一点、形状少一笔——这种"几乎成功"的状态驱使人不断尝试
- **社交比较**：观看他人的解法视频（尤其是出人意料的巧妙方案）会激发"我也能想出更好办法"的竞争心理

## Meta 系统

- **关卡解锁系统**：完成一定数量关卡后解锁新关卡集合，每集合有不同的主题和目标类型。
- **皇冠评级**：部分关卡提供"皇冠"作为完美解法的奖励，鼓励玩家寻找最优方案。
- **每日挑战**：每天推送新的特殊关卡，增加持续游玩动力。

## 实现难度

中。核心难点在于2D物理引擎的集成和自定义形状的碰撞体生成。需要将玩家手绘的任意形状实时转换为物理碰撞体，这在技术上有一定挑战但Box2D等成熟引擎已能较好处理。最大的设计难点是关卡设计——需要确保每道关卡既有解又不会太容易。
