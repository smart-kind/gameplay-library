# Flow Free Bridges（Flow Free: Bridges）

- **类型**: 解谜 / 连线
- **平台**: Mobile (iOS+Android) / Web
- **开发商**: Big Duck Games
- **首次发布**: 2013
- **一句话描述**: 经典连线解谜游戏Flow的变体，增加了桥梁叠加的机制

## 玩法规则

游戏画面为一个N×N的网格（关卡从5×5逐渐增大到10×10甚至更大），网格上有若干彩色圆点成对出现。每对圆点颜色相同，需要用一条连续路径连接起来。

玩家用手指从一个彩色圆点按住拖动到同色的另一个圆点，画出一条路径。路径只能沿网格上下左右移动，不能斜走。路径不能交叉其他颜色的路径（除非使用桥梁）。

桥梁是本游戏相比原版Flow的核心创新：在路径交叉点，玩家可以放置一座小桥让两条不同颜色的路径在视觉上交叉而不冲突。桥梁数量有限（每个关卡有固定数量的桥梁可使用），需要策略性使用。

通关需要同时满足两个条件：（1）所有同色圆点都被路径连接，（2）整个网格被路径完全填满，没有空白格子。两个条件缺一不可。

关卡按难度递增，网格越来越大，颜色对越来越多（从2对到10+对），桥梁使用限制也越来越严格（有些关卡禁止使用桥梁）。

## 核心循环

观察颜色配对 → 规划整体路径布局 → 画出连线 → 检查填满 → 挑战下一关

## 核心机制

- **桥梁叠加机制**：相比原版Flow，Bridges版本允许路径在交叉点建桥通过。桥梁是有限资源，每个关卡只有特定数量的桥梁可用。玩家需要判断在哪个交叉点使用桥梁才能最优地填满整个网格。桥梁用完后就无法在剩余位置交叉。
- **空间填充约束**：不仅要连接所有颜色对，还要完全填满网格不留空格。这意味着每条路径都需要尽可能"挤满"可用空间。路径不能太短（否则留空），也不能绕太远（否则与其他路径冲突）。
- **路径回溯**：画出的路径可以随时擦除重画。但效率高的玩家需要先在脑中规划好整体布局再动手，而非边画边改。高手通常能快速看出最优解的整体结构。

## 为什么好玩

从简单关卡的"一目了然"到高难度关卡的"绞尽脑汁"，解谜的满足感层层递进。看到网格被完美填满的瞬间非常有成就感。桥梁机制在原版基础上增加了策略维度。

## 粘性来源

关卡递进（从5×5到10×10+）+ 完美追求（填满网格的强迫症满足）+ 每日挑战（每日更新的特殊关卡）。桥梁机制增加了策略深度，让老玩家也有新的挑战。

## Meta 系统

关卡包系统：游戏按主题分为多个关卡包（如"经典"、"彩虹"、"专家"），每个包有数十到上百个关卡。纯免费模式，通过广告变现，无付费内容。

## 实现难度

低 — 核心算法（路径验证、桥梁放置）简单。最大技术难点是关卡设计和难度曲线的把控，确保每关有且仅有一个优雅解。
