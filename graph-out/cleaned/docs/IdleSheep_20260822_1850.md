# 闲置羊场（Idle Sheep!）

- **类型**: 放置 / 点击 / 模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: Mindstorm Studios
- **首次发布**: 2016
- **一句话描述**: 点击屏幕养羊赚钱，打造自动化农场——即使不玩游戏也在持续盈利

## 玩法规则

Idle Sheep! 是一款极简的放置点击农场游戏。核心操作只有一种：点击屏幕上的羊来赚取金钱。随着游戏推进，系统会自动产生收益，即使玩家不在线也在积累财富。

游戏界面非常简洁：中央是一只可以点击的大羊，点击一次赚取一定数量的金钱。顶部显示当前金币总数和每秒产出（GPS）。右侧有一排升级按钮，可以购买更多羊、升级点击效率、解锁自动化生产设备。

每次升级都会提高单位时间的产出。购买的羊越多、等级越高，每秒自动产生的金币就越多。自动化设备如自动剪毛机、羊毛加工厂等，可以在玩家不操作时持续产出。

当金币积累到一定程度后，可以进行"转生"（prestige），重置当前进度但获得永久加成倍数。每次转生后的游戏速度都比上次更快，解锁的内容也更多。

游戏目标是积累尽可能多的金币，解锁所有升级项和自动化设备，体验从零到天文数字的增长过程。

## 核心循环

点击羊赚取金币 → 购买升级 → 提高自动产出 → 转生获得永久加成 → 重新开始更快进程

## 核心机制

- 点击反馈机制：每次点击都有视觉弹跳和金币数字飞溅效果，产生即时满足感。这种微小的反馈循环是点击游戏上瘾的基础
- 自动化递增：随着升级，产出从手动点击逐渐过渡到全自动运行，玩家角色从操作者变为管理者
- 转生系统：重置进度换取永久加成，让每次新游戏都比上一次更强。这是放置游戏的经典设计

## 为什么好玩

极简操作配合指数增长的数字带来纯粹的快感。看着金币从个位数增长到万亿级别，成就感十足。游戏界面可爱有趣，羊的动画效果增加了娱乐性。适合碎片时间偶尔点开看一眼。

## 粘性来源

数字增长的视觉冲击——从几金币到天文数字的进化过程令人上瘾。转生系统让每次重置都充满期待。自动化产出让玩家'即使不玩也在赚钱'的安心感。可爱的视觉风格让人愿意打开App。

## Meta 系统

转生（Prestige）系统：重置所有金币和建筑，获得永久加成系数。每次转生后加成系数递增，游戏进度更快。对核心玩法的影响是让每次重开都比上次更高效，形成螺旋上升的进度感。

## 实现难度

低 — 纯数值驱动，无需复杂AI或物理引擎。最大技术难点是数值曲线设计，需要确保从游戏开始到后期都有合适的挑战节奏，避免后期变得无聊。
