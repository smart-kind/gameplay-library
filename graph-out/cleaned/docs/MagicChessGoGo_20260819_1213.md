# Magic Chess: Go Go（自走棋：冲锋）

- **类型**: 自走棋 / 策略 / 多人对战
- **平台**: Mobile (iOS+Android)
- **开发商**: Skystone Games Pte. Ltd.
- **首次发布**: 2024
- **一句话描述**: 在自走棋玩法基础上加入即时操作元素，自动战斗中加入手动技能释放，8人对战直到最后一人。

## 玩法规则

每局8名玩家参与对战。游戏在一个棋盘上进行，棋盘分为两个区域：**准备区**（玩家自己的区域，用于排兵布阵）和**战斗区**（自动进行战斗）。

游戏分为回合制，每个回合分为两个阶段：

**准备阶段**：玩家从随机出现的英雄池中购买英雄（消耗金币），将英雄拖拽到准备区/战斗区的棋盘上。英雄按职业和种族分为不同类别，同时上阵相同职业/种族的多个英雄会激活羁绊加成（如3个法师获得全队法术伤害+30%）。每回合结束后，玩家获得金币收入（基础收入+连胜/连败奖励+利息——未使用的金币会生息，每10金币每回合产生1金币利息）。

**战斗阶段**：战斗自动进行，玩家操控的英雄自动寻找敌方单位攻击。但在战斗过程中，玩家可以**手动释放英雄技能**——当英雄的能量条满时，玩家可以点击英雄主动施放技能，这是与传统自走棋最大的区别。技能释放的时机选择（如等敌方聚集后再放范围技能）直接影响战斗结果。

战斗失败的玩家会失去生命值，生命值为0时被淘汰。最后存活的玩家获胜。

## 核心循环

购买英雄 → 排兵布阵激活羁绊 → 战斗阶段手动释放技能 → 获得金币 → 升级/购买更强英雄 → 持续强化阵容 → 击败所有对手

## 核心机制

- **手动技能释放**：与传统自走棋的纯自动战斗不同，玩家需要判断最佳技能释放时机，增加了操作维度和策略深度。
- **经济管理**：金币的使用需要在"购买英雄"、"升级等级"（增加可上阵英雄数量）和"存钱吃利息"之间做权衡。
- **羁绊系统**：不同职业/种族的组合产生不同的加成效果，玩家需要根据随机出现的英雄池灵活调整策略。
- **随机英雄池**：每回合出现的英雄是随机的，玩家需要在"追求完美阵容"和"利用现有资源"之间做决策。

## 为什么好玩

Magic Chess: Go Go 在传统自走棋的"策略深度"基础上加入了"操作时刻"——手动释放技能的环节让战斗不再只是旁观。当你看到敌方英雄聚成一团，然后精准地按下技能按钮释放一个大范围控制技时，那种"操作改变战局"的成就感是纯自动自走棋无法提供的。

## 粘性来源

- **8人对战**：每局都是与其他7名真实玩家竞争，社交竞技感强。
- **随机性+策略**：随机英雄池确保每局体验不同，但策略深度保证了可玩性。
- **段位系统**：排位赛驱动玩家不断提升。
- **阵容多样性**：大量英雄和羁绊组合鼓励玩家尝试不同策略。

## Meta 系统

- **段位系统**：青铜到王者的排位赛制。
- **英雄收藏**：解锁和收集不同英雄的皮肤。
- **赛季通行证**：每赛季推出新内容和奖励。

## 实现难度

高。核心难点是8人实时对战的网络同步、自动战斗的AI逻辑（路径寻路、目标选择、伤害计算）、手动技能释放的低延迟要求，以及经济系统和英雄平衡的数值设计。
