# 糖果消消乐（Gummy Drop! Match 3 Puzzles）

- **类型**: 三消 / 世界旅行 / 城市建设
- **平台**: Mobile (iOS+Android)
- **开发商**: Big Fish Games / 7 Hits Games
- **首次发布**: 2014
- **一句话描述**: 以世界旅行为主题的三消游戏，通过消除关卡收集资源，重建世界各地的标志性建筑

## 玩法规则

游戏棋盘为 8×8 或更大的网格，铺满各种颜色和形状的软糖。玩家交换相邻软糖实现三消或更多连消。

消除特定颜色/类型的软糖后，会产生对应的"资源"（如木材、石头、金属），这些资源用于修复和建造世界各地的地标建筑（如埃菲尔铁塔、金字塔、泰姬陵等）。

关卡目标多样：在限定步数内消除指定数量的软糖、收集特定物品、清除障碍物（冰块、藤蔓、石头）、或帮助软糖掉落到底部的"传送门"。

特殊消除机制与普通三消类似：四消、五消、L/T型消除产生特殊软糖。但本作加入了"传送带"、"锁链"等额外障碍元素，增加策略复杂度。

部分关卡有"掉落"机制：需要从顶部消除障碍物，让底部的软糖能"掉落"到指定出口。

## 核心循环

消除软糖完成关卡 → 收集建造资源 → 修复世界地标 → 解锁新城市和关卡

## 核心机制

- **三消匹配机制**: 经典交换匹配玩法，但在基础三消之上加入了障碍物系统（冰块、锁链、传送带），需要特定次数的消除或特定消除方式才能破除
- **资源收集机制**: 消除特定颜色的软糖产出对应资源，资源用于城市建设。这种"消除=收集"的映射让每次消除都有双重意义
- **世界旅行主题**: 每个城市有独特的地标建筑需要修复，建筑修复过程可视化展示（从废墟到完整），提供强烈的成就感

## 为什么好玩

将三消的即时快感和城市建设的长线目标结合，每次消除不仅在解谜，还在"建造"世界。看到埃菲尔铁塔从一堆废墟逐渐修复完成的视觉反馈非常有满足感。

## 粘性来源

地标建筑的渐进修复提供长期目标；世界旅行主题的探索欲（"下一个城市是哪里"）；三消关卡本身的短周期正反馈；资源收集的不完全感（"再消除几个就够了"）。

## Meta 系统

城市建设系统：通过关卡获得的资源修复各地标建筑，每个建筑修复后解锁新城市和新关卡。建筑修复进度可视化，是游戏的主要长线驱动力。对核心三消玩法无影响。

## 实现难度

低到中。三消引擎成熟，最大技术难点是多样的障碍物逻辑、资源与消除的映射系统，以及大量关卡内容的配置管理。
