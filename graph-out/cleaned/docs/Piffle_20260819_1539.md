# Piffle

- **类型**: 益智 / 物理弹射 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: HIPSTER WHALE
- **首次发布**: 2016 (最初), 2025 (重制版)
- **一句话描述**: 在圆形弹珠台上发射球，利用物理反弹和道具组合消除数字方块

## 玩法规则

游戏画面中央是一个圆形弹珠台区域，周围环绕着带数字的方块。屏幕底部有一个弹射器（类似弹球台的发射杆）。

玩家拖拽弹射器瞄准方向并松开，球沿直线发射进入弹珠台区域。球在弹珠台内利用物理反弹机制运动，碰到数字方块时方块数字减 1，数字归零后方块消除。

弹珠台内有各种道具和障碍物：
- **挡板（Flippers）**：左右两个可操作的挡板，点击激活将球弹回，防止球掉落
- **弹跳器（Bumpers）**：圆形弹性装置，球碰到后被弹开并加速
- **倍增器（Multipliers）**：球经过时获得分数倍增
- **障碍物（Bumps/Bars）**：固定障碍，改变球的弹道

每次发射球后，如果球掉落到弹珠台底部（挡板没有接住），该球消耗。如果方块全部消除，关卡通过。

部分关卡有额外机制：特殊球（穿透、爆炸、多重球等）、限时方块（需要在时间耗尽前消除）、连锁反应（消除一个方块引发相邻方块消除）等。

## 核心循环

瞄准弹射方向 → 发射球 → 球在弹珠台内反弹撞击方块 → 数字递减/消除 → 球掉落 → 下一发射 → 消除全部方块过关

## 核心机制

- **物理弹射系统**：球的运动遵循简化的物理规则（速度、角度、碰撞反弹）。每次发射的角度和力度决定了球的轨迹，玩家需要预判球的弹道路径。
- **挡板操作**：两个挡板由玩家手动控制（点击左/右挡板），在球接近时激活将球弹回。挡板操作时机直接影响球的后续轨迹和能撞击到的方块。
- **数字递减消除**：方块上的数字代表需要击中的次数。大数字方块需要多次撞击才能消除，需要策略性地安排球的路径以高效降低所有方块数字。
- **道具连锁效应**：某些道具（如弹跳器）被球碰到后会加速球或改变方向，形成连锁反应。好的弹射可以利用道具网络让球在弹珠台内长时间运动，一次发射撞击多个方块。

## 为什么好玩

弹珠台本身的物理随机性带来天然的娱乐性——同样的发射角度，球每次的弹道路径都略有不同。这种可控中的不可控感让每次发射都充满期待。配合可爱的像素画风和轻松的音效，形成一种"看球弹来弹去也很开心"的治愈感。而当一发射击触发一连串道具和方块消除时，那种意外惊喜的快感是手动瞄准类游戏难以提供的。

## 粘性来源

- **物理随机性**：即使瞄准同样的方向，球的弹道也略有不同，增加重玩趣味
- **关卡递进**：新道具和新机制逐步引入，保持新鲜感
- **视觉满足**：球在弹珠台内弹来弹去的画面本身就令人放松
- **短局体验**：单局 3-5 分钟，适合碎片时间

## Meta 系统

- **世界/章节解锁**：按章节推进，每章有不同主题和视觉风格
- **特殊球收集**：解锁不同功能的球（爆炸球、穿透球等）
- **每日挑战**：特殊条件的每日关卡

## 实现难度

中。核心是 2D 物理引擎（碰撞检测、反弹计算、速度衰减）。最大技术难点在于：(1) 物理模拟的稳定性和可预测性——需要在随机性和可控性之间找到平衡；(2) 球与多种道具的交互逻辑（每个道具都有不同的物理响应）；(3) 流畅的 60fps 物理模拟和动画同步。建议使用成熟的 2D 物理引擎（如 Box2D/Unity Physics2D）。
