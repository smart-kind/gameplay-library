# 子弹冲刺（Bullet Rush!）

- **类型**: 超休闲/动作
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2020
- **一句话描述**: 快节奏射击闯关小游戏

## 玩法规则

玩家控制角色在关卡中移动并射击敌人。通过拖拽或虚拟摇杆控制角色移动方向，点击或自动射击。敌人从四面八方涌来，玩家需要灵活躲避子弹并反击。关卡逐渐增加敌人数量和复杂度。玩家可通过收集道具获得临时能力（护盾、多倍射击等）。每关通关后获得金币用于升级角色属性。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

移动射击 → 消灭敌人 → 收集金币 → 升级角色 → 下一关

## 核心机制

- **自动射击**:  角色自动射击，玩家专注于走位躲避
- **弹幕躲避**:  大量敌人子弹需要灵活闪避
- **道具升级**:  收集道具获得临时或永久增强

## 为什么好玩

快节奏的战斗和密集的弹幕带来刺激感，升级反馈明确

## 粘性来源

持续升级的数值成长感；更高难度关卡的挑战欲

## Meta 系统

角色升级系统，用金币提升生命值、射速、伤害等属性

## 实现难度

低 - 核心是碰撞检测和简单AI - 大量子弹和敌人同时存在时的性能优化
