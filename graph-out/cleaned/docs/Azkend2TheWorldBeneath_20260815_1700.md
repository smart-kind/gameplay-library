# Azkend 2: The World Beneath

- **类型**: 消除 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: 10tons Ltd
- **首次发布**: 2012
- **一句话描述**: 一款独特的方块消除解谜游戏，玩家需要将相同的方块配对连接来消除，通过消除解锁通往地底的通道，探索地下世界。

## 玩法规则

游戏画面呈现一个充满各种图案方块的棋盘式界面。每个方块上都刻有独特的图案（如花朵、星星、月亮等符号）。

玩家的操作是选择两个相同的方块，系统会自动在两者之间绘制一条连接路径。连接路径可以是直线或折线，但不能穿过其他方块。配对成功的两个方块被消除，露出下方的内容。

与经典消除游戏的'三点连线'不同，本作采用'两两配对'机制，每次只能消除两个相同方块。方块被消除后，上方的方块不会下落填补，而是显露出新的方块或特殊机关。

游戏设有多种特殊方块：锁住的方块需要特定条件才能消除、炸弹方块可以清除周围区域、钥匙方块可以解锁被封锁的区域。

通关条件通常是消除所有方块、找到特定物品或到达棋盘底部。游戏采用关卡制推进，每关有独特的棋盘布局和特殊机制。

## 核心循环

观察棋盘 → 配对消除 → 显露新内容 → 应对新机制 → 完成关卡目标

## 核心机制

- 两两配对消除：不同于三消的'三个一组'，本作只需要两个相同方块即可配对。这大幅降低了消除难度，但策略深度转向'选择哪两个'和'消除顺序'。
- 通道探索机制：消除方块不是为了得分，而是为了打开前进的通道。这种'消除即探索'的设计赋予每次操作明确的目标感。
- 特殊方块系统：锁、炸弹、钥匙等特殊方块增加了解谜维度，玩家需要规划消除顺序来应对这些障碍。

## 为什么好玩

将消除和解谜冒险结合——不是单纯地匹配方块，而是通过消除'打通道路'。每一关都有独特的布局和目标，像在解开一个立体的拼图。

## 粘性来源

关卡制的推进感和'解锁新区域'的探索欲望是主要粘性。每关都有新的棋盘布局和挑战机制，保持新鲜感。

## Meta 系统

无外围成长系统。游戏通过关卡数量和难度递增来提供内容消耗。

## 实现难度

低。最大技术难点在于关卡编辑器——设计'可解但有挑战性'的棋盘布局需要精心的约束条件验证。
