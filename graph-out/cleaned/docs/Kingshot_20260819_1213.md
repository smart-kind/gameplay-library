# Kingshot（王者之箭）

- **类型**: 策略 / 弹射 / 塔防
- **平台**: Mobile (iOS+Android)
- **开发商**: Century Games Pte. Ltd.
- **首次发布**: 2023
- **一句话描述**: 拉弓射箭，选择最佳角度和力度射击敌方阵地，利用物理弹道消灭敌人并占领据点。

## 玩法规则

屏幕被一条分界线分为两半——下方是玩家阵地，上方是敌方阵地。双方各自拥有若干士兵和防御建筑。玩家的操作是**拖拽弓箭**——按住屏幕从弓箭位置向后拉，形成一条弹道预测线（类似弹弓的拉拽效果），松开后箭矢沿抛物线飞出。

箭矢飞行受重力影响，形成弧形弹道。玩家需要考虑**拉拽力度**（决定初速度）和**拉拽角度**（决定飞行方向）来命中目标。箭矢命中敌方单位造成伤害，某些特殊箭矢（爆炸箭、冰箭、火箭）附带额外效果。

敌方阵地中有不同类型的单位：近战士兵（向前推进）、弓箭手（远程反击）、盾牌兵（阻挡正面攻击）、投石车（范围轰炸）。玩家需要优先消灭高威胁目标，同时保护己方单位。

每关有预设的敌方阵容，玩家需要在限定次数的射击内清除所有敌人或摧毁敌方指挥部。

## 核心循环

观察敌方阵型 → 拉弓瞄准 → 调整力度和角度 → 射箭 → 观察效果 → 选择下一目标 → 重复直到胜利

## 核心机制

- **物理弹道**：箭矢的抛物线飞行轨迹基于真实物理公式（初速度、重力加速度、空气阻力），玩家需要预估弹道来命中目标。
- **特殊箭矢**：不同箭矢类型提供不同的战术选择——爆炸箭适合对付密集敌人，冰箭可以冻结敌方行动，火箭附带持续伤害。
- **角度优先策略**：由于重力影响，从不同角度射击同一目标需要的力度完全不同，增加了策略深度。
- **连锁反应**：爆炸箭击中目标后产生的冲击波可以波及周围单位，精心瞄准可以实现"一箭多杀"。

## 为什么好玩

Kingshot 将弹弓游戏的"物理手感"和策略游戏的"目标优先级"结合起来。每次拉弓时的瞄准过程充满紧张感——你需要考虑重力、距离、敌方移动速度等多个变量。当一箭射中后看到爆炸波及周围敌人时的爽快感，以及"差一点就命中"时的懊恼感，都让玩家忍不住再来一局。

## 粘性来源

- **弹射手感**：物理弹道带来的"手感"是一种难以言喻但极具吸引力的体验。
- **一箭多杀的成就感**：精准命中关键目标并触发连锁反应是最大的正反馈。
- **关卡递进**：每关敌方阵容不同，挑战逐渐升级。
- **短时局**：每关只需几分钟，适合碎片时间。

## Meta 系统

- **箭矢收集与升级**：解锁新箭矢类型并升级其效果（爆炸范围、冰冻时长等）。
- **角色皮肤**：不同的弓箭手外观。
- **关卡星评级**：每关根据完成效率获得1-3星。

## 实现难度

中。核心是物理弹道计算和碰撞检测。最大技术难点是弹道预测线的准确性（需要模拟真实的物理公式）和爆炸效果的视觉反馈（冲击波的范围判定和动画）。
