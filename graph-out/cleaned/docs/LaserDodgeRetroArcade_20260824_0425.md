# Laser Dodge: Retro Arcade

- **类型**: 街机生存 / 反应躲避
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立开发者
- **首次发布**: 2024
- **一句话描述**: 一款极简风格的街机生存游戏，激光从屏幕四面射入，玩家用单指操控角色在激光的缝隙中求生。

## 玩法规则

游戏画面极简：一个深色背景上，玩家控制的小角色位于中央，激光从屏幕四个方向射入。

操作方式只有一个：单指虚拟摇杆控制角色在2D平面上移动。不能攻击，不能释放技能，只能移动。目标是尽可能长时间存活。

激光从屏幕四边随机方向射入，有固定的宽度和速度。激光之间会形成缝隙，即安全的移动通道。激光模式逐渐增加复杂度：初期是单束激光速度慢，中期多束激光同时出现，后期出现交叉激光和旋转激光。

得分系统：存活时间越长分数越高。靠近激光但没被击中有额外加分（擦弹奖励）。连续躲避一定数量激光有连击加分。游戏结束时总分决定排行榜排名。

角色碰到激光即死，无生命值概念。一局通常持续30秒到3分钟。死亡后立即可以重新开始，无缝衔接。

## 核心循环

移动躲避激光 → 存活时间增长 → 激光越来越多 → 被击中 → 高分重试

## 核心机制

- **单指生存控制**: 只有一个操作：移动。没有攻击、没有技能、没有道具。极简设计让核心体验极其纯粹。全部注意力集中在如何在激光中找到生存空间上。单指操作降低入门门槛，但精通需要极高反应速度和空间感知能力。

- **动态激光生成算法**: 激光从四面射入，但并非完全随机。算法确保激光之间总有缝隙存在，理论上永远有生存空间。但随着时间推移，缝隙越来越窄，通过窗口期越来越短。玩家需要在安全等待和冒险穿越之间做出判断。有路但很难走的设计是生存游戏核心张力。

- **擦弹奖励系统**: 靠近激光但没被击中获得额外加分。这个机制鼓励玩家冒险。待在安全区虽然安全但得分低，靠近激光虽然危险但得分高。风险回报机制让游戏从单纯躲避变成有策略地冒险，大大增加操作天花板。

## 为什么好玩

极简画面下的极高紧张感。激光从四面八方袭来时的压迫感非常刺激。差一点就死了的擦弹瞬间既惊险又有成就感。每局30秒到2分钟的节奏让人忍不住再来一次。像素风格的美术让游戏有复古街机的味道。

## 粘性来源

街机游戏差一点就过的不甘心感加上极简操作的低门槛和高分排行榜的竞争欲，构成经典街机循环。每次失败都觉得自己可以更好，驱动反复尝试。

## Meta 系统

无核心Meta系统。纯高分驱动型游戏，可能有皮肤或主题解锁作为装饰性收集。

## 实现难度

低。核心是2D碰撞检测和激光生成算法。像素级碰撞判定需要精确但不复杂。主要挑战是激光模式设计要难但公平。
