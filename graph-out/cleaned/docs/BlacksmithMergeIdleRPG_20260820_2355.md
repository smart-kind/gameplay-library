# Blacksmith（Blacksmith - Merge Idle RPG）

- **类型**: 放置RPG / 合成
- **平台**: Mobile (iOS+Android)
- **开发商**: Fumb Games Ltd.
- **首次发布**: 2019
- **一句话描述**: 一款铁匠主题的放置合成RPG，通过合并武器来打造装备帝国。

## 玩法规则

游戏界面中央是一个锻造台，周围有各种武器格（剑、弓、法杖等）。玩家拖拽两个相同武器合并为更高级武器（两把铁剑→钢剑，两把钢剑→魔法剑等）。

每种武器类型有独立的合成链，通常有9-12个等级。合成到最高等级后，该武器出售获得金币。金币用于解锁新武器类型、升级锻造台（增加格子数）、购买符文。

符文系统：玩家收集各种符文（金币加成、合成加速、物品复制等），符文提供被动加成效果，可以装备到锻造台上。

转生机制（灵魂宝石）：当进度达到瓶颈时，玩家可以重置所有进度，获得灵魂宝石。灵魂宝石提供全局倍率加成（所有金币获取+X%、合成速度+Y%等），使后续进度大幅加快。

游戏完全放置化，不需要持续操作。玩家打开游戏后进行一波合并操作，关闭后自动产出金币。离线期间自动合成低阶物品。

## 核心循环

合并武器 → 出售获金币 → 解锁新武器/升级锻造台 → 转生获灵魂宝石 → 加速下一轮合成

## 核心机制

- **多武器类型合成**: 每种武器有独立合成链，解锁新武器类型（从剑→弓→法杖→特殊武器）带来持续的新鲜感和目标感。不同武器的合成难度和回报不同，需要策略性分配资源
- **符文被动加成**: 符文提供多种被动效果（金币倍率、合成加速、物品复制），玩家可以自由组合符文，形成不同的build风格
- **灵魂宝石转生**: 重置进度换取永久倍率，是增量游戏的核心循环。每次转生后进度大幅加快，但新的瓶颈在更远处，形成螺旋上升的长期动力

## 为什么好玩

将合成操作的满足感与RPG装备养成的成就感融合。锻造台从简陋小作坊到装备帝国的视觉变化提供强烈目标感。转生后的加速感让人上瘾，再来一次就能更快的心理持续驱动。

## 粘性来源

合成链的差一个就能合成更好武器心理；灵魂宝石倍率的确定性成长；离线产出的回归动力；新武器类型解锁的惊喜感。

## Meta 系统

- **灵魂宝石与符文系统**: 转生获得灵魂宝石提供全局倍率，符文提供特殊加成
- **对核心玩法的影响**: 灵魂宝石是长期进度的核心驱动力，符文提供个性化build空间

## 实现难度

低 — 增量游戏模板成熟，最大技术难点是多武器类型合成链的数据结构和数值平衡
