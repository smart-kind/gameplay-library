# Smash Cops Heat

- **类型**: 动作 / 竞速
- **平台**: Mobile (iOS+Android)
- **开发商**: Hutch Games
- **首次发布**: 2012
- **一句话描述**: 操控警车追击并撞击犯罪车辆的快节奏动作游戏

## 玩法规则

玩家扮演警察，驾驶警车在城市中追击犯罪分子。游戏的核心机制是通过撞击来降低犯罪车辆的生命值，最终将其逼停。

游戏界面以俯视视角呈现城市道路和交通。玩家通过虚拟摇杆或触屏滑动控制警车的方向和速度。犯罪车辆会试图逃离，沿着城市道路行驶并躲避玩家的拦截。

撞击是主要攻击手段。从侧面或后方撞击犯罪车辆会降低其生命值。正面撞击（对撞）会对双方都造成伤害。犯罪车辆生命值降为零时即被逮捕。

城市中有交通车辆和障碍物，需要小心避让。误伤无辜车辆会扣分。某些关卡有特殊任务，如在限定时间内逮捕特定数量的罪犯。

## 核心循环

发现目标 → 追击 → 撞击削弱 → 逼停逮捕 → 进入下一关

## 核心机制

- **撞击系统**：通过撞击角度和力度影响效果，侧面撞击最有效
- **城市追击**：在开放城市环境中追击，需要考虑道路和交通因素
- **损伤管理**：警车也有生命值，需要避免过度碰撞
- **关卡目标**：每关有不同的任务类型和评分标准

## 为什么好玩

警车追击的题材本身就充满紧张感。撞击犯罪的爽快感加上城市追击的策略性（预判路线、利用障碍物）让游戏很有吸引力。

## 粘性来源

警车追击的题材吸引力 + 撞击犯罪的爽快感 + 关卡目标多样性 + 三星评价的收集驱动

## Meta 系统

车辆解锁系统 — 通过关卡进度解锁不同类型的警车，各有不同的性能和外观

## 实现难度

中 — 需要物理碰撞和城市AI交通系统，最大技术难点在于碰撞物理的真实感和AI车辆的智能寻路
