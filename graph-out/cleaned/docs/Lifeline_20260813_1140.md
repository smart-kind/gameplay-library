# 生命线（Lifeline）

- **类型**: 文字冒险 / 互动叙事
- **平台**: Mobile (iOS+Android)
- **开发商**: 3 Minute Games
- **首次发布**: 2015
- **一句话描述**: 一款纯文字互动冒险游戏，玩家通过与遇难宇航员Taylor实时通讯来帮助其在陌生星球上生存

## 玩法规则

游戏没有传统意义上的画面和UI布局——整个游戏界面就是一个即时通讯式的对话框。玩家扮演一个收到来自陌生星球遇难者Taylor信号的人。Taylor的飞船坠毁在一颗未知星球上，同伴遇难，唯一的通讯方式是通过一个名为Omegon的神秘设备向你发送文字消息。

玩家的唯一操作是：阅读Taylor发来的消息，然后从2-3个回复选项中选择一个。这些选择包括建议Taylor往哪个方向走、是否应该信任遇到的陌生人、如何处理食物和水的短缺、是否进入某个危险的区域等。

每个选择都会直接影响Taylor的生存概率和故事走向。有些选择会导致Taylor安全度过难关，有些则可能致命。游戏采用实时机制——当Taylor需要睡觉、长途跋涉或执行某项任务时，他会告诉玩家"我过会儿再联系你"，此时游戏进入等待状态，需要等待现实时间（几分钟到几小时不等）才能收到下一条消息。

游戏有多条故事线和多个结局，取决于玩家的选择。

整个游戏过程中，玩家会看到Taylor的情绪变化——从初期的恐慌，到中期的适应和乐观，再到遭遇挫折时的绝望。这些情绪变化通过文字的语气、用词和标点传达出来，让一个纯文字游戏拥有了情感深度。

游戏中还有隐藏的成就和彩蛋，比如找到某些特定路线后会解锁额外的对话内容。续作引入了不同的角色和情境（Lifeline: Silent Night中的宇航员Arik，Lifeline: Halfway Dead中的科学家Nicole），但核心玩法保持不变。

## 核心循环

收到Taylor的消息 → 阅读情境描述并理解当前危机 → 从选项中选择回复 → 推动剧情发展 → 等待现实时间流逝 → 收到新的进展消息

## 核心机制

- **实时叙事系统**：游戏内时间与现实时间同步，Taylor的活动周期（睡觉、走路、探索）需要真实时间完成，营造一种"你真的在远程帮助某人"的沉浸感
- **分支叙事网络**：每个选择都影响后续剧情发展，形成庞大的分支树，多条故事线和多个结局大幅增加重玩价值
- **推送通知驱动**：利用手机系统通知推送Taylor的消息，让玩家在现实生活中也能"收到Taylor的求救"，打破游戏与现实的界限
- **风险评估机制**：每个回复选项都有隐含的风险等级，玩家需要权衡"安全但缓慢"和"冒险但快速"的路线

## 为什么好玩

独特之处在于将手机的通知系统变成游戏机制本身——当你在上班或开会时突然收到Taylor发来"我发现了一个洞穴，但不确定里面有没有危险"的推送时，那种紧迫感和真实感是传统游戏无法提供的。Taylor的角色塑造非常成功，他的幽默、恐惧、绝望和希望都通过文字传达得淋漓尽致。

## 粘性来源

实时等待机制制造了独特的焦虑与期待——当Taylor说"我要睡一觉，8小时后再聊"时，你既担心他的安危又期待下一步剧情。分支叙事和多结局（包括多种死亡方式）促使玩家反复重玩，探索"如果当时选了另一个选项会怎样"。文字叙事本身的想象力补充也让每个玩家在脑海中构建出不同的画面。

## Meta 系统

无传统外围成长系统。游戏的主要消耗内容是系列续作（Lifeline: Silent Night, Lifeline: Halfway Dead, Lifeline: Whiteout等），每个续作讲述不同的角色和故事。

## 实现难度

中 — 最大技术难点是实时消息调度系统的精确时间控制和分支叙事的复杂状态管理。需要设计一个可靠的后台调度系统来在正确的现实时间推送消息，同时管理庞大的分支叙事状态树。叙事内容的创作成本远高于技术实现成本。
