# 迷失之地（Badland）

- **类型**: 横版飞行 / 生存 / 解谜
- **平台**: Mobile (iOS+Android) / PC / Switch / PS / Xbox
- **开发商**: Frogmind
- **首次发布**: 2013
- **一句话描述**: 一款氛围感极强的横版飞行游戏，玩家操控一群毛茸茸的黑色小球在危险的奇幻森林中飞行求生。

## 玩法规则

玩家控制一只或多只毛茸茸的黑色球形生物（克隆体），在横向滚动的关卡中飞行。
操作极其简单：按住屏幕使克隆体上升，松开使它们下降。没有其他按钮。
关卡中布满各种危险：旋转的锯齿、吞噬克隆体的黑色触手、移动的平台、激光束、粘性陷阱、爆炸装置等。
克隆体被危险碰到后会死亡，关卡目标是让至少一只克隆体到达终点。
关卡中散布着绿色收集品，需要规划飞行路线来获取。
支持多人同时操控多个克隆体，增加策略维度——需要决定哪些克隆体牺牲、哪些前进。
通关条件是至少一只克隆体抵达关卡终点。收集品数量和存活克隆体数量影响评级。

## 核心循环

按住屏幕飞行 → 躲避障碍物 → 收集绿色物品 → 到达终点 → 解锁下一关卡

## 核心机制

- **单按钮操控**：只需按住和松开屏幕，通过控制时机来操控飞行高度。极简操作下蕴含着精确的时机把控。
- **克隆体系统**：随着游戏推进，同时控制的克隆体数量增加。更多克隆体意味着更多生存机会，但也增加操控复杂度。
- **动态关卡生成**：部分关卡包含随机元素或动态变化的障碍，增加重玩价值。
- **氛围营造**：剪影风格的美术、深邃的背景层次、环境音效共同营造出神秘压抑但充满探索欲的氛围。

## 为什么好玩

极简的单按钮操作与精心设计的关卡难度曲线相结合，每一次飞行都充满紧张感。剪影美术和音效营造出独特的沉浸式体验。

## 粘性来源

单局时间短但难度递增带来'再试一次'的冲动；收集全部绿色物品的完美主义驱动；克隆体数量增加带来的策略深度变化。

## Meta 系统

关卡解锁系统——完成关卡后解锁新区域，每个区域有独特的主题和障碍类型。收集全部绿色物品解锁隐藏关卡。

## 实现难度

中 — 单按钮操控的输入处理简单，但物理飞行模拟（重力、惯性、浮力）和碰撞检测需要精细调校。最大技术难点在于关卡编辑器设计和动态障碍的流畅运行。

## 游戏变体

多数游戏在不同平台上发布了HD版、重制版或移植版本，核心玩法保持不变。
