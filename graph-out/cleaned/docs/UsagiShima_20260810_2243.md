# 可爱兔子岛收集放置游戏（Usagi Shima）

- **类型**: 放置
- **平台**: Mobile (iOS+Android)
- **开发商**: Hit-Point
- **首次发布**: 2017
- **一句话描述**: 可爱兔子岛收集放置游戏

## 玩法规则

玩家在一个小岛上放置各种物品（玩具、食物、家具等）来吸引兔子。兔子会来岛上玩耍，玩家可以给兔子拍照和收集。每只兔子有独特的外观和名字。游戏是纯放置机制，兔子自动来访。

## 核心循环

放置物品 → 吸引兔子 → 收集兔子 → 解锁新物品 → 吸引更多兔子

## 核心机制

- 放置吸引：放置物品吸引兔子
- 兔子收集：收集不同品种的兔子
- 拍照系统：给兔子拍照
- 物品解锁：用胡萝卜解锁新物品

## 为什么好玩

可爱的兔子和治愈的画面。看着兔子们来岛上玩耍的满足感。

## 粘性来源

兔子收集；治愈体验。

## Meta 系统

兔子收集+物品解锁。

## 实现难度

低。放置类，操作极少。最大技术难点：兔子AI行为。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
