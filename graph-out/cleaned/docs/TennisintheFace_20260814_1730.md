# 迎面网球（TennisintheFace）

- **类型**: 物理解谜
- **平台**: Mobile (iOS+Android) / PC (Steam)
- **开发商**: 2and2 Games
- **首次发布**: 2014
- **一句话描述**: 一款独特的物理解谜游戏，利用网球和各种物理机关来击中目标人物的脸部

## 玩法规则

游戏采用横版2D视角，画面风格略带卡通和恶搞色彩。每个关卡呈现一个独立的场景，场景中有目标人物（通常是各种反派或讨厌的角色）、各种物理机关和障碍物，以及一颗网球。

玩家需要通过点击和拖拽来设定网球的发射方向和力度。网球发射后遵循真实的物理弹道，会受到重力影响，可以与场景中的物体发生碰撞反弹。场景中散布着各种可互动物体：弹簧可以将球弹射到高处，风扇可以改变球的飞行方向，传送带可以水平移动球体，蹦床可以大幅弹起球等。

游戏的关键在于利用场景中的机关组合出正确的弹道路径。通常需要一次或多次反弹才能绕过障碍物最终击中目标。玩家可以在发射前自由调整角度和力度，也可以预览弹道路径（部分关卡）。

击中目标后有夸张的动画效果和音效反馈，增加了游戏的喜剧感和满足感。每个关卡的目标位置和机关布局都不同，需要重新思考解决方案。部分关卡有额外挑战，如用最少次数击中目标、收集场景中的额外物品等。

## 核心循环

观察关卡布局和机关 → 思考弹道路径 → 调整发射角度和力度 → 发射网球 → 根据结果调整策略重试

## 核心机制

- **物理弹道模拟：基于Box2D等物理引擎实现真实的网球飞行、重力、碰撞和反弹效果，是游戏的核心机制**
- **交互式场景元素：弹簧、风扇、传送带、蹦床、挡板等多种机关，每种机关有独特的物理效果，组合使用可以产生复杂的弹道**
- **多关卡递进设计：从简单的直接瞄准到需要多次反弹的复杂弹道，逐步提升难度。后期关卡加入移动目标、限时挑战等变化**
- **预览与试错机制：允许玩家在不计次数的情况下预览弹道，降低试错成本**

## 为什么好玩

将物理弹射与恶搞元素完美结合，每次成功击中都有很强的满足感。关卡设计巧妙，需要认真思考弹道，但找到解决方案后的成就感极强。夸张的击中动画和音效增加了喜剧效果。

## 粘性来源

物理解谜固有的'差一点就成功'效应，加上恶搞的视觉反馈，让人忍不住想再试一次。每个关卡的最优解可能不同，追求完美解法的驱动力。

## Meta 系统

关卡解锁系统，完成一定数量或难度的关卡后解锁新场景和新机关类型。部分版本有成就系统。

## 实现难度

中，需要精确的物理计算和角度判断。最大技术难点在于物理引擎的准确性和弹道预览的实现。

### 机关详细说明

弹簧：将球垂直弹射，弹射高度取决于球的入射速度。风扇：水平或垂直推动球体，风力大小可调。传送带：沿固定方向移动球体，适合改变水平方向。蹦床：大幅弹起球体，适合到达高处目标。

### 关卡类型

标准关：单次弹道击中目标。多反弹关：需要2-3次反弹才能绕过障碍。动态关：场景中有移动机关，需要预判时机。收集关：额外要求收集场景中的星星。

### 恶搞元素

目标人物被击中后有夸张的动画效果，包括面部变形、飞出屏幕、撞倒周围物体等。不同目标有不同的反应动画，增加了重复游玩的趣味性。
