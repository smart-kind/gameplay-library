# Hero Roll 骰子Roguelike（Heroll : Dice Roguelike）

- **类型**: Roguelike / 骰子 / 棋盘
- **平台**: Mobile (iOS+Android)
- **开发商**: Crater Co., Ltd.
- **首次发布**: 2025
- **一句话描述**: 命运系于一次掷骰——在疯狂的世界中重建村庄的骰子Roguelike

## 玩法规则

游戏画面是一个神秘的游戏棋盘，英雄在上面移动。玩家通过掷骰子来决定英雄的移动步数和遭遇事件。

每次掷骰后，英雄沿着棋盘路径前进，会遇到不同类型的格子——战斗格触发回合制战斗，宝箱格获得奖励物品，商店格可以购买道具，陷阱格造成伤害或负面效果，事件格触发特殊剧情或选择。

核心策略在于：掷骰前可以选择不同的骰子（面数和效果不同），并搭配英雄已有的技能。好的骰子+技能组合可以让英雄获得巨大的优势，而差的组合可能让英雄陷入危险。比如选择一个有更多有利面的骰子，或者使用技能来修改骰子结果。

游戏中包含村庄重建系统——通过冒险获得的资源可以用来重建被摧毁的村庄，解锁新功能和NPC。村庄的重建进度直接影响英雄可以获得的支援和道具。

## 核心循环

选择骰子 → 掷骰移动 → 遭遇事件/战斗 → 获取资源重建村庄

## 核心机制

- **骰子驱动移动**：英雄的移动和遭遇完全由骰子决定，每次掷骰都充满不确定性，但可以通过选择不同的骰子来影响概率。骰子的面数、数值分布和特殊效果各不相同
- **技能+骰子组合**：不同骰子与不同技能的搭配产生不同的效果，玩家需要根据当前局势选择最优组合。这种组合系统提供了丰富的策略深度
- **村庄重建**：冒险获得的资源用于重建村庄，提供长期目标感和成长反馈。村庄每解锁一个新建筑，英雄就能获得新的能力或道具

## 为什么好玩

掷骰的瞬间紧张感和'掷出完美数字'的爽快感是核心乐趣。配合棋盘上各种事件的不可预测性，每局都充满戏剧性。

## 粘性来源

掷骰的随机快感 + 村庄重建的长期目标 + 技能解锁的持续新鲜感

## Meta 系统

村庄重建系统 + 骰子收集 + 技能解锁 + 英雄等级成长

## 实现难度

中 — 骰子概率设计+棋盘事件平衡是核心，最大难点是确保随机性不会让玩家感到完全失控
