# Dead Man's Cross（死亡十字）

- **类型**: 卡牌对战 / 策略RPG
- **平台**: Mobile (iOS + Android)
- **开发商**: Square Enix
- **首次发布**: 2015
- **评分**: Square Enix出品卡牌策略游戏
- **一句话描述**: Square Enix出品的卡牌策略对战游戏，玩家操控角色在十字形战场上使用卡牌进行回合制战斗

## 玩法规则

游戏采用独特的"十字形"战场布局——战斗区域呈十字形状，这是游戏名称的来源。玩家和敌人各占十字形战场的一侧。

玩家在战斗中收集和使用卡牌。每张卡牌代表一种攻击、防御或特殊能力。卡牌系统融合了Square Enix经典的RPG元素——角色职业、技能树、装备等概念都被融入了卡牌机制中。

战斗是回合制的。在自己的回合，玩家选择卡牌来攻击敌人或增强己方。卡牌的使用受到手牌和能量/费用系统的限制，玩家需要合理管理资源。

游戏的特色在于将Square Enix旗下多款经典RPG（如Final Fantasy、Dragon Quest等）的角色和世界观融合到同一个卡牌对战框架中。

## 核心循环

收集/抽取卡牌 → 在十字战场上选择出牌攻击敌人 → 获得胜利获得奖励 → 收集更多卡牌强化卡组

## 核心机制

- **十字形战场**：独特的战场布局影响攻击范围和策略选择
- **卡牌对战系统**：回合制出牌，管理手牌和费用资源
- **RPG融合**：角色等级、装备、技能等RPG元素与卡牌系统结合
- **Square Enix IP联动**：多个经典游戏世界的角色和设定融合
- **卡组构建**：收集和组合不同的卡牌形成自己的战斗策略

## 为什么好玩

Dead Man's Cross的最大卖点是Square Enix的IP宝库——Final Fantasy、Dragon Quest等经典角色齐聚一堂。对于RPG粉丝来说，看到这些角色以卡牌对战的形式重新演绎是一种独特的体验。十字形战场的独特布局也区别于传统的横向或网格战场。

## 粘性来源

(1) **IP情怀**——Square Enix经典角色的收集和使用欲望；(2) **卡组构建的长期目标**——不断优化卡组组合；(3) **角色收集**——RPG式的角色收集养成；(4) **对战策略深度**——不同卡组之间的克制关系和策略博弈

## Meta 系统

- **角色收集/养成系统**：收集来自不同Square Enix游戏的角色
- **卡牌收集/升级**：通过游戏进程获得更多卡牌并强化
- **等级/经验系统**：角色升级解锁新能力

## 实现难度

**中** — 卡牌对战框架本身不复杂，但需要大量内容设计（卡牌效果平衡、角色数值、战场策略空间）。技术难点在于战斗AI和卡牌效果的多样性实现
