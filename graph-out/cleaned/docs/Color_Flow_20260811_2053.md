# Color Flow

- **类型**: 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Big Duck Games LLC
- **首次发布**: 2012
- **一句话描述**: Flow Free® is a simple yet addictive puzzle game

## 玩法规则

Flow Free® is a simple yet addictive puzzle game Connect matching colors with pipe to create a Flow®

具体玩法流程：

1. **观察阶段**：玩家观察当前关卡的初始布局和目标
2. **操作阶段**：通过点击/拖拽/滑动等方式移动游戏元素
3. **验证阶段**：系统检查操作是否满足过关条件
4. **反馈阶段**：正确操作获得正向反馈并进入下一步，错误操作需要重新思考
5. **通关阶段**：完成所有目标后过关，解锁下一关

游戏特色内容：

- 10 different board sizes

## 核心循环

观察关卡布局 → 思考解决方案 → 执行操作 → 验证结果 → 过关或重试 → 进入下一关

## 核心机制

- **关卡系统**：游戏包含多个精心设计的关卡，难度循序渐进。
- **极简视觉**：采用简洁优雅的视觉风格，不依赖华丽特效，让玩家专注于核心玩法本身。
- **逻辑推理**：玩家需要通过逻辑推理来找到最优解，每次移动都需要考虑后续影响。

## 为什么好玩

游戏以解谜为核心，通过简洁直观的操作降低了上手门槛，同时通过精心设计的关卡/内容保证了足够的深度。游戏的美术风格简洁明快，让玩家在短时间游玩中也能获得完整的体验。

## 粘性来源

多个关卡的递进式难度曲线是核心粘性来源。
每关都有新的挑战机制，通关后的成就感驱动玩家继续推进。
单关时长短，适合碎片时间游玩，容易形成"再玩一关就停"的心理。

## Meta 系统

无显著外围成长系统。游戏以核心玩法体验为主，不提供复杂的养成线。

## 实现难度

低到中等。核心机制相对简单，主要技术难点在于关卡设计的合理性和难度曲线。
最大难点：确保每个关卡都有唯一/最优解，同时保持难度递进的平滑性。
