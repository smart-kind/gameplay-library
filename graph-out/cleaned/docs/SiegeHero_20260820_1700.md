# Siege Hero（Siege Hero）

- **类型**: 物理弹射 / 解谜 / 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Armor Games Studios Inc
- **首次发布**: 2011
- **一句话描述**: 用投石机和攻城武器摧毁中世纪城堡的物理益智游戏，曾在89个国家登顶Puzzle排行榜。

## 玩法规则

每个关卡呈现一座中世纪城堡的横截面或3D结构，城堡中驻守着敌人。屏幕下方或侧方有一个投射武器（投石机、弩炮、加农炮等）。

玩家操作：用手指拖拽调整投射武器的角度和力度，松开发射投射物（巨石、火球、箭矢等）。投射物沿抛物线飞行，命中城堡后对建筑结构造成物理破坏。建筑中的砖块、木板、石柱会根据物理引擎倒塌、碎裂、掉落。

游戏目标是消灭城堡中的所有敌人。消灭敌人的方式不是直接射击，而是通过摧毁他们脚下的建筑结构——让敌人从高处坠落、被倒塌的建筑压扁、或被掉落的碎石砸中。每个关卡的城堡结构各不相同，玩家需要找到结构的"关键支撑点"，一击命中即可引发连锁倒塌。

部分关卡提供多种武器选择，不同武器有不同的破坏特性：巨石适合大面积破坏，火球可以点燃木制结构，炸弹则产生爆炸冲击波。

## 核心循环

观察城堡结构 → 选择武器并瞄准关键支撑点 → 发射投射物引发连锁破坏 → 消灭所有敌人获得皇冠评价

## 核心机制

- **结构弱点识别**：每座城堡都有一个或多个关键支撑点。击中这些点会引发最大范围的倒塌，而击中非关键点可能只造成局部破坏。玩家需要观察建筑结构的力学关系，找出"压垮骆驼的最后一根稻草"。
- **武器多样性**：不同关卡提供不同武器，每种武器有不同的弹道、威力和特殊效果。投石机发射巨石造成大范围物理冲击，弩炮发射精确的弩箭穿透薄弱点，火球可以引燃木制结构产生持续破坏。
- **皇冠评价体系**：每个关卡根据使用的投射物数量给予1-3颗皇冠评价。追求完美评价（最少投射物通关）是核心挑战。

## 为什么好玩

找到城堡结构弱点并一击摧毁的成就感极强。看着整座城堡在物理引擎下轰然倒塌，敌人四散坠落，这种"聪明的破坏"带来智力+视觉的双重满足。400+关卡提供了充足的挑战内容。

## 粘性来源

"结构弱点"的谜题设计是核心驱动力。每个城堡都是一个小型物理谜题，解开它的快感让人上瘾。同时，皇冠评价体系鼓励玩家反复尝试优化方案，用最少的攻击次数完成关卡。五个时代（Ages）的主题变化和武器升级提供了持续的新鲜感。

## Meta 系统

Treasure Map（藏宝图）系统：在所有城堡获得金皇冠后解锁额外的掠夺关卡。这是一个奖励性质的外围系统，为完美主义者提供额外挑战内容。

## 实现难度

中。2D/3D混合物理引擎是核心，需要精确模拟建筑结构的力学关系和破坏效果。最大技术难点在于建筑结构的可信度——建筑倒塌必须看起来自然且有逻辑，不能出现违反物理常识的行为，这对物理参数的调校要求极高。
