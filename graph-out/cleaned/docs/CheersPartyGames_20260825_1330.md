# Cheers - Party Games

- **类型**: 派对迷你游戏合集
- **平台**: Mobile (iOS+Android)
- **开发商**: Peter Skarheim
- **首次发布**: 2017
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

选择游戏模式 -> 轮流参与 -> 获得乐趣/积分 -> 排名

## 核心机制

- **派对问答模式**: 包含经典的'最有可能'（Most Likely）问答模式。玩家轮流回答问题，投票选出最符合描述的人。这种模式天然适合聚会场景。
- **多种派对游戏**: 除了问答，还包含多种派对小游戏，满足不同场景的需求。从破冰游戏到深度互动，游戏类型丰富。
- **社交互动驱动**: 游戏的核心是促进玩家之间的互动和交流。每个问题和小游戏都设计为能引发有趣的话题和笑声。

## 为什么好玩

'最有可能'问答模式天然有趣，看到朋友们被'揭穿'总是充满笑声。游戏不需要任何特殊技能，任何人都能参与。

## 粘性来源

粘性来源于社交互动的新鲜感。每次不同的参与者组合都会产生不同的化学反应。

## Meta 系统

- 无传统Meta系统
- 核心社交体验本身就是最大的粘性来源

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
