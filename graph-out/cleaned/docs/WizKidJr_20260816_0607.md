# 小巫师（Wiz Kid Jr.）

- **类型**: 冒险 / 平台 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: 移动平台独立冒险游戏
- **首次发布**: 约 2010 年代
- **一句话描述**: 扮演小巫师在奇幻世界中冒险，使用魔法解决谜题并击败敌人

## 玩法规则

游戏画面呈现 2D 横向卷轴的平台场景，玩家控制一名小巫师角色。屏幕左侧是虚拟方向键控制移动，右侧是魔法按钮和技能按钮。

小巫师可以在平台上左右移动和跳跃。核心能力是使用魔法——不同魔法有不同的效果：火球术攻击敌人、冰冻术冻结障碍物、传送术穿越障碍、护盾术防御攻击。

场景中散布着各种谜题：需要特定魔法才能打开的门、需要按顺序激活的机关、需要避开或消除的障碍。某些区域有敌人巡逻，需要用魔法击败或绕过。

游戏目标是穿越各个关卡，收集魔法能量，击败 Boss，推进冒险故事。

## 核心循环

探索关卡 → 收集魔法 → 解决谜题 → 击败敌人 → 到达关卡终点

## 核心机制

- **魔法系统**: 多种魔法技能，每种有不同的效果和消耗，需要根据场景选择合适的魔法
- **平台跳跃**: 经典的平台游戏操作——跑、跳、二段跳，精确的时机控制是关键
- **谜题解决**: 环境谜题需要玩家观察、尝试不同魔法组合来找到解决方案
- **收集要素**: 关卡中隐藏收集品（星星、宝石、魔法卷轴），增加探索动机
- **Boss 战**: 每关末尾有 Boss，需要观察其攻击模式并找到弱点

## 为什么好玩

魔法系统的多样性让每次解谜都有多种解法。平台跳跃的精确操作和魔法释放的组合提供了丰富的操作深度。奇幻冒险的视觉风格和轻松的节奏适合休闲玩家。

## 粘性来源

收集要素驱动反复探索——第一次可能漏掉了隐藏的魔法卷轴，需要重玩关卡。新魔法的逐步解锁让玩家期待下一个能力。Boss 战的挑战性让玩家反复练习直到通关。

## Meta 系统

魔法解锁系统：通过收集魔法卷轴或通关特定关卡来解锁新魔法。收集的宝石可以用于升级已有魔法的威力和效果。

## 实现难度

中。需要平台物理（碰撞、重力）、魔法效果动画、敌人 AI。最大的技术难点是魔法效果与场景物体的交互——火焰需要能烧毁特定障碍、冰冻需要能冻结水面等。
