# Lums

- **类型**: 解谜 / 物理
- **平台**: Mobile (iOS)
- **开发商**: OhNoo Studio
- **首次发布**: 2013
- **一句话描述**: 操控发光小生物 Lums 来驱散占领森林的外星吸血鬼

## 玩法规则

游戏画面呈现一个茂密的森林场景，阳光只能从树冠的缝隙中透入。外星吸血鬼选择在阴暗的森林中定居，玩家需要操控 Lums 这种软体发光生物来驱逐它们。

屏幕采用俯视视角，玩家通过触摸屏幕来引导 Lums 移动。Lums 可以无限漂浮，只要不碰到固体表面就会一直跟随玩家手指滑动。

Lums 有多种类型，各自具备不同能力：炮弹 Lum 可以撞击木块和混凝土块将其击倒；光 Lum 撞击表面后产生一束阳光；透明 Lum 可以将石头变成玻璃，让阳光透入并烤死藏匿的吸血鬼；反重力 Lum 是最强力的——触碰物体后将其抛向空中，然后物体以毁灭性的方式坠落。

玩家需要用阳光蒸发掉关卡中的所有吸血鬼才能过关，同时收集关卡中的星星来解锁后续关卡组。收集星星需要耐心——星星很小，很难看清，可以通过让 Lums 身体直接触碰收集，也可以让掉落的碎片砸中星星来间接收集。

玩家可以滑动手指有限地预览关卡地形，但真正看清关卡全貌的唯一方法是用 Lums 去侦察。这是一次冒险，因为 Lums 碰到固体就会消失。

## 核心循环

发射 Lums → 制造阳光驱散吸血鬼 → 收集星星 → 解锁新关卡

## 核心机制

- **Lum 分身制**：每关分配固定数量的 Lums，每种类型有独特物理效果（撞击、发光、透明化、反重力），玩家需要规划发射顺序和角度
- **连锁破坏**：反重力 Lum 将物体抛高后坠落，可以连锁触发更多破坏，产生"爽快感"反馈
- **光线解谜**：通过将石头变玻璃让阳光透入，需要空间想象力来规划光线路径

## 为什么好玩

Lums 将物理破坏的乐趣与光线解谜巧妙结合。反重力 Lum 将物体抛向空中然后看它们砸落的过程充满快感，而用阳光驱散吸血鬼的设定带来了一种独特的"以光克暗"的满足感。4 星评价说明它是一款品质优良的小众佳作。

## 粘性来源

"差一点就成功"的不甘心——关卡中星星的收集往往需要精确的物理操控，每次失败都让人觉得"再试一次就能行"。多种 Lum 的组合可能性也带来策略深度。

## Meta 系统

无。关卡解锁依赖星星收集数量，无外围成长系统。
