# 午夜圣所（The Midnight Sanctuary）

- **类型**: 视觉小说 / 悬疑冒险
- **平台**: Switch / PC
- **开发商**: 独立开发
- **首次发布**: 2023
- **一句话描述**: 一款以低多边形美术风格呈现的诡异悬疑视觉小说，玩家扮演向导引导来访者探索小镇的秘密。

## 玩法规则

玩家扮演一个无名角色，作为向导帮助来访者 Hamamoru 探索 Daiusu 小镇的历史和民俗。游戏采用地图导航系统——在章节之间，屏幕上会出现一张小镇地图，玩家选择下一个要前往的地点，然后观看该地点发生的故事片段。

玩家的唯一交互就是选择接下来观看哪段故事。游戏没有对话选项、没有分支剧情、没有选择影响结局的机制。选择地点后，玩家观看一段过场动画，然后回到地图界面继续选择。整个过程就像在翻阅一本互动故事书。

游戏时长约两小时，采用低多边形美术风格，配合鲜明的色块渲染，营造出一种朦胧诡异的氛围。故事在前半小时内就开始变得离奇，随着剧情推进会出现一群性格怪异、各怀心思的角色，每个人都有自己的隐藏动机。

视觉风格上，低多边形模型被涂上大块鲜明的色彩，创造出一种奇怪、朦胧的感觉，就像经历的一切都是一场无法醒来的梦。故事本身在前半小时内就进入"怪异模式"，并且再也不会停下来。

## 核心循环

选择地图地点 → 观看故事片段 → 获得线索 → 回到地图 → 选择下一个地点

## 核心机制

- **地图导航**: 章节间的核心交互，玩家通过地图选择故事推进方向，给予一定的探索感
- **非线性叙事**: 虽然故事是固定的，但观看顺序由玩家选择，不同的顺序可能带来不同的理解和感受
- **低多边形美术**: 独特的视觉风格用色块和低多边形模型创造出一种梦境般的诡异感
- **群像叙事**: 多角色各自怀有隐藏动机，剧情随着时间逐渐揭露，每个人物都不像表面那么简单
- **悬疑氛围**: 故事充满了让人不安的细节和暗示，看完后"问题比答案多"

## 为什么好玩

游戏的诡异氛围和低多边形美术风格组合产生了独特的视觉体验。故事本身充满悬疑和反转，看完后"问题比答案多"的设计让人回味无穷。两小时的紧凑时长让体验不拖沓，每一段故事都有新发现。对于喜欢独立叙事游戏的玩家来说，这是一次值得体验的奇异旅程。

## 粘性来源

主要来自叙事层面的好奇心——"接下来会发生什么？"地图导航给了玩家一种"自主探索"的错觉，虽然不是真正的分支剧情，但选择观看顺序让玩家感觉自己在主导故事的展开。通关后留下的未解之谜也会让人想和他人讨论、寻找答案。

## Meta 系统

无。游戏为纯叙事体验，没有外围系统。所有动力来自故事本身的吸引力。

## 实现难度

低。核心是文本叙事和场景切换，技术上是视觉小说的标准实现。最大难点在于用低多边形美术营造出准确的诡异氛围，以及编写引人入胜的多角色悬疑故事。场景切换和地图导航的逻辑也比较简单。
