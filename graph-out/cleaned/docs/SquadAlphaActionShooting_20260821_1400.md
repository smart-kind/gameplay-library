# Squad Alpha - Action Shooting

- **类型**: 休闲射击
- **平台**: Mobile (iOS+Android)
- **开发商**: SayGames LTD
- **首次发布**: 2021
- **一句话描述**: 俯视角小队射击，控制小队对抗成群敌人

## 玩法规则

游戏采用竖屏俯视角。玩家通过虚拟摇杆或点击控制小队移动。小队成员会自动瞄准并射击范围内的敌人。

玩家需要带领小队在战场上移动，消灭沿途的敌人，到达关卡终点。敌人会从四面八方涌来，形成压迫感。

不同关卡有不同类型的敌人和障碍物。后期会出现坦克、机枪塔等重型敌人，需要更谨慎的路线选择。

战场上有多个路线可选：有些路线敌人少但有额外奖励，有些路线直接但敌人密集。玩家需要根据小队实力选择合适的路线。

每局约2-3分钟，操作简化但策略性不减。

## 核心循环

控制小队移动 → 自动消灭沿途敌人 → 到达关卡终点 → 升级小队成员

## 核心机制

- **小队自动战斗**: 小队成员自动瞄准射击范围内的敌人，玩家专注于走位和路线选择。操作简化但策略性不减，不同小队成员有不同的武器特性。
  （操作简化）
- **敌人集群压迫**: 大量敌人从各个方向涌来，形成视觉和心理上的压迫感。不同类型的敌人有不同的血量和攻击方式，需要不同的应对策略。
  （压迫感）
- **路线策略选择**: 战场上有多个路线可选，有些路线敌人少但有奖励，有些路线直接但敌人密集。玩家需要根据小队实力选择合适的路线。
  （策略选择）

## 为什么好玩

小队作战的爽快感十足，看着敌人成片倒下很有成就感。自动战斗让玩家专注于策略而非操作，适合休闲玩家。

## 粘性来源

消灭大量敌人的爽快感、小队成长的数值反馈、不同关卡的挑战性。'再来一局升级装备'的心理驱动持续游玩。

## Meta 系统

升级小队成员的武器和属性，解锁新角色。通关获得金币用于升级，形成明确的成长目标。

## 实现难度

低 — 俯视角2D射击+自动战斗，技术实现相对简单。敌人AI和波次设计是主要工作量。
