# 神经沙洲六角棋（Neuroshima Hex）

- **类型**: 桌面策略 / 回合制战棋 / 抽象策略
- **平台**: Mobile (iOS+Android) / PC / 实体桌游
- **开发商**: Board Game Factory / 原桌游设计: Michał Oracz
- **首次发布**: 2006 (实体桌游原版)
- **一句话描述**: 在六角形棋盘上放置指令标记，通过精心编排的指令序列指挥军队作战的抽象策略战棋游戏。

## 玩法规则

游戏在一个六角形网格棋盘上进行。玩家控制一个军事阵营（游戏中有多个可选阵营），每个阵营由总部（HQ）和若干作战单位组成。棋盘中央放置中立方（如Neuroshima军团）的部队作为障碍。

回合流程：每回合玩家从手牌中选择一张指令标记放到自己的作战单位上。指令包括：移动（向相邻格移动1格）、攻击（对射程内的敌人造成伤害）、特殊指令（各阵营独特的能力）。放完指令后进入结算阶段，所有单位按速度值从高到低依次执行各自的指令。

攻击有射程和伤害值——近战单位只能攻击相邻格，远程单位可以攻击2-3格外的目标。某些单位有穿透攻击（一条直线上的多个目标）、范围攻击（周围一圈）、狙击（超远射程）等特殊能力。

核心策略在于"指令编排"——你需要预判敌方指令、保护己方总部、利用地形优势、在合适的时机发动攻击。速度值决定执行顺序，高速单位可以先手攻击，但可能被打乱节奏。

## 核心循环

观察棋盘局势 → 部署指令标记 → 按速度结算 → 分析结果 → 调整策略 → 继续下一回合

## 核心机制

- **指令编程**：每回合放置指令而非直接控制单位，结算时自动按速度执行，形成"编程→执行"的独特体验
- **速度优先级**：速度高的单位先执行指令，速度低的后执行，需要预判执行顺序来规划策略
- **阵营差异化**：不同阵营有独特的单位和指令类型，策略风格截然不同
- **地形利用**：棋盘上的障碍物和地形影响移动和攻击路线，需要巧妙利用
- **总部保护**：总部被摧毁即输，所有行动围绕保护己方总部和威胁敌方总部展开

## 为什么好玩

Neuroshima Hex将"编程思维"融入桌游——你不是在控制单个单位的即时战斗，而是在设计一套指令序列，然后观察它如何展开。这种"设局→见证"的体验非常独特：你放置的指令就像设定了一个小机器人，结算阶段看着它按你的设计行动，既有期待感又有意外惊喜。不同阵营的独特机制让每局游戏都有新鲜感，策略深度足以支撑数百小时的游戏时间。

## 粘性来源

- **策略深度**：指令编排的复杂性提供了巨大的策略空间
- **阵营多样性**：每个阵营有完全不同的玩法，需要分别学习和精通
- **每局不同**：棋盘布局、敌方行动、手牌组合都让每局独一无二
- **精通曲线**：从新手到高手需要大量练习，每次都有新的理解

## Meta 系统

阵营解锁系统——初始只有1-2个阵营可用，通过完成挑战任务解锁更多阵营。部分版本包含AI对战模式和多人在线对战。

## 实现难度

中 — 抽象策略游戏的核心在于AI算法和规则引擎。最大技术难点在于"AI对手"的智能程度——需要足够聪明以提供挑战，但又不能过于完美让新手绝望。指令结算逻辑（速度排序、连锁反应、同时结算等）也需要精确实现。
