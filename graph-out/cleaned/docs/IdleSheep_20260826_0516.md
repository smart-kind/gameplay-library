# Idle Sheep!

- **类型**: 放置点击 / 农场经营
- **平台**: Mobile (iOS)
- **开发商**: Mindstorm Studios
- **首次发布**: 2016
- **一句话描述**: Idle Sheep!（又名Farm Inc）是一款轻松的农场放置点击游戏。玩家通过点击屏幕养殖羊群、牛和猪，逐步扩大农场规模。

## 玩法规则

游戏画面以卡通3D风格呈现，屏幕上显示农场场景，有草地、围栏和各种动物。底部显示金币数量和点击按钮。核心操作非常简单：点击屏幕上的动物来收集金币，每次点击产生一定数量的收入。金币用于购买更多动物、升级农场设施、解锁研究项目。随着农场扩大，每次点击的收入也会增加。游戏支持离线收入：即使不玩游戏，农场也在持续产生金币，打开游戏时可以收取离线期间积累的收入。

## 核心循环

点击收集金币 -> 购买更多动物 -> 升级设施 -> 离线积累收入 -> 收取并继续扩展 -> 重复

## 核心机制

- 点击收集：点击动物收集金币，是最基础的交互方式
- 农场扩张：购买更多种类的动物（羊、牛、猪）增加收入
- 升级系统：投资金币升级农场设施，提高每次点击的收益
- 离线收入：关闭游戏后持续产生金币，降低玩家压力

## 为什么好玩

超级简单的操作让任何人都能立刻上手：只需点击。看着农场从小变大、动物越来越多的过程很有满足感。3D视觉效果和生动的动物动画让放置游戏不枯燥。

## 粘性来源

离线收入让每天都有回归的理由；农场视觉成长提供即时反馈；点击收集的节奏感让人上瘾

## Meta 系统

有研究升级系统：通过投资金币解锁新科技，提高农场效率。宠物狗和老鹰的互动增加视觉趣味。

## 实现难度

中。核心难点在于放置点击玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
