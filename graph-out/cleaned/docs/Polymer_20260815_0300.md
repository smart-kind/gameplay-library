# 聚合（Polymer）

- **类型**: 益智 / 三消变体 / 色彩消除
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Playdots / 独立开发者
- **首次发布**: 2014
- **一句话描述**: 在网格中连接相邻同色方块进行消除，通过策略规划实现连锁反应的休闲益智游戏。

## 玩法规则

游戏在一个N×N的网格上进行，网格中随机分布着不同颜色的方块。玩家的操作是：从一个方块开始，用手指向相邻（上下左右）的同色方块滑动，连接成一个"链"。松开手指后，所有连接的方块被消除。

消除后上方的方块会下落填补空位，顶部生成新方块。某些关卡有特殊方块：炸弹（消除周围所有方块）、彩虹（消除所有同色方块）、冰块（需要两次消除才能清除）、锁链（被锁定的方块需要先消除相邻方块才能操作）。

关卡目标多样：在限定步数内达到目标分数、消除特定数量的某种颜色方块、清除所有冰块、将特定方块移动到指定位置等。步数越少、得分越高，评价越高（1-3星）。

策略核心在于"规划"——不是简单看到同色就消除，而是要思考消除后哪些方块会合并，能否制造连锁反应。消除大块同色区域获得额外分数和特殊方块。

## 核心循环

规划消除路径 → 执行消除 → 观察方块下落和合并 → 规划下一步 → 完成关卡目标

## 核心机制

- **滑动连接**：手指滑动连接相邻同色方块，形成长链获得更高分数
- **重力下落**：消除后上方方块下落，可能形成新的同色合并
- **连锁反应**：一次消除可能让多个方块合并，触发连锁消除
- **特殊方块**：炸弹、彩虹、冰块等增加游戏策略深度
- **步数限制**：限定步数内完成目标，逼迫玩家思考最优解

## 为什么好玩

Polymer的魔力在于"规划的乐趣"——你需要像下棋一样思考几步之后的局面。消除一大片同色方块时，看着方块哗啦啦落下、新的同色合并在一起、再次消除，这种连锁反应带来的视觉和心理满足感极强。规则简单到三岁小孩都能理解，但精通需要大量思考和规划。

## 粘性来源

- **连锁反应快感**：制造大规模连锁消除的视觉和心理满足感
- **关卡挑战**：每个关卡都有独特的布局和限制条件
- **三星追求**：从"过关"到"三星过关"的优化过程
- **短暂对局**：每局几分钟，适合碎片时间游玩

## Meta 系统

关卡解锁系统——完成当前关卡解锁下一关，章节之间有难度递进。部分版本包含每日挑战和无尽模式。

## 实现难度

低 — 网格消除类游戏技术成熟。最大技术难点在于"动画流畅度"——方块下落、合并、消除的动画需要丝滑且符合物理直觉。重力下落算法和连锁反应检测需要精确实现。关卡设计的平衡性（难度曲线、步数设定）也是关键。
