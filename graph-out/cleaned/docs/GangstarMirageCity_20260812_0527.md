# 黑手党：海市蜃楼之城（Gangstar Mirage City）

- **类型**: 开放世界/动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Gameloft
- **首次发布**: 2026
- **一句话描述**: Gameloft Gangstar 系列最新作，开放世界犯罪动作游戏。

## 玩法规则

开放世界动作游戏，玩家在虚构城市中扮演犯罪角色，完成任务、驾驶车辆、参与枪战和帮派斗争。Gangstar 系列以 GTA 式的自由探索为基础，加入了手机优化的操控和任务设计。

玩家可以在城市中自由移动，接取各种任务包括抢劫、追逐、暗杀等。车辆系统包含多种可驾驶车辆，武器系统涵盖近战到枪械。

## 核心循环

自由探索城市 → 接取任务 → 完成犯罪行动 → 赚取金钱和声望 → 解锁新区域和武器

## 核心机制

- 开放世界探索：城市环境可自由移动，包含多种任务和活动
- 任务多样性：抢劫、追逐、暗杀等不同类型任务
- 载具系统：多种车辆可供驾驶，包含地面和可能的空中载具

## 城市探索与互动

城市包含多个区域：市中心商业区、贫民窟、海滩度假区、工业区等。每个区域有独特的犯罪类型和任务风格。

小游戏系统包含街头赛车、赌博、房地产投资等，为玩家提供主线任务之外的收入来源和娱乐内容。

## 为什么好玩

Gangstar 系列的经典犯罪题材加上最新的手机图形技术，提供流畅的开放世界体验。

## 粘性来源

任务推进、车辆和武器收集、城市探索的持续新鲜感。
