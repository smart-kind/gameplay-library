# Partymasters - Fun Idle Game

- **类型**: 派对迷你游戏合集
- **平台**: Mobile (iOS+Android)
- **开发商**: AI Games FZ
- **首次发布**: 2018
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

点击获取金币 -> 升级设施和舞者 -> 吸引更多顾客 -> 获得更多金币

## 核心机制

- **放置点击循环**: 通过点击屏幕获得金币。金币用于升级设施和雇佣舞者。升级后的设施自动产生更多金币，形成放置循环。
- **设施升级系统**: 使用金币升级各种设施（灯光、音响、舞台等）。每个升级都提高收入效率，加速金币获取。
- **舞者收集**: 雇佣和收集不同类型的舞者，每个舞者有独特的外观和能力。收集元素增加了游戏的长期目标。

## 为什么好玩

放置循环的爽快感在于数字的持续增长。金币越来越多，设施越来越好。游戏不需要持续关注，适合碎片时间游玩。

## 粘性来源

粘性来源于数值成长的满足感和收集元素的长期目标。每次登录都有新的升级可以解锁。

## Meta 系统

- 设施升级系统：提高收入效率
- 舞者收集：雇佣和收集不同舞者
- 离线收益：离线期间也会获得一定金币
- 对核心玩法的影响：升级和收集提供了长期的成长目标

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
