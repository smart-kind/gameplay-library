# Little Things™ Forever（Little Things™ Forever）

- **类型**: 找物 / 解谜 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: KlickTock Pty Ltd
- **首次发布**: 2012
- **一句话描述**: 在由数千个小物件组成的彩色马赛克中寻找隐藏物品

## 玩法规则

游戏画面是一幅由成百上千个真实小物件（纽扣、回形针、贝壳、小玩具、树叶等）精心排列而成的彩色马赛克图案。屏幕上方会显示一个需要寻找的物品名称或图标。

玩家需要在密密麻麻的物件中找到目标物品，用手指点击选中。找到的物品会高亮显示并从场景中移除，然后出现下一个寻找目标。每个关卡需要找到指定数量的物品。

物件的位置是随机生成的，每次进入同一关卡看到的布局都不一样。这保证了每次游玩都有新鲜感，即使同一个关卡玩 100 次也能有不同的体验。没有倒计时压力，玩家可以按照自己的节奏慢慢寻找。

游戏过关条件：找到该关卡所有指定的物品。没有失败条件——玩家可以无限期地搜索下去。这种设计让游戏成为一种放松减压的工具，而不是一种压力测试。

本作是 2012 年经典游戏的 HD 重制版，使用 Godot 引擎从底层重建，画面质量和流畅度都有显著提升。

## 核心循环

查看目标 → 在马赛克中寻找 → 点击选中 → 获取下一个目标

## 核心机制

- **随机化物件布局**：每次打开关卡时物件位置都会重新随机排列，确保同一关卡可以反复游玩而不会觉得重复。随机算法需要保证物品之间不会重叠且都在可视范围内
- **无压力计时**：不设置倒计时，玩家可以慢慢欣赏和搜索，降低挫败感，提升放松体验。这种设计让游戏适合任何年龄段和任何情绪状态的玩家
- **真实物件摄影**：所有马赛克物件都是真实物品的照片，这种写实风格让寻找过程更有质感，视觉上更像在探索一个微型世界。物件的选择和排列本身就是一种艺术

## 为什么好玩

Little Things Forever 提供了一种独特的'慢节奏解谜'体验——在一堆看似杂乱的小物件中突然发现目标时的那种'啊！原来你藏在这儿'的惊喜感。游戏的放松氛围让它成为睡前或通勤时的理想选择。

## 粘性来源

发现隐藏物品时的惊喜感 + 随机化布局带来的可重复性 + 无压力氛围让人愿意一直玩下去

## Meta 系统

无外围成长系统。纯关卡推进

## 实现难度

中 — 需要设计物件随机摆放算法确保目标始终可找到且不会重叠遮挡，最大难点是物件碰撞检测和可解性保证
