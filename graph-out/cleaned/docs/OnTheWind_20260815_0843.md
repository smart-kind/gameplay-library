# 随风飘叶（On The Wind (Leaf on the Wind)）

- **类型**: 物理益智 / 冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: Pangea Software, Inc.
- **首次发布**: 2014
- **一句话描述**: 一款基于物理引擎的益智冒险游戏，用手指吹动树叶在关卡中穿行，避开自然力和机械障碍。

## 玩法规则

游戏画面为2D横版，树叶是玩家控制的对象，受到真实物理引擎影响。屏幕上散布着各种自然力和机械障碍：火会烧毁树叶、水会打湿树叶增加重量、风扇会改变风向、机器会造成机械伤害。

玩家通过手指在屏幕上滑动来产生风力，推动树叶向目标方向移动。滑动的速度、方向和持续时间影响风力大小。需要精确控制才能通过狭窄通道和躲避障碍。

游戏共30个关卡，每个关卡有独特的布局和挑战。目标是让树叶安全到达指定地点。树叶被烧毁或落入危险区域则关卡失败。

每关有星级评分，基于到达时间和风力使用次数。高效通关获得更高评价。

## 核心循环

玩什么 → 得到什么 → 用来做什么：用手指吹动树叶躲避障碍到达目标，解锁新关卡挑战更复杂的物理谜题

## 核心机制

- **物理吹气控制**：用手指滑动模拟吹气，物理引擎真实模拟空气动力学效果。力度和角度决定树叶飞行轨迹，需要精细操作
- **多重环境力**：火、水、风、机器等不同障碍有独特的物理交互。火焰产生上升热气流，水增加重量改变飞行特性，善用环境力是通关关键
- **渐进难度**：30个关卡从简单的直线飞行逐步过渡到需要利用多重环境力组合的复杂谜题。后期关卡需要同时考虑多种力的作用

## 为什么好玩

控制一片树叶在复杂环境中穿行的体验非常独特。物理引擎带来的真实感让每次吹气都像是在玩真实的树叶。30个关卡设计精巧，每关都有新的物理谜题等待解决。

## 粘性来源

解谜成就感（每关都有最优解）+ 物理模拟的新鲜感 + 高分数挑战（Game Center排名）。每次尝试都觉得自己离完美通关更近一步。

## Meta 系统

- **Game Center排行榜**：每关分数通过Game Center与全球玩家竞争
- **对核心玩法影响**：无，纯关卡制益智游戏，无外围成长系统。排行榜提供长期挑战目标

## 实现难度

低 — 滑动吹气的操作简单直观，任何人都能快速上手。最大技术难点在于物理引擎的精确调优和关卡设计平衡。需要确保物理模拟既真实又可预测。
