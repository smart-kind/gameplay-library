# Alto's Odyssey（奥德赛）

- **类型**: 休闲跑酷 / 沙丘冲浪
- **平台**: Mobile (iOS+Android) / Switch
- **开发商**: Snowman
- **首次发布**: 2018
- **一句话描述**: 在无尽的沙漠沙丘上冲浪滑行，操作简单但视觉效果极美，配合氛围音乐创造一种禅意般的休闲体验。

## 玩法规则

游戏为横版卷轴自动前进的跑酷游戏。角色Alto站在滑板上从左向右自动滑行，背景是不断变化的沙漠风景——沙丘、绿洲、神庙、风化的建筑。画面采用极简的剪影风格，天空随着时间从黎明渐变到黄昏到星空。

操作只有两种：点击屏幕跳跃，长按屏幕做后空翻。点击跳跃的时机决定跳跃高度。在坡道上跳跃可以做特技动作（后空翻），每个特技动作增加分数。落地失误（头朝地）会摔倒，游戏结束。

除了基本操作，还有三种特殊机制：滑墙（靠近墙壁时自动滑行）、浮空（利用热气球和风筝在空中漂浮）、弹跳（利用特定地形弹到空中）。这些机制让简单的操作产生丰富的变化。

游戏没有"通关"概念——目标是尽可能滑得更远、获得更高分数。Zen模式没有分数、没有Game Over，只有纯粹的滑行体验和动态天气变化。

## 核心循环

滑行 → 跳跃和做特技 → 收集金币 → 用金币解锁新角色和装备 → 继续滑行追求更高分数

## 核心机制

- **特技系统**：在空中长按做后空翻，每个完整的后空翻（360度）获得分数奖励。连续做多个后空翻有连击加成。但落地必须脚朝地，否则摔倒结束。这创造了风险与回报的平衡——敢不敢再多翻一圈？
- **连锁机制**：连续做出不同动作（跳跃→特技→滑墙→弹跳）形成"连锁"，连锁越长分数倍率越高。这鼓励玩家在安全滑行和冒险特技之间找平衡。
- **动态天气和时间**：游戏内的天气（沙暴、彩虹、极光）和时间（黎明、黄昏、夜晚）自然变化，配合氛围音乐创造出每局都不同的视觉体验。

## 为什么好玩

它把跑酷游戏的紧张感和禅意完美结合。当你进入"心流"状态——不需要思考就知道何时跳跃、何时做特技——那种沉浸感极强。配合极简的美术和氛围音乐，它更像是一个可以玩的冥想体验。

## 粘性来源

- **分数追求**：每次死亡都想"再来一次"刷更高分数
- **解锁收集**：解锁不同角色（各有微小的手感差异）和滑板的视觉变化
- **任务系统**：每局有随机的3个任务（如"做一次360度后空翻"、"滑行500米"），完成获得金币
- **Zen模式**：无压力纯享受模式，适合放松时玩

## Meta 系统

- **金币**：滑行中收集金币，用于解锁新角色和装备
- **任务**：每局随机3个任务，完成后获得额外金币
- **排行榜**：全球高分排行榜，和全世界玩家比较
- **对核心玩法的影响**：金币和解锁提供目标感，但不改变核心——滑行技术才是得分关键

## 实现难度

低 + 自动前进跑酷的核心逻辑相对简单。最大难点在于手感调校（跳跃力度、滑行物理、特技判定）和视觉效果（动态天空、粒子效果、流畅动画）。氛围音乐和画面的配合也需要艺术感。技术实现不难，但做出"感觉好"的体验需要大量微调。
