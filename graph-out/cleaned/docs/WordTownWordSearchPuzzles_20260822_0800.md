# Word Town 单词搜索解谜（Word Town: Word Search Puzzles）

- **类型**: 文字解谜 / 休闲 / 益智
- **平台**: Mobile (iOS+Android)
- **开发商**: Hi Studio Limited
- **首次发布**: 2018
- **一句话描述**: 结合传统单词搜索和"消除式"反馈的文字解谜游戏

## 玩法规则

游戏界面呈现一个字母网格（通常6×6到10×10不等）。每关给出若干目标单词（通常5-10个），玩家需要在字母网格中找到这些单词并划线连接。

**操作方式**：手指从一个字母开始滑动，经过相邻字母（水平、垂直、对角线均可），连出目标单词后松手。正确的单词会高亮显示并从网格中消除，同时播放满足感反馈动画。

**关卡推进**：完成一关所有目标单词后即可进入下一关。随着关卡推进，网格尺寸增大、单词数量增多、单词长度变长。

**辅助机制**：
- **提示系统**：消耗游戏内货币可高亮一个字母作为提示
- **主题关卡**：不同关卡围绕特定主题（动物、食物、国家等）组织单词
- **每日挑战**：特殊每日关卡提供额外奖励

## 核心循环

浏览目标单词列表 → 在字母网格中搜索并滑动连接单词 → 消除已找到的单词 → 完成所有目标 → 进入下一关

## 核心机制

- **字母网格搜索**：在杂乱的字母矩阵中识别目标单词，考验词汇量和模式识别能力。单词可以以任何方向排列，增加了搜索难度。
- **滑动划线操作**：直观的手指滑动操作比传统"点击字母"更流畅，配合消除动画提供即时满足感。
- **主题分类**：按主题组织单词降低了搜索范围，玩家可以在脑中先筛选与主题相关的字母组合。
- **渐进难度**：从小网格短单词到大网格长单词，难度曲线平滑，适合各水平玩家。

## 为什么好玩

找单词的过程像是一场"寻宝游戏"——当你突然在混乱的字母中发现隐藏的单词时，那种"啊哈"的顿悟感是核心快感。消除动画的视觉反馈进一步强化了这种满足感。

## 粘性来源

- **顿悟快感**：每次发现隐藏单词时的认知快感驱动持续游玩。
- **渐进挑战**：难度逐渐提升，始终保持"有点挑战但能完成"的心流状态。
- **每日挑战**：限时每日关卡创造了"今天还没做"的紧迫感。

## Meta 系统

- **关卡进度系统**：线性关卡推进，每关完成后获得星星评分。
- **提示货币系统**：通过游玩或内购获得提示币，用于卡关时获取帮助。

## 实现难度

低 — 核心逻辑是字母网格+字典匹配，技术实现简单。最大难点在于关卡设计（确保每关都有合理的解法）和大量关卡内容的生产。
