# Gun Head Run

- **类型**: 超休闲 / 动作 / 跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: MondayOFF
- **首次发布**: 2021
- **一句话描述**: 操控一个头部是枪的角色在跑道上自动前进，点击射击产生后坐力来移动和消灭敌人。

## 玩法规则

游戏画面呈现3D跑道场景，角色自动向前移动。玩家的点击操作控制角色向点击方向射击——子弹飞出的同时，角色被后坐力推向相反方向。这个反向物理机制是游戏的核心。

玩家在跑道上需要同时做两件事：躲避障碍物（箱子、墙壁、陷阱）和消灭敌人。每次射击既是攻击也是位移——玩家需要精确计算射击角度，既要击中敌人又要将自己推向安全区域。

跑道两侧和前方会生成各种敌人，有的固定不动，有的来回巡逻，有的会向玩家射击。障碍物包括墙壁、锥桶、移动的方块等。被任何敌人或障碍物碰到即游戏结束。部分跑道设有收集品（金币、宝石），靠近即可自动拾取。

## 核心循环

自动前进 → 点击射击(消灭敌人+利用后坐力位移) → 收集金币 → 死亡后用金币解锁皮肤

## 核心机制

- **后坐力位移**：射击方向与位移方向相反，需要反向思考操作
- **自动前进节奏**：角色不断向前，没有暂停或回头的机会
- **双目标决策**：每次射击都需要同时考虑"攻击谁"和"往哪躲"

## 为什么好玩

"射击=移动"的设定创造了独特的决策空间——你不能同时攻击敌人和躲避障碍，必须在两者之间取舍。熟练利用后坐力进行连续闪避时会产生极强的"心流"体验。

## 粘性来源

每局1-2分钟的超短节奏让"再来一局"的冲动极强。从"不会移动"到"精准操控"的技能成长曲线明显，皮肤收集提供额外动力。

## Meta 系统

金币解锁角色皮肤和枪械外观，不影响核心玩法平衡。包含每日挑战和排行榜。

## 实现难度

低。2D/3D混合场景，核心物理逻辑简单。难点在于关卡节奏调校——敌人和障碍物的生成需要精确平衡。
