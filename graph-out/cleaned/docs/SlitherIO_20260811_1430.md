# Slither.io（Slither.io）

- **类型**: 多人在线 / 生存 / 动作
- **平台**: Web / Mobile (iOS+Android)
- **开发商**: Steve Howse
- **首次发布**: 2016
- **一句话描述**: 控制一条蛇吃光点变长，用身体围堵其他玩家将其消灭

## 玩法规则

玩家控制一条蛇在一个巨大的二维圆形地图中移动，用鼠标（Web版）或虚拟摇杆（移动版）控制蛇头的行进方向。地图上散布着大量发光的小圆点，蛇吃到后会变长。

核心机制：当其他蛇的头部碰到你的蛇身时，那条蛇就会死亡并变成大量光点。你需要躲避别人的蛇身，同时想办法让别人撞到你的身体。

加速功能：按住鼠标左键或点击加速按钮，蛇会加速前进，但加速过程中会持续掉落身上的光点（缩短身体）。加速主要用于快速穿越危险区域或追击。

"围堵"策略：用蛇身围绕其他蛇形成包围圈，缩小空间迫使对方撞到你的身体。这是高级玩家的主要战术。

## 核心循环

吃光点变长 → 用身体消灭对手 → 吃对手掉落的光点 → 变得更大 → 继续猎杀

## 核心机制

- **身体=武器**: 蛇身既是你的"命"（被碰到就死），也是你的武器（别人碰到你他就死）
- **加速-缩短权衡**: 加速让你更快但身体变短，是保命和追敌之间的关键决策
- **围堵战术**: 利用蛇身形成封闭曲线困住对手，创造了空间策略维度
- **视觉引导**: 蛇身的发光效果和移动轨迹让战场信息一目了然

## 为什么好玩

Slither.io在Agar.io的基础上增加了"身体"这个维度，让策略从单纯的"吃与被吃"升级为"用身体布局围堵"。看着自己从一条小蛇慢慢长成占据半个地图的巨蛇，成就感极强。

## 粘性来源

视觉上的成长反馈（蛇越来越长、颜色越来越炫） + 围堵成功时的战术满足感 + 随时可能遇到更大对手的紧张感。每局都是全新的开局，死亡后立刻重生，无缝衔接。

## Meta 系统

无。纯竞技场模式。

## 实现难度

中 — 蛇身段的平滑移动（每段跟随前一段的轨迹）需要较好的插值算法。多人同步和碰撞检测是技术难点。但对于小游戏来说，已有成熟的实现方案。
