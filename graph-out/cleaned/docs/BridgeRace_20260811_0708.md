# Bridge Race（Bridge Race）

- **类型**: 休闲 / 竞技 / 堆叠
- **平台**: Mobile (iOS+Android)
- **开发商**: Garawell Games / Supersonic
- **首次发布**: 2020
- **一句话描述**: 收集积木块搭建桥梁，抢先到达终点并抢夺财宝

## 玩法规则

游戏以俯视角3D呈现。玩家控制一个小人角色在一条跑道上移动。跑道上散落着各种颜色的积木块（通常为绿色），玩家跑过时自动收集这些积木。

收集到的积木会堆叠在角色脚下。玩家可以用这些积木搭建桥梁——向前方伸出桥面。需要按住屏幕来持续搭桥，松开则停止。桥会向角色面对的方向延伸。

赛道上还有其他AI对手（或其他玩家），他们也在收集积木和搭桥。目标是比对手更快到达终点。到达终点后，可以抢夺终点处的财宝（金币堆）。

游戏的创新之处在于"堆叠"和"新输出"——玩家不仅堆叠积木（传统输出），还用这些积木搭建桥梁（新输出）来推进关卡。

## 核心循环

收集积木 → 搭桥前进 → 到达终点 → 抢夺财宝 → 下一关

## 核心机制

- **收集+建造双循环**: 传统堆叠游戏只收集，Bridge Race加入了建造输出——用收集的积木搭桥。这形成了"收集→建造→推进"的完整循环。
- **实时竞争**: 多个角色在同一赛道上竞争，玩家需要判断何时收集、何时搭桥、何时加速。
- **路径规划**: 终点位置不总是正前方，有时需要横向搭桥或绕路，增加了策略维度。
- **资源管理**: 积木既是"分数"也是"建筑材料"——搭桥消耗积木，玩家需要在速度和资源间做权衡。

## 为什么好玩

竞争感极强——看着对手在前面搭桥而自己落后时会产生紧迫感。到达终点抢夺财宝的瞬间有很强的成就感。

## 粘性来源

- **实时竞争**: 与其他角色同时比赛创造了"不能输"的紧迫感
- **抢宝快感**: 到达终点时抢夺金币的瞬间满足感
- **关卡多样性**: 不同赛道布局（直行、转弯、分叉）保持新鲜感
- **快速单局**: 每局只需几十秒，随时可以再来

## Meta 系统

关卡推进系统——完成一定数量的关卡后解锁新场景或新角色外观。部分版本有角色解锁系统。

## 实现难度

中。核心是3D角色控制 + 积木堆叠物理 + 多角色AI竞争 + 桥梁动态生成。最大难点在于AI平衡——让AI对手既不会太强让玩家绝望，也不会太弱失去竞争感。
