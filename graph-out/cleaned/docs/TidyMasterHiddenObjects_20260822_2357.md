# 整理大师：隐藏物品（Tidy Master: Hidden Objects）

- **类型**: 找物 / 整理 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Longwind Studio
- **首次发布**: 2024
- **一句话描述**: 结合整理收纳和找物玩法的休闲游戏，在杂乱空间中寻找物品并整理归位。

## 玩法规则

玩家面对一个杂乱的房间或区域（如凌乱的书架、散落的厨房台面、堆满杂物的桌子）。画面中有大量物品随机散布，视觉噪音较高。

游戏包含两个阶段：第一阶段是'找物'——根据列表在杂乱场景中找到指定物品并点击选中；第二阶段是'整理'——将找到的物品拖拽到正确的位置或分类区域中。

整理阶段的正确位置通常有视觉暗示（如轮廓阴影、颜色匹配区），玩家需要判断每件物品应该放在哪里。放对位置时物品会'吸附'到位并播放满意音效；放错则弹回原位。

场景难度通过物品数量和杂乱程度递增。早期场景只有几个区域需要整理，后期可能涉及多个房间的分类整理。部分关卡限时，需要在时间耗尽前完成整理。

## 核心循环

在杂乱场景中找物品 → 拖拽归位整理 → 获得整洁场景 → 进入下一关卡

## 核心机制

- 双重玩法融合机制：'找物'满足观察搜索的快感，'整理'满足秩序恢复的满足感。两种玩法自然衔接——找到物品后立刻有'整理归位'的动作承接，不浪费注意力。
- 视觉噪音递进机制：关卡从'有点乱'到'极其混乱'，杂乱程度直接影响搜索难度。玩家在面对高度混乱场景后完成整理时，'从无序到有序'的视觉对比产生强烈的成就感。
- 分类归位机制：整理不是简单放回，而是按类别或规则分类（如厨具归厨房、书籍归书架）。加入轻度逻辑判断，让整理本身也有解谜性质。

## 为什么好玩

找物+整理的组合天然有'爽感'。看到混乱场景逐渐变得整洁的视觉反馈极其满足，加上整理归位时的吸附动画和音效，形成类似ASMR的舒适体验。

## 粘性来源

'整洁冲动'——人类天生喜欢秩序，看到混乱变整洁的视觉变化本身就是一种奖励。每个关卡的'整理完成'瞬间提供即时满足，促使'再来一关'。

## Meta 系统

关卡解锁系统，完成一组关卡解锁新主题（如办公室整理、车库整理、衣柜整理等）。部分版本设有装饰系统，用积分解锁家具外观。

## 实现难度

低。找物热区+拖拽判定+分类逻辑，技术简单。最大难点在于场景杂乱度的美术设计——需要'乱得有趣但不恶心'，以及整理规则的合理性。

游戏中的场景设计贴近日常生活——乱糟糟的书桌、堆满衣服的沙发、塞满食品的冰箱——让玩家有强烈的代入感。整理完成后的场景不仅变整洁，还会'焕新'——原本被杂物覆盖的装饰物显露出来，墙面变得更明亮，整个空间焕然一新。这种视觉变化是核心奖励。
