# 生吃还是烤熟（Raw or Roasted）

- **类型**: 益智 / 休闲 / 反应
- **平台**: Nintendo 3DS
- **开发商**: 独立开发者
- **首次发布**: 2011
- **一句话描述**: 根据食物的烹饪状态进行分类判断的快节奏益智游戏

## 玩法规则

屏幕上不断从上方掉落各种食物物品（肉类、蔬菜、水果、海鲜等），玩家需要快速判断每种食物应该'生吃(Raw)'还是'烤熟(Roasted)'，然后通过滑动或点击将它们分配到左侧或右侧的对应区域。判断依据包括食物的种类常识（三文鱼可以生吃但鸡肉必须烤熟）和关卡给出的特殊规则。

随着游戏推进，掉落速度越来越快，新规则不断加入——某些食物有特殊要求（如某些蔬菜既可以生吃也可以烤熟，需要根据关卡指定的偏好来选择）、某些关卡出现'既不能生也不能烤'的食物需要拖到第三个特殊区域。错误分类会扣分/扣生命，正确分类获得分数和连击加成。

游戏包含多种模式：限时模式（在规定时间内尽可能多分类）、无尽模式（速度持续增加直到失误）、挑战模式（完成特定目标如连续正确20次）。3DS的触控操作让拖拽分类非常直观，下屏显示当前规则和食物信息，上屏显示游戏区域。

## 核心循环

食物掉落 → 快速判断Raw或Roasted → 拖到正确区域 → 累积分数和连击

## 核心机制

- **规则递进系统**：早期规则简单直接（肉类烤熟、水果生吃），后期叠加多层条件（如'本周特惠：蘑菇必须烤熟'、'过敏原警告：坚果类单独分类'）。规则在屏幕上方以提示条显示，需要快速阅读和应用
- **时间压力与连击系统**：掉落速度递增，考验反应速度和判断力。连续正确分类获得连击加成（分数倍增），一旦失误连击清零。这创造了'保持连击'的紧张感和动力
- **特殊食物与异常处理**：部分食物有特殊分类规则或属于第三类（如过期食品需要丢弃），需要打破二元思维，增加判断难度

## 为什么好玩

简单直接的分类玩法带来快节奏的刺激感，连击系统的正反馈让人停不下来。食物图鉴和烹饪小知识作为附加内容增加趣味性。

## 粘性来源

分数排行榜驱动竞争（和朋友比谁分高）。'再试一次就能突破连击纪录'的心理。每日更新的规则变体保持新鲜感。

## Meta 系统

无复杂Meta系统。分数排名、连击记录和食物图鉴收集作为基础进度。解锁新食物类型和主题皮肤。

## 实现难度

低 —— 操作简单（滑动分类），核心挑战在于反应速度、记忆力和多规则并行处理。最大技术难点是流畅的动画效果和触控响应的精确性。
