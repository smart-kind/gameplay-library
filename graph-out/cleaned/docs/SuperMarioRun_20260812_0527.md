# 超级马里奥酷跑（Super Mario Run）

- **类型**: 平台跳跃/跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: Nintendo
- **首次发布**: 2016
- **一句话描述**: 任天堂出品的自动跑酷式马里奥平台跳跃游戏。

## 玩法规则

马里奥自动向右奔跑，玩家通过点击屏幕控制跳跃。轻点短跳，长按长跳，空中再按一次可以进行二段跳。游戏包含多种关卡，每个关卡有隐藏的粉红色和紫色金币需要收集。

关卡设计融入了经典马里奥元素：砖块、问号块、管道、敌人。部分关卡有特殊的主题和机制，如水下关卡、地下关卡等。

## 核心循环

自动奔跑 → 点击跳跃躲避障碍和敌人 → 收集金币 → 完成关卡 → 解锁新关卡

## 核心机制

- 自动跑酷：马里奥自动前进，玩家只控制跳跃时机
- 多色金币收集：除普通金币外，还有隐藏的粉红和紫色金币，鼓励多次通关
- 经典平台元素：砖块、问号块、管道等马里奥标志性设计

## Kingdom Builder 系统

完成关卡后获得的金币可以用于建造和装饰马里奥王国。王国建设提供额外的游戏目标，鼓励玩家反复通关收集更多金币。

王国中的建筑有不同的功能和装饰价值，解锁特殊建筑需要收集特定数量的彩色金币。

## 为什么好玩

任天堂品质的平台跳跃设计，单手操作即可享受完整马里奥体验。经典关卡设计经过移动端优化。

## 粘性来源

全金币收集挑战、竞速模式的时间竞争和 Kingdom Builder 的建设乐趣。

## Meta 系统

免费下载（前几关免费），完整版需一次性购买

## 实现难度

中等 — 自动奔跑但跳跃时机需要精确掌握
