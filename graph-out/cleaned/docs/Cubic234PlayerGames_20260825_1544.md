# Cubic 多人小游戏合集（Cubic 2 3 4 Player Games）

- **类型**: 休闲合集 / 多人派对
- **平台**: Mobile (iOS+Android)
- **开发商**: Cubic
- **首次发布**: 2020
- **一句话描述**: 一款支持2-4人同屏对战的多人小游戏合集，适合朋友聚会时一起游玩。

## 玩法规则

游戏提供多种小游戏选择，支持2-4名玩家在同一设备上进行对战。每款小游戏有不同的操作方式。

在坦克对战中，每个玩家控制一个坦克，通过虚拟摇杆移动和射击，最后存活的玩家获胜。在赛跑游戏中，玩家需要快速交替点击屏幕让角色奔跑。

每局游戏通常持续1-3分钟，最先达到目标或分数最高的玩家获胜。游戏支持本地多人模式，所有玩家共享同一台设备。

## 核心循环

选择小游戏 -> 邀请朋友 -> 同屏对战 -> 决出胜负 -> 换下一款游戏

## 核心机制

- 同屏多人对战: 多名玩家在同一屏幕上各自控制角色，通过屏幕分区避免误操作。
- 多样小游戏库: 包含赛车、射击、运动、益智等多种类型的小游戏，满足不同场景需求。
- 即开即玩: 无需注册登录，打开游戏即可开始，适合聚会场景快速上手。

## 为什么好玩

面对面竞技的社交乐趣是核心。朋友间的竞争和互动比游戏本身更有趣。

每款游戏都有独特的操作方式，从快速点击到精准滑动，测试不同方面的反应能力。

## 粘性来源

社交聚会场景的天然粘性。多款游戏的轮换让每局都有新鲜感。

简单易上手的特性让即使是平时不玩游戏的人也能参与进来，扩大了游戏的适用场景和人群。

## Meta 系统

游戏解锁系统：随着游玩次数增加，解锁更多小游戏。

成就系统：完成特定挑战获得徽章。

## 实现难度

低 - 每款小游戏实现简单，核心难点在于多玩家输入处理和UI适配。
