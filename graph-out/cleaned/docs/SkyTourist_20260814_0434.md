# Sky Tourist

- **类型**: 解谜 / 物理
- **平台**: Mobile (iOS+Android)
- **开发商**: Playbox
- **首次发布**: 2013
- **一句话描述**: 操控两端火箭之间的绳索，让太空游客在外星迷宫中穿行探索

## 玩法规则

游戏画面呈现外星世界的俯视角或侧视角场景。玩家的交通工具是一根绳索，绳索两端各连接一枚火箭，太空游客（你操控的角色）悬挂在绳索中间。

操作方式：左手大拇指控制左侧火箭的高度，右手大拇指控制右侧火箭的高度。两个火箭高低不同，绳索就会产生倾斜角度，游客就会沿着绳索滑向低处。通过交替调整两端火箭的高度，让游客在外星迷宫中穿行。

关卡中分布着金币和纪念品需要收集，还有各种地形障碍如岩层和平台。如果绳索拉得太长会断裂，游客就会坠落死亡。绳索也可能被缠绕卡住，需要小心选择逃生路线。

关卡中还有简单的物理谜题需要解决：推开大门、敲开障碍物等。不同的路线可能隐藏着秘密通道和特殊奖励。

## 核心循环

操控火箭升降 → 让游客沿绳索滑行 → 收集金币和纪念品 → 解开物理谜题 → 完成关卡

## 核心机制

- **双火箭绳索操控**：左右手独立控制两端火箭高度，绳索倾斜产生滑动方向，是一种独特的"双指倾斜"操作模式
- **绳索张力管理**：绳索拉太长会断裂，需要时刻注意两端火箭的距离差
- **物理互动解谜**：用游客的重量推开机关、敲开障碍，不同路线有不同奖励

## 为什么好玩

用绳索在迷宫中穿行的概念在移动端非常新颖——大多数解谜游戏都是点击移动或拖拽，而 Sky Tourist 的双火箭绳索系统创造了一种全新的操控体验。小关设计精炼，谜题简洁但有趣。评测指出偶尔会出现绳索莫名其妙断裂或游客被卡住的挫折感，但整体体验令人难忘。

## 粘性来源

"再试一次"的冲动——绳索断裂导致关卡重新开始时会让人觉得"就差一点"，激励反复尝试。75 个关卡分布在三个不同星球，提供了充足的探索目标。

## Meta 系统

金币和纪念品收集系统，用于衡量关卡完成度。无明显的外围成长系统。
