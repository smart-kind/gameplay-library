# Juice Jam! Match 3 Puzzle Game

- **类型**: 三消解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Jam City, Inc.
- **首次发布**: 2015
- **一句话描述**: 一款以水果为主题的三消益智游戏，由Cookie Jam原班团队打造，玩家通过匹配水果制作果汁，穿越数百个关卡。

## 玩法规则

游戏界面展示一个充满各种水果的网格棋盘。玩家通过滑动交换相邻的两颗水果（上下左右方向），将3颗或更多相同水果排列成一行或一列来完成消除。消除后水果消失，上方水果下落填补空位，新水果从顶部补充。

匹配4颗水果产生"搅拌器"道具，可以清除一整行或一列；匹配5颗产生"果汁炸弹"，可以清除屏幕上所有同色水果；两个道具相邻合并会产生更强大的组合效果（如全清炸弹、大面积消除等）。

游戏采用世界地图式的关卡推进结构，每个"世界"包含数十个关卡，拥有独特的美术风格和主题。关卡目标多样：在限定步数内收集指定数量的水果、清除果酱覆盖的区域、达到目标分数等。

## 核心循环

选择关卡 → 滑动交换水果进行匹配 → 触发连击和道具 → 达成目标 → 前往新世界

## 核心机制

- **水果主题匹配系统**：以水果作为消除元素（猕猴桃、芒果等），视觉风格清新可爱。每种水果对应不同的颜色和消除效果，与"果汁"主题高度契合。
- **道具协同机制**：不同道具的合并产生更强大的效果，鼓励玩家思考如何制造并利用道具组合。策略性体现在"先制造道具"还是"先使用道具"的选择上。
- **世界探索结构**：数百个关卡分布在不同的"世界"中，每个世界有独特的视觉主题和关卡设计，提供了持续的探索感和新鲜感。

## 为什么好玩

水果消除的视觉和音效反馈非常令人满足——鲜艳的水果、清脆的匹配音效、以及道具爆炸时的绚丽动画。Cookie Jam团队的经验确保了关卡难度曲线的合理设计，既不会太简单让人无聊，也不会太难让人沮丧。

## 粘性来源

世界地图式的探索感和"差一步就通关"的执着是核心粘性。每个新世界提供全新的视觉体验，激发"接下来会是什么样子"的好奇心。道具组合的爆炸效果带来了强烈的爽感反馈，让人想"再来一局看看能不能做出更好的组合"。

## Meta 系统

无独立的外围成长系统。游戏通过关卡推进和新世界解锁提供持续目标，偶尔有限时活动和特殊挑战关卡。

## 实现难度

低。核心三消逻辑成熟，主要工作量在于数百个关卡的设计和美术资产的创建。最大技术难点在于关卡难度平衡——确保每个关卡既有挑战性又不会让人感到绝望。
