# 点击英雄 - 放置猎手（Clicker Heroes - Idle Slayer）

- **类型**: 放置/点击
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2015
- **一句话描述**: 经典点击放置游戏

## 玩法规则

玩家点击屏幕攻击怪物，击杀后获得金币。雇佣英雄自动攻击，减少手动点击需求。金币用于升级英雄和解锁新英雄。随着进度推进，遇到更强的怪物。每击杀一定数量的怪物可进入下一区域，获得永久加成。游戏结合了手动点击和自动放置两种模式。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

点击/自动攻击 → 击杀获得金币 → 雇佣升级英雄 → 挑战更强怪物 → 区域进阶

## 核心机制

- **点击攻击**:  玩家点击对怪物造成伤害
- **英雄雇佣**:  雇佣英雄自动攻击
- **区域进阶**:  击杀足够怪物进入新区域

## 为什么好玩

点击反馈的即时满足感，英雄团队不断壮大的成就感

## 粘性来源

英雄收集的欲望；区域进阶的里程碑感

## Meta 系统

英雄雇佣和升级，区域进阶系统

## 实现难度

低 - 核心是点击计数和数值增长 - 数值平衡，保持长期可玩性
