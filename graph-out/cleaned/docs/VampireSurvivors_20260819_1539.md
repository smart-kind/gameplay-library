# Vampire Survivors

- **类型**: Roguelike / 弹幕射击 / 放置生存
- **平台**: Mobile (iOS+Android) / PC (Steam) / Switch
- **开发商**: Poncle
- **首次发布**: 2022
- **一句话描述**: 在怪物大军中存活30分钟，自动攻击 + 移动闪避，靠升级选技能不断变强

## 玩法规则

游戏画面是一张开阔的地图，玩家控制一个角色在地图上自由移动（摇杆或键盘）。屏幕四面八方不断涌来大量敌人，敌人数量随时间递增，从几十个到几百个甚至上千个。

玩家角色**自动攻击**最近的敌人，玩家唯一需要做的就是控制角色移动，避开敌人和弹幕。敌人被击杀后会掉落经验宝石（绿色小菱形），玩家靠近宝石即可拾取升级。

每次升级时，画面暂停，弹出随机选项让玩家从武器、被动技能中选择一项。武器决定攻击方式（如飞刀、魔杖、圣水、斧头等），被动技能增强属性（如移动速度、最大生命、拾取范围、攻击速度等）。

游戏目标是存活到 30 分钟（或更长），Boss 会在特定时间点出现。被敌人碰到会扣血，生命值归零则游戏结束。部分武器组合后可以"进化"为更强形态。

## 核心循环

移动闪避 → 自动杀敌捡经验 → 升级选武器/被动 → 更强火力杀更多敌 → 存活更久

## 核心机制

- **自动攻击系统**：玩家不手动攻击，武器按自己的冷却周期自动发射或释放效果，玩家专注于走位。武器类型多样：投射物（飞刀）、环绕物（大蒜光环）、区域效果（圣水溅射）、追踪弹（魔法弹）等。
- **升级选牌系统**：每次升级从 3-5 个随机选项中选择一项，构建独特的武器+被动组合。选择策略决定存活能力——是先堆满武器栏位，还是优先提升拾取范围和移动速度？
- **武器进化系统**：特定的武器在满级后，搭配对应的被动技能，可以进化为更强大的形态（如魔杖→千刃）。这是游戏中后期的核心追求。
- **敌潮递增机制**：敌人数量和种类随时间逐步升级，形成压迫感。后期满屏弹幕，考验玩家的路线规划能力。

## 为什么好玩

极短的决策周期带来极强的"再来一局"冲动——每次死都觉得差一点就能活更久，而新一次的升级选择总能构建出不同的体验。满屏敌人被成片消灭的视觉爽感，加上不断变强的正反馈，形成独特的多巴胺循环。

## 粘性来源

- **随机Build体验**：每局武器选择随机，每次都是全新的构筑路线
- **解锁驱动**：用金币解锁新角色、新武器、新地图，解锁条件本身就是玩法挑战（如"用X角色存活15分钟"）
- **进化收集**：武器进化图鉴驱动玩家反复尝试不同组合
- **"差一点"心理**：经常死在27/29分钟，不甘心感极强

## Meta 系统

- **金币商店**：游戏结束后根据表现获得金币，用于永久升级属性（最大生命、移动速度、拾取范围、冷却缩减等），即使Build不好也能靠永久属性走得更远
- **角色解锁**：通过达成特定条件解锁新角色，每个角色自带不同的初始武器和属性倾向
- **隐藏角色/武器**：特定操作或条件触发隐藏内容，驱动探索

## 实现难度

低-中。核心循环简单（自动攻击 + 移动 + 经验升级），最大技术难点是大规模敌人渲染和性能优化——屏幕上可能有上千个敌人同时移动，需要高效的对象池管理和碰撞检测（如空间分区/网格化碰撞）。
