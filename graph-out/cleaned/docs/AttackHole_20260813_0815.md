# Attack Hole

- **类型**: 休闲/物理吞噬
- **平台**: Mobile (iOS+Android)
- **开发商**: Rollic Games (Zynga)
- **首次发布**: 2021
- **一句话描述**: 控制黑洞吞噬物体的物理超休闲游戏，基于"吞噬变大"核心循环

## 玩法规则

玩家控制一个黑色空洞在3D场景中移动，目标是吞噬场景中的各种物体。
屏幕UI显示当前关卡进度和已吞噬物体数量，场景以俯视角呈现。
玩家通过手指滑动控制黑洞移动方向，黑洞会自动吞噬在其范围内且体积小于黑洞的物体。
黑洞吞噬物体后会逐渐变大，能够吞噬更大的物体。
场景中物体的体积从小到大分布，玩家需要按从小到大的顺序逐步吞噬。
关卡目标是吞噬场景中的所有指定物体或达到一定体积。
每个关卡的场景和可吞噬物体不同，提供多样化的视觉体验。

## 核心循环

控制黑洞移动 -> 吞噬小物体变大 -> 能吞噬更大物体 -> 清空关卡场景

## 核心机制

- **体积增长**：黑洞吞噬物体后体积增大，解锁吞噬更大物体的能力，形成清晰的成长反馈
- **尺寸限制**：只能吞噬比黑洞小的物体，需要按从小到大的顺序策略性规划吞噬路线
- **物理交互**：被吞噬的物体有明显的物理动画效果（吸入、消失），提供视觉满足感
- **场景多样性**：每个关卡有不同的场景主题和物体类型，保持新鲜感

## 为什么好玩

Attack Hole将"吃豆豆"的核心循环具象化为黑洞吞噬，视觉冲击力极强。看着黑洞从小变大、从小物体吞到大物体的成长过程带来天然的成就感。干净清爽的3D视觉效果和流畅的物理动画让吞噬过程极具满足感。

## 粘性来源

核心粘性来自"吞噬变大"的正反馈循环。每局从小黑洞开始，逐步成长为能吞噬大型物体的过程充满成就感。关卡场景的多样性和"清空所有物体"的目标提供持续动力。

## Meta 系统

关卡解锁系统。完成当前关卡后解锁新关卡，每个关卡有不同场景和物体主题。对核心玩法无影响，提供进度感。

## 实现难度

低。核心是3D场景中的碰撞检测+体积比较+物理吞噬动画。技术难点在于吞噬动画的流畅性和大量物体同时存在时的性能优化。
