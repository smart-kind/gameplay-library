# 射手射击（Marksman Shooting）

- **类型**: 射击 / 模拟
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发者
- **首次发布**: 2015
- **一句话描述**: 第一人称射击训练模拟游戏，玩家在靶场上使用各种枪械进行精准射击挑战

## 玩法规则

游戏以第一人称视角呈现射击靶场，玩家看到枪械瞄准镜和远处的靶子。画面中有不同距离的靶标（固定靶、移动靶、突然出现的闪现靶），每种靶子有不同的分值。

玩家需要通过触屏控制准星瞄准目标，点击屏幕开火。长按可以更稳定地瞄准但需要控制呼吸抖动（准星会有轻微晃动）。游戏中有多种枪械可选：手枪、步枪、狙击枪等，每种枪械的后坐力、射速和精准度不同。

操作方式：拖动屏幕移动准星、点击开火、双指缩放切换瞄准镜倍率、滑动切换武器。移动靶需要预判目标运动轨迹提前瞄准，闪现靶需要快速反应。

游戏目标是在限定时间内击中尽可能多的靶子并获得高分。未击中的靶子不扣分但浪费宝贵的射击时间。某些关卡要求击中特定颜色或形状的靶子，击错靶子会扣分。

## 核心循环

选择武器 → 瞄准靶标 → 开火射击 → 获得分数 → 解锁新关卡和武器

## 核心机制

- **精准瞄准系统**：准星会受呼吸影响产生微小抖动，需要在稳定瞬间开火，模拟真实射击体验
- **多武器系统**：不同枪械有不同手感——手枪后坐力小但威力低，狙击枪精准但射速慢，霰弹枪适合近距离，鼓励玩家根据关卡特点选择
- **动态靶标**：移动靶需要预判运动轨迹，闪现靶考验反应速度，组合靶考验判断力，提供多样化的瞄准挑战
- **连击奖励**：连续命中获得倍率加分，一旦脱靶连击重置，鼓励玩家追求精准而非盲目开火

## 为什么好玩

射击游戏的核心爽感——精准命中目标时的即时反馈让人满足。从手枪到狙击枪的多样武器选择和不同距离的挑战，让每次射击都有新鲜感。

## 粘性来源

高分排行榜竞争、"差一发就完美命中"的不甘心、新武器解锁的探索欲。精准射击的成就感直接而纯粹，让人想要不断突破自己的记录。

## Meta 系统

武器解锁系统：通过累积分数解锁新枪械和配件（瞄准镜、握把等），提升射击体验和精准度。

## 实现难度

低。核心逻辑是准星控制和碰撞检测，第一人称视角和简单的3D/2D靶场即可实现。最大技术难点是射击物理（后坐力模拟）和准星抖动的自然感。
