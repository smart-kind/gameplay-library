# 无限循环：放松谜题（Infinity Loop: Relaxing Puzzle）

- **类型**: 逻辑连接解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: INFINITY GAMES, LDA
- **一句话描述**: 基于实际描述提炼的一句话概括

## 玩法规则

玩家面对的是一组精心设计的游戏元素，通过直觉化的操作与游戏世界互动。

**画面与UI布局**：游戏采用简洁直观的视觉风格，核心玩法区域占据屏幕中央，操作区域位于底部或边缘。UI元素包括分数显示、进度指示器和操作按钮，均设计为不干扰核心游戏体验。

**操作方式**：玩家通过点击屏幕来触发核心操作。根据具体游戏类型的不同，操作可能是单点触发（如释放物体）、拖拽移动（如放置方块）、或长按蓄力（如发射弹丸）。每种操作都经过精心设计，确保单手即可流畅完成。

**操作效果**：每次操作都会产生即时的视觉和音效反馈。物体移动、消除、碰撞等动作都有清晰的动画表现，帮助玩家理解操作结果。连击或特殊操作会触发额外的视觉特效，增强成就感。

**游戏目标**：完成当前关卡的挑战，获得尽可能高的分数。不同类型的游戏有不同的通关条件——可能是清除所有方块、连接所有线路、或在限定时间内完成任务。

**过关/失败条件**：当达成关卡目标时自动进入下一关。失败通常由资源耗尽（如托盘满格无法消除）、时间超时、或角色被击败触发。

## 核心循环

操作 → 获得分数/消除进度 → 解锁新关卡/获得升级 → 挑战更高难度

## 核心机制

- **即时反馈机制**：每次操作都有明确的视觉、音效和分数反馈，让玩家立即理解自己的行为产生了什么效果。这种即时反馈循环是大脑释放多巴胺的关键，也是让人上瘾的核心原因。

- **渐进难度曲线**：从极简的入门关卡开始，每关引入一个新元素或小幅增加复杂度。玩家在不知不觉中掌握了高级技巧，当突然面对复杂关卡时，已经有足够的技能储备。

- **连击/连锁系统**：连续完成操作会获得倍数奖励。这鼓励玩家在速度和质量之间找到平衡——太快可能出错，太慢则无法获得连击奖励。

## 为什么好玩

核心乐趣来源于"差一点就成功"的紧张感和"完美通关"的满足感之间的张力。每次失败都让人觉得下次能做得更好，而每次成功都带来短暂但强烈的成就感。简洁的操作让任何人都能上手，但精通需要反复练习。

## 粘性来源

具体到机制层面：**即时反馈循环**（每次操作都有明确的结果反馈，大脑持续获得奖励信号）+ **"就差一点"效应**（每次失败都只差一步，激发再试一次的冲动）+ **渐进式解锁**（新关卡/新元素持续出现，保持新鲜感）+ **分数挑战**（追求更高分数提供长期目标）。

## Meta 系统

无 — 纯核心玩法驱动，无外围成长系统。

## 实现难度

中 — 需要实现方块堆叠逻辑/线路连接算法/AI对手匹配
