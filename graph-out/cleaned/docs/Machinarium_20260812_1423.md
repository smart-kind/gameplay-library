# 机械迷城（Machinarium）

- **类型**: 解谜 / 点击冒险
- **平台**: PC / Mac / Linux / iOS / Android / PS3 / PS Vita / Switch
- **开发商**: Amanita Design
- **首次发布**: 2009
- **一句话描述**: 一款手绘风格的点击式解谜冒险游戏，玩家扮演机器人约瑟夫，在机械城市中寻找线索、解开谜题，拯救被绑架的女友。

## 玩法规则

玩家在一个完全由手绘插图构成的2D世界中操控机器人约瑟夫（Josef）探索场景。画面没有文字对话，所有提示通过漫画气泡中的图画传达。
核心操作是点击拾取物品到背包栏，再将物品拖拽到场景中的目标位置使用。例如找到齿轮安装到机器上、找到钥匙开门、组合两个物品形成新工具。
游戏中包含大量逻辑谜题：水管连接谜题（旋转管道使水流通）、电路谜题（连接正确线路）、数独变体、迷宫逃脱、滑块拼图等。
过关条件是解开当前区域的所有谜题并推进剧情。没有生命值或倒计时，失败可以无限重试。
每解开一个谜题，剧情向前推进一步，约瑟夫前往城市的下一个区域。
游戏进程可以通过存档点随时保存和加载，方便玩家分次完成较长的解谜流程。
部分关卡包含小游戏元素，如接水管、射击小怪物、记忆翻牌等，增加玩法多样性。

## 核心循环

探索场景 → 发现谜题 → 收集/组合物品 → 解开谜题 → 推进到下一区域

## 核心机制

- **无文字叙事**：全游戏没有任何文字对话，所有信息通过手绘插图和漫画气泡传达。这种设计让游戏跨越语言障碍，任何人都能理解。
- **物品组合系统**：背包中的物品可以相互组合形成新工具。例如找到电线和手电筒组合成带电的手电筒，增加了谜题的层次感和解决思路。
- **提示系统**：游戏中内置了提示灯泡系统，卡住时可以获取线索，但每次使用需要观看广告（移动版）。
- **手绘美术风格**：全部场景和角色由手绘完成，呈现独特的复古机械美学，让解谜过程如同翻阅一本立体绘本。

## 为什么好玩

手绘机械美学与精巧谜题的完美结合，每一个场景都像一件艺术品。没有文字障碍，纯视觉叙事让解谜过程沉浸感十足。

## 粘性来源

手绘美术的独特审美吸引力、谜题解开后的成就感、以及'就差一点'的探索欲——想知道约瑟夫接下来会遇到什么。

## Meta 系统

无。本作是纯粹的单机解谜体验，无内购或成长系统。

## 实现难度

中 — 手绘美术和关卡设计需要大量美术资源，但核心交互（点击、拖拽、物品组合）技术实现难度不高。最大技术难点在于场景交互热区的精准设计和谜题逻辑的无bug实现。

## 游戏变体

多数游戏在不同平台上发布了HD版、重制版或移植版本，核心玩法保持不变。
