# 僵尸扫雷 (Zombie Minesweeper)

- **类型**: 扫雷变体/动作解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: 未明确标注
- **首次发布**: 未明确标注
- **一句话描述**: 将经典扫雷游戏与僵尸主题结合的动作解谜游戏，在充满地雷的场景中护送角色安全通行

## 玩法规则

玩家扮演一个年轻女孩，她需要穿过一片布满地雷的区域，前去与男朋友浪漫约会。

角色可以在整个区域中自由移动，但需要注意地面上显示的数字——这些数字表示周围相邻区域中隐藏的地雷数量（经典扫雷机制）。触发地雷会导致角色死亡，但惩罚仅仅是被送回关卡起点。

游戏目标不仅是避开地雷，还要到达一个引爆器，引爆器会引爆所有剩余地雷并完成关卡。在前进过程中，角色会被各种僵尸袭击。

玩家并非毫无防御能力：可以拾取炸弹并将其放置在任何位置来消灭多个僵尸。也可以用新鲜大脑引诱僵尸踩过已标记的地雷，或者用新鲜大脑将僵尸引到特定位置。

游戏采用3D场景配合手绘2D角色精灵，配以阴森的音乐和僵尸音效，视听效果出色。

## 核心循环

在雷区中自由移动 -> 根据数字提示避开地雷 -> 消灭或智取僵尸 -> 到达引爆器通关

## 核心机制

- 经典扫雷数字提示：地面上的数字表示周围地雷数量，玩家需要推理地雷位置并安全通行
- 自由移动探索：与经典扫雷的逐格点击不同，玩家可以自由操控角色在场景中移动
- 炸弹放置系统：拾取炸弹并放置在任意位置消灭多个僵尸，为通行开辟安全路径
- 僵尸引诱机制：可以引诱僵尸踩过已标记的地雷，或用新鲜大脑将僵尸引到特定位置

## 为什么好玩

将经典的扫雷解谜与动作元素结合——不再是被动点击格子，而是主动操控角色在雷区中穿梭。引诱僵尸踩地雷的玩法充满创意和乐趣。

## 粘性来源

经典的扫雷机制本身就有很强的重复游玩价值，加上僵尸主题的新包装和动作元素。但玩法变化较少，长期可能缺乏新鲜感。

## Meta 系统

关卡制推进，死亡后从起点重新开始但保留已发现的雷区信息。无复杂的成长或收集系统。

## 实现难度

低到中等 — 扫雷逻辑是核心难度，但死亡惩罚极低（回到起点，进度保留）。最大技术难点是3D场景与2D精灵的混合渲染以及角色碰撞检测。
