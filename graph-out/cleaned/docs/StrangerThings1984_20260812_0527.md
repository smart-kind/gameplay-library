# 怪奇物语：1984（Stranger Things: 1984）

- **类型**: 动作冒险/解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Bonus XP（Netflix）
- **首次发布**: 2019
- **一句话描述**: 以《怪奇物语》为背景的动作冒险游戏，玩家控制小十一等角色探索逆世界。

## 玩法规则

俯视角动作游戏，玩家控制小十一和剧中其他角色。探索霍金斯小镇的各个区域，与魔狗（Demogorgon）等怪物战斗，解谜并揭开秘密。游戏采用像素风格画面，包含探索、战斗和叙事推进。

玩家在不同场景中移动，使用角色的特殊能力（如小十一的念动力）来解谜和战斗。场景包括霍金斯实验室、学校、森林等剧中的标志性地点。

## 核心循环

探索区域 → 与怪物战斗 → 解开谜题 → 解锁故事进展和新角色

## 核心机制

- 角色能力：每个角色有独特技能（念动力、战斗技能等），用于解谜和战斗
- 探索与发现：在熟悉的《怪奇物语》场景中发现隐藏物品和秘密
- 叙事集成：剧中的故事线索融入游戏推进中

## 视觉与叙事风格

游戏采用复古像素美术风格，致敬80年代街机游戏的视觉语言。角色和场景以像素化形式呈现，同时保留了 Stranger Things 剧集的阴暗氛围。

故事围绕小十一的超能力展开，玩家需要运用念动力解决谜题、打开隐藏通道、对抗强大的敌人。每章结束后有剧情过场，串联整个故事线。

## 为什么好玩

《怪奇物语》粉丝可以从全新视角体验霍金斯，控制喜爱的角色面对熟悉的威胁。像素风格还原了 80 年代的氛围。

## 粘性来源

故事驱动推进、角色收集和探索奖励，加上《怪奇物语》IP 本身的吸引力。
