# Bix 挑战（Bix Challenge）

- **类型**: 休闲 / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Padadaz SARL
- **首次发布**: 2008
- **一句话描述**: 在屏幕上绘制形状来困住弹跳球并触发特殊能力

## 玩法规则

游戏画面是一个开放的弹球场，若干个彩色小球在屏幕中不断弹跳运动。玩家需要在屏幕上用手指绘制封闭的形状来困住这些球。

当绘制的封闭形状面积达到屏幕面积的 75% 时，被形状包围的球会被困住并触发它们的特殊能力。每个球都有独特的特效——有的能炸掉屏幕上已有的图形，释放更多空间；有的会改变球的弹跳方向，让场面变得更混乱；有的会让球减速，给玩家更多喘息时间。

玩家需要策略性地决定先困哪些球，因为不同球的特殊能力在不同阶段有不同效果。有时你需要一个炸屏球来清空累积的线条，有时你需要一个减速球来降低难度。

随着关卡推进，球的数量会增加，弹跳速度会加快，留给玩家的空间越来越小。游戏的核心挑战在于：你绘制的每一条线都会永久留在屏幕上，占用后续可用的空间，所以每次绘制都需要精打细算。

游戏结束条件：当球弹跳的空间被压缩到太小无法继续绘制新的封闭形状时，游戏结束。目标是在尽可能长的时间内存活并获得更高的分数。

游戏曾获得法国免费榜第 2、德国第 3、英国第 4、美国前 50 的成绩，证明了其简单但上瘾的玩法设计。

## 核心循环

绘制形状 → 困住球触发能力 → 获得分数 → 在更拥挤的屏幕上继续绘制

## 核心机制

- **形状绘制困球**：玩家在屏幕上绘制封闭形状，当面积≥75%时触发困球效果。这是核心操作，要求玩家快速判断最佳绘制路径，同时考虑后续空间利用。绘制过程需要流畅的触屏手势识别，封闭判定需要高效的几何算法
- **球体特殊能力**：每种球被捕获后会释放独特效果（如清屏、减速、反弹），玩家需要策略性地选择困球顺序来最大化收益。不同球的组合使用可以产生协同效应
- **渐进空间压缩**：已绘制的线条永久占据屏幕空间，随游戏进行可用面积越来越小，迫使玩家不断提高精确度。这种渐进难度曲线让玩家始终处于挑战与能力的平衡点上

## 为什么好玩

Bix Challenge 的爽感来自'画出一个完美形状困住所有球'的瞬间满足感。同时随着空间越来越拥挤，每次决策都有紧迫感，让人忍不住'再来一局'试试能不能突破上次的记录。简洁的操作方式让它任何人都能快速上手。

## 粘性来源

空间压缩带来的'差一点就成功'的不甘心 + 高分驱动的反复挑战 + 不同球体能力组合带来的策略变化

## Meta 系统

无外围成长系统。纯高分驱动，每次都是新的开始

## 实现难度

低 — 核心逻辑只是形状检测和面积计算，最大技术难点是触屏绘制的手势识别和封闭形状的快速判定
