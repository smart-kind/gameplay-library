# 百战天虫2010（Worms 2010）

- **类型**: 回合制策略
- **平台**: Mobile (iOS+Android) / PC / Console
- **开发商**: Team17
- **首次发布**: 2010
- **一句话描述**: 经典回合制炮兵策略游戏的移动版，玩家操控一队卡通风格的虫子用各种奇葩武器消灭对手。

## 玩法规则

游戏采用2D横版可破坏地形，地图上有小山、洞穴、水体等多样地形。每队虫子（通常2-4条）分散在地图各处，轮流行动。
每回合玩家有60秒行动时间，可以选择以下操作之一：移动（行走/跳跃/使用绳索/传送）、使用武器攻击、或结束回合。时间耗尽自动结束回合。
武器种类极其丰富：火箭筒、手榴弹、棒球棍、绵羊炸弹、香蕉炸弹、神圣手雷等。每种武器有不同的发射方式、伤害范围和物理效果。
使用武器时需要考虑发射角度、力度（蓄力条控制）、风向和地形遮挡。爆炸会破坏地形，让虫子掉入水中直接阵亡。
当一条虫子的生命值降至0，它会从地图上消失（配有夸张的死亡动画）。全部虫子阵亡的队伍被判负。
游戏支持单人战役和多人对战（本地同屏和在线对战），有多种地图生成模式和自定义选项。风力指示器显示当前风向和强度，影响弹道武器。

## 核心循环

观察地形和虫子位置 → 选择武器和角度 → 蓄力发射 → 观察爆炸效果和地形变化 → 等待对手回合 → 循环直到一方全灭

## 核心机制

- 物理弹道系统：需要考虑重力弧线、风力偏移和反弹效果，每次射击都需要估算，制造'打中了！'的爽快感和'差一点！'的遗憾感
- 可破坏地形：爆炸会改变地形结构，创造新的通路或让对手掉入水中，增加了策略深度。玩家可以利用爆炸'挖隧道'或制造陷阱
- 武器随机性与多样性：每回合武器箱中出现的武器不同，既有熟悉的基本武器也有搞笑的特殊武器（会爆炸的绵羊、香蕉炸弹等），保持每局新鲜感

## 为什么好玩

虫子们夸张的死亡动画、奇葩武器的意外效果（比如一只绵羊飞过来炸翻全场）、以及精准命中后对手全队覆灭的成就感，共同构成了一种独特的搞笑策略体验。
每次精心计算角度和力度后一击命中的满足感，以及武器箱开出特殊武器时的惊喜感。
多人对战时的社交乐趣——看着朋友因为你的一个完美射击而懊恼的表情。

## 粘性来源

物理弹道的'差一点'效应让人忍不住'再来一局调整角度'，武器箱的随机性让每局体验不同，多人对战的社交竞争更是粘性核心。

## Meta 系统

解锁新武器、新虫子自定义外观和语音包、地图编辑器。单人战役模式。

## 实现难度

中 — 需要实现可破坏2D地形、物理弹道模拟、AI寻路、多人同步。技术难点在于地形实时破坏的算法和多武器物理效果的平衡，以及2D物理引擎在移动端的性能优化。

游戏还包含自定义规则模式：可以调整回合时间、武器箱内容、地形破坏程度等参数，创造独特的游戏体验。游戏的地图生成器允许玩家创建自定义地图，增加了无限的 replay 价值。
