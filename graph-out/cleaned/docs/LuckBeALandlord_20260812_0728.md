# 运气当房东 (Luck Be a Landlord)

- **类型**: Roguelike / 老虎机 / 策略
- **平台**: Mobile (iOS+Android) / PC / Switch / PS / Xbox
- **开发商**: Trampoline Tales
- **首次发布**: 2021
- **一句话描述**: 将老虎机和Roguelike结合——每次旋转老虎机获得金币来付房租，通过选择和组合物品产生连锁加成

## 玩法规则

游戏界面是一个老虎机式网格（初始3×3，可扩展到更大）。玩家每回合按下旋转按钮，网格中的物品随机排列。匹配的物品产生金币收入。

每个物品有独特的效果：有些物品单独产生金币（如水果），有些物品与相邻物品组合产生倍乘效果（如相邻的水果数量越多，单个水果的价值越高），有些物品改变网格结构（如增加行数或列数），还有些物品有特殊机制（如复制相邻物品的效果、消除特定类型物品等）。

每旋转一次需要支付金币，目标是在金币耗尽前支付不断上涨的"房租"。如果无法支付房租，游戏结束。玩家需要在旋转收益和成本之间做权衡。

每几轮后，玩家从三个随机物品中选择一个加入自己的老虎机网格。这个选择过程是策略的核心——好的物品组合可以产生指数级的金币增长。

## 核心循环

旋转老虎机 → 获得金币 → 支付房租 → 选择新物品加入网格 → 形成更强的组合 → 应付更高的房租

## 核心机制

- **物品协同系统**：每种物品都有独特的触发条件和效果。例如"相邻的水果"类物品在相邻的水果越多时价值越高；"复制"类物品复制相邻物品的效果；"倍增"类物品将相邻物品的效果翻倍。物品之间的空间排列是策略核心。
- **网格扩展**：通过选择特定物品可以扩展网格大小，增加更多格子意味着更多物品和更复杂的组合可能性。
- **指数增长**：好的物品组合可以产生指数级的金币增长——这是游戏最令人上瘾的部分。当多个倍增/复制类物品形成连锁反应时，一次旋转可以获得天文数字的金币。
- **房租递增**：房租每轮递增，迫使玩家不断优化自己的网格。这是一个持续的压力机制，推动玩家追求更高的效率。

## 为什么好玩

将老虎机的随机性和Roguelike的策略深度完美结合。旋转的刺激感加上物品组合的策略性，形成了独特的游戏体验。每次旋转都可能是改变命运的"大爆发"。

游戏的极简设计是其魅力所在——没有复杂的故事、没有冗长的教程，核心就是一个老虎机网格和一堆有趣的物品。但正是这种极简主义让策略深度更加突出。每个物品都是一个小小的谜题："它怎么运作？它能和什么配合？"

解锁新角色（各有不同的起始条件和特殊规则）进一步扩展了游戏的重玩价值。每个角色都改变了基本的游戏规则，需要全新的策略思考。

## 粘性来源

指数增长的爽感是最强的驱动力——当玩家精心构建的物品组合终于产生爆炸性收益时，那种"我做到了"的成就感极其强烈。同时，"差一点就成功"的失败也让人忍不住再来一局。每局的随机物品选择保证了重玩性。

## Meta 系统

解锁系统：通过达成条件解锁新的物品池和角色。无付费内容，核心游戏买断制。

## 实现难度

中等。老虎机网格和物品效果在技术上不难实现，但数值平衡是巨大挑战——物品效果之间的指数级相互作用需要大量的模拟测试来确保游戏既有趣又不会失衡。
