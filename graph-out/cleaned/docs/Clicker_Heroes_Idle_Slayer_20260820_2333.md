# 点击英雄：放置杀手（Clicker Heroes - Idle Slayer）

- **类型**: 放置 / 点击 / RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: Playsaurus, Inc.
- **首次发布**: 2015
- **一句话描述**: 放置点击类游戏的经典之作，通过雇佣英雄团队自动打怪、不断转生变强。

## 玩法规则

游戏界面分为上下两部分：上方是战斗区域，显示当前怪物和玩家的英雄团队；下方是操作面板，包含英雄列表、升级按钮和资源统计。

玩家初期需要手动点击怪物造成伤害。随着金币积累，可以雇佣第一个英雄——雇佣后该英雄自动攻击，玩家可以从手动点击中解放出来。

游戏设计了10+个不同的英雄角色，每个英雄有独特的攻击方式和技能。英雄按等级排列在底部面板，点击可以升级单个英雄的攻击力。

怪物波次（Wave）不断推进，每10波出现一个Boss。Boss有倒计时限制，必须在时间内击杀，否则回退5波。这是游戏唯一的'失败'机制。

当玩家推进到足够高的波次后，可以执行'转生'（Ascension）——重置所有英雄等级和金币，但获得英雄之魂（Hero Souls），用于购买永久的全局加成。
## 核心循环

点击/雇佣英雄打怪 → 获取金币升级英雄 → 推进波次击杀Boss → 转生获取英雄之魂 → 永久加成加速下次循环

## 核心机制

- **英雄雇佣与升级**：每个英雄有独立的等级和攻击力。升级成本递增，玩家需要在多个英雄之间分配金币。英雄自动攻击，实现从手动到全自动的过渡。
- **Boss倒计时机制**：每10波的Boss有时间限制，给放置游戏增加了紧迫感。这种'软失败'设计既不惩罚过重，又推动玩家优化策略。
- **转生系统(Ascension)**：经典放置类设计。重置进度换取英雄之魂，用于购买永久加成。每次转生后进度更快，形成螺旋上升的循环。

## 为什么好玩

从最初艰难地点击一只小怪，到后来英雄团队自动秒杀一切，这种成长感是放置类最纯粹的乐趣。转生后'碾压'之前卡关的Boss尤其爽快。

## 粘性来源

转生系统的螺旋上升循环是核心粘性。英雄收集（10+个不同角色）提供中期目标。Boss倒计时的紧张感打破放置的单调。全局加成收集（英雄之魂）提供长期追求。

## Meta 系统

英雄之魂系统。转生获得的英雄之魂用于购买上古之魂（Ancients）——提供永久全局加成的特殊角色。不同上古之魂有不同的效果（金币获取+X%、点击伤害+Y%等），玩家可以选择组合。

## 实现难度

中 — 放置类核心逻辑不复杂，但10+英雄的技能系统、Boss机制和转生加成需要精细的数值平衡。技术难点在于长时间挂机后的数值计算准确性。

## 同类游戏

与此游戏类似的推荐：放置类可参考 Clicker Heroes 和 Idle Slayer；肉鸽类可参考 Slay the Spire 和 Vampire Survivors。
