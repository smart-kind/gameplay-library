# Iron Marines

- **类型**: 即时策略/塔防
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Ironhide Game Studio
- **首次发布**: 2017
- **一句话描述**: 由 Kingdom Rush 团队制作的科幻题材即时策略游戏，融合了塔防、英雄和即时战略元素。

## 玩法规则

游戏背景设定在未来科幻世界，玩家在地图上建造防御设施、训练部队、指挥英雄，对抗外星入侵者。

画面为横向卷轴式的科幻地图，有固定的敌人路径和可建造的防御塔位置。

操作元素：
- **防御塔** — 类似 Kingdom Rush 的塔防系统，但增加了科幻武器（激光塔、导弹塔等）
- **英雄** — 独特角色，有主动和被动技能，可以在战场上自由移动，提供关键支援
- **部队** — 训练士兵、机甲等单位，可以直接控制它们移动到战场任意位置
- **特殊技能** — 轨道轰炸、空投补给等全局技能，冷却时间较长但效果强大

与传统塔防不同，Iron Marines 允许玩家更直接地控制战场，移动部队、集中火力、撤退重组等，更像简化版的即时战略。

## 核心循环

建造防御 -> 训练部队 -> 击退敌人波次 -> 获得资源 -> 升级设施

## 核心机制

- 英雄系统 — 可移动的独特角色，拥有升级树和技能，是战场的核心
- 部队控制 — 不同于传统塔防的被动防御，可以主动指挥部队进攻或防守
- 科幻武器多样化 — 激光、导弹、电磁脉冲等不同类型的武器应对不同敌人

## 为什么好玩

Kingdom Rush 团队的品质保证，优秀的关卡设计、丰富的敌人类型、精美的科幻美术。比传统塔防多了一层战略深度（部队控制），比传统 RTS 更休闲易上手。

## 粘性来源

多关卡战役；英雄升级系统；不同难度和隐藏挑战；系列续作（Iron Marines Invasion）持续更新。

## Meta 系统

英雄升级 — 英雄在战役中获得经验升级，解锁新技能。星级评定系统奖励完美通关。

## 实现难度

中 — 基础塔防机制容易上手，但英雄控制和部队管理增加了复杂度。最大技术难点在于在移动端简化 RTS 操作同时保持战略深度。
