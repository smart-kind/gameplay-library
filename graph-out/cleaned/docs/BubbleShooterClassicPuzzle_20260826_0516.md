# Bubble Shooter Classic Puzzle

- **类型**: 益智消除 / 泡泡射击
- **平台**: Mobile (iOS)
- **开发商**: 德建 刘
- **首次发布**: 2016
- **一句话描述**: Bubble Shooter Classic是一款经典的泡泡射击消除游戏。玩家通过瞄准和发射彩色泡泡，匹配3个或更多相同颜色的泡泡使其消除。

## 玩法规则

游戏屏幕上方是排列成各种图案的彩色泡泡阵列，下方是玩家的发射器和当前泡泡颜色。玩家通过拖动或点击确定发射方向，泡泡沿直线飞行。当泡泡接触到相同颜色的泡泡群时，如果形成3个或更多的连接，这些泡泡全部消除。消除泡泡会获得分数。如果泡泡阵列到达屏幕底部，游戏结束。目标是清除屏幕上所有泡泡来完成关卡。某些关卡有步数限制，需要在限定次数内完成。

## 核心循环

瞄准发射 -> 匹配3加同色泡泡 -> 消除获得分数 -> 推进关卡 -> 重复

## 核心机制

- 瞄准发射：通过拖动或点击确定发射方向和力度
- 颜色匹配：3个或更多相同颜色泡泡连接在一起时消除
- 连锁反应：消除一组泡泡可能导致其他泡泡掉落，获得额外分数
- 关卡系统：逐步增加难度的泡泡排列

## 为什么好玩

泡泡射击是最经典的休闲益智游戏之一，规则简单到任何人都能立刻理解。但精准的瞄准和连锁消除带来的满足感让游戏极具吸引力。

## 粘性来源

精准的连锁消除带来强烈的满足感；关卡逐步增加难度提供持续挑战；免费无门槛让随时可玩

## Meta 系统

无外围系统。纯粹的消除游戏体验，通过关卡推进提供进度感。

## 实现难度

中。核心难点在于益智消除玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
