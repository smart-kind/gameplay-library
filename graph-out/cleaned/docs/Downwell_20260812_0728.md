# 井底探险 (Downwell)

- **类型**: Roguelike / 平台动作 / 射击
- **平台**: Mobile (iOS+Android) / PC / PlayStation / Switch
- **开发商**: Moppin
- **首次发布**: 2015
- **一句话描述**: 穿着神奇的"Gunboots"从深井顶部一路跳下去，在下降过程中射击敌人、收集宝石、探索随机生成的洞穴

## 玩法规则

游戏画面为竖屏向下滚动的洞穴。玩家角色穿着Gunboots（一种可以从脚部发射子弹的神奇靴子），从井的顶部开始向下探索。

核心操作极其简单：左右移动、跳跃、射击。Gunboots的关键机制是——当玩家在空中时，可以向下方发射子弹。子弹不仅攻击敌人，还能产生向上的反冲力，减缓下落速度或改变方向。这意味着"射击"既是攻击手段也是移动手段。

洞穴由程序随机生成，包含平台、敌人、宝石、商店和秘密房间。玩家需要一路向下，穿过不同的区域（洞穴、水下、地狱等），最终到达底部。

宝石是主要货币，用于在商店购买升级和补给。死亡后所有未花费的宝石丢失，但可以解锁永久升级。

## 核心循环

跳入深井 → 射击敌人/利用反冲力移动 → 收集宝石 → 在商店购买升级 → 继续向下 → 死亡后重新开始

## 核心机制

- **Gunboots反冲机制**：射击产生的反冲力是游戏的核心创新。向下射击减缓下落，向侧方射击产生侧向位移，向上射击（在特定条件下）可以短暂上升。这使得射击和移动合二为一，形成了独特的"射击平台"玩法。
- **连击系统**：连续消灭敌人（不落地）获得连击加分，连击越高分数越高。鼓励玩家保持在空中连续作战，增加了游戏的刺激感。
- **风格选择**：Gunboots有三种风格（普通、爆破、激光），每种风格有不同的射击模式。选择不同风格完全改变游戏玩法——爆破风格范围大但精度低，激光风格精准穿透。
- **秘密房间**：通过破坏特定墙壁或找到隐藏入口可以进入秘密房间，获得大量宝石或稀有升级。探索是高分的关键。

## 为什么好玩

将射击和平台跳跃完美融合——每一次射击都既是攻击也是移动。极简的操作（三个按钮）下隐藏着极高的技巧深度。一局只需几分钟，但精通需要数百小时。

复古的像素美术风格和电子配乐完美契合游戏的氛围。三种Gunboots风格（黑白、彩色、Game Boy配色）不仅是视觉变化，更代表了不同的游戏难度和体验。黑白模式最纯粹，彩色模式有额外提示，Game Boy模式最难但最有挑战性。

## 粘性来源

技巧提升的满足感是最强驱动力。从最初的笨拙坠落到后来能在空中连续射击敌人并精确控制落点，这种技能成长带来的成就感极强。风格选择和永久解锁也提供了重玩动力。

## Meta 系统

永久升级：通过收集宝石解锁新的Gunboots风格、额外生命值、特殊能力等。这些升级在每次游戏开始时生效，帮助新手逐步适应游戏。

## 实现难度

中等。核心的物理反冲机制需要精确的碰撞检测和物理模拟。随机洞穴生成算法需要保证可玩性（每个洞穴都有可行路径）。最大难点在于关卡生成的质量保证——既随机又确保可玩。
