# 经典塔防游戏，用各种植物抵御僵尸进攻（Plants vs Zombies）

- **类型**: 塔防
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: PopCap Games
- **首次发布**: 2009
- **一句话描述**: 经典塔防游戏，用各种植物抵御僵尸进攻

## 玩法规则

玩家在5×9的草坪网格上种植各种植物来阻止僵尸从右侧进攻。向日葵/阳光菇产生阳光（资源），豌豆射手等植物发射攻击，坚果墙阻挡僵尸，寒冰射手减速僵尸等。

每关开始前选择要携带的植物（6-8个槽位）。僵尸有多种类型：普通僵尸、路障僵尸、铁桶僵尸、撑杆跳僵尸、跳舞僵尸等，各有不同特性。

游戏有多个世界（白天、夜晚、泳池、雾天、屋顶），每个世界有不同机制。

## 核心循环

收集阳光 → 种植植物 → 抵御僵尸 → 过关 → 解锁新植物/新关卡

## 核心机制

- 阳光经济：种植产生阳光的植物来获取资源
- 植物多样性：每种植物有独特功能（攻击/防御/辅助/生产）
- 僵尸多样性：不同类型的僵尸需要不同策略应对
- 多世界机制：不同环境有不同的规则和挑战

## 为什么好玩

丰富的植物和僵尸组合让每关都有不同的解法。看着成群的僵尸被你的植物防线全部消灭的满足感极强。

## 粘性来源

关卡驱动；植物收集；迷你游戏和益智模式增加重玩价值。

## Meta 系统

植物解锁+迷你游戏解锁。通过关卡进度和小游戏获得新植物。

## 实现难度

中。塔防核心清晰但需要理解植物特性和僵尸弱点。最大技术难点：大量单位同时运行的性能优化。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
