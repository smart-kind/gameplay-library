# 饥饿鲨（Hungry Shark）

- **类型**: 休闲 / 生存 / 街机
- **平台**: Mobile (iOS+Android)
- **开发商**: Future Games → Ubisoft London
- **首次发布**: 2010
- **一句话描述**: 控制一条饥饿的鲨鱼在海洋中不断进食来生存和成长的街机游戏

## 玩法规则

游戏采用横向卷轴的 2D 海底场景。玩家通过滑动屏幕控制鲨鱼的游动方向——上、下、左、右四个方向，鲨鱼会持续向前游动。画面中会出现各种海洋生物：小鱼、海龟、水母、海豹、人类游泳者等。

鲨鱼碰到比自己体型小的生物时会将其吃掉，恢复饥饿值并获得金币。碰到比自己大的生物（如大型鱼类、潜水员、水雷）时，鲨鱼会受伤减少生命值。

屏幕上方有两个核心数值条：饥饿值随时间持续减少，归零后鲨鱼持续扣血直至死亡，吃东西可以恢复；生命值被大型生物攻击时减少，归零后游戏结束，吃东西也可以少量恢复。

吃掉生物时会掉落金币和宝石。金币用于购买新鲨鱼和升级属性（速度、咬合力、生命值），宝石是高级货币用于购买稀有鲨鱼。

游戏没有"通关关卡"的概念，而是一直游到死亡，然后结算金币，用金币购买新鲨鱼或升级后重新开始。

## 核心循环

控制鲨鱼游泳吃鱼 → 恢复饥饿值并收集金币 → 金币购买新鲨鱼或升级 → 挑战更大的海洋生物

## 核心机制

- **饥饿计时机制**：饥饿值持续下降是游戏核心驱动力，创造紧迫感迫使玩家主动寻找食物而不是保守躲藏。这是"不进食就饿死"的生存压力设计。饥饿值的倒计时在屏幕上方以进度条显示，玩家始终能看到剩余时间。
- **体型等级系统**：不同鲨鱼有不同的大小和属性。小鱼鲨只能吃小鱼，大型鲨鱼可以吃更大的生物。升级后鲨鱼变大，可以吃更多种类的食物。这种"成长感"是核心满足来源。游戏中有多种鲨鱼可解锁，从小丑鱼鲨到大白鲨到史前巨齿鲨。
- **连续进食加成（Frenzy）**：连续吃掉多个生物后，鲨鱼进入 Frenzy 状态——体型变大、无敌、自动追踪附近食物。这是典型的"爽感爆发"机制，让玩家在高潮时刻获得极强正面反馈。Frenzy 状态持续约 10-15 秒，期间可以肆无忌惮地吞噬一切。
- **收集驱动**：游戏中有多种鲨鱼可供解锁，每种鲨鱼有不同的外观、速度和咬合力。收集所有鲨鱼是长期游戏目标。此外还有宠物系统（部分版本）可以给鲨鱼提供额外能力。

## 为什么好玩

Hungry Shark 把"吃"这个最简单动作变成了有趣的游戏循环。滑动控制简单易上手，但何时攻击大型目标、何时保守吃小鱼的管理决策增加了策略性。Frenzy 状态下的无敌吞噬体验提供了极强的爽感反馈。

## 粘性来源

- **成长感**：从最小鲨鱼开始，通过不断进食和金币积累逐步解锁更大鲨鱼，形成明确成长线
- **Frenzy 爽感**：连续进食后的爆发时刻提供强烈正面反馈，让人追求更长连击
- **收集欲**：解锁所有鲨鱼和升级项目的长期目标
- **短局设计**：每局几分钟就结束（饿死或被击杀），适合碎片时间反复游玩

## Meta 系统

金币用于升级鲨鱼属性（速度、咬合力、生命值）和购买新鲨鱼。续作 Hungry Shark Evolution 在此基础上增加了开放海域探索、宠物系统和在线排行榜。本作无社交竞争系统，纯单机休闲体验。

## 实现难度

低 — 操作极其简单（四方向滑动），核心乐趣在于收集和成长。最大技术难点是海洋生物 AI 的移动路径生成、碰撞检测的流畅度，以及 Frenzy 状态下大量物体同时存在的性能优化。
