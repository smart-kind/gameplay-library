# 瘦长鬼影崛起（Slender Rising）

- **类型**: 恐怖生存
- **平台**: Mobile (iOS)
- **开发商**: Michael Hegemann / MD Games
- **首次发布**: 2012
- **一句话描述**: 在黑暗的森林中收集散落的笔记页，同时躲避不可名状的恐怖存在——Slender Man的追踪

## 玩法规则

游戏场景设定在一片阴暗的森林中，采用第一人称视角。玩家通过虚拟摇杆控制角色移动，屏幕边缘可见手电筒的光束范围。玩家需要在森林中找到并收集指定数量的笔记页（Pages），这些页面散落在树丛、岩石和建筑之间。

核心操作是移动和寻找：玩家在黑暗环境中探索，手电筒光束照亮的范围有限。每次找到一页笔记后，屏幕上会出现新的提示或线索指引下一页的大致方向。随着收集的笔记越来越多，Slender Man的出现频率会增加，玩家的心率（游戏内的紧张度指标）也会上升。

如果Slender Man接近并抓住玩家，游戏立即结束。玩家需要在收集完所有笔记后到达指定的逃生点才能过关。游戏环境包含树木、岩石、废弃建筑等障碍物，需要绕路行走。

## 核心循环

探索寻找笔记 → 收集页面 → 躲避Slender Man → 集齐所有页面后逃生

## 核心机制

- **黑暗环境探索**：手电筒提供有限视野，玩家只能看到光束范围内的地形。视野受限制造了持续的紧张感，因为你永远不知道光束之外有什么。
- **动态威胁系统**：Slender Man的出现频率和攻击性随收集进度递增。收集越多笔记，他出现的次数越多、停留时间越长、移动速度越快。这种递增压力形成了独特的紧张曲线。
- **笔记收集与线索**：每收集一页笔记，游戏会短暂显示该页内容（通常是模糊的文字或图像），同时给出下一页的方向提示。这既是进度标记也是导航辅助。
- **心跳/紧张度系统**：游戏内的心跳声和视觉效果会随Slender Man的接近而加剧，为玩家提供无形的压力提示。

## 为什么好玩

Slender Rising成功将Creepypasta文化中的Slender Man恐怖概念转化为移动设备上可玩的恐怖体验。黑暗森林中有限视野带来的未知恐惧是真实的——每次转身都可能看到那个苍白的身影站在远处。这种"想看又不敢看"的心理张力是游戏的核心乐趣。

## 粘性来源

恐怖游戏的"再试一次"心理——明明吓得半死但还是想知道下一页写了什么、能不能逃出去。递增难度曲线意味着每次重玩都能体验到不同的紧张程度。笔记页的随机分布让每次游戏体验不同，重玩价值较高。

## Meta 系统

无传统Meta成长系统。游戏通过多关卡/多场景解锁提供进度感。

## 实现难度

中。核心需要3D环境渲染（或伪3D）、第一人称移动控制、AI追踪系统和动态难度调整。最大技术难点在于在移动设备上营造恐怖氛围——有限的性能下如何通过光影效果、音效设计和UI反馈实现心理恐怖，而不是依赖高分辨率贴图。
