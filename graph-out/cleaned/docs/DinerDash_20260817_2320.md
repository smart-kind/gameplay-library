# 美女餐厅（Diner Dash）

- **类型**: 时间管理
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: PlayFirst
- **首次发布**: 2004
- **一句话描述**: 经典时间管理游戏的开山之作，玩家扮演弗洛经营餐厅服务顾客。

## 玩法规则

游戏画面是俯视视角的餐厅平面图。顾客从门口进入，头上显示耐心值（心形气泡）和座位偏好。
玩家需要：点击空桌安排顾客入座 → 点击餐桌接受点餐 → 餐品出现在厨房后点击送回 → 收款 → 清理餐盘。
每个环节都有时间要求：顾客等待时间越长耐心越低，耐心耗尽会愤怒离开。服务越快小费越高。
关卡有目标收入要求，达到金额过关。如果太多顾客离开则失败。
随着关卡推进，餐厅规模扩大（更多桌子）、顾客类型增多（带小孩的、戴耳机的、VIP等），每种类型有不同的行为模式和服务需求。
某些顾客是'麻烦型'（耐心低、需要频繁关注），某些是'大方型'（给更多小费）。识别并优先服务不同类型的顾客是通关关键。

## 核心循环

迎接顾客安排座位 → 点餐送厨房 → 取餐送餐桌 → 收款清理 → 循环直到达成收入目标

## 核心机制

- 优先级排序：不同类型顾客需要不同的服务策略，需要快速判断谁最着急、谁最大方。VIP优先、麻烦型优先安抚
- 路径优化：在多个任务之间规划最短移动路径，减少无效往返。高峰期需要同时记住多个任务的状态
- 难度递增：每关增加新的顾客类型或减少时间限制，保持挑战性。后期可能需要同时处理8个以上的任务

## 为什么好玩

多任务管理的紧张感和'一个都没让顾客失望'的完美成就感形成强烈对比。
在高峰期同时处理6-7个任务的流畅体验非常上瘾，像在做一场多线操作的交响乐。

## 粘性来源

关卡递进的难度爬坡、追求满星评价的完美主义冲动、以及小费数字增长带来的即时正向反馈。

## Meta 系统

餐厅升级、装饰解锁、星级评价系统。

## 实现难度

低 — 核心是任务队列管理和简单AI。主要技术难点在于多顾客状态同步和路径优化，以及高峰期多任务状态的视觉呈现清晰度。

游戏还包含升级系统：使用收入升级厨房设备（加快出餐速度）、增加座位数、改善餐厅装饰（提高顾客初始耐心值）。每个场景有多个难度等级，三星评价需要完美服务所有顾客且收入远超目标。
