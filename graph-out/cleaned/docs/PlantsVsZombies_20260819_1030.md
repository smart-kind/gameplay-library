# 植物大战僵尸（Plants vs. Zombies）

- **类型**: 塔防 / 策略 / 休闲
- **平台**: PC / Mobile (iOS+Android) / 主机
- **开发商**: PopCap Games
- **首次发布**: 2009
- **一句话描述**: 在庭院中种植具有不同攻击能力的植物，阻止一波又一波的僵尸入侵你的房子。

## 玩法规则

游戏画面是一个横向的庭院网格（5行×9列），僵尸从右侧出现，向左移动，最终目标是到达左侧的房子。玩家在网格上种植各种植物来防御。

每种植物需要消耗"阳光"来种植，阳光通过种植向日葵自动产生或从天上随机掉落。玩家需要在"种向日葵生产阳光"和"种攻击植物消灭僵尸"之间做资源分配决策。

僵尸种类多样：普通僵尸速度慢但血厚；撑杆跳僵尸可以跳过第一道防线；铁桶僵尸有额外护甲；潜水僵尸从水下绕过地面防御等。每关会预告即将出现的僵尸类型，玩家需要针对性地搭配植物。

游戏按关卡推进，分为白天、黑夜、泳池、雾夜、屋顶等多种场景，每种场景有不同的地形限制。通关后解锁新植物和新场景。

## 核心循环

收集阳光 → 种植植物 → 抵御僵尸 → 获得新关卡 → 解锁新植物 → 更复杂的关卡

## 核心机制

- **阳光经济**：向日葵是经济基础，但占用种植槽。过早种太多向日葵会缺乏防御，种太少则后期无法种植关键植物。这个资源分配决策是游戏的核心策略点。
- **植物搭配**：不同植物有不同功能——豌豆射手（基础攻击）、寒冰射手（减速）、坚果墙（肉盾）、樱桃炸弹（范围爆发）。玩家需要根据僵尸组合选择合适的植物阵容。
- **波次设计**：每关有多波僵尸，最后一波是大举进攻（"一大波僵尸正在接近"）。波次间的间隔给玩家调整布防的时间。
- **场景限制**：不同场景有不同约束——泳池需要睡莲才能种植，雾夜有视野限制，屋顶有坡度影响豌豆射击角度。这些限制迫使玩家适应不同策略。

## 为什么好玩

塔防的乐趣加上PopCap标志性的幽默感——僵尸戴着各种搞笑的帽子和道具，植物有生动的表情和动作。策略深度恰到好处：新手可以靠直觉玩，高手可以精细优化植物搭配和阳光管理。

## 粘性来源

- **策略深度**：同一关卡有多种过关方式，玩家会反复尝试不同植物组合
- **收集驱动**：解锁新植物是持续的动力，每株新植物都带来新玩法
- **幽默感**：僵尸和植物的可爱设计让人会心一笑，增加重复游玩意愿
- **迷你游戏**：通关后解锁各种迷你游戏模式（如老虎机、保龄球等）

## Meta 系统

- **植物图鉴**：收集所有植物并解锁详细资料
- **迷你游戏**：通关后解锁多种特殊玩法模式
- **花园系统**（Zen Garden）：通过游戏中获得的蜗牛培育植物，获得金币和装饰

## 实现难度

中 + 核心塔防逻辑不难，但需要处理大量单位的碰撞、路径、动画。最大难点在于关卡平衡——确保每关既有趣又不至于太难或太简单。
