# 三消+动物园经营的休闲游戏（Zookeeper World）

- **类型**: 三消/模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: Playdots
- **首次发布**: 2021
- **一句话描述**: 三消+动物园经营的休闲游戏

## 玩法规则

核心是三消玩法，匹配动物获得资源。用资源建设和装饰动物园，吸引游客。每个动物有独特的外观和能力。

## 核心循环

三消 → 获得资源 → 建设动物园 → 吸引游客 → 更多资源

## 核心机制

- 三消核心
- 动物园建设
- 动物收集
- 游客系统

## 为什么好玩

三消和动物园经营的结合，可爱动物主题。

## 粘性来源

动物收集；动物园建设进度。

## Meta 系统

动物收集+动物园建设。

## 实现难度

低。三消玩法简单。最大技术难点：关卡设计和经济平衡。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
