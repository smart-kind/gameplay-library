# Word Collect 单词收集（Word Collect : Word Search）

- **类型**: 文字解谜 / 休闲 / 益智
- **平台**: Mobile (iOS+Android)
- **开发商**: Super Lucky Games LLC
- **首次发布**: 2017
- **一句话描述**: 拥有2500+关卡的文字解谜游戏，从简单的单词搜索逐步升级到复杂的字母组合挑战

## 玩法规则

游戏的核心玩法是字母环拼图。屏幕上显示一个圆环状排列的字母（通常6-8个字母），玩家需要在这些字母中找出所有可能的单词。

**操作方式**：手指从任意字母开始滑动，连接相邻字母形成单词。每个有效单词被识别后消除并获得分数和金币。

**关卡机制**：
- 每关给出一组字母，需要找出一定数量的单词才能过关
- 找出"全部单词"获得额外奖励
- 长单词（使用更多字母）获得更高分数
- 某些关卡有主题提示（如"动物"、"食物"）

**进度系统**：
- 2500+关卡，难度递增
- 每关完成后获得金币和星星
- 金币可用于购买提示
- 连续登录和每日任务提供额外奖励

## 核心循环

查看字母环 → 滑动连接字母组成单词 → 获得金币和分数 → 找出足够数量的单词过关 → 进入下一关

## 核心机制

- **字母环拼图**：与传统字母网格不同，字母环的设计让所有字母都互相可达，降低了搜索难度但增加了"能组成什么词"的创造性挑战。
- **渐进难度**：从小字母环（6个字母）到大字母环（8个字母），单词从3字母到7+字母，难度递增。
- **金币经济**：通关获得金币，金币可以购买提示，形成自循环经济系统。卡关时可以用金币获取帮助。
- **主题多样性**：不同关卡围绕不同主题，保持新鲜感的同时也提供了语义线索。

## 为什么好玩

从一组看似随机的字母中发现隐藏单词的过程充满"啊哈"时刻。当你偶然发现一个长单词或一个意想不到的词时，那种智力满足感是核心快感。2500+关卡提供了海量的内容。

## 粘性来源

- **关卡推进**：线性关卡进度让玩家有"继续下一关"的动力。
- **每日奖励**：每日登录和任务创造了日常习惯。
- **收集成就感**：完成每关的所有单词带来的满足感。

## Meta 系统

- **关卡进度**：2500+关卡线性推进，每关最多3星。
- **金币经济**：通过游玩获得金币，可购买提示和道具。
- **每日挑战**：每日特殊关卡提供额外奖励。

## 实现难度

低 — 核心是字母环+字典匹配。需要预先计算每个字母环的所有有效单词组合。最大难点在于2500+关卡的内容生产和难度平衡。
