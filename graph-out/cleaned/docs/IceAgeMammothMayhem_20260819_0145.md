# 冰河世纪：猛犸象大逃亡（Ice Age: Mammoth Mayhem）

- **类型**: 跑酷 / 动作冒险
- **平台**: Mobile (iOS)
- **开发商**: Unknown (基于电影IP授权)
- **首次发布**: 2008
- **一句话描述**: 一款基于《冰河世纪》电影IP的跑酷游戏，玩家控制角色在史前世界中奔跑逃生。

## 玩法规则

玩家看到的画面是一个横向或前向卷轴的史前场景——冰川、洞穴、原始丛林等。角色自动向前奔跑，玩家需要操控角色的移动来躲避障碍物和敌人。

操控方式：向上滑动跳跃、向下滑动蹲下、左右滑动切换跑道（多跑道版本）。障碍物包括掉落的冰块、地面上的裂缝、原始动物敌人等。

游戏过程中散落着电影主题的收集品（如橡果——Scrat的最爱），收集橡果获得额外分数。某些关卡包含特殊机制：滑行下坡、利用弹跳物飞跃悬崖、或短暂获得特殊能力（如无敌护盾）。

## 核心循环

自动奔跑 → 躲避障碍/收集物品 → 尽可能跑得更远 → 解锁新角色和场景

## 核心机制

- **无尽跑酷**：核心是持续加速的奔跑机制，随着时间推移速度越来越快，障碍物越来越密集，形成自然的难度递增。
- **多跑道切换**：如果是多跑道设计，玩家可以在2-3条跑道之间快速切换来选择最优路径，增加了策略维度。
- **IP主题收集**：以电影中的经典元素（如Scrat追逐橡果的执念）作为收集目标，增强代入感。

## 为什么好玩

《冰河世纪》IP本身就广受欢迎，加上跑酷游戏天然的上瘾性——"差一点就能破纪录"的不甘心驱动玩家不断重玩。可爱的角色和幽默的动画也增加了娱乐性。

## 粘性来源

- **分数挑战**：不断突破自己的最高分记录。
- **角色解锁**：使用游戏中收集的货币解锁电影中的不同角色（Manny、Sid、Diego等），每个角色可能有不同的视觉特效。
- **每日挑战**：每天更新特定目标（如"今天收集100个橡果"），给玩家持续回来的理由。

## Meta 系统

- **角色解锁**：收集足够橡果解锁不同电影角色，每个角色有独特外观。
- **场景解锁**：达到特定分数后解锁新场景（从冰川到热带岛屿），改变视觉体验。

## 实现难度

低。跑酷游戏的技术实现非常成熟。最大难点在于生成算法——需要确保障碍物的分布既有趣又公平，不会生成无法通过的配置。程序化生成需要精心调优概率分布。

## 变体设计

可以加入"赛道编辑"功能，玩家自己设计赛道并分享给其他人挑战。也可以加入"角色技能"系统——不同角色有不同的被动能力（如二段跳、磁吸收集品），增加策略选择。
