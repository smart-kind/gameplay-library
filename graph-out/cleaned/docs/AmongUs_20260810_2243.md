# 太空主题多人社交推理游戏（Among Us）

- **类型**: 社交推理
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: Innersloth
- **首次发布**: 2018
- **一句话描述**: 太空主题多人社交推理游戏

## 玩法规则

每局游戏有10名玩家，其中1-3名是伪装成船员的内鬼(Impostor)。内鬼需要通过暗杀船员、破坏飞船设施来获胜；船员则需要完成任务或通过投票找出内鬼。

游戏分为行动阶段和会议阶段。行动阶段玩家可以自由移动、执行任务（如刷卡、连接电线、清理垃圾等小任务），内鬼还可以使用通风管道快速移动、暗杀船员、发动破坏（关闭灯光、切断氧气等）。

当有人发现尸体可以报告，触发全员会议讨论并投票驱逐嫌疑人。被驱逐的玩家会揭示身份。游戏持续进行直到内鬼数量等于或超过船员数量（内鬼胜），或所有内鬼被找出（船员胜）。

## 核心循环

行动/暗杀/破坏 → 会议讨论/投票 → 揭示身份 → 继续下一轮

## 核心机制

- 身份隐藏：内鬼伪装成普通船员，需要在不被怀疑的情况下执行暗杀
- 任务系统：船员需要完成各种小游戏式任务，进度条满则船员阵营获胜
- 破坏机制：内鬼可以发动限时破坏，船员需要在时间内修复否则失败
- 会议投票：发现尸体或按紧急按钮触发全员讨论和投票驱逐

## 为什么好玩

完美的狼人杀式心理博弈体验，简单规则下蕴含丰富的策略深度。和朋友一起玩的戏剧性和搞笑场面是核心乐趣所在。

## 粘性来源

随机身份分配让每局都有新鲜感；差一点就投对了的不甘心和成功骗过所有人的成就感形成双重驱动；社交互动带来的情感波动极强。

## Meta 系统

皮肤、帽子、宠物等外观收集系统。玩家通过游戏内货币或真实货币购买外观装饰，不影响游戏平衡，纯属视觉自定义。

## 实现难度

低。多人社交推理游戏，核心逻辑简单但需要多人配合。最大技术难点：网络同步和反作弊机制。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手
