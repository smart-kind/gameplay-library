# G30 - 记忆迷宫（G30 - A Memory Maze）

- **类型**: 记忆 / 解谜 / 意识流
- **平台**: Mobile (iOS+Android)
- **开发商**: Ivan Zanotti
- **首次发布**: 2019
- **一句话描述**: 一款探索记忆本质的抽象解谜游戏，玩家通过旋转和重组碎片化的画面来拼凑完整的记忆场景。

## 玩法规则

游戏画面呈现为抽象的几何碎片——画面被切割成多个层次，每个层可以独立旋转。
玩家的操作：用手指在屏幕上拖动，旋转不同层面的几何图形，让它们对齐组合成一幅完整的画面。
当所有层面正确对齐时，碎片会合为一体，展现一幅有意义的场景或图像。
游戏没有文字教程或说明，玩家通过直觉和视觉线索理解操作方式。
每个关卡代表一段记忆片段，完成拼图后可以看到完整的记忆画面。
游戏中包含关于记忆、意识、时间的哲学性主题，通过视觉隐喻而非文字传达。
旋转的精度要求随关卡推进而提高，早期关卡容差较大，后期需要精确对齐。

## 核心循环

观察碎片化的画面 → 旋转不同层面 → 对齐碎片 → 拼出完整记忆画面

## 核心机制

- **多层旋转拼图**：核心玩法是在多个透明层上旋转几何图形，使它们对齐形成完整画面。不同层面的旋转速度和方向各不相同。
- **无文字叙事**：游戏没有任何文字说明，完全依靠视觉和直觉引导玩家理解规则。
- **意识流设计**：关卡之间的转换如同记忆片段的跳跃，没有线性逻辑，营造出梦境般的体验。
- **记忆隐喻**：碎片化的画面象征记忆中不完整的部分，拼凑完整象征回忆的重组过程。

## 为什么好玩

将记忆的抽象概念转化为可操作的视觉体验。旋转碎片逐渐对齐的过程有一种从混沌到秩序的满足感。

## 粘性来源

每段记忆画面揭示后的好奇心——'下一段记忆是什么'；碎片逐渐对齐的视觉满足感；短小精悍的关卡适合反复体验。

## Meta 系统

无。纯体验式游戏。

## 实现难度

低 — 旋转对齐的检测算法不复杂（角度容差判定）。最大技术难点在于3D层面渲染的性能优化和旋转动画的流畅度。

## 游戏变体

多数游戏在不同平台上发布了HD版、重制版或移植版本，核心玩法保持不变。
