# SimCity BuildIt

- **类型**: 模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: EA / TrackTwenty
- **首次发布**: 2014
- **一句话描述**: 《模拟城市》系列的移动端作品，建造和管理你的城市，满足市民的需求。

## 玩法规则

游戏画面为等距视角的城市建造界面，玩家在一块空地上从零开始建设城市。

核心操作：
- **放置建筑** — 选择住宅、商业、工业、娱乐等建筑类型，放置在地图上
- **生产资源** — 工厂和商店生产建材、家具、电子产品等资源，需要等待时间完成
- **满足需求** — 市民有电力、供水、垃圾处理、教育、医疗等需求，需要建造相应设施
- **升级建筑** — 满足所有需求后住宅可以升级，增加人口和税收
- **交易** — 在 Global Trade HQ 向其他玩家出售多余资源或购买稀缺资源

城市规划需要合理的布局，住宅需要靠近商业和工业（方便市民上班），但工业区会产生污染影响住宅满意度。

游戏有市长任务系统（完成任务获得 SimCash）和 War 系统（与其他城市竞争，互派灾难）。

## 核心循环

生产资源 -> 建造/升级建筑 -> 增加人口和税收 -> 解锁新建筑 -> 扩大城市规模

## 核心机制

- 资源生产链 — 从原材料到成品的多级生产，需要合理分配产能
- 城市需求系统 — 电力、供水、教育、医疗等多维度需求，相互关联
- 全球贸易 — 玩家可以互相买卖资源，形成社区经济

## 为什么好玩

看着空地变成繁华城市的成就感极强。SimCity 品牌的号召力；城市布局的策略性；与其他玩家交易和竞争增加了社交元素。

## 粘性来源

持续的城市发展目标（更多人口、更多建筑）；市长通行证（赛季制任务）；Club Wars（城市间对战）；每日登录奖励。

## Meta 系统

城市等级系统，人口增长解锁新建筑和功能。市长通行证（赛季制）提供任务和目标。SimCash（高级货币）可加速进程。

## 实现难度

低 — 基本操作简单直观，但资源管理和城市布局需要一定策略。最大技术难点在于平衡免费体验与内购压力（生产等待时间较长，可用 SimCash 跳过）。
