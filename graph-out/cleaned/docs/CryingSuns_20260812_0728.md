# 泣血太阳 (Crying Suns)

- **类型**: Roguelike / 战术 / 太空
- **平台**: Mobile (iOS+Android) / PC / Nintendo Switch
- **开发商**: Alt Shift
- **首次发布**: 2019
- **一句话描述**: 太空版FTL的战术Roguelike——指挥舰队穿越危险的银河系，在回合制战斗中管理战机编队

## 玩法规则

游戏画面为俯视的太空战场，玩家指挥一艘母舰（旗舰），携带不同类型的战机进行战斗。战斗采用回合制——玩家和敌方各自部署战机，然后同时执行移动和攻击。

玩家需要在网格状的战场上部署战机。每种战机有独特的功能：拦截机（快速近战）、轰炸机（范围伤害）、导弹机（远程精确打击）、电子战机（干扰敌方）等。战机的部署位置至关重要——前线战机保护后方的脆弱单位。

每场战斗后，玩家可以获得资源来购买新战机、升级现有战机或修复旗舰。在星系间移动时，玩家会遇到随机事件、商店、NPC等。

旗舰的生命值是核心资源——如果旗舰被摧毁，游戏结束。玩家需要在进攻和防御之间找到平衡。

## 核心循环

选择星系目标 → 进入战斗 → 部署战机 → 执行战斗 → 获取资源 → 升级舰队 → 前往下一区域

## 核心机制

- **战机编队管理**：不同类型的战机有各自的优势和克制关系。拦截机克制轰炸机，轰炸机克制密集阵型，电子战机干扰敌方部署。玩家需要根据敌方配置调整自己的编队。
- **旗舰系统**：旗舰不仅是战斗单位，也是移动基地。旗舰有独特的模块槽位，可以安装不同的模块（武器、护盾、引擎等），影响战斗风格。
- **叙事驱动探索**：与传统的Roguelike不同，游戏有完整的叙事线索。随着游戏进展，玩家逐步揭开帝国崩溃的真相。叙事与Roguelike的重复游玩形成了独特的体验。
- **Boss战**：每个区域有一个独特的Boss，需要特定的策略来击败。Boss有独特的战斗机制和弱点，需要玩家学习和适应。

## 为什么好玩

将FTL的核心乐趣（资源管理、战术决策、紧张感）提炼为更纯粹的回合制战斗体验。加上引人入胜的科幻叙事，让每次游玩都有明确的目标感。

美术风格非常出色——精细的像素风太空场景、独特的战机设计、氛围感十足的配乐。即使在手机上，画面表现力也令人印象深刻。战斗时的镜头震动和特效让每次交火都有足够的视觉冲击力。

## 粘性来源

叙事的逐步揭示是核心驱动力——玩家想知道"接下来发生了什么"。Boss战的挑战性和战术深度（每次失败都能学到新东西）也形成了强烈的重玩动力。

## Meta 系统

科技树解锁：通过游戏进程解锁新的战机类型和旗舰模块。叙事进度永久保存，即使游戏结束也能保留已解锁的内容。

## 实现难度

高。回合制战术战斗的AI、战机编队的自动执行逻辑、多种战机类型的平衡都需要大量工作。叙事与Roguelike的结合更是设计上的挑战——如何让重复游玩仍然有新鲜感。
