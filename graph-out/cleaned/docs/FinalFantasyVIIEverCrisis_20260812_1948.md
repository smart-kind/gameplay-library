# 最终幻想 VII：永恒危机（Final Fantasy VII Ever Crisis）

- **类型**: 动作 RPG / 剧情驱动
- **平台**: Mobile (iOS+Android)
- **开发商**: Square Enix / Applibot
- **首次发布**: 2023
- **一句话描述**: 以全新视角重温 FF7 经典故事的手游，包含原版、降临之子、核心危机等全部 FF7 宇宙的剧情内容

## 玩法规则

游戏采用半即时制战斗系统。玩家控制角色在战场上移动，面对敌人时使用技能、魔法和物品进行战斗。每个角色有独特的技能树和装备系统。

战斗中，角色自动进行普通攻击，玩家可以手动释放技能和魔法。技能有冷却时间或资源消耗限制，需要合理安排释放时机。每个角色有独特的战斗风格：克劳德近战输出、巴雷特远程射击、爱丽丝魔法治疗等。

探索部分采用章节制线性推进，玩家在场景中与 NPC 对话、完成任务、进入战斗。场景设计还原了 FF7 原版的经典地点——米德加、尼布尔海姆、忘却之都等。

## 核心循环

推进剧情章节 → 完成战斗获得经验值和素材 → 强化角色和装备 → 解锁新剧情章节 → 挑战高难度 boss

## 核心机制

- **全剧情整合**：将 FF7 原版、降临之子、核心危机、地狱犬的挽歌等全部 FF7 宇宙内容整合到一个游戏中，玩家以不同角色视角体验同一事件。为什么有效：对于 FF7 粉丝来说，这是一个"终极合集"——所有散落在不同游戏中的故事汇聚一处，提供了前所未有的叙事完整性。
- **角色切换战斗**：战斗中可以切换控制不同角色，每个角色有独特的技能组和战斗风格。为什么有效：它让玩家在同一个任务中体验不同的战斗节奏——克劳德的近战爆发、爱丽丝的魔法支援、蒂法的连击输出，丰富了战斗的多样性。
- **武器收集系统**：游戏中包含 FF7 历史上出现过的所有标志性武器（毁灭剑、加特林枪、贤者之杖等），每种武器有独特的外观和技能。为什么有效：对于系列粉丝来说，收集这些武器本身就是一种情怀满足。
- **限时活动剧情**：定期推出限时活动，补充原作中未详细展开的故事片段。为什么有效：它让游戏在主线剧情之外也有持续的内容更新，维持了 FF7 宇宙的不断扩展。

## 为什么好玩

对于 FF7 的粉丝来说，这款游戏就像是一个可以互动的博物馆。你不仅能重温克劳德和萨菲罗斯的史诗对决，还能从其他角色的视角看到同一事件的不同侧面。当你第一次在手机上听到"One-Winged Angel"响起时，那种感动是其他游戏无法提供的。

## 粘性来源

- **FF7 IP 情怀**：全球数百万 FF7 粉丝是天然的核心用户群
- **全剧情收集**：整合所有 FF7 宇宙内容给玩家一个"我要全部看完"的完成驱动力
- **定期活动**：限时活动补充原作故事，制造回归动机
- **武器收集**：收集所有 FF7 经典武器是长期的收集目标

## Meta 系统

**角色与武器强化系统**：
- 角色等级、技能等级、武器等级和突破
- 武器通过抽卡和活动获取，每种武器有独特的技能和外观
- 对核心玩法的影响：高星武器提供更强的技能和属性，但游戏设计保证了低星武器和免费角色也能通关大部分内容

## 实现难度

中 — 基于现有 FF7 IP 的手游改编，技术挑战主要在于**高质量 3D 建模在移动端的性能优化**和**大量剧情内容的制作与管理**。战斗系统相对标准，但需要确保每个角色的技能动画和特效在手机上流畅运行。最大的挑战是内容量——整合 FF7 全宇宙的剧情需要庞大的脚本、配音和过场动画制作。
