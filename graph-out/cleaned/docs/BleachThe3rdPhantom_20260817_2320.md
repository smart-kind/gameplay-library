# 死神：第三幻影（Bleach: The 3rd Phantom）

- **类型**: 策略角色扮演
- **平台**: Mobile (iOS+Android) / DS
- **开发商**: Sega / Treasure
- **首次发布**: 2008
- **一句话描述**: 基于死神（Bleach）动漫改编的战棋策略RPG，在网格地图上进行回合制战斗。

## 玩法规则

游戏采用网格地图的俯视视角，玩家和敌方单位分布在地图的不同格子上。屏幕显示双方的回合、剩余时间和单位状态。
每个回合玩家可以选择一个单位进行行动：移动（在一定格数范围内）、攻击（近战或远程）、使用技能/道具。行动结束后轮到下一个单位。
角色有不同的属性（攻击力、防御力、速度、灵力）和技能类型（攻击型、防御型、辅助型）。死神角色可以释放'斩魄刀'技能，虚角色有特殊能力。
单位之间存在克制关系：近战克远程、远程克飞行、飞行克近战（简化版）。某些角色可以变身（卍解）获得临时能力提升。
战斗在角色移动到敌人相邻格子时触发，进入战斗动画展示攻击效果。战斗结果由双方属性、技能加护和随机因素决定。
关卡目标多样：消灭所有敌人、在限定回合内到达指定位置、保护特定角色等。

## 核心循环

观察地图和单位位置 → 选择单位移动和攻击 → 利用克制关系和技能 → 推进到下一个单位 → 完成关卡目标

## 核心机制

- 网格移动战术：每个单位的移动范围和攻击范围不同，需要合理分配每个单位的行动，形成有效的攻防阵型。先动还是后动、集火哪个目标都是策略决策
- 角色养成：通过战斗获得经验值升级，提升属性和解锁新技能。不同角色有独特的成长路线，需要根据队伍需要培养
- 变身系统（卍解）：关键时刻释放变身获得临时巨大增益，是逆转战局的王牌。变身有使用次数限制，需要谨慎选择时机

## 为什么好玩

对于死神动漫粉丝来说，操控自己喜欢的角色释放卍解的满足感很强。
战棋策略的深度也让人享受——每次精心安排一次'完美回合'的成就感。

## 粘性来源

角色养成的数值积累、剧情推进的好奇心、以及'下一关我要试试不同策略'的策略粘性。

## Meta 系统

角色升级系统、技能解锁、装备系统、剧情章节。

## 实现难度

中 — 需要实现网格地图、回合制战斗AI、角色属性系统和战斗动画。主要技术难点在于AI的策略性和战斗平衡，以及变身系统的数值设计。

游戏中的剧情模式忠实还原了死神动漫的经典情节，玩家可以在战斗中看到角色释放卍解的动画演出。每个章节结束后有剧情对话和角色互动，增加了游戏的叙事深度。某些关卡有隐藏要素，需要特定条件才能触发。
