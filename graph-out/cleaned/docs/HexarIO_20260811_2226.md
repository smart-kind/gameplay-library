# Hexar.io（Hexar.io）

- **类型**: .io 多人对战 / 领土争夺 / 策略
- **平台**: Web（浏览器）
- **开发商**: Unknown .io 开发者
- **首次发布**: 2010s 末期
- **一句话描述**: .io 风格的领土争夺游戏，玩家在六边形网格地图上移动，用轨迹圈占领土地，同时防止其他玩家入侵你的领地

## 玩法规则

画面是一个六边形网格地图。玩家控制一个移动的点（或小角色），从自己的"基地"出发在地图上移动。移动时会留下一条轨迹线，当轨迹线回到自己的领地时，轨迹线所包围的区域就会被标记为你的领土。

操作方式：鼠标或方向键控制移动方向。移动速度相对较慢，但可以在自己的领地上快速移动。

其他玩家也会做同样的事情——离开领地去圈地，同时试图切断你的轨迹线（如果他们在你的轨迹线回到领地之前碰到它，你就死了）。杀死其他玩家后，他们的领土会变成无主之地，其他玩家可以重新圈占。

目标是占领尽可能多的领土（以百分比显示）。当你在地图上显示你的名字和领土占比时，其他人也在做同样的事——这是一个零和博弈。

## 核心循环

离开领地画轨迹 → 回到领地圈占新区域 → 切断其他玩家的轨迹 → 扩大领土

## 核心机制

- **轨迹圈地系统**：核心机制是"离开领地 → 画轨迹 → 回到领地"的循环。轨迹越长，圈到的地越大，但风险也越高——因为你的轨迹暴露在外面，其他玩家可以切断它。
- **风险回报平衡**：圈大地（画长轨迹）可以获得大量领土，但长轨迹意味着更长的暴露时间。圈小地安全但收益低。
- **多人竞争**：所有玩家在同一张地图上竞争，领土是零和博弈——你多了别人就少了。杀死其他玩家后，他们的领土变成无主之地，引发争夺战。
- **领地内安全**：在自己的领地上是安全的——其他玩家无法在你的领地内切断你的轨迹。领地是你的"安全区"。

## 为什么好玩

Hexar.io 把领土争夺简化到了最核心的机制——画线圈地。简单到任何人都能在一秒内理解，但多人竞争带来的策略深度让它非常耐玩。是冒险圈大地还是保守扩张？是防守自己的领地还是去攻击别人？

## 粘性来源

- **策略选择**：每局面临不同的策略选择——冒险还是保守？进攻还是防守？
- **多人竞争**：真人玩家的不可预测性是最大的乐趣——你不知道谁会来切断你的轨迹
- **即时反馈**：领土百分比实时变化，提供持续的进度反馈

## Meta 系统

无。纯核心玩法。

## 实现难度

中 + 需要多边形面积计算（轨迹围成的区域）、碰撞检测（轨迹切断）、多人网络同步。最大技术难点是轨迹围成区域的面积计算——需要高效的几何算法来确定轨迹线包围的多边形面积。
