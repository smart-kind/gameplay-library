# 蜈蚣（Centipede）

- **类型**: 射击/街机
- **平台**: 街机 / Mobile (iOS+Android) / Atari 2600 / 多平台复刻
- **开发商**: Atari
- **首次发布**: 1981
- **一句话描述**: 经典竖版射击游戏，控制屏幕底部的炮台射击不断向下蛇形移动的蜈蚣

## 玩法规则

游戏画面是一个竖版区域，屏幕底部是玩家控制的炮台（蘑菇精灵造型），只能左右移动。屏幕上方出现一条由多个节段组成的蜈蚣，从顶部开始向下蛇形移动。

蜈蚣的移动方式是：水平移动，碰到屏幕边缘或蘑菇（障碍物）时向下移动一行并改变水平方向。这种蛇形移动模式让蜈蚣逐步逼近屏幕底部的玩家区域。

玩家的射击可以消灭蜈蚣的单个节段。被击中的节段从蜈蚣身上分离，变成蘑菇留在屏幕上。当蜈蚣的最后一个节段被消灭后，它会从屏幕顶部重生为一条新的完整蜈蚣，但速度更快。

随着游戏推进，屏幕上积累的蘑菇越来越多，这些蘑菇不仅阻碍蜈蚣的移动（迫使它更快向下），也阻碍玩家的射击（子弹碰到蘑菇会被挡住）。玩家需要利用蘑菇来引导蜈蚣的移动路径——在关键位置射击产生蘑菇，将蜈蚣引导到更容易瞄准的位置。

除蜈蚣外还有三种敌人：蜘蛛在屏幕底部区域随机快速移动，碰到蘑菇会转向；跳蚤从顶部垂直掉落，经过时会留下蘑菇；蝎子从顶部水平移动，碰到玩家会使炮台暂时失控。

## 核心循环

左右移动炮台 → 射击蜈蚣节段 → 节段变蘑菇 → 利用蘑菇引导路径 → 清空屏幕过关

## 核心机制

- **障碍生成与利用**：射击产生的蘑菇既是障碍也是战略工具。合理射击可以在关键位置产生蘑菇，引导蜈蚣移动路径。这种'障碍即武器'的设计是游戏策略核心
- **多敌人协同**：蜈蚣、蜘蛛、跳蚤、蝎子四种敌人行为各异：蜈蚣蛇形逼近、蜘蛛底部乱窜、跳蚤垂直掉落、蝎子横向干扰。同时应对多种威胁增加游戏复杂度
- **蛇形路径算法**：蜈蚣碰到障碍物自动改变方向并下移一行，这种简洁的AI产生了复杂而有趣的移动模式。蘑菇的分布直接影响蜈蚣的逼近速度

## 为什么好玩

简洁的射击操作配合丰富的敌人行为，每次游戏都有不同体验。蜈蚣被击中后节段分离变成蘑菇的视觉效果和音效反馈极具满足感。蘑菇既是障碍又是工具的巧妙设计让射击行为具有双重意义。四种敌人的协同作战让游戏充满了动态变化。

## 粘性来源

射击的即时反馈提供持续的感官刺激、敌人行为的多样性确保每次体验不同、高分挑战的驱动力（连续消灭节段分数递增）、经典街机体验的怀旧情怀、以及蘑菇策略的深度（从单纯射击到 strategic 放置的转变）

## Meta 系统

分数排行榜系统——追求高分是核心长期目标；关卡速度递增提供持续挑战；多人轮流游戏模式增加社交竞争

## 实现难度

低 — 操作极简（移动+射击），上手零门槛。最大的技术难点在于多敌人AI的协调和难度递增曲线的设计——确保游戏随着蘑菇增多自然变难，但不会突然变得无法应对
