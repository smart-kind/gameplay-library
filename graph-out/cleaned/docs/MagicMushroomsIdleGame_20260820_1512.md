# Magic Mushrooms - Idle Game（Magic Mushrooms）

- **类型**: 放置 / 模拟 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: Digital Media Technology SLU
- **首次发布**: 2024
- **一句话描述**: 一款以蘑菇种植为主题的放置类游戏，通过种植、收获和销售蘑菇来扩展农场，享受悠闲的田园经营体验。

## 玩法规则

Magic Mushrooms 的画面呈现一个蘑菇农场的俯视图或斜视角场景。初始状态下一小块土地上种着基础蘑菇，周围是未开垦的荒地。屏幕布局分为：上方是农场主画面，下方是操作面板（种植、收获、升级按钮），侧边是资源统计（金币、蘑菇数量、农场等级）。

玩家通过点击完成基本操作：点击空地种植蘑菇种子，等待一段时间后点击成熟的蘑菇进行收获，收获后获得金币用于购买更多土地、解锁新蘑菇品种或升级设施。蘑菇的生长有明确的时间进度条显示，不同品种有不同的生长周期。

不同品种的蘑菇有不同的生长时间、售价和稀有度。普通蘑菇生长快但售价低，稀有品种生长时间长但售价高，是长期目标。解锁新蘑菇品种需要达到一定的农场等级或消耗特定数量的金币。

游戏即使在不在线时也会继续计算蘑菇生长进度（离线收益机制），重新打开游戏时会显示离线期间收获的总收益。自动化升级可以减少手动操作，让游戏更加"放置"。

## 核心循环

种植蘑菇 → 等待生长 → 收获获得金币 → 购买更多土地/新品种 → 扩大农场规模 → 解锁自动化

## 核心机制

- **离线收益系统**：游戏在后台继续运行，离线期间蘑菇照常生长并产出金币，降低"必须在线"的压力
- **品种解锁机制**：通过积累金币解锁更稀有、更高价值的蘑菇品种，提供明确的长期目标和收集驱动力
- **农场可扩展设计**：购买更多土地扩大种植面积，视觉上的扩张带来直观的成就感
- **自动化升级路径**：解锁自动收获、自动种植等功能，逐步减少手动操作，符合放置游戏核心理念

## 为什么好玩

种植和收获的循环天然令人放松——看着蘑菇从小变大、从普通变稀有的过程有一种自然的满足感。不需要快速反应或复杂策略，适合在忙碌间隙打开玩几分钟，或者睡前打开看一下收获。

蘑菇种植的主题在放置游戏中非常独特——不同于常见的金币或宝石，蘑菇的生长过程本身就是有机的、有生命力的。看着不同品种的蘑菇在农场上绽放，每种蘑菇有独特的颜色和形态，这种视觉上的多样性让重复的收集过程保持新鲜感。

## 粘性来源

"解锁下一个稀有品种"的收集驱动力。每次打开游戏看到新蘑菇成熟都是一次小惊喜。离线收益机制也让用户即使几天不打开也不会落后太多，减少焦虑感，保持轻松的游玩心态。

## Meta 系统

农场扩展系统：购买更多土地、升级种植设施、解锁自动化工具。蘑菇品种图鉴：收集所有蘑菇品种，记录每种蘑菇的生长特性和售价。成就系统记录特定里程碑。

## 实现难度

低 — 放置类游戏的核心逻辑简单（定时器+资源计算）。最大难点是经济系统的平衡设计——确保金币产出和消耗的节奏感，既不让玩家觉得太慢也不觉得太容易，同时离线收益的比例需要仔细调校。
