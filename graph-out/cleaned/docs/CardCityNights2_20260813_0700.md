# 卡城之夜2（Card City Nights 2）

- **类型**: 卡牌对战 / Roguelike
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: Annapurna Interactive / Vodeo Games
- **首次发布**: 2018
- **一句话描述**: 2v2卡牌对战，每回合双方同时出牌，根据卡牌组合和对手行动结算胜负

## 玩法规则

游戏采用双人对战界面，上方是对手的角色和手牌区，下方是玩家自己的角色和手牌。每回合双方各自从手牌中选择一张牌，然后同时揭示。

每张牌有两个数值——正面攻击值和背面防御值。出牌后，系统比较双方卡牌：如果一方的攻击值高于对方的防御值，该方获胜并造成伤害。

游戏特色在于2v2格式——每方有两个角色，可以同时出牌。角色有不同的属性（力量、敏捷、智慧）和特殊技能。

目标是击败对方的两个角色。游戏包含单人Roguelike模式和多人对战模式。

## 核心循环

选择手牌 → 同时揭示 → 比较攻防数值 → 造成伤害/受伤（循环至一方全败）

## 核心机制

- 同时出牌机制：双方同时选择一张牌然后揭示，不是回合制的"你出完我出"，而是同时决策，制造了心理博弈。
- 双数值系统：每张牌同时具有攻击和防御值，但一面只能展示一个。选择展示攻击还是防御是核心策略。
- 角色属性克制：不同角色有不同属性倾向（力量/敏捷/智慧），属性之间的相互作用影响伤害计算。

## 为什么好玩

同时出牌的心理博弈像石头剪刀布的升级版，猜中对手意图的瞬间极其爽快。2v2格式让策略深度大幅提升。

## 粘性来源

猜中对手出牌的心理博弈快感。Roguelike模式的随机性让每局都是新体验。

## Meta 系统

Roguelike模式：玩家通过冒险获得新角色解锁和永久性加成。多人对战模式有等级和排名系统。

## 实现难度

低-中。卡牌逻辑本身不复杂，但2v2同时出牌的结算系统需要仔细设计（特别是平局处理、技能连锁）。最大技术难点：AI对手的决策逻辑（要能做出有意思的选择）。
