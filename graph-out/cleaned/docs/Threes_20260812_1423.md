# 小三传奇（Threes!）

- **类型**: 解谜 / 数字消除 / 益智
- **平台**: Mobile (iOS+Android)
- **开发商**: Sirvo LLC
- **首次发布**: 2014
- **一句话描述**: 一款在4×4棋盘上滑动合并数字的益智游戏，是2048的灵感前身，但拥有更精妙的合并规则。

## 玩法规则

游戏在一个4×4的小棋盘上进行。棋盘上散布着数字方块，包括蓝色的1、红色的2以及它们的组合。
玩家每次可以选择上/下/左/右四个方向之一滑动，所有方块会朝该方向移动到极限位置。
合并规则严格：只有1和2可以合并成3。之后只能合并相同的数字（3+3=6，6+6=12，12+12=24）。
每次滑动后，棋盘对面边缘会生成一个新的随机方块（1、2或3），迫使棋盘逐渐填满。
游戏目标是在棋盘填满前合成尽可能大的数字。棋盘被填满且无法合并时游戏结束。
最终得分为所有方块数值之和，高分可以挑战自己的记录。
与2048不同，Threes!的合并规则更严格，策略性更强，空间管理要求更高。

## 核心循环

滑动棋盘 → 合并数字 → 新方块生成 → 保持棋盘不塞满 → 合成更大数字

## 核心机制

- **严格合并规则**：只有1+2=3，之后必须相同数字合并。这迫使玩家更精确地规划每一步，而非像2048那样随意合并。
- **4×4紧凑棋盘**：小棋盘意味着每一步决策都很关键，空间管理是核心挑战。
- **卡片收集系统**：游戏中包含28张可收集的卡片，每张对应一个数字成就，拥有独特的角色设定和动画。
- **滑动反馈**：每个数字方块都有可爱的表情动画，合并时有独特的音效和动画反馈。

## 为什么好玩

极简规则下的深度策略体验。每一步都需要权衡短期合并和长期空间管理，紧凑的4×4棋盘让决策压力恰到好处。

## 粘性来源

紧凑棋盘带来的'差一点就能合成更大数字'的不甘心；卡片收集系统提供长期目标；每局游戏时间短（2-5分钟），适合反复来一局。

## Meta 系统

卡片收集系统——28张可解锁的卡片，每张代表一个数字成就，拥有独特的角色设定和动画。不影响gameplay，但提供收集动力。

## 实现难度

低 — 核心逻辑是4×4网格的滑动和合并，算法实现简单。最大技术难点在于UI动画的流畅度和触摸手势的精准识别。
