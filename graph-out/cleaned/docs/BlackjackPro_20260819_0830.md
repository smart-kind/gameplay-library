# Blackjack Pro（21点专业版）

- **类型**: 卡牌 / 策略 / 赌场
- **平台**: Mobile (iOS + Android)
- **开发商**: Dealer Bust Time LLC
- **首次发布**: 2010
- **一句话描述**: 21点纸牌游戏与算牌训练器的结合，既是赌场模拟也是专业学习工具

## 玩法规则

基于标准 21 点（Blackjack）规则。

**核心目标**：手牌点数总和尽可能接近 21 点但不超过（爆牌即输）。A 可计为 1 或 11，J/Q/K 计为 10，其余按面值计算。

**核心操作**：每局开始，玩家和庄家各发两张牌（庄家一张明牌一张暗牌）。玩家可选择——
- **Hit（要牌）**：再拿一张牌
- **Stand（停牌）**：不再要牌，保持当前手牌
- **Double Down（加倍下注）**：加倍赌注但只能再拿一张牌
- **Split（分牌）**：如果两张牌相同，可分成两手分别下注
- **Surrender（投降）**：放弃一半赌注

**庄家规则**：庄家必须要在手牌点数小于 17 时要牌，17 或以上必须停牌。

**算牌训练**：专业版本包含算牌练习功能，教授 Hi-Lo 等经典算牌系统。玩家在实际游戏中练习记牌，系统评估算牌准确度。

## 核心循环

下注 → 发牌 → 决策（要牌/停牌/加倍/分牌） → 与庄家比大小 → 结算 → 继续

## 核心机制

- **概率决策**：基于已知牌面计算最佳行动的概率期望值，培养玩家的概率思维
- **算牌系统**：Hi-Lo 算牌法将每张牌赋予 +1/-1/0 值，通过追踪已出牌来估算剩余牌堆的优势
- **基本策略表**：内置最优决策参考表，根据玩家手牌和庄家明牌推荐最佳行动
- **多副牌支持**：模拟真实赌场中多副牌（6-8 副）的环境，增加算牌难度

## 为什么好玩

21 点是赌场游戏中为数不多玩家可以通过策略和技能获得优势的游戏。这款游戏不仅提供了赌场模拟体验，更是一个真正的学习工具——通过算牌训练，玩家可以掌握一个在现实中有实际用途的技能。

## 粘性来源

主要来自技能提升的成就感——算牌能力会随着练习不断提高，这种"我在掌握一项真技能"的感觉是其他纯娱乐游戏无法提供的。同时，21 点本身的概率博弈也带有天然的刺激感。

## Meta 系统

无（作为训练工具，重点在于技能提升而非游戏内成长）

## 实现难度

低 — 核心是卡牌发牌逻辑、21 点规则引擎和 UI。算牌训练功能需要追踪已出牌并计算真数（true count），逻辑清晰。最大技术难点在于生成符合概率分布的洗牌结果，确保模拟的真实性。
