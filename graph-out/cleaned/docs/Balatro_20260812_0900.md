# Balatro

- **类型**: Roguelike / 扑克
- **平台**: PC / Switch / PS / Xbox / Mobile
- **开发商**: LocalThunk
- **首次发布**: 2024
- **一句话描述**: 2024 年几乎获得年度游戏的扑克 Roguelike，用一副牌和 Joker 创造无限可能。

## 玩法规则

玩家使用扑克牌型（对子、三条、顺子、同花等）作为攻击手段，对抗不断增长的盲注目标。核心机制是通过 Joker（小丑牌）改变计分规则——每个 Joker 提供独特的倍率加成或规则改变。

每轮游戏选择一个牌型，打出匹配的扑克牌获得分数。分数必须超过盲注目标才能进入下一轮。商店中购买新的 Joker、塔罗牌（改变卡牌属性）和星球牌（提升牌型基础分）。

游戏的魔力在于 Joker 之间的协同效应——某些 Joker 组合可以产生指数级的分数增长，让看似不可能的盲注目标变得可行。

## 核心循环

打出牌型 → 获得分数 → 购买 Joker → 挑战更高盲注

## 核心机制

- 扑克牌型：用标准扑克牌组合作为攻击手段
- Joker 系统：改变计分规则的小丑牌
- 商店系统：购买 Joker、塔罗牌和星球牌增强牌组
- 盲注递增：每轮目标分数不断提高
- 协同效应：Joker 之间组合产生指数级增长

## 为什么好玩

简单规则（扑克牌型）和复杂策略（Joker 协同）的完美结合。找到 Joker 之间的强力组合时的兴奋感无与伦比。

## 粘性来源

- Joker 协同发现：找到指数级增长的组合极具满足感
- 盲注递增的紧张感：目标不断提高，每次都是挑战
- 简单规则复杂策略：扑克人人都懂，但 Joker 组合创造深度
- 每局随机性：不同的 Joker 池确保每局体验不同

## Meta 系统

解锁新牌组和 Joker。通过达成特定条件解锁新的起始牌组和稀有 Joker。

## 实现难度

低。核心逻辑是扑克牌型计算和 Joker 效果叠加。难点在于数值平衡——确保游戏在后期仍有挑战但不过于困难。
