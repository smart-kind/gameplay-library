# Prison Tycoon（Prison Tycoon）

- **类型**: 模拟经营/管理
- **平台**: Mobile (iOS)
- **开发商**: 待确认
- **首次发布**: 2010
- **一句话描述**: 管理监狱囚区的模拟经营游戏，保持囚犯平衡并盈利

## 玩法规则

游戏采用等距视角，画面展示一个监狱牢房区域。玩家以上帝视角管理囚犯的日常活动。

**操作方式**：
- 点击囚犯查看其状态和情绪气泡
- 拖拽囚犯到不同区域（工作台、篮球场、举重区）
- 点击升级按钮改善设备
- 点击建造按钮添加新建筑

**核心玩法**：
- 管理牢房区的囚犯，保持他们开心、安分和有生产力
- 送囚犯到工作台赚钱，但会让他们疲惫
- 当囚犯攻击性上升时，安排他们在篮球场或举重区锻炼来冷静
- 监控囚犯情绪，防止暴动发生
- 升级设备和建造新建筑提高生产力
- 保持监狱盈利

**胜利/结束条件**：
- 成功：监狱持续盈利，囚犯得到改造
- 失败：暴动发生或监狱破产

## 核心循环

安排囚犯工作 → 获得收入 → 升级设备 → 建造新建筑 → 提高盈利

## 核心机制

- **情绪系统**：囚犯有愤怒、疲惫、幸福等情绪状态，用类似The Sims的气泡图标表示
- **工作-休息循环**：工作台赚钱但消耗体力，锻炼恢复但浪费时间
- **暴动预警**：游戏会在暴动发生前发出警告
- **等距视角**：干净的等距画面风格
- **设备升级**：升级工作台和锻炼设备提高效率
- **建造系统**：建造新建筑提高生产力和盈利能力

## 为什么好玩

监狱管理题材本身就充满争议性和话题性。玩家可以在自由派和严厉派之间选择自己的管理风格。虽然实际操作更像"全知狱警"而非"大亨"，但管理囚犯情绪的玩法仍然有趣。

## 粘性来源

- **经营挑战**：平衡盈利和囚犯福利的策略思考
- **情绪管理**：监控和调节囚犯情绪的成就感
- **渐进升级**：设备和建筑的逐步解锁
- **题材吸引力**：监狱管理本身的争议性话题

## Meta 系统

- **设备升级**：升级工作台和锻炼设备
- **建筑解锁**：建造新建筑提高生产力

中 — 模拟经营系统需要良好的数值设计，主要技术难点在于囚犯AI的情绪模拟和资源平衡计算。
