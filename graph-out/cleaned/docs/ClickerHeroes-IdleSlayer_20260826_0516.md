# Clicker Heroes - Idle Slayer

- **类型**: 放置RPG / 点击冒险
- **平台**: Mobile (iOS)
- **开发商**: Playsaurus, Inc.
- **首次发布**: 2015
- **一句话描述**: Clicker Heroes是一款从Steam和PC浏览器移植到移动端的经典放置RPG游戏。玩家通过点击击杀怪物、招募英雄、解锁技能，在1000多种区域中冒险。

## 玩法规则

游戏以卡通风格的横版战斗场景呈现，屏幕中央是怪物和英雄。底部有点击区域和技能按钮。核心操作是点击怪物进行攻击。随着怪物血量降低，点击伤害需要不断提升。可以招募各种英雄，每个英雄有独特的技能。英雄自动攻击怪物，玩家也可以手动点击辅助。战斗中使用最多9种主动技能增加策略深度。通过击杀怪物获得金币，用于升级英雄、解锁新区域和挑战Boss。转生系统允许玩家重置进度以解锁远古力量，获得永久性提升。

## 核心循环

点击击杀怪物 -> 获得金币 -> 升级英雄/解锁技能 -> 推进新区域 -> 转生获取远古力量 -> 挑战氏族Boss -> 重复

## 核心机制

- 点击战斗：手动点击攻击怪物，是基础交互方式
- 英雄系统：招募和培养多种英雄，各有独特技能
- 主动技能：最多9种技能在战斗中战略性使用
- 转生系统：重置进度解锁远古力量，永久性提升
- 氏族系统：组队挑战不朽者Boss的多人合作玩法

## 为什么好玩

作为从PC移植到移动端的经典放置游戏，Clicker Heroes证明了其设计的经久不衰。1000多种区域的庞大内容量、丰富的英雄系统和氏族合作让游戏深度远超一般放置游戏。

## 粘性来源

1000多种区域提供海量内容；英雄培养和技能解锁提供持续目标；氏族Boss战增加社交合作维度；转生系统让进度永不停止

## Meta 系统

有转生系统（Ascension解锁远古力量）、英雄升级系统、技能系统（9种主动技能）、氏族系统（组队Boss战）、排行榜和成就系统。27种语言支持。

## 实现难度

中。核心难点在于放置RPG玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
