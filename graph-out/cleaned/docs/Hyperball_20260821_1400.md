# Hyperball

- **类型**: 休闲体育
- **平台**: Mobile (iOS+Android)
- **开发商**: AI Games FZ
- **首次发布**: 2018
- **一句话描述**: 极简风格的微型足球对战，滑动控制小车撞球入网

## 玩法规则

游戏采用俯视视角的微型足球场。屏幕左右两侧各有一个球门，玩家控制一辆小车在球场上进行足球比赛。

玩家通过滑动屏幕控制小车移动，目标是将球撞入对方球门。小车和球都有物理碰撞效果，球的运动轨迹受碰撞角度和力度影响。撞球的角度和速度决定了球的飞行方向。

比赛通常限时进行（如60秒），进球多者获胜。球场上有墙壁，球撞到墙壁会反弹，增加了比赛的不可预测性和趣味性。

每场比赛非常短暂（约1分钟），操作只需要单指滑动，上手零门槛。

## 核心循环

滑动控制小车 → 撞球入网得分 → 获胜得奖励 → 解锁新球场

## 核心机制

- **物理碰撞系统**: 小车与球的碰撞角度和力度决定了球的运动轨迹。球的反弹效果基于真实物理，需要玩家预判球的落点和反弹方向。碰撞时的力度感是核心体验。
  （物理模拟）
- **微型球场设计**: 球场面积小，节奏极快，球几乎一直在运动中，几乎没有停歇时间。小空间内的快速对抗带来高强度的紧张感。
  （节奏控制）
- **墙壁反弹互动**: 球场中的墙壁会反弹球，增加了比赛的随机性和策略性。利用墙壁反弹可以打出意想不到的进球。
  （环境互动）

## 为什么好玩

极简操作+物理碰撞带来极致的快节奏体验。1分钟一局的比赛让人忍不住'再来一局'。球的反弹轨迹充满惊喜。

## 粘性来源

物理碰撞的不可预测性、极短的比赛时长降低失败成本、'就差一球'的竞技刺激感。每局的随机性保证了不会重复。

## Meta 系统

解锁新球场和新外观，无深度数值成长。

## 实现难度

低 — 核心是2D物理碰撞模拟，技术成熟。主要是球场和外观的内容填充工作。
