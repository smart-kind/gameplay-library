# My Little City（My Little City）

- **类型**: 模拟经营 / 放置建造
- **平台**: Mobile (iOS+Android)
- **开发商**: 待确认
- **首次发布**: 约2012
- **一句话描述**: 一款城市建设模拟游戏，玩家从一个小城镇开始，通过规划和发展逐步将其建设为繁华都市

## 玩法规则

游戏开始时，玩家获得一小块空地作为城镇的起点。画面采用等距视角展示城市布局，画面清新明快。屏幕底部是建筑菜单，分为住宅、商业、工业、公共设施、装饰等类别。顶部显示城市资金、人口、满意度和城市等级等核心指标。

玩家从建筑菜单中选择要建造的建筑类型，点击空地放置。每种建筑消耗一定资金，产生不同的效果：住宅增加人口和住房供应，商业建筑产生税收收入，工业建筑提供就业机会但可能降低周边满意度。玩家需要合理规划不同区域的功能分区。

建筑建造需要时间——从几秒（小型建筑）到几分钟（大型建筑）不等，完成后自动开始产出收益。随着城市规模扩大，玩家需要管理交通（建造道路和公共交通）、电力（建造发电厂和输电线路）、水源（水厂和水管）等城市基础设施。基础设施不足会降低建筑效率和居民满意度。

升级系统允许玩家对已有建筑进行升级，提升产出效率或解锁新功能。例如，住宅从平房升级到公寓楼可以容纳更多居民，商业建筑从便利店升级到百货商店可以产生更多税收。城市等级提升后，解锁新的建筑类型和更大的城市区域。

游戏采用"放置"机制——即使离线，城市也在持续产生收益。再次上线时可以收集离线期间的收益（有上限，通常为离线4小时的收益），用于继续扩展和建设。这种机制让玩家可以利用碎片时间管理城市。

市民满意度是核心管理指标之一。满意度受多种因素影响：环境污染（工业区靠近住宅区会降低满意度）、交通便利度（道路拥堵降低满意度）、公共设施覆盖（公园、学校、医院提高满意度）。满意度低会导致人口流失和税收减少。

城市发展过程中会遇到随机事件：自然灾害（地震、洪水）、经济危机、特殊机遇（举办活动、获得投资）等。正确处理这些事件可以获得奖励，处理不当会造成损失。

## 核心循环

完成关卡或日常任务 → 获得评分、经验或游戏货币 → 升级角色能力或解锁新内容 → 挑战更高难度的关卡或模式

## 核心机制

- **渐进难度设计**：关卡难度从简单到复杂逐步递增，每个新关卡引入1-2个新机制或变化，确保玩家在适应当前难度的同时学习新玩法。
- **即时反馈系统**：每次操作后系统立即给出视觉和音效反馈（命中特效、得分弹出、连击计数），强化操作的成就感和爽快感。
- **资源约束机制**：玩家的操作次数、时间或生命值有限，需要在约束条件下做出最优决策，增加了策略深度。
- **评价与重玩驱动**：1-3星评级系统鼓励玩家在通关后反复挑战以获得更高评价。

## 为什么好玩

这款游戏通过简洁直观的操作方式和逐步提升的难度曲线，让玩家在每次尝试中都能获得明确的进步感。关卡设计的多样性确保了长时间游玩不会感到重复乏味，而即时反馈系统则让每次操作都充满满足感。

## 粘性来源

具体到机制层面：1) 1-3星评分系统激发"再试一次拿到三星"的心理驱动力——玩家往往在2星时感到"差一点就完美"，这种不甘心是推动重复游玩的核心力量；2) 关卡逐步解锁的设计制造了持续的目标感和期待感；3) 排行榜或成就系统引入了社交竞争元素，让玩家与他人的成绩比较。

## Meta 系统

无核心外围成长系统。游戏以关卡通关和评分提升为主要进度驱动，可能包含基础的道具购买、角色解锁或外观收集机制。
