# Push Master

- **类型**: 超休闲 / 物理
- **平台**: Mobile (iOS)
- **开发商**: tatsumaki games
- **首次发布**: 2023
- **评分**: ⭐ 4.7/5 (27,013 评价)
- **价格**: Free
- **一句话描述**: 一款超休闲游戏，把人群推向迎面而来的车辆，看着他们飞出去——刺激和罪恶感的混合体验。

## 玩法规则

游戏采用3D画面，玩家站在一个平台上。通过滑动或拖拽控制推动方向和力度。平台上有一群人（或物体），玩家需要把他们推向赛道上行驶的车辆。人被车撞后会飞出去，有物理抛物线效果。游戏目标是用最少的人撞到最多的车，或者获得最高的飞行距离分数。界面包含：人群、行驶的车辆、分数显示。游戏有"罪恶快感"的心理设计——看似暴力的画面以卡通风格呈现，减轻不适感。

## 核心循环

选择目标 → 滑动推动 → 观看物理飞出去 → 获得分数 → 下一关

## 核心机制

- 物理飞行动画：人被撞后的抛物线飞行提供视觉爽感
- 拖拽控制：滑动方向和力度决定推动效果
- 分数系统：基于飞行距离、撞到车辆数量等计算分数

## 为什么好玩

"罪恶快感"的心理设计——看似暴力但以卡通风格呈现，让人既觉得刺激又不会真的不适。

## 粘性来源

物理飞行的视觉爽感、"再来一次试试不同角度"的好奇心、分数挑战

## Meta 系统

关卡解锁、皮肤。不影响核心玩法。

## 实现难度

低——物理引擎+简单触控，超休闲标准模板
