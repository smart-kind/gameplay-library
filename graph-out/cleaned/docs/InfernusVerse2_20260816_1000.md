# Infernus: Verse 2

- **类型**: 第一人称冒险解谜
- **平台**: Mobile (Android)
- **开发商**: Motalen
- **首次发布**: 2011
- **一句话描述**: 延续第一人称地下实验室冒险，拥有接近PS2水平的画面表现

## 玩法规则

Infernus: Verse 2 延续了第一部中玩家在一个秘密地下设施中醒来的故事。你仍然是那个在其他人撤离后独自醒来的困惑角色，需要探索这个废弃的设施来寻找答案。

游戏的画面引擎值得称赞，在某些场景下几乎达到了PS2级别的视觉效果，精美的贴图工作和丰富的道具细节让游戏世界生动有趣。音效也很出色，探索废弃设施时的惊吓效果虽然有些可预测（低语声、灯光熄灭、突然的画面切换等），但氛围营造得很好。

操控方面有些笨拙——特别是旋转视角需要大量滑动屏幕——但响应速度还不错。这仍然是一款有限制的老派冒险游戏，而且似乎对它那些无意义的故事情节过于着迷。第一部游戏中充满了尴尬的像素搜寻和试图弄清楚开发者想让你用看似随机的物品做什么的问题。第二部稍微没那么复杂，大多数物品都有提示，但这些提示只在一定程度上有帮助。

### 核心循环
探索设施 → 收集物品 → 解开谜题 → 推进故事 → 进入新区域

### 核心机制
- **第一人称探索**：在3D环境中探索，通过滑动屏幕旋转视角
- **物品解谜**：收集各种物品并在环境中使用它们来推进进度
- **提示系统**：大多数物品都提供提示，帮助玩家理解如何使用它们
- **像素狩猎式寻物**：需要在场景中仔细寻找关键物品

### 为什么好玩
游戏的画面和音效质量在移动端作品中相当出色，探索废弃设施的紧张感营造得很好。虽然谜题有时过于晦涩，但对于喜欢老式冒险游戏的玩家来说，这种挑战本身就是一种乐趣。

### 粘性来源
粘性主要来自解谜的成就感——当你终于想通了一个困扰你很久的谜题时的那种兴奋。同时，故事的神秘感也促使玩家想要继续探索以揭开真相。不过，过于晦涩的谜题也可能导致挫败感。

### Meta 系统
无。游戏是线性推进的故事模式，没有外围成长系统。

### 实现难度
中。3D场景渲染和第一人称控制在移动端有一定挑战，但Unity等引擎可以很好地处理。最大的技术难点在于设计平衡的谜题系统——既不能太简单也不能太晦涩。
