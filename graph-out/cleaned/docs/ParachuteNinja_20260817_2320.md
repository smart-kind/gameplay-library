# 降落伞忍者（Parachute Ninja）

- **类型**: 动作街机
- **平台**: Mobile (iOS+Android)
- **开发商**: Halfbrick
- **首次发布**: 2010
- **一句话描述**: 由Halfbrick（水果忍者开发商）出品的俯视角动作游戏，忍者从天而降消灭敌人。

## 玩法规则

游戏画面是俯视视角，忍者角色从屏幕上方跳伞降落到一个被敌人占据的区域。地面有各种敌人（士兵、忍者、武士等）在巡逻。
玩家操控忍者的移动（虚拟摇杆或点击移动），忍者自动攻击附近范围内的敌人。攻击方式是快速挥砍，一次命中即可消灭普通敌人。
在消灭所有区域敌人后，忍者会呼叫直升机接应。直升机到达前有一个短暂的等待时间，期间可能会有额外敌人出现。
游戏有多条路线，玩家可以选择下一个降落区域。不同区域的敌人数量和类型不同。收集沿途的金币和道具（生命恢复、攻击力提升等）。
游戏过程中忍者可以收集临时道具：手里剑（远程投掷）、烟雾弹（隐身短暂时间）、飞镖（扇形攻击）。
游戏结束条件：忍者被敌人击中且生命值耗尽。目标是在尽可能多的区域完成清理并到达安全撤离点。

## 核心循环

跳伞降落区域 → 移动并自动攻击敌人 → 清理完所有敌人 → 呼叫直升机撤离 → 选择下一个降落区域继续

## 核心机制

- 自动攻击+手动走位：玩家专注于移动和走位来避开敌人攻击，攻击自动进行，降低操作门槛同时保留策略性
- 区域清剿循环：每个区域是一个独立的战斗单元，完成后获得成就感并推进到下一区域。区域之间有短暂的过渡时间用于收集道具
- 道具收集：临时道具改变战斗风格，手里剑适合远程清理、烟雾弹适合突围，增加战术选择

## 为什么好玩

忍者从天而降的入场方式本身就很酷炫，加上自动攻击带来的'割草'快感，以及清理完一个区域后呼叫直升机撤离的那种'任务完成'的满足感。
Halfbrick标志性的流畅手感和视觉反馈，让每次挥砍都有很好的打击感。

## 粘性来源

区域递进的推进感（'再看下一个区域有什么'）、道具收集的收集欲、以及'我能坚持多少个区域'的自我挑战。

## Meta 系统

解锁新忍者角色、新武器皮肤、成就系统。

## 实现难度

低 — 自动攻击降低了复杂度，核心是碰撞检测和简单的AI移动。主要技术难点在于多敌人情况下的性能优化和碰撞检测精度。

游戏还包含连击系统：连续消灭敌人获得连击加成，连击越高得分倍数越高。某些区域有隐藏收集品（卷轴），找到它们可以解锁新角色。游戏的视觉效果采用简洁的2D卡通风格，色彩鲜明。
