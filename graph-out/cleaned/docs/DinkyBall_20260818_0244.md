# Dinky Ball（Dinky Ball）

- **类型**: 平衡解谜/休闲
- **平台**: Mobile (iOS)
- **开发商**: Ketchapp
- **首次发布**: 2010
- **一句话描述**: 倾斜设备在圆形平台上滚动小球到达终点的解谜游戏

## 玩法规则

游戏采用伪3D视觉风格，实际为2D玩法。画面展示一个圆形平台，小球在平台上滚动。

**操作方式**：
- 倾斜设备控制小球在圆形平台上滚动方向
- 点击屏幕触发小球跳跃
- 滑动调整视角观察平台全貌

**核心玩法**：
- 在迷宫般的圆形平台上引导小球到达终点（红色方块）
- 在限定时间内完成关卡
- 部分关卡时间充裕，重点是判断 tricky 的跳跃
- 部分关卡时间极短，需要快速反应
- 收集关卡中出现的各种方块道具
- 60个关卡逐步增加难度

**胜利/结束条件**：
- 关卡成功：在限定时间内将小球滚到终点红色方块
- 关卡失败：小球掉落平台或时间耗尽（屏幕显示"YOU LOOSE!"）

## 核心循环

倾斜设备引导小球 → 避开陷阱 → 到达终点 → 解锁新关卡

## 核心机制

- **倾斜控制**：利用设备陀螺仪控制小球滚动
- **跳跃机制**：点击屏幕触发跳跃跨越间隙
- **时间挑战**：不同关卡有不同时间限制，从几秒到近一分钟
- **道具方块**：减速方块、加速方块、弹跳方块、消失方块等
- **关卡变化**：看似重复的关卡在最后时刻改变关键元素
- **60关卡**：循序渐进的难度曲线

## 为什么好玩

看似简单的平衡游戏，但时间压力和关卡变化让每次挑战都有新鲜感。简单的操作背后是复杂的策略判断——何时跳跃、何时加速、何时小心谨慎。"YOU LOOSE!"的拼写错误反而成了游戏的幽默标签。

## 粘性来源

- **时间挑战**："差几秒就成功"的不甘心驱动再来一次
- **关卡变化**：重复关卡的意外变化防止自满
- **短关卡设计**：多数关卡只需几十秒，适合碎片时间
- **道具收集**：各种方块道具增加策略深度

## Meta 系统

无 — 游戏以60关卡推进为主，无外围成长系统。

## 实现难度

低 — 倾斜控制物理框架成熟，主要技术难点在于陀螺仪灵敏度调校和关卡难度曲线设计。
