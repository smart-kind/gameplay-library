# Escaping the Prison

- **类型**: 解谜/点击冒险
- **平台**: Web
- **开发商**: PuffballsUnited
- **首次发布**: 2013
- **一句话描述**: 经典点击式越狱冒险游戏——通过选择不同路径逃离监狱，每个选择导致不同的结局

## 玩法规则

Escaping the Prison 是 Henry Stickmin 系列中的经典点击式冒险解谜游戏。玩家扮演被冤枉入狱的主角，需要通过一系列选择来逃离监狱。

游戏采用2D动画风格，画面简洁但充满幽默感。每个场景呈现一个困境（如牢房、走廊、狱警巡逻区），玩家需要在屏幕下方出现的2-4个选项中选择行动方案。每个选择会触发不同的动画结果——可能成功进入下一场景，也可能以搞笑的方式失败。

玩家的操作非常简单：只需点击屏幕上的选项按钮即可。但每个选择都至关重要，选错会导致主角以各种滑稽的方式失败（被狱警发现、触发警报、掉进陷阱等），然后需要回到选择点重新尝试。

游戏的主要目标是找到正确的选择序列来成功逃离监狱。游戏有多个分支路线和多种不同的结局（成功逃脱、被抓回、各种搞笑失败等）。失败条件：做出错误的选择导致被狱警捕获或触发致命陷阱。

值得一提的是，Henry Stickmin 系列的这个作品后来被重制并收录进了 The Henry Stickmin Collection 中，在 Steam 上获得了极高评价，证明了其设计的优秀。

## 核心循环

观察场景 → 选择行动方案 → 观看动画结果 → 成功则进入下一场景 / 失败则重新选择 → 找到正确路线逃离监狱

## 核心机制

- **分支选择系统**: 每个场景提供2-4个选项，每个选项对应不同的动画和后续路径。正确的选择通往下一关，错误的选择导致搞笑的失败动画。这种"试错-学习"的循环是核心体验。
- **多结局设计**: 游戏有多条路线可以通关，每条路线有不同的过程和结局。收集所有结局是游戏的重要目标之一，增加了重复游玩价值。
- **喜剧式失败**: 失败不是惩罚而是娱乐——每次失败都会播放一段精心制作的搞笑动画，让玩家即使选错了也会忍不住笑。这降低了挫败感，鼓励继续尝试。
- **线索推理**: 部分场景需要玩家根据环境线索推断正确选项，而非盲目试错。增加了推理和解谜的乐趣。

## 为什么好玩

最大的乐趣在于"选错了也比选对了有意思"——每个失败动画都像一段精心制作的喜剧短片。主角 Henry 面无表情的搞笑反应和荒诞的失败方式让人欲罢不能。同时，找到正确路线通关时的成就感也很强，因为正确的选择往往出人意料却又合情合理。

## 粘性来源

多结局收集是最主要的粘性来源——"还差3个结局就全收集了"让人不断重试。每个搞笑的失败动画本身就值得观看，降低了失败的负面情绪。选择分支的"如果当时选了另一个会怎样"的好奇心也驱动着反复尝试。

## Meta 系统

结局收集系统——游戏记录玩家解锁的所有结局和失败方式。收集全部结局是游戏的主要Meta目标，部分隐藏结局需要特定的选择序列才能解锁。

## 实现难度

低——本质上是状态机驱动的点击冒险游戏，每条选择路线预先制作好动画和场景切换。最大技术难点在于动画制作的创意和数量（需要制作大量不同的失败动画），而非技术实现本身。
