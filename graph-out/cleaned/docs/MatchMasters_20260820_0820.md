# 消除大师（Match Masters）

- **类型**: 三消 / 对战竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: Candivore LTD
- **首次发布**: 2019
- **一句话描述**: 实时PvP三消对战，两个玩家在同一棋盘上竞速消除，先达成目标者获胜

## 玩法规则

Match Masters 的核心是实时对战三消。两名玩家共享同一个棋盘布局，各自在自己的棋盘上进行消除操作。

每轮比赛中，玩家在限定时间内（通常约60秒）尽可能多地进行消除。消除三个同色宝石获得基础分，消除四个或更多获得更高分数和特殊能力（如炸弹、火箭等）。

特殊能力可以对对手的棋盘产生负面效果——例如在对手棋盘上放置障碍物、随机消除对手的部分宝石、或打乱对手的部分区域。

比赛采用回合制或实时竞速制。先达到目标分数或在时间结束时分数更高的玩家获胜。连胜会积累连胜奖励和排位积分。

玩家还可以组队参与团队赛，队伍成员的分数累计决定团队胜负。

## 核心循环

消除宝石得分 → 获得特殊能力攻击对手 → 率先达标获胜 → 获取奖励和排位积分

## 核心机制

- **实时对战三消**: 将传统单机三消转变为竞技对抗，同一棋盘布局下玩家竞速消除，加入心理博弈——何时使用特殊能力攻击对手
- **能力干扰系统**: 消除产生的特殊能力可以对对手棋盘产生干扰（放置障碍、打乱顺序、冻结宝石），增加竞技深度和策略选择
- **连胜奖励机制**: 连续胜利积累额外奖励，鼓励玩家持续对战。排位系统根据胜负记录调整匹配对手水平

## 为什么好玩

传统三消的爽感加上对抗的紧张感，"我要消除得比你快"的竞争冲动非常强烈。使用特殊能力干扰对手棋盘时的"复仇快感"是单机三消没有的体验。

## 粘性来源

PvP竞争驱动——没有人想在三消对战中输给陌生人；排位积分和连胜纪录提供长期目标；团队赛增加社交粘性；每局时间短（1-2分钟），随时可以再来一局。

## Meta 系统

排位系统：根据胜负记录匹配同级别对手。团队（公会）系统允许组队参加团队赛。宝箱和卡牌收集系统提供额外成长感（卡牌赋予被动加成）。

## 实现难度

中。三消引擎本身简单，但实时PvP需要处理网络同步、延迟补偿、防作弊等。最大技术难点是保证两个玩家棋盘状态的一致性和公平性。
