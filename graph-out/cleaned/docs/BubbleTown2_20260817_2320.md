# 泡泡小镇2（Bubble Town 2）

- **类型**: 泡泡射击
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Absolutist
- **首次发布**: 2010
- **一句话描述**: 经典泡泡射击消除游戏的续作，加入了小镇建设元素。

## 玩法规则

游戏画面分为上下两部分：上方是悬挂的彩色泡泡群，下方是发射器（可以左右旋转瞄准）和当前泡泡颜色。
玩家通过调整发射角度，发射彩色泡泡到上方的泡泡群中。当三个或更多相同颜色的泡泡相连时，它们会消除并从画面上掉落。
如果一个泡泡因为上方的支撑泡泡被消除而失去了所有连接（悬空），它也会掉落。利用这种连锁效应可以用一次射击消除大量泡泡。
发射器会预告下一个泡泡的颜色（Next泡泡），玩家需要根据预告颜色规划射击策略。
某些泡泡有特殊效果：炸弹泡泡（消除周围所有泡泡）、彩虹泡泡（可以匹配任何颜色）、冰块泡泡（需要击中两次才能消除）。
游戏目标：清除所有泡泡或阻止泡泡群下降到底线。泡泡群会逐渐下降，如果到达底线则游戏结束。消除泡泡获得积分，积分可以用于建设小镇。

## 核心循环

观察泡泡群布局 → 瞄准并发射泡泡 → 消除同色泡泡组 → 利用连锁效应清除更多 → 收集积分建设小镇

## 核心机制

- 物理反射弹道：泡泡沿直线飞行并在墙壁上反弹，可以利用反弹角度击中难以直接瞄准的位置
- 连锁消除：通过消除关键支撑泡泡让大片泡泡悬空掉落，一次射击产生连锁反应的满足感极强。找到那个'关键泡泡'需要观察力和耐心
- 小镇建设进度：消除获得的积分用于建设小镇，提供了一个长期的进度目标，让单纯的消除游戏多了一层意义

## 为什么好玩

当一次精准射击触发连锁反应，大片泡泡同时掉落时的视觉效果和成就感非常爽快。
小镇建设元素让单纯的消除游戏多了一个长期目标，每次消除都在为小镇添砖加瓦。

## 粘性来源

'差一个泡泡就能清除这片区域'的不甘心、小镇建设的进度驱动、以及特殊泡泡带来的偶然性惊喜。

## Meta 系统

小镇建筑解锁和升级、关卡递进、每日挑战。

## 实现难度

低 — 核心是泡泡的物理弹道和颜色匹配算法。主要技术难点在于悬空检测（需要图搜索算法判断泡泡是否仍有连接）和反弹轨迹计算。

游戏还包含计时模式：在限定时间内尽可能多地消除泡泡获得高分。高分可以解锁特殊建筑装饰和小镇外观。某些关卡有步数限制而非时间限制，要求在有限射击次数内完成清除。
