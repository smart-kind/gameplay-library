# Bejeweled

- **类型**: 三消 / 益智
- **平台**: Mobile (iOS+Android) / PC / Web / Console
- **开发商**: PopCap Games
- **首次发布**: 2000
- **一句话描述**: 玩家交换相邻宝石，三个或更多相同宝石连成一线时消除，持续获得分数

## 玩法规则

游戏画面是一个8x8的方格棋盘，上面随机排列着7种不同颜色和形状的宝石。这是三消类游戏的鼻祖。

玩家操作：
- 交换：选择相邻的两个宝石（横或竖），交换它们的位置
- 匹配：交换后如果三个或更多相同颜色的宝石连成一线，这些宝石被消除
- 填补：消除后上方的宝石下落，新的宝石从顶部补充

游戏目标：持续获得分数，直到没有可用移动为止。

核心规则：
- 只有能形成匹配的交换才有效
- 三个宝石消除获得基础分数
- 四个宝石消除产生特殊宝石（火焰宝石、星爆宝石）
- 五个宝石连成一线产生超级宝石（可以消除所有同色宝石）
- 连锁消除（一次交换触发多组消除）分数倍增

游戏结束条件：
- 没有可用的有效移动时游戏结束（经典模式）
- 时间用完（限时模式）
- 宝石堆到顶部（禅模式无结束）

## 核心循环

交换宝石 → 匹配消除 → 获得分数 → 寻找下一次交换

## 核心机制

- **三消核心**: 交换相邻宝石使三个或更多同色宝石连成一线，简洁而深度的核心机制
- **特殊宝石**: 四个宝石消除产生火焰宝石（消除十字形范围），五个产生星爆宝石（消除所有同色宝石）
- **连击系统**: 连锁消除分数倍增，鼓励玩家寻找能触发连锁的交换
- **多种模式**: 经典模式（无尽得分）、限时模式（时间压力）、禅模式（放松无压力）、扑克模式（特殊规则）

## 为什么好玩

简单操作下的深度策略。找到能触发连锁消除的交换位置时的满足感极强。特殊宝石的产生和使用带来大招般的爽快感。音效和视觉反馈精致。

## 粘性来源

再玩一把效应，每局游戏独立，输了立刻想重试。高分竞争和特殊宝石收集是主要驱动力。多种模式满足不同心情。

## Meta 系统

通常无外围成长系统。部分版本有成就系统或得分排行榜。

## 实现难度

低。核心是匹配算法和棋盘状态管理。技术难点在于确保每关有解和动画流畅度。
