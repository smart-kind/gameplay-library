# Gridd 2

- **类型**: 解谜 / 网格
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款极简风格的网格解谜游戏，玩家通过在网格中填充不同形状和颜色的方块来解决逻辑谜题

## 玩法规则

游戏呈现一个空白的网格棋盘（从4x4到10x10不等）。每关提供一组不同形状的方块（类似俄罗斯方块的多格骨牌）。

玩家通过拖拽将方块放置到网格中的指定位置。放置后方块锁定，不能移动。某些方块可以旋转90度或翻转，增加放置的灵活性。

关卡给出约束条件：某些格子必须填充特定颜色，某些格子必须留空，某些方块必须相邻放置，某些形状不能出现在特定区域等。满足所有约束条件即过关。

随着关卡推进，网格变大，约束条件更复杂（多重要求叠加），方块形状更不规则。部分关卡有时间模式，要求在限定时间内完成。后续关卡引入多层网格概念。

游戏采用极简黑白配色方案，视觉焦点完全集中在解谜逻辑上。部分关卡引入对角线约束，增加新的解题维度。

## 核心循环

观察约束条件 → 合理放置方块到网格 → 满足所有条件过关

## 核心机制

- **约束叠加**：每关多重要求同时满足，考验综合推理能力
- **方块旋转/翻转**：增加放置的灵活性但也增加决策空间
- **时间模式**：限时完成增加紧迫感

- **对角线约束**：部分关卡要求对角线上的格子也满足特定条件

## 为什么好玩

极简美学配合严密的逻辑设计，解出谜题的顿悟感是核心体验。每关约束条件的巧妙组合让解谜过程充满挑战。

## 粘性来源

逻辑谜题的标准粘性：每关解出后解锁下一关的进度感，以及'再试一关'的心理驱动。

## Meta 系统

无。纯解谜。

## 实现难度

中 — 需要逻辑推理能力。最大技术难点是约束条件的生成和验证。
