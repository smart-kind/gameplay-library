# Speedthru Potzols Puzzle（Speedthru Potzols Puzzle）

- **类型**: 拼图 / 方块消除
- **平台**: Mobile (iOS+Android)
- **开发商**: 待确认
- **首次发布**: 约2012
- **一句话描述**: 一款六边形方块消除益智游戏，玩家需要将不同形状的方块填入网格中以消除行或列

## 玩法规则

游戏界面中央是一个六边形网格棋盘，棋盘由多个正六边形格子组成。每回合开始时会生成3-4个不同形状的方块供玩家放置，这些方块出现在棋盘下方的预览区域。

每个方块由若干个小六边形连接而成，形状各异——有直线形（2-5格连成一线）、L形、T形、十字形、Z形等。方块的形状和数量每回合随机生成。

玩家需要用手指拖拽方块到棋盘的空白区域放置。放置后，系统立即检查是否有完整的行被填满——在六边形网格中，"行"指的是沿六个方向之一的连续格子被全部占据。当一行被填满时，该行所有方块同时消除并得分。

如果所有当前回合生成的方块都无法放入棋盘的剩余空间，游戏立即结束。因此玩家需要在放置时考虑空间利用效率：不仅要消除行得分，还要为后续方块预留足够的空间。

消除行数越多，得分越高。连续消除多行可以获得连击加分。某些特殊方块（如带有炸弹标记的方块）在被消除时会触发范围消除效果，清除周围多个格子。

游戏采用"无尽模式"——没有关卡限制，玩家持续放置方块直到无法继续。最终得分取决于消除的行数、连击次数和特殊消除效果。游戏提供每日挑战模式，所有玩家从相同的方块序列开始，比较谁能获得更高分数。

## 核心循环

完成关卡或日常任务 → 获得评分、经验或游戏货币 → 升级角色能力或解锁新内容 → 挑战更高难度的关卡或模式

## 核心机制

- **渐进难度设计**：关卡难度从简单到复杂逐步递增，每个新关卡引入1-2个新机制或变化，确保玩家在适应当前难度的同时学习新玩法。
- **即时反馈系统**：每次操作后系统立即给出视觉和音效反馈（命中特效、得分弹出、连击计数），强化操作的成就感和爽快感。
- **资源约束机制**：玩家的操作次数、时间或生命值有限，需要在约束条件下做出最优决策，增加了策略深度。
- **评价与重玩驱动**：1-3星评级系统鼓励玩家在通关后反复挑战以获得更高评价。

## 为什么好玩

这款游戏通过简洁直观的操作方式和逐步提升的难度曲线，让玩家在每次尝试中都能获得明确的进步感。关卡设计的多样性确保了长时间游玩不会感到重复乏味，而即时反馈系统则让每次操作都充满满足感。
