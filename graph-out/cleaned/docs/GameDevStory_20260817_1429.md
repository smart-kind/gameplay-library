# Game Dev Story

- **类型**: 模拟经营
- **平台**: iOS+Android
- **开发商**: Kairosoft
- **首次发布**: 2010
- **一句话描述**: As I write this I&rsquo;m very angry at Kairosoft, developer of Game Dev Story. Not because it&rsquo;s produced a bad game &ndash; far from it &ndash;

## 玩法规则

游戏画面采用像素风格俯视角办公室模拟布局。玩家作为游戏开发公司的社长，管理一个逐步扩大的开发团队。

玩家能做什么操作：
- 点击空位雇佣不同类型的员工（程序员、编剧、设计师等），每个员工有独特的能力值和成长曲线，雇佣后需要安排工位
- 点击"开发游戏"按钮启动新项目，选择游戏类型（RPG、冒险、模拟、解谜、动作等）和主题方向（幻想、科幻、历史、忍者等）
- 在游戏开发过程中，分配开发精力到四个维度：程序、画面、音效、游戏性，每个维度的投入会消耗开发点数
- 应对开发过程中的随机事件：员工灵感爆发会提升某项数值、遇到技术难题会消耗额外时间、加班决定影响员工士气
- 用赚到的金币购买办公室扩建、升级家具（提升员工能力）、参加游戏展获取灵感、给员工加薪留住核心人才

游戏目标：从小办公室起步，逐步发展成为业界顶级游戏公司。追求开发出让玩家疯狂的游戏，赢得游戏大奖，培养传奇员工，解锁所有游戏类型和主题组合。游戏没有强制结束条件，属于开放式经营体验。
当连击数积累到足够高时，能研发出独特的隐藏组合类型（例如"忍者+RPG"），这是游戏的核心惊喜点。

## 核心循环

招募员工 -> 开发游戏 -> 获得评价和销量 -> 升级办公室和研发更强游戏 -> 解锁新类型组合 -> 开发更爆款

## 核心机制

- 员工养成系统：雇佣不同职业的开发人员（程序员、编剧、设计师），每个职业有独特的基础能力值（编程/脚本/画面/音效）。通过培训和实际开发项目提升等级，高级员工可以转职为更强的专家职业
- 游戏开发四维度：每款游戏需要在程序、画面、音效、游戏性四个维度分配开发点数。不同游戏类型对不同维度的权重不同，合理分配才能获得高评价
- 硬件世代迭代：游戏内年份推进会带来硬件升级，从早期8位机到现代主机，新硬件支持更复杂的游戏类型和更高的画面要求
- 连击Combo系统：连续开发出好评游戏会累积连击数，连击达到阈值时解锁隐藏的游戏类型和主题组合，这些组合能产生爆款效应
- 经营成长循环：赚来的金币用于扩建办公室（容纳更多员工）、购买高级家具（提升员工能力）、参加游戏展（获得灵感和粉丝）、员工加薪（防止跳槽）

## 为什么好玩

经营成长的成就感是核心吸引力。从一个只有几个人的小办公室起步，通过策略决策逐步壮大成为业界巨头，每一步升级都能看到明确的正反馈。资源分配和规划布局带来持续的思考乐趣，特别是当自己开发的组合类型打出高评价时的满足感无可替代。连击系统和隐藏组合类型提供了深度探索的动力，让老玩家也能不断发现新内容。像素画风复古可爱，配合轻松的音乐营造出舒适的游戏氛围。

## 粘性来源

数值成长的持续正反馈驱动反复游玩：每一次升级、解锁新游戏类型组合都让玩家感到进步。隐藏组合类型的发现驱动（"还有什么组合我没试过？"）是核心粘性来源。追求满分评价和传奇难度的长期目标。员工成长带来的情感连接（看着自己培养的员工成为传奇开发者）。

## Meta 系统

- 科技树/解锁系统：随着游戏进度解锁新的游戏类型和主题组合，形成丰富的搭配可能性
- 员工转职系统：员工达到一定等级可以转职为更强力的专家职业，提供不同的能力加成
- 难度升级：通关后解锁Super难度，挑战更高的评价和更难的开发环境
- 游戏展系统：定期参加游戏展获得灵感、提升粉丝数量和获取媒体评价

## 实现难度

中 -- 需要实现完整的经济系统（收入/支出平衡）、员工AI行为模拟、游戏开发的随机事件系统、连击系统的状态追踪。最大的技术难点是经济系统的数值平衡，确保游戏节奏既不会太快无聊也不会太慢挫败，以及随机事件的概率分布调优。此外，隐藏组合类型的触发条件需要精心设计以避免过早暴露或永不可达。
