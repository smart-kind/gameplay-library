# 管道连接：桥梁（Flow Free: Bridges）

- **类型**: 益智 / 连线
- **平台**: Mobile (iOS + Android)
- **开发商**: Big Duck Games LLC
- **首次发布**: 2012
- **一句话描述**: 将相同颜色的圆点用管道连接起来且不交叉的经典益智游戏，桥梁版本增加了管道交叉的创新机制

## 玩法规则

游戏画面呈现一个网格棋盘，上面有若干对相同颜色的圆点。玩家需要用手指从一种颜色的圆点滑向同色的另一个圆点，画出一条路径将两个圆点连接起来。

规则要求：所有颜色对都必须连接、管道不能交叉（除非使用桥梁机制）、最终棋盘上不能有空白格子（完美通关）。每对颜色之间用不同颜色的管道连接，视觉上清晰可辨。

桥梁版本的独特之处在于引入了"桥梁"——允许两条管道在特定位置交叉通过，一条从桥上过、一条从桥下过。桥梁位置是预先标记的，玩家可以将管道铺设在桥梁上来实现交叉。

操作方式：手指从一个圆点拖向同色圆点画出路径、点击已画路径可以撤销、长按管道可以擦除重画。每步操作即时生效。

游戏目标是用最少的移动完成所有连接，同时争取完美通关（不留空白格子）。每个关卡有多个星级评定。

## 核心循环

观察棋盘 → 规划路径 → 连接颜色对 → 检查是否留有空白 → 优化路径 → 通关下一关

## 核心机制

- **路径规划**：每对颜色的连接路径不能与其他管道交叉（除桥梁外），需要在有限的网格空间内合理安排所有路径
- **桥梁机制**：预标记的桥梁位置允许管道交叉，增加了策略维度——需要判断哪条管道应该走桥梁、哪条走地面
- **完美通关挑战**：不留空白格子要求路径填满整个棋盘，这需要精确的空间规划
- **渐进难度**：从小棋盘（4x4）到大棋盘（10x10以上），从少量颜色到大量颜色，逐步增加复杂度

## 为什么好玩

连线游戏的魅力在于"看到解法"那一瞬间的豁然开朗——看似不可能的棋盘布局在经过思考后找到唯一解法，成就感极强。桥梁机制让原本不可能的交叉变成可能，增添了新的思考层次。

## 粘性来源

完美通关的收集欲（"这关我还没拿到完美三星"）、关卡数量的海量积累、从简单到困难的自然难度曲线让人不知不觉玩了很多关。

## Meta 系统

关卡包系统：游戏包含多个关卡包，每个包有数十个关卡，按难度递进排列。累积通关解锁新关卡包。

## 实现难度

低。网格路径绘制和交叉检测逻辑简单。最大技术难点是大棋盘上路径规划的求解验证（需要确保关卡有解且解不唯一以保持趣味性）。
