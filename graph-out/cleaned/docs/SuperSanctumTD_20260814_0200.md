# Super Sanctum TD（超级圣域塔防）

- **类型**: 塔防 / 第一人称射击混合
- **平台**: PC / Mobile
- **开发商**: Coffee Stain Studios
- **首次发布**: 2013
- **评分**: Coffee Stain Studios出品塔防游戏
- **一句话描述**: 将塔防策略与第一人称射击结合的独特游戏——先在第一人称视角下建造防御塔和路径，然后在第三人称视角下亲自参战

## 玩法规则

游戏的核心创新在于将两种看似不相关的玩法融合在一起：塔防策略和第一人称射击。

游戏分为两个阶段。第一阶段是"建造阶段"——玩家以第一人称视角在3D地图上规划和建造防御设施。与传统的俯视角塔防不同，玩家需要在3D空间中放置炮塔、陷阱和路障。

玩家可以设计敌人的进攻路径——通过放置路障和墙壁来引导敌人走特定的路线，使其暴露在更多防御塔的火力之下。这是塔防游戏的核心策略元素。

第二阶段是"战斗阶段"——玩家从第一人称视角切换到第三人称视角，拿起武器亲自加入战斗。玩家自己的攻击力和防御设施共同抵御敌人的进攻波次。

敌人波次逐渐增强，从简单的近战单位到装甲单位和飞行单位。玩家需要不断调整防御策略，升级现有设施，并在战斗中利用自己的射击技巧来弥补防御的不足。

## 核心循环

在3D地图上建造防御设施 → 设计敌人路径 → 亲自参战抵御敌人波次 → 获得资源升级防御 → 面对更强的敌人

## 核心机制

- **双阶段玩法**：建造阶段(策略规划) + 战斗阶段(动作射击)，两种玩法交替进行
- **3D路径设计**：在三维空间中设计敌人的进攻路线，比2D塔防有更多维度
- **亲自参战**：玩家不仅是旁观者，也是战斗的参与者，自己的射击技巧直接影响战局
- **设施升级系统**：用获得的资源升级现有防御设施，提升火力和范围
- **敌人类型多样化**：从普通步兵到重装单位再到飞行单位，需要不同的防御策略

## 为什么好玩

Super Sanctum TD的独特之处在于打破了塔防游戏"建完就看着"的传统模式。玩家的直接参与让每场战斗都有操作感——你可以用精准的射击消灭漏网之鱼，也可以在危急时刻亲自上阵守住防线。第一人称建造+第三人称战斗的视角切换也带来了独特的沉浸感。

## 粘性来源

(1) **双玩法的多样性**——策略+动作的结合避免了单一玩法的疲劳；(2) **路径设计的创造性**——每次都可以尝试不同的路径和防御布局；(3) **亲自战斗的参与感**——不是被动观看而是主动参与；(4) **逐步升级的成就感**——防御设施和自己角色的双重成长

## Meta 系统

- **关卡/战役推进**：多关卡的战役模式，逐步解锁新武器和设施
- **武器/设施解锁**：通过游戏进程获得新的防御设施和武器类型

## 实现难度

**高** — 需要同时实现3D塔防系统和FPS/TPS射击系统。技术难点在于两个系统的无缝衔接、3D路径finding算法、以及大规模敌人波次的性能优化
