# 恶霸鲁尼（Bully）

- **类型**: 开放世界 / 冒险 / 动作
- **平台**: Mobile (iOS+Android) / PlayStation / Xbox
- **开发商**: Rockstar Vancouver
- **首次发布**: 2006
- **一句话描述**: 一款校园题材的开放世界动作冒险游戏，玩家扮演15岁的吉米·霍普金斯，在布尔斯沃斯学院这个充满派系斗争

## 玩法规则

游戏采用第三人称视角，玩家在校园和周边城镇中自由探索。核心玩法围绕上课、完成任务、与不同派系互动展开。

上课小游戏是独特机制——每门课程（英语、化学、艺术、体育等）都是一个独立的小游戏，完成课堂表现会获得特殊能力（如化学课让你能制作恶作剧道具）。

战斗系统简单但有趣——拳头、弹弓、鞭炮、臭蛋等校园风格武器。战斗有连击系统和闪避机制。不同场景有不同的战斗规则——课堂上打架会被教导主任追，而在巷战中可以自由战斗。

## 核心循环

上课获得能力 → 完成任务推进剧情 → 与各派系建立/破坏关系 → 统一校园

## 核心机制

- 上课小游戏系统：每门课程是一个独特的迷你游戏——英语课是单词拼写、化学课是配药、艺术课是绘画、体育课是运动。这种设计让'上学'这件事本身变得有趣，同时将学习与游戏能力直接挂钩。

- 派系系统：校园内有多个派系（书呆子、运动员、预科生、小混混等），每个派系有独立的好感度。与某派系友好会遭到另一派系的敌视，制造了有趣的社交动态。

- 恶作剧系统：可以制作各种恶作剧道具（鞭炮、臭蛋、泻药等），这些不仅是武器，也是推进任务的手段。道具制作与化学课学到的知识直接相关。

- 校园生态模拟：NPC有独立的日程表——上课、吃饭、睡觉、课外活动。校园在不同时间呈现不同的面貌，增强了世界的真实感。

## 为什么好玩

将'讨厌上学'的童年感受转化为游戏乐趣——上课变成了有趣的小游戏，恶作剧成了合法行为，校园里的社交等级成了可以操控的系统。对校园生活的高度还原让每个玩家都能找到共鸣。

## 粘性来源

派系统一的目标驱动 + 课程逐步解锁的成就感 + 恶作剧的趣味性 + 校园探索的好奇心。上课小游戏的多样性让核心玩法保持新鲜。

## Meta 系统

课程进度 + 派系好感度 + 服装收集 + 成就系统。随着课程推进获得新的恶作剧能力和工具，派系统一后解锁新的区域和任务。

## 实现难度

中 — 开放世界 + 多系统交互（派系、课程、恶作剧），代码层面需要管理复杂的NPC日程和派系关系。最大的技术难点是平衡多个派系的好感度系统和确保开放世界中任务的连贯性。
