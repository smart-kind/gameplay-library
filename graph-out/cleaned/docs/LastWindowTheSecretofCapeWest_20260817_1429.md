# Last Window: The Secret of Cape West

- **类型**: 冒险/解谜
- **平台**: DS
- **开发商**: Cing
- **首次发布**: 2010
- **一句话描述**: It's been a bumpy year for fans of the whodunit puzzler Hotel Dusk. First a sequel was announced in March, then there was speculation that we wouldn't

## 玩法规则

游戏画面采用2D像素美术风格，场景以公寓大楼内部和周边环境为主要舞台。本作是Hotel Dusk的精神续作，由Cing开发，充分发挥了Nintendo DS双屏和触控的特性。

玩家能做什么操作：
- 在场景中移动调查：通过触控笔点击场景中的各个物品和区域进行调查，发现隐藏的线索和关键道具
- 与NPC对话：选择不同的对话选项获取不同信息，部分选择会影响NPC的信任度，从而影响后续可获取的信息量
- 在关键时刻做出推理判断：系统会给出几个推理选项，需要基于已收集的线索选择正确的推理方向
- 管理收集到的线索：在笔记本（下屏显示）中查看已收集的证据、人物关系图和事件时间线
- 在限时场景中做出快速决策：部分关键场景有倒计时，需要在有限时间内找到关键线索或做出正确选择

游戏目标：解开Last Window公寓背后的秘密和一系列相关谜团，逐步还原完整的故事真相。
游戏没有传统意义上的失败条件（不会Game Over），但错误的推理会导致错过部分剧情内容，影响最终真相的完整度。

## 核心循环

调查线索 -> 推理分析 -> 揭开真相 -> 推进剧情 -> 发现更深层秘密

## 核心机制

- 场景调查系统：在每个场景中点击可疑的物品和区域进行调查，发现隐藏线索、关键道具和隐藏信息
- 分支对话树：与NPC对话时有多种问题选项，不同的提问顺序和内容会影响获取的信息量和NPC的信任度
- 推理判定系统：在关键时刻需要从多个推理选项中选择正确的方向，错误选择不会导致Game Over但会错过部分剧情内容
- 多视角叙事：游戏从不同角色的视角展开，每个角色有自己的故事线和获取的独特信息
- DS双屏设计：上屏显示主场景和对话，下屏显示笔记本（线索整理）、地图和触控操作

## 为什么好玩

叙事驱动的解谜体验让玩家沉浸在引人入胜的故事世界中。每个线索的发现和推理的验证都带来智力上的满足感。多线叙事和角色互动增加了探索的驱动力，想知道"接下来会发生什么"是持续游玩的最大动力。复古像素美术配合悬疑氛围营造出独特的游戏体验。

## 粘性来源

叙事悬念驱动：想知道故事结局是持续游玩的最大动力。解谜的智力满足感：每个推理正确的时刻都带来成就感。收集线索的探索乐趣：不放过任何细节的强迫感。多视角叙事的拼图效应让玩家想看到完整的故事。

## Meta 系统

- 章节解锁：完成当前章节解锁下一章，推进主线剧情
- 隐藏要素：场景中隐藏的可收集物品和彩蛋，增加探索价值
- 多结局系统：根据关键选择和推理准确度可能触发不同的结局分支
- 成就系统：完成特定推理链或发现所有隐藏线索获得成就

## 实现难度

高 -- 需要实现复杂的叙事系统、分支对话树、线索收集和管理、推理判定逻辑。最大的技术难点是叙事内容的脚本化管理和多分支剧情的状态追踪。每个线索、每个对话选项都需要精确的条件判定，确保剧情的连贯性和逻辑性。
