# Hades（黑帝斯）

- **类型**: Roguelike动作 / 独立游戏
- **平台**: PC / Mobile (iOS+Android) / Switch / PS / Xbox
- **开发商**: Supergiant Games
- **首次发布**: 2020
- **一句话描述**: 以希腊神话为背景的Roguelike动作游戏，玩家扮演冥王之子扎格列欧斯，一次次尝试逃离冥界，每次死亡后故事继续推进。

## 玩法规则

游戏为俯视角2.5D动作游戏，玩家在每个房间选择战斗、奖励或事件，逐步向上层推进。战斗节奏极快，玩家需要实时移动、攻击、闪避和使用特殊技能。

每个房间是固定布局的战斗场景，清除所有敌人后获得奖励并选择下一个房间的方向。房间类型包括：战斗房（击败所有敌人）、精英房（强力Boss）、Boss房（每层关底）、奖励房（选择奥林匹斯神的祝福）。

武器有六种形态，每种有独特的攻击模式和特殊攻击。玩家通过"黑暗"（永久货币）解锁武器能力和升级属性。每次逃离尝试中，玩家获得奥林匹斯众神的祝福（被动增益），不同祝福之间可以产生"双重祝福"（特定组合的额外效果）。

死亡不是结束——回到冥界大厅后可以用收集的资源升级永久能力、解锁新剧情对话、改善起始装备。每次死亡后NPC会有新的对话，故事随死亡次数推进。

## 核心循环

进入下一房间 → 战斗获得祝福 → 选择路线 → 挑战Boss → 死亡后升级永久能力 → 带着更强能力重新开始

## 核心机制

- **祝福系统（Boons）**：每次战斗后从多位奥林匹斯神中选择祝福，每种祝福给武器或能力添加元素效果（如宙斯的雷电、雅典娜的反弹、波塞冬的击退）。不同神的祝福组合产生"双重祝福"，创造无限build可能。
- **武器系统**：6种基础武器各有4种隐藏形态，每种形态改变攻击方式和特殊攻击。武器的选择和升级是长期进度核心。
- **契约惩罚**：通关后可以签订"惩罚契约"增加游戏难度（如敌人更强、起始血量更少、房间奖励更差），但提供更高的分数和成就。这为高手提供了可调节的挑战空间。

## 为什么好玩

死亡不再是"Game Over"而是故事的一部分——每次回到冥界，角色们会说新的话、推进新的剧情。战斗本身也极度爽快，高速移动+华丽特效+多样祝福组合让每次逃离都有不同的体验。

## 粘性来源

- **剧情推进**：死亡推动故事发展，想解锁所有对话和剧情线
- **Build多样性**：武器×祝福×双重祝福的组合空间极大，每次都是新体验
- **契约系统**：通关后可以通过增加难度来持续挑战自己
- **成就和音乐解锁**：收集要素丰富，音乐和艺术本身就是奖励

## Meta 系统

- **暗夜镜**：冥界大厅中的永久升级系统，用"黑暗"解锁起始加成（额外生命、额外金钱、额外复活机会等）
- **武器升级**：用材料升级武器解锁新形态和能力
- **好感度**：给NPC赠送花蜜和仙酒提升好感，解锁额外内容和对话
- **对核心玩法的影响**：永久升级让新玩家更容易上手，但高手可以通过契约抵消这些加成保持挑战

## 实现难度

高 + 快节奏动作游戏需要优秀的战斗手感、流畅的动画、丰富的敌人AI和精确的碰撞检测。最大难点是祝福系统的平衡——数百种祝福和双重祝福组合需要确保没有绝对无敌的build，同时每种组合都有趣。剧情和语音内容的量也很大。
