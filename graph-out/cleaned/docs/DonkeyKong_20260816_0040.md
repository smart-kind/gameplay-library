# 大金刚（Donkey Kong, 1981）

- **类型**: 平台跳跃 / 街机
- **平台**: 街机 / NES / Game Boy / 多平台移植
- **开发商**: Nintendo
- **发行商**: Nintendo
- **首次发布**: 1981
- **一句话描述**: 操控水管工马里奥攀爬梯子和平台，从巨大猩猩大金刚手中营救宝琳的经典街机游戏

## 玩法规则

游戏画面为一个固定视角的建筑工地场景，由多层平台、梯子和斜坡组成。屏幕底部是玩家控制的角色马里奥（当时尚未正式命名，称为"Jumpman"），屏幕顶部是大猩猩大金刚和被他劫持的宝琳。

玩家通过摇杆控制马里奥左右移动，按跳跃键可以跳跃躲避障碍物。场景中有梯子可以上下攀爬，连接不同层的平台。大金刚会不断向马里奥投掷木桶，木桶沿平台和斜坡滚下，玩家需要跳跃或攀爬来躲避。除了木桶，后续关卡中还会出现火焰、弹簧等不同类型的障碍物。

游戏的核心操作就是"左右移动 + 攀爬梯子 + 跳跃"三者的组合，看似简单但要求精准的操作时机。玩家需要在不被障碍物击中的情况下，从屏幕底部一路到达顶部。

每一关的结构略有不同，但基本模式相同——躲避障碍到达顶部。全部关卡通过后循环回到第一关，但难度递增（障碍物速度更快、数量更多）。

## 核心循环

攀爬平台躲避障碍 → 到达顶部 → 进入下一关 → 难度递增 → 追求更高分数

## 核心机制

- **平台跳跃 + 攀爬组合**：马里奥可以左右移动、跳跃和攀爬梯子，三者组合形成了丰富的移动可能性。梯子不仅是垂直通道，也是躲避障碍的安全区域
- **障碍物模式化**：木桶沿固定路径滚动，火焰在固定位置闪烁，每种障碍物都有可学习的规律。掌握规律后可以找到最优路径
- **锤子道具**：场景中偶尔出现锤子道具，拾取后马里奥可以砸碎木桶获得额外分数，但持有锤子期间无法攀爬梯子，形成风险与收益的权衡
- **多关卡轮换**：游戏有 4 个不同的关卡结构循环出现，每一轮速度递增，形成"永无止境"的挑战模式

## 为什么好玩

作为平台跳跃游戏的鼻祖，Donkey Kong 确立了这一类型的基本范式。它的魅力在于"看似简单但极难精通"——每个操作都是基础的，但组合起来需要精准的时机判断。大金刚扔木桶的动画和马里奥躲避的紧张感在 1981 年的街机上是革命性的体验。它也是马里奥这个史上最著名游戏角色的首次亮相。

## 粘性来源

- **分数驱动**：躲避木桶、砸碎木桶、营救宝琳都有分数奖励，高分驱动玩家反复挑战
- **"差一点就过了"的不甘心**：每一关的失败往往只差几步，这种"差一点"的感觉强烈刺激再来一次的欲望
- **难度递增循环**：每轮循环后速度更快，给追求极限的玩家提供渐进式挑战
- **街机文化的社交性**：在街机厅排队等待、围观高手操作、竞争最高分，构成了强大的社交粘性

## Meta 系统

无。作为 1981 年的街机游戏，没有外围成长系统，每局都是独立的挑战，分数是唯一的进度记录。

## 实现难度

低。固定视角的 2D 平台跳跃，精灵动画简单（马里奥、木桶、梯子），物理系统仅涉及重力和碰撞检测。最大技术难点在于精确的碰撞判定——需要确保跳跃和攀爬的手感流畅，障碍物的运动轨迹可预测但具有挑战性。
