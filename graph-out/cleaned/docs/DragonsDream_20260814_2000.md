# Dragon's Dream (龙之梦境)

- **类型**: 解谜 / 休闲
- **平台**: Nintendo 3DS
- **开发商**: Nintendo
- **首次发布**: 2014
- **一句话描述**: 在梦境世界中解决谜题的3DS休闲解谜游戏

## 玩法规则

游戏发生在一个梦境般的奇幻世界中。玩家操控角色在各个梦境场景中移动，通过解决环境谜题来推进故事。

游戏界面以3DS双屏显示：上屏显示游戏场景，下屏显示操作界面和物品栏。玩家使用触控笔与场景中的物品互动，通过拖拽、点击和旋转来操作谜题元素。

每个场景包含多个互动元素，玩家需要观察它们之间的关系并找出正确的操作顺序。谜题类型包括配对、排序、路径连接和逻辑推理。

游戏目标是通过解决每个场景的谜题来推进故事，最终完成整个梦境冒险。

## 核心循环

观察场景 → 识别谜题 → 操作解谜 → 推进故事 → 进入新场景

## 核心机制

- **环境谜题系统**：谜题与场景元素紧密结合，需要观察和推理而非单纯反应
- **双屏交互**：利用3DS的双屏特性，上屏呈现、下屏操作，分工明确
- **渐进式难度**：谜题从简单到复杂逐步递进，每类谜题引入新的机制元素
- **梦境叙事**：通过谜题推进的非线性叙事，营造奇幻的梦境氛围

## 为什么好玩

轻松愉快的解谜体验配合梦幻的美术风格，适合碎片时间游玩。每个谜题类型都有独特的解决方式，不会感到重复。

## 粘性来源

轻松休闲的游玩节奏 + 每关谜题类型不同的新鲜感 + 梦境故事的好奇驱动 + 完成谜题的即时成就感

## Meta 系统

无

## 实现难度

低 — 基于触控的2D解谜游戏，最大技术难点在于谜题设计的趣味性和难度曲线控制
