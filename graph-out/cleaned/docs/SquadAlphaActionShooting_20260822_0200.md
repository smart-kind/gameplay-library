# 阿尔法小队 - 动作射击（Squad Alpha - Action Shooting）

- **类型**: 动作/射击
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2021
- **一句话描述**: 小队战术射击游戏

## 玩法规则

玩家控制一个小队进行战斗任务。通过虚拟摇杆移动，点击瞄准射击。小队成员自动跟随，可切换控制不同成员。任务目标包括消灭敌人、解救人质、拆除炸弹等。战斗中可拾取武器和补给。每关通关后获得经验值升级角色。游戏结合了射击和策略元素。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

接受任务 → 移动射击 → 完成目标 → 获得经验 → 升级角色

## 核心机制

- **小队控制**:  可切换控制不同小队成员
- **战术射击**:  结合射击和策略的团队作战
- **任务多样化**:  多种任务类型增加变化

## 为什么好玩

小队协同作战的战术深度，多样化的任务保持新鲜感

## 粘性来源

角色升级和装备收集；新任务解锁

## Meta 系统

角色升级和装备系统
