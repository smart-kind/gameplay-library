# Stick Wars 3

- **类型**: 策略塔防 / Strategy
- **平台**: Mobile (iOS+Android)
- **开发商**: Max Games Studios
- **首次发布**: 2012
- **一句话描述**: 一款在移动平台上发布的策略塔防类型游戏

## 玩法规则

火柴人风格的策略塔防游戏。画面横向布局，左侧为玩家基地，右侧为敌方基地。

玩家点击生产按钮创建不同类型的火柴人士兵（剑士、弓箭手、法师、巨人等），士兵会自动向右推进攻击敌方建筑和单位。同时玩家点击放置防御塔保护己方基地。

核心操作是资源分配：在进攻部队和防御建设之间平衡投入。每种兵种有独特的攻击方式——剑士近战、弓箭手远程、法师范围伤害。兵种之间有克制关系。

游戏目标是在敌方摧毁己方基地之前，推进并摧毁敌方基地。每关难度递增，敌人数量和种类逐渐增多。

## 核心循环

生产兵种 → 自动推进攻击 → 获取资源 → 生产更高级兵种 → 摧毁敌方基地

## 核心机制

- **兵种克制**：近战、远程、法师之间相互制约
- **资源管理**：在进攻和防御间分配有限资源
- **自动战斗**：放置后士兵自主战斗，玩家关注战略决策而非操作

## 为什么好玩

看着自己的火柴人军团推进敌方基地有种指挥千军万马的感觉。兵种搭配的战术深度和自动战斗的轻松感结合得很好。

## 粘性来源

兵种收集+升级的成长系统，每次战斗后获得更多资源解锁新兵种的期待感。自动战斗的轻松感适合碎片化时间。

## Meta 系统

- **兵种解锁**：通过战斗获得资源解锁新兵种
- **升级系统**：提升兵种属性和生产能力
- **对核心玩法的影响**：更多兵种选择增加战术组合深度

## 实现难度

中等——需要实现自动战斗 AI 和兵种克制逻辑。最大的技术难点是多单位同时战斗时的性能优化和 AI 决策效率（寻路、目标选择、技能释放时机）。
