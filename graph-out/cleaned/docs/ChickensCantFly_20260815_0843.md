# 小鸡不会飞（Chickens Cant Fly (Rocket Chicken)）

- **类型**: 跑酷 / 物理弹射
- **平台**: Mobile (iOS+Android)
- **开发商**: nanobitsoftware.com
- **首次发布**: 2012
- **一句话描述**: 一款物理驱动的跑酷游戏，控制一只试图逃离养鸡场的小鸡，借助火箭背包或地形弹跳来前进。

## 玩法规则

游戏画面为2D横版卷轴，小鸡自动向前奔跑，屏幕随机生成各种障碍（栅栏、坑洞、车辆）和弹跳点（山坡、蹦床）。

玩家只需单指点击屏幕控制小鸡跳跃，长按可以跳得更高。借助山坡等弹跳点可以实现远距离飞跃。点击炸弹可以借力跳得更远。

游戏中收集金币用于升级火箭背包和解锁新主题。每次飞行距离越远，得分越高。

游戏结束条件为小鸡撞到障碍物或落入坑洞。随着距离增加，障碍密度和速度都会提升。

## 核心循环

玩什么 → 得到什么 → 用来做什么：点击跳跃躲避障碍收集金币，升级火箭背包来挑战更远距离

## 核心机制

- **物理弹跳**：借助地形（山坡、蹦床）实现高难度飞跃，物理引擎让每次弹跳都有不可预测的趣味。弹跳角度和力度影响飞行轨迹
- **一键操作**：极简的点击跳跃控制，易于上手但难以精通。时机判断是关键，按早按晚效果完全不同
- **多主题系统**：14种不同主题场景，每个主题有独特的视觉风格和障碍物组合。解锁新主题带来新鲜感

## 为什么好玩

一只小鸡拼命逃跑的滑稽设定本身就很有趣。物理引擎带来的意外弹飞效果常常出人意料地搞笑，单指操作让任何人都能立刻上手。每次飞行都有独特体验。

## 粘性来源

差一点就能破纪录的执念驱动反复尝试 + 升级系统（新装备带来新能力）+ 主题收集。每次失败都觉得下次能更远。

## Meta 系统

- **火箭背包升级**：用收集的金币升级火箭背包的高度、飞行时间和燃料效率。升级后更容易跨越障碍
- **主题解锁**：达成距离里程碑解锁新主题场景，每个主题有独特美术风格
- **对核心玩法影响**：升级提供数值加成，但不改变核心操作机制。操作技巧仍是决定性因素

## 实现难度

低 — 单指点击操作极其简单，任何人都能快速上手。最大技术难点在于物理引擎的稳定性和障碍生成的节奏控制。需要确保在不同设备上物理表现一致。
