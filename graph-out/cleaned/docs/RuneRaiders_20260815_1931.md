# Rune Raiders

- **类型**: 动作 / 解谜 / 冒险
- **平台**: Nintendo DS
- **开发商**: Renegade Kid
- **首次发布**: 2010
- **一句话描述**: 第一人称视角的3D动作解谜游戏，在神秘的地牢中探索并解决符文谜题。

## 玩法规则

游戏采用第一人称视角，3D渲染的地牢环境。玩家在迷宫般的地下城中探索，使用触控笔和DS的上下屏幕。

操作方式：
- **触控笔点击屏幕**：控制移动方向（点击屏幕上的箭头或直接点击想去的位置）。
- **触控笔滑动**：切换视角，观察周围环境。
- **下屏幕显示地图**：实时更新的迷你地图，标注已探索区域和关键标记。
- **上屏幕显示3D第一人称画面**：玩家看到的地牢场景。
- **互动按钮**：与场景中的符文石板、机关、门等互动。

地牢中有多种符文石板需要解谜——每个符文石板显示一组符号，玩家需要找到正确的排列方式或匹配图案来激活机关、打开门或触发事件。解谜线索散布在地牢各处（墙壁上的符号、物品上的标记等）。

地牢中有敌人（石像鬼、幽灵、骷髅等），靠近后会触发战斗。战斗通过触控笔快速点击敌人来完成，部分敌人需要特定的攻击模式或解谜才能击败。

## 核心循环

探索地牢 → 发现符文谜题 → 解谜获取线索 → 打开新区域 → 面对更强的敌人 → 继续深入

## 核心机制

- **第一人称探索**：DS上少见的第一人称3D探索体验，上下屏分别显示地图和场景，提供了沉浸式的迷宫探索感。
- **符文解谜系统**：核心解谜机制。符文石板显示符号，玩家需要观察环境、收集线索来推断正确的符文排列。谜题难度递增，从简单的符号匹配到复杂的多步推理。
- **实时地图**：下屏幕的迷你地图随探索实时更新，帮助玩家定位和导航。
- **触控笔战斗**：与敌人遭遇时需要快速点击触控笔进行战斗，增加了紧张感。

## 为什么好玩

Rune Raiders 将"第一人称地牢探索"和"符号解谜"结合在一起，在DS平台上提供了独特的体验。上下屏的分屏设计让地图和场景同时可见，减少了迷路感。符文解谜需要观察力和逻辑思维，而不是简单的试错，让解谜过程有真正的思考乐趣。

## 粘性来源

- **探索未知的好奇心**：每打开一扇门后面是什么？这种好奇心驱动持续探索。
- **解谜成就感**：解开复杂符文谜题后的智力满足感。
- **地牢递进难度**：越深处的谜题和敌人越难，形成自然的目标感。

## Meta 系统

无 — 单次冒险体验，无成长系统。

## 实现难度

**中** — 3D第一人称渲染和实时地图生成是技术难点，特别是在DS的硬件限制下。最大技术难点在于地牢的3D渲染性能和触控操作的精确映射。
