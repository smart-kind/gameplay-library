# 画中世界（Gorogoa）

- **类型**: 解谜 / 叙事 / 艺术
- **平台**: PC / Switch / Mobile / PlayStation / Xbox
- **开发商**: Jason Roberts（独立开发）
- **首次发布**: 2017
- **一句话描述**: 在一个由手绘画面组成的2x2网格中，通过移动和缩放画块来解谜并推进故事

## 玩法规则

游戏界面是一个2x2的方格网格，每个方格中有一幅手绘画面。玩家可以对每幅画进行以下操作：
- **缩放**：点击画面可以放大/缩小，放大后画面会显示更多细节
- **平移**：放大后的画面可以左右上下移动
- **移动**：可以把一幅画拖到另一个方格中，替换原有的画
- **叠加**：某些画可以叠加在其他画上，组合出新的画面

游戏的核心玩法就是：通过缩放、平移、移动、叠加等操作，让画面中的元素"对齐"——例如把一幅画中的门和另一幅画中的走廊连起来，角色就可以走过去；或者把不同画面中的人物拼在一起完成互动。

随着谜题解决，一个关于一个男孩寻找神秘彩色生物的故事逐渐展开。整个游戏没有文字，全靠画面叙事。

## 核心循环

观察画面 → 缩放/平移/移动/叠加画块 → 让元素对齐 → 角色前进/剧情推进 → 新画面出现

## 核心机制

- **2x2网格画布系统**：永远只有4个方格，但每幅画都可以被放大（变成可平移的大画面）、缩小（变成可替换的小块）、移动（拖到其他方格）、叠加（多层合并）。这4种操作组合出了极其丰富的可能性。
- **跨画面连接**：这是最精妙的设计——一幅画中的元素可以与另一幅画中的元素"连接"。例如：画面A中有一扇窗户，画面B中有一个房间，把窗户拖到房间的墙上，窗户就"嵌入"了墙面，角色可以从窗户进出。
- **时间维度**：某些谜题涉及时间的推进——同一幅画在不同的"时间层"（过去、现在、未来）有不同的状态。切换时间层可以改变画面中的元素。
- **视觉隐喻**：所有谜题都通过视觉隐喻来表达——成长、衰老、战争、和平、信仰。没有文字解释，玩家需要自己理解。

## 为什么好玩

Gorogoa 是游戏作为艺术形式的极致体现。每一帧都是精美的手绘插画，组合起来就是一部可互动的绘本。当你第一次发现"原来可以把两幅画拼在一起"时，那种顿悟感是震撼的。游戏的解谜设计极其优雅——每个谜题的解法都简单到让你觉得"我怎么没想到"，但又精妙到让你拍案叫绝。

## 粘性来源

好奇心+视觉美感。每个新画面都是一个未知——你想知道"这两幅画能怎么组合？"。故事本身也很吸引人，关于信仰、战争、成长的叙事虽然没有文字，但画面足以传达深刻的情感。通关后重玩，你会从解谜的角度欣赏它的美。

## Meta 系统

无。纯线性叙事，无收集品、无重玩要素（除欣赏画面外）。

## 实现难度

高 — 最大的挑战是画面叠加和连接的渲染技术（多层手绘画面的精确对齐和融合）。每个画块需要支持多级缩放和平移，且缩放后的细节需要保持清晰。交互系统需要直觉且精确（拖拽、放置、叠加的判定）。美术工作量巨大——7年的独立开发，全部手绘。
