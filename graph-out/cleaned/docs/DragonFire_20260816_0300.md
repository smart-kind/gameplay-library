# Dragon Fire

- **类型**: 交通疏导解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 2011
- **一句话描述**: 交通疏导解谜游戏，引导不同颜色的火球通过轨道和开关到达正确目标
- **PocketGamer评分**: 6/10

## 玩法规则

玩家扮演交通疏导员的角色，需要引导不同颜色的火球（代表交通流）通过一个由轨道、开关和分流器组成的网络，将每种颜色的火球引导到对应颜色的目标位置。

游戏界面上，龙头会持续发射不同颜色的火球，这些火球沿着轨道前进。玩家可以通过点击切换轨道上的开关/道岔，改变火球的行进方向。目标是将红色火球送到红色出口、蓝色火球送到蓝色出口，以此类推。

游戏的难度在于：火球持续发射且速度不慢，玩家需要在有限时间内做出正确的开关切换决策。后期关卡中，轨道网络变得更加复杂，多个颜色的火球同时流动，需要玩家提前规划路线、在恰当的时机切换开关。如果火球走错了出口或发生碰撞，就会扣分或导致游戏失败。

## 核心循环

放置/操作 → 获得奖励/进展 → 升级/解锁新内容 → 挑战更高难度

## 核心机制

- **机制1**：交通疏导解谜核心循环 — 通过交通疏导解谜操作完成关卡目标，获得金币/分数奖励
- **机制2**：渐进式难度 — 每个关卡引入新的元素或增加复杂度，玩家需要调整策略
- **机制3**：资源管理 — 有限的建造材料/金币/时间，需要玩家做出取舍决策

## 为什么好玩

尽管名字像奇幻史诗，Dragon Fire实际上是一款交通疏导模拟游戏。 游戏的评分为6/10，说明这款游戏有一定亮点但也有明显不足。

## 粘性来源

具体到机制层面：核心循环的"完成关卡→获得奖励→解锁新内容"驱动玩家持续游玩；渐进式难度带来的挑战感让玩家想"再来一关"；解谜类游戏特有的"顿悟时刻"（想通了解法）提供强烈的成就感。

## Meta 系统

外围成长系统：通过关卡获得的金币/分数可以解锁新的塔类型/角色/赛道，或升级已有元件的性能。对核心玩法的影响：解锁内容提供了新的策略选择，但不改变核心操作方式。

## 实现难度

中 — 核心玩法基于成熟的交通疏导解谜机制，最大技术难点在于流畅的手势识别和实时物理反馈。
