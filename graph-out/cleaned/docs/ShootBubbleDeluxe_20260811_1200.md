# Shoot Bubble Deluxe（泡泡射击豪华版）

- **类型**: 解谜 / 弹射
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立开发
- **首次发布**: 2015
- **一句话描述**: 瞄准并发射彩色泡泡，将三个或更多相同颜色的泡泡连在一起使其消除，清空所有泡泡即可过关。

## 玩法规则

游戏界面顶部悬挂着一片由不同颜色泡泡组成的区域。底部有一个炮台，玩家可以控制炮台的瞄准方向。点击屏幕发射泡泡，泡泡沿直线飞行，碰到顶部泡泡墙或其他泡泡后停下并附着。

当发射的泡泡与顶部区域中的两个或更多同色泡泡连接在一起（总数至少三个）时，这些泡泡会同时消除并发出音效。消除后，如果某些泡泡失去了与顶部的连接（即没有路径连通到顶部边缘），它们也会掉落并获得额外分数。

游戏目标是在有限次数的发射内清空所有泡泡。如果泡泡墙下降到屏幕底部，游戏失败。某些关卡有障碍物（如石头泡泡、锁定泡泡）增加难度。

泡泡的发射路线有预测线辅助瞄准，但在某些模式下预测线会隐藏或缩短，增加难度。

## 核心循环

瞄准 → 发射泡泡 → 匹配三个以上同色泡泡消除 → 利用掉落机制获得额外清除 → 清空所有泡泡过关

## 核心机制

- **颜色匹配消除**：核心机制是经典的三消逻辑，但在弹射场景下增加了角度预判的维度
- **物理附着**：泡泡击中目标后根据碰撞角度和位置附着，不同的附着点会改变后续泡泡的落点
- **连锁掉落**：消除部分泡泡后，失去支撑的泡泡会自动掉落，这个机制允许玩家用一次射击清除远超直接匹配数量的泡泡
- **墙壁反弹**：泡泡可以从屏幕两侧墙壁反弹，增加瞄准策略的复杂性

## 为什么好玩

泡泡射击类游戏有着数十年的历史，其核心魅力在于"瞄准-发射-消除"这个简单的循环带来的即时满足感。每一次精准的射击（尤其是利用反弹命中关键位置触发大量掉落）都会带来强烈的成就感。关卡设计由易到难，前期给玩家"我很聪明"的满足感，后期挑战玩家的策略规划能力。

## 粘性来源

- **即时反馈**：每次消除都有视觉和听觉的双重正向反馈
- **关卡递进**：数百个关卡由易到难排列，持续提供新的挑战
- **"差一点就过了"的心理**：经常只剩几个泡泡就通关，促使玩家再试一次
- **利用掉落机制的快感**：一次射击触发连锁掉落清除大量泡泡的瞬间非常爽快

## Meta 系统

关卡进度系统。玩家按顺序解锁关卡，部分版本有星星评级系统（根据剩余射击次数评定 1-3 星）。某些版本有道具系统（如颜色炸弹、回溯道具）帮助玩家通过困难关卡。

## 实现难度

低。核心逻辑是碰撞检测和连通性判断（BFS/DFS 查找连接泡泡组），技术实现成熟。最大技术难点在于物理碰撞的精确性和性能优化（当泡泡数量很多时的连通性检测效率）。
