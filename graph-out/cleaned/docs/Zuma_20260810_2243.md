# 射击消除游戏，用彩球消除轨道上的球链（Zuma）

- **类型**: 解谜
- **平台**: PC / Mobile (iOS+Android)
- **开发商**: PopCap Games
- **首次发布**: 2003
- **一句话描述**: 射击消除游戏，用彩球消除轨道上的球链

## 玩法规则

玩家控制屏幕中央的青蛙发射器，向轨道上移动的彩色球链发射同色球。3个或更多同色球连在一起时消除。

如果球链到达终点（骷髅口），游戏失败。消除后球链断开，两端合拢时如果产生新的匹配则连锁消除。有连击系统（连续命中得分增加）。

## 核心循环

瞄准 → 发射彩球 → 匹配消除 → 阻止球链到达终点 → 过关

## 核心机制

- 轨道球链：彩色球沿轨道向终点移动
- 射击消除：3+同色球消除
- 连锁反应：合拢时产生新的匹配
- 连击加分：连续命中获得额外分数

## 为什么好玩

紧张感和消除快感结合。球链逼近终点时的紧张感和精准消除的成就感。

## 粘性来源

关卡驱动；连击追求；高分挑战。

## Meta 系统

关卡解锁系统。

## 实现难度

低。瞄准射击操作简单。最大技术难点：球链运动和碰撞的流畅度。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
