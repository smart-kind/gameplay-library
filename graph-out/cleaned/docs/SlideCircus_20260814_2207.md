# 滑动马戏团（Slide Circus）

- **类型**: 益智 / 滑动拼图
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发者
- **首次发布**: 2014
- **一句话描述**: 通过滑动彩色方块匹配消除的益智游戏，独特的滑动机制让经典消除玩法焕然一新

## 玩法规则

游戏画面呈现一个网格棋盘，上面散布着不同颜色的方块。玩家每次选择一个方块并沿四个方向之一滑动，该方块会一直滑动直到碰到墙壁或其他方块为止。

当三个或更多同色方块连成一行或一列时，它们会被消除并获得分数，上方的方块会下落填补空位。新的方块从顶部随机掉落补充棋盘。

操作方式：点击选中一个方块、向上下左右滑动手指释放该方块、方块沿滑动方向一直移动直到被阻挡。需要预判滑动后的连锁反应——一个方块的移动可能导致多个颜色组合同时消除。

游戏目标是在限定步数内获得指定分数，或清除指定数量的特定颜色方块。如果棋盘被填满无法继续操作，游戏结束。

## 核心循环

选择方块 → 滑动释放 → 颜色匹配消除 → 获得分数 → 新方块掉落 → 继续下一轮

## 核心机制

- **惯性滑动系统**：方块一旦滑动就会一直前进直到被阻挡，不同于传统的相邻交换消除，需要玩家提前规划滑动路径和碰撞顺序
- **连锁消除**：一次滑动可能触发多个消除组合，产生连锁反应和额外分数奖励，鼓励玩家寻找最优解
- **重力系统**：消除后上方方块下落，可能形成新的匹配，产生二次消除
- **步数限制**：玩家需要在有限步数内达成目标，增加策略深度

## 为什么好玩

滑动机制给消除类游戏带来了全新的策略维度——不再是简单的相邻交换，而是要考虑"推一个方块会撞到哪里、消除什么、空出什么位置"的连锁思考。每次成功触发大连锁的满足感极强。

## 粘性来源

连锁消除的爽感反馈（"一步消除五组"）、关卡目标的递进挑战、"差一步就过关"的不甘心。滑动机制的不可撤销性增加了决策的紧张感。

## Meta 系统

关卡解锁系统：完成当前关卡解锁下一关，不同关卡有不同的目标和棋盘布局。累积星星解锁特殊道具（撤销一步、清除一组颜色等）。

## 实现难度

低。网格管理、碰撞检测、匹配消除逻辑都很成熟。最大技术难点是滑动动画的流畅性和连锁反应的实时计算效率。
