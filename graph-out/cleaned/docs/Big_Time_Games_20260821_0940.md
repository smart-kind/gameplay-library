# Big Time Games

- **类型**: 休闲游戏合集 / 轻度博彩
- **平台**: Mobile (iOS+Android)
- **开发商**: WINR Games Inc.
- **首次发布**: 2014
- **评分**: ⭐ 4.6/5 (6,226 评价)
- **价格**: Free
- **一句话描述**: 包含15款不同休闲游戏的合集，以轻松放松为主题，适合休闲玩家消磨时间。

## 玩法规则

应用启动后展示15款游戏的图标网格。每款游戏都是经典的休闲类型：纸牌、拼图、街机、益智等。点击游戏图标进入对应游戏。每款游戏有独立的规则和操作方式，但都遵循简单的单指交互。游戏内通常没有复杂的教程，规则一目了然。部分游戏支持离线游玩。界面设计简洁，以放松舒缓的色调为主。

## 核心循环

选择游戏 → 游玩获得分数/硬币 → 解锁新关卡/难度 → 继续玩

## 核心机制

- 多游戏合集：15款不同类型的游戏满足各种偏好
- 渐进难度：每款游戏内关卡逐渐增加难度
- 离线支持：无需网络即可游玩大部分游戏

## 为什么好玩

一个应用解决"不知道玩什么"的问题。15款游戏覆盖纸牌、拼图、街机等多种类型，总有一款适合当前心情。

## 粘性来源

多游戏多样性、渐进难度曲线、离线可用、每日挑战

## Meta 系统

硬币/积分系统——游玩获得虚拟货币，可用来解锁特殊关卡或道具。轻度激励系统。

## 实现难度

低——经典休闲游戏类型，规则简单，实现容易
