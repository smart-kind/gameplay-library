# Erase Games 脑力 tricky 测试（Erase Games: Brain Tricky Test）

- **类型**: 脑筋急转弯 / 益智 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Arcade Puzzle
- **首次发布**: 2021
- **一句话描述**: 一款反直觉的脑筋急转弯益智游戏，需要玩家跳出常规思维来解决问题

## 玩法规则

游戏由一系列独立的谜题关卡组成，每关呈现一个视觉场景和一个目标（如"让猫高兴"、"找到钥匙"等）。解决方案往往不是直觉上最直接的方式，而是需要"脑筋急转弯"式的思维。

**操作方式**：
- **点击**：点击屏幕上的特定元素触发事件
- **拖拽**：拖动物体到目标位置
- **擦除**：用手指擦除屏幕上的某些元素（游戏名称"Erase"的来源）
- **摇晃**：摇动设备触发隐藏效果
- **多点触控**：同时使用多个手指操作

**典型谜题示例**：
- 题目："让太阳出来" — 直觉方法是点太阳，实际答案是擦除遮住太阳的云
- 题目："叫醒他" — 不是点击人物，而是摇动设备
- 题目："找到隐藏的东西" — 需要用手指在屏幕上擦除遮挡层

## 核心循环

观察场景 → 尝试直觉操作 → 失败后重新思考 → 发现反直觉解决方案 → 过关 → 下一关

## 核心机制

- **反直觉设计**：每关的解决方案都故意违背玩家的直觉预期，迫使玩家跳出框架思考。这是游戏的核心创新点。
- **多操作类型**：点击、拖拽、擦除、摇晃、长按等多种交互方式，增加了谜题的多样性。
- **视觉误导**：场景中故意放置误导性元素，引导玩家走向错误的解决方向。
- **即时反馈**：每次尝试都有即时反馈，即使失败也能获得线索。

## 为什么好玩

Erase Games的快感来自于"啊哈！原来如此！"的顿悟时刻。当你发现答案其实很简单，只是自己的思维被惯性锁住时，那种恍然大悟的感觉既有趣又让人有些懊恼——而这正是你再来一关的动力。

## 粘性来源

- **顿悟快感**：每次解谜成功的"啊哈"时刻是核心驱动力。
- **好奇心驱动**："下一关会是什么奇葩解法？"的好奇心驱动持续游玩。
- **社交分享**：有趣的谜题解法适合分享给朋友，增加传播性。

## Meta 系统

无核心Meta系统。主要是线性关卡推进。

## 实现难度

低 — 每个关卡本质上是条件触发系统。最大难点在于创意设计——需要大量新颖且合理的反直觉谜题，以及确保谜题不会过于晦涩导致玩家放弃。
