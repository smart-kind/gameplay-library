# 小亚马逊（LittleAmazon）

- **类型**: 模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer 收录独立游戏
- **首次发布**: 2012
- **一句话描述**: 一款亚马逊雨林主题的模拟经营游戏，建设和管理自己的生态保护区

## 玩法规则

游戏采用俯视角的等距画面，呈现亚马逊雨林的 lush 环境。玩家从一小块空地开始，逐步建设和扩展自己的生态保护区。

核心玩法包括：
- 种植：在空地上种植各种热带植物，包括树木、花卉、药用植物等。不同植物有不同的生长周期、维护成本和收益
- 养殖：引入各种亚马逊动物，如猴子、鹦鹉、树懒、美洲虎等。动物需要合适的栖息环境和食物
- 建设：建造游客中心、观景台、餐厅、商店等设施，吸引更多游客来访
- 管理：平衡收入和支出，维护动植物的健康状态，处理突发事件

动植物之间有生态关系。某些植物可以为动物提供食物或栖息地，某些动物可以帮助植物传播种子或授粉。合理搭配动植物可以提高整个生态系统的效率。

游客会沿着设置好的路线参观，对不同的动植物和设施有不同的兴趣度。游客的满意度影响收入和口碑。口碑越好，吸引的游客越多。

定期会发生特殊事件：新物种发现、自然灾害（洪水、火灾）、游客特殊需求等，需要玩家及时应对。

## 核心循环

种植动植物 → 建设游客设施 → 吸引游客获得收入 → 投资扩张 → 发现更多物种 → 打造完整的雨林生态

## 核心机制

- **生态模拟系统：动植物之间存在真实的生态关系（食物链、共生关系、授粉等），合理搭配可以提高整体效率**
- **经营规划机制：在有限的土地上合理规划动植物和设施的布局，平衡生态保护和经济效益**
- **游客管理系统：游客有不同的兴趣偏好和行为模式，需要设置合适的参观路线和设施来最大化满意度**
- **随机事件系统：新物种发现、自然灾害、游客投诉等事件增加游戏的变化性和挑战性**

## 为什么好玩

将经营模拟与生态保护主题结合，既有经营的策略乐趣，又有教育意义。亚马逊雨林的丰富生物多样性提供了大量可收集内容。

## 粘性来源

经营类游戏固有的成长性和收集完整性的满足感。图鉴系统（收集所有动植物）是强大的长期目标。

## Meta 系统

动植物图鉴解锁系统、设施升级系统、游客满意度评级。部分版本有成就系统。

## 实现难度

低，经营类游戏节奏相对轻松。最大技术难点在于生态关系模拟的复杂度和AI游客行为。
