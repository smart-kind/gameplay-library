# 破译密码（Decipher）

- **类型**: 解谜 / 抽象旋转
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发
- **首次发布**: 2018
- **一句话描述**: 一款抽象风格的旋转解谜游戏，玩家需要旋转嵌套的圆圈使它们的缺口与星图的分支对齐。

## 玩法规则

游戏画面中心是一组嵌套的破损圆环，周围是星图的分支。每个圆环都有一个缺口，玩家需要旋转这些圆环，使所有圆环的缺口与星图分支对齐。

圆环之间存在各种关联：有些嵌套在其他圆环内部，有些对齐方向不同，有些圆环的旋转会带动其他圆环一起转动。玩家需要"破译"这些圆环之间的关联关系，找到正确的旋转顺序和方法。

当一个嵌套组的所有圆环都对齐后，对应部分的星图会被点亮，带来强烈的满足感。游戏没有计分系统，没有倒计时，玩家可以在放松的状态下慢慢思考，按照自己的节奏推进。

解谜的起点是发现圆环之间的关联——哪些圆环是联动的，哪些是独立的，哪些嵌套在其他圆环内部。理解这些关系后，玩家就可以制定策略，按正确的顺序旋转圆环。

## 核心循环

观察圆环关联 → 旋转圆环 → 发现联动关系 → 全部对齐点亮星图

## 核心机制

- **嵌套旋转**: 圆环层层嵌套，旋转外层会影响内层的位置和角度
- **联动机制**: 某些圆环的旋转会带动其他圆环，形成连锁反应，需要理解关联
- **缺口对齐**: 将圆环的缺口对准星图分支，全部对齐后点亮对应区域，获得视觉反馈
- **无压力设计**: 没有计分、没有倒计时，玩家可以按照自己的节奏解谜
- **渐进揭示**: 随着圆环对齐，星图逐渐被点亮，提供持续的进度感

## 为什么好玩

Decipher 创造了一种类似观察机械表运转的冥想式解谜体验。抽象的视觉风格和触觉化的旋转操作让解谜过程充满感官满足。联动机制的发现——"原来这个圆环的旋转会影响那个！"——是游戏最大的乐趣来源。

## 粘性来源

主要来自解谜的"顿悟时刻"——当理解了圆环之间的关联关系后，那种"原来如此"的满足感极强。无压力设计让玩家可以随时放下随时拿起，没有紧迫感带来的焦虑。点亮星图的视觉反馈也提供了即时满足。

## Meta 系统

无。纯解谜体验，没有外围系统。

## 实现难度

低。核心是圆环旋转和联动逻辑。最大难点是谜题设计的创意——设计出既有巧妙关联又不会过于隐晦的联动关系，以及实现流畅的旋转动画和视觉反馈。
