# Kingdom Rush

- **类型**: 塔防
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Ironhide Game Studio
- **首次发布**: 2011
- **一句话描述**: 经典塔防游戏，在固定路线上建造防御塔阻止敌人前进，保护王国。

## 玩法规则

游戏画面为横向卷轴式的奇幻地图，敌人沿着固定路径从一端走向另一端。玩家需要在路径旁建造防御塔拦截敌人。

四种基础塔类型：
- **弓箭塔** — 远程物理攻击，射速快但伤害低，适合清理大量弱敌人
- **兵营** — 训练士兵阻挡敌人前进，士兵在路径上近战拦截敌人
- **法师塔** — 魔法攻击伤害高但射速慢，可对付高血量敌人
- **炮塔** — 范围伤害（AOE），对聚集的敌人效果显著

操作方式：点击空位选择塔类型，点击已建造的塔可以升级（最多 3 级）或出售。每个关卡有有限的金币和建造位，需要策略性分配。

除了塔，玩家还可以召唤援军（点击路径上的任意点）、使用英雄（独特角色，可移动）、释放法术（流星雨、雷电等全图攻击）。

敌人类型多样：普通步兵、重甲兵、飞行单位、Boss，需要不同塔的组合来应对。

## 核心循环

观察敌人波次 -> 建造/升级塔 -> 击杀敌人获金币 -> 强化防御 -> 通过关卡

## 核心机制

- 塔防组合策略 — 四种塔各有优劣，需要针对敌人类型搭配
- 英雄系统 — 可移动的独特角色，可以在战线薄弱处提供临时支援
- 波次设计 — 每关多波敌人，难度递增，最后一波通常有 Boss

## 为什么好玩

塔防品类标杆，塔的种类克制清晰，敌人设计有趣（比如会飞行的、会分身的、会召唤的），关卡节奏感极佳。每次通关需要多次尝试优化策略。

## 粘性来源

三星评级系统（不损失生命通关）驱动完美主义；多关卡（每代 10+ 关卡）提供持续内容；续作（Frontiers、Origins、Vengeance）各有新机制；英雄升级和天赋系统增加深度。

## Meta 系统

英雄等级系统 — 英雄在战斗中积累经验升级，解锁新技能。星级评级解锁额外关卡和挑战模式。

## 实现难度

中 — 基本操作（放塔、升级）直观易懂，但三星通关需要深入理解敌人弱点和塔的协同。最大技术难点在于关卡平衡，让多次尝试都能有进步感而非重复。
