# Janksy

- **类型**: 解谜/益智
- **平台**: Mobile (iOS)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款创意十足的益智解谜游戏

## 玩法规则

游戏画面中有一个或多个角色需要到达目标位置。玩家通过放置平台、改变地形等方式为角色开辟道路。点击放置道具，点击开始让角色移动。

每关有有限数量的道具可用，需要精确计算放置位置。某些道具有特殊功能（如弹跳板、传送门、开关等）。

画面采用简约的几何风格，色彩鲜明。界面下方为道具栏，上方为游戏区域。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

设计路径让角色到达目标 → 通关解锁新关卡 → 面对更复杂的地形

## 核心机制

- 道具放置解谜：有限道具下设计可行路径
- 多种道具类型：平台、弹跳板、传送门等各有功能
- 物理模拟：角色移动受重力和物理规则影响

## 为什么好玩

创意设计带来的成就感，每关都有多种解法，激发创造力。

## 粘性来源

关卡递进和最少步数挑战。
