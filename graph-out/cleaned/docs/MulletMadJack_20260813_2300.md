# Mullet MadJack（鲻鱼头疯杰克）

- **类型**: FPS / Roguelite
- **平台**: PC / Xbox
- **开发商**: Hammer95 Studios
- **发行商**: Epopeia Games
- **首次发布**: 2024年5月15日
- **一句话描述**: 时间倒计时驱动的快节奏 FPS Roguelite，每一秒都在燃烧你的生命线。

## 玩法规则

游戏采用第一人称视角，画面风格为低多边形（low-poly）的赛博朋克美学。玩家操控一个留着标志性鲻鱼头的角色，在 procedurally generated 的关卡中战斗。

游戏最核心的机制是"时间倒计时"：进入关卡后，一个计时器就开始倒计时。每消灭一个敌人可以获得少量时间，但如果不持续杀敌，时间就会耗尽——游戏结束。这意味着你不能停下来慢慢探索或寻找最优路线，必须在移动中不断击杀敌人来维持生命线。

操作方式包括：移动（WASD/摇杆）、瞄准射击（鼠标/右摇杆）、换弹、使用武器技能。武器种类多样，从霰弹枪到冲锋枪到特殊武器，每种武器有不同的射速、伤害和弹药管理方式。

关卡由多个房间组成，每个房间有一波或多波敌人。清理完一个房间的敌人后，玩家可以进入下一个房间或选择特殊事件（商店、升级、休息等）。这种结构类似传统的 Roguelite 地牢探索，但"时间倒计时"的加入彻底改变了玩家的决策方式。

升级系统是游戏的重要部分：每次完成一波战斗后，玩家可以选择获得新武器、升级现有武器、获得被动加成等。选择直接影响后续战斗的风格和效率。

## 核心循环

进入关卡 → 杀敌续命 → 清理房间 → 选择升级 → 进入下一房间 → 持续杀敌

## 核心机制

- **时间倒计时（Kill to Live）**：这是游戏最核心的创新——每杀一个敌人获得时间，不杀就会死。这个机制从根本上改变了 FPS 的游玩节奏：你不能停下来，不能躲起来，不能"安全"地探索。你必须持续进攻。
- **波次式关卡**：每个房间是一波敌人，清理后获得选择升级的机会。这种结构让玩家在"高压战斗"和"策略选择"之间交替。
- **武器多样性**：不同武器组合可以创造截然不同的战斗风格——近战流、远程狙击流、霰弹rush流等。
- **Roguelite 永久升级**：虽然每次运行会丢失武器，但可以通过积累资源解锁永久加成，让后续运行更强。

## 为什么好玩

Mullet MadJack 的核心魅力在于它把"杀敌"从"手段"变成了"目的"。在大多数 FPS 中，你杀敌是为了通关；在这里，你杀敌是为了活下去。这种紧迫感创造了肾上腺素飙升的体验——每一次击杀都像是一次"续命"，每一次犹豫都可能是最后一次。

## 粘性来源

- **肾上腺素驱动**：时间倒计时机制创造了持续的紧张感，每次成功存活都会释放大量多巴胺。
- **"再来一次"的冲动**：Roguelite 的随机性意味着每次运行都不同——不同的武器、不同的敌人组合、不同的升级选择。"如果这次选不同的升级会怎样？"这种好奇心驱动反复游玩。
- **分数竞争**：高分和排行榜（如果有的话）为重复游玩提供了明确的目标。

## Meta 系统

**Roguelite 永久解锁系统**。玩家通过多次运行积累资源，解锁永久加成（如初始武器库扩展、基础属性提升等）。这些加成让后续运行从起点就更强，但不取代单次运行中的策略选择。

## 实现难度

**中等**。FPS 基础框架成熟，主要难点在于：1）波次式关卡的程序化生成需要平衡性和趣味性；2）时间倒计时机制需要精细的节奏调优——太快玩家无法承受，太慢失去紧张感；3）武器和升级系统的平衡。
