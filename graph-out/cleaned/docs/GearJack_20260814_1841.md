# Gear Jack（Gear Jack）

- **类型**: 动作射击 / 横版过关
- **平台**: Mobile (iOS+Android)
- **开发商**: Chillingo
- **首次发布**: 2012
- **一句话描述**: 装备动力装甲的主角在横版关卡中战斗闯关的动作射击游戏

## 玩法规则

游戏采用横版卷轴视角，玩家控制身穿动力装甲的Jack在2.5D场景中从左向右推进。画面为3D渲染，场景包含工厂车间、军事基地、地下设施等工业风格环境，带有金属质感和机械细节。

左半屏幕虚拟摇杆控制Jack的移动（左/右移动、蹲下躲避），右半屏幕按钮控制射击方向和跳跃。Jack的动力装甲可以装备不同类型的武器，战斗中可实时切换。

武器系统包括多种类型：机枪（高射速、低伤害、弹药充足，适合对付大量小兵）、霰弹枪（近距离范围伤害，对付成群的敌人效果极佳）、火箭筒（远距离爆炸伤害，对付装甲单位和Boss）、激光武器（持续伤害，需要保持瞄准）。每种武器有独立的弹药限制。

关卡中充满敌人：步兵（近战或射击）、炮台（固定位置持续射击）、机甲（高HP高伤害的精英敌人）。敌人在固定位置或沿巡逻路线活动。玩家需要利用场景中的掩体（箱子、墙壁、柱子）躲避敌方火力并反击。

Boss战占据关卡末尾。Boss拥有多种攻击模式和阶段转换。玩家需要观察Boss的攻击前摇动作（如蓄力发光、改变姿态），找到安全窗口输出伤害。

## 核心循环

横版推进 → 消灭敌人收集弹药和补给 → 击败Boss → 解锁新关卡和武器

## 核心机制

- **多武器切换系统**：Jack可同时携带多种武器，战斗中需要根据敌人类型和距离切换。机枪对付大量小兵效率最高，火箭筒对付Boss和装甲目标更有效。弹药管理是重要策略——什么时候用高伤害武器，什么时候节省弹药？
- **掩体躲避机制**：场景中有可互动的掩体，Jack可以躲在掩体后减少受弹面积。Boss的大范围弹幕攻击需要玩家利用掩体规避，等待攻击间隙反击。掩体的耐久度有限，持续受击会被摧毁。
- **装甲升级系统**：过关后获得的资源可用于升级装甲属性（HP上限、移动速度、武器伤害、弹药容量）。升级后的装甲在后续关卡中更容易生存，但也面临更强的敌人以保持挑战。

## 为什么好玩

动力装甲的设定本身就很有吸引力。横版射击配合多武器切换的战斗节奏紧凑，不同武器带来不同的战斗体验。Boss战的多阶段攻击模式增加了挑战性，需要观察和学习。

## 粘性来源

关卡推进（解锁新场景和Boss）+ 装甲升级（数值成长带来的能力提升感）+ 武器收集（获得新武器体验不同战斗风格）。

## Meta 系统

装甲升级系统：使用关卡中获得的资源升级HP、速度、武器伤害、弹药容量等属性。武器解锁需要完成特定关卡或达到收集条件。升级效果叠加，让玩家感受到明确的成长。

## 实现难度

中 — 横版射击的核心玩法成熟。最大技术难点是Boss的多阶段攻击模式设计和碰撞检测精度，确保玩家感觉战斗公平。
