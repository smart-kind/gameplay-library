# 与死者同行 - 放置RPG（Rogue with the Dead: Idle RPG）

- **类型**: 放置/RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2022
- **一句话描述**: 结合Roguelike和放置元素的RPG游戏

## 玩法规则

英雄自动在地牢中探索战斗。每次探险自动进行，玩家可安排装备和技能。击败敌人获得经验和装备。Roguelike元素意味着每次探险的地图和敌人不同。永久升级保留到下次探险。离线时英雄继续探索。结合放置的便利性和Roguelike的随机性。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

安排探险 → 自动战斗 → 获得经验装备 → 永久升级 → 下次更强

## 核心机制

- **自动探险**:  英雄自动在地牢中战斗
- **Roguelike随机**:  每次探险地图和敌人随机
- **永久升级**:  部分升级在死亡后保留

## 为什么好玩

Roguelike的随机性和放置的便利性结合，每次探险都有新鲜感

## 粘性来源

永久升级的长期目标；随机地图保持探索欲

## Meta 系统

永久升级和装备收集

## 实现难度

中 - 需要Roguelike随机生成和放置系统 - 随机地图生成的趣味性和平衡性
