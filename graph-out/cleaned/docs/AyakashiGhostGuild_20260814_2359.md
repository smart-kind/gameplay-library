# Ayakashi: Ghost Guild

- **类型**: 卡牌 RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款以日本妖怪为主题的卡牌收集 RPG 游戏

## 玩法规则

玩家收集各种日本妖怪卡牌，组建队伍进行回合制战斗。通过抽卡获得新妖怪，每种妖怪有独特的属性和技能。

战斗中，玩家选择妖怪卡牌进行攻击、防御或使用技能。妖怪之间存在属性克制关系（如风克火、火克木等）。界面分为战斗区域和手牌区。

画面采用精美的日本浮世绘风格，妖怪设计各具特色。每只妖怪有立绘和战斗动画。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

抽卡收集妖怪 → 组建队伍战斗 → 获取更多资源抽卡

## 核心机制

- 抽卡收集系统：通过召唤获得妖怪卡牌，稀有度从普通到传说
- 属性克制：五行属性相克系统，策略体现在属性搭配
- 回合制战斗：选择妖怪行动，使用技能或攻击

## 为什么好玩

精美的妖怪立绘加上丰富的收集要素，对日本神话爱好者特别有吸引力。

## 粘性来源

抽卡的随机性快感和妖怪全收集的长期目标。

## Meta 系统

- 妖怪养成系统：消耗材料提升妖怪等级和突破上限
- 公会系统：加入公会参与公会战获取特殊奖励

## 实现难度

中等 — 卡牌战斗和抽卡系统设计成熟，最大的技术难点是卡牌平衡性和抽卡概率设计。
