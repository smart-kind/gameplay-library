# 折线（ZigZag）

- **类型**: 街机反应 / 极简
- **平台**: Mobile (iOS+Android)
- **开发商**: Gram Games
- **首次发布**: 2015
- **一句话描述**: 一款极简的点击转向游戏，小球在锯齿形路径上自动前进，玩家点击屏幕控制90度转向

## 玩法规则

游戏画面极简：一个白色小球在一个锯齿形（Z字形）的彩色路径上自动前进。小球始终以恒定速度沿着当前的锯齿方向移动，玩家唯一能做的就是点击屏幕让小球转向90度——从向左前方变为向右前方，或从向右前方变为向左前方。

路径上散布着可收集的钻石。如果小球偏离了锯齿路径（没有及时转向），就会从边缘掉落，游戏立即结束。

随着前进距离增加，路径的颜色会发生变化（每行进一定距离切换颜色），形成漂亮的视觉过渡。路径的转折频率也会逐渐增加，要求玩家更快的反应速度。游戏没有终点——目标是在掉落前尽可能走得更远，收集更多钻石，打破自己的最高分纪录。

游戏的音效设计同样极简——点击转向时发出清脆的"嗒"声，收集钻石时有悦耳的提示音，掉落时则是低沉的失败音效。背景音乐会随着游戏进程逐渐加速，与视觉节奏同步，强化心流体验。

## 核心循环

小球沿锯齿路径自动前进 → 观察即将到来的转折点 → 点击屏幕控制90度转向 → 收集路径上的钻石 → 路径越来越密集 → 未及时转向则掉落结束 → 挑战更高分

## 核心机制

- **单触转向机制**：唯一操作是点击转向，极简到只有一个输入方式。但正是这种极简让游戏对反应速度和节奏感的要求极高。点击时机决定了生死
- **自动生成锯齿路径**：路径按照规则自动生成，每次转折的角度固定为90度，但转折间距和方向变化提供无限的可玩性
- **钻石收集系统**：路径上散布钻石，增加风险与回报的权衡——为了收集偏离主线的钻石，玩家可能面临更大的掉落风险
- **视觉颜色过渡**：路径颜色随行进距离平滑变化，提供视觉上的进展感和美感

## 为什么好玩

操作极简但节奏感极强。点击、转向、再点击——形成一种近乎冥想的游戏节奏。当你进入"心流"状态时，手指点击和视觉节奏完美同步，体验非常独特。极简设计没有任何干扰元素，让注意力完全集中在"下一个转折"上。

## 粘性来源

极简操作让"再来一局"几乎没有门槛——死亡后瞬间就能重新开始，没有加载、没有菜单。心流体验让人上瘾——一旦找到节奏就想一直保持。最高分竞赛和全球排行榜提供社交竞争动力。颜色变化带来的视觉新鲜感让长时间游玩不会单调。

## Meta 系统

钻石收集解锁新皮肤和路径颜色主题。通过收集的钻石可以购买不同风格的小球皮肤、路径颜色方案和背景主题，满足个性化需求。无其他成长系统。

## 实现难度

低 — 最大技术难点是路径生成的算法设计，需要确保路径始终可到达且具有适当的难度递增曲线。碰撞检测（小球是否在路径上）需要精确但高效的实现。性能优化确保在低端设备上也能流畅运行60帧。
