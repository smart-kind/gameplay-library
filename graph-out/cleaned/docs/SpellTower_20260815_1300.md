# SpellTower

- **类型**: 文字益智 / 消除
- **平台**: Mobile (iOS + Android) / Web
- **开发商**: Zach Gage
- **首次发布**: 2011
- **一句话描述**: 结合俄罗斯方块和拼字游戏的创新文字消除游戏，通过拼单词来阻止字母堆溢出

## 玩法规则

SpellTower在一个矩形网格中运行，字母格子从顶部不断下落（类似俄罗斯方块）。玩家需要在字母堆积到顶部溢出之前，找出并消除有效的英文单词。

游戏操作方式：点击相邻的字母（水平、垂直或对角线方向连接）组成单词。选中的字母必须互相邻接形成一条连续路径。点击组成单词后，确认提交即可消除这些字母，获得分数。消除后上方的字母会下落填补空位，同时顶部会持续生成新的字母行。

玩家可以选择不同长度的单词——越长的单词得分越高，同时消除的字母越多，给玩家争取更多时间。游戏有多种模式：经典模式（生存到网格满）、每日挑战、以及多人对战模式（消除的字母会落到对手的棋盘上）。

游戏结束条件：当字母堆积到网格顶部且无法消除时，游戏结束。

## 核心循环

识别单词 → 消除字母获得分数 → 新字母下落 → 持续生存更久

## 核心机制

- **单词拼写消除**: 玩家通过点击相邻字母组成有效英文单词，单词越长得分越高
- **重力下落**: 消除字母后上方字母自动下落，新字母从顶部补充
- **多人对战干扰**: 在多人模式中，玩家消除的字母会转化为垃圾行落到对手棋盘上
- **词典系统**: 游戏使用Merriam-Webster权威词典作为单词验证标准（2017年更新后）

## 为什么好玩

SpellTower巧妙地融合了两款经典游戏的精髟：俄罗斯方块的紧迫感和拼字游戏的知识性。每次成功找出一个长单词时的成就感极强。多人模式中看着对手被你的垃圾字母淹没也是一种独特的快感。

## 粘性来源

粘性来自双重来源：一是生存模式下“再坚持一秒”的紧张循环；二是词汇量挑战——遇到不会拼的单词时会好奇，激发求知欲。

## Meta 系统

无外围成长系统。游戏纯粹依赖技能提升——玩家的词汇量和模式识别能力随游戏时长自然增长。

## 实现难度

中 — 最大技术难点在于高效的单词验证算法和词典查找，以及多人模式的实时同步。
