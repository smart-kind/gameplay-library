# 宇宙快递（Cosmic Express）

- **类型**: 解谜 / 逻辑规划
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: Draknek & Casey Muratori
- **首次发布**: 2017
- **一句话描述**: 一款规划火车路线的益智游戏，玩家需要在太空站上规划火车轨道路线，将不同颜色的外星人送到对应的目的地。

## 玩法规则

游戏画面采用极简几何风格：太空站是一个方格地图，上面有不同颜色的外星人和对应颜色的终点站。
玩家的操作是绘制一条火车轨道路径。火车沿路径自动行驶，经过外星人时自动接上，到达对应颜色终点站时放下。
规则：火车只能沿绘制的路径行驶；路径不能交叉；火车必须按顺序接上所有外星人并送到正确终点。
操作：在网格上点击放置轨道块（直线、转弯），或使用工具直接拖拽绘制路径。
关卡目标：规划一条路径让火车接上所有外星人并送到正确颜色的终点站，且火车最终能回到起点。
每个关卡有唯一的最优解（或少数几个解），玩家需要反复调整路径直到满足所有条件。
随着关卡推进，会增加更多颜色、更多外星人、以及墙壁等障碍物，增加规划复杂度。

## 核心循环

观察外星人和终点位置 → 规划轨道路径 → 放置轨道 → 测试运行 → 调整路径直到完美

## 核心机制

- **路径规划约束**：路径不能交叉、必须连接所有外星人的起点和对应终点、火车必须能回到起点。这些约束创造出丰富的逻辑谜题。
- **顺序逻辑**：火车按路径顺序接人，因此路径的先后顺序决定了哪个外星人先被接上。这是核心策略维度。
- **极简几何美学**：简洁的几何图形和柔和的色彩搭配，视觉上不干扰逻辑思考。
- **渐进式难度**：从简单的单颜色、少外星人开始，逐步增加颜色种类、外星人数量、以及障碍物（墙壁）。

## 为什么好玩

路径规划的纯粹逻辑乐趣。每次画出完美路径让火车顺利运送所有外星人时，有一种'工程美学'的满足感。

## 粘性来源

逻辑谜题的'差一点'体验——路径看起来完美但总有一个外星人送错了；追求最优解的完美主义驱动；渐进式难度保持新鲜感。

## Meta 系统

无。纯关卡解谜体验，共72个关卡。

## 实现难度

低 — 网格路径算法和简单的逻辑判定，技术实现不难。最大技术难点在于关卡设计的趣味性和难度曲线的平滑性。
