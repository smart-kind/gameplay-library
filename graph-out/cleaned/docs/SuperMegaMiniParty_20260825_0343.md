# 超级迷你派对（Super Mega Mini Party）

- **类型**: 多人派对/休闲竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: RED GAMES CO, LLC
- **首次发布**: 2019
- **一句话描述**: 20款多人迷你游戏，支持1v1对战和4人派对

## 玩法规则

Super Mega Mini Party 提供 20 款多人迷你游戏，支持本地同设备和在线多人对战。游戏主界面分为几个模式：在线匹配（与全球玩家1v1对战）、派对模式（最多4人同设备或联机对战）、单人训练模式。

每款小游戏有不同的操作规则，但都采用简化的触屏控制：滑动、点击、长按等单指操作。例如，赛跑类小游戏需要快速点击屏幕加速；格斗类需要滑动出招；反应类需要在正确时机点击。

派对模式下，系统会在短时间内连续切换多款小游戏，每款小游戏结束后即时计分。最终总分最高的玩家获胜。

在线1v1模式中，玩家先选择一款喜欢的游戏进行对战，赢后解锁新角色、宠物或小游戏。

## 核心循环

选择对战模式 → 完成多款小游戏 → 获得分数/成就 → 解锁新角色/宠物/小游戏

## 核心机制

- **机制1**：快速轮转机制：派对模式中连续切换多款小游戏，每款只玩很短时间。防止玩家对单一游戏产生厌倦。
- **机制2**：角色与宠物收集：通过赢得对战解锁角色变体和宠物。宠物会跟随角色并做出表情，增加个性化。
- **机制3**：技能训练模式：提供单人训练让玩家磨练技巧，提升在线对战的竞争力。

## 为什么好玩

核心乐趣在于'派对'体验——和朋友一起玩、互相嘲笑对方在迷你游戏中的笨拙表现。20款小游戏确保每轮都有不同的挑战，不会重复。角色和宠物的收集系统增加了长期目标。

## 粘性来源

粘性来源：(1) 20款游戏轮换，保持新鲜感；(2) 角色/宠物收集驱动持续对战；(3) 与朋友/全球玩家的对战提供社交竞争；(4) 成就系统提供明确的进度目标；(5) 1v1对战的'复仇'心理驱动重复游玩。

## Meta 系统

解锁系统：赢得对战→解锁角色变体和宠物。角色变体改变外观，宠物提供视觉跟随和表情反馈。不影响核心玩法平衡，纯外观收集。

## 实现难度

低到中。主要技术难点在于网络同步（1v1在线对战的实时性）和20款不同小游戏的统一框架设计。需要处理不同设备的输入延迟问题。
