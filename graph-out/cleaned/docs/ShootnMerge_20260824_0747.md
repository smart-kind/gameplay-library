# 射击合并（Shoot n Merge）

- **类型**: 合并解谜 / 泡泡射击 / 数字消除
- **平台**: Mobile (iOS + Android)
- **开发商**: Metajoy
- **首次发布**: 2018
- **一句话描述**: 将数字合并、泡泡射击和三消三种玩法融合的创新休闲解谜游戏。

## 玩法规则

游戏画面呈现一个垂直的棋盘区域，底部有射击发射器。玩家控制发射器左右瞄准，发射带有数字标记的泡泡到棋盘上方的区域。当相同数字的泡泡彼此接触时，它们会自动合并为一个数字更大的泡泡（例如两个 2 合并为 4，两个 4 合并为 8）。

每次发射前，玩家可以预览即将发射的数字。玩家需要策略性地将泡泡射击到合适位置，确保相同数字能够相邻接触触发合并。棋盘空间有限，如果泡泡堆积到顶部，游戏结束。

游戏目标是通过不断合并产生越来越大的数字，每完成一次合都会得分。同时，合并腾出的空间可以继续发射新泡泡，维持棋盘不溢出。部分关卡设有目标分数或指定数字要求。

## 核心循环

发射数字泡泡 → 相邻相同数字合并升级 → 腾出空间继续射击 → 冲击更高数字和分数

## 核心机制

- **数字合并机制**：相同数字接触即合并为翻倍数值，形成"2→4→8→16→32"的增长链条，给玩家持续的正向反馈和成长感。
- **射击定位机制**：玩家需要精确控制发射角度和位置，将泡泡送到理想区域，考验空间规划能力。
- **空间管理机制**：棋盘空间有限，合并不仅是得分手段更是腾出空间的必要操作，形成"合并=生存"的双重压力。

## 为什么好玩

三合一玩法的创新组合让每局都有新鲜感——射击的瞄准乐趣、数字翻倍的爽快感、以及三消式的连锁反应同时存在。看着数字从 2 一路合并到 1024 的成就感极具吸引力。

## 粘性来源

"差一个就能合成更大数字"的不甘心驱动玩家反复尝试；每次合并的视觉和音效反馈即时且满足；数字增长链天然带有进度感，玩家总想看到下一个翻倍。

## Meta 系统

无。纯关卡驱动，无外围成长系统。

## 实现难度

低。核心逻辑为数字匹配+碰撞检测+射击物理。最大技术难点是合并连锁的递归处理——一次合并可能引发相邻泡泡的连锁合并，需要正确处理级联事件的顺序和动画时序。
