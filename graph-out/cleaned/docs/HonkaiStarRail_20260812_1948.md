# 崩坏：星穹铁道（Honkai: Star Rail）

- **类型**: 回合制 RPG / 抽卡
- **平台**: Mobile (iOS+Android) / PC / PS5
- **开发商**: miHoYo / HoYoverse
- **首次发布**: 2023
- **一句话描述**: 乘坐星穹列车穿梭于不同星球之间，在回合制战斗中运用策略击败敌人、揭开宇宙谜团的科幻 RPG

## 玩法规则

战斗采用经典的回合制系统，但加入了"行动条"机制。屏幕右侧显示所有角色的行动顺序，速度属性决定了角色在行动条上的移动速度。速度快的角色在一轮内可以行动多次。

玩家组建最多 4 名角色的队伍，每个角色有普攻、战技（消耗战技点）、终结技（消耗能量）三种行动类型。战技点全队共享（上限 5 个），需要合理分配给不同角色使用。

每个角色属于一种"命途"（职业定位）和一种"属性"（物理、火、冰、雷、风、虚数、量子）。属性攻击可以击破敌人的"韧性条"，韧性条归零后敌人进入弱点击破状态，受到伤害增加且暂时无法行动。

探索部分采用半箱庭式设计：玩家在精致的场景中行走、与环境互动、解谜、触发剧情，进入战斗后切换到回合制界面。

## 核心循环

探索新星球 → 完成剧情和支线任务 → 抽卡获取新角色 → 培养角色和光锥（武器） → 挑战高难度模拟宇宙 → 等待下一版本更新

## 核心机制

- **回合制行动条系统**：不同于"你一招我一招"的传统回合制，行动条让速度成为核心属性。高速角色可以频繁行动，低速角色需要等待。为什么有效：它保留了回合制的策略深度（可以仔细思考每一步），同时通过行动条增加了"速度管理"的动态策略维度——给低速角色加速、给高速角色减速都成为有效的战术选择。
- **弱点击破系统**：每种敌人有特定的属性弱点，使用对应属性攻击削减韧性条，归零后触发击破效果（额外伤害 + 行动延后）。为什么有效：它将"属性克制"从"打得多一点"升级为"直接改变战场格局"——击破后的额外行动机会可以扭转战局。
- **模拟宇宙（Roguelike 模式）**：一个独立于主线的高难度挑战模式，玩家在随机生成的关卡序列中选择祝福（增益效果），组建独特的技能组合。为什么有效：它为回合制游戏注入了 Roguelike 的"每一局都不同"的变数，让培养好的角色有更多策略组合可以试验。
- **终结技插队机制**：角色能量满后可以随时释放终结技，即使在敌方回合中也可以"插队"释放。为什么有效：它增加了战斗的戏剧性和策略深度——在敌人即将行动时释放控制技能打断，或者在队友即将被击杀时释放治疗。

## 为什么好玩

回合制最大的优势是"思考的时间"。在星穹铁道中，你不需要拼反应速度，而是可以看着行动条，思考"先让佩拉降防，再用希儿终结技收割"。每一次完美的击破和连招带来的成就感不亚于动作游戏的华丽操作。而且——你可以在上班摸鱼时单手玩。

## 粘性来源

- **版本更新节奏**：与原神相同的 6 周更新周期，新星球、新角色、新剧情持续供给
- **角色收集与培养**：每个角色有独特的技能组和背景故事，收集欲望强烈
- **每日任务与体力限制**：简短的每日任务和体力系统维持稳定的日活
- **忘却之庭**：类似深渊的高难度挑战，验证角色培养成果
- **剧情驱动**：每个星球的独立故事线有完整的叙事弧线，给玩家"追剧"般的体验

## Meta 系统

**角色与光锥（武器）养成系统**：
- 角色等级、行迹（天赋）、光锥（装备）、遗器（圣遗物类似物）
- 遗器提供属性加成和套装效果，随机副属性决定了养成的随机性和重复游玩价值
- 开拓力（体力）限制每日养成资源获取量
- 对核心玩法的影响：养成深度决定可挑战内容的上限，但游戏设计保证了免费角色和低星角色也能通关大部分内容

## 实现难度

中 — 回合制游戏的技术复杂度低于动作游戏。主要难点在于**战斗动画表现力和 UI 信息呈现**：回合制需要清晰展示大量信息（行动条、属性、技能效果、Buff/Debuff），同时保持动画的观赏性。跨平台渲染和内容量（多星球、大量角色动画、配音）是主要挑战。
