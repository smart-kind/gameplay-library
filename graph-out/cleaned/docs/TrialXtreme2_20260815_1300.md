# Trial Xtreme 2

- **类型**: 物理驾驶 / 技巧竞速
- **平台**: Mobile (iOS + Android)
- **开发商**: Deemedya
- **首次发布**: 2012
- **一句话描述**: 摩托车越野竞速游戏，利用真实物理引擎在极端地形上完成高难度赛道

## 玩法规则

Trial Xtreme 2是一款基于物理引擎的摩托车越野游戏。玩家控制一辆摩托车，在各种极端地形构成的赛道上行驶。赛道由坡道、断桥、绳索桥、陡坡、深谷等障碍组成。

操控方式：屏幕右侧有两个虚拟踏板——油门（加速前进）和刹车（减速/倒车）。同时，玩家可以通过前后倾斜设备（陀螺仪）或点击屏幕来调整摩托车的重心——前倾让车头朝下，后倾让车头朝上。重心控制是游戏的核心技能。

赛道的挑战在于：太快的速度可能导致冲出赛道掉入深渊，太慢的速度则无法越过陡坡。在某些极端坡道上，玩家需要精确地调整重心来保持平衡——车头抬得太高会翻倒，压得太低则无法爬坡。赛道中还散布着收集品（金币或星星），增加额外挑战。

每个赛道有通关时间记录，玩家可以挑战自己的最佳成绩或与其他玩家的成绩竞争。

## 核心循环

选择赛道 → 油门+重心控制通过障碍 → 完成赛道获得评分 → 挑战更好成绩

## 核心机制

- **物理重心控制**: 通过前后倾斜调整摩托车重心，在陡坡上保持平衡需要精确控制
- **油门/刹车**: 两个虚拟踏板控制速度和方向，需要与重心控制配合使用
- **物理引擎驱动**: 所有运动和碰撞都基于物理引擎计算，确保真实感和可预测性
- **计时挑战**: 每关有通关时间记录，鼓励玩家反复练习以达到最优路线
- **收集品系统**: 赛道中散布的金币和星星增加了额外目标

## 为什么好玩

Trial Xtreme 2的乐趣在于物理操控的精确性和"终于通过了"的成就感。每个赛道都像是一个谜题——你需要找到最佳的速度、重心和路线组合才能通过。当你在一个反复失败的弯道终于成功通过时，那种成就感无与伦比。

## 粘性来源

粘性来自技巧游戏的天然循环——"差一点就通过了"的不甘心。每个弯道失败后你都知道是什么原因（速度太快/重心不对），这种明确的反馈让人想立刻重试。

## Meta 系统

摩托车解锁系统：通过游戏进程解锁不同性能的摩托车。关卡解锁系统：线性推进。计时排行榜。

## 实现难度

中 — 最大的技术难点在于物理引擎的精确调校（既要真实又要可玩）和陀螺仪控制的灵敏度适配。
