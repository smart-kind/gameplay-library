# 青蛙过河（Frogger）

- **类型**: 动作/街
- **平台**: Multi-platform (Arcade, Mobile iOS/Android, PC)
- **开发商**: Konami（原版）/ Sega（北美发行）
- **首次发布**: 1981
- **一句话描述**: 玩家控制一只青蛙穿过车流不息的公路和漂流着原木的河流，安全到达对岸的五个家。

## 玩法规则

画面从上方俯视，分为上下两部分。上方是目标区域——河岸上有五个洞穴（青蛙的家），中间是湍急的河流，河面上漂浮着原木、荷叶、乌龟等可踩踏的移动平台。下方是玩家起始区域，中间隔着一条有多条车道的繁忙公路。

玩家每回合只能向上下左右四个方向之一移动一步（一个网格单位）。公路上的车辆（汽车、卡车、赛车）以不同速度和方向来回行驶——碰到即失去一条命。河流上的原木和荷叶顺流而下，站在上面的青蛙随之漂流——漂出屏幕范围也失去一条命。

每个关卡开始时，玩家需要将五只青蛙分别送进五个洞穴才算过关。如果一只青蛙成功到家，该洞穴关闭，后续青蛙不能再进。关卡有时间限制，超时即失败。

操作非常简单：点击或滑动屏幕，青蛙向对应方向跳一格。移动端也可以点击目标位置让青蛙跳过去。

## 核心循环

躲避车辆和障碍物 → 利用河流平台过河 → 把青蛙送进洞穴 → 五只全部安全到家过关

## 核心机制

- **网格移动**：每次只能移动一格，操作简单但策略深刻——需要在车流中找到节奏，在河面上抓住时机
- **动态障碍物**：车辆以恒定速度移动，河流平台以不同速度漂移，玩家需要记忆和预判运动模式
- **风险递增**：随着关卡推进，车辆速度加快、河流平台间距变大，难度自然提升
- **多目标管理**：需要将5只青蛙全部送回家，中途死亡需要从下一只重新开始

## 为什么好玩

极简操作下的纯粹紧张感。每一秒都在做判断：现在冲不冲？等下一辆车还是跑？站在原木上随波逐流时的不确定性让人心跳加速。成功将青蛙送入洞穴时的成就感与5只全部到齐时的满足感形成强烈的正反馈。

## 粘性来源

- **即时反馈循环**：每步决策立刻看到结果，"差一点就过了"的遗憾驱动重试
- **难度递增**：每关车辆更快、河流更难，持续提供新挑战
- **高分竞争**：分数 = 成功到家数量 + 时间奖励 + 收集加分，驱动追求更高分
- **怀旧情怀**：经典街机IP，自带认知度和情感共鸣

## Meta 系统

无经典版本没有外围系统。现代移动版可能加入关卡解锁、皮肤收集等轻度Meta系统，但不改变核心玩法。

## 实现难度

低 — 网格移动+固定路径的障碍物，逻辑非常简单。最大技术难点在于确保移动端触控响应精准，以及在不同屏幕尺寸下保持网格比例和可读性。
