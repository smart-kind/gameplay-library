# Cubemen 2

- **类型**: 塔防 / 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款3D立体方块风格的塔防游戏，玩家在多层迷宫中布置防御单位，阻止敌人通过

## 玩法规则

游戏呈现一个多层3D迷宫场景，采用等距视角展示。敌人从入口出发，沿固定路径向出口移动，路径可能跨越不同楼层。

玩家可以在迷宫的特定位置放置防御单位（各种方块人）。每个单位有不同的攻击类型：近战（范围小但伤害高）、远程（射速快）、范围伤害（AOE）、减速（减缓敌人移动速度）。

放置单位需要花费资源。每消灭一个敌人获得资源。资源可用于购买新单位或升级已有单位（提升攻击力、攻击范围或解锁特殊能力如暴击）。

不同敌人有不同属性：速度（影响移动快慢）、血量（需要多少伤害）、护甲（减少远程伤害）。部分敌人可以飞行（无视地面障碍直接穿越），部分敌人有护盾。玩家需要根据敌人类型调整防御布局。

游戏设有沙盒模式，玩家可以自由设计防御布局并测试效果。多人合作模式允许两名玩家共同布置防御。

## 核心循环

分析敌人路径 → 布置防御单位 → 获取资源升级防御

## 核心机制

- **多层迷宫**：敌人可以在不同楼层间移动，需要立体布局防御
- **单位类型**：近战/远程/范围/减速等分工明确，需要组合搭配
- **敌人多样性**：飞行、护甲、高速等不同属性考验防御策略

- **沙盒模式**：自由设计防御布局并测试效果

## 为什么好玩

3D立体迷宫让塔防从平面变成空间思考，布局策略更丰富。单位组合的协同效应让防御体系有构建感。

## 粘性来源

塔防策略的深度+每波敌人升级带来的挑战感。找到最优防御布局的成就感是核心粘性。

## Meta 系统

单位升级系统：解锁新单位类型和升级路径。关卡进度系统：完成所有关卡后解锁更高难度。

## 实现难度

中 — 塔防策略有一定门槛。最大技术难点是3D迷宫的寻路算法和多层渲染。
