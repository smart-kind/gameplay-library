# Cats are Cute（猫咪真可爱）

- **类型**: 放置 / 收集 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: D3 Publisher
- **首次发布**: 2023
- **一句话描述**: 在小镇中放置各种猫咪家具，吸引不同品种的流浪猫前来，收集猫咪图鉴的治愈系放置游戏。

## 玩法规则

游戏发生在一个宁静的小镇上。玩家可以放置各种猫咪相关的家具和道具到场景中：猫爬架、猫窝、猫玩具、猫粮碗等。每种道具对不同类型的猫有不同的吸引力。

放置道具后，经过一段时间（离线也会累积），会有不同的猫咪前来造访。每只猫有独特的外观和性格。玩家可以用相机拍摄猫咪的照片，照片会自动收录到图鉴中。

游戏没有战斗、没有竞争、没有时间压力。玩家只需要偶尔上线查看哪些猫咪来了，给它们拍照，然后放置新的道具吸引更多猫咪。

游戏的主要货币是"小鱼干"，通过猫咪来访和拍照获得。小鱼干用于购买新的猫咪道具。某些稀有猫咪需要特定的道具组合才能吸引到。

## 核心循环

放置猫咪道具 → 等待猫咪来访（可离线）→ 拍照收集 → 获得小鱼干 → 购买新道具 → 吸引更多猫咪

## 核心机制

- **道具吸引力系统**：每种道具对不同品种的猫有不同的吸引概率，玩家需要研究哪些道具组合能吸引稀有猫
- **离线累积**：即使关闭游戏，猫咪来访也会继续发生，上线后一次性收取，降低游玩压力
- **图鉴收集**：游戏的核心目标是收集所有猫咪品种的照片，每只猫都有独特的插画和简介
- **场景切换**：游戏有多个场景（小镇、公园、海滩等），不同场景吸引不同种类的猫

## 为什么好玩

Cats are Cute 的成功在于它精准击中了"云养猫"的需求。不需要铲屎、不需要负责、只需要享受猫咪的可爱。游戏的节奏完全由玩家控制，没有任务催促、没有社交压力、没有竞争焦虑。对于那些喜欢猫但不能养猫的人来说，这是一个完美的替代品。美术风格温馨治愈，每只猫咪的设计都有鲜明的个性。

## 粘性来源

- **收集驱动**：图鉴收集是核心长期目标，"就差几只就全收集了"的心态让人持续游玩
- **低压力体验**：完全无时间压力，什么时候想玩就玩，不会有任何落后焦虑
- **视觉治愈**：可爱的猫咪插画和温馨的场景设计提供持续的情绪价值
- **离线收益**：即使几天不上线，回来也有收获，不会惩罚玩家的生活节奏

## Meta 系统

小鱼干货币与道具商店系统。玩家通过猫咪来访获得小鱼干，用于购买新的猫咪道具。道具分为普通和稀有两种，稀有道具需要更多小鱼干或特定条件解锁。场景解锁需要完成特定收集目标。

## 实现难度

低。核心逻辑简单：放置道具 → 计时器触发 → 随机选择猫咪 → 展示动画。最大技术难点在于猫咪的插画资源和动画表现需要大量美术工作，技术实现本身并不复杂。
