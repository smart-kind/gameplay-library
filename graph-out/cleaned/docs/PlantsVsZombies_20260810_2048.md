# Plants vs. Zombies（Plants vs. Zombies）

- **类型**: 塔防 / 策略放置
- **平台**: PC / Mobile (iOS+Android) / 主机
- **开发商**: PopCap Games
- **首次发布**: 2009
- **一句话描述**: 用各种功能的植物在 5 条车道上抵御一波波来袭的僵尸

## 玩法规则

游戏画面是 5 行 × 9 列的草坪网格。僵尸从右侧出现，沿着每条 lane 向左行走，最终目标是到达最左侧的房子。

游戏开始前，玩家从卡池中选择合适的植物种子（每关可用植物不同，后期关卡卡池更大）。游戏中，顶部有一个阳光计数器（初始 50 阳光）。

核心资源是"阳光"——向日葵每几秒产出一颗阳光（25 点），点击收集。阳光用于购买并放置植物到网格中。

僵尸有多种类型：普通僵尸（慢）、路障僵尸（戴路障帽，更耐打）、铁桶僵尸（铁桶头盔，极耐打）、撑杆僵尸（跳过第一个植物）、潜水僵尸（水下移动）等。

每波僵尸来袭前屏幕提示 "A huge wave of zombies is approaching!"。消灭所有波次 = 过关。僵尸到达最左侧 = 失败。

## 核心循环

种植向日葵产阳光 → 用阳光购买战斗植物 → 布置防线 → 抵御僵尸波次 → 过关获得新植物 → 挑战新关卡/模式

## 核心机制

- 机制1：经济循环——向日葵是基础，没有阳光就无法购买战斗植物。需要在"投资经济"（多种向日葵）和"投资防御"（多种战斗植物）之间平衡
- 机制2：5 行并行防御——每条 lane 独立运行，但玩家资源有限，需要全局统筹。不同植物有不同功能：豌豆射手（远程射击）、坚果墙（阻挡）、樱桃炸弹（范围爆炸）、寒冰射手（减速）、双发射手（双倍输出）等
- 机制3：植物选择策略——每关开始前选择携带哪些植物（最多 8 种），需要根据僵尸类型和关卡特点搭配阵容

## 为什么好玩

幽默的僵尸题材 + "看着自己布置的防线自动运转"的满足感。每种植物都有独特的动画和音效（豌豆射手"突突突"、樱桃炸弹"轰"），反馈感极佳。

## 粘性来源

新植物解锁（每关结束后获得新植物，丰富策略组合）+ 迷你游戏模式（老虎机、保龄球、传送带等变种）+ 成就系统 + 夜间/泳池/屋顶等不同场景变化

## Meta 系统

关卡推进解锁新植物和新区域（白天草坪 → 夜间 → 泳池 → 浓雾 → 屋顶）。小游戏/解谜/生存模式在通关主模式后解锁。无外围养成系统。

## 实现难度

低。核心是网格塔防逻辑——植物放置、僵尸寻路（直走）、碰撞检测、波次调度。技术门槛很低，最大的工作量是关卡设计和平衡（每种植物/僵尸的数值调整）。
