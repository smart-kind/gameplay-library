# Chef Merge - Fun Match Puzzle

- **类型**: 合成解谜 / 装饰经营
- **平台**: Mobile (iOS+Android)
- **开发商**: HIGGS TECHNOLOGY CO., LIMITED
- **首次发布**: 2021-11-11
- **一句话描述**: 拖拽合成相同物品，获得资源装饰庄园，在田园主题中享受轻松解谜

## 玩法规则

Chef Merge 是一款合成+装饰的休闲游戏。玩家在一个合成棋盘上看到各种农场物品（蔬菜、水果、农作物等），通过拖拽将相同物品合并，生成更高级的物品。

核心操作：点击带闪电标记的箱子获取新物品放入棋盘；拖拽相同物品到一起合成更高级物品；将合成好的物品交给特殊邻居换取金币和钻石；使用金币和钻石购买装饰品（地毯、灯具、桌椅、墙纸等）来装饰自己的庄园。

棋盘有有限的格子空间，需要合理规划合成路径。高级物品需要多个低级物品逐步合成（例如：小麦→面粉→面包→精致蛋糕）。装饰系统有多个区域和风格可选，玩家可以自由设计自己的庄园外观。

## 核心循环

获取物品 → 拖拽合成 → 交换资源 → 装饰庄园 → 解锁新区域

## 核心机制

- **链式合成系统**：物品按等级链条排列，每次合成向上一级推进。这种"2合1"或"3合1"的机制创造了清晰的进度感——你知道每个物品最终能变成什么。
- **资源转化经济**：合成产物不是终点，而是换取装饰资源的中间货币。这给合成行为赋予了明确的目的性，避免了"为了合成而合成"的空洞感。
- **自由装饰系统**：装饰品的种类繁多（地毯、灯具、家具、墙纸等），每个区域有多种风格可选，玩家有充分的表达空间。

## 为什么好玩

Chef Merge 把"整理收纳"的满足感和"装修设计"的创造力结合在了一起。拖拽合成的动作本身就有解压效果，而最终的装饰成果让你有实实在在的成就感。田园主题和轻松的节奏让它成为一款非常适合碎片时间的游戏。

## 粘性来源

具体到机制层面：装饰系统的目标驱动（"我想把客厅装完"）让人持续合成；合成链条的"差一级就完成"产生继续玩下去的动力；新区域和新装饰品的解锁提供了长期目标。

## Meta 系统

庄园装饰系统是核心外围系统。玩家通过合成获得资源，资源用于购买装饰品，装饰品改变庄园外观。装饰不影响核心合成玩法，但提供了明确的目标和视觉反馈。活动系统（限时特殊物品、节日装饰）提供短期目标。

## 实现难度

中 — 合成逻辑和装饰系统的实现相对直接。最大的技术难点是大量装饰品的渲染和布局系统的灵活性（不同装饰品之间的位置关系、层级关系）。

合成棋盘的空间管理是游戏的核心策略之一。棋盘格子有限，如果不及时合成低等级物品，棋盘会被占满导致无法获取新物品。玩家需要在"快速合成释放空间"和"等待更好的合并机会"之间做权衡。

特殊邻居系统是资源转化的关键节点。不同的邻居需要不同的合成产物，给出的奖励也不同。有的邻居用金币收购农产品，有的用钻石交换高级加工品。了解每个邻居的需求和出价是高效游戏的关键。

庄园装饰的自由度很高——每个区域（客厅、卧室、厨房、花园等）有多种风格主题可选，同一件家具也可以放在不同位置。装饰完成后可以截图分享，增加了社交展示的维度。
