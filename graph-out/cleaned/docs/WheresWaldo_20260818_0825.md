# Wheres Waldo

- **类型**: 解谜 / 找物
- **平台**: Mobile (iOS)
- **开发商**: Ludia / Gameloft
- **首次发布**: 2009
- **一句话描述**: 在拥挤的插画场景中找到隐藏的角色沃尔多

## 玩法规则

玩家在主屏幕上看到一幅拥挤的插画场景，画面中包含大量人物、建筑和物品。

游戏的目标是在限定时间内从场景中找到指定的角色（沃尔多和其他关键人物）。

玩家通过点击屏幕上的可疑位置来查找目标——如果点击正确，角色会被高亮标记并获得积分，同时播放欢呼音效。

如果点击错误位置，计时器会扣除少量时间作为惩罚，并显示失败音效。

每个关卡的插画场景不同，难度逐步递增：人物密度增大、可寻找的角色数量增多、时间限制缩短。

游戏提供提示系统，使用提示可以快速锁定目标位置，但会减少最终评分。

过关条件：在限定时间内找到所有指定角色。

失败条件：时间耗尽仍未找到全部目标。

## 核心循环

观察场景 -> 点击目标 -> 获得积分 -> 解锁下一幅插画（一句话）

## 核心机制

- 视觉扫描机制：玩家需要在密集的画面中快速定位特定角色，训练观察力和模式识别能力。每张插画包含数十个可能的目标位置，玩家需要通过快速扫描来筛选。
- 时间压力机制：倒计时迫使玩家在速度和准确性之间做出权衡。每次点击失败不但扣除时间，还会打断扫描节奏。
- 渐进难度：每关增加干扰元素密度和减少可用时间，维持挑战感。后期关卡甚至会引入移动的干扰物。
- 提示系统：当玩家长时间未找到目标时，可以使用提示功能高亮目标区域。提示次数有限，需要谨慎使用。

## 为什么好玩

经典找物玩法的数字化移植，每张插画都精心设计了大量细节，让每次寻找都有新发现。除了核心角色外，画面中还藏有各种彩蛋和隐藏物品，增加了探索的乐趣。

## 粘性来源

差一点就找到的心理驱动——每次失败都让人觉得再试一次就能成功。场景细节丰富，重复游玩时仍能发现新元素。评分系统鼓励玩家在不使用提示的情况下完成，提供了额外的挑战目标。

## Meta 系统

关卡系统：完成当前场景后解锁下一幅插画。部分版本含收集要素——隐藏的特殊标记或彩蛋。评分排名系统鼓励玩家反复挑战以提高分数。

## 实现难度

低 — 纯视觉识别，无需复杂算法。最大技术难点在于插画资源的管理和高分辨率下的点击区域精确判定。需要确保点击检测在不同屏幕尺寸下都能准确工作。
