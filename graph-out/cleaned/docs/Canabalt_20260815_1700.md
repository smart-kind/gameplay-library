# Canabalt

- **类型**: 无尽跑酷
- **平台**: Mobile (iOS+Android) / PC (Steam) / Web (Flash)
- **开发商**: Adam Saltsman (Semi Secret Software)
- **首次发布**: 2009
- **一句话描述**: 一款单按钮无尽跑酷游戏，玩家控制一个在屋顶间狂奔的角色，自动向前奔跑，只需按一个键即可跳跃。

## 玩法规则

玩家看到的是一个不断向右移动的 2D 横版画面，角色自动向前奔跑。玩家唯一能做的操作是按下任意键（点击/触摸/空格），使角色跳跃。

画面中的建筑屋顶高度各不相同，屋顶之间存在间隙和宽度差异。跳跃时机是关键——按得太早会撞到前方墙壁，按得太晚会坠入深渊。屋顶上偶尔会出现窗户，撞碎窗户可以加速但不会改变方向。

游戏的速度会随着时间逐渐加快，从慢跑到冲刺再到极速，给玩家越来越大的反应压力。画面采用灰度像素艺术风格，远处有模糊的工厂烟囱和飞鸟，营造末世氛围。

游戏没有明确终点，目标是在不断加速的情况下尽可能跑得更远。距离以米为单位实时显示。碰到任何障碍物（墙壁、起重机、坠落物）或掉入屋顶间隙即游戏结束。

游戏中偶尔会出现直升机追逐和建筑物坍塌等事件，增加紧迫感和视觉变化。

## 核心循环

奔跑 → 跳跃 → 跑得更远 → 速度加快 → 更极限的跳跃

## 核心机制

- 单按钮操作：整个游戏只有一个输入——跳跃。这种极简设计降低了学习成本，但深度来自时机判断。随着速度递增，容错窗口不断缩小，形成天然难度曲线。
- 程序化生成关卡：每次游戏的屋顶序列都是随机生成的，但遵循一定的间距规则保证可玩性。没有两局完全相同，保证无限重玩价值。
- 速度递增系统：游戏从慢跑开始，逐渐加速到极限速度。速度变化不可见但可感知，玩家在不知不觉中进入心流状态，直到某个极限时刻突然失误。

## 为什么好玩

一局只需要几秒钟到几分钟，但'差一点就打破纪录'的感觉让人忍不住再来。极简操作让任何人都能立刻上手，但高速度下的精准跳跃又提供了极高的技巧上限。

## 粘性来源

核心粘性来自'再来一局'的冲动——每次死亡都觉得自己只差一点点。距离数字的实时反馈、速度递增带来的肾上腺素飙升、以及不断刷新个人纪录的成就感共同构成了强大的重玩循环。

## Meta 系统

无。游戏没有任何成长系统或收集要素，纯粹靠玩法本身驱动。这种'无Meta'设计恰恰是其魅力所在——每次都是从零开始，成绩完全取决于当下表现。

## 实现难度

低。最大技术难点在于程序化生成的关卡设计——需要在随机性和可玩性之间找到精确平衡，确保每个屋顶序列都是'困难但可达成的'。
