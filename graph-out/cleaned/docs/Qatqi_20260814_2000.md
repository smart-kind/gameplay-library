# QatQi

- **类型**: 益智 / 抽象策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2013
- **一句话描述**: 连接彩色节点的抽象益智游戏，考验空间规划和逻辑推理

## 玩法规则

游戏在一个网格棋盘上进行，棋盘上分布着不同颜色的节点。玩家需要通过绘制路径将相同颜色的节点连接起来，同时路径不能交叉。

游戏界面显示一个网格棋盘和若干彩色节点对。每种颜色有两个节点。玩家通过手指在网格上滑动来绘制路径，从一个颜色的节点画到另一个同色节点。

路径绘制规则：路径只能沿网格线移动，不同颜色的路径不能交叉或重叠，每条路径必须从一个节点连接到其同色配对节点。

游戏目标是将所有颜色的节点对都连接起来。随着关卡推进，棋盘变大、颜色种类增多，难度逐步增加。

## 核心循环

观察节点布局 → 规划路径 → 绘制连接 → 检查是否交叉 → 完成所有连接

## 核心机制

- **路径连接**：在网格上绘制路径连接同色节点，考验空间规划能力
- **不交叉约束**：不同颜色的路径不能交叉，这是核心限制条件
- **空间推理**：需要在有限的网格空间内为所有颜色找到互不干扰的路径
- **渐进式难度**：从少量颜色开始，逐步增加到多颜色复杂布局

## 为什么好玩

规则简单到极致（连线不交叉），但解谜深度随着颜色增加呈指数增长。每个关卡都有唯一的最优解，找到解法的成就感很强。

## 粘性来源

"连上最后一根线"的满足感 + 难度递增的挑战性 + 简洁抽象的美学 + "就差一步"的执着

## Meta 系统

关卡解锁系统 — 完成当前关卡解锁下一阶段

## 实现难度

低 — 基于网格的2D益智游戏，最大技术难点在于关卡生成的趣味性和解的唯一性保证
