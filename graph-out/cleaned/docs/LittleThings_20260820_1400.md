# 小东西™（Little Things™）

- **类型**: 找物 / 解谜 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: KlickTock Pty Ltd
- **首次发布**: 2010
- **一句话描述**: 在真实物件组成的马赛克中寻找隐藏物品的经典休闲解谜

## 玩法规则

Little Things 是经典找物游戏，画面由数百个真实小物件精心排列成马赛克图案。屏幕显示一个需要寻找的物品，玩家在密集的物件中找到并点击它。

每个关卡包含多个寻找目标，找到所有目标后过关。物件位置每次随机生成，确保重复游玩不重复。游戏支持 24 种语言本地化，面向全球玩家。

没有倒计时，没有生命值，没有失败条件——玩家可以完全按照自己的节奏搜索。这种零压力的设计让游戏适合任何年龄段和任何时间场景。

点击错误物品没有惩罚，只有找到正确物品时的正面反馈。这种纯正向的反馈循环让游戏体验非常友好，即使是小朋友也可以放心游玩。

本作是 2010 年原版的高清重制版，使用 Godot 引擎从底层重建，画面质量和流畅度都有显著提升。

## 核心循环

看目标 → 搜索马赛克 → 点击找到 → 下一个目标

## 核心机制

- **随机物品排列**：每次进入关卡物件位置完全随机，保证同一关卡可以无限次重复游玩。随机算法需要确保所有目标物品都能被找到，不会出现被完全遮挡的情况
- **零压力设计**：无倒计时、无惩罚、无失败，纯粹的正向搜索体验，适合放松减压。这种设计理念在当今快节奏的手游市场中独树一帜
- **写实物件美学**：使用真实物品照片而非卡通绘制，马赛克具有独特的视觉美感和探索乐趣。物件的选择和排列经过精心设计，每个马赛克本身就是一件艺术品

## 为什么好玩

简单纯粹的找物乐趣——当视线从混乱中捕捉到目标物品时那种瞬间的'啊哈！'时刻。没有压力、没有竞争，只有安静地发现。

## 粘性来源

发现物品的即时满足感 + 随机化保证每次不同 + 放松氛围形成习惯

## Meta 系统

无外围系统，纯关卡推进

## 实现难度

低 — 核心是物件随机放置和碰撞检测，技术门槛不高，难点在于物件库的丰富度和视觉美观度
