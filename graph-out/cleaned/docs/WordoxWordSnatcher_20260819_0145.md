# Wordox: 文字掠夺者（Wordox: Word Snatcher）

- **类型**: 文字 / 策略对战
- **平台**: Mobile (iOS)
- **开发商**: Unknown
- **首次发布**: 2008
- **一句话描述**: 一款双人对战的文字拼词游戏，玩家通过在共享棋盘上拼写单词来争夺领地。

## 玩法规则

游戏界面展示一个网格棋盘，类似于拼字游戏但加入了对战元素。两位玩家轮流在棋盘上放置字母，组成有效的英文单词。

每个字母占据一个格子，单词完成后，该单词覆盖的格子就归属放置方的"领地"。棋盘上的格子会显示当前归属颜色。游戏结束时（棋盘满了或双方都无法再放置），领地多的一方获胜。

玩家手中有随机分配的字母牌（类似Scrabble的字母抽取机制），需要在每轮选择一个字母放置到棋盘上。放置字母时必须与已有的字母相连并能组成至少一个有效单词。某些特殊格子提供分数加成（如双倍字母分、三倍单词分）。

## 核心循环

选择字母 → 放置到棋盘组成单词 → 占领格子 → 比较领地数量获胜

## 核心机制

- **领地争夺**：与传统拼字游戏只比分数不同，Wordox引入"占领格子"的领地概念。一个单词越长，占领的格子越多，直接增加领地优势。
- **字母管理**：手中的字母牌是有限资源，需要权衡是立刻使用还是等待更好的组合。
- **空间策略**：放置位置不仅要考虑组成单词，还要考虑如何扩大自己的领地、阻断对手的扩张路线。

## 为什么好玩

将文字游戏的知识性和策略对战的空间规划结合，既有"我知道这个词"的智力优越感，又有"我把你的路堵死了"的策略快感。双人对战的不确定性让每局都不一样。

## 粘性来源

- **双人对战的社交性**：和朋友比拼谁认识更多单词、谁的策略更好。
- **学习新词**：遇到对手拼出的不认识的好词，本身就是一种学习体验。
- **快速对局**：一局10-15分钟，适合碎片时间对战。

## Meta 系统

- **段位/排名**：在线对战的积分排名系统。
- **词汇量统计**：记录玩家使用过的独特单词数量，形成个人词汇量成就。

## 实现难度

中。核心难点是英文词典的集成和验证——需要内置一个高效的词典数据结构来实时验证单词有效性。另外，AI对手的实现也需要合理的词汇难度调优，确保AI既不会太强也不会太弱。

## 变体设计

可以加入"中文拼词"版本——使用汉字部首或偏旁作为拼词单元，创造完全不同的玩法体验。也可以加入"限时闪电战"模式——在固定时间内尽可能多占地盘，去掉对手互动只保留速度挑战。
