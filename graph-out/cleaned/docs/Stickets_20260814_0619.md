# Stickets

- **类型**: 解谜 / 路径规划
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款以贴纸为主题的创意解谜游戏，玩家需要在网格中放置不同形状的贴纸来覆盖指定区域

## 玩法规则

游戏呈现一个带有网格的区域，某些格子需要用贴纸覆盖，某些格子必须留空。目标图案以预览图的形式显示。

玩家获得一组不同形状的贴纸。每张贴纸由多个相邻方格组成（类似多格骨牌/Tetromino），颜色各异。

通过拖拽将贴纸放置到网格上。贴纸不能重叠，必须完全落在网格范围内。放置后可以调整位置但不能旋转（部分关卡允许旋转）。目标是用给定的贴纸覆盖所有需要覆盖的格子，不遗漏不多余。

部分贴纸可以旋转90度。随着关卡推进，贴纸形状更复杂（从简单直线到L型、T型、十字型等），网格更大，需要覆盖的模式更不规则。

游戏设有创意模式，玩家可以自由设计贴纸拼图并分享给其他玩家。每日挑战提供随机生成的贴纸谜题。

## 核心循环

观察目标图案 → 放置和旋转贴纸覆盖区域 → 完成覆盖过关

## 核心机制

- **形状旋转**：贴纸可旋转90度，增加放置的灵活性
- **完美覆盖**：所有格子必须恰好覆盖，无多余无遗漏
- **形状复杂度递进**：从简单直线到复杂多格形状

- **创意模式**：玩家自制拼图并分享

## 为什么好玩

贴纸主题的视觉呈现温馨可爱。找到完美放置方案的满足感很强。

## 粘性来源

路径/覆盖谜题的标准粘性：每关解出后解锁下一关的进度感。

## Meta 系统

无。纯解谜。

## 实现难度

低 — 拖拽放置直观。最大技术难点是关卡设计和解的验证。
