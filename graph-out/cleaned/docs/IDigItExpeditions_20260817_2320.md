# 我来挖挖挖：探险（I Dig It Expeditions）

- **类型**: 挖掘冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: Chillingo
- **首次发布**: 2010
- **一句话描述**: 横向卷轴的挖掘冒险游戏，玩家操控小人在地下挖掘探索并收集宝藏。

## 玩法规则

游戏画面是横版2D地下世界，地面以上是天空和云朵。玩家角色是一个戴着安全帽的小人，手持铲子在地下挖掘。
操控：点击/拖拽决定挖掘方向（上/下/左/右），角色会自动向目标方向挖掘并移动。不能挖掘到石头（灰色方块），只能挖泥土（棕色方块）。
挖掘过程中会遇到：宝石（收集获得积分）、化石（收集完成图鉴）、钥匙（开启宝箱）、敌人（需要躲避或绕开）、特殊方块（弹簧、传送带等机关）。
目标是在限定时间内收集尽可能多的宝石和化石到达出口。某些关卡需要找到特定物品才能过关。
收集到的宝石可以用于购买升级：更快的挖掘速度、更大的视野范围、额外的时间等。
游戏有多个区域（草地、沙漠、雪地、火山等），每个区域有不同的地形特征和特殊元素。

## 核心循环

选择挖掘方向 → 收集宝石和化石 → 避开敌人和障碍 → 到达出口完成关卡 → 使用宝石购买升级 → 进入新区域

## 核心机制

- 路径规划：在有限时间内规划最优挖掘路径，既要收集高价值物品又要保证能到达出口
- 不可逆挖掘：已经挖过的区域无法恢复，需要慎重选择路径，挖错方向可能导致被困。这种不可逆性增加了决策的紧张感
- 区域探索：每个区域有独特的视觉风格和收集品，激发探索欲。新区域的解锁带来持续的新鲜感

## 为什么好玩

挖到宝藏时的惊喜感（'这块泥土下面藏着什么'）、规划好一条收集路线并完美执行的成就感，以及解锁新区域时的探索欲。
简单的操作背后藏着有趣的路径规划挑战，让人在'休闲'和'烧脑'之间找到平衡。

## 粘性来源

化石图鉴收集的收集欲、升级系统的数值成长、以及'下一次我能挖到更多'的冲动。

## Meta 系统

升级系统（速度/视野/时间）、化石图鉴收集、区域解锁。

## 实现难度

低 — 核心是网格挖掘和碰撞检测。主要技术难点在于路径可行性的预判和关卡设计，以及不可逆挖掘带来的'玩家被困'问题的预防。

游戏还包含隐藏收集品：每个区域有特殊的化石或文物，需要挖掘特定位置才能发现。收集完整的化石图鉴是游戏的长期目标之一。某些关卡有隐藏的捷径，可以找到但需要放弃一些宝石收集。
