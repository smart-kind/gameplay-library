# 土豆兄弟 (Brotato)

- **类型**: Roguelike / 弹幕生存 / 自动射击
- **平台**: Mobile (iOS+Android) / PC / Switch / PS / Xbox
- **开发商**: Blobfish
- **首次发布**: 2022
- **一句话描述**: 在波次制弹幕生存中扮演一个同时持有最多6把武器的土豆，通过疯狂升级组合击杀外星敌人

## 玩法规则

游戏画面为俯视的封闭竞技场，玩家操控一个土豆角色，手持最多6把武器自动向最近的敌人开火。游戏共20波敌人，每波持续时间从20秒到90秒不等，敌人数量和强度逐波递增。第20波为最终Boss战。

玩家通过虚拟摇杆移动角色躲避弹幕，武器自动射击无需手动瞄准。消灭敌人后掉落经验值球和材料（木头、金属、豆子等）。每波结束后进入商店阶段，玩家用材料购买新武器、升级属性（生命、速度、伤害、射程等）或选择角色天赋。

当角色生命值归零时游戏结束，需要重新从第1波开始。每局游戏约15-25分钟。

## 核心循环

生存一波敌人 → 收集材料和经验 → 商店购买武器和升级 → 下一波更强的敌人

## 核心机制

- **多武器系统**：最多同时装备6把武器，武器类型包括枪械、法杖、近战、投掷等。每种武器有独立的射速、伤害、射程属性。武器组合产生不同的战斗风格——可以全远程火力覆盖，也可以近战+远程混合。
- **属性成长**：每波结束后用材料购买属性提升，包括最大生命、生命回复、移动速度、近战伤害、远程伤害、弹速、攻击速度、闪避、护甲等。属性之间需要取舍，形成不同的流派build。
- **角色选择**：24个可选角色，各有独特的起始属性和特殊机制。例如有些角色不能买武器但属性更强，有些角色有额外的材料获取，有些角色有独特的战斗方式。
- **波次制节奏**：每波敌人设计各不相同，有普通波、精英波、Boss波。节奏紧凑，20波的渐进式难度曲线让游戏有足够的深度。第5、10、15波通常会出现精英敌人，第20波是最终Boss。每波之间的商店阶段是策略调整的关键窗口。

## 为什么好玩

极低的学习门槛，极高的策略深度。移动+自动射击的操作任何人都能上手，但6把武器的组合选择、属性的优先级判断、不同角色的玩法差异提供了丰富的策略空间。一局只需15-25分钟，节奏紧凑不拖沓。

## 粘性来源

"再来一局"的核心驱动力来自build的多样性——24个角色 × 数十种武器 × 属性选择的组合产生了几乎无限的玩法可能。每次死亡后都能尝试不同的角色和武器组合，保持新鲜感。解锁新角色和成就也提供了长期目标。

## Meta 系统

角色解锁系统：通过达成特定条件（如用某角色通关、达到某难度等）解锁新角色。难度系统：通关后解锁更高难度（危险、疯狂等），敌人更强但奖励更多。

成就系统提供了额外的长期目标——如"在不购买生命的情况下通关"、"使用特定武器组合通关"等挑战成就。这些成就鼓励玩家尝试不同的玩法风格，进一步扩展了游戏的重玩价值。每个成就解锁后会有视觉提示和统计记录，让玩家追踪自己的进度。

## 实现难度

低到中。自动射击的弹幕生存游戏在技术上比较成熟，核心是碰撞检测、弹幕模式和AI路径寻路。最大的难点在于数值平衡——24个角色、60+种武器、多种属性的组合需要大量的测试和调优。

性能优化也是一个挑战——后期屏幕上可能同时存在数百个敌人、子弹和特效，需要高效的批量渲染和对象池管理来保证流畅的帧率。
