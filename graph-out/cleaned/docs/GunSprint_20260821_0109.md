# Gun Sprint (枪弹冲刺)

- **类型**: 休闲竞速 / 射击
- **平台**: Mobile (iOS+Android)
- **开发商**: KAYAC Inc.
- **首次发布**: 2019
- **一句话描述**: 一款反向移动机制的竞速游戏，通过后坐力推动角色前进

## 玩法规则

这是一款反向移动机制的竞速游戏，你的枪朝后射击，通过后坐力推动角色前进。赛道从上方俯视，角色初始朝左，枪口朝右射击产生反作用力推动角色向右移动。

操作是点击屏幕开枪：每次点击发射一颗子弹，子弹击中目标产生反作用力推动角色。点击越快，角色前进越快。但需要注意赛道上有障碍物（墙壁、炸弹、尖刺），直接碰撞会扣血或死亡。

赛道中散布着各种道具：加速箭头（临时加速）、盾牌（抵挡一次伤害）、多子弹（一次发射多颗增加推力）。赛道终点前有Boss战，需要围绕Boss边移动边射击其弱点。

游戏目标是率先到达终点。每局3到5名AI对手同时竞速，名次决定奖励多少。赛道越来越长，障碍越来越多，需要更高的点击频率和更精确的移动路线。

后期赛道的障碍设计更加密集，需要玩家在高速推进的同时做出精确的躲避决策。部分赛道有分叉路口，选择正确的捷径可以大幅缩短距离但风险更高。

## 核心循环

点击射击产生后坐力前进 -> 躲避障碍物 -> 率先到达终点 -> 获得排名奖励和硬币

## 核心机制

- **反直觉后坐力推进**：向后射击推动角色前进，独特的物理机制增加趣味
- **高速点击节奏**：点击频率直接影响速度，制造快节奏的爽快感
- **障碍躲避**：赛道上的障碍物需要精确路线规划，平衡快和准的矛盾
- **分叉路径选择**：捷径高风险高回报，增加策略决策维度

## 为什么好玩

后坐力推进的物理机制新颖有趣，高速点击的节奏感让人上瘾，赛道上的障碍让每次前进都充满变数。

## 粘性来源

快节奏点击的爽快感，反直觉物理机制的新鲜感，赛道排名竞争。每次就差一点点的遗憾让人忍不住再来。

## Meta 系统

角色和枪械解锁加赛道解锁。通过完成关卡获得硬币，解锁新角色（不同外观和属性）和新赛道。排名系统提供竞争动力。

## 实现难度

低 -- 后坐力物理推进的核心机制简单直观。最大技术难点是物理模拟的手感调优，让点击推进反馈既爽快又不失控。
