# 农场模拟经营游戏，种植、养殖、生产和销售（Hay Day）

- **类型**: 放置
- **平台**: Mobile (iOS+Android)
- **开发商**: Supercell
- **首次发布**: 2012
- **一句话描述**: 农场模拟经营游戏，种植、养殖、生产和销售

## 玩法规则

玩家拥有一座农场，需要种植作物（小麦、玉米、甘蔗等）、饲养动物（鸡、牛、猪等）、生产商品（面包、黄油、糖等）。

作物需要时间生长，动物需要时间产出，生产设施需要时间加工。玩家可以开设路边商店出售商品给其他玩家，也可以完成卡车/轮船/城镇订单获得经验和金币。

游戏有扩建系统，解锁新的土地、建筑和装饰。

## 核心循环

种植/养殖 → 等待成熟 → 生产加工 → 完成订单/出售 → 获得金币和经验 → 扩建农场

## 核心机制

- 时间管理：不同作物/生产有不同的生长/加工时间，需要合理安排
- 订单系统：卡车、轮船、城镇订单提供不同奖励
- 路边商店：玩家可以定价出售商品给其他玩家
- 社交互动：可以加入社区，捐赠物品和帮助社区成员

## 为什么好玩

农场经营的满足感很强，看着自己的农场从小变大、从简单到丰富。订单完成时的成就感驱动持续游玩。

## 粘性来源

数值成长驱动（扩建、升级建筑）；时间管理策略；社交社区的协作感；收集的成就感。

## Meta 系统

农场扩建和建筑升级系统。玩家通过经验值提升等级，解锁新的作物、动物和建筑。

## 实现难度

低。放置经营类游戏，节奏轻松，适合休闲玩家。最大技术难点：经济系统平衡和多人交互的数据同步。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
