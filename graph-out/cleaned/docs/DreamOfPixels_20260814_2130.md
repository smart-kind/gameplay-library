# Dream of Pixels（Dream of Pixels）

- **类型**: 益智 / 放置 / 像素艺术
- **平台**: Mobile (iOS+Android)
- **开发商**: Futuremarks
- **首次发布**: 2013
- **一句话描述**: 通过放置方块来自动绘制像素画的益智游戏，将俄罗斯方块式的方块放置与像素艺术创作结合。

## 玩法规则

游戏画面展示一个像素画布的轮廓区域，玩家需要从上方落下的不同形状方块中选择合适的方块填充到画布的正确位置。每个方块由若干像素组成，形状各异（L形、T形、长条等类似俄罗斯方块的组合）。

玩家通过点击选择要放置的方块类型，然后点击画布上的目标位置放置。方块会吸附到最近的合法位置，如果放置位置正确（与目标像素图案匹配），该区域的像素就会被填充并显示颜色。

游戏的目标是在限定时间内或有限方块数量内，正确填充整个像素画布以还原目标图像。每关有不同的像素画目标，从简单的小动物到复杂的人物肖像。

画布上未填充的区域以灰色轮廓显示，已经填充的区域则显示彩色像素。玩家可以看到目标图像的缩略图作为参考。放置错误的方块不会破坏已经正确的填充，但会浪费宝贵的方块配额。

## 核心循环

选择方块 → 放置到画布上匹配像素 → 逐步还原图像 → 解锁新的像素画关卡

## 核心机制

- **像素匹配系统**：每个方块有特定的形状，玩家需要判断哪个方块能完美填补画布的空白区域，考验空间想象力
- **颜色填充反馈**：正确放置后像素显示颜色，错误的放置会导致方块消失或浪费，即时反馈让决策有明确后果
- **渐进式难度**：早期关卡像素画简单、方块选择少，后期画布更大、形状更复杂，形成平滑的学习曲线

## 为什么好玩

将俄罗斯方块的直觉操作与像素艺术创作的美感结合，每次完成一幅像素画都有强烈的成就感，而且作品本身就值得分享。

## 粘性来源

具体到机制层面：像素画还原带来的"揭晓答案"式满足感——随着空白区域逐渐被填满，目标图像慢慢显现，这种渐进式的视觉奖励让人想要完成每一幅画。同时像素画主题的多样性（从动物到名画）提供了内容层面的新鲜感。

## Meta 系统

- **关卡解锁系统**：完成当前像素画解锁下一幅
- **分享系统**：完成的作品可以截图分享
- **对核心玩法的影响**：无核心玩法影响，主要为内容驱动

## 实现难度

低——核心机制本质上是方块放置+图案匹配，没有复杂的物理或AI系统。最大的技术难点是像素画数据的存储和验证逻辑，需要精确判断方块放置是否与目标图案匹配。
