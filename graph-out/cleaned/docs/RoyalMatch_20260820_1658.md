# Royal Match

- **类型**: 三消解谜+装饰
- **平台**: Mobile (iOS+Android)
- **开发商**: Dream Games Dijital Teknolojiler A.S.
- **首次发布**: 2021
- **一句话描述**: 一款将三消解谜与城堡装饰相结合的游戏，玩家通过消除关卡收集金币来恢复皇家城堡的昔日辉煌。

## 玩法规则

游戏分为两个主要界面：三消关卡界面和城堡装饰界面。在三消界面中，玩家在网格上交换相邻的彩色方块（上下左右滑动），形成3个或更多相同方块的连线来消除它们。

消除过程中会生成各种强力道具：横向或纵向消除一整行/列的火箭道具、消除周围方块的炸弹道具、以及清除整屏同色方块的彩虹球道具。这些道具可以通过匹配更多方块来组合升级，产生更强的消除效果。

每关有明确的目标：在限定步数内收集指定数量的特定颜色方块、清除障碍物（树叶、箱子、锁链等）、或达到目标分数。通关后获得金币奖励。

在城堡界面中，玩家使用通关获得的金币来选择不同的装饰方案，逐步修复和装饰罗伯特国王的城堡。每个区域有多个装饰选项可供选择，玩家的个人审美偏好决定了城堡的最终面貌。

## 核心循环

完成三消关卡 → 收集金币 → 装饰城堡 → 解锁新区域 → 挑战更高难度关卡

## 核心机制

- **消除+装饰双循环**：三消提供即时挑战和奖励，装饰提供长期目标。玩家不只是在"过关卡"，而是在"建造自己的城堡"，两种动机相互强化。
- **道具组合系统**：两个基础道具相邻时可以合并为更强大的道具（如火箭+炸弹产生十字消除），增加了策略深度。玩家需要规划如何最大化道具组合效果。
- **无障碍广告干扰**：游戏以流畅的体验著称，没有弹出式广告打断游戏流程，保持了沉浸感。

## 为什么好玩

装饰城堡的成就感弥补了三消游戏常见的"通关后空虚感"——每次消除不仅是为了通过关卡，更是为了收集金币来美化城堡。看到城堡从破败到华丽的渐进变化，提供了持续的视觉奖励。

## 粘性来源

装饰系统的个性化表达和关卡推进的"差一步就完成"是核心粘性。每个装饰选择都反映了玩家的个人品味，这种"这是我建造的城堡"的归属感驱动持续回归。限时活动和锦标赛提供了额外的竞争层次，让玩家有理由每天回来。

## Meta 系统

城堡装饰系统是核心Meta。玩家通过通关收集金币，在城堡的多个区域（花园、王座厅、厨房等）中选择不同的装饰方案。每个区域解锁后提供多套装饰风格，玩家的选择永久改变城堡外观。装饰不影响力学平衡，纯粹是审美表达。

## 实现难度

中。三消逻辑本身成熟，核心难点在于装饰系统的资产量（每个区域需要多套3D/2D装饰资源）以及装饰效果与关卡系统的无缝整合。最大技术难点在于维护大规模装饰资产的性能优化——确保在不同设备上流畅渲染完整的城堡场景。
