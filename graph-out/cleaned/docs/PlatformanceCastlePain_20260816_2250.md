# 平台城堡大冒险（Platformance: Castle Pain）

- **类型**: 平台跳跃 / 解谜
- **平台**: Mobile (iOS) / Web
- **开发商**: Nitrome / I-play
- **首次发布**: 2011
- **一句话描述**: 操控小人在充满机关的城堡中跳跃穿梭，利用物理特性到达终点

## 玩法规则

玩家控制一个小人角色在一座充满障碍和机关的城堡中穿行。城堡由多个房间组成，每个房间都是一个独立的谜题关卡。

核心操作：左右移动和跳跃。玩家需要利用跳跃来跨越沟壑、躲避尖刺、踩踏开关、推动箱子等。城堡中还有各种机关：移动平台、旋转刀刃、弹跳垫、传送门等。

游戏的美术风格独特——城堡是一个巨大的"痛楚之堡"（Castle Pain），每个房间的机关设计都充满创意。部分房间需要利用物理特性（重力、惯性、反弹）来通过。

部分关卡有收集品（金币/星星），收集全部后才能解锁隐藏房间或特殊结局。

## 核心循环

进入房间 → 观察机关布局 → 操控角色跳跃躲避 → 找到出口 → 进入下一房间

## 核心机制

- **精准跳跃（Precision Jumping）**：核心操作，需要精确控制落点和时机。许多机关只有一瞬间的安全窗口
- **物理机关（Physics Obstacles）**：移动平台、旋转刀刃、弹跳垫等利用物理特性创造障碍和通路
- **房间解谜（Room Puzzles）**：每个房间都是一个独立谜题，需要观察机关运作规律找到最佳路径
- **收集要素（Collectibles）**：散布在各房间的金币/星星，鼓励探索隐藏路径

## 为什么好玩

独特的城堡主题和精美的像素美术风格让平台跳跃有了沉浸感。每个房间的机关设计都有新意，不会感到重复。

## 粘性来源

具体到机制层面：1）"差一点就过"的平台跳跃——每次失败都让人觉得下次能行；2）房间机关的新奇设计带来的探索欲；3）收集品的完美主义驱动；4）到达终点时的成就感。

## Meta 系统

房间解锁系统。完成一定数量的房间后解锁新区域，新区域有更高难度的机关设计。

## 实现难度

中。最大的技术难点是关卡设计——每个房间都需要手工精心布置，确保难度递进合理且存在解法。物理碰撞检测的精确性也很关键，平台跳跃对碰撞判定要求很高。
