# Block Blast!（方块爆破）

- **类型**: 益智 / 方块消除 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Hungry Studio
- **首次发布**: 2022
- **一句话描述**: 将不同形状的方块放置到 8×8 网格中，填满一行或一列即可消除

## 玩法规则

游戏画面中央是一个 8×8 的空网格棋盘。屏幕底部同时展示 3 个不同形状的方块（类似俄罗斯方块的积木块，有 L形、T形、直线、2×2方块等）。

玩家将方块拖放到棋盘上的任意空位，方块一旦放置就不能移动。每次放置后，如果某一行或某一列被完全填满（所有格子都被方块占据），该行/列立即消除并计分，格子恢复为空。

3 个方块全部放置完毕后，会出现下一组 3 个新方块。如果底部任何一块方块在当前棋盘上都无法找到合法的放置位置（被已有方块挡住），游戏立即结束。

游戏没有步数限制，目标是尽可能长时间地存活并获得高分。连续消除多行/列会获得连击加分。某些特殊消除（如同时消除多行多列）有额外奖励。

## 核心循环

放置方块 → 填满行/列触发消除 → 获得分数 → 新方块出现 → 继续放置 → 避免无空间可放

## 核心机制

- **空间规划消除**：与传统下落式方块不同，Block Blast! 的方块由玩家自主放置到任意位置。这要求玩家不仅考虑当前消除，还要为后续方块预留空间。
- **三连方选择**：每次出现 3 个方块，玩家可以决定放置顺序。先放哪个、后放哪个、把哪个留在最后，都是策略决策。
- **终局压力机制**：当大尺寸方块（如 3×3 或 L形长臂）出现时，棋盘剩余空间是否足够容纳成为关键。这种空间焦虑是游戏紧张感的来源。
- **连击奖励**：同时消除多行/列时获得倍率加分，鼓励玩家规划"一次性填满"的高价值操作。

## 为什么好玩

看似简单的"放方块消行"却有深度的策略层面——每个方块都是一次空间决策，而三连方的组合让每回合都有多种选择。消除时格子爆裂消失的动画配合音效带来即时的爽感反馈，而棋盘即将被填满时的紧迫感又让人高度集中注意力。

## 粘性来源

- **空间规划成就感**：成功规划出一套完美的消除序列（连续清掉多行多列）带来的智力满足感
- **短局快节奏**：一局通常 3-10 分钟，随时可以"再来一局"
- **高分挑战**：不断刷新个人最高分的驱动力
- **视觉反馈**：方块放置和消除的动画效果令人满足

## Meta 系统

无显著外围系统。游戏以纯玩法驱动，无角色成长或收集元素。部分版本可能有每日挑战模式或排行榜。

## 实现难度

低。核心是一个 8×8 的二维数组 + 方块碰撞检测 + 行/列填充判断。最大技术难点在于方块形状的灵活表示（不规则多格骨牌的合法性验证）和流畅的拖放手势处理。UI/UX 的手感优化（吸附、高亮预览）是关键。
