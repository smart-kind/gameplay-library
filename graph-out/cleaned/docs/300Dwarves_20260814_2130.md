# 300 Dwarves（300 Dwarves）

- **类型**: 放置 / 策略 / RPG / 塔防
- **平台**: Mobile (iOS+Android) / PC (Steam)
- **开发商**: WiSTONE Entertainment
- **首次发布**: 2014
- **一句话描述**: 管理一支由300名矮人组成的队伍，自动挖掘、建造、战斗的放置策略游戏。

## 玩法规则

游戏画面呈现一个垂直向下的矿洞截面，玩家在顶部放置矮人单位。每个矮人自动向下挖掘方块，遇到矿石会采集，遇到敌人会自动战斗。画面采用像素风格，从上到下分为多层区域，每层有不同的地形、矿石类型和敌人。

玩家通过点击屏幕放置不同类型的矮人（矿工矮人负责挖掘，战士矮人负责战斗，工匠矮人负责建造），每个矮人占据一个网格位置。矮人一旦放置就会自动工作，玩家不需要实时操控他们的行动。

游戏的目标是不断向下挖掘，采集稀有矿石来升级装备和建筑，同时抵御来自深处的怪物入侵。每到达一个里程碑深度（如100层、200层等）会遇到Boss战，需要足够的矮人战力才能通过。

在每一层挖掘过程中，矮人会遇到三种基本交互对象：矿石块（可采集获得资源）、敌人单位（需要战斗消灭）、以及空方块（可以挖掘通过）。玩家需要根据当前层的构成来调整矮人的类型比例，例如矿石密集的层多放矿工，敌人多的层多放战士。

## 核心循环

放置矮人自动挖掘 → 获得矿石和资源 → 升级矮人装备和建筑 → 放置更强力的矮人继续挖掘

## 核心机制

- **自动放置系统**：玩家选择矮人类型并放置到网格上，矮人自动执行挖掘、战斗、建造等任务，降低操作门槛
- **资源采集链**：不同矿石有不同的价值和用途，普通矿石用于基础升级，稀有矿石用于高级装备制作
- **深度递进难度**：随着挖掘深度增加，矿石品质提升但敌人强度也同步增长，形成自然的难度曲线

## 为什么好玩

将放置类游戏的轻松感与塔防策略的深度结合，看着矮人们忙碌工作的画面本身就很有满足感，而深度递增带来的挑战又保持了足够的紧张感。

## 粘性来源

具体到机制层面：深度里程碑系统制造"再挖一层就睡觉"的心理——每次到达整数深度就解锁新内容，配合稀有矿石的随机掉落（老虎机式的变比奖励），让人不断想"再来一局看看能挖多深"。

## Meta 系统

- **装备升级系统**：用采集到的矿石为矮人打造更好的镐和武器
- **矮人招募系统**：解锁新类型的矮人（如爆破手、治疗师等）
- **对核心玩法的影响**：新矮人类型改变放置策略组合，装备升级让深入挖掘成为可能

## 实现难度

中等——自动寻路和AI逻辑有一定复杂度，矮人的挖掘路径规划、敌人遭遇判断、资源分配等需要精心设计。最大的技术难点是大量矮人单位同时进行自动化操作时的性能优化和逻辑一致性。
