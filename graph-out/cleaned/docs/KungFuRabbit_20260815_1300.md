# Kung Fu Rabbit

- **类型**: 横版动作平台 / 跑酷
- **平台**: Mobile (iOS + Android) / PC / 3DS
- **开发商**: Pastagames
- **首次发布**: 2012
- **一句话描述**: 以中国功夫为主题的横版跑酷游戏，玩家控制一只会功夫的兔子在竹林和古寺中穿梭

## 玩法规则

Kung Fu Rabbit是一款横向滚动的动作跑酷游戏。玩家控制一只穿着功夫服的兔子，在充满中国风情的场景中从左向右奔跑。场景包括竹林、古寺、悬崖、瀑布等中国传统元素。

游戏采用单按钮操作：点击/触摸屏幕让兔子跳跃。兔子会自动奔跑，玩家需要判断时机进行跳跃以避开障碍物和陷阱。二代加入了攻击能力——兔子可以在跳跃的同时发动功夫攻击，击碎途中的障碍物和敌人。

障碍物类型多样：地面尖刺需要跳过，悬挂的钟摆需要找准时机穿过，移动的平台需要在恰当的时机跳到上面，敌人需要跳跃攻击来消灭。部分关卡还有收集品（胡萝卜或金币）分布在危险位置，增加挑战。

游戏结束条件：兔子掉入深渊、被陷阱击中、或者被敌人碰到。

## 核心循环

自动奔跑 → 判断时机跳跃/攻击 → 清除障碍 → 收集物品 → 到达终点

## 核心机制

- **单按钮跳跃+攻击**: 点击跳跃，跳跃中再次点击发动功夫攻击——简洁的操作下包含两层策略
- **中国风场景设计**: 竹林、古寺、悬崖、瀑布等场景不仅视觉独特，也提供了不同的障碍组合
- **功夫攻击系统**: 在空中的攻击可以消灭敌人和击碎障碍物，为跑酷增加了动作元素
- **收集品分布**: 胡萝卜/金币分布在危险位置，鼓励玩家冒险走更难的路线
- **关卡分段设计**: 每个关卡分为多个小段，每段通过后自动保存进度

## 为什么好玩

Kung Fu Rabbit的乐趣在于将功夫动作与跑酷玩法的巧妙结合——单纯的跳跃躲避可能让你到达终点，但加上功夫攻击后，你可以主动清除障碍和敌人，这种从被动躲避到主动进攻的转变让游戏更有层次感。

## 粘性来源

粘性来自跑酷游戏的天然循环——"差一点就过了"的不甘心。每个障碍失败后你都能明确看到自己的失误（跳早了/跳晚了/没攻击），这种清晰的反馈让人想立刻重试。

## Meta 系统

关卡解锁系统：线性推进。收集品系统：每关有隐藏的胡萝卜/金币可收集。

## 实现难度

低 — 核心机制（自动奔跑+单按钮跳跃）简单，最大技术难点在于关卡设计的趣味性和难度曲线的平滑度。
