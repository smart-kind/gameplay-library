# Glow Artisan

- **类型**: 益智/解谜
- **平台**: Mobile (iOS)
- **开发商**: PocketGamer收录作品
- **首次发布**: 2010
- **一句话描述**: 一款以发光线条和色彩为主题的创意解谜游戏，通过连接光点来绘制图案并解决谜题。

## 玩法规则

在黑暗的画布上，玩家需要通过连接发光的光点来绘制线条和图案。每条连接都会产生光线效果，当光线照射到特定区域时会触发解谜效果。

1. 每个关卡的画布上分布着若干发光点和目标区域。玩家需要在光点之间画线连接，线条会发出光线照亮路径。

2. 光线的颜色可以变化，不同颜色的光线对目标区域有不同的效果。例如红色光线可以激活红色机关，蓝色光线可以冻结水流等。

3. 线条有长度限制，玩家需要合理规划连接路径。某些关卡要求用最少的线条完成目标，这增加了策略性。

4. 部分关卡存在障碍物阻挡光线路径，需要通过多次反射或折射来改变光线方向。反射镜和棱镜是关键道具。

## 核心循环

观察关卡布局 -> 连接光点绘制线条 -> 光线触发效果 -> 完成目标进入下一关

## 核心机制

- **光线连接系统**：通过在光点之间绘制线条来创建光线路径。线条的方向、长度和颜色决定了最终的光线效果。多条光线可以交汇产生混合色效果。

- **色彩解谜**：不同颜色的光线对环境和机关有不同的作用。混合色（如红+蓝=紫）可以解锁特殊区域。色彩组合是解谜的核心要素。

- **反射与折射**：关卡中放置的反射镜可以改变光线方向，棱镜可以将白光分解为多色光。利用这些光学元件可以创造出复杂的光线路径。

- **创意评分**：某些关卡允许自由创作，系统根据图案的复杂度和美观度给出评分。这种开放式解谜鼓励玩家发挥创意。

## 为什么好玩

将光学原理转化为视觉解谜游戏，光线在黑暗中绽放的效果极具美感。色彩混合和反射折射的机制让解谜有科学探索的趣味。

## 粘性来源

光学现象的探索好奇心，创意评分的追求，以及每个关卡新的光学组合带来的挑战。

## Meta 系统

外围成长系统：金币或经验积累用于解锁新关卡、新角色或新能力。部分游戏包含每日挑战或排行榜等社交竞争元素，鼓励玩家持续回归。

## 实现难度

中。光线渲染的视觉效果优化，以及色彩混合和反射路径的精确计算。
