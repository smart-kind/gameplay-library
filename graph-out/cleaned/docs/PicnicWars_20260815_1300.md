# Picnic Wars

- **类型**: 策略塔防 / 即时战略
- **平台**: Mobile (iOS + Android)
- **开发商**: Cactus Soft
- **首次发布**: 2012
- **一句话描述**: 卡通风格的策略对战游戏，玩家指挥蚂蚁部队进行攻防战斗

## 玩法规则

Picnic Wars是一款横向卷轴的策略对战游戏。画面被分为左右两个阵营，玩家控制一方的蚂蚁部队，与对手的蚂蚁部队展开战斗。屏幕左侧是玩家的基地，右侧是敌方基地，中间是战场。

玩家通过点击屏幕底部的卡牌来召唤不同类型的蚂蚁单位。每种蚂蚁单位消耗不同数量的"蜂蜜"（游戏内资源），蜂蜜随时间自动积累。单位被召唤后会自动向敌方基地推进，途中遇到敌方单位时会进入战斗。

游戏的核心策略在于兵种搭配和召唤时机。不同类型的蚂蚁有不同的角色：前排肉盾蚂蚁负责承受伤害，后排输出蚂蚁造成远程攻击，特殊功能蚂蚁（如治疗蚁、加速蚁）提供辅助效果。玩家需要在有限资源下做出最优的兵种组合。

当一方的基地被完全摧毁时，游戏结束。某些关卡中玩家还需要保护正在进行的"野餐"（一个需要防守的目标）。

## 核心循环

积累蜂蜜 → 召唤蚂蚁单位 → 推进/防守 → 摧毁敌方基地 → 解锁新关卡/兵种

## 核心机制

- **卡牌召唤系统**: 通过点击卡牌召唤不同兵种，卡牌消耗不同数量的蜂蜜资源
- **自动战斗**: 单位被召唤后自动移动和攻击，玩家专注于策略决策而非微操
- **兵种搭配**: 不同蚂蚁有不同定位（坦克、输出、辅助），需要合理搭配
- **资源管理**: 蜂蜜随时间积累，需要在"快速召唤弱单位"和"等待积累召唤强单位"之间权衡
- **关卡递进**: 随着游戏进行解锁新兵种和新关卡

## 为什么好玩

Picnic Wars的乐趣在于轻松的卡通美术风格与深度策略的完美结合。看着你精心搭配的蚂蚁部队浩浩荡荡地向敌方推进，与敌军在战场上激烈交锋，那种"运筹帷幄"的感觉非常满足。每个兵种都有独特的视觉效果和动画。

## 粘性来源

粘性来自策略游戏的天然循环——每次失败后你会思考"如果我换一种兵种组合会怎样"。新兵种的解锁提供了阶段性目标。

## Meta 系统

兵种解锁系统：随着关卡推进解锁新的蚂蚁单位。三星评价系统：部分关卡有条件达成。

## 实现难度

低 — 核心机制（单位自动移动+碰撞战斗）相对简单，最大技术难点在于AI寻路和大量单位同时存在时的性能优化。
