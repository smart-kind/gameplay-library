# Crazy Quest Express

- **类型**: 休闲射击 / 横版闯关
- **平台**: Mobile (iOS)
- **开发商**: PocketGamer Review
- **首次发布**: 2011
- **一句话描述**: 操控坦克在成群的鸡群中穿行，用机械臂或喇叭清除敌人

## 玩法规则

Crazy Quest Express 的故事背景是经典的"拯救公主"套路，但实际玩法非常独特——你操控一辆坦克，在一群迎面而来的鸡群中穿行。

根据关卡不同，你可以用从坦克前部伸出的可伸缩机械臂抓住鸡群，或者通过鸣喇叭把它们吹飞——两种操作都通过点击来完成。你的目标是保持坦克完好地到达舞台的另一侧——但不同颜色的鸡脚代表着不同的力量等级，这让事情变得复杂。

在每个关卡之间可以修理坦克，甚至升级它以应对迎面而来的敌人，但为什么要费这么多功夫呢？因为这里根本没有真正的游戏性可言。关卡只是由一辆坦克从左向右移动组成，你唯一的作用是在屏幕上移动它的位置或者用描述的方式消灭鸡群。

### 核心循环
操控坦克 → 清除鸡群敌人 → 到达终点 → 维修或升级坦克 → 进入下一关

### 核心机制
- **坦克移动**：控制坦克在屏幕上的位置，躲避或冲向敌人
- **机械臂抓取**：伸出机械臂抓住鸡群敌人
- **喇叭驱逐**：用喇叭声波清除鸡群
- **坦克升级**：在关卡之间修理或升级坦克以应对更多敌人
- **彩色等级系统**：鸡脚的颜色代表不同的力量等级

### 为什么好玩
这款游戏的概念很有趣——在鸡群中操控坦克的设定非常荒诞搞笑。但实际游戏过程中几乎没有真正的游戏性可言，只是看着坦克从左向右移动，玩家的角色非常被动。

### 粘性来源
几乎没有真正的粘性来源。游戏缺乏深度和挑战性，升级系统也没有实质意义，因为游戏本身过于简单。荒诞的设定可能会带来短暂的新鲜感，但很快就会失去吸引力。

### Meta 系统
坦克升级系统。玩家可以在关卡之间修理和升级坦克，但由于游戏本身的简单性，升级的意义不大。

### 实现难度
低。2D横向移动加上简单的碰撞检测，技术上没有太大挑战。最大的问题在于游戏设计本身缺乏深度。
