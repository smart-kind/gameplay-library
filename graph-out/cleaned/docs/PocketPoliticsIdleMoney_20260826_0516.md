# Pocket Politics: Idle Money

- **类型**: 放置经营 / 政治模拟
- **平台**: Mobile (iOS)
- **开发商**: Kongregate, Inc.
- **首次发布**: 2016
- **一句话描述**: Pocket Politics是一款政治主题的放置经营游戏。玩家从基层政客开始，通过自动化游说、筹集竞选资金，逐步晋升为世界总统。

## 玩法规则

游戏以卡通风格的政治场景呈现，屏幕显示当前职位、资金数量和可用的游说团队。底部有升级和互动按钮。玩家通过投资金币解锁不同的游说团队，每个游说团队自动产生资金，这是游戏的核心收入来源。资金用于竞选更高职位：从地方政客到州长、总统候选人，最终成为世界总统。每个新职位带来更高的收入倍率。可以收集知名政治家的背书，这些背书提供永久的收入加成。声望系统允许玩家重置进度以获取追随者，追随者提供全局加成，让下次发展更快。

## 核心循环

投资游说团队 -> 自动产生资金 -> 竞选更高职位 -> 收集政治家背书 -> 声望重置 -> 更快发展 -> 重复

## 核心机制

- 自动化收入：游说团队自动产生资金，无需持续操作
- 职位晋升：从基层到世界总统的阶梯式职业发展
- 背书系统：收集知名政治家的背书获得永久加成
- 声望重置：牺牲当前进度获取全局加成，加速下次发展

## 为什么好玩

政治主题在放置游戏中非常少见，带来了独特的幽默感。从无名小卒到世界总统的职业阶梯提供了清晰的成长目标，游说团队自动赚钱的设定既讽刺又有趣。

## 粘性来源

职位晋升提供明确的进度目标；声望系统让每次重置都更有价值；活动排行榜提供竞争维度

## Meta 系统

有声望系统（重置获取追随者）、背书收集系统（政治家永久加成）、活动排行榜（竞争系统）。内购可加速进度。

## 实现难度

中。核心难点在于放置经营玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
