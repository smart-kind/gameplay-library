# 水果忍者（Fruit Ninja）

- **类型**: 动作 / 休闲 / 街机
- **平台**: Mobile (iOS+Android) / PC / 主机
- **开发商**: Halfbrick Studios
- **首次发布**: 2010
- **一句话描述**: 用手指滑动屏幕切开抛向空中的水果，避免切到炸弹，尽可能获得高分。

## 玩法规则

游戏画面底部是刀痕，水果从底部被抛向空中，划过抛物线后掉落。玩家用手指在屏幕上滑动，滑过的轨迹会留下一道刀光，被刀光划过的水果会被切开成两半。

水果有多种类型：西瓜、苹果、橙子、香蕉、草莓等，每种水果切开后有不同的视觉和音效反馈。切到炸弹则立即结束游戏（经典模式）或扣分（其他模式）。

特殊水果有特殊效果：石榴切开后爆出多个小水果（可以连续切割得分）；火龙果切开有额外加分。这些特殊水果增加了游戏的变数。

游戏有多种模式：经典模式（限时3分钟，切到炸弹扣分）；街机模式（无限时间但炸弹更多）；禅模式（无炸弹，纯切割体验）。每种模式有不同的计分规则。

## 核心循环

水果抛出 → 手指滑动切割 → 获得分数 → 水果速度加快 → 切到炸弹游戏结束 → 重新开始

## 核心机制

- **触控切割**：用手指滑动切割水果的操作非常直觉和满足。刀光的视觉反馈和水果切开的音效配合得很好，创造出强烈的"切水果"快感。
- **连击系统**：一次滑动切开多个水果获得连击加分（Double、Triple等）。这鼓励玩家等待多个水果同时出现在空中时一次性切割，增加了策略性。
- **炸弹回避**：炸弹与水果一起被抛出，形状和颜色有明显区分（黑色圆形带引信），但仍可能在快速切割中误切。这给游戏增加了紧张感。
- **水果组合**：某些关卡有特定水果组合要求（如切到10个西瓜、切开所有橙子等），完成任务获得额外奖励。

## 为什么好玩

简单的操作（滑动屏幕）配合出色的视觉和音效反馈，创造出一种纯粹的快乐。切开水果的瞬间非常满足，连击时的屏幕特效更是让人兴奋。

## 粘性来源

- **高分挑战**：不断刷新个人最高分是主要动力
- **连击快感**：一次切割多个水果的连击反馈非常上瘾
- **模式多样性**：经典、街机、禅三种模式满足不同需求
- **成就系统**：解锁成就和特殊刀痕提供长期目标

## Meta 系统

- **刀痕解锁**：通过游戏进度或成就解锁不同颜色和样式的刀光
- **背景解锁**：解锁新的游戏背景主题
- **每日挑战**：完成每日任务获得奖励

## 实现难度

低 + 核心是触摸轨迹检测和碰撞判断，技术实现简单。最大难点在于切割动画的流畅度和水果抛出的物理效果。
