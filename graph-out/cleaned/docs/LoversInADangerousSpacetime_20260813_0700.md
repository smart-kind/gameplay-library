# 危险时空的恋人（Lovers in a Dangerous Spacetime）

- **类型**: 合作动作 / 太空射击
- **平台**: Mobile (iOS+Android) / PC / Switch / PS4
- **开发商**: Asteroid Base
- **首次发布**: 2015
- **一句话描述**: 1-2人合作操控一艘太空飞船的不同舱位（引擎、武器、护盾），在危险时空中营救小动物

## 玩法规则

玩家操控一艘圆形的太空飞船，飞船内部被分成多个功能舱位：引擎室（控制移动）、武器舱（发射子弹/导弹）、护盾舱（防御敌方攻击）、锚舱（抓取太空中的物体和小动物）。

单人模式下玩家需要在不同舱位之间快速切换来操作飞船；双人模式下两人各控制一部分舱位，需要协调配合。

飞船在太空中移动，周围有敌人、陨石、激光障碍和被困的小动物。需要击退敌人、避开障碍、营救小动物。

营救的小动物会提供被动加成（如自动射击、加速等），目标是活着完成关卡，尽可能多地救动物。

## 核心循环

操作飞船舱位 → 击退敌人/营救动物 → 获得加成 → 完成关卡

## 核心机制

- 舱位分工机制：飞船的每个功能都在独立的舱位中，操作一个舱位意味着放弃其他功能，制造了决策压力。
- 合作依赖：双人模式下，引擎和武器往往需要不同人控制，沟通不畅直接导致游戏失败。
- 动物加成系统：营救的小动物提供被动增益，但占据飞船空间，需要在防御和火力之间做取舍。

## 为什么好玩

合作混乱的喜剧效果——两个人手忙脚乱地切换舱位，失误频出但笑声不断。通关后的成就感来自真正的协作。

## 粘性来源

合作模式中的喜剧效果——每次失败都是笑点，笑声本身就成了继续玩下去的动力。动物收集的收集欲也是长线目标。

## Meta 系统

关卡解锁系统：通关一定数量后解锁新的世界区域。动物收集图鉴提供了长线目标。

## 实现难度

中高。需要处理飞船多舱位切换、弹道物理、敌人AI、合作模式同步。最大技术难点：双人模式的输入管理和舱位切换的流畅过渡。
