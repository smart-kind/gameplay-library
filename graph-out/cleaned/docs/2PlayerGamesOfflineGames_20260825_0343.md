# 双人离线游戏合集（2 Player Games : Offline Games）

- **类型**: 多人派对/本地对战
- **平台**: Mobile (iOS+Android)
- **开发商**: Moreno Maio
- **首次发布**: 2019
- **一句话描述**: 多款经典2人游戏合集，支持AI对战

## 玩法规则

2 Player Games 专注于双人同设备对战体验。主界面以图标网格展示所有可用游戏：乒乓球（移动球拍）、旋转大战（把对手推出擂台）、空气曲棍球（推动球进对方球门）、贪吃蛇（避免撞到对方）、台球、井字棋、点球大战、相扑等。

每个游戏的操作方式不同，但都很简单：用手指拖动控制角色或物品。例如，乒乓球中上下拖动球拍；相扑中推动对手；台林中瞄准击球。

游戏支持AI对手——如果没有朋友在身边，可以和AI对战。AI难度可调，适合不同水平的玩家。

所有游戏都采用极简的图形风格，让玩家专注于对战本身而非花哨的视觉效果。

## 核心循环

选择游戏 → 与朋友/AI对战 → 记录比分 → 继续下一款游戏/杯赛

## 核心机制

- **机制1**：经典游戏数字化：把乒乓球、台球、井字棋等经典双人游戏搬到手机上，保留了面对面竞争的乐趣。
- **机制2**：AI对手系统：没有朋友时可以和AI玩，确保游戏始终可用。AI难度可调节。
- **机制3**：极简视觉风格：去除多余视觉元素，让玩家专注对战。减少视觉干扰。

## 为什么好玩

这款游戏的核心是'把经典面对面游戏数字化'。和朋友在沙发上用一台手机打乒乓球、下棋、打台球——这种体验是独特的。极简的视觉风格反而增强了专注度。',可以毁掉友谊'的标语也体现了它的有趣竞争性。

## 粘性来源

粘性来源：(1) 经典游戏的永恒吸引力；(2) 面对面竞争的独特社交体验；(3) AI对手确保单人也能玩；(4) 多款游戏轮换不会疲劳；(5) 比分记录功能支持多轮杯赛。

## Meta 系统

比分记录系统（跨游戏累计，支持多轮杯赛）。无复杂付费系统。

## 实现难度

低。每款小游戏逻辑简单，AI实现（如乒乓球AI、台球AI）有一定技术含量。整体开发难度不高。
