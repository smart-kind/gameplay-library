# Matchland Quest（Matchland Quest）

- **类型**: 三消 / RPG冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: Wooga
- **首次发布**: 2019
- **一句话描述**: 将RPG冒险叙事与三消解谜结合的手游，玩家通过匹配方块来推进冒险故事并夺回被占领的土地。

## 玩法规则

游戏采用双线结构：三消棋盘是核心玩法，RPG冒险是叙事框架。在三消棋盘上，玩家交换相邻的彩色方块来匹配3个或更多同色方块。匹配4个方块产生十字火箭道具，匹配5个产生彩虹球道具。消除方块可以对"敌人"造成伤害，不同的方块颜色对应不同的攻击类型。

RPG冒险部分以地图形式呈现——玩家控制的角色沿着一条冒险路径前进，路径上分布着各种敌人和关卡。每通过一个三消关卡就能在地图上前进一步，击败路上的敌人。关卡目标包括：在限定步数内达到目标分数、消除特定数量的特定颜色方块、清除地图上的障碍物等。

角色拥有不同的技能和属性，通过关卡升级可以提升能力。部分关卡需要特定角色或特定技能组合才能通过，鼓励玩家培养多个角色。

## 核心循环

挑战三消关卡 → 对敌人造成伤害/完成任务 → 推进冒险地图 → 解锁新区域和角色 → 获得升级材料 → 提升角色能力 → 挑战更强敌人

## 核心机制

- **三消RPG融合**：将传统的三消玩法嵌入RPG框架中——消除方块等同于"攻击"，特殊道具等同于"技能"，关卡目标等同于"击败敌人"。这种融合让三消不再只是纯粹的解谜，而是有叙事驱动的冒险体验。
- **角色能力系统**：不同角色有不同的被动技能和主动技能。有些角色擅长消除特定颜色的方块，有些角色可以在步数紧张时提供额外步数。角色选择影响关卡策略。
- **地图进度可视化**：冒险地图提供了清晰的进度反馈——每过一关角色就在地图上前进一段，击败敌人、发现宝箱、解锁新区域。这种可视化进度比单纯的"第X关"更有成就感。
- **事件关卡多样性**：除了标准三消关卡，还有Boss战（需要在限定步数内造成足够伤害）、宝箱关（收集特定物品）、障碍关（清除地图上的障碍物）等不同类型。

## 为什么好玩

Matchland Quest聪明地将"三消"这个已被验证的核心玩法与"RPG冒险"这个提供长期动力的框架结合。对于三消玩家来说，RPG元素提供了"为什么我要玩下一关"的理由——想看到故事发展、想击败Boss、想解锁新区域。对于RPG玩家来说，三消提供了轻松的解谜体验作为"战斗"方式。Wooga的关卡质量保证了基础玩法的趣味性。

- **关卡目标与叙事的结合**：每个关卡不仅仅是解谜挑战，还是故事的一部分——"清除路上的敌人"、"打开被封锁的通道"、"击败守卫Boss"。关卡目标与叙事目标一致，让玩家感觉每次消除都在推动故事前进。
- **技能释放时机**：角色的主动技能可以在三消过程中释放，好的释放时机可以扭转局势——在步数紧张时使用额外步数技能，在棋盘有利时使用伤害加成技能。

## 粘性来源

- **叙事推进的好奇心**：想知道"接下来会发生什么"是最基本的驱动力之一。故事中的角色和冲突让玩家有理由持续游玩
- **角色培养的收集欲**：解锁和培养不同角色提供了类似"收集"的满足感，每个新角色都带来了新的策略可能性
- **Boss战的挑战感**：Boss战关卡需要玩家全力以赴使用所有策略和道具，通关后的成就感远超普通关卡

## Meta 系统

- **冒险地图系统**：核心Meta系统。线性地图上的节点代表关卡，完成关卡推进角色位置，解锁新区域和新故事章节。
- **角色升级系统**：通过关卡获得经验值升级角色，提升基础属性和解锁新技能。
- **每日任务**：每日刷新的任务目标提供额外奖励。

## 实现难度

低到中。三消引擎和地图进度系统都是成熟技术。主要工作量在内容创作——关卡设计、角色设计、故事编写、美术资源。三消与RPG的融合设计需要仔细平衡数值（如伤害量、角色等级、关卡难度的匹配关系）。
