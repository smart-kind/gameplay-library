# FMX IV Pro（FMX IV Pro）

- **类型**: 摩托车越野 / 体育竞速
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立游戏开发者
- **首次发布**: 约2012
- **一句话描述**: 一款摩托车越野竞速游戏，玩家在复杂的赛道上完成特技表演和竞速挑战

## 玩法规则

游戏画面采用2D横版卷轴视角，展示一个摩托车越野赛道。赛道包含各种地形——土坡、跳台、环形赛道、狭窄的平衡路段和各种障碍物。玩家控制一辆越野摩托车，从起点出发向终点前进。

操作方式简洁直观：屏幕左侧虚拟按钮控制加速和刹车，右侧控制前倾和后仰。在飞越跳台时，玩家需要调整摩托车的空中姿态——后仰可以让车头抬起完成特技动作，前倾则帮助平稳落地。

特技系统是游戏的核心玩法之一。在空中完成特定姿态保持（如后轮行驶、前轮行驶、360度翻转等）可以获得特技分数。连续完成多种特技可以获得连击加分。但如果落地角度不对，摩托车会摔倒，需要重新开始当前赛段。

赛道设计中包含检查点（checkpoint），到达检查点后即使失败也会从最近的检查点重新开始，而不是从头开始。这降低了高难度赛段的挫败感。

游戏有多种模式：计时赛模式（以最快速度完成赛道）、特技赛模式（在规定时间内获得最高特技分数）、自由练习模式（无时间限制，熟悉赛道和技巧）。

摩托车有多种可调配件——悬挂系统（影响落地缓冲）、引擎（影响加速和极速）、轮胎（影响抓地力）。升级配件可以提升在不同赛道条件下的表现。

游戏结束条件：在计时赛中超过时间限制则失败；在特技赛中分数未达最低要求则失败。连续摔倒多次（通常3次）也会强制结束当前赛段。

## 核心循环

完成关卡或任务 → 获得评分和奖励 → 解锁新关卡、新角色或新道具 → 挑战更高难度的内容

## 核心机制

- **渐进难度设计**：关卡难度从简单到复杂逐步递增，每个新关卡引入1-2个新机制或变化，确保玩家在适应当前难度的同时学习新玩法。
- **即时反馈系统**：每次操作后系统立即给出视觉和音效反馈，强化操作的成就感和爽快感。
- **资源约束机制**：玩家的操作次数、时间或生命值有限，需要在约束条件下做出最优决策，增加了策略深度。
- **评价与重玩驱动**：1-3星评级系统鼓励玩家在通关后反复挑战以获得更高评价。

## 为什么好玩

这款游戏通过简洁直观的操作方式和逐步提升的难度曲线，让玩家在每次尝试中都能获得明确的进步感。关卡设计的多样性确保了长时间游玩不会感到重复乏味，而即时反馈系统则让每次操作都充满满足感。

## 粘性来源

具体到机制层面：1) 1-3星评分系统激发"再试一次拿到三星"的心理驱动力——玩家往往在2星时感到"差一点就完美"，这种不甘心是推动重复游玩的核心力量；2) 关卡逐步解锁的设计制造了持续的目标感和期待感；3) 收集元素（特殊道具、角色解锁、成就系统）提供了额外的长期目标。
