# Infinity Loop: Relaxing Puzzle（Infinity Loop）

- **类型**: 连线解谜 / 逻辑 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: INFINITY GAMES, LDA
- **首次发布**: 2015
- **一句话描述**: 通过旋转管道片段创建无限循环连线的极简逻辑解谜游戏。

## 玩法规则

屏幕呈现一个网格，网格中散布着各种管道片段——直管、弯管、T型管、十字管等。这些片段以随机方向放置，尚未连接成完整的回路。

玩家操作：点击一个管道片段，它旋转90度。再次点击继续旋转。玩家需要将所有管道片段旋转到正确的方向，使它们首尾相连，形成完整的闭合回路（loop）。当一个回路形成时，管道会发光或变色，表示该回路已完成。

游戏没有步数限制、没有时间压力。玩家可以在任何时候旋转任何管道，直到所有回路都连接完成。随着关卡推进，网格变大、管道类型增多、回路数量增加，难度逐步提升。

## 核心循环

观察未连接的管道布局 → 旋转管道片段 → 形成回路（视觉确认） → 继续旋转其他管道 → 所有回路完成进入下一关

## 核心机制

- **旋转连接系统**：每个管道片段只能旋转（不能移动或替换），玩家通过旋转调整方向使片段之间正确连接。这个机制简洁但深度足够——每个片段有4种可能的朝向，正确组合需要逻辑推理。
- **回路形成反馈**：当一个完整的回路形成时，管道会以视觉方式（发光、变色、动画）给予即时反馈。这个设计让玩家明确知道"这部分做对了"，同时获得视觉满足感。
- **极简无压设计**：没有计时器、没有步数限制、没有惩罚机制。玩家可以随时思考、随时尝试、随时修正。这种设计让游戏适合任何技能水平——新手可以慢慢推理，老手可以快速解题。

## 为什么好玩

旋转管道形成回路的逻辑谜题简单优雅，完成时的视觉反馈（发光的回路）提供了即时的满足感。极简的UI和无压力的节奏让它成为一款理想的放松游戏——不需要紧张，只需要专注。

## 粘性来源

核心是"完成回路"的视觉+逻辑满足感。看到杂乱无章的管道在旋转之后变成完美发光的回路，这种秩序感让人放松和满足。无尽模式（endless mode）提供了无限的关卡，适合随时随地的碎片化游玩。禅模式（zen mode）更是强调放松体验，帮助玩家清空思绪。

## Meta 系统

无尽模式（Endless Mode）：无限生成的关卡，没有终点，适合想要持续游玩的玩家。逻辑技能提升：游戏潜移默化地锻炼空间推理和模式识别能力。

## 实现难度

低。核心逻辑是网格中的管道连接检测算法——检查相邻片段的接口是否匹配。视觉渲染和动画相对简单。最大技术难点在于关卡生成算法——需要确保每个生成的关卡都有且仅有唯一的解，否则玩家可能面临无解或多解的困扰。
