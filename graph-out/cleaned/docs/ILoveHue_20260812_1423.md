# 色彩之爱（I Love Hue）

- **类型**: 色彩排序 / 解谜 / 禅意
- **平台**: Mobile (iOS+Android)
- **开发商**: Zut!
- **首次发布**: 2016
- **一句话描述**: 一款通过交换色块来恢复渐变色矩阵的禅意解谜游戏，适合色觉敏感和喜欢整理的人。

## 玩法规则

游戏画面是一个由彩色方块组成的矩阵（通常是6×8或更大）。大部分色块已按渐变规律排列，但部分被随机打乱。
玩家的操作：点击选中一个色块，再点击另一个色块交换它们的位置。也可以滑动直接交换相邻色块。
目标：通过交换色块，让整张色板恢复正确的渐变顺序。渐变可能是水平方向（左到右由深到浅）、垂直方向、或双方向。
判定：当所有色块都处于正确位置时，关卡自动完成，色板会短暂高亮显示。
色板有不同的形状（矩形、心形、花朵等），增加了视觉趣味。
没有倒计时或移动次数限制，纯放松体验。
每个关卡的色板使用不同的色彩空间（RGB、HSV、LAB等），挑战玩家对不同类型渐变的识别能力。

## 核心循环

观察色块渐变规律 → 找出错位色块 → 交换色块位置 → 恢复完整渐变

## 核心机制

- **色彩渐变识别**：核心挑战是识别色板中的渐变方向（水平、垂直、对角线）和渐变步长（每次变化多少色相/明度）。
- **无压力体验**：没有时间限制、没有移动次数限制、没有失败惩罚。纯粹的观察和调整体验。
- **多样形状**：色板有矩形、心形、圆形、花朵等不同形状，非规则形状增加了渐变识别的复杂度。
- **色觉友好**：游戏提供色觉辅助模式，帮助色弱或色盲玩家区分细微的色差。

## 为什么好玩

将色彩渐变的视觉美感和整理的满足感结合。当最后一块色块归位、完整渐变呈现的那一刻，有强烈的视觉愉悦感。

## 粘性来源

整理强迫症的满足感；色彩渐变的视觉愉悦；无压力体验适合放松；新关卡持续提供不同的渐变模式挑战。

## Meta 系统

关卡解锁系统——完成一定数量关卡后解锁新的色板形状和渐变类型。

## 实现难度

低 — 核心是数组交换和颜色插值验证，技术实现简单。最大技术难点在于色板生成算法——需要确保每个关卡有唯一正确解且难度可控。

## 游戏变体

多数游戏在不同平台上发布了HD版、重制版或移植版本，核心玩法保持不变。
