# Tap Titans 3

- **类型**: 放置 / 点击
- **平台**: Mobile
- **开发商**: Game Hive
- **首次发布**: 2025
- **一句话描述**: 热门点击者系列的续作，史诗 Boss 战和自动英雄升级。

## 玩法规则

点击屏幕造成伤害，雇佣英雄自动攻击，升级装备和技能。离线期间英雄继续战斗。核心是数值递增——每次升级都让数字变得更大，满足感更强。

Boss 战是游戏的高潮——限时内造成足够伤害即可通关，失败则回到上一个检查点。英雄技能搭配和装备选择影响效率。

## 核心循环

点击造成伤害 → 雇佣英雄 → 升级装备 → 挑战 Boss

## 核心机制

- 点击伤害：基础操作产生递增数值
- 英雄自动化：雇佣英雄自动战斗
- Boss 限时挑战：时间压力增加紧张感
- 离线进度：英雄继续战斗
- 装备系统：升级武器和技能

## 为什么好玩

数字不断增大的满足感。每次升级都看到伤害数字翻倍，Boss 战的限时压力让被动玩法有了紧张时刻。

## 粘性来源

- 数值递增的满足感：看到数字不断变大
- Boss 战压力：限时挑战的紧张感
- 离线成长：不在线也在进步
- 英雄搭配：不同英雄技能组合

## Meta 系统

英雄等级、装备和技能升级。通过金币和宝石提升能力。

## 实现难度

低。数值递增系统是成熟模板，难点在于平衡成长曲线和付费设计。
