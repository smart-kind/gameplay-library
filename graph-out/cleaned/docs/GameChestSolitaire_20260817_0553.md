# Game Chest: Solitaire

- **类型**: 卡牌/益智
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer收录作品
- **首次发布**: 2011
- **一句话描述**: 一款收录多种经典纸牌玩法的合集游戏，包含Klondike、Spider、FreeCell等多种变体。

## 玩法规则

游戏合集包含多种经典纸牌游戏变体，玩家可以在一款游戏中体验不同规则的纸牌挑战。每种变体都有独特的规则和策略。

1. Klondike（经典接龙）：7列纸牌从上到下依次排列1-7张，玩家需要按花色从A到K依次叠放到4个基座。列间可以按红黑交替、递减顺序移动纸牌。

2. Spider（蜘蛛纸牌）：使用两副牌，玩家需要将13张同花色纸牌从K到A依次排列并移除。所有列必须保持递减顺序排列。

3. FreeCell（空当接龙）：所有牌面朝上分布在8列中，有4个自由格用于临时存放纸牌。玩家需要将纸牌按花色从A到K移至基座。

4. 每种变体的目标都是将所有纸牌整理好，但规则和难度各不相同。玩家可以通过撤销、提示等功能辅助游戏。

## 核心循环

选择纸牌变体 -> 洗牌发牌 -> 按规则移动纸牌 -> 完成排列或无法继续 -> 选择新游戏

## 核心机制

- **多种变体规则**：包含Klondike、Spider、FreeCell等多种经典纸牌玩法，每种规则独特但都围绕纸牌的排序和移动展开。

- **辅助功能**：提供撤销、提示、自动完成等辅助功能，降低新手入门门槛。同时保留无辅助的挑战模式供高手使用。

- **统计与成就**：记录每局游戏的步数、时间和胜率，设有各种成就目标（如无撤销通关、限时通关等）。

- **主题与定制**：可选不同的牌面设计和背景主题，让长时间游玩保持视觉新鲜感。

## 为什么好玩

经典纸牌游戏的数字化呈现，随时随地都能玩。多种变体满足不同难度偏好，从休闲放松到极限挑战都有。

## 粘性来源

纸牌游戏的天然成瘾性加上统计数据的自我挑战，追求更少步数和更高胜率的欲望让人不断开新局。

## Meta 系统

外围成长系统：金币或经验积累用于解锁新关卡、新角色或新能力。部分游戏包含每日挑战或排行榜等社交竞争元素，鼓励玩家持续回归。

## 实现难度

低。多种变体规则的准确实现和发牌算法的随机性保证。
