# 2 3 4 Player Games

- **类型**: 多人本地派对
- **平台**: Mobile (iOS+Android)
- **开发商**: Penji Games B. V.
- **首次发布**: 2017
- **评分**: ⭐ 4.2/5 (5,982 评价)
- **价格**: Free
- **一句话描述**: 支持2-4人在同一设备上同时游玩的迷你游戏合集，适合朋友聚会。

## 玩法规则

游戏将屏幕分割为2/3/4个区域，每个玩家控制一个区域。每款迷你游戏有不同的规则，但都使用简单的单指触控。玩家同时操作，而不是轮流——例如：两人同时点击比赛谁更快、四人同时控制方向躲避障碍等。游戏类型包括：反应力测试、节奏点击、记忆配对、躲避障碍等。每款游戏持续30-60秒，快速决出胜负。游戏结束后显示排名和简短动画庆祝/安慰。

## 核心循环

选择人数 → 选择游戏 → 同时游玩 → 查看排名 → 再来一局

## 核心机制

- 分屏多人：2-4人在同一设备同时游玩，无需多设备
- 同时操作：不是轮流制，所有人同时操作增加紧张感
- 快速一局：每款游戏30-60秒，节奏明快

## 为什么好玩

朋友聚在同一部手机前同时操作，竞争和搞笑并存。规则简单到不需要教学，任何人都能立刻上手。

## 粘性来源

社交聚会场景刚需、多款游戏轮换、简单上手的低门槛

## Meta 系统

无——纯本地多人游戏，无在线系统。依赖社交场景驱动。

## 实现难度

低——分屏+简单触控，技术实现容易，难点在于设计有趣的多人互动
