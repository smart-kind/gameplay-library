# Color Zen

- **类型**: 解谜 / 色彩
- **平台**: Mobile (iOS+Android) / Switch / PC
- **开发商**: Large Animal Games / Cypronia
- **首次发布**: 2018
- **一句话描述**: 一款极简主义色彩解谜游戏，玩家通过切换节点颜色来让所有相邻节点颜色一致，追求极致的平静体验

## 玩法规则

游戏呈现一个由多个节点和连线组成的网络图。每个节点显示一种颜色（通常是两种颜色之一）。

玩家点击一个节点，该节点及其所有直接相连的邻居节点会同时切换颜色。目标是通过最少的点击次数，让所有节点变成同一颜色。

每次点击后，节点颜色的变化遵循简单规则：被点击的节点和邻居切换为另一种颜色。玩家需要预判连锁反应，规划最优点击顺序——先点击哪个节点会影响最终结果。

游戏没有步数限制也没有计时，强调冥想式的平静体验。每关都有最优解（最少步数），系统会在完成后显示。后续关卡引入三种颜色，节点间的连接关系也更复杂，形成更密集的网络图。

游戏配乐与环境音效极简，只有柔和的切换声和背景白噪音。这种设计强化了冥想般的解谜体验。

## 核心循环

观察颜色分布 → 点击节点切换颜色连锁 → 使所有节点同色过关

## 核心机制

- **连锁切换**：点击一个节点影响其所有邻居，形成连锁反应
- **最优解追求**：每关有理论最少步数，鼓励反复尝试优化
- **多色进阶**：从双色到三色，逐步增加颜色数量和节点复杂度

- **环境音效**：极简的声音设计强化冥想体验

## 为什么好玩

极简规则下隐藏着丰富的策略空间。找到最优解时的简洁之美令人愉悦。无时间压力的设计让解谜过程如冥想般平静。

## 粘性来源

追求最优解的执念是核心粘性。每次'差一步就最优'的感觉让人不断重试。无压力设计反而让人更愿意反复挑战。

## Meta 系统

无。纯解谜体验。

## 实现难度

低-中 — 规则简单但策略有深度。最大技术难点是最优解的计算和验证。
