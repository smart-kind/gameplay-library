# 地狱边境（Limbo）

- **类型**: 解谜 / 平台跳跃
- **平台**: PC / Mobile (iOS+Android) / Switch / PlayStation / Xbox
- **开发商**: Playdead
- **首次发布**: 2010
- **一句话描述**: 一款黑白风格的横版解谜平台游戏，玩家控制一名不知名的小男孩，在充满死亡陷阱的地狱边缘世界中寻找失踪的

## 玩法规则

玩家在2D横版卷轴场景中探索，通过点击/滑动控制角色移动和互动。游戏中的机关包括致命的陷阱、重力反转、时间控制等谜题。玩家需要观察环境线索，利用物理引擎解决谜题。每个谜题都有唯一的解法，但游戏不会给出明确提示，完全依靠玩家试错和观察。

画面采用独特的黑白剪影风格，前景和背景以不同灰度区分，营造压抑而神秘的氛围。音效极简，只有环境声和角色动作声，增强了孤独感和紧张感。

游戏目标是通过一系列精心设计的关卡，到达旅途的终点。玩家死亡后会从检查点重新开始，死亡次数不限。

## 核心循环

观察环境 → 尝试解谜 → 失败学习 → 成功通过 → 进入下一谜题

## 核心机制

- 黑白剪影视觉风格：通过极简的黑白对比营造独特美学，降低视觉噪音，让玩家聚焦于谜题本身。前景角色为纯黑剪影，背景以灰度渐变呈现深度感。

- 环境叙事：游戏没有任何文字或对话，故事通过场景细节和角色行为自然传达。这种设计让每个玩家都能产生不同的解读。

- 物理引擎谜题：游戏中的谜题基于真实的物理规则——重力、惯性、杠杆、压力板等。玩家需要在试错中理解每个场景的物理逻辑。

- 死亡学习机制：玩家会反复死于各种隐蔽陷阱，但每次死亡都是学习机会。这种设计让失败变得有趣而非沮丧。

## 为什么好玩

每次解开一个看似无解的谜题时带来的成就感，以及发现新死法时的好奇心驱动，构成了持续游玩的动力。极简的视听风格反而放大了情感冲击——当小男孩在黑暗中孤独前行时，玩家会本能地产生保护欲。

## 粘性来源

好奇心（下一个场景是什么样？）+ 不甘心（这个谜题一定还有其他解法）+ 成就感（终于过了这个难关！）。黑白极简画面降低了认知负担，让解谜本身成为纯粹的享受。

## Meta 系统

无外围系统。游戏的吸引力完全来自核心玩法的精妙设计。

## 实现难度

中 — 2D平台跳跃 + 物理谜题，技术难度主要在于关卡设计而非代码实现。最大的技术难点是设计一套由浅入深的谜题系统，让玩家在不知不觉中掌握所有机制。
