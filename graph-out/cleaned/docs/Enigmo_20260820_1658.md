# Enigmo

- **类型**: 3D物理益智解谜
- **平台**: Mobile (iOS+Android) / Mac
- **开发商**: Pangea Software, Inc.
- **首次发布**: 2008（原版），2019（移动版）
- **一句话描述**: 一款3D物理谜题游戏，玩家通过放置和旋转各种道具，引导流动的液体到达指定容器。

## 玩法规则

游戏画面呈现一个3D立体场景，液体（水、油或岩浆）从顶部的滴漏装置持续流出，在重力作用下自由下落并在墙壁间弹跳。玩家需要在液体流动路径上放置各种类型的导流板和容器，改变液体的流动方向，最终将液体引导到目标容器中。

道具类型包括各种倾斜的导流板、漏斗、管道等，每种道具可以在3D空间中进行移动和旋转。玩家需要根据液体的物理特性（水是常规流动，油可能更轻，岩浆可能更重）调整策略。不同关卡可能混合多种液体类型，每种液体有不同的行为特性。

关卡目标通常是在限定时间内将指定数量的液体导入目标容器。玩家通过观察液体的流动轨迹，预判其运动路径，然后放置合适的导流装置。

## 核心循环

观察液体流动 → 放置导流装置 → 引导液体到目标 → 解锁新关卡

## 核心机制

- **3D液体物理模拟**：液体在3D场景中遵循真实的重力和碰撞物理规律，在墙壁和道具表面弹跳流动。玩家需要理解三维空间中的物理运动规律来规划解决方案。
- **多材质液体系统**：水、油、岩浆三种液体类型具有不同的物理行为，有些关卡需要同时处理多种液体，增加了策略维度。
- **道具旋转系统**：每种导流道具可以在3D空间中旋转角度，微小的角度差异可能导致液体流向完全不同的方向，提供精细的控制空间。

## 为什么好玩

3D液体流动的视觉效果本身就非常吸引人——看着液体在玩家精心设计的导流系统中流动并最终汇入目标容器，有一种类似"鲁布·戈德堡机械"的满足感。3D空间带来的额外维度让解谜深度远超传统的2D物理游戏。

## 粘性来源

"液体终于流进去了！"的成就感是核心粘性。每次液体按预期路径流动并成功到达目标的时刻，都能产生强烈的正面反馈。3D旋转带来的"差一点就成功"的感觉驱动玩家不断微调角度重新尝试。

## Meta 系统

包含多人网络对战模式（通过Game Center联机），玩家可以在同一关卡中竞争，看谁能更高效地完成任务。

## 实现难度

高。3D液体物理模拟是核心技术难点——需要实现流体动力学计算、碰撞检测、以及多类型液体的交互效果。最大技术难点在于在移动设备上保持3D物理模拟的流畅运行，同时确保液体行为的视觉真实性和物理准确性。
