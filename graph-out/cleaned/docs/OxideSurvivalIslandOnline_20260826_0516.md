# Oxide: Survival Island Online

- **类型**: 多人在线生存 / 开放世界
- **平台**: Mobile (iOS)
- **开发商**: HYPERHUG LTD
- **首次发布**: 2021
- **一句话描述**: Oxide: Survival Island是一款硬核多人在线生存游戏。玩家被投放到危险的岛屿上，需要采集资源、制造工具、建造基地，在三个不同气候生物群落中求生。

## 玩法规则

游戏以3D第一人称或第三人称视角呈现荒岛世界。屏幕上有生命值、饥饿度、口渴度等状态指示器，底部是物品栏和快捷操作栏。玩家开局只有基础工具，需要在岛上采集木材、石材、食物等资源，通过制作系统将原材料加工成更高级的工具、武器和建筑材料。游戏包含三个生物群落：寒冷区、温带区、热带区，每个区域有不同的资源分布和环境挑战。多人系统允许玩家组队合作或对抗其他玩家，可以建造基地、掠夺敌方营地、交易资源。天空中有直升机巡逻，增加了不可预测的危险因素。

## 核心循环

采集资源 -> 制作工具和武器 -> 建造基地 -> 与其他玩家合作或对抗 -> 扩展领土 -> 重复

## 核心机制

- 三气候系统：寒冷/温带/热带三个生物群落各有不同的资源和环境挑战
- 深度制作系统：从简陋工具到高级武器和防御工事的制作链
- 多人在线互动：组队合作、资源交易、营地掠夺等社交玩法
- 基地建造：建造和升级基地来存储资源和防御敌人

## 为什么好玩

硬核生存游戏的紧张感来自真实感：资源有限、环境危险、其他玩家可能随时出现。三人称视角下的荒岛求生体验沉浸感强，多人互动让每局游戏都不同。

## 粘性来源

多人对战的社交竞争：你永远不知道下一个遇到的人是敌是友；基地建设的成就感；持续更新的新内容保持新鲜感

## Meta 系统

有好友系统（组队）、会员订阅（月付$9.99/周付$2.99，提供额外功能）。游戏持续更新新事件和反作弊修复。

## 实现难度

中。核心难点在于多人在线生存玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
