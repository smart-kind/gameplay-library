# 木筏求生：多人联机（Raft Survival: Multiplayer）

- **类型**: 多人生存 / 海上建造
- **平台**: Mobile (iOS)
- **开发商**: 未知
- **首次发布**: 2021
- **一句话描述**: 海上木筏生存游戏——邀请朋友一起从几块木板开始，逐步建造梦想中的海上堡垒

## 玩法规则

玩家出生在一小块木筏上，漂浮在茫茫大海中。木筏周围漂浮着各种资源——木板、塑料、棕榈叶、椰子等，玩家使用鱼钩将它们从海中捞取。

界面布局：第一人称视角，可以环顾四周的海面和木筏。下方显示快捷工具栏（鱼钩、斧头、建造模式等），上方显示生命值、饥饿值和口渴值。

采集的资源用于扩展木筏（添加新的木板区域）和制作设施（净水器、烤架、床、储物箱等）。木筏可以不断扩建，从一小块变成多层的大型海上平台。

多人模式下可以邀请朋友加入同一个木筏，分工合作——有人负责采集资源，有人负责建造，有人负责防御鲨鱼攻击。共同目标是建立一个功能齐全的海上基地，并最终探索周围的岛屿。

## 核心循环

鱼钩捞取漂浮资源 → 扩建木筏和制作设施 → 维持生存需求（食物、水） → 探索岛屿获取更多资源 → 继续扩建

## 核心机制

- **木筏扩建**：每次获得木板就可以扩展木筏面积，视觉上从小木筏到大型平台的变化很有成就感
- **资源漂流**：资源从四面八方的海面漂来，需要时刻关注并用鱼钩捞取
- **生存三要素**：饥饿值、口渴值、生命值，必须持续补充食物和水
- **多人合作**：和朋友分工合作，效率倍增，也增加了社交乐趣
- **鲨鱼威胁**：鲨鱼会攻击木筏边缘，需要加固防御
- **岛屿探索**：偶尔发现岛屿，可以上岸采集稀缺资源

## 为什么好玩

"从小木筏到海上堡垒"的视觉成长过程极具成就感。和朋友一起建造的体验比单人更有趣——分工合作的社交互动让生存压力变成了共同目标。

## 粘性来源

**建造成就感**：木筏从几块板变成多层建筑的视觉变化非常满足。**社交粘性**：和朋友一起玩是最大的留存驱动力。**探索欲望**：海面上可能漂来什么、下一座岛屿有什么资源，未知的吸引力持续存在。

## Meta 系统

外围成长系统：
- **配方解锁**：随着进度解锁更多建筑和设施的制作配方
- **皮肤系统**：木筏外观和角色外观的自定义
- 对核心玩法的影响：新配方让建造内容更丰富，但不改变核心的采集-建造循环

## 实现难度

高。多人联机同步是最大技术难点——需要同步木筏状态、资源位置、玩家动作和物理碰撞。海洋环境的渲染（水面、天气）也需要较好的图形处理能力。
