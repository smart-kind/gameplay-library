# Target Smash - Physics Puzzle（Target Smash!）

- **类型**: 物理弹射 / 解谜 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: Supercent Inc.
- **首次发布**: 2026
- **一句话描述**: 向超市货架和商品堆投掷球体，利用物理连锁反应击倒所有商品的解压益智游戏。

## 玩法规则

屏幕呈现一个超市场景——货架上摆满罐头、盒子、商品等堆叠物品，排列成各种形状。屏幕下方或侧方有一个可移动的投掷点，玩家控制投掷方向和力度。

玩家操作：首先拖拽移动投掷点调整水平位置，然后拖拽瞄准线调整射击角度和力度（类似弹弓机制），松开发射球体。球体沿物理轨迹飞行，命中商品后产生碰撞效果。被击中的商品会飞散、滚动、撞击相邻商品，产生连锁倒塌效应。

关卡目标是清除所有商品——让指定数量的商品掉出货架或倒地。不同关卡有不同的商品排列：有的是整齐的罐头金字塔，有的是拥挤的货架，有的包含特殊物品（如易碎品、重物）。玩家只需要投中关键位置，一次完美的投掷可以引发整排商品的连锁倒塌。

## 核心循环

移动投掷点瞄准 → 发射球体 → 商品连锁倒塌 → 清除所有目标 → 进入更复杂的陈列关卡

## 核心机制

- **超市场景主题**：将物理弹射与日常超市场景结合，罐头塔、货架、促销堆头等陈列方式天然具有"一触即倒"的物理特性。这种熟悉的场景降低了理解门槛——任何人都知道推倒一堆罐头是什么效果。
- **关键点击破设计**：每堆商品都有结构弱点。击中底部的关键支撑可以让整堆商品崩塌，击中顶部可能只影响少数商品。玩家需要观察陈列结构，找出最优打击点。
- **物理连锁反应**：商品之间的碰撞传递是游戏的核心机制。一个罐头倒下撞击旁边的罐头，旁边的又撞击下一个，形成连锁效应。物理引擎模拟的重量、弹性和摩擦力让每次倒塌效果都不完全相同。

## 为什么好玩

超市商品倒塌的视觉和听觉反馈极其解压——看着整排罐头轰然倒塌的满足感是游戏最大的卖点。熟悉的场景让破坏行为变得有趣而不暴力，任何人都能理解"推倒一堆东西"的乐趣。

## 粘性来源

"连锁倒塌"的爽感反馈是核心驱动力。每次完美的投掷看着商品多米诺式倒塌，这种视觉满足感让人上瘾。关卡设计逐步引入更复杂的陈列结构，让玩家不断挑战"能否一击清场"的极限。

## Meta 系统

无。游戏专注于纯粹的物理弹射挑战。

## 实现难度

低到中。2D物理引擎即可满足需求，商品碰撞逻辑相对简单。最大技术难点在于大量物体同时碰撞时的性能优化——一关可能有数十个商品同时运动，需要保持流畅的帧率和物理模拟的准确性。
