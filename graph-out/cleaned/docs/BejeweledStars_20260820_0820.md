# 宝石之星（Bejeweled Stars: Match 3 Game）

- **类型**: 三消 / 休闲解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Electronic Arts / PopCap
- **首次发布**: 2016
- **一句话描述**: 经典的宝石消除系列新作，通过交换相邻宝石实现三消及以上连消，在限定步数内达成目标

## 玩法规则

游戏棋盘为 8×8 的网格，上面铺满不同颜色和形状的宝石。玩家每次操作是交换相邻（上下左右）的两个宝石位置。

如果交换后形成三个或更多相同宝石连成一线（横或竖），这些宝石被消除并计分。消除后上方的宝石掉落填补空位，新宝石从顶部继续掉落，可能产生连锁消除（combo）。

如果交换后不形成消除，宝石会弹回原位，该操作无效。玩家不能重复上一次操作。

每个关卡有特定目标：在限定步数内消除指定数量的某色宝石、收集掉落到底部的特殊物品、或达到目标分数。步数用完但目标未完成则失败。

特殊组合：四个同色宝石消除生成"闪电宝石"（消除整行或整列），五个同色消除生成"彩虹宝石"（消除所有同色宝石），L型或T型消除生成"爆炸宝石"（范围消除）。

## 核心循环

交换宝石触发消除 → 宝石掉落产生连锁 → 完成关卡目标 → 解锁新关卡

## 核心机制

- **交换匹配机制**: 核心交互简单直观，交换相邻宝石寻找三消机会。低门槛但精通难——需要预判掉落和连锁反应
- **特殊宝石系统**: 四消、五消、L/T型消除产生不同能力的特殊宝石，特殊宝石之间的组合产生更强大的消除效果，形成策略深度
- **连锁反应（Combo）**: 消除后宝石掉落可能自动形成新的消除链，一次操作触发多轮消除带来强烈的正反馈

## 为什么好玩

宝石消除的视觉和音效反馈极其精致——每次消除都有清脆的碎裂声和闪光效果，特殊宝石的组合爆炸带来强烈的爽感高潮。

## 粘性来源

连锁消除的不可预测性带来赌博般的兴奋感；特殊宝石的组合探索有实验乐趣；关卡目标多样性（限时/限步/收集）保持新鲜感；PopCap一贯的精致美术和音效是品质保证。

## Meta 系统

星级评价系统：每关根据表现获得1-3星。星星用于解锁新区域和新宝石类型。宝石收集册记录已发现的所有宝石种类。对核心玩法无直接影响，但提供进度感。

## 实现难度

低。三消引擎是成熟模式，最大技术难点是宝石掉落物理和连锁消除的检测逻辑，以及特殊宝石效果的优先级处理。
