# Lollipop 3: Match 3 Puzzles（棒棒糖3：消除谜题）

- **类型**: 经典三消 / 益智解谜
- **平台**: Mobile (iOS + Android)
- **开发商**: Puzzle1Studio, Inc.
- **首次发布**: 2022
- **评分**: 4.79/5 (iOS 用户评分)
- **一句话描述**: 在糖果乐园中交换消除糖果、解救甜点伙伴的经典三消游戏，由Lollipop: Link & Match同厂出品

## 玩法规则

游戏画面呈现一个方格棋盘，每个格子放置不同种类的糖果——彩虹糖、棒棒糖、棉花糖等。玩家通过交换相邻的两个糖果来尝试连成3个或更多同色糖果。

当3个同色糖果连成一线（横或竖）时，它们会被消除并获得分数。消除后上方的糖果会下落填补空缺，可能触发连锁消除反应。

游戏目标是在限定步数内完成关卡任务：消除指定数量的特定糖果、清除障碍物（如方框、锁链等）、或收集特定物品来拯救甜点朋友。每一步都很珍贵，需要谨慎规划。

特殊组合可以产生强力道具：4个糖果组成方块消除产生"火箭"（清除一整行或列）；L型或T型消除产生"炸弹"（范围爆炸消除）；5个糖果直线排列产生"彩虹糖"（消除棋盘上所有同色糖果）。这些道具可以组合使用，产生更大范围的消除效果。

游戏包含1000+关卡，分布在不同的主题环境中，如"棒棒糖山丘"和"焦糖沼泽"，每个环境有独特的视觉风格和关卡设计。

## 核心循环

交换糖果连成消除 → 产生分数和特殊道具 → 完成关卡目标 → 解锁新关卡和新区域

## 核心机制

- **经典交换消除**：相邻两个糖果交换位置，连成3+消除——最简单直观的交互
- **特殊道具系统**：4方=火箭（线清）、L/T=炸弹（范围清）、5线=彩虹（同色全清），道具之间可以组合产生超级效果
- **障碍物设计**：方框（需多次消除）、锁链（需从旁边消除来解开）、冰块等，增加关卡策略性
- **步数限制**：每关有固定步数，考验玩家的效率而非无限尝试
- **Marshmallow Heroes收集系统**：通过消除激活棉花糖英雄，获得额外能力辅助通关

## 为什么好玩

作为Lollipop系列的第三代，本作在成熟的三消框架上加入了更丰富的道具组合和环境主题。4.79的高分（比第二代的4.72还高）说明它在关卡设计和内容量上做得很好。1000+关卡保证了长期的游玩内容，而道具组合的创造性则让每局都有新鲜感。

## 粘性来源

(1) **道具组合的创造性乐趣**——找到火箭+炸弹的组合清屏时有巨大的满足感；(2) **进度驱动的通关欲望**——每一关完成后立即想挑战下一关；(3) **1000+关卡的长期目标**——足够的内容量支撑长期游玩；(4) **"差一步过关"的再试欲**——步数用尽只差消除几个时的不甘心感

## Meta 系统

- **关卡星星系统**：根据剩余步数获得1-3星评级，鼓励完美通关
- **Marshmallow Heroes收集**：通过关卡激活棉花糖英雄角色，提供收集驱动力
- **区域解锁**：完成一定关卡数量解锁新环境主题
- **日常活动/奖励**：常规留存机制

## 实现难度

**低** — 核心三消逻辑成熟且开源实现众多。技术难点在于关卡平衡设计（让每关既有挑战又可完成）和道具组合的交互逻辑处理
