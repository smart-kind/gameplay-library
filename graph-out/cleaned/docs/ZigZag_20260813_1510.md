# ZigZag（之字狂奔）（ZigZag）

- **类型**: 反应 / 无尽
- **平台**: Mobile (iOS+Android)
- **开发商**: Ketchapp
- **首次发布**: 2015
- **一句话描述**: 一款极简风格的无尽反应游戏，小球在之字形轨道上自动移动，玩家点击屏幕改变行进方向。

## 玩法规则

游戏画面是一个之字形即zigzag的3D轨道，小球在轨道上自动向前移动。轨道在每个转角处分叉，可以向左或向右延伸，形成连续之字形的路径。

操作只有一个：点击屏幕。每次点击，球会在下一个转角处改变方向，如果原来向左延伸就变为向右，反之亦然。不点击则球沿原方向继续前进。

玩家需要在球到达转角之前点击，使其转向正确的方向。如果不点击或点击时机错误，球会沿原方向继续移动并掉出轨道边缘，游戏立即结束。

轨道上偶尔出现彩色方块，球经过时收集并得分。不同颜色的方块分值不同，有些特殊颜色方块有额外效果。目标是存活尽可能久，收集更多方块，获得更高分数。

## 核心循环

球在轨道上自动移动 → 接近转角时点击换向 → 收集彩色方块 → 轨道不断延伸 → 追求更高分数

## 核心机制

- **机制1**：节奏化点击机制：随着游戏推进，球速加快，转角间距缩短，点击节奏需要越来越快。熟练后玩家会进入一种无意识节奏状态，手指自动在正确时机点击，这种心流体验非常上瘾。
- **机制2**：收集品分布机制：彩色方块分布在轨道的不同分支上，玩家需要在保命随便选一边都能活下去和贪分选有方块的一边之间做快速抉择。这种风险与奖励的权衡增加了决策层次。
- **机制3**：极简视觉设计：低多边形3D风格和简洁配色让视觉信息一目了然，减少认知负担。玩家不需要花时间理解画面，可以完全专注于节奏和操作本身。

## 为什么好玩

极其简单的操作却能在高速状态下创造出令人窒息的紧张感。当你进入自动节奏状态时，那种心流体验非常迷人，感觉球和自己融为一体。

## 粘性来源

进入心流状态的快感加上每次刷新纪录的成就感加上收集方块颜色的视觉满足感，三者结合形成了极强的重复游玩循环。

## Meta 系统

简单分数系统加解锁不同颜色主题和轨道风格，最高分排行榜。部分版本有基于分数的成就系统。

## 实现难度

低 -- 核心是方向切换加碰撞检测，3D渲染可用简单引擎实现。最大难点是视觉和节奏的调优，让球速和转角间距的配合恰到好处。

## 彩色方块系统

- **白色方块**：基础分值1分，最常见
- **绿色方块**：分值3分，出现频率中等
- **红色方块**：分值5分，较少出现
- **金色方块**：分值10分，稀有出现，通常出现在危险分支上

每收集10个同色方块可解锁一个新的轨道颜色主题。
