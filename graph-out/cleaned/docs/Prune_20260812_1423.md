# 修剪艺术（Prune）

- **类型**: 解谜 / 禅意 / 种植
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Joel McDonald
- **首次发布**: 2015
- **一句话描述**: 一款极简风格的树木修剪解谜游戏，玩家通过修剪树枝来引导树木朝向阳光生长。

## 玩法规则

游戏画面极简：黑色背景上，一棵树的种子在屏幕底部开始生长。树枝从种子处向外延伸。
玩家的操作只有一种：用手指滑动剪掉不需要的树枝。被剪掉的树枝会飘散成花瓣。
目标：引导树的主枝干向上生长并触碰到屏幕上方的阳光区域。
障碍包括：暗色的污染区（树枝伸入会被腐蚀）、红色的危险区域、需要绕过的障碍物。
如果所有树枝都被污染或无法到达阳光，关卡失败。
每关的花瓣数量会被记录，修剪越少花瓣得分越高。
游戏没有文字教程，第一关通过自然引导教会玩家操作。

## 核心循环

观察树枝生长方向 → 滑动剪掉偏离的枝条 → 引导主干朝向阳光 → 触碰阳光过关

## 核心机制

- **单一操作（修剪）**：玩家只能做一件事：剪掉树枝。这个简单的操作在关卡设计中产生出丰富的策略变化。
- **自然生长模拟**：树枝按照一定的生长算法自然延伸，玩家需要预判生长方向并提前修剪。
- **极简美学**：黑色背景、白色枝条、粉色花瓣、金色阳光。极简的视觉设计创造出禅意般的体验。
- **花瓣评分**：修剪次数越少，飘散的花瓣越少，评分越高。鼓励玩家用最少的操作完成目标。

## 为什么好玩

将树木修剪这一日常行为转化为禅意解谜体验。极简的视觉和音效设计让人放松，同时关卡设计又有足够的思考深度。

## 粘性来源

禅意体验带来的放松感；追求最少花瓣的完美主义；每关独特的障碍布局创造新鲜感；修剪时的花瓣飘散动画极具满足感。

## Meta 系统

无内购或成长系统。纯关卡解锁模式，共48个关卡。

## 实现难度

低 — 核心算法是树枝生长的简单模拟（分形算法变体），碰撞检测和修剪逻辑不复杂。最大技术难点在于生长算法的自然感和不同关卡的平衡性设计。

## 游戏变体

多数游戏在不同平台上发布了HD版、重制版或移植版本，核心玩法保持不变。
