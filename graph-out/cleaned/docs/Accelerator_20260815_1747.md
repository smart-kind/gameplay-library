# 极速穿梭（Accelerator）

- **类型**: 竞速 / 反应
- **平台**: Web (Flash)
- **开发商**: TenebrousP
- **首次发布**: 2011
- **一句话描述**: 在高速飞行的同时躲避障碍物，比拼谁飞得更远更快的极限反应游戏

## 玩法规则

玩家控制一个高速飞行的物体，在隧道或赛道中不断向前冲刺。
左右移动（或上下）躲避迎面而来的障碍物（墙壁、柱子、球体等）。
随着时间推移速度越来越快，障碍物越来越密集。
撞到任何障碍物即刻游戏结束。
游戏设有全球排行榜，比拼谁能在最高速度下存活最久。
部分版本有收集品（能量球、金币），收集后可以获得加速或护盾。

## 核心循环

加速飞行 → 躲避障碍 → 收集道具 → 速度越来越快 → 追求更高存活时间

## 核心机制

- 持续加速机制：速度不是固定的而是不断递增，玩家需要在越来越快的节奏中保持冷静
- 即时死亡判定：碰到障碍立即结束，零容错率让每次飞行都充满紧张感
- 全球排行榜竞争：实时排名系统让每次游玩都变成与他人比较

## 为什么好玩

速度感带来的肾上腺素飙升是核心体验。从轻松到失控的转变过程令人上瘾——前一秒还游刃有余，下一秒就被密密麻麻的障碍吞噬。

## 粘性来源

排行榜驱动的竞争性粘性。看到自己的名字在榜单上就忍不住想再冲一次刷更高。"差一秒就进前十"的遗憾感极强。

## Meta 系统

全球排行榜系统。部分版本有皮肤/道具解锁。

## 实现难度

低 — 核心是碰撞检测和渐进加速逻辑，技术难点在于高速下的流畅渲染

赛道环境包括太空隧道、霓虹城市、海底管道等主题场景。
高速飞行时屏幕边缘会出现速度线效果，速度越快线条越密集。
收集的能量球可以暂时提供无敌护盾，撞到障碍物也不会立刻死亡。
游戏有每日挑战和周赛模式，特定时间段内的成绩参与特殊排名。
