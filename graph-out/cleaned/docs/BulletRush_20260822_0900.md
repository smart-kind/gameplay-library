# Bullet Rush! (Bullet Rush!)

- **类型**: 超休闲射击 / 弹幕躲避
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2020
- **一句话描述**: 在充满敌人的竞技场中疯狂射击，触发火力模式一波清场的快节奏弹幕射击游戏

## 玩法规则

游戏采用简洁的竖屏画面设计，玩家控制一个小人角色在封闭的竞技场地中移动。屏幕上会不断涌现大量敌人，玩家需要在躲避敌人弹幕的同时进行反击射击。

操作方式非常直观：手指拖拽或滑动屏幕控制角色移动，角色会自动向最近的敌人开火。当玩家消灭足够数量的敌人后，会触发"火力模式"（Firemode）——在这个短暂的时间窗口内，角色的攻击力和射速大幅提升，可以一次性消灭数十个敌人，产生壮观的连锁清场效果。

游戏的核心目标是尽可能长时间地存活并获得高分。每一波敌人都会比前一波数量更多、速度更快。游戏没有传统的生命值系统——被敌人碰到即结束回合。

过关/失败条件：存活越久分数越高；一旦被敌人碰到，游戏立即结束，显示最终得分。

## 核心循环

消灭敌人 → 积累击杀数 → 触发火力模式清场 → 获得更高分数 → 进入更难的波次

## 核心机制

- **自动射击机制**：角色会自动瞄准并射击最近/最多的敌人，玩家只需专注于走位躲避，降低了操作门槛但提高了策略深度（走位即输出）
- **火力模式（Firemode）**：通过连续击杀积累的进度条，满后进入爆发状态，攻击力大幅提升，带来"割草"式的爽快感反馈
- **弹幕密度递增**：每波敌人数量和移动速度逐步增加，营造紧张感曲线，考验玩家的空间感知和反应速度
- **碰撞即死机制**：没有血量缓冲，任何接触都导致失败，强调精准走位，增加"差一点就成功"的不甘心感

## 为什么好玩

火力模式触发瞬间的清场效果提供了极强的爽快感——从被围追堵截到瞬间逆转的戏剧性转变让人上瘾。操作简单到任何人都能上手，但高分却需要精妙的走位规划。

## 粘性来源

"差一点就能触发火力模式就死了"的不甘心感是核心粘性来源。每次失败都让人想"再试一次"。火力模式的爆发性视觉反馈（满屏敌人瞬间消失）提供即时的多巴胺奖励，而弹幕密度递增带来的难度曲线确保每局都有"我比上次多活了3秒"的微进步感。

## Meta 系统

无。典型的超休闲即开即玩设计，无外围成长或收集系统。

## 实现难度

低。核心是2D角色移动+自动瞄准射击+碰撞检测。最大技术难点在于大量敌人（数百个）同时存在时的性能优化，以及火力模式触发时的视觉粒子效果渲染。
