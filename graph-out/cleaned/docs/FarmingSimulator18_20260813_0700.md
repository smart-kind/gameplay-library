# 模拟农场18（Farming Simulator 18）

- **类型**: 模拟经营
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: GIANTS Software
- **首次发布**: 2017
- **一句话描述**: 在开放农场中种植作物、饲养牲畜、收割销售，体验真实的农业经营循环

## 玩法规则

游戏呈现一片开放式的3D农场。玩家可以自由控制拖拉机、收割机等农业机械在田间移动。

核心操作循环：翻地→播种→施肥→浇水（可选）→收割→出售。不同作物有不同生长周期和市场价格。

玩家可以饲养奶牛、猪、鸡等牲畜，生产牛奶、猪肉、鸡蛋等产品出售获得收入。

随着赚钱，可以购买更多土地、更先进的机械设备，扩大经营规模。天气系统会影响作物生长。

## 核心循环

种植作物 → 等待生长 → 收割 → 出售获利 → 扩大农场/购买新设备

## 核心机制

- 真实农业循环：翻地-播种-生长-收割-销售的完整流程模拟真实农业，每一步都有时间成本。
- 机械设备经营：不同作物需要不同的农机设备，投资回报率计算是核心策略。
- 多元化经营：作物种植+畜牧养殖+产品加工，多渠道收入降低风险。

## 为什么好玩

看着自己经营的小农场逐步扩大、从手动耕作到机械化生产的成就感。适合喜欢规划和经营的玩家。

## 粘性来源

长线目标驱动——从一块荒地到完整农场的成就感。每个作物周期结束后的收获爽感让人想要"再种一季"。

## Meta 系统

经济系统：资金累积用于购买土地和设备。无等级系统，但有"解锁新农机"的进度感。

## 实现难度

高。3D开放场景 + 多种农机物理 + 作物生长模拟 + 经济系统。最大技术难点：不同农机的操作手感和物理模拟的真实性。
