# Raid Rush（Raid Rush: Tower Defense TD）

- **类型**: 塔防 / 卡牌策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Panteon
- **首次发布**: 2023
- **一句话描述**: 一款融合卡牌元素和塔防策略的混合游戏，玩家在战斗中抽取防御塔卡牌来构建防线。

## 玩法规则

游戏采用固定路径的塔防地图。与传统塔防不同，玩家不能预先建造所有塔，而是在战斗中通过抽卡获得防御塔。

战斗界面：上方显示当前波次和敌人进度条，中间是塔防战场（敌人沿固定路径前进），底部是手牌区（4-6张塔卡牌）。

每回合开始，玩家抽取防御塔卡牌到手中。每张卡牌有费用值，消耗当前回合的法力值打出。塔打出后自动攻击路径上的敌人。

关键机制是运气+策略的平衡：抽到什么塔是随机的，但如何利用手中的塔做出最优布局是策略性的。玩家可以通过升级获得选卡能力（从2张中挑1张）来降低随机性。

每波敌人被消灭后获得金币，金币用于在波次间升级塔的等级或购买永久增益。

游戏采用章节制，每章有15-20波敌人，最后一波是Boss战。通关章节解锁新章节和新塔类型。

## 核心循环

抽取塔卡牌 → 消耗法力部署塔防 → 击杀敌人获金币 → 升级塔和购买增益 → 进入下一波

## 核心机制

- **随机抽卡+策略部署**: 抽卡的随机性带来不确定性和新鲜感（这局能抽到好塔吗？），而部署决策保留策略深度（这个塔放这里能覆盖最多路径）。随机性和可控性的平衡是核心乐趣
- **战斗卡牌升级**: 战斗中选择升级已有塔（提升伤害/攻速/范围）或购买全局增益（如法力恢复加快），提供波次间的决策点
- **战斗牌组构建**: 通关后获得新塔卡牌加入牌组，玩家可以在战斗前调整牌组构成，影响抽卡概率。牌组构建本身就是一个策略层

## 为什么好玩

将塔防的规划感和卡牌游戏的随机性结合，每局体验都不同。抽到稀有塔时的惊喜感和巧妙利用手中牌完成防守的成就感并重。短波次节奏快，适合碎片时间。

## 粘性来源

抽卡的赌博心理（下一张会不会是传说塔？）；牌组收集的完整性驱动；通关解锁新章节的进度感；高难度挑战（无升级通关）的重玩价值。

## Meta 系统

- **塔卡牌收集与牌组构建**: 通关获得新塔卡牌，战前调整牌组构成
- **对核心玩法的影响**: 更多塔卡牌提供更多策略组合，但不改变核心战斗规则

## 实现难度

中 — 需要平衡随机性（不能太随机导致纯运气）和策略性，最大技术难点是卡牌掉落概率设计和难度曲线的动态调整
