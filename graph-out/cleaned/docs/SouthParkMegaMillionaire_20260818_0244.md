# South Park Mega Millionaire（南方公园超级百万富翁）

- **类型**: 平台跳跃/动作
- **平台**: Mobile (iOS)
- **开发商**: Mr Goodliving
- **首次发布**: 2010
- **一句话描述**: 南方公园四主角穿着轮滑鞋参加日本游戏节目赢百万日元的平台游戏

## 玩法规则

游戏采用横版卷轴平台跳跃视角。四个角色穿着轮滑鞋在各种关卡中高速滑行。

**操作方式**：
- 点击屏幕左侧控制角色向左移动
- 点击屏幕右侧控制角色向右移动
- 点击屏幕中间控制跳跃
- 倾斜设备控制角色在轮滑上的平衡

**核心玩法**：
- Stan、Kyle、Kenny和Cartman四个角色可切换操作
- 穿着轮滑鞋在关卡中高速滑行收集现金
- 完成各种特技动作取悦观众（如被相扑选手击打、头顶盆景树、用头撞击上方平台）
- 角色具有类似Sonic和Mario的惯性加速和减速物理
- 在关卡中尽可能多地收集现金

**胜利/结束条件**：
- 关卡成功：收集足够现金并到达终点
- 游戏目标：赢得日本游戏节目的一百万日元大奖

## 核心循环

滑行 → 收集现金 → 完成特技动作 → 取悦观众 → 通关赢大奖

## 核心机制

- **轮滑物理**：类似Sonic和Mario的惯性加速减速系统
- **特技系统**：完成各种特技动作（被相扑击打、头顶盆景、头撞平台）取悦观众
- **角色切换**：四个南方公园角色各有特点
- **现金收集**：在关卡中收集尽可能多的现金
- **横版卷轴**：经典横版平台跳跃玩法

## 为什么好玩

将南方公园的四个男孩放入日本游戏节目的设定既荒诞又有趣。特技动作系统让观众取悦成为核心玩法，与平台跳跃相结合创造出独特体验。角色还原度极高，从外观到动作到对话都忠于原作。

## 粘性来源

- **IP吸引力**：南方公园粉丝的自然驱动
- **特技挑战**：完成各种荒诞特技的成就感
- **现金收集**：收集现金的直接快感反馈
- **角色切换**：四个角色各有不同体验

## Meta 系统

无 — 游戏以关卡推进为主，无外围成长系统。

## 实现难度

中 — 平台跳跃物理系统需要精细调校，主要技术难点在于轮滑惯性手感和特技动作的流畅动画。
