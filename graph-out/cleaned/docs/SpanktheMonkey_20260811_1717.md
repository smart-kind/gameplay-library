# Spank the Monkey

- **类型**: 搞笑/休闲
- **平台**: Web
- **开发商**: Addicting Games
- **首次发布**: 2004
- **一句话描述**: 经典搞笑休闲游戏——用各种搞笑方式"教训"一只烦人的猴子，简单操作带来纯粹的快乐

## 玩法规则

Spank the Monkey 是一款轻松搞笑的点击式休闲游戏。画面中央是一只表情滑稽的猴子（通常挂在一根杆子上或站在一个平台上），周围分布着各种可以点击的"武器"或道具。

游戏画面布局简洁：
- **中央区域**: 猴子角色，会随着被打击做出各种搞笑的表情和动作反应
- **周围区域**: 各种可点击的道具/武器（如巴掌、拖鞋、锤子等），通常围绕猴子排列
- **计分区域**: 显示当前连击数、总分或剩余时间

玩家的操作非常简单：
- **点击道具**: 点击屏幕上的任意道具来"打"猴子
- **连续点击**: 快速连续点击可以打出连击，获得更高分数
- **尝试所有道具**: 每种道具会让猴子有不同的反应动画，收集所有反应是游戏的一个目标
- 游戏没有明确的"输"的概念，主要是追求高分和收集所有道具的反应

游戏的主要目标是获得尽可能高的分数，并尝试所有道具看看猴子会做出什么搞笑反应。

## 核心循环

点击道具 → 猴子做出搞笑反应 → 获得分数 → 尝试新道具 → 刷新最高分

## 核心机制

- **道具反应系统**: 每种道具对应猴子的一种独特反应动画。有些道具会立刻触发反应，有些需要连续使用几次。收集所有道具的反应是游戏的核心收集目标。
- **连击计分**: 快速连续点击同一种道具可以积累连击数，连击越高分数倍率越高。这鼓励玩家找到节奏并保持连续操作。
- **搞笑反馈循环**: 每次点击都伴随着搞笑的音效和猴子的夸张表情变化。这种即时的视听反馈是游戏的核心乐趣来源。
- **无压力玩法**: 游戏没有失败条件，玩家可以完全按照自己的节奏进行。这种"零压力"的设计让它成为打发时间的完美选择。

## 为什么好玩

纯粹的快乐——点击一下，猴子就会做出一个让你忍不住笑出来的反应。没有复杂的规则，没有失败的挫败感，就是最简单的"点一下 → 笑一下"循环。在压力大的时候玩几分钟，效果堪比看了一段搞笑视频。

## 粘性来源

收集所有道具反应的完成欲让人想尝试每一种组合。刷高分的冲动（"再试一次就能突破纪录"）也是持续的驱动力。最重要的是，猴子的反应确实很好笑——这种基于内容本身的粘性比任何数值系统都更持久。

## Meta 系统

无——这是一个纯休闲游戏，没有外围系统。分数记录和道具收集进度是唯一的"进度"。

## 实现难度

低——简单的点击事件触发预设动画，无需复杂的游戏逻辑。最大技术难点在于动画制作的质量——猴子的表情和动作需要足够搞笑才有吸引力。
