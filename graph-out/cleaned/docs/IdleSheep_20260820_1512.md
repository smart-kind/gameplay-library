# Idle Sheep!（Idle Sheep!）

- **类型**: 放置 / 点击 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: Digital Media Technology SLU
- **首次发布**: 2023
- **一句话描述**: 一款以绵羊养殖为主题的放置点击游戏，通过收集羊毛、繁殖绵羊和升级牧场来打造最大的绵羊帝国。

## 玩法规则

Idle Sheep! 的画面呈现一个牧场景观，绵羊在草地上悠闲地吃草和走动。屏幕中央是牧场主画面，绵羊分散在草地上，下方是操作面板（收集羊毛、购买新绵羊、升级按钮），上方是资源统计（金币、羊毛数量、绵羊总数、牧场等级）。

绵羊会定期产出羊毛，玩家点击绵羊或点击收集按钮获取羊毛。羊毛可以出售换取金币，金币用于购买更多绵羊、解锁新绵羊品种或升级牧场设施。每只绵羊的产出速率和羊毛品质不同，影响金币收入。

不同品种的绵羊有不同的羊毛产量和售价。普通绵羊产量稳定但收益一般，稀有品种产量更高、羊毛更值钱。繁殖系统允许玩家让两只绵羊交配，有概率产出稀有品种的后代，类似"抽卡"机制。

牧场设施升级包括：扩大牧场面积（容纳更多绵羊）、升级剪毛工具（提高收集效率）、自动化设备（减少手动操作，自动收集羊毛）。每种升级都有明确的成本效益比。

## 核心循环

绵羊产毛 → 收集羊毛 → 出售换金币 → 购买新绵羊/升级设施 → 扩大牧场规模 → 繁殖稀有品种

## 核心机制

- **放置产出机制**：绵羊自动产毛，离线时也有产出（按比例计算），降低在线压力，适合碎片化游玩
- **品种繁殖抽卡系统**：通过繁殖获得稀有品种，增加收集乐趣和策略性（选择哪两只交配），带来"抽卡"式惊喜
- **多维设施升级路径**：面积、效率、自动化三个方向，玩家可以选择不同的发展策略和优先级
- **点击加速参与感**：手动点击可以快速收集羊毛，提供短期内的活跃参与感，平衡纯放置的无聊感

## 为什么好玩

绵羊本身就是治愈系动物，加上放置游戏的轻松节奏，整体体验非常放松。繁殖系统带来的"抽卡"式惊喜（可能获得稀有品种）增加了刺激感。看着牧场从几只羊发展到成群结队，视觉上的成长很有满足感。

繁殖系统是这款游戏最具创意的设计。两只普通绵羊交配可能产出稀有品种，这种"彩票机制"让人上瘾。牧场从几只羊发展到数百只的视觉扩张过程也很有成就感。每只绵羊在草地上悠闲吃草的画面本身就是一幅治愈系的动态风景画。

## 粘性来源

繁殖稀有品种的收集驱动 + 牧场规模的数字增长。每只新绵羊都是一次"抽奖"，稀有品种的出现带来强烈的正面反馈。"再繁殖一次可能出稀有"的心理让人停不下来。离线收益也减少了弃坑的可能性。

## Meta 系统

绵羊图鉴系统（收集所有品种，记录每种绵羊的特性和稀有度）+ 牧场等级系统（综合评估牧场规模）+ 成就系统（特定里程碑奖励，如"收集100只绵羊"）。

## 实现难度

低 — 放置点击游戏的核心逻辑成熟且简单（定时器+资源计算+概率系统）。最大难点是繁殖概率系统的平衡设计，需要确保稀有品种既不会太容易获得也不会太难，以及经济系统的长期可持续性。
