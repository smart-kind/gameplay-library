# Starfall HD

- **类型**: 休闲/射击
- **平台**: iOS
- **开发商**: Chillingo
- **首次发布**: 2010
- **一句话描述**: The worst thing about the tower defence genre isn’t so much the saturation (although that is an issue), but that nearly all the titles are exactly the

## 玩法规则

游戏采用太空射击的经典玩法，高清2D太空场景画面精美。玩家操控一艘飞船在太空中对抗各种类型的敌人。

玩家能做什么操作：
- 手指触摸屏幕任意位置控制飞船移动方向，飞船会自动朝触摸方向持续飞行，松开则停止
- 飞船自动开火，玩家只需专注于躲避密集的敌人弹幕和瞄准敌方弱点，无需手动射击
- 消灭敌人后收集掉落的强化道具，包括武器升级（增加火力）、护盾（吸收伤害）、炸弹（清除全屏敌人）
- 面对BOSS敌人时，需要观察其攻击模式，找到安全窗口进行集中输出，躲避BOSS的全屏弹幕攻击

游戏目标：在每关中消灭所有来袭的敌人波次，顺利通关进入下一关。部分关卡包含保护任务（保护空间站）或限时挑战（在时间耗尽前完成目标），增加了关卡多样性。
失败条件：飞船被敌人子弹击中导致生命值归零，游戏结束。部分关卡有续关机制，使用有限的信用继续。

## 核心循环

操控飞船射击 -> 消灭敌人获得分数和道具 -> 通关解锁新关卡和新飞船 -> 挑战更高难度

## 核心机制

- 触控移动+自动射击：极简操作设计，触摸屏幕控制飞船移动方向，飞船自动朝该方向飞行并自动开火，玩家只需专注走位和瞄准
- 波次敌人系统：每关分为多个波次，每波敌人有不同的组成（固定炮台、移动飞行物、快速小型机、大型BOSS），难度逐波递增
- 道具掉落和拾取：消灭特定敌人掉落强化道具，包括火力升级（增加弹道数量）、护盾（吸收伤害）、炸弹（清除屏幕所有敌人）、生命回复
- BOSS战机制：每关末尾出现BOSS，拥有多阶段攻击模式和大量生命值，需要观察攻击规律、找到安全输出窗口

## 为什么好玩

太空射击的爽快感来自满屏弹幕中的闪转腾挪。操作门槛低（只需移动，射击自动），但精通需要练习，既能吸引休闲玩家也能满足硬核需求。高清画面和流畅的射击反馈带来视觉和触觉的双重享受。每关末尾的BOSS战提供了阶段性的成就感和挑战感。

## 粘性来源

关卡解锁的驱动力（"下一关是什么？"）。追求高分和完美通关的重复挑战。道具收集和飞船解锁提供了长期目标。弹幕闪避的紧张感让人欲罢不能。

## Meta 系统

- 关卡解锁：通关后解锁新的关卡区域和难度等级
- 飞船解锁：完成特定条件解锁不同性能的飞船，提供不同的游戏体验
- 成就系统：完成特定挑战获得成就奖励
- 高分排行榜：与全球玩家比较成绩

## 实现难度

低 -- 经典的2D射击游戏框架，需要实现碰撞检测、弹幕系统、波次管理、道具掉落和拾取。最大的技术难点是弹幕密度高时的性能优化和流畅的手感调校。自动射击+触摸移动的操作模式降低了实现复杂度，但需要精细的碰撞体设计来保证公平感。
