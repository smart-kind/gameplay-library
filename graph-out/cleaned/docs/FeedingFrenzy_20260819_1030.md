# 大鱼吃小鱼（Feeding Frenzy）

- **类型**: 动作 / 休闲 / 生存
- **平台**: PC / Mobile (iOS+Android) / Xbox
- **开发商**: Sprout Games (原版) / PopCap
- **首次发布**: 2004
- **一句话描述**: 控制一条小鱼在水下世界中不断吞食比自己小的生物，躲避比自己大的捕食者，从小鱼成长为海洋霸主。

## 玩法规则

游戏画面是一个横向或纵向滚动的水下场景。玩家控制一条小鱼在水中自由游动，画面中同时存在大量大小不一的海洋生物。玩家可以吞食所有比自己体型小的生物，每吞食一个生物都会获得经验值并增长体型。

操作方式非常简单：通过点击/滑动控制鱼的游动方向，鱼会持续向前游动。碰到比自己小的生物会自动吞食，碰到比自己大的生物则需要躲避，被大生物碰到会失去生命值，生命值归零则游戏结束。

游戏按关卡进行，每关有明确的目标：在限定时间内长到指定体型/吞食指定数量的生物。每关结束后进入进化阶段，鱼的体型和外观都会升级，解锁新的海洋区域。

## 核心循环

寻找比自己小的生物 → 吞食获得经验 → 体型增长 → 能吃更大的生物 → 通关进化 → 进入新关卡

## 核心机制

- **体型等级系统**：所有生物按体型分为多个等级，你只能吃比你小一级的生物。每次吞食都会积累生长进度，达到阈值后体型自动升级。这个系统让玩家始终有"下一步目标"——总有一种更大的生物等待被征服。
- **危险预警**：比自己大的生物在靠近时会有视觉提示（红色轮廓或震动），帮助玩家及时做出躲避反应。
- **限时生存**：每关有倒计时，但倒计时可以通过吞食生物来延长。这创造了紧张感——你不吃东西就会饿死。
- **Boss战**：每关最后会出现一个巨型Boss，需要玩家利用之前积累的体型和速度来挑战。Boss有特殊攻击模式，需要策略应对。

## 为什么好玩

"从小虾米到海洋霸主"的成长弧线极其满足。看着自己从一条几乎谁都能吃你的小鱼，逐渐变成能吞食一切的大鲨鱼，这种视觉和能力上的双重成长反馈非常强烈。同时，水下世界的色彩缤纷和生物多样性也提供了很好的视觉体验。

## 粘性来源

- **成长反馈**：每次体型增长都有明显的视觉变化和新的可吞食目标，持续的正反馈循环
- **"就差一点"心理**：经常在最后一刻差一点就能通关，促使立即重开
- **收集元素**：不同关卡解锁不同种类的海洋生物，满足收集欲望
- **短关卡设计**：每关2-5分钟，"再来一局"的心理门槛极低

## Meta 系统

- **进化解锁**：通关后解锁新的鱼类皮肤和海洋区域
- **成就系统**：完成特定挑战（如不受伤通关、吞食特定数量等）解锁成就
- **分数排名**：每关有星级评分和全球排名

## 实现难度

低 + 核心是碰撞检测和简单的AI路径，技术实现简单。最大难点在于设计合理的体型曲线和关卡难度，确保游戏节奏张弛有度。
