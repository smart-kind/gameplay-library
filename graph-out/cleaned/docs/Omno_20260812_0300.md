# 奥姆诺（Omno）

- **类型**: 解谜 / 探索 / 冒险
- **平台**: PC / Switch / PlayStation / Xbox
- **开发商**: Studio Inkyfox
- **首次发布**: 2021
- **一句话描述**: 在一个没有文字的奇幻世界中滑行、跳跃、解谜，探索古老文明的遗迹

## 玩法规则

玩家扮演一位戴兜帽的小人，在一个色彩斑斓、风格独特的3D世界中自由探索。游戏没有任何文字对话或教程，所有信息通过视觉和环境传达。

核心操作包括：跑、跳、滑行、使用一根神秘的"魔杖"。魔杖可以用来激活场景中的机关——照射古老石碑上的符号、推动浮空的石块、开启隐藏通道、与场景中的生物互动。

游戏世界被划分为多个区域（沙漠、冰川、森林、深海、天空等），每个区域有独特的视觉风格和谜题类型。谜题大多是环境谜题：利用场景中的元素（浮石、水流、风力、光线反射等）来打开通往下一区域的路径。

游戏中散布着可收集的"记忆碎片"——一些发光的物体，收集后解锁一段远古文明的动画片段。没有战斗、没有死亡惩罚、没有时间限制，纯粹以探索和解谜为核心。

## 核心循环

探索环境 → 发现并激活机关 → 解锁新区域 → 收集记忆碎片 → 继续深入

## 核心机制

- **魔杖交互系统**：魔杖是唯一的"工具"，通过照射不同物体产生不同效果。照射石碑→激活机关，照射浮石→使其移动，照射生物→与其互动。同一工具在不同场景有不同用法，保持了统一性和新鲜感。
- **环境叙事**：没有文字，故事完全通过环境细节传达。玩家看到的是什么就是什么——一座废弃的雕像、一面满是符号的墙壁、一个沉睡的巨兽。玩家自己拼凑故事。
- **无惩罚设计**：没有生命值、没有死亡、没有计时器。玩家可以无限尝试任何谜题，不会因为失败而受挫。这种设计让游戏对所有年龄段和技能水平的玩家开放。
- **多区域自由探索**：虽然有一定线性进度（解锁新区才能继续深入），但在已解锁区域内玩家可以自由穿梭，收集之前遗漏的碎片。

## 为什么好玩

Omno 的魅力在于它营造了一种宁静的探险氛围。没有战斗、没有紧迫感，只有你和一个美丽的世界。每次激活机关打开新通道时的"啊哈"时刻，就像在现实中发现了一个隐藏的房间。视觉艺术风格独树一帜——色彩饱和、造型简洁、场景宏大。

## 粘性来源

探索欲和收集欲是核心驱动力。"下一个区域会是什么样子？"这个问题推动着玩家不断前进。记忆碎片的收集提供了明确的进度反馈。宁静的美学体验本身就让人沉浸——很多人把它描述为"可玩的冥想"。

## Meta 系统

无传统Meta系统。进度仅体现在已探索区域和收集的记忆碎片数量上。没有数值成长、没有装备系统。

## 实现难度

中 — 技术难点在于3D场景的美术设计和氛围营造（光影、色彩、空间感）。谜题系统相对简单（机关激活+路径解锁），但需要精心设计每个谜题的提示方式（因为没有文字）。相机控制和角色动画需要流畅自然。

游戏没有失败状态，死亡不会发生，玩家可以以任意速度探索世界。
