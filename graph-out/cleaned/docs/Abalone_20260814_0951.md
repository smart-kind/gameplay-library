# 阿巴隆 (Abalone)

- **类型**: 棋盘策略/对抗
- **平台**: Mobile (iOS+Android)
- **开发商**: 未明确标注
- **首次发布**: 未明确标注
- **一句话描述**: 一款经典的棋盘游戏移动端移植，类似黑白棋与相扑的奇妙结合

## 玩法规则

Abalone在一个六角形棋盘上进行，棋盘上布满可以放置彩色弹珠的凹槽。游戏双方分别使用黑色和白色弹珠。

核心规则非常简单：每次可以移动一个弹珠一格空间，也可以移动相邻的弹珠一起移动。当你的弹珠与对手弹珠相邻时，如果你拥有数量优势，就可以将对手的弹珠推出去。

具体来说：三个己方弹珠可以推回一到两个对手弹珠，但两个弹珠推不动三个。这就是所谓的推挤机制。目标是将对手的弹珠推出棋盘——先推出6个弹珠的一方获胜。

除了直接的推挤，玩家还可以利用侧推（从侧面推动对手弹珠）来创造更有利的位置。保持中心阵地几乎总是有利的——就像真正的战争一样，分而治之是关键策略。

游戏节奏相对缓慢和沉稳，需要深思熟虑的规划和横向思维能力。

## 核心循环

移动弹珠 -> 创造数量优势推挤对手 -> 将对手弹珠推出棋盘 -> 推出6个获胜

## 核心机制

- 数量优势推挤：己方弹珠数量多于对方时才能推动，三个推一两个，两个推不动三个
- 六角形棋盘移动：弹珠可以一格一格地移动，相邻弹珠可以一起移动，增加了策略组合
- 侧推机制：从侧面推动对手弹珠，创造更有利的位置
- 中心控制策略：占据棋盘中心位置通常更有利，但需要平衡进攻和防守

## 为什么好玩

规则极其简洁（移动+推挤），但策略深度惊人。每次推挤成功时的满足感类似于下棋中的将军时刻。物理推挤的数字化实现带来了直观的反馈。

## 粘性来源

每局游戏都是全新的策略博弈，没有随机元素，纯粹的智力对抗。学会基本策略后可以与不同水平的对手反复对弈。

## Meta 系统

无外围系统——纯粹的棋盘游戏，没有成长或收集要素。

## 实现难度

中等偏高 — 规则简单但精通需要大量练习。最大技术难点是AI对手的智能设计——要在不同难度级别上提供合理的挑战。
