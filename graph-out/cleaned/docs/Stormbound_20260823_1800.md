# Stormbound

- **类型**: 卡牌对战 / Roguelike
- **平台**: Mobile (iOS)
- **开发商**: Stormbound Games
- **首次发布**: 2018-2024
- **一句话描述**: Stormbound: PVP Card Battle - Where deck building for Collectible Cards and Strategic gameplay collide in unique PVP Turn-based Tactical battles

## 玩法规则

游戏开始时，玩家面对一个核心游戏区域（棋盘/房间/战场），其中包含各种互动元素。

在方块益智类模式中，屏幕中央显示一个网格或空白区域，底部或侧边提供待放置的方块/图形。玩家通过拖拽操作将方块放入游戏区域，当填满一行或一列时自动消除并计分。游戏持续生成新方块直到无法放置为止。

在卡牌对战模式中，玩家手中有数张卡牌，每回合从牌库抽取新牌。每张卡牌有费用、攻击力和特殊效果。玩家需要合理分配资源点（法力/能量）来出牌，攻击敌方单位或释放技能。敌方也会在自己回合行动，形成回合制对抗。

在逃脱解谜模式中，玩家被放置在一个封闭场景中，需要通过点击探索来寻找线索。场景中包含可互动的物品、隐藏的密码和道具。找到钥匙解开锁、组合物品触发机关、输入正确密码打开门——这些都是通关的必要步骤。

游戏目标：在益智模式中尽可能获得高分或清除所有方块；在卡牌模式中击败所有敌人到达终点；在逃脱模式中解开所有谜题成功逃脱。游戏在无法继续操作（方块无处可放/生命耗尽）或完成目标时结束。

## 核心循环

抽卡/选卡 → 组建卡组 → 对战敌人 → 获取新卡/资源 → 循环强化

## 核心机制

- 卡组构建（Deckbuilding）：玩家从有限的卡牌池中挑选和组合卡牌，形成独特的战斗策略。每次冒险开始时卡组基础不同，需要随机应变。
- 资源管理：每张卡牌有消耗费用，玩家每回合获得固定资源点，需要合理规划出牌顺序以最大化效益。
- Roguelike随机性：每次冒险遇到的敌人、获得的卡牌和遗物（被动道具）都不同，保证重复游玩的新鲜感。

- 连锁反应/Combo系统：多张卡牌之间可以产生协同效果，打出特定组合可以触发强力连招。

## 为什么好玩

这款游戏在同类中找到了独特的切入点。卡牌对战 / Roguelike的核心体验被精炼到极致，每一次操作都有明确的反馈。多人模式增加了社交维度，让原本单人的益智体验变成了一场智力的较量。

## 粘性来源

Roguelike的随机性让每局体验都不同；卡组的不断构建和优化带来成就感；高难度挑战激发反复尝试的欲望。

## Meta 系统

卡牌收集系统：通过多次游玩解锁新角色、新卡牌和成就，扩展可用卡组池。

中 — 卡牌数据平衡和Roguelike内容量是主要挑战
