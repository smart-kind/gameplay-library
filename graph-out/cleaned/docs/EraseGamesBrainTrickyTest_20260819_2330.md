# Erase Games: Brain Tricky Test

- **类型**: 益智解谜 / 擦除交互 / 脑筋急转弯
- **平台**: Mobile (iOS+Android)
- **开发商**: Arcade Puzzle
- **首次发布**: 2021
- **一句话描述**: 一款以"擦除"为核心交互机制的解谜游戏，玩家通过擦除屏幕上的元素来解决问题，答案往往出人意料

## 玩法规则

游戏画面展示一个包含多个元素的情境场景，通常有文字提示（如"找到隐藏的物体"、"帮助角色脱困"、"解决这个矛盾"等）和看似完整但缺少某个关键要素的画面。

玩家的核心操作是"擦除"——用手指在屏幕上涂抹，像用橡皮擦一样擦掉画面上的元素。被擦除的部分会消失，露出后面的内容或改变场景的状态。这种交互方式打破了常规"添加/构建"的解谜模式，转而通过"删除/消除"来解决问题。

每个关卡的目标看起来是一个常规问题，但正确答案通常需要擦除某个特定元素——可能擦掉一堵墙让角色通过，擦掉一个错误的数字让等式成立，擦掉角色的衣服（搞笑向），擦掉问题文字本身（"没有问题了"）等等。

屏幕上方显示关卡目标，中间是主要场景，下方可能有"提示"按钮和关卡进度。玩家可以通过橡皮擦工具在屏幕上任意擦除，擦除后观察场景变化是否满足目标条件。如果擦除了错误的东西，可以重置关卡重新尝试。

## 核心循环

观察场景和目标 -> 用手指擦除画面元素 -> 观察变化判断是否达成目标 -> 解锁下一关

## 核心机制

- **擦除交互系统**: 这是游戏的核心创新——通过"删除"而非"添加"来解决问题。擦除操作直观且有物理感（手指摩擦的效果），同时擦除后露出隐藏内容的"揭秘感"提供了强烈的反馈
- **反直觉答案系统**: 正确答案往往不是"做加法"而是"做减法"——不是画一座桥，而是擦掉一条河；不是找钥匙，而是擦掉门锁。这种逆向思维设计让每个关卡都充满惊喜
- **多层次隐藏内容**: 部分关卡需要擦除多层内容——第一层擦除显示一个线索，基于这个线索再擦除另一个区域才能找到真正的答案。这种"层层揭秘"的结构增加了探索的深度

## 为什么好玩

擦除操作本身就有种"破坏"的快感——在正常情况下不允许删除的东西，在这里可以随意擦掉。同时，发现"原来答案这么简单（只要擦掉这个就行了）"时的自嘲式快乐是独特的。搞笑向的答案设计让解谜过程充满笑声

## 粘性来源

具体来说：1）好奇心——"擦掉这个会怎样？"的探索欲驱动玩家尝试各种擦除方式；2）幽默感——搞笑的答案让人忍不住想继续看下一关还有什么"套路"；3）低门槛高满足——擦除操作简单到任何人都能做，但找到正确答案的满足感不亚于任何硬核解谜；4）关卡密集——每个谜题都很短，几分钟一个，适合碎片化游玩

## Meta 系统

提示系统：消耗游戏内货币查看提示，货币通过通关或观看广告获得。部分版本包含每日挑战和排行榜功能

## 实现难度

低（技术实现）。核心难点是创意设计而非技术——需要持续产出大量有趣、不重复的擦除谜题。技术上主要是擦除效果的平滑渲染和多图层管理

## 关卡设计趋势

游戏关卡通常遵循由浅入深的设计原则：前期关卡（1-50关）主要让玩家熟悉基本操作和规则，圆点种类少、网格小、步数充裕；中期关卡（50-200关）开始引入多目标并行的挑战，如同时消除两种颜色的圆点、在步数限制内达到分数目标等；后期关卡（200关以上）则加入特殊元素——如不可消除的"石头"圆点、会随步数增加而"冻结"的圆点、需要多次消除才能清除的"多层"圆点等，大幅提升策略复杂度。

这种渐进式难度设计确保了玩家在每个阶段都能感受到"略有挑战但可克服"的心流体验，既不会因为太简单而无聊，也不会因为太难而放弃。
