# Scoundrel's Cross

- **类型**: 文字冒险 / RPG
- **平台**: Mobile (Android)
- **开发商**: Minion Factory
- **首次发布**: 2011
- **一句话描述**: 一款以文字冒险为核心的RPG游戏，灵感来自80年代的Fighting Fantasy游戏书

## 玩法规则

Scoundrel's Cross 是一款基于Fighting Fantasy游戏书风格改编的文字冒险RPG。玩家扮演一个从监狱中被神秘僧侣招募的"Scoundrel"角色，与一名见习圣武士一起逃离怪物的围剿、对抗狡诈的盗贼团伙。

游戏采用第一人称叙事视角，通过文字描述推进故事。玩家在十字路口需要做出选择：走哪条路、躲在哪里、是否叫醒守卫等。这些选择影响故事走向，但并不提供真正的控制力——战斗和关键事件都在文字中自动发生。

游戏讲述了Scoundrel被神秘僧侣从监狱中招募的故事。他和一名见习圣武士一起逃离怪物的围剿，对抗狡诈的盗贼团伙，还被一位火焰般头发的猎人纠缠。与传统的Fighting Fantasy游戏书不同，这是第三人称冒险——玩家有选择权，但从未真正控制Scoundrel的行动。战斗发生在文字中，听起来很刺激，但玩家完全没有参与。

### 核心循环
做出选择 → 推进故事情节 → 获得故事奖励或惩罚 → 继续冒险

### 核心机制
- **分支叙事选择**：在关键节点做出选择（走哪条路、躲在哪里），虽然选择数量有限但影响故事分支
- **文字驱动战斗**：战斗过程完全由文字描述，玩家无法直接参与操作
- **角色扮演框架**：基于Fighting Fantasy式的RPG规则，但大幅简化了掷骰子等机制
- **故事解锁**：随着冒险推进，逐渐解锁新的故事章节

### 为什么好玩
虽然这款游戏因缺乏交互性和内容不足而获得较低评价，但它的艺术表现非常精美，偶尔能让人沉浸在其冒险故事中。它更像是一本互动小说而非传统游戏。

### 粘性来源
主要粘性来自Fighting Fantasy游戏书的情怀感——那些在80年代读过这类书的玩家会被这种形式吸引。但实际粘性不高，因为内容太短且选择太少。

### Meta 系统
无。游戏没有外围成长系统，纯粹是线性文字冒险体验。

### 实现难度
低。主要是文字展示 + 分支选择逻辑，技术上没有难点。最大的挑战在于写出足够吸引人的故事内容。
