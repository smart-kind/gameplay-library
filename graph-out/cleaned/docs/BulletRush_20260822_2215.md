# 子弹冲刺（Bullet Rush!）

- **类型**: 射击 / 超休闲动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2020
- **一句话描述**: 操控角色在战场上移动，向数百名敌人疯狂射击。拥有最可爱的画面风格，需要精准走位和射击技巧。

## 玩法规则

游戏主界面呈现简洁直观的布局，核心操作区域占据屏幕中央，上方显示关键数值（金币/进度/等级），下方排列功能按钮。玩家通过点击屏幕触发核心行为——例如放置游戏中点击产生资源、射击游戏中瞄准并开火、潜行游戏中滑动控制角色移动方向。

在放置类游戏中，玩家初始手动点击获取基础资源，随后解锁自动产出单元。每次点击或等待都会累积资源，资源用于购买更多产出单元或升级效率。游戏不会强制结束，玩家可以随时退出，离线期间仍会按一定比例积累资源。

在动作/射击类游戏中，屏幕会出现大量敌人或障碍，玩家通过滑动/点击操控角色躲避伤害并消灭目标。游戏通常以关卡为单位，每关有波次递增的敌人数量。玩家的血量归零或时间耗尽则关卡失败，需要重新开始或使用道具复活。

在潜行/解谜类游戏中，玩家需要仔细观察场景中的巡逻路线、障碍物位置和可交互元素。操作以滑动为主，控制角色沿安全路径移动。碰到障碍物或被发现则当前尝试失败，需要重新规划路线。每个关卡有明确的终点或目标需要到达。

## 核心循环

点击/操作 → 获得资源/进度 → 升级/解锁更多内容 → 效率提升 → 获得更多

## 核心机制

- **放置/离线收益机制**：即使关闭游戏，后台也会按一定比例（通常为在线时的30%-50%）累积资源，保证玩家回归后仍有收获感。这一机制降低了时间门槛，让玩家可以在碎片时间游玩。
- **指数级升级系统**：每次购买升级的成本呈指数增长（通常1.15倍递增），但产出也同步提升。这种设计让"下一个目标"始终触手可及但需要时间，维持持续的游戏动力。
- **关卡波次递增**：在动作/射击类游戏中，敌人数量和种类逐波增加，难度曲线经过精心设计，让玩家在"稍有挑战但可通过"的区间内获得心流体验。

## 为什么好玩

这些游戏的共同点是将复杂的体验压缩为最简操作——一根手指就能完成所有交互。放置游戏利用"后台也在赚钱"的心理暗示，让人忍不住每隔几分钟打开看看攒了多少；射击游戏用海量敌人和弹幕营造紧张刺激，配合可爱的画面风格形成反差萌；合集游戏则通过20+种不同小游戏的轮换，保证新鲜感不会消退。

## 粘性来源

**放置类**的核心粘性来自数值成长——看着数字从几百涨到几百万几亿的多巴胺反馈，配合离线收益机制"回来就赚到了"的心理暗示。
**动作类**的核心粘性来自"差一点就过关"的不甘心和每波新敌人带来的短暂新鲜感，以及角色升级后的爽快感反馈。
**合集类**的粘性来自游戏多样性——20+种玩法轮换出现，不会因单一机制疲劳而流失，同时离线可玩的特性覆盖了大量碎片时间场景。

## Meta 系统

- **皮肤/外观解锁系统**：通过累积游戏内货币解锁角色外观、场景主题、特效等纯视觉奖励，不影响核心玩法但满足收集欲。
- **成就/里程碑系统**：设置一系列可量化的目标（点击1000次、消灭10000个敌人等），完成后给予一次性奖励，提供阶段性成就感。
- **每日登录/签到奖励**：连续登录天数递增奖励，第7天给予较大奖励，培养每日打开习惯。

## 实现难度

中等 + 放置游戏核心逻辑简单但需要精细的数值平衡设计，最大的技术难点在于离线收益计算（需要准确记录时间差、按比例计算产出、处理异常时间跳跃如系统时间篡改）。动作类游戏难点在于性能优化——同屏大量敌人/弹幕时保持60帧流畅度。
