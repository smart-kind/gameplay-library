# Ookibloks (Ooblest)

- **类型**: Reference
- **平台**: iOS
- **开发商**: Steven Foskett
- **首次发布**: 2022
- **一句话描述**: A reference game available on iOS, developed by Steven Foskett.

## 玩法规则

Ooblest is a searchable, easy to use reference app for gamers who play Ooblets. Ooblest Features: -Ooblets details view that shows what they require in order to dance battle them so you don't have to run all the way to where they are to check each day. -Lists of Crops, Recipes, and Found Items that you can search through so you don't have to run all around town to figure out what you need and where to get it. -Ability to mark if you've grown an ooblet, which variation (normal, unusual, gleamy), and where they currently are. This is a third-party app and not affiliated with Glumberland LLC.
