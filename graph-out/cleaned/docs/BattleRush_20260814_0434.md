# Battle Rush

- **类型**: 跑酷 / 对战
- **平台**: Mobile (iOS)
- **开发商**: Chillingo / EA
- **首次发布**: 2013
- **一句话描述**: 类 Totoro 生物在无尽跑酷中收集虫子积累攻击能量，与随机匹配的对手隔空对战

## 玩法规则

游戏采用第三人称追尾视角（类似无尽跑酷游戏），玩家操控一个类 Totoro 的生物向屏幕深处奔跑。画面中可以看到前方的障碍物、可收集的虫子和道具。

操作方式：左右滑动躲避障碍物，向上滑动跳跃越过障碍。屏幕中分布着两种虫子：绿色虫子增加生命值，红色虫子积累"攻击"计量条。

攻击计量条满后，击中目标框就会对屏幕外的对手发动攻击。对手以独立的血条形式显示在屏幕右侧——你看不到对手，只能看到他的血条。

通过 Game Center 可以匹配随机对手或与朋友对战。游戏结束条件是双方的血量/攻击计量条有一方先耗尽。

## 核心循环

跑酷收集虫子 → 积累攻击能量 → 攻击屏幕外对手 → 消耗对方血条 → 获胜

## 核心机制

- **双资源系统**：绿色虫子 = 生命值，红色虫子 = 攻击能量，玩家需要在保命和攻击之间做出路线选择
- **隔空对战**：虽然匹配了真实玩家，但双方不在同一画面中，只能通过血条变化感知对方状态
- **角色强化**：比赛前可以用虚拟货币强化角色属性，影响比赛结果

## 为什么好玩

Battle Rush 尝试在无尽跑酷这个已经饱和的品类中加入 PVP 对战元素，想法有创意。绿色/红色虫子的资源取舍给跑酷增加了决策维度——是贪攻击条还是保命。但评测指出，看不到对手的血条反馈让对战缺乏紧张感，而且赛前付费强化系统让胜利的成就感大打折扣。

## 粘性来源

PVP 对战的竞争欲——"再赢一把就睡"的冲动。但由于看不到对手、缺乏直接反馈，这种粘性比较脆弱。赛前强化系统可能让付费玩家产生短暂的"碾压快感"。

## Meta 系统

- **角色强化系统**：使用虚拟货币（含内购）提升角色属性，直接影响对战结果
- **双币种收集**：红色虫子和绿色虫子分别对应攻击和生命，在比赛中自然获取，赛后用于角色升级
