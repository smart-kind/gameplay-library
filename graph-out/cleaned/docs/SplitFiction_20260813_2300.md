# Split Fiction（双影奇境）

- **类型**: 合作冒险 / 动作
- **平台**: PC / PlayStation / Xbox
- **开发商**: Hazelight Studios
- **发行商**: Electronic Arts
- **首次发布**: 2025
- **一句话描述**: 双人合作冒险游戏，两位玩家被困在自己创作的故事世界中，需要协作才能逃脱。

## 玩法规则

游戏采用分屏或在线双人模式，两位玩家分别扮演作家 Mio Hudson 和 Zoe Foster。两人被意外困在自己共同创作的故事世界中，需要合作穿越不同风格的游戏场景才能逃脱。

画面风格多变——因为游戏场景会随着故事世界切换而变化，从科幻太空站到奇幻城堡、从恐怖地牢到西部小镇，每个场景都有完全不同的视觉风格和玩法机制。

两位玩家的核心操作包括：移动、跳跃/攀爬、互动、使用场景特有的能力或工具。关键是两位玩家的能力通常不同——一个玩家可能负责战斗，另一个负责解谜；或者一个在 A 场景操作机关，为 B 场景中的同伴开辟道路。这种"分工合作"是游戏的核心设计理念。

关卡设计强制要求两位玩家协作：没有单人可以完成的挑战，每个谜题和战斗都需要两人配合。比如一个玩家需要引开敌人，另一个玩家趁机通过；或者一个玩家操作电梯，另一个玩家进入目标区域。

## 核心循环

进入场景 → 分工协作 → 解决谜题/击败敌人 → 推进故事 → 切换到新场景

## 核心机制

- **强制双人合作**：没有单人模式，所有挑战都需要两人配合。这种设计确保了合作不是"可选项"而是"唯一选项"。
- **场景切换机制**：故事世界的切换让玩法保持多样性——刚在一个科幻场景中战斗，下一个场景可能是一个需要合作的平台跳跃关卡。
- **角色能力差异化**：两位玩家有不同的能力和视角，需要互补才能完成任务。
- **叙事驱动**：游戏以"作家被困在自己的故事中"为核心叙事，每个场景都是一个故事片段，玩家在其中既是角色也是"作者"。

## 为什么好玩

Hazelight Studios（《A Way Out》《It Takes Two》的开发商）是强制双人合作游戏的专家。Split Fiction 延续了他们的设计理念：合作不只是"一起玩"，而是"必须一起玩"。这种设计创造了独特的社交体验——你和朋友必须沟通、协调、互相依赖，这种互动本身就很有趣。

## 粘性来源

- **社交互动**：和朋友一起解决难题、互相调侃、共同完成挑战，这种社交体验是单人游戏无法替代的。
- **场景多样性**：不断切换的故事世界让玩法保持新鲜。
- **共同成就感**：一起完成挑战的成就感比单人完成更强烈，因为你知道这需要两个人的配合。

## Meta 系统

无。游戏是纯粹的合作冒险体验。

## 实现难度

**高**。主要难点在于：1）双人协作关卡设计——每个关卡都需要为两个玩家设计不同的角色和路径，工作量是单人游戏的两倍以上；2）在线多人同步——需要确保两位玩家的动作和状态实时同步；3）场景多样性——大量不同风格的场景需要各自独特的美术和玩法设计。Hazelight Studios 有丰富的同类游戏开发经验。
