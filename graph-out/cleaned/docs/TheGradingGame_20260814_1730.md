# 批改游戏（TheGradingGame）

- **类型**: 文字益智
- **平台**: Nintendo DS / Mobile
- **开发商**: PocketGamer 收录独立游戏
- **首次发布**: 2012
- **一句话描述**: 一款模拟老师批改试卷的文字益智游戏，在试卷中找出各种错误

## 玩法规则

游戏画面模拟一张试卷的视觉效果，上面有学生的作答内容（包括文字、算式、图表等）。玩家扮演老师，需要在限定时间内批改这份试卷。

错误类型包括：
- 拼写错误：单词拼写不正确，如 'recieve' 应为 'receive'
- 语法错误：句子语法不正确，如主谓不一致、时态错误等
- 标点错误：标点符号使用不当或缺失
- 计算错误：数学算式中的计算错误
- 事实错误：陈述中的事实性错误
- 逻辑错误：论述中的逻辑谬误

玩家通过DS触控笔在试卷上圈出错误，然后选择正确的答案。每找对一个错误得分，遗漏的错误会扣分。

游戏有不同的科目：语文、数学、科学、历史、地理等。每个科目有专门的错误类型和知识点。

难度随关卡推进递增：低年级试卷错误明显且较少，高年级试卷错误更隐蔽且数量更多。部分关卡有时间压力，需要在规定时间内完成批改。

每完成一份试卷后会显示评分、找到的错误、遗漏的错误，以及总体评价。

## 核心循环

查看试卷内容 → 仔细寻找各类错误 → 标记并纠正错误 → 获得评分 → 进入下一份更难的试卷

## 核心机制

- **找错机制：在大量文字内容中找出隐藏的各类错误（拼写、语法、计算、事实等），考验玩家的细心程度和知识储备**
- **多学科覆盖：涵盖语文、数学、科学、历史等多个学科，每科有专门的错误类型和知识点，内容丰富**
- **限时挑战机制：部分关卡有时间限制，在规定时间内完成批改增加紧张感和挑战性**
- **难度递增系统：从简单的明显错误到复杂的隐蔽错误，难度平滑递增。高年级试卷可能需要特定学科知识**

## 为什么好玩

独特的'找错'玩法，将日常批改试卷的经验转化为游戏乐趣。多学科内容让不同知识背景的玩家都能找到擅长的领域。扮演老师的角色代入感强。

## 粘性来源

眼力挑战和知识展示的双重满足感。评分系统和等级提升提供持续的进步感。多学科内容保证长期的新鲜感。

## Meta 系统

评分系统和教师等级提升。累积评分达到一定标准后晋升教师等级（实习教师→正式教师→资深教师→教授）。

## 实现难度

中，需要良好的语言基础和观察力。最大技术难点在于题库的丰富性和错误设计的合理性。
