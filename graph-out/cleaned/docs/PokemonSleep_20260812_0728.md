# 宝可梦睡眠 (Pokémon Sleep)

- **类型**: 睡眠追踪 / 收集 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Select Button / The Pokémon Company
- **首次发布**: 2023
- **一句话描述**: 通过追踪真实睡眠来收集和研究宝可梦的睡眠模式，将健康生活习惯与收集玩法结合

## 玩法规则

游戏的核心循环与现实生活中的睡眠时间紧密绑定。玩家在睡前打开应用，将手机放在枕边（需插电），或佩戴Pokémon GO Plus +配件。应用在玩家睡眠期间追踪睡眠时长、睡眠类型（浅睡、深睡、REM睡眠）和翻身次数。

第二天醒来后，玩家打开应用查看睡眠报告。根据睡眠质量，卡比兽的"瞌睡之力"会计算出吸引来的宝可梦种类和数量。睡眠类型分为三种：无忧无虑型（翻身多）、呼呼大睡型（深睡多）、认认真真型（浅睡多）。不同类型的睡眠会吸引不同属性的宝可梦。

吸引来的宝可梦出现在营地，玩家可以查看它们的睡眠姿态（每种宝可梦有多种独特的睡姿），并用宝可饼干招募它们成为助手。助手宝可梦会在白天自动收集食材，用于给卡比兽制作餐点。卡比兽进食后会成长，提升"瞌睡之力"等级，从而在下次睡眠时吸引更多、更稀有的宝可梦。

游戏还包含研究任务系统——完成特定的研究任务（如收集某种宝可梦的所有睡姿、达到特定的睡眠质量等）可以获得奖励，包括稀有的宝可饼干和研究点数。这些任务为玩家提供了额外的短期目标。

## 核心循环

睡觉 → 收集睡眠数据 → 吸引宝可梦 → 查看睡姿 → 招募助手 → 收集食材 → 喂食卡比兽 → 卡比兽成长 → 更强的吸引能力 → 循环往复

这个过程构成了每日的游戏节奏：早上醒来查看睡眠结果，白天管理助手团队收集食材并制作餐点，晚上睡觉前做好准备（使用熏香等增益道具），然后进入下一个睡眠周期。

## 核心机制

- **睡眠类型系统**：游戏将睡眠分为三种类型，每种类型对应不同属性的宝可梦。玩家需要通过不同的睡眠习惯来吸引目标宝可梦，这鼓励玩家保持多样化的睡眠模式。
- **睡姿收集**：每种宝可梦有多种独特的睡眠姿态（如皮卡丘有仰睡、侧睡、趴睡等），每种姿态有不同的稀有度。收集睡姿是核心收集目标。
- **助手系统**：招募的宝可梦成为助手，在白天的三个时段（早餐、午餐、甜点）自动收集食材。不同宝可梦有不同的专长（食材收集S、L、M型号）和收集频率。
- **卡比兽成长**：通过喂食餐点，卡比兽等级提升，瞌睡之力增强，吸引更多宝可梦。这是核心的数值成长循环。

## 为什么好玩

将健康行为（好好睡觉）与游戏奖励巧妙结合，形成了独特的正向反馈循环。玩家不会因为"玩得多"而变强，反而会因为"睡得好"而变强。这种反直觉的设计让游戏在mobile游戏市场中独树一帜。

## 粘性来源

日常习惯的嵌入是最强的粘性——一旦养成睡前打开应用的习惯，每天都想看看昨晚吸引了什么宝可梦。睡姿收集的稀有度驱动（如金色睡姿的极低概率）和卡比兽的渐进式成长形成了双重动力。

## Meta 系统

研究等级系统：通过持续追踪睡眠提升研究等级，解锁新的宝可梦、新的岛屿（研究区域）。岛屿解锁带来更多样化的宝可梦和新的收集目标。付费通行证（Premium Pass）提供额外的研究点数和功能。

## 实现难度

高。需要精确的睡眠追踪算法（利用加速度传感器、麦克风等），以及将睡眠数据映射到游戏机制的复杂系统。最大的技术难点在于睡眠类型判定的准确性和跨设备兼容性。
