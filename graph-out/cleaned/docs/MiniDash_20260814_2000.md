# Mini Dash

- **类型**: 跑酷 / 反应
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2013
- **一句话描述**: 极简风格的快速反应跑酷游戏

## 玩法规则

玩家控制一个几何形状角色在自动前进的路径上奔跑。游戏的核心操作是通过点击或滑动来改变角色的运动方向或执行特定动作。

游戏界面以极简的几何风格呈现。路径上布满障碍物和缺口，玩家需要在正确的时机做出反应——跳跃、滑行、转向或加速。

每个障碍物都有固定的应对方式。例如，遇到缺口需要跳跃，遇到低矮障碍需要滑行，遇到分岔路需要选择正确方向。反应时间窗口很小，考验玩家的专注力和反应速度。

游戏目标是尽可能前进更远距离。失败后从起点重新开始，但会积累距离记录。

## 核心循环

自动奔跑 → 遇到障碍 → 快速反应 → 继续前进 → 刷新记录

## 核心机制

- **自动奔跑**：角色自动前进，玩家专注于时机判断而非方向控制
- **即时反应**：障碍出现到反应窗口很短，考验直觉和专注力
- **极简设计**：简洁的几何美术风格让注意力集中在核心玩法上
- **记录挑战**：以距离为衡量标准，鼓励不断突破自我

## 为什么好玩

极简设计和即时反馈让游戏体验纯粹而直接。每次失败都知道是自己的反应慢了，而不是游戏不公平，激发"再来一次"的冲动。

## 粘性来源

即时反应带来的肾上腺素刺激 + "差一点就破了记录"的不服输 + 极简美学 + 随时可玩的便捷性

## Meta 系统

无 — 纯粹的反应挑战游戏

## 实现难度

低 — 简单的跑酷游戏，最大技术难点在于障碍生成的随机性和难度曲线的平滑控制
