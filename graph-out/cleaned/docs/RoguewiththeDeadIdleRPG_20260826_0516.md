# Rogue with the Dead: Idle RPG

- **类型**: 肉鸽放置RPG / 像素艺术
- **平台**: Mobile (iOS)
- **开发商**: room6 inc.
- **首次发布**: 2022
- **一句话描述**: Rogue with the Dead是一款原创的肉鸽RPG放置游戏。玩家指挥一支士兵队伍进行300英里的无尽旅程，目标是击败终点的魔王。

## 玩法规则

游戏以精美的像素艺术风格呈现奇幻世界。屏幕显示队伍自动前进和战斗的场景，底部有升级和技能按钮。士兵自动战斗，玩家可以选择观看或加入战斗。击杀怪物和完成任务获得金币，用于强化士兵。核心机制：士兵死后会重生，但玩家角色会死亡并失去所有士兵、金币和物品（神器除外），需要从头开始。收集神器是变强的关键，击败Boss获得神器，神器在死亡后保留并提供永久加成。可以雇佣治疗师、召唤师、魔法师等不同职业。

## 核心循环

指挥队伍战斗 -> 收集金币强化士兵 -> 收集神器 -> 死亡后保留神器重新开始 -> 变得更强 -> 继续前进 -> 重复

## 核心机制

- 肉鸽死亡机制：死亡后失去士兵和金币，但保留神器，每次重新开始都更强
- 多职业系统：剑士、弓箭手、侏儒、巫师等不同兵种组合策略
- 神器收集：击败Boss获得永久神器，是长期进化的关键
- 离线进度：关闭游戏后队伍继续战斗，返回时收取金币

## 为什么好玩

由room6团队制作（代表作Unreal Life、Gen'ei AP），像素艺术质量很高。肉鸽加放置的完美结合：自动战斗降低了操作压力，但死亡惩罚和神器收集提供了策略深度。

## 粘性来源

神器收集提供长期目标：每次死亡都不是白费；多职业组合让每次尝试都不同；像素艺术和故事情节提供叙事驱动；离线进度让随时可玩

## Meta 系统

有神器系统（永久加成）、多兵种系统（剑士/弓箭手/侏儒/巫师等）、料理系统（烹饪增强士兵）、在线排行榜。离线自动战斗。

## 实现难度

中。核心难点在于肉鸽放置RPG玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
