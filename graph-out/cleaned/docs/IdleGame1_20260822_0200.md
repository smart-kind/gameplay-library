# 放置游戏1（Idle Game 1）

- **类型**: 放置/休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2020
- **一句话描述**: 基础放置类游戏

## 玩法规则

玩家通过放置方式让游戏自动进行。资源自动增长，玩家点击收集并用于升级。升级提升资源产出速度。游戏包含多层升级系统，每次升级都可能解锁新功能。离线时资源继续积累。游戏设计简洁，专注于数值成长的快感。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

资源自动增长 → 收集升级 → 产出提升 → 解锁新内容 → 继续增长

## 核心机制

- **自动增长**:  资源持续自动积累
- **多层升级**:  多层次的升级系统
- **离线收益**:  离线时继续增长

## 为什么好玩

数值持续增长的满足感，升级反馈的即时性

## 粘性来源

数值增长的不可逆性让人持续回归；新升级解锁的期待

## Meta 系统

多层升级系统

## 实现难度

低 - 核心是数值计算 - 数值平衡设计
