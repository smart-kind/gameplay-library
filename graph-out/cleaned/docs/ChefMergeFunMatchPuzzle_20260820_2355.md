# Chef Merge（Chef Merge - Fun Match Puzzle）

- **类型**: 合成解谜 / 模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: HIGGS TECHNOLOGY CO., LIMITED
- **首次发布**: 2021
- **一句话描述**: 一款轻松的合成装饰解谜游戏，玩家通过合并蔬菜水果等元素获取资源，用来装饰庄园。

## 玩法规则

游戏采用棋盘式网格布局，玩家可以看到各种蔬菜水果、农作物散落在棋盘上。核心操作是拖拽两个相同物品到彼此上面进行合并，合并后会生成更高阶的物品。合并产生的物品可以兑换给特殊邻居获取金币和钻石。玩家使用金币和钻石购买家具、地毯、灯具等装饰品来设计自己的庄园。每个装饰品的图案、形状、风格都由玩家自由选择，没有固定搭配限制。

游戏没有步数限制或时间压力，属于完全放松型解谜。棋盘初始状态由系统随机生成，每次移动后新物品会补充到棋盘上。高阶合并会产出稀有装饰品材料。当玩家完成一组装饰目标后解锁新的场景区域。

游戏胜利条件是完成当前区域的装饰任务，进入下一章节。每个章节有明确的主题风格（如中式庭院、欧式花园等），玩家需要收集对应风格的装饰物来通关。

## 核心循环

拖拽合并物品 → 获取金币钻石 → 购买装饰品完成庄园设计 → 解锁新区域

## 核心机制

- **合成升级链**: 两个相同物品合并生成高阶物品，形成递进式合成链（蔬菜→沙拉→大餐→盛宴），每次合并产生数值跃升，给予清晰的成长反馈
- **自由装饰系统**: 地毯、灯具、桌椅等每个装饰类别有多个可选方案，玩家按个人审美搭配，没有标准答案，强化个性化表达和归属感
- **邻居交换机制**: 合并产出物可以兑换给不同邻居，每位邻居提供不同奖励（金币/钻石/稀有材料），玩家需要在不同需求间做策略取舍

- **装饰目标系统**: 每个区域有明确的装饰清单（如"完成客厅装修需要5件家具"），清单进度条清晰可见，给玩家"差两件就完成了"的心理驱动。完成清单后获得星星奖励和剧情对话
- **季节性活动**: 定期推出限定装饰主题（如万圣节、圣诞节），限时装饰链提供额外奖励，利用稀缺性驱动玩家活跃度

## 为什么好玩

将合成解谜的爽快感与模拟经营的成就感融合。每次合并都有即时的数值反馈，而装饰庄园则提供长线目标。无需时间压力或体力限制，适合碎片化休闲游玩。

## 粘性来源

合成链的差一次就能合并出更好物品心理驱动持续游玩；装饰系统提供收集欲和个性化表达空间；章节主题切换维持新鲜感。

## Meta 系统

- **章节解锁系统**: 完成当前区域装饰任务解锁下一章
- **对核心玩法的影响**: 新章节带来新装饰主题和合成链，不改变核心玩法但扩展内容量

## 实现难度

低 — 核心合并逻辑极简，最大技术难点是装饰设计系统的UI交互流畅度和大量装饰素材的资源管理
