# Idle Slayer: Addictive Clicker

- **类型**: 放置 / RPG / 冒险
- **平台**: Mobile (iOS)
- **开发商**: Pablo Leban
- **首次发布**: 2020
- **评分**: ⭐ 4.8/5 (27,375 评价)
- **价格**: Free
- **一句话描述**: Idle Slayer不仅仅是一个放置游戏——它是一个永无止境的传奇！消灭怪物、赚取金币、解锁升级。

## 玩法规则

游戏采用横版画面。角色自动向右移动并攻击遇到的怪物。通过点击屏幕加速攻击。消灭怪物获得金币，用于升级攻击力、速度、自动攻击频率等。随着游戏进展，解锁新区域、新怪物类型、新武器。角色可以装备不同武器（剑、弓、法杖等），每种武器有不同攻击模式。界面包含：横版战斗场景、角色、怪物、资源计数、升级菜单。

## 核心循环

自动战斗 → 消灭怪物获金币 → 升级属性/武器 → 进入新区域 → 面对更强怪物

## 核心机制

- 自动战斗：角色自动移动和攻击，放置玩法
- 武器多样性：不同武器有不同攻击模式和特效
- 区域探索：解锁新区域带来新怪物和挑战

## 为什么好玩

横版RPG的视觉表现力比纯数字放置更强。看着角色一路砍杀前进，成就感满满。

## 粘性来源

武器/区域解锁、数值成长、自动战斗的轻松感

## Meta 系统

放置战斗+RPG装备系统。核心玩法即meta。

## 实现难度

中——横版动画+自动战斗需要更多技术实现
