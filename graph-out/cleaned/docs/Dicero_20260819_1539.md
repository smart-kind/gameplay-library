# Dicero!

- **类型**: Roguelike / 骰子策略 / 地牢探索
- **平台**: Mobile (iOS+Android)
- **开发商**: HABBY
- **首次发布**: 2026
- **一句话描述**: 掷骰子决定行动点数，在随机生成的地牢中规划最优路线击败怪物

## 玩法规则

游戏核心是一个骰子投掷系统 + 地牢格子地图。每回合玩家投掷一颗或多颗骰子（通常1-3颗），骰子点数决定本回合可以执行的行动步数或攻击强度。

地图是随机生成的地牢格子，包含：敌人格子、宝箱格子、商店格子、Boss格子、陷阱格子、空房间。玩家从入口出发，目标是到达地牢深处击败Boss。

每次掷骰后，玩家需要在几个行动选项中做出选择——是用这个点数移动到安全位置？还是冒险靠近强敌获取更好的奖励？点数用不完会浪费，用超了可能落入陷阱。

随着地牢推进，玩家可以获得被动技能（如"骰子+1"、"双倍伤害"、"免疫陷阱"等），以及消耗性道具（如"重掷一次"、"指定点数"）。这些道具在关键时刻使用可以扭转局面。

## 核心循环

掷骰子 → 根据点数规划行动 → 移动/战斗/拾取 → 获得奖励和道具 → 进入下一层地牢 → 掷下一轮骰

## 核心机制

- **骰子行动点系统**：骰子点数就是资源。低点数（1-2）只能做小动作，高点数（5-6）可以长距离移动或强力攻击。但骰子是随机的，关键在于如何在运气不佳时做出最优决策。
- **风险/回报路线规划**：每个地牢层有多条路径可选。安全路线奖励少但稳定，危险路线有大量敌人但宝箱更丰厚。玩家需要根据当前骰子点数和自身状态选择路线。
- **道具时机管理**：重掷道具、锁定道具、翻倍道具等资源有限，需要在最关键的回合使用。例如Boss战前保存重掷比在普通层使用价值更高。
- **永久升级系统**：通关或失败后获得永久资源，解锁新的骰子类型、被动技能、角色外观，降低后续难度。

## 为什么好玩

骰子的随机性带来天然的紧张感和惊喜——掷出6点时的兴奋，掷出1点时的绝望，都让每个回合充满情绪波动。而玩家需要在随机结果中做出策略选择，这种"在不确定中寻找最优解"的体验正是策略游戏的核心乐趣。

## 粘性来源

- **随机性+策略的完美结合**：每次掷骰结果不同，每局都是全新体验
- **永久升级驱动**：即使失败也能积累资源解锁新内容
- **"再来一把"效应**：掷骰本身有天然的上瘾性
- **地牢多样性**：随机生成的地牢布局保证每局新鲜感

## Meta 系统

- **永久技能树**：失败后积累资源，解锁"骰子加成"、"初始道具"、"额外生命"等被动升级
- **角色解锁**：不同角色有不同初始属性和专属骰子
- **成就系统**：完成特定挑战（如"无伤通过第5层"）获得特殊奖励

## 实现难度

低-中。核心是随机骰子生成 + 网格地图寻路 + 简单的战斗计算。最大技术难点在于地牢生成的平衡性——确保每局既有趣又公平，避免不可通过的随机地图。需要精心设计地牢生成算法和难度曲线。
