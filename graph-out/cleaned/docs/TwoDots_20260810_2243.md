# 连接同色圆点的极简解谜游戏（Two Dots）

- **类型**: 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Playdots
- **首次发布**: 2014
- **一句话描述**: 连接同色圆点的极简解谜游戏

## 玩法规则

玩家在网格上连接两个或更多相邻的同色圆点。连接4个同色点形成一个方块，消除该颜色所有点。

目标是在限定步数内完成特定任务（消除特定颜色的点、收集特定数量的点等）。

游戏有数百个关卡，难度逐渐增加。

## 核心循环

连接同色点 → 形成方块消除 → 完成关卡目标 → 下一关

## 核心机制

- 连接机制：连接相邻同色点
- 方块消除：连接4点形成方块，消除该色所有点
- 关卡目标：多样化任务
- 步数限制：需要在限定步数内完成

## 为什么好玩

极简的美术风格和优雅的连接机制。形成方块时消除所有同色点的爽快感。

## 粘性来源

关卡驱动；步数限制带来的策略思考。

## Meta 系统

关卡解锁。

## 实现难度

低。连接操作简单。最大技术难点：关卡设计。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
