# Oxide: Survival Island Online

- **类型**: 休闲
- **平台**: Mobile (iOS)
- **开发商**: HYPERHUG LTD
- **首次发布**: 2021
- **一句话描述**: 一款休闲类移动游戏

## 玩法规则

玩家在开放或半开放世界中收集资源（木材、石材、食物等），利用收集到的资源建造工具、武器和庇护所。画面通常采用俯视或第一人称视角，左下角为移动摇杆，右上角为操作按钮（攻击/采集/互动）。

采集资源需要靠近目标物并长按交互键，不同工具有不同的采集效率。建造系统允许玩家放置墙壁、地板、家具等组件，部分游戏支持多层建筑和装饰。

生存元素包括生命值、饥饿值等状态管理——玩家需要定期进食、治疗伤口，在夜晚或恶劣天气中寻找安全的庇护所。

## 核心循环

采集资源 → 制作工具/建造设施 → 提升生存能力 → 探索更危险区域获取更高级资源

## 核心机制

- 机制1：资源采集与制作：不同资源组合可制作不同工具和物品，形成制作树
- 机制2：环境生存：饥饿、温度、昼夜交替等环境变量增加策略维度
- 机制3：渐进式建造：从简陋庇护所到完善基地的视觉成长带来成就感

### 资源管理系统

游戏中的资源通常分为基础资源（木材、石材、食物）和高级资源（金属、魔法材料、稀有矿物）。基础资源通过采集获得，高级资源需要制作特定工具后才能获取。资源库存有容量限制，迫使玩家在探索和携带之间做出权衡。

### 建造与防御

建造系统是核心玩法的重要组成部分。玩家需要根据环境威胁选择建造策略——在开放世界中优先建造围墙和陷阱，在洞穴环境中则注重照明和通风。建筑耐久度会随时间和攻击损耗，需要定期维护。

### 探索与发现

随着游戏进程，新区域会逐渐解锁。每个新区域都有独特的资源类型、敌对生物和环境挑战。探索新区域既是获取高级资源的途径，也是推动游戏叙事的主要方式。地图通常采用迷雾系统——未探索区域被遮挡，激发探索欲望。

## 为什么好玩

从无到有的创造过程本身就是最大的乐趣——看着一片荒地变成自己的家园。生存压力让每次资源采集都有紧迫感。

## 粘性来源

'还差一点就能建好XX'的渐进目标链让人停不下来。基地的视觉成长是最直观的进度反馈。

## Meta 系统

科技树系统：通过解锁新配方来扩展制作和建造能力。对核心玩法的影响是逐步扩大可交互内容的范围，从生存到发展到扩张。

## 实现难度

中 + 休闲类游戏核心逻辑相对成熟，最大的技术难点在于数值平衡——既要保证前期成长速度足够快以留住玩家，又要让后期有足够的深度和追求。
