# 跨路城堡（Crossy Road Castle）

- **类型**: 合作平台跳跃
- **平台**: Mobile (iOS+Android)
- **开发商**: HIPSTER WHALE
- **首次发布**: 2020
- **一句话描述**: 由天天过马路团队打造的旋转城堡合作平台游戏，支持多人在同一设备或跨设备联机游玩

## 玩法规则

游戏场景是一个不断旋转的城堡塔楼内部，多个平台分布在塔楼内壁上。玩家需要操控角色在旋转的塔楼中向上攀爬。

支持最多4人合作，玩家可以连接多个手柄在同一设备上游玩，也可以跨设备联机。一个玩家跳上平台后平台会暂时固定，帮助其他玩家跳跃。

城堡中散布着各种收集品（Crossy Chicken等角色解锁道具），以及不同主题楼层。每个楼层有独特的视觉风格和平台布局。

如果角色从平台上掉落，则游戏结束，需要重新开始。游戏支持单人和多人模式。

每个楼层的新主题不仅改变视觉风格，还带来新的平台类型和机制变化。

## 核心循环

在旋转塔楼中向上攀爬 → 收集角色解锁道具 → 到达更高楼层 → 解锁新主题和角色

## 核心机制

- 旋转平台机制：塔楼不断旋转改变了传统的平台跳跃体验，玩家需要预判平台位置并选择正确的跳跃时机
- 多人合作机制：最多4名玩家可以一起攀爬，可以互相帮助也可以互相干扰。平台互动是合作的核心机制
- 主题楼层系统：不同楼层有不同视觉风格和平台布局变化，保持新鲜感并逐步增加难度

## 为什么好玩

旋转塔楼的独特视角和多人合作的混乱互动创造出独特的派对游戏体验。

每个楼层的新主题保持新鲜感。

和朋友一起玩的乐趣远超单人——互相推搡、意外掉下去的搞笑时刻、一起到达新楼层的欢呼，这些社交互动是游戏最大的乐趣来源。

## 粘性来源

多人合作模式是核心粘性——和朋友一起玩的乐趣远超单人。角色收集系统提供长期目标

## Meta 系统

角色收集系统：收集Crossy Chicken等角色，每个角色有独特外观，部分角色有微小能力差异

## 实现难度

中等 — 旋转平台需要适应新的空间感知。最大的技术难点在于多人同步和旋转场景的流畅渲染
