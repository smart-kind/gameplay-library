# Idroidsmania

- **类型**: 塔防 / 策略
- **平台**: Mobile (iOS)
- **开发商**: Gameloft
- **首次发布**: 2009
- **一句话描述**: 机器人塔防战，部署防御单位抵御入侵

## 玩法规则

玩家需要在战场上部署机器人防御单位来阻止敌人的进攻。

游戏采用俯视角，战场被划分为网格，玩家可以在网格上放置不同类型的防御机器人。

每种机器人有不同的攻击范围、伤害类型和特殊技能（如对空、对地、范围攻击、冻结等）。

敌人从地图边缘沿着固定路径向基地推进，玩家需要在路径周围合理布置防御。

通过消灭敌人获得资源，用来建造更多防御机器人或升级现有单位。

在波次之间，玩家可以调整布防——移动、升级或拆除防御机器人。

过关条件：在所有敌人波次结束后基地未被摧毁。

失败条件：基地被摧毁。

## 核心循环

布置防御 -> 消灭敌人 -> 获取资源 -> 增强防御（一句话）

## 核心机制

- 网格塔防机制：在固定网格上放置单位，需要预判敌人路径来优化布局。不同网格位置可能有不同的战略价值（如交叉点、转弯处）。
- 单位协同机制：不同类型防御机器人组合产生协同效果（如减速+范围伤害的组合）。合理的单位搭配比单一单位堆砌更有效。
- 波次递进：每波敌人更强更多样，迫使玩家调整防御策略。后期波次可能包含多路同时进攻的敌人。

## 为什么好玩

机器人题材塔防的科幻感，多种防御单位的搭配组合提供丰富的策略深度。每种机器人的攻击动画和效果都精心设计。

## 粘性来源

策略优化带来的成就感——每次尝试更优的布局方案。新单位和敌人类型保持新鲜感。星级评分系统鼓励以最优资源消耗通关。

## Meta 系统

解锁系统：通关解锁新防御单位和升级选项。部分版本含跨关卡的永久升级系统。

## 实现难度

中 — 与Battle for Mars类似的塔防核心，但增加了网格和协同机制。核心技术难点是多单位同时运行的性能优化和路径寻找算法。
