# Idle Sheep!

- **类型**: 放置 / 模拟经营
- **平台**: Mobile (iOS)
- **开发商**: Mindstorm Studios
- **首次发布**: 2016
- **评分**: ⭐ 4.7/5 (4,694 评价)
- **价格**: Free
- **一句话描述**: 你能点得够快吗？点击-建造- farming，即使不玩也在继续！

## 玩法规则

游戏开始于一个小型农场和几只羊。通过点击屏幕让羊产出羊毛/金币。用金币购买更多羊、升级农场设施、雇佣工人自动生产。随着农场扩大，解锁新动物类型、新设施、新产品。界面以农场为核心视图，显示羊群、建筑、资源计数。

## 核心循环

点击产出 → 购买更多羊/升级 → 自动生产 → 扩展农场

## 核心机制

- 点击加速：手动点击加速生产，离线自动生产
- 农场扩展：从几只羊到大型农场的渐进发展
- 多样化动物：解锁不同动物类型，增加变化

## 为什么好玩

农场经营的主题温馨可爱。看着农场从几只羊扩展到大型牧场，成就感满满。

## 粘性来源

农场扩展的视觉反馈、离线收益、解锁期待

## Meta 系统

放置生产+农场扩展系统。核心玩法即meta。

## 实现难度

低——放置游戏模板成熟
