# Hyper Arrow

- **类型**: 跑酷 / 动作
- **平台**: Mobile (iOS)
- **开发商**: Thu Nguyen Thi
- **首次发布**: 2026
- **评分**: ⭐ 1.3/5 (47 评价)
- **价格**: Free
- **一句话描述**: 一款霓虹风格的快节奏跑酷游戏，滑动控制箭群冲撞数字方块，像滚雪球一样不断壮大。

## 玩法规则

游戏画面是霓虹风格的赛道。玩家控制一群箭矢向前飞行。赛道上布满标有数字的方块。通过左右滑动控制箭群的移动方向。箭群撞击方块时，如果箭的数量大于方块上的数字，方块被击碎，箭群数量增加；如果小于，部分箭被消耗。目标是在到达终点前尽可能壮大箭群。赛道上还有加分道具和障碍物。界面采用霓虹美学：发光的箭矢、彩色数字方块、暗色背景。

## 核心循环

控制箭群方向 → 撞击数字方块 → 壮大箭群 → 到达终点

## 核心机制

- 数量管理：箭群数量是核心资源，需要权衡风险（撞大方块）和收益
- 霓虹视觉：发光的霓虹美学提供强烈的视觉反馈
- 滑动控制：单指滑动控制方向，操作简单

## 为什么好玩

霓虹美学+数字方块碰撞的爽快感。滚雪球式的壮大过程让人上瘾。

## 粘性来源

视觉爽感、数字增长的满足感、跑酷的节奏感

## Meta 系统

箭矢皮肤/特效解锁。不影响核心玩法。

## 实现难度

低——跑酷+碰撞检测，技术实现简单
