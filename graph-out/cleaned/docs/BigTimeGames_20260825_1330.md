# Big Time Games

- **类型**: 休闲游戏合集
- **平台**: Mobile (iOS+Android)
- **开发商**: WINR Games Inc.
- **首次发布**: 2014
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 游戏主界面通常包含多个操作按钮和信息显示区域。顶部可能显示分数、计时器或关卡进度。
- 中央区域是主要的游戏操作区域，显示游戏元素（泡泡、宝石、角色、地图等）。
- 底部或侧边显示可用操作、手牌或待放置元素。

玩家的操作方式包括：
- 点击/拖拽：选择并放置游戏元素，进行匹配或移动操作
- 滑动：在某些游戏中进行方向控制或瞄准
- 长按：在某些游戏中蓄力或执行特殊操作

## 核心循环

选择小游戏 -> 游玩 -> 获得积分 -> 发现新游戏

## 核心机制

- **休闲合集**: 提供多款休闲小游戏，涵盖不同类型。适合放松和消遣。
- **即时游玩**: 即点即玩，无需下载安装。适合碎片时间。
- **积分系统**: 游玩获得积分，积分可用于解锁更多内容。

## 为什么好玩

多款游戏的集合提供了丰富的选择。轻松休闲的氛围适合放松。

## 粘性来源

粘性来源于丰富的内容和积分解锁系统。

## Meta 系统

- 积分系统：游玩获得积分
- 对核心玩法的影响：积分解锁提供了成长目标

## 实现难度

中 -> 作为游戏平台/合集，核心难点在于游戏内容的整合和管理。每款小游戏的实现难度因类型而异，但整体架构需要良好的模块化设计。
