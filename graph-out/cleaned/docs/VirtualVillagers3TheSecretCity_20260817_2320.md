# 虚拟村庄3：秘密之城（Virtual Villagers 3: The Secret City）

- **类型**: 虚拟生活模拟
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Last Day of Work
- **首次发布**: 2008
- **一句话描述**: 上帝视角的虚拟部落模拟游戏，玩家指导一群村民在一个神秘岛屿上建立文明。

## 玩法规则

游戏画面是俯瞰视角的神秘岛屿地图，上面有丛林、海滩、废墟和未探索区域。屏幕下方是村民列表和状态栏。
村民（Villagers）有自己的名字、年龄、职业倾向和技能。每个村民会自主行动：走路、采集食物、休息、社交等。
玩家通过拖拽村民到特定位置来分配任务：拖到浆果树旁=采集食物、拖到废墟旁=清理废墟、拖到水边=捕鱼、拖到书架旁=学习科技。
村民会自然成长：儿童会长大成人、成年人会变老。通过配对两个成年村民，他们可以结婚生子，增加村庄人口。
游戏的核心目标是探索和恢复神秘岛屿上的古代文明：清理废墟发现科技、建造新建筑、解开谜题。
游戏是实时进行的，即使关闭游戏后时间也在流逝。村民会自主行动，但效率较低。打开游戏后可以通过拖拽分配任务加速进展。

## 核心循环

观察村民状态 → 拖拽分配任务（采集/建造/探索） → 等待任务完成 → 获得科技和资源 → 解锁新区域和建筑 → 继续探索

## 核心机制

- 异步实时模拟：村民24小时自主生活，玩家打开游戏时查看进展并做出新决策，类似电子宠物
- 拖拽任务分配：直观的拖拽操作分配村民到不同岗位，降低操作门槛同时保留策略性。同一村民在不同岗位效率不同
- 文明恢复叙事：从废墟中发现古代科技、重建建筑、解开历史谜题，提供持续的目标感。每个新发现都推进故事

## 为什么好玩

看着自己引导的小村庄从一片荒芜逐渐发展为繁荣的文明，这种'世界在我手中'的创造感很强。
村民结婚生子的温馨时刻也让人有情感连接，你会记住每个村民的名字和故事。

## 粘性来源

实时模拟的自然粘性（'关掉游戏他们还在干活，回来看看进展'）、未探索区域的好奇心、以及村庄发展的长期目标。

## Meta 系统

科技树系统、建筑解锁、村民世代传承、谜题解锁。

## 实现难度

低 — 核心是简单的状态机+定时任务系统。主要技术难点在于村民AI的自主行为合理性和实时模拟的持久化存储。

游戏还包含村民寿命系统：村民会自然衰老并最终去世，需要不断培育新一代村民来维持村庄运转。年长村民的经验和技能需要传承给年轻人，增加了村庄管理的长期规划维度。
