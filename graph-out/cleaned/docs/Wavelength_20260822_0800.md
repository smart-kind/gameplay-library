# Wavelength 波长猜测（Wavelength）

- **类型**: 社交推理 / 派对 / 协作
- **平台**: Mobile (iOS+Android) / PC / Board Game
- **开发商**: Palm Court LLC
- **首次发布**: 2022
- **一句话描述**: 一款社交猜测游戏，玩家需要判断线索在光谱上的位置，并读懂队友的心思

## 玩法规则

Wavelength是一款2-10+人的社交派对游戏。游戏的核心是一个"光谱转盘"，转盘上有两个极端概念作为端点（如"热↔冷"、"软↔硬"、"法师↔不是法师"）。

**回合流程**：
1. **线索阶段**：一名玩家担任"线索 giver"，抽取一张线索卡。卡上有一个秘密标记，指示答案在光谱上的精确位置（只有 giver 能看到）。
2. **给出线索**：Giver 说一个词或短语来提示队友，帮助他们在光谱上定位。例如，光谱是"热↔冷"，秘密答案靠近"热"端，giver 可能说"夏天"。
3. **讨论与定位**：其他玩家讨论线索的含义，然后一起在光谱上选择一个位置。
4. **揭晓结果**：转动转盘揭示秘密标记的真实位置。根据标记与玩家选择位置的距离计分——越接近得分越高。
5. **角色轮换**：每位玩家轮流担任 giver。

**计分规则**：距离标记越近得分越高。如果标记在玩家选择的那一侧，团队得分；如果在另一侧，不得分。

## 核心循环

抽取秘密标记 → 给出线索 → 队友讨论定位 → 揭晓答案 → 计分 → 轮换 giver

## 核心机制

- **语义光谱**：游戏将抽象概念映射到连续的光谱上，如"无聊↔有趣"、"便宜↔贵"。这种设计让讨论变得既主观又有趣——不同的人对同一个词可能有不同的理解。
- **线索约束**：Giver 只能用一个词或短语提示，不能说太多也不能说太少。这种约束创造了策略空间——太精确可能被对手猜到，太模糊队友找不到位置。
- **团队讨论**：队友必须达成共识才能做出选择。讨论过程中的争论和说服本身就是游戏的核心乐趣。
- **无广告免费**：游戏没有广告干扰，专注于纯粹的社交体验。

## 为什么好玩

Wavelength的魅力在于它揭示了"你的想法和朋友的想法有多大差异"。当队友对"夏天"应该放在光谱的什么位置争论不休时，当答案揭晓后大家惊呼"你居然这么想？"时——这些时刻让游戏充满欢笑。

## 粘性来源

- **社交惊喜**：发现朋友对事物的看法与自己的差异总是有趣的。
- **无限组合**：光谱对的组合几乎是无限的，每局都是全新的讨论话题。
- **适合各种场合**：家庭聚会、朋友聚餐、远程视频都能玩。

## Meta 系统

无核心Meta系统。主要是光谱对的轮换和自定义光谱创建。

## 实现难度

低 — 核心逻辑简单（随机光谱对+转盘+计分）。最大难点在于设计足够多且有趣的光谱对，以及良好的UI动画让转盘效果令人满意。
