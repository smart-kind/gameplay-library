# Picnic Wars

- **类型**: 塔防 / 即时战略 / 策略
- **平台**: Mobile (iOS + Android)
- **开发商**: Babil Games
- **首次发布**: 2012
- **一句话描述**: 指挥蚂蚁军队，在野餐场景中与敌方蚂蚁军团对战，争夺食物资源。

## 玩法规则

游戏采用俯视角画面，战场被分为左右两半——己方基地在左，敌方基地在右。中间是一条或多条路径连接双方基地，沿途散布着食物资源点。

操作方式：
- **生成蚂蚁**：点击己方基地消耗食物资源生成不同类型的蚂蚁士兵。
- **蚂蚁自动前进**：生成的蚂蚁自动沿路径向敌方基地前进，途中遇到敌方蚂蚁会自动交战。
- **特殊技能**：部分蚂蚁类型有主动技能（如加速、范围攻击），点击可以释放。
- **资源管理**：食物资源随时间缓慢积累，也可以派遣工蚁去采集场上的食物点来加速积累。

兵种类型包括：
- **工蚁**：负责采集食物资源，不参战。
- **步兵蚁**：基础战斗单位，成本低。
- **重装蚁**：高血量，移动慢，适合正面推进。
- **飞行蚁**：速度快，可以越过某些障碍。
- **特殊蚁**：具有特殊能力（爆炸、治疗等）。

游戏目标：指挥己方蚂蚁攻破敌方基地。如果己方基地被攻破则失败。

## 核心循环

采集资源 → 生成蚂蚁 → 推进战线 → 攻破敌方基地 → 解锁新关卡和兵种

## 核心机制

- **资源管理**：食物是核心资源，需要在"采集更多食物"和"生成更多蚂蚁"之间做权衡。过度采集可能错失战机，过度出兵可能被敌方反推。
- **兵种克制**：不同蚂蚁类型有相互克制的关系，需要根据敌方阵容调整己方出兵策略。
- **路线选择**：多条路径的设计允许玩家选择主攻方向，可以分散进攻或集中突破。
- **波次推进**：后续关卡中敌方兵力和兵种更加多样，需要更精细的资源管理和兵种搭配。

## 为什么好玩

Picnic Wars 将传统的塔防/即时战略简化为手机平台友好的操作——你不需要精确控制每个单位，只需做出宏观决策（出什么兵、什么时候出、走哪条路）。蚂蚁主题让战争场面变得轻松有趣。看着两军蚂蚁在野餐布上大战，有一种"微观世界史诗"的幽默感。

## 粘性来源

- **策略深度**：看似简单的出兵决策背后有资源管理和兵种克制的策略深度。
- **关卡多样性**：不同关卡的地图布局、资源点分布和敌方配置各不相同。
- **解锁新兵种**：随着进度解锁更多蚂蚁类型，增加策略选择。

## Meta 系统

- **关卡解锁**：通关后解锁新关卡和新地图。
- **兵种解锁**：随着进度解锁新的蚂蚁类型。
- **星级评价**：每关根据表现获得1-3星评价，驱动完美通关挑战。

## 实现难度

**中** — 需要实现AI路径寻路、战斗判定和资源管理三套系统。最大技术难点在于同屏大量单位的性能优化和AI行为设计。
