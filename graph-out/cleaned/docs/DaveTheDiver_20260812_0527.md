# 潜水员戴夫（Dave the Diver）

- **类型**: 冒险/经营
- **平台**: Mobile (iOS+Android)
- **开发商**: MINTROCKET（Nexon）
- **首次发布**: 2026（手机版）
- **一句话描述**: 白天潜水捕鱼、晚上经营寿司店的冒险经营游戏，从 PC/Switch 移植到手机。

## 玩法规则

游戏分为两个核心部分：白天潜水探索海洋和晚上经营寿司店。潜水部分，玩家控制戴夫潜入逐渐加深的海洋区域，用鱼叉捕捉各种鱼类和海洋生物，同时探索海底洞穴和沉船。

晚上部分，玩家利用白天捕获的鱼类经营寿司店，雇佣员工、升级设施、调整菜单吸引顾客。寿司店的利润可以用于购买更好的潜水装备，潜入更深的海域。

## 核心循环

白天潜水捕鱼 → 晚上经营寿司店 → 赚取利润 → 购买更好的装备 → 潜入更深的海域 → 发现更多鱼类和秘密

## 核心机制

- 潜水探索：逐渐加深的海域，不同深度有不同鱼类和危险
- 寿司店经营：菜单管理、员工雇佣、设施升级
- 装备升级：氧气量、鱼叉威力、潜水速度等属性的逐步提升

## 海洋生态与季节变化

海洋中的鱼类种类丰富，从普通的沙丁鱼到稀有的深海生物。不同天气和时间影响鱼类分布，增加了探索的变数。

游戏包含季节系统，不同季节有不同的鱼类出现和特殊的季节性事件。这为重复游玩提供了新的体验。

## 为什么好玩

潜水探索和寿司店经营两个循环互相促进，形成'越潜越有钱，越有钱潜越深'的正反馈。轻松幽默的氛围和丰富多样的海洋生物。

## 粘性来源

装备升级驱动的深度探索、鱼类图鉴收集、寿司店经营策略的持续优化。

## Meta 系统

2026年8月移植到手机平台

## 实现难度

低-中等 — 轻松节奏，但深潜区域有一定挑战
