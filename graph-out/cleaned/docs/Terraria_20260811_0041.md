# Terraria

- **类型**: 沙盒冒险
- **平台**: Mobile (iOS+Android) / PC / Switch / PlayStation / Xbox
- **开发商**: Re-Logic
- **首次发布**: 2011
- **一句话描述**: 2D 像素风格的沙盒冒险游戏，融合了探索、建造、战斗和 crafting 系统。

## 玩法规则

玩家在一个随机生成的 2D 世界中醒来，手持初始工具（铜斧和铜短剑）。世界由不同层次的方块构成：地表、地下、洞穴、地狱。

核心操作：
- **挖掘** — 用镐类工具破坏方块，收集资源（木材、矿石、宝石等）
- **建造** — 用收集的材料搭建房屋、工作台、熔炉等建筑
- **战斗** — 用武器对抗各种怪物，包括白天的小型怪物和夜晚/特定事件中的 Boss
- **Crafting** — 在工作台、熔炉、铁砧等制造台前，将原材料合成更高级的工具、武器、盔甲

游戏有明确的进度线：铜/锡 -> 铁/铅 -> 银/钨 -> 金/铂金 -> 恶魔/猩红 -> 地狱 -> 困难模式。击败 Boss 会解锁新材料和新区域。

NPC 系统：当玩家建造符合标准的房屋后，各种 NPC（向导、商人、护士、军火商等）会搬进来，提供服务和商品。

## 核心循环

挖掘资源 -> 制作装备 -> 挑战 Boss -> 解锁新材料 -> 制作更强装备

## 核心机制

- 分层进度系统 — 从基础铜工具到困难模式的终极装备，每一层都有明确的目标和奖励
- 生物群系多样性 — 森林、沙漠、丛林、腐化/猩红、雪原、地狱等，各有独特资源和怪物
- 事件驱动玩法 — Blood Moon、Goblin Army、Pirate Invasion 等随机事件增加不确定性

## 为什么好玩

无限的可能性，你可以当建筑师、探险家、战士或收集家。随机生成的世界意味着每次都是全新体验；与好友联机的合作/竞争乐趣倍增。

## 粘性来源

收集驱动（数百种物品）；Boss 挑战的成就感；建造创意的自我表达；多周目新世界的随机性；持续更新的内容（游戏已更新十几年仍在出新内容）。

## Meta 系统

角色和世界的持久化，角色保留装备和物品，世界保留所有建筑。成就系统追踪进度。NPC 入住提供功能性奖励（治疗、弹药、药水等）。

## 实现难度

高 — 系统极其庞大（数百种物品、几十个 Boss、多种生物群系），新玩家需要大量时间理解。最大技术难点在于在移动端实现如此丰富的系统并保持操作流畅。
