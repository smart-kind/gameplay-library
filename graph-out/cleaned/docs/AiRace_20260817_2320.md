# AI竞速（AiRace）

- **类型**: 竞速
- **平台**: Mobile (iOS+Android)
- **开发商**: QubicGames
- **首次发布**: 2009
- **一句话描述**: 未来风格的街机竞速游戏，以简洁的几何赛道设计和高速驾驶体验为特色。

## 玩法规则

游戏画面是第三人称追尾视角或驾驶舱第一人称视角，赛道由简洁的几何图形构成，充满未来科技感。屏幕显示速度、圈数和当前位置。
操控方式：倾斜设备或虚拟按键控制车辆左右转向，自动加速或手动加速按钮。车辆有加速、刹车和氮气加速三个基本操作。
赛道设计以高架道路、隧道和环形赛道为主，路面光滑且反光效果突出。赛道旁有护栏，撞到会减速但不会停下。
比赛中需要完成规定圈数到达终点。每场比赛有3-5名AI对手。赛道上有加速带（驶过时自动加速）和危险区域（弯道外侧）。
游戏有多个杯赛（Championship），每个杯赛包含多场比赛。根据每场比赛的排名获得积分，总积分决定杯赛名次。
时间挑战赛模式中，玩家需要在限定时间内完成赛道，不断刷新个人最佳纪录。

## 核心循环

选择赛道和比赛 → 竞速驾驶（加速/转弯/氮气） → 完成比赛获得排名积分 → 推进到下一场比赛 → 争夺杯赛冠军

## 核心机制

- 赛道几何设计：未来风格的几何赛道（螺旋、高架、隧道）提供视觉新鲜感和不同的操控挑战
- 加速带系统：赛道上散布加速带，合理利用可以节省时间和超越对手
- 积分杯赛制：多场比赛的累计积分决定最终排名，单场失利可以通过后续比赛弥补

## 为什么好玩

未来感的赛道设计和高速行驶的视觉冲击结合得很好。
在几何赛道上高速漂移过弯的那种流畅感，以及不断刷新圈速纪录的成就感。

## 粘性来源

杯赛制的多场累积（'这场输了下场赢回来'）、时间挑战的自我突破、以及解锁新车/赛道的目标感。

## Meta 系统

解锁新车辆、新赛道、杯赛奖杯收藏。

## 实现难度

中 — 需要实现3D赛道渲染、车辆物理模拟、AI对手。主要技术难点在于几何赛道的碰撞检测精度和性能优化。

游戏还包含时间挑战模式：在限定时间内完成赛道并尽可能刷新个人最佳纪录。每个赛道的纪录可以单独查看和对比。此外游戏还设置了每日挑战，每天更新一个特殊赛道条件。
