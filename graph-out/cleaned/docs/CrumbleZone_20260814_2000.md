# Crumble Zone (粉碎地带)

- **类型**: 物理弹射 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2013
- **一句话描述**: 弹射小球摧毁建筑结构的物理弹射解谜游戏

## 玩法规则

游戏场景中有一个由方块构成的建筑结构。玩家通过拖拽屏幕上的弹射器来瞄准和发射小球，目标是击毁结构中的所有方块。

玩家从屏幕边缘的弹射点拖拽设定发射角度和力度，松开后小球沿抛物线飞行。小球撞击方块后产生物理碰撞效果，方块会根据撞击力和结构稳定性发生坍塌。

每个关卡有方块数量限制，需要在限定球数内摧毁所有方块。不同类型的方块有不同的硬度和重量，有些需要多次撞击才能击碎。

游戏目标是用最少的球数完成关卡，三星评价系统鼓励玩家优化弹射策略。

## 核心循环

观察结构 → 瞄准弹射 → 观察坍塌效果 → 调整角度 → 继续弹射

## 核心机制

- **物理弹射系统**：真实的物理引擎模拟小球碰撞和结构坍塌，每次弹射产生连锁反应
- **结构弱点识别**：玩家需要找到建筑的关键支撑点，一击造成最大破坏
- **角度力度控制**：拖拽力度决定发射初速度，角度决定弹道，两者组合创造丰富策略
- **关卡递增难度**：后期加入移动平台、爆炸物等元素增加复杂性

## 为什么好玩

物理碰撞的不可预测性和连锁反应带来的爽快感让玩家欲罢不能。每次成功找到关键支撑点一击摧毁的满足感极强。

## 粘性来源

物理碰撞的随机乐趣 + "差一球过关"的不服输 + 关卡递进的新鲜感 + 三星评价的挑战欲

## Meta 系统

关卡解锁系统 — 完成当前关卡解锁下一阶段

## 实现难度

中 — 需要物理引擎支持，最大技术难点在于物理模拟的性能优化和碰撞精度的平衡
