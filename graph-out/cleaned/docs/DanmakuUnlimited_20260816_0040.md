# 弹幕无限（Danmaku Unlimited）

- **类型**: 弹幕射击 / 街机
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Destructive Creations
- **首次发布**: ~2012
- **一句话描述**: 一款竖版弹幕射击游戏，在密集的弹雨中闪转腾挪，考验玩家的微操和路线规划能力

## 玩法规则

游戏采用竖屏视角，玩家控制的战机位于屏幕下方，需要从下方向上穿越敌方阵地。屏幕上布满了敌方发射的各种弹幕——直线弹、曲线弹、环形弹、螺旋弹等不同轨迹的子弹形成了密集的弹幕墙。

玩家通过触摸屏幕控制战机移动——触摸位置即为目标位置，战机会快速移动到触摸点。移动范围限定在屏幕下半部分（射击区域）。战机自动射击，玩家不需要手动开火，只需要专注于躲避弹幕和收集道具。

每关卡由多波敌人组成，最终有 Boss 战。Boss 有复杂的弹幕模式，通常会在几种攻击模式之间切换。击败 Boss 后进入下一关卡，弹幕密度和复杂度递增。

游戏中散布着道具——升级武器、增加火力、恢复生命等。玩家需要在躲避弹幕的同时尽量收集道具来增强战斗力。

## 核心循环

穿越弹幕 → 收集道具升级 → 击败 Boss → 进入下一关 → 弹幕密度递增

## 核心机制

- **纯躲避为核心**：战机自动射击，玩家的全部注意力都放在躲避弹幕上，这种设计让弹幕射击回归了最纯粹的体验——在弹雨中找到安全路径
- **弹幕模式识别**：每种敌人的弹幕有固定模式，熟练后可以在密集的弹幕中找到安全区域。从"满屏都是子弹无处可躲"到"我知道哪里安全"是游戏的核心成长体验
- **Boss 阶段切换**：Boss 有多种攻击模式，会在不同阶段切换。有些阶段弹幕密集但规律，有些阶段弹幕稀疏但难以预测
- **擦弹系统**（可能）：在子弹附近擦过可以获得额外分数，鼓励玩家在危险边缘游走而不是躲在安全角落

## 为什么好玩

Danmaku Unlimited 把传统街机弹幕射击带到了移动平台上，触摸操控比摇杆更精确，让玩家可以在极小的缝隙中穿梭。当你在满屏子弹中找到了唯一的安全路径并成功穿越时，那种"我是弹幕大师"的成就感无与伦比。游戏的难度曲线设计让新手也能体验通关，但高手有无尽的挑战空间。

## 粘性来源

- **弹幕模式的 mastery**：从看不懂到完全掌握每种弹幕模式，这种学习曲线本身就是粘性来源
- **分数驱动**：擦弹系统和高难度通关的分数排名驱动硬核玩家反复挑战
- **"我差点就过了"效应**：Boss 战往往差一点就能击败，这种不甘心让人想立刻再来一次
- **弹幕的美学**：精心设计的弹幕图案本身就有一种几何美感，欣赏弹幕的排列也是一种乐趣

## Meta 系统

轻度。可能包含战机解锁和武器升级系统，但核心体验在于每局独立的弹幕挑战。

## 实现难度

中。弹幕射击需要处理大量子弹的运动轨迹计算、碰撞检测和渲染优化。最大技术难点在于在移动设备上保持高帧率的同时渲染数百颗子弹，以及确保碰撞检测的精确性（弹幕射击的 Hitbox 通常比精灵小得多，需要精确的判定区域）。
