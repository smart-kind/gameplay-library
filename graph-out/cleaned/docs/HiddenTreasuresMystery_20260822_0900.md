# The Hidden Treasures・Mystery (The Hidden Treasures・Mystery)

- **类型**: 隐藏物品寻物 / 三消解谜 / 冒险叙事
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: G5 Entertainment AB
- **首次发布**: 2019
- **一句话描述**: 在加勒比海的神秘背景中，通过寻找隐藏物品或消除宝石来揭开家族谜团的冒险解谜游戏

## 玩法规则

游戏以加勒比海为背景，呈现精美的手绘场景。每个关卡是一幅充满细节的静态画面，其中隐藏着若干需要寻找的物品。同时在画面之外，玩家可以选择通过三消宝石来推进剧情。

操作方式有两种：（1）在隐藏物品模式中，玩家浏览画面中密密麻麻的物品，根据底部的物品清单找到对应的物品并点击。物品可能部分被遮挡、伪装或缩小，需要仔细观察。（2）在三消模式中，玩家交换相邻宝石形成三个或更多相同宝石的连线，宝石消除后获得分数或推进道具。

玩家可以选择任意一种模式推进，或者随时在两种模式间切换。勇敢的女船长艾米（Aimee）、一只名叫维吉尔（Virgil）的鸟，以及一群性格各异的角色组成船队，在加勒比群岛间航行，解开艾米家族的谜团。

游戏目标：通过完成每个关卡的寻物或三消任务，推进主线剧情，最终揭开家族谜团的真相。

## 核心循环

寻找物品/消除宝石 → 获得线索和道具 → 推进剧情 → 解锁新场景 → 发现更多谜团

## 核心机制

- **双模式切换机制**：玩家可自由选择隐藏物品或三消两种玩法，满足不同偏好和心情，降低了单一玩法的疲劳感
- **叙事驱动推进**：寻物和三消不仅是独立小游戏，它们直接服务于故事推进——每次完成任务都会解锁新的剧情片段
- **伪装与隐藏层级**：物品不是简单摆放，而是通过部分遮挡、缩小、融入背景等方式增加寻找难度
- **角色互动系统**：旅途中遇到的NPC提供线索、道具和支线任务，增加世界感

## 为什么好玩

将寻物解谜与冒险叙事完美结合——你不是在"找东西"，而是在"破案"。加勒比海盗风的角色设定和剧情转折让整个寻物过程有了意义和动力。双模式切换让大脑在专注寻找和策略消除间交替休息。

## 粘性来源

叙事悬念是核心粘性——"艾米的家族到底隐藏着什么秘密"驱动玩家持续游玩。每个场景的美术设计本身就值得探索，而"差一个就找到所有物品"的强迫症式收集欲提供即时粘性。三消模式的随机性保证每次体验不同。

## Meta 系统

- **剧情收集系统**：玩家收集线索碎片、日记、信件等叙事道具，逐步拼凑完整故事
- **角色好感度**：与NPC互动获得不同对话和支线，影响剧情走向
- **道具收集**：游戏中收集的各种道具可在后续关卡中使用，提供提示或跳过功能

## 实现难度

中。寻物模式的核心是2D静态画面+物品坐标检测，技术不难。但大量精美的手绘场景美术工作量极大，且需要为每个场景设计合理的物品布局（既不能太容易也不能太刁钻）。三消引擎和叙事系统的集成也增加复杂度。
