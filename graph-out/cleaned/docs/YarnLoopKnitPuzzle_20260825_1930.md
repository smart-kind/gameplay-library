# Yarn Loop: Knit Puzzle

- **类型**: 益智解谜 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: Combo Games
- **首次发布**: 2025
- **一句话描述**: Yarn Loop is a relaxing and satisfying puzzle game featuring colorful yarn bobbins and knitted patterns.

## 玩法规则

（基于App Store描述整理）

Yarn Loop is a relaxing and satisfying puzzle game featuring colorful yarn bobbins and knitted patterns.

Bobbins move onto the conveyor and collect stitches of their own color. Each bobbin has a capacity value that decreases as stitches are picked up. When its capacity reaches zero, the bobbin disappears. If capacity remains, the bobbin is transferred to the rack and can be used again later.

Complete each knitted pattern by using the right bobbins in the right order. Game Features ► Simple One-Tap Gameplay: Bobbins move smoothly through the conveyor system and collect matching stitches with ease.

► Color-Based Collection Mechanic: Each bobbin clears only the stitches of its own color. ► Capacity Management System: Every bobbin has a limited pickup value, creating thoughtful and satisfying puzzle decisions. ► Rack Reuse Function: Bobbins that still have capacity return to the rack and remain available for later use. ► Hundreds of Engaging Levels: New knitted layouts, color combinations, and puzzle arrangements appear throughout progression. ► Cozy Yarn Aesthetic: Soft textures, warm colors, and pleasant animations create a calm and enjoyable experience. Yarn Loop offers a smooth, calm, and visually charming journey through handcrafted yarn puzzles.

## 核心循环

匹配相同方块 → 消除获得分数 → 清理棋盘 → 进入下一关

## 核心机制

- **容量管理机制**：每个收集容器有固定容量值，收集同色物品时容量递减，归零时容器消失，未归零的容器可放回架子复用，需要精确计算收集顺序。

## 为什么好玩

游戏以轻松解压为核心体验，没有计时器的催促，玩家可以在安静的氛围中专注于解谜本身。每次成功消除的视觉反馈和音效设计带来即时的满足感，适合在工作间隙或睡前放松。

## 粘性来源

精心设计的关卡难度曲线让每次过关都有成就感，"再来一局"的心理来自于"差一点就完美通过"的不甘心。多样化的关卡布局和视觉主题保持了长期的新鲜感。

## Meta 系统

无。游戏以纯粹的关卡推进为核心，没有外围成长系统。
## 实现难度

中等。核心逻辑（拖拽放置/消除）实现不复杂，但高质量的手工关卡设计需要大量时间和创意，关卡编辑工具是主要工作量。
