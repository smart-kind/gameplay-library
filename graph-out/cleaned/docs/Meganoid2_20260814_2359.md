# Meganoid 2

- **类型**: Roguelike/平台动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Pascal Bestebroer
- **首次发布**: 2012
- **一句话描述**: 一款像素风格的 Roguelike 平台动作游戏

## 玩法规则

玩家控制机器人在随机生成的地牢中探索。每次死亡后重新开始，但地图、敌人和道具都会重新生成。通过虚拟按键控制移动、跳跃和攻击。

地牢中有各种敌人，每种有不同的攻击方式。击败敌人获得金币，可以在商店购买武器和道具。每层地牢末尾有 Boss 战。

画面采用像素风格，角色和环境设计复古。界面左下角为方向键，右下角为攻击和跳跃按钮。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

探索地牢获取装备 → 死亡后重新开始 → 用新装备走得更远

## 核心机制

- 随机地牢生成：每次重新开始的地图都不同
- 永久死亡机制：死亡后失去所有进度，但可解锁新角色
- 装备收集：击败敌人和打开宝箱获得随机装备

## 为什么好玩

Roguelike 的随机性让每次冒险都是全新体验，像素风复古感十足。

## 粘性来源

随机性和"再来一局"的驱动力，角色解锁提供长期目标。

## Meta 系统

- 角色解锁系统：通过成就解锁不同机器人角色
- 成就系统：完成特定挑战获得永久加成

## 实现难度

中等 — 随机地图生成和敌人 AI 需要精细设计，最大的技术难点是地图生成的可玩性和难度平衡。
