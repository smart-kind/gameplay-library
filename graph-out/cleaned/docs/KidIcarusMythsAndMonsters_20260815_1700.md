# Kid Icarus: Of Myths and Monsters

- **类型**: 动作平台 / 横版闯关
- **平台**: Game Boy / 3DS Virtual Console
- **开发商**: Nintendo
- **首次发布**: 1991
- **一句话描述**: 一款1991年发售的Game Boy动作平台游戏，是Kid Icarus的续作，玩家操控天使战士皮特在二维关卡中收集物品、战斗怪物，最终击败恶魔奥科斯。

## 玩法规则

游戏画面为横版2D卷轴视角。玩家操控天使战士皮特在希腊神话风格的关卡中冒险。皮特可以在地面行走和跳跃，也可以短暂飞行（受限于飞行槽能量）。

关卡中分布着多种道具：心形道具增加生命值上限、箭矢增加远程攻击数量、药壶可以恢复生命、魔法物品赋予临时能力（如反射盾、护甲等）。玩家需要探索关卡，收集钥匙和特殊物品来解锁新区域。

战斗系统包含近战和远程攻击。远程攻击发射箭矢，近战通过短距离攻击对付小型敌人。敌人类型多样，包括飞行怪物、地面守卫和Boss。Boss战需要找到其弱点并利用特定道具才能击败。

每关的目标是收集特定数量的圣物或到达关卡终点，最终击败关底Boss。三个圣物集齐后可进入最终关卡对抗恶魔奥科斯。

游戏设有迷宫式的大型关卡，包含隐藏房间和秘密通道，鼓励探索。

## 核心循环

探索关卡 → 收集道具和圣物 → 战斗敌人和Boss → 解锁新区域 → 进入下一关

## 核心机制

- 有限飞行系统：皮特可以飞行但能量有限，飞行槽耗尽后坠落。这既是移动方式也是解谜工具——玩家需要在飞行能量和地面行动之间做出选择，增加策略深度。
- 道具收集与永久成长：收集的心形增加永久生命上限，药壶恢复当前生命。这种'收集即成长'的机制让玩家在探索中获得持续的成就感，同时鼓励100%探索。
- 迷宫式关卡设计：每个关卡都是非线性的迷宫，包含隐藏房间、秘密通道和可选区域。这种设计在Game Boy时代非常超前，赋予游戏RPG般的探索感。

## 为什么好玩

在Game Boy的小屏幕上呈现一个充满秘密和隐藏的希腊神话世界，探索感极强。每次发现隐藏房间或拿到关键道具都很有成就感。飞行系统让移动本身变得有趣而不仅仅是到达目的地的手段。

## 粘性来源

迷宫式关卡设计中的'探索未完成感'是主要粘性来源——玩家总觉得还有秘密没发现、还有道具没收集。三个圣物的收集目标提供了明确的中期驱动力，最终Boss战则是终极目标。

## Meta 系统

无外围系统。游戏内的心形道具提供永久生命上限成长，这是唯一的成长机制，内嵌于关卡探索中。

## 实现难度

低。最大技术难点在于非线性的迷宫关卡设计和碰撞检测——在Game Boy的硬件限制下实现流畅的平台跳跃和飞行控制。
