# 茧（Cocoon）

- **类型**: 解谜 / 冒险
- **平台**: PC / Switch / PlayStation / Xbox
- **开发商**: Geometric Interactive（Jump Force Studios）
- **首次发布**: 2023
- **一句话描述**: 在一个可以背起整个世界的神秘生物身上解谜，每个世界都藏在一个球体中

## 玩法规则

玩家控制一只外星生物，它背上可以"驮"一个发光的球体——每个球体实际上是一个完整的微型世界。你可以跳进球体进入那个世界，在那个世界中解谜、探索，然后带着球体回到外层世界。

每个世界都有自己的生态系统和谜题。球体可以被放置、搬运、从一个位置移到另一个位置。有些球体内部有机关，需要在外层世界操作才能激活；反过来，有些外层世界的机关需要把球体放到特定位置才能触发。

游戏的核心创新在于"世界套世界"的嵌套结构。你背着的球体里有一个世界，那个世界里又有一个更小的球体，跳进去又是另一个世界……最多可以嵌套3-4层。

没有战斗，没有文字叙事，没有计时器。纯粹的探索+解谜。通过激活5个世界传送门来通关。

## 核心循环

进入球体世界 → 解谜+搬运球体 → 激活机关/开启传送门 → 带着球体返回外层 → 进入下一个世界

## 核心机制

- **世界嵌套机制**：这是Cocoon最革命性的设计。每个球体都是一个完整的世界，你可以跳进去探索，也可以把它搬运到外层世界的特定位置。这意味着同一个谜题可能需要在不同层级之间反复切换才能解决。
- **球体搬运系统**：球体可以被举起、放下、滚动、放置。在不同世界中，球体的物理属性可能不同（重力方向、浮力、电磁力等），这增加了谜题的维度。
- **跨层交互**：某些机关的效果会跨越世界层级——你在外层世界激活的开关可能影响内层世界的某个元素，反之亦然。这种跨层因果关系是谜题设计的核心。
- **渐进式复杂度**：游戏从简单的"搬运一个球体到指定位置"开始，逐步引入多层嵌套、多球体交互、跨层因果等复杂机制，但每次只引入一个新元素。

## 为什么好玩

Cocoon 的设计天才之处在于，它用一个简单规则（球体=世界）衍生出了极其丰富的谜题可能性。当你第一次意识到自己可以"背着一个世界进入另一个世界"时，那种顿悟感是无与伦比的。每个新机制的引入都经过精心设计，让玩家在"我懂了"和"等等，这还能这样用？"之间反复惊喜。

## 粘性来源

"好奇心驱动"——每个新世界都是未知的，你不知道里面会有什么机制。嵌套结构让解谜有了深度，一个看似简单的谜题可能需要你进入世界内的世界才能找到答案。通关后重玩时，你对规则的理解更深，可以用不同方式解决谜题。

## Meta 系统

无传统Meta系统。进度体现在已激活的传送门数量和已探索的世界数量上。无收集品、无数值成长。

## 实现难度

高 — 最大的技术挑战是世界嵌套渲染（一个世界中渲染另一个世界的完整场景，且可以无限递归进入）。需要处理多层世界的物理模拟、相机切换、状态同步。球体的搬运和放置需要精确的碰撞检测和物理反馈。

游戏获得多个年度最佳独立游戏提名，被视为叙事解谜游戏的标杆之作。
