# Sunless Sea

- **类型**: 探索 RPG / 叙事
- **平台**: PC
- **开发商**: Failbetter Games
- **首次发布**: 2014
- **一句话描述**: 在黑暗的地下海洋中航行、探索和发现秘密的最佳独立探索 RPG。

## 玩法规则

玩家在黑暗的地下海洋"Unterzee"中航行一艘蒸汽船。游戏以探索和叙事为核心——探索未知岛屿、与奇怪的角色交易、发现隐藏的秘密。

游戏采用文字驱动的体验——大部分叙事通过精美的文字描述呈现，玩家的选择影响故事走向和资源管理。玩家需要管理燃料、补给、船员的理智，在探索和生存之间平衡。

永久死亡机制意味着角色和船只最终会沉没，但每次航行获得的知识可以用于下一次——解锁新区域、新故事和新可能性。

## 核心循环

航行探索 → 发现岛屿 → 交易和叙事 → 管理资源 → 继续或死亡

## 核心机制

- 地下海洋探索：在黑暗海洋中航行发现未知
- 文字驱动叙事：精美的文字描述和选择
- 资源管理：燃料、补给、船员理智的平衡
- 永久死亡：角色死亡但知识保留
- 多结局：不同选择导向不同结局

## 为什么好玩

文学级的叙事配合神秘的地下海洋探索。每次航行的未知感和发现的秘密让人沉浸其中。

## 粘性来源

- 未知的吸引力：每次航向未知海域的好奇心
- 叙事深度：文学级的文字和故事
- 资源管理的紧张感：在探索欲望和生存需求之间挣扎
- 知识即进度：死亡不是终点，而是新航行的开始

## Meta 系统

知识解锁。通过多次航行发现新区域、故事和秘密，解锁更多内容。

## 实现难度

中。核心难点在于叙事内容的创作（数十万文字）和资源管理系统的平衡。
