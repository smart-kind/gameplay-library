# 9小时9人9门（9 Hours, 9 Persons, 9 Doors）

- **类型**: 视觉小说解谜 / 逃脱
- **平台**: Mobile (iOS) / Nintendo DS
- **开发商**: Chunsoft
- **首次发布**: 2009
- **一句话描述**: 九名被绑架者被困在一艘沉船上，必须通过解谜和逃脱游戏在9小时内找出真相

## 玩法规则

游戏采用双视角叙事结构，玩家在"现实逃脱"和"视觉小说"两个模式间切换。

逃脱模式下，玩家被困在密闭房间中，需要调查场景中的物品、收集线索、解开各种类型的谜题（密码锁、数字谜题、逻辑推理、机关操作等）。每个房间都有倒计时压力，限时内无法逃脱会导致游戏结束。

视觉小说模式下，玩家以第一人称视角体验剧情，通过对话选择推进故事。不同选择导致不同的剧情分支（6条结局路线），需要多次通关才能拼凑出完整的真相。

核心谜题类型包括：数字根谜题（digital root）、迷宫逃脱、密码破解、物品组合和场景调查。

## 核心循环

调查房间收集线索 → 解开谜题逃脱 → 阅读剧情获得信息 → 进入新房间 → 发现更大阴谋

## 核心机制

- **逃脱游戏（Escape the Room）**：经典密室逃脱玩法，调查场景中每个角落找线索，组合道具，解开各类机关。限时压力增加紧张感
- **数字根谜题（Digital Root）**：核心谜题机制，玩家通过数学运算破解密码，是贯穿整个游戏的关键谜题形式
- **多路线叙事（Branching Story）**：6条不同结局路线，每条路线揭示故事的不同侧面。需要全部通关才能理解完整真相
- **AMB游戏（Nonary Game）**：9人参与者手腕被植入数字手表和炸弹，必须在9小时内破解秘密——这是推动整个游戏的核心设定

## 为什么好玩

将密室逃脱的紧张感和科幻悬疑故事完美结合，每次逃脱都推动剧情发展，解谜不再是孤立的小游戏而是故事的一部分。多重结局设计让通关多次也有新鲜感。

## 粘性来源

具体到机制层面：1）"差一点就明白真相"的悬念驱动玩家继续通关不同路线；2）密室逃脱的限时压力制造紧张感；3）数字根谜题的数学美感让人有解开后的成就感；4）多条结局线之间的信息互补让重复游玩有意义。

## Meta 系统

无。游戏为一次性叙事体验，无外围成长系统。

## 实现难度

中高。最大的技术难点是多路线叙事的分支管理和谜题设计的合理性——每个谜题必须与故事逻辑自洽，且多条路线的剧情需要精心编排避免矛盾。逃脱场景的交互设计也需要大量手工打磨。
