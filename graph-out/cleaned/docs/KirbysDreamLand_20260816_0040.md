# 星之卡比：梦之泉（Kirby's Dream Land）

- **类型**: 平台跳跃 / 休闲
- **平台**: Game Boy (GB)
- **开发商**: HAL Laboratory
- **发行商**: Nintendo
- **首次发布**: 1992
- **一句话描述**: 操控粉色圆球卡比在 Dream Land 中冒险，吸入敌人并吐出攻击的经典横版过关游戏

## 玩法规则

游戏画面为横向滚动的 2D 平台场景，玩家控制粉色圆形生物卡比（Kirby），从屏幕左侧向右侧移动。画面中分布着各种平台、敌人、道具和障碍物。

卡比的核心操作包括左右移动、跳跃，以及最重要的"吸入"能力——面对敌人时按住方向键朝向敌人，卡比会张开嘴产生吸力，将面前的敌人或小物件吸入口中。吸入后玩家可以按攻击键将敌人作为星弹吐出，对远处的敌人造成伤害。

每一关卡从起点到终点设有多个敌人和障碍，玩家需要灵活运用跳跃和吸入攻击来清除障碍。关卡中还散布着食物道具（如 Maxim Tomato 恢复全部体力，其他食物恢复部分体力），以及隐藏的收集品。

游戏目标是从关卡起点到达终点，在 Boss 战中击败关卡首领。卡比拥有 6 点生命值（可通过食物恢复），被敌人碰到或碰到尖刺等陷阱会扣血，生命值耗尽则失去一条命。全部生命耗尽则 Game Over。

## 核心循环

闯关前进 → 吸入敌人获得星弹攻击 → 收集食物维持生命值 → 击败 Boss 进入下一关

## 核心机制

- **吸入与吐出**：卡比吸入敌人后可将其作为星弹吐出，星弹有抛物线轨迹，可以打击不在正前方的敌人。这是游戏最标志性的机制，既是攻击手段也是解谜工具（可以吸入场景物件）
- **漂浮飞行**：连续按跳跃键可以让卡比在空中漂浮一段距离，降低了平台跳跃的难度门槛，使得 Game Boy 新手也能顺利游玩
- **隐藏食物收集**：关卡中隐藏的食物道具为玩家提供续航，鼓励玩家探索关卡的每个角落而非直线冲刺
- **Boss 战模式切换**：每个 Boss 有固定的攻击模式和弱点，需要观察模式后找到安全时机反击

## 为什么好玩

作为卡比系列的首作，它以极低的入门门槛吸引了大量休闲玩家——漂浮飞行让跳跃失误的惩罚变得极低。同时吸入敌人吐出攻击的反馈感很强，"噗"的一声吸入再射出星弹的过程有独特的爽快感。对于 1992 年的掌机游戏来说，这种简单易上手的平台跳跃体验非常难得。

## 粘性来源

- **短关卡 + 低难度**：每关只需几分钟，随时可以玩一局，死亡惩罚低（6点血量+漂浮能力）
- **收集驱动**：隐藏食物和道具激励玩家重复探索已通过的关卡
- **"差一点"的 Boss 战**：Boss 攻击模式固定但节奏紧凑，玩家容易在失败后立即产生"再来一次"的冲动

## Meta 系统

无。作为 1992 年的掌机游戏，没有外围成长系统，通关即结束。

## 实现难度

低。2D 横版平台跳跃是游戏开发中最基础的类型之一，物理引擎简单（移动+跳跃+漂浮），敌人 AI 为简单的巡逻模式。最大技术难点在于关卡节奏的设计和 Boss 战的模式编排，而非技术实现。
