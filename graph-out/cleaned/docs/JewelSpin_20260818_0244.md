# Jewel Spin（Jewel Spin）

- **类型**: 三消/解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: IVYMOBILE
- **首次发布**: 2010
- **一句话描述**: 以海盗珠宝探险为主题的三消益智游戏

## 玩法规则

游戏采用经典三消网格布局。画面展示一个充满珠宝的探险场景，玩家在网格中交换珠宝进行消除。

**操作方式**：
- 点击选中一颗珠宝
- 再次点击相邻珠宝进行交换
- 三个或以上相同珠宝连成一线即可消除
- 滑动也可以交换相邻珠宝

**核心玩法**：
- 在网格中交换相邻珠宝，使三个或以上相同珠宝连成一线
- 消除珠宝后获得分数和金币
- 消除的珠宝会掉落新珠宝填补空位
- 完成关卡目标（如消除特定数量珠宝、达到目标分数）
- 通过冒险模式推进故事情节
- 收集珠宝碎片解锁新关卡

**胜利/结束条件**：
- 关卡成功：完成关卡目标（分数/消除数量/时间限制）
- 关卡失败：用完所有步数或时间耗尽

## 核心循环

交换珠宝 → 消除匹配 → 获得分数 → 完成关卡目标 → 推进冒险模式

## 核心机制

- **三消核心**：经典三消玩法，交换相邻珠宝形成三连线
- **连锁反应**：消除后新珠宝掉落可能引发连锁消除
- **关卡目标**：每个关卡有特定目标（分数、数量、时间）
- **海盗探险主题**：珠宝收集与海盗探险故事相结合
- **冒险模式**：通过关卡推进故事情节

## 为什么好玩

将三消与海盗珠宝探险主题结合，让传统的三消玩法有了新的叙事包装。虽然核心是经典的三消机制，但海盗主题和冒险模式给玩家提供了持续推进的动力。

## 粘性来源

- **关卡推进**：完成当前关卡解锁后续内容的欲望
- **分数挑战**：追求更高分数的成就感
- **连锁反应**：消除后引发连锁的爽快感
- **收集要素**：收集珠宝碎片解锁新内容

## Meta 系统

- **冒险模式**：通过关卡推进故事情节
- **关卡解锁**：完成当前关卡解锁新关卡

## 实现难度

低 — 三消游戏核心算法成熟，主要技术难点在于关卡难度曲线设计和连锁消除的动画效果。
