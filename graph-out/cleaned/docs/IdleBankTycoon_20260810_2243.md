# 放置类银行经营模拟游戏（Idle Bank Tycoon）

- **类型**: 放置
- **平台**: Mobile (iOS+Android)
- **开发商**: Kolibri Games
- **首次发布**: 2019
- **一句话描述**: 放置类银行经营模拟游戏

## 玩法规则

玩家经营一家银行，雇佣柜员处理客户业务、升级设施提高效率。柜员自动服务客户获得收入，玩家用收入开设新分行、雇佣更多员工、升级设备。游戏是纯放置机制，离线也能获得收入。

## 核心循环

雇佣柜员 → 自动服务客户获得收入 → 升级/开设新分行 → 雇佣更多员工 → 更高收入

## 核心机制

- 自动产出：柜员自动工作产生收入
- 多分行系统：在不同城市开设分行
- 升级系统：提升柜员效率、设备容量
- 离线收益：离线期间继续获得收入

## 为什么好玩

看着银行账户数字不断增长的满足感。放置机制让游戏节奏轻松。

## 粘性来源

数值成长驱动；多分行解锁；离线收益让每次打开都有惊喜。

## Meta 系统

分行解锁+员工升级系统。

## 实现难度

低。纯放置游戏，操作极少。最大技术难点：数值平衡和离线收益计算。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
