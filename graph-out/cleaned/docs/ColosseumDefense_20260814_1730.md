# 竞技场塔防（ColosseumDefense）

- **类型**: 塔防
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer 收录独立游戏
- **首次发布**: 2013
- **一句话描述**: 以古罗马竞技场为背景的经典塔防游戏，在圆形竞技场中抵御一波波敌军进攻

## 玩法规则

游戏采用俯视角的圆形竞技场地图，敌人从竞技场外围的入口进入，沿固定路径向中心目标推进。玩家需要在路径两侧或特定位置放置防御塔来消灭敌人。

游戏提供多种防御塔类型，每种有不同的攻击方式和特性：
- 弓箭塔：射速快、伤害低、射程远，适合持续输出
- 投石塔：伤害高、射速慢、范围伤害，适合对付密集敌人
- 法师塔：特殊效果（减速、灼烧等），辅助输出
- 近战塔：在近距离阻挡并攻击敌人，适合 choke point

每消灭一个敌人获得金币奖励，金币用于建造新塔或升级已有塔。升级可以显著提升塔的攻击力、射程或攻击速度。不同类型的塔升级路线可能不同。

敌人分波次进攻，每波敌人的数量、种类和强度逐步增加。后期会出现特殊敌人，如高血量Boss、快速移动单位、抗性单位等，需要针对性的防御策略。

游戏提供多种关卡，每个关卡的地图布局、敌人类型和特殊机制都不同。部分关卡有特殊地形或机关可以利用。

## 核心循环

观察敌人路径 → 建造和布置防御塔 → 抵御敌人进攻波次 → 获得金币 → 升级或建造新塔 → 应对更强的敌人

## 核心机制

- **多种防御塔选择：弓箭、投石、法师、近战等不同类型，每种有独特的攻击方式和适用场景，需要玩家根据敌人类型和地图布局进行搭配**
- **升级系统：每座塔可以升级多个等级，显著提升属性。合理的升级投资是通关的关键策略之一**
- **波次进攻系统：敌人分波次进攻，每波之间提供短暂的准备时间。波次难度递增，后期出现特殊敌人增加策略深度**
- **圆形竞技场布局：不同于传统的线性塔防路径，圆形地图允许多方向进攻，需要更全面的防御布局**

## 为什么好玩

经典塔防玩法与古罗马主题的结合，策略性和视觉表现都不错。圆形竞技场的设计让防御布局更加灵活，每种塔的组合都能产生不同的战术效果。

## 粘性来源

塔防游戏固有的策略深度和数值成长，每波成功防守后的成就感。追求完美通关和三星评价的驱动力。

## Meta 系统

关卡解锁系统和塔升级系统，部分版本有成就和挑战模式。

## 实现难度

中，需要平衡资源分配和防御布局。最大技术难点在于AI寻路和多人同时攻击的性能优化。
