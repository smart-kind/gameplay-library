# 龙之焰（Dragon Fire）

- **类型**: 动作 / 跑酷 / 射击
- **平台**: Mobile (iOS+Android)
- **开发商**: 移动平台动作游戏
- **首次发布**: 约 2010 年代
- **一句话描述**: 操控喷火巨龙在关卡中飞行，用火焰消灭敌人并收集宝藏

## 玩法规则

游戏画面呈现横向卷轴或纵向卷轴的场景，玩家控制一只会飞行的龙。屏幕上有虚拟控制区域——拖拽控制飞行方向和高度，点击按钮喷射火焰。

龙自动向前飞行（或玩家控制速度），场景中散布着敌人、障碍物和可收集的金币/宝石。玩家需要控制龙的飞行路径避开障碍物，同时用火焰攻击敌人。

火焰攻击有范围效果——在龙的正面形成一个扇形火焰区域，区域内的敌人受到伤害。连续消灭敌人会获得连击加分。收集金币可以增加火焰威力或延长飞行时间。

某些关卡有 Boss——巨大的怪物或城堡，需要多次火焰攻击才能摧毁。Boss 有特定的攻击模式，需要躲避其投射物同时进行反击。

## 核心循环

控制飞行 → 躲避障碍 → 喷射火焰消灭敌人 → 收集金币 → 升级能力

## 核心机制

- **飞行控制**: 拖拽屏幕控制龙的飞行方向和高度，需要精确控制来避开障碍物
- **火焰攻击**: 点击释放火焰，有冷却时间和范围限制，需要把握时机
- **连击系统**: 连续消灭敌人获得倍率加分，鼓励玩家保持攻击节奏
- **收集系统**: 金币和宝石散落在关卡中，鼓励玩家冒险走危险路线获取
- **Boss 战**: 大型 Boss 需要多次攻击，需要观察攻击模式找到反击窗口

## 为什么好玩

操控巨龙飞行的自由感和火焰喷射的爽快感是核心体验。连击系统的正反馈让玩家追求更高的分数。收集要素和路线选择增加了策略性——是安全地走常规路线还是冒险拿高分？

## 粘性来源

高分排行榜激发竞争欲望——每次都想打破自己的纪录。金币收集用于升级龙的能力（火焰威力、速度、护盾），让玩家有长期目标。Boss 战的挑战性让通关充满成就感。

## Meta 系统

能力升级系统：用收集的金币升级龙的火焰威力、飞行速度、护盾强度。升级后的龙在后续关卡中更有优势，但仍需要技巧来应对更难的挑战。

## 实现难度

中。需要飞行物理、碰撞检测、火焰粒子效果、敌人 AI。最大的技术难点是性能优化——火焰粒子效果和大量敌人同时存在时的帧率稳定性。
