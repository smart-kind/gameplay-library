# Scavenger Hunt－Hidden objects!

- **类型**: 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: ENJOY GAMES
- **首次发布**: 2023
- **一句话描述**: 一款解谜类手机游戏，核心玩法围绕隐藏物品寻找展开

## 玩法规则

玩家在Casual, Puzzle类型的游戏界面中，主要进行隐藏物品寻找的操作。

玩家在精心绘制的场景中寻找清单上的物品，场景细节丰富，物品巧妙隐藏在画面各处。找到所有物品后过关，可使用有限次数的提示功能辅助。每个场景都有独特的艺术风格和主题背景。

游戏的目标是观察场景寻找物品，当所有隐藏物品被找出时即可过关。

每局游戏的画面布局清晰，UI元素分布合理，玩家可以轻松识别可操作区域和当前状态。操作方式以点击和拖拽为主，符合移动端用户的操作习惯。

游戏通过精心设计的视觉效果和音效反馈，让每个操作都有明确的响应。随着关卡推进，游戏逐步引入新的元素和机制，保持新鲜感的同时不会让玩家感到信息过载。

游戏的难度曲线经过精心设计，前期关卡主要帮助玩家熟悉操作和基本规则，随着进度推进逐步引入新的挑战和限制条件。每个关卡都有明确的成功条件和失败条件，让玩家清楚知道自己需要达成什么目标。

游戏界面中的关键信息（如当前进度、剩余资源、可用道具等）始终清晰可见，确保玩家随时掌握游戏状态。在关键时刻提供适当的视觉和听觉反馈，增强操作的满足感。

## 核心循环

观察场景寻找物品 -> 找出清单上的所有隐藏物品 -> 解锁新场景和新剧情

## 核心机制

- **隐藏物品寻找**: 玩家在精心绘制的场景中寻找清单上的物品，场景细节丰富，物品巧妙隐藏在画面各处。找到所有物品后过关，可使用有限次数的提示功能辅助。每个场景都有独特的艺术风格和主题背景。

## 为什么好玩

精美的场景画面带来沉浸感，每发现一个隐藏物品都有即时反馈的成就感。随着关卡推进场景变化丰富，满足探索欲和观察力挑战。

## 粘性来源

场景探索的不确定性——不知道物品藏在哪里驱动持续游玩；提示次数有限增加了差一点就找到的不甘心感；收集完整图鉴的收集欲。

## Meta 系统

场景解锁系统——完成一定数量关卡后解锁新场景主题，每个场景有独特的艺术风格和故事背景，提供持续的视觉新鲜感。

## 实现难度

低 — 核心是图片展示和点击判定，最大难点在于设计足够多不重复的高质量场景图片。
