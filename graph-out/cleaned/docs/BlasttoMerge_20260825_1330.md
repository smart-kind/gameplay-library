# Blast to Merge

- **类型**: 合并解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: kadir ozden
- **首次发布**: 2019
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

点击相同数字的气泡进行合并 -> 获得更高数字 -> 解锁新关卡

## 核心机制

- **数字合并机制**: 点击相邻且数字相同的气泡，它们会合并成下一个数字（如两个2合并成3）。随着合并进行，数字不断增长，形成连锁反应。这种设计利用了简单的数学递增逻辑，玩家只需要识别相同数字即可操作，门槛极低但策略性随数字增长而提升。
- **关卡目标制**: 每关设有特定目标分数或合并次数限制。玩家需要在有限步数内达到目标数字或清除指定数量的方块。这种限制创造了紧张感，迫使玩家规划合并路径而非随意点击。
- **气泡物理布局**: 气泡以不同形状排列在屏幕上，每次合并后剩余气泡会因重力下落重新排列，产生新的相邻关系。这种动态重组机制确保每步操作都可能创造新的合并机会，也增加了不可预测的趣味性。

## 为什么好玩

数字递增合并带来的爽快感非常直接。每次合并都伴随清晰的视觉反馈和数字跳动。随着数字变大，成就感呈指数增长。

## 粘性来源

粘性来源于'差一点就合成目标数字'的不甘心，以及数字递增带来的数值成长爽感。

## Meta 系统

- 关卡系统：通过完成关卡解锁新区域和新挑战
- 每日任务：完成指定合并目标获取奖励
- 对核心玩法的影响：关卡递进提供阶段性目标，每日任务增加日常活跃度

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
