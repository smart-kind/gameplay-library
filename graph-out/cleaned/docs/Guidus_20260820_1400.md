# 吉度斯（Guidus）

- **类型**: Roguelike RPG / 像素
- **平台**: Mobile (iOS+Android)
- **开发商**: izzle Inc.
- **首次发布**: 2021
- **一句话描述**: 像素风地牢探险，从深渊中觉醒的最后战士重夺王宫的冒险

## 玩法规则

游戏背景是深渊的怪物从王宫封印下觉醒，双胞胎王子和公主与最后的战士一起英勇战斗但最终被击败，流放到地牢中。玩家扮演在地牢深处苏醒的最后战士，踏上一场重夺王宫的冒险。

游戏采用经典像素 Roguelike 地牢爬升玩法。玩家控制角色在随机生成的地牢中探索，每层有多个房间，房间之间有通道连接。遇到敌人后进入回合制战斗。

战斗中玩家可以选择攻击、防御、使用物品或技能。每个角色有独特的职业属性和技能树。地牢中有宝箱、商店、事件房间等丰富内容。每次探索都需要仔细规划每一步，因为错误的决定可能导致死亡。

每次死亡后从头开始，但可能解锁新的角色或内容。随着进度推进，可以解锁更多职业和地牢层数。游戏的难度曲线通过逐步解锁更多内容来调节。

## 核心循环

探索地牢 → 回合制战斗 → 收集物品强化 → 挑战Boss → 死亡重新开始

## 核心机制

- **职业差异化**：多个职业各有独特的技能树和战斗风格，解锁新职业后可以用完全不同的方式通关。战士适合正面战斗，法师擅长远程法术，盗贼则擅长偷袭和暴击
- **随机地牢生成**：每次冒险的地牢布局、敌人分布、宝物位置都不同，保证重玩价值。生成算法需要确保地牢始终可通关，不会出现死路
- **回合制策略战斗**：需要仔细考虑每回合的行动选择，攻击、防御、道具使用的时机都很关键。回合制给了玩家充分的思考时间，策略深度远超即时战斗

## 为什么好玩

Guidus 提供了一种经典的像素 Roguelike 体验——每层地牢都有未知的惊喜，回合制战斗让每次决策都有分量，死亡后重新挑战的过程本身就是乐趣。

## 粘性来源

随机地牢的探索欲 + 多职业的差异化体验 + 回合制策略的深度

## Meta 系统

多角色解锁 + 技能树 + 地牢层数推进

## 实现难度

中 — 回合制战斗AI+随机地牢生成+多职业平衡，最大难点是战斗策略深度与移动操作便利性的平衡
