# Enigmo（Enigmo）

- **类型**: 3D管道导向解谜
- **平台**: Mobile (iOS+Android), PC
- **开发商**: Pangea Software
- **首次发布**: 2008
- **一句话描述**: 通过旋转和放置3D管道来引导流体到达目标的经典空间解谜游戏，曾获得2008年GDC独立游戏展展示奖项。

## 玩法规则

游戏采用3D透视视角，场景中有一个流体源头（如水、岩浆、气体的出口）和一个或多个接收容器。场景中还散布着各种管道部件——直管、弯管、T型管、漏斗等。玩家需要将这些管道部件拖放到正确位置并旋转到正确角度，搭建一条从源头到接收容器的完整管道通路。

管道搭建完成后，玩家启动流体流动，流体会沿着管道前进。如果管道连接正确、没有泄漏、方向正确，流体就能顺利到达接收容器完成关卡。如果管道有断点、方向错误或未连接到容器，流体会从缺口处泄漏，关卡失败。

随着关卡推进，场景变得更加复杂：3D空间中出现多个层级（需要管道在不同高度间转向）、流动速度加快、出现分流点（一个源头需要同时流向多个容器）、需要特定类型的管道来应对特定流体（如岩浆需要耐火管道）。

## 核心循环

观察源头和容器的空间位置 → 选择并放置管道部件 → 旋转调整连接方向 → 启动流动测试 → 观察泄漏点并修正

## 核心机制

- **3D空间管道搭建**：与2D管道游戏不同，Enigmo的管道在3D空间中延伸，需要考虑上下、左右、前后的方向。玩家需要在3D视角中理解空间关系并正确连接管道。视角可以旋转以从不同角度观察管道布局。
- **流体物理模拟**：流体在管道中的运动遵循重力规律——向下流动快、向上流动需要压力、水平流动保持匀速。玩家需要理解这些物理特性来设计合理的管道布局（例如避免"水往高处流"的不可能设计）。
- **限时挑战**：部分关卡设置了时间限制，流体必须在特定时间内到达容器。这增加了额外的约束——不仅需要管道连接正确，还需要路径尽可能短或直。
- **多目标分流**：高级关卡要求一个源头同时流向多个接收容器，需要设计分支管道系统。这增加了规划的复杂度——需要平衡各分支的流量和到达时间。

## 为什么好玩

Enigmo将"接水管"这个经典的解谜概念提升到了3D空间，增加了空间想象的维度。当流体沿着你搭建的管道一路畅通、最终注入容器时，那种"我设计的系统完美运行"的满足感很强。游戏的3D美术在2008年iPhone游戏界属于顶尖水准，管道和流体的视觉效果精致流畅。多人模式（通过Game Center）增加了竞争性——看谁能用更少的管道部件或更短的时间完成。

- **管道部件的种类**：游戏中包含多种管道部件——直管（连接两点）、弯管（90度转向）、T型管（分流）、交叉管（双向分流）、漏斗（汇集流体）、阀门（控制流向）。不同部件的组合创造了丰富的解谜可能性。
- **流体类型的变化**：不同关卡使用不同的流体——水（标准）、岩浆（流速更快需要耐火管道）、气体（流速最慢但需要密封管道）。每种流体对管道布局有不同的要求。

## 粘性来源

- **空间思维的挑战性**：3D管道搭建需要良好的空间想象力，这种认知挑战对喜欢解谜的玩家有持续吸引力
- **"看到泄漏点"的即时反馈**：每次启动流体流动都能立即看到哪里出了问题，不需要猜测——泄漏点清晰可见，修正目标明确
- **难度递增合理**：从简单的2D平面管道逐步过渡到复杂的多层3D管道系统，学习曲线平缓但深度充足

## Meta 系统

- **关卡解锁系统**：完成一组关卡解锁下一组。
- **多人对战模式**：通过Game Center进行异步竞赛，比较通关时间和管道使用数量。
- **成就系统**：完成特定挑战获得成就。

## 实现难度

中。3D管道系统需要实现空间变换、碰撞检测和流体运动模拟。最大技术难点在于管道连接的判定——需要确保两个管道部件的接口在3D空间中精确对齐。流体模拟可以使用粒子系统或预设动画路径。视角控制和3D交互在移动设备上需要精心设计以避免操作困难。
