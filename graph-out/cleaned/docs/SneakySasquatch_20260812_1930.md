# 鬼鬼祟祟的大脚怪（Sneaky Sasquatch）

- **类型**: 冒险 / 模拟 / 沙盒
- **平台**: Mobile (iOS via Apple Arcade) / macOS / tvOS
- **开发商**: RAC7
- **首次发布**: 2019
- **一句话描述**: 扮演一只大脚怪，在人类营地偷食物、伪装成人类潜入各种场所，在开放世界中自由探索

## 玩法规则

游戏画面为俯视角的 2D 像素风格，场景以加拿大不列颠哥伦比亚省的 Squamish 地区为灵感，包含森林、露营地、小镇、湖泊等多样环境。

玩家控制一只毛茸茸的大脚怪，核心能力是"潜行"和"伪装"。在人类营地中，你需要悄悄接近帐篷和冰箱，偷取食物（这是大脚怪的主要食物来源）。当人类靠近时，必须躲进灌木丛或逃跑，被发现会引发追逐。

伪装系统是游戏的核心玩法之一。找到人类丢弃的衣服后，大脚怪可以穿上它们伪装成人类。穿上不同的服装可以进入不同的场所——穿上工作服可以混入建筑工地，穿上西装可以进入办公室，穿上运动服可以进入健身房。伪装让你能自由进出原本无法进入的区域。

操作方式：虚拟摇杆控制移动，点击屏幕进行互动（打开帐篷、拾取物品、驾驶载具）。驾驶是游戏的重要组成部分——你可以驾驶汽车、卡车、皮划艇、甚至飞机在地图中快速移动。

游戏没有明确的"通关"目标，而是鼓励玩家自由探索。你可以做各种事情：在露营地偷食物、打零工赚钱、买衣服和载具、钓鱼、露营、参加迷你游戏、探索地图上的每个角落。

## 核心循环

探索地图 → 发现新区域/任务 → 获取金钱和物品 → 解锁新能力/载具 → 继续探索

## 核心机制

- **潜行与伪装系统**：游戏的核心循环围绕"偷东西不被发现"展开。你需要观察人类的活动模式（他们什么时候巡逻、什么时候离开帐篷），选择最佳时机行动。穿上人类服装后可以大摇大摆地进入各种场所，从"偷东西的大脚怪"变成"正常的人类公民"，这种身份切换带来了独特的喜剧效果。
- **开放世界探索**：地图包含多个区域——森林露营地、小镇、海滩、山区、高尔夫球场、停车场等。每个区域有独特的活动和可互动的 NPC。地图会随着游戏进度逐步解锁。
- **经济系统**：通过打零工（如当停车场管理员、高尔夫球童、建筑工人）赚取金币，用于购买服装、载具、露营装备和食物。
- **载具系统**：游戏中有多种可驾驶的载具——自行车、汽车、卡车、皮划艇、船只、飞机。每种载具有不同的操控特性和适用场景。
- **迷你游戏**：游戏中穿插着各种迷你游戏，如钓鱼、打高尔夫、跳舞比赛等，既有趣又能获得奖励。

## 为什么好玩

Sneaky Sasquatch 最吸引人的地方是它把"做大脚怪"这个简单的概念玩出了花。你可以在一个场景里是鬼鬼祟祟偷热狗的怪物，穿上衣服后下一秒就变成小镇上打工的普通公民。这种荒诞感贯穿始终，配合轻松的像素画风和悠闲的节奏，创造出一种独特而温暖的游戏体验。

## 粘性来源

探索驱动的"下一个角落有什么"的好奇心。地图很大，每个区域都有隐藏内容和惊喜。收集服装和载具的成就感。各种迷你游戏提供了丰富的内容密度。没有死亡压力，没有失败惩罚——纯粹的探索乐趣让任何人都能放松享受。

## Meta 系统

- **服装收集**：解锁各种服装，从休闲装到职业装到搞笑服装（如热狗装）。
- **载具收藏**：从自行车到飞机，逐步解锁更多交通工具。
- **营地升级**：购买更好的露营装备，提升在野外的生活质量。
- **房产购买**：在游戏后期可以购买自己的房子。

## 实现难度

中等。开放世界地图需要大量的内容设计（每个区域的活动、NPC、互动点），技术层面的 2D 渲染和碰撞检测相对简单。最大的挑战是内容密度——确保地图的每个角落都有有趣的事情可做，而不是空旷的填充物。这也是 Apple Arcade 独占游戏通常能做到的事情——有足够的时间和预算来打磨内容。
