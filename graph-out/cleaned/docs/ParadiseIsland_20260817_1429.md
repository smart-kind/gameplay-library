# Paradise Island

- **类型**: 模拟经营
- **平台**: iOS+Android
- **开发商**: Game Insight
- **首次发布**: 2010

## 玩法规则

游戏画面为热带岛屿的俯视角建设模拟。玩家拥有一座荒芜的热带岛屿，需要将其打造成五星级旅游度假胜地。

玩家能做什么操作：
- 点击地图上的空地选择要建造的建筑类型：酒店（提高住宿容量）、餐厅（提供餐饮服务）、商店（出售纪念品）、娱乐设施（水上乐园、高尔夫球场等）
- 拖拽调整建筑位置，优化岛屿布局和游客动线，让游客能方便地在各设施之间移动
- 点击已建造的建筑进行升级，提升收入能力和吸引力。升级需要时间和金币，高等级建筑产出更多收益
- 收集建筑定时产出的金币和经验值，经验值用于提升玩家等级，解锁更多建筑类型
- 装饰岛屿：种植热带树木、花卉，摆放长椅、喷泉等装饰物美化环境，提升整体吸引力评分

游戏目标：将荒岛打造成五星级度假胜地，吸引最大数量的游客，获得最高的旅游评分。建筑需要等待时间完成建造和升级，可以用钻石（付费货币）加速。
游客满意度取决于设施的丰富度和质量等级，需要在不同设施类型之间平衡发展。

## 核心循环

建造设施吸引游客 -> 收取费用获得金币 -> 解锁更多建筑和装饰 -> 提升岛屿星级

## 核心机制

- 岛屿空间规划：在有限的岛屿面积上合理布局各类建筑，需要考虑游客动线、景观美观度和收入最大化
- 建筑升级系统：每个建筑有多个等级，升级后提升收入产出、吸引力和容量。高等级建筑外观也会变化
- 游客满意度模型：游客在岛上的体验由设施丰富度、环境质量、服务态度等多维度决定，综合评分影响口碑传播和新客流量
- 任务驱动解锁：完成游戏内任务获得奖励和经验值，经验值提升等级后解锁新的建筑类型

## 为什么好玩

从无到有打造度假胜地的成就感是核心驱动力。海岛主题本身就有天然的吸引力，看着荒芜的岛屿变成繁华的度假天堂非常有满足感。社交互访功能提供了展示自己成果的平台，激发建设热情。

## 粘性来源

建设解锁的持续驱动力（"解锁下一个建筑会是什么？"）。布局规划的创造性：每个人都想打造独一无二的岛屿。社交比较动机：访问好友岛屿激发竞争意识。收集类元素驱动反复上线。

## Meta 系统

- 建筑解锁：随着等级提升解锁新的建筑类型和装饰
- 任务系统：日常和长期任务引导玩家行为，完成后给予奖励
- 社交系统：访问好友岛屿、赠送礼物、排行榜竞争
- 活动系统：限时活动提供特殊建筑和奖励

## 实现难度

低 -- 经典的放置经营框架，需要实现建筑放置系统、经济产出模拟、游客AI。最大的技术难点是经济系统的数值平衡和等待时间的调优，确保玩家有足够的事情做但又不会感到被催促。
