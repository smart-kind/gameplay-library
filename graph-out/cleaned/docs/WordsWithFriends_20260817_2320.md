# Words With Friends（Words With Friends）

- **类型**: 社交文字
- **平台**: Mobile (iOS+Android) / Web
- **开发商**: Zynga (原Newtoy)
- **首次发布**: 2009
- **一句话描述**: 一款基于拼字的社交对战游戏，玩家轮流在棋盘上放置字母组成单词来得分。

## 玩法规则

游戏界面是一个15x15的棋盘格，与经典Scrabble棋盘布局完全相同。棋盘包含多种加成格：DL（Double Letter，字母分值翻倍）、TL（Triple Letter，字母分值翻三倍）、DW（Double Word，单词分值翻倍）、TW（Triple Word，单词分值翻三倍）以及中心星形格（第一个词必须经过，兼具DW效果）。
玩家每回合从字母袋中抽取7个字母牌。每个字母牌对应一个英文字母和分值——常用字母如A/E/I/O/U/N/R/S/T为1分，稀有字母如Q/Z为10分，X/J为8分，K为5分。字母袋中字母数量和种类固定，与Scrabble标准相同。
玩家在自己回合选择一个单词，在棋盘上横向或纵向放置，与已有字母相连（首个词必须经过中心格）。放置后计算该回合得分：所有字母分值之和，再乘以经过的单词倍率格。
如果放置的字母同时与已有字母组成多个合法英语单词，所有这些新单词都同时计分，实现一回合多次得分。例如横向放一个词时纵向也拼出了另一个词，两个词的分值都算入当回合总分。
每回合结束后，从字母袋中抽取新字母补足7个。当字母袋空且某玩家用完手中所有字母时，该回合结束。用完字母的玩家获得剩余对手手中字母分值之和作为额外加分。最终得分最高的玩家获胜。支持异步多人对战，玩家可以在自己方便的时间回应对手的回合，也支持单人AI练习模式。

## 核心循环

观察棋盘布局 → 用手中字母组成高分单词 → 占领加成格最大化得分 → 抽取新字母 → 等待对手回应 → 继续下回合

## 核心机制

- 拼字策略：选择最佳位置和方向最大化分值，利用高价值字母（Q/X/Z）落在三倍字母格上实现分数爆发。同时要考虑堵住对手可能利用的加成格位置
- 加成格博弈：棋盘上的DL/TL/DW/TW加成格是核心战略资源。抢先占领这些位置能产生显著分值差距，但也要防止给对手留下更好的利用机会。高手会在放置时考虑'我放了这个之后对手下一步能做什么'
- 异步社交回合制：不需要同时在线，每回合给对方留下难题或开放格局。这种机制兼具策略深度和社交趣味性——你可以故意留下一个看似有利实则暗藏陷阱的格局

## 为什么好玩

每回合都在'我能想到什么好词'的创造性满足感和'我把对手逼到死角'的策略快感之间摇摆。
发现一个能同时形成三个单词的绝佳落点时，那种智力上的成就感极强。
异步机制让你有充足时间思考最佳策略，甚至可以去查字典或请教朋友——这本身也是游戏乐趣的一部分。
和朋友对战时，互相吐槽'这个词你也想得出来'的社交体验是纯AI对战无法替代的。

## 粘性来源

核心粘性来自社交关系链——你想回应朋友的挑战，不想让对方等太久。机制层面的粘性来自'差一点就能超过对方'的不甘心和偶尔抽到高分字母牌带来的偶然性惊喜。每日挑战模式也提供了额外的回归动力。

## Meta 系统

每日登录奖励、连胜成就、词汇量统计等轻度外围系统，主要围绕社交排行榜和好友邀请展开。游戏还设有每日词汇挑战和主题赛等特殊活动。

## 实现难度

低 — 拼字逻辑和回合制状态管理简单，核心就是一个棋盘格状态数组加词典验证。主要技术难点在于异步多人状态同步（需要持久化存储每个玩家的状态）和合法词汇表的高效查询（需要前缀树或哈希表加速）。

游戏还包含每日词汇挑战：每天一个特定的字母组合，看谁能找到总分最高的单词排列。某些版本支持'word wizard'功能，自动记录你在游戏中使用过的所有单词，帮助扩展词汇量。
