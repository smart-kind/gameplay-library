# Wordle（Wordle）

- **类型**: 文字推理 / 解谜
- **平台**: Web / Mobile (iOS+Android)
- **开发商**: Josh Wardle → The New York Times
- **首次发布**: 2021
- **一句话描述**: 每天猜一个5字母单词，6次机会，每次猜测获得颜色反馈

## 玩法规则

游戏每天给出一个目标单词（5个英文字母）。玩家有6次机会猜出这个单词。

每次猜测输入一个5字母英文单词后，系统用三种颜色反馈每个字母的信息：
- **绿色**: 字母正确且位置正确
- **黄色**: 字母在单词中但位置不对
- **灰色**: 字母不在这个单词中

玩家根据颜色反馈调整下一次猜测，逐步缩小范围。比如第一次猜"CRANE"，如果C和N是灰色、R是绿色（第二位）、A是黄色、E是灰色，就知道目标词第二位是R，包含A但不在第4位。

每天只有一个新单词，全球玩家猜的都是同一个词。

## 核心循环

猜测单词 → 获得颜色反馈 → 分析缩小范围 → 再次猜测 → 6次内猜中或失败

## 核心机制

- **三色反馈推理**: 每次猜测获得的信息量（绿色=确定位置，黄色=确定存在，灰色=排除）构成一个推理游戏
- **每日一词限制**: 每天只有一道题，制造了稀缺性和共同话题
- **猜测词汇选择**: 初始词的选择很重要（如"CRANE""SLATE"等含常见字母的组合），形成了策略维度
- **硬模式**: 可选约束——必须使用已确认的字母进行后续猜测

## 为什么好玩

Wordle把"猜词"做成了一个纯粹的推理游戏。它的魔力在于"每天一道题"的稀缺性——不是无限关卡让你刷，而是一道题让你反复咀嚼。加上颜色反馈带来的即时满足感（每个绿色字母都是一次小胜利），形成了独特的体验。

## 粘性来源

每日一词的稀缺性制造了"明天再来"的期待。全球玩家猜同一词创造了社交分享的基础（那个著名的色块emoji分享就是传播的核心驱动力）。6次机会的限制创造了恰到好处的紧张感。

## Meta 系统

连续答题天数统计（Streak）——连续猜中的天数是唯一的长期指标。分享功能（色块emoji）是社交传播的核心机制。

## 实现难度

低 — 核心只是一个字典查找+颜色比对算法。最大技术难点可能是单词列表的筛选（哪些词作为答案，哪些词作为合法猜测），以及每日答案的确定性生成（伪随机种子）。
