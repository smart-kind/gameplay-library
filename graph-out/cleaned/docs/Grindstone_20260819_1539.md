# Grindstone（磨石）

- **类型**: 三消 / 解谜 / 策略
- **平台**: Mobile (iOS) / PC
- **开发商**: Capybara Games Inc.
- **首次发布**: 2019
- **一句话描述**: 画线连接同色怪物并连续消灭，在连锁中策略规划路线

## 玩法规则

游戏画面是一个由不同颜色怪物填充的方形网格。玩家用滑动手指在相邻的同色怪物之间画出一条连续的路径（类似贪吃蛇），松开后角色沿路径跑过，消灭所有连线上的同色怪物。

消除一个颜色组后，上方的怪物会掉落填补空位，形成新的布局。每次消除时，怪物会掉落"帽子"（小图标），角色可以捡起这些帽子来解锁后续关卡中的装饰道具。

某些怪物带有特殊标记：带帽子的怪物（消除后获得额外奖励）、冻结怪物（需要用相邻消除来解冻才能消除）、带盾怪物（需要两次消除才能消灭）、爆炸怪物（消除后引发连锁爆炸）。

关卡目标是消除指定数量的特定怪物或到达网格底部出口。步数/移动次数有限制，每次画线路径算一次移动。消除不同颜色的组之间可以形成连锁加成——如果新形成的路径经过上一轮消灭的区域，会获得分数倍增。

## 核心循环

观察棋盘 → 画线连接同色怪物 → 消除并获得奖励 → 棋盘更新 → 规划下一轮消除 → 完成关卡目标

## 核心机制

- **路径规划消除**：不同于传统三消的交换配对，Grindstone 让玩家自由绘制任意长度的同色路径，路径越长分数越高。但路径只能走相邻格子，且不能交叉自身。
- **连锁倍率系统**：如果角色在消除后经过上一轮消除的格子区域，触发连锁倍率（x2、x3），鼓励玩家思考多步消除的叠加效果。
- **怪物特殊状态**：冻结、盾牌、爆炸等状态让消除不只是颜色匹配，而是需要考虑消除顺序和时机。例如，先消爆炸怪可以连锁清除周围障碍。
- **帽子收集**：每个被消除的怪物头上可能有帽子道具，角色必须经过帽子所在位置才能捡起。这要求玩家在追求高分的同时，也要规划捡帽子的路线。

## 为什么好玩

将三消的直觉快感与路径规划的策略深度完美结合——每次消除都像是在下一盘微型象棋。画出一条长长的彩色路径并看着角色跑过的视觉反馈极其爽快，而发现一个能触发多重连锁的"完美路线"带来的成就感则令人上瘾。

## 粘性来源

- **帽子收集驱动**：每关都有特定帽子需要收集，解锁角色装饰外观
- **关卡递进难度**：怪物种类和特殊机制逐步增加，保持新鲜感
- **最优解追求**：每关都追求最高分和最优路线，重玩价值高
- **视觉爽感**：长路径消除的动画反馈和连锁倍率的数字飙升

## Meta 系统

- **帽子图鉴**：消除怪物获得各种帽子（厨师帽、皇冠、圣诞帽等），收集解锁后可装饰角色
- **角色装扮**：用收集的帽子改变角色外观，纯装饰性
- **章节推进**：每章有新怪物类型和机制引入

## 实现难度

中。核心算法难点在于：路径合法性验证（相邻同色不交叉）、消除后棋盘掉落模拟、连锁倍率区域追踪。网格碰撞和动画系统需要流畅的 60fps 表现，特别是长路径消除时的角色跑动动画。
