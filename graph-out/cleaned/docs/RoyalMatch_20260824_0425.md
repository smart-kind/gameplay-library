# Royal Match

- **类型**: 三消解谜 / 装饰模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: Dream Games
- **首次发布**: 2020
- **一句话描述**: 一款三消加城堡装饰的休闲游戏，玩家通过消除关卡收集资源，帮助国王Robert修复和装饰皇家城堡。

## 玩法规则

游戏核心是经典三消玩法，加入装饰城堡的Meta目标。玩家在一个彩色网格中进行消除，同时通过完成关卡获得星星来装饰城堡。

在网格中交换相邻元素，使3个或更多相同元素连成一线。3个消除获得基础分数。4个消除（L形或T形）生成火箭道具，消除整行或整列。5个消除生成彩色球道具，消除所有同色元素。两个道具组合使用产生更强大的连锁效果。

每个关卡有明确目标：收集指定数量元素、清除障碍物、解救角色等。限制条件包括步数限制或时间限制。障碍物类型有锁链（需消除两次）、冰块（需相邻消除）、盒子（需特定次数消除）。每关目标与城堡修复进度相关联。

完成关卡获得星星和金币。星星用于解锁城堡新区域和装饰选项。每个区域有多个装饰选择，玩家可自定义风格。城堡从破败状态逐步恢复到华丽模样，视觉反馈极为明显。

关卡开始前可购买额外道具如锤子、洗牌、额外步数。游戏内生成的强力道具可战略性使用。失败时有机会用金币购买额外步数继续。

## 核心循环

消除闯关 → 获得星星 → 装饰城堡 → 解锁新区域 → 更难的关卡

## 核心机制

- **三消加装饰双循环**: 核心消除提供即时爽感反馈，装饰系统提供长期目标。消除关卡是怎么过，装饰城堡是为什么过。两者相互促进：装饰进度推动玩家挑战更难关卡，关卡产出支撑装饰需求。双循环设计让游戏既有短期目标又有长期目标。

- **道具连锁系统**: 4消和5消生成的道具可单独使用产生大范围消除，也可两个道具组合使用产生更强大效果。火箭加彩色球等于全屏消除同色行。道具组合策略深度让游戏超越找匹配层面，玩家需要主动规划：消除眼前3个，还是等待更好组合。

- **渐进式障碍系统**: 随着关卡推进，障碍物种类和复杂度递增。初期简单锁链到中后期多层复合障碍，要求玩家掌握不同应对策略。渐进式难度曲线保证新手不挫败，老手不无聊。

## 为什么好玩

消除本身就有天然爽感，加上修复城堡的可视化进度反馈，让玩家有明确成就感。动画精致、色彩明快，每次消除都有令人满意的视觉和听觉反馈。装饰系统的个性化选择让玩家有主人翁感。

## 粘性来源

三消上瘾性加上城堡装饰的收集欲和每日挑战的持续性，构成长期留存。装饰系统的选择权让玩家有个性化投入，增加沉没成本。赛季活动和锦标赛提供阶段性目标。

## Meta 系统

城堡装饰系统：玩家用星星解锁和自定义城堡各区域。赛季活动和锦标赛提供额外奖励。每日任务和连胜挑战维持日常活跃。关卡地图展示进度，激励玩家持续前进。

## 实现难度

中。三消关卡生成算法是核心技术难点（需保证每关有解但不过于简单）。装饰系统资产量大。道具组合效果动画和逻辑需精细调优。需要大量关卡设计和数值平衡工作。
