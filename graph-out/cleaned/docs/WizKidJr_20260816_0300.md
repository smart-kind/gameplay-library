# Wiz Kid Jr.

- **类型**: 连线消除解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Super Combo Collective
- **首次发布**: 2011
- **一句话描述**: 连线消除谜题游戏，在网格上滑动连接相同图腾形成链条
- **PocketGamer评分**: 8/10

## 玩法规则

玩家在一个网格状的屏幕上，通过滑动手指连接三个或更多相同的图腾（totem）来消除它们。这是一种连线消除玩法，但与传统的三消不同，玩家需要手动绘制连接路径。

当玩家连接图腾时，会填充Mana条并获得雷电之力。雷电可以用于执行特殊的游戏改变动作，比如消除一整行或列的图腾、清除特定颜色的所有图腾、或者获得额外分数。Mana条满了之后可以释放强力的连锁攻击。

游戏的核心挑战在于：网格上的图腾会不断出现，玩家需要在有限时间内完成消除，否则网格会被填满导致游戏结束。随着游戏推进，图腾种类增加，需要更长的连接链才能消除。特殊图腾和障碍物也会出现，需要玩家灵活应对。游戏的紧张感来自"差一点就能连上"的紧迫感。

## 核心循环

放置/操作 → 获得奖励/进展 → 升级/解锁新内容 → 挑战更高难度

## 核心机制

- **机制1**：连线消除解谜核心循环 — 通过连线消除解谜操作完成关卡目标，获得金币/分数奖励
- **机制2**：渐进式难度 — 每个关卡引入新的元素或增加复杂度，玩家需要调整策略
- **机制3**：资源管理 — 有限的建造材料/金币/时间，需要玩家做出取舍决策

## 为什么好玩

Super Combo Collective团队的Wiz Kid Jr.是一款简单但引人入胜的连线消除谜题游戏，在网格上滑动连接相同图腾。 游戏的评分为8/10，说明这款游戏质量不错，有独特的玩法乐趣。

## 粘性来源

具体到机制层面：核心循环的"完成关卡→获得奖励→解锁新内容"驱动玩家持续游玩；渐进式难度带来的挑战感让玩家想"再来一关"；解谜类游戏特有的"顿悟时刻"（想通了解法）提供强烈的成就感。

## Meta 系统

外围成长系统：通过关卡获得的金币/分数可以解锁新的塔类型/角色/赛道，或升级已有元件的性能。对核心玩法的影响：解锁内容提供了新的策略选择，但不改变核心操作方式。

## 实现难度

中 — 核心玩法基于成熟的连线消除解谜机制，最大技术难点在于流畅的手势识别和实时物理反馈。
