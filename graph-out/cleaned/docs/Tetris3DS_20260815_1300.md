# Tetris (3DS版)

- **类型**: 益智消除 / 方块堆叠
- **平台**: Nintendo 3DS / DS
- **开发商**: Nintendo / h.a.n.d.
- **首次发布**: 2011
- **一句话描述**: 经典方块消除游戏的3DS版本，利用立体视觉和双屏特性重新诠释玩法

## 玩法规则

在Tetris (3DS)中，玩家面对一个垂直的游戏区域，由七种不同形状的方块（I、O、T、S、Z、J、L）从顶部随机掉落。玩家需要实时操作：左右移动方块、旋转方块、加速下落或硬降。每当玩家用方块填满一整行时，该行消除，上方所有方块下落一格，玩家获得分数。游戏的核心目标是在方块堆积到顶部之前尽可能多地消除行。

3DS版本独有特性：上屏显示游戏主区域，下屏可显示下一个方块预览或特殊模式。利用3DS的陀螺仪，玩家可以在某些模式中通过倾斜设备来微调方块方向。游戏包含多种模式：经典马拉松模式（坚持到Level 15/20）、40行冲刺模式（以最快速度消除40行）、以及利用3DS擦肩通信的多人对战模式。

游戏结束条件：当新方块无法在顶部生成时，游戏结束（Game Over）。在马拉松模式中，方块下落速度随等级递增，考验玩家的反应速度和空间规划能力。

## 核心循环

放置方块 → 消除行获得分数 → 等级提升速度加快 → 坚持更久获得更高分

## 核心机制

- **七种标准方块(Tetrominoes)**: I/O/T/S/Z/J/L七种形状，每种由四个方格组成，玩家必须根据当前堆积状况选择最优放置位置
- **硬降(Hard Drop)**: 按下按钮让方块瞬间落到底部，节省时间并获得额外分数，是高手必备技巧
- **踢墙(Wall Kick)**: 当方块在墙边旋转时，系统自动将方块偏移一格以允许旋转，降低操作门槛
- **T旋(T-Spin)**: 利用T形方块在狭窄空间旋转消除的技术，在3DS版中可获得额外奖励分数
- **3D立体视觉**: 利用3DS的裸眼3D特性，方块呈现出深度感，帮助玩家更直观地判断方块间的空隙

## 为什么好玩

Tetris的魅力在于极简规则下的无限深度——任何人都能上手，但精通需要数百小时练习。3DS版本通过立体视觉带来全新的空间感知体验。方块消除时的爽快反馈配合不断加速的紧张感，创造出“再来一局”的强迫循环。

## 粘性来源

“差一行就升级”的不甘心是核心粘性来源。每次游戏结束玩家都清楚看到自己“差一点”就能做得更好，这种心理驱动力极强。

## Meta 系统

无核心外围系统。部分版本包含解锁成就和排行榜功能，但对核心玩法无影响。

## 实现难度

低 — 规则简单直观，最大的技术难点在于方块掉落的实时响应控制和3D深度渲染的精确对齐。
