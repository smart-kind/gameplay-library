# PUBG Mobile（绝地求生手游）

- **类型**: 大逃杀 / 射击
- **平台**: Mobile (iOS+Android)
- **开发商**: Tencent Games / Krafton
- **首次发布**: 2018
- **一句话描述**: 100 名玩家空降到一座岛屿上，搜寻武器装备，在逐渐缩小的安全区内战斗到最后。

## 玩法规则

每局比赛开始时，约 100 名玩家从一架运输机上跳伞，降落到一座约 8×8 公里的地图上。玩家落地后没有任何装备，需要在建筑物、村庄和军事基地中搜寻武器、弹药、防具、医疗用品和载具。

地图上的安全区（白圈）会随时间逐渐缩小，圈外的玩家会持续受到伤害。玩家需要不断向安全区移动，同时与遇到的其他玩家交战。最后存活的玩家或队伍获胜，这就是"Winner Winner Chicken Dinner"。

游戏支持单人、双人（组队）和四人（组队）模式。组队模式下，队友被击倒后可以被救助，全部被淘汰后该队伍出局。

地图中有多种武器类型：突击步枪、狙击枪、冲锋枪、霰弹枪、手枪、近战武器。不同武器有不同的射程、射速和伤害特性。玩家需要在背包容量有限的情况下做出装备选择。

## 核心循环

跳伞降落 → 搜寻装备 → 在安全区内移动和战斗 → 最后存活者获胜 → 获得经验/货币 → 解锁外观

## 核心机制

- **缩圈机制**：安全区不断缩小是核心驱动力，迫使玩家从分散到集中，自然形成遭遇战，同时控制单局时长在 20-30 分钟
- **随机装备分布**：每次跳伞后获得的装备完全随机，保证每局体验不同，降低失败挫败感
- **地形多样性**：大地图包含城市、乡村、山地、水域等多种地形，不同地形适合不同的战斗风格和武器选择
- **声音定位**：脚步声、枪声有方向提示，听觉信息是游戏重要的信息来源

## 为什么好玩

PUBG 开创了大逃杀品类的热潮，其核心乐趣在于"从零开始到全副武装"的成长过程。每局都是全新的开始，无论上一局表现如何都不影响下一局。随机性保证了新鲜感，而枪法、走位、战术意识的技术深度保证了可玩性。组队模式下的社交协作也是重要乐趣来源。

## 粘性来源

- **每局都不同**：随机跳伞点和装备分布保证了无限的新鲜感
- **技术成长曲线**：从落地就死到能吃鸡，技术进步带来强烈的成就感
- **"差一点就赢了"的心理**：经常以第 2-5 名结束，让人觉得"再来一局就能赢"
- **社交驱动**：组队开黑是与朋友互动的好方式，朋友上线就是上线的理由
- **赛季/通行证**：定期更新的外观奖励提供收集动力

## Meta 系统

赛季通行证系统。玩家通过游戏获得 BP（战斗点数）和银币，可用于购买赛季通行证解锁外观奖励，或在商店购买武器皮肤、角色服装、载具皮肤等。外观纯 cosmetic，不影响游戏平衡。

## 实现难度

高。大规模多人在线同步（100 人同时在一个大地图上）对服务器架构和网络同步要求极高。最大技术难点在于反作弊（外挂是大逃杀游戏的致命问题）和大地图的资源加载优化（移动端性能限制）。
