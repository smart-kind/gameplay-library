# 大厨合并（Chef Merge - Fun Match Puzzle）

- **类型**: 合并益智 / 装饰 / 农场模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: HIGGS TECHNOLOGY CO., LIMITED
- **首次发布**: 2021
- **一句话描述**: 一款轻松休闲的合并游戏，玩家合并农场食材获取硬币和钻石，用于装饰自己的庄园，打造理想中的豪宅。

## 玩法规则

游戏画面主要分为三个区域：上方是邻居需求栏（显示需要的物品和奖励），中央是合并棋盘（一个网格化的农场场景），下方是道具栏。

棋盘上分布着各种农场元素（蔬菜、水果、农作物等）。带有闪电标记的盒子点击后会产生新的可合并物品。玩家将相同的物品拖拽到一起进行合并，生成更高级的物品。

邻居会在需求栏中显示他们需要的特定物品。玩家合并出这些物品后，将其"卖"给邻居，获得金币和钻石奖励。

获得金币后，玩家进入装饰模式，选择庄园中的装饰项目（地毯图案、灯具形状、桌椅风格等），用金币购买并放置。每个装饰项目都有多种可选样式。

## 核心循环

点击获取物品 → 拖拽合并升级 → 卖给邻居换金币 → 装饰庄园 → 解锁更多庄园

## 核心机制

- **农场元素合并链**：游戏中的合并链基于农场和农作物主题。从基础农作物到加工食品，每个合并阶段都有清晰的视觉升级路径。
- **邻居交易系统**：邻居充当了合并产出的"买家"，将合并行为转化为经济收益。不同的邻居需要不同的物品组合，玩家需要策略性地决定合并方向。
- **自由装饰系统**：装饰系统没有固定模板，玩家可以自由选择地毯、灯具、桌椅等装饰元素来打造独一无二的庄园。这种自由度让玩家有强烈的个人表达欲望。
- **无时间压力**：游戏没有倒计时或强制通关机制，玩家可以完全按照自己的节奏进行合并和装饰。

## 为什么好玩

农场主题的合并链天然具有"种植-收获-加工"的满足感循环。看着简单的种子一步步变成精美的食物和装饰品，过程本身就很有趣。装饰系统的自由度让游戏不仅是解谜，更像是一种数字版的"装扮我的家"体验。

## 粘性来源

装饰完成度是核心粘性来源——看到自己的庄园从空荡荡到逐渐丰满，每一步都是视觉上的奖励。收集农场元素图鉴（收获相册）功能让收集爱好者有额外的追求目标。"差一点就装饰完这个房间"的心理驱动玩家持续游玩。

## Meta 系统

游戏包含多个庄园的设计项目，完成一个庄园后可以开始新的设计挑战。农场元素收集系统记录了所有已解锁和已合并的物品。无复杂的付费成长系统。

## 实现难度

低。合并逻辑和装饰系统都是成熟的技术方案。最大的技术难点在于大量装饰元素的组合渲染性能——当庄园中有大量装饰物品时，需要优化渲染管线以保持流畅。
