# 风暴突击者（Storm Strikers）

- **类型**: 射击 / 街机 / 弹幕
- **平台**: Mobile (iOS)
- **开发商**: Doragon Entertainment
- **首次发布**: 2012
- **一句话描述**: 极致难度的弹幕射击游戏，玩家操控宇宙飞船在密集的子弹和激光中穿梭，通过精准操作和持续练习来突破极限。

## 玩法规则

玩家用单指在屏幕上滑动控制飞船移动。飞船自动开火，无需手动射击。

敌人被消灭后会掉落三种道具：星星（增加武器扩散范围和射速）、金色水晶（提升分数倍率）、绿色宝石（填充防护罩）。

飞船周围有一个光环圆环。如果在圆环范围内击杀敌人，可获得更多绿色宝石，并将敌人发射的等离子弹转化为金色硬币（增加分数）。

游戏使用代币系统进行进度推进。每次游玩都会获得代币，存活越久、操作越有风格，获得的代币越多。代币可用于购买新飞船和更强大的武器。

游戏共七个关卡，每个关卡都有Boss战。Boss战需要极高的专注力和精确的时机把握，timing偏差一秒、向左而非向右闪避，都可能导致生命迅速耗尽。
## 核心循环

单指滑动操控飞船，击杀敌人获得道具和代币，死亡后用代币升级，再次挑战突破更远

## 核心机制

- **光环击杀机制**：飞船周围有光环圆环，在光环范围内击杀敌人可额外获得绿色宝石并将敌方子弹转化为金币，鼓励高风险近距离战斗
- **代币进度系统**：每次死亡获得代币，存活越久和操作越有风格获得越多，代币用于购买新飞船和武器升级
- **秒级进度测量**：游戏以存活秒数来衡量进度，每次多活一秒都是进步，适合弹幕游戏的渐进学习曲线
- **三道具系统**：星星强化火力、金水晶提升分数、绿宝石充能护盾，三种道具覆盖战斗、得分和生存三个维度

## 为什么好玩

霓虹激光和弹幕的视觉冲击力极强，在最低难度下已经极具挑战性。对iOS平台来说，这是一款证明移动设备也能承载硬核游戏体验的佳作。

游戏的七种飞船各有不同的基础属性（速度、武器散射角度、护盾大小），玩家可以根据自己的操作风格选择最合适的飞船。新飞船需要花费代币解锁。

难度系统提供了多个等级选择，从"极具挑战"到"噩梦级别"。高难度下不仅敌人弹幕密度增加，玩家的容错空间也急剧缩小。

Boss战是游戏的精髓所在。每个Boss都有独特的攻击模式和多阶段转换，需要玩家记住弹幕规律并在密集弹雨中寻找安全的移动路径。

代币购买系统允许玩家在死亡后仍然获得进度感。即使只存活了几秒钟，获得的代币也离下一件升级更近了一步，这种设计鼓励持续尝试。
## 粘性来源

弹幕游戏特有的差一秒就过的执念是终极粘性来源。每次死亡后获得代币的反馈让玩家感觉至少有收获。Boss战的精确时机要求让每次突破都成为个人成就。只有最坚毅的玩家才能通关全部七关。

## Meta 系统

代币系统。每次游玩获得代币，用于购买新飞船和武器。进度以存活秒数衡量，每次多活一秒都是可见进步。无等级系统。

## 实现难度

高。最大技术难点在于大量弹幕弹道的精确计算和渲染性能，以及单指触屏操作下的高精度移动响应。
