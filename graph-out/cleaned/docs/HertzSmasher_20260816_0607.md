# Hertz Smasher（Hertz Smasher）

- **类型**: 街机 / 动作 / 节奏
- **平台**: Mobile (iOS+Android)
- **开发商**: 移动平台街机游戏
- **首次发布**: 约 2010 年代
- **一句话描述**: 快速点击或滑动屏幕，粉碎不断出现的频率波或目标

## 玩法规则

游戏画面呈现一个充满动态元素的屏幕，各种频率波、能量球或目标物从不同方向出现并向中心或玩家控制点移动。

玩家通过快速点击屏幕上的目标来"粉碎"它们。不同目标有不同的特性——有些需要多次点击，有些需要特定方向的滑动，有些会分裂成更小的目标。

屏幕上有生命值或时间限制。如果太多目标突破防线或时间耗尽，游戏结束。连续粉碎目标会获得连击加分和特殊能力充能。

某些关卡有 Boss——巨大的频率波或能量核心，需要持续攻击才能摧毁。Boss 会释放子目标或改变攻击模式。

## 核心循环

观察目标出现 → 快速点击/滑动粉碎 → 获得分数 → 充能特殊能力 → 应对更多目标

## 核心机制

- **快速反应**: 目标出现后需要在限定时间内粉碎，考验反应速度和手眼协调
- **连击系统**: 连续粉碎目标获得倍率加分，中断连击则倍率重置
- **目标多样性**: 不同目标需要不同操作——普通目标单击、装甲目标多次点击、分裂目标需要快速处理碎片
- **特殊能力**: 连击充能后可以释放特殊技能（全屏清除、时间减速、自动攻击）
- **波次递增**: 每波目标数量和速度增加，难度逐步提升

## 为什么好玩

高频次的操作反馈（点击→粉碎→分数跳动）提供了强烈的即时满足感。连击系统的节奏感让游戏像一场手指舞蹈。速度递增带来的压力让每次游戏都充满紧张感。

## 粘性来源

"破纪录"的欲望是核心粘性——每次都想比上次多坚持几秒。连击倍率的正反馈让玩家追求完美操作。特殊能力的充能和释放提供了阶段性目标。

## Meta 系统

能力解锁系统：通过累计分数解锁新的特殊技能。高分排行榜提供全球竞争目标。

## 实现难度

低。核心是目标生成、碰撞检测、点击响应。最大的技术难点是多触控支持和大量目标同时出现时的性能优化。
