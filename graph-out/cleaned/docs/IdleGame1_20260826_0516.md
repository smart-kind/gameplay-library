# Idle Game 1

- **类型**: 放置点击 / 策略
- **平台**: Mobile (iOS)
- **开发商**: Cem Kamiloglu
- **首次发布**: 2020
- **一句话描述**: Idle Game 1是一款专为经验丰富的放置游戏玩家设计的策略点击游戏。核心特色是随机声望加成，每轮给予不同的颜色和提升类型。

## 玩法规则

游戏界面简洁，以颜色系统为核心。屏幕上显示当前的颜色配置、加成倍数和进度信息。玩家通过常规放置游戏的方式积累资源，但核心策略在于如何优化随机声望加成。每轮声望重置时，游戏随机分配颜色和提升类型的加成，玩家需要根据本轮的随机加成制定最优策略。不同的颜色组合可以无限种方式升级，每个玩家的故事都不同。

## 核心循环

积累资源 -> 声望重置获得随机加成 -> 根据加成优化策略 -> 积累更多资源 -> 重复

## 核心机制

- 随机声望加成：每轮不同的颜色和提升类型，策略各不相同
- 颜色系统：不同的颜色组合提供无限的升级可能性
- 速度升级：在颜色速度满后开始影响收益的进阶机制
- 无障碍功能：低对比度模式、触觉振动、防屏幕损伤提醒

## 为什么好玩

大多数放置游戏有固定的最优策略，但Idle Game 1的随机声望系统让每轮都成为新的策略挑战。对经验丰富的放置玩家来说，这种每次都要重新思考的变数正是深度所在。

## 粘性来源

随机声望加成让每轮策略都不同；颜色组合的无限可能性提供深度；触觉振动和音乐播客兼容让游戏融入日常生活

## Meta 系统

有随机声望系统（每轮不同加成）、颜色升级系统（无限组合）、作弊道具（单用途物品帮助推进，非随机可选）。

## 实现难度

中。核心难点在于放置点击玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
