# Quell Reflect（Quell Reflect）

- **类型**: 逻辑解谜 / 禅意益智
- **平台**: Mobile (iOS, Android), Nintendo 3DS, Steam
- **开发商**: Fallen Tree Games（英国）
- **首次发布**: 2011年8月19日
- **一句话描述**: Quell系列第二款作品，一款以雨滴滑动为核心机制的禅意逻辑解谜游戏

## 玩法规则

玩家控制一颗雨滴在封闭的关卡网格中移动。通过手指向上下左右滑动，雨滴会沿选定方向持续滑行，直到撞到墙壁或障碍物才会停下——玩家无法在中途停止雨滴。

关卡中散布着若干金色圆球（golden balls），玩家的目标是让雨滴在滑行过程中触碰所有金色球，同时避免撞入尖刺陷阱或被卡在无法移动的死胡同中。

在基础机制之上，Quell Reflect 引入了多种机关元素：
- **开关**：触碰后改变关卡中的门或其他障碍物的状态
- **可移动方块**：雨滴推动后改变位置，可以打通新路径或阻挡旧路径
- **门/闸门**：可以开启或关闭的障碍物，通常由开关控制
- **单向通道**：只能从特定方向通过的路段

游戏整体节奏舒缓，没有倒计时、没有失败惩罚（除了需要重新开始当前关卡），营造了一种"禅意"的解谜体验。

## 核心循环

观察关卡布局（金色球分布+障碍物位置）→ 规划滑行路线 → 执行滑动 → 调整剩余路径 → 触碰所有金色球通关

## 核心机制

- **滑动到停（Slide-to-Stop）**：雨滴沿方向持续滑行直到撞墙，不能中途停止。这是整个游戏的核心约束，要求玩家提前预判每一步的终点位置。
- **全收集目标**：每个关卡必须触碰所有金色球才能通过，这要求路线设计必须覆盖所有球的位置，而非简单的最短路径。
- **机关互动系统**：开关、方块、门等元素增加了关卡的层次复杂度，某些球需要先激活开关改变地形才能到达。
- **无限重试无惩罚**：失败后可以立即重开，没有次数限制或资源消耗，降低了挫败感，鼓励反复尝试。

## 为什么好玩

Quell Reflect 的吸引力在于它将一个极其简单的操作（四个方向滑动）与精心设计的关卡布局结合，创造出"看起来简单但做起来烧脑"的体验。雨滴滑行的物理直觉让玩家容易上手，但要找到触碰所有金色球的正确顺序和路径则需要真正的逻辑思考。游戏的美术风格简洁优美，配合舒缓的节奏，让人在解谜的同时感到放松。

## 粘性来源

- **逻辑满足感**：每关解开时都有强烈的"啊哈！"时刻，大脑得到即时正反馈
- **低门槛高上限**：操作极简（只需滑动），但关卡复杂度逐步提升
- **禅意体验**：没有倒计时、没有惩罚，玩家可以按自己的节奏思考，适合碎片时间
- **系列连续性**：作为 Quell 系列第二作，玩过初代的玩家自然会想继续体验，而系列后续还有 Quell Memento 和 Quell Zen 等续作

## Meta 系统

无外围成长系统。游戏通过关卡解锁作为进度反馈，没有内购、没有数值成长、没有社交排名，是纯粹的单机解谜体验。

## 实现难度

低 + 核心机制（滑动到停+碰撞检测）实现简单，关卡数据可以用二维网格表示。最大的难点在于关卡设计——如何确保每关都有合理的解法、难度曲线平滑、且不会让玩家觉得"这不可能做到"。需要设计者手动验证每关的可行性。
