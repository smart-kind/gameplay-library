# Make Hexa Puzzle（六边形拼拼乐）

- **类型**: 三消 / 六边形消除 / 益智
- **平台**: Mobile (iOS+Android)
- **开发商**: BitMango, Inc.
- **首次发布**: 2017
- **一句话描述**: 在六边形棋盘上移动色块，将三个或以上相同颜色的相邻色块消除，清空棋盘即可过关。

## 玩法规则

游戏在一个六边形网格棋盘上进行。棋盘上有若干不同颜色的方块，每个方块占据一个六边形格子。玩家的操作是**拖拽色块**——选中一个色块，将其拖拽到相邻的空格中。

当**三个或以上相同颜色的色块相邻连接**时（任意方向，不要求直线），它们会被消除。消除后上方的色块会向下掉落（重力效果），空出的位置由上方的色块填充。

每个关卡有预设的消除目标：例如"消除10个红色方块+15个蓝色方块"或"消除所有方块"。同时有步数限制（通常20-40步），在步数用完前完成目标则过关，否则失败。

部分关卡有障碍物——被锁定的方块需要先消除相邻的同色方块来解锁，特殊道具方块（消除时同时消除同行/同列/周围一圈的色块）可以辅助快速清场。

## 核心循环

观察棋盘 → 拖拽色块使其相邻 → 匹配消除 → 色块掉落形成新组合 → 继续消除直到达成目标或步数耗尽

## 核心机制

- **六边形拓扑连接**：与传统三消的上下左右四方向不同，六边形有6个相邻方向，增加了连接的可能性和策略维度。
- **重力连锁**：消除后上方色块掉落，可能自动形成新的匹配（连锁反应），是获得高分和道具的关键。
- **步数限制**：要求玩家在有限的步数内做出最优决策，每一步都需要考虑"当前消除"和"为后续连锁创造条件"两个层面。
- **道具系统**：消除4个或5个同色方块会生成特殊道具（炸弹、彩虹球等），使用后可以大范围消除，是通关高难度关卡的关键。

## 为什么好玩

Make Hexa 的核心乐趣在于"连锁反应"——一步消除引发一连串自动匹配时的爽快感极强。六边形的拓扑结构让匹配的可能性比传统三消更多，每次棋盘重排都会出现意想不到的新组合。步数限制则给游戏增加了策略深度：你是选择稳妥地消除眼前的同色块，还是冒险尝试制造连锁？

## 粘性来源

- **关卡递进**：数百个精心设计的关卡，每个关卡的目标和布局不同。
- **连锁快感**：触发大型连锁消除时的多巴胺释放是最强的正反馈。
- **步数挑战**：差几步就过关的遗憾感驱动玩家重试。
- **道具收集**：积累和使用强力道具给玩家额外的目标感。

## Meta 系统

- **每日任务和奖励**：完成每日目标获得额外道具和奖励。
- **道具商城**：通过游戏内货币购买辅助道具。
- **关卡进度**：线性解锁关卡，完成一个解锁下一个。

## 实现难度

低到中。核心是六边形网格的匹配检测和重力掉落算法，逻辑清晰。最大难点是连锁反应的稳定计算（避免无限循环）和关卡平衡设计（步数与难度的合理匹配）。
