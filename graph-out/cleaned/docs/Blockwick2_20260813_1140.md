# 方块维克2（Blockwick 2）

- **类型**: 益智解谜 / 色块消除
- **平台**: Mobile (iOS+Android)
- **开发商**: Tactile Games（后为Yodo1 Games）
- **首次发布**: 2015
- **一句话描述**: 一款极简风格的色块消除解谜游戏，玩家通过移动和连接相同颜色的方块来清除棋盘

## 玩法规则

游戏界面是一个由不同颜色方块组成的网格棋盘。玩家点击一个方块后，可以向上下左右滑动来将其推向相邻位置，推动一个方块时，同列/同行的所有方块都会随之移动（类似推箱子但有重力）。

核心消除规则：当相同颜色的方块在移动后相邻连接时，它们会被消除。消除后上方的方块会受重力影响下落填补空位，可能触发新的相邻连接和连锁消除。

每个关卡都有特定的目标：通常是清除所有方块、消除特定颜色的方块、或在限定步数内达到目标分数。关卡设计精巧，随着进程引入新的机制——比如障碍物（不可移动的石块）、特殊方块（消除时触发爆炸）、多色连锁等。

玩家需要在有限的步数内完成目标，这要求每一步移动都要精确规划，考虑当前的消除和后续的连锁可能性。

游戏的视觉设计采用扁平化极简风格——没有复杂的纹理和特效，只有干净的色块和流畅的动画。消除时的动画简洁而有力，方块缩小消失的过程配以清脆的音效。

## 核心循环

观察方块布局和目标要求 → 选择要推动的方块和方向 → 推动后触发消除和连锁反应 → 评估剩余局面 → 在限定步数内完成关卡目标

## 核心机制

- **滑动推动机制**：点击方块后滑动方向决定整列/整行方块的移动，推动一个会影响整排方块的位置，策略性地重新排列整个棋盘。这是游戏的核心操作
- **颜色连接消除**：相同颜色方块相邻连接后消除，下落产生连锁消除。消除不仅仅是视觉反馈，更是推进关卡的核心手段
- **步数限制系统**：每关步数有限，要求玩家在每一步都做出最优决策，增加了策略深度
- **渐进式机制引入**：随着关卡推进，逐步引入障碍物、特殊方块、多色连锁等新元素，保持新鲜感和挑战性

## 为什么好玩

极简美术风格下隐藏着深度的益智玩法。每一步推动都可能引发意想不到的连锁消除，当你规划出一条"一步到位"的完美方案、看到满屏方块连锁消除时带来的成就感极强。关卡设计精巧，越到后期越需要全局思考和多步预判。

## 粘性来源

连锁消除的视觉反馈让人上瘾——满屏同色方块同时消失的画面非常满足。"差一步就能过"的关卡设计促使反复尝试，玩家会在脑海中反复模拟不同推法。每日挑战和渐进式难度曲线保持长期参与。极简美术风格赏心悦目，本身就是一种享受。

## Meta 系统

渐进式关卡解锁系统。通过完成关卡获得星星评价（通常三星制：完成基本目标得1星，在限定步数内完成得2星，用更少步数完成得3星），累积星星解锁新章节和特殊关卡。

## 实现难度

中 — 最大技术难点是连锁反应的模拟计算（推动后的消除→下落→新的消除→再下落...直到稳定）和关卡设计工具链。需要确保每个关卡在限定步数内有解且解的难度符合设计预期。重力系统和碰撞检测也需要精确实现。
