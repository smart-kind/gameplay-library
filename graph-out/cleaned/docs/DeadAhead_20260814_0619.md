# Dead Ahead

- **类型**: 动作 / 生存
- **平台**: Mobile (iOS+Android)
- **开发商**: Mobirate
- **首次发布**: 2013
- **一句话描述**: 一款末日僵尸生存题材的动作游戏，玩家驾驶车辆穿越僵尸横行的世界，收集资源并生存

## 玩法规则

游戏呈现一个横向滚动的末日场景。玩家驾驶一辆改装车辆，在僵尸群中前进。

玩家通过点击屏幕控制车辆上的武器开火。不同武器有不同的射击模式：机枪（快速连射但弹药消耗快）、霰弹（范围伤害但射程短）、火箭（高伤害但装填慢）。

车辆前进时，僵尸从两侧涌来。消灭僵尸获得资源（零件、燃料、弹药）。资源用于升级车辆和武器。

车辆在行驶中会受到损坏，需要收集零件修复。燃料耗尽则游戏结束。目标是在末日世界中尽可能远地行驶，解锁新区域和新武器。

游戏设有Boss战模式，面对特殊的巨型僵尸群。Boss战需要特定武器组合和策略才能通过。

## 核心循环

驾驶车辆消灭僵尸 → 收集资源升级 → 行驶更远距离

## 核心机制

- **武器系统**：多种武器类型，需要平衡弹药消耗
- **资源管理**：零件修复车辆、燃料维持行驶、弹药保持火力
- **车辆升级**：用收集的资源提升车辆性能

- **Boss战**：巨型僵尸群需要特定武器组合

## 为什么好玩

末日生存的紧张氛围配合爽快的射击体验。车辆升级带来的成长感很强。

## 粘性来源

生存游戏的进度粘性：每次行驶更远、车辆更强。资源收集的目标感。

## Meta 系统

车辆升级系统：提升速度、耐久、武器槽位。武器收集：解锁不同武器类型。

## 实现难度

中 — 需要平衡多种资源。最大技术难点是大量僵尸实体的流畅渲染。
