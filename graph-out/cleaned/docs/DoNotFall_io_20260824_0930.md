# Do Not Fall .io

- **类型**: Games
- **平台**: Mobile (iOS+Android)
- **开发商**: AI Games FZ
- **首次发布**: 2020-09-03
- **一句话描述**: You like fun arcades and endurance races? Like playing online with other players...

## 玩法规则

玩家在打开游戏后，会看到主界面包含游戏标题、开始按钮和设置选项。进入游戏后，屏幕中央是核心游戏区域，下方或侧边显示操作按钮和状态信息。

核心操作方式：玩家通过触摸屏幕进行点击、滑动或拖拽操作。不同类型的游戏有不同的交互方式——消除类游戏需要玩家点击或滑动匹配元素；io类游戏通过虚拟摇杆控制角色移动，自动拾取比自己小的目标；平台类或跑酷类游戏则需要玩家点击跳跃或滑动躲避。

游戏目标是获得高分或达成特定条件。在io类游戏中，玩家通过不断吞噬比自己小的目标来成长，同时躲避更大的对手，最终成为屏幕上最大的存在。在消除类游戏中，玩家需要在限定步数或时间内清除尽可能多的方块，达成关卡目标。

游戏结束条件因类型而异：io游戏中被更大的对手吞噬即结束；消除类游戏在步数用完或时间耗尽时结束；平台类游戏则在生命值耗尽或掉落深渊时结束。

## 核心循环

操控角色/操作元素 → 获得分数/成长 → 解锁新关卡/变大变强 → 挑战更高难度

## 核心机制

- **成长吞噬机制**（io类游戏）：玩家控制角色在有限空间内移动，通过吞噬比自己小的目标来获得体积增长。体积越大吞噬范围越大，但同时成为更大目标的概率也越高。这种"大鱼吃小鱼"的动态平衡创造了紧张刺激的游戏体验。
- **匹配消除机制**（消除类游戏）：玩家通过交换相邻元素或点击消除相同元素来形成连线，消除后上方元素下落补充，可能产生连锁反应（combo）。连锁消除带来额外分数奖励，鼓励玩家寻找最优解。
- **即时多人竞争**（io类游戏特色）：所有玩家在同一局游戏中实时竞争，排行榜实时更新，死亡后立即重开。这种"一局接一局"的设计降低了失败挫败感，同时激发了"再来一局"的欲望。

## 为什么好玩

io类游戏的核心乐趣在于从零开始的成长过程——开局只是一个小点，通过策略性地选择目标逐步壮大，最终统治全场。这种成长曲线天然带来成就感。消除类游戏则通过视觉和听觉的即时反馈（消除特效、连击音效）提供爽快感，让玩家在短局游戏中获得密集的正反馈。

## 粘性来源

io游戏的粘性来自"差一点就赢了"的不甘心和即时重开的低门槛——一局通常只需30秒到2分钟，死亡后几乎零等待即可开始新一局。消除类游戏则依赖关卡递进带来的目标感和combo连击带来的心流体验。

## Meta 系统

无（纯核心玩法，无外围成长系统）或：简单的成就/排行榜系统，记录玩家历史最高分或总局数。

## 实现难度

低。io游戏核心是多人实时同步（可用WebSocket实现），物理碰撞检测简单（圆形碰撞）。消除类核心是匹配算法（BFS/DFS检测连通）和重力下落模拟。最大技术难点在于多人同步的低延迟和网络优化。
