# 反向弹幕射击，自动攻击+走位躲避海量敌人（Vampire Survivors）

- **类型**: Roguelike/弹幕射击
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: poncle
- **首次发布**: 2022
- **一句话描述**: 反向弹幕射击，自动攻击+走位躲避海量敌人

## 玩法规则

玩家控制角色在开放区域移动，武器自动攻击。目标是存活30分钟（标准模式）。

敌人如潮水般涌来，数量和种类随时间增加。击杀敌人获得经验宝石，升级时选择新武器或升级现有武器。

可以组合多个武器进化为终极形态。游戏结束后用金币解锁新角色、新武器和新地图。

## 核心循环

走位躲避 → 自动攻击击杀 → 获得经验 → 升级选武器 → 存活到时间结束

## 核心机制

- 自动攻击：武器自动瞄准，玩家只需走位
- 升级选择：每次升级从3-4个选项中选择
- 武器进化：特定武器+特定被动技能=终极武器
- 海量敌人：屏幕同时存在数百个敌人

## 为什么好玩

从被几百个敌人追赶的绝望到满屏特效秒杀一切的快感，成长感极强。

## 粘性来源

武器组合的无限可能；解锁新角色的收集欲；再试一次就通关的不甘心。

## Meta 系统

角色和武器解锁系统。

## 实现难度

低。只需控制移动，但需要了解武器组合。最大技术难点：同时渲染数百个敌人的性能优化。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
