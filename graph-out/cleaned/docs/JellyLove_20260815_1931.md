# Jelly Love

- **类型**: 物理益智 / 配对消除
- **平台**: Mobile (iOS + Android)
- **开发商**: Wooga
- **首次发布**: 2012
- **一句话描述**: 在有限的步数内，通过物理连接让相同颜色的果冻相互接触并消除。

## 玩法规则

游戏画面为一个被围栏包围的区域，里面散布着各种颜色的果冻（Jelly）。这些果冻受到重力影响，会向下落并堆积在底部。

操作方式：
- **画线/连接**：玩家用手指在屏幕上画线，连接两个相邻的果冻。连接线形成物理约束，让被连接的果冻可以一起移动。
- **切割**：部分关卡支持切割操作，将连接线或障碍切断。
- **物理互动**：连接后的果冻组作为一个整体受到物理影响（重力、碰撞），玩家可以利用这一点让不同位置的果冻相互接触。

游戏目标：让相同颜色的果冻相互接触，接触后它们会合并并消除。每个关卡有步数限制（或连接次数限制），需要在限制步数内消除所有果冻（或达到目标分数）。

某些关卡有障碍物：不可移动的墙壁、不同颜色的隔离物、特殊的特殊果冻等。后续关卡引入更多复杂元素。

## 核心循环

观察果冻布局 → 规划连接方案 → 执行连接 → 触发消除 → 在步数用完前完成目标

## 核心机制

- **物理约束连接**：核心机制是用画线将果冻连接起来，形成物理上联动的组。连接后，重力、碰撞等物理力同时作用于整个果冻组，玩家需要预判连接后的物理结果。
- **颜色配对消除**：同色果冻接触后消除，这是经典配对逻辑与物理引擎的结合。
- **步数限制**：每个关卡限制操作次数，迫使玩家思考最优方案而非随机尝试。
- **连锁反应**：一次消除可能改变下方果冻的布局，引发连锁消除，这是获取高分的关键。

## 为什么好玩

Jelly Love 的独特之处在于它将"配对消除"和"物理模拟"结合在一起。你不是简单点击相同颜色来消除，而是需要思考"怎么让这些果冻碰到一起"。物理引擎让每次连接都有不可完全预测的结果，增加了探索乐趣。果冻Q弹的动画和音效也让整个游戏体验更加愉悦。

## 粘性来源

- **物理随机性**：每次连接后的物理结果可能略有不同，鼓励反复尝试找到最优方案。
- **连锁消除的爽感**：看到一次操作触发一连串消除的满足感。
- **关卡递增难度**：后续关卡的布局越来越精巧，解谜感更强。

## Meta 系统

无 — 独立关卡制。

## 实现难度

**中** — 物理引擎是核心，需要处理大量软体（果冻）的碰撞、变形和约束计算。最大技术难点在于物理模拟的稳定性——连接多个果冻后的物理计算可能出现不稳定（抖动、穿模）。
