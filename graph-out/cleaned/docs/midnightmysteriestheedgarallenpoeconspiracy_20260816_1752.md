# Midnight Mysteries: The Edgar Allen Poe Conspiracy（午夜谜案：埃德加·爱伦·坡阴谋）

- **类型**: 冒险 / 寻物解谜
- **平台**: Nintendo DS
- **开发商**: MumboJumbo
- **首次发布**: 2011
- **一句话描述**: 一款以埃德加·爱伦·坡的真实死亡之谜为主题的寻物解谜冒险游戏，由坡的鬼魂引导玩家探索诡异场景、寻找线索并揭开谜团。

## 玩法规则

游戏以 19 世纪美国作家埃德加·爱伦·坡的真实死亡之谜为背景。历史上坡的死因至今仍是个谜团，游戏以此为起点展开虚构的冒险故事。

玩家由坡的鬼魂引导，在各种诡异的场景中进行探索。每个场景是一个充满物品和线索的画面——典型的寻物解谜（Hidden Object）布局。

核心操作流程：在当前场景中找到隐藏的物品和线索 → 用找到的物品打开新的通道或解锁下一个场景 → 进入新场景继续寻找 → 逐步收集足够线索来揭开坡死亡之谜的真相。

每个场景中的物品需要仔细观察才能找到——它们巧妙地融入场景背景中。找到的物品不仅仅是收集品，而是推进剧情的关键：一把钥匙可能打开一扇门，一份文件可能揭示一段线索。

场景设计偏向恐怖/诡异风格，符合爱伦·坡作品的哥特式氛围。玩家需要在这些阴森的环境中找到线索，解开一个又一个谜题来推进调查。

评测指出，虽然题材本身充满悬念和吸引力（爱伦·坡之死的确是个引人入胜的真实谜团），但游戏的实际玩法单调乏味，场景缺乏变化，最终会让玩家失去继续探索的动力。

## 核心循环

在诡异场景中寻找隐藏物品 → 用物品解锁新区域或解开谜题 → 收集线索推进调查 → 逐步揭开坡死亡之谜

## 核心机制

- **寻物解谜**：在哥特式场景中寻找隐藏物品，物品融入背景需要仔细观察
- **鬼魂引导叙事**：坡的鬼魂作为向导，通过线索讲述故事和提供指引
- **道具解锁**：找到的物品用于打开新通道或解锁后续场景
- **线索收集**：通过收集到的线索逐步拼凑出坡死亡之谜的真相

## 为什么好玩

题材本身极具吸引力——埃德加·爱伦·坡的真实死亡之谜是一个世纪级的悬疑故事。哥特式场景和爱伦·坡作品的文学氛围也为游戏增添了独特的调性。但评测认为玩法本身过于单调，无法支撑起这个好题材。

## 粘性来源

对爱伦·坡之谜的好奇心和叙事驱动——玩家想知道真相；哥特式恐怖氛围的沉浸感。但粘性因单调的玩法而被削弱。

## Meta 系统

无。线性叙事驱动的冒险游戏。

## 实现难度

低 — 寻物游戏技术成熟。最大难点是场景美术设计（需要大量高质量的哥特式场景）和谜题/线索的逻辑设计，确保叙事连贯且谜题有趣。
