# 吃豆人狂热（Pac-Mania）

- **类型**: 街机/平台跳跃/迷宫
- **平台**: 街机 / Mobile (iOS+Android) / 多平台复刻
- **开发商**: Namco
- **首次发布**: 1987
- **一句话描述**: 吃豆人的等距视角进化版，增加了跳跃能力和多层迷宫结构，保留了经典的吃豆和躲避幽灵玩法

## 玩法规则

游戏在等距视角的三层迷宫中进行，相比原版的平面迷宫，增加了垂直维度。玩家控制吃豆人在迷宫中移动，吃掉所有豆子即可过关。

核心新增操作是跳跃。吃豆人可以向上跳跃，这带来了两种用途：一是跳过一些障碍物或地面上的幽灵来逃脱危险；二是跳到更高的楼层继续探索。跳跃高度有限，无法跳过某些较高的障碍。

迷宫的三层结构通过楼梯连接。楼梯有单向和双向之分——单向楼梯只能从一侧上到另一侧，可以作为逃生手段（幽灵如果追到楼梯口但方向不对就无法跟上）。玩家需要记住迷宫的楼梯布局，在紧急情况下快速找到逃生路线。

幽灵的行为模式与原版相似但有进化。四种基本幽灵（Blinky、Pinky、Inky、Sue）保留原有行为特征，但新增了可以在层间移动的幽灵。部分关卡还有特殊Boss幽灵，需要特定方式才能消灭。

能量豆的效果与原版相同——吃掉后幽灵变蓝可被反杀。但由于多层迷宫的存在，能量豆的分布更加分散，玩家需要规划路线来高效收集。

## 核心循环

吃迷宫中的豆子 → 跳跃跨越障碍 → 在多层间移动 → 躲避或反杀幽灵 → 清空迷宫过关

## 核心机制

- **跳跃系统**：新增的跳跃能力改变了移动方式。既可以用来逃脱幽灵的追逐（跳过它们），也可以用来到达更高层的迷宫。跳跃时机和高度判断是需要练习的技巧
- **多层迷宫结构**：三层迷宫通过楼梯连接，大幅增加了空间复杂度。玩家需要同时关注同层和上下层的威胁。楼梯的单向设计增加了策略性——可以引诱幽灵进入死胡同
- **经典幽灵AI进化**：保留了原版四种幽灵的行为模式，但新增了可以在层间移动的类型。部分特殊幽灵有独特的行为模式，增加了追逐的不可预测性
- **等距视角呈现**：等距视角让多层迷宫的立体结构一目了然，玩家可以看到上下层的布局。这种视角选择让空间关系更清晰，但也带来了新的挑战

## 为什么好玩

在经典吃豆玩法基础上增加了跳跃和多层迷宫，让熟悉的老玩家有新鲜感。等距视角带来独特的视觉体验，看着吃豆人在三层迷宫中穿梭很有趣。跳跃操作增加了动作游戏的爽快感——成功跳过幽灵的瞬间很有成就感。

## 粘性来源

经典IP的延续提供熟悉感和情怀、跳跃操作的新鲜感增加操作深度、多层迷宫的策略性让每次探索都有新发现、熟悉玩法的舒适感降低学习门槛、分数挑战的驱动力延续原版传统

## Meta 系统

关卡推进系统——完成当前迷宫解锁新迷宫，每个迷宫有不同布局和难度；分数排行榜系统延续原版传统；部分版本包含生命系统，给予多次尝试机会

## 实现难度

低 — 操作直观（移动+跳跃），经典吃豆玩法的延续让老玩家快速上手。最大的技术难点在于多层迷宫的空间关系呈现——等距视角需要精心调整以确保玩家能清楚理解上下层关系
