# 地狱边境（Limbo）

- **类型**: 解谜 / 平台跳跃 / 恐怖
- **平台**: PC / Mac / PS / Xbox / Switch / iOS / Android
- **开发商**: Playdead
- **首次发布**: 2010
- **一句话描述**: 一款黑白风格的横版解谜平台游戏，玩家扮演一个小男孩在充满危险的地狱边境中寻找失踪的姐姐。

## 玩法规则

玩家在黑白风格的2D横版场景中操控一个小男孩，画面只有黑色剪影和灰色背景，营造出诡异压抑的氛围。
操作极简：左右移动、跳跃、推动/拉动物品。没有攻击按钮，没有生命值条。
游戏的核心体验是'试错式解谜'——玩家在未知危险中前进，可能会突然死亡，然后从检查点重生。
谜题类型包括：物理谜题（推箱子压机关、利用重力摆动物体）、环境谜题（利用灯光驱赶蜘蛛、用电磁铁吸附金属物体）、timing谜题（在旋转齿轮间穿梭、躲避坠落物）。
游戏目标是穿越危险的区域，最终找到姐姐。没有明确的任务提示，方向感来自于场景的自然引导。
死亡是游戏设计的一部分，每次死亡都以剪影动画呈现，然后回到最近检查点。
游戏后半段进入工业化区域，出现更多机械机关和巨型陷阱，难度逐步提升。

## 核心循环

探索前进 → 遭遇危险死亡 → 学习机关规律 → 找到正确解法 → 推进下一区域

## 核心机制

- **试错式死亡学习**：死亡不是失败而是学习工具。玩家通过死亡了解机关的危险模式和触发条件，然后在下次尝试中避免。
- **黑白剪影美学**：极简的视觉风格——前景纯黑剪影、灰色迷雾背景、偶尔出现的白色光源。危险和机关在视觉上极为醒目。
- **无UI设计**：全程没有HUD、没有生命值、没有背包栏、没有教程文字。所有信息都通过环境和角色动作传达。
- **环境叙事**：没有对话和旁白，剧情完全通过场景中的视觉元素暗示——远处的姐姐身影、废弃的工厂、诡异的陷阱。

## 为什么好玩

黑白剪影美学与死亡学习机制的独特结合，让每次死亡都变成'啊原来如此'的顿悟时刻。探索未知的紧张感与解开谜题的释然形成强烈对比。

## 粘性来源

'差一点就过去了'的不甘心驱动反复尝试；每次死亡后快速重生的节奏让人'再来一次'；最终找到正确解法的顿悟快感极强。

## Meta 系统

无。纯单机体验。

## 实现难度

中 — 横版平台跳跃是成熟技术，但精准的死亡判定和流畅的检查点系统需要大量测试。最大技术难点在于机关时序设计和物理引擎的稳定性。
