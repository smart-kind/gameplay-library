# 椰子闪避（Coconut Dodge）

- **类型**: 休闲 / 动作
- **平台**: Mobile (iOS)
- **开发商**: Rovio（愤怒的小鸟开发商早期作品）
- **首次发布**: 2010
- **一句话描述**: 由 Rovio 制作的休闲游戏，控制小螃蟹在沙滩上躲避掉落椰子并收集金币

## 玩法规则

游戏采用横向卷轴的海滩场景。玩家控制一只小螃蟹在沙滩上左右移动。椰子从屏幕顶部的椰子树上不断掉落，砸向沙滩。玩家需要左右移动来避开椰子的落点。

同时，沙滩上散落着金币和各种收集品，玩家需要在躲避椰子的同时尽可能多地收集它们。被椰子击中会扣血或减少生命值，生命值归零则游戏结束。

随着关卡推进，椰子掉落频率增加、掉落速度加快，可能出现特殊椰子（更大、更快或带有爆炸效果），金币数量增加但分布更分散。游戏有多个关卡和区域，每个区域有独特的背景主题和椰子掉落模式。

关卡主题包括：热带海滩（基础椰子掉落）、热带丛林（椰子从不同高度和角度掉落，增加预判难度）、海盗船甲板（移动平台增加了落点不确定性）、度假村泳池边（椰子掉落在光滑瓷砖上会弹跳，改变物理规律）。每个主题有 5-10 个关卡，难度逐步递增。

部分关卡有特殊目标：收集特定数量的金币、在不被击中的情况下通过关卡、在限定时间内完成等。这些特殊目标增加了关卡的多样性。

## 核心循环

左右移动躲避椰子 → 收集金币 → 完成关卡目标 → 进入下一关

## 核心机制

- **躲避与收集的双重目标**：玩家需要在"保命"（躲避椰子）和"得分"（收集金币）之间找到平衡。过于保守只能活命但得分低，过于贪婪收集金币容易被击中。这种风险/回报权衡是游戏的核心乐趣。
- **掉落模式记忆**：椰子掉落并非完全随机，某些模式会重复出现。记住这些模式可以帮助玩家预判落点。随着关卡推进，模式变得更复杂，需要更快的反应速度。
- **节奏递增**：随着关卡推进，椰子越来越密集，玩家需要越来越快的反应速度。这是典型的街机难度曲线，让玩家在"几乎能应付"和"完全失控"之间找到刺激点。
- **角色能力**：部分版本有角色升级——更快的移动速度、额外的生命值、短暂的无敌时间等，让玩家有成长感。

## 为什么好玩

Coconut Dodge 的核心循环极其简单——左右移动躲椰子——但正是这种简单让它容易上瘾。金币收集的诱惑和椰子威胁的压迫感创造了完美的"再试一次"心理。作为 Rovio 愤怒的小鸟之前的作品，展示了 Rovio 对休闲游戏节奏的把握。

## 粘性来源

- **风险/回报**：收集更多金币意味着冒更大风险，这种紧张感让人欲罢不能
- **短局快玩**：一局几分钟，随时可以开始
- **高分挑战**：每个关卡都有分数目标，鼓励反复尝试
- **Rovio 品质**：作为愤怒的小鸟同开发商的作品，品质有保障

## Meta 系统

金币用于解锁新关卡和新角色。无社交或付费系统，纯休闲体验。

## 实现难度

低 — 操作只有左右移动，门槛极低。最大技术难点是椰子掉落的随机性控制和碰撞检测的流畅度。
