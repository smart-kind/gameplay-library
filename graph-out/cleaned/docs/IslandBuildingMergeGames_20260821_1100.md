# 小岛建造：合并游戏（Island Building : Merge Games）

- **类型**: 合并 / 放置点击 / 模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: byss mobile
- **首次发布**: 2018
- **一句话描述**: 一款以"美国梦"为主题的合并放置游戏，通过合并电脑挖矿赚取金币，购买私人岛屿和海滨度假村，实现从平凡到亿万富翁的蜕变。

## 玩法规则

游戏画面分为两个主要区域：上方是玩家的"资产展示"（岛屿、豪宅、游艇等已购买的物品），下方是合并操作区（电脑农场）。

合并操作区中分布着多个电脑图标，从低端到高端不等。玩家点击相同等级的两个电脑，它们合并为一台更高级的电脑。高级电脑每秒钟自动产生更多的金币。

金币自动累积，玩家可以用来购买更高级的电脑、升级现有电脑、雇佣经理和顾问来加速收入。随着收入增加，玩家逐步解锁购买更大的物品：更好的汽车、更大的房子、超级游艇、直升机甚至私人飞机。

海滨度假村是游戏的第二阶段目标。玩家用赚取的金币购买和升级各种商业设施：赌场、披萨店、潜水学校、餐厅、冰淇淋店、码头、码头和五星级酒店等。每个设施都会产生被动收入。

## 核心循环

合并升级电脑 → 自动赚取金币 → 购买更大资产/解锁度假村设施 → 持续扩大产业规模

## 核心机制

- **合并+放置混合玩法**：核心操作是合并电脑来升级，升级后的电脑自动产生收入。这结合了合并游戏的策略性和放置游戏的轻松感——玩家可以随时回来收集金币，也可以持续在线手动合并。
- **资产升级阶梯**：从一台小电脑到超级游艇，游戏设计了极其宽泛的物品升级链。每个新物品的解锁都是一次视觉和成就感的双重奖励。
- **经理顾问系统**：雇佣经理和顾问可以倍增收入。这为游戏添加了策略维度——玩家需要在购买新资产和投资收入倍增之间做出权衡。
- **海滨度假村经营**：购买各种商业设施后，它们会自动产生金币收入。这为玩家提供了"即使不在线也在赚钱"的放置体验，增加了游戏的粘性。

## 为什么好玩

"从一无所有到亿万富翁"的叙事弧线本身就有很强的吸引力。看着自己的资产从小电脑一步步扩展到私人岛屿和五星级酒店，这种视觉上的成长反馈非常满足。合并操作的简单性让任何人都能立刻上手，而放置收入系统让游戏可以长时间运行而无需持续操作。

## 粘性来源

资产解锁是核心粘性来源——每个新物品的购买都是一次小的里程碑，而"下一个更大的东西就在眼前"的感觉让人停不下来。被动收入系统（经理倍增、度假村设施自动赚钱）让玩家即使离线也在"进步"，回归时看到金币堆积的爽感也驱动持续游玩。

## Meta 系统

游戏包含VIP订阅系统（每周$4.99，首3天免费），提供去广告和额外奖励。核心游戏进度完全免费可获得，VIP是可选的加速选项。无强制付费点。

## 实现难度

低。合并逻辑和放置收入计算都是成熟的技术方案。最大的技术难点在于大量资产的视觉呈现和数值平衡——需要确保从第一台电脑到私人飞机的每个阶段都有合理的进度节奏，既不让人等得太久也不让进度太快失去挑战感。
