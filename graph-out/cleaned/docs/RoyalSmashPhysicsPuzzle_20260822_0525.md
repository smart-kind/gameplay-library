# Royal Smash!（Royal Smash! - Physics Puzzle）

- **类型**: 物理弹射解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Lion Studios / Casual Games Studio
- **首次发布**: 2020
- **一句话描述**: 通过发射炮弹来击倒堆叠塔楼的物理弹射解谜游戏，追求一击全倒的极致爽快感。

## 玩法规则

游戏画面呈现一系列堆叠的物品塔——木桶、板条箱、果酱罐、干草捆、水果蔬菜等各种物品按物理规律堆叠而成。玩家通过拖拽瞄准线来设定炮弹的发射角度和力度，松手后炮弹沿弹道飞出，撞击物品塔并引发连锁倒塌。

每个关卡的目标是清除桌面上的所有物品（或达到特定清除百分比）。玩家有有限的炮弹数量（通常1-3发），需要在最少炮弹数内完成清除。物品的堆叠方式经过精心设计——有的平衡脆弱、有的底部沉重、有的顶部松散——每种结构需要不同的攻击策略。

游戏采用物理引擎模拟物品的倒塌过程：被击中的物品会飞散，上方的物品失去支撑会下落，相邻物品会被挤压弹开。这种连锁反应是游戏的核心乐趣——一发射击引发整塔崩塌的视觉和听觉反馈极其满足。

## 核心循环

瞄准发射 → 观察倒塌 → 评估结果 → 调整策略再次射击

## 核心机制

- **物理弹道射击**：玩家拖动瞄准线设定角度和力度，炮弹按照物理抛物线飞行。需要考虑重力下坠、物品碰撞、反弹效果等因素。不同关卡可能需要直射、高抛、侧击等不同策略。
- **堆叠结构弱点分析**：每种堆叠方式都有其结构弱点——有些塔需要击倒底部支柱让整体塌陷，有些需要从侧面推倒利用惯性。识别并击中"关键支撑点"是高效通关的核心技能。
- **连锁反应评分**：单次射击引发的倒塌范围越大，评分越高。游戏鼓励玩家寻找"一击全倒"的完美方案，而非逐层清理。
- **有限资源约束**：有限的炮弹数量迫使玩家认真规划每次射击，增加了策略深度。

## 为什么好玩

"看一塔东西轰然倒塌"本身就是一种原始快感。游戏将这种快感包装成解谜挑战——不是随便打，而是找到那个最关键的点，用一发炮弹引发最大规模的崩塌。当完美的一击让整座塔像多米诺一样倒下时，满足感爆棚。操作简单（拖拽瞄准+松手）但精通困难，适合各种玩家。

- **主题变化**：游戏按主题分组关卡（农场、厨房、工地等），每个主题有不同的物品类型和视觉效果，保持新鲜感。
- **道具系统**：部分关卡提供特殊炮弹（如爆炸弹、穿透弹）作为限时道具，改变标准玩法并提供通关捷径。

## 粘性来源

- **一击全倒的完美主义追求**：每次射击后看到"差一点就全倒"的结果，会本能地想"换个角度再来一次"
- **结构多样性的新鲜感**：数百个关卡的物品组合和堆叠方式各不相同，从简单的单塔到复杂的多塔联动，每关都是新的物理谜题
- **即时满足反馈**：每次射击都有视觉（物品飞散）、听觉（碰撞音效）和数值（评分）三重反馈，形成强烈的即时满足循环

## Meta 系统

- **关卡进度系统**：线性关卡解锁，完成一关解锁下一关。部分关卡组设有主题（如农场主题、厨房主题等）。
- **星级评价**：根据清除效率和炮弹使用量评定星级，三星为完美通关。
- **装饰收集**：部分版本包含通过通关获得的装饰物品，用于自定义游戏界面。

## 实现难度

低到中。物理弹道和刚体碰撞在现代游戏引擎中是标准功能。最大难点在于关卡设计——需要手工设计数百种不同的堆叠结构，确保每种既有解又有趣。需要大量测试来验证每个关卡的物理行为在不同设备上的表现一致性。
