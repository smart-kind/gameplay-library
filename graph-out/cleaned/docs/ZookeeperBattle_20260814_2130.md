# Zookeeper Battle（Zookeeper Battle）

- **类型**: 益智 / 三消 / 竞速对战
- **平台**: Mobile (iOS+Android)
- **开发商**: Nexon
- **首次发布**: 2013
- **一句话描述**: 竞速版动物主题三消游戏，两个玩家同时消除相同动物，谁先完成目标谁就获胜。

## 玩法规则

游戏画面分为上下两个部分（或左右分屏），上方是自己的游戏区域，下方是对手的区域（在本地对战中可见）。游戏棋盘是一个6×6或8×8的网格，每个格子中有一种动物图案（狮子、大象、猴子等）。

玩家通过滑动手指连接相邻的相同动物（至少3个相连）来消除它们。消除的动物被"收集"进自己的动物园，当某种动物的收集数量达到目标值（如10只狮子）时，该种类即被"捕获"。

游戏的目标是在对手之前捕获目标数量的动物种类。通常是先捕获5种不同动物的玩家获胜。消除速度越快，收集效率越高，同时给对手施加的压力也越大。

棋盘上的动物分布是随机的，但系统保证总有可消除的组合。当某个区域没有可消除的组合时，系统会自动调整棋盘布局以维持游戏的可玩性。

## 核心循环

滑动连接相同动物 → 消除并收集 → 达成收集目标 → 比对手更快完成所有目标种类

## 核心机制

- **竞速三消**：与传统三消不同，不是追求最高分数，而是在有限时间内比对手更快完成目标，节奏紧张刺激
- **压力传递系统**：快速消除会给对手的棋盘增加干扰（如额外方块或锁定的格子），形成间接对抗
- **动物收集目标**：每局随机指定需要收集的种类和数量，增加策略性——玩家需要判断优先收集哪种动物

## 为什么好玩

将三消这种休闲玩法注入了强烈的竞争感，看着对手进度条的同时加快自己消除速度的紧张感非常上瘾。

## 粘性来源

具体到机制层面：竞速带来的肾上腺素刺激是核心粘性——"就差一只就赢了"的紧迫感驱动再来一局。同时每局随机化的动物目标和棋盘布局确保不会有重复体验，配合"差一点就赢"的不甘心感，形成强烈的重玩欲望。

## Meta 系统

- **玩家等级系统**：根据胜负记录提升等级
- **动物图鉴收集**：长期收集各种出现的动物类型
- **对核心玩法的影响**：轻度影响，主要为进度展示

## 实现难度

中等——需要实时同步两个玩家的状态（在线对战时），同时消除逻辑和压力传递算法需要精细平衡。最大的技术难点是网络对战中的状态同步和延迟处理，确保两个玩家的体验公平一致。
