# 极简的城市建造沙盒，点击生成可爱小镇（Townscaper）

- **类型**: 创造
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: Oskar Stalberg
- **首次发布**: 2020
- **一句话描述**: 极简的城市建造沙盒，点击生成可爱小镇

## 玩法规则

玩家在一个海上网格中点击放置彩色方块，系统会自动根据周围方块生成建筑（房屋、拱门、楼梯、阳台等）。没有目标、没有计分、没有失败条件，纯粹享受建造过程。每个点击都会根据上下文智能生成相应的建筑结构。

## 核心循环

点击放置方块 → 自动生成建筑 → 继续建造 → 创造美丽小镇

## 核心机制

- 智能生成：根据周围方块自动生成建筑结构
- 色彩系统：不同颜色代表不同建筑元素
- 无目标设计：无计分、无失败、无压力
- 上下水系统：水上和水下有不同的建筑表现

## 为什么好玩

点击即生成精美建筑的满足感。没有压力的纯粹创造体验。

## 粘性来源

创造的满足感；截图分享。

## Meta 系统

无

## 实现难度

低。点击放置极简。最大技术难点：智能建筑生成算法。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手
