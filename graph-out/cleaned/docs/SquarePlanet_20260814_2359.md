# Square Planet

- **类型**: 解谜/益智
- **平台**: Mobile (iOS)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款在球形表面上进行的创意解谜游戏

## 玩法规则

游戏画面是一个球体表面，玩家控制一个方形角色在球面上移动。点击改变角色的运动方向，让角色到达目标位置。

球面特性让移动方向会不断变化，增加了空间思维的挑战。某些关卡有障碍物、传送门和机关。需要理解球面几何才能找到正确路径。

画面采用极简的几何风格，球体和方块的设计简洁但富有创意。界面简洁，主要是球体场景。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

操控方块在球面上到达目标 → 通关解锁新关卡 → 面对更复杂的球面谜题

## 核心机制

- 球面移动：角色在球体表面移动，方向感与传统平面不同
- 机关互动：传送门、障碍、移动平台等增加挑战
- 空间思维：需要理解球面几何来规划路径

## 为什么好玩

独特的球面概念让人耳目一新，解谜过程需要转换思维角度。

## 粘性来源

关卡递进和空间思维挑战。
