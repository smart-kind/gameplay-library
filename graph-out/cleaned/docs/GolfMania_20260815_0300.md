# 高尔夫狂热（Golf Mania）

- **类型**: 体育 / 迷你高尔夫 / 物理益智
- **平台**: Mobile (iOS+Android)
- **开发商**: Tivola / 独立开发者
- **首次发布**: 2015
- **一句话描述**: 用手指拉动高尔夫球控制力度和方向，在各种趣味地形中以最少的杆数将球打入洞中的休闲体育游戏。

## 玩法规则

游戏采用俯视或斜45度视角，画面中显示球道、球洞和障碍物。玩家通过拖拽高尔夫球来瞄准——拖拽方向决定击球方向，拖拽距离决定力度，松开手指后球沿设定方向飞出。

球在草地上滚动时会受到摩擦力逐渐减速，遇到斜坡会加速或减速，撞到墙壁会反弹，掉入沙坑会减速，碰到水障碍则直接罚杆。球洞周围有引力效果——靠近球洞时球会被轻微吸引。

每个关卡有"标准杆"设定（如标准杆3杆），玩家需要在标准杆内或以下将球打入洞中获得好成绩。1杆进洞（hole in one）是最高成就。关卡评价系统：低于标准杆为"小鸟球"（birdie），等于标准杆为"平标准杆"（par），高于标准杆为"柏忌"（bogey）。

关卡中设有各种障碍：墙壁（反弹）、沙坑（减速）、水塘（罚杆）、风扇（改变球的方向）、传送门（传送到另一位置）、斜坡（改变球的轨迹）等。高级关卡需要利用障碍物的特性——比如利用墙壁反弹绕过障碍物，利用风扇改变方向到达球洞。

## 核心循环

规划击球路线 → 拖拽瞄准击球 → 观察球的滚动轨迹 → 继续击球直至入洞 → 挑战下一关

## 核心机制

- **拖拽瞄准**：拉弓射箭式的操作方式，方向+力度一体化控制
- **物理模拟**：球的滚动受摩擦力、重力、弹力等物理规律影响
- **地形交互**：不同地形对球有不同的影响，需要理解并利用这些特性
- **反弹利用**：利用墙壁反弹可以绕过障碍物或改变球的方向
- **杆数评价**：标准杆系统提供明确的成绩目标和评价标准

## 为什么好玩

Golf Mania将高尔夫运动的精髓浓缩为简单的拖拽操作。"拉弓→瞄准→松手"的操作直观易懂，但要做到精准命中需要大量练习。利用墙壁反弹一击入洞的瞬间、1杆进洞时的狂喜、球在洞口边缘擦过的遗憾——这些情绪体验构成了游戏的核心吸引力。每个关卡像一个小谜题，需要思考最佳击球路线。

## 粘性来源

- **精准击球的成就感**：一杆进洞的快感无可替代
- **路线规划**：每个关卡都是一道空间推理谜题
- **杆数挑战**：追求更少的杆数，不断挑战自我
- **创意解法**：利用障碍物特性找到非传统的击球路线

## Meta 系统

关卡解锁系统——完成当前章节解锁下一章节。部分版本包含皮肤系统（不同颜色的高尔夫球、球杆、球道主题）和每日挑战。

## 实现难度

低 — 2D物理球类运动模拟。最大技术难点在于"物理手感"的调优——球的摩擦力、弹性、旋转等参数的微调决定了操作是否真实流畅。反弹计算和碰撞检测需要精确。关卡设计的难度曲线控制也很关键。
