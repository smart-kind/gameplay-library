# SongRush

- **类型**: 音乐 / 跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: Playdots / Playdom
- **首次发布**: 2014
- **一句话描述**: 根据你上传的音乐自动生成关卡，在节奏中左右滑动躲避障碍物的音乐跑酷游戏

## 玩法规则

游戏采用自动向前奔跑的视角，玩家操控角色在关卡中奔跑。障碍物由游戏中的音乐自动生成——不同的歌曲会生成完全不同布局的关卡。

操作非常简洁：点击屏幕左侧滑动躲避，点击屏幕右侧跳跃躲避。碰到障碍物会减速，碰到太多就会被关底追逐的触手抓住，游戏结束。

如果在即将撞上障碍物的瞬间操作（并且与播放中的音乐节奏合拍），角色会加速并向屏幕中央靠拢。越靠近屏幕中央得分越高，连续 Near-miss（险些擦过）可以形成连击加成。

游戏自带几首歌曲，通关后可以上传自己的音乐。上传一首歌大约需要 30 秒，上传后系统会根据歌曲特性评定难度等级。

每次跑图需要消耗一个 Token（代币），初始只有两个 Token。跑图过程中收集的音符可以用来购买更多 Token，但通常赚的不够花。

## 核心循环

选择/上传音乐 → 根据节拍躲避障碍 → 收集音符 → 购买 Token → 再次跑图

## 核心机制

- **音乐生成关卡**：每首歌的波形/节拍数据转化为障碍物布局，同一首歌每次生成相同的关卡，但不同歌曲带来完全不同的体验
- **精准时机系统**：在障碍物前瞬间操作+合拍 = 加速+靠近中央+高分，鼓励玩家追求完美时机
- **Token 消耗制**：每次跑图消耗 Token，通过收集音符购买，限制无限制游玩

## 为什么好玩

用自己喜欢的音乐来生成关卡是核心卖点——"跑我自己的 BGM"这个概念本身就很酷。不同的音乐风格会产生完全不同的关卡布局：电子乐可能生成密集的障碍矩阵，慢歌则生成稀疏的障碍加空地。精准时机的操作反馈（加速+靠近中央）也提供了"技术感"的满足。但评测指出障碍物种类只有 6-7 种，背景画面不变，重复感较强。

## 粘性来源

"我的歌单就是我的关卡库"——收集更多歌曲来体验不同关卡。追求完美合拍的 Near-miss 连击也带来技术挑战的粘性。但 Token 限制系统可能让玩家产生"想玩却没 Token"的焦虑感，而非正向粘性。

## Meta 系统

- **Token 经济**：初始 2 个 Token，每次跑图消耗 1 个 → 收集音符兑换更多 Token → 兑换率通常不足 → 引导付费或等待
- **歌曲难度评级**：上传的歌曲被系统自动评定难度，方便玩家选择适合的挑战等级
- **歌曲库收集**：通关自带歌曲后解锁上传功能，鼓励收集更多音乐
