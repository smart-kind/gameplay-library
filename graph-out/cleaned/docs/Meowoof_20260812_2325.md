# 喵汪大冒险（Meowoof）

- **类型**: 街机动作 / 解谜平台
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发
- **首次发布**: 2020
- **一句话描述**: 控制被绳子拴在一起的猫和狗两只动物，通过交替移动来通过关卡、躲避障碍、收集物品的创意动作游戏。

## 玩法规则

游戏画面中有一只猫和一只狗，它们被一根绳子拴在一起。主人的失踪让它们踏上了寻找之旅。两只动物永远不会同时移动——一只静止时，另一只围绕它做圆周运动，移动范围受绳子长度限制。

核心操作是点击屏幕：点击后，正在移动的动物会停在当前位置，而原本静止的动物开始围绕它旋转。通过这种交替移动的方式，玩家需要让两只动物通过布满障碍的关卡，收集物品，躲避敌人。

游戏初期看起来只是简单的一指街机游戏，但随着推进会逐渐加入新元素：需要点击攻击的敌人、需要思考的谜题、追逐玩家角色的邪恶叉子、布满尖刺的旋转通道等。某些道具对猫和狗的效果不同——比如某个道具只有猫能拾取生效，另一个道具则需要狗来使用。

游戏不断在核心机制上叠加新内容，而不是停留在"一个机制做到底"。有时你在躲避邪恶叉子的追逐，有时你需要穿过旋转的尖刺通道，有时你需要利用道具来通过特定区域。这种持续的变化让游戏始终保持新鲜感。

## 核心循环

交替移动通过障碍 → 收集物品 → 到达终点 → 解锁新关卡和新机制

## 核心机制

- **交替移动**: 点击切换哪只动物在移动，另一只作为锚点旋转——这是游戏的核心机制，简单但有深度
- **绳长限制**: 绳子长度限制了移动动物的范围，玩家需要利用这个限制来精确定位两只动物
- **战斗系统**: 接近敌人时点击可以攻击，将战斗融入移动节奏中，不能盲目通过
- **差异化道具**: 某些道具只对猫或狗生效，需要规划使用哪只动物来拾取，增加策略维度
- **多变关卡**: 游戏不断引入新机制——尖刺通道、追逐敌人、旋转平台等，保持玩法新鲜感

## 为什么好玩

Meowoof 的精妙之处在于它用一个极简的核心机制衍生出丰富的玩法变化。游戏不会停留在"一个机制做到底"，而是不断加入新元素让玩家应对。猫和狗的组合既可爱又有策略深度——什么时候让谁移动、利用绳子长度做什么，都是有趣的决策。

## 粘性来源

主要来自关卡挑战的"再来一次"冲动——每次失败都只差一点，而关卡通常很短，重试成本极低。不断出现的新机制让人好奇"接下来还会加入什么"。猫狗双主角的可爱设定也增加了情感粘性，让人想要看到它们找到主人的故事结局。

## Meta 系统

无复杂外围系统。游戏以关卡推进为主，通过解锁新区域和新机制来保持动力。没有角色升级或装备系统。

## 实现难度

中。核心物理系统需要处理两只动物的绳子连接和旋转运动，碰撞检测和路径规划有一定复杂度。最大难点是确保绳子物理表现自然且操作响应灵敏，同时处理两只动物的独立动画和状态切换。
