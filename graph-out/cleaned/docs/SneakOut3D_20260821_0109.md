# Sneak Out 3D (潜行逃脱3D)

- **类型**: 潜行解谜 / 动作冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: MondayOFF
- **首次发布**: 2023
- **一句话描述**: 一款3D潜行解谜游戏，玩家需要在守卫眼皮底下悄悄到达出口

## 玩法规则

玩家控制一个角色在3D场景中悄悄移动，目标是避开守卫、摄像头和巡逻犬，成功到达出口。场景从俯视或斜45度视角呈现，可以看到角色、守卫（红色视野锥）和出口位置。

操作为单手滑动：向某个方向滑动，角色向该方向移动一段距离。移动是网格化的，每次滑动移动一格。守卫按照固定路线巡逻，头顶有视野范围指示（绿色安全或红色危险）。

玩家需要在守卫背对时通过危险区域。如果进入守卫视野，会触发警报并游戏失败。部分关卡有道具：钥匙（开门）、伪装（短暂隐身）、诱饵（吸引守卫注意力）。

游戏目标是在不被发现的情况下通过所有关卡。每关有3星评分：不被发现3星、被发现1到2次2星、多次被发现1星。后期关卡加入摄像头（固定视野）、激光网（需要特定时间通过）、巡逻犬（嗅觉范围）等增加难度。

部分场景有可互动的环境元素，如箱子（可以推到特定位置作为掩体）、通风管道（可以绕开守卫区域）、暗门（需要钥匙打开的捷径）。这些元素增加了关卡的策略深度。

## 核心循环

观察守卫巡逻路线 -> 选择安全时机移动一格 -> 避开视野到达出口 -> 解锁下一关

## 核心机制

- **网格化移动**：每次滑动移动一格，将潜行策略转化为可计算的空间推理
- **视野锥系统**：守卫的视野范围可视化（绿色或红色），提供明确的风险反馈
- **道具系统**：钥匙、伪装、诱饵等道具增加解谜深度，需要合理分配使用
- **环境互动**：箱子、通风管道、暗门等可互动元素增加关卡策略深度

## 为什么好玩

在守卫眼皮底下溜过去的紧张感让人心跳加速，成功逃脱后的成就感爆棚。网格化移动让每次决策都有策略深度。

## 粘性来源

成功潜行的成就感，差一点被发现的紧张刺激，关卡难度递增带来的挑战欲。每关3星评分驱动完美通关。

## Meta 系统

关卡解锁系统加道具商店。完成关卡解锁新场景，获得硬币购买道具（伪装、诱饵等）。部分道具在关卡内使用，增加策略选择。

## 实现难度

中等 -- 网格化移动和AI巡逻路径相对容易实现。最大技术难点是3D视野锥计算和玩家AI碰撞检测的精确性。
