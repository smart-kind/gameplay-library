# Idle Sheep!

- **类型**: 休闲
- **平台**: Mobile (iOS)
- **开发商**: Mindstorm Studios
- **首次发布**: 2016
- **一句话描述**: 一款休闲类移动游戏

## 玩法规则

玩家通过点击或触摸屏幕来积累资源（金币/能量/经验等）。随着资源积累，玩家可以购买升级来加速资源获取速度。游戏采用自动化机制——即使玩家离线，资源也会继续积累。

画面布局简洁明了：上方显示当前资源数量和每秒/每分钟产出速率，中央为主要交互区域（点击目标/角色），下方为升级购买面板。每个升级项目都有明确的成本、效果和解锁条件。

玩家点击屏幕产生资源 → 资源用于购买自动生产升级 → 自动生产产生更多资源用于购买更高级的升级，形成指数增长循环。当资源积累到一定程度后，可以解锁新的游戏区域或重置以获得倍率加成。

## 核心循环

点击/积累资源 → 购买升级提升产出 → 更高产出积累更快 → 解锁新内容或重置获得倍率

## 核心机制

- 机制1：指数增长机制：每次升级都让资源产出呈指数级增长，给玩家持续的正反馈
- 机制2：离线收益：即使关闭游戏，后台仍按最后已知速率积累资源，鼓励定期回游
- 机制3：重置/转生系统：积累到一定程度后可重置进度获得永久倍率加成，创造新的目标感

### 数值成长曲线

游戏的数值设计遵循精心计算的指数增长模型。早期升级成本低、效果显著，给玩家快速正反馈。中期开始出现收益递减，促使玩家寻找新的增长途径（如转生、解锁新区域）。后期数值可达天文级别，但增长速率的控制让玩家始终保持目标感。

### 自动化策略

随着游戏进程，玩家从手动点击逐渐转向自动化管理。关键转折点在于选择合适的升级顺序——优先投资产出型升级还是效率型升级，会显著影响中期进度。高级玩家会计算每次购买的边际收益，优化资源分配策略。

### 里程碑与成就系统

游戏设置大量短期里程碑（首次达到100/1000/10000资源），每个里程碑都伴随视觉反馈（特效、音效、成就通知）。这些微奖励构成了"再来一分钟"的心理基础——'就差一点就能达到下一个里程碑了'。

## 为什么好玩

看着数字从个位数飙升到天文数字的成就感非常直接，每次升级都能立刻感受到产出速度的变化，满足感即时且持续。

## 粘性来源

指数增长的数学确定性让人欲罢不能——'再买一个升级就能翻倍'的心理陷阱。离线收益机制让'不回来看看就亏了'成为自然驱动力。

## Meta 系统

转生/重置系统：玩家可选择重置当前进度，获得永久倍率加成。重置次数越多，基础产出倍率越高。对核心玩法的影响是每次重新开始都比上次更快达到新的里程碑。

## 实现难度

中 + 休闲类游戏核心逻辑相对成熟，最大的技术难点在于数值平衡——既要保证前期成长速度足够快以留住玩家，又要让后期有足够的深度和追求。
