# 疯狂计划： Nexus（Madness: Project Nexus）

- **类型**: 动作射击 / 横版过关 / 暴力
- **平台**: Web（浏览器）/ Flash（原始版）/ PC（重制版）
- **开发商**: Krinkels
- **首次发布**: 2004（原版 Flash）
- **一句话描述**: 疯狂的横版动作射击游戏——玩家扮演一名装备精良的战士，在充满敌人的设施中杀出一条血路

## 玩法规则

游戏采用横版卷轴视角，画面是简洁的线条/火柴人风格。玩家控制一名战士（通常是 Hank 或其他角色）在设施走廊、实验室、废墟等场景中移动和战斗。

操作方式：方向键移动，鼠标瞄准，点击射击。游戏支持多种武器（手枪、霰弹枪、步枪、近战武器等），可以切换使用。

关卡设计是线性的——从左向右推进，沿途消灭所有敌人。敌人有巡逻、警戒、攻击等不同状态。战斗节奏极快——敌人数量多、火力猛，需要快速反应和精准射击。

部分关卡有 Boss 战——面对强大的敌人或机械装置，需要利用场景和武器优势取胜。

## 核心循环

推进关卡 → 消灭敌人 → 收集武器和弹药 → 打败 Boss → 进入下一关

## 核心机制

- **快节奏战斗**：战斗是游戏的核心——敌人数量多、火力猛、反应快。玩家需要快速移动、瞄准、射击、换弹。战斗节奏类似 DOOM 或 Hotline Miami。
- **武器系统**：多种武器选择，每种武器有不同的射程、射速、伤害和弹匣容量。可以在场景中拾取敌人的武器。
- **场景互动**：部分场景中有可互动的元素（可破坏的墙壁、可引爆的油桶、可使用的机关）。

## 为什么好玩

Madness 系列以其极端的暴力和简洁的画面风格在 Flash 游戏时代独树一帜。Project Nexus 是系列中完成度最高的作品——流畅的战斗手感、多样的武器选择、精心设计的关卡，让它成为 Flash 时代最好的动作射击游戏之一。

## 粘性来源

- **战斗快感**：快节奏的战斗提供了强烈的肾上腺素刺激
- **武器多样性**：不同武器带来不同的战斗体验
- **关卡挑战**：每个关卡的敌人配置和地形设计都有挑战

## Meta 系统

无（Flash 版）。PC 重制版有角色升级和技能系统。

## 实现难度

- **学习曲线**：新手可以立即上手，但精通需要数十小时的练习。每次游玩都能发现新的技巧或策略。
- **重玩价值**：高。每局游戏都有不同的体验，无论是随机的地图/敌人，还是玩家的策略选择。
- **社区生态**：作为经典浏览器游戏，它在玩家社区中有良好的口碑。
- **技术亮点**：在浏览器环境中实现流畅的交互体验，充分利用了现代 Web 技术的能力。
中 + 需要横版战斗系统、敌人 AI、武器系统、碰撞检测。最大技术难点是战斗节奏的把控——要让战斗紧张刺激但不会让玩家感到不公平。
