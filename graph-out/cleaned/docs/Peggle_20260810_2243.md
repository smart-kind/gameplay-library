# 弹珠台+打砖块的物理弹射游戏，消除所有橙色钉子过关（Peggle）

- **类型**: 物理弹射
- **平台**: PC / Mobile (iOS+Android)
- **开发商**: PopCap Games
- **首次发布**: 2007
- **一句话描述**: 弹珠台+打砖块的物理弹射游戏，消除所有橙色钉子过关

## 玩法规则

玩家在屏幕顶部发射一颗弹珠，弹珠在下落过程中碰到钉子会消除该钉子并得分。目标是消除所有橙色钉子（部分关卡有蓝色钉子不影响通关）。

弹珠遵循真实物理反弹，碰到墙壁和钉子会弹回。有10个不同角色可选，每个角色有独特特殊能力（如慢动作、火焰弹、多球等）。

每关有3颗星星评级。当弹珠消除最后一个橙色钉子时会有Extreme Fever庆祝动画。

## 核心循环

瞄准 → 发射弹珠 → 弹珠反弹消除橙色钉子 → 全部消除过关 → 下一关

## 核心机制

- 物理弹射：真实的弹珠反弹物理
- 橙色/蓝色钉子区分：只需消除橙色钉子即可过关
- 角色特殊能力：10个角色各有独特技能
- Extreme Fever：消除最后一个橙色钉子时的爽感庆祝

## 为什么好玩

弹珠物理的不可预测性和Extreme Fever的极致爽感。看着弹珠在钉子间弹来弹去最终消除最后一个橙色钉子的满足感极强。

## 粘性来源

关卡驱动；三星评级驱动完美主义；角色解锁；Extreme Fever的多巴胺释放。

## Meta 系统

关卡解锁+角色解锁系统。

## 实现难度

低。单点发射操作极简，但精准瞄准需要技巧。最大技术难点：物理模拟的准确性和反弹计算。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
