# Minigame Party: Pocket Edition

- **类型**: 派对迷你游戏合集
- **平台**: Mobile (iOS+Android)
- **开发商**: Com2uS Corp.
- **首次发布**: 2023
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

选择迷你游戏 -> 完成挑战 -> 获得奖励 -> 解锁新游戏

## 核心机制

- **迷你游戏合集**: Com2uS出品的迷你游戏合集，包含多种类型的迷你游戏。定期添加新游戏，保持内容的新鲜感。
- **角色自定义**: 玩家可以自定义角色外观，增加个性化体验。角色外观是社交展示的一部分。
- **排行榜系统**: 每个迷你游戏都有排行榜，玩家可以与全球玩家竞争。排行榜提供了竞争目标。

## 为什么好玩

多种迷你游戏确保了不会玩腻。Com2uS的品质保证让每款小游戏都有不错的完成度。

## 粘性来源

粘性来源于丰富的游戏内容和定期更新。排行榜提供了竞争目标。

## Meta 系统

- 排行榜系统：按迷你游戏表现排名
- 角色自定义：个性化角色外观
- 定期更新：持续添加新迷你游戏
- 对核心玩法的影响：排行榜和更新提供了长期目标

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
