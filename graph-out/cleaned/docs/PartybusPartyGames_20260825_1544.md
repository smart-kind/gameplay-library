# Partybus 派对游戏（Partybus - Party Games）

- **类型**: 社交派对 / 聚会游戏
- **平台**: Mobile (iOS+Android)
- **开发商**: Partybus
- **首次发布**: 2021
- **一句话描述**: 一款专为聚会设计的多人派对游戏合集，包含多种适合群体游玩的互动小游戏。

## 玩法规则

游戏提供多种派对小游戏，支持多名玩家通过各自的设备连接同一个房间。

在你画我猜模式中，一名玩家用屏幕画画，其他人实时观看并输入猜测。在谁是卧底模式中，玩家中有一名卧底，通过描述和投票找出卧底。

每款游戏有各自的规则和回合制流程，主持人可以设置游戏参数如时间限制、难度等。

## 核心循环

创建房间 -> 邀请朋友加入 -> 选择派对游戏 -> 轮流游玩 -> 计分排名

## 核心机制

- 多人联机: 玩家通过房间码连接，各自使用自己的设备，无需共享屏幕。支持2-10人同时游玩。
- 多样派对游戏: 涵盖画画猜词、问答、推理、音乐等多种社交游戏类型，满足不同群体偏好。
- 自定义设置: 主持人可以调整游戏参数，适应不同群体和场合的需求。

## 为什么好玩

社交互动的乐趣远超游戏本身。朋友间的反应、答案的出人意料都制造了天然的欢乐氛围。

每款游戏都设计为容易理解但充满变数，保证了不同群体的参与度。

## 粘性来源

社交场景的天然粘性。聚会时自然成为焦点。每款游戏时间短，可以快速轮换。

新游戏内容更新保持新鲜感。自定义房间设置让主持人可以根据群体特点调整游戏体验。

## Meta 系统

游戏库扩展：持续添加新游戏类型。

成就和统计：记录每人的胜率和搞笑时刻。

## 实现难度

中 - 多人实时联机同步是主要技术难点。需要稳定的WebSocket连接和低延迟通信。
