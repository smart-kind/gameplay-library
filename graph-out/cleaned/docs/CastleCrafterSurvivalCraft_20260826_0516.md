# Castle Crafter: Survival Craft (Castle Crafter Survival Craft)

- **类型**: 像素风多人对战 / 沙盒建造 / 生存
- **平台**: Mobile (iOS)
- **开发商**: 4 GEN BILGI TEKNOLOJILERI
- **首次发布**: 2015
- **一句话描述**: 一款像素风格的多人在线城堡攻防游戏，玩家分为红蓝两队进行夺旗、团队死战等模式的对抗。

## 玩法规则

游戏采用像素方块风格的3D画面，玩家控制一个方块人角色在城堡场景中行动。屏幕左侧是虚拟方向摇杆，右侧有攻击按钮和交互按钮。

游戏提供四种模式：
1. **夺旗模式**：玩家选择红方或蓝方，防守方保护己方旗帜不被夺走，进攻方需潜入敌方城堡夺取旗帜并带回己方阵地。时间耗尽前完成夺旗的队伍获胜。
2. **团队死战**：红蓝两队对抗，时间结束时击杀数更多的队伍获胜。
3. **自由死战**：每个玩家各自为战，击杀数最高者获胜。
4. **世界探索**：离线单人模式，自由探索战场和城堡，无输赢条件。

玩家可使用剑、镐、弓箭等武器。还可以挖掘隧道、开秘密门、建造桥梁和梯子、搭建庇护所和盾牌。支持语音聊天与队友沟通战术。还可以潜水绕到敌方后方。

## 核心循环

选择模式 → 加入战斗 → 使用武器和建筑工具对抗敌人 → 获得击杀/完成任务 → 重复

## 核心机制

- **4种游戏模式**：夺旗、团队死战、自由死战、世界探索，满足不同玩法偏好
- **方块建造系统**：可以挖掘、建造、搭建，利用地形和建筑制定战术
- **多人在线对战**：与真实玩家实时对抗，支持语音聊天配合
- **武器与装备**：剑、镐、弓箭等5种不同武器，每种有不同用途

## 为什么好玩

像素风的城堡攻防对战融合了Minecraft式的建造和传统FPS的对战乐趣。夺旗模式特别刺激——你需要潜入敌方城堡、找到旗帜、突破防线带回己方阵地，整个过程充满紧张感和策略性。

## 粘性来源

- **多人对战的不确定性**：每场对战的对手和局势都不同，重复可玩性高
- **模式多样性**：4种模式满足不同心情下的游戏需求
- **建造自由**：可以挖隧道、造桥梁、搭盾牌，战术创意空间大
- **社交互动**：语音聊天让团队配合更有乐趣

## Meta 系统

无外围成长系统。游戏完全免费，无内购。每局重新开始，无角色等级或装备积累。

## 实现难度

低。像素风渲染资源需求低，4种模式的核心逻辑（移动、射击、旗帜交互）都是成熟玩法。最大技术难点是多人网络同步和反作弊。
