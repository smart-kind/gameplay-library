# 文字绿洲：宁静解谜（Word Oasis: Calm Puzzle Game）

- **类型**: 文字解谜 / 单词连接 / 种田模拟
- **平台**: Mobile (iOS + Android)
- **开发商**: Oasis Games LTD
- **首次发布**: 2024
- **一句话描述**: 将单词连接与花园建设相结合的创新文字游戏，每连接一个单词就在你的绿洲中种下一棵树。

## 玩法规则

游戏画面分为上下两个区域：上方是字母板（类似于 Wordscapes 的环形字母排列），下方是你的"绿洲"——一片可以种植的荒地。

在字母板上，玩家通过滑动连接字母形成单词。与纯文字游戏不同，Word Oasis 每找到一个单词都会产生双重效果：单词被记录得分，同时在绿洲中种下一棵树或一株植物。连续找到多个单词会触发连锁效果，种植更多或更稀有的植物。

每个关卡有目标单词数量和种植目标。完成关卡后，绿洲中种植的植物会生长，逐渐将荒地变成繁茂的绿洲景观。关卡推进时，字母板的字母数量和单词难度递增。

## 核心循环

连接字母组成单词 → 单词转化为植物种在绿洲 → 绿洲逐渐繁荣 → 解锁新关卡和植物种类

## 核心机制

- **单词-植物映射**：每个单词对应一种植物，单词越长越稀有，对应的植物也越特别。这种将抽象词汇转化为视觉成果的设计提供了强烈的成就感。
- **绿洲建设**：随着关卡推进，玩家的绿洲从一片荒地逐渐变成繁花似锦的花园。这种可视化的进度展示是区别于其他文字游戏的核心特色。
- **连锁种植**：连续快速找到多个单词触发连锁奖励，一次性种植多棵植物或稀有品种，鼓励流畅的解题节奏。

## 为什么好玩

它巧妙地将文字解谜（脑力活动）与花园建设（视觉满足）结合在一起。其他文字游戏的进度只是一个数字或星级，而这里的进度是一个可见的、美丽的花园。看着荒地变绿洲的满足感远超单纯"过关"。

## 粘性来源

花园建设的长期目标感——玩家想看到自己的绿洲变成什么样；单词与植物的映射关系激发了收集欲（"我想种那棵稀有树"）；每日登录可以收获绿洲中的植物资源。

## Meta 系统

绿洲建设系统。玩家持续解锁新的植物种类和装饰物品。绿洲的美观程度与通关进度直接相关，但不影响核心解谜难度。可解锁特殊主题花园（日式庭院、热带花园等）。

## 实现难度

中。文字解谜部分与标准 Wordscapes 类相同，但需要额外维护植物生长状态、花园渲染和关卡-植物映射关系。最大技术难点是设计关卡与植物之间的有意义的关联——不能简单随机分配。
