# 投石车国王（Catapult King）

- **类型**: 弹射解谜 / RPG冒险 / 物理
- **平台**: Mobile (iOS+Android)
- **开发商**: Chillingo
- **首次发布**: 2012
- **一句话描述**: 操控投石车发射弹丸，利用物理弹道摧毁敌方堡垒、解救公主的弹射类RPG冒险游戏。

## 玩法规则

游戏采用侧视角2D画面，左侧是玩家的投石车，右侧是敌方堡垒。玩家通过拖拽屏幕来瞄准——拖拽距离决定发射力度，拖拽角度决定发射方向。松手后弹丸沿抛物线轨迹飞出，命中目标后造成破坏。

弹丸类型多样：普通石弹（基础伤害）、火弹（爆炸伤害，可以引燃木质结构）、冰弹（冻结移动目标）、炸弹弹（大范围爆炸）、分裂弹（空中分裂成多个小弹丸）。不同弹丸针对不同结构有特效——火弹对木头伤害高，石弹对石头更有效。

堡垒由多种材料构成：木头（易燃）、石头（坚固但怕重击）、玻璃（脆弱）。堡垒中还关押着需要解救的公主、骑士等NPC。每关需要在有限的弹丸数量内摧毁堡垒并解救所有NPC。

部分关卡有特殊敌人——会移动的平台、会反击的投石车、会释放魔法的巫师等。玩家需要根据敌人类型选择合适的弹丸和攻击策略。

## 核心循环

发射弹丸摧毁堡垒 → 收集金币和宝石 → 升级投石车和弹丸 → 挑战更难关卡

## 核心机制

- **弹道物理**：拖拽瞄准+抛物线轨迹，需要估算角度和力度来命中目标
- **弹丸种类**：不同弹丸有不同特效和适用场景，策略选择是核心
- **材料破坏**：木头易燃、石头坚固、玻璃脆弱，不同材料需要不同攻击方式
- **连锁反应**：击中关键支撑点可以引发整个结构的连锁倒塌，造成额外伤害
- **RPG成长**：金币用于升级投石车威力、弹丸数量解锁、新弹丸类型

## 为什么好玩

Catapult King将"弹射摧毁"的爽快感发挥到了极致。看着自己发射的弹丸精准命中敌方堡垒，木质结构在火焰中坍塌，石头城墙在重击下碎裂，这种"破坏的快感"是核心吸引力。弹丸种类的多样性让每个关卡都有不同的解法，不是简单的瞄准射击，而是需要思考"用什么弹丸打什么位置"的策略游戏。

## 粘性来源

- **连锁倒塌的爽感**：击中关键点引发整个建筑倒塌的视觉满足感极强
- **弹丸收集**：解锁新弹丸类型带来新的玩法体验
- **关卡挑战**：从简单堡垒到复杂多层结构，难度逐步提升
- **RPG成长**：升级投石车和能力带来的持续进步感

## Meta 系统

RPG成长系统——通过关卡获得的金币和宝石可以升级投石车威力、增加弹丸携带量、解锁新弹丸类型、提升弹丸特效范围。装备系统允许穿戴不同属性的盔甲和武器。

## 实现难度

中 — 需要2D物理引擎和破坏效果模拟。最大技术难点在于"结构破坏"的真实感——建筑物被击中后的坍塌动画需要看起来自然且有物理感。弹道抛物线的计算和碰撞检测也是关键技术点。
