# Lorelei and the Laser Eyes（罗蕾莱与激光之眼）

- **类型**: 解谜 / 冒险
- **平台**: PC / PlayStation / Nintendo Switch
- **开发商**: Simogo
- **发行商**: Annapurna Interactive
- **首次发布**: 2024
- **一句话描述**: 在一座巨大的酒店中探索和解谜的超现实冒险游戏，没有预先解释，一切等待玩家自己发现。

## 玩法规则

游戏采用固定视角的2D/2.5D混合画面，玩家操控角色 Lorelei 探索一座庞大而诡异的酒店。酒店由多个楼层、房间和走廊组成，每个区域都有独特的视觉风格和谜题。

游戏最显著的特点是"没有教程"——玩家进入酒店后不会被教导如何操作、如何解谜。所有信息都隐藏在环境中：墙上的文字、画中的图案、物品的排列、房间之间的关联。玩家需要观察、推理、连接线索来推进。

谜题类型多样且高度创新：有些需要玩家记住之前房间中看到的数字并在后续场景中使用；有些需要将不同房间的信息组合起来才能解开；有些涉及时间和空间的非常规逻辑。游戏没有明确标记"这是一个谜题"——线索可能隐藏在看似普通的装饰物中。

画面风格是黑白为主，偶尔有红色或其他颜色作为视觉强调。这种极简的色彩选择增强了游戏的超现实氛围，同时也让关键的视觉信息（如红色标记）更加突出。

## 核心循环

探索房间 → 发现线索 → 推理谜题 → 解开谜题 → 进入新区域 → 发现更多线索

## 核心机制

- **无引导探索**：游戏不提供任何教程或提示，玩家必须自己发现所有规则和谜题。这种设计创造了强烈的"发现感"——每个解开的谜题都是玩家自己推理的结果。
- **跨房间谜题**：许多谜题的答案散布在不同的房间中，玩家需要记住之前看到的信息并将其与当前场景关联。这要求玩家保持高度的注意力和记忆力。
- **视觉叙事**：酒店中的画作、雕塑、文字和装饰不仅仅是背景，它们本身就是谜题的一部分。玩家需要学会"阅读"环境。
- **黑白美学中的色彩编码**：黑白主色调中的彩色元素往往是关键线索，这种视觉设计帮助玩家在信息量巨大的环境中标记重要信息。

## 为什么好玩

Simogo（《Sayonara Wild Hearts》《Device 6》的开发商）和 Annapurna Interactive 的合作创造了一款独一无二的解谜体验。游戏的魅力在于它信任玩家的智力——不解释、不提示、不降低难度。每个"啊，原来如此！"的时刻都是纯粹由玩家自己实现的，这种成就感远超大多数有引导的解谜游戏。

## 粘性来源

- **"原来如此"的顿悟感**：解谜游戏中最强烈的正向反馈就是"我明白了！"的瞬间。本作将这种体验推向了极致——因为没有提示，顿悟感完全来自玩家自己的推理。
- **好奇心驱动**："那个房间后面是什么？""这幅画在暗示什么？"这种好奇心让玩家停不下来。
- **美学沉浸**：黑白酒店的神秘氛围让人想一直探索下去。

## Meta 系统

无。游戏是纯粹的解谜冒险体验。

## 实现难度

**中等偏高**。技术难点不在引擎而在设计：1）谜题设计需要极高的创意和严谨的逻辑——每个谜题都要有足够的线索支持解答，又不能太明显；2）信息分布需要精心规划，确保玩家能在不提示的情况下找到答案；3）环境叙事和视觉谜题需要大量的迭代测试。Simogo 有丰富的创新解谜游戏经验，但这仍是一个极具挑战性的设计任务。
