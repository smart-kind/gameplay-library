# 狼人杀：Wolvesville（Wolvesville）

- **类型**: 社交推理 / 多人在线 / 卡牌
- **平台**: Mobile (iOS+Android) / Web
- **开发商**: Wolvesville GmbH & Co. KG
- **首次发布**: 2018
- **一句话描述**: 一款多人在线社交推理游戏，村民对抗狼人，通过推理和投票找出隐藏的狼人

## 玩法规则

游戏开始前，系统根据玩家数量分配角色卡牌。角色分为三大阵营：村民阵营（好人）、狼人阵营（坏人）、第三方阵营（独立目标）。每局游戏分为白天和夜晚两个阶段，交替进行。

**夜晚阶段**：所有玩家闭眼（屏幕变暗），狼人睁眼并私下协商选择一名玩家击杀；特殊角色依次行动——预言家查验一名玩家身份，女巫可以使用解药救人或毒药杀人，守卫守护一名玩家免受伤害。所有夜间行动在限时内完成。

**白天阶段**：所有玩家睁开眼睛，公布夜间死亡情况。存活的玩家依次发言，分析局势，指出可疑目标。发言结束后进行投票，得票最多的玩家被放逐。平票则无人出局。

**胜利条件**：村民阵营胜利——所有狼人被放逐；狼人阵营胜利——狼人数量≥非狼人数量；第三方各有独立胜利条件（如幸存者存活到最后）。

## 核心循环

夜间行动（杀人/查验/救人）→ 白天讨论 → 投票放逐 → 揭晓结果 → 进入下一夜

## 核心机制

- **角色多样性**：游戏包含数十种角色（预言家、女巫、守卫、猎人、丘比特等），每局随机组合。不同角色提供不同的信息视角和行动能力，让每局都有新鲜感。
- **信息博弈**：预言家的查验信息是单向且不完全的（只知道是否狼人），玩家需要拼凑碎片信息做出判断。真假预言家的对跳是游戏的核心戏剧点。
- **时间压力**：发言和投票都有时间限制，迫使玩家在信息不足时做出决定，增加了误判的可能性和戏剧性。
- **阵营隐藏与伪装**：狼人需要伪装成村民发言，同时暗中协调击杀目标。这种"说谎游戏"的本质带来了极强的心理博弈。

## 为什么好玩

每局游戏都是一场全新的心理战。好的发言能扭转局势，一次错误的投票可能直接葬送整局。角色组合的多样性保证了长期的新鲜感，而与真人对抗带来的不可预测性让每局都充满惊喜。

## 粘性来源

- **社交竞争**：与朋友或陌生人博弈的社交乐趣是核心驱动力。
- **角色收集**：游戏提供大量可解锁角色和外观，驱动玩家持续游玩。
- **段位系统**：排位赛机制给熟练玩家提供了持续的进步目标。

## Meta 系统

- **角色解锁系统**：通过游戏获得金币解锁新角色，不同角色提供不同玩法体验。
- **外观/装扮系统**：可购买或解锁角色外观、头像框、表情等个性化元素，不影响游戏平衡。
- **排位段位**：从青铜到传奇的段位系统，提供竞技目标和匹配依据。

## 实现难度

中 — 核心逻辑（角色分配、昼夜交替、投票）不复杂，但角色技能系统的扩展性设计需要良好的架构。多人实时同步、掉线重连、反作弊是主要技术难点。
