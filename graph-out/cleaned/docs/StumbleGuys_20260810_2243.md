# 移动端糖豆人，多人闯关淘汰赛（Stumble Guys）

- **类型**: 休闲
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Kitka Games / Scopely
- **首次发布**: 2020
- **一句话描述**: 移动端糖豆人，多人闯关淘汰赛

## 玩法规则

32名玩家同时参加闯关比赛，在各种障碍赛道上奔跑、跳跃、躲避。每轮淘汰一定数量的玩家，直到最后一名获胜。

关卡类型多样：穿越旋转锤子的赛道、在方块上保持平衡的平台、需要抓住边缘的悬崖等。

玩家角色是圆滚滚的卡通形象，物理碰撞让角色互相推挤。

## 核心循环

匹配进入比赛 → 闯关 → 淘汰/晋级 → 下一关 → 最终获胜

## 核心机制

- 物理碰撞：角色之间的碰撞和推挤增加混乱感和乐趣
- 多样化关卡：每轮随机选择不同类型的障碍赛道
- 淘汰机制：每轮淘汰部分玩家，增加紧张感
- 角色自定义：各种皮肤和表情

## 为什么好玩

混乱的多人闯关充满喜剧效果，角色摔倒和碰撞的场面极其搞笑。每局都有新关卡保持新鲜感。

## 粘性来源

每局不同的随机关卡；角色收集；与好友组队的社交乐趣；获胜的成就感。

## Meta 系统

角色皮肤、表情、庆祝动作等外观解锁系统。

## 实现难度

低。操作简单的多人闯关游戏。最大技术难点：32人实时物理同步和网络延迟处理。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
