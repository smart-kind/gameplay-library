# 灵魂对决（Soul.io）

- **类型**: io 竞技 / 吞噬进化
- **平台**: Mobile (iOS+Android)
- **开发商**: Jointsoft
- **首次发布**: 2019
- **一句话描述**: 怪物与幽灵两大阵营的 io 对战游戏，通过吞噬比自己小的对手来成长，成为竞技场上最大的存在。

## 玩法规则

游戏在一个封闭的圆形竞技场中进行。玩家开局时是一个小型生物（可选择怪物方或幽灵方），在地图中自由移动。地图上散布着比玩家更小的生物，触碰它们即可吞噬并获得体型增长。

核心操作是滑动屏幕控制移动方向。当你的体型大于其他玩家时，你可以触碰并吞噬对方；当你的体型小于对方时，被触碰就会被吞噬。体型越大，移动速度越慢，形成天然的平衡机制。

游戏支持多人实时在线对战，竞技场中同时存在多个玩家。目标是成为竞技场上体型最大的生物。随着体型增长，你需要更谨慎地规划路线，避免被更大的玩家截杀。

## 核心循环

吞噬小生物 → 体型增大 → 能吞噬更大的目标 → 成为竞技场最大者

## 核心机制

- **体型压制**：大吃小的简单规则，直观且易于上手，同时天然形成食物链层级
- **速度代价**：体型越大移动越慢，防止无限滚雪球，给小体型玩家反杀大体型玩家的机会
- **阵营对抗**：怪物 vs 幽灵两大阵营，增加团队归属感和竞争维度

## 为什么好玩

io 游戏的核心魅力在于"大鱼吃小鱼"的本能快感。从一只小不点成长为全场最大的生物，这个过程充满成就感。同时，即使你是最大的，也随时可能因为速度变慢而被围攻，保持紧张感。

## 粘性来源

- **快速重开**：一局被吞噬后只需几秒钟即可重新开始，失败惩罚极低
- **成长快感**：从弱小到强大的正向反馈循环
- **多人竞争**：实时与真实玩家对战，每局体验不同

## Meta 系统

无

## 实现难度

低。核心是 2D 圆形竞技场中的碰撞检测和体型比较。最大技术难点是多人实时同步和匹配系统。

## 补充：游戏经济

游戏内置轻度广告和可选的内购项目，主要用于解锁额外的角色外观和特效。核心玩法完全免费，不影响平衡性。
