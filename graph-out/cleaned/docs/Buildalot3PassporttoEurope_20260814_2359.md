# Build-a-lot 3: Passport to Europe

- **类型**: 模拟经营/建造
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款以欧洲旅行为主题的城市建造模拟游戏

## 玩法规则

玩家扮演房地产开发商，在欧洲各地进行房产开发。通过拖放方式建造各类建筑（住宅、商业、工业），满足居民需求。

每个关卡有明确目标：在预算和时间内建造指定数量的房屋、达到特定房产价值或满足居民满意度。资源包括金钱、建材和工人，需要合理分配。

关卡场景以欧洲城市为背景，建筑风格融入当地特色。界面下方是建筑选项栏和资源显示，上方是当前目标进度。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

建造建筑获得收入 → 积累资金建造更高级房产 → 完成关卡目标解锁新城市

## 核心机制

- 建筑放置与升级：不同建筑有不同产出，升级提高效率和产能
- 资源管理系统：平衡金钱、建材和工人三种资源
- 关卡目标系统：每关有明确的建设目标和时间/预算限制

## 为什么好玩

看着一片空地变成繁荣的欧洲小镇，有很强的创造满足感。关卡设计有欧洲风情。

## 粘性来源

关卡推进的目标驱动和三星评价挑战。

## Meta 系统

- 建筑升级系统：每种建筑有多个等级
- 成就系统：完成特定挑战获得成就奖励

## 实现难度

中等 — 经济系统需要精细平衡，最大的技术难点是资源产出和消耗的数值设计。
