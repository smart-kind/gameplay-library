# Idle Game 1

- **类型**: 放置 / 点击 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: Cem Kamiloglu
- **首次发布**: 2020
- **一句话描述**: 一款极简主义的放置游戏，通过数字递增带来纯粹的数值成长快感。

## 玩法规则

游戏界面极其简洁，核心是一个巨大的数字计数器和少量操作按钮。玩家进入游戏后会看到一个初始数值（通常为0或1），以及一个主操作按钮。

玩家点击主按钮，计数器数值增加。随着数值积累，系统会自动解锁"购买"选项——玩家可以用积累的数值购买"自动生产器"，每个生产器以固定速率产生新的数值。

随着游戏进程，玩家会解锁多层级的生产系统。第一层可能是最基础的"点击器"，第二层是"自动点击器"，后续还有更高级的"倍增器"和"加速器"。每一层的生产器都有自己的成本和产出效率。

游戏的目标是尽可能快地让数字增长。没有明确的终点或失败条件——玩家追求的是突破一个个数量级里程碑（千、万、百万、十亿等），每次跨越都会带来强烈的成就感。

## 核心循环

点击获取数值 → 购买自动生产器 → 数值自动增长 → 解锁更高级生产器 → 数值指数级增长

## 核心机制

- **递增生产机制**：每购买一个生产器，该生产器的价格会按固定比例（通常1.15倍）递增，确保经济系统始终需要玩家做出选择。这种价格递增曲线是放置类游戏的标准设计，既保证了进度感，又维持了决策张力。
- **多层级自动化**：从手动点击到全自动生产，游戏设计了清晰的能力阶梯。玩家在每个阶段都有明确的下一步目标。
- **数量级里程碑**：游戏没有设置传统关卡，而是以数值跨越（从千到万到百万）作为隐性进度标记，让玩家始终有"差一点就到下一个级别"的动力。

## 为什么好玩

它的魅力在于将"成长感"提炼到了最纯粹的形式。没有复杂的系统，没有华丽的画面，只有数字跳动带来的持续正反馈。当看到数值从每秒1增长到每秒百万时，那种成就感是其他类型游戏难以替代的。

## 粘性来源

数值递增本身就是一种强效的多巴胺触发器。每次购买新生产器后的"效率飙升"瞬间，以及看着数字跨越整数关口（如99万→100万）的时刻，都会产生强烈的满足感。此外，"离线收益"机制让玩家即使关闭游戏也在"赚钱"，回来后的收获感促使再次打开。

## Meta 系统

无传统Meta系统。游戏的核心就是数值成长本身，没有角色培养、装备收集或社交系统。所有进度体现在数字大小和生产器数量上。

## 实现难度

低 — 核心逻辑仅涉及简单的数学运算和定时更新。最大的技术难点在于处理大数字的精度问题（超过2^53后JavaScript等语言的浮点精度会丢失），需要使用专门的大数库或自定义数值系统。

## 同类游戏

与此游戏类似的推荐：放置类可参考 Clicker Heroes 和 Idle Slayer；递增类可参考 Cookie Clicker 和 AdVenture Capitalist。
