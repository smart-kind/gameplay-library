# 闲置宇宙（Idle Universe）

- **类型**: 放置 / 创意 / 模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: Dominik Stallmann
- **首次发布**: 2017
- **一句话描述**: 从基本物质开始创造自己的宇宙，让天体碰撞产生更多物质

## 玩法规则

Idle Universe 是一款以太空创作为主题的放置游戏。玩家从最基本的物质开始，逐步创造出各种天体和宇宙结构。

游戏开始时，玩家需要手动点击收集基础物质（matter）。积累足够的物质后，可以创造第一个天体对象。这些对象会自动碰撞并产生更多物质，形成自我维持的循环。

界面左侧显示当前可用的物质数量，中央是宇宙可视化区域（展示已创造的天体），右侧是可创造的对象列表。每个对象需要一定数量的物质来创造，创造后会持续产出更多物质。

随着游戏推进，可以创造的天体越来越复杂：从基本粒子到原子、分子、行星、恒星、星系，甚至多重宇宙。每个新层级的创造都带来视觉上的震撼和产出的飞跃。

不同天体之间的碰撞会产生额外的物质奖励，这鼓励玩家创造更多样化的天体组合。某些天体组合会产生特殊反应，提供额外的产出加成。

## 核心循环

点击收集物质 → 创造天体对象 → 对象碰撞自动产出 → 创造更复杂天体 → 扩展宇宙

## 核心机制

- 天体碰撞产出机制：创造的对象之间自动碰撞产生额外物质，形成网络效应。创造的天体越多、种类越丰富，碰撞收益越高
- 层级递进创造：从粒子到多重宇宙的渐进解锁，每层都有全新体验。这种递进式设计让玩家始终保持好奇心
- 可视化宇宙展示：玩家创造的天体在屏幕上可见，提供直观的成就感。看着自己创造的宇宙运转是一种独特的满足

## 为什么好玩

太空主题极具吸引力，从小粒子到宏大宇宙的进化过程充满想象力。看着自己创造的宇宙在屏幕上运转，满足感极强。游戏兼具放松感和探索欲，适合放松时游玩。

## 粘性来源

创造欲望——'下一个天体是什么？'的好奇心驱动持续游玩。视觉效果反馈让玩家想看到更壮观的宇宙景象。层级递进设计确保始终有新目标。天体碰撞的随机奖励增加了惊喜感。

## Meta 系统

天体层级解锁系统：每创造一定数量的天体，解锁新的、更复杂的天体类型。对核心玩法的影响是持续提供新的创作素材和目标，确保游戏后期仍有新鲜感。

## 实现难度

低 — 放置游戏的变体，核心是数值增长。最大技术难点是天体碰撞的物理模拟和视觉渲染，需要保证性能和视觉效果的平衡。
