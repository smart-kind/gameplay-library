# Space Hedgehogs vs. Space Cacti

- **类型**: 策略/塔防
- **平台**: Mobile (iOS)
- **开发商**: PocketGamer收录作品
- **首次发布**: 2011
- **一句话描述**: 一款以太空刺猬对抗太空仙人掌为主题的策略塔防游戏，充满荒诞幽默的科幻风格。

## 玩法规则

在遥远的星系中，太空刺猬和太空仙人掌展开了史诗般的战争。玩家需要部署各种刺猬单位，在太空中建立防线，抵御仙人掌大军的进攻。

1. 游戏采用经典的塔防布局，每条进攻路线上有多个可以放置防御单位的位置。玩家每关获得固定数量的初始资源，用于部署不同类型的刺猬战士。

2. 太空刺猬分为多种类型：近战型负责近距离阻挡敌人，远程型提供火力输出，特殊型拥有独特技能（如减速、爆炸、治疗等）。每种类型有不同的部署成本和升级路径。

3. 太空仙人掌也有多种类型，各自有不同的移动速度和防御力。部分仙人掌会分裂成多个小单位，部分会释放毒雾降低刺猬的攻击力。

4. 波与波之间有短暂的休息时间，玩家可以利用这段时间补充资源、升级已有单位或调整防御布局。

## 核心循环

部署防御单位 -> 敌人波次进攻 -> 消灭敌人获得资源 -> 升级/补充单位 -> 迎接下一波更强的敌人

## 核心机制

- **单位类型克制**：不同类型的刺猬对不同类型的仙人掌有克制效果。例如远程刺猬对飞行仙人掌效果好，近战刺猬对地面重甲仙人掌效果好。合理的单位搭配是通关关键。

- **升级系统**：每个部署的单位可以通过战斗经验升级，提升攻击力、射速或生命值。升级后的单位可以解锁特殊技能。

- **波次设计**：每关包含多波敌人，波次间隔提供策略调整时间。最后一波通常有Boss级仙人掌出现，需要集中火力才能击败。

- **资源管理**：击杀敌人获得金币，金币用于部署新单位或升级已有单位。资源有限，需要在数量和升级质量之间做出取舍。

## 为什么好玩

荒诞的太空刺猬vs仙人掌设定本身就充满趣味，加上丰富的单位类型和策略搭配让塔防玩法不单调。每次波次之间的策略调整让游戏有思考的乐趣。

## 粘性来源

波次递进带来的持续挑战感，单位升级的数值成长反馈，以及通关后解锁新关卡的探索欲。

## Meta 系统

外围成长系统：金币或经验积累用于解锁新关卡、新角色或新能力。部分游戏包含每日挑战或排行榜等社交竞争元素，鼓励玩家持续回归。

## 实现难度

低。多单位同时战斗的性能优化，以及波次难度曲线的合理设计。
