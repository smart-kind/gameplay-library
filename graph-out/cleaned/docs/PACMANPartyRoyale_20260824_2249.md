# PAC-MAN Party Royale

- **类型**: 派对社交
- **平台**: Mobile (iOS+Android)
- **开发商**: Bandai Namco Entertainment Inc.
- **首次发布**: 2019

## 玩法规则

游戏是一个多人派对/休闲合集类应用，包含多种小游戏供玩家在同一设备上轮流或同时游玩。

游戏界面通常分为大厅和多个小游戏入口。玩家可以选择不同的迷你游戏，每个游戏有独立的规则和界面。

多人模式下，2-4名玩家共享一台设备，轮流操作或同时触控屏幕。每个小游戏持续1-3分钟，一局可以快速切换多个游戏。

操作方式因游戏而异：点击、滑动、长按、多指触控等。每个游戏都有明确的目标：比如谁最快到达终点、谁得分最高、谁存活到最后。

## 核心循环

选择小游戏 → 多人同台竞技 → 获得积分排名 → 换下一个游戏继续

## 核心机制

- 游戏合集模式：一个APP内包含数十种不同的迷你游戏，每种有独立规则和操作方式，保持新鲜感
- 本地多人竞技：2-4人在同一设备上游玩，轮流或同时操作，天然适合聚会场景
- 快速回合制：每个小游戏1-3分钟一局，节奏快，不会因为单一游戏太长而无聊
- 积分排行榜：各小游戏的得分汇总为总排名，激发竞争欲

## 为什么好玩

多人同台的社交互动是最大乐趣来源。朋友间互相竞争的紧张感、失败时的欢笑、偶然获胜的惊喜，这些都是单机游戏无法替代的体验。

## 粘性来源

社交竞争驱动（"再来一局不服"）；游戏种类多，总有新内容探索；低门槛高上限，任何人都能快速上手但精通需要练习

## Meta 系统

- 游戏解锁：通过总积分或游玩次数解锁新的迷你游戏
- 角色/皮肤：可自定义的角色外观
- 成就系统：完成特定挑战解锁成就徽章

## 实现难度

中 — 核心难点在于维护多个独立小游戏模块的代码架构，以及本地多人触控输入的冲突检测
