# 超级猴子球（Super Monkey Ball）

- **类型**: 平台/益智/聚会
- **平台**: Multi-platform (iOS/Android, Switch, PS, Xbox, Arcade)
- **开发商**: Sega（原 Amusement Vision / RGG Studio）
- **首次发布**: 2001（街机原版），移动版后续推出
- **一句话描述**: 玩家通过倾斜平台来控制一个装在透明球里的猴子，在充满障碍的关卡中滚动到达终点。

## 玩法规则

游戏画面展示一个悬浮在空中的立体赛道，赛道上有平台、坡道、桥梁、管道等各种地形。玩家不能直接控制猴子，只能控制整个平台的倾斜角度——左倾平台，球就向左滚；右倾则向右滚。

每个关卡都设有时间限制，玩家必须在倒计时结束前将球体滚到终点的绿色目标区域。赛道上布满各种陷阱：缺口（掉下去就失去一条命）、移动平台、弹簧、风扇、敌人等。

操作上，移动端通常使用虚拟摇杆或重力感应来倾斜平台。玩家通过微调倾斜力度来控制球的速度和方向——倾斜幅度越大，滚动越快；幅度小则精细移动。球体带有物理惯性，在坡道上会加速，在平台上会因惯性继续滚动，需要玩家提前预判。

游戏目标是用最短时间到达终点，并尽可能收集赛道上的香蕉（收集品）。每个关卡设有隐藏路径和捷径，鼓励玩家反复探索。

## 核心循环

倾斜平台控制球滚动 → 到达终点并收集香蕉 → 解锁新关卡和新球皮肤

## 核心机制

- **倾斜控制**：整个平台就是控制器，玩家倾斜平台来影响球的运动方向。这种间接控制方式让简单操作变得充满技巧——需要在速度、精度和物理惯性之间找到平衡。
- **物理引擎**：球体的加速度、减速、弹跳都遵循真实物理规律。下坡时加速、上坡时减速，在边缘处可能弹起甚至飞出赛道。这种物理真实感让每次滚动都有独特的体验。
- **香蕉收集**：赛道上散布香蕉作为收集品，鼓励玩家冒险走危险路径。香蕉数量影响评级，激发反复挑战的欲望。
- **多模式玩法**：除了主线关卡模式，还有竞速模式（与其他玩家比速度）、挑战模式（特殊规则关卡）和多人派对模式。

## 为什么好玩

"差一点就成功"的挫败感和"再来一次就能过"的期待感形成完美循环。当你只差0.1秒就能过关时，你会忍不住立刻重开。球体在赛道边缘摇晃却不掉下去的瞬间，心跳加速的体验让人上瘾。

## 粘性来源

- **关卡递进**：每个关卡都比上一个更具挑战性，形成稳定的技能成长曲线
- **收集驱动**：香蕉收集、隐藏关卡、可解锁角色和球皮肤
- **重试冲动**："差一点就过"的心理效应，让玩家停不下来
- **多人派对**：支持多人竞速和对战模式，社交竞争增强粘性

## Meta 系统

- **评级系统**：每关根据时间和香蕉收集量给出评级（S/A/B/C）
- **可解锁内容**：新球皮肤、新角色（不同猴子）、隐藏关卡
- **对核心玩法的影响**：解锁内容不影响核心机制，主要是外观和额外挑战内容

## 实现难度

中 — 核心物理模拟（球体滚动+平台倾斜）需要良好的物理引擎支持，但现代游戏引擎（Unity/Phaser）已有现成方案。最大技术难点在于关卡设计——需要精心构造每一条赛道的难度曲线，确保"有挑战但不令人沮丧"。3D赛道设计和相机跟随也是难点。
