# 监控者（Surveillant）

- **类型**: 策略 / 潜行 / 解谜
- **平台**: Mobile (iOS)
- **开发商**: 独立开发者
- **首次发布**: 2011
- **一句话描述**: 扮演监控系统的操作者，通过监控摄像头观察目标区域，发现异常并采取行动

## 玩法规则

玩家扮演监控室的操作员，面前有多个监控摄像头画面。需要在多个摄像头之间切换观察，发现可疑活动并采取相应行动。

每个关卡有不同的监控场景（办公室、仓库、街道等），玩家需要识别异常行为：可疑人员、异常物品、安全漏洞等。发现异常后，玩家可以采取的行动包括：标记目标、报警、切换摄像头追踪、记录证据等。

随着关卡推进，监控场景越来越复杂：摄像头数量增加、异常行为更加隐蔽、需要同时关注多个目标。时间压力也逐渐增大。

游戏考验玩家的观察力和注意力分配能力，需要在有限时间内从多个画面中筛选有用信息。

## 核心循环

切换监控画面 → 观察异常情况 → 采取行动（标记/报警/追踪） → 完成关卡目标 → 进入更复杂的场景

## 核心机制

- **多屏监控（Multi-Screen Surveillance）**：同时监控多个摄像头画面，需要合理分配注意力
- **异常识别（Anomaly Detection）**：从正常场景中识别异常行为，考验观察力和模式识别能力
- **时间压力（Time Pressure）**：异常事件在限定时间内发生，错过则扣分或失败
- **行动响应（Response Actions）**：发现异常后可以采取不同行动，正确的行动选择影响评分

## 为什么好玩

独特的"幕后操作者"视角让玩家体验监控室操作员的日常工作，观察和发现的成就感很强。随着难度提升，需要同时处理多个异常事件的紧张感很独特。

## 粘性来源

具体到机制层面：1）观察力挑战——"我能发现多少异常"的自我挑战；2）时间压力下的紧张感；3）难度递增带来的能力提升感；4）"差一点就全部发现"的再试一次冲动。

## Meta 系统

关卡评分系统。每关根据发现的异常数量、响应速度和正确性评分，高分解锁新区域。

## 实现难度

中。最大的技术难点是异常事件的随机生成算法——需要确保每局的异常事件既不过于明显也不过于隐蔽，且在不同难度下有合理的挑战曲线。
