# 梯子大师（Ladder Master）

- **类型**: 休闲 / 反应 / 攀爬
- **平台**: Mobile (iOS+Android)
- **开发商**: Tummy Games
- **首次发布**: 2025
- **一句话描述**: 在旋转梯子上保持平衡不断向上攀爬的反应力游戏。

## 玩法规则

游戏画面呈现一个垂直延伸的梯子或柱状结构，玩家控制的角色位于梯子侧面。梯子会缓慢旋转，同时不断有新的台阶从上方出现。

玩家通过点击屏幕控制角色在梯子之间跳跃。每次点击，角色向下一个台阶跃去。台阶的位置分布在旋转的梯子周围，有些在正面，有些在背面。玩家需要在梯子转到合适位置时点击，让角色跳到下一个台阶上。

如果点击时机不对——比如角色跳到了一个已经旋转到背面的台阶，或者跳得太早/太晚——角色会失去平衡并掉落，游戏结束。

游戏没有明确的关卡终点，而是无尽模式。目标是尽可能爬得更高。随着高度增加，梯子旋转速度会加快，台阶间距也会变化，难度持续上升。

## 核心循环

观察梯子旋转 → 点击跳跃到下一个台阶 → 继续向上攀爬 → 直到失误掉落

## 核心机制

- **时机判断**：核心机制是判断何时点击。台阶在旋转，玩家需要预测位置而非直接反应
- **无尽攀爬**：没有终点，只有更高的纪录，每次失败都想挑战自己的最高分
- **旋转难度递增**：梯子越转越快，台阶间距也会不规则变化，后期需要极快的反应速度
- **节奏感**：成功攀爬会产生一种节奏感，玩家在连续跳跃中进入"心流"状态

## 为什么好玩

Ladder Master 的乐趣在于它极简的规则和极高的挑战性之间的张力。操作只有一个——点击——但时机的精准度要求让每一秒都充满紧张感。当玩家连续成功跳跃 50 次、100 次时，会产生一种"我在和梯子对话"的节奏感，这种心流体验让人欲罢不能。

## 粘性来源

1. **"差一点"效应**——每次失败都是因为"再快/慢一点点就能上去"，这种不甘心让人立刻重开
2. **节奏心流**——连续跳跃成功后产生的节奏感和成就感
3. **高分挑战**——每次都在刷新自己的纪录，纯粹的自我竞争
4. **即时反馈**——每一跳都有明确的成/败反馈，没有模糊空间

## Meta 系统

无。没有升级、角色或装饰系统。纯高分驱动。

## 实现难度

低。核心是一个旋转的 3D 柱体和角色跳跃动画，物理逻辑简单。最大技术难点是确保旋转动画的流畅性和跳跃时机判定的一致性——如果帧率波动会影响游戏体验。
