# Kahuna（卡胡纳）

- **类型**: 双人策略卡牌 / 抽象棋盘
- **平台**: Board Game (桌游) / Digital
- **开发商**: 原版由Gunther Cornett设计（1998年桌游），Reiner Knizia关联作品
- **首次发布**: 1998 (桌游原版)
- **评分**: 经典双人策略桌游
- **一句话描述**: 两名玩家在热带岛屿上争夺控制权的极简双人卡牌游戏，通过出牌建立岛屿间的连接并夺取对手的控制权

## 玩法规则

游戏背景设定在热带岛屿群中。两名玩家各自代表一个部落，目标是在12个岛屿之间建立连接网络，控制尽可能多的岛屿。

游戏使用一套特殊的卡牌。每张卡牌代表一个岛屿的名称。玩家轮流出牌，将卡牌放置在手牌中对应的岛屿位置上。

当一个玩家在某两个岛屿之间都拥有卡牌时，他就在这两个岛屿之间建立了"连接"。连接是双向的——如果A岛同时与B岛和C岛有连接，那么A-B-C形成一条路径。

游戏的核心冲突机制是"夺取"：如果一名玩家在某个岛屿上出的牌数量超过对手，他就夺取了该岛屿的控制权，对手的牌被移除。

当所有卡牌都出完后游戏结束。计分基于控制的岛屿数量以及岛屿之间的连通性。控制更多岛屿且形成更大连通网络的玩家获胜。

## 核心循环

出牌建立岛屿连接 → 争夺岛屿控制权 → 评估连通性和控制权 → 继续出牌直到牌堆耗尽

## 核心机制

- **岛屿连接系统**：通过在特定岛屿上出牌来建立岛屿间的连接，形成网络
- **控制权争夺**：同岛屿上牌多者胜，是简单的数量比较但策略深度在于时机选择
- **极简规则**：核心规则几句话就能说明白，但策略深度随对局经验增长
- **双人零和博弈**：只有两名玩家，每一手牌都是直接对抗
- **手牌管理**：玩家需要决定何时出牌、出哪些牌，是等待更好的时机还是抢先占领

## 为什么好玩

Kahuna的魅力在于极简规则下的策略深度。虽然规则简单到一分钟就能学会，但每一次出牌都涉及多重考量：是巩固已有连接还是开拓新领土？是立即夺取对手的关键岛屿还是耐心等待？这种"易懂难精"的特质让它成为经典的双人桌游。

## 粘性来源

(1) **每局不同的策略路径**——手牌的随机分布意味着每局都需要新的策略；(2) **双人对抗的紧张感**——零和博弈中每一步都在直接对抗；(3) **"我本可以"的复盘乐趣**——结束后总能想到更好的走法，促使再来一局；(4) **快速对局**——一局时间短，适合反复对弈

## Meta 系统

无——纯对局游戏

## 实现难度

**低** — 核心是卡牌管理和简单的比较逻辑。技术实现简单，难点在于AI对手的设计（需要评估连通性和控制权的综合价值）
