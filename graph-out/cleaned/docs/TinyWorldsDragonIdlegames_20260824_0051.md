# Tiny Worlds: Dragon Idle games

- **类型**: 放置
- **平台**: Mobile (iOS+Android)
- **开发商**: Old Skull Games
- **首次发布**: 2020
- **一句话描述**: 一款放置类移动游戏，由Old Skull Games开发

## 玩法规则

玩家在手机上通过点击、拖拽或滑动进行操作。游戏界面展示游戏核心元素，如棋盘、角色或叙事场景。

每个回合/操作中，玩家根据当前局势做出决策。操作产生即时反馈——消除方块、获得资源、推进剧情或击败敌人。

游戏目标因模式而异：在解谜模式中清空棋盘或达成特定条件；在放置模式中最大化资源产出和升级进度；在射击模式中消灭所有敌人并完成关卡。

游戏通过关卡递进、难度曲线或叙事章节推进。失败条件包括棋盘空间耗尽、生命值归零或做出错误的推理选择。

最新版本更新内容：Several minor bug fixes.

## 核心循环

放置核心循环：执行操作 → 获得资源/推进 → 升级/解锁 → 挑战更高难度

## 核心机制

- **放置点击 (Idle/Clicker)**: 通过点击或自动累积资源，购买升级提升产出效率。离线时持续获得收益，重玩时获得永久加成。
- **方块解谜 (Block Puzzle)**: 将不同形状的方块放置在网格中，填满整行或整列后消除。需要预判形状序列和空间利用。
- **升级成长 (Progression)**: 通过升级系统逐步增强角色能力，解锁新技能和装备。
- **离线休闲 (Offline)**: 简单易上手的操作，适合碎片化时间游玩，无需联网即可畅玩。

该游戏在App Store获得4.7/5.0的用户评分，适合4+及以上年龄玩家。游戏通过精心设计的放置机制和流畅的操作反馈，提供了令人满足的游戏体验。

## 粘性来源

粘性主要来自放置核心循环的"再来一次"驱动力：消除的爽感和连锁反应、数值成长的满足感、或揭开真相的好奇心驱动。每次操作都有明确的正向反馈，让玩家持续投入。

## Meta 系统

放置外围系统：通过升级、解锁和收集元素提供长期目标。玩家通过积累游戏内货币或资源，解锁新内容、提升基础属性或获得永久加成。

## 实现难度

中。放置机制在移动端有成熟的实现模式。主要技术难点在于数值平衡和长期留存设计。
