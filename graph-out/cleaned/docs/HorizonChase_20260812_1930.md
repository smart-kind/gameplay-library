# 追逐地平线（Horizon Chase）

- **类型**: 街机竞速
- **平台**: Mobile (iOS+Android)
- **开发商**: Aquiris Game Studio
- **首次发布**: 2015
- **一句话描述**: 向 90 年代经典街机赛车致敬的 3D 竞速游戏，灵感来自 Top Gear 和 Out Run

## 玩法规则

游戏采用伪 3D 的赛道渲染方式，模仿 16 位时代的经典街机赛车视觉风格。画面为从后方追视的视角，赛道以多边形的方式向远方延伸，呈现出复古的低多边形美学。

玩家通过虚拟方向盘（滑动左右转向）和虚拟踏板（点击加速/刹车）控制赛车。操作简洁直观：向左滑动转向左，向右滑动转向右，按住屏幕下半部分加速，松开即刹车。没有复杂的换挡或调校系统——纯粹的速度与方向控制。

赛道通常包含多个弯道、起伏和直道。玩家需要在弯道前适当减速，在直道上全力加速。赛道两侧有树木、建筑等景观元素掠过，增强速度感。每圈比赛完成后，如果用时足够短会获得星级评价。

游戏的目标是在限定时间内跑完赛道并获得尽可能高的分数。分数来源于超越对手、完美过弯和完成圈速。某些模式下还有计时挑战——在时间耗尽前完成赛道。

## 核心循环

比赛竞速 → 获得分数/金币 → 解锁新车新赛道 → 挑战更高难度

## 核心机制

- **伪 3D 赛道渲染**：使用经典街机式的 Mode 7 伪 3D 渲染技术，赛道从近到远逐渐缩小，营造出速度感和纵深感。画面风格刻意模仿 SNES 时代的像素美术，低多边形车辆和赛道边缘的色块都是对 90 年代赛车的致敬。
- **漂移过弯**：在弯道中按住方向可以漂移，漂移角度越大、持续时间越长，过弯速度越快，但同时风险越高——可能冲出赛道。掌握漂移时机是高分的关键。
- **燃料/时间管理**：赛道上散布着燃料罐/时间道具，拾取后可以延长比赛时间。玩家需要在追求速度和收集道具之间做出取舍，形成路线规划的策略层。
- **动态天气系统**：部分赛道支持日夜交替和天气变化（晴天、雨天、黄昏），影响视觉氛围和抓地力。

## 为什么好玩

Horizon Chase 的核心魅力在于纯粹的街机竞速快感——没有复杂的调校、没有漫长的养成，坐下来就是跑。配合 Nintendocore 风格的电子音乐，速度感和怀旧感完美融合，让人想起在街机厅玩 OutRun 的年代。

## 粘性来源

"再来一把"的街机循环——每场比赛只需几分钟，分数排行榜激发竞争欲。解锁新赛道和车辆的进度感让每次游玩都有目标。天气和日夜变化让同一赛道每次跑都有不同体验。

## Meta 系统

- **车辆解锁系统**：通过比赛获得金币，用于购买新车。不同车辆有不同的最高速度和操控特性。
- **赛道解锁**：完成初始赛道后解锁更多赛段，最终形成完整的杯赛结构。
- **星级评级**：每赛道最多三星，收集全部三星是长期目标。

## 实现难度

低到中等。伪 3D 赛道渲染有成熟的算法（参考 OutRun 的 road rendering），弯道、起伏的实现都有经典文献可参考。最大的技术难点是在移动设备上保持 60fps 的同时渲染流畅的伪 3D 赛道和车辆模型。
