# NOM: Billion Year Timequest

- **类型**: 解谜/冒险
- **平台**: Mobile (iOS)
- **开发商**: PocketGamer收录作品
- **首次发布**: 2010
- **一句话描述**: 一款时间旅行题材的益智冒险解谜游戏，玩家在不同时代之间穿梭解决谜题。

## 玩法规则

玩家扮演一名时间旅行者，需要在不同的历史时期之间穿梭，利用各个时代的特色来解决谜题并推进冒险。每个时代都有独特的环境和可交互元素。

1. 游戏将关卡设定在不同的历史时期，如恐龙时代、古埃及、中世纪、未来世界等。每个时代的环境元素和可用工具各不相同。

2. 玩家在某个时代做出的选择会影响其他时代的场景。例如在恐龙时代种下一棵树，在未来时代这棵树已经长成参天大树，可以作为跨越障碍的桥梁。

3. 每个时代都有可收集的道具，这些道具可以带到其他时代使用。某些谜题需要先在A时代获得道具，然后在B时代使用该道具才能解开。

4. 谜题通常涉及平台跳跃、物品使用和逻辑推理。玩家需要观察环境、收集线索、尝试不同的道具组合来找到解决方案。

## 核心循环

探索当前时代 -> 发现谜题 -> 收集/使用道具 -> 解决谜题解锁新区域 -> 切换到另一时代 -> 利用跨时代影响继续解谜

## 核心机制

- **跨时代影响系统**：在某个时代的行动会永久改变该时代的环境，这些改变会延续到后续时代。这种蝴蝶效应让解谜有了更深层次的策略考量。

- **道具携带机制**：玩家可以在时代之间携带道具，某些时代的道具在其他时代有特殊用途。例如在未来时代获得的高科技激光笔，在古代可以用来点燃火炬。

- **环境解谜**：每个时代的场景都是精心设计的谜题空间，玩家需要利用环境中的各种元素（杠杆、开关、重力、水流等）来创造通路。

- **叙事驱动**：游戏通过时间旅行串联起不同时代的故事片段，玩家在解谜的过程中逐步拼凑出完整的故事线索。

## 为什么好玩

时间旅行的设定让解谜有了独特的维度，跨时代影响系统让每个决策都有了长远的意义。不同时代的场景变化带来持续的视觉新鲜感。

## 粘性来源

跨时代蝴蝶效应带来的策略深度，拼凑完整故事线的好奇心，以及每个时代新场景的探索欲。

## Meta 系统

外围成长系统：金币或经验积累用于解锁新关卡、新角色或新能力。部分游戏包含每日挑战或排行榜等社交竞争元素，鼓励玩家持续回归。

## 实现难度

中。跨时代状态同步的逻辑设计，确保每个时代的改变都能正确地反映在其他时代。
