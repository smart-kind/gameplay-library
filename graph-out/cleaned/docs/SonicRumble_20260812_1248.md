# 索尼克大乱斗（Sonic Rumble）

- **类型**: 多人竞技 / 派对游戏
- **平台**: Mobile (iOS+Android)
- **开发商**: SEGA
- **首次发布**: 2025
- **一句话描述**: 基于索尼克IP的多人实时竞技手游，类似《糖豆人》的闯关淘汰玩法。

## 玩法规则

每局游戏开始时有32-64名玩家进入竞技场，通过多轮闯关逐步淘汰玩家，最后一轮选出胜者。

每轮关卡类型不同：竞速赛（跑到终点）、生存赛（避开障碍物存活）、收集赛（收集指定数量物品）、团队赛（分组对抗）。

玩家控制索尼克宇宙中的角色，使用虚拟摇杆控制方向，点击按钮进行跳跃、冲刺和特殊动作。每个角色有独特的技能（如索尼克的加速、纳克鲁斯的滑翔）。

关卡中布满各种障碍：旋转的锤子、移动平台、弹跳垫、陷阱等。碰到障碍物会被击退或减速，从高处掉落会被淘汰。

每轮淘汰约一半玩家，最后一轮通常只有4-8人竞争。最终胜者获得大量奖励。

## 核心循环

加入多人比赛 → 通过多轮闯关 → 获胜获得奖励 → 解锁新角色和外观

## 核心机制

- 角色差异化：不同角色有不同的速度/跳跃/技能，玩家可以解锁和收集多个角色，每种带来不同的手感
- 随机关卡池：每场比赛从几十种关卡中随机抽取，保证重复游玩时体验不同，增加新鲜感
- 物理驱动玩法：角色和障碍物的互动基于物理引擎，每次碰撞效果略有不同，产生有趣的意外情况

## 为什么好玩

混乱的多人混战充满戏剧性时刻——你可能因为前面的人被击退而意外获胜，也可能在最后一秒被淘汰。轻松搞笑的物理效果让每次失败都不令人沮丧。

## 粘性来源

随机关卡带来的不可预测性和'再来一局'的冲动；角色收集和外观自定义提供收集动力；与朋友组队游玩的社交乐趣；短局快节奏（每局3-5分钟）让人'只是再玩一局'。

## Meta 系统

角色解锁系统：通过游戏获得代币，解锁新角色和外观皮肤。赛季通行证：每赛季提供独家外观。成就系统：完成特定挑战获得称号。好友排行榜：和朋友比拼通关次数。

## 实现难度

中 — 需要稳定的多人实时同步、物理引擎优化和反作弊机制。最大难点是在32-64人同屏时保持流畅的物理计算和网络同步。
