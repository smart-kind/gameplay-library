# Sniper Team

- **类型**: 射击/策略
- **平台**: Web
- **开发商**: Addicting Games
- **首次发布**: 2013
- **一句话描述**: 战术狙击射击游戏——组建狙击小队，在多个任务场景中执行精准击杀和战术配合

## 玩法规则

Sniper Team 是一款以狙击为主题的战术射击游戏。游戏采用第一人称狙击视角，玩家通过瞄准镜观察战场，需要瞄准并消灭指定目标。

游戏画面分为几个区域：
- **主瞄准区域**: 占据大部分屏幕，显示狙击镜视野。瞄准镜内有十字准星，可能包含距离标记、风速指示等信息。
- **目标信息**: 显示当前需要击杀的目标列表，包括目标类型（敌方士兵、车辆、重要人物等）和优先级。
- **弹药/状态栏**: 显示剩余弹药量、任务进度、队友状态等信息。
- **小地图/雷达**: 部分关卡提供战场鸟瞰图，显示目标位置和队友分布。

玩家的操作：
- **瞄准**: 移动鼠标控制瞄准镜方向，对准目标
- **射击**: 点击左键开火，需要考虑子弹飞行时间和目标移动
- **换弹**: 按R键或点击换弹按钮补充弹药
- **切换武器/倍镜**: 在不同倍率或武器之间切换以适应不同距离的目标
- **下达指令**: 部分关卡中可以指挥队友进行掩护射击或同步攻击

游戏的主要目标是完成所有指定的击杀任务并安全撤离。失败条件：队友全部阵亡、目标逃脱、或任务超时。

## 核心循环

接收任务简报 → 观察战场环境 → 瞄准并消灭目标 → 获得任务奖励 → 解锁新武器/关卡 → 执行更难的任务

## 核心机制

- **精准射击系统**: 需要考虑子弹飞行时间、目标移动速度和方向。远距离目标需要提前量瞄准，增加了射击的真实感和挑战性。部分版本还包含风速和重力对弹道的影响。
- **战术小队配合**: 玩家不是孤军奋战，可以指挥队友进行协同攻击。例如让队友A吸引注意力，玩家从侧面狙击关键目标。这种配合让游戏从单纯的射击升级到了战术层面。
- **潜行机制**: 开枪会暴露位置，引来敌方增援。因此需要规划射击顺序——优先击杀警报装置或通讯兵，避免过早暴露。
- **多目标管理**: 每个任务通常有多个目标需要清除，需要判断击杀顺序。先打哪个、后打哪个，直接影响任务难度和结果。

## 为什么好玩

一枪命中要害的瞬间快感是狙击游戏永恒的魅力。通过瞄准镜看到目标、调整呼吸、扣动扳机、然后看着目标倒下的整个过程充满了仪式感。战术层面的小队配合让游戏不只是"看到就打"，而是需要动脑子规划击杀顺序和路线。

## 粘性来源

解锁新武器和装备的进度系统提供了持续目标感。越来越难的任务设计（更多目标、更短时间、更复杂的战场环境）让人想不断挑战自己的极限。完成一次完美任务（不暴露、全目标清除、队友无伤亡）的成就感极强。

## Meta 系统

武器解锁和升级系统——完成任务获得分数/金钱，可购买新狙击步枪、消音器、高倍瞄准镜等装备。新关卡/任务线的解锁也提供了Meta进度。

## 实现难度

中——需要实现弹道物理计算、AI敌人行为逻辑（巡逻、警戒、增援）、多单位战术协调。最大技术难点是让AI表现得"聪明但不作弊"——敌人需要有合理的反应时间和行为模式，不能瞬间锁定玩家位置。
