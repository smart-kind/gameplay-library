# Idle Game 1

- **类型**: 放置点击
- **平台**: Mobile (iOS+Android)
- **开发商**: Cem Kamiloglu
- **首次发布**: 2020
- **一句话描述**: 用一句话说清楚这个游戏是什么

## 玩法规则

屏幕中央展示主要产出设施（如农场、工厂、角色等），周围环绕资源计数器和升级按钮。

玩家主要操作是点击主设施获取初始资源，或在资源足够时点击升级按钮提升产出效率。每次升级后，单位时间内的资源产出量会增加，解锁新的设施或功能区域。

游戏通常包含多层级的产出链：低级资源用于解锁中级设施，中级设施产出更高级的资源，以此类推形成递进式的成长体系。

游戏目标是通过策略性地分配资源到不同的升级路线，最大化整体产出效率，解锁所有可用的设施和内容。

放置机制是核心特色——即使玩家不在线，设施也会持续产生资源（通常以一定折扣计算），确保玩家每次回归都有收获。

## 核心循环

点击/等待获得资源 → 升级产出效率 → 解锁新内容 → 继续积累更多资源

## 核心机制

- 点击产出：点击主设施获得基础资源，是游戏初期的主要收入来源。随着升级，单次点击产出逐渐增加
- 自动产出：购买自动化设施后，资源会随时间自动累积，无需手动操作。这是放置类游戏的核心机制
- 升级系统：消耗资源提升设施等级、效率或解锁新功能。每次升级成本递增，形成指数级成长曲线
- 离线收益：玩家退出游戏后，设施仍按一定比例（通常50-100%）继续产出，回归时一次性结算
- 成就/里程碑：达到特定数值时解锁奖励，提供阶段性目标和额外资源 boost

## 为什么好玩

数值成长的持续正反馈让人欲罢不能，看着数字不断飙升带来强烈的成就感

## 粘性来源

离线收益机制让玩家每次打开都有收获感；阶段性解锁提供持续目标；数值膨胀带来的爽感反馈

## Meta 系统

多重升级树系统。玩家可以将资源投入到不同的升级分支（如产出倍率、自动化程度、特殊加成等），每个分支有独立的等级和效果。这要求玩家做出策略选择，而非无脑全升。

prestige（转生）系统：在达到某个阶段后可以重置进度，但获得永久加成，加速下一轮的成长。这是维持长期可玩性的关键设计。

## 实现难度

低 — 核心循环简单，最大难点是数值平衡，需要确保不同阶段的成长曲线平滑且始终有追求目标
