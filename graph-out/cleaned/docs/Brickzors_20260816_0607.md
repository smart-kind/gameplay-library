# Brickzors（Brickzors）

- **类型**: 解谜 / 消除 / 物理
- **平台**: Mobile (iOS+Android)
- **开发商**: 移动平台独立解谜游戏
- **首次发布**: 约 2010 年代
- **一句话描述**: 通过策略性地消除砖块来完成关卡目标的益智小游戏

## 玩法规则

游戏画面呈现一个由彩色砖块组成的网格或结构，玩家通过点击或拖拽来消除砖块。屏幕上方显示关卡目标（消除指定数量的砖块、达到目标分数、清除特定颜色等）。

玩家点击一组相邻的同色砖块来消除它们。消除后上方的砖块因重力下落填补空缺，可能触发连锁消除反应。每次消除获得的分数取决于消除的砖块数量——越多越好。

某些关卡可能有特殊机制：不可消除的固定砖块、需要多次点击的强化砖块、会改变颜色的变色砖块、或限时消除的倒计时。

游戏目标是完成每个关卡的特定目标。某些版本中，如果无法完成目标（没有可消除的组合或步数用完），则游戏失败。

## 核心循环

观察砖块布局 → 选择消除组合 → 触发连锁反应 → 获得分数 → 完成关卡目标

## 核心机制

- **相邻消除**: 点击一组相邻同色砖块同时消除，消除数量越多分数越高
- **重力连锁**: 消除后上方砖块下落，可能形成新的同色相邻组，产生连锁反应
- **关卡目标**: 不同关卡有不同目标（分数、特定砖块数量、清除所有砖块），要求不同策略
- **特殊砖块**: 炸弹砖块（消除周围）、彩虹砖块（消除所有同色）、锁定砖块（需要先解锁）
- **步数限制**: 部分关卡限制操作次数，要求精确规划每一步

## 为什么好玩

消除类游戏的"再来一局"魔力——每次连锁反应都带来即时的视觉和数值反馈。规划最优消除路径的智力挑战让人沉浸。连锁反应的意外惊喜（消除一小块触发大串连锁）带来爽快感。

## 粘性来源

关卡递增难度是核心粘性——每个新关卡都是一个新的谜题。三星评分系统鼓励反复挑战。连锁反应的爽快感提供了即时满足，让人忍不住"再玩一关"。

## Meta 系统

关卡解锁系统：完成当前关卡解锁下一关。某些版本有星星收集系统——每关最多三星，总星数决定解锁特殊关卡。

## 实现难度

低。核心逻辑是网格状态管理和简单的重力模拟。最大的技术难点是连锁反应的动画流畅性和视觉特效的优化。
