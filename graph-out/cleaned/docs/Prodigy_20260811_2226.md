# 神童数学（Prodigy Math Game）

- **类型**: 教育 / MMORPG / 数学学习
- **平台**: Web（浏览器）/ Mobile（iOS+Android）
- **开发商**: Prodigy Education（加拿大教育科技公司）
- **首次发布**: 2011（私立学校试点）；2014 年公开发布
- **一句话描述**: 将数学练习包装成 MMORPG 冒险游戏——玩家通过正确回答数学问题来施放魔法、击败怪物

## 玩法规则

游戏画面是卡通风格的奇幻世界俯视图。玩家创建一个角色（小法师），在开放世界中探索不同的区域和地牢。

核心玩法是回合制战斗——当玩家遇到怪物时进入战斗画面。战斗中，玩家每施放一个魔法攻击，需要正确回答一道数学题。答对则魔法生效，答错则攻击失败。数学题的难度根据玩家的年级和水平自动调整。

除了战斗，玩家还可以收集装备（法杖、帽子、宠物等）、完成任务、探索地图、与其他玩家互动（非战斗的社交功能）。装备和宠物可以通过完成任务或游戏内货币获得。

游戏有明确的进度系统——角色等级提升、解锁新区域、收集新装备。所有这些进度都建立在"回答数学问题"的基础上。

## 核心循环

探索地图 → 遇到怪物 → 回答数学题施放魔法 → 获得经验和装备 → 继续探索

## 核心机制

- **自适应数学题库**：系统根据玩家的年级和表现自动调整题目难度。答对了提高难度，答错了降低难度。这确保了每个学生都在"最近发展区"内练习。
- **RPG 进度系统**：角色升级、装备收集、宠物养成、任务完成——这些 RPG 元素提供了外在动机，让学生愿意回答更多的数学题。
- **战斗回合制**：每次攻击需要回答一道数学题，答对则攻击成功。这确保了学习是游戏的核心，而不是附属品。
- **教师仪表板**：教师版本可以看到每个学生的进度、哪些数学概念掌握得好、哪些需要加强。

## 为什么好玩

Prodigy Math 成功地把"做数学题"这个枯燥的活动包装成了一个有趣的 RPG 冒险。学生不是在"做作业"，而是在"打怪升级"——但本质上，他们确实在做数学题。这种"伪装"让它成为少数真正有效的教育游戏之一。

## 粘性来源

- **RPG 进度**：装备收集、宠物养成、角色升级提供了持续的外在动机
- **自适应难度**：题目难度始终在"有点挑战但能答对"的范围内，不会太难（挫败）也不会太简单（无聊）
- **社交元素**：可以看到其他玩家的装备和宠物，激发收集和比较的欲望

## Meta 系统

完整的 RPG 外围系统：角色等级、装备收集、宠物养成、任务系统。所有这些 Meta 系统的核心目的是激励学生回答更多的数学问题。

## 实现难度

中-高 + 需要完整的 MMORPG 架构（角色系统、物品系统、战斗系统、多人同步）+ 自适应题库系统 + 教师仪表板。最大技术难点是自适应算法——确保每个学生都能得到合适难度的题目，同时保持游戏的趣味性。
