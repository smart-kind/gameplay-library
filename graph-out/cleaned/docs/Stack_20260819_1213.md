# 叠叠高（Stack）

- **类型**: 休闲 / 堆叠
- **平台**: Mobile (iOS+Android)
- **开发商**: Ketchapp
- **首次发布**: 2016
- **一句话描述**: 在精准时机点击屏幕，将移动中的方块层层堆叠，方块越高越好。

## 玩法规则

游戏画面底部有一个静止的基础方块。每一轮，一个新的方块从屏幕一侧水平滑入，覆盖在已有堆叠方块的上方。玩家唯一能做的操作是**点击屏幕**——点击的瞬间，当前移动中的方块停止运动并落下。

方块停止后，**超出下方方块边界的部分会被切除**，只保留与下方方块重叠的部分。切除的部分会从堆叠上掉落，同时屏幕上的方块变得越来越小。下一轮的方块基于裁剪后的新宽度继续移动。

游戏目标是将方块堆得越高越好。随着层数增加，方块的移动速度会逐渐加快，颜色也随之渐变，形成视觉上的彩虹塔。当方块的宽度被裁切到趋近于零（即玩家连续失误导致重叠区域过小）时，游戏结束。

## 核心循环

移动方块 → 在正确时机点击 → 方块被裁切变小 → 下一轮方块基于新宽度继续 → 重复堆叠直到失败

## 核心机制

- **精准时机裁切**：每次点击时机越准，保留的方块面积越大，后续操作空间也越大。失误会导致方块越来越窄，形成"雪球效应"的压力递增。
- **速度递增**：每堆叠几层，方块的水平移动速度加快，反应窗口缩小，形成自然的难度曲线。
- **色彩渐变**：方块颜色随层数渐变（彩虹效果），给予玩家强烈的视觉成就感，激励继续堆叠。
- **掉落碎片反馈**：被切除的部分掉落时有物理下落动画和音效，强化了"切割"的爽快感。

## 为什么好玩

Stack 的核心乐趣在于"差一点就完美"的紧张感和连续精准点击的成就感。每次点击都像走钢丝，玩家的大脑在"再叠一层"和"已经够高了"之间拉扯。彩虹塔的视觉奖励让每次成功都像在创造一件艺术品。

## 粘性来源

- **自我挑战**：分数即层数，玩家会不断追求打破自己的最高纪录。
- **差一点就成功的不甘心**：方块在最后几层被切掉时的懊恼感极强，立刻想再来一局。
- **极简操作**：单点即玩，碎片时间友好，没有任何学习门槛。
- **视觉满足感**：彩虹塔的渐变色提供了天然的收集/成就驱动。

## Meta 系统

无。纯街机模式，无成长系统。

## 实现难度

低。核心逻辑仅为矩形碰撞检测和裁切，移动动画可用简单的线性插值实现。最大技术难点是裁切时的视觉反馈（掉落碎片的物理动画）和颜色渐变的平滑过渡。
