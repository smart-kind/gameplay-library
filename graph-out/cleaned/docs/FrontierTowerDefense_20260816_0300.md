# Frontier Tower Defense

- **类型**: 塔防
- **平台**: Mobile (iOS+Android)
- **开发商**: Frontier Developments
- **首次发布**: 2011
- **一句话描述**: 一款经典塔防游戏，玩家在路径旁放置防御单位阻止敌人到达基地
- **PocketGamer评分**: 3/10

## 玩法规则

玩家需要在敌人行进路径的两侧放置各种防御塔单位，阻止敌人从入口到达自己的基地。游戏采用经典的塔防布局，玩家可以看到敌人沿着预设路径前进，防御塔自动攻击范围内的敌人。

玩家通过点击屏幕选择要建造的防御塔类型，然后点击地图上的有效位置进行放置。不同类型的防御塔有不同的攻击范围、伤害值和特殊效果。当敌人被消灭时，玩家获得金币奖励。

游戏的目标是在有限的资源下合理布置防御塔，确保没有任何敌人能够到达基地。随着关卡推进，敌人的数量和种类会增加，需要玩家不断升级防御塔或调整布局策略。玩家获得的金币可以用来建造新的防御塔、升级已有防御塔的攻击力/范围/射速，或在关卡之间解锁新的塔类型。

## 核心循环

放置/操作 → 获得奖励/进展 → 升级/解锁新内容 → 挑战更高难度

## 核心机制

- **机制1**：塔防核心循环 — 通过塔防操作完成关卡目标，获得金币/分数奖励
- **机制2**：渐进式难度 — 每个关卡引入新的元素或增加复杂度，玩家需要调整策略
- **机制3**：资源管理 — 有限的建造材料/金币/时间，需要玩家做出取舍决策

## 为什么好玩

Frontier Tower Defence是款塔防游戏，但在 genre 基础控制上就出了问题，操控糟糕、设计决策怪异。 游戏的评分为3/10，说明这款游戏有一定亮点但也有明显不足。

## 粘性来源

具体到机制层面：核心循环的"完成关卡→获得奖励→解锁新内容"驱动玩家持续游玩；渐进式难度带来的挑战感让玩家想"再来一关"；解谜类游戏特有的"顿悟时刻"（想通了解法）提供强烈的成就感。

## Meta 系统

外围成长系统：通过关卡获得的金币/分数可以解锁新的塔类型/角色/赛道，或升级已有元件的性能。对核心玩法的影响：解锁内容提供了新的策略选择，但不改变核心操作方式。

## 实现难度

低 — 核心玩法基于成熟的塔防机制，最大技术难点在于AI路径规划和实时响应。
