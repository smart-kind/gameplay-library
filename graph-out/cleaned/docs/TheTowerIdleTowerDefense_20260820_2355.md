# The Tower（The Tower - Idle Tower Defense）

- **类型**: 放置塔防 / 增量游戏
- **平台**: Mobile (iOS+Android)
- **开发商**: Tech Tree Games LLC
- **首次发布**: 2021
- **一句话描述**: 一款增量塔防游戏，玩家只控制一座塔，通过永久升级来抵御越来越强的敌人波次。

## 玩法规则

游戏界面中央显示一座塔，四周不断涌来敌人波次。塔自动攻击范围内的敌人，玩家不能手动瞄准或移动塔，但可以进行各种永久升级。

升级系统分为多个分支：攻击力（增加每次伤害）、攻击速度（缩短射击间隔）、攻击范围（扩大覆盖区域）、金币获取（增加击杀奖励）、特殊能力（暴击率、穿透、闪电链等）。

每击杀一定数量敌人后，玩家获得升级点数，可以选择一个升级项目。升级是永久性的，即使离线后再次上线也保留。

游戏有转生（Prestige）机制：当进度达到瓶颈时，玩家可以选择重置所有升级，换取一种永久加成代币。代币提供全局倍率提升（如所有升级效果+10%），使后续进度更快。

敌人波次无限递增，每波敌人血量/数量增加。游戏没有通关概念，目标是尽可能推进到更高的波次。

## 核心循环

塔自动击杀敌人 → 获得升级点数 → 选择永久升级 → 推进更高波次 → 转生获取全局倍率

## 核心机制

- **永久升级树**: 每次升级永久生效，玩家在任何时刻都能感受到变强的正向反馈。多分支升级提供策略选择——优先攻击还是先扩范围？
- **转生倍率系统**: 重置进度换取全局倍率，典型的增量游戏设计。转生后前期进度飞快，中期遇到新瓶颈，再次转生，形成螺旋上升的成长曲线
- **离线进度**: 离线期间塔继续自动击杀（效率较低），上线后可领取离线收益。降低游玩压力，放着也能变强的安心感

## 为什么好玩

将塔防的看塔打怪满足感与增量游戏的数值成长结合。不需要操作技巧，纯粹的数值规划乐趣。每次转生后的加速感让人上瘾，再来一次就能突破的心理持续驱动。

## 粘性来源

数值成长的确定性反馈（每次升级都看得到数字变大）；转生后碾压前期关卡的爽快感；更高波次的解锁目标；离线收益的回归动力。

## Meta 系统

- **转生代币与永久倍率**: 转生获得代币，代币提供全局倍率加成
- **对核心玩法的影响**: 倍率使后续升级效果成倍放大，是长期进度的核心驱动力

## 实现难度

低 — 增量游戏逻辑成熟，最大技术难点是数值曲线设计（太陡则卡关、太平则无聊）和大量升级选项的平衡
