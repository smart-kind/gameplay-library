# 形状工厂（Shapez.io）

- **类型**: 工厂建造 + 自动化解谜
- **平台**: Web (浏览器) / PC (Steam)
- **开发商**: tobes
- **首次发布**: 2020
- **一句话描述**: 在无限平面上建造自动化生产线，将基础形状切割、旋转、染色，加工成目标形状并交付

## 玩法规则

游戏画面是俯视角的无限平面。玩家从中心的提取器开始，提取器从地下提取基础形状（圆形、方形、星形等），通过传送带运输到加工机器。

加工机器包括：切割器（将形状切成两半）、旋转器（旋转90度）、染色器（给形状上色）、合并器（将两个形状叠在一起）、平衡器（将传送带上的物品均分到两条线）。

每个关卡会给出一个目标形状（如"红色的半圆叠在蓝色的半方上"），玩家需要设计一条生产线来生产这个形状。完成后解锁下一个更复杂的目标形状。

传送带和机器的布局需要精心设计。生产线越往后越复杂，需要管理多条传送带的交汇、平衡、分叉。空间利用率是核心挑战。

游戏没有敌人、没有时间限制、没有资源枯竭，完全是纯粹的工厂建造体验。

## 核心循环

观察目标形状 → 设计生产线 → 放置传送带和机器 → 观察运行 → 优化效率 → 解锁下一个形状

## 核心机制

- **组合逻辑**：每个目标形状都是基础形状经过一系列操作的结果。玩家需要逆向思维：从目标形状反推需要哪些操作，然后正向搭建生产线。
- **传送带管理**：随着关卡推进，生产线越来越长，传送带交汇处的拥堵成为主要问题。平衡器和分流器是解决拥堵的关键工具。
- **空间优化**：有限的提取器数量和传送带长度上限迫使玩家优化空间布局。高效的布局可以用更少的资源生产更多形状。

## 为什么好玩

纯粹的"流水线"满足感。看着形状在传送带上移动、被切割、旋转、染色、合并，最终变成目标形状，有一种工程美学。没有敌人和压力，是"禅意"版的工厂游戏。

## 粘性来源

- **工程美感**：优化生产线布局本身就是一种解谜乐趣
- **渐进复杂度**：从简单的切割到复杂的多色合并，难度自然递增
- **"我可以做得更好"**：即使通关，玩家也会想"能不能用更少的机器完成"
- **无压力环境**：没有时间限制和敌人，可以按照自己的节奏享受

## Meta 系统

- **科技解锁**：每完成一个目标解锁新的机器类型
- **无限模式**：通关后可以继续挑战更复杂的形状
- **速度跑**：社区有计时挑战，比拼最快通关时间

## 实现难度

中。2D传送带和物品流动的逻辑需要精确的模拟。最大的技术难点是性能优化——当生产线扩展到数千个机器和传送带时，需要高效的更新算法来保持流畅。
