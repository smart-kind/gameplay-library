# My Little Pony: Friendship is Magic (小马宝莉：友谊魔法)

- **类型**: 模拟经营 / 社交
- **平台**: Mobile (iOS+Android)
- **开发商**: Gameloft
- **首次发布**: 2012
- **一句话描述**: 基于同名动画改编的小镇模拟经营游戏

## 玩法规则

玩家在 Ponyville 小镇中建造和管理各种设施，收集不同的小马角色，完成剧情任务。

游戏界面以俯视视角呈现小镇地图。玩家通过点击空地选择要建造的建筑——房屋、商店、装饰物等。每种建筑需要一定的游戏内货币和时间来建造。

小马角色是游戏的核心收集元素。每种小马有独特的外观和技能。玩家可以通过完成任务或抽奖获得新小马。放置小马在对应建筑上可以获得额外收益。

游戏包含故事模式，重现动画中的经典场景和剧情。完成剧情任务获得奖励和解锁新内容。

## 核心循环

建造设施 → 收集小马 → 完成任务 → 获得资源 → 扩建小镇

## 核心机制

- **小镇建设**：自由放置各种建筑和装饰，打造个性化的小镇
- **角色收集**：收集不同外观和技能的小马，增加小镇活力和产出
- **任务系统**：剧情任务和日常任务提供目标和奖励
- **社交互动**：访问朋友的小镇，互相赠送礼物和协作

## 为什么好玩

对动画粉丝来说，收集和培养喜爱的小马角色有很强的吸引力。小镇建设的创造性和任务系统的目标感让游戏有持续的游玩动力。

## 粘性来源

IP角色的收集欲 + 小镇建设的创造性 + 剧情任务的持续目标 + 社交互动的社区感

## Meta 系统

小马收集系统 — 通过任务、抽奖和活动收集不同稀有度的小马角色

## 实现难度

中 — 模拟经营系统相对成熟，最大技术难点在于角色动画的美术质量和IP还原度
