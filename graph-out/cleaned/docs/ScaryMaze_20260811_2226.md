# 恐怖迷宫（Scary Maze Game）

- **类型**: 恐怖 / 恶作剧 / 反应类
- **平台**: Web（浏览器）/ Flash（原始版）
- **开发商**: Jeremy Winterrowd
- **首次发布**: 2004
- **一句话描述**: 表面上是一个需要精确操作的迷宫游戏，但在第三关结束时会突然出现一张恐怖图片（来自《驱魔人》的 Regan MacNeil）并伴随尖叫声

## 玩法规则

游戏画面是一个简单的迷宫俯视视角。玩家需要用鼠标控制一个点（或光标）沿着迷宫的路径移动，不能碰到墙壁。

第一关和第二关是"正常"的迷宫——路径较宽，容易通过。玩家逐渐放松警惕，专注于"不要碰到墙壁"。

第三关的迷宫路径非常狭窄，需要高度集中注意力和精确的鼠标控制。当玩家接近终点时，屏幕突然闪现一张恐怖图片（《驱魔人》中被附身的 Regan MacNeil 的脸）并伴随尖锐的尖叫声——这是一个 jump scare（突然惊吓）。

这本质上不是一个"游戏"，而是一个恶作剧——设计用来吓人的。玩家在 2000s 经常用它来恶作剧朋友——让他们玩这个"迷宫游戏"，然后看他们被吓到的反应。

## 核心循环

移动鼠标穿过迷宫 → 越来越专注 → 突然被吓到 → 笑（或尖叫）

## 核心机制

- **精确操作**：迷宫路径狭窄，需要精确的鼠标控制。这要求玩家高度集中注意力，为 jump scare 做准备。
- **渐进难度**：前两关容易，第三关极难。玩家在前两关建立信心，第三关需要全神贯注——这正是 jump scare 最有效的时机。
- **Jump Scare**：游戏的核心"机制"就是突然惊吓——在玩家最放松（以为快通关了）或最紧张（专注于狭窄路径）的时候突然给出恐怖画面和声音。

## 为什么好玩

Scary Maze Game 的乐趣不在于游戏本身（它几乎没有任何游戏性），而在于"看别人被吓到"的社交娱乐性。在 2000s 的互联网文化中，它是一个经典的恶作剧工具——和朋友分享链接，看他们被吓到的反应，然后一起笑。

## 粘性来源

- **恶作剧乐趣**：核心乐趣是分享和看别人被吓到
- **怀旧价值**：作为早期互联网文化的代表，它有怀旧价值
- **短视频素材**：在 YouTube/TikTok 时代，它仍然是制作反应视频的好素材

## Meta 系统

无。

## 实现难度

极低 + 简单的 2D 迷宫、鼠标位置检测、定时触发图片和声音。几乎是最简单的游戏之一。
