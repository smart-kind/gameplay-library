# 跳跳蛙2：城市大逃亡（Hoppy Frog 2 - City Escape）

- **类型**: 无尽跳跃
- **平台**: Mobile (iOS+Android)
- **开发商**: Turbo Chilli Pty Ltd
- **首次发布**: 2015
- **一句话描述**: 经典无尽跳跃游戏的续作，操控青蛙在城市天际线上不断跳跃逃离追捕

## 玩法规则

游戏呈现3D卡通风格的画面，玩家操控一只绿色青蛙在连续的平台之间跳跃。操作方式为点击屏幕控制跳跃方向和力度。

青蛙需要落在各种平台、屋顶、气球、移动物体上，不能掉落到屏幕下方。场景中散布着金币收集品和特殊道具（如弹簧可跳得更高，气球可缓慢飘浮）。

追逐者（鲨鱼等敌人）从下方逼近，增加紧迫感。如果青蛙停留太久或跳跃不够远，追逐者就会追上导致游戏结束。

随着游戏进行，平台间距变大、移动速度加快、平台类型变化（从固定平台到移动平台到消失平台），难度逐渐递增。

游戏支持离线游玩，无需网络连接。每次游戏结束后会显示分数和最高记录对比。

## 核心循环

连续跳跃 → 收集金币和道具 → 达到更远距离 → 刷新个人记录

## 核心机制

- 无尽跳跃机制：核心玩法是持续在平台间跳跃求生，每次跳跃的方向和力度选择决定生死
- 追逐者压力系统：鲨鱼等敌人从后方逼近形成持续压力，迫使玩家不断前进不能停留
- 道具辅助系统：弹簧、气球、磁铁等道具在关键时刻提供救命机会，增加运气和策略元素

## 为什么好玩

简洁但极具挑战性的操作体验，每次成功跨越大距离平台都带来成就感。

追赶者的存在制造持续紧张感，让简单的跳跃玩法变得刺激。

3D卡通画风和可爱的青蛙角色降低了失败的挫败感，青蛙逃跑时的滑稽动画让每次游戏都有视觉上的新鲜感。

## 粘性来源

无尽模式天然追求再试一次超越记录的心理——每次失败后都会觉得差一点就能超越上次。每次失败后快速重开减少挫败感

## Meta 系统

纯街机分数制无外围系统。最高分记录是唯一的长期目标，驱动玩家反复挑战

## 实现难度

低 — 操作极简但精通需要大量练习。最大的技术难点在于物理手感的精细调校和不同设备上的操作一致性
