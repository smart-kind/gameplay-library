# Idle Factory Tycoon

- **类型**: 放置 / 管理
- **平台**: Mobile
- **开发商**: Kongregate
- **首次发布**: 2019
- **一句话描述**: 结合管理策略和放置机制的工厂经营游戏。

## 玩法规则

玩家经营工厂，从一条生产线开始逐步扩展到多条生产线。核心是效率优化——升级机器、雇佣经理、优化生产流程。

放置机制允许离线获得收入。经理系统自动化生产线。多条生产线需要资源分配策略。

## 核心循环

升级机器 → 雇佣经理 → 扩展生产线 → 优化效率

## 核心机制

- 多生产线管理：每条独立升级
- 经理系统：自动化生产
- 效率优化：资源分配策略
- 离线收益：持续收入
- 扩展系统：新生产线解锁

## 为什么好玩

从单一生产线到工厂帝国的成长过程令人满足。效率优化的策略深度让放置玩法保持参与感。

## 粘性来源

- 生产线扩张：从一条到多条的成长
- 效率优化：持续寻找更优配置
- 经理雇佣：从手动到自动的转型
- 离线收入：不在线也在赚钱

## Meta 系统

生产线解锁和经理雇佣。升级设施、雇佣经理、开新生产线。

## 实现难度

低。放置管理核心系统简单，多生产线平衡是难点。
