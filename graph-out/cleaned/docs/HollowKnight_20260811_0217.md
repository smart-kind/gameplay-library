# Hollow Knight（空洞骑士）

- **类型**: 银河恶魔城 / 动作冒险
- **平台**: PC / Mobile (iOS+Android) / Switch / PS / Xbox
- **开发商**: Team Cherry
- **首次发布**: 2017
- **一句话描述**: 探索广阔地下王国圣巢的2D动作冒险游戏，在充满危险和秘密的世界中战斗、收集能力、解锁新区域。

## 玩法规则

游戏为横向卷轴2D视角，玩家控制一个无名小骑士在庞大且相互连通的地下王国"圣巢"中探索。初期只能到达一小片区域，随着获得新能力（冲刺、二段跳、爬墙等），逐渐解锁更多区域。

战斗使用骨钉（武器）进行近战攻击，可以上劈、下劈和斜劈。法术（消耗灵魂）提供远程攻击和治疗能力。击败敌人获得"吉欧"（货币），用于购买物品和升级。

地图通过购买和探索逐步揭示——在特定NPC处购买地图和羽毛笔后，走过的区域会显示在地图上，但需要自己标注。没有自动寻路或任务标记，探索完全依赖玩家的记忆和方向感。

长椅上可以坐下休息，这重置所有敌人、恢复满血满灵魂，但也刷新了已击杀的Boss（除最终Boss）。死亡后在最近的长椅复活，但丢失所有吉欧，需要回到死亡地点回收。如果途中再次死亡，吉欧永久消失。

## 核心循环

探索新区域 → 战斗获得吉欧 → 购买能力和升级 → 解锁新能力 → 进入之前无法到达的区域 → 发现新秘密

## 核心机制

- **能力锁（Metroidvania Progression）**：新能力解锁新区域的经典设计。冲刺让你能穿过尖刺、二段跳到达高处、爬墙上墙、超级冲刺穿越更远距离、螳螂爪让你能攀墙。每次获得新能力都意味着大片的旧区域可以重新探索。
- **灵魂系统**：攻击敌人积累灵魂，灵魂可以用来施放法术（伤害技能）或治疗。战斗中需要在攻击积累灵魂、使用法术输出、使用灵魂治疗之间做实时决策。
- **护符系统**：装备不同的护符（被动效果）来定制角色能力，但护符槽位有限。需要权衡——带更多攻击护符还是生存护符？这个系统提供了深度的角色定制。

## 为什么好玩

探索圣巢的过程本身就是一种冒险——每进入一个新区域都有独特的氛围、音乐和敌人。当你终于用新能力到达之前看到但无法抵达的地方，发现隐藏的房间或Boss时，那种"我做到了"的感觉是其他游戏给不了的。

## 粘性来源

- **探索欲望**：地图巨大且秘密众多，想知道"那片区域后面有什么"
- **Boss挑战**：每个Boss有独特的攻击模式，学习并击败它们带来成就感
- **全收集目标**：112%完成度要求收集所有物品、打败所有Boss、完成所有挑战
- **免费DLC内容**：多个大型免费更新增加了大量内容，性价比极高

## Meta 系统

- **吉欧**：货币系统，用于购买物品、地图和升级
- **护符**：被动装备系统，提供多种build选择
- **Boss万神殿**：通关后的终极挑战模式，连续挑战所有Boss
- **对核心玩法的影响**：货币和升级系统辅助探索，但不改变核心——技术和地图记忆才是通关关键

## 实现难度

高 + 银河恶魔城游戏的关卡设计难度极高——需要确保每个区域的能力锁逻辑严密（不能出现能力不够就能到的漏洞），同时保持探索的流畅感。战斗系统的平衡、Boss设计的多样性、音乐和氛围的统一性都需要大量精心设计。最大的技术难点是无缝大地图的管理和加载。
