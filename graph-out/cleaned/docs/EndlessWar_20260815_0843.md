# 无尽战争（Endless War (Last War: Survival)）

- **类型**: 生存 / 塔防 / 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: FUNFLY PTE. LTD.
- **首次发布**: 2023
- **一句话描述**: 一款末日丧尸题材的生存策略游戏，在丧尸潮中存活并建设和扩建自己的庇护所。

## 玩法规则

游戏分为两个主要部分：跑酷躲避和基地建设。

跑酷部分：画面呈现多条赛道，丧尸和障碍物从屏幕上方涌来。玩家通过左右滑动选择赛道躲避丧尸和障碍，点击屏幕射击消灭丧尸。不同赛道有不同数量和类型的丧尸。

基地建设部分：视角切换到俯瞰的基地地图，玩家可以建造和升级各种设施（兵营、武器库、农场、围墙）。设施提供不同功能：兵营增加士兵数量，武器库解锁新武器，农场提供食物资源。

游戏目标是在丧尸潮中尽可能存活更久，同时不断扩大庇护所。资源通过跑酷关卡和基地生产获得。

## 核心循环

玩什么 → 得到什么 → 用来做什么：跑酷躲避加射击丧尸获得资源，扩建基地和训练士兵来抵御更强大的丧尸潮

## 核心机制

- **赛道选择策略**：三条赛道各有不同丧尸密度和障碍类型，快速判断最优路线是生存关键。有时故意走困难路线获取更好奖励，风险与收益并存
- **基地建设系统**：多种设施各司其职，合理分配资源决定基地发展方向。设施等级影响整体实力，需要优先升级关键设施
- **丧尸波次递进**：每波丧尸数量和种类递增，从普通丧尸到特殊变异体，难度曲线陡峭。后期需要合理搭配兵种才能抵挡

## 为什么好玩

跑酷部分的紧张刺激加上基地建设的策略深度，两种截然不同的玩法结合在一起不会单调。丧尸末日题材代入感强，每次存活下来都有成就感。

## 粘性来源

基地建设进度（不想放弃辛苦建立的基地）+ 数值成长（士兵和武器升级）+ 丧尸波次的挑战欲。每天上线看看基地发展情况形成习惯。

## Meta 系统

- **基地建设**：多种设施可升级，每个设施有不同等级解锁不同功能。设施之间有协同效应
- **士兵训练**：训练不同类型士兵（步兵、射手、医疗），组成作战队伍。兵种搭配影响战斗效率
- **对核心玩法影响**：基地和士兵实力直接影响跑酷关卡的难度和奖励。强大的基地可以降低生存压力

## 实现难度

中 — 跑酷操作加基地管理的双重系统，需要同时掌握两种玩法。最大技术难点在于两个系统之间的数据同步和平衡。需要确保跑酷和基地建设之间有合理的资源流转。
