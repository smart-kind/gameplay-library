# 推挤大师（Push Master）

- **类型**: 超休闲/物理
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2023
- **一句话描述**: 推挤物体闯关游戏

## 玩法规则

玩家控制角色将方块或其他物体推入指定区域。通过拖拽或滑动控制推动方向和力度。物体有物理属性，可能滑动、翻转或与其他物体碰撞。关卡目标通常是将所有物体推入指定位置或清除跑道上的障碍。推动需要考虑物体的惯性和碰撞连锁反应。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

选择推动目标 → 拖拽推动 → 观察物理效果 → 完成关卡

## 核心机制

- **物理推动**:  基于物理的物体推挤和碰撞
- **连锁反应**:  一次推动可能引发连锁效果
- **关卡递增**:  物体数量和布局逐渐复杂

## 为什么好玩

物理连锁反应的满足感，一次完美推动引发连锁效果特别爽快

## 粘性来源

寻找最优解的挑战；新关卡布局保持新鲜感

## Meta 系统

关卡解锁系统

## 实现难度

低 - 核心是2D/3D物理引擎 - 物理碰撞的精确性和性能
