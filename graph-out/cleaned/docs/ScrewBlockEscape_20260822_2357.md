# 螺丝积木逃脱（Screw Block Escape）

- **类型**: 物理解谜 / 逃脱
- **平台**: Mobile (iOS+Android)
- **开发商**: IEC GAMES AUSTRALIA PTY LTD
- **首次发布**: 2025
- **一句话描述**: 通过移除螺丝、释放积木块，利用物理重力解开机关逃脱的益智解谜游戏。

## 玩法规则

画面中有一个被螺丝和木板固定的结构，下方是出口或目标区域。玩家需要通过移除特定位置的螺丝来释放积木块，让积木块按照正确的方式掉落或移动，最终为出口让出通道。

玩家点击螺丝将其移除，被该螺丝固定的积木块会因重力而下落或移动。移除顺序至关重要——错误的顺序可能导致积木块卡在错误位置，阻挡出口或使结构无法继续拆解。

某些关卡引入特殊机制：弹簧（移除螺丝后积木弹起）、传送带（积木沿特定方向移动）、磁铁（影响积木移动路径）等。这些机制增加了解谜的维度。

部分关卡设有步数限制——只能移除有限数量的螺丝，要求玩家精确规划每一步。还有部分关卡需要在移除螺丝前预览重力效果，帮助玩家规划策略。

## 核心循环

观察结构 → 规划移除顺序 → 点击螺丝释放积木 → 检查出口是否畅通

## 核心机制

- 顺序依赖机制：螺丝的移除顺序直接决定积木的运动轨迹和最终位置。这不是'移除所有螺丝就行'的游戏——每一步都会改变物理状态，形成动态的解谜过程。
- 物理模拟机制：积木受重力、碰撞、摩擦等物理规则影响，运动轨迹可预测但需要空间想象力。这种'可计算但需要想清楚'的设计让玩家有掌控感。
- 机制叠加机制：后期关卡加入弹簧、传送带、磁铁等元素，从纯重力问题变成多物理系统的综合谜题。每个新机制引入时都通过简单关卡教学，然后逐步增加复杂度。

## 为什么好玩

移除螺丝、看着积木按预期（或意外）运动的过程本身就有物理模拟的爽感。正确规划后'一切按预期发生'的满足感，和'没想到还能这样'的创意解法，都是独特的乐趣。

## 粘性来源

物理谜题的'差一点'效应特别强——明明思路对了但顺序差一步。这种'就差一点'的张力驱动反复尝试。此外，看到积木按自己预期的方式运动的满足感是核心粘性。

## Meta 系统

关卡解锁制，每完成一组关卡解锁新机制。无付费数值成长，部分版本有提示系统（看广告获取解法提示）。

## 实现难度

中等。需要2D物理引擎支持（重力、碰撞、关节约束），最大难点在于关卡设计——需要确保每个关卡都有合理且唯一的解法，同时解法不是显而易见的。

游戏的核心乐趣在于'预判-验证'循环：玩家在脑海中模拟移除螺丝后的物理效果，然后点击确认。当实际运动与预期一致时获得满足感，当出现意外时则获得学习机会。这种循环让游戏既是智力挑战又是物理实验，玩家同时在使用逻辑思维和空间想象力。
