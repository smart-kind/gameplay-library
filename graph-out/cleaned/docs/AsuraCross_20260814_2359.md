# Asura Cross

- **类型**: 动作 RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款融合即时战斗与角色养成的动作 RPG 手游

## 玩法规则

玩家在游戏中控制角色在战场上移动和战斗。屏幕下方通常显示技能按钮，点击按钮释放不同的攻击技能或法术。敌人会按波次出现，玩家需要合理安排攻击顺序，优先消灭威胁最大的敌人。

战斗过程中角色会获得经验值，升级时可以选择提升攻击力、防御力或解锁新技能。游戏关卡通常以章节形式组织，每关有最终 Boss 等待挑战。

游戏画面采用东方神话风格，角色设计精美。界面布局清晰，上方显示角色血量和关卡进度，下方为操作区。玩家可以通过连招系统组合不同技能，打出高伤害输出。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

战斗获取经验和装备 → 升级强化角色 → 挑战更难关卡和副本

## 核心机制

- 波次战斗系统：敌人分多波出现，每波难度递增，考验玩家的资源管理能力
- 技能连招机制：不同技能可以组合释放，形成连招获得额外伤害加成
- Boss 战机制：每关末尾有 Boss 战，Boss 有特殊攻击模式，需要观察并找到应对策略
- 装备掉落系统：击败敌人后随机掉落装备，品质从普通到传说不等

## 为什么好玩

融合了角色养成和即时战斗的快感，看着角色从弱小成长为强大的过程有很强的成就感。连招系统让战斗充满操作乐趣。

## 粘性来源

数值成长带来的持续正反馈，配合收集新装备和角色的驱动力。每次掉落稀有装备都有惊喜感。

## Meta 系统

- 装备收集与强化系统：通过副本和任务获取装备，消耗材料升级装备属性
- 角色升星系统：收集角色碎片提升星级，解锁新技能

## 实现难度

中等 — 战斗系统设计不复杂但需要精细调优，最大的技术难点是技能连招判定和战斗数值平衡。
