# Alto's Odyssey: The Lost City

- **类型**: 无尽跑酷 / 艺术
- **平台**: Mobile (iOS+Android)
- **开发商**: Team Alto / Snowman
- **首次发布**: 2023
- **一句话描述**: 以 breathtaking 艺术风格和冥想式玩法著称的无尽跑酷，可选禅模式完全去除分数追求。

## 玩法规则

玩家控制角色 Alto 在沙漠、山脉和城市遗迹中滑行。画面为横向卷轴侧视图，背景有美丽的光影变化。玩家通过单点点击进行跳跃，长按进行后空翻。后空翻成功落地获得额外分数，失败则摔倒结束游戏。

游戏的核心是流畅的滑行体验——角色在沙丘上顺势而下，利用坡度加速，在合适时机跳跃跨越峡谷。收集金币和拯救失散的羊驼获得分数。环境中的热气流可以让角色短暂升空，彩虹是稀有但壮观的加速道。

游戏最独特的是禅模式——完全移除分数和 Game Over，玩家可以纯粹享受滑行过程中的视觉和音乐体验。日夜交替、天气变化（沙暴、雨、雪）让每次滑行都有不同的视觉感受。

## 核心循环

滑行 → 跳跃躲避障碍 → 完成特技获得分数 → 收集金币和羊驼

## 核心机制

- 单点跳跃控制：极简操作，点击即跳，长按后空翻
- 地形互动：坡度加速、热气流升空、水面滑行
- 特技系统：后空翻成功获得额外分数和连续加成
- 禅模式：移除 Game Over 和分数，纯粹享受滑行体验
- 动态环境：日夜交替、天气变化、季节更替

## 为什么好玩

Alto's Odyssey 更像一段冥想旅程而非竞技游戏。优美的视觉、舒缓的音乐和流畅的物理让每次滑行都是一种享受，禅模式更是将这种体验推向极致。

## 粘性来源

- 视觉和音乐的沉浸式体验：动态光影和配乐让游戏过程本身就是一种享受
- 禅模式：完全无压力的体验，适合放松
- 特技的精准满足感：后空翻成功落地的瞬间反馈极强
- 环境变化：每次滑行的天气和光线都不同，保持新鲜感

## Meta 系统

金币收集解锁角色和服装。部分角色和服装是装饰性的，不影响核心玩法。

## 实现难度

中。流畅的物理引擎和程序化地形生成是难点。动态光影和天气系统需要较高的美术和渲染能力。
