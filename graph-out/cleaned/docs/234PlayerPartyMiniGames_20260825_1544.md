# 多人派对小游戏合集（2 3 4 Player Party Mini Games）

- **类型**: 休闲合集 / 多人派对
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2019
- **一句话描述**: 一款支持2-4人本地多人游玩的小游戏合集，涵盖多种经典派对游戏类型。

## 玩法规则

游戏提供数十种不同类型的小游戏，每款都支持2-4名玩家在同一设备上对战或合作。

操作方式简单直观：点击、滑动、长按等基础操作。在投篮游戏中滑动屏幕控制力度，在赛车游戏中左右滑动控制方向。

每局游戏通常1-2分钟，系统自动计分，最终分数最高的玩家获胜。游戏按类别分组：体育、益智、动作、竞速等。

## 核心循环

选择游戏类型 -> 设定玩家人数 -> 开始对战 -> 计分排名 -> 换下一款

## 核心机制

- 同屏多人操作: 屏幕分为多个区域，每个玩家控制自己的区域，通过触控操作。操作区域自适应屏幕大小。
- 快速轮换: 每局游戏时间短，可以快速尝试多款不同游戏。
- 难度自适应: 根据玩家表现自动调整难度，确保各水平玩家都能享受乐趣。

## 为什么好玩

简单直观的操作让任何人都能立即上手，朋友间的竞争是主要乐趣来源。

游戏类型涵盖体育、益智、动作等多个品类，确保每个人都有自己擅长的领域。

## 粘性来源
