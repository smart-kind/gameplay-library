# Clicker Heroes

- **类型**: 角色扮演/放置
- **平台**: Mobile (iOS+Android)
- **开发商**: Playsaurus, Inc.
- **首次发布**: 2015
- **一句话描述**: 一款角色扮演类放置游戏，英雄自动战斗成长，玩家负责策略升级和方向选择

## 玩法规则

游戏主界面以战斗场景，英雄自动攻击怪物，伤害数字和金币掉落不断弹出为核心视觉元素，整体布局简洁直观。屏幕上方/中央区域展示战斗画面、英雄属性面板和进度条，玩家一眼即可了解当前的核心状态。屏幕下方或侧边排列升级按钮、技能选择和装备栏，这些是玩家可以交互的按钮或操作区域。

玩家通过点击屏幕进行攻击和选择升级路线进行核心操作。具体而言，英雄在画面中自动前进并攻击沿途的怪物。每次攻击产生伤害数字，怪物被击败后掉落金币和道具。玩家通过点击升级按钮提升英雄的属性（攻击力、防御力、生命），或在技能树中选择新的战斗技能。装备栏中可以更换武器和防具，提升整体战斗力。随着层数推进，怪物类型和强度逐渐变化。每次操作后，系统会即时给出伤害数字弹出、金币收集动画和技能释放特效，确保玩家对操作结果有清晰的感知。

游戏的核心目标是让英雄尽可能深入地探索，击败强大的Boss。为了达成这一目标，玩家需要收集战斗掉落的金币，升级英雄属性和技能，更换更强的装备，推进到更深层的战斗区域。当击败当前区域的Boss或达到层数目标时，玩家进入下一阶段或解锁新内容。反之，如果英雄生命值归零（但放置游戏通常不会真正死亡，只是暂停前进），则需要重新开始或调整策略。

随着游戏进程的推进，英雄会逐步解锁新的技能、面对更强的怪物类型，并在达到里程碑时触发转生事件。玩家需要逐步掌握技能树的最优路径规划和装备搭配，才能在更高难度下持续进步。游戏的深度在于技能树的深度组合和转生后的永久加成形成双重成长维度。不同的技能组合可以构建出截然不同的战斗风格，而转生系统确保即使到达瓶颈也能通过重置获得新的增长空间，这让简单的操作框架下蕴含着丰富的策略空间。

游戏中的装备按稀有度分为普通、稀有、史诗和传说四个等级，高稀有度装备带有随机属性词条，形成类似暗黑破坏神的装备追逐系统。

## 核心循环

自动战斗获取金币 → 升级英雄技能和装备 → 挑战更强的怪物获取更多金币

## 核心机制

- **自动战斗系统**: 英雄自动攻击敌人，伤害数值实时显示。玩家通过升级英雄属性和技能来增强自动战斗效率。战斗是全自动的，玩家的参与度体现在策略性的升级选择上，而非操作层面
- **技能树网络**: 庞大的技能树系统，每个节点提供不同的战斗加成或新能力。技能之间可能存在联动效果（如"暴击率提升"配合"暴击伤害加成"），玩家可以自由选择构建方向。某些高级技能需要多个前置技能解锁
- **转生突破**: 达到等级上限或特定里程碑后可以选择转生。转生保留部分核心能力（如永久加成点数、特殊技能），同时重置等级。转生后英雄从1级重新开始，但凭借永久加成可以更快地达到之前的高度并突破上限

## 为什么好玩

英雄自动战斗的场面本身就很爽，看着伤害数字不断跳动、怪物接连倒下，产生强烈的视觉满足感。加上庞大的技能树和转生系统，让"放置"不再是纯挂机，而是持续的策略构建过程。

每次打开游戏都能看到英雄比上次更强、走得更远，这种持续成长的确定性在随机性充斥的世界中尤为珍贵。

## 粘性来源

技能树的深度组合和转生后的永久加成形成双重粘性。看着英雄从弱小到强大的成长过程本身就是一种情感投入，"我的英雄越来越强了"的成就感让人持续投入。转生后的"加速跑"体验也很上头。

同时，每层Boss战的挑战性和"差一点就能打过"的不甘心驱动玩家不断优化装备和技能组合。

## Meta 系统

英雄转生与装备系统：转生保留核心属性和装备，获得永久加成点数。对核心玩法的影响是让英雄的成长上限不断提高，战斗效率和奖励倍率随之提升。装备系统提供额外的自定义空间。

装备词条的随机性形成了类似赌博的兴奋感——每次掉落都有可能是改变战局的极品装备。

## 实现难度

中等。技能树和自动战斗系统需要较多内容填充。最大技术难点：技能树平衡——确保所有分支都有可玩性而非单一路径最优，需要大量的数值测试和组合验证。
