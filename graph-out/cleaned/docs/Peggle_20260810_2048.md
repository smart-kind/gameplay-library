# Peggle（Peggle）

- **类型**: 弹球消除 / 精准射击
- **平台**: PC / Mobile (iOS+Android) / 主机 / Web
- **开发商**: PopCap Games
- **首次发布**: 2007
- **一句话描述**: 发射弹球击中并消除所有橙色 pegs（钉子），在物理反弹中寻找完美一球

## 玩法规则

游戏画面中布满了密密麻麻的小圆钉（pegs），大部分是蓝色，约 25% 是橙色。顶部有一个弹球发射器。

玩家左右移动鼠标/手指调整发射角度，点击发射弹球。弹球沿直线飞行，碰到 pegs 后反弹，在 pegs 之间弹跳。

每次弹球击中一个 peg，该 peg 被消除（橙色 peg 消除后变成金色并消失，蓝色 peg 消除后会重新亮起）。目标是在弹球掉落之前消除所有橙色 pegs。

每关给 10 颗弹球。弹球用完后仍有未消除的橙色 pegs = 失败。消除所有橙色 pegs = 过关。

通关时如果最后还剩弹球，会进入"Extreme Fever"模式——背景变彩虹色，播放贝多芬第九交响曲，最后一球有"魔法效果"，轻松消除剩余 pegs 获得额外分数。

## 核心循环

瞄准 → 发射弹球 → 观察反弹路径 → 消除橙色 pegs → 过关 → 获得新角色/能力

## 核心机制

- 机制1：物理反弹——弹球在 pegs 之间的反弹路径遵循真实物理（入射角=反射角），但 pegs 的密集排列导致路径难以完全预测，介于"精准"和"随机"之间
- 机制2：角色超能力——每个角色有不同"Extreme Shot"能力：Bjorn 的多球（同时发射 3 个）、Katrina 的慢动作（减速看清路径）、Isolde 的火焰球（沿途消除所有 pegs）、Claude 的指南针（显示最佳角度）等
- 机制3：自由落体球——少数关卡底部有"自由球"可以接住重新发射，增加策略性

## 为什么好玩

"最后一球清全场"的极致爽快感是 Peggle 的标志性体验。当弹球在密集的 pegs 间疯狂反弹、一个个消除橙色钉子的过程，配合彩虹+贝多芬的庆祝仪式，带来极强的正向反馈。同时"差一个就过关"的不甘心让人欲罢不能。

## 粘性来源

角色收集（10 个角色各有独特超能力）+ 超能力多样性（每换一个新角色体验完全不同）+ "差一个就过关"的再来一局冲动 + 冒险模式进度

## Meta 系统

冒险模式——选择不同角色的关卡线推进，每关有 1-3 星的评分。解锁全部角色后进入挑战模式（特殊规则的变体关卡）。

## 实现难度

低。弹球物理（Box2D 或自定义碰撞检测）+ pegs 的预设布局 + 简单的消除逻辑。技术门槛低，关卡设计（pegs 的排列）是主要工作量。
