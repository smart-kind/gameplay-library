# Yarn Loop (毛线编织解谜)

- **类型**: 休闲益智 / 手工主题
- **平台**: Mobile (iOS+Android)
- **开发商**: Combo Games
- **首次发布**: 2024
- **一句话描述**: 一款以编织为主题的休闲益智游戏，通过旋转毛线球完成图案

## 玩法规则

游戏界面展示一个编织网格，上面有彩色毛线球和已编织好的图案。目标是通过旋转毛线球的位置和角度，将毛线连接成完整的编织图案。

每个毛线球有多个出口（2到4个方向），玩家需要旋转毛线球使出口对齐。旋转操作：点击毛线球，每次点击旋转90度。毛线连接成功后会显示漂亮的编织纹理。

网格中有固定障碍物（已编织好的部分不能动）和可旋转的毛线球。部分关卡有颜色要求，同色毛线必须相连，不同颜色不能交叉。随着关卡推进，网格变大、毛线球数量增多、颜色种类增加。

游戏目标是在不限时的情况下完成所有编织图案。每关没有倒计时，可以慢慢思考。完成关卡解锁新的编织图案和配色方案。

高级关卡引入了分支路径和回路约束：某些毛线球需要同时连接多个方向，或者必须形成特定的几何图案才能过关。这增加了空间推理的复杂度。

## 核心循环

旋转毛线球对齐出口 -> 完成彩色编织图案 -> 解锁新图案和配色

## 核心机制

- **旋转连接机制**：点击旋转90度对齐管道，简单操作但需要空间想象力
- **颜色匹配约束**：同色相连、不同色不交叉的规则增加逻辑推理深度
- **无倒计时设计**：不施加时间压力，定位为放松型解谜，适合碎片时间
- **分支路径和回路约束**：高级关卡要求同时连接多个方向，增加空间推理复杂度

## 为什么好玩

看着毛线从混乱变为精美编织图案的满足感极强，柔和的色彩搭配和舒缓的节奏是完美的减压体验。

## 粘性来源

完成编织图案的视觉满足感，无时间压力的放松体验，新图案和配色的收集驱动。

## Meta 系统

图案和配色解锁。完成关卡解锁新的编织图案和配色方案。无付费系统，纯内容解锁。

## 实现难度

低 -- 旋转连接机制逻辑简单。最大技术难点是关卡自动生成算法，确保每关有解且难度递进。
