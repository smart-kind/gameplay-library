# Tap Titans（点击泰坦）（Tap Titans）

- **类型**: 放置 / 点击RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: Game Hive Corporation
- **首次发布**: 2015
- **一句话描述**: 一款放置点击类RPG游戏，玩家通过点击屏幕攻击怪物，获得金币来升级英雄、雇佣帮手和推进关卡。

## 玩法规则

游戏画面中央是玩家操控的英雄角色，前方会出现一波波怪物。英雄会自动进行基础攻击，但玩家可以点击屏幕来手动攻击，造成比自动攻击更高的伤害。

每次击杀怪物获得金币奖励，金币用于升级英雄的攻击力、解锁新技能和雇佣帮手即DPS角色自动输出。随着关卡推进，怪物的生命值按指数增长，需要更高的攻击力才能击杀。

当击败当前关卡的所有怪物后，会出现一个Boss怪物，Boss有倒计时时间限制。在时间内击杀Boss可进入下一关并获得丰厚奖励。如果超时未能击杀，则退回前一关重新积累。

游戏的核心循环非常简单直接：击杀怪物获得金币加升级加击杀更强的怪物获得更高金币，形成一个不断加速的成长循环。

## 核心循环

点击或自动攻击怪物 → 获得金币 → 升级英雄和雇佣帮手 → 击杀更强怪物 → 推进关卡 → 获得更强奖励

## 核心机制

- **机制1**：指数成长机制：怪物HP和玩家攻击力都按指数级增长，玩家需要不断升级才能推进关卡。这种数值膨胀带来持续的变强感，伤害数字从个位数飙升到亿级是游戏的核心爽点。
- **机制2**：自动加手动混合机制：英雄会持续自动攻击即放置元素，但手动点击可以造成数倍于自动攻击的伤害即点击元素。两者结合让玩家既可以挂机休息也可以爆发输出，兼顾了休闲和活跃玩家。
- **机制3**：Boss关机制：每十关出现一个Boss，有时间限制。Boss关是进度检验点，通过了获得丰厚奖励和转生机会，通不过则倒退。这种设计创造了紧张感和阶段性成就感。

## 为什么好玩

看着伤害数字从个位数飙升到百万甚至亿级，这种数值膨胀的快感是放置游戏的核心魅力。每次转生后从头开始但带着永久加成，让人想不断循环突破更高的关卡数。

## 粘性来源

数值膨胀的持续爽感加上转生系统的进度循环加上离线收益机制让不看手机也在玩，三者结合让游戏占据了玩家的碎片时间和潜意识。

## Meta 系统

英雄升级系统加帮手雇佣系统加转生即Prestige系统。转生后获得永久加成让下一次循环更快更远。技能树系统提供更多自定义选项，不同技能组合影响玩法风格。

## 实现难度

低 -- 核心是数值系统加自动战斗加点击交互，技术实现简单。最大难点是数值平衡让成长感持续但不崩坏，以及转生后的进度感设计让玩家觉得每次转生都有意义。

## 转生系统详解

转生（Prestige）是游戏的核心循环机制：

- 当玩家达到一定关卡（通常是Boss关）后可以选择转生
- 转生后关卡进度重置为第1关，英雄等级归零
- 但获得永久加成如伤害倍率提升、新帮手解锁、特殊技能
- 每次转生的加成递增，第二次转生比第一次更强
- 转生次数越多，进度推进越快，形成加速循环

这种设计让玩家不断重复"从弱到强"的成长过程，但每次循环都比上一次更快更远。
