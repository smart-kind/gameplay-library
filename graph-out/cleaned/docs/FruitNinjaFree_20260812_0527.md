# 水果忍者免费版（Fruit Ninja Free）

- **类型**: 休闲/街机
- **平台**: Mobile (iOS+Android)
- **开发商**: Halfbrick Studios
- **首次发布**: 2010
- **一句话描述**: 经典触屏切水果游戏，滑动屏幕切割飞出的水果。

## 玩法规则

水果从屏幕底部飞出，玩家用手指滑动切割它们。经典模式下游戏持续进行直到错过三个水果或切到炸弹。街机模式限时内切水果获得最高分。禅模式无炸弹，纯粹享受切割。

切割水果时有令人满意的视觉和音效反馈。连击系统奖励连续切割多个水果。炸弹是主要威胁，切到炸弹直接扣分或结束游戏。

## 核心循环

滑动切割水果 → 获得分数 → 连击获得额外奖励 → 躲避炸弹 → 追求最高分

## 核心机制

- 滑动切割：直观的触屏操控，滑动即切割
- 连击系统：连续切割多个水果获得额外分数
- 炸弹机制：切到炸弹扣分或结束游戏，增加紧张感

## 游戏模式与社交功能

除经典、街机和禅模式外，游戏还包含限时挑战模式和每日挑战。每日挑战提供特殊规则，如只能用特定方式切割水果。

社交功能允许玩家分享分数和成就，与朋友比较切割技巧。部分版本支持多人合作切割模式。

## 为什么好玩

最简单也最经典的触屏游戏之一，切割水果的满足感和连击的爽快感让人欲罢不能。

## 粘性来源

追求最高分的竞争心理，连击的爽快感，以及随时可以来一局的便利性。

## Meta 系统

免费下载，有广告和可选内购

## 实现难度

低 — 上手即玩，但高分需要练习
