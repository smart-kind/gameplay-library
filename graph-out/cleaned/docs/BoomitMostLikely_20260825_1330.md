# Boomit - Most Likely

- **类型**: 社交派对问答
- **平台**: Mobile (iOS+Android)
- **开发商**: SmartID Technologies b.v.
- **首次发布**: 2020
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

回答'最有可能'问题 -> 传递炸弹 -> 倒计时结束持有者输

## 核心机制

- **炸弹传递机制**: 玩家回答'最有可能'类型的问题后，将'炸弹'传递给下一个玩家。炸弹有倒计时，在倒计时结束时持有炸弹的人'爆炸'并失去一分。
- **社交推理问答**: 问题如'谁最有可能在聚会上迟到'，玩家需要思考并投票。这种问题天然引发讨论和笑声。
- **紧张倒计时**: 炸弹的倒计时增加了紧张感。玩家需要在有限时间内传递炸弹。这种时间压力让简单的问答变得刺激。

## 为什么好玩

'最有可能'问题本身就有娱乐性，加上炸弹倒计时的紧张感，形成了独特的游戏体验。朋友间的互相'揭穿'是最大的乐趣来源。

## 粘性来源

粘性来源于社交互动和紧张感的结合。每次问题不同，参与者反应不同，重复游玩不会腻。

## Meta 系统

- 积分系统：每次爆炸扣分
- 对核心玩法的影响：积分记录增加竞争感

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
