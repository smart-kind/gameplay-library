# 城市冠军（Urban Champion）

- **类型**: 格斗/动作
- **平台**: NES / Famicom Disk System / 3DS Virtual Console / Mobile
- **开发商**: Nintendo
- **首次发布**: 1984
- **一句话描述**: Nintendo早期的1v1格斗游戏，两个街头斗士在城市街道上对决，目标是将对手打进身后的下水道。

## 玩法规则

画面为横版，两个角色面对面站在城市街道上，身后各有一个下水道入口。玩家控制左边的斗士，电脑（或另一个玩家）控制右边的。

操作：方向键控制移动（左/右/蹲/跳），A键出拳，B键防御。攻击命中会让对手后退，连续命中会让对手不断后退直到掉进下水道。

核心机制是"击退"——每次攻击命中都会让对手后退一段距离。对手也可以攻击你，双方都在争夺"谁把谁推得更远"。街道中间偶尔会有障碍物（花盆、自行车），被击中会额外后退。

每回合有时间限制，时间结束时谁离下水道近谁就输。如果双方距离相等则平局。

## 核心循环

出拳和防御 → 击退对手 → 将对手逼进下水道获胜

## 核心机制

- **击退系统**：不是传统的"血量归零"胜负，而是"位置决定胜负"。这让战斗更像"推挤游戏"，需要持续施压而不是一次性爆发。
- **防御机制**：防御可以减少被击退的距离，但防御时无法攻击。攻防转换的时机是关键。
- **环境互动**：街道上的障碍物会额外击退被击中的玩家，增加了不确定性。
- **时间压力**：倒计时迫使玩家在"稳扎稳打"和"冒险进攻"之间做选择。

## 为什么好玩

将格斗游戏简化到最纯粹的形态——没有血条、没有连招、没有特殊技能，只有"推"和"被推"。这种极简设计反而让每一步决策都至关重要：是进攻还是后退？是冒险出拳还是稳住防御？

## 粘性来源

- **即时对决**：每回合30秒，快速且紧张
- **简单上手**：只有移动、出拳、防御三个操作，零学习门槛
- **AI难度递增**：电脑对手的攻防策略逐渐变聪明
- **双人对战**：支持两人轮流操作，本地对战的乐趣

## Meta 系统

无 — 这是纯粹的街机式格斗游戏，没有外围系统。现代重制版可能加入成就和排名。

## 实现难度

低 — 1v1格斗的核心逻辑非常简单。最大技术难点在于AI设计——需要让电脑对手有合理的攻防决策，同时保持不同难度级别的区分度。
