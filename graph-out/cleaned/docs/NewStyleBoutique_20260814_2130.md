# Nintendo presents: New Style Boutique（Nintendo presents: New Style Boutique）

- **类型**: 模拟经营 / 时尚 / 角色扮演
- **平台**: Nintendo 3DS
- **开发商**: SPD / Nintendo
- **首次发布**: 2013
- **一句话描述**: 经营一家时尚精品店，为各种顾客搭配服装满足他们需求的模拟经营游戏。

## 玩法规则

游戏画面以精品店的内部视角呈现，玩家可以看到店内陈列的服装货架和前来购物的顾客。每个顾客进入商店后会描述自己的需求（"我要去参加婚礼"、"我需要面试穿的衣服"等），包含场合、风格偏好和预算限制。

玩家从店内的服装库存中选择上衣、下装、配饰等单品，为顾客搭配一套完整的造型。搭配完成后顾客会给出评分，评分越高，顾客的满意度和店铺声誉就越高。

通过销售获得的金币可以购买新的服装款式、扩展店面、升级装饰。不同品牌的服装有不同的风格和价格区间，了解每个品牌的特色是成功的关键。

每个顾客的需求包含三个层次：基本要求（场合）、偏好要求（颜色风格）、隐藏要求（个人喜好）。满足基本要求即可获得合格评分，满足所有要求才能获得满分。玩家需要在游戏过程中逐渐学习识别不同类型顾客的需求模式。

## 核心循环

接待顾客 → 根据需求搭配服装 → 获得评分和金币 → 购买新商品 → 吸引更多顾客

## 核心机制

- **时尚匹配系统**：顾客需求包含多个维度（场合、风格、颜色偏好），玩家需要理解不同服装单品的属性来做出合适的搭配
- **品牌系统**：游戏中有多个虚构服装品牌，每个品牌有独特的风格定位，玩家需要了解品牌特性才能做出最佳搭配
- **声誉系统**：高分搭配提升店铺声誉，吸引更多高要求的顾客和稀有的品牌入驻

## 为什么好玩

将时尚搭配的乐趣与模拟经营的成就感结合，每次成功搭配出一套让顾客满意的造型都有创意实现的满足感。

## 粘性来源

具体到机制层面：创意搭配的自由度与顾客评分反馈形成正循环——玩家想要尝试更多搭配组合来获得更高评分。品牌收集元素（解锁所有品牌的所有款式）提供了明确的收集目标，配合店铺升级的进度感，形成长期驱动力。

## Meta 系统

- **品牌解锁系统**：通过提升声誉解锁新品牌
- **店铺装修系统**：用赚到的金币装饰店面，提升吸引力
- **时尚挑战活动**：定期举办搭配比赛，以评分竞争排名
- **对核心玩法的影响**：新品牌扩展搭配可能性，装修提升顾客流量

## 实现难度

中等——服装搭配系统需要设计完善的属性标签体系和评分算法。最大的技术难点是搭配评分逻辑的设计，需要在"客观规则"和"主观审美"之间找到平衡，让玩家觉得评分公平合理。
