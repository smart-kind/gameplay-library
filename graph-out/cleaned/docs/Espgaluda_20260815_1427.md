# 怒首领蜂 银河（Espgaluda）

- **类型**: 射击/弹幕（STG）
- **平台**: Arcade / iOS / Android / PS3 / Xbox 360
- **开发商**: Cave / AMI
- **首次发布**: 2003
- **一句话描述**: Cave经典弹幕射击游戏，玩家操控拥有特殊能力的角色在密集弹幕中穿梭，利用"觉醒"系统将敌人弹幕转化为自己的分数。

## 玩法规则

画面为竖版卷轴射击。玩家控制一个角色在屏幕底部移动，向上飞行并射击敌人。敌人从屏幕顶部和两侧涌来，发射密集的弹幕图案（圆形、螺旋、激光等）。玩家需要在弹幕缝隙中穿梭，同时消灭敌人。

核心特色是"觉醒系统"（Kakusei）：玩家可以随时激活觉醒模式，此时屏幕上已有的敌人弹幕会被染色并变成"珠宝"——收集这些珠宝可以获得巨额分数。觉醒期间玩家的火力也会增强，但同时敌人的弹幕模式可能变得更密集。觉醒有持续时间限制，需要在合适的时机使用。

操作：移动端使用虚拟摇杆控制移动，自动射击或按住射击键。屏幕上有觉醒按钮，点击激活觉醒系统。

游戏有多个可解锁角色，每个角色有独特的觉醒效果：有些角色觉醒后弹幕变珠宝的效率更高，有些则觉醒期间移动速度更快。

## 核心循环

射击消灭敌人 → 躲避弹幕 → 激活觉醒系统将弹幕变珠宝 → 收集珠宝获高分 → 解锁新角色和新模式

## 核心机制

- **觉醒系统（Kakusei）**：这是游戏最独特的机制。激活后，屏幕上已有的弹幕会被"染色"，变成可收集的珠宝。玩家需要在"保命"和"贪分"之间做出抉择——觉醒时弹幕虽然变珠宝，但新的弹幕也会同时产生。
- **弹幕密度**：Cave式弹幕射击的标志性特征——屏幕上同时存在数百发子弹，但总有安全路径。玩家需要在密集的弹幕中找出缝隙，这种"万军从中过"的体验是核心乐趣。
- **角色差异化**：不同角色的觉醒效果、移动速度和基础火力不同，鼓励尝试不同玩法风格。
- **连击/计分系统**：连续收集珠宝不中断会形成连击，分数成倍增长，驱动玩家追求极限操作。

## 为什么好玩

在看似不可能的弹幕密中找到一条生路，那种"我居然穿过去了"的成就感无与伦比。觉醒系统将"躲避弹幕"这个防御行为转化为"收集分数"的进攻行为，彻底改变了弹幕射击的玩法逻辑——从"逃命"变成"主动引诱敌人开火然后转化为分数"。

## 粘性来源

- **技巧成长曲线**：从"满屏弹幕无处躲"到"弹幕间隙任我行"，可见的技能提升带来持续动力
- **高分驱动**：觉醒系统的计分机制支持极限操作，追求更高分需要精确到帧的时机把握
- **角色解锁**：不同角色带来不同体验，增加重复游玩价值
- **街机移植情怀**：经典街机游戏的移动端版本，自带粉丝基础

## Meta 系统

- **角色解锁**：通关或达到特定分数解锁新角色
- **难度选择**：从新手到专家多级难度
- **对核心玩法的影响**：角色差异影响觉醒效果，但核心射击+觉醒机制不变

## 实现难度

高 — 弹幕系统需要高效的碰撞检测（数百发子弹同时存在），觉醒系统的珠宝化逻辑需要精确追踪每一发弹幕的状态。最大技术难点在于移动端性能优化：确保在大量弹幕和特效同时渲染时保持60fps流畅度。
