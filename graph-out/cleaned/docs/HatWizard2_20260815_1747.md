# 帽子巫师2（Hat Wizard 2）

- **类型**: 动作 / 解谜
- **平台**: Web (Flash/HTML5)
- **开发商**: taccommandeur
- **首次发布**: 2018
- **一句话描述**: 用一顶有魔力的帽子解决战斗和谜题的动作冒险续作

## 玩法规则

玩家扮演一个戴着魔法帽子的巫师，在各个关卡中探险。
帽子是核心工具：可以抓取敌人、投掷物体、激活机关、作为盾牌等。
每个关卡有不同的敌人和障碍，需要灵活运用帽子的各种功能来解决。
战斗方面，用帽子抓取敌人然后投掷到其他敌人身上，或者把敌人扔进陷阱。
解谜方面，用帽子搬运物品、触发开关、跨越障碍等。
关卡设计精巧，通常有多种通关方式（战斗路线或解谜路线）。
续作新增了地下世界章节和更多帽子能力。

## 核心循环

进入关卡 → 用帽子解决敌人和谜题 → 到达终点 → 解锁新能力/新关卡

## 核心机制

- 帽子多功能系统：一顶帽子同时是武器、工具、盾牌、搬运工具，一个输入方式实现多种功能
- 物理交互谜题：利用帽子抓取和投掷物体，通过物理引擎解决关卡中的谜题
- 多路径通关：每个关卡通常有战斗和解谜两种以上的通关方式，鼓励创造性玩法

## 为什么好玩

"万物皆可帽子"的设计理念让人眼前一亮。抓起敌人扔向另一个敌人的连锁反应充满乐趣，关卡设计的精妙之处在于总能找到你没想到的通关方式。

## 粘性来源

关卡设计精巧，每关都有"原来可以这样"的顿悟时刻。多路径通关鼓励反复探索找最优解。续作新增的地下世界提供了大量新内容。

## Meta 系统

能力解锁系统：随着进度获得新的帽子功能。地下世界作为隐藏章节提供额外挑战。

## 实现难度

中 — 帽子物理交互系统需要精确的碰撞检测和物理模拟，关卡编辑器也增加了开发复杂度

帽子可以附在敌人头上短暂控制其行动，让它攻击其他敌人。
地下世界章节有全新的敌人类型和更复杂的谜题设计。
每个章节末尾有Boss战，需要巧妙利用帽子机制才能取胜。
游戏内置了关卡编辑器，玩家可以创建和分享自制关卡。
