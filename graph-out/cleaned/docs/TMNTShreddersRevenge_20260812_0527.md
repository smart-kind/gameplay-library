# 忍者神龟：施莱德的复仇（TMNT: Shredder's Revenge）

- **类型**: 动作/清版过关
- **平台**: Mobile (iOS+Android)
- **开发商**: Tribute Games / Dotemu（Netflix）
- **首次发布**: 2023（Netflix版）
- **一句话描述**: 经典清版过关游戏，以忍者神龟为主角。

## 玩法规则

横版清版过关游戏，玩家可控制李奥纳多、拉斐尔、多纳泰罗或米开朗基罗。与脚帮敌人战斗、击败 Boss、通过关卡推进。游戏融合了经典街机 TMNT 游戏的元素，支持合作游戏、连招系统和角色专属技能。

玩家使用拳、踢、跳跃和特殊攻击组合来消灭敌人。每个关卡有多个敌波和最终 Boss 战。连招系统鼓励连续攻击以获得更高评分。

## 核心循环

通过关卡战斗 → 击败敌人 → 获得积分/道具 → 解锁新招式 → 推进到下一关 → 面对 Boss

## 核心机制

- 清版过关战斗：经典横版战斗，包含拳、踢、跳和特殊攻击连招
- 多角色阵容：每只神龟有独特招式和战斗风格
- Boss 战：与标志性 TMNT 反派的高难度对决，需要模式识别

## 角色与多人模式

除了四只神龟外，游戏还解锁了爱普莉尔·奥尼尔、凯西·琼斯和斯普林特老师等角色。每个角色有独特的战斗风格和特殊技能。

最多支持6人本地或在线合作，多人模式下关卡难度相应提升。合作模式中队友之间可以互相救援，增加了策略维度。

## 为什么好玩

忠实还原经典 TMNT 街机玩法，同时加入现代打磨。粉丝怀旧，新手友好。

## 粘性来源

可解锁角色、连招精通和经典街机式推进的满足感。
