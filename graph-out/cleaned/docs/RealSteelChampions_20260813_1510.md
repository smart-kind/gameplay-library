# Real Steel Champions（铁甲钢拳冠军）（Real Steel Champions）

- **类型**: 格斗 / 对战
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer收录
- **首次发布**: 2015
- **一句话描述**: 一款基于铁甲钢拳IP的机器人格斗游戏，玩家操控各种机器人进行PvE对战，通过锦标赛模式提升排名。

## 玩法规则

游戏画面是3D格斗竞技场，玩家操控的机器人与对手的机器人在封闭场地中对峙。每个机器人有生命值条显示在屏幕上方，以及特殊技能槽随攻击积累。

操作包括点击或滑动控制机器人移动和走位，点击攻击按钮进行拳击攻击，分为左拳、右拳和特殊攻击三种。部分操作支持滑动方向来决定攻击角度和类型。

战斗是实时制的，玩家需要观察对手的攻击模式和习惯，在合适的时机发动进攻或防守闪避。不同机器人有不同的基础属性包括力量、速度、防御值和专属特殊技能。

游戏目标是在战斗中击败对手，通过锦标赛模式逐步提升排名并解锁新机器人。每场胜利获得金币和经验用于升级和解锁。

## 核心循环

选择机器人出战 → 与对手实时对战 → 获胜获得金币和经验 → 升级机器人属性和解锁新角色 → 挑战更强对手

## 核心机制

- **机制1**：机器人属性差异化机制：每个机器人有独特的力量、速度、防御属性和专属特殊技能。选择合适的机器人对抗特定对手是策略的核心部分，不同机器人之间存在类似石头剪刀布的克制关系。
- **机制2**：连击系统机制：连续命中对手可以形成连击combo，造成额外伤害并获得技能槽加速积累。这需要玩家掌握攻击节奏和时机，而非胡乱点击按钮。
- **机制3**：技能冷却机制：强力特殊技能有冷却时间，需要在关键时刻使用。何时释放技能是战斗策略的重要决策点，用得太早可能浪费，用得太晚可能没机会用。

## 为什么好玩

机器人格斗的视觉冲击力很强，金属碰撞的火花和机器人的厚重感带来了类似看机甲动画的体验。击败强敌的成就感直接而强烈，尤其是以弱胜强时。

## 粘性来源

机器人收集与养成的长期目标加上对战胜利的直接爽感加上锦标赛模式的阶梯式挑战，三者构成了从即时满足到长期追求的完整体验链。

## Meta 系统

机器人收集加升级系统，通过战斗获得金币和经验用于升级机器人属性和解锁新角色。锦标赛排名系统提供额外奖励和荣誉展示。部分版本有PvP对战模式。

## 实现难度

高 -- 需要3D机器人模型、骨骼动画系统、AI对手行为树和战斗物理碰撞。最大技术难点是流畅的战斗动画和合理的AI难度曲线，让对手看起来聪明但不作弊。

## 机器人属性详解

- **力量**：影响基础攻击伤害和连击伤害加成
- **速度**：影响移动速度和攻击出手速度
- **防御**：影响受到的伤害减免量
- **特殊技能**：每个机器人独有的必杀技，有不同效果如范围伤害、护盾、吸血等

机器人之间存在一定的克制关系，力量型克制速度型但被防御型克制，形成类似石头剪刀布的循环。
