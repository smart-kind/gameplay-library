# 放置游戏1号（Idle Game 1）

- **类型**: 放置点击/基础
- **平台**: Mobile (iOS+Android)
- **开发商**: Cem Kamiloglu
- **首次发布**: 2024
- **一句话描述**: 基础放置点击游戏

## 玩法规则

Idle Game 1 是一款基础的放置点击游戏。玩家通过点击获取资源，用资源购买自动生产设施，实现被动收入。

核心操作：点击获取初始资源，购买自动生产者，生产者自动产出资源，购买更多或更高级的生产者。

游戏有升级系统：可以升级每个生产者的效率和产出。随着生产者数量增加，资源产出呈指数增长。

离线收益：关闭应用期间生产者继续工作，下次打开时可以收取离线收益。

## 核心循环

点击获取资源，购买生产者，离线收益积累，升级效率，继续扩大规模

## 核心机制

- 基础放置循环：点击后购买生产者，自动产出后购买更多。这是放置游戏最核心的循环。
- 升级系统：提升每个生产者的效率，增加策略性，先升级还是先买新的。
- 离线收益：关闭期间仍在产出。

## 为什么好玩

Idle Game 1 回归了放置游戏最纯粹的体验，没有复杂的系统和花哨的包装，就是简单的数字不断上涨的快乐。对于喜欢纯粹放置体验的玩家来说，这种简洁反而是一种优势。

## 粘性来源

粘性来源：（1）离线收益降低回归门槛；（2）数字上涨的即时反馈；（3）简洁设计降低认知负担；（4）升级系统提供短期目标。

## Meta 系统

生产者系统。升级系统。离线收益计算。
