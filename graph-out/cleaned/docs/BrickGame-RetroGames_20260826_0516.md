# Brick Game - Retro Games

- **类型**: 复古游戏合集 / 街机
- **平台**: Mobile (iOS)
- **开发商**: Dat Pham Thanh
- **首次发布**: 2016
- **一句话描述**: Brick Game - Retro Games是一款90年代经典掌机游戏合集，包含19款复古小游戏。8位音效和经典主题唤起怀旧情怀。

## 玩法规则

游戏启动后显示19款游戏的列表，以复古掌机的风格呈现。选择任一游戏即可开始游玩。包含19款经典游戏：经典方块拼图（俄罗斯方块变体）、经典坦克大战、经典赛车、经典贪吃蛇、补充射击、射击方块、打砖块、青蛙过河、三消配对，以及俄罗斯方块的多种变体（移动、隐身、反向等）。每款游戏有不同的操作方式：方向键移动、旋转、射击等。游戏速度随关卡增加而加快。包含11种不同的经典主题外观。支持通过社交应用分享高分。

## 核心循环

选择游戏 -> 游玩 -> 获得高分 -> 分享或尝试新游戏 -> 重复

## 核心机制

- 19款游戏合集：俄罗斯方块、坦克、赛车、贪吃蛇、打砖块等
- 8位音效：经典掌机的怀旧音效
- 速度递增：每款游戏的难度随关卡增加
- 11种主题：不同的视觉外观可选
- 高分分享：通过社交应用分享成绩

## 为什么好玩

90年代经典掌机游戏的完美复刻：方块机的19合1合集。8位音效和像素画面直接触发怀旧神经。每款游戏都是经过时间考验的经典，简单但耐玩。

## 粘性来源

19款游戏提供足够多样性；怀旧主题吸引特定受众；速度递增提供持续挑战；高分分享增加社交维度

## Meta 系统

有11种经典主题外观、高分排行榜、社交分享功能。无内购。

## 实现难度

中。核心难点在于复古游戏合集玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
