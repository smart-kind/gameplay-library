# Basket Random

- **类型**: 体育 / 休闲 / 双人对战
- **平台**: Web (浏览器) / Mobile
- **开发商**: Two Player Games
- **首次发布**: 2020
- **一句话描述**: 搞笑风格的双人篮球游戏，用随机物理效果进行投篮对决

## 玩法规则

Basket Random 是一款双人对战的篮球游戏，采用火柴人风格的简化画面。游戏界面分为左右两侧，两名玩家各控制一个火柴人角色。

玩家只需要一个按键即可控制角色——点击或按下按键时角色跳跃，同时单手举起篮球。角色会自动追踪篮球的位置。游戏的目标是把球投进对方的篮筐得分。

比赛采用计分制，先达到指定分数（通常是 5 分）的玩家获胜。每局比赛场地和篮筐位置会随机变化——有时篮筐在上方，有时在侧面，有时两个篮筐离得很近有时很远。

角色的体型也会在每局之间随机变化——有时一个角色很大另一个很小，有时两边差不多。这种随机性让每场比赛都充满变数。

### 操作方式

- **玩家1**：W 键跳跃，A/D 键左右移动
- **玩家2**：上方向键跳跃，左/右方向键移动
- 或者本地双人同屏模式，各自使用不同按键
- Web 版支持单键盘双人同时操作

## 核心循环

选择对手 → 随机场地生成 → 投篮得分 → 比分领先 → 赢得比赛 → 再来一局

## 核心机制

- **随机物理效果**：每次投篮的抛物线、弹跳都受物理引擎影响，结果难以精确预测
- **随机场地变化**：每局比赛的篮筐位置、场地大小、角色体型都会随机变化
- **单按键操作**：极简操作降低门槛，任何人都可以立刻上手
- **本地双人对战**：同屏竞技的社交乐趣

## 为什么好玩

随机性是最好的笑料制造机。看到你的火柴人角色突然变成巨人或侏儒，或者篮球以不可思议的角度弹进篮筐，这种不可预测的搞笑场面让每一局都充满欢乐。极简操作让完全不会玩游戏的人也能参与。

## 粘性来源

"再来一局"效应是核心粘性——每局比赛只需几分钟，加上随机性带来的新鲜感和搞笑场面，让人忍不住想再试一次。本地双人模式更是社交聚会的神器，朋友间的竞争和笑声是最好的留存工具。

## Meta 系统

无

纯粹的即开即玩体验，没有外围成长系统。

## 实现难度

低 — 核心是简单的物理引擎加两个角色的控制。最大的技术难点是物理手感调校（既要随机搞笑又要保持基本公平）和双人同屏的按键冲突处理。
