# Phase 10 休闲卡牌（Phase 10: Casual Card Game）

- **类型**: 卡牌 / 策略 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Mattel163 Limited
- **首次发布**: 2019
- **一句话描述**: 基于经典Phase 10规则的手机卡牌游戏，玩家通过完成10个阶段任务赢得比赛

## 玩法规则

Phase 10是一款阶段式Rummy（拉米）卡牌游戏。游戏的目标是按顺序完成10个不同的"阶段"（Phase），每个阶段要求组成特定的牌型组合。

**基本操作**：
- 每位玩家获得10张起始手牌
- 每回合从牌堆顶或弃牌堆取一张牌
- 然后打出一张牌到弃牌堆
- 当手中牌满足当前阶段的牌型要求时，可以"出牌"（lay down），展示组合

**10个阶段示例**：
1. 两组各3张同数字牌
2. 一组3张同数字+一组4张同花色
3. 一组4张同数字+4张同花色
4. 7张同花色（同花顺概念）
5. 8张同花色
6. 7张同花色+另4张同花色
7. 两组各4张同数字
8. 7张同花色
9. 一组5张同数字+一组2张同数字
10. 一组5张同数字+一组3张同数字

**游戏流程**：完成当前阶段后，进入下一阶段。最先完成全部10个阶段的玩家获胜。如果牌堆耗尽，本局结束，未完成阶段的玩家继续从当前阶段开始下一局。

## 核心循环

抽牌 → 分析手牌 → 打牌 → 收集所需牌型 → 完成阶段 → 进入下一阶段

## 核心机制

- **阶段递进**：10个阶段难度递增，从简单的"对子"到复杂的"多组合同花"。每完成一个阶段都有明确的成就感反馈。
- **Rummy组牌策略**：玩家需要在"保留有用牌"和"防止对手拿到"之间做选择。弃牌堆的策略性使用是关键——有时冒着给对手好牌的风险去取自己需要的牌。
- **Skip牌**：特殊卡牌，打出后可以跳过下一位玩家的回合。这是一种防御/攻击机制，可以用来阻止即将获胜的对手。
- **Wild牌**：万能牌，可以代替任何数字或花色。数量有限，使用时机决定了策略深度。

## 为什么好玩

Phase 10将复杂的牌型要求拆解为10个渐进目标，让玩家始终有明确的方向感。每局大约20-40分钟，适合认真的卡牌游戏爱好者。"就差一个阶段了"的紧张感是核心驱动力。

## 粘性来源

- **阶段性成就感**：每完成一个阶段都是一次明确的正反馈。
- **策略深度**：Rummy类游戏的计算和预判提供了持续的挑战。
- **社交互动**：多人在线模式支持朋友间的竞争。

## Meta 系统

- **统计追踪**：记录各阶段完成率、胜率等数据。
- **主题卡牌皮肤**：可解锁不同视觉主题的牌面和背景。

## 实现难度

低 — Rummy类卡牌游戏逻辑成熟，状态管理清晰。主要工作是UI设计和网络同步。最大难点在于AI对手的难度曲线设计。
