# Butterfly

- **类型**: 休闲/解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer收录作品
- **首次发布**: 2011
- **一句话描述**: 一款以蝴蝶为主题的休闲解谜游戏，通过引导蝴蝶飞行的路径来完成各种挑战。

## 玩法规则

玩家通过操控风向、放置花朵和消除障碍来引导蝴蝶在花丛间飞行。每关的目标是让蝴蝶到达指定的花朵或收集所有花蜜。

1. 每个关卡中有一只或多只蝴蝶在场景中飞行。蝴蝶会自动朝着最近的花朵方向飞行，但路径上可能有障碍物阻挡。

2. 玩家可以通过放置或移动花朵来改变蝴蝶的飞行方向。花朵有不同类型，吸引蝴蝶的能力也不同。某些花朵可以连续吸引多只蝴蝶。

3. 障碍物包括蜘蛛网（困住蝴蝶）、风车（改变飞行方向）、食人花（消灭蝴蝶）等。玩家需要在蝴蝶到达这些危险区域之前清除或绕过它们。

4. 部分关卡有时限要求，需要在蝴蝶体力耗尽前引导它到达目标花朵。蝴蝶的体力会随着飞行距离逐渐消耗。

## 核心循环

观察蝴蝶位置和障碍物 -> 放置/移动花朵引导路径 -> 蝴蝶沿路径飞行 -> 清除障碍收集花蜜 -> 到达目标完成关卡

## 核心机制

- **花朵引导系统**：花朵是引导蝴蝶飞行的核心工具。不同类型的花朵有不同的吸引范围和持续时间。放置位置和时机直接影响蝴蝶的飞行路径。

- **障碍清除**：蜘蛛网可以通过点击清除，风车可以旋转方向，食人花需要绕过或用花朵引开。每种障碍有不同的处理方式。

- **多蝴蝶协作**：后期关卡出现多只蝴蝶，需要同时引导它们到达不同的目标花朵。多蝴蝶的路径规划是主要挑战。

- **体力与时间**：蝴蝶的体力有限，飞行距离越长消耗越大。合理规划最短路径是高效通关的关键。

## 为什么好玩

蝴蝶飞行的视觉表现优美，引导蝴蝶找到正确路径的过程既有解谜的策略性，又有欣赏蝴蝶飞舞的放松感。

## 粘性来源

寻找最优引导路径的策略思考，收集花蜜的进度驱动，以及欣赏蝴蝶优美飞行的视觉享受。

## Meta 系统

外围成长系统：金币或经验积累用于解锁新关卡、新角色或新能力。部分游戏包含每日挑战或排行榜等社交竞争元素，鼓励玩家持续回归。

## 实现难度

低。蝴蝶飞行路径的物理模拟（受花朵吸引力和风力影响的曲线运动）。
