# 亡者肉鸽 放置RPG（Rogue with the Dead: Idle RPG）

- **类型**: 放置RPG/肉鸽
- **平台**: Mobile (iOS+Android)
- **开发商**: room6 LLC.
- **首次发布**: 2024
- **一句话描述**: 肉鸽元素的放置RPG游戏

## 玩法规则

Rogue with the Dead 结合了肉鸽（Roguelike）和放置 RPG 两种玩法。玩家控制一名角色在地牢中自动战斗，同时通过放置收益来强化角色。

核心操作：角色自动战斗，玩家主要负责装备管理、技能选择和升级决策。每次地牢探索是独立的肉鸽体验，死亡后重新开始但保留部分永久进度。

装备系统：每次探索中随机获得装备，装备有不同品质和属性。永久装备可以保留到下次探索。

技能树：永久技能树允许玩家在多次探索中逐步解锁新技能和被动加成。

## 核心循环

进入地牢自动战斗，获取随机装备，死亡或通关后保留部分进度，升级技能树，再次探索

## 核心机制

- 肉鸽加放置融合：每次地牢探索是独立的肉鸽体验（随机生成、永久死亡），但放置系统提供永久进度（技能树、部分装备）。
- 随机装备系统：每次探索获得不同的装备组合，增加重玩价值。
- 永久技能树：多次探索积累的永久加成，让每次重新探索都比上次更强。

## 为什么好玩

Rogue with the Dead 把肉鸽的随机性和放置的进度感巧妙结合。肉鸽的每次都是新体验和放置的持续变强相辅相成，肉鸽提供短期的刺激和新鲜感，放置提供长期的进度和目标感。

## 粘性来源

粘性来源：（1）肉鸽的随机性确保每次探索都不同；（2）永久技能树提供长期进度感；（3）放置系统允许离线进度；（4）再来一次试试的肉鸽心理。

## Meta 系统

永久技能树系统。随机装备系统。地牢探索系统。放置收益系统。

## 实现难度

中。肉鸽地图随机生成和放置系统的融合是主要技术难点。数值平衡也需要精心设计。
