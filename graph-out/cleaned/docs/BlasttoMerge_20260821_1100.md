# 爆破合并（Blast to Merge）

- **类型**: 数字合并 / 泡泡射击 / 益智
- **平台**: Mobile (iOS+Android)
- **开发商**: kadir ozden
- **首次发布**: 2019
- **一句话描述**: 一款独特的数字气泡合并游戏，玩家点击相邻的相同数字气泡使其爆破合并为更大的数字，简单直观但极具策略深度。

## 玩法规则

游戏画面中充满各种数字气泡，散布在屏幕上。每个气泡都有一个数字（通常是2的幂次：2、4、8、16等），气泡之间可能相互接触。

玩家点击两个或多个相互接触（相邻）的相同数字气泡，这些气泡会爆破合并为一个更大的气泡，其数字为原数字的两倍。例如，三个相邻的4气泡会合并为一个8气泡。

合并后的新气泡占据原来气泡群的中心位置，可能会与周围的其他相同数字气泡形成新的相邻关系，从而触发连续合并的可能。

游戏没有明确的结束条件，玩家可以持续合并直到追求最大的数字。每次合并都会增加分数，玩家的目标是获得尽可能高的分数。

## 核心循环

点击相邻相同数字气泡 → 爆破合并为更大数字 → 产生新的相邻关系 → 持续合并挑战更高数字

## 核心机制

- **相邻爆破合并**：核心机制是点击相邻的相同数字气泡群。与传统拖拽合并不同，这种"点击即合"的操作方式更直觉化，降低了学习门槛。
- **空间关系策略**：由于气泡分布在二维空间中，玩家需要观察整个屏幕的数字布局，决定哪些相邻气泡群优先合并。合并一个群体可能会改变周围气泡的相邻关系，创造或破坏新的合并机会。
- **无尽模式**：游戏采用无尽模式，没有关卡限制。玩家可以持续游玩，追求数字和分数的不断突破。这种模式特别适合喜欢自由节奏的休闲玩家。
- **大脑训练**：游戏的本质是空间思维训练——在有限的屏幕空间内找到最优的合并路径，锻炼玩家的观察力和逻辑规划能力。

## 为什么好玩

"点一下就变大"的即时反馈让游戏有一种解压感。看着小数字气泡一步步变成巨大的数字，这种视觉和数值上的成长感非常满足。同时，由于合并会影响周围气泡的布局，每次合并都需要一定的策略思考，不会变成纯粹的无脑点击。

## 粘性来源

数字增长是核心粘性来源——玩家总想着"合成一个更大的数字就收手"。但更大的数字意味着需要更多的合并操作，而每次合并都可能创造新的机会，让玩家不知不觉地继续玩下去。空间布局的不确定性（不知道下一次会触发什么合并）也提供了探索乐趣。

## Meta 系统

游戏没有复杂的元系统。主要功能是分数记录和最高分追踪。无社交功能、无付费成长系统，专注于纯粹的益智体验。

## 实现难度

低。气泡合并逻辑和相邻检测都是基础算法。最大的技术难点在于气泡群的空间布局优化——需要确保气泡分布既不会过于拥挤（导致无法区分）也不会过于稀疏（缺乏合并机会），同时保持视觉美观。
