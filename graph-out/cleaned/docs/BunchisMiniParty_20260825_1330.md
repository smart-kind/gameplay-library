# Bunch is MiniParty!

- **类型**: 派对迷你游戏合集
- **平台**: Mobile (iOS+Android)
- **开发商**: Bunch Live, Inc
- **首次发布**: 2017
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

创建/加入房间 -> 选择小游戏 -> 语音聊天中游玩 -> 社交互动

## 核心机制

- **语音+游戏融合**: Bunch将语音聊天和小游戏结合在一起。玩家在语音聊天的同时参与各种小游戏。这种设计让社交和娱乐同时进行。
- **跨平台支持**: 支持在任何屏幕（手机、平板、电脑）上游玩，降低了参与门槛。无论使用什么设备都能加入游戏。
- **多种小游戏**: 提供多种小游戏类型，适合不同场景和人数。从轻松的聊天游戏到需要合作的挑战，应有尽有。

## 为什么好玩

语音聊天+小游戏的组合创造了独特的社交体验。在和朋友聊天的同时玩游戏，氛围轻松愉快。

## 粘性来源

粘性来源于社交关系链。朋友越多，游戏越有趣。语音聊天的沉浸感是单纯游戏无法替代的。

## Meta 系统

- 房间系统：创建/加入房间进行社交
- 对核心玩法的影响：房间系统支持灵活的社交场景

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
