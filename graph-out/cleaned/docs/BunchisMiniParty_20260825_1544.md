# Bunch 迷你派对（Bunch is MiniParty!）

- **类型**: 社交派对 / 休闲合集
- **平台**: Mobile (iOS+Android)
- **开发商**: Bunch
- **首次发布**: 2020
- **一句话描述**: 一款结合视频聊天和多人小游戏的社交平台，玩家可以在游戏的同时与朋友语音交流。

## 玩法规则

玩家创建或加入一个游戏房间，可以邀请好友或匹配陌生人。房间内包含视频语音聊天功能和多种小游戏。

在画画猜词游戏中，一名玩家用屏幕画画，其他人实时观看并输入猜测。在记忆力挑战中，记住卡片位置并配对。

视频聊天和游戏界面同时显示，玩家可以在游玩时看到彼此的反应和表情。

## 核心循环

加入房间 -> 视频聊天 -> 选择小游戏 -> 轮流游玩 -> 社交互动

## 核心机制

- 视频加游戏融合: 将视频聊天与小游戏无缝结合，社交和游戏同时进行。
- 多类型小游戏: 包含画画、问答、反应等多种适合社交场景的小游戏。
- 实时互动: 低延迟的视频和音频传输，确保社交体验流畅。

## 为什么好玩

边玩游戏边聊天的体验是核心乐趣。看到朋友的实时反应和表情让游戏更加有趣。

视频聊天的加入让远程聚会也有了面对面游玩的感觉，特别适合异地朋友之间的社交需求。

## 粘性来源

社交关系的粘性。朋友邀请你来玩，你自然会加入。视频聊天的沉浸式体验让玩家停留时间更长。

新游戏内容更新保持活跃度。虚拟形象和个性化设置也增加了用户的投入感。

## Meta 系统

社交关系链：添加好友、创建群组。

虚拟形象：自定义角色外观。

成就系统：完成挑战获得徽章。

## 实现难度

高 - 视频聊天加游戏同步是最大技术难点。需要处理音视频传输、低延迟同步、多人状态管理等复杂问题。
