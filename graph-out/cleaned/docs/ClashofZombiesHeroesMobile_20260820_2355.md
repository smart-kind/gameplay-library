# 部落冲突（Clash of Zombies:Heroes Mobile）

- **类型**: 策略战争 / 塔防 / 英雄养成
- **平台**: Mobile (iOS+Android)
- **开发商**: 铭 颜
- **首次发布**: 2017
- **一句话描述**: 一款融合英雄养成、塔防和联盟对战的策略战争游戏，以末日僵尸为背景。

## 玩法规则

游戏界面分为基地建设和战斗两大模块。基地建设采用俯视角网格地图，玩家可以建造资源建筑（金矿、油田）、防御设施（炮塔、围墙）、兵营等功能建筑。建筑可以升级，等级越高产能或战斗力越强。

战斗部分：玩家选择英雄（不同英雄有不同技能）和兵种组成进攻队伍。进攻时，玩家先部署英雄到战场，然后逐个释放兵种。兵种自动沿最短路径攻击目标，玩家需要手动释放英雄技能来扭转战局。

防守部分：其他玩家进攻时，你的防御设施自动反击。防御塔的放置位置和类型搭配决定防守强度。

资源获取：随时间积累（金矿产出）+ 掠夺其他玩家 + 完成任务。资源用于升级建筑和训练兵种。

联盟系统：加入联盟后可以请求援军、参与联盟战争、共享资源。

## 核心循环

建设基地收集资源 → 训练兵种和升级英雄 → 进攻掠夺/防守 → 获取资源升级建筑

## 核心机制

- **英雄+兵种协同**: 英雄提供主动技能（AOE伤害/治疗/护盾），兵种作为持续战力，两者在战斗中形成互补。玩家需要根据敌方配置选择合适的英雄和兵种组合
- **建筑升级树**: 每个建筑有明确的升级路径和前置条件（如先升级兵营到3级才能训练高级兵种），形成清晰的成长目标和资源规划需求
- **掠夺-防御循环**: 进攻获取资源加速成长，但资源过多会吸引其他玩家进攻，需要在进攻扩张和防御加固间保持平衡

## 为什么好玩

将基地建设、英雄养成、塔防防守和实时进攻融合在一个闭环中。每次战斗既是策略对抗（兵种搭配）又有操作感（英雄技能释放时机），联盟社交增加竞争和合作维度。

## 粘性来源

建筑升级的时间锁制造回归动力（等我的兵营升级完）；资源被掠夺的紧迫感促使加强防御；联盟排名和赛季奖励提供社交竞争目标；英雄收集满足收集欲。

## Meta 系统

- **英雄养成与联盟系统**: 英雄通过战斗获取经验升级技能，联盟成员互相支援参与联盟战
- **对核心玩法的影响**: 高等级英雄提供更强战斗力，联盟加成影响资源获取和防守能力

## 实现难度

中 — 需要平衡经济系统、战斗AI、匹配机制等多方面，最大技术难点是大规模PVP的实时数据同步和反作弊机制
