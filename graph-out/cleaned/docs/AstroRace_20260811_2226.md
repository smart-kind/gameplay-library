# Astro Race（Astro Race）

- **类型**: 竞速 / 太空 / 反应类
- **平台**: Web（浏览器）/ Mobile
- **开发商**: 浏览器游戏开发者
- **首次发布**: 2010s
- **一句话描述**: 太空主题竞速游戏，玩家控制飞船在太空中穿行，躲避障碍物并收集加速道具

## 玩法规则

游戏画面是太空场景（星空背景、行星、星云）。玩家控制一艘飞船在赛道上飞行。赛道可能是直线型（向前飞行）或环形（绕圈竞速）。

操作方式：方向键或鼠标控制飞船的上下左右移动。赛道上有障碍物（陨石、激光、小行星）和加速道具（推进器、护盾、磁力）。

竞速模式通常有多个对手（AI 或其他玩家），目标是第一个到达终点。无尽模式下，赛道不断延伸，目标是尽可能存活更长时间。

## 核心循环

控制飞船飞行 → 躲避障碍 → 收集道具 → 加速前进 → 到达终点或存活更久

## 核心机制

- **障碍躲避**：赛道上的障碍物需要快速反应来躲避。部分障碍物有固定模式（来回移动的陨石），部分随机出现。
- **道具系统**：加速道具（推进器提升速度）、防御道具（护盾抵挡一次碰撞）、辅助道具（磁力吸引收集品）。
- **竞速/无尽模式**：竞速模式有明确的终点和对手，无尽模式没有终点，难度逐渐增加。

## 为什么好玩

Astro Race 把竞速游戏搬到了太空场景——没有重力限制，飞船可以在三维空间中自由移动（虽然通常是 2D 表现）。太空的视觉效果（星空、行星、星云）提供了良好的氛围。

## 粘性来源

- **竞速快感**：和对手竞争第一个到达终点
- **无尽挑战**：无尽模式下的存活时间挑战
- **道具策略**：选择合适的道具可以改变比赛结果

## Meta 系统

无。纯核心玩法。

## 实现难度

- **学习曲线**：新手可以立即上手，但精通需要数十小时的练习。每次游玩都能发现新的技巧或策略。
- **重玩价值**：高。每局游戏都有不同的体验，无论是随机的地图/敌人，还是玩家的策略选择。
- **社区生态**：作为经典浏览器游戏，它在玩家社区中有良好的口碑。
- **技术亮点**：在浏览器环境中实现流畅的交互体验，充分利用了现代 Web 技术的能力。
低 + 2D 卷轴、碰撞检测、道具系统。最大技术难点是赛道生成（无尽模式）的难度曲线设计。
