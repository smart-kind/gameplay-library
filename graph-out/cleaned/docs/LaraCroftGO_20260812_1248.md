# 劳拉GO（Lara Croft GO）

- **类型**: 回合制解谜
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: Square Enix Montreal
- **首次发布**: 2015
- **一句话描述**: 基于《古墓丽影》IP的棋盘式回合解谜游戏，劳拉在每个回合中移动一格。

## 玩法规则

游戏场景是一个等距视角的棋盘网格，劳拉和敌人（蛇、蜥蜴、大型怪物等）都在格子上。

玩家控制劳拉每次向上下左右移动一格。劳拉移动后，所有敌人也会各自移动一格。

目标是让劳安全到达关卡出口。途中需要收集水晶（分数）、利用机关（杠杆、传送门）和躲避/消灭敌人。

可以推方块挡路、触发陷阱消灭敌人、利用杠杆改变地形。每个关卡都是精心设计的'一步一杀'棋局。

后期加入新机制：可以控制的其他角色（需要保护或协作）、会飞的敌人（不遵循地面格子）、需要同时操作的多机关。

## 核心循环

分析棋盘布局 → 移动劳拉一格 → 敌人跟随移动 → 利用机关和陷阱 → 到达出口

## 核心机制

- 同步回合制：劳拉的每一步都会触发敌人的移动，整个关卡就像一个精密的机械装置——玩家的每个选择都有连锁反应
- 环境互动：杠杆、传送门、陷阱、可推方块等机关构成关卡的核心挑战，不是'打败敌人'而是'利用环境'
- 路径规划：因为敌人的移动是确定的，玩家需要在脑中模拟多步之后的局面，类似于下棋的思考过程

## 为什么好玩

将动作冒险IP转化为纯智力游戏的设计非常巧妙。每个关卡像一个精心编排的舞蹈——找到正确的节拍就能优雅通关，走错一步就可能导致连锁灾难。成功破解复杂关卡的成就感极强。

## 粘性来源

关卡设计的精巧度是核心粘性——每关都是一个新的'大脑急转弯'；三星评价系统（收集所有水晶）鼓励重复游玩；关卡数量有限但质量极高。

## Meta 系统

线性关卡制。收集宝石解锁隐藏关卡。无外围成长系统，纯解谜体验。

## 实现难度

中低 — 回合制网格系统实现简单。最大难点是关卡设计——每个关卡需要精心测试确保有且仅有少数优雅解法。
