# 超级迷你派对（Super Mega Mini Party）

- **类型**: 多人派对 / 迷你游戏
- **平台**: Mobile (iOS)
- **开发商**: Red Games Co
- **首次发布**: 2019
- **一句话描述**: 20款多人迷你游戏的合集，支持在线对战和最多4人的本地派对模式。

## 玩法规则

玩家可以在线与全球玩家进行1v1对战，或者与最多3名好友进行多人派对模式。

每场比赛包含多个快速迷你游戏。

游戏还有单人训练模式和AI对战模式。

通过赢得比赛解锁新角色、宠物和迷你游戏。

## 核心循环

玩对战比赛 -> 赢得解锁奖励 -> 新角色宠物游戏 -> 继续对战

## 核心机制

- **快速对战循环**：每场比赛包含多个快速迷你游戏，每局时间短但节奏紧凑
- **角色收集**：解锁和自定义角色及其替代外观
- **宠物跟随系统**：宠物会跟随角色并做出表情，增加个性化
- **多人社交**：支持在线匹配和好友对战，派对模式最多4人

## 为什么好玩

派对游戏的天然社交属性，适合和朋友一起玩。每局游戏快速，随时可以开始。

## 粘性来源

社交竞争（排行榜和好友对战）+ 角色收集 + 快速对局的再来一局效应。

## Meta 系统

角色和宠物收集系统。通过赢得对战解锁新外观，影响社交展示但不影响平衡。

## 实现难度

中 - 需要网络同步和20款不同的迷你游戏。最大技术难点：多人实时同步和20款游戏的平衡性是最大难点。
