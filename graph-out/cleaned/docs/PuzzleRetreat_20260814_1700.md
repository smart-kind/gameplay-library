# 谜题撤退（Puzzle Retreat）

- **类型**: 解谜 / 三消
- **平台**: Mobile (iOS+Android)
- **开发商**: The Voxel Agents
- **首次发布**: 2013
- **一句话描述**: 通过拖拽匹配同色方块来消除，在宁静的氛围中享受独特的解谜体验——不同于传统三消，方块下落方向可变

## 玩法规则

游戏画面呈现一个方形棋盘，格子上布满不同颜色的方块。与传统三消不同，玩家通过拖拽操作来移动方块——不是交换相邻方块，而是将一列或一行中的方块整体滑动，使相同颜色的方块聚集在一起。

当三个或更多相同颜色的方块相邻时，它们自动消除。消除后，剩余方块会根据当前的重力方向（可从四个方向中选择）滑落填补空缺。玩家可以随时改变重力方向，这意味着方块的下落路径可以被精确控制。

每个关卡的目标是在限定步数内清除所有方块或达到指定分数。部分关卡包含特殊元素——锁定的方块需要多次消除才能清除，彩虹方块可以匹配任何颜色。游戏没有计时压力，玩家可以慢慢思考每一步。

## 核心循环

拖拽方块聚集同色 → 消除方块 → 改变重力方向引导下落 → 清空棋盘过关

## 核心机制

- **滑动聚合机制**：不同于传统三消的"交换"操作，玩家通过滑动整行或整列来移动方块。这种操作方式更接近滑块拼图，需要更多前置规划。
- **可变重力系统**：玩家可以随时改变方块的下落方向（上/下/左/右）。这是游戏的核心创新——通过控制重力，可以制造连锁消除或为后续操作创造条件。
- **无时间压力**：游戏不计时，没有步数之外的紧迫限制。这种设计鼓励深度思考而非快速反应。
- **连锁反应规划**：一次消除可能触发多个后续消除，但需要预先规划方块的下落路径。好的策略可以在一步之内清除大量方块。

## 为什么好玩

可变重力+滑动聚合的组合创造了一种全新的三消体验。传统三消是"看哪里能消就消"，而Puzzle Retreat要求你思考"消除之后方块会怎么落、落下来之后又能消什么"。这种前瞻性的思考过程让游戏更像策略解谜而非运气消除。

## 粘性来源

解谜游戏的"想通就爽"效应——卡在一个关卡很久后突然找到关键步骤，那种顿悟感极强。关卡逐步引入新机制（锁定方块、彩虹方块、多重力区域等），持续带来新鲜感。无时间压力的设计让玩家可以随时放下、随时拿起，没有挫败感。

## Meta 系统

无传统Meta成长系统。游戏通过关卡解锁提供进度感。

## 实现难度

中。核心需要实现可变重力系统下的方块物理和消除检测。最大技术难点在于重力切换时方块的下落动画和连锁消除的精确计算——需要确保玩家的每一步操作都能得到明确、可预测的反馈。
