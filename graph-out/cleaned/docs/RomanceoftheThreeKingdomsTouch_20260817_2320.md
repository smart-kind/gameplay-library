# 三国志Touch（Romance of the Three Kingdoms Touch）

- **类型**: 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Koei Tecmo (光荣特库摩)
- **首次发布**: 2010
- **一句话描述**: 经典三国志系列的移动简化版，以触控操作重新设计了战略指挥体验。

## 玩法规则

游戏画面是俯视视角的中国古代地图，分为多个城池和领地。玩家选择一方势力（刘备、曹操、孙权等），目标是统一天下。
基本操作：点击己方城池查看信息和下达命令（征兵、训练、任命武将）。点击地图上的其他城池可以进行外交或军事行动。
军事行动：派遣武将带领部队出征，选择行军路线和目标城池。战斗采用自动+干预模式——战斗开始后部队自动交战，玩家可以点击释放武将技能或使用特殊战术。
武将系统：每个武将有自己的属性（统率、武力、智力、政治）和技能。属性决定了带兵数量和战斗力。武将之间有相性关系，相性好的搭配有加成。
内政系统：管理城池的农业、商业和军事设施。农业增加粮食收入，商业增加金钱收入，军事增加兵力。需要平衡三者发展。
外交系统：与其他势力结盟、宣战、停战。利用外交手段分化敌人、巩固盟友。

## 核心循环

管理城池内政 → 训练武将和士兵 → 制定军事策略出征 → 战斗中使用技能干预 → 占领城池扩大领土 → 继续向统一目标推进

## 核心机制

- 武将驱动的战略：武将是核心资源，不同武将的组合和搭配决定了战术选择，增加了策略深度
- 自动战斗+技能干预：降低了微操要求，但关键时刻释放技能可以逆转战局，保留了参与感
- 内政-军事平衡：需要同时管理经济和军事，过度扩张会导致经济崩溃，过于保守会错失战机

## 为什么好玩

从一城之地到统一天下的宏大叙事感很强。
看到自己培养的武将在战场上大显身手时的那种成就感，以及外交博弈中'合纵连横'的策略满足感。

## 粘性来源

长期战略目标（统一天下）、武将收集的收集欲、以及'下一回合就能翻盘'的策略粘性。

## Meta 系统

武将收集、历史事件触发、成就系统、多势力 replay。

## 实现难度

高 — 需要实现地图系统、战斗AI、武将属性系统、内政经济模拟。主要技术难点在于战斗系统的策略深度和AI的合理性。

游戏还包含历史事件系统：当满足特定条件时触发经典历史事件（如三顾茅庐、赤壁之战）。这些事件有时提供特殊奖励或剧情分支。武将的忠诚度系统也是一个重要因素，忠诚度低的武将在被攻击时可能叛变。
