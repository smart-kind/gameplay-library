# Dig!

- **类型**: 休闲 / 挖掘
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款以挖掘为主题的休闲游戏，玩家控制钻探机向下挖掘，收集矿石并避开危险

## 玩法规则

游戏呈现一个地下横截面场景。玩家控制一台钻探机持续向下挖掘。

点击屏幕控制钻探方向：左滑=向左下方钻，右滑=向右下方钻。钻探机会持续向下移动，不能停止。

地下不同深度有不同材质的岩层：泥土（易钻，减速少）、岩石（硬，钻速慢）、宝石层（稀有高价值，需要特殊钻头）。收集宝石获得高分和稀有资源。

同时存在危险区域：岩浆（立即损失大量HP）、地下河（减速并可能冲偏方向）、空洞（掉落损失HP）。在燃料耗尽前尽可能深地挖掘。深度越深，矿物价值越高。收集的资源可用于升级钻探机的速度、耐久和燃料容量。

游戏设有每日深度挑战，每天提供固定的地形排列，所有玩家挖掘相同路线。每日挑战有独立排行榜。

## 核心循环

控制钻探方向向下挖掘 → 收集矿石和宝石 → 升级钻探机

## 核心机制

- **深度递增**：越深矿物价值越高但危险也越多
- **资源管理**：燃料限制决定每次挖掘的最大深度
- **钻探机升级**：提升速度、耐久和燃料容量

- **每日深度挑战**：固定地形排列，独立排行榜

## 为什么好玩

挖掘带来的探索感是核心体验——永远不知道下一层会遇到什么。宝石收集的即时正反馈很强。

## 粘性来源

深度追求+收集目标的驱动。每次'再深一点就能拿到那个宝石'的心理。

## Meta 系统

钻探机升级系统：永久性的属性提升。宝石收集图鉴：发现并记录所有宝石种类。

## 实现难度

低 — 滑动控制简单。最大技术难点是地形生成算法和矿物分布。
