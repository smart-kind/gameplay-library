# Icy Village: Survival Idle

- **类型**: 放置经营 / 生存模拟
- **平台**: Mobile (iOS)
- **开发商**: UNIMOB VIET NAM COMPANY LIMITED
- **首次发布**: 2023
- **一句话描述**: Icy Village: Survival Idle是一款冰雪主题的放置生存模拟游戏。玩家带领一群幸存者在冰冻荒野中建立并管理一个逐渐繁荣的村庄。

## 玩法规则

游戏以俯视角呈现冰雪覆盖的村庄场景，画面温馨可爱。屏幕上方显示资源状态（木材、石材、食物），下方是建筑和功能按钮。玩家需要采集木材、石材和食物来维持村民的生存，点击场景中的资源点进行采集，或通过已建造的建筑自动生产。村庄可以从一个简陋的篝火营地逐步升级为拥有各种工坊和设施的繁荣定居点，每个建筑有不同的功能和升级路线。村民管理系统允许玩家分配工作：伐木工、矿工、猎人、农夫等，不同职业影响资源获取效率。游戏支持离线进度，关闭游戏后村庄仍在运转，下次打开时可收取离线期间积累的资源。

## 核心循环

采集资源 -> 建造和升级建筑 -> 分配村民工作 -> 离线积累资源 -> 收取并继续扩展 -> 重复

## 核心机制

- 资源管理：木材、石材、食物三种核心资源，需要平衡分配
- 村民分配：给村民分配不同职业，影响资源产出效率
- 建筑升级：从简陋营地到繁荣村庄的渐进式建造系统
- 离线收益：关闭游戏后持续积累资源，降低玩家压力

## 为什么好玩

冰雪生存主题在放置游戏中比较少见，带来新鲜感。看着小村庄从篝火营地一步步发展为繁华定居点的过程很有成就感。放置机制让游戏轻松无压力。

## 粘性来源

离线收益让每天都有回归的理由；建筑升级提供持续的进度感；资源管理的策略深度让放置不只是放着

## Meta 系统

有村民管理系统（职业分配）、建筑升级树、离线奖励系统。社区通过Facebook和Discord运营。

## 实现难度

中。核心难点在于放置经营玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
