# 在几何空间中飞行，用球击碎玻璃障碍物（Smash Hit）

- **类型**: 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Mediocre
- **首次发布**: 2014
- **一句话描述**: 在几何空间中飞行，用球击碎玻璃障碍物

## 玩法规则

玩家在一个不断向前移动的3D几何空间中，用手指点击发射金属球击碎前方的玻璃障碍。

球数量有限，击中玻璃获得额外球。撞到玻璃（球用完）游戏结束。

## 核心循环

飞行 → 瞄准发射球 → 击碎玻璃 → 获得球 → 继续前进

## 核心机制

- 自动前进
- 瞄准射击
- 球资源管理

## 为什么好玩

击碎玻璃的物理反馈极其满足。

## 粘性来源

关卡进度；高分挑战。

## Meta 系统

关卡解锁。

## 实现难度

低。点击射击简单。最大技术难点：物理破碎效果。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
