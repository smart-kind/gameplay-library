# Word Mole（单词鼹鼠）

- **类型**: 文字 / 益智 / 拼词
- **平台**: Mobile (Android / BlackBerry)
- **开发商**: Nukenin LLC（Android 版本）
- **首次发布**: 2012（原版为 BlackBerry 预装游戏）
- **一句话描述**: 在 6×6 字母网格中拼写单词的文字益智游戏，灵感来自 PopCap 的 Bookworm

## 玩法规则

Word Mole 的核心玩法是在一个图形压缩的 6×6 字母网格中拼写单词，类似 PopCap 经典游戏 Bookworm 的变体。

**核心操作**：玩家点击网格中的字母来组成单词。被选中的字母必须彼此相邻——如果选择的字母不相邻，它们之间的空格会被铲平的泥土填充，减少可用空间。

**单词要求**：至少需要三个字母的单词。由于网格空间有限，玩家很难组成长单词，大多数情况下只能拼出三个字母的短词。

**得分目标**：每个关卡有目标分数（初始为拼出 10 个单词），但分数要求似乎不会随关卡增加而提高，导致重复游玩时目标缺乏挑战性。

**字母刷新**：被使用的字母会被新字母替换，但字母池偏向辅音，导致屏幕上很快充斥着无用的 P、Q 等字母，难以组成有效单词。

**语音功能**：默认情况下，游戏会用机器人女声朗读每个输入的字母，这个功能在公共场合可能造成尴尬，但可以静音。

## 核心循环

选择相邻字母 → 组成单词 → 获得分数 → 字母刷新 → 继续拼写

## 核心机制

- **相邻字母约束**：只有相邻的字母才能组成一个单词，这个约束增加了策略性——不能随意从网格各处选字母
- **空格惩罚**：选择不相邻字母会导致中间空间被泥土覆盖，永久性减少可用字母格，这是一个惩罚机制
- **辅音偏差**：字母池中辅音过多，导致长单词难以组成，限制了游戏的深度
- **计时模式**：对抗时钟的模式增加紧迫感

## 为什么好玩

原版（BlackBerry 预装版）曾是早期智能手机上最好的文字游戏之一，提供了简单但有挑战性的拼词体验。但 Android 移植版质量大幅下降——图形压缩、字母分布不合理、缺乏难度递进，使其变成了令人沮丧的重复操作。

## 粘性来源

文字游戏天生具有粘性——每次字母组合不同，玩家总想试试能不能拼出更好的词。但 Android 版本的辅音偏差和目标缺乏变化严重削弱了这一点。

## Meta 系统

声称有三种难度模式，但实际上除了名称外没有可感知的区别。

## 实现难度

低 — 核心就是字母网格渲染、相邻判定和词典验证。最大技术难点在于字母分布算法的设计——需要保证合理的元音/辅音比例，避免游戏中期出现无解局面。
