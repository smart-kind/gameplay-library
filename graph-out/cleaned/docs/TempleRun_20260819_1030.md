# 神庙逃亡（Temple Run）

- **类型**: 无尽跑酷 / 动作 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Imangi Studios
- **首次发布**: 2011
- **一句话描述**: 在古老神庙中向前狂奔，躲避障碍物、陷阱和追赶的怪物，尽可能跑得更远以获得更高分数。

## 玩法规则

游戏画面是第三人称后方视角，角色在一条不断向前延伸的神庙通道中自动奔跑。通道中有各种障碍物：断裂的地面需要跳跃、低矮的横梁需要滑行、转弯需要左右滑动、陷阱需要跳跃躲避。

操作方式只有四个滑动手势：向上滑跳跃（越过沟壑和矮障碍）、向下滑滑行（从横梁下穿过）、向左滑左转（在岔路口选择左边）、向右滑右转（在岔路口选择右边）。操作需要快速反应，因为障碍物出现后留给玩家的时间很短。

角色身后有怪物（恶魔猴子）在追赶，如果撞到障碍物或掉入陷阱，怪物会追上并抓住玩家，游戏结束。游戏没有终点，是"无尽模式"——跑的时间越长，速度越快，障碍物越密集。

游戏中散布着金币和道具（磁铁、加速、护盾等），金币可以用来购买新角色和升级道具。

## 核心循环

向前奔跑 → 躲避障碍 → 收集金币 → 速度加快 → 失误被怪物追上 → 游戏结束 → 用金币升级 → 重新开始

## 核心机制

- **反应速度挑战**：障碍物的出现和逼近速度随着游戏进行越来越快，对玩家的反应速度要求越来越高。这是游戏难度的核心来源。
- **三岔路选择**：通道不时出现左右分岔，玩家需要快速选择方向。分岔路后面可能通向不同的路线，有些路线障碍物更少。
- **道具系统**：磁铁（自动吸引金币）、加速（短时间内免疫碰撞并加分）、护盾（抵挡一次碰撞）、分数倍增。道具的使用时机影响最终分数。
- **任务系统**：每次游戏都有随机生成的任务（如"收集500金币"、"使用3次护盾"、"跑1000米"等），完成任务获得额外金币奖励。

## 为什么好玩

极致的紧张感——怪物在身后紧追不舍，速度越来越快，任何一个小失误就意味着结束。那种"手心出汗、心跳加速"的体验是其他游戏很难提供的。

## 粘性来源

- **高分挑战**：无尽模式天生适合刷高分，每次跑得更远都是个人突破
- **任务驱动**：随机任务给每次奔跑额外目标，增加重玩意愿
- **收集系统**：解锁新角色和升级道具提供长期目标
- **随时可玩**：单局1-5分钟，等车、排队等碎片时间完美匹配

## Meta 系统

- **角色解锁**：用金币购买新角色，每个角色有独特外观
- **道具升级**：用金币延长道具效果持续时间
- **任务成就**：完成特定任务获得成就和奖励

## 实现难度

低 + 核心是3D无尽跑道生成和碰撞检测，技术实现相对简单。最大难点在于跑道生成的随机性和难度曲线的平衡，确保游戏既刺激又公平。
