# Twingo

- **类型**: 益智 / 旋转解谜 / 休闲
- **平台**: Nintendo DS
- **开发商**: Nintendo SPD
- **首次发布**: 2009
- **一句话描述**: 通过旋转和连接彩色管道，引导水流从起点到达终点。

## 玩法规则

游戏画面为俯视视角的网格棋盘，棋盘上散布着各种管道碎片（直管、弯管、T型管、交叉管等），每种管道有不同的颜色。

操作方式：
- **触控笔点击/拖拽**：点击管道碎片将其旋转90度。
- **触控笔拖拽**：将管道碎片移动到相邻的空格。
- **旋转**：每次点击一个管道碎片，它会顺时针旋转90度。
- **连接判定**：当所有管道的开口相互对齐并形成从起点到终点的连续通道时，水开始流动。

游戏目标：通过旋转（有时还包括移动）管道碎片，使它们相互连接形成一条从水源（起点）到目标（终点）的完整管道通路。连接完成后，水会流过管道，视觉上确认解谜成功。

每个关卡有步数限制（旋转次数限制），需要在限制步数内完成连接。部分关卡有时间限制，需要在规定时间内完成。

后续关卡引入更多颜色、更多管道类型、更复杂的棋盘布局。

## 核心循环

观察管道布局 → 规划连接方案 → 旋转/移动管道 → 验证通路 → 水流通过/成功 → 下一关

## 核心机制

- **旋转解谜**：核心机制是旋转管道碎片使它们的开口对齐。每个碎片有多个可能的朝向，玩家需要找到正确的组合。
- **多色管道**：不同颜色的管道不能互相连接，增加了谜题的复杂度。需要同时解决多条独立的管道路径。
- **步数限制**：限制旋转次数迫使玩家思考最优方案而非随机尝试。
- **路径规划**：玩家需要预判多个管道的旋转结果，找到全局最优解而非局部最优。

## 为什么好玩

Twingo 是经典"Pipe Mania"类游戏在DS平台上的变体。它的乐趣在于"差一点就通了"的紧张感和最终水流通过时的满足感。触控笔操作让旋转管道非常直观——点一下转90度，简洁明了。多色管道的引入让简单机制有了策略深度。

## 粘性来源

- **解谜快感**：找到正确解法后的成就感。
- **关卡递增**：后续关卡的管道更多、颜色更多、布局更复杂。
- **步数挑战**：在最少步数内完成关卡的高难度挑战。

## Meta 系统

无 — 独立关卡制。

## 实现难度

**低** — 旋转逻辑和连接判定算法简单。最大技术难点在于关卡设计——需要确保每个关卡有解且难度适当递增。
