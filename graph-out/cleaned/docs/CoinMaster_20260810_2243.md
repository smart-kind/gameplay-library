# 老虎机+村庄建设的休闲社交游戏（Coin Master）

- **类型**: 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Moon Active
- **首次发布**: 2015
- **一句话描述**: 老虎机+村庄建设的休闲社交游戏

## 玩法规则

玩家通过旋转老虎机获得金币、攻击/突袭其他玩家村庄的机会、护盾或能量。

金币用于建设和升级自己的村庄（5个建筑，每个10级）。攻击可以破坏其他玩家的建筑获得金币，突袭可以一次性获得大量金币，护盾保护自己不被攻击。

游戏有卡片收集系统，完成卡片组获得额外奖励。玩家有5次旋转能量，随时间恢复。

## 核心循环

旋转老虎机 → 获得金币/攻击机会 → 建设村庄 → 收集卡片 → 升级 → 解锁新世界

## 核心机制

- 老虎机随机性：每次旋转可能获得不同类型的奖励
- 村庄建设：5个建筑各有10级，提供进度目标
- 社交互动：可以攻击好友或其他玩家的村庄，也可以赠送能量
- 卡片收集：收集成套卡片获得大量奖励

## 为什么好玩

老虎机的随机快感结合村庄建设的成就感，攻击他人村庄的报复心理和防御的紧张感形成有趣的社交互动。

## 粘性来源

随机奖励的成瘾性；村庄进度的可视化成长；社交互动的竞争感；卡片收集的收集欲。

## Meta 系统

村庄建设进度+卡片收集系统。玩家逐关解锁新世界和主题。

## 实现难度

低。操作极简（只需点击旋转），但策略在于资源管理和社交互动。最大技术难点：多人交互系统的实时性和经济系统平衡。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
