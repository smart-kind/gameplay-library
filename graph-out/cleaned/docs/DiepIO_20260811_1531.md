# 坦克大作战（Diep.io）

- **类型**: 多人在线竞技 + 升级
- **平台**: Web (浏览器)
- **开发商**: Matheus Valadares
- **首次发布**: 2016
- **一句话描述**: 控制一个几何坦克在竞技场中射击形状和对手，通过击杀获得经验升级的多人游戏

## 玩法规则

游戏画面是一个巨大的2D平面竞技场。玩家控制一个圆形坦克，可以移动（WASD）和射击（鼠标瞄准，自动射击）。

竞技场上散布着各种几何形状（正方形、三角形、五边形），射击它们可以获得经验和分数。击杀其他玩家的坦克获得更多分数。

获得经验后坦克升级，获得技能点。技能点可以分配到八个属性：最大生命值、生命恢复、子弹速度、子弹穿透、子弹伤害、移动速度、穿透能力、射程。

升级后玩家可以选择不同的坦克形态：双管坦克、狙击坦克、机枪坦克、无人机坦克等。不同形态有不同的射击模式和战术优势。

游戏有多个模式：自由对战、团队死斗、大逃杀（逐渐缩小的安全区）、Boss战等。

## 核心循环

射击形状/敌人 → 获得经验 → 升级加点 → 选择新形态 → 继续击杀

## 核心机制

- **属性加点策略**：八个属性提供了丰富的Build可能性。全加子弹伤害是进攻型，全加生命和恢复是防御型，均衡加点是通用型。没有唯一最优解。
- **坦克进化树**：升级后选择不同的坦克形态，每种形态有独特的攻击方式。从基础坦克可以进化出十几种不同变体。
- **形状生态**：正方形最简单击杀但经验少，五边形最难击杀但经验多。这创造了一个"风险-回报"的选择：是安全地打正方形还是冒险打五边形？

## 为什么好玩

简单的几何画面下是深度的升级策略。每次升级都面临选择：加什么属性？进化成什么坦克？这种持续的选择让游戏保持新鲜。多人对战的不确定性也增加了变数。

## 粘性来源

- **Build多样性**：每次可以尝试不同的属性加点和坦克形态
- **多人对战**：每次匹配的敌人水平不同，对战体验变化丰富
- **快速一局**：死亡后立即重生，节奏快
- **排行榜**：成为服务器最高分是荣耀

## Meta 系统

- **排行榜**：显示服务器前几名的玩家
- **多种游戏模式**：FFA、Team、Maze、Tag、Survival等
- **等级解锁**：达到特定等级解锁新坦克形态

## 实现难度

低。2D碰撞检测和射击逻辑是成熟技术。最大的技术难点是多人同步——需要处理大量玩家同时在线的网络延迟和状态同步。
