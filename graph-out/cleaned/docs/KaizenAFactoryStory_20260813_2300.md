# Kaizen: A Factory Story（改善：工厂物语）

- **类型**: 自动化 / 解谜 / 工厂建造
- **平台**: PC (Windows)
- **开发商**: Coincidence（Zach Barth 新工作室）
- **发行商**: Astra Logical
- **首次发布**: 2025
- **一句话描述**: 由 Zachtronics 创始人打造的全新自动化解谜游戏，在工厂建设中融入持续改善（Kaizen）理念。

## 玩法规则

游戏画面为俯视视角的工厂平面图，玩家在一个网格化的工作台上设计和建造生产线。界面布局清晰：左侧是可用元件库（传送带、机器臂、加工设备等），中间是工作区，右侧或上方显示当前关卡的目标输出（需要生产的产品规格和数量限制）。

每一关都有明确的生产目标：在有限的空间内，用给定的元件搭建一条能将原材料转化为成品的生产线。原材料从入口进入，经过一系列加工步骤（切割、焊接、组装、质检等），最终输出成品。

玩家的核心操作是拖拽元件到工作区，连接传送带建立物流通道，然后启动生产线观察运行效果。生产线启动后，你会看到小方块（原材料）在传送带上流动，进入加工设备，被机器臂抓取和移动——整个过程像是一个微缩工厂在自动运转。

如果生产线出现问题（比如材料堵塞、加工顺序错误、输出不合格），玩家可以暂停运行，重新调整布局，然后再次启动测试。这种"设计→测试→调试→优化"的循环是游戏的核心玩法。

与 Zachtronics 之前的作品不同，Kaizen 引入了"持续改善"理念：你不仅要完成生产目标，还要不断优化你的生产线，提高效率、减少浪费。

## 核心循环

设计生产线 → 运行测试 → 发现问题 → 优化调整 → 追求更高效率

## 核心机制

- **网格化建造系统**：所有元件放置在网格上，精确但不会过于繁琐。这种设计让玩家既能进行精密规划，又不会陷入像素级的繁琐操作。
- **实时可视化反馈**：生产线运行时有直观的动画效果——材料流动、机器运转、故障点高亮显示。玩家一眼就能看出问题出在哪里，无需阅读复杂的日志。
- **"Kaizen"评分系统**：不仅看"能不能完成"，还看"完成得有多好"。效率、空间利用率、材料浪费率都可能影响评分，鼓励玩家不断优化。
- **逐步解锁的元件库**：新元件随关卡推进解锁，确保玩家每次只面对复杂度的一小部分增量，避免 overwhelm。

## 为什么好玩

Kaizen 的开发商 Coincidence 由 Zach Barth 创立——他是 Zachtronics 的创始人，开发了《SpaceChem》《Infinifactory》《Opus Magnum》等被公认为最优秀的自动化解谜游戏。这款新作延续了"用工程思维解决有趣问题"的核心理念，同时加入了"持续改善"的日式工业哲学，让优化过程本身成为一种乐趣。

## 粘性来源

- **"再优化一下"的强迫症循环**：自动化解谜游戏最强的粘性就是——"我已经完成了目标，但我想知道能不能做得更好"。评分系统、效率排名、更优雅的解决方案都会驱使玩家反复回到同一关卡。
- **工程成就感**：看着自己设计的复杂生产线流畅运转，本身就是一种巨大的成就感。
- **渐进式复杂度**：每关只引入少量新元素，玩家始终在"舒适区边缘"学习，不会因难度陡增而放弃。

## Meta 系统

无。游戏是纯粹的关卡式解谜体验，没有外围成长或收集系统。

## 实现难度

**中等偏高**。核心难点在于：1）生产线模拟引擎——需要精确模拟元件间的时序和碰撞关系，避免状态死锁；2）元件交互逻辑——每种元件的行为规则需要精确定义，组合爆炸会带来大量边界情况；3）UI/UX 设计——需要让复杂的工厂布局操作直观流畅。Zach Barth 团队有多款成功作品的经验积累，技术风险可控。
