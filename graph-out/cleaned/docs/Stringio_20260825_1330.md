# String.io

- **类型**: IO多人在线竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: Metajoy
- **首次发布**: 2017

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 游戏主界面通常包含多个操作按钮和信息显示区域。顶部可能显示分数、计时器或关卡进度。
- 中央区域是主要的游戏操作区域，显示游戏元素（泡泡、宝石、角色、地图等）。
- 底部或侧边显示可用操作、手牌或待放置元素。

玩家的操作方式包括：
- 点击/拖拽：选择并放置游戏元素，进行匹配或移动操作
- 滑动：在某些游戏中进行方向控制或瞄准
- 长按：在某些游戏中蓄力或执行特殊操作

## 核心循环

进入在线房间 -> 与其他玩家实时竞技 -> 扩大体型/领地 -> 争夺排行榜第一

## 核心机制

- **多人实时竞技**: 多个玩家在同一张地图上实时对战。所有玩家从相同起点开始，通过收集资源或击败对手来成长。
- **成长吞噬机制**: 玩家通过收集地图上的资源点或击败其他玩家来增长体型。体型越大，能控制的区域越大，但也成为更明显的目标。
- **排行榜竞争**: 游戏实时显示所有玩家的排名。登顶排行榜是最终目标。排行榜提供了明确的竞争目标。

## 为什么好玩

IO游戏的魅力在于与真人对抗的紧张感。每次对局都是全新的体验，因为对手的策略和行为无法预测。

## 粘性来源

粘性来源于真人对抗的不可预测性和排行榜竞争的刺激感。'差一点就赢了'的不甘心驱动再来一局。

## Meta 系统

- 实时排行榜：按当前对局表现排名
- 对核心玩法的影响：排行榜提供竞争目标

## 实现难度

中 -> IO游戏需要实时多人服务器和同步机制。核心玩法实现不难，但多人同步、延迟处理和服务器运维是主要难点。
