# 港口管理员（Harbor Master）

- **类型**: 休闲 / 益智 / 交通管理
- **平台**: Mobile (iOS, Android)
- **开发商**: Imangi Studios
- **首次发布**: 2009
- **一句话描述**: 一款经典的交通管理小游戏，玩家需要引导不同颜色和类型的船只安全进出繁忙的港口。

## 玩法规则

游戏画面为俯视视角的港口地图，有不同颜色的码头区域。不同类型的船只（货轮、快艇、渔船等）从屏幕边缘出现，每种船有对应的颜色标记。地图上还可能有浮标、暗礁等障碍物。

玩家操作是画线引导——用触控笔从船只拖画一条航线到对应颜色的码头。船只会自动沿画好的航线行驶。核心规则是：船只不能相撞！两船航线交叉或距离过近会导致碰撞，游戏立即结束。

每种船的行驶速度不同：快艇速度快但灵活度低，货轮速度慢但转弯半径大。玩家需要预判船的行驶轨迹，合理安排进出顺序。后期还会出现油轮等特殊船只，需要特别小心。

游戏目标是在尽可能长的时间内管理港口，让所有船只安全停靠。随着游戏进行，船只数量增多、速度加快、种类变复杂，难度逐步上升。分数基于安全停靠的船只数量和时间。

## 核心循环

观察 incoming 船只 -> 画线引导到码头 -> 避免碰撞 -> 获得分数 -> 迎接更多船只

## 核心机制

- 航线绘制系统：玩家用手指画线为船只规划航线，画出的路径会被船只自动跟随。线条颜色需与码头颜色匹配。
- 碰撞检测机制：任何两船距离过近或航线交叉即判定碰撞，游戏立即结束。这要求玩家具有前瞻性的空间规划能力。
- 渐进式难度：船只种类从单一到多样，速度从慢到快，数量从少到多，让玩家逐步适应游戏节奏。

## 为什么好玩

Harbor Master的乐趣在于空中交通管制员般的紧张感——眼睛要同时关注多个移动目标，大脑要快速规划最优航线。每次成功引导一批船只安全进港后的放松感与下一波船只带来的紧张感交替，形成独特的游戏节奏。

## 粘性来源

粘性来自再试一次的心理——每次碰撞都让人觉得就差一点，忍不住重新挑战更高的分数。简洁的画线操作也让每局游戏非常碎片化，适合随时随地来一把。

## Meta 系统

无核心外围系统，纯分数挑战模式。部分版本有成就系统和排行榜。

## 实现难度

低。最大的技术难点在于碰撞检测的精度和船只AI的路径跟随——需要确保画出的航线平滑且船只不会因碰撞检测过于敏感而误判。
