# Zookeeper World（Zookeeper World）

- **类型**: 三消匹配 + 模拟经营
- **平台**: Mobile (iOS Apple Arcade)
- **开发商**: Kairosoft / Apple Arcade 独占版
- **首次发布**: 2022（Apple Arcade 版本，原作 2003）
- **一句话描述**: 消除匹配动物获得资源，用资源建造和升级自己的动物园

## 玩法规则

游戏分为两个部分：三消棋盘和动物园地图。

三消棋盘是标准的 8x8 网格，里面填充各种动物头像（猴子、大象、企鹅、蛇等）。玩家交换相邻动物实现 3+ 连消，消除后获得对应动物的"资源点数"。

消除的动物资源用于动物园部分：购买新动物、建造栖息地、升级设施。不同的动物需要不同类型的栖息地，栖息地建成后吸引更多游客，游客带来更多收入。

收入反过来可以购买更多三消棋盘上的"道具"（炸弹、刷新、额外步数等），帮助在三消中走得更远。

## 核心循环

三消匹配动物 → 获得动物资源 → 建造/升级动物园 → 获得收入 → 购买三消道具 → 继续三消

## 核心机制

- 机制1：三消+经营双循环——不同于 Candy Crush 的纯三消，这里的消除直接服务于经营目标，两个系统互相驱动
- 机制2：动物收集——每种动物有独特外观和栖息地需求，收集全部动物是长线目标
- 机制3：栖息地建造——动物需要匹配类型的栖息地（水生、陆地、极地等），增加了规划的策略维度

## 为什么好玩

三消的即时爽感 + 动物园建设的长线满足感。比纯三消多了"我在建造什么"的目标感，比纯经营多了三消的操作乐趣。

## 粘性来源

动物收集（解锁新物种）+ 动物园扩建（从小动物园到大型主题公园）+ 三消关卡推进 + Apple Arcade 独占的内容持续更新

## Meta 系统

动物园等级提升 + 栖息地解锁树 + 每日任务 + 特殊活动（节日限定动物等）。

## 实现难度

中。需要两套系统（三消引擎 + 经营模拟）的对接。三消部分成熟方案多，经营部分需要设计资源平衡和建筑解锁树。难点在于两个系统的资源循环不能互相卡死。
