# 放置游戏1（Idle Game 1）

- **类型**: 放置 / 策略 / 增量
- **平台**: Mobile (iOS+Android)
- **开发商**: Cem Kamiloglu
- **首次发布**: 2020
- **一句话描述**: 专为资深放置玩家设计的增量游戏，每轮随机声望加成带来全新的策略体验

## 玩法规则

Idle Game 1 是一款专为资深放置游戏玩家设计的增量游戏。与传统放置游戏不同，它引入了随机升级系统，让每一轮都有独特的策略体验。

游戏界面简洁：顶部显示当前资源数量和倍率，中部是升级列表，底部是操作按钮。玩家通过积累资源购买各种升级来提升产出效率。

每轮游戏开始时会随机分配一个"声望加成"（prestige bonus），这个加成会影响本轮的游戏策略。例如，某个加成可能大幅提升某一类升级的效果，玩家需要根据当前加成调整升级优先级。

玩家需要分析当前随机加成，决定最优的资源分配策略。这与传统放置游戏的固定升级路线不同，每轮都需要重新思考和优化。没有'标准答案'，只有当前加成的最优解。

当资源积累到一定程度后，可以进行声望重置，获得新的随机加成并开始新一轮。每轮的随机加成都不同，需要不同的策略应对。

## 核心循环

分析随机加成 → 优化升级策略 → 积累资源 → 声望重置 → 新加成新策略

## 核心机制

- 随机声望加成：每轮开始时随机分配特殊加成，改变最优策略。这是游戏最大的特色，让每轮都不同
- 策略优化需求：玩家必须根据当前加成调整升级优先级，增加策略深度。与传统放置游戏的固定路线形成对比
- 面向资深玩家：复杂的数值系统和策略考量，不适合新手。这反而形成了一个精准的受众定位

## 为什么好玩

为放置游戏老手量身定制，随机加成系统让每轮都是新体验。策略优化过程本身就是一种乐趣——找到当前加成的最优解很有成就感。没有固定答案的设计鼓励思考和实验。

## 粘性来源

策略求解乐趣——'这个加成下应该怎么升级最优？'的思考过程让人欲罢不能。随机性确保不会重复。声望系统提供长期目标。资深玩家社区可能分享策略，增加社交维度。

## Meta 系统

声望重置系统：重置进度获得随机加成，每轮加成不同。加成类型多样，影响不同的升级路径。对核心玩法的影响是让每次重开都有新的策略挑战，而不是简单的进度加速。

## 实现难度

中等 — 需要实现随机加成系统和策略评估逻辑。最大技术难点是确保随机加成的多样性与平衡性，避免某些加成过强或过弱导致策略单一。
