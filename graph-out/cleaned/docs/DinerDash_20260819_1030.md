# 餐厅冲冲冲（Diner Dash）

- **类型**: 时间管理 / 模拟经营
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: PlayFirst (原版) / Glu Games (Adventures版)
- **首次发布**: 2004
- **一句话描述**: 扮演餐厅服务员Flo，在有限的时间内为顾客安排座位、点单、上菜、收账，管理越来越繁忙的餐厅。

## 玩法规则

游戏画面是一个餐厅俯视图，分为入口、餐桌区、厨房（或吧台）、收银台等区域。顾客从门口进入，头顶显示耐心值（颜色从绿到红渐变），玩家需要将顾客引导到空桌上坐下。

顾客坐下后会发出点单信号（头顶出现食物图标），玩家需要走到顾客面前记下订单，然后走到厨房将订单放入。厨房制作完成后，食物出现在出餐口，玩家需要将食物端到对应顾客的桌上。顾客吃完后头顶出现账单信号，玩家需要去收银结账并清理桌面。

游戏按关卡进行，每关有时间限制和分数目标。随着关卡推进，顾客数量增多、耐心降低、订单组合变复杂，还可能同时出现多组顾客需要分配不同大小的餐桌。

## 核心循环

接待顾客 → 记录订单 → 厨房制作 → 上菜 → 结账清台 → 获得金币和分数 → 升级餐厅

## 核心机制

- **多任务调度**：玩家需要同时追踪多个顾客的状态（等待入座、等待点单、等待上菜、等待结账），合理安排行动顺序。核心挑战在于"先服务谁"的决策——耐心值低的顾客优先，但也需要考虑行走路径的效率。
- **耐心值系统**：每位顾客有独立耐心计时器，耐心耗尽会离开并扣分。耐心值通过颜色变化直观显示，给玩家紧迫感。
- **餐桌优化**：不同大小的餐桌容纳不同人数的顾客组。合理匹配顾客人数与餐桌大小，避免大桌坐小客造成座位浪费，也影响通关效率。
- **关卡递进**：每关有明确的分数目标，通过关卡后解锁新餐厅主题和装饰，给予成就感。

## 为什么好玩

"手忙脚乱"的紧张感是核心体验——当你同时面对5桌客人，每个人都等着不同的服务时，那种"先顾谁"的决策焦虑和高效完成任务后的爽快感形成强烈对比。游戏完美模拟了真实餐厅服务员的工作节奏。

## 粘性来源

- **时间管理挑战**：每一关的分数目标和限时机制让玩家想反复尝试刷更高分
- **"差一点就过"的挫败感**：经常差几十分就能过关，促使玩家再来一局
- **进度解锁**：新餐厅主题、装饰和道具的逐步解锁提供长期目标
- **节奏上瘾**：短关卡（3-5分钟）让"再来一把"的心理门槛极低

## Meta 系统

- **餐厅升级**：用赚取的金币购买新桌椅、装饰和道具，提升餐厅美观度和小费收入
- **关卡解锁**：每关通关后解锁下一关，线性推进
- **小游戏元素**（Adventures版）：融入消除等小游戏机制进行餐厅翻新

## 实现难度

低 + 核心是路径规划和状态机管理，技术上不复杂。最大难点在于平衡关卡难度曲线和玩家体验，确保游戏既紧张又不至于让人沮丧。
