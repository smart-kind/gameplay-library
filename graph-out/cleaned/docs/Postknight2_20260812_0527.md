# 扑克骑士 2（Postknight 2）

- **类型**: RPG/放置
- **平台**: Mobile (iOS+Android)
- **开发商**: Kurechii
- **首次发布**: 2021
- **一句话描述**: 放置 RPG 续作，扮演邮递骑士穿越王国送达邮件。

## 玩法规则

自动战斗 RPG，玩家控制邮递骑士穿越王国各个区域送达邮件。战斗自动进行，玩家可以在关键时刻使用技能和物品。非战斗时间可以升级装备、学习技能和完成任务。

每个区域有不同的敌人和环境，Boss 战需要手动使用技能。角色可以装备不同武器和盔甲，影响战斗风格。

## 核心循环

自动战斗通过区域 → 使用技能应对 Boss → 送达邮件 → 获得奖励 → 升级装备 → 前往下一个区域

## 核心机制

- 自动战斗：角色自动攻击，玩家管理技能和物品使用
- 装备系统：不同武器和盔甲改变战斗风格
- 任务推进：送达邮件推进故事，解锁新区域

## 角色成长与社交

角色通过战斗获得经验值，升级后可以分配属性点到力量、敏捷、智力等属性。不同属性影响不同的战斗风格。

社交功能允许玩家拜访其他玩家的小镇，互相赠送礼物和协助完成任务。公会系统提供团队合作内容。

## 为什么好玩

轻松放置与关键时刻手动操作的结合，适合碎片时间游玩。可爱的像素风格和幽默的剧情对话。

## 粘性来源

装备收集、角色升级和故事推进的持续动力。

## Meta 系统

免费下载，有可选内购

## 实现难度

低 — 自动战斗为主，手动操作集中在关键时刻
