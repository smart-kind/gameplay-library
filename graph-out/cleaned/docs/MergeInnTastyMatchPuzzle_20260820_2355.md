# Merge Inn（Merge Inn - Tasty Match Puzzle）

- **类型**: 合成解谜 / 模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: Original Games Pte. Ltd.
- **首次发布**: 2021
- **一句话描述**: 一款餐厅主题合成游戏，通过合并食材完成顾客订单，逐步将破旧小餐馆升级为梦幻咖啡馆。

## 玩法规则

游戏主界面展示一个餐厅场景（初始为破旧状态）和一个合成棋盘。棋盘上有各种食材格子（面包、肉、蔬菜等）。玩家拖拽两个相同食材合并为更高级的食物（如两片面包→三明治，两个三明治→套餐）。

上方区域展示顾客订单栏，显示当前顾客需要什么食物。完成订单获得金币和装饰积分。金币用于升级厨房设备（更多格子、更快刷新），装饰积分用于翻新餐厅（换墙纸、买新桌椅、添置装饰画）。

每个顾客有耐心条，耐心耗尽会离开（不扣资源但失去奖励）。高级顾客需要更复杂的食物组合，但奖励更丰厚。

游戏没有关卡失败机制，只有进度推进。当餐厅装饰达到一定等级时解锁新的餐厅区域或章节。

## 核心循环

合并食材完成订单 → 获得金币和装饰积分 → 升级厨房设备和翻新餐厅 → 解锁新章节

## 核心机制

- **订单驱动合成**: 与纯探索式合成不同，顾客订单提供明确目标——我需要合并出3份三明治，给合成操作赋予意义和方向感，减少无目的性
- **餐厅渐进改造**: 从破旧 diner 到梦幻 café 的视觉变化提供强烈的成就感，每个装饰改变都是可视化的进度条
- **厨房设备升级**: 升级扩大棋盘格子数、增加刷新速度，降低游戏难度曲线，让玩家感觉我在变强而非关卡在变难

- **顾客分层系统**: 顾客分为普通（1星）、VIP（2星）、美食家（3星）三个等级，等级越高订单越复杂但奖励越丰厚。VIP顾客出现概率受餐厅装饰等级影响，鼓励玩家持续升级
- **食材配方图鉴**: 每次发现新配方（合并出从未出现过的食物组合）时录入图鉴，图鉴完成度百分比提供明确的收集目标

## 为什么好玩

合成操作的即时满足感叠加餐厅改造的长线目标，形成双重正向反馈。顾客订单提供明确目标而不仅是随便合并，让每次操作都有意义。餐厅从破旧到华丽的转变过程有很强的叙事感。

## 粘性来源

餐厅改造的半成品效应——看到餐厅还差几个装饰就能完成下一阶段的强烈冲动；订单刷新带来的短期目标循环；顾客离开产生的轻微损失厌恶。

## Meta 系统

- **餐厅装修与厨房升级**: 消耗装饰积分购买装修项目，消耗金币升级厨房设备
- **对核心玩法的影响**: 装修解锁新场景和顾客类型，厨房升级降低游戏难度

## 实现难度

低 — 合成+装修模板成熟，最大技术难点是订单生成的平衡算法（不能让订单太难或太简单）
