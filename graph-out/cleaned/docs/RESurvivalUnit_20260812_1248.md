# 生化危机：生存小队（Resident Evil Survival Unit）

- **类型**: 战术射击 / 生存恐怖
- **平台**: Mobile (iOS+Android)
- **开发商**: NetEase Games / Capcom
- **首次发布**: 2025
- **一句话描述**: 基于《生化危机》IP的战术生存射击手游，玩家在丧尸横行的环境中组队完成生存任务。

## 玩法规则

玩家在俯视角或第三人称视角的废墟城市地图中控制一名角色，屏幕左侧虚拟摇杆控制移动，右侧按钮控制瞄准和射击。

地图中随机刷新武器（手枪、霰弹枪、步枪）、医疗用品和弹药。玩家需要在限定时间内抵达安全点或消灭指定数量的感染者。

每次任务开始前，玩家可以选择角色职业（突击兵、医疗兵、工程师），不同职业携带不同的初始装备和技能。

游戏采用永久死亡或半永久死亡机制——如果角色在任务中阵亡，需要等待一段时间恢复或使用复活道具。队伍最多4人，可以匹配陌生人或邀请好友。

目标是在充满丧尸和其他敌对玩家的危险区域中存活并完成特定目标（如收集线索、护送NPC、守卫据点）。当所有队员阵亡或时间耗尽时任务失败。

## 核心循环

进入危险区域 → 搜集装备 → 完成任务目标 → 撤离获得奖励 → 用奖励升级角色和解锁新区域

## 核心机制

- 职业分工系统：突击兵擅长火力输出，医疗兵可复活队友和回血，工程师能布置陷阱和修理设备，强制玩家协作
- 动态威胁系统：随着时间推移，感染区域会扩大，丧尸密度增加，同时可能出现特殊感染者（如暴君、舔食者）
- 装备稀缺机制：弹药和医疗用品有限，玩家需要在'冒险探索'和'保守保命'之间做选择

## 为什么好玩

紧张刺激的生存压力和团队协作的成就感完美结合。每次进入地图都是未知体验，装备的稀缺性让每次捡到好武器都像中彩票。

## 粘性来源

永久死亡/半永久死亡机制带来的'差一点就成功'的不甘心感是核心粘性；角色职业解锁和装备收集提供长期成长目标；与好友组队的社交互动增强重复游玩动力。

## Meta 系统

角色等级系统：完成任务获得经验升级，解锁新职业技能和属性加成。装备仓库：收集不同品质的武器和装备，可以强化和改装。赛季通行证：每个赛季提供专属任务和外观奖励。

## 实现难度

中高 — 需要实现多人同步、AI导航、动态难度调节和装备系统，技术复杂度较高。最大难点是多人网络同步下的实时射击手感和丧尸AI的性能优化。
