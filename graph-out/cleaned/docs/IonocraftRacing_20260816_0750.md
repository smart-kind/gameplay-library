# Ionocraft Racing（Ionocraft Racing）

- **类型**: 竞速 / 放置
- **平台**: Mobile (iOS + Android)
- **开发商**: MADBOX
- **首次发布**: 2021
- **一句话描述**: 结合放置元素的多人竞速游戏，玩家训练角色、提升属性，与其他玩家比赛

## 玩法规则

游戏以赛车（或竞速角色）为核心，玩家拥有一个可以训练和提升的角色。角色在不同赛道上自动进行竞速比赛，玩家不需要实时操控比赛过程。

玩家在比赛间隙可以查看角色属性（速度、耐力、加速等），通过消耗游戏内资源来提升各项数值。提升后的角色在下一次自动比赛中会有更好的表现。

多人竞速是核心体验——玩家的角色与其他玩家的角色在同一赛道上竞争，排名基于角色的属性和玩家的升级策略。

游戏的目标是在排行榜上获得更高的排名，通过不断训练角色和合理分配升级资源来提升比赛成绩。

## 核心循环

训练角色提升属性 → 自动参与多人竞速 → 获得奖励 → 用来进一步提升角色

## 核心机制

- **放置竞速**：比赛过程自动进行，玩家不需要实时操作，降低了参与门槛，让游戏可以融入碎片时间
- **角色养成**：通过消耗资源提升速度、耐力等属性，玩家需要在不同属性间做出取舍，形成不同的竞速风格
- **多人异步竞争**：虽然比赛是自动的，但对手是真实玩家的角色，排行榜和实时排名提供了竞争感

## 为什么好玩

放置+竞速的组合非常巧妙——玩家不需要长时间在线，但每次回来都能看到比赛结果和排名变化。角色养成的数值成长提供了持续的成就感。

## 粘性来源

数值成长是主要粘性来源：看到角色属性不断提升、排名逐步上升的快感让人欲罢不能。异步多人竞争也增加了社交比较的动力。

## Meta 系统

角色养成系统 — 玩家通过比赛获得的奖励来训练角色、提升各项属性（速度、耐力、加速等），直接影响后续比赛表现

## 实现难度

中 — 放置竞速的核心逻辑不难，但多人异步匹配的服务器架构和数值平衡是主要技术难点
