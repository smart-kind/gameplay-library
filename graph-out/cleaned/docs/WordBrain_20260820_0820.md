# WordBrain (WordBrain: classic word puzzle)

- **类型**: 文字解谜 / 词汇拼写
- **平台**: Mobile (iOS+Android)
- **开发商**: MAG Interactive
- **首次发布**: 2013
- **一句话描述**: 在字母网格中滑动连接字母拼出隐藏的单词，每关需要找出所有目标词汇

## 玩法规则

游戏展示一个由字母组成的方形网格（常见尺寸为 4×4 到 7×7 不等），网格中隐藏着若干个英文单词。玩家需要用手指在相邻字母之间滑动连接，拼出正确的单词。字母必须水平、垂直或对角线相邻才能连接。

屏幕上方显示本轮需要找到的单词数量（如"3/5"表示需要找到5个单词，已找到3个）。每个单词用字母数量标识提示（如"5字母"、"7字母"），但不会显示具体字母顺序。

当玩家拼出正确的单词时，该单词从网格中消失（或高亮标记），同时屏幕播放简短的成功动画和音效。拼完所有目标单词即过关，进入下一关。

操作方式单一：手指滑动连接字母，松开即尝试拼写。没有倒计时限制，玩家可以无限思考。

## 核心循环

滑动字母拼单词 → 单词消除 → 找出所有目标词 → 进入下一关（字母网格变化）

## 核心机制

- **滑动连接机制**: 玩家通过在相邻字母间滑动手指来构建单词路径，支持8个方向（上下左右+四对角线），操作直觉自然，比键盘输入更适合移动端
- **字母数量提示**: 每个目标词只显示字母总数而不显示具体内容，提供恰到好处的线索——既不会太容易也不会无从下手
- **渐进难度曲线**: 从简单短词（3-4字母）开始，逐步增加网格尺寸和单词长度，后期关卡出现生僻词和更长单词

## 为什么好玩

核心乐趣来自"灵光一闪"的顿悟时刻——盯着一堆字母突然看出一个单词。每次成功拼出隐藏词时的满足感类似解开小型谜题。游戏节奏完全自主，没有压力感，适合碎片时间游玩。

## 粘性来源

"只差一个"效应：经常剩最后一个单词找不到，不甘心继续试；每日挑战模式提供额外目标；关卡编号递进（数百关）制造收集冲动；每关过关时的正反馈动画和音效形成习惯回路。

## Meta 系统

关卡递进制：线性推进，无货币系统或角色养成。主要外围元素为每日挑战任务和成就系统。对核心玩法无影响。

## 实现难度

低。核心逻辑为字母网格遍历+字典验证，最大技术难点是高效的单词路径搜索算法（回溯或BFS）。滑动触控和动画为常规UI实现。
