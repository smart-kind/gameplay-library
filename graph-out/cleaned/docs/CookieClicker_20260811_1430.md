# Cookie Clicker（Cookie Clicker）

- **类型**: 放置 / 点击 / 数值成长
- **平台**: Web
- **开发商**: Orteil
- **首次发布**: 2013
- **一句话描述**: 点击屏幕生产饼干，用饼干购买自动化设备，指数级增长产量

## 玩法规则

游戏主界面中央有一个巨大的饼干图案，玩家点击它就能获得一个饼干。屏幕右侧是可购买的升级选项列表，左侧显示当前饼干数量。

核心经济系统：用赚到的饼干购买自动生产建筑，如老奶奶（自动烤饼干）、农场、工厂、矿井等。每种建筑有基础价格和产量，价格随购买数量指数增长（每次购买后价格上涨约15%）。

游戏还包含多种升级道具：点击效率翻倍、特定建筑产量提升、全局生产加成等。这些升级进一步加速了产量增长。

中后期会出现"Golden Cookie"（金色饼干）随机出现在屏幕某个位置，点击后获得临时大量加成（如产量x7持续77秒、瞬间获得大量饼干等）。玩家需要保持关注以不错过这些随机奖励。

## 核心循环

点击/等待产生饼干 → 购买建筑或升级 → 产量增加 → 产生更多饼干

## 核心机制

- **指数级增长**: 建筑数量和升级效果叠加，产量从每秒1个饼干增长到数万亿
- **Golden Cookie随机事件**: 不定期的奖励机制制造了意外惊喜，鼓励玩家持续关注
- **里程碑解锁**: 达到特定饼干数量后解锁新建筑类型和成就
- **声望系统（Prestige）**: 达到一定目标后可以"升天"重置游戏，获得永久产量加成

## 为什么好玩

Cookie Clicker是放置类游戏的开山之作。它捕捉到了人类对数字增长的天然痴迷——看着产量从个位数飙到天文数字，那种"数字在飞涨"的爽感令人上瘾。它既是游戏也是一种"数字玩具"。

## 粘性来源

数值成长的正反馈循环——每买一个新建筑，产量就上一个台阶，立刻能看到效果。Golden Cookie的随机出现让放置不再是"纯挂机"，需要偶尔回来查看。成就系统和里程碑提供了明确的中期目标。

## Meta 系统

成就系统 + 声望系统（Heavenly Chips）。玩家累积足够的饼干后可以"升天"重置，获得Heavenly Chips用于永久加成。这创造了meta层面的循环：玩到一定阶段重置 → 下次更快到达更远阶段。

## 实现难度

低 — 核心只是一个定时器 + 数值累加 + UI更新。最大技术难点在于大数计算（饼干数量可达10^308以上，需要特殊的大数库）和保存/读取机制。Golden Cookie的随机事件逻辑也很简单。
