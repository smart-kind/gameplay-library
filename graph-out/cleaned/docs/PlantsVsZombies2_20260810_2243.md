# PvZ续作，穿越不同时代抵御僵尸（Plants vs Zombies 2）

- **类型**: 塔防
- **平台**: Mobile (iOS+Android)
- **开发商**: PopCap Games / EA
- **首次发布**: 2013
- **一句话描述**: PvZ续作，穿越不同时代抵御僵尸

## 玩法规则

核心机制与一代相同，但加入了新元素：植物能量系统（给植物充能获得临时强化）、不同时代主题（古埃及、海盗港湾、狂野西部、未来世界等）、每时代有独特的场地机制（如海盗时代的船会倾斜、未来时代的激光栅栏等）。

植物有等级系统，升级后能力增强。

## 核心循环

收集阳光 → 种植植物 → 使用植物能量 → 抵御僵尸 → 过关 → 解锁新植物/新时代

## 核心机制

- 植物能量系统：临时强化植物
- 多时代主题：不同场地有不同机制
- 植物升级：提升植物能力
- 新植物类型：每时代引入新植物

## 为什么好玩

一代的升级版，不同时代的主题变化让游戏保持新鲜感。植物能量系统增加了策略深度。

## 粘性来源

时代解锁进度；植物收集；每日挑战。

## Meta 系统

植物解锁+升级系统+时代进度。

## 实现难度

中。塔防核心清晰，但时代机制增加了复杂度。最大技术难点：多场景机制的实现和平衡。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
