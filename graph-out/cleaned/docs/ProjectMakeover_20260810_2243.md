# 三消+时尚改造的休闲游戏（Project Makeover）

- **类型**: 三消/时尚
- **平台**: Mobile (iOS+Android)
- **开发商**: Magic Tavern
- **首次发布**: 2019
- **一句话描述**: 三消+时尚改造的休闲游戏

## 玩法规则

核心三消玩法，通过消除关卡获得资源。用资源给角色做时尚改造（化妆、换装、发型等）和家居装修。每个关卡有剧情推进，玩家帮助角色完成形象转变。

## 核心循环

三消 → 获得资源 → 改造角色/装修 → 推进剧情 → 更多关卡

## 核心机制

- 三消核心
- 时尚改造系统
- 家居装修
- 剧情推进

## 为什么好玩

三消和时尚改造的结合，看着角色从普通变美丽的满足感。

## 粘性来源

剧情驱动；时尚收集；装修进度。

## Meta 系统

时尚解锁+装修进度+剧情。

## 实现难度

低。三消玩法简单。最大技术难点：时尚系统和关卡设计。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
