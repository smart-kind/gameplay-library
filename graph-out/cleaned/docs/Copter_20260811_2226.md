# Copter（Copter / Helicopter Game）

- **类型**: 街机 / 反应类 / 躲避
- **平台**: Web（浏览器）
- **开发商**: 经典浏览器游戏（原始版本可追溯至 2000s 早期）
- **首次发布**: 2000s 早期
- **一句话描述**: 按住鼠标/空格让直升机上升，松开让它下降——在狭窄的洞穴通道中尽可能飞得更远

## 玩法规则

画面是一个横向滚动的洞穴通道，玩家控制一架小直升机（或类似飞行器）在其中飞行。操作极其简单：按住鼠标（或空格键）直升机上升，松开则因重力下降。

洞穴通道的上下边界不断变化——有时很宽，有时非常狭窄。通道中还可能有移动的障碍物（石柱、火焰、炸弹等）。碰到任何边界或障碍物，直升机爆炸，游戏结束。

游戏没有终点——目标是尽可能飞得更远，距离越远分数越高。随着距离增加，通道通常会变得越来越窄，障碍物越来越多，难度持续上升。

## 核心循环

按住上升/松开下降 → 穿过狭窄通道 → 躲避障碍物 → 持续前进直到碰撞

## 核心机制

- **极简操作**：只有一个输入（按住/松开），但精确控制需要大量练习。直升机上升和下降的速度不同（通常上升快、下降慢），增加了控制难度。
- **程序化生成**：洞穴通道是程序化生成的，每次游戏都不一样。通道宽度和障碍物分布随距离增加而变化。
- **难度递增**：游戏没有固定的难度级别，而是通过通道逐渐变窄和障碍物增多来自然增加难度。

## 为什么好玩

Copter 的魅力在于"看似简单，实则极难"——操作只有一个按键，但要精确控制直升机在狭窄通道中飞行需要极高的手眼协调能力。每次打破自己的最高分记录都会带来强烈的成就感。

## 粘性来源

- **高分挑战**：和自己的最高分竞争是最核心的动机——"上次飞了 2000 米，这次一定能更远"
- **极简上手**：任何人都能在一秒内理解规则，但 mastery 需要大量练习
- **节奏感**：掌握上升/下降的节奏后，游戏有一种独特的"流动感"，让人进入心流状态

## Meta 系统

无。纯街机游戏。

## 实现难度

- **学习曲线**：新手可以立即上手，但精通需要数十小时的练习。每次游玩都能发现新的技巧或策略。
- **重玩价值**：高。每局游戏都有不同的体验，无论是随机的地图/敌人，还是玩家的策略选择。
- **社区生态**：作为经典浏览器游戏，它在玩家社区中有良好的口碑。
- **技术亮点**：在浏览器环境中实现流畅的交互体验，充分利用了现代 Web 技术的能力。
低 + 核心是 2D 碰撞检测、通道生成、简单的重力物理。几乎是最简单的游戏类型之一。最大技术难点（如果有）是通道生成的难度曲线设计——要让难度平滑上升而不是突然变得不可能。
