# Racing Fever（赛车狂热）（Racing Fever）

- **类型**: 竞速 / 躲避
- **平台**: Mobile (iOS+Android)
- **开发商**: Gameguru Advertisement FZC
- **首次发布**: 2015
- **一句话描述**: 一款竖版无尽赛车游戏，玩家在车流中穿梭躲避其他车辆，追求更远的行驶距离和更高分数。

## 玩法规则

游戏采用第三人称后方视角或轻度俯视视角，玩家控制的车辆沿着多车道道路向前行驶。道路上有其他车辆包括汽车、卡车、巴士以不同速度在不同车道行驶。

操作包括向左或向右滑动切换车道，向上滑动加速获得短暂的速度爆发，向下滑动减速或刹车。部分版本支持倾斜设备控制方向作为替代操作方式。

玩家需要不断躲避前方慢车和迎面而来的逆向行驶车辆，同时尽可能保持高速行驶以获得更高分数。道路上散布着金币和燃油可以收集，金币用于购买新车，燃油延长游戏时间。

游戏在碰撞到任何车辆或障碍物时立即结束。目标是行驶尽可能远的距离，创造个人最高分。行驶距离越远、速度越快，分数越高。

## 核心循环

在车流中穿梭躲避 → 收集金币和燃油 → 行驶更远获得高分 → 用金币解锁新车 → 挑战更高纪录

## 核心机制

- **机制1**：无尽驾驶机制：道路无限延伸，车辆速度逐渐加快，车流密度不断增加，形成自然的难度递增曲线。玩家唯一的目标就是跑得更远，这种纯粹的目标设定让游戏极具可重复性。
- **机制2**：近距擦边奖励机制：从其他车辆旁极近距离擦过会触发close call效果并获得额外分数加成，鼓励冒险操作而非保守驾驶。这种机制制造了额外的紧张感和刺激感。
- **机制3**：车辆解锁机制：用收集的金币购买新车，不同车辆有不同的操控感、速度和外观属性，提供收集动力和成长感。部分车辆有特殊的加速或操控优势。

## 为什么好玩

高速状态下的紧张感和完美超车瞬间的快感形成了强烈的多巴胺反馈。每次差一点就撞上的心跳加速让人欲罢不能，而突破个人最高分的成就感推动了持续游玩。

## 粘性来源

追求更远距离的自驱目标加上close call的额外刺激加上车辆收集系统提供长期目标，三者结合形成了从短期刺激到长期目标的完整循环。

## Meta 系统

金币系统加车辆购买升级，不同车辆有不同属性如速度、操控稳定性、耐久度。部分版本有每日任务系统和全球排行榜，增加了社交竞争元素。

## 实现难度

中 -- 需要3D场景渲染和碰撞检测，车辆AI和流畅的操控手感是主要技术挑战。最大难点是让不同速度的车辆AI行为看起来自然而不机械。

## 车辆类型说明

- **轿车类**：操控灵活，速度中等，适合新手
- **跑车类**：速度极快但操控难度大，适合追求极限的玩家
- **SUV类**：稳定性好，容错率高，但速度偏慢
- **特殊车辆**：部分版本有摩托车、卡车等特殊类型，各自有独特的手感
