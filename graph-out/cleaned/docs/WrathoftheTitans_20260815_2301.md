# Wrath of the Titans（Wrath of the Titans）

- **类型**: 动作冒险 / 跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: Rovio / Super Action
- **首次发布**: 2012
- **一句话描述**: 基于同名电影的横版动作游戏，砍杀怪物并推进到关卡终点

## 玩法规则

游戏采用横版卷轴视角，玩家控制主角（Perseus）在神话世界中战斗前进。画面左侧角色向右移动，敌人和障碍物从右侧出现。

操作包括：滑动屏幕控制角色移动和闪避、点击攻击按钮进行近战攻击、滑动释放特殊技能或投掷武器。某些版本可能包含划屏攻击——在屏幕上画出特定图案来释放强力攻击。

角色可以装备不同的武器（剑、斧等）和盔甲，影响攻击力和防御力。击败敌人获得金币和经验，用于升级武器或购买道具。

关卡目标：到达终点或击败Boss。失败条件：角色HP归零。

## 核心循环

战斗前进 → 击败敌人获取金币/经验 → 升级装备 → 挑战更强的敌人和Boss

## 核心机制

- **横版战斗**：经典的横版动作玩法，近战攻击配合闪避。简单直接的战斗系统。
- **武器系统**：不同武器有不同的攻击范围和伤害，提供一定的策略选择。
- **技能释放**：通过特定手势释放技能，增加了操作深度和视觉反馈。
- **Boss战**：每个关卡末有大型Boss，需要特定的攻击模式来击败。

## 为什么好玩

作为电影改编游戏，Wrath of the Titans提供了快节奏的横版砍杀体验。神话背景下的怪物设计和Boss战给玩家带来史诗感。简单上手的操作让任何人都能享受战斗的乐趣。

游戏的怪物设计融合了希腊神话元素——美杜莎、牛头人、独眼巨人等经典怪物的出现让玩家在砍杀之余感受到神话世界的氛围。每个怪物都有独特的攻击模式，需要不同的应对策略，避免了单纯的"乱按攻击键"式玩法。

Boss战的设计是游戏的亮点——大型Boss通常有阶段转换、弱点机制和特殊攻击模式，需要玩家观察和学习才能有效应对。这种"学习—适应—击败"的循环是动作游戏最经典的快感来源。

## 粘性来源

装备升级的数值成长是主要驱动力——每次战斗获得的金币和经验让角色逐渐变强。Boss战的挑战性（需要多次尝试找到正确打法）让人反复挑战。电影IP的吸引力也为游戏带来初始关注。

连招系统的掌握也是一个重要的粘性来源——从最初只能按按钮乱打，到后来能流畅地释放连招和特殊技，这种技巧上的进步本身就是奖励。当玩家发现自己能用华丽的连招轻松击败之前需要苦战的敌人时，那种成就感是巨大的。

## Meta 系统

装备升级和角色成长系统——使用战斗中获取的金币购买更好的武器和盔甲，提升战斗力。无在线元素。
