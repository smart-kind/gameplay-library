# The Way Home: Pixel Roguelike

- **类型**: 肉鸽平台跳跃
- **平台**: Mobile (iOS+Android)
- **开发商**: Concode Corp.
- **首次发布**: 2021
- **一句话描述**: 一款像素风格的肉鸽平台跳跃游戏，以程序化地图生成和技能组合为核心特色

## 玩法规则

游戏主界面以像素风格的随机生成地图，角色在平台间跳跃为核心视觉元素，整体布局简洁直观。屏幕上方/中央区域展示角色当前位置、地图视野和可用技能列表，玩家一眼即可了解当前的核心状态。屏幕下方或侧边排列移动/跳跃按钮和技能快捷键，这些是玩家可以交互的按钮或操作区域。

玩家通过点击或滑动控制角色移动、跳跃和使用技能进行核心操作。具体而言，玩家通过虚拟按键或滑动手势控制角色在平台间移动。角色可以左右移动、跳跃、使用技能攻击敌人或与环境互动。每个平台层都有独特的地形特征、敌人分布和可收集物品。击败敌人或打开宝箱可以获得新技能或强化现有技能。技能释放有冷却时间，需要合理使用。每次操作后，系统会即时给出跳跃动画、技能释放特效和收集物品提示，确保玩家对操作结果有清晰的感知。

游戏的核心目标是探索尽可能多的层数，找到回家的路。为了达成这一目标，玩家需要控制角色在平台上移动和跳跃，使用技能消灭敌人，收集新技能并组合使用，逐层向下探索。当到达终点或完成特定层数的探索时，玩家进入下一阶段或解锁新内容。反之，如果角色坠入深渊或生命值归零，则需要重新开始或调整策略。

随着游戏进程的推进，每层地图由算法实时生成，敌人类型和技能掉落也随机变化。玩家需要逐步掌握平台跳跃技巧、技能组合搭配和地图探索策略，才能在更高难度下持续进步。游戏的深度在于程序化地图的新鲜感和技能组合的策略深度让每次游玩都不同。15种以上技能可以自由组合，不同技能之间产生协同效果。即使同一职业也能玩出完全不同的风格，探索未知地图的紧张感和找到强力技能组合的惊喜感交替出现，这让简单的操作框架下蕴含着丰富的策略空间。

游戏中的技能分为攻击型（直接伤害）、辅助型（移动增强、护盾）和环境型（改变地形、触发机关），三类技能的组合创造了丰富的玩法可能性。

## 核心循环

探索地图获取技能 → 组合技能击败敌人 → 进入下一层获取更强技能

## 核心机制

- **程序化地图生成**: 每次进入新层时，地图由算法实时生成，确保每次游玩的路线、敌人和宝藏位置都不同。生成算法保证地图始终可通关，同时提供足够的变化和挑战
- **技能组合系统**: 15种以上技能可以自由组合，包括攻击、防御、移动辅助和环境交互等类型。不同技能之间产生协同效果——例如火焰技能配合燃油技能形成大面积持续燃烧，构建独特的战斗风格
- **多人协作模式**: 支持组队进入地牢，玩家之间可以共享技能效果和战利品。协作模式下难度提升但奖励更丰厚，队友之间的技能互补是通关的关键

## 为什么好玩

每次地图都是全新的，配合多技能组合系统，即使同一职业也能玩出完全不同的风格。探索未知地图的紧张感和找到强力技能组合的惊喜感交替出现，平台跳跃的精准操作也带来操作层面的成就感。

"这个技能组合太巧妙了"的智力满足感和"我能跳到那里"的操作成就感形成双重正反馈。

## 粘性来源

程序化地图的新鲜感和技能组合的策略深度。"这次我能走多远"的好奇心和找到完美技能组合的成就感交替驱动。多人模式增加了社交粘性，和朋友一起探索的乐趣远超单人游玩。

技能图鉴的收集进度条也是一种持续的驱动力——"就差3个技能就能集齐了"。

## Meta 系统

技能图鉴与角色解锁：收集所有技能并解锁新角色，每个角色有独特起始技能。对核心玩法的影响是提供不同的技能构建起点，增加探索动机。收集图鉴本身也是一个长期目标。

某些隐藏技能需要特定条件才能触发（如"在不受伤的情况下通关第三层"），鼓励玩家尝试不同的挑战方式。

## 实现难度

高。程序化地图生成、技能组合系统和多人协作需要复杂的技术实现。最大技术难点：程序化地图的可玩性保证——确保生成的地图始终有趣且可通关，同时维持性能稳定。
