# City of Wonder

- **类型**: 城市建设 / 社交游戏
- **平台**: Mobile (iOS)
- **开发商**: PocketGamer Review
- **首次发布**: 2011
- **一句话描述**: 从Facebook移植到iOS的社交城市建设游戏，受文明系列启发

## 玩法规则

City of Wonder 是一款从Facebook移植到iOS的社交城市建设游戏。玩家的目标是将一个小小的村落发展成一个繁荣的文明，通过社交元素和城市建设玩法的结合来实现。

一系列任务逐步引导你了解游戏的各种元素，其中最主要的是建设。可以建造的不同建筑自然服务于不同的目的：可用的建筑类型由你的等级和新技术研究的程度决定。住宅增加人口，文化建筑增加幸福度，市场、牧场和采石场产生收入。

一旦你熟悉了城市建设的要点，你就需要与其他文明联系。朋友或友好的陌生人可以成为盟友，然后用来扩建城市或建造奇迹。你也可以探索随机城市并进行攻击、贸易或文化交流。

### 核心循环
建造建筑 → 完成任务获得经验 → 升级解锁新建筑 → 研究新技术 → 与其他文明互动 → 扩大城市

### 核心机制
- **建筑系统**：住宅增加人口，文化建筑增加幸福度，市场和农场产生收入
- **等级系统**：通过完成任务获得经验值来升级，解锁更多建筑选项
- **研究系统**：研究新思想和技术来解锁更高级的建筑
- **时间等待**：生产时间越短的商品收益越少且会过期
- **社交互动**：盟友可以帮助扩建城市或建造奇迹
- **文明探索**：探索随机城市并进行攻击、贸易或文化交流

### 为什么好玩
任务引导系统让玩家逐步了解游戏的各种元素，从建造不同类型的建筑到与其他文明互动。军事、贸易和文化三种力量的平衡策略有一定深度。

### 粘性来源
社交互动是核心粘性——盟友的互助、探索其他文明、攻击和贸易都依赖于社交网络。城市规模的不断扩大也提供了成就感。但社交功能过于简陋，限制了长期粘性。

### Meta 系统
等级和研究系统是核心Meta。通过经验值升级解锁新建筑，通过研究解锁新技术。军事、贸易、文化三种力量的发展影响与其他文明的互动效果。

### 实现难度
中。城市建设逻辑和数值平衡是核心挑战。社交系统的实现需要后端服务器支持。最大的技术难点在于数值系统的设计——确保游戏进程既不太快也不太慢。
