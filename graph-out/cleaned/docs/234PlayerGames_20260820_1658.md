# 2 3 4 Player Games

- **类型**: 多人派对游戏合集（本地同屏对战）
- **平台**: Mobile (iOS+Android)
- **开发商**: Penji Games B.V.
- **首次发布**: 2017
- **一句话描述**: 一款支持2-4人本地同屏对战的迷你游戏合集，所有操作均为单点触控，适合聚会多人游玩。

## 玩法规则

游戏主界面展示一个包含40款迷你游戏的列表。所有游戏的核心设计原则是"一根手指就能玩"——玩家只需点击屏幕即可参与，不需要复杂的虚拟摇杆或手势。

多人模式下，2-4名玩家共享同一台设备的屏幕，每位玩家占据屏幕的一个区域，各自使用屏幕上的按钮进行操控。游戏采用轮流制或同时进行制，具体取决于迷你游戏类型。

每款迷你游戏有独立的规则，例如：Snake Arena中玩家控制蛇吃星星并避免撞到边界或对手；其他游戏可能包含弹跳球、反应速度测试、记忆匹配等玩法。游戏通常以回合积分制进行，率先达到目标分数或存活到最后的玩家获胜。

## 核心循环

选择迷你游戏 → 多人同屏对战 → 积累积分 → 挑战下一款游戏

## 核心机制

- **同屏共享机制**：2-4名玩家共用一台设备的屏幕，通过划分屏幕区域和各自的触控按钮实现多人互动，这是线下社交场景的天然催化剂。
- **单指极简操作**：所有40款游戏都只需要点击操作，确保任何人（包括儿童和老人）都能立即上手，消除了学习成本。
- **多样化迷你游戏轮换**：40款不同的迷你游戏确保不会单调，每次可以选择不同的游戏进行对战。

## 为什么好玩

面对面同屏竞技带来的社交乐趣远超在线对战——看到朋友在身边惊呼、大笑或懊恼的体验是无法替代的。极简操作确保了任何人都能参与，不会因为"不会玩"被排除在外。

## 粘性来源

社交竞争是核心粘性——朋友间"再来一局"的冲动非常强烈。40款不同游戏提供丰富的选择，每次对战可以选择不同游戏组合，保持新鲜感。4人锦标赛模式（4 Player Cup）增加了额外的竞争层次。

## Meta 系统

包含4人锦标赛模式（4 Player Cup），通过连续多轮游戏决出最终赢家，为多场对战提供结构化的竞赛框架。无角色成长或数值系统。

## 实现难度

低。每款迷你游戏逻辑简单，核心挑战在于屏幕区域的合理划分、多玩家触控输入的准确区分、以及游戏间切换的流畅度。40款游戏的开发工作量分散，每款只需2-3天即可完成原型。
