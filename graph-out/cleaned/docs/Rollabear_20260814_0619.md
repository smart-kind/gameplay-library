# Rollabear

- **类型**: 街机 / 滚球
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款控制小熊在倾斜平台上滚动的街机游戏，玩家需要通过控制平台倾斜方向引导小熊收集星星并避开陷阱

## 玩法规则

游戏呈现一个倾斜的3D平台，平台上有一只可滚动的球形小熊。平台可以朝不同方向倾斜，小熊受重力影响随之滚动。

玩家通过滑动屏幕或倾斜设备（重力感应）来改变平台倾斜方向。小熊会因重力向倾斜方向滚动，速度随倾斜角度增加。

平台上散布着星星和宝石，收集可获得分数和评价。同时存在陷阱区域：尖刺、深坑、移动障碍等，小熊碰到即损失生命值。

目标是在限定时间内收集所有星星并到达出口。部分关卡有时间奖励——越快完成获得越高评价。平台可能包含活动部件（旋转板、弹射器、传送带），改变小熊的滚动路径。

游戏设有计时挑战模式，在原有关卡基础上增加严格的时间限制。完成计时挑战可获得金色星星评价。

## 核心循环

倾斜平台引导小熊滚动 → 收集星星避开陷阱 → 到达出口过关

## 核心机制

- **重力控制**：通过倾斜平台控制滚动方向，物理驱动的移动方式
- **限时挑战**：倒计时增加紧迫感，鼓励快速通关
- **活动机关**：旋转板、弹射器等动态元素增加关卡变化

- **计时挑战**：严格时间限制下的更高难度版本

## 为什么好玩

物理驱动的滚动手感有趣且变化多端，每次滚动路线不可完全预测。收集所有星星的完美通关目标驱动反复尝试。

## 粘性来源

物理随机性+收集目标的组合。每次'差一点就全收集'的遗憾感驱动重玩。

## Meta 系统

无。纯关卡挑战。

## 实现难度

低 — 倾斜控制直观。最大技术难点是稳定的物理引擎和重力模拟。
