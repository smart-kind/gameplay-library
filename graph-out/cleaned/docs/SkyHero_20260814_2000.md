# Sky Hero

- **类型**: 飞行射击 / 街机
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2013
- **一句话描述**: 竖版卷轴飞行射击游戏，操控战机躲避弹幕并消灭敌人

## 玩法规则

玩家操控一架战斗机在竖版卷轴的天空中飞行，躲避敌方弹幕并消灭出现的敌人。

游戏界面以竖屏呈现，战机位于屏幕下半部分。玩家通过拖拽屏幕来控制战机的移动方向。战机自动向前飞行，背景持续向下滚动。

屏幕上会出现各种敌人——小型战斗机、大型轰炸机、地面防空炮等。每种敌人有不同的攻击模式和血量。玩家需要躲避敌方子弹，同时用战机的武器进行反击。

游戏包含道具系统——击落特定敌人会掉落增强道具，如武器升级、护盾、炸弹等。合理使用道具可以大幅提高生存能力。

## 核心循环

移动躲避 → 射击敌人 → 收集道具 → 消灭Boss → 进入下一关

## 核心机制

- **弹幕躲避**：敌方子弹以各种图案发射，需要精准的走位和时机把握
- **武器升级**：通过收集道具升级武器，从单发到多发，从普通到激光
- **Boss战**：每关末尾有Boss战，Boss有多阶段攻击模式
- **自动射击**：战机持续自动射击，玩家专注于移动和道具收集

## 为什么好玩

弹幕射击的紧张刺激感和武器升级的成长感形成良好循环。看着自己的战机从弱小到强大的过程很有成就感。

## 粘性来源

弹幕躲避的高技巧上限 + 武器升级的即时反馈 + Boss战的挑战欲 + 高分排行榜竞争

## Meta 系统

战机解锁系统 — 通过关卡进度或成就解锁不同外观和属性的战机

## 实现难度

低 — 竖版射击是成熟玩法，最大技术难点在于弹幕模式的多样性和难度曲线的平衡
