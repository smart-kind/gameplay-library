# 奥伯拉丁的回归（Return of the Obra Dinn）

- **类型**: 解谜 / 推理 / 第一人称
- **平台**: Steam / Nintendo Switch / Xbox / PlayStation / itch.io
- **开发商**: Lucas Pope
- **首次发布**: 2018
- **一句话描述**: 在一艘神秘的幽灵船上，通过怀表回溯死亡瞬间来推理 60 名船员命运的侦探解谜游戏。

## 玩法规则

游戏以独特的 1-bit 单色像素风格呈现。玩家扮演一名保险调查员，登上了一艘失踪多年的商船——奥伯拉丁号。船上空无一人，但通过一块神秘的怀表，你可以回到每个人死亡的那一刻。

游戏的核心机制是"回溯"：当你接近一具尸体时，使用怀表可以回到该人死亡前的一瞬间。你会看到一个静止的 3D 场景，展示死亡的瞬间。在这个场景中，你可以：
- 环顾四周，观察死亡发生时的环境
- 查看周围的人、物品和动作
- 注意关键细节：谁在做什么、谁拿着什么武器、谁是凶手

每次回溯后，你需要在一本日志中填写该船员的信息：
- 姓名（从 60 个船员名单中选择）
- 命运（从选项中选择：被杀、自杀、意外、失踪等）

游戏会立即告诉你答案是否正确——如果三个连续的答案都正确，系统会给出确认。如果全部错误，系统也会告知。

玩家需要在船上自由探索，找到每一具尸体，回溯每一个死亡场景，最终拼凑出整艘船上发生的故事。

## 核心循环

在船上探索 → 找到尸体 → 使用怀表回溯死亡瞬间 → 观察细节 → 在日志中填写推理结果 → 继续探索

## 核心机制

- **死亡回溯**：核心机制是观察静止的死亡场景，从中推理出发生了什么
- **逻辑推理**：通过已知的信息推断未知的信息。比如知道了 A 是被 B 杀死的，而 B 后来也被杀了，那么可以推断 B 的命运
- **关联推理**：船员之间有各种关系（同事、上下级、亲属），利用这些关系来缩小推理范围
- **渐进解锁**：每确认三个答案，系统会给出反馈，帮助玩家调整推理方向
- **环境叙事**：船上每个角落都有故事线索——信件、物品、血迹等

## 为什么好玩

Return of the Obra Dinn 把推理变成了真正的游戏。你不是在读一本推理小说，而是在主动地观察、思考和验证。每次你通过逻辑推理正确判断一个船员的命运时，那种"福尔摩斯时刻"的满足感是巨大的。而且整个故事随着你的推理逐渐展开，从散落的碎片到完整的全景，这种认知上的成就感是独一无二的。

## 粘性来源

1. **推理快感**——每次正确推理都带来强烈的智力满足
2. **叙事悬念**——"这艘船上到底发生了什么？"的好奇心推动玩家不断探索
3. **渐进反馈**——三个连续正确的确认机制给了明确的进展信号
4. **多线叙事**——60 个人的命运相互交织，解开一条线会为其他线提供线索

## Meta 系统

无。游戏没有升级或成长系统。所有"成长"都是玩家推理能力的提升和故事理解的加深。

## 实现难度

中。核心技术是 1-bit 渲染风格（单色像素）和静态 3D 场景的交互。回溯场景是预渲染的，不需要实时物理。最大技术难点是场景设计——每个死亡场景都需要精确的 3D 布局和细节安排，以确保玩家能够从中推理出足够的信息，但又不会太明显。
