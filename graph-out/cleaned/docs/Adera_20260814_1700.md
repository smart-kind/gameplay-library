# 阿德拉（Adera）

- **类型**: 解谜冒险
- **平台**: Xbox One / Mobile (iOS+Android)
- **开发商**: Exient Entertainment / Microsoft Studios
- **首次发布**: 2015
- **一句话描述**: 在古埃及遗迹中寻找失踪的考古学家父亲，通过解决环境谜题和机关挑战深入探索神秘洞穴

## 玩法规则

游戏采用等距视角（isometric view），玩家控制一名女性考古学家在古埃及风格的洞穴和遗迹中探索。通过触屏点击或虚拟摇杆控制角色移动，与环境中的各种机关和物体互动。

核心操作是环境解谜：玩家需要观察场景中的线索——壁画符号、石碑文字、机关位置等，然后找到正确的操作顺序来开启通路。谜题类型包括：旋转石柱对齐符号、推动石块激活压力板、按特定顺序触碰图腾柱、利用光线反射照亮隐藏通道等。

游戏场景分为多个章节，每个章节设定在一个独特的洞穴或遗迹中。玩家需要在场景中收集关键物品（如符文石、钥匙碎片），解开守护通道的谜题，逐步深入遗迹核心。场景中散布着可收集的古埃及文物，为游戏增加探索动力。

## 核心循环

探索遗迹环境 → 发现并解决谜题 → 解锁新区域 → 收集文物 → 逐步接近失踪父亲的下落

## 核心机制

- **环境线索解谜**：谜题的答案通常隐藏在场景的壁画、符号和建筑细节中。玩家需要观察和思考，而不是随机尝试。这种设计鼓励真正的解谜而非暴力穷举。
- **机关连锁系统**：一个谜题的解决往往会触发一系列连锁反应——开启新的通路、激活新的机关或揭示隐藏的线索。解谜的成就感不仅来自解决单个谜题，还来自看到整个环境因你的操作而"活起来"。
- **文物收集**：场景中隐藏的可收集文物为探索提供了额外动力，部分文物还包含古埃及历史背景的补充信息。
- **多区域探索**：游戏场景由多个相互连接的洞穴和房间组成，解锁新区域后玩家可以回溯已探索区域，利用新获得的信息解决之前无法通过的谜题。

## 为什么好玩

等距视角的古埃及美术风格独特而迷人，壁画和建筑的细节丰富。谜题设计偏向"观察-思考-解决"的经典冒险解谜路线，不依赖快速反应或精确操作，适合喜欢沉浸式解谜体验的玩家。故事线索（寻找失踪父亲）为解谜提供了情感驱动力。

## 粘性来源

环境解谜的"顿悟时刻"——当你终于看懂壁画上的线索、找到正确的机关操作顺序时，成就感极强。章节式的叙事结构让每个新章节都像是进入了一个全新的谜题世界。文物收集为完成度提供目标。

## Meta 系统

文物收集图鉴：记录已发现的所有古埃及文物及其背景信息。章节解锁系统随剧情推进开放新区域。对核心玩法无直接影响。

## 实现难度

中。核心需要等距视角的场景渲染、交互判定系统和谜题逻辑管理。最大技术难点在于设计既有趣又合理的谜题——谜题需要足够挑战但不能让人卡关沮丧，线索需要隐蔽但不能不公平。这需要大量迭代测试。
