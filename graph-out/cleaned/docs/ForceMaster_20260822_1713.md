# Force Master

- **类型**: 动作解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2020
- **一句话描述**: 利用场景中的物体作为武器，用环境力量消灭敌人

## 玩法规则

游戏核心玩法是"操控环境力"。

玩家可以抓取场景中的任意物体，然后将它们投掷向敌人或用来改变地形布局。

每个关卡都有若干敌人需要消灭，玩家需要观察场景中可用的物体，思考最优的投掷策略。

操作方式非常简单：触摸屏幕上的物体进行抓取，拖拽到目标位置或目标敌人身上释放。

不同物体有不同效果：炸药桶会造成范围爆炸伤害，箱子可以用来砸扁敌人，平台可以被抽走让敌人掉落深渊。

游戏强调"用敌人打敌人"的策略，比如把一个敌人抓起砸向另一个敌人，同时消灭两个目标。

每个关卡有星级评分系统，根据消灭敌人的方式、使用的步数、是否达成额外挑战条件来计算分数。

游戏采用渐进式难度设计，从简单的单敌人单物体关卡开始，逐步引入多个敌人、障碍物、定时炸弹、移动平台等复杂元素。

## 核心循环

观察场景 → 抓取物体 → 投掷消灭敌人 → 获得评分 → 解锁新关卡

## 核心机制

- **物理投掷**：利用游戏内置的物理引擎，物体被投掷后有真实的运动轨迹和碰撞效果
- **环境武器化**：场景中的每个物体都可以被利用，鼓励玩家创造性地思考解决方案
- **连锁反应**：一个投掷可以触发连锁效果（如炸药爆炸引发更多物体运动），产生"一箭多雕"的爽快感

## 为什么好玩

物理引擎带来的不确定性和创造性解法让每局都有新鲜感。

玩家可以用多种方式解决同一个关卡，找到自己满意的方案时会有强烈的成就感。

"用敌人打敌人"的设定增添了幽默感和策略深度。

## 粘性来源

主要来自物理交互带来的实验欲望和关卡设计的"差一点"感。

玩家会不断尝试不同的投掷角度和物体组合来追求更高评分，爆炸和碰撞的视觉反馈也提供了很强的即时满足感。

## Meta 系统

无。游戏采用Voodoo典型的极简风格，专注于核心玩法循环，没有复杂的外围成长系统。
