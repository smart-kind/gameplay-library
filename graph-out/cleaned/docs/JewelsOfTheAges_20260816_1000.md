# Jewels of the Ages

- **类型**: 三消 / 解谜
- **平台**: Mobile (iOS)
- **开发商**: PocketGamer Review
- **首次发布**: 2011
- **一句话描述**: 包含两个主题三消游戏的合集——奥林匹斯宝石和古埃及法老宝石

## 玩法规则

Jewels of the Ages 包含两个独立的三消游戏——《奥林匹斯宝石》和《古埃及法老宝石》。两个游戏提供了相似的核心体验，但设定不同。

在《奥林匹斯》中，玩家骑着飞马在天空中翱翔，通过三消宝石来消灭野兽和解决谜题。而《古埃及法老宝石》则将场景搬到了埃及。

匹配三消的动作与预期完全一致。玩家需要在网格上将特定类型的物品排列成行，并不断将这些特定物品以三行或三列的方式消除。宝石爆炸的方式令人满意，游戏中有大量combo和连锁动作。游戏侧重于随机选择的匹配和爆炸，而非长期的精心策略。

### 核心循环
匹配三个宝石 → 触发消除爆炸 → 获得积分和推进关卡 → 继续匹配

### 核心机制
- **经典三消**：在网格上排列相同物品形成三行或三列来消除
- **连锁反应**：一次消除可以触发连锁消除，产生combo
- **随机匹配优先**：游戏侧重于随机选择的匹配和爆炸，而非长期策略规划
- **双主题游戏**：奥林匹斯和古埃及两个不同主题的独立游戏
- **升级系统**：通过消除获得经验值来升级

### 为什么好玩
宝石消除的视觉效果令人满意，丰富的combo和连锁动作让游戏感觉比实际更有活力。随机匹配的哲学运作良好，让游戏感觉更加动作导向。操控响应灵敏。

### 粘性来源
消除带来的爽快感是核心粘性来源——宝石爆炸的视觉反馈和连锁反应让人想要继续匹配。升级系统提供了短期目标。但重复性高的玩法和无聊的剧情故事削弱了长期粘性。

### Meta 系统
升级系统。通过消除获得经验值来升级，解锁新的关卡或内容。但这主要是为了掩盖游戏重复性而设计的外围系统，对核心玩法影响有限。

### 实现难度
低。三消游戏有成熟的算法和实现方案。最大的挑战在于关卡设计和难度曲线的平衡。
