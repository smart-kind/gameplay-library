# Idle Planet Miner

- **类型**: 放置经营 / 太空采矿
- **平台**: Mobile (iOS)
- **开发商**: Tech Tree Games LLC
- **首次发布**: 2019
- **一句话描述**: Idle Planet Miner是一款太空主题的放置采矿游戏。玩家经营自己的太空矿业公司，从小行星采矿开始，逐步建立跨星系的矿业帝国。

## 玩法规则

游戏以太空为背景，屏幕显示玩家的矿业飞船和各个采矿星球。底部有资源数量、升级按钮和功能选项。玩家可以通过点击小行星手动采矿获得稀有矿石，也可以升级采矿星球获得被动收入。矿石可以熔炼或制作成更有价值的物品。金币用于雇佣经理自动化采矿流程。市场系统让玩家根据星系的供需关系调整销售策略，最大化利润。星球改造可以提高采矿星球的产出效率。

## 核心循环

点击采矿/升级星球 -> 获得矿石和金币 -> 熔炼/制作高价值物品 -> 根据市场调整销售 -> 雇佣经理自动化 -> 重复

## 核心机制

- 手动加自动采矿：点击小行星手动获取，升级星球获得被动收入
- 熔炼和制作：将矿石加工为更有价值的物品
- 市场系统：根据星系供需调整销售策略
- 星球改造：提高采矿星球的产出效率
- 多人锦标赛：每周实时竞赛

## 为什么好玩

太空采矿主题独特且有吸引力。从手动点击到完全自动化的成长过程满足了从小作坊到大企业的经营梦想。市场系统增加了策略维度，不只是简单的点击升级。

## 粘性来源

离线收益让每天回归有收获；多人锦标赛提供竞争目标；星球改造和制作系统增加策略深度

## Meta 系统

有市场系统（供需关系调整）、星球改造系统、经理雇佣（自动化）、多人锦标赛（每周竞赛）、任务系统。

## 实现难度

中。核心难点在于放置经营玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
