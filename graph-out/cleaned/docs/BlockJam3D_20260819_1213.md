# Block Jam - 3D Block Puzzle（方块堵塞3D）

- **类型**: 三消 / 物理消除 / 益智
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2023
- **一句话描述**: 在3D立体方块堆中点击匹配三个相同颜色的方块消除它们，清空整个结构即可过关。

## 玩法规则

游戏场景是一个由彩色方块堆叠而成的3D结构（类似俄罗斯方块的立体版本）。每个方块显示一个颜色，方块之间以不同的高度层叠在一起，形成错落有致的立体造型。

玩家的操作是**点击三个相同颜色的方块**来消除它们。但有一个关键限制：**只有"可触及"的方块才能被选中**——即没有被其他方块覆盖在上面的方块。如果某个方块被其他方块压在下面，玩家需要先消除上方的方块才能接触到它。

消除方块时，方块会碎裂消失（带粒子效果），上方的方块可能会掉落或倾斜，改变结构的形态。某些关卡中，消除特定方块会触发连锁反应（如消除支撑方块后上方的方块整体掉落）。

每个关卡有步数限制（通常40-60步），需要在步数耗尽前消除所有方块。部分关卡有计时模式，要求在限定时间内完成。

## 核心循环

观察3D方块结构 → 选择三个同色且可触及的方块 → 消除 → 结构变化/方块掉落 → 新的方块变为可触及 → 继续消除直到清空

## 核心机制

- **3D空间遮挡**：方块的层叠关系决定了可消除顺序，玩家需要在"当前能消除的同色方块"和"为后续创造更好条件"之间做决策。
- **结构崩塌**：消除底层支撑方块后，上方结构可能整体掉落，一次性暴露大量新方块，这是通关的关键时刻。
- **颜色分布策略**：同色方块通常分布在不同层级，玩家需要判断消除顺序——先消除哪一层更有利于后续操作。
- **步数压力**：有限步数要求高效消除，随机选择会浪费步数导致失败。

## 为什么好玩

Block Jam 的核心乐趣在于"解开一个立体结"的满足感。当3D结构因为你的消除而层层崩塌，大量方块同时暴露出来时，那种"解开了"的爽快感非常强。同时，3D层叠带来的"遮挡-解锁"机制比传统平面三消多了空间维度的策略——你不仅要考虑颜色匹配，还要考虑"先拆哪一层"。

## 粘性来源

- **崩塌快感**：结构崩塌时大量方块同时消除的视觉冲击力极强。
- **空间解谜**：3D层叠带来的"拆楼"体验是平面消除游戏无法提供的。
- **步数挑战**：差几步就清空时的不甘心驱动重试。
- **关卡多样性**：不同3D造型（塔形、球形、不规则形）带来不同的消除体验。

## Meta 系统

- **关卡解锁**：线性推进。
- **皮肤系统**：解锁不同的方块纹理和消除特效。
- **每日挑战**：特殊关卡和限时任务。

## 实现难度

中。核心是3D方块的层叠关系计算和物理掉落模拟。最大技术难点是准确判断方块的"可触及"状态（需要实时计算遮挡关系）和结构崩塌时的物理模拟（方块掉落、碰撞、堆叠的真实感）。
