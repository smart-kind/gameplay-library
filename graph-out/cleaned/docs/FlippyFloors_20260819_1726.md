# Flippy Floors

- **类型**: Puzzle
- **平台**: Mobile (iOS+Android)
- **开发商**: Stanislas Mettra
- **首次发布**: 2018
- **一句话描述**: Perspective-shifting puzzle game where player manipulates the environment's rotation to guide a ball to the exit.

## 玩法规则

玩家在Mobile (iOS+Android)上体验Puzzle类型的核心玩法。游戏画面以Puzzle的典型视觉呈现方式为基础，主操作区域占据屏幕中央，关键信息（分数、时间、道具栏）分布在屏幕顶部或两侧，功能按钮（设置、暂停、商店）通常位于屏幕角落。

游戏的核心操作方式为触屏交互——根据具体玩法，玩家需要进行点击选择、拖拽移动、滑动方向或长按蓄力等动作。每次操作都会立即产生视觉动画和音效反馈，让玩家明确感知操作结果。例如点击选中目标后会有高亮或弹跳效果，拖拽物品时会有跟随动画。

游戏目标因模式而异：在限时模式中玩家需要在倒计时结束前完成指定任务；在闯关模式中玩家需要逐步解决越来越复杂的关卡挑战；在无尽模式中玩家追求尽可能高的分数。游戏结束的条件包括：时间耗尽、生命值归零、或无法继续推进。过关后解锁新关卡并获得奖励。

Puzzle游戏的核心设计哲学是"低门槛、高深度"——初学者可以在10秒内学会基本操作，但精通需要理解更深层的策略和时机把握。游戏通过渐进式难度曲线保持挑战性，早期关卡引导玩家理解规则，后期关卡考验熟练度和反应能力。

## 核心循环

执行操作（点击/拖拽/滑动/选择） → 获得即时反馈（分数/动画/通关） → 解锁新关卡/获得奖励/继续挑战

## 核心机制

- **触屏交互机制**: 利用移动设备的触控特性，将传统按键操作转化为直觉化的触屏手势（滑动、点击、长按），降低学习成本的同时增加操作精度要求
- **即时反馈循环**: 每个操作都配有视觉特效和音效反馈（弹跳、闪光、得分数字飘出），形成"操作-反馈-满足感"的正向循环
- **渐进难度系统**: 关卡按难度梯度设计，每个新关卡引入一个额外的变量（更多障碍、更少时间、新敌人类型），让玩家持续处于"学习-掌握-挑战新事物"的状态

## 为什么好玩

Puzzle的乐趣在于"简单但上瘾"的设计——规则一目了然，但要做到完美需要大量练习。每次"差一点就过"的瞬间都让人忍不住再来一局。短时游戏节奏（通常一局1-5分钟）让玩家可以随时随地玩上一把，没有沉重的时间投入压力。

## 粘性来源

最强的粘性来自"就差一点点"心理——当玩家以微弱差距失败时，大脑会产生强烈的"再来一次我就能过"的冲动。配合自动保存的进度系统、成就解锁机制和可选的排行榜竞争，玩家可以持续找到新的追求目标。每日签到和限时活动也增加了回访动力。

## Meta 系统

包含外围成长系统——通过游戏获得的金币或积分可以解锁新的游戏模式、角色外观或特殊道具。这些元素不影响核心玩法的公平性，但提供了额外的收集欲望和个性化空间。部分游戏包含赛季通行证或限时挑战活动。

## 实现难度

中 + 核心交互逻辑需要精细的触控事件处理和物理碰撞检测 + 最大的技术难点在于不同设备和屏幕分辨率下的操作手感一致性，以及关卡设计的平衡性调优
