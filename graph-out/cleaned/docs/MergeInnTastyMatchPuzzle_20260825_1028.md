# Merge Inn - Tasty Match Puzzle

- **类型**: 合成解谜 / 模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: Original Games Pte. Ltd
- **首次发布**: 2021-10-04
- **一句话描述**: 合成食物完成顾客订单，逐步将破旧餐厅升级为梦幻咖啡厅

## 玩法规则

Merge Inn 以合成食物为核心玩法。玩家有一个合成棋盘，上面有各种食材和食物。通过拖拽相同的食物进行合并，生成更高级的食物品种。同时有顾客订单系统——顾客会点特定的食物，玩家需要合成出对应的食物来完成订单。

界面分为几个区域：上方是顾客订单区（显示需要的食物和奖励），中间是合成棋盘，下方是已解锁的食材列表。每次移动都会向目标靠近，不存在"卡关"的情况——这与传统消除游戏的"步数限制"设计不同。

随着进度推进，餐厅从破旧的旧餐馆逐步升级为精致的梦幻咖啡厅。解锁新食材（卷饼、糖果、烘焙食品、各国料理等），装饰餐厅的不同区域（厨房、用餐区、户外露台等）。

## 核心循环

查看订单 → 合成食物 → 完成订单获得奖励 → 升级餐厅 → 解锁新食材和区域

## 核心机制

- **无步数限制的合成**：与传统match-3不同，Merge Inn 的每一步都是正向推进，没有"步数用完失败"的挫败感。这种设计让游戏始终保持轻松愉快的氛围。
- **订单驱动合成**：顾客订单告诉玩家"现在需要做什么"，避免了合成棋盘上"不知道该合什么"的迷茫。订单的多样性（不同食物、不同数量）让合成策略有变化。
- **全球料理收集**：从简单的卷饼到各国特色料理，食物合成链条丰富多样，满足了收集和发现的心理需求。

## 为什么好玩

Merge Inn 的"每次移动都有进展"的设计消除了挫败感，让游戏体验始终保持正面。从破旧餐馆到梦幻咖啡厅的视觉变化提供了强烈的成就感。食物合成的过程本身也很治愈——看着简单的食材一步步变成精致料理。

## 粘性来源

具体到机制层面：餐厅升级的视觉反馈（从破旧到华丽的渐变）是最强驱动；新食材的解锁满足收集欲；订单完成时的即时奖励（金币、钻石、装饰）形成正向循环。"差一点就升级"的设计让玩家想再来几个订单。

## Meta 系统

餐厅升级和装饰系统是核心外围系统。合成获得资源用于解锁和装饰餐厅区域（厨房升级、用餐区扩建、户外区域解锁等）。这些系统不改变核心合成规则，但提供了明确的长期目标和视觉奖励。

## 实现难度

中 — 合成逻辑和订单系统的实现相对直接。最大的技术难点是大量食材和装饰品的数据管理，以及合成链条的平衡设计（确保每种食材的合成路径既有挑战又不过于困难）。
