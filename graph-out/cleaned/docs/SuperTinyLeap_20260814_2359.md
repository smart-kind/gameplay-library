# Super Tiny Leap

- **类型**: 平台跳跃/休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款极简风格的平台跳跃小游戏

## 玩法规则

玩家控制一个小角色在平台之间跳跃。点击屏幕让角色跳跃，长按跳得更高。角色自动向一个方向移动，遇到墙壁会反弹。

关卡由不同形状和位置的平台组成，某些平台会移动或消失。目标是到达关卡终点（通常是一面旗帜或门）。某些关卡有收集品（星星或金币）。

画面采用极简风格，色彩鲜艳。界面非常干净，主要是平台、角色和背景。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

通过关卡收集星星 → 解锁新世界 → 面对更复杂的平台布局

## 核心机制

- 单键操作：只需点击/长按即可完成所有操作，极简设计
- 动态平台：部分平台会移动、旋转或消失，增加挑战
- 收集品系统：每关隐藏星星，增加重玩价值

## 为什么好玩

极简但不简单的关卡设计，每次跳跃都需要精确判断。

## 粘性来源

全收集挑战和时间挑战的重复游玩驱动力。

## Meta 系统

无

## 实现难度

低 — 核心玩法简洁，最大的技术难点是关卡设计和跳跃手感调优。
