# Bullet Rush!

- **类型**: 休闲射击
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2020
- **一句话描述**: 快节奏俯视射击，角色自动开火，玩家专注走位消灭来袭敌人

## 玩法规则

游戏采用竖屏操作。角色会自动向前移动，玩家通过左右滑动控制角色在跑道上的横向位置。角色会自动向最近的敌人开火。

跑道两侧和前方会不断出现敌人，需要灵活躲避和射击。敌人有不同类型：普通敌人、快速敌人、重甲敌人等，每种有不同的血量和移动速度。

每关有固定的敌人波次，消灭所有敌人即可过关。部分关卡有Boss战，Boss血量较高且有特殊攻击模式。

角色可以收集跑道上的金币和道具来升级武器。武器升级包括威力、射速、子弹数量等多个维度。

游戏节奏极快，每局约2-3分钟，操作简单但需要良好的反应和走位。

## 核心循环

滑动走位 → 自动射击消灭敌人 → 收集金币升级武器 → 挑战更难关卡

## 核心机制

- **自动射击系统**: 角色自动瞄准最近的敌人开火，玩家专注于走位躲避。这种操作分工降低了操作门槛，让玩家集中精力在策略层面。子弹有飞行时间和弹道。
  （操作分工）
- **敌人波次设计**: 每关敌人从不同方向出现，有普通敌人、快速敌人、重甲敌人等多种类型。不同敌人组合形成不同的战术挑战。Boss战增加高潮体验。
  （敌人多样性）
- **武器升级系统**: 收集金币可以升级武器威力、射速、子弹数量等属性。升级后战斗效率明显提升，有强烈的数值成长反馈。
  （数值成长）

## 为什么好玩

自动射击让玩家专注于走位，快节奏的战斗非常爽快。看着敌人成片倒下有强烈的成就感。Voodoo的品质保证了流畅的体验。

## 粘性来源

战斗爽快感、武器成长的数值反馈、敌人波次的变化性。'差一点就过关'的不甘心推动重复游玩。升级武器的期待感也很强。

## Meta 系统

武器升级系统：提升射速、伤害、子弹数量等属性。通关获得金币用于升级，形成明确的成长目标。

## 实现难度

低 — 竖屏2D射击+自动瞄准，技术实现相对简单。Voodoo作为成熟发行商有标准化的开发管线。
