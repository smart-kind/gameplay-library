# 纸钞屋：终极计划（Money Heist: Ultimate）

- **类型**: 潜行/解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Klei Entertainment / Netflix
- **首次发布**: 2023
- **一句话描述**: 基于《纸钞屋》（La Casa de Papel）的潜行冒险游戏。

## 玩法规则

俯视角潜行游戏，玩家作为教授的团队成员策划并执行抢劫。穿越安保系统、避开守卫、与队友协调并完成目标而不被发现。

玩家需要观察守卫的巡逻路线、监控摄像头的位置，选择合适的时机和路径潜入目标区域。每个任务有不同的布局和挑战。

## 核心循环

策划抢劫方案 → 潜入地点 → 避免被发现 → 完成目标 → 逃脱 → 策划下一次抢劫

## 核心机制

- 潜行机制：视线回避、噪音管理和守卫巡逻模式
- 团队协作：为不同队员分配具有独特能力的角色
- 抢劫策划：为每次任务选择入口、时机和策略

## 角色与剧情

游戏中可以扮演剧中多个角色，包括东京、里约、丹佛、内罗毕等经典角色。每个角色在潜行中有不同的能力优势。

剧情跟随剧集的时间线展开，同时包含原创任务。玩家在任务中与熟悉的角色互动，体验从另一个角度看待的抢劫故事。

## 为什么好玩

捕捉了剧中标志性抢劫的紧张感和策划感，让玩家在执行精心策划的抢劫时拥有主动权。

## 粘性来源

抢劫任务多样性、角色推进和执行完美潜行行动的挑战。

## Meta 系统

Netflix Games — 包含在订阅中

## 实现难度

中等 — 潜行需要耐心和规划
