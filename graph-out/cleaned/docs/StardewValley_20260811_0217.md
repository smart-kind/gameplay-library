# Stardew Valley（星露谷物语）

- **类型**: 农场模拟 / 生活模拟
- **平台**: PC / Mobile (iOS+Android) / Switch / PS / Xbox
- **开发商**: ConcernedApe（Eric Barone）
- **首次发布**: 2016
- **一句话描述**: 继承爷爷的废弃农场，开垦土地、种植作物、养殖动物、采矿钓鱼、与镇上居民建立关系，按照自己的节奏过田园生活。

## 玩法规则

游戏为俯视角像素风格，每天代表游戏内一天。玩家有固定的精力值（体力），每项操作消耗体力，体力耗尽会晕倒并损失部分金钱。每天早上6点自动醒来，凌晨2点强制睡觉。

农场是核心活动区域。玩家用锄头开垦土地、播撒种子、浇水（每天需要，除非下雨）、收获成熟作物。不同作物有不同的生长周期和售价，需要根据季节选择合适的作物。春季种草莓、夏季种蓝莓、秋季种南瓜是经典选择。

除了种田，玩家可以采矿（进入矿洞打怪获取矿石和宝石）、钓鱼（各水域有不同的鱼种，有QTE小游戏）、觅食（在镇上各处收集野生物品）、烹饪（用收集的食材制作恢复体力的料理）。

镇上有数十位NPC，每个有独特的日程、喜好和好感度。通过对话和送礼提升好感度，达到一定等级后可以结婚。每位NPC有喜欢的礼物和讨厌的礼物，送对礼物事半功倍。

## 核心循环

种植收获赚金币 → 升级工具扩大产能 → 探索采矿钓鱼获取额外收入 → 社交解锁新配方和剧情 → 按照自己的节奏规划农场发展

## 核心机制

- **季节系统**：春夏秋冬四个季节，每个季节有不同的作物和可钓鱼种。季节结束时未收获的当季作物全部枯死。这迫使玩家做季节性规划——什么季节种什么、如何最大化每季收入。
- **时间管理**：每天只有约15-20分钟的游戏时间，需要在有限的时间内完成浇水、喂食、采矿、社交等活动。体力是有限的——不能一天做完所有事。这种限制创造了有意义的选择：今天去采矿还是去钓鱼？
- **技能升级**：五个技能（耕种、采矿、觅食、钓鱼、战斗）通过对应活动升级，每级解锁新配方或加成。技能10级时可以选择两种专精路线（如耕种选"农耕人"增加作物10%售价或"畜牧人"增加动物产品售价）。

## 为什么好玩

没有"正确"的玩法——你可以专注种田成为农业大亨，可以天天采矿成为冒险家，可以到处送礼成为社交达人，也可以只是钓鱼看风景。游戏尊重你的选择，不强加任何目标。这种自由度让人放松。

## 粘性来源

- **农场建设**：想要打造完美农场是长期目标，布局规划永远有新想法
- **全收集**：收集所有物品（完成博物馆捐赠、完成社区中心任务）是清晰的目标线
- **社交关系**：想和每个村民成为朋友甚至结婚，了解每个人的故事
- **多周目**：每局可以选择不同的农场布局和技能路线，体验不同玩法
- **持续更新**：作者十多年持续免费更新，每次更新都有新内容

## Meta 系统

- **金币**：核心货币，通过卖作物、采矿、钓鱼等获得
- **社区中心**：通过收集特定物品包来修复社区中心，是游戏的主要目标线
- **技能专精**：10级后选择专精，影响后续游戏风格
- **对核心玩法的影响**：金币和技能升级让游戏进程有清晰的方向感，但不强制——玩家完全可以按自己节奏玩

## 实现难度

中 + 模拟经营的核心系统（种植、时间、体力）实现不难，但内容量巨大——数十种作物、数百种物品、数十个NPC各有日程和对话、多个小游戏（钓鱼、采矿）。最大的难点是确保所有内容有内在一致性，让游戏世界感觉"活"而不是机械重复。单人开发完成全部内容需要极强的执行力和时间管理。
