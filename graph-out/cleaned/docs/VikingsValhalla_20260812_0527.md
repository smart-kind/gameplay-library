# 维京传奇：英灵神殿（Vikings: Valhalla）

- **类型**: 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Netflix（原创）
- **首次发布**: 2024
- **一句话描述**: 基于 Netflix 剧集《维京传奇：英灵神殿》的即时战略游戏。

## 玩法规则

玩家扮演维京氏族领袖，建造定居点、管理资源、训练战士并进行战术战斗。游戏设定在剧集的世界观中，包含哈拉尔·哈德拉达、芙蕾迪丝·埃里克斯多蒂尔和莱夫·埃里克松等角色。

玩家需要在地图上建造各类建筑：伐木场、铁匠铺、兵营等，产生资源和训练士兵。战斗采用即时策略模式，不同类型单位有克制关系。

## 核心循环

建造定居点 → 训练战士 → 收集资源 → 攻击敌人/完成任务 → 扩张领地

## 核心机制

- 基地建设：建造和升级维京建筑以产生资源和训练军队
- 战术战斗：即时战斗中不同兵种和地形优势形成策略深度
- 资源管理：平衡食物、木材等资源维持氏族运转

## 角色与剧情集成

游戏融入了剧集的核心角色，包括哈拉尔·哈德拉达的军事才能、芙蕾迪丝·埃里克斯多蒂尔的政治手腕和莱夫·埃里克松的探索精神。每个角色在游戏中有独特的技能和加成。

剧情任务重现了剧中的经典事件，玩家可以亲身体验维京人的征战与探索。

## 为什么好玩

将热门 Netflix 剧集的丰富维京背景与易于上手的即时战略玩法结合，让玩家指挥传奇角色。

## 粘性来源

基地推进、剧中角色收集和持续的氏族战争创造长期参与循环。
