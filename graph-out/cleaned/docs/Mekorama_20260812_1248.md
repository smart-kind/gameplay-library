# 微型世界（Mekorama）

- **类型**: 3D解谜 / 探索
- **平台**: Mobile (iOS+Android)
- **开发商**: Martin Magni
- **首次发布**: 2016
- **一句话描述**: 精致的3D微缩景观解谜游戏，玩家旋转场景帮助小机器人找到回家的路。

## 玩法规则

屏幕中央展示一个精巧的微缩3D场景，像建筑模型一样可以360度旋转和缩放。

场景中有一个小机器人（B），目标是通过点击场景中的平台或按钮，为机器人创造一条通往目标位置（房子/星星）的路径。

点击平台可以升起或降下，点击按钮可以触发机关（如移动桥梁、旋转平台、打开门）。玩家需要观察场景的全貌，找出平台之间的连接关系。

因为是微缩模型，旋转视角本身就是解谜的一部分——从某个角度看，两个不相连的平台看起来是连在一起的，这就是可以通过的路径（类似彭罗斯三角的视觉错觉）。

部分关卡有隐藏星星收集，需要找到特殊的隐藏路径。关卡没有失败条件，可以无限尝试。

## 核心循环

观察微缩场景 → 旋转视角发现路径 → 点击机关创造通路 → 机器人走到目标位置

## 核心机制

- 视角错觉机制：利用3D场景的透视效果，某些角度下看起来连通的路径实际上是视觉错觉——这是游戏最独特的设计，将'改变视角'本身变成解谜手段
- 场景互动：每个关卡是一个自成一体的微缩世界，机关之间的联动关系需要玩家通过观察和实验来理解
- 无失败压力：没有死亡或时间限制，玩家可以悠闲地观察和思考，适合放松体验

## 为什么好玩

微缩景观的精致美感本身就是享受——每个关卡都是一件艺术品。视角错觉带来的'原来如此！'顿悟时刻非常满足。旋转场景探索隐藏角度的过程充满好奇心驱动的乐趣。

## 粘性来源

视觉美感吸引重复查看；隐藏星星收集提供额外目标；关卡数量有限但每个都是精心打磨的精品；DIY关卡编辑器让玩家可以创造和分享自己的微缩景观。

## Meta 系统

线性关卡制。隐藏星星收集。DIY关卡编辑器：玩家可以创建和分享自己的3D微缩景观。无付费系统。

## 实现难度

低 — 核心是3D场景渲染和简单点击交互。技术难度低，最大挑战是关卡的3D设计和视角错觉的创造，需要艺术感和空间想象力。
