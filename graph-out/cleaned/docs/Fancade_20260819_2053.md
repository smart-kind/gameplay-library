# Fancade

- **类型**: 迷你游戏合集 / 游戏创作
- **平台**: Mobile (iOS+iPadOS)
- **开发商**: WebVentures B.V.
- **首次发布**: 2020
- **一句话描述**: 包含超过100款迷你游戏的合集平台，同时允许玩家用内置工具自己创作游戏。

## 玩法规则

玩家进入Fancade后，主界面展示为多个"世界"的网格布局。每个世界是一个独立的迷你游戏集合，世界图标上标注着主题和已解锁/未解锁状态。玩家点击已解锁的世界进入后，可以看到该世界内包含的所有迷你游戏缩略图。

每个迷你游戏有独特的玩法和操作方式。有些是动作类需要反应速度，有些是解谜类需要逻辑思考，有些是平台跳跃需要精准操作。游戏界面通常简洁明了，底部或侧边显示操作按钮和得分。完成游戏后获得星星奖励，星星数量取决于表现（通关速度、得分、隐藏要素发现等）。

玩家收集到足够星星后，可以在主界面解锁新的世界。每个新世界包含完全不同类型的迷你游戏，保持新鲜感。游戏中还包含街机模式，在这里可以看到所有迷你游戏的全球排行榜，玩家可以反复挑战同一款游戏以追求更高分数。

创作模式是Fancade的核心特色之一。玩家可以选择从空白画布开始或使用预设模板。创作工具采用积木式编程界面，玩家通过拖拽逻辑块来构建游戏行为。创作完成后，游戏会自动发布到社区，其他玩家可以游玩、点赞和评论。创作者根据获得的好评数量获得宝石奖励。

## 核心循环

玩迷你游戏收集星星 -> 解锁新世界和游戏 -> 在街机模式中竞争排名 -> 创作自己的游戏分享

## 核心机制

- **世界解锁系统**：收集足够星星解锁新世界，每个世界有独特的迷你游戏集合，形成递进式目标
- **UGC创作工具**：玩家可以用积木式编辑器从零创建游戏或从模板开始，降低创作门槛
- **街机排行榜**：全球排行榜系统覆盖每款迷你游戏，驱动竞争和反复挑战高分
- **社区分享**：玩家创作的游戏可以被其他玩家游玩、点赞，创作者获得宝石奖励，形成创作者经济

## 为什么好玩

既是游戏合集也是创作平台。100+款游戏确保永不会无聊，而创作功能让玩家从消费者变成创造者，极大扩展了内容生态。任何人都可以成为游戏设计师。

## 粘性来源

UGC内容的无限性（社区持续产出新游戏）+ 排行榜竞争 + 创作成就感。每天发现新游戏的惊喜感，以及创作出被他人认可的游戏时的满足感。

## Meta 系统

创作者经济系统。玩家创作游戏获得游玩数、点赞数和宝石奖励。宝石可用于解锁创作工具的高级功能（更多素材、更复杂的逻辑块、自定义UI等）。对核心玩法的影响：高级工具让创作更自由，创作出更好玩的游戏获得更多反馈。

## 实现难度

高 - 需要构建完整的UGC游戏引擎、社区系统和内容审核机制。最大技术难点：移动端游戏创作工具的性能优化（在小屏幕上操作复杂的逻辑块）和社区内容审核系统（确保内容安全）。
