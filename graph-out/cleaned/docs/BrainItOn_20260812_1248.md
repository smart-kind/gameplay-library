# 脑力大作战（Brain It On!）

- **类型**: 物理益智
- **平台**: Mobile (iOS+Android)
- **开发商**: Orbital Nine Games
- **首次发布**: 2016
- **一句话描述**: 画线解谜游戏——在屏幕上画出的形状会变成物理实体，用来解决各种物理谜题。

## 玩法规则

每关给出一个目标（如'让球落入杯中'、'使两个方块接触'），屏幕显示相关物理元素。

玩家用手指在屏幕上画线或形状，画完后这些线条会变成有质量的物理实体，受重力影响并与其他物体碰撞。

可以画圆球、方块、杠杆、斜坡等任何形状。画出的物体会和场景中的已有物体产生物理互动——球会滚动、方块会掉落、斜坡会让物体滑动。

关卡中可能有多个解法：可以画一个斜坡让球滚下去，也可以画一个弹射器把球弹过去，或者直接画一个杯子接住球。

部分关卡有时限或画线条数限制，增加挑战性。随着关卡推进，谜题变得越来越复杂，需要更巧妙的物理思考。

## 核心循环

观察谜题 → 画出形状 → 观察物理反应 → 成功过关或调整画法重试

## 核心机制

- 画线即创造：手指画出的线条变成真实物理物体，将'涂鸦'直觉与物理模拟结合，操作门槛极低但解谜空间极大
- 多解开放性：大多数关卡没有唯一解法，不同玩家可以画出完全不同的方案，社区分享激发创造力
- 物理直觉驱动：不需要数学计算，只需要凭物理直觉（重力、杠杆、惯性）来设计方案，让各年龄段玩家都能上手

## 为什么好玩

操作的即时性和物理反馈的真实感形成完美循环——你画的东西真的会按物理规律运动。每次'居然还能这样'的意外解法都带来惊喜。简单的画线操作隐藏着深度的解谜可能性。

## 粘性来源

物理谜题的'多解性'让人想尝试不同画法；'差一点就成功'的微调过程令人上瘾；社区分享的高分和最简解法激发竞争心；每天推送新关卡保持新鲜感。

## Meta 系统

关卡解锁制。星星评分系统：用更少的线条或更快的时间完成可获得额外星星。每日挑战关卡。

## 实现难度

低 — 核心是2D物理引擎（如Box2D）的集成和手绘形状的多边形转换。技术难度低，最大挑战是关卡设计质量——需要保证每关有多个可行解法。
