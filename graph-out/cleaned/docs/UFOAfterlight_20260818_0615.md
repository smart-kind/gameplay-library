# UFO：劫后余生（UFO: Afterlight）

- **类型**: 策略 / 回合制战术
- **平台**: PC
- **开发商**: Altar Games
- **首次发布**: 2007
- **一句话描述**: X-COM风格的科幻策略游戏，结合了小队战术战斗和全球战略管理，设定在一个被外星生物入侵的火星殖民地。

## 玩法规则

游戏分为两个层面：全球战略层和小队战术层。全球战略层以火星地图为基础，玩家需要管理基地、研究外星科技、生产武器装备。小队战术层采用回合制，玩家指挥一支小队在3D场景中与外星生物战斗。

战略层操作：在火星地图上选择任务地点、派遣小队、分配科研资源、建造设施、管理资金。每个决策都有时间成本。资金来源于火星殖民地的税收和任务奖励。

战术层操作：小队成员以回合制方式移动、射击、使用物品。每个成员有行动点数（AP），移动、射击、使用物品都会消耗AP。射击有命中率，受距离、掩体、视野等因素影响。利用掩体和侧翼攻击是关键战术。

游戏目标是保护火星殖民地，逐步揭开外星入侵的真相，最终消灭所有外星威胁。随着剧情推进，会发现外星人入侵背后的更大秘密。

## 核心循环

执行战术任务 -> 获得外星样本/资源 -> 研究新科技 -> 提升战斗力 -> 应对更大威胁

## 核心机制

- 双层面玩法：全球战略管理（基地建设、科研、生产）和小队战术战斗（回合制射击）交替进行，两种玩法相互影响。
- 永久死亡（Permadeath）：战术任务中阵亡的队员永久消失，增加了每次决策的紧张感和重量感。
- 科技研究树：通过研究外星样本解锁新的武器、装备和能力，形成明确的成长路径。

## 为什么好玩

UFO: Afterlight的乐趣来自战略与战术的双重挑战。战略层面上，你需要在资源有限的情况下做出艰难的选择——是研究新武器还是扩建基地？战术层面上，每次战斗都是独特的——队员的走位、掩体利用、射击时机都需要精心计算。一个队员的永久死亡会让你痛下决心。

## 粘性来源

粘性来自长期成长曲线和差一点就成功的战术挑战。每次任务失败后你会想如果上次那个队员没有死，这种遗憾感驱动你重新开始。科技树的逐步解锁也提供了持续的成就感。

## Meta 系统

基地建设+科技研究+装备制造系统。玩家需要建造不同的设施（实验室、生产车间、医疗室等），研究外星科技来解锁新装备，为小队成员提供更好的武器和护甲。

## 实现难度

高。最大的技术难点在于回合制AI设计——需要让敌方单位表现出合理的战术行为（寻找掩体、侧翼包抄、集火目标等），同时还要处理双层面系统的状态同步。
