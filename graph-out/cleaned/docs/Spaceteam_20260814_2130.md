# Spaceteam（Spaceteam）

- **类型**: 社交合作 / 派对 / 模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: Sleeping Beast Games / Henry Smith
- **首次发布**: 2012
- **一句话描述**: 2-6名玩家各自扮演飞船船员，通过大喊大叫传递指令来共同操作飞船的合作派对游戏。

## 玩法规则

每个玩家的手机显示自己飞船控制台的一部分，上面有各种开关、滑块和仪表。屏幕上会出现指令卡，例如"将曲率驱动调到6"或"开启反物质泵"，但这些指令需要的控件往往不在你自己的屏幕上，而在其他玩家的屏幕上。

玩家必须大声喊出自己需要的指令（"谁有曲率驱动？调到6！"），拥有对应控件的玩家听到后操作并确认。同时，飞船会不断遭遇各种危机（小行星、太空怪兽、黑洞等），需要在限定时间内完成一系列操作才能化解。

如果未能在倒计时结束前完成所有必要操作，飞船就会受损。多次受损后游戏失败。随着游戏进行，指令出现的速度越来越快，指令也越来越复杂。

指令的科幻术语设计是游戏的核心特色——大量使用虚构的技术名词（"离子推进器"、"量子纠缠发生器"、"超空间跃迁引擎"），让沟通本身就充满喜剧效果。

## 核心循环

接收指令 → 大声喊出需求 → 其他玩家响应并操作 → 化解危机 → 进入下一轮（更快更难）

## 核心机制

- **信息不对称**：每个玩家只能看到自己屏幕上的控件，必须通过口头沟通才能完成任务，天然制造混乱和欢笑
- **时间压力**：倒计时机制迫使玩家快速沟通，越到后面时间越紧迫，紧张感不断升级
- **指令复杂度递增**：从简单的单步操作到多步组合操作，难度曲线陡峭但公平

## 为什么好玩

这是一款让人笑到肚子疼的游戏——混乱的沟通场景、荒谬的指令内容（"量子通量电容器调到11！"）和朋友间手忙脚乱的反应本身就是最大的乐趣。

## 粘性来源

具体到机制层面：社交互动带来的情绪体验是核心粘性——和朋友一起大喊大叫的欢乐记忆让人想要重复体验。每局游戏的随机指令组合确保不会重复，而且随着玩家默契度提升，通关更高难度带来的成就感也是重要驱动。

## Meta 系统

- **解锁系统**：完成关卡解锁新的飞船和场景
- **对核心玩法的影响**：新飞船有不同的视觉主题，不影响核心机制

## 实现难度

低——核心机制本质上是随机指令生成+分布式UI分配，技术上没有复杂算法。最大的技术难点是多人设备的连接同步（蓝牙或WiFi），以及确保所有玩家在同一时刻接收到协调一致的指令序列。
