# 三消游戏的鼻祖，交换宝石完成匹配消除（Bejeweled）

- **类型**: 三消
- **平台**: PC / Mobile (iOS+Android)
- **开发商**: PopCap Games
- **首次发布**: 2001
- **一句话描述**: 三消游戏的鼻祖，交换宝石完成匹配消除

## 玩法规则

在8×8的网格上，玩家交换相邻宝石使3个或更多同色宝石连成一行或一列。消除后上方宝石下落填补空缺，产生连锁消除。

特殊组合：4个产生闪电宝石（消除整行或整列），5个产生超新星（消除所有同色宝石），T或L形产生火焰宝石（爆炸消除周围宝石）。

游戏有多种模式：经典（限时计分）、禅（无时间限制放松）、益智（步数限制）、闪电（连锁反应模式）。

## 核心循环

交换宝石 → 匹配消除 → 连锁反应 → 获得分数 → 时间到/步数用完 → 结算

## 核心机制

- 经典三消：交换相邻宝石完成3+连珠
- 特殊宝石：4连/5连/L形/T形产生不同特殊消除效果
- 连锁反应：消除后下落可能触发自动消除
- 多模式：经典、禅、益智、闪电满足不同需求

## 为什么好玩

三消玩法的始祖，简单规则下蕴含丰富的策略性。特殊宝石的连锁消除效果极其爽快。

## 粘性来源

分数驱动；多模式设计；特殊宝石的爽感反馈；再玩一局的冲动。

## Meta 系统

分数记录和成就系统。

## 实现难度

低。三消玩法简单直观，适合所有年龄。最大技术难点：消除算法的效率和连锁反应的判定。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
