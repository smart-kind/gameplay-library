# League of Mages

- **类型**: 卡牌对战 / 多人在线
- **平台**: Mobile (iOS+Android)
- **开发商**: Gamelion
- **首次发布**: 2013
- **一句话描述**: 真人玩家间一对一法术对决，通过抓取和投掷符文组合魔法攻击

## 玩法规则

游戏以第一人称静态视角呈现，玩家正对着屏幕外的对手。画面中漂浮着各种元素符文，玩家需要用触摸屏来抓取这些符文。

操作方式：用手指抓取漂浮的符文，然后将其甩向对手方向发动攻击。随着解锁更多法术，玩家可以组合不同元素符文来释放更强大的攻击——比如两个火符文组合成基础火球。

同时，当对手发动攻击时，玩家需要在屏幕上点击对手的攻击来减轻对自己血条的伤害影响。

每个玩家有一个血条显示在屏幕一侧，血条归零即战败。战斗中还可以使用付费购买的道具来阻碍对手或回复自身血量。

## 核心循环

匹配对手 → 抓取符文组合法术 → 攻击对手 → 点击防御 → 获胜解锁新法术

## 核心机制

- **符文组合系统**：不同元素符文的组合产生不同法术（火+火=火球），类似魔法版的"合成公式"
- **攻守同步**：抓取符文攻击的同时还要点击防御对手攻击，形成多任务处理压力
- **付费道具干扰**：可以使用内购道具直接干扰对手或回复血量，影响对战平衡

## 为什么好玩

符文抓取+组合的魔法施放概念很有趣——在触屏上"画符"的感觉比单纯点击按钮更有魔法氛围。不同元素组合的可能性提供了策略空间。但评测指出核心战斗系统手感迟钝，物理引擎缺乏说服力，导致"甩符文"的动作与实际效果之间缺乏真实连接感。

## 粘性来源

真人对战的竞争欲和新法术解锁的成就感。但由于战斗系统本身缺乏深度，这种粘性比较脆弱。付费道具的存在也可能让免费玩家感到挫败。

## Meta 系统

- **法术解锁系统**：通过战斗胜利解锁新法术，增加可组合的元素种类
- **付费道具商店**：可购买干扰对手或回复血量的道具，直接影响对战结果（争议性设计）
- **角色自定义**：后期版本允许自定义角色外观，解决早期"一堆替身互打"的问题
