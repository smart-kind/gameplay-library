# The Great Jitters Pudding Panic

- **类型**: 路径规划解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 2011
- **一句话描述**: 路径规划解谜游戏，引导布丁角色Jitters穿过充满怪物的轨道到达出口
- **PocketGamer评分**: 9/10

## 玩法规则

玩家控制一个名叫Jitters的布丁角色，在充满怪物和陷阱的轨道网络中引导它安全到达出口。游戏的核心玩法是路径规划和实时切换轨道方向。

游戏界面上，Jitters沿着轨道自动前进。玩家需要在Jitters到达分岔路口之前，点击切换轨道的道岔，为Jitters选择正确的路线。目标是引导Jitters到达出口，同时避开沿途的女巫、骷髅、幽灵等各种怪物。

除了路径规划，游戏还包含收集元素——沿途散布着各种道具和加分物品，玩家可以引导Jitters经过这些物品来获取额外分数。游戏的关卡设计巧妙，需要玩家提前规划路线，在Jitters前进的同时快速做出决策。后期关卡中，轨道网络更加复杂，怪物更多，移动速度也更快。

## 核心循环

放置/操作 → 获得奖励/进展 → 升级/解锁新内容 → 挑战更高难度

## 核心机制

- **机制1**：路径规划解谜核心循环 — 通过路径规划解谜操作完成关卡目标，获得金币/分数奖励
- **机制2**：渐进式难度 — 每个关卡引入新的元素或增加复杂度，玩家需要调整策略
- **机制3**：资源管理 — 有限的建造材料/金币/时间，需要玩家做出取舍决策

## 为什么好玩

Pudding Panic是路径规划和鬼屋冒险的成功结合，引导布丁角色Jitters穿过充满怪物的轨道到达出口。 游戏的评分为9/10，说明这款游戏质量不错，有独特的玩法乐趣。

## 粘性来源

具体到机制层面：核心循环的"完成关卡→获得奖励→解锁新内容"驱动玩家持续游玩；渐进式难度带来的挑战感让玩家想"再来一关"；解谜类游戏特有的"顿悟时刻"（想通了解法）提供强烈的成就感。

## Meta 系统

外围成长系统：通过关卡获得的金币/分数可以解锁新的塔类型/角色/赛道，或升级已有元件的性能。对核心玩法的影响：解锁内容提供了新的策略选择，但不改变核心操作方式。

## 实现难度

中 — 核心玩法基于成熟的路径规划解谜机制，最大技术难点在于流畅的手势识别和实时物理反馈。
