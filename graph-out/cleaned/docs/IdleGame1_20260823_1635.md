# 放置游戏1号（Idle Game 1）

- **类型**: 放置点击 / 策略增量
- **平台**: Mobile (iOS+Android)
- **开发商**: Cem Kamiloglu
- **首次发布**: 2020
- **一句话描述**: Idle Game 1 is aimed at experienced incremental game players with special emphasis on random upgrades。

## 玩法规则

Idle Game 1 的核心玩法围绕放置点击 / 策略增量展开。游戏启动后，玩家看到主菜单界面，可选择开始新游戏、继续进度或查看统计信息。进入核心游戏后，idle game 1 is aimed at experienced incremental game players with special emphasis on random upgrades。

屏幕布局根据游戏类型有所不同。对于放置类游戏，上方显示当前资源数量和生产速率，中央展示游戏主体区域（如文明场景、地下城地图等），下方排列升级选项和操作按钮。对于动作类游戏，中央是主要操作区域，边缘显示生命值、得分等关键信息。

玩家的操作包括：点击/触碰执行主动动作（攻击、收集、移动），打开菜单进行策略规划（升级分配、路线选择、装备更换），查看进度指标调整下一步行动。每种操作都有即时的视觉和数值反馈。

## 核心循环

idle game 1 is aimed at experienced incremental game players with special emphasis on random upgrades → 获得奖励或资源 → 升级能力 → 挑战更高难度 → 重复循环

## 核心机制

- **核心交互机制**：Idle Game 1 is aimed at experienced incremental game players with special emphasis on random upgrades，这是游戏最基础也最重要的操作，贯穿整个游戏体验
- **渐进式成长系统**：通过升级、解锁和能力提升，玩家角色/设施/队伍逐步变强，提供持续的进步感
- **自动化与手动平衡**：放置类游戏的核心张力——在主动操作获取即时收益和建立自动化获取长期收益之间找到平衡
- **随机性与策略**：每轮游戏都有不同的随机因素（敌人配置、升级选项、地图布局），要求玩家灵活调整策略

## 为什么好玩

Idle Game 1 成功地将放置点击 / 策略增量的核心乐趣提炼为一个紧凑而上瘾的体验。玩家始终处于"差一点就更好"的状态——差一点就能升下一级、差一点就能通关、差一点就能击败Boss。这种持续的不甘心驱动着"再来一次"的冲动。

## 粘性来源

- **进度可视化**：清晰展示从起点到当前进度的成长轨迹，成就感直观可感
- **随机奖励的变比率强化**：随机掉落的升级选项或稀有物品创造类似老虎机的心理依赖
- **"差一点"效应**：每次失败都让人觉得只差一点点就能成功，促使反复尝试
- **转生/重置的深度**：每次重新开始都带着更强的基础，形成螺旋上升的游戏体验

## Meta 系统

- **声望/转生系统**：达到特定条件后可选择重置游戏进程，换取永久性的基础加成，让后续游戏更高效
- **成就与收藏**：记录玩家的各种里程碑，提供收集要素和展示价值
- **每日挑战/事件**：周期性变化保持游戏内容的新鲜感

## 实现难度

低 — 放置类和基础动作类游戏的核心机制在技术上已非常成熟。最大技术难点在于数值平衡设计——确保经济增长曲线和游戏难度曲线相互配合，既不会让玩家感到无聊也不会让他们过度受挫。
