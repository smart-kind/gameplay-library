# 超级迷你派对（Super Mega Mini Party）

- **类型**: 派对/休闲合集
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2019
- **一句话描述**: 多人派对小游戏合集，支持本地多人游玩

## 玩法规则

玩家选择或随机分配小游戏进行对战。每款小游戏有独特的操作方式：点击、滑动、拖拽等。游戏支持2-4人同屏对战，每局游戏持续数十秒至一分钟。最先完成小游戏目标或得分最高的玩家获胜。多轮小游戏后累计分数最高者胜出。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

选择小游戏 → 多人对战 → 计分排名 → 下一轮

## 核心机制

- **派对模式**:  2-4人同屏实时对战，适合社交聚会
- **随机小游戏**:  每轮随机分配不同小游戏，保持新鲜感
- **短局设计**:  每局数十秒，适合碎片时间

## 为什么好玩

与朋友同屏对战的社交乐趣，每款小游戏规则简单但竞争激烈，充满欢笑

## 粘性来源

社交互动是核心驱动力；随机小游戏保持重复游玩的新鲜感

## Meta 系统

无

## 实现难度

中 - 需要实现多人同屏输入处理和多种小游戏逻辑 - 多人同时触屏输入的冲突处理和小游戏快速切换
