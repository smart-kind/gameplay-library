# 整理物品的禅意解谜游戏（Unpacking）

- **类型**: 解谜
- **平台**: Mobile (iOS+Android) / PC / Switch / PS / Xbox
- **开发商**: Witch Beam
- **首次发布**: 2021
- **一句话描述**: 整理物品的禅意解谜游戏

## 玩法规则

玩家从一个箱子中取出物品，将它们放置到房间中的合适位置。每个物品有特定的可放置区域。通过物品可以了解主人公的生活故事。游戏没有计时或分数压力，纯粹享受整理过程。

## 核心循环

打开箱子 → 取出物品 → 放置到合适位置 → 完成房间 → 下一场景

## 核心机制

- 物品放置：将物品拖放到合适位置
- 叙事驱动：通过物品了解主人公故事
- 无压力体验：无计时、无失败条件
- 多场景：不同人生阶段的房间

## 为什么好玩

整理物品的满足感和通过物品讲述故事的巧妙设计。极其治愈的游戏体验。

## 粘性来源

剧情驱动的好奇心；整理的满足感。

## Meta 系统

场景解锁。

## 实现难度

低。拖放操作简单。最大技术难点：物品放置的判定。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
