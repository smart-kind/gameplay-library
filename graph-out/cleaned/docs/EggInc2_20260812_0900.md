# Egg, Inc. 2

- **类型**: 放置 / 增量
- **平台**: Mobile
- **开发商**: Auxbrain Inc.
- **首次发布**: 2025
- **一句话描述**: 古怪的增量放置游戏——经营鸡蛋农场，策略升级和自动化。

## 玩法规则

玩家管理一个鸡蛋农场，从几只鸡开始逐步扩展到工业化生产。核心机制是鸡蛋价值升级——通过研究解锁更高价值的鸡蛋品种（从普通鸡蛋到未来科技蛋）。

自动化和加速器最大化空闲收入。任务和活动提供多样性。简单但有策略的机制让游戏既放松又上瘾。

## 核心循环

养殖鸡群 → 生产鸡蛋 → 升级品种 → 扩大规模

## 核心机制

- 鸡蛋品种升级：从普通到未来科技蛋
- 自动化系统：最大化空闲收入
- 任务和活动：增加多样性
- 研究解锁：新科技和升级
- 规模扩张：从小农场到工业化

## 为什么好玩

简单但有深度的机制。从几只鸡到工业化农场的成长过程令人满足，每次解锁新鸡蛋品种都有新鲜感。

## 粘性来源

- 品种升级的新鲜感：每次解锁新鸡蛋类型
- 规模扩张的成就感：从小到大的成长
- 自动化效率：看到收入不断增长的满足感
- 任务多样性：活动和任务保持兴趣

## Meta 系统

鸡蛋品种研究和设施升级。解锁新鸡蛋类型、提升生产效率和扩大规模。

## 实现难度

低。增量放置核心系统简单，数值平衡是关键。
