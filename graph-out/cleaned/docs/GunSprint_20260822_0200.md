# 枪战冲刺（Gun Sprint）

- **类型**: 超休闲/竞速射击
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2021
- **一句话描述**: 边跑边射击的快节奏对战游戏

## 玩法规则

玩家控制角色在赛道上奔跑，同时向对手射击。通过滑动屏幕改变跑动方向，点击射击。赛道上有障碍物需要躲避。射击会消耗弹药，弹药有限需要合理使用。对手也在移动和射击，先击中对手或先到达终点者获胜。游戏节奏极快，每局约30秒。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

跑动+射击 → 躲避障碍+攻击对手 → 决出胜负 → 下一局

## 核心机制

- **移动射击**:  在奔跑中瞄准射击对手
- **赛道障碍**:  需要同时躲避障碍和攻击
- **快节奏**:  每局30秒的极速体验

## 为什么好玩

极速节奏带来的紧张刺激，同时需要跑位和瞄准的技巧挑战

## 粘性来源

短局设计让人"再来一局"；技巧提升带来的成就感

## Meta 系统

角色和皮肤解锁

## 实现难度

低 - 核心是简单碰撞和射击判定 - 快节奏下的输入响应和碰撞检测精度
