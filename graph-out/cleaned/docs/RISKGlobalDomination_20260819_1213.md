# RISK: Global Domination（统治全球）

- **类型**: 策略 / 战争 / 版图
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: SMG Studio
- **首次发布**: 2019
- **一句话描述**: 经典桌面策略游戏的数字版——在世界版图上部署军队、进攻邻国、最终征服全球。

## 玩法规则

游戏在一个分割为多个区域（领土）的世界地图上进行。每个领土有一定数量的军队，由不同玩家控制。回合制进行，每回合分为三个阶段：

**增援阶段**：玩家根据当前控制的领土数量获得新增援军队（控制的领土越多，获得的增援越多；完整控制一个大洲有额外奖励）。玩家将增援军队部署到自己控制的领土上。

**进攻阶段**：玩家可以选择从自己控制的领土进攻相邻的敌方领土。进攻操作为：选择进攻方领土 → 选择相邻敌方领土 → 掷骰子。进攻方最多投3个骰子，防守方最多投2个骰子，骰子点数逐对比较，点数小的一方损失一个军队。玩家可以使用"自动战斗"让系统自动计算结果，或"手动掷骰"体验传统骰子机制。

**行军阶段**：进攻结束后，玩家可以将军队从一个领土移动到另一个相邻领土，巩固防线或为下一回合进攻做准备。

游戏目标根据模式不同而异：经典模式需要消灭所有对手；其他模式有特殊胜利条件（如控制特定领土、在规定时间内达到目标等）。

## 核心循环

获得增援 → 部署军队 → 进攻邻国（掷骰子决定战斗） → 占领领土 → 巩固防线 → 回合结束

## 核心机制

- **掷骰子战斗**：战斗结果基于概率而非确定性，骰子的随机性让每场战斗都有悬念——优势方也可能因连续低点数而失败。
- **大洲加成**：完全控制一个大洲会在每回合获得大量额外增援，这是游戏的核心战略目标。
- **外交与联盟**：多人模式中的玩家间谈判、结盟和背叛是游戏体验的重要组成部分。
- **多种游戏模式**：除了经典全球征服，还有"首都征服"（攻占敌方首都）、"快速模式"（缩小版图、加速节奏）、"秘密任务"等。

## 为什么好玩

RISK 的魅力在于它完美的"策略深度+随机性"组合。你需要思考领土部署、进攻优先级、大洲控制策略，但同时骰子的随机性又让每场战斗充满悬念——有时候你会因为连续投出6点而逆转局势，有时候又因为连续1点而功亏一篑。这种不确定性让游戏永远不会变得可预测。

## 粘性来源

- **每局不同**：骰子随机性和多人互动确保没有两局游戏是相同的。
- **社交博弈**：与朋友间的谈判、结盟和背叛是游戏最大的乐趣来源。
- **翻盘快感**：在劣势下通过一次关键进攻逆转局势的满足感极强。
- **多种模式**：不同游戏模式和地图提供持续的新鲜感。

## Meta 系统

- **等级和成就系统**：通过游戏积累经验值，解锁称号和成就。
- **皮肤和地图主题**：解锁不同的地图视觉风格和军队外观。
- **季节性活动**：定期举办限时活动和锦标赛。

## 实现难度

中。核心是版图数据结构（领土邻接关系图）和骰子战斗的概率计算。最大技术难点是AI的对手行为设计（需要模拟人类的战略思维）和多人模式下的网络同步与房间管理。
