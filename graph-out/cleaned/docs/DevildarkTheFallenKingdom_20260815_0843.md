# 暗黑堕落王国（Devildark The Fallen Kingdom）

- **类型**: 格斗 / 动作RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: Brave HK Limited
- **首次发布**: 2019
- **一句话描述**: 一款黑暗奇幻题材的横版格斗动作游戏，无需联网，从四位暗影骑士中选择在黑暗世界中战斗。

## 玩法规则

游戏画面为2D横版卷轴，角色在左侧，敌人从右侧或平台不同位置出现。屏幕右下角有虚拟摇杆控制移动，左侧有攻击、技能和跳跃按钮。

玩家通过虚拟摇杆控制角色移动，点击攻击按钮进行基础连击，点击技能按钮释放特殊技能。每个角色有独特的武器和攻击方式（剑术、魔法、远程等）。

游戏分为多个关卡，每关有若干小怪和最终BOSS。击败敌人获得经验值和金币，用于升级角色和购买装备。

游戏过关条件为击败关卡BOSS。角色生命值归零时可以从检查点复活。

## 核心循环

玩什么 → 得到什么 → 用来做什么：战斗闯关获得金币和装备，升级角色和解锁新技能来挑战更难的关卡和BOSS

## 核心机制

- **四角色系统**：四位暗影骑士各有独特武器和战斗风格（剑士、法师、刺客、弓箭手），玩家可以切换角色体验不同玩法。每个角色有专属技能树
- **装备收集**：通过战斗和关卡奖励获得不同稀有度的装备和盔甲套装，提升属性。套装效果提供额外加成，鼓励收集完整套装
- **离线可玩**：不依赖网络连接，随时随地可以游玩，降低进入门槛。适合碎片时间游玩

## 为什么好玩

硬核格斗的爽快感（连招、闪避、技能释放）与RPG成长系统结合。黑暗奇幻画风和打击感在移动端格斗游戏中表现突出。每个角色的战斗节奏完全不同。

## 粘性来源

装备收集（追求套装完整）+ 角色培养（每升一级都变强）+ BOSS战挑战（每次失败都想再试一次）。四角色切换让游戏内容翻倍。

## Meta 系统

- **角色等级与技能树**：通过经验值升级，解锁新技能和被动加成。技能树提供多种发展路线
- **装备系统**：收集不同品质的武器和盔甲，套装效果提供额外加成。装备有强化和精炼系统
- **对核心玩法影响**：装备和等级显著提升数值，但操作技巧仍是通关关键。高难度关卡需要技术而非纯数值碾压

## 实现难度

中 — 格斗游戏操作要求较高，需要掌握连招和闪避时机。虚拟摇杆需要适应。最大技术难点在于虚拟摇杆加技能按钮的手感调优和BOSS AI设计。需要在小屏幕上实现流畅的格斗操作。
