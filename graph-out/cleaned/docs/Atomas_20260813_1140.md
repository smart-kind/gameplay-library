# 原子消除（Atomas）

- **类型**: 益智消除 / 化学主题
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Sirvo LLC
- **首次发布**: 2015
- **一句话描述**: 一款以化学元素为主题的环形消除游戏，玩家通过排列原子来合成更重的元素并获取高分

## 玩法规则

游戏界面是一个圆形的原子环轨道。每回合系统给玩家一个随机原子（氢H、氦He、锂Li等元素），玩家点击环上的一个空位放置该原子。

当两个相同原子在环上相邻放置时，它们会融合成原子序数+1的更重元素（两个氢融合成氦，两个氦融合成锂，以此类推）。融合后空出一个位置，周围的原子会收缩填补空位，可能触发新的相邻融合（连锁反应）。

游戏中还有三种特殊道具原子：
- **正号原子(+)**：放在两个相同元素中间时，触发大范围融合——两个相同元素向中间合并，消除中间的所有原子，合成一个更重元素并获得大量分数
- **负号原子(-)**：清除环上的一个原子，腾出空间
- **黑洞原子**：清除周围一圈所有原子，制造大片空位，同时消除的原子会转化为分数

当原子环被完全填满、没有空位可以放置新原子时，游戏结束。目标是在游戏结束前合成尽可能重的元素并获得最高分。

游戏过程中屏幕上方会显示下一个即将出现的原子类型，让玩家有机会提前规划放置位置。已合成的重元素（如金Au、银Ag、铂Pt）在屏幕上会以更大的图标显示，带来视觉上的成就感。分数计数器实时更新，合成越重的元素分数越高。

## 核心循环

获得随机原子 → 选择放置位置 → 触发融合反应获得分数 → 使用特殊道具(+/-/黑洞)创造更大连击 → 原子环空间越来越小，需要更精妙的策略 → 合成更重元素突破纪录

## 核心机制

- **元素融合系统**：同类原子相邻融合为更重的元素，形成连锁反应链条。这是游戏的核心策略层——不仅要考虑当前回合，还要预判后续几个回合的放置位置以最大化连锁
- **正号原子高分机制**：'+'号原子放在两个相同元素中间时，触发对称融合并清除中间所有原子，是获取高分的最重要手段。规划"+"的使用时机和位置是游戏的核心技巧
- **黑洞清场机制**：清除周围原子创造大片操作空间，既是危机应对工具（空间不足时）也是连击触发器（大量原子被消除计入分数）
- **随机原子分配**：系统随机给出下一个原子，玩家需要根据已有信息灵活调整策略，运气和策略并存

## 为什么好玩

看似简单的放置消除，却蕴含极深的策略性。当一连串融合反应被触发、屏幕上出现漂亮的连锁动画、分数飞速上涨时，那种智力上的满足感是无与伦比的。规则简单到30秒就能学会——"相同颜色放一起就融合"——但要精通需要大量的练习和预判能力。

## 粘性来源

连锁反应的视觉和分数反馈极强，形成强烈的正反馈循环。每次突破自己的最高分都来自更精妙的布局规划——"这次我用+号清掉了中间6个原子合成了金元素！"。"差一个位置就能合成更重元素"的不甘心让人不断重开一局。化学元素的渐进解锁也提供了收集成就感。

## Meta 系统

原子元素图鉴系统——随着游戏进程，玩家逐步解锁更重的元素（从氢到铀共118种），图鉴记录每种元素的合成次数和最高分。解锁新元素是主要的长期目标驱动。

## 实现难度

低 — 核心玩法是简单的环形数据结构+相邻匹配逻辑。最大难点是连锁反应的递归计算和性能优化（大量原子同时消除时的动画流畅度），以及正号原子的对称融合算法。随机分配的平衡性也需要精心设计。
