# 疯狂出租车（Crazy Taxi）

- **类型**: 街机驾驶
- **平台**: Mobile (iOS+Android) / Arcade
- **开发商**: Sega
- **首次发布**: 1999
- **一句话描述**: 一款快节奏的出租车驾驶街机游戏，玩家需要在限定时间内尽可能多地接送乘客赚取小费。

## 玩法规则

游戏画面采用第三人称追尾视角，玩家驾驶一辆色彩鲜艳的出租车在城市街道上行驶。屏幕上方显示剩余时间和当前收入金额，右侧有小地图显示乘客位置和目的地方向。
屏幕上会出现各种行人（带有感叹号标记），玩家需要靠近行人接载他们。接载后屏幕会显示目的地的大致方向（箭头指示），玩家需要尽快将乘客送达。
操作包括加速、刹车、转向。核心玩法是利用特技驾驶来增加小费收入：贴近障碍物擦过、飞跃坡道、在人行道上行驶、逆行等危险行为都会触发额外小费加成。
驾驶越疯狂、越接近障碍物，乘客给予的小费越多。但过度碰撞会导致出租车损坏，严重损坏时无法继续行驶。
游戏有多个关卡和城市地图（旧金山风格、纽约风格、东京风格），每个地图有不同的建筑布局、道路结构和乘客密度。
游戏结束条件：倒计时归零或出租车严重损坏。最终得分基于总收入（车费+小费）。高分可以解锁新车辆和新城市。

## 核心循环

接载乘客 → 疯狂驾驶抄近路 → 送达获得小费 → 寻找下一位乘客 → 时间耗尽结算

## 核心机制

- 疯狂驾驶奖励：贴近障碍物擦过、飞跃坡道、逆行等危险行为都会触发额外小费加成，鼓励玩家冒险而非保守驾驶
- 时间压力系统：倒计时制造紧迫感，让玩家在'安全慢开'和'疯狂飙车'之间做取舍，形成独特的紧张刺激体验
- 城市探索元素：不同路线到达同一目的地，发现捷径能节省时间接送更多乘客。城市中有隐藏的加速带和捷径通道

## 为什么好玩

把'危险驾驶'变成了合法赚钱的方式，反叛感带来纯粹的快乐。
每次成功飞跃或惊险擦过障碍时的爽快感极强，配上摇滚音乐让驾驶过程像一场狂欢。
发现一条从未走过的捷径时的探索成就感，以及时间紧迫时极限送达的刺激感。

## 粘性来源

每次差几秒就能多接一单的不甘心、发现新捷径的惊喜、以及'这局我可以拿到更高分'的街机式再来一局冲动。

## Meta 系统

解锁新出租车外观、新城市地图和新司机角色。高分排行榜。

## 实现难度

中 — 需要实现物理驱动的驾驶手感、城市碰撞检测、NPC行人AI和路径指示系统。技术难点在于让'疯狂驾驶'既有反馈感又不显得过于简单，以及城市环境的性能和加载优化。

游戏还包含自由驾驶模式：没有时间限制和乘客，纯粹享受在城市中飙车的乐趣。某些地图有隐藏的近道和秘密区域，需要反复探索才能发现。游戏的配乐以朋克摇滚为主，与疯狂驾驶的风格完美契合。
