# 50个小房间逃脱（50 Tiny Room Escape）

- **类型**: 解谜 / 逃脱 / 找物
- **平台**: Mobile (iOS+Android)
- **开发商**: Kiary Games Ltd
- **首次发布**: 2023
- **一句话描述**: 在每个微型房间中寻找线索、解开谜题，最终逃脱的3D场景逃脱解谜游戏。

## 玩法规则

每个关卡是一个小巧精致的3D房间模型，玩家可以旋转视角从不同角度观察房间。房间内布满了各种物品和细节：家具、装饰画、书、抽屉、挂钟等。

玩家通过点击物品来交互——打开抽屉查看内部、翻开书本寻找线索、旋转挂钟发现背后的暗格等。部分物品需要组合使用：在A处找到钥匙，用来打开B处的锁；在C处发现密码提示，用来解开D处的密码锁。

房间中隐藏了逃离所需的关键物品或信息。玩家需要系统地探索房间的每个角落，不放过任何细节。有些线索非常隐蔽——如画框背后的数字、地毯下的暗门、书架上特定排列的书籍等。

找到所有逃离所需元素后，房间的门或出口打开，进入下一个房间。部分房间之间有剧情关联，拼凑线索可以了解背后的故事。

## 核心循环

旋转观察房间 → 点击探索物品 → 收集线索和道具 → 解开谜题打开出口

## 核心机制

- 3D可旋转场景机制：房间是3D模型而非静态2D图，玩家可以旋转视角查看各个面。这增加了探索的自由度和真实感——'墙后面会不会有东西'的悬念推动玩家旋转检查每一面。
- 线索关联链机制：线索之间形成逻辑链——A处的提示指向B处的操作，B处的结果又指向C。玩家需要自己建立关联，而不是跟着线性提示走。
- 隐藏空间机制：暗格、暗门、地板下的空间等设计让'探索'本身成为游戏的核心乐趣。每次发现隐藏空间都带来'还有我看不到的东西'的惊喜。
- 微缩模型美学机制：小房间的精巧设计本身就是一种视觉享受。细节密度高但不杂乱，每个物品都有存在的意义，这种'小而精'的美学是游戏的独特卖点。

## 为什么好玩

3D可旋转的小房间像一个精致的解谜玩具盒。探索每个角落的'发现感'、解开线索链的'顿悟感'、打开出口的'成就感'三重体验叠加。小尺寸反而让探索更聚焦，不会迷失在大场景中。

## 粘性来源

每个房间是一个独立的'谜题包'，完成一个后自然想试下一个。隐藏空间的惊喜感和线索关联的智力挑战形成双重驱动。'差一个线索就能逃出去'的张力让人停不下来。

## Meta 系统

50个房间依次解锁，部分房间有剧情关联。完成所有房间可了解完整故事。无付费数值，纯内容消耗型。

## 实现难度

中等。3D场景渲染+交互逻辑是技术门槛，最大难点在于关卡设计——需要在有限空间内放置足够多的线索和谜题，同时保持难度合理和线索逻辑清晰。

50个房间虽然都是'逃脱'主题，但每个房间的故事背景和装饰风格不同——有的是废弃实验室，有的是中世纪城堡的囚室，有的是现代公寓的密室。每个房间的谜题设计也融入了场景特色：实验室里有化学试剂和仪器谜题，城堡里有机械锁和暗道，公寓里有电子密码和智能家居机关。
