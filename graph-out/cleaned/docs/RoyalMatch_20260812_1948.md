# 皇家对决（Royal Match）

- **类型**: 三消匹配
- **平台**: Mobile (iOS+Android)
- **开发商**: Dream Games
- **首次发布**: 2020
- **一句话描述**: 一款通过消除方块来修复和装饰城堡的三消手游，以流畅的操作手感和无广告体验著称

## 玩法规则

游戏主画面呈现一座需要修复的城堡和一组待消除的彩色方块棋盘。棋盘是标准的 8x8 或 9x9 网格，填充各种颜色的宝石或方块。屏幕一侧显示当前关卡的目标（如"消除 30 个红色方块""在 25 步内清除所有冰块"）。

玩家通过交换相邻两个方块的位置，使三个或更多同色方块连成一行或一列。匹配成功时方块消除并获得分数，上方方块下落填充空位，可能触发连锁反应。达到关卡目标即过关，步数用尽但目标未完成则失败。

游戏中有多种特殊消除方式：四个同色连成一线产生条纹方块（消除整行/列）、五个同色连成一线产生彩虹球（消除棋盘上所有同色方块）、L/T 型匹配产生炸弹（消除 3x3 范围）。多个特殊方块交换会触发更强大的组合效果，如彩虹球+炸弹 = 消除所有同色方块并将其转化为特殊方块。

## 核心循环

消除方块完成关卡目标 → 获得星星 → 用星星修复城堡房间和装饰 → 新装饰解锁新关卡区域 → 继续消除

## 核心机制

- **无广告纯净体验**：游戏不插入插屏广告或激励视频，所有收入来自内购道具。这消除了传统三消游戏中"看广告续命"的打断感。为什么有效：玩家沉浸在解谜节奏中不会被打断，提升了整体体验质量，也是它从众多三消竞品中脱颖而出的核心差异点。
- **国王任务系统**：在棋盘消除之外，设有独立的小游戏任务（如"在限定时间内找到隐藏物品""旋转齿轮配对"）。完成国王任务获得额外道具奖励。为什么有效：它提供了三消之外的变化节奏，在连续卡关时给玩家一条额外的进度路径，减少挫败感。
- **竞技场（Team Competition）**：玩家加入队伍，与其他队伍的消除总量进行周排名竞赛。每周结算后根据排名获得奖励。为什么有效：它将个人解谜行为转化为集体贡献，制造"我不能拖队伍后腿"的责任感和竞争驱动力。
- **关卡难度曲线**：游戏关卡设计遵循"简单入门 → 逐渐增加障碍类型 → 引入新机制 → 制造卡关点 → 提供付费道具解决方案"的节奏。为什么有效：它让玩家在"我能行"和"差一步"之间反复摇摆，这是三消游戏留存的核心心理机制。

## 为什么好玩

Royal Match 的操作手感极其顺滑——方块交换动画、消除特效、连锁反应都经过精心打磨，让每次消除都有"啪"的爽快感。没有广告的打扰让玩家可以连续沉浸，而城堡修复的视觉反馈给抽象的数字分数一个具体的"家园"载体。

## 粘性来源

- **城堡修复进度**：每次过关都能看到城堡多修好一块，视觉上的"建设感"是抽象分数之外的具象动力
- **竞技场社交**：团队排名制造"不想让队友失望"的责任感和竞争意识
- **每日奖励**：连续登录奖励递增，断签则重置，利用损失厌恶维持活跃
- **"差一步"效应**：关卡经常在第 24/25 步时让玩家差一个消除就能过关，促使使用付费道具或再来一局

## Meta 系统

**城堡装饰系统**：
- 玩家使用过关获得的星星解锁和装饰城堡中的各个房间和区域
- 每个装饰项目有明确的星星成本，玩家可选择装饰顺序
- 装饰完成后永久展示在城堡视图中，形成个人化的"成就展示"
- 对核心玩法的影响：纯外观奖励，不影响棋盘消除的难度或机制，但提供长期的视觉进度反馈

## 实现难度

中 — 三消核心算法（匹配检测、消除判定、连锁反应、特殊方块生成）是成熟的技术。难度在于**关卡设计平衡和手感调校**：数百个关卡需要逐一调整目标、步数限制和障碍布局，确保"有挑战但可通关"的精细平衡。此外，消除动画的帧时间、下落物理的流畅度、特效的层次感都需要大量打磨才能达到 Royal Match 级别的"丝滑感"。
