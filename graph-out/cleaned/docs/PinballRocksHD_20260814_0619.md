# Pinball Rocks HD

- **类型**: 弹球 / 街机
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2012
- **一句话描述**: 一款摇滚主题的HD弹球游戏，将经典弹球台玩法与摇滚音乐和视觉元素结合

## 玩法规则

游戏呈现一个垂直视角的弹球台，台面上有多个弹射目标、bumper（圆形碰撞器）和得分区域。HD画质让所有元素清晰可见，视觉反馈丰富。

玩家通过点击屏幕左右两侧来触发对应的弹球拨杆（flipper）。左侧按钮控制左拨杆，右侧控制右拨杆。拨杆将弹球弹回台面，防止球从底部掉落。弹射时机需要精准判断。

台面上有各种得分目标：bumper被弹球击中时弹开球并给予分数，ramp（坡道）引导球到达台面特定区域触发特殊模式，target（目标板）被击中后计分并可能改变台面状态（如点亮得分倍率灯）。

弹球从底部掉落失去一条命，通常游戏有3条命。通过击中特定目标链可以触发多球模式（Multiball），台面上同时出现2-3个球，得分倍增。特殊模式下还有额外的限时高分机会。

游戏包含多个不同风格的弹球台，每个台面有独特的目标布局、特殊规则和环境音效。部分台面与特定摇滚乐队合作，带有乐队标志性元素。

## 核心循环

操控拨杆保持弹球在台面 → 击中各种目标获得分数 → 触发特殊模式和多球

## 核心机制

- **拨杆操控**：精准的时机判断，左/右拨杆配合使用控制弹球轨迹
- **多球模式**：达成条件后台面出现多个弹球，得分倍增但操控难度陡增
- **特殊模式**：完成台面目标链后触发限时模式，获得高分奖励

- **乐队合作台面**：每个合作台面有独特的音乐曲目和视觉主题

## 为什么好玩

弹球的物理随机性配合摇滚音乐的节奏感，让每局都有独特体验。多球模式爆发得分的爽快感极强。

## 粘性来源

弹球本身的物理不可预测性是核心粘性——每局都不同，总想刷新个人最高分。多球模式的刺激体验让人不断重开。

## Meta 系统

无。纯街机弹球体验。

## 实现难度

低 — 两个按钮即可操作。最大技术难点是流畅的弹球物理模拟和碰撞检测。
