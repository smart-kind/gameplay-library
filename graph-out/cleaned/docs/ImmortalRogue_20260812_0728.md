# 不朽流氓 (Immortal Rogue)

- **类型**: Roguelike / 动作 / 时间循环
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Kyle Barrett
- **首次发布**: 2018
- **一句话描述**: 扮演一个被困在时间循环中的不朽者，每个时代以不同身份重生，在程序生成的地牢中战斗、收集、成长

## 玩法规则

游戏画面为俯视角的动作场景，玩家操控角色在程序生成的地牢中战斗。每个"时代"（轮回）玩家扮演不同的角色，拥有不同的起始武器和能力。

战斗是实时的——玩家移动、攻击、使用技能和物品。敌人有各自的AI行为模式，需要不同的策略应对。消灭敌人获得经验和金币。

每次轮回（时代）有独特的主题和敌人类型。例如中世纪时代有骑士和法师，未来时代有机器人和外星生物。每个时代的环境、音乐和敌人设计都不同。

轮回之间，玩家获得永恒点数，用于解锁永久升级和新角色。这些升级在所有轮回中生效，帮助玩家逐步变强。

## 核心循环

进入时代 → 探索地牢 → 战斗获取金币和经验 → 收集物品 → 完成时代目标 → 获得永恒点数 → 解锁升级 → 进入下一个时代

## 核心机制

- **时代系统**：每个时代（轮回）有独特的主题、敌人、Boss和奖励。时代顺序部分随机，保证每次游戏体验不同。
- **角色多样性**：每个时代玩家扮演不同角色，各有独特的武器和能力。例如武士时代的角色使用刀剑，法师时代的角色使用魔法。
- **永久升级**：永恒点数用于解锁永久升级，包括新角色、新武器、属性提升等。这些升级跨越所有时代，形成渐进式成长。
- **时间循环叙事**：游戏有隐含的叙事——主角为什么被困在时间循环中？随着游戏进展，线索逐渐浮现。

## 为什么好玩

时代主题的变化让游戏保持新鲜感——从中世纪到未来，每个时代都有独特的战斗体验。永久升级系统确保即使失败也有进展。

音乐和美术随时代变化而切换，从中世纪的鲁特琴到未来时代的电子音效，每个时代都有独特的氛围。这种视听上的变化大大增强了时间循环的主题感，让"重生"不仅仅是游戏机制的变化，更是完整的世界观切换。

## 粘性来源

永久升级的渐进式成长是最强驱动力。每个新解锁的角色带来全新的玩法体验。时代之间的变化也保证了重复游玩的新鲜感。

## Meta 系统

永恒点数解锁系统：解锁新角色、武器和能力。叙事线索收集：随着游戏进展，逐步揭示时间循环的真相。

## 实现难度

中等。俯视角动作战斗的技术门槛不高，但多个时代的差异化设计（不同的敌人AI、环境、Boss）需要大量内容制作。永久升级系统的数值平衡也需要精心设计。
