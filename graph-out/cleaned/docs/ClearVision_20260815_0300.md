# 火柴人狙击手（Clear Vision）

- **类型**: 狙击射击 / 益智 / 弹道计算
- **平台**: Web (Flash) / Mobile (iOS+Android)
- **开发商**: Brandy Kamins / Adult Swim Games
- **首次发布**: 2008 (Flash原版)
- **一句话描述**: 扮演火柴人狙击手，根据风力、距离、移动速度计算弹道，精准击杀目标的回合制射击游戏。

## 玩法规则

游戏采用静态狙击镜视角，画面中心是十字准星。玩家需要在每个关卡中击杀指定数量的目标。操作方式为：鼠标瞄准、调整焦距、计算弹道、扣动扳机。

每发子弹射出前，玩家需要考虑三个关键因素：距离（目标远近影响子弹下坠幅度）、风力（风向和风速会偏移子弹轨迹）、目标移动速度（移动目标需要预判提前量）。游戏界面上会显示当前风力和距离数据，玩家需要根据这些数据手动调整准星位置。

瞄准过程包括：先通过滚轮或按键调整焦距看清目标，然后估算子弹偏移量，将准星移到目标偏移方向的反侧（例如有右风时准星要偏左），最后扣动扳机。一发命中的快感极强，打偏则可能惊动目标导致任务失败。

部分关卡有特殊要求——需要在特定时间内完成、不能误伤无辜、需要按特定顺序击杀目标等。关卡场景包括屋顶、仓库、街道、室内等多种环境，每个场景中的障碍物和掩体布局不同。

## 核心循环

接任务 → 观察场景分析目标 → 计算弹道精准击杀 → 获得报酬 → 接更难任务

## 核心机制

- **弹道物理计算**：距离越远子弹下坠越大，风力越强偏移越大，需要手动估算补偿量
- **风速指示器**：界面上有风力箭头显示当前风向和强度，是计算的核心依据
- **一发必杀**：通常只有一发子弹的机会，打偏即失败，制造极强的紧张感
- **目标行为模式**：每个目标有固定的移动路径和行为规律，观察并记忆是关键
- **场景解谜**：某些目标需要先清除障碍或击杀保护者才能攻击到

## 为什么好玩

Clear Vision将"狙击手"的紧张感完美还原——你只有一次机会，需要冷静观察、精确计算、果断扣扳机。当子弹穿过屏幕、精准命中目标的那一刻，满足感爆棚。游戏不需要快速反应，而是考验观察力和计算能力，是一种"慢节奏的刺激"。火柴人的简洁画风反而让注意力集中在弹道计算上。

## 粘性来源

- **精准命中的成就感**：一发入魂的快感是核心驱动力
- **难度递增**：从静态目标到移动目标，从无风到大风，挑战不断升级
- **解谜元素**：某些关卡需要找出正确的击杀顺序或找到隐藏目标
- **时间挑战**：部分关卡需要在倒计时内完成，增加紧迫感

## Meta 系统

任务/关卡解锁系统——完成一个关卡解锁下一个，部分版本包含武器升级系统（更高倍率瞄准镜、消音器等）。

## 实现难度

低 — 2D静态场景+弹道物理计算，技术门槛较低。最大难点在于弹道物理的准确性——需要让玩家感受到"计算正确就能命中"的公平性，而不是随机性。关卡设计和目标行为模式的多样化是内容制作重点。
