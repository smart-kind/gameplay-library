# 合并旅馆（Merge Inn - Tasty Match Puzzle）

- **类型**: 合并益智 / 烹饪 / 模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: Original Games Pte. Ltd.
- **首次发布**: 2021
- **一句话描述**: 一款融合合并和烹饪元素的益智游戏，玩家通过合并食物食材来完成顾客订单，升级厨房设备，将破旧小餐厅打造成梦幻咖啡馆。

## 玩法规则

游戏画面中央是合并棋盘（类似一个工作台面），上方显示顾客订单和所需食物，下方是玩家的食物库存区域。玩家从库存中拖拽相同的食物到棋盘上进行合并。

两个相同的食物合并后会变成更高级的食物（例如两个面包合并为三明治，两个三明治合并为套餐）。每次合并都会推进顾客的订单进度。

当顾客所需的食物合并完成后，玩家点击"服务"按钮将食物上给顾客。完成订单获得金币和经验值，用于解锁新的食物种类和升级厨房设备。

厨房设备升级后，可以制作更高级的食物品类。例如解锁寿司线后，可以合并生成寿司相关食物；解锁披萨烤炉后，可以制作披萨系列。

## 核心循环

拖拽合并食物 → 完成顾客订单 → 获得金币 → 升级厨房/解锁新食物 → 服务更多顾客

## 核心机制

- **无卡关合并系统**：与传统三消游戏不同，Merge Inn的每次移动都向目标推进，不会因为解不开关卡而无法继续。这消除了传统消除游戏的挫败感，提供了持续的正向反馈。
- **厨房升级系统**：通过游戏进程解锁新的厨房设备和食物制作线。寿司、披萨、海鲜市场等不同烹饪线提供了多样化的合并内容和视觉反馈。
- **订单驱动玩法**：顾客订单是游戏进度的驱动力。每个订单指定了需要完成的食物组合，玩家围绕订单需求进行合并操作，目标明确。
- **收集系统**：游戏包含大量可收集的食物物品和厨房装饰。完成每个章节和支线任务可以解锁隐藏的收藏品，满足收集爱好者的需求。

## 为什么好玩

合并食物的过程本身就有满足感——看着简单食材一步步变成精致的料理，视觉上很有成就感。没有卡关的设计让游戏保持轻松愉快的节奏，适合想要放松的玩家。厨房从破旧到豪华的渐进式改造也提供了持续的视觉激励。

## 粘性来源

收集系统是核心粘性来源——每种新食物的首次合成、每个厨房设备的解锁都是一次小的成就感爆发。顾客订单的完成节奏（"再做一单就解锁新的"）让玩家很难停下来。季节性活动和限时活动也提供了回归动力。

## Meta 系统

游戏包含章节系统和限时活动。主线章节推进解锁新的厨房区域和故事内容，限时活动提供特殊食物和装饰。厨房装修系统允许玩家自定义餐厅外观和布局。无付费卡点，所有内容可通过正常游玩解锁。

## 实现难度

中。合并逻辑本身简单，但大量食物种类的组合关系管理和视觉呈现是工作量较大的部分。最大的技术难点在于合并棋盘的状态管理和自动补货逻辑——需要确保玩家始终有足够的食物可以合并，同时保持游戏的挑战性。
