# 数织：画图数独（Nonogram: Picture Cross Sudoku）

- **类型**: 逻辑解谜 / 数织
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 2019
- **一句话描述**: 通过数字线索推理出隐藏的像素画——1000+数织谜题，锻炼逻辑思维和专注力

## 玩法规则

数织（Nonogram/Picross）是一种经典的逻辑数字谜题。游戏界面呈现一个网格（如10×10、15×15或更大），网格的上方和左侧各有一组数字线索。

每组数字表示该行/列中**连续填充方块**的长度。例如，一行左侧的数字是"3 2"，意味着该行有一组连续3个被填充的方块，然后至少一个空格，然后是连续2个被填充的方块。玩家的任务是根据所有行和列的数字线索，推理出哪些格子应该填充、哪些应该留空。

玩家的操作是点击格子——点击填充（涂黑）、再次点击标记为空（打叉）、第三次点击恢复未确定状态。当所有格子都被正确标记时，一幅隐藏的像素画就会显现出来。

## 核心循环

分析数字线索 → 推理确定格子状态 → 填充或排除 → 获得新线索 → 逐步揭开隐藏画面

## 核心机制

- **逻辑推理机制**：不是猜测，而是纯逻辑推理——每个格子都可以通过线索100%确定
- **交叉验证**：行线索和列线索相互制约，确定一行后会影响列的推理
- **逐步揭示**：每确定一个格子都可能触发连锁反应，让其他格子也变得可推理
- **像素画奖励**：完成谜题后显现的像素画是一种视觉奖励
- **难度递进**：从简单的小网格到大网格，从少线索到多线索

## 为什么好玩

解开一个数织谜题的满足感极强——从完全不确定到全部清晰的转变过程非常享受。每完成一道题都能看到一幅隐藏的像素画，视觉反馈直接。纯逻辑推理没有运气成分，适合喜欢思考的玩家。

## 粘性来源

**解谜完成感**：每次完整揭开一幅像素画都是一次小胜利。**逻辑推理的乐趣**：找到关键突破口时的"顿悟时刻"令人上瘾。**数量驱动**：1000+谜题提供了长期的游玩内容。

## Meta 系统

无复杂外围系统，主要是：
- **关卡选择**：按难度分类的谜题库
- **进度追踪**：记录已完成的谜题数量
- 对核心玩法的影响：保持纯粹的解谜体验，没有外围系统干扰

## 实现难度

低。数织谜题的逻辑引擎不复杂，核心是验证玩家答案是否正确。最大难点在于谜题内容的生成和验证——需要确保每个谜题有唯一解，且难度梯度合理。
