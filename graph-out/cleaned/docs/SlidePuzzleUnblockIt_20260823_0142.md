# 滑块解谜：挪出去（Slide Puzzle: Unblock It）

- **类型**: 滑块解谜 / 逻辑
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 2011
- **一句话描述**: 经典滑块谜题——在有限的空间内战略性地移动方块，解决越来越难的谜题关卡，锻炼问题解决能力

## 玩法规则

游戏界面是一个方形或长方形的棋盘，内部放置了不同大小和方向的方块。其中有一个特殊的"目标方块"（通常用颜色或标记区分），玩家需要通过移动其他方块，为目标方块让出一条通往出口的路径。

操作方式：手指按住一个方块，沿其滑动方向拖动。方块只能沿其纹理方向移动（水平条纹的方块只能左右滑动，垂直条纹的只能上下滑动），移动受其他方块和棋盘边界的阻挡。

每个关卡的棋盘大小、方块数量和布局都不同。简单关卡可能只有5-6个方块，几步就能解决；困难关卡可能有15+个方块，需要几十步的精心规划。游戏的目标是用最少的步数将目标方块移到出口。

## 核心循环

观察棋盘布局 → 规划移动顺序 → 拖拽方块 → 检查目标方块位置 → 继续移动直到目标方块到达出口

## 核心机制

- **受限移动**：每个方块只能沿固定方向滑动，这限制了移动的可能性
- **连锁移动**：移动一个方块可能为另一个方块让路，形成连锁反应
- **步数优化**：虽然目标是通过，但用最少步数完成是进阶追求
- **空间推理**：需要在脑中预判多步之后的局面，考验空间思维能力
- **关卡多样性**：不同棋盘形状、不同方块组合、不同出口位置

## 为什么好玩

看似简单的规则下隐藏着深度的策略思考。每个关卡都是一个新的逻辑挑战，找到解决方案时的满足感很强。游戏节奏可以很快（简单关卡）也可以很慢（困难关卡需要深思），适应不同场景。

## 粘性来源

**解谜满足感**：每次找到正确移动序列都是一次小胜利。**难度递进**：从几步就能解决的简单关卡到需要精心规划的复杂关卡，保持了持续的挑战。**"再来一关"**心理：每关只需几分钟，很容易"就再玩一关"。

## Meta 系统

外围成长系统：
- **关卡解锁**：完成一定数量后解锁新关卡包
- **提示系统**：卡住时可以使用提示查看下一步
- **星级评价**：根据步数给予星级评定
- 对核心玩法的影响：保持纯粹的解谜体验，外围系统主要是进度管理

## 实现难度

低。核心是移动逻辑和碰撞检测，实现不复杂。关卡数据的存储和读取也很简单。最大难点在于关卡设计——需要确保每个关卡有解，且解法有趣不无聊，人工设计和测试工作量大。
