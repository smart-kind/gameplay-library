# Block Jam Out (方块消除解压)

- **类型**: 休闲益智 / 方块消除
- **平台**: Mobile (iOS+Android)
- **开发商**: PLAY2EVER GAMES LIMITED
- **首次发布**: 2024
- **一句话描述**: 一款3D方块消除解谜游戏，通过三消机制清除多层堆叠的方块

## 玩法规则

游戏界面展示一个3D方块堆叠平台，上面有多层彩色方块。底部有一个存放栏（通常7个槽位），中间是正在消除的方块。

操作：点击任意可见方块，它落入底部存放栏。存放栏中如果有3个相同颜色的方块，它们自动消除并空出槽位。如果存放栏满了（7个槽位全满）且没有3个相同颜色，游戏失败。

方块是分层的，上层方块遮挡下层方块。玩家需要先点击消除上层方块，才能触及下层方块。部分方块被锁定（需要消除旁边方块才能解锁）或被冰冻（需要点击两次）。

游戏目标是清除所有方块。每关有特定方块布局，需要思考消除顺序。没有倒计时，可以慢慢规划。消除所有方块即过关。

高级关卡中，方块数量可达数百个，层级深度超过5层，颜色种类多达6种。这种复杂度要求玩家在每一步操作前都思考后续3到5步的连锁反应，否则很容易在存放栏中卡死。

## 核心循环

点击方块落入存放栏 -> 凑齐3个同色方块消除 -> 清除所有方块过关

## 核心机制

- **三消加层级遮挡**：经典三消机制与多层方块堆叠结合，需要规划消除顺序
- **有限存放栏**：7个槽位的硬约束制造紧迫感，需要精确计算消除顺序
- **锁定和冰冻方块**：特殊方块类型增加策略维度，需要先解再消除
- **多层级深度**：超过5层的堆叠和6种颜色增加复杂度，需要预判连锁反应

## 为什么好玩

消除3个相同方块时的爽快感让人欲罢不能，多层堆叠让每次消除都像在解一个微型谜题。

## 粘性来源

三消的即时爽感反馈，层级遮挡的策略深度，无时间压力让人随时开一局。每次差一个就消除让人欲罢不能。

## Meta 系统

关卡解锁系统。完成当前关卡解锁下一关，难度逐步递增。部分关卡有广告解锁道具（额外槽位、撤回等）。

## 实现难度

中等 -- 三消加层级遮挡的组合需要精心设计关卡。最大技术难点是确保每关有解的自动验证算法和多层方块的渲染性能。
