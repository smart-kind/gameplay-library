# Limbo

- **类型**: 解谜冒险
- **平台**: Mobile (iOS+Android) / PC / Switch / PlayStation / Xbox
- **开发商**: Playdead
- **首次发布**: 2010
- **一句话描述**: 一个黑白风格的横版解谜冒险游戏，玩家操控一个小男孩在诡异的边境世界中寻找失散的姐姐。

## 玩法规则

游戏画面采用极简的黑白剪影风格，前景是黑色的人物和物体剪影，背景是灰色的雾气。

玩家通过虚拟摇杆控制小男孩左右移动，通过按钮控制跳跃、攀爬和推动物体。操作非常简单，但每个谜题的设计精巧：

- **物理谜题** — 需要推动箱子、木板等物体来搭桥或触发机关
- **环境陷阱** — 蜘蛛、捕兽夹、悬崖、水下区域等，第一次遇到几乎必死，但死亡本身就是学习过程
- **时序谜题** — 需要精确把握时机，比如在摆动的重物下冲过
- **光学谜题** — 利用光线、反射、影子来揭示隐藏的路径

游戏没有文字教程，没有 UI 提示，玩家通过不断试错来理解世界规则。死亡画面（男孩被刺穿、碾碎、淹死）虽然简短但令人印象深刻，强化了游戏的阴暗氛围。

## 核心循环

探索 -> 遇到障碍 -> 试错死亡 -> 理解机制 -> 通过谜题 -> 继续前进

## 核心机制

- 试错学习机制 — 死亡不是惩罚而是教学，玩家通过死亡了解世界规则
- 物理引擎解谜 — 重力、浮力、惯性等真实物理规律作为谜题基础
- 无 UI 沉浸设计 — 没有生命值、没有菜单、没有提示文字，完全的沉浸式体验

## 为什么好玩

独特的黑白剪影美术风格营造出诡异而美丽的氛围；解谜的顿悟时刻带来强烈的满足感；没有任何文字说明却能让玩家理解并投入其中。

## 粘性来源

游戏流程约 3-4 小时，是一次性体验。吸引力来自美术风格和氛围而非重复游玩。但想看看后面还有什幺的好奇心驱动玩家一口气通关。

## Meta 系统

无 — 这是一个线性的、一次通关即结束的体验，没有外围系统。

## 实现难度

中 — 操作上只需要移动和跳跃，但谜题设计需要逻辑推理和空间想象。最大技术难点在于精心设计的关卡节奏，太难会挫败，太简单会无聊。
