# Railbot（Railbot）

- **类型**: 解谜 / 物流 / 益智
- **平台**: Mobile (iOS+Android) / PC (Steam)
- **开发商**: Zachtronics
- **首次发布**: 2016
- **一句话描述**: 设计铁路网络让小机器人运送货物到达正确目的地的物流解谜游戏。

## 玩法规则

游戏画面呈现一个俯视的网格地图，地图上有货物生成点（工厂）、目的地（仓库）和若干可放置轨道的位置。玩家需要在空白网格上铺设轨道，将货物从起点运送到正确颜色的目的地。

玩家通过点击网格单元格来放置轨道段，轨道段有不同形状（直线、弯道、交叉、道岔）。货物生成后会沿着轨道自动移动，如果轨道通向错误的目的地，货物会被拒绝并造成扣分或失败。

每个关卡有特定数量的货物需要运送，轨道一旦铺设完成就不能更改（部分关卡允许有限修改）。关卡有步数/成本限制，要求玩家用最少的轨道段完成任务。

货物以不同的颜色标识目标仓库，玩家需要在轨道设计阶段就规划好每条路径的终点。高级关卡中，多个货物可能同时运行，需要考虑轨道交叉时的通行优先级问题。

## 核心循环

观察地图布局 → 规划轨道路线 → 铺设轨道 → 运行测试 → 优化方案

## 核心机制

- **路径规划**：玩家需要在有限的空间内设计不交叉、不冲突的轨道路线，每个关卡都是一个新的空间谜题
- **信号系统**：高级关卡引入信号灯和道岔，需要控制货物在不同轨道之间的切换时机
- **成本优化**：不仅要求完成任务，还要求用最少的轨道段和最低的复杂度，鼓励寻找优雅的最优解

## 为什么好玩

将物流网络设计转化为纯粹的逻辑谜题，每解决一个关卡都有"我设计了一个完美系统"的满足感。

## 粘性来源

具体到机制层面：解谜游戏固有的"顿悟时刻"——当你在脑中理清所有路径关系、找到那条最优路线时的智力愉悦感。同时三星级评分系统（步数、时间、复杂度）驱动玩家反复优化已有方案，追求完美。

## Meta 系统

- **关卡解锁**：完成当前关卡解锁下一组
- **排行榜**：以效率和复杂度排名的全球排行榜
- **对核心玩法的影响**：排行榜驱动玩家追求最优解

## 实现难度

中等——轨道系统的逻辑判断（碰撞检测、路径有效性验证、货物运输模拟）需要精确实现。最大的技术难点是自动路径验证算法，需要实时检测轨道网络是否存在死锁、环路或冲突。
