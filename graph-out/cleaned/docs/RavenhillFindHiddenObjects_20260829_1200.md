# 鸦丘镇：寻物探秘（Ravenhill: Find Hidden Objects）

- **类型**: 寻物解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Mytona
- **首次发布**: 2018
- **一句话描述**: 在被阴影笼罩的Ravenhill城中寻找隐藏物品、解开谜题，揭开城市失踪人口的秘密

## 玩法规则

游戏设定在一座神秘的城镇Ravenhill，街道上笼罩着阴影和秘密。画面采用精美的暗黑现实主义风格。

玩家需要在场景中找到指定物品列表中隐藏的项目——有些物品直接可见，有些需要与环境互动（打开门、移动物品）。

找到物品后可以获得线索，推动调查失踪案件的剧情。游戏还包含任务系统，每个区域有独立的任务链。

故事围绕Ravenhill城的失踪事件展开。随着调查深入，玩家发现失踪事件背后隐藏着更大的阴谋。

任务的类型多样——有些是简单的寻物任务，有些需要逻辑推理，有些需要物品组合。

## 核心循环

在城镇场景中寻找隐藏物品 → 收集线索 → 完成调查任务 → 揭开城市秘密和失踪案件真相

## 核心机制

- 调查式寻物：不同于单纯的寻物，每个场景都与调查案件相关。找到的物品都是线索，增强代入感
- 任务系统：每个区域有独立的任务链，完成任务获得奖励和故事推进。任务类型多样
- 环境互动：部分场景需要修复或互动才能解锁新的寻物区域

## 为什么好玩

悬疑的故事情节和暗黑美学营造出独特的侦探体验。

每个场景都像一幅画值得细细品味。

解开谜团的成就感强烈，特别是当所有线索拼凑出真相时。Ravenhill城本身就像一个角色，它的每条街道、每栋建筑都有自己的故事。

## 粘性来源

悬疑故事驱动想知道接下来发生什么的心理。任务系统提供清晰的短期目标

## Meta 系统

任务奖励系统：完成任务获得星星和金币，用于购买提示和解锁新区域

## 实现难度

中等 — 暗黑场景和复杂细节增加寻物难度。最大的技术难点在于在叙事和寻物之间保持平衡
