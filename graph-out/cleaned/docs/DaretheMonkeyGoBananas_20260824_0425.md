# Dare the Monkey: Go Bananas!

- **类型**: 横版跑酷 / 反应平台
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立开发者
- **首次发布**: 2024
- **一句话描述**: 一款以猴子为主角的单指横版跑酷游戏，通过点击控制猴子跑、跳、滚，穿越充满障碍的关卡。

## 玩法规则

玩家控制一只小猴子在自动前进的横版关卡中穿越障碍。关卡自动向前推进，玩家只需要做操作判断。

点击屏幕猴子跳跃，按住更久跳得更高。下滑手势让猴子滑行或滚动通过低矮障碍。某些关卡中双击可以二段跳。

关卡包含多种元素：地面障碍如尖刺陷阱和移动平台，空中障碍如树枝飞镖和摆锤。收集物包括香蕉作为主要货币和宝石作为稀有道具。特殊区域有滑梯、弹跳垫和加速带。

关卡模式有三种：闯关模式是线性关卡逐步解锁，无尽模式随机生成关卡看能跑多远，挑战模式是特殊条件下的限时挑战。

闯关模式有固定生命值，碰到障碍扣血，收集心形道具可以回血，生命归零则关卡失败。无尽模式一次死亡即结束，考验极限操作。

## 核心循环

跑跳滑行 → 收集香蕉 → 避开障碍 → 到达终点或死亡 → 升级重试

## 核心机制

- **按压时长控制跳跃高度**: 不是简单点一下就跳固定高度，而是按住屏幕越久跳得越高。这种可变跳跃机制让玩家精准控制。短按跳过小坑，长按跳过高墙。操作直觉但需要练习才能精准，形成自然技能曲线。

- **滑行通过低矮障碍**: 下滑手势让猴子贴地滑行通过上方障碍物。跳跃和滑行两种操作分别对应两种障碍类型，玩家需要在瞬间判断该跳还是该滑。这种二元决策在高速游戏中制造持续认知挑战。判断错误就撞上了。

- **收集驱动的路径选择**: 香蕉和宝石分布在不同的路径上。安全路径上的收集物少，危险路径上的收集物多。玩家需要在安全通过和冒险收集之间做选择。这种设计让游戏不只是不犯错，还需要主动规划路线。

## 为什么好玩

可爱的猴子角色加上流畅的跑酷动作和丰富的关卡变化，构成经典的横版跑酷乐趣。按压跳跃的手感调得好会非常满足。收集香蕉的过程有种天然的愉悦感。超过200万玩家的验证说明游戏设计的成功。

## 粘性来源

横版跑酷差一点就过的感觉加上香蕉收集的满足感和关卡解锁的目标感，构成经典跑酷循环。无尽模式提供无限重玩价值。角色皮肤解锁提供长期目标。

## Meta 系统

角色皮肤解锁：用香蕉或宝石解锁新的猴子外观和服装。关卡解锁：线性推进。无尽模式高分排行榜。

## 实现难度

低。横版跑酷是成熟品类。核心技术是物理碰撞和关卡生成。主要工作量在关卡设计和美术资源。
