# 回家之路（The Journey Home）

- **类型**: 冒险 / 解谜
- **平台**: Web (HTML5/Unity)
- **开发商**: Raius_
- **首次发布**: 2016
- **一句话描述**: 一名冒险者旅途中偶遇小女孩，两人结伴踏上回家之路的剧情冒险游戏

## 玩法规则

游戏采用横版卷轴视角，玩家控制冒险者在各种场景中行走探索。
点击场景中的交互点可以触发对话、拾取物品或推动剧情。
解谜部分包括寻找隐藏道具、操作机关、与环境互动等。
小女孩作为同伴会在关键时刻提供帮助或触发特殊事件。
每个场景有明确的出口标识，但到达出口需要完成场景中的谜题。
游戏有多个章节，每个章节有不同的场景和故事线。
没有战斗系统，核心体验是探索和叙事。

## 核心循环

探索场景 → 解谜/互动 → 推动剧情 → 进入新场景

## 核心机制

- 叙事驱动探索：通过环境细节和对话推进故事，没有文字量的堆砌而是通过视觉叙事
- 同伴互动系统：小女孩作为AI同伴会在特定情境下自主行动，增加世界的生动感
- 轻量解谜：谜题难度适中，以逻辑推理和环境观察为主，不打断叙事节奏

## 为什么好玩

温馨治愈的冒险故事，美术风格简洁但有辨识度。冒险者与小女孩之间的互动充满温情，让人想起《ICO》式的无声情感表达。每个章节的场景设计都独具匠心。

## 粘性来源

主要粘性来自故事驱动——"想知道接下来发生什么"。作为独立游戏更多是一次性体验，但多结局设计鼓励重玩。

## Meta 系统

无外围成长系统。纯叙事体验，通关即结束。

## 实现难度

低 — 横版点击冒险，最大技术难点是剧情分支管理和AI同伴行为设计

游戏全篇无文字对白，角色之间的情感交流全靠动作和表情传达。
每个场景有独特的色调和音乐主题，从森林到城镇到雪山逐步变化。
隐藏收藏品散落在各个场景中，收集后解锁额外的剧情片段。
游戏时长约2-3小时，节奏舒缓但内容充实。
