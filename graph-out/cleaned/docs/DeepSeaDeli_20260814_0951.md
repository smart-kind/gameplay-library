# 深海熟食店 (Deep Sea Deli)

- **类型**: 连线消除/时间管理
- **平台**: Mobile (iOS+Android)
- **开发商**: 未明确标注
- **首次发布**: 未明确标注
- **一句话描述**: 一款在海底世界中制作三明治订单的连线消除解谜游戏

## 玩法规则

游戏画面呈现一个海底风格的棋盘，棋盘上分布着各种三明治食材（培根、生菜、奶酪、番茄、火腿等）。屏幕底部会显示顾客点的三明治订单，列出需要的食材组合。

玩家需要在棋盘上画一条线，将相同食材连接起来。连接后，这些食材会被选中并用于完成订单。完成一个订单后，新顾客到来，玩家继续连线选取新订单所需的食材，直到棋盘上所有食材被消耗完毕——此时棋盘翻转，进入下一轮。

游戏没有计时器限制，玩家可以慢慢思考。但如果某时刻无法制作出当前订单所需的三明治，玩家可以点击右下角的饥饿吸尘器，它会开始清除棋盘上的食材来推进游戏。

随着游戏推进，会逐渐加入更多食材种类（从基础的培根、生菜、奶酪扩展到番茄、火腿等），增加连线的复杂度和策略性。

## 核心循环

连线选取食材 -> 完成三明治订单 -> 棋盘翻转刷新 -> 获取更高分数

## 核心机制

- 连线消除机制：在棋盘上画线连接相同食材，连得越多效率越高
- 订单驱动系统：屏幕底部显示顾客订单，明确当前目标，引导玩家选择策略
- 无计时器休闲设计：没有时间压力，适合休闲玩家从容思考
- 饥饿吸尘器救援机制：无法完成订单时点击吸尘器清除棋盘食材，避免卡死

- 食材多样性递进：从基础的三种食材逐步扩展到多种食材组合，每次新增食材都显著增加连线策略的复杂度，保持游戏新鲜感

## 为什么好玩

连线操作直观流畅，海底主题和食材搭配营造出轻松愉悦的氛围。完成订单时的满足感来自于从混乱的棋盘中精准找出所需食材组合。

## 粘性来源

分数排行榜驱动重复游玩（每周更新排行榜）。无计时器设计让每次游戏都是纯粹的策略体验而非紧张压力，适合碎片时间反复开局。

## Meta 系统

可使用金币在游戏开始前购买特殊道具，例如清除整个棋盘的能力。金币通过完成订单获得，也可通过Facebook关联获取额外奖励。

## 实现难度

低 — 连线操作简单，无时间限制让难度保持在极低水平。最大技术难点是连线算法的流畅度（支持任意形状连线的触摸判定）。
