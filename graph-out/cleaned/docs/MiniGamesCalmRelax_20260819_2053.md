# 迷你游戏平静与放松（Mini Games: Calm & Relax）

- **类型**: 休闲益智 / 减压游戏
- **平台**: Mobile (iOS+Android)
- **开发商**: Unico Studio
- **首次发布**: 2024
- **一句话描述**: 50+款减压迷你游戏的合集，包含fidget游戏、ASMR风格和放松解谜。

## 玩法规则

游戏启动后，主界面呈现为一个简洁的心情选择面板，提供三种模式：Calm Mode、Relaxed Mode和Energized Mode。每种模式用不同的色彩主题和图标区分，玩家可以直观地根据当前心情选择。

Calm Mode下，游戏展示一系列轻柔的fidget类小游戏。例如Pop It（按压气泡，带有柔和的爆破音效和触觉震动）、挤压玩具（拖拽变形，松手后缓慢回弹）、沙子画布（手指滑动产生流动效果）。这些游戏的操作极为简单，主要是点击、长按、拖拽和滑动。没有失败条件，没有倒计时，没有分数压力，纯粹为了放松。

Relaxed Mode展示解谜和逻辑类小游戏。例如颜色匹配、形状排序、路径规划等。这些游戏有明确的目标和通关条件，但难度曲线平缓，不会让人感到挫败。解谜过程中配有柔和的背景音乐和舒缓的动画效果。

Energized Mode提供快节奏的街机迷你游戏。例如快速反应点击、节奏匹配、限时消除等。这些游戏有得分系统和计时器，适合想要短暂刺激的玩家。操作方式同样是简单的点击和滑动。

每个游戏都有独立的入口页面，页面展示游戏缩略图、简短说明和开始按钮。游戏过程中，界面保持极简风格，没有弹出广告，没有内购提示。

## 核心循环

选择心情模式 -> 玩减压迷你游戏 -> 获得放松感或成就感 -> 尝试新游戏

## 核心机制

- **三模式切换**：根据心情选择Calm、Relaxed或Energized模式，提供不同节奏的游戏体验，满足不同场景需求
- **ASMR触觉反馈**：游戏配合柔和音效和触觉震动，增强放松感，利用手机的触觉引擎创造物理反馈
- **极简设计**：干净的视觉风格、柔和的色彩搭配和可爱图形，减少视觉压力和认知负担
- **50+游戏合集**：一个应用包含所有游戏，不需要分别下载，降低获取门槛

## 为什么好玩

在快节奏生活中提供即时放松。不需要思考复杂策略，只需简单操作就能获得满足感。随时拿起手机就能进入平静状态，是现代人的数字减压工具。

## 粘性来源

减压需求是日常持续的，50+款游戏的多样性确保不会厌倦，ASMR的生理愉悦反馈形成身体记忆。'再玩一局就睡觉'的陷阱让睡前时间不知不觉流逝。

## Meta 系统

无复杂外围系统。主要依赖游戏本身的多样性来维持兴趣。游戏库按主题分类，新游戏会定期添加到合集中。

## 实现难度

低 - 单个迷你游戏逻辑简单，主要是数量堆叠。最大技术难点：50+款不同游戏的开发工作量和ASMR音效的设计（需要精细调校触觉反馈和音频的同步）。
