# Skate Story（滑板故事）

- **类型**: 滑板 / 冒险 / 动作
- **平台**: PC / PS5 / Switch 2 / Windows
- **开发商**: Sam Eng
- **发行商**: Devolver Digital
- **首次发布**: 2025
- **一句话描述**: 不追求"真实感"的超现实滑板游戏，用万花筒般的视觉效果捕捉滑板文化的叛逆精神。

## 玩法规则

游戏采用第三人称视角，玩家操控角色在超现实的滑板世界中滑行。画面风格极其独特——万花筒般的扭曲视觉效果、色彩斑斓的环境、不合常理的物理规则。这不是追求"模拟真实滑板"的游戏，而是用抽象和夸张的手法表达滑板的"感觉"。

玩家的核心操作是滑行和技巧：加速、刹车、跳跃、翻转（Kickflip、Heelflip、360 Flip 等）、滑行栏杆（grind）。但与传统滑板模拟游戏不同，这里的物理规则更加宽容和风格化——重点不是"这个动作在现实中是否可行"，而是"这个动作看起来是否酷"。

关卡设计充满创意：场景可能在天空、水下、扭曲的建筑之间切换，每个区域有独特的视觉主题和挑战。玩家需要在这些环境中完成技巧组合、到达目标地点或解锁新区域。

游戏没有复杂的评分系统，更多关注"滑板的感觉"——流畅的连招、创意的路线选择、视觉上的满足感。

## 核心循环

探索场景 → 发现技巧路线 → 练习和完成连招 → 解锁新区域 → 继续探索

## 核心机制

- **超现实物理**：不追求真实滑板物理，而是用风格化的规则让滑板动作看起来更酷、更有创意。
- **万花筒视觉**：扭曲、色彩斑斓、不合常理的视觉效果是游戏最大的卖点，创造了一种"迷幻滑板"的体验。
- **连招系统**：将不同的滑板技巧组合起来形成连招，流畅的连招带来视觉和成就感的双重满足。
- **场景多样性**：每个区域有独特的视觉主题和挑战，保持探索的新鲜感。

## 为什么好玩

Skate Story 的魅力在于它"不在乎真实性"的态度。大多数滑板游戏都在追求"像真的一样"，但这款游戏反其道而行——它用超现实的视觉效果和风格化的物理规则，捕捉了滑板文化最核心的精神：反叛、创造力和自由表达。

## 粘性来源

- **创意表达的自由**：玩家可以用滑板做各种现实中做不到的动作，这种创意自由让人上瘾。
- **视觉满足感**：万花筒般的视觉效果让每次滑行都像在欣赏一件艺术品。
- **连招的流畅感**：成功完成一套复杂的连招会带来强烈的成就感。

## Meta 系统

无明显的 Meta 系统。游戏专注于纯粹的滑板和探索体验。

## 实现难度

**高**。最大技术难点：1）超现实视觉效果的渲染——万花筒扭曲、色彩变换等需要自定义渲染管线；2）风格化物理系统——需要在"不真实"和"可玩"之间找到平衡；3）场景设计的工作量巨大——每个区域需要独特的视觉主题和关卡布局。独立开发者 Sam Eng 与 Devolver Digital 合作，获得了必要的资源支持。
