# 史酷比恐怖奔跑（Scooby Doo Creepy Run）

- **类型**: 跑酷 / 休闲
- **平台**: Web (Flash)
- **开发商**: funnychasegames
- **首次发布**: 2013
- **一句话描述**: 帮助Shaggy在墓地中躲避幽灵追逐的横版跑酷小游戏

## 玩法规则

Shaggy在墓地中自动向右奔跑，玩家需要控制他跳跃躲避障碍物。
障碍物包括墓碑、坑洞、木桶等，碰到障碍物会被身后的幽灵追上。
点击屏幕（或按空格键）让Shaggy跳跃，长按可以跳得更高。
途中可以收集三明治等道具获得额外分数。
幽灵始终在身后追赶，碰到障碍物减速后被幽灵追上则游戏结束。
随着奔跑距离增加，障碍物频率和速度逐渐提高。
史酷比系列的角色和场景为游戏增添了经典的卡通氛围。

## 核心循环

奔跑 → 跳跃躲避障碍 → 收集道具 → 速度越来越快 → 追求更远距离

## 核心机制

- 幽灵追赶机制：幽灵始终在身后，障碍物不是直接导致死亡而是减速让幽灵追上，增加了心理压力
- 简单单键操作：只需跳跃一个操作，但时机判断需要精准
- 渐进加速：障碍物出现频率和奔跑速度同步提升，后期几乎需要肌肉记忆

## 为什么好玩

经典IP加持让游戏有天然的亲和力。Shaggy胆小怕事却被迫狂奔的设定很有喜剧效果。障碍物设计融入了墓地元素（墓碑、鬼火、骷髅）增强了氛围感。

## 粘性来源

作为休闲小游戏，主要粘性来自IP粉丝和"差一点就跑更远"的不甘心。单局时间短适合碎片化游玩。

## Meta 系统

无。纯分数驱动的跑酷游戏。

## 实现难度

低 — 标准横版跑酷框架，最大技术难点是障碍物生成的节奏控制

障碍物分为地面障碍（墓碑、树桩）和空中障碍（蝙蝠、蜘蛛网），需要不同的跳跃时机。
三明治收集品有三种类型：普通（+10分）、大份（+25分）、史酷比特供（+50分+短暂无敌）。
幽灵追赶时有距离指示器，距离越近屏幕边缘越红，增加紧迫感。
场景会随距离推进从墓地入口深入到墓地内部再到废弃古堡，视觉层次丰富。
