# Idle Miner Tycoon（Idle Miner Tycoon）

- **类型**: 放置经营 / 点击增量（Idle/Incremental）
- **平台**: Mobile (iOS+Android)
- **开发商**: Kolibri Games
- **首次发布**: 2017
- **一句话描述**: 管理一座不断深挖的矿井，升级设备、雇佣经理，让钱自动滚雪球

## 玩法规则

画面是竖屏 2D 横截面，展示一座多层的矿井。每一层有矿工（小人）、电梯（把矿石运到地面）、仓库（在地面出售矿石获得现金）。

玩家初始只有一层矿井和一个矿工。操作是点击矿工让他挖矿，点击电梯让他运矿，点击仓库让他卖矿换钱。

当赚够第一桶金后，可以：（1）购买第二个矿工；（2）升级挖矿速度；（3）升级电梯速度；（4）升级仓库容量。每一级升级都需要更多钱，价格指数增长。

解锁新矿井层后，每层是独立的"子系统"，有自己的矿工、电梯、升级链。地面层也有独立的升级链（更好的卡车卖更多钱）。

雇佣"经理"后，对应的角色（矿工/电梯司机/仓库管理员）会自动工作，不再需要手动点击——这就是"Idle"的含义。

## 核心循环

手动点击赚钱 → 升级设备 → 解锁新矿井层 → 雇佣经理自动化 → 离线也赚钱 → 上线后收获一大笔 → 继续升级

## 核心机制

- 机制1：多层递进式升级——每一层矿井有独立的升级链（矿工速度、电梯速度、仓库容量），形成嵌套的决策空间：先升哪层？先升级矿工还是电梯？
- 机制2：经理自动化——每个经理永久绑定一个岗位，雇佣后该岗位完全自动运行。经理本身需要"超能力"升级（加速、双倍产出等），形成次级养成线
- 机制3：离线收益——关闭游戏后，经理继续工作，下次上线时获得离线期间积累的收益。这是"放置类游戏"的核心粘性来源——玩家感觉"即使不在玩也在进步"

## 为什么好玩

看着数字从 10 变成 100、1000、100 万、1 亿——这种"数字膨胀"带来的满足感是人类大脑很难抵抗的。同时，每一层新矿井的解锁都带来短暂的"重新开始"的新鲜感，避免了单调。

## 粘性来源

数值成长（数字膨胀的快感）+ 被动收益（离线也在赚钱，上线有惊喜）+ 解锁新矿井的目标驱动（"再挖一层就能解锁新东西"）+ Prestige/重置系统

## Meta 系统

Prestige（重置）系统——达到某个条件后可以"重置"整个游戏进度，但获得永久性的全局乘数（所有产出 x2、x4 等）。重置后重新开始，但速度远快于第一次。这是放置游戏的核心长线驱动。此外还有皮肤、活动等。

## 实现难度

低。核心是数值系统和 UI 展示。不需要物理引擎、AI、复杂的碰撞检测。最大的工作量是平衡数值曲线——让升级价格、产出增长、解锁节奏形成一个"永远觉得差一点"的正反馈循环。技术上用简单的计时器和数值乘数即可实现。
