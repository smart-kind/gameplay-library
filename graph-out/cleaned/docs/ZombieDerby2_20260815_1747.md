# 僵尸赛车2（Zombie Derby 2）

- **类型**: 竞速 / 动作
- **平台**: Web (HTML5) / Mobile
- **开发商**: BrineMedia
- **首次发布**: 2017
- **一句话描述**: 驾驶改装汽车在僵尸群中横冲直撞的3D末日竞速游戏

## 玩法规则

玩家选择一辆改装汽车，在僵尸横行的赛道上高速行驶。
车辆自动前进，玩家通过左右转向和加速/刹车来控制方向。
撞飞沿途的僵尸获得金币，不同类型的僵尸分值不同。
金币用于升级车辆：速度、耐久度、武器（机枪、火焰喷射器等）。
赛道上有障碍物（废弃车辆、路障、油桶），撞上会减速或损坏车辆。
有多种游戏模式：无尽模式（直到车辆损毁）、任务模式（完成特定目标）、PVP模式（与好友比较分数）。
8辆不同特性的车辆可选，包括独特的僵尸联合收割机。

## 核心循环

驾驶撞僵尸 → 收集金币 → 升级车辆/解锁新车 → 在更远的赛道上撞更多僵尸

## 核心机制

- 车辆升级系统：速度、装甲、武器三个维度升级，每次升级直接影响下一次的表现
- 3D物理碰撞：僵尸被撞击后的飞散效果提供爽快的视觉反馈
- 多模式竞争：无尽模式+PVP模式让玩家既有个人目标又有社交竞争

## 为什么好玩

在僵尸群中横冲直撞的爽快感是核心体验。3D画面下僵尸飞散的夸张物理效果配合重金属BGM，营造出末日狂欢的氛围。每解锁一辆新车都有全新的驾驶手感。

## 粘性来源

车辆升级提供清晰的目标感。"再跑一次就能买新武器了"的想法驱动持续游玩。PVP排行榜增加了与他人比较的竞争欲。

## Meta 系统

完整的车辆升级系统（速度/装甲/武器）+ 多车辆解锁（8辆各有特色）+ 无尽模式排行榜。

## 实现难度

中 — 3D渲染+物理碰撞+车辆操控是技术难点，移动端优化尤其关键

武器系统包括车载机枪（自动射击）、火焰喷射器（范围伤害）、电磁脉冲（瘫痪僵尸）。
赛道环境从城市废墟到沙漠公路到隧道，每种环境有不同障碍物组合。
车辆损毁时有详细的破坏动画，引擎冒烟、车门脱落等细节丰富。
PVP模式下可以和好友的录像 ghost 同场竞技，比拼谁撞得更远。
