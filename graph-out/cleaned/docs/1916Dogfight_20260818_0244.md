# 1916 Dogfight（1916 Dogfight）

- **类型**: 飞行模拟/空战
- **平台**: Mobile (iOS)
- **开发商**: 待确认
- **首次发布**: 2010
- **一句话描述**: 一战背景的空战模拟游戏，驾驶早期战斗机进行空中格斗

## 玩法规则

游戏采用3D渲染的飞行视角。玩家驾驶一战时期的战斗机在天空中执行任务。

**操作方式**：
- 键盘数字键4和6控制飞机左右转向
- 键盘数字键2和8控制飞机上下升降
- 无法翻滚（roll），转弯半径较大
- 投弹需要从驾驶舱一侧将炸弹扔下

**核心玩法**：
- 飞行训练关卡：穿越空中圆环练习飞行技巧
- 空中格斗：与其他战斗机进行空战
- 轰炸任务：向地面目标投掷炸弹
- 多人对战：支持最多6名玩家通过蓝牙联机空战
- 可以添加CPU控制的AI作为敌人或盟友

**胜利/结束条件**：
- 任务成功：击落敌机或完成轰炸目标
- 训练通过：成功穿越所有指定圆环
- 多人模式：击落数最多的玩家获胜

## 核心循环

起飞 → 执行任务（训练/格斗/轰炸） → 完成任务 → 解锁新任务/多人对战

## 核心机制

- **一战飞行物理**：飞机操控笨拙，转弯半径大，符合历史真实感
- **无翻滚系统**：无法执行翻滚动作，增加操作难度
- **手动投弹**：从驾驶舱一侧扔炸弹，需要精确判断时机
- **多人联机**：支持最多6人蓝牙联机，可加入CPU AI
- **3D渲染**：飞机模型采用流畅3D渲染，环境较为简洁

## 为什么好玩

一战空战的原始感和笨拙操作反而成为一种独特体验。虽然训练关卡令人沮丧，但实际空战和轰炸任务充满挑战性。多人对战是游戏最大的亮点，6人空中混战带来刺激体验。

## 粘性来源

- **多人对战**：6人蓝牙联机的空中混战是核心吸引力
- **历史代入感**：一战飞行员的真实体验
- **技术挑战**：掌握笨拙操控后的成就感
- **AI对战**：可以添加CPU作为盟友或敌人增加变数

## Meta 系统

无 — 游戏以关卡和多人对战为主，无外围成长系统。

## 实现难度

中 — 飞行物理模拟需要一定技术功底，主要技术难点在于飞机操控手感的调校和3D空战场景的性能优化。
