# 跑酷射击（RunnGun）

- **类型**: 跑酷射击
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer 收录独立游戏
- **首次发布**: 2013
- **一句话描述**: 一款结合跑酷和射击元素的动作游戏，在奔跑中同时战斗

## 玩法规则

游戏采用横版卷轴视角，角色自动向右方奔跑，背景不断向后滚动。画面风格通常是卡通或像素风，场景主题多样（城市、丛林、太空等）。

玩家需要进行两类操作：
1. 移动操作：上滑跳跃（可以连跳）、下滑滑行或下蹲。用于躲避地面上的障碍、躲避上方的障碍、或跳到更高的平台。
2. 射击操作：点击屏幕向角色面向的方向射击。部分版本支持滑动瞄准，可以向上或向下调整射击角度。

场景中会不断出现各种敌人，有些会向玩家发射子弹，有些会直接冲撞。玩家需要同时躲避障碍和敌人的攻击，同时消灭前方的敌人。场景中还散布着各种道具：武器升级（提升射速、伤害、散射等）、生命值恢复、护盾、分数加倍等。

游戏通常采用无尽模式，跑的距离越远分数越高。也有部分版本提供关卡模式，有明确的终点和Boss战。

角色死亡后游戏结束，显示本次跑动距离、消灭敌人数、收集道具数等统计数据。可以通过收集的货币解锁新角色或武器。

## 核心循环

自动奔跑 → 跳跃躲避障碍 → 射击敌人 → 收集道具强化 → 追求更远的距离和更高的分数

## 核心机制

- **自动跑酷系统：角色自动前进，玩家专注于躲避和射击操作。不同地形（平台、陷阱、间隙）需要不同的应对策略**
- **双任务处理机制：同时处理移动（跳跃/滑行）和射击两个维度的操作，考验玩家的多任务处理能力**
- **武器升级系统：收集的道具可以临时或永久提升武器性能，包括射速、伤害、散射范围、特殊效果等**
- **随机生成机制：每次游戏的障碍和敌人布局不同，确保每局都是新的挑战，防止背板**

## 为什么好玩

跑酷的紧张感和射击的爽快感结合，需要同时处理多个任务，带来高度集中的心流体验。每次死亡后的'再来一局'冲动很强。

## 粘性来源

无尽模式的分数竞争和每次不同的随机生成，追求更高分的驱动力。武器和角色的解锁收集系统增加长期目标。

## Meta 系统

角色解锁、武器升级、成就系统。收集的货币可以用于购买新角色或升级武器属性。

## 实现难度

中，需要良好的反应速度和多任务处理能力。最大技术难点在于随机生成的平衡性和手感调优。
