# Attack of the Friday Monsters! A Tokyo Tale

- **类型**: 冒险 / 叙事驱动
- **平台**: Mobile (iOS / 3DS)
- **开发商**: Level-5
- **首次发布**: 2013
- **一句话描述**: 在 1970 年代日本小镇长大的男孩与朋友们一起追踪每周出没的巨型怪兽

## 玩法规则

游戏背景设定在 1970 年代日本的一个宁静小镇。玩家扮演刚搬来这里的男孩 Sohta。画面采用预渲染 2D 风格，阳光洒满小镇，远处工业烟囱冒着烟雾。

玩家在小镇中自由探索，与各种 NPC 对话推进线性剧情。你会遇到认识你的友好警察、当地电视台工作人员、小镇里的恶霸，以及与你家有矛盾的餐厅老板。随着探索深入，你会对小镇的每条街道产生亲密感，最终能像本地人一样走各种捷径。

在小镇中行走时，可以收集散落在各处的小型光团，称为"Monster Glim"。收集足够的 Monster Glim 后会生成一张怪兽卡，可以用来参与 Sohta 朋友圈中流行的怪兽卡牌对战。

怪兽卡牌游戏本质上是一个简化的"石头剪刀布"系统。玩家偶尔需要和朋友们对战并获胜才能推进剧情。失败没有严厉惩罚。还可以通过将两张弱卡合成来制作更强的卡牌，提高获胜几率。

每隔周五，巨型怪兽会"袭击"小镇（类似哥斯拉电影中的场景），Sohta 和朋友们痴迷于追踪这些怪兽并揭开它们背后的真相。

## 核心循环

探索小镇 → 收集 Monster Glim → 合成卡牌 → 与朋友对战 → 推进剧情

## 核心机制

- **Monster Glim 收集**：在探索小镇过程中自然收集光团，是卡牌系统的基础资源
- **卡牌对战（石头剪刀布）**：简单直观的对战系统，可以通过卡牌合成来增强实力
- **环境叙事**：通过反复探索同一条街道，玩家逐渐建立起对小镇的归属感，形成情感连接

## 为什么好玩

这不是一个以机制深度取胜的游戏——它的魅力在于氛围营造。阳光下的 1970 年代日本小镇、蝉鸣声、慢节奏的探索体验，以及怪兽出现时的兴奋感形成鲜明对比。正如评测所说，让你回来的是剧情和世界本身。

## 粘性来源

情感依恋——玩家会逐渐爱上这个小镇和其中的角色。怪兽的神秘真相是推动力，而小镇的日常宁静则让人留恋。"差一点就知道真相"的好奇心也是持续的粘性来源。

## Meta 系统

无外围成长系统。卡牌合成（两张弱卡合成一张强卡）是唯一的"成长"机制。
