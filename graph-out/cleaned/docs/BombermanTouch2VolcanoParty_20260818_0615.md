# 触摸炸弹人2：火山派对（Bomberman Touch 2: Volcano Party）

- **类型**: 动作 / 策略 / 解谜
- **平台**: Mobile (iOS)
- **开发商**: Hudson Soft
- **首次发布**: 2009
- **一句话描述**: 经典炸弹人系列的iOS版本，保留了放置炸弹、炸毁障碍、消灭敌人的核心玩法。

## 玩法规则

游戏采用经典的俯视角网格地图。画面中布满可破坏的砖块和不可破坏的石墙，玩家控制的炸弹人在迷宫中移动。地图风格以火山主题为主，包含熔岩、火山口等元素。

玩家通过虚拟摇杆控制角色移动，点击屏幕放置炸弹。炸弹在几秒后爆炸，火焰沿十字方向扩散。爆炸会摧毁可破坏的砖块，消灭范围内的敌人。玩家自己被爆炸波及也会失去生命。

每关的目标是消灭所有敌人或找到出口（藏在砖块下方）。随着关卡推进，可以获得能力增强道具：增加炸弹数量、增大爆炸范围、提高移动速度等。这些道具显著改变游戏策略。

游戏有单人闯关模式和多人对战模式。多人模式下，最多四名玩家在同一张地图上互相放置炸弹，最后一个存活的玩家获胜。多人模式支持本地同屏和在线对战。

## 核心循环

放置炸弹炸毁障碍 -> 发现道具/消灭敌人 -> 获得能力提升 -> 挑战更难关卡

## 核心机制

- 炸弹放置与爆炸：在网格上放置炸弹，定时爆炸产生十字火焰。火焰会摧毁砖块和消灭敌人，是攻击和解谜的核心工具。
- 道具收集系统：炸毁砖块后随机掉落道具（增加炸弹数、增大爆炸范围、加速、穿透炸弹等），改变游戏策略。
- 迷宫探索：每关的迷宫布局由程序生成，部分砖块下隐藏着过关所需的出口或强力道具。

## 为什么好玩

炸弹人的核心乐趣在于策略性爆破——你需要计算爆炸范围、预判敌人移动路径、利用道具组合创造连锁反应。多人对战时的互相陷害和意外翻盘更是充满了欢乐。

## 粘性来源

粘性来自每关不同的迷宫生成和道具掉落随机性。下一个砖块后面会是什么的好奇心驱使你不断前进。多人对战的社交竞争也是重要粘性来源。

## Meta 系统

关卡解锁系统。完成一定数量的关卡后解锁新的关卡主题和特殊能力。多人模式解锁需要达到特定关卡进度。

## 实现难度

低。最大的技术难点在于爆炸的级联计算——多个炸弹同时爆炸时火焰范围的叠加和碰撞检测，以及多人模式下的网络同步。
