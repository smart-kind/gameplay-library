# ProgressBar95 - retro arcade

- **类型**: 超休闲 / 复古街机
- **平台**: Mobile (iOS)
- **开发商**: Spooky House Studios UG (haftungsbeschraenkt)
- **首次发布**: 2019
- **一句话描述**: Progressbar95是一款怀旧风格的超休闲游戏。玩家需要移动进度条来填满它，看起来简单但掌握起来有挑战性。

## 玩法规则

游戏屏幕模拟老式Windows 95的界面风格，带有经典的灰色面板、按钮和图标。屏幕中央有一个进度条。玩家用一根手指拖动进度条来收集填充物（类似碎片的物体）。进度条需要接住从上方落下的填充物来填满。每次游戏过程中会出现不同的障碍物，需要避开。障碍物碰到进度条会减少填充进度。当进度条被填满时游戏胜利。如果进度条被障碍物填满则游戏失败。游戏包含经典的HDD硬盘噪音音效，增强怀旧感。

## 核心循环

拖动进度条接住填充物 -> 避开障碍物 -> 填满进度条获胜 -> 重复

## 核心机制

- 单手操作：一根手指拖动进度条，简单易上手
- 随机障碍：每局不同的障碍物分布，保持新鲜感
- 怀旧界面：Windows 95风格的UI和HDD音效
- 无尽模式：持续挑战更高分数

## 为什么好玩

怀旧主题让这款游戏在众多休闲游戏中脱颖而出：老Windows界面的灰色面板、经典图标、HDD噪音，每一个细节都在触发nostalgia。简单的接东西玩法因为随机障碍而有了挑战性。

## 粘性来源

每局随机障碍让重复游玩有趣；怀旧主题吸引特定受众；单手操作适合碎片时间；无尽模式提供持续挑战

## Meta 系统

无外围系统。纯粹的街机体验，通过随机生成保持新鲜感。

## 实现难度

中。核心难点在于超休闲玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
