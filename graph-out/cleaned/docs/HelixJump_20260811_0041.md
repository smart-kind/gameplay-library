# Helix Jump

- **类型**: 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2018
- **一句话描述**: 超休闲游戏，通过旋转螺旋塔让小球穿过缺口一路下降，避开红色区域。

## 玩法规则

画面中央是一个多层螺旋圆柱塔，每一层都有缺口。玩家控制一个小球在塔的中央位置。

操作：左右滑动屏幕来旋转螺旋塔，让小球从当前层掉到下一层。

核心规则：
- 小球会自然下落，遇到有缺口的层就会穿过
- 如果小球落在红色区域，游戏结束
- 有些层全是红色，不能通过，需要等待塔旋转到正确角度
- 连续穿过多个层（combo）会获得额外分数

游戏节奏非常快，一次失败就重新开始，但每次只需要几秒钟就能再次开始。

后期关卡会出现移动的红色区域、更密的红色层、旋转速度变化等增加难度的元素。

## 核心循环

旋转塔 -> 小球下落穿过缺口 -> 连续通过多层 -> 到达下一关卡

## 核心机制

- 旋转控制 — 单手操作，通过旋转塔而非移动球来控制下落路径
- 风险/回报 — 可以快速旋转连续穿过几层（combo 加分），但也更容易失误落到红色区域
- 即时重来 — 死亡后立即可以重新开始，没有加载时间

## 为什么好玩

极致简单的操作加上恰到好处的难度递增加上流畅的物理下落动画，让人停不下来。差一点就通过的感觉让人不断重试。

## 粘性来源

超短的单局时间（30 秒到 1 分钟）让再来一次几乎没有阻力；关卡数量极多（数百关）；皮肤和塔的图案解锁。

## Meta 系统

关卡解锁和皮肤收集系统。通过关卡或观看广告获得金币，用于解锁不同的球和塔的外观。

## 实现难度

低 — 操作极其简单（左右滑动），但随着层数增加，缺口变小、红色区域增多，需要更高的反应速度和预判能力。最大技术难点在于让难度曲线平滑，不能太简单也不能太难。
