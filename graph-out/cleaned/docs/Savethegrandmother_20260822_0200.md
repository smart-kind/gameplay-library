# 拯救老奶奶（Save the grandmother）

- **类型**: 解谜/超休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2022
- **一句话描述**: 趣味解谜小游戏合集

## 玩法规则

每个关卡是一个独立的谜题场景，玩家需要通过特定操作帮助老奶奶脱离困境。操作方式包括点击、拖拽、滑动等。每个谜题需要观察场景、理解逻辑、找到正确的操作顺序。谜题设计常常有出人意料的解法，充满幽默感。部分关卡有错误操作导致的搞笑失败动画。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

观察场景 → 思考解法 → 执行操作 → 成功/失败 → 重试或下一关

## 核心机制

- **创意解谜**:  每个关卡有独特的谜题设计
- **幽默元素**:  搞笑的失败动画增加乐趣
- **逻辑推理**:  需要理解场景中的因果关系

## 为什么好玩

出人意料的解法和幽默的失败动画让解谜过程充满笑声

## 粘性来源

想知道'下一关会是什么'的好奇心；分享搞笑失败瞬间的社交传播

## Meta 系统

关卡解锁系统

## 实现难度

低 - 每关是独立的交互逻辑 - 创意关卡设计的持续产出
