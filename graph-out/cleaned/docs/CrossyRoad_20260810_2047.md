# Crossy Road（Crossy Road）

- **类型**: 无尽跑酷 / 反应躲避
- **平台**: Mobile (iOS+Android) / PC / 主机
- **开发商**: Hipster Whale
- **首次发布**: 2014
- **一句话描述**: "Frogger 的现代版本"——操控角色不断向前穿越道路、河流和铁轨

## 玩法规则

画面是 3D 方块风格的等距视角。屏幕被分为若干横向条带：有些是安全草地，有些是公路（有车辆行驶），有些是河流（有浮木移动），有些是铁轨（有火车驶过）。

玩家控制一个方块角色站在最下方的安全区域。每次点击屏幕，角色向前跳一步；左右滑动，角色横向移动一格。角色自动在安全草地上行走，但到达公路/河流/铁轨时必须谨慎——被车撞到、掉进河里、被火车碾到都会立刻死亡。

游戏目标只有一个：走得越远越好。每向前走一步得 1 分。角色死亡后游戏结束，显示总分和最高分。

每隔几步会出现一个安全草地行，可以停下来喘口气。河流上漂浮的圆木和睡莲是天然跳板，角色跳到圆木上会随圆木一起移动。

## 核心循环

点击/滑动前进 → 躲避障碍 → 分数增加 → 死亡 → 获得新角色 → 再来一局

## 核心机制

- 机制1：极简单操作——只有"点击=前进，滑动=左右"，任何人都能在 3 秒内上手，降低了准入门槛
- 机制2：程序化道路生成——每次游戏道路排列不同，车辆速度和间距随机，保证每局体验不重复
- 机制3：角色收集——死亡后有概率获得新角色（青蛙、狗、名人、节日限定角色等数百种），角色纯装饰但提供收集乐趣

## 为什么好玩

"再来一次就能超过上次"的冲动 + "差一步就破纪录"的不甘心。极其简单的操作意味着每次死亡都感觉是"我的错"而非"游戏的问题"，这正是让人欲罢不能的关键。

## 粘性来源

自我挑战（刷新最高分）+ 角色收集（数百种角色需要解锁）+ 社交竞争（好友排行榜）+ 随机性（每局地图不同）

## Meta 系统

角色收集系统是核心外围玩法——通过投掷骰子（死亡后获得）随机解锁角色。还有每日挑战模式和主题世界（西部、太空、万圣节等）随时间解锁。

## 实现难度

低。核心是道路生成算法、碰撞检测和简单的角色移动逻辑。技术门槛很低，美术资产（方块风格）也很简单。最大的挑战是如何让道路生成的难度曲线既公平又有趣。
