# Pac-Man

- **类型**: 迷宫 / 动作
- **平台**: Arcade / Mobile (iOS+Android) / PC / Console
- **开发商**: Namco
- **首次发布**: 1980
- **一句话描述**: 玩家在迷宫中吃豆子并躲避四个不同行为模式的幽灵，吃能量豆后可反杀幽灵

## 玩法规则

游戏画面是一个封闭的迷宫，内部散布着大量小豆子。玩家控制黄色圆形角色Pac-Man在迷宫通道中移动。

迷宫中有四个幽灵：Blinky（红色，追击）、Pinky（粉色，伏击）、Inky（青色，包夹）、Clyde（橙色，随机）。每个幽灵有独特的AI行为模式。

玩家操作：
- 四方向移动：上下左右控制Pac-Man在迷宫通道中移动
- 持续移动：Pac-Man会持续朝当前方向移动直到碰到墙壁

游戏目标：吃掉迷宫中所有小豆子即可过关。每个豆子10分。

核心机制：
- 能量豆（Power Pellet）：迷宫四个角落各有一个大能量豆，吃掉后幽灵变为蓝色（恐惧状态），此时可以吃掉幽灵获得200-1600分（连续吃分数递增）
- 水果奖励：关卡中偶尔出现水果，吃掉获得额外分数
- 隧道：迷宫左右两侧有隧道，进入后从另一侧出现

游戏结束条件：
- 被幽灵碰到（非恐惧状态）失去一条命
- 所有生命用尽游戏结束

## 核心循环

吃豆子 → 躲避幽灵 → 吃能量豆反杀 → 清除迷宫 → 进入下一关

## 核心机制

- **四种幽灵AI**: 每个幽灵有独立的行为算法：Blinky直接追击、Pinky预判位置、Inky基于Blinky位置包夹、Clyde在远近之间切换
- **恐惧状态**: 吃能量豆后幽灵变蓝逃跑，创造猎人变猎物的反转快感，恐惧状态有时间限制
- **迷宫导航**: 通道系统设计让玩家需要记忆最优路线，同时躲避幽灵追击增加紧张感
- **分数倍率**: 连续吃恐惧状态的幽灵分数递增（200、400、800、1600），鼓励冒险

## 为什么好玩

四种幽灵的不同行为模式让每次追逐都有变化。吃能量豆后反杀幽灵的权力反转带来极大的爽快感。迷宫中差一点就被抓到的紧张感令人欲罢不能。

## 粘性来源

高分竞争和关卡递进（速度越来越快）是主要粘性。每关的布局和节奏变化让玩家不断挑战自我极限。幽灵行为的不可预测性（特别是Clyde）增加重玩价值。

## Meta 系统

无。原始版本无外围成长系统。

## 实现难度

低。迷宫碰撞检测和幽灵AI是核心技术点。难点在于四种幽灵行为的调优，既要让玩家感到威胁，又不能让人觉得不公平。
