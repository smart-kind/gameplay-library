# Dress to Play: Cute Witches! (装扮游戏：可爱女巫！)

- **类型**: 休闲 / 益智 / 装扮
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2013
- **一句话描述**: 以可爱女巫为主题的休闲益智装扮游戏

## 玩法规则

游戏结合了装扮和解谜两种玩法。玩家需要为女巫角色选择合适的服饰和配饰来通过关卡，同时解决简单的益智谜题。

游戏界面分为两个部分：左侧是角色展示区，右侧是可选服饰和道具的展示区。玩家通过拖拽的方式将服饰应用到角色身上。

每关有特定的主题或要求（如特定颜色、风格或场景搭配）。玩家需要从可用选项中选择最匹配的组合。搭配完成后，游戏会根据匹配度给出评分。

部分关卡包含益智元素，如记忆配对或物品排序，需要通过解谜来解锁新服饰。

## 核心循环

查看关卡要求 → 选择搭配 → 提交评分 → 解锁新物品 → 挑战下一关

## 核心机制

- **装扮匹配系统**：根据主题要求进行服饰搭配，考验审美和观察力
- **收集解锁**：通过完成关卡获得新服饰，形成收集驱动
- **主题关卡**：每关有不同的场景和风格要求，增加变化性
- **益智谜题**：穿插的益智关卡提供玩法变化，避免单调

## 为什么好玩

轻松愉快的画风和简单的操作让游戏适合所有年龄段的玩家。装扮的创造性和收集欲让游戏有很强的重玩价值。

## 粘性来源

收集驱动（解锁所有服饰）+ 搭配创造性的自我表达 + 轻松休闲的节奏 + 主题变化的新鲜感

## Meta 系统

服饰收集系统 — 通过关卡进度和成就解锁新服饰和配饰

## 实现难度

低 — 基于UI的休闲装扮游戏，最大技术难点在于关卡设计和搭配评分算法的合理性
