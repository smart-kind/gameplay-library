# 死亡细胞 (Dead Cells)

- **类型**: Roguelike / 类银河战士恶魔城 / 平台动作
- **平台**: Mobile (iOS+Android) / PC / Switch / PS / Xbox
- **开发商**: Motion Twin
- **首次发布**: 2018
- **一句话描述**: 在程序生成的城堡中高速战斗，每次死亡重新开始但保留解锁的新武器和能力

## 玩法规则

游戏画面为精美的像素风横版场景，玩家操控一个无头细胞体在城堡中战斗。城堡由程序生成，每次游戏的布局不同。

玩家使用武器（近战和远程）与敌人战斗。近战武器包括剑、矛、镰刀等，远程武器包括弓、弩、法杖等。武器有品质等级（普通、罕见、稀有、传奇），高品质武器伤害更高且有特殊效果。

战斗强调速度和流畅性——翻滚躲避、盾牌格挡、冰冻控制等防御手段与攻击同等重要。玩家在战斗中需要不断移动和闪避，静态战斗往往意味着死亡。

城堡分为多个生物群系（有罪者的大道、被弃者的沼泽、藏骨堂等），每个群系有独特的敌人、Boss和环境。玩家需要选择合适的路线前往Boss。

死亡后所有进度丢失，但收集到的细胞（货币）可以带回起始区域解锁永久的新武器、能力和升级。

## 核心循环

进入城堡 → 探索房间 → 战斗获取装备和细胞 → 击败Boss进入下一区域 → 死亡或通关 → 用细胞解锁新内容 → 重新开始

## 核心机制

- **武器系统**：大量武器类型（50+种），分为近战、远程、技能三大类。每局随机出现不同武器组合，形成独特的战斗风格。武器有品质等级和词条系统。
- **卷轴系统**：收集卷轴提升属性（生命值、伤害）。每次升级需要选择提升生命值、伤害或特殊属性，形成不同的build。
- **永久死亡与解锁**：每次死亡丢失当前进度，但收集到的细胞可以永久解锁新武器和能力。这保证了即使失败也有进展。
- **Boss Rush模式**：通关后可以挑战连续Boss模式，测试玩家的极限操作。

## 为什么好玩

战斗手感极佳——每一次攻击、翻滚、格挡都感觉精准有力。高速的战斗节奏和丰富的武器组合让每次游玩都充满新鲜感。像素美术和配乐也达到了极高的水准。

## 粘性来源

武器和能力的多样性保证了长期重玩性——50+种武器的组合几乎无限。永久解锁系统让每次失败都有收获。高难度挑战（5 Boss细胞难度）为高手提供了终极目标。

## Meta 系统

细胞解锁系统：收集细胞解锁新武器、能力和升级。Boss细胞系统：通关后获得Boss细胞，增加游戏难度但解锁新内容。最高5个Boss细胞难度。

## 实现难度

高。流畅的平台动作战斗需要精确的碰撞检测、动画系统和输入响应。程序化生成的关卡需要保证可玩性和趣味性。武器系统的平衡（50+种武器）需要大量测试。
