# Word Connect – Words of Nature（Word Connect）

- **类型**: 文字解谜 / 拼字游戏
- **平台**: Mobile (iOS+Android)
- **开发商**: Zentertain
- **首次发布**: 2016
- **一句话描述**: 连接圆圈中的字母组成单词，在宁静的自然风景背景中锻炼词汇量

## 玩法规则

画面底部是 6-7 个排成圆环的字母，背景是风景照片或插画。玩家需要在字母之间画线连接它们组成有效英文单词。

例如圆环中有字母 A、E、T、L、S、E，可以连接出 TEA、EAT、LATE、SALE、LEAST 等。每找到一个单词，它会填入中间的空格中。找完所有单词即可过关。

随着关卡推进，字母数量增加（从 4 个到 7 个以上），单词组合更复杂。某些关卡会有提示功能（显示单词长度和首字母），但提示数量有限。

## 核心循环

观察字母环 → 画线连接成单词 → 填满空格过关 → 进入下一关

## 核心机制

- 机制1：画线连接——用手指在字母之间滑动连线，比传统的"选择字母"更直观，操作本身有流畅感
- 机制2：关卡递进——早期关卡字母少、单词简单（3-4字母），后期字母多、需要找到 7-8 字母长词，难度自然递增
- 机制3：背景风景——每关对应一张自然风光背景，完成任务后解锁新的风景图，提供视觉奖励

## 为什么好玩

拼字游戏天然的"啊哈！"时刻——突然从一堆字母中看到一个隐藏的长词，那种顿悟感是大脑的天然奖励。加上安静的背景和渐进的难度，非常适合碎片时间放松。

## 粘性来源

词汇量挑战（"我还能找到几个没发现的词？"）+ 关卡递进（数千关）+ 风景收集（视觉奖励）+ 脑力锻炼的成就感

## Meta 系统

风景照片收集系统 + 每日挑战 + 关卡编号推进。无其他外围养成系统，是纯解谜体验。

## 实现难度

低。核心是字典查找算法——给定 N 个字母，找出所有有效的英文单词组合。词库可以预加载，连接线的 UI 交互也很简单。最大挑战是关卡设计：需要确保每关有合适的单词数量（不能太少显得无聊，不能太多让人沮丧）。
