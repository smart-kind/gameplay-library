# Mini Metro（Mini Metro）

- **类型**: 极简策略 / 线路规划解谜
- **平台**: Mobile (iOS+) / PC (Steam) / Switch
- **开发商**: Dinosaur Polo Club
- **首次发布**: 2015
- **一句话描述**: 在极简的城市地图上画地铁线路，用越来越拥挤的客流考验你的规划能力

## 玩法规则

游戏画面极度极简：白色或单色背景上，各种几何图形代表站点（圆形、三角形、方形等），线条是你画的地铁线路。

游戏开始时只有一两个站点。每过一周（游戏内时间），城市会随机冒出新的站点，同时你获得一个"资源"——可能是一条新的线路、一个车厢、一个隧道（用于跨河）或交换站（让乘客换乘线路）。

玩家用鼠标/手指从一个站点拖到另一个站点画出线路。站点会自动连接到最近的线路。不同形状的站点产生不同形状的乘客，乘客只会乘坐能到达目标形状站点的线路。

如果某个站点积累的乘客超过容量上限，站点会闪烁红色，持续闪烁几次后游戏结束。游戏的目标是尽可能延长存活时间。

## 核心循环

观察城市扩张 → 画线连接站点 → 分配车厢和换乘站 → 应对增长的客流 → 某站崩溃游戏结束 → 重试

## 核心机制

- 机制1：极简策略——UI 只有几何图形，没有文字、没有菜单、没有教程。所有信息通过颜色和形状传达，降低了认知负担但保留了策略深度
- 机制2：动态压力——城市每周随机扩展，玩家资源有限，必须在"增加线路"和"优化现有线路"之间做选择。每次只能解决一个瓶颈，永远不够用
- 机制3：乘客路径自动化——乘客自动寻路沿着你画的线路移动，你只需要关注线路设计，不需要管理列车运行

## 为什么好玩

看着自己设计的地铁系统在白色背景上优雅运转，有一种"建筑师"的满足感。同时，当系统开始崩溃时——某条线路突然爆满、乘客开始滞留——又有一种紧迫的救火感。禅意和紧张并存。

## 粘性来源

自我挑战（每次都想撑更久/得分更高）+ 随机地图（每局城市布局不同）+ 多城市解锁（完成一个城市解锁下一个）+ "差一点就成功"的再来一局冲动

## Meta 系统

城市解锁系统——每个真实城市（伦敦、巴黎、纽约、柏林、上海等）有独特的地理挑战（河流、海湾、岛屿等），完成一个城市的目标分数解锁下一个。纯关卡制，无其他外围系统。

## 实现难度

中。技术难点在于：（1）乘客的自动寻路算法——需要计算最优路径并在多条线路间做出合理选择；（2）线路拖拽的 UI 交互要流畅自然；（3）城市生成的随机性需要平衡公平性和趣味性。但整体不涉及复杂物理或 AI，核心是图论算法。
