# 阿尔卑斯谋杀案（Murder in Alps: Hidden Mystery）

- **类型**: 寻物冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: Nordcurrent UAB
- **首次发布**: 2015
- **一句话描述**: 以1930年代阿尔卑斯山酒店为背景的互动犯罪小说游戏，融合寻物和解谜元素破解连环失踪案

## 玩法规则

游戏采用互动小说加寻物解谜的混合形式。故事设定在1930年代阿尔卑斯山的一家酒店中，画面精美还原了那个时代的建筑、服饰和生活细节。

玩家扮演调查员Anna Myers，需要在各种场景中寻找隐藏物品和线索——包括酒店房间、地下室、雪山、村庄。

找到线索后，游戏会推进剧情，揭示新的信息和嫌疑人。寻物场景中物品列表显示在屏幕一侧。

部分关卡包含逻辑谜题和小游戏来推进关键剧情节点。故事围绕酒店中发生的连环失踪案展开。

每个章节都有新的场景、角色和情节转折。章节之间的过渡动画展示了故事的发展。

## 核心循环

在1930年代场景中寻找隐藏线索 → 分析线索推进调查 → 解开逻辑谜题 → 揭示真相进入下一章节

## 核心机制

- 互动小说叙事：以章节式互动小说的形式讲述犯罪故事。玩家的调查发现直接影响故事走向
- 时代场景寻物：1930年代阿尔卑斯山的独特背景为寻物提供了丰富的视觉元素和历史氛围
- 逻辑谜题系统：关键剧情节点设置逻辑谜题，需要玩家综合分析已有线索才能解开

## 为什么好玩

1930年代的怀旧氛围和阿尔卑斯山的美景让每次寻物都像在翻阅一本精美的画册。

犯罪故事紧张刺激引人入胜，每个嫌疑人都有自己的秘密和动机。

互动小说的叙事方式让玩家感觉自己是故事的一部分而不仅仅是旁观者——你的每一个发现都推动着故事的走向。

## 粘性来源

章节式犯罪小说天然驱动凶手是谁的好奇心。Nordcurrent的持续内容更新保证了新章节的供应

## Meta 系统

章节解锁系统：完成章节解锁新故事线，部分章节需要游戏内货币解锁

## 实现难度

中等 — 犯罪推理增加了寻物的思考深度。最大的技术难点在于叙事节奏和寻物难度的平衡
