# Skullgirls Mobile

- **类型**: puzzle
- **平台**: Mobile (iOS+Android) / Switch/Console
- **开发商**: Autumn Games
- **首次发布**: 2018
- **一句话描述**: The ultimate free-to-play 2D anime fighting RPG — collect over 300 unique fighters, master deep combos, and battle your way to the top!

STUNNING HAND-DRAWN ANIMATION
Every fighter features thousands of frames of carefully hand-drawn 2D animation — a visual experience unlike any other mobile game

## 玩法规则

在 Skullgirls Mobile 中，玩家面对一系列精心设计的谜题需要逐一解决。

游戏界面通常呈现一个简洁的画面布局，谜题元素以直观的方式展示在屏幕上。玩家通过点击、拖拽或滑动来与谜题元素互动。

具体操作方式：
- 观察谜题的初始状态和可用元素
- 通过点击选择要操作的对象，通过拖拽来移动它们
- 尝试不同的组合和操作顺序来解开谜题
- 某些谜题有时间限制或步数限制

游戏的目标是找出正确的解法，让所有元素达到预期的排列状态。每解开一个谜题，就会进入下一个更具挑战性的关卡。

## 核心循环

观察谜题 -> 尝试解法 -> 解开谜题 -> 进入下一关 -> 面对更复杂的挑战

## 核心机制

- 渐进式难度曲线：谜题从简单到复杂逐步递进
- 多维度思考：每个谜题需要从不同角度思考，打破常规思维模式
- 即时反馈：操作后立即看到结果，让玩家能够快速调整策略
- 优雅的设计美学：简洁的画面和音效设计让解谜过程本身成为一种享受

## 为什么好玩

Skullgirls Mobile 的好玩之处在于解开谜题时那种恍然大悟的快感。每个谜题设计精巧，答案往往就在眼前却难以发现。

## 粘性来源

粘性来自于"差一点就想出来"的不甘心——每个谜题解开后，你迫不及待地想要挑战下一个。

## Meta 系统

游戏通常包含关卡解锁系统——完成一定数量的关卡后解锁新的主题或难度。部分游戏有每日挑战模式。

## 实现难度

中等。核心机制简单但关卡设计是关键。最大技术难点在于确保每个谜题有唯一解且解法合理。
