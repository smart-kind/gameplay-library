# 拉吉：远古传奇（Raji: An Ancient Epic）

- **类型**: 动作冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: Nodding Heads Games（Netflix）
- **首次发布**: 2023（Netflix版）
- **一句话描述**: 以印度神话和文化为背景的动作冒险游戏。

## 玩法规则

第三人称动作冒险，玩家控制拉吉——一个注定要对抗威胁人类的恶魔势力的年轻女孩。包含神圣武器战斗、解谜和探索，环境灵感来自印度建筑和神话。

玩家使用多种武器进行近战和远程战斗，每种武器有独特的攻击模式和升级路径。解谜环节需要观察环境和运用逻辑。

## 核心循环

探索环境 → 对抗恶魔 → 解开谜题 → 解锁新能力 → 推进故事 → 面对 Boss 恶魔

## 核心机制

- 神圣武器：多种武器，各有独特战斗风格和升级路径
- 神话背景：环境和敌人基于印度教神话和印度艺术
- 谜题集成：测试观察力和逻辑思维的环境谜题

## 文化与艺术价值

游戏的美术设计大量借鉴了印度传统艺术形式，包括拉杰普特绘画风格和南印度建筑元素。配乐使用传统印度乐器，如西塔琴和塔布拉鼓。

游戏中的神话叙事基于印度史诗《摩诃婆罗多》和《罗摩衍那》，将古老传说以现代游戏形式呈现。

## 为什么好玩

美丽的印度灵感艺术风格和神话为动作冒险类型带来了全新的文化视角。

## 粘性来源

丰富的故事、武器多样性和印度灵感世界设计的视觉壮观。

## Meta 系统

Netflix Games — 完整游戏包含在订阅中

## 实现难度

中等 — 战斗需要时机和策略，谜题复杂度不一
