# Dots: A Game About Connecting

- **类型**: 休闲 / 连线
- **平台**: Mobile (iOS+Android)
- **开发商**: Playdots, Inc.
- **首次发布**: 2013
- **一句话描述**: 一款极简风格的连线消除游戏，玩家在限定时间内连接相同颜色的圆点来获得分数

## 玩法规则

游戏呈现一个6x6的彩色圆点网格，每个圆点是一种颜色（通常4-6种颜色）。圆点颜色柔和，视觉风格极简。

玩家用手指从一个圆点滑动到相邻同色圆点（水平或垂直相邻），形成一条连线。松开手指后，连线上的所有圆点被消除。连线越长消除越多。

消除后上方圆点下落填补空缺，新的圆点从顶部随机生成。下落过程中如果新排列形成同色连线，不会自动消除（需要手动操作）。在限定时间内尽可能消除更多圆点。

特殊机制：连接4个圆点消除时，最后一个圆点变成彩色圆点（消除时清除所有同色圆点）。连接5个圆点消除时，最后一个圆点变成彩虹圆点（消除时清除屏幕上所有圆点）。

游戏设有禅模式，去除时间限制让玩家可以无限时地连接圆点。禅模式适合放松和冥想。

## 核心循环

连接同色圆点消除 → 获得分数和特殊圆点 → 在限时内最大化消除

## 核心机制

- **连锁消除**：连接消除后新圆点可能自动形成新的连线
- **特殊圆点**：彩色圆点清屏同色，彩虹圆点清屏所有
- **限时挑战**：倒计时压力增加紧张感

- **禅模式**：无时间限制的放松模式

## 为什么好玩

极简的视觉设计配合流畅的消除动画，让操作本身成为一种享受。发现特殊圆点并触发大范围消除的爽快感极强。

## 粘性来源

限时挑战的分数追求是核心粘性。每次'差几秒就破纪录'的感觉让人不断重开。

## Meta 系统

无。纯限时挑战。

## 实现难度

低 — 滑动连接直观。最大技术难点是流畅的消除动画和圆点下落物理。
