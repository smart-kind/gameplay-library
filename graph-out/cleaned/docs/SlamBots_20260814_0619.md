# SlamBots

- **类型**: 动作 / 平台格斗
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款快节奏的平台格斗游戏，玩家控制小型机器人在擂台上互相碰撞，将对手打出擂台即获胜

## 玩法规则

游戏呈现一个封闭的擂台（圆形、方形或不规则形状）。2-4名机器人选手在擂台上战斗。

玩家通过虚拟摇杆控制移动，点击攻击按钮执行不同攻击：轻击（快速但伤害/击退低）、重击（慢但伤害高且击退远）、特殊攻击（需要充能条蓄满）。

目标不是削减对手生命值，而是将对手击打出擂台。击退距离取决于攻击力度、对手当前状态（是否在空中）和擂台边缘距离。

擂台可能包含动态元素：移动平台、弹簧板（额外弹跳力）、掉落物品（临时增强）。被击落后重新进入擂台的玩家有短暂无敌时间。

游戏设有自定义擂台模式，玩家可以设计自己的擂台布局并邀请好友对战。擂台编辑器提供多种地形和机关。

## 核心循环

操控机器人攻击对手 → 将对手击出擂台 → 获胜

## 核心机制

- **击退机制**：伤害不是主要目标，击退才是胜负关键
- **擂台动态**：移动平台等环境元素改变战斗空间
- **充能攻击**：特殊攻击需要时间充能，风险高回报大

- **自定义擂台**：玩家设计擂台布局

## 为什么好玩

快节奏的碰撞战斗带来强烈的即时反馈。将对手击飞擂台的瞬间爽快感极强。

## 粘性来源

格斗游戏的竞争性粘性。与朋友对战尤其有趣。

## Meta 系统

机器人外观定制：解锁不同皮肤和配件。

## 实现难度

中 — 需要良好的时机判断。最大技术难点是击退物理和多人同步。
