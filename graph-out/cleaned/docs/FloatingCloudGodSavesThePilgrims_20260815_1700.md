# Floating Cloud God Saves the Pilgrims

- **类型**: 动作 / 射击
- **平台**: Xbox Live Arcade / PC
- **开发商**: Goblinz Studio
- **首次发布**: 2010
- **一句话描述**: 一款上帝视角的射击游戏，玩家扮演云朵之神，操控天气和云朵来保护朝圣者穿越危险区域，通过降雨、闪电等自然力量消灭敌人。

## 玩法规则

游戏画面为俯视视角，一群朝圣者在地面上沿着固定路线行进。玩家不直接控制角色，而是操控天空中的云朵来影响地面局势。

玩家的主要操作包括：移动云朵到指定位置、控制云朵降雨、释放闪电攻击敌人、制造风力影响朝圣者和敌人的移动方向。

敌人从四面八方涌来，试图攻击行进中的朝圣者。玩家需要利用天气力量消灭敌人、清除障碍、为朝圣者开辟安全通道。

朝圣者的生命值有限，如果太多朝圣者死亡则任务失败。玩家需要全程保护他们安全到达目的地。

游戏中有多种天气能力可以解锁和升级：降雨范围、闪电强度、风力大小等。不同能力组合使用可以产生更强的效果，例如先降雨让敌人减速再闪电攻击。

关卡设计包含多种地形和挑战：有些区域朝圣者行走缓慢，有些区域敌人密集，有些区域需要特定的天气能力才能通过。

## 核心循环

观察敌人分布 → 选择天气能力 → 操控云朵保护朝圣者 → 到达目的地 → 升级能力进入下一关

## 核心机制

- 间接控制模式：玩家不控制朝圣者本身，而是操控天气来影响战局。这种'保护者'而非'执行者'的角色定位创造了独特的游戏体验。
- 天气能力组合：降雨、闪电、风力等能力各有特点，组合使用产生协同效应。例如降雨+闪电=范围电击，风力+降雨=定向水炮。
- 资源管理：天气能力消耗能量，玩家需要在'大规模攻击'和'精准保护'之间平衡能量分配。

## 为什么好玩

扮演'云朵之神'的设定本身就很有趣。俯视全局、运筹帷幄的感觉让玩家有'神明'般的掌控感，同时朝圣者的安危又带来紧迫感。

## 粘性来源

关卡递进+能力升级的双重驱动力。每关都有新的挑战，每次升级都让玩家感觉自己变得更强，想要挑战更难的关卡。

## Meta 系统

天气能力升级系统是唯一的成长维度，通过关卡进度解锁和强化。

## 实现难度

中。最大技术难点在于天气效果的物理模拟——降雨、风力等自然力量的视觉效果和碰撞检测需要兼顾性能和真实感。
