# SpongeBob Moves In

- **类型**: 模拟经营 / 放置
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款海绵宝宝主题的城市建设游戏，玩家在比奇堡中建造各种标志性建筑并管理居民活动

## 玩法规则

游戏呈现比奇堡的鸟瞰地图，初始只有一小块空地。玩家通过建造各种海绵宝宝动画中的经典建筑来扩展城市——蟹堡王、珊迪的树屋、章鱼哥的房子等。

每个建筑需要花费游戏内货币（贝壳币）建造，建造需要一定等待时间（几分钟到几小时不等）。时间到了后建筑完工，开始自动产出货币或资源。部分建筑需要前置条件——比如蟹堡王建成后才能解锁痞老板的餐厅。

玩家可以放置海绵宝宝、派大星、章鱼哥等角色到不同的建筑上工作。每个角色在特定建筑上工作效率不同，产出更多资源。角色可以通过经验升级提升效率。

完成任务链可以获得额外奖励。任务通常与动画剧情相关——比如帮助蟹老板经营餐厅、和派大星抓水母等。部分任务限时完成，超时失败但可重试。

游戏中设有社交系统，玩家可以访问好友的比奇堡，互赠礼物和协助完成任务。定期举办限时活动，推出特殊建筑和角色。

## 核心循环

建造和升级建筑 → 安排角色工作产出资源 → 解锁新建筑和任务

## 核心机制

- **角色分配**：不同角色在不同建筑有不同效率加成，需要合理配置
- **任务链**：与动画剧情相关的任务提供额外奖励和解锁条件
- **计时建造**：建筑需要等待时间完成，可用游戏内货币加速

- **社交互动**：访问好友基地，互赠礼物和协助任务

## 为什么好玩

海绵宝宝IP的还原度高，各种经典角色和场景重现带来情怀加成。建设过程中不断解锁新内容的惊喜感是核心体验。

## 粘性来源

IP粉丝粘性+模拟经营的长期进度系统。收集所有建筑和角色的目标感驱动持续游玩。定时产出资源的机制鼓励频繁回看。

## Meta 系统

建筑升级系统：建筑可以从1级升到多级，每级提升产出效率。角色收集系统：解锁并收集所有海绵宝宝系列角色。

## 实现难度

低 — 典型的放置经营玩法。最大技术难点是角色AI路径规划和大规模场景管理。
