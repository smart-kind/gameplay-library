# Gish Reloaded

- **类型**: 平台跳跃/冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer收录作品
- **首次发布**: 2010
- **一句话描述**: 一款主角为黑色粘性球体的2D平台跳跃游戏，利用变形能力通过各种障碍。

## 玩法规则

玩家控制一团名为Gish的黑色粘性物质（类似焦油或沥青），在充满陷阱和机关的2D关卡中冒险。Gish可以通过改变自身的物理特性（粘性、弹性、重量）来应对不同挑战。

1. Gish的基本移动通过方向键控制左右移动和跳跃。与普通平台游戏不同，Gish不是刚性物体，而是柔软可变形的粘性球体。

2. Gish有三种物理模式切换：正常模式（标准移动和跳跃）、粘性模式（可以粘附在墙壁和天花板上移动）、重物模式（增加重量压碎脆弱的地面或机关）。

3. 关卡中布满各种机关：尖刺陷阱、移动平台、传送带、风扇、磁铁等。玩家需要根据当前情况切换Gish的物理模式来安全通过。

4. 部分关卡包含收集品（如小方块），收集所有收集品是获得完美评价的条件。同时存在隐藏路径和秘密区域等待探索。

## 核心循环

探索关卡 -> 切换物理模式应对障碍 -> 收集物品 -> 到达关卡终点

## 核心机制

- **三态变形系统**：Gish可以在三种物理模式间自由切换：正常模式适合标准平台跳跃；粘性模式让Gish附着在垂直表面和天花板上；重物模式增加下压力可以压碎特定地面或触发压力机关。

- **物理特性互动**：Gish的柔软特性让它可以通过狭窄缝隙、挤压变形穿过障碍。但同时也会被尖刺等危险物伤害，需要谨慎规划路线。

- **机关解谜**：关卡中的机关设计需要结合Gish的不同模式来解决。例如先用重物模式压碎地面打开通路，再用粘性模式爬上墙壁到达高处。

- **收集与探索**：隐藏收集品分布在非常规路线上，鼓励玩家尝试不同的路径和方法。完全探索关卡需要熟练掌握所有三种模式。

## 为什么好玩

柔软可变形的角色设定在平台游戏中独树一帜，三种物理模式的切换让解谜有了多种解法。探索隐藏路径的成就感很强。

## 粘性来源

收集品驱动的全面探索欲，寻找最优路线的策略思考，以及每个新关卡中新的机关组合带来的挑战。

## Meta 系统

外围成长系统：金币或经验积累用于解锁新关卡、新角色或新能力。部分游戏包含每日挑战或排行榜等社交竞争元素，鼓励玩家持续回归。

## 实现难度

中。柔软物体的物理模拟（变形、碰撞、粘附）以及三种模式切换的流畅过渡。
