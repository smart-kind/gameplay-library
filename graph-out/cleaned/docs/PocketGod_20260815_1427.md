# 口袋上帝（Pocket God）

- **类型**: 模拟/沙盒/互动玩具
- **平台**: iOS / Android / Facebook
- **开发商**: Bolt Creative
- **首次发布**: 2009
- **一句话描述**: 玩家扮演一个小岛上的神明，对岛上的原始部落居民进行各种有趣的互动和"实验"。

## 玩法规则

画面展示一个热带小岛，岛上有若干个原始部落居民（Pygmy）。居民们在岛上自由活动：走路、跳舞、睡觉、采集食物。玩家可以以"上帝"的身份与他们互动——没有传统意义上的"目标"或"输赢"，核心是探索和实验。

互动方式包括：点击居民让他们执行动作（捡起物品、跳进火山、爬上棕榈树）；使用自然灾害（召唤闪电、龙卷风、地震）；改变环境（下雨、日出日落、种树）；给居民道具（食物、乐器、武器）。

每个互动都有独特的动画和音效反馈。居民被闪电劈中会冒烟跳舞，被扔进火山会有夸张的反应，这些反应本身就是"奖励"。游戏会定期更新新内容（新互动、新事件），通过"剧集"形式发布。

操作：点击/拖拽居民，点击工具栏选择互动方式，滑动屏幕改变视角。

## 核心循环

探索可用互动 → 对居民执行有趣操作 → 观察反应和动画 → 发现新互动方式

## 核心机制

- **开放式互动**：没有固定目标或规则，玩家自由探索各种互动方式。这种"玩具"式设计让游戏更像数字沙盒而非传统游戏。
- **反应系统**：每个互动都有独特的动画、音效和连锁反应。居民被闪电劈后会冒烟，被火烧后会跑动，这些反应本身构成内容。
- **剧集式更新**：游戏以"剧集"形式更新内容，每集添加新的互动方式和事件。这种模式在2009年非常创新。
- **居民AI**：居民有基本的自主行为（走路、采集、社交），但也可以被玩家直接控制。

## 为什么好玩

满足"当上帝"的权力幻想——没有道德约束，没有惩罚，只有纯粹的探索和恶作剧乐趣。每次更新都带来新的互动方式，保持新鲜感。居民夸张的卡通反应让每次互动都像看动画片。

## 粘性来源

- **内容更新**：剧集式更新持续添加新内容，老玩家有理由回来
- **探索驱动**：没有目标意味着没有"通关"，总有新互动等待发现
- **社交分享**：有趣的反应和场景适合截图/录屏分享
- **低门槛**：无需学习规则，打开就能玩，适合休闲玩家

## Meta 系统

无 — 这是纯粹的沙盒互动玩具，没有外围系统。所有内容都直接集成到核心互动中。

## 实现难度

低 — 核心是角色动画+物理交互+事件触发，不需要复杂的游戏逻辑。最大技术难点在于动画系统的丰富度——需要大量独特动画来支撑各种互动方式，以及确保物理交互的趣味性。
