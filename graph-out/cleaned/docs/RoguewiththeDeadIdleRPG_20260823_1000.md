# Rogue with the Dead: Idle RPG

- **类型**: 放置/点击
- **平台**: Mobile (iOS+Android)
- **开发商**: room6 inc.
- **首次发布**: 2022
- **一句话描述**: Rogue with the Dead is an original roguelike RPG where you command and power up troops on an endless, looping journey.

## 玩法规则

Rogue with the Dead: Idle RPG是一款放置/点击类移动游戏。游戏的核心体验围绕简单直观的触控操作展开，玩家通过屏幕互动来完成游戏目标。

游戏启动后，玩家看到主界面，通常包含开始按钮、设置选项和可能的进度展示区域。进入游戏后，画面中央是主要游戏区域，四周分布着操作按钮和状态信息。

玩家的操作方式以单指触控为主——点击、滑动或拖拽，具体取决于当前游戏模式。每次操作都会产生即时的视觉和物理反馈，让操作结果一目了然。

游戏的目标因模式而异：在竞速模式中需要比其他玩家更快到达终点；在解谜模式中需要找到正确的解决方案；在放置模式中则是持续积累资源并解锁新的升级。

游戏结束或过关的条件取决于具体模式：竞速模式以到达终点或时间耗尽为结束条件；解谜模式以完成当前关卡的谜题为过关条件；放置模式则没有明确的结束点，而是以不断解锁新内容为持续目标。

## 核心循环

放置 → 获得资源/金币 → 用于解锁升级和新内容

## 核心机制

- **放置战斗循环**：角色自动与怪物战斗，玩家无需持续操作，收益随时间自动累积，离线后仍可获取部分收益
- **Roguelike永久死亡与成长**：每次冒险失败后角色会死亡，但可通过累积资源解锁永久增益，使下一次冒险更强
- **装备与技能选择**：在冒险过程中收集装备和技能书，自由搭配构建独特角色build

## 为什么好玩

数值增长的快感是核心驱动力——每次升级都带来立竿见影的效果提升，让玩家忍不住"再看一眼"进度。离线收益机制确保玩家即使不在线也有成就感。

## 粘性来源

数值增长的持续反馈是最强粘性来源。即使不主动游玩，离线收益也在增长，创造"我赚了"的心理暗示。每次上线都有新的升级可以购买，形成持续的"再玩一会儿"循环。

## Meta 系统

升级与自动化系统：玩家通过累积资源解锁更高效的收集器和自动化设备，显著提升被动收入。升级树提供多个方向选择（产量、效率、解锁新区域），让玩家有策略性参与。对核心玩法的影响：从手动点击逐步过渡到策略管理，玩法重心从操作转向规划。

## 实现难度

中 — 核心循环简单，但需要设计好数值平衡和离线收益系统，最大的技术难点是数据存储和同步

每款独立小游戏的设计都遵循易于上手、难于精通的原则——入门只需几秒钟理解规则，但要达到高分需要反复练习和熟练掌握操作技巧。
