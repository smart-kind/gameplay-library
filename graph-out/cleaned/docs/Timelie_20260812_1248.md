# 时间线（Timelie）

- **类型**: 解谜 / 潜行
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Urbankh
- **首次发布**: 2020
- **一句话描述**: 独特的时间操控解谜游戏，玩家可以预览时间线上的未来事件并回溯。

## 玩法规则

屏幕显示一个2D俯视的设施地图，玩家控制一个角色在设施中移动，目标是避开监控和守卫到达出口。

独特的时间线系统：屏幕底部有一条时间轴，玩家可以拖动它来预览角色在未来几秒内会遭遇什么——守卫会在什么时间经过哪条走廊、监控摄像头会在什么时候转向。

玩家的操作是'先规划再执行'：先预览时间线找到安全路径，然后控制角色按规划移动。如果被发现或失败，可以沿时间线回溯重新规划。

随着关卡推进，设施变得更复杂——更多的守卫、移动的监控、激光陷阱、需要同时操作的机关。

后期需要同时控制两个角色，需要协调两条时间线，一个角色引开守卫，另一个角色通过通道。

## 核心循环

预览时间线找到安全路径 → 规划并执行移动 → 失败则回溯重新规划 → 到达出口进入下一关

## 核心机制

- 时间预览机制：可以像看录像一样预览未来几秒内发生的所有事件，这是游戏的核心创新——让'潜行'从实时反应变成了逻辑推理
- 时间回溯机制：随时可以回到时间线上的任意一点重新开始，消除失败挫折感，鼓励实验和探索
- 多角色协调：后期需要同时操作两个角色，两条时间线需要完美配合，解谜复杂度指数级上升

## 为什么好玩

它重新定义了'潜行解谜'——不再是紧张的实时操作，而是优雅的时间拼图。当你发现一个完美的通过方案时，执行过程的流畅感令人满足。时间预览机制让失败变成学习而非惩罚。

## 粘性来源

解谜完成后的'顿悟'快感（Aha moment）是核心粘性；每个关卡只有一种最优解，找到它需要反复试验和时间规划；关卡难度渐进设计让人上瘾。

## Meta 系统

线性关卡制，无外围系统。纯解谜体验，收集要素为隐藏路径和速通时间挑战。

## 实现难度

中低 — 2D俯视角和基于事件的时间线系统实现相对简单。最大难点是时间回溯时的状态管理和多角色协调的AI逻辑。
