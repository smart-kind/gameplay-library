# CivCrafter

- **类型**: 策略/放置
- **平台**: Mobile (iOS+Android)
- **开发商**: Naquatic
- **首次发布**: 2014
- **一句话描述**: 一款策略与放置相结合的游戏，玩家需要规划资源分配和科技路线，实现文明的持续发展

## 玩法规则

游戏主界面以文明发展界面，展示资源、军队、科技等多个维度的进度条和数值为核心视觉元素，整体布局简洁直观。屏幕上方/中央区域展示多维资源面板和科技树，玩家一眼即可了解当前的核心状态。屏幕下方或侧边排列科技节点、建造按钮和资源分配器，这些是玩家可以交互的按钮或操作区域。

玩家通过点击选择建筑、科技升级和战略决策进行核心操作。具体而言，玩家在资源面板上查看当前各项资源的存量，点击建筑可以查看其产出信息和升级选项。科技树界面中，已解锁的科技节点以亮色显示，未解锁的呈灰色。点击科技节点可以查看前置条件和解锁效果，满足条件后即可投入资源进行研究。资源在建筑之间可以手动调配，形成不同的发展策略。每次操作后，系统会即时给出科技解锁的动画、资源数值变化和建筑建成提示，确保玩家对操作结果有清晰的感知。

游戏的核心目标是建立完整的产业体系，发展军队，征服更多领土。为了达成这一目标，玩家需要采集基础资源，建造生产设施，研究科技解锁新能力，组建军队进行扩张，用征服获得的资源反哺发展。当完成阶段性征服目标或达到科技树顶端时，玩家进入下一阶段或解锁新内容。反之，如果资源链断裂或军事实力不足以抵御入侵，则需要重新开始或调整策略。

随着游戏进程的推进，从单一的农业采集逐步发展到工业生产和科技研究，每个阶段解锁新的建筑类型和单位。玩家需要逐步掌握资源链的优先级排序和科技路线选择，才能在更高难度下持续进步。游戏的深度在于多层资源链和科技树的策略深度让玩家不断优化自己的发展路线。每条科技分支都有独特的加成效果，选择不同的路线组合会产生截然不同的发展轨迹，这让简单的操作框架下蕴含着丰富的策略空间。

游戏中的资源分为经济资源（金币、粮食）、军事资源（兵力、装备）和科技资源（研究点数、知识值），三者之间相互制约又相互促进。

## 核心循环

收集资源 → 建造军队和研究科技 → 征服更多领土获取资源

## 核心机制

- **资源链管理**: 基础资源通过多层加工转化为高级资源，每层加工需要时间和投入，形成完整的产业链。例如：木材→建材→高级建材→奇观。玩家需要确保产业链各环节的产能匹配，避免瓶颈
- **科技树解锁**: 通过消耗资源解锁科技节点，每个节点解锁新功能或效率加成。科技树有多条分支路线，玩家需要根据自身发展策略选择优先解锁的路径。某些高级科技需要多个前置节点同时满足
- **自动化战争**: 军队自动执行战斗任务，玩家负责战前配置（兵种搭配、进攻目标）和资源补给。战利品转化为后续发展的资源，形成战争-发展-再战争的正向循环

## 为什么好玩

从一颗棋子到整个帝国的扩张过程令人着迷。科技树的多路线选择和资源链的复杂管理为看似简单的放置游戏注入了策略深度，每次做出正确的决策都能看到实实在在的发展成果。

看着自己的文明从原始部落一步步发展到繁荣帝国，这种"从无到有"的创造过程本身就充满成就感。

## 粘性来源

多层资源链和科技树的策略深度让玩家不断优化自己的发展路线。每次转生后尝试不同的科技分支组合，形成"再来一局试试另一种策略"的驱动力。"就差一个科技就能解锁XXX"的期待感持续推动游玩。

征服不同领土带来的多样性奖励让每次扩张都有新的发现，保持探索的新鲜感。

## Meta 系统

科技树永久加成系统：通过成就解锁科技树中的永久节点，影响后续轮次的起始资源、建造速度和单位强度。对核心玩法的影响是提供不同的发展路线选择，让每轮游戏都有新的策略可能性。

成就系统记录了玩家的里程碑数据（如"累计征服50块领土"），既是荣誉也是额外加成的来源。

## 实现难度

中高。需要设计完整的资源链、科技树和自动化战斗系统。最大技术难点：多维度资源系统的平衡——确保不同发展路线的竞争力相当，以及AI战斗逻辑的合理性。
