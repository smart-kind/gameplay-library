# Idle Stickman

- **类型**: 放置 / 动作
- **平台**: Mobile (iOS)
- **开发商**: Zplay (Beijing) Info. Tech. Co.,Ltd.
- **首次发布**: 2019
- **评分**: ⭐ 4.8/5 (24,722 评价)
- **价格**: Free
- **一句话描述**: 欢迎来到你的火柴人工厂！训练各种武器的火柴人，消灭敌人，解锁50+火柴人和武器。

## 玩法规则

游戏画面中，火柴人自动战斗。玩家通过点击屏幕加速生产火柴人战士。不同火柴人使用不同武器（剑、弓箭、魔法等），有不同攻击力和速度。随着游戏进展，解锁更强大的火柴人和武器。敌人一波波来袭，玩家需要确保火柴人的数量和质量足够应对。界面包含：战斗场景（火柴人自动对战）、资源计数器、解锁/升级菜单。

## 核心循环

点击生产火柴人 → 自动战斗消灭敌人 → 获得资源 → 解锁新火柴人/武器 → 面对更强敌人

## 核心机制

- 自动战斗：火柴人自动攻击敌人，玩家只需管理生产
- 多样性解锁：50+火柴人和武器，每种有不同特性
- 波次敌人：敌人一波波增强，需要持续升级

## 为什么好玩

火柴人战斗的视觉效果有趣。看着自己的火柴人大军壮大并碾压敌人，满足感极强。

## 粘性来源

解锁收集（50+火柴人）、数值成长、自动战斗的轻松感

## Meta 系统

放置生产+解锁收集系统。核心玩法即meta。

## 实现难度

低——放置+自动战斗模板成熟
