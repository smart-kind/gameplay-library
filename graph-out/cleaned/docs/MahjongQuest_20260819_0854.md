# Mahjong Quest

- **类型**: 麻将消除 / 益智解谜
- **平台**: PC / Mobile (iOS+Android)
- **开发商**: Vinnick
- **首次发布**: 2005
- **一句话描述**: 将传统麻将配对玩法与冒险地图结合的消除游戏，玩家通过消除麻将块来推进故事

## 玩法规则

游戏画面展示一个堆叠的麻将块金字塔或自定义形状的布局。每个麻将块上有传统麻将图案（筒子、条子、万子、风牌、花牌等）。

玩家操作：
- 点击/触摸：选择一块未被其他块覆盖的麻将（即自由块）
- 配对：选择另一块相同图案的麻将，两块配对后消除
- 自由块判定：只有上方没有其他块覆盖，且至少左侧或右侧没有其他块紧邻的麻将才能被选择

游戏目标：消除所有麻将块即可过关。

核心规则：
- 只能选择"自由"的麻将块（未被上方块覆盖）
- 两块相同图案的自由块可以配对消除
- 某些版本中，花牌可以与任意其他花牌配对
- 关卡通常有时间限制或步数限制
- 部分麻将块有特殊效果（炸弹、提示、洗牌等）

游戏结束条件：
- 消除所有麻将块则过关
- 时间用完或步数用完则失败
- 没有可配对的自由块时游戏结束（死锁）

## 核心循环

配对消除麻将 → 推进冒险地图 → 解锁新关卡 → 面对更复杂布局

## 核心机制

- **麻将配对**: 经典麻将连连消玩法，需要识别相同图案并判断哪些块是"自由"可操作的，考验观察力和空间思维
- **冒险地图**: 与传统麻将消除不同，Mahjong Quest将消除进度映射到冒险地图上，每完成一组消除就推进一段故事情节，增加叙事驱动
- **层叠布局**: 麻将块多层堆叠形成立体结构，玩家需要从上到下逐层消除，规划消除顺序以避免死锁
- **道具辅助**: 提示（高亮可配对块）、洗牌（重新排列剩余块）、炸弹（消除指定块）等道具帮助玩家度过难关

## 为什么好玩

传统麻将配对玩法与冒险叙事的结合让它不同于普通麻将消除游戏。看着地图一步步推进、故事逐渐展开，给消除过程增加了目标感。多层堆叠的布局要求玩家有策略地规划消除顺序，而不是盲目配对。

## 粘性来源

冒险地图的进度推进是主要粘性来源，玩家想知道故事接下来会发生什么。关卡布局的复杂性递增（更多层、更多图案、更少的道具）提供持续挑战。收集元素（隐藏物品、成就）增加额外目标。

## Meta 系统

冒险故事系统。玩家通过消除麻将块推进地图上的冒险旅程，每个章节有独特的故事背景和目标。消除进度直接影响故事进展，对核心玩法的影响是提供叙事驱动的目标感。

## 实现难度

中。核心技术是3D层叠布局的渲染和自由块判定算法。最大技术难点在于确保每关有解（死锁检测和布局生成），以及3D堆叠结构的空间计算。
