# 果冻防御（Jelly Defense）

- **类型**: 塔防/策略
- **平台**: iOS / Android / PC
- **开发商**: Infinite Dreams
- **首次发布**: 2011
- **一句话描述**: 画面精美的塔防游戏，玩家放置两种不同类型的果冻塔来保护 Jelly 王国免受敌人入侵。

## 玩法规则

画面为横向卷轴地图，敌人从右侧沿着固定路径向左移动，目标是到达左侧的 Jelly 王国。玩家需要在路径两侧放置塔防单位——果冻塔。

游戏中有两种基本塔类型：
- **红色果冻塔**：对红色敌人有额外伤害，对蓝色敌人伤害较低
- **蓝色果冻塔**：对蓝色敌人有额外伤害，对红色敌人伤害较低

这个颜色克制系统是游戏的核心策略——玩家需要根据来袭敌人的颜色组合来决定放置哪种塔。后期还会出现混合颜色的敌人，需要两种塔配合。

敌人沿着蜿蜒的路径前进，玩家在路径旁边放置塔。塔自动攻击范围内的敌人。每关开始前可以看到敌人波次的预览，让玩家提前规划防御布局。

操作：点击塔图标选择类型，点击地图上的空位放置。游戏进行中可以点击塔升级。

## 核心循环

观察敌人波次 → 放置果冻塔 → 塔自动攻击敌人 → 收集掉落的资源 → 升级塔或放置新塔

## 核心机制

- **颜色克制**：核心策略层。红色塔打红色敌人伤害翻倍，打蓝色只有50%。玩家需要根据敌人组合灵活搭配两种塔。
- **双塔系统**：只有两种塔，但通过升级（攻击力、射程、攻速）可以产生丰富的变体。
- **路径限制**：敌人沿固定路径移动，玩家只能在路径两侧放置塔。这限制了布局自由度，但也降低了决策复杂度。
- **资源管理**：击杀敌人获得资源（星星），用于购买和升级塔。需要在"多放塔"和"升级已有塔"之间权衡。

## 为什么好玩

将塔防简化到极致——只有两种塔、颜色克制、固定路径。但这种简化反而让每局都充满策略性：什么时候放红塔？什么时候放蓝塔？升级还是新放？可爱的果冻美术风格让紧张的战斗多了几分轻松。

## 粘性来源

- **关卡递进**：每关敌人组合更复杂，需要更精妙的塔布局
- **升级系统**：塔可以升级，提供成长感
- **视觉满足感**：果冻塔的Q弹动画和爆炸效果非常有满足感
- **短局节奏**：每关3-5分钟，适合碎片时间

## Meta 系统

- **塔升级**：永久性升级（攻击力、射程、攻速）
- **关卡解锁**：完成关卡解锁新关卡
- **对核心玩法的影响**：升级让后期关卡更容易，但不改变核心的颜色克制+塔防机制

## 实现难度

低 — 塔防逻辑成熟，颜色克制系统简单。最大技术难点在于动画效果——果冻塔的Q弹动画和攻击特效需要流畅且有趣。
