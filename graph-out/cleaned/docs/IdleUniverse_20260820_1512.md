# Idle Universe（Idle Universe）

- **类型**: 放置 / 模拟 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: Digital Media Technology SLU
- **首次发布**: 2024
- **一句话描述**: 一款以宇宙演化为主题的放置类游戏，从大爆炸开始逐步创造恒星、行星和生命，体验宇宙从无到有的壮丽过程。

## 玩法规则

Idle Universe 的画面呈现一个宇宙空间，初始状态下一片黑暗，只有中央一个微小的光点。玩家通过点击或放置操作触发"大爆炸"，开始宇宙演化过程。爆炸后，基本粒子开始形成，逐步演化为更复杂的结构。

屏幕分为几个区域：中央是宇宙主画面（恒星、行星、星系等天体的实时画面），下方是能量面板和操作按钮（创造天体、升级、加速），侧边是演化进度和已创造的天体列表。

宇宙的基本资源是"能量"，通过恒星等天体的自然辐射持续产生。玩家消耗能量来创造新的天体：先创造恒星（提供能量），然后用恒星的能量创造行星，再创造卫星、小行星带、星云等更复杂的天体结构。

随着天体数量增加，宇宙的复杂度提升。某些天体组合会触发特殊事件（如行星碰撞产生新物质、生命在适宜的行星上诞生、超新星爆发创造重元素）。这些事件是游戏的重要里程碑，标志着一个演化阶段的完成。

## 核心循环

天体自然产生能量 → 消耗能量创造新天体 → 触发天体组合事件 → 宇宙复杂度提升 → 创造更高级天体 → 见证新演化阶段

## 核心机制

- **指数增长经济模型**：天体数量增加导致能量产出增加，形成自我强化的增长循环，后期增速极快
- **天体组合事件系统**：特定天体组合触发特殊事件（生命诞生、超新星爆发等），增加策略性和期待感
- **宇宙演化时间线**：从大爆炸到生命诞生的完整时间线，提供清晰的长期目标和阶段性里程碑
- **离线收益机制**：离线期间天体继续产生能量，重新打开时显示离线期间的新天体和事件

## 为什么好玩

宇宙演化的主题本身就充满魅力——从一片虚无到繁星点点，再到生命诞生，每一步都让人惊叹。看着自己"创造"的宇宙逐渐变得复杂和美丽，有一种创世者的满足感和宏大的成就感。

游戏将数十亿年的宇宙演化浓缩在几十分钟的游玩体验中，这种时间尺度的压缩让人惊叹。从基本粒子到恒星，从恒星到行星，从行星到生命——每一步都对应着真实的科学原理。看着一片黑暗变成繁星点点的宇宙，这种视觉冲击是其他游戏难以复制的。

## 粘性来源

"解锁下一个演化阶段"的期待感。从恒星到行星到生命，每个新阶段都带来全新的天体和事件，以及全新的视觉效果。宇宙的视觉扩张（从几个点到整个星系）提供了强烈的成就感，让人想看看"最终会是什么样子"。

## Meta 系统

宇宙演化时间线（记录所有已触发的里程碑事件）+ 天体图鉴（收集所有天体类型，记录创造条件和特性）+ 总能量统计（衡量宇宙规模）。

## 实现难度

中 — 需要实现天体间的引力模拟和组合事件检测系统。最大难点是指数增长模型的经济平衡，确保增长速度既不显得太慢也不失控，以及后期大量天体的渲染性能优化。
