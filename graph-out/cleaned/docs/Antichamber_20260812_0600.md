# 反室（Antichamber）

- **类型**: 解谜 / 第一人称 / 非欧几何
- **平台**: Steam
- **开发商**: Alexander Bruce
- **首次发布**: 2013
- **一句话描述**: 在一个不断欺骗你感知的第一人称解谜游戏中，忘掉所有你对空间和逻辑的常识。

## 玩法规则

游戏以第一人称视角呈现，玩家在一个白色抽象的迷宫中探索。迷宫由各种走廊、房间和通道组成，但这些空间的运作方式完全违反直觉。

核心体验是空间悖论：
- 走一条走廊，到达的目的地和你出发时的朝向不一致
- 回头看看来时的路，发现它已经改变了
- 走进一扇门，从另一扇门出来，但位置完全不符合逻辑
- 同一个空间从不同方向进入，内部的布局不同

玩家有一个特殊的"枪"，可以拾取和放置彩色方块。这些方块用于压住开关、阻挡激光、或者作为垫脚石。但方块的使用也受到空间悖论的影响——你放置方块的位置可能在你转身之后就不存在了。

游戏没有明确的终点或线性路径。玩家需要通过探索、实验和观察来理解这个空间的"规则"，而这些规则本身就是反常规的。

## 核心循环

进入一个房间/通道 → 尝试理解其空间逻辑 → 使用方块工具解决问题 → 发现新路径 → 继续探索

## 核心机制

- **非欧几何**：空间不遵循常规几何规则。转弯可能改变方向但不改变位置，前进可能回到原点
- **方块枪**：唯一工具，可以拾取和放置彩色方块。不同颜色的方块有不同的属性
- **感知欺骗**：游戏的核心设计是挑战玩家的空间直觉。你看到的不一定是你得到的
- **实验性学习**：没有教程，玩家必须通过尝试和失败来理解每个区域的运作方式
- **渐进理解**：随着游戏进程，玩家逐渐学会用"非直觉"的方式思考空间

## 为什么好玩

Antichamber 是少数真正挑战玩家认知方式的游戏。它不只是"难"，而是从根本上改变了你对"难"的定义——在大多数游戏中，困难来自于反应速度或操作技巧，但在这里，困难来自于"我不知道这个世界的规则是什么"。每次你以为自己理解了某个区域，它就会用一个新的悖论来颠覆你的理解。

## 粘性来源

1. **认知挑战**——不是操作难，而是理解难，这种挑战是全新的
2. **实验乐趣**——尝试各种操作来"探测"空间的运作方式，像在做科学实验
3. **突破快感**——当你终于理解一个区域的逻辑时，那种"啊！"的顿悟非常强烈
4. **艺术体验**——极简的白色美学和抽象的空间设计创造了独特的艺术感

## Meta 系统

无。游戏没有评分、成就系统之外的 Meta。所有的"成长"都是认知层面的。

## 实现难度

高。核心技术是实现非欧几何的空间渲染和逻辑。需要自定义的渲染管线和碰撞检测系统，因为标准的 3D 引擎都是基于欧几里得几何的。最大技术难点是确保空间悖论在技术上可行——比如一个走廊的两端连接到不同的位置，这需要特殊的世界渲染和传送逻辑。
