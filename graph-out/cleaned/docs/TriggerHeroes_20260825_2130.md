# Trigger Heroes

- **类型**: 肉鸽射击
- **平台**: Mobile (iOS+Android)
- **开发商**: Lucky Kat Studios
- **首次发布**: 2018
- **一句话描述**: 一款俯视视角的肉鸽射击游戏，以随机武器收集和弹幕躲避为核心体验

## 玩法规则

游戏主界面以俯视视角的战场地图，敌人从四面八方涌来，子弹在屏幕上飞舞为核心视觉元素，整体布局简洁直观。屏幕上方/中央区域展示角色位置、敌人分布和弹幕图案，玩家一眼即可了解当前的核心状态。屏幕下方或侧边排列触摸控制区域和武器信息面板，这些是玩家可以交互的按钮或操作区域。

玩家通过单指触摸控制角色移动和射击方向进行核心操作。具体而言，玩家触摸屏幕上的任意位置，角色会向该方向移动并同时自动射击。松开手指角色停止移动但继续射击。击败敌人后会随机掉落武器，拾取新武器会替换当前武器。不同武器有不同的射速、伤害、弹道和特殊效果（如穿透、散射、追踪）。随着波数推进，敌人数量和弹幕密度逐渐增加。每次操作后，系统会即时给出命中伤害数字、爆炸特效和武器切换动画，确保玩家对操作结果有清晰的感知。

游戏的核心目标是尽可能存活更久并通关所有Boss关卡。为了达成这一目标，玩家需要控制角色移动躲避弹幕，击败敌人获取新武器，选择最优武器应对当前战况，挑战阶段Boss。当击败所有阶段Boss通关游戏时，玩家进入下一阶段或解锁新内容。反之，如果角色生命值归零，当前回合结束，则需要重新开始或调整策略。

随着游戏进程的推进，每通过一个区域会进入新的环境主题，敌人类型和弹幕模式发生变化，武器池也会更新。玩家需要逐步掌握弹幕模式识别和武器特性运用，才能在更高难度下持续进步。游戏的深度在于单指操作的极简控制与紧张刺激的弹幕躲避形成强烈反差。每次捡到新武器都带来不同的战斗体验，武器的随机掉落让每局都有独特的节奏和策略。"再来一局"的冲动难以抑制，这让简单的操作框架下蕴含着丰富的策略空间。

游戏中的弹幕图案遵循一定的数学规律，玩家通过学习这些规律可以找到安全的移动路径，这赋予了看似混乱的弹幕以可学习性和可预测性。

## 核心循环

消灭敌人获取武器 → 探索新区域遭遇更强敌人 → 获取更强武器继续推进

## 核心机制

- **单指操控射击**: 通过触摸屏幕控制角色移动和射击方向，操作极简但需要精确的时机把握和走位判断。手指的位置同时决定了移动方向和射击方向，玩家需要在两者之间找到平衡
- **随机武器掉落**: 击败敌人后随机掉落武器，每种武器有独特的射速、伤害和弹道特性。从机枪到激光，从散射到追踪，每种武器改变战斗策略。玩家无法预知下一个武器是什么，需要快速适应
- **阶段Boss战**: 每5层出现阶段Boss，拥有独特的攻击模式和大量生命值。Boss的弹幕有明确的规律和可学习的躲避节奏，掌握后形成"背板"的成就感。Boss战中获得的奖励通常更丰厚

## 为什么好玩

单指操作的极简控制与紧张刺激的弹幕躲避形成强烈反差，每次捡到新武器都带来不同的战斗体验。弹幕游戏的"擦弹"快感和肉鸽的随机性结合，让每局都充满新鲜感。

"这把武器太厉害了"的惊喜时刻和"差点就躲过了"的刺激感交替出现，情绪波动本身就是核心乐趣。

## 粘性来源

随机武器掉落的惊喜感和"差一点就通关"的不甘是核心粘性。每次死亡后都能解锁新的起始选项，让下一次尝试感觉更有希望。"这把武器太厉害了，再来一局试试"的循环让人停不下来。

排行榜的社交比较增加了外部动力，看着自己的名字向上攀升也是一种成就感。

## Meta 系统

永久解锁系统：通过完成挑战解锁新角色、起始武器和被动能力。对核心玩法的影响是扩大可选策略范围，但不降低基础难度。解锁内容作为收集目标，增加长期游玩动力。

隐藏角色的解锁条件本身就是一个挑战目标（如"在不受伤的情况下通关"），鼓励玩家探索极限玩法。

## 实现难度

中高。弹幕物理、碰撞检测和随机武器系统需要精细实现。最大技术难点：弹幕系统的性能优化和Boss攻击模式的流畅性——在移动设备上维持高帧率的同时处理大量弹幕和碰撞计算。
