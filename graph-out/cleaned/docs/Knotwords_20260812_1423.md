# 结词（Knotwords）

- **类型**: 字谜 / 逻辑解谜
- **平台**: Mobile (iOS+Android) / Web
- **开发商**: Zach Gage
- **首次发布**: 2021
- **一句话描述**: 一款创新的字谜游戏，将填字游戏和数独的玩法融合在一起，玩家在网格中填入字母形成纵横交错的单词。

## 玩法规则

游戏在一个不规则形状的网格上进行，网格被划分为多个区域。
每个区域需要填入特定的字母集合，玩家从底部的字母池中选择字母填入网格。
填入的字母必须在横向和纵向上都形成有效单词（或单词的一部分）。
操作：点击网格格子，然后从字母池中选择字母填入；再次点击已填入的格子可以修改。
当所有格子都填入正确字母且纵横都形成有效单词时，关卡自动完成。
与填字游戏不同，Knotwords不提供单词提示或定义，玩家需要通过字母组合的逻辑推断出正确排列。
与数独相似之处在于每个区域的字母集合是固定的，只是排列不同。

## 核心循环

观察网格和字母池 → 推断字母排列 → 填入格子 → 纵横检查 → 完成所有单词

## 核心机制

- **填字+数独融合**：结合了填字游戏（字母纵横成词）和数独（固定字母集合的区域约束）两种经典玩法的要素。
- **无提示推断**：不提供单词定义或首字母提示，完全依靠字母组合的逻辑和已知单词来推断未知部分。
- **每日谜题**：游戏提供每日更新的谜题，类似Wordle的模式，培养每日游玩习惯。
- **渐进式难度**：谜题从简单的3×3网格开始，逐步增加到更复杂的形状和更大的字母组合。

## 为什么好玩

将两种经典解谜游戏巧妙融合，创造出全新的思维挑战。每次填入字母后的验证反馈让人有'啊哈'的顿悟时刻。

## 粘性来源

每日谜题机制培养习惯；每局时间短（5-15分钟）适合碎片化游玩；解开单词后的成就感强；字母组合的可能性丰富。

## Meta 系统

无成长系统。每日更新谜题，已完成谜题可无限重玩。

## 实现难度

低 — 核心是字典匹配和约束满足算法，技术实现中等。最大技术难点在于词典的维护和有效单词的判定，以及生成有唯一解的高质量谜题。

## 游戏变体

多数游戏在不同平台上发布了HD版、重制版或移植版本，核心玩法保持不变。
