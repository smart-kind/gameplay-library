# Stray

- **类型**: 冒险 / 探索
- **平台**: PC / PS / Xbox
- **开发商**: BlueTwelve Studio
- **首次发布**: 2022
- **一句话描述**: 以流浪猫视角探索赛博朋克城市的冒险游戏，独特的视角和氛围。

## 玩法规则

玩家扮演一只在赛博朋克地下城市中迷路的流浪猫。游戏以第三人称视角呈现——玩家控制猫在城市的屋顶、小巷和房间中穿梭、跳跃和攀爬。

核心玩法是探索和轻度解谜——找到前进的路径、与环境互动（抓沙发、推倒物品、喵喵叫）、与机器人居民交流。猫的行为高度还原真实猫咪——可以跳跃到高处、钻进狭小空间、抓挠表面。

游戏的氛围营造极为出色——赛博朋克风格的地下城市、霓虹灯光、雨水和蒸汽，配合猫咪的视角创造了一种独特的沉浸感。

## 核心循环

探索城市 → 与环境互动 → 解谜推进 → 找到回家的路

## 核心机制

- 猫咪视角：独特的第三人称猫咪控制
- 探索驱动：在赛博朋克城市中自由探索
- 轻度解谜：找到路径和与环境的互动
- 真实猫咪行为：跳跃、攀爬、抓挠、喵喵叫
- 氛围沉浸：霓虹灯光、雨水、蒸汽的赛博朋克美学

## 为什么好玩

以猫咪视角探索赛博朋克城市的体验独一无二。真实还原的猫咪行为（抓沙发、推东西）带来意外的乐趣。

## 粘性来源

- 独特视角：以猫咪而非人类视角探索世界
- 猫咪行为的真实感：每个动作都让人会心一笑
- 赛博朋克氛围：精美的视觉和音效设计
- 情感连接：为猫咪找到回家路的情感驱动力

## Meta 系统

无。游戏是纯粹的线性冒险体验。

## 实现难度

中。猫咪动画和行为模拟需要大量动画工作。赛博朋克城市的美术和环境设计也是重要投入。
