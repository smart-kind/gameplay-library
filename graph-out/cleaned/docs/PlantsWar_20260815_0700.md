# 植物战争（Plants War）

- **类型**: 策略 / 塔防 / 动作RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: Gamevil
- **首次发布**: 2012
- **一句话描述**: 人类灭亡后植物与动物争夺地球控制权的策略游戏，玩家操控植物英雄和单位从基地出发进攻敌方基地。

## 玩法规则

游戏采用对称地图布局：玩家的基地在一端，敌方动物阵营基地在另一端。中间是战斗区域。

战斗前，玩家选择携带的英雄角色和一组单位（兵种）。不同单位有不同技能，对某些对手有克制关系。初始选择有限，随着进程解锁更多兵种。

战斗中，玩家通过点击屏幕控制英雄移动和攻击。单位会自动向敌方推进并交战。玩家也可以让植物单位自动作战，自己只需控制英雄。

英雄通过战斗获得经验升级，升级后可获得技能点。技能点可以分配到不同方向：学习或强化特殊技能、增加攻击力、或提升其他属性。

通关条件为摧毁敌方基地。
## 核心循环

选择兵种，操控英雄出战，获得经验升级技能，解锁更多兵种，挑战更难的关卡

## 核心机制

- **英雄加单位混合战斗**：英雄由玩家直接操控（点击移动和攻击），单位自动推进交战，结合了RPG和RTS元素
- **局内技能成长系统**：英雄在单局战斗中升级获得技能点，可即时分配强化属性或学习新技能，但每局结束后重置
- **兵种克制系统**：不同单位对特定敌人有强弱关系，战前编队需要考虑阵容搭配
- **Freemium付费模式**：游戏内货币和付费道具加速进程

## 为什么好玩

植物vs动物的设定有新意，英雄加兵种的混合玩法理论上有趣，但实际体验偏向点击重复操作，策略深度不足。

游戏的付费系统设计较为激进。虽然基础游戏可以免费游玩，但获取强力兵种和加速进程的成本较高。这种设计在当时的移动游戏市场较为常见，但在后续玩家评价中普遍被认为是减分项。

每场战斗的地图虽然布局相似，但敌方兵种配置和数量会有变化。玩家需要根据敌人的阵容调整自己的兵种选择。

英雄角色有多个可选，每个英雄拥有不同的基础属性和初始技能。英雄的选择会影响战斗风格和战术偏好。

技能树系统允许玩家在不同发展方向之间做出选择：是优先强化英雄的个人战斗能力，还是增加召唤单位的数量和强度。
## 粘性来源

技能升级带来的数值成长是主要驱动力，但核心玩法缺乏足够的策略变化，容易陷入点击等待的循环。付费系统反而可能挫伤玩家积极性。

## Meta 系统

英雄等级系统（跨局永久成长）和局内临时技能系统（单局内成长）。付费货币系统允许玩家购买加速道具和更强单位。永久等级解锁新兵种，对核心玩法的影响在于扩大可选策略范围。

## 实现难度

中等。最大技术难点在于多单位AI路径规划和战斗计算的同步，以及触屏操作下精准控制英雄移动的体验优化。
