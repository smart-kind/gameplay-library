# 100道门逃脱游戏（100 Doors Escape Game）

- **类型**: 解谜 / 逃脱
- **平台**: Mobile (iOS+Android)
- **开发商**: Peaksel
- **首次发布**: 2019
- **一句话描述**: 经典的100道门系列，每扇门代表一个关卡，需要解开不同谜题才能打开门通过的益智游戏。

## 玩法规则

每个关卡呈现一扇关闭的门，门上或周围有一个需要解决的谜题。谜题类型极为多样，涵盖：滑动拼图、数学计算、颜色匹配、形状识别、找不同、拖拽排序、重力感应、长按/连点等。

玩家通过多种手势操作解谜：点击、长按、拖拽、滑动、摇动设备等。例如：长按按钮直到能量条满门就打开；滑动数字排列成正确顺序；摇晃手机让隐藏的钥匙掉落；拖拽图形拼成门上的图案等。

谜题通常不给出明确说明，玩家需要通过观察门的特征、周围环境元素来推断操作方式。这种'猜'的过程是游戏的核心——观察、假设、验证、调整。

每打开一扇门就自动进入下一关。100道门从简单到困难逐步递增，早期门可能只需点击就能打开，后期门则需要多步操作和多种技能的组合。

## 核心循环

观察门的谜题 → 尝试不同操作 → 根据反馈调整 → 打开门进入下一关

## 核心机制

- 无提示探索机制：游戏不告诉玩家每个谜题怎么解，玩家需要自己发现操作方式。这种'发现游戏规则'的过程本身就是一种解谜，让简单的开门动作变得有趣。
- 操作类型轮换机制：点击、拖拽、滑动、长按、摇动等操作类型交替出现，防止玩家形成固定思维。每次新门都是新的'交互实验'。
- 100关卡递进机制：从第1门的'点击开门'到第100门的'多步骤复合谜题'，100关的设计让'通关全部100道门'成为一个明确的、有吸引力的目标。
- 环境暗示机制：门周围的物品、颜色、图案都是谜题的线索。例如门上有3个颜色孔，旁边正好有3个对应颜色的物品——玩家自己发现这个关联时获得'啊哈时刻'。

## 为什么好玩

每扇门都是一个新的'交互谜题'，没有两个关卡是完全一样的解谜方式。发现'原来是要摇手机'或'原来是要长按'的瞬间惊喜感是核心乐趣。100关的明确目标让通关有仪式感。

## 粘性来源

数字目标驱动——'我已经开了50/100道门'的进度感让人想完成全部。同时，每个关卡的短时长（1-3分钟）让'再来一关'几乎没有阻力。

## Meta 系统

100关卡线性推进，无外围系统。完成全部100道门即为通关。部分版本有续作（200门、300门等）扩展内容。

## 实现难度

低。单个谜题逻辑简单，交互操作成熟。最大难点在于100个谜题的多样性设计——确保每个门都有独特的解谜方式且不重复，需要大量创意。

100道门的设计哲学是'每扇门都是一个独立的交互实验'。从第1门的简单点击到第100门的复杂多步操作，整个过程是玩家与游戏交互方式的'学习曲线'。每扇门都在教玩家一种新的交互可能性，当玩家掌握所有操作类型时，游戏也完成了它的教学使命。
