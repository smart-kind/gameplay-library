# Meowcenaries（Meowcenaries）

- **类型**: 双摇杆射击/动作
- **平台**: Mobile (iOS)
- **开发商**: Mr Goodliving
- **首次发布**: 2010
- **一句话描述**: 四只猫咪佣兵排成单列执行营救总统任务的双摇杆射击游戏

## 玩法规则

游戏采用经典双摇杆射击布局，画面为俯视视角。四只猫咪佣兵排成一列，跟随领头猫咪移动。

**操作方式**：
- 左侧虚拟摇杆控制猫咪队伍的整体移动方向
- 右侧虚拟摇杆控制射击方向，向敌人开火
- 点击屏幕瞄准特定目标
- 滑动调整队伍在战场上的位置

**核心玩法**：
- 四只猫咪排成单列跟随领头猫移动
- 领头猫咪按玩家指令移动，后面的猫咪依次跟随
- 队尾猫咪容易"掉队"暴露，需要玩家注意保护
- 精心布置队伍位置可以增加火力覆盖范围
- 与敌方猫咪（BadCatz）进行枪战

**胜利/结束条件**：
- 任务成功：击败所有敌人并完成关卡目标
- 任务失败：猫咪队伍全部被消灭

## 核心循环

移动猫咪队伍 → 射击敌人 → 完成关卡 → 解锁新任务

## 核心机制

- **双摇杆射击**：左摇杆移动右摇杆射击的经典移动端操作
- **跟随系统**：领头猫咪按指令移动，其他猫咪依次跟随成单列
- **阵型保护**：队尾猫咪容易暴露，需要玩家注意保护
- **火力扩散**：合理布置队伍位置增加射击覆盖面
- **卡通幽默**：LOL猫咪军事化的荒诞设定，故意 tongue-in-cheek 的幽默感

## 为什么好玩

将LOL猫咪文化军事化，四只不会拼写"entrance"的猫咪执行英雄任务，这种荒诞设定为射击游戏增添了独特娱乐价值。猫咪排成单列跟随的机制为传统射击增加了策略层次。

## 粘性来源

- **幽默感驱动**：猫咪军事行动的荒诞设定让人忍不住继续
- **关卡推进**：完成当前关卡解锁后续内容
- **策略深度**：如何布置猫咪阵型获得最大火力覆盖
- **射击快感**：双摇杆射击的即时满足感

## Meta 系统

- **关卡解锁**：完成当前关卡解锁后续任务

## 实现难度

低 — 双摇杆射击框架成熟，主要技术难点在于跟随系统AI设计和火力覆盖计算。
