# 空闲猎人：放置点击（Idle Slayer: Addictive Clicker）

- **类型**: 放置 / 点击 / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Pablo Leban
- **首次发布**: 2020
- **一句话描述**: 一款自动奔跑+自动战斗的放置游戏，通过升级装备和技能不断提升效率。

## 玩法规则

游戏画面中，一个猎人角色自动向右奔跑，沿途自动攻击遇到的怪物。玩家的角色持续移动，不需要手动控制方向。

玩家主要操作是点击怪物进行额外攻击，获得金币奖励。金币用于在商店中购买新武器、升级攻击力、解锁技能。

游戏设计了多个世界/关卡区域，每个区域有不同外观和不同强度的怪物。当玩家击杀足够多的怪物后，自动进入下一区域。

角色死亡后会回到上一个检查点，但已获得的永久升级保留。游戏通过" Prestige"（转生）系统允许玩家重置进度以获取特殊货币，用于购买全局加成。

画面底部显示角色的攻击力、金币获取率、当前区域等关键数值。升级按钮始终可见，方便随时购买。
## 核心循环

自动击杀怪物获取金币 → 购买装备和技能升级 → 进入更高难度区域 → 转生获取特殊货币 → 全局加成加速

## 核心机制

- **自动战斗+手动加速**：角色自动攻击但玩家点击可额外输出，兼顾放置的轻松感和手动参与的爽快感。
- **转生系统(Prestige)**：重置当前进度获取特殊货币，购买永久性全局加成。这是放置类最经典的长期循环设计，让玩家在每次重置后感觉比之前更强。
- **区域递进解锁**：每个区域有独特的怪物群和视觉风格，击杀进度条满了自动前进，提供明确的阶段性目标。

## 为什么好玩

看着角色从被小怪虐到一刀秒杀全屏的逆袭过程非常爽快。每次转生后的'我比上次强10倍'的感觉是核心乐趣。

## 粘性来源

转生后的数值飙升是核心粘性。'再转一次就能更快'的心理驱动持续游玩。区域解锁提供短期目标，转生次数和总金币提供长期追求。

## Meta 系统

转生货币系统。每次重置获得灵魂宝石等特殊货币，可购买永久加成如'全局金币+50%'、'暴击率+5%'等。这些加成跨转生效，是游戏的长期进度载体。

## 实现难度

中 — 自动战斗逻辑不复杂，但转生系统的设计需要精细的数值平衡。技术难点在于多区域无缝切换和大量怪物AI同时运行的性能。

## 同类游戏

与此游戏类似的推荐：放置类可参考 Clicker Heroes 和 Idle Slayer；肉鸽类可参考 Slay the Spire 和 Vampire Survivors。
