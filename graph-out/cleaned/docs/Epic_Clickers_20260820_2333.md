# 史诗点击（Epic Clickers）

- **类型**: 放置 / 点击
- **平台**: Mobile (iOS+Android)
- **开发商**: Tiny Games
- **首次发布**: 2014
- **一句话描述**: 经典放置点击游戏，通过点击和升级不断提升效率，追求数值极致。

## 玩法规则

游戏采用经典的放置点击布局：屏幕中央是一个可以交互的主目标（通常是一个生物或物体），下方是升级选项列表。

玩家点击主目标获得金币。金币用于购买两种升级：'每次点击金币+'（增加手动点击的收益）和'每秒自动金币'（实现自动化）。

游戏设计了多层级的自动生产单元，从最低级的'助手'到最高级的'传奇生物'，每个单元有不同的成本和产出效率。购买越多，单价越高。

随着金币积累，玩家可以解锁新的关卡/世界。每个世界有不同的视觉主题和更高的金币倍率。进入新世界后，之前的自动生产继续工作。

游戏界面保持简洁，主目标可以切换外观，升级按钮显示当前成本和效果。进度条显示距离下一个里程碑的距离。
## 核心循环

点击获取金币 → 购买自动生产单元 → 金币自动增长 → 解锁新世界 → 重复循环追求更高数值

## 核心机制

- **双层升级系统**：'点击收益'和'自动产出'两条线并行，玩家需要在手动效率和自动化之间做权衡。早期侧重点击收益，后期完全依赖自动产出。
- **递进定价**：每个生产单元的购买价格按固定比例递增（约1.15倍），确保经济曲线平滑。玩家始终面临'买哪个最划算'的决策。
- **世界/关卡切换**：不同世界提供不同的金币倍率和视觉主题，切换世界是进度感的显性标记，同时不会中断已有生产。

## 为什么好玩

看着金币数字飞速滚动的快感是最直接的满足。从一个点击只值1金币，到每秒百万金币的飞跃，数值增长本身就是乐趣。

## 粘性来源

数值增长的持续反馈是核心粘性。每次购买后'效率提升'的即时感受驱动再次购买。世界解锁提供阶段性目标。'再升一级就到下一个级别'的心理让玩家停不下来。

## Meta 系统

无传统Meta系统。游戏进度完全体现在金币数量和生产单元等级上。部分版本包含成就系统，在达到特定里程碑时解锁。

## 实现难度

低 — 放置点击类最基础的设计。技术难点仅在于大数值的精确计算和UI上大量数字的实时更新性能。

## 同类游戏

与此游戏类似的推荐：放置类可参考 Clicker Heroes 和 Idle Slayer；肉鸽类可参考 Slay the Spire 和 Vampire Survivors。
