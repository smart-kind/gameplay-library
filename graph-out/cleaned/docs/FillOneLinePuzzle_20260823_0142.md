# 一笔画谜题（Fill One-Line Puzzle）

- **类型**: 逻辑解谜 / 连线
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 2016
- **一句话描述**: 简约但容易上瘾的一笔画连线解谜——用一条不间断的线连接所有方块，锻炼大脑的活跃度和规划能力

## 玩法规则

游戏界面呈现由方块组成的网格，部分方块被标记为"需要连接"。玩家的目标是用**一条连续的线**，经过所有需要连接的方块，且每个方块只能经过一次。

操作方式非常简单：手指从一个方块开始滑动，经过相邻方块，形成一条路径。当手指抬起时，如果路径覆盖了所有目标方块且没有重复经过，则关卡通过。

随着关卡推进，网格变得更大更复杂，出现障碍物（不可通过的方块）、特殊方块（必须最后经过的终点方块）等变化元素。玩家需要提前规划整条路径，而不是盲目滑动——因为一旦路径走错，就必须重新开始。

## 核心循环

观察方块布局 → 脑中规划路径 → 手指滑动连线 → 检查是否通过所有方块 → 失败则重新规划

## 核心机制

- **一笔画规则**：必须一条线连接所有目标方块，不能断开、不能重复
- **路径规划**：需要在脑中预判整条路径，考验空间思维和前瞻能力
- **障碍物机制**：部分关卡加入不可通行的方块，限制路径选择
- **终点标记**：某些关卡指定了终点方块，增加了方向性约束
- **关卡递进**：从3×3简单网格到复杂形状的大网格，难度逐步提升

## 为什么好玩

规则极其简单但难度可以无限增加。每次失败后立刻知道哪里出了问题，重新尝试的动力很强。"差一点就成功"的不甘心促使玩家不断重试。

## 粘性来源

**规划成就感**：找到正确路径的瞬间有一种"我想通了"的满足感。**短平快**：每关只需几秒到几分钟，适合碎片时间。**难度曲线精准**：每个新关卡都比前一关难一点点，保持挑战但不让人绝望。

## Meta 系统

无复杂外围系统：
- **关卡进度**：线性推进的关卡列表
- **星星评分**：根据完成时间和尝试次数评分
- 对核心玩法的影响：保持纯粹，没有成长系统干扰解谜体验

## 实现难度

低。核心逻辑是路径验证——检查玩家绘制的路径是否满足条件。图形渲染和触摸交互也很简单。最大难点是关卡设计——需要确保每个关卡有解且难度适当，人工设计需要大量时间和测试。
