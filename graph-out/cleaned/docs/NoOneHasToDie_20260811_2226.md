# 无人生还（No One Has to Die）

- **类型**: 解谜 / 叙事 / 道德选择
- **平台**: Web（浏览器）
- **开发商**: J. Kyle Pitts / 独立开发者
- **首次发布**: 2011
- **一句话描述**: 叙事驱动的解谜游戏——玩家通过改变时间线来拯救所有角色，每个决定都有道德重量

## 玩法规则

游戏画面是像素风格的 2D 场景。每个场景呈现一个困境——有人处于危险中，玩家需要通过操作场景中的元素来改变结果。

操作方式：点击或键盘操作场景中的互动元素（拉杆、按钮、障碍物等）。每个操作会影响场景中的角色命运。

游戏的核心机制是"时间线分支"——每次操作都会创建一个平行的时间线。玩家可以看到不同时间线的结果（有人活下来、有人死亡），然后回到分支点，尝试不同的操作来拯救所有人。

叙事上，游戏探讨了道德和选择的主题——每个角色都有自己的故事和动机，玩家的每个决定都影响着他们的命运。最终目标是找到一条所有人都能活下来的时间线。

## 核心循环

观察困境 → 操作场景元素 → 查看结果 → 回到分支点尝试新操作 → 找到拯救所有人的方案

## 核心机制

- **时间线系统**：每次操作创建一个新的时间线分支。玩家可以在不同时间线之间切换，比较结果。
- **道德选择**：每个场景中的选择都有道德重量——救一个人可能意味着牺牲另一个人。游戏不告诉玩家"正确"答案，需要自己判断。
- **叙事驱动**：游戏的核心驱动力是故事——了解每个角色的背景和动机，做出有同情心的决定。

## 为什么好玩

No One Has to Die 把解谜和道德叙事结合在一起——解谜不是为了分数，而是为了拯救角色。每个角色的故事让选择有了情感重量，找到所有人都活下来的方案后的满足感远超普通解谜游戏。

## 粘性来源

- **情感投入**：角色的故事让选择有了情感重量
- **解谜挑战**：找到所有人都活下来的方案需要策略和思考
- **叙事好奇心**：想知道故事的发展和结局

## Meta 系统

无。纯叙事驱动游戏。

## 实现难度

- **学习曲线**：新手可以立即上手，但精通需要数十小时的练习。每次游玩都能发现新的技巧或策略。
- **重玩价值**：高。每局游戏都有不同的体验，无论是随机的地图/敌人，还是玩家的策略选择。
- **社区生态**：作为经典浏览器游戏，它在玩家社区中有良好的口碑。
- **技术亮点**：在浏览器环境中实现流畅的交互体验，充分利用了现代 Web 技术的能力。
中 + 需要叙事系统、时间线分支管理、场景互动。最大技术难点是叙事设计——写出让玩家有情感投入的角色故事。
