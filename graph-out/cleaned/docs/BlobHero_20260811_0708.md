# Blob Hero（Blob Hero）

- **类型**: 休闲 / Roguelike / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Rollic
- **首次发布**: 2022
- **一句话描述**: 引导一个果冻状角色穿越无尽的敌人波次，通过技能树打造独特战斗风格

## 玩法规则

玩家控制一个可自定义的果冻状角色（Blob），在一条自动前进的路径上移动。屏幕上会不断出现敌人波次从前方涌来。玩家通过滑动或点击来控制Blob的移动和攻击。

核心特色是融合了Roguelike的技能树系统。每局游戏开始前或游戏中，玩家可以选择不同的技能升级路线：
- **敏捷型**: 更快速度、更小碰撞体积、闪避能力
- **力量型**: 更高伤害、更大体型、近战冲撞
- **防御型**: 更高生命、护盾能力、恢复效果

每次选择都会永久改变该局游戏中Blob的属性和外观。不同的技能组合创造出完全不同的游戏体验——可以是快速穿梭的刺客型Blob，也可以是横冲直撞的重型Blob。

游戏采用自动攻击机制，Blob会攻击接触到的敌人。玩家的主要任务是控制移动方向和选择升级路线。

## 核心循环

引导移动自动攻击 → 清除波次获得经验 → 选择技能升级 → 面对更强波次

## 核心机制

- **技能树构建**: 每局游戏都可以选择不同的技能路线，创造出独特的Blob。这种"构建自己的角色"的系统在超休闲游戏中很少见，提供了极大的重玩价值。
- **自动战斗**: 攻击是自动的，玩家专注于移动和路线选择。这降低了操作门槛，同时保留了策略深度。
- **体型变化**: Blob的外观会随技能选择而变化——变得更瘦更快、更壮更肉、或更有特殊效果。视觉反馈直接反映了角色构建。
- **无尽波次**: 敌人会越来越多、越来越强，直到Blob被击败。

## 为什么好玩

将Roguelike的技能树概念带入超休闲游戏，创造出"每次都不一样"的体验。看着自己打造的Blob从弱小变得强大，很有成就感。

## 粘性来源

- **构建多样性**: 不同的技能组合创造完全不同的游戏体验，鼓励反复尝试新路线
- **角色自定义**: Blob的外观随技能变化，视觉反馈强烈
- **成长感**: 从弱小的Blob变成强大的战斗机器，过程充满满足感
- **Roguelike重玩性**: 每次失败都想知道"换个路线会怎样"

## Meta 系统

局外角色解锁系统——通过累计游戏进度解锁新的初始Blob形态或特殊皮肤。部分版本有每日挑战和排行榜。

## 实现难度

中。核心是自动战斗系统 + 技能树逻辑 + 波次生成 + 碰撞检测。最大难点在于技能树平衡——确保每条路线都有趣且可行，同时不同路线之间有明显的差异感。
