# 多任务挑战（Multitask）

- **类型**: 休闲 / 反应
- **平台**: Web (Flash)
- **开发商**: IcyLime
- **首次发布**: 2009
- **一句话描述**: 同时操控多个小游戏，考验玩家多任务处理能力的反应挑战

## 玩法规则

屏幕上同时运行2-4个不同的小游戏（如接物、躲避、射击等）。
每个小游戏有独立的控制和判定，玩家需要同时关注并操作所有游戏。
任何一个小游戏失败都会导致整体游戏结束。
随着时间推移，每个小游戏的难度会逐渐提升（速度加快、频率增加）。
玩家需要在有限的注意力下合理分配精力，确保所有游戏同时存活。
支持多人合作模式——每个玩家负责一部分小游戏。

## 核心循环

同时操作多个游戏 → 应对逐渐增加的难度 → 存活更久 → 挑战更高分数

## 核心机制

- 多任务并行：同时运行多个独立小游戏，强制玩家分配注意力，产生独特的认知负荷体验
- 渐进难度加速：所有小游戏同步提速，玩家需要在手忙脚乱中找到节奏
- 合作模式支持：允许多人各管一摊，将个人挑战转化为社交协作

## 为什么好玩

手忙脚乱的搞笑体验是核心乐趣——眼睛盯着一个游戏时另一个就挂了，永远在补救和崩溃之间循环。和朋友一起玩时互相埋怨更是快乐加倍。

## 粘性来源

"这次我能坚持更久"的冲动。每次失败都觉得自己只差一点就能更好，加上多人合作模式的社交粘性让人不断重开。

## Meta 系统

无。纯分数驱动的高分挑战游戏。

## 实现难度

低 — 核心是多游戏状态管理和UI布局，技术难点在于保持多游戏流畅同步

每个小游戏的视觉风格截然不同（有的像素风有的矢量风），帮助大脑快速区分。
游戏支持最多4个小游戏同时运行，难度随存活时间指数增长。
失败时会有一个慢动作回放显示哪个小游戏先挂掉。
多人模式下每个玩家分配到不同的键盘区域控制各自的游戏。
