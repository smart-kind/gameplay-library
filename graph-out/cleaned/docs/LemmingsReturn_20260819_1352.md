# 雷曼归来（Lemmings）

- **类型**: 解谜/策略
- **平台**: Mobile / PC / Amiga / 多平台
- **开发商**: DMA Design / Rockstar North
- **首次发布**: 1991
- **一句话描述**: 经典引导解谜游戏，通过给小矮人们分配不同技能，引导他们安全通过充满陷阱的关卡

## 玩法规则

游戏画面是一个横向剖面视图，展示关卡的地形结构。一群绿色头发、穿着蓝色衣服的小矮人（Lemmings）从屏幕左侧的入口持续走出，沿着地面自动向右行进。玩家无法直接控制小矮人的移动，只能通过给他们分配特殊技能来间接引导。

当小矮人遇到墙壁时会自动转身，遇到缺口会直接掉下去（可能摔死），遇到陷阱（深水、尖刺、熔岩）也会死亡。玩家的目标是在限定时间内，将要求比例的小矮人引导到屏幕右侧的出口。

玩家拥有8种技能，每种有使用次数限制：阻挡者（Blocker）——停下变成一面墙，其他小矮人碰到他会转身；挖掘者（Digger）——向下挖隧道；建造者（Builder）——建造向上的楼梯；爆破者（Bomber）——倒计时后爆炸，炸开周围的墙壁和地形；飞行者（Floater）——撑开雨伞减缓下落速度，防止摔死；攀爬者（Climber）——爬上垂直墙壁；矿工（Miner）——斜向挖隧道；挖掘者（Basher）——水平挖穿墙壁。

关卡设计是游戏精髓。好的解法需要全局规划——先在哪里放阻挡者改变路线，在哪里派挖掘者打通隧道，在哪里用爆破者炸开障碍。时机至关重要，因为小矮人在持续行进，错过时机就无法挽回。

## 核心循环

观察关卡布局 → 规划技能分配方案 → 实时分配技能 → 引导小矮人到出口 → 达到救出比例过关

## 核心机制

- **实时技能分配**：小矮人持续行进不停歇，玩家需要在行进过程中实时点击分配技能。时机和位置的选择决定成败，错过一秒可能导致整批小矮人死亡。这种实时压力是游戏紧张感的来源
- **多角色协同解谜**：不同技能组合可以创造复杂的解决方案。一个关卡通常需要多种技能配合——先用阻挡者改变路线，再派挖掘者打通隧道，最后用爆破者炸开障碍。全局规划能力是通关关键
- **物理环境互动**：地形、陷阱、障碍物构成丰富的解谜要素。深水、尖刺、熔岩等不同陷阱需要不同的应对策略。墙壁可以被挖穿或炸开，地形可以被改变

## 为什么好玩

看着一群小矮人按照你精心设计的路线安全前进的成就感极强。每个关卡都有多种解法，找到最优解的过程充满智力挑战。小矮人的可爱形象和滑稽动作（比如被炸飞时的表情）增加了趣味性。实时操作的压力让每次执行都充满紧张感。

## 粘性来源

解谜的智力挑战提供持续思考空间、找到完美路线的成就感带来强烈正反馈、小矮人的可爱表现增加情感连接、'差一点就全救'的不甘心驱动再试一次、多解法设计鼓励重复游玩寻找最优方案

## Meta 系统

关卡推进系统——完成度（救出比例）影响后续解锁；评级系统根据救出小矮人数量和用时给予评价；部分版本包含玩家自制关卡功能

## 实现难度

中 — 单个技能易于理解但多技能协同需要练习。最大的技术难点在于路径规划和实时操作的平衡——既不能太简单失去挑战，也不能太复杂让玩家无从下手
