# 骰子合成（Dice Merge by Staple Games）

- **类型**: 合成消除 / 骰子策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Staple Games
- **首次发布**: 2023
- **一句话描述**: 通过掷骰子和合成相同骰子来创造更高数值，策略性地管理棋盘空间

## 玩法规则

游戏棋盘为六边形网格布局，玩家拥有几个骰子生成器（类似老虎机的槽位），每次生成一组随机面值的骰子（1-6面）。

玩家操作方式是将相同面值的骰子拖拽到一起进行合成。两个1面骰合成一个2面骰，两个2面合成一个3面，以此类推直到最高面值。

棋盘空间有限，新的骰子不断从生成器中产出。如果棋盘被填满且没有可合成的骰子对，游戏结束。

玩家需要决定合成时机：是立刻合成低级骰子腾出空间，还是等待更高级的合成机会。高级骰子不仅数值更大，有时还具有特殊效果（如爆炸清除周围骰子、生成金币等）。

游戏目标是获得尽可能高的分数。分数由合成产生的骰子面值累加计算，高级骰子的分数呈指数增长。

## 核心循环

掷骰子获得随机值 → 合成相同骰子升级 → 腾出空间继续生成 → 追求更高分

## 核心机制

- **骰子生成机制**: 每次从槽位随机产出骰子，面值有概率分布（低面值概率高），为游戏注入随机性和不确定性
- **合成升级机制**: 相同面值合成高一级，形成清晰的递进路径。高级骰子有时附带特殊能力（爆炸、范围清除、加分），增加策略深度
- **空间管理**: 六边形棋盘限制了同时存在的骰子数量，每次合成都是空间博弈——合成低级腾空间还是保留等高级合成

## 为什么好玩

骰子的随机性让每次局面都不同，合成高级骰子时的数值飙升感非常爽快。"再投一次就能合成"的冲动让人停不下来。

## 粘性来源

随机骰子掉落提供持续新鲜感；追求更高面值的合成是天然的数字递进成瘾；棋盘空间紧张时的"差一点"感促使再来一局；分数排行榜激发竞争。

## Meta 系统

无显著外围系统。主要为分数驱动的高分挑战。

## 实现难度

低。骰子生成、合成逻辑、棋盘管理均为成熟模式。最大技术难点是六边形网格的UI渲染和拖拽交互流畅度。
