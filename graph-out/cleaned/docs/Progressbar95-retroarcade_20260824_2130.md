# Progressbar95（Progressbar95）

- **类型**: 超休闲/复古益智
- **平台**: Mobile (iOS+Android) / PC (Windows)
- **开发商**: PROGREDBAR
- **首次发布**: 2020
- **一句话描述**: 一款怀旧风格的益智游戏，以Windows 95界面为背景，玩家需要通过移动进度条来填满进度槽完成关卡。

## 玩法规则

游戏界面模拟Windows 95的桌面环境，包含经典的灰色窗口、蓝色标题栏和像素风格的图标。每个关卡中，屏幕上出现一个或多个进度条，进度条上有不同颜色的分段（绿色表示已填充、灰色表示空）。

玩家通过滑动或点击来移动进度条分段，将散落的绿色分段推进进度槽中。当进度条被填满到100%时关卡完成。关卡中可能包含障碍物、锁定的分段或需要特定顺序操作的机制。随着关卡推进，进度条的数量增加、排列方式更复杂、出现干扰元素（如移动的障碍物或倒计时限制）。

## 核心循环

观察布局 → 移动进度条分段 → 填满进度槽 → 解锁下一关 → 面对更复杂的布局挑战

## 核心机制

- **进度条操作**：通过滑动/拖拽将进度条分段推入槽中，类似推箱子但有方向限制
- **多进度条联动**：后期关卡中多个进度条相互关联，填充一个可能影响另一个的状态
- **障碍系统**：锁定的分段需要特定操作解锁，障碍物阻挡推进路径
- **怀旧元素**：Windows 95视觉风格、经典错误提示音、蓝屏死机效果作为"Game Over"动画

## 为什么好玩

怀旧美学是核心吸引力——90后/00后玩家对Windows 95界面的亲切感转化为游玩动力。操作极其简单（滑动/点击），但关卡设计从简单到复杂的递进让游戏保持了持续的挑战性。蓝屏死机作为失败动画的设计充满幽默感，消解了失败的挫败感。

## 粘性来源

"再试一关"的冲动来自于关卡难度的平滑递增——每一关都比前一关难一点点，但看起来总是"差一点点就能过"。怀旧视觉风格本身也是一种收集驱动力：解锁不同的Windows版本主题（从Windows 3.1到Windows 10）给玩家持续的目标。极简的操作让游戏可以在任何场景下随时开始，降低了进入门槛。

## Meta 系统

- **主题解锁**：完成关卡解锁不同Windows版本的主题皮肤
- **成就系统**：完成特定挑战（如无操作失误通关、限定步数内完成等）
- **关卡进度**：线性关卡地图，数百个精心设计的谜题关卡
- **难度模式**：除标准模式外可能包含挑战模式和限时模式

## 实现难度

低 — 核心是2D物理/滑动逻辑和关卡状态检测。最大技术难点在于关卡编辑器和难度曲线设计，需要确保每个关卡有且只有一种或几种最优解法，同时保持可解性。
