# Idle Universe

- **类型**: 放置 / 模拟
- **平台**: Mobile (iOS)
- **开发商**: Dominik Stallmann
- **首次发布**: 2017
- **评分**: ⭐ 4.3/5 (1,514 评价)
- **价格**: Free
- **一句话描述**: 在这个新的上瘾放置游戏中创造你自己的宇宙！首先通过点击收集物质，然后创造物体来自动继续。

## 玩法规则

游戏开始于一片虚空。通过点击收集"物质"（matter）。当物质足够时，可以创造第一个物体（如基本粒子）。创造出的物体会自动产生更多物质，解锁更多物体类型。从基本粒子到原子、分子、星球、星系——逐步创造整个宇宙。界面以宇宙空间为核心，显示已创造的物体和物质计数。

## 核心循环

点击收集物质 → 创造物体 → 物体自动产生物质 → 创造更高级物体 → 扩展宇宙

## 核心机制

- 宇宙进化：从基本粒子到星系的完整进化链
- 自动生产：创造的物体自动产生资源，放置玩法
- 层级解锁：每级物体解锁下一级创造选项

## 为什么好玩

从虚空创造整个宇宙的宏大叙事。看着宇宙从粒子到星系逐步成型，震撼感极强。

## 粘性来源

宇宙进化的宏大叙事、解锁期待、离线收益

## Meta 系统

完整的放置经济+进化系统。核心玩法即meta。

## 实现难度

低——放置游戏模板，数值和层级设计是关键
