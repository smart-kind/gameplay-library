# 合并加2：冒险（Merge Plus 2: Adventure）

- **类型**: 数字合并 / 益智解谜 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: 书圣 王
- **首次发布**: 2019
- **一句话描述**: 一款手牌式数字合并益智游戏，玩家将手牌拖到棋盘上合并相同数字，通过多种关卡类型挑战策略思维，无需联网即可游玩。

## 玩法规则

游戏画面分为两个区域：下方的手牌区（显示当前可用的数字牌）和上方的棋盘区（网格布局）。玩家从手牌区选择一张牌，拖拽到棋盘上的空位。

当手牌落在棋盘上与其相邻的数字牌上时，两个数字相加合并为它们的总和。如果三个或更多相邻的相同数字合并在一起，会触发三重清除（triple-clear），合并为一个数字+1的新牌。

游戏包含多种关卡类型：
- **分数关卡**：在限定步数内达到目标分数
- **收集关卡**：在限定步数内收集目标数字
- **冰层关卡**：需要通过合并来压碎覆盖在数字上的冰层
- **冰块关卡**：需要通过在冰块周围合并来击碎冰块

当步数用完且未达到目标时，关卡失败。玩家需要在有限步数内最大化合并效率。

## 核心循环

拖放手牌 → 数字相加合并 → 触发连锁获得分数/清除障碍 → 完成关卡目标

## 核心机制

- **加法合并系统**：不同于传统的"相同数字翻倍"合并，本作采用"相邻相加"机制。两个2合并为4，2和3合并为5。这增加了策略深度，因为玩家不仅需要匹配相同数字，还需要考虑数字组合的最优解。
- **多重关卡类型**：四种不同的关卡目标（分数、收集、冰层、冰块）让游戏保持多样性。每种类型需要不同的策略思路，避免重复感。
- **三重清除机制**：三个相同数字相邻时触发特殊清除，产生数字+1的新牌。这是一种高级合并策略，需要玩家规划棋盘布局来创造三重清除的条件。
- **离线可玩**：游戏无需网络连接即可完整体验，适合通勤、旅行等无网络场景。

## 为什么好玩

加法合并比传统翻倍合并需要更多的数学思考——每次放置都要考虑"这个数字和旁边的哪个组合最优"。多种关卡类型让游戏不会陷入单一的解题模式，冰层和冰块的加入增加了空间解谜的维度。

## 粘性来源

关卡渐进难度是核心粘性来源——每通过一关就离下一个挑战更近一步。三重清除带来的"哇"时刻（意外触发大范围清除的惊喜）和分数突破让每次游玩都有高光时刻。离线可玩性也保证了任何场景下都能随时开始一局。

## Meta 系统

游戏包含关卡进度系统，玩家通过完成关卡逐步解锁后续内容。无复杂的付费成长系统或社交功能。游戏专注于纯粹的单人数益智体验。

## 实现难度

低。数字合并逻辑和关卡系统都是成熟的技术方案。最大的技术难点在于三重清除的检测算法——需要准确判断三个相邻相同数字的连通性，以及合并后的级联效果计算。
