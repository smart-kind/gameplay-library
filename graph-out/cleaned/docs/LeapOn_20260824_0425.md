# Leap On!

- **类型**: 街机生存 / 弹跳躲避
- **平台**: Mobile (iOS+Android)
- **开发商**: Ketchapp
- **首次发布**: 2016
- **一句话描述**: 一款在圆形轨道上弹跳的街机游戏，玩家按住屏幕让球体外跳避开黑色障碍，收集彩色方块获得高分。

## 玩法规则

游戏在一个充满彩色球体的圆形轨道上进行，玩家控制一个弹跳球体在轨道上移动。球体自动沿轨道旋转前进。

操作方式极简：按住屏幕球体向轨道外侧跳跃，松开屏幕球体回到轨道内侧。目标是避开轨道上的黑色障碍物，同时尽可能多地收集彩色方块。

轨道上有彩色方块和黑色方块。彩色方块用于收集加分，黑色方块碰到即死。不同颜色的轨道区域可能影响球的旋转方向或速度。

收集系统：轨道上散布彩色方块，收集方块获得分数和连击。连续收集无间隔有额外加分。收集足够分数可以解锁新球体外观。

游戏以无尽模式为主，持续进行直到撞到障碍物。彩色方块区域可以安全通过，黑色障碍物区域需要精准判断时机跳跃。速度随时间逐渐增加，后期挑战大幅提升。

## 核心循环

按住松开控制跳跃 → 收集方块 → 避开障碍 → 速度加快 → 失误死亡 → 重试

## 核心机制

- **按住跳跃机制**: 操作极简：按住跳外圈，松开回内圈。但轨道上的障碍物分布在内圈和外圈不同位置，玩家需要在瞬间判断该跳还是该松。这种二元选择在持续旋转中制造了持续的认知挑战。按住时间长短还影响跳跃幅度，形成微操空间。

- **旋转轨道加视觉识别**: 球沿轨道自动旋转，障碍物以不同颜色区分。彩色代表安全或收集，黑色代表危险。玩家需要在旋转中快速识别颜色并做出反应。颜色即语义的设计让信息传递极其高效，但高速旋转时识别难度大幅上升。

- **渐进式速度增加**: 游戏速度随时间自然增加，形成无缝难度曲线。初期悠闲地收集方块，后期在高速中惊险躲避。速度增加也是天然的个人极限标记，推动反复尝试。我上次跑到300分，这次要冲400。

## 为什么好玩

极简操作下的极高紧张感。彩色方块和黑色障碍在旋转中交替出现，判断时机需要集中注意力。球体在轨道上弹跳的物理手感非常满足。差一点就过了的瞬间让人忍不住再来。Ketchapp一贯的极简美学让游戏体验干净利落。

## 粘性来源

街机游戏差一点的不甘心感加上极简操作的低门槛和新球体外观的收集欲，构成经典街机循环。每局30秒到2分钟，适合碎片时间。高分排行榜提供竞争目标。

## Meta 系统

球体外观解锁系统：收集分数解锁不同颜色和图案的球体。无其他Meta系统，纯高分驱动。

## 实现难度

低。核心是圆形轨道碰撞检测和旋转逻辑。2D图形实现简单。主要挑战是手感调优和关卡生成算法。
