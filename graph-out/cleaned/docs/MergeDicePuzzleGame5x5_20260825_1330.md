# Merge Dice - Puzzle Game 5x5

- **类型**: 合并解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Le Nhung
- **首次发布**: 2020
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

掷出骰子 -> 将骰子放到棋盘上合并相同数字 -> 获得更高分

## 核心机制

- **骰子投掷机制**: 玩家每次投掷一组骰子（通常为5个），骰子显示不同的数字（1-6）。玩家需要将骰子拖放到5x5的棋盘上，相同数字的骰子相邻时会合并为更高数字。
- **5x5棋盘布局**: 棋盘为5x5网格，骰子放置后占据一个格子。合并后产生的新骰子仍占一个格子。棋盘空间有限，需要策略性地规划放置位置以最大化合并效率。
- **行列清除机制**: 当一行或一列的数字之和达到特定阈值时，该行/列会被清除，释放空间。这个机制帮助玩家管理棋盘空间，同时也是得分的重要来源。

## 为什么好玩

骰子的随机性+棋盘的策略性形成了有趣的组合。每次投掷都有新的可能性，需要快速决策放置位置。

## 粘性来源

粘性来源于骰子投掷的随机性和合并时的成就感。高分驱动玩家不断尝试更好的放置策略。

## Meta 系统

- 得分系统：合并和清除行/列获得分数
- 对核心玩法的影响：高分目标驱动玩家不断优化策略

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
