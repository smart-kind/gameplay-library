# 2 Player Games : Offline Games

- **类型**: 休闲合集/派对游戏
- **平台**: Mobile (iOS)
- **开发商**: Moreno Maio
- **首次发布**: 2019
- **一句话描述**: If you want to play with your friend on the same device, this is the right game! But also if you have no friends to have

## 玩法规则

2 Player Games : Offline Games是一款休闲合集/派对游戏类型的移动游戏，由Moreno Maio开发。以下详细说明其玩法规则：

**游戏画面与UI**：游戏主界面以核心玩法区域为中心，操作按钮和状态信息分布在屏幕周围。界面设计简洁直观，操作区域占据屏幕主要部分，确保玩家能够专注于游戏内容。状态栏显示当前的关键信息（如分数、剩余步数/时间、资源数量等）。

**操作方式**：游戏主要采用触屏操作，核心操作包括匹配消除。操作响应灵敏，适合单手持握游玩。通过简单直观的手势即可完成大部分游戏操作，降低了上手门槛。

**游戏目标**：通过匹配消除完成当前关卡或挑战，在达到关卡条件后进入下一阶段。

**胜利/失败条件**：达成关卡设定的目标条件（如完成指定操作、达到目标分数、在限制条件下通关等）即可过关。若无法满足继续游戏的条件（如步数耗尽、生命值归零、时间用尽等）则挑战失败，需要重新开始当前关卡。

## 核心循环

选择小游戏 → 完成挑战 → 获得积分 → 解锁更多游戏

## 核心机制

- **多游戏切换**：内置数十种不同类型的迷你游戏，涵盖反应力、记忆力、策略等多种类型。
- **多人同屏竞技**：支持本地多人模式，朋友间可在同一设备上进行比拼。
- **积分解锁系统**：通过游玩获得积分，累积解锁新的迷你游戏和自定义内容。

## 为什么好玩

一个App包含数十种不同玩法，永远不会无聊。多人同屏竞技的欢乐氛围，是聚会破冰的利器。

## 粘性来源

玩法多样性确保不会无聊。多人竞技的欢乐氛围和"赢一局"的满足感是核心粘性。

## Meta 系统

- **积分与解锁系统**：游玩获得积分，累积解锁新游戏和自定义选项。部分游戏有本地排行榜。
- **对核心玩法的影响**：积分系统驱动全游戏探索，解锁内容维持新鲜感。

## 实现难度

低 — 每个小游戏独立实现，技术门槛都不高。难点在于将多种游戏整合为流畅的体验，以及本地多人模式的手柄触屏适配。
