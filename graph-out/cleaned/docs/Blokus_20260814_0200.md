# Blokus（布鲁克斯）

- **类型**: 抽象策略棋盘 / 益智对战
- **平台**: Mobile (iOS + Android) / Board Game / Web
- **开发商**: 原版由Bernard Tavitian设计（2000年桌游），数字版由TEQUILA/FusionX等开发
- **首次发布**: 2000 (桌游原版)
- **评分**: 经典桌游数字化改编
- **一句话描述**: 四名玩家在共享棋盘上轮流放置彩色多格骨牌，每块新牌必须至少有一角与己方已有棋子接触，但不能与己方棋子边对边相邻

## 玩法规则

游戏在一个20x20的方格棋盘上进行，最多支持4名玩家，每人拥有一套21块不同形状的彩色积木（类似俄罗斯方块的多格骨牌，从单格到五格共21种形状）。

游戏开始时，四名玩家各自选择一个角作为起始位置。第一位玩家必须将自己的一块积木放在自己的角落格子上。

从第二位玩家开始，每轮放置规则如下：新放置的积木必须至少有一个角与己方已放置的积木的角接触（对角线接触），但绝不能与己方任何积木的边相邻（上下左右）。可以与其他玩家的积木边对边相邻——这实际上是一种阻挡策略。

玩家轮流放置积木，直到所有玩家都无法再放置为止。无法放置任何剩余积木时，玩家退出游戏。

当所有玩家都无法继续放置时游戏结束。计分规则：每块未放置的积木按其格数扣分（例如一块五格积木扣5分），如果成功放置完所有21块积木则加15分奖励。最高分获胜。

## 核心循环

选择并放置积木 → 扩张领土同时阻挡对手 → 评估剩余空间和可用积木 → 继续放置直到无法放置

## 核心机制

- **角接触规则**：新积木必须以角（非边）与己方积木相连——这一规则迫使玩家在扩张时做出空间取舍，是游戏策略深度的核心
- **共享空间竞争**：4名玩家争夺同一块棋盘，空间是有限资源。你需要同时考虑自身发展和限制对手
- **积木形状多样性**：21种不同形状（1-5格）的组合意味着每局的策略路径完全不同
- **阻挡策略**：通过巧妙地放置积木来封锁对手的扩张路线，是攻击性的防御手段
- **终局计分**：不仅要放得多，还要尽可能放完所有积木（15分奖励），这鼓励全盘规划

## 为什么好玩

Blokus的优雅在于规则的极简与策略的极深之间的反差。规则一句话就能说明白，但实际对局中需要同时考虑空间规划、对手意图、终局计分等多重因素。看着棋盘从空旷到逐渐被彩色积木填满，像在完成一幅抽象画，同时又在和其他三名画家争夺画布。

## 粘性来源

(1) **每局不同的策略路径**——21种积木的组合意味着没有两局游戏相同；(2) **多玩家社交竞争**——4人对局的动态联盟和互相阻挡产生不可预测的乐趣；(3) **"啊我怎么没想到"的顿悟时刻**——对手一步棋封锁你多个选择时的恍然大悟；(4) **快速重开**——一局10-15分钟，适合快速再来一局

## Meta 系统

无——纯对局游戏，无外围成长系统

## 实现难度

**低** — 核心是棋盘状态管理 + 放置合法性验证。技术难点在于AI对手的设计（评估函数需要考虑空间利用率、对手限制等多因素）
