# Farty Pants（Farty Pants）

- **类型**: 物理益智 / 搞笑休闲
- **平台**: Mobile (iOS)
- **开发商**: 独立开发者
- **首次发布**: 2010
- **一句话描述**: 利用角色放屁产生的反推力，通过物理弹射到达目标位置

## 玩法规则

游戏采用卡通风格的2D横版画面。玩家控制一个角色（通常是一个小人或动物），需要通过控制放屁的方向和力度来移动角色，到达关卡的目标位置。

操作方式：长按屏幕蓄力，松开时角色放屁产生反推力。通过调整角色的朝向（左右翻转）来决定推力方向。蓄力时间越长，推力越大。

画面中有各种障碍物——墙壁、尖刺、移动平台、风扇等。角色碰到尖刺或掉出屏幕外即失败。某些关卡有收集品（星星、硬币等）需要顺便收集。

每个关卡的目标是将角色送到指定区域（通常是一个门或旗帜）。过关条件：到达目标区域。失败条件：碰到障碍物或掉出画面。

## 核心循环

观察关卡 → 规划弹射路线 → 蓄力放屁 → 飞行 → 到达目标/失败 → 重试

## 核心机制

- **物理弹射**：利用放屁产生的反推力推动角色飞行，角度和力度决定飞行轨迹。基于真实物理的飞行效果增加了可预测性和策略性。
- **蓄力系统**：长按蓄力控制推力大小，给玩家精确操作的空间。
- **环境互动**：墙壁反弹、风扇助推、移动平台等环境元素增加了关卡的复杂度和解谜深度。
- **收集品**：关卡中的可选收集品增加了挑战性和重玩价值。

## 为什么好玩

Farty Pants的搞笑主题掩盖了它实际上是一个相当精巧的物理弹射解谜游戏。放屁这个荒诞的推进方式让游戏充满幽默感，但关卡设计却需要认真思考。每次弹射都是一次小型物理实验——调整角度、力度、利用反弹，成功到达目标时的满足感很强。

游戏的物理引擎是其核心竞争力——角色的飞行轨迹遵循真实的抛物线物理，玩家可以逐渐学会预判飞行路径。这种"可学习性"让游戏从"靠运气"变成了"靠技巧"，提供了明确的成长路径。

环境元素的多样化也让游戏保持新鲜感——风扇可以把角色吹得更高，传送带可以改变方向，弹簧可以额外增加高度。这些元素的引入和组合让每个新关卡都有新的思考角度。

## 粘性来源

物理弹射类游戏的粘性来自"差一点就成功了"的体验。每次飞行路线都有微小的调整空间，失败后玩家会立刻知道"下次我应该多蓄力一点"或"换个角度"。这种即时的反馈循环让人不断重试。搞笑的主题也让失败变得有趣而非沮丧。

收集关卡中的所有星星（或硬币）提供了额外的目标层次——你可能已经通关了，但没有拿到全部收集品。这种"完美通关"的追求驱动玩家反复挑战已经通过的关卡，尝试不同的弹射路线来获取那些难以到达的收集品。

## Meta 系统
