# Matchstick Wars

- **类型**: 策略/塔防
- **平台**: Mobile (iOS+Android)
- **开发商**: 云飞 李
- **首次发布**: 2020
- **一句话描述**: 一款火柴人风格的策略对战游戏

## 玩法规则

玩家指挥火柴人军队进行对战。通过点击屏幕在己方阵地生成不同兵种（步兵、弓箭手、法师等），兵种自动向敌方阵地前进并交战。

每种兵种有相克关系（如步兵克弓箭手、弓箭手克法师等）。玩家需要根据敌方出兵类型调整己方策略。战场分为左右两方，中间为交战区。

画面采用极简火柴人风格。界面底部为兵种选择栏，上方显示双方基地血量和资源数。资源随时间自动增长，生成兵种消耗资源。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

积累资源生成兵种 → 击败敌方军队 → 攻破敌方基地

## 核心机制

- 兵种相克系统：不同兵种之间存在克制关系，策略体现在兵种搭配
- 实时出兵机制：消耗资源生成兵种，考验资源分配和时机判断
- 基地攻防：双方都有基地血量，先攻破对方基地获胜

## 为什么好玩

极简画风下的深度策略博弈，每局都是全新的心理战。

## 粘性来源

兵种解锁和关卡推进，以及 PVP 排名的竞争驱动。

## Meta 系统

- 兵种解锁系统：通过胜利解锁新兵种
- 科技升级：消耗资源永久提升兵种属性

## 实现难度

低 — 核心玩法简洁但策略深度足够，最大的技术难点是 AI 对手的难度曲线和兵种平衡。
