# Flappy Bird（Flappy Bird）

- **类型**: 休闲 / 无尽跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: Dong Nguyen (Gears Studios)
- **首次发布**: 2013
- **一句话描述**: 点击屏幕让小鸟上下飞行，穿越绿色管道之间的缝隙

## 玩法规则

游戏画面极简——一只像素风格的小鸟在左侧，右侧不断有上下两组绿色管道水平移动过来，中间留出一个缝隙。整个画面没有复杂的UI，只有上方显示当前得分数字。

玩家只能做一个操作：点击屏幕（或触摸）。每次点击小鸟就向上扑腾一下（获得一段向上的冲力），不点击时小鸟会因重力持续下坠。目标就是控制小鸟穿过每一对管道之间的缝隙。

每成功穿过一对管道得 1 分。如果小鸟碰到了上方管道、下方管道或地面/天花板，游戏立刻结束，显示最终得分。游戏没有任何减速或缓冲——失败是即时的。

游戏没有关卡概念，难度会随分数增加而微幅提升（管道间距可能变小），核心挑战在于保持稳定的节奏感。

## 核心循环

点击飞行 → 穿过管道得 1 分 → 继续下一对管道

## 核心机制

- **重力与冲力**: 小鸟持续受到向下的重力，每次点击获得向上的瞬时冲力。这种二元物理状态（上冲 vs 下坠）形成了最基础的操作反馈。
- **管道生成**: 管道从右向左匀速移动，每组管道的缝隙高度位置随机，但宽度一致。玩家无法改变管道速度，只能通过点击频率控制小鸟高度。
- **即时死亡**: 碰撞即结束，无任何缓冲或容错。这种"一碰就死"的设计创造了极强的紧张感和"再来一局"的冲动。

## 为什么好玩

简单到任何人都能上手，但精通却极难——每次失败都感觉"只差一点点"。这种"差一点就成功"的不甘心感让玩家忍不住反复尝试。

## 粘性来源

- **"差一点"效应**: 每次死亡都极其接近成功，玩家总觉得自己下次能过
- **即时重启**: 死亡到重新开始只需一秒，无加载无等待
- **分数攀比**: 极简的得分系统激发社交比较和炫耀欲
- **节奏上瘾**: 掌握节奏后会产生一种心流般的节奏感体验

## Meta 系统

无。纯核心玩法，没有任何外围系统。

## 实现难度

低。核心就是一个重力物理模拟 + 碰撞检测 + 管道随机生成。最大技术难点在于调整手感——重力大小、点击冲力、管道间距需要精确调校才能达到"难但不绝望"的体验。
