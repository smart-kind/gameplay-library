# 射击合并（Shoot n Merge）

- **类型**: 益智 / 数字合并 / 泡泡射击
- **平台**: Mobile (iOS+Android)
- **开发商**: Metajoy
- **首次发布**: 2018
- **一句话描述**: 将泡泡射击和数字合并融合的创新益智游戏，玩家发射数字砖块到棋盘上，相同数字碰撞后合并为更大的数字，挑战最高分。

## 玩法规则

游戏画面分为上下两部分：上方是游戏棋盘（类似2048的网格布局），下方是发射器。发射器中会显示当前可发射的数字砖块（通常是2、4、8等小数字）。

玩家瞄准棋盘上的空位，点击屏幕发射数字砖块。砖块沿直线飞行并落在棋盘上。当发射的砖块与棋盘上相同数字的砖块接触时，两者合并为一个数字翻倍的砖块（例如两个4合并为8）。

合并产生的连锁反应是游戏的核心乐趣：一次合可能会触发周围相同数字的连续合并，形成分数爆炸。玩家需要在有限的棋盘空间内策略性地安排发射位置，避免棋盘被填满。

当棋盘被砖块填满且无法继续合并时，游戏结束。玩家的目标是获得尽可能高的分数，即合成最大的数字。

## 核心循环

发射数字砖块 → 相同数字碰撞合并 → 获得分数 → 继续发射挑战更高分

## 核心机制

- **泡泡射击+数字合并混合玩法**：传统泡泡射击的方向瞄准和弹道物理，结合2048式的数字合并逻辑。两种经典玩法的结合产生了新的策略维度——不仅要考虑合并，还要考虑发射角度和弹道。
- **连锁反应系统**：一次合并可能触发周围相同数字的连续合并，产生连锁反应。连锁次数越多，分数倍率越高。这鼓励玩家战略性地布置棋盘，为大规模连锁创造条件。
- **无尽模式**：游戏没有关卡限制，玩家持续发射直到棋盘满为止。这种"一直玩到输"的模式让玩家专注于自我突破，追求更高的分数记录。
- **道具辅助**：游戏提供锤子（移除单个砖块）和扳手（交换两个砖块位置）等道具，帮助玩家度过难关。道具需要通过游戏内收集获得。

## 为什么好玩

泡泡射击的瞄准乐趣和数字合并的策略深度相结合，创造出一种独特的益智体验。每次发射都需要同时考虑"合并哪些数字"和"如何精准命中目标"，双重思考让游戏既有休闲感又有挑战性。连锁合并的视觉效果和分数飙升带来的爽感非常满足。

## 粘性来源

高分挑战是核心粘性来源——每次游戏结束后看到自己的分数，总想着"下一次一定能更高"。连锁合并的不可预测性（不知道下一次会触发多大的连锁）和分数倍率的增长让玩家不断尝试新的策略。

## Meta 系统

游戏包含每日挑战和社交排行榜功能。玩家可以与好友比拼分数，参与每日特定条件的挑战任务获取额外奖励。无复杂的付费成长系统。

## 实现难度

低。泡泡射击的物理引擎和数字合并的逻辑都是成熟的技术方案。最大的技术难点在于连锁反应的正确计算——需要确保合并顺序和连锁触发的逻辑正确，避免边界情况导致的错误合并。
