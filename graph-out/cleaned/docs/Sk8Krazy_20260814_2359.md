# Sk8 Krazy

- **类型**: 体育/滑板
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款滑板主题的极限运动游戏

## 玩法规则

玩家控制滑板手在半管、街道等场景中表演特技。通过滑动屏幕执行翻转、抓板等特技动作，点击加速按钮提升速度。

特技动作根据难度和完成度获得分数。连续完成特技获得连击加分。场景中有障碍物和跳台，合理利用可以获得更高分数。

画面采用 3D 卡通风格，场景设计充满街头文化元素。界面底部为操作按钮，上方显示分数和时间。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

表演特技获得高分 → 解锁新场景和滑板 → 挑战更高难度

## 核心机制

- 特技系统：滑动执行不同特技动作，难度越高分数越高
- 连击加成：连续完成特技获得分数倍率
- 场景探索：不同场景有不同路线和跳台

## 为什么好玩

极限运动的刺激感搭配简单易上手的操作。

## 粘性来源

高分挑战和场景解锁的驱动力。

## Meta 系统

- 滑板解锁：获得金币解锁不同滑板和外观
- 角色解锁：通过成就解锁新滑板手

## 实现难度

中等 — 3D 特技动画和物理模拟需要一定开发量，最大的技术难点是特技判定和动画流畅度。
