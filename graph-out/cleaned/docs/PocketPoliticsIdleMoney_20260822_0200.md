# 口袋政治 - 放置金钱（Pocket Politics: Idle Money）

- **类型**: 放置/策略
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2016
- **一句话描述**: 政治竞选中的金钱管理放置游戏

## 玩法规则

玩家扮演政治竞选者，通过放置方式积累竞选资金。资金自动增长，玩家点击可加速收集。资金用于雇佣团队、投放广告、举办活动，提升支持率。随着支持率提高，解锁更高级的竞选策略和资源。游戏以讽刺幽默的方式呈现政治竞选。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

积累资金 → 投入竞选活动 → 提升支持率 → 解锁新策略 → 继续增长

## 核心机制

- **资金增长**:  自动积累竞选资金
- **策略投入**:  资金用于各种竞选活动
- **支持率系统**:  支持率影响可解锁内容

## 为什么好玩

讽刺幽默的政治主题，策略选择的多样性

## 粘性来源

支持率增长的成就感；新策略解锁的期待

## Meta 系统

竞选策略解锁和团队雇佣

## 实现难度

低 - 核心是数值管理和策略选择 - 数值平衡和策略多样性
