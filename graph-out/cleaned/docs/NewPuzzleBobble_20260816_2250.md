# 新泡泡龙（New Puzzle Bobble）

- **类型**: 弹射消除 / 益智
- **平台**: Mobile (iOS)
- **开发商**: Taito
- **首次发布**: 2011
- **一句话描述**: 经典泡泡龙玩法的移动版，从底部发射彩色泡泡，将相同颜色的泡泡连在一起消除

## 玩法规则

屏幕上方悬挂着大量彩色泡泡，屏幕底部有一个发射器。玩家控制发射器的角度，发射彩色泡泡。当发射的泡泡与上方相同颜色的泡泡接触时，它们会连接在一起。

当3个或更多相同颜色的泡泡连接在一起时，它们会被消除。消除后的泡泡如果失去支撑会掉落并计分。

泡泡群会从上方缓慢下压，如果泡泡触及底部底线则游戏结束。玩家需要在泡泡到达底线前消除足够多的泡泡。

游戏中有特殊泡泡：彩虹泡泡（匹配任何颜色）、炸弹泡泡（消除周围所有泡泡）、石头泡泡（无法消除，需要消除周围的泡泡使其失去支撑掉落）。

## 核心循环

瞄准发射泡泡 → 匹配相同颜色消除 → 失去支撑的泡泡掉落得分 → 新泡泡加入 → 继续消除

## 核心机制

- **弹射匹配（Bubble Shooter）**：核心机制。控制角度发射泡泡，利用墙壁反弹命中目标位置
- **连锁消除（Chain Reaction）**：消除一组泡泡后，失去支撑的下方泡泡会全部掉落，可能引发连锁反应大量得分
- **墙壁反弹（Wall Bouncing）**：泡泡可以在墙壁上反弹，利用反弹可以命中被遮挡的目标
- **特殊泡泡（Special Bubbles）**：彩虹泡泡万能匹配、炸弹泡泡大范围消除，是突破困境的关键道具

## 为什么好玩

弹射泡泡的物理手感非常令人满足——每次命中目标、看到连锁消除都有强烈的正反馈。利用墙壁反弹命中隐藏位置的技巧感很强。

## 粘性来源

具体到机制层面：1）连锁消除的视觉和音效反馈——泡泡大量掉落时的爽快感；2）利用反弹命中目标的技巧成就感；3）"再打一关"的心理——每关时间不长随时可以来一局；4）分数竞争——追求更高分数或通关全部关卡。

## Meta 系统

关卡解锁系统。完成一个区域后解锁新区域，难度逐步提升。部分版本包含限时挑战和分数排行榜。

## 实现难度

低。泡泡消除的核心算法（碰撞检测、连接判断、消除判定）相对成熟。最大的难点是物理手感调优——泡泡的反弹角度、连接位置、消除动画需要精确且流畅。
