# AFK Arena

- **类型**: 放置 RPG
- **平台**: Mobile
- **开发商**: Lilith Games
- **首次发布**: 2019
- **一句话描述**: 结合放置 RPG 机制和奇幻叙事的放置游戏，角色自动战斗，丰富的战役。

## 玩法规则

角色在你离开时自动战斗，获得奖励并通过丰富的战役推进。核心是英雄收集与协同——组建具有协同效应的战略团队。

战役模式推进故事，竞技场模式提供 PVP 挑战。放置机制允许离线获得资源，登录后收取奖励。

## 核心循环

组建团队 → 自动战斗 → 获取奖励 → 升级英雄 → 推进战役

## 核心机制

- 英雄收集与协同：战略团队构建
- 自动战斗：离线获得资源
- 战役模式：丰富的故事推进
- 竞技场：PVP 挑战
- 放置收益：离线奖励

## 为什么好玩

角色自动战斗的便利性加上英雄收集的策略深度。每次登录都有丰厚奖励等待收取。

## 粘性来源

- 离线收益：不在线也在进步
- 英雄收集：数十个英雄等待解锁
- 协同策略：英雄搭配的深度
- 战役叙事：丰富的故事体验

## Meta 系统

英雄升级和装备。提升英雄等级、解锁技能和获取装备。

## 实现难度

低。放置 RPG 核心系统成熟，英雄平衡是难点。
