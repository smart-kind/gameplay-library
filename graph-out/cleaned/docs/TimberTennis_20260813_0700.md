# 木头网球（Timber Tennis）

- **类型**: 休闲 / 反应
- **平台**: Mobile (iOS+Android)
- **开发商**: Digital Melody
- **首次发布**: 2017
- **一句话描述**: 两只像素风格的小动物用球拍互相对打网球，操作简单但节奏快速

## 玩法规则

游戏采用竖屏视角，两只像素小动物（通常是熊和兔子等）分别位于屏幕上方和下方，各持一个网球拍。

玩家通过点击屏幕左右两侧来移动球拍接球。球速会随着回合数逐渐加快，增加反应难度。

球落在对方半场得分，对方漏球也得一分。先得7分者获胜（需领先2分）。

操作极其简单——只有左右移动。但随着球速越来越快，考验的是反应速度和预判能力。

## 核心循环

移动球拍 → 接球回击 → 球速加快 → 先漏球者输

## 核心机制

- 渐进难度曲线：球速随回合逐步增加，从悠闲到极快，考验的是反应速度的极限。
- 极简操作：只有左右移动一个输入维度，但深度来自对球速和轨迹的预判。
- 连胜计数：连续得分会有视觉/音效反馈，强化了"再来一局"的冲动。

## 为什么好玩

极短的单局时间（通常1-3分钟）和"差一个球就赢"的遗憾感让人忍不住再来一局。适合碎片化时间。

## 粘性来源

超短单局时间 + 即时反馈（得分/失分立刻看到） + 球速越来越快的紧张感 = 碎片时间杀手。

## Meta 系统

角色/皮肤解锁：连胜获得金币，用于解锁新的动物角色和主题。纯装饰性，不影响游戏平衡。

## 实现难度

低。球拍移动 + 球的物理弹跳 + 计分系统。最大技术难点：球速曲线的平滑增加（太快玩家反应不过来，太慢无聊）。
