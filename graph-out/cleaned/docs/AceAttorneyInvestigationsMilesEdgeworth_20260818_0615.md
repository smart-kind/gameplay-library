# 逆转检察官（Ace Attorney Investigations: Miles Edgeworth）

- **类型**: 冒险 / 解谜 / 推理
- **平台**: Nintendo DS / iOS / Android
- **开发商**: Capcom
- **首次发布**: 2009
- **一句话描述**: 逆转裁判系列的衍生作品，玩家扮演检察官御剑怜侍，通过调查犯罪现场和逻辑推理揭开真相。

## 玩法规则

游戏采用2D卡通风格的画面，场景包括犯罪现场、办公室、会议室等。UI主要由对话文本框、证据栏和逻辑面板组成。触控笔是主要的操作工具。

玩家有两个核心阶段：调查阶段和逻辑阶段。调查阶段中，玩家用触控笔点击场景中的各个位置进行搜索，收集证据物品和线索。点击NPC进行对话，获取证词。逻辑阶段中，玩家将收集到的证据进行配对组合——选择两个相关的线索，如果匹配正确则触发新的推理，揭示隐藏信息。

每个案件有明确的目标：找出真凶并还原案件真相。玩家需要将所有线索串联起来，用证据指出证词中的矛盾。如果推理错误次数过多，游戏会给出提示引导玩家思考。

游戏的目标是完成所有案件的调查，揭露背后的阴谋。案件之间有关联，最终指向一个更大的真相。整个游戏包含5个独立但又相互关联的案件。

## 核心循环

调查现场收集线索 -> 逻辑推理组合证据 -> 揭示新信息 -> 推进案件

## 核心机制

- Logic Chess（逻辑推理系统）：将收集到的两个相关线索配对，推理出新的结论。这是游戏的核心机制，玩家需要理解线索之间的逻辑关系。
- Crime Scene Investigation（现场调查）：在360度全景场景中搜索隐藏证据，使用触控笔放大、点击、拖拽物品，体验真实的现场勘查。
- Witness Interrogation（证人问询）：通过与证人的对话获取信息，用已有的证据指出证词中的矛盾，逼迫证人说出真相。

## 为什么好玩

与逆转裁判系列的法庭辩论不同，本作以调查和推理为核心。御剑怜侍作为主角的冷峻形象搭配精密的逻辑推理，提供了不同于成步堂的推理体验。每次成功连接线索时的顿悟时刻非常有成就感，仿佛自己也成为了名侦探。

## 粘性来源

粘性来自推理过程的拼图感——每条线索都像拼图碎片，当玩家找到正确组合时的满足感极强。案件之间的悬念关联也促使玩家连续推进，想知道真相到底是什么。

## Meta 系统

无。本作是纯线性叙事游戏，没有外围成长系统。所有剧情内容一次性解锁。

## 实现难度

中。最大的技术难点在于逻辑推理引擎——需要设计线索之间的配对关系图和推理触发条件，确保推理链条的完整性和提示系统的合理性。
