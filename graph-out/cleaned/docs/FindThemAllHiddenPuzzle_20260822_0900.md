# Find Them All - Hidden Puzzle (Find Them All - Hidden Puzzle)

- **类型**: 隐藏物品寻物 / 休闲解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Wuhan Maimeng Network Technology Co Limited
- **首次发布**: 2020
- **一句话描述**: 在精美图片中寻找隐藏物品的益智寻物游戏，包含百余关卡和拼图收集系统

## 玩法规则

游戏呈现一幅充满细节的画面，玩家需要在有限时间内找到所有隐藏在画面中的物品。物品可能巧妙地融入背景、部分遮挡或与周围物体混淆，考验玩家的观察力和耐心。

操作方式：双指放大画面可以更仔细地查看细节（"Enlarge the picture to see better"）。在画面中滑动浏览，发现目标物品后点击即可收集。如果遇到困难，可以使用提示功能（Tips）来高亮显示某个物品的位置。

游戏设有时间限制——需要在限定时间内找齐所有物品。完成一个关卡后解锁下一个，难度逐步递增。超过100个关卡，且每周更新。

游戏结束条件：在规定时间内未能找到所有物品则关卡失败；找齐所有物品则过关并获得拼图碎片奖励。

## 核心循环

观察画面 → 找到隐藏物品 → 收集拼图碎片 → 解锁新关卡 → 继续寻找

## 核心机制

- **放大镜机制**：双指放大查看细节，模拟真实寻物的观察体验，增加沉浸感
- **限时寻物**：时间压力增加紧张感，平衡了寻物游戏的休闲属性
- **拼图收集奖励**：每关完成后获得一块拼图碎片，拼完整图提供长期目标和视觉成就感
- **提示系统**：在困难时可使用提示，降低挫败感，确保不同水平的玩家都能推进

## 为什么好玩

每周更新的关卡保证了内容的新鲜感，拼图收集系统提供了超越单局游戏的长期目标。"找到藏得很巧妙的物品"带来的"原来在这里！"的顿悟瞬间是核心乐趣。

## 粘性来源

"每周更新"是内容粘性——总有新关卡等待挑战。拼图收集是成就粘性——拼完整幅图的满足感驱动持续游玩。限时模式制造了紧张感和重复挑战的动力（"上次差3秒就找完了"）。适合全家一起玩的设计也增加了社交分享的动力。

## Meta 系统

- **拼图收集系统**：每关完成后获得拼图碎片，收集碎片拼成完整图画，提供视觉化的进度反馈和长期目标

## 实现难度

低。核心是静态图片+物品坐标检测+放大镜功能。最大技术难点是关卡设计——为上百个关卡找到合适的图片并合理放置隐藏物品，需要大量美术和内容工作，而非技术挑战。
