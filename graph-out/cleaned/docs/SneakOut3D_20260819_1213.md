# Sneak Out 3D（潜行逃脱3D）

- **类型**: 潜行 / 解谜 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: MondayOFF
- **首次发布**: 2023
- **一句话描述**: 操控角色在充满守卫和机关的场景中潜行移动，躲避视线，到达终点。

## 玩法规则

游戏采用俯视或斜45度视角。场景中有起点、终点、障碍物、守卫和机关。玩家通过**滑动屏幕**控制角色移动方向，松开后角色沿该方向匀速移动。

场景中的守卫有固定的巡逻路线和锥形视野区域（通常以扇形显示）。如果角色进入守卫的视野范围，会被发现并触发警报，游戏失败。玩家需要**等待守卫转身或移动的空档**，快速穿过危险区域。

部分关卡包含激光栅栏（触碰即失败）、移动平台（需要把握时机跳跃）、隐身道具（短时间内不被发现）等元素。玩家需要规划移动路线，在守卫巡逻的间隙中找到安全通道。

操作方式简单但精确度要求高——滑动一次角色移动一段固定距离，玩家需要预判守卫的巡逻节奏来规划每一步。

## 核心循环

观察场景和守卫巡逻路线 → 规划移动路径 → 滑动控制角色 → 等待时机穿过危险区 → 到达终点 → 进入下一关

## 核心机制

- **时机驱动的潜行**：守卫有固定的巡逻节奏，玩家需要在"安全窗口"内快速移动。这类似于节奏游戏，但节奏是由敌人的行为决定的。
- **视野预判**：守卫的视野范围以扇形显示，玩家可以清楚看到哪些区域是安全的，但守卫的转向时机和速度会影响实际安全窗口。
- **一笔画移动**：部分版本中，角色一旦开始移动就不会停止，直到撞墙或到达目标，这要求玩家提前规划完整路径。
- **道具辅助**：隐身斗篷（短时间内不被发现）、减速钟（减缓守卫移动速度）等道具帮助玩家通过高难度关卡。

## 为什么好玩

Sneak Out 3D 的核心乐趣在于"猫鼠游戏"的紧张感——你紧贴着守卫的视野边缘滑行，差一毫米就会被发现。每次成功穿过看似不可能的巡逻路线时的成就感非常强。游戏将复杂的潜行机制简化为"滑动+等待时机"两个操作，降低了门槛但保留了策略深度。

## 粘性来源

- **"差一点就过了"的懊恼**：在终点前一步被发现是最强的重试驱动力。
- **关卡递进**：每个关卡引入新的机关和守卫类型，保持新鲜感。
- **完美通关挑战**：部分关卡有"不被发现"和"最短时间内完成"的额外成就。
- **短时局**：每关只需几十秒到几分钟，失败后立即重试无负担。

## Meta 系统

- **关卡解锁**：线性推进，完成一关解锁下一关。
- **角色皮肤**：通过金币解锁不同的潜行者外观。
- **每日挑战**：每天提供特殊关卡或限时任务。

## 实现难度

低到中。核心是简单的碰撞检测和视野判定（扇形区域检测）。最大技术难点是守卫巡逻路径的流畅动画和视野扇形的准确计算（角色与扇形边界的实时判定）。
