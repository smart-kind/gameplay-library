# 模糊特技赛车（Blur）

- **类型**: 竞速 / 战斗赛车
- **平台**: PC / PS3 / Xbox 360 / Mobile
- **开发商**: Bizarre Creations
- **首次发布**: 2010
- **一句话描述**: 将现实世界的赛车与街机风格的道具战斗相结合的竞速游戏，是Project Gotham Racing的精神续作。

## 玩法规则

游戏画面以真实城市和赛道为背景，使用真实授权车辆（如宝马、福特、雪佛兰等）。赛道上有散布的能量点（Powerups），玩家驾车经过时会收集到攻击性或防御性道具。

玩家通过加速/刹车/转向控制车辆，收集赛道上的道具（如导弹、地雷、护盾、涡轮增压等）。道具使用后对前方或周围的对手造成伤害，造成车辆失控或减速。

比赛名次由到达终点的顺序决定。道具系统允许落后者通过强力攻击反超，保持比赛的悬念。不同车辆有不同的性能参数：最高速度、加速能力、操控性和耐久度。

游戏有多种模式：锦标赛模式（完成一系列比赛）、多人对战（在线或本地分屏）、Bionic模式（结合真实与虚拟赛道）等。

## 核心循环

赛车收集道具 -> 使用道具攻击对手 -> 提升名次 -> 赢得比赛解锁新车/赛道

## 核心机制

- Reality-based Powerup系统：道具散布在真实赛道上，玩家需要在高速驾驶中判断是否冒险偏离路线去收集道具，还是保持线路领先。
- Shatter/Repel攻击系统：不同的道具组合产生不同的效果，如导弹追踪、地雷陷阱、护盾防御等。
- 动态名次系统：落后的玩家会获得更强大的道具，确保比赛始终保持悬念。

## 为什么好玩

Blur将拟真赛车的速度感与道具战斗的混乱感完美结合。在真实的城市街道上飞驰，同时用导弹攻击对手，既有速度快感又有战斗刺激。Bizarre Creations对赛道设计的精湛技艺让每条赛道都充满乐趣。

## 粘性来源

粘性来自多人对战的社交竞争和车辆/赛道的收集解锁。每场比赛都有不同的道具分布和对手行为，保证了重复游玩的新鲜感。

## Meta 系统

车辆收集与升级系统。通过比赛获得Fan Points（粉丝点数），解锁新的真实授权车辆和特殊涂装。车辆有不同的属性（速度、操控、耐久性）。

## 实现难度

高。最大的技术难点在于物理引擎——需要同时处理真实车辆的物理模拟和道具攻击造成的异常物理效果，还要保证多人模式的同步性。
