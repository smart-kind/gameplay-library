# 精英小队 动作射击（Squad Alpha - Action Shooting）

- **类型**: 动作射击 / 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: SayGames
- **首次发布**: 2021
- **一句话描述**: 一款俯视视角的动作射击游戏，玩家控制特种小队成员完成各种战术任务。

## 玩法规则

玩家控制一支特种小队，在俯视视角的地图中完成各种任务。操作方式：虚拟摇杆控制移动，点击目标进行射击，滑动切换武器。

关卡设计包含掩体、敌人据点、人质救援等多种元素。玩家需要利用掩体躲避敌人火力，合理分配小队成员的站位。

敌人有不同的行为模式：有些会巡逻，有些会躲在掩体后射击，有些会呼叫增援。玩家需要观察和适应不同的敌人策略。

## 核心循环

选择关卡 -> 部署小队 -> 战术推进 -> 完成任务 -> 升级装备 -> 挑战新关卡

## 核心机制

- 小队指挥: 控制多名小队成员，需要合理分配站位和火力。每个成员有独立的武器和技能，组合使用产生战术效果。
- 掩体系统: 利用掩体躲避敌人火力，增加战术深度。掩体有耐久度，被多次射击后会破坏。
- 装备升级: 完成任务获得资源，升级武器、护甲和特殊技能。升级后的小队成员在后续关卡中表现更强。

## 为什么好玩

俯视角射击的爽快感加上战术决策的深度，让游戏既有动作的刺激又有策略的满足。

每个关卡都像一道战术谜题，需要玩家观察、思考和执行。

## 粘性来源

关卡的渐进式难度和装备升级系统让玩家想过一关就升级。

数百个关卡提供了充足的游玩内容。角色和武器的多样化搭配让每次游玩都有不同的体验。

## Meta 系统

装备升级系统：消耗资源升级武器和技能。

角色解锁：解锁新的小队成员。

关卡进度：跟踪任务完成度。
