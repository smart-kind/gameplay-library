# 汉堡冲刺（Burger Rush）

- **类型**: 模拟经营 / 时间管理
- **平台**: Mobile (iOS)
- **开发商**: Unknown
- **首次发布**: 2008
- **一句话描述**: 一款餐厅模拟经营游戏，玩家需要在限定时间内满足顾客的汉堡订单。

## 玩法规则

游戏界面展示一个汉堡餐厅的工作台，上面排列着各种食材（面包、肉饼、生菜、番茄、芝士等）和烹饪设备（烤炉、炸锅）。顾客从一侧进入，坐在吧台前，头顶显示他们的订单需求。

玩家需要按照订单要求，依次将食材拖放到制作区域：先放底层面包，然后放肉饼、配料，最后放顶层面包。制作完成的汉堡拖给对应的顾客即可得分。

顾客有耐心值，等待时间过长会愤怒离开，导致扣分和失去收入。随着关卡推进，顾客数量增多、订单复杂度增加（如双层汉堡、特殊配料要求）、出现VIP顾客（给小费但要求更快）。

## 核心循环

接收订单 → 按顺序组装汉堡 → 服务顾客获得收入 → 升级设备解锁新关卡

## 核心机制

- **多任务时间管理**：同时处理多个顾客订单是核心挑战。玩家需要预判哪些订单可以合并处理（比如多个顾客都要肉饼时一次性烤多块），这类似于《Diner Dash》的多线程操作逻辑。
- **升级系统**：用赚取的收入购买更快的烤炉、自动配料机等设备升级，降低操作压力。
- **连击加分**：连续正确服务顾客会获得combo加分，鼓励玩家保持稳定节奏而不是手忙脚乱。

## 为什么好玩

时间压力带来的紧张感和完成服务后的成就感形成强烈对比。当多个顾客同时催促时，大脑高速运转做出决策的体验非常有代入感，就像真的在厨房忙活一样。

## 粘性来源

- **渐进式挑战**：每关比上一关多一个变量（更多顾客、更复杂订单、更快流失），让玩家不断适应新节奏。
- **升级的正反馈**：看到自己用赚的钱买新设备、餐厅变得更豪华，有明确的成长感。
- **"就差一点"效应**：差一秒完成目标或差一个顾客就能三星，强烈驱动重玩。

## Meta 系统

- **餐厅升级**：用游戏内货币购买更快的设备和更多的工作台位置。
- **关卡解锁**：达到目标分数后解锁新餐厅场景（从街边小摊到高级餐厅），每个场景有新的视觉主题和食材类型。

## 实现难度

低。核心是UI拖拽和计时器逻辑。最大难点是同时管理多个顾客状态的调度系统——需要确保在触屏设备上操作流畅且不发生误触，同时保持动画的流畅性。

## 变体设计

可以加入"时间挑战"模式——不设置顾客，而是要求在限定时间内完成尽可能多的订单。也可以加入"多人合作"模式，两个玩家各自负责不同工作台的食材组装。
