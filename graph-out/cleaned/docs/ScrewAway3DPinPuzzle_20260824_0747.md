# 螺丝钉逃离（Screw Away: 3D Pin Puzzle）

- **类型**: 3D 螺丝解谜 / 物理益智 / 手指灵活性
- **平台**: Mobile (iOS + Android)
- **开发商**: WONDER GROUP HOLDINGS LIMITED
- **首次发布**: 2023
- **一句话描述**: 通过精确的手指操作拧下 3D 场景中的螺丝钉，释放被固定物体的物理益智游戏。

## 玩法规则

游戏呈现 3D 渲染的场景，包含木板、金属板等物体，用多个螺丝钉固定在墙上或彼此叠加。玩家通过触屏操作旋转螺丝钉（手指在螺丝上滑动或长按旋转）将其拧出。

与普通螺丝解谜不同，本游戏强调手指操作的精确性和力度感。螺丝钉在拧出过程中有真实的阻力反馈——需要持续旋转直到完全退出。某些螺丝钉可能因生锈或紧固需要更多旋转圈数。

每颗螺丝钉拧出后，检查是否有物体不再被固定。失去所有固定的物体会在重力作用下掉落，发出真实的碰撞音效。关卡目标是拧下所有必要的螺丝钉让所有指定物体掉落。

部分关卡设有"关键螺丝"——拧下后会引发连锁反应，释放多个物体。找到这些关键螺丝是高效通关的秘诀。

## 核心循环

观察 3D 场景 → 选择并旋转拧下螺丝 → 物体因重力掉落 → 清理场景 → 进入下一关

## 核心机制

- **3D 旋转操作**：区别于简单的点击拆卸，本游戏要求玩家模拟真实拧螺丝的动作——持续旋转直到退出。这增加了触觉反馈和操作满足感。
- **物理掉落**：物体在失去固定后按真实物理规则掉落，包括碰撞、滚动和堆叠。这不仅是视觉反馈，也是游戏机制——掉落的物体可能撞击其他螺丝。
- **阻力系统**：不同螺丝有不同的"拧紧度"，影响拧出所需的旋转次数，模拟真实体验。

## 为什么好玩

3D 渲染和物理引擎的结合让简单的"拧螺丝"变成了感官享受。每次旋转的金属摩擦声、螺丝脱落时的"咔嗒"声、物体落地的碰撞声，共同构建了极具满足感的 ASMR 式体验。同时，解谜的脑力挑战和操作的触觉反馈形成了双重乐趣。

## 粘性来源

物理解谜的空间挑战——随着关卡复杂度增加（更多层叠、更隐蔽的螺丝），推理难度递增；ASMR 式的操作反馈让人上瘾——即使不解谜，光是拧螺丝的触感反馈就令人放松；关卡数量大，从简单到复杂提供了平滑的学习曲线。

## Meta 系统

轻度进度系统：关卡进度地图、星星评价（基于螺丝拆卸次数）。可能包含广告解锁提示或付费去广告。

## 实现难度

中。3D 渲染 + 物理引擎（需要处理刚体碰撞、重力、摩擦力）。最大技术难点是物理模拟的确定性——需要确保每关在给定螺丝拆卸顺序下有可预期的结果，同时物理引擎的性能在移动设备上需要优化。
