# 悄悄溜走3D（Sneak Out 3D）

- **类型**: 超休闲 / 解谜 / 潜行
- **平台**: Mobile (iOS+Android)
- **开发商**: MondayOFF
- **首次发布**: 2020
- **一句话描述**: 利用简单的点击操作在3D场景中潜行前进，避开巡逻者的视线，到达终点即为成功。

## 玩法规则

游戏画面呈现一个3D俯视角的小型场景，玩家需要控制角色从起点潜行到终点。场景中有巡逻的守卫或移动的障碍物，被守卫发现即告失败。

操作极为简单：点击场景中的一个位置，角色会向该位置移动。但关键在于时机——守卫的视野范围通常以锥形显示（绿色/红色区域），角色必须在守卫视线盲区或背对时移动。点击后角色会持续移动到目标位置，不会中途停止，因此需要预判守卫的移动路线。

每个关卡有独特的布局：走廊、房间转角、家具遮挡、巡逻路线等。部分关卡还设有可互动的道具，如关闭灯光、开门等，为玩家创造潜行机会。

## 核心循环

观察守卫巡逻路线 → 选择合适的时机和目标位置点击 → 角色移动 → 被发现则重试/到达终点则过关

## 核心机制

- **视线潜行**：守卫的视野范围可视化显示，玩家需要在盲区内移动，类似经典潜行游戏但简化为点击即走
- **预判移动**：点击后角色不会中途停止，玩家必须预判守卫在角色移动期间的路径变化
- **关卡递增难度**：从单一守卫到多个守卫交叉巡逻，从固定路线到随机巡逻，逐步增加复杂度

## 为什么好玩

Sneak Out 3D 将"潜行"这一复杂的游戏类型简化为最核心的体验——观察、等待、行动。每次成功穿越守卫视线的紧张感，以及被发现后的"差一点"懊恼，形成了极强的重玩动力。极简的操作让注意力完全集中在策略思考上。

## 粘性来源

- **"差一点就成功"的不甘心**：被发现的瞬间往往只差一秒，激发立即重来的冲动
- **关卡数量充足**：数百个精心设计的关卡提供持续的挑战内容
- **解谜满足感**：找到完美路线时的"原来如此"时刻带来强烈的智力成就感

## Meta 系统

无复杂外围系统。通过关卡获得星星评价（基于用时和被发现次数），星星用于解锁新章节。没有付费内购或社交功能，纯粹的单机解谜体验。

## 实现难度

低。3D场景可以做得简约，核心逻辑是简单的视野检测和碰撞判断。最大技术难点在于3D视角下视野锥形的准确计算和角色路径的可视化预览，需要确保玩家能清楚看到"哪里安全、哪里危险"。
