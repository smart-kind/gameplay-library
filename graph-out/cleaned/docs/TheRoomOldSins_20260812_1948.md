# 迷室：旧罪的迷宫（The Room: Old Sins）

- **类型**: 解谜 / 密室逃脱
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Fireproof Games
- **首次发布**: 2018
- **一句话描述**: 在一座诡异的娃娃屋中探索，通过旋转、拆解、组合各种精密机关装置来逐步揭开黑暗秘密的 tactile 解谜游戏

## 玩法规则

玩家置身于一个精致的场景中——一座维多利亚风格的娃娃屋。这个娃娃屋不是玩具，而是一个充满机关和秘密的装置。每个房间都有各种锁、抽屉、暗格和机械装置等待解开。

操作完全基于触控手势：点击放大查看细节、双指旋转物体从不同角度观察、滑动打开抽屉和暗格、拖拽组合零件。游戏强调"tactile"（触觉）体验——每个机关的转动、齿轮的咬合、锁芯的弹跳都有对应的触觉反馈和音效。

解谜流程是线性的：解开一个机关发现下一个线索，逐步深入。每个谜题的答案通常隐藏在场景中，需要仔细观察、尝试和逻辑推理。游戏提供"提示眼镜"道具（消耗品），在卡关时可以查看提示。

随着探索深入，场景从温馨的娃娃屋逐渐变成黑暗诡异的密室，暗示着一个不祥的故事。

## 核心循环

观察场景 → 找到可交互的机关 → 旋转/拆解/组合解开机关 → 发现新区域和新线索 → 逐步揭开故事真相

## 核心机制

- **触觉解谜系统**：每个机关的交互都经过精心设计——转动的阻力感、锁扣的咔嗒声、齿轮的咬合感都通过动画、音效和触觉反馈完美呈现。为什么有效：它将"解谜"从"找出正确答案"升级为"体验一个精密装置的运作过程"。即使你知道答案，操作机关本身也是一种享受。
- **多层嵌套谜题**：一个抽屉打开后里面有一个盒子，盒子里有一把钥匙，钥匙打开另一个房间的锁。为什么有效：它创造了"俄罗斯套娃"式的解谜节奏——每解开一层都有"里面还有什么"的期待感，这种嵌套结构天然制造好奇心驱动。
- **环境叙事**：游戏几乎没有文字叙述，故事通过场景中的物品、信件、照片和逐渐变化的氛围传递。为什么有效：它让玩家成为故事的"发现者"而非"接受者"——你自己找到的线索比任何过场动画都更有冲击力。
- **提示系统**：使用"眼镜"道具可以查看当前场景中的可交互对象提示，但提示数量有限。为什么有效：它在"不卡关"和"保持挑战"之间取得了平衡——卡得太难受时可以求助，但需要消耗资源，促使玩家先尝试自己解决。

## 为什么好玩

The Room 系列的魔力在于它把一个"解谜游戏"变成了一个"可以互动的精密钟表"。每一次齿轮的转动、每一次锁扣的弹开都让你感受到设计师对细节的极致追求。当最后一个机关解开，一个隐藏空间在你面前缓缓打开时——那种"原来如此"的满足感是其他游戏无法提供的。

## 粘性来源

- **章节制体验**：每部作品有 4-5 章，每章约 1-2 小时，完美适配手机游戏的单次游玩时长
- **系列连贯性**：四部作品共享同一个世界观，玩完一部自然想买下一部
- **口碑传播**：精致的机关设计和独特的触觉体验让游戏在社交媒体上极具分享价值
- **无时间压力**：没有倒计时、没有生命值，玩家可以按照自己的节奏慢慢解谜

## Meta 系统

**无外围系统**：
- 游戏没有等级、装备、抽卡等 Meta 系统
- 提示道具（眼镜）是唯一消耗品，但可通过游戏内成就获得
- 对核心玩法的影响：无 Meta 系统意味着游戏设计完全专注于解谜体验本身，不被留存或付费机制妥协

## 实现难度

中 — 技术难点在于**3D 物体的精细交互系统**：每个机关都需要独立的交互逻辑、动画序列、音效和触觉反馈。最大的挑战是**交互设计的精细度**——不是"能不能实现"的问题，而是"做得够不够好"的问题。齿轮转动的阻尼感、锁扣弹开的力度、抽屉滑动的摩擦力……这些细节需要大量手工调校，无法用算法自动生成。
