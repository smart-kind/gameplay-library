# Disc Drivin'（飞盘赛车）

- **类型**: 竞速 / 弹射
- **平台**: Mobile (iOS+Android)
- **开发商**: VooFoo Studios
- **首次发布**: 2011
- **一句话描述**: 用弹射飞盘的方式操控赛车，在赛道上竞速并收集能量

## 玩法规则

玩家通过弹射飞盘来控制赛车。屏幕底部有一个飞盘发射器，玩家拖动飞盘设置方向和力度后释放，飞盘飞出后会沿着赛道前进并推动赛车。

赛道上有各种障碍物（弯道、墙壁、陷阱），飞盘撞到墙壁会反弹，玩家需要预判弹射角度来绕过障碍。赛道上散布着能量道具（加速、护盾、导弹），飞盘收集后转化为赛车的能力。

支持多人对战模式，玩家同时弹射飞盘在赛道上竞争。每圈结束后重新发射飞盘，最先完成规定圈数者获胜。

赛车有不同的属性（速度、操控、重量），影响飞盘碰撞后的物理效果。

## 核心循环

瞄准并弹射飞盘 → 飞盘沿赛道前进并推动赛车 → 收集道具 → 到达终点或完成圈数 → 下一圈/下一关

## 核心机制

- **弹射物理（Fling Physics）**：核心操作机制。飞盘有真实的物理反弹效果，玩家利用墙壁反弹绕过弯道或抄近路
- **能量收集（Energy Pickup）**：赛道上的道具自动被飞盘收集，转化为赛车能力（加速、护盾、攻击）
- **多人同步竞速（Multiplayer Racing）**：多名玩家同时弹射飞盘，飞盘碰撞产生干扰效果，增加竞技乐趣
- **赛道设计（Track Design）**：精心设计的赛道利用物理反弹创造多种路线选择，高手可以找到捷径

## 为什么好玩

将弹射操作和竞速结合，每次发射都是一次小冒险——飞盘的反弹轨迹充满不确定性但又有规律可循。多人对战时互相干扰的场面非常欢乐。

## 粘性来源

具体到机制层面：1）弹射物理的"差一点"效应——每次发射都让人觉得下次可以更好；2）赛道捷径发现带来的成就感；3）多人对战中的意外碰撞和反转；4）能量道具收集的即时正反馈。

## Meta 系统

赛车解锁系统。通过完成关卡和比赛获得金币，解锁不同属性的赛车。不同赛车有不同的速度、操控和重量，影响飞盘碰撞后的物理表现，为重复游玩提供动力。

## 实现难度

中。最大的技术难点是物理引擎的调优——飞盘的反弹需要既真实又可预测，太难玩家会感到随机，太简单则缺乏挑战。多人同步的物理状态同步也是一个技术点。
