# Push Battle 推挤对战（Push Battle - cool game）

- **类型**: 休闲竞技 / 物理对战
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2019
- **一句话描述**: 一款基于物理引擎的推挤对战游戏，玩家控制角色将对手推出场地即可获胜。

## 玩法规则

玩家在一个圆形或方形的竞技场上与其他玩家对战。通过点击或滑动屏幕控制角色移动，目标是利用冲撞将对手推出场地边界。

角色有一定的质量和惯性，推撞时的力度和角度会影响效果。重角色推力强但移动慢，轻角色移动快但推力弱。

场地边缘没有护栏，一旦掉出场地即被淘汰。支持单人对战AI和多人在线对战。某些场地有动态元素如移动平台、旋转障碍等。

## 核心循环

选择对战模式 -> 控制角色冲撞 -> 将对手推出场地 -> 获胜晋级 -> 解锁新角色

## 核心机制

- 物理推挤: 基于真实物理模拟的碰撞系统，角色的质量、速度、角度共同决定推撞效果。
- 场地淘汰制: 没有生命值概念，唯一目标是将对手推出边界，规则简单直观，任何人都能理解。
- 角色差异化: 不同角色有不同质量、速度和特殊技能，影响推撞策略。

## 为什么好玩

物理碰撞的不可预测性和把对手推出场地的简单快感让游戏充满乐趣。每局时间短，节奏快。

不同角色之间的质量差异创造了丰富的策略选择，是选择快速轻角色灵活游走还是选择重型角色正面碾压。

## 粘性来源

差一点就把他推下去了的不甘心感让人想再来一局。角色解锁和皮肤收集提供长期目标。

多人在线匹配增加了对战的多样性，每次遇到不同的对手和角色组合都带来新鲜的体验。

## Meta 系统

角色解锁系统：通过比赛获得金币解锁新角色。

皮肤系统：为角色更换外观。

排位赛：参与排位赛提升段位。

## 实现难度

中 - 物理引擎的调优是最大难点，需要确保碰撞效果既真实又有趣。多人同步也是技术挑战。
