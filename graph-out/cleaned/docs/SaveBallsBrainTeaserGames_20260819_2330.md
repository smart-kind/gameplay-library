# Save Balls: Brain Teaser Games

- **类型**: 益智解谜 / 物理绘制 / 逻辑
- **平台**: Mobile (iOS+Android)
- **开发商**: AI Games FZ
- **首次发布**: 2022
- **一句话描述**: 一款物理绘制类解谜游戏，玩家通过画线来保护球体免受障碍物伤害，考验逻辑思维和物理直觉

## 玩法规则

游戏画面展示一个场景，其中包含需要保护的球体（通常是彩色的圆形物体）和威胁它们的障碍物（如尖刺、移动刀片、下落的石块、火焰等）。球体可能悬挂在某处或正在向危险区域坠落。

玩家的核心操作是在屏幕空白区域用手指画出线条或封闭形状。这些画出的线条会立即变成具有物理属性的实体屏障——它们有质量、有碰撞体积、遵循重力和物理法则。画线的位置、角度、长度和形状决定了它们能否有效保护球体。

屏幕通常显示：上方的球体（保护目标）、周围的障碍物（威胁源）、以及玩家可绘制区域。部分关卡会限制可绘制线条的数量或总长度。玩家需要在观察障碍物运动模式后，画出能够阻挡、引导或改变球体运动路径的屏障。

当所有球体被安全保护（不接触任何危险物）达到关卡要求时间，或球体被引导到安全区域时，关卡通过。如果任何球体被障碍物击中或掉落出屏幕，游戏失败，玩家需要重新绘制。

## 核心循环

观察障碍物运动模式 -> 画出线条作为屏障引导球体 -> 验证保护效果 -> 获得评价进入下一关

## 核心机制

- **物理绘制屏障系统**: 玩家画出的每条线都变成具有真实物理属性的实体——有质量、有碰撞体积、受重力影响。线条可以水平放置作为平台，倾斜放置作为滑道，或围成封闭区域作为容器。这种自由度让同一个关卡有多种解法
- **障碍物运动模式系统**: 障碍物有不同的运动方式——固定尖刺（静态威胁）、来回摆动的刀片（周期性威胁）、从上往下落的石块（定时威胁）、旋转的火焰圈（持续威胁）。玩家需要识别每种模式并针对性地绘制屏障
- **多球体保护系统**: 高级关卡同时保护多个球体，它们可能在不同位置以不同速度运动。玩家需要在有限线条数量内设计一个能同时保护所有球体的方案，大幅提升策略复杂度

## 为什么好玩

画线变实体的即时物理反馈非常直观——你画什么它就变成什么，这种"所见即所得"的创造力让玩家感觉自己在"设计解决方案"。同时物理模拟的不可完全预测性（线条可能滑动、球体可能弹跳）带来了"意外效果可能恰好解决问题"的惊喜感

## 粘性来源

具体来说：1）创造力满足——每个关卡都有多种解法，玩家会尝试"能不能用更少的线条解决"；2）"差点就成功"的驱动力——球体就差一点点就被保护住了，促使玩家微调线条位置再试；3）关卡递进带来的能力成长——从保护一个球到保护多个球，从静态障碍到复杂运动模式，玩家逐步掌握物理直觉；4）简洁的美术风格和清晰的视觉效果降低了理解门槛，让人容易"再来一局"

## Meta 系统

无（纯关卡制游戏，无外围成长系统。部分版本可能有提示系统，消耗游戏内货币获取绘制方案的提示）

## 实现难度

中等。最大技术难点在于物理引擎的性能优化——每次玩家画线都需要实时计算碰撞检测和物理模拟，同时在移动端保持流畅。另一个难点是不同设备屏幕比例下，物理参数的一致性调整

## 关卡设计趋势

游戏关卡通常遵循由浅入深的设计原则：前期关卡（1-50关）主要让玩家熟悉基本操作和规则，圆点种类少、网格小、步数充裕；中期关卡（50-200关）开始引入多目标并行的挑战，如同时消除两种颜色的圆点、在步数限制内达到分数目标等；后期关卡（200关以上）则加入特殊元素——如不可消除的"石头"圆点、会随步数增加而"冻结"的圆点、需要多次消除才能清除的"多层"圆点等，大幅提升策略复杂度。

这种渐进式难度设计确保了玩家在每个阶段都能感受到"略有挑战但可克服"的心流体验，既不会因为太简单而无聊，也不会因为太难而放弃。
