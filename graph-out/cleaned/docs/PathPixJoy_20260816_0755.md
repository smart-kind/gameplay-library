# PathPix Joy（PathPix Joy）

- **类型**: 益智 / 连线解谜
- **平台**: Mobile (iOS + Android)
- **开发商**: Kris Pixton
- **首次发布**: 2012
- **一句话描述**: 用彩色线条连接配对的点来完成路径的益智解谜游戏

## 玩法规则

游戏画面是一个网格，网格上分布着若干配对的彩色圆点。玩家的任务是在每对相同颜色的圆点之间画一条连续的路径线条。

路径不能交叉或重叠——每条路径必须占据独立的网格单元格。当所有配对都用路径连接且没有冲突时，整个网格被填满，谜题即告完成。

玩家通过触屏滑动来绘制路径：从某个彩色圆点开始，沿着网格向同色的另一个圆点滑动。绘制完成后，可以重新调整路径的走向。

随着关卡推进，网格尺寸增大（从5×5到更大的尺寸），配对数量增加，可用空间变得更紧张，需要更精细的规划。

游戏包含99个关卡，难度从"easy到extreme"逐步递增，适合不同水平的玩家。

## 核心循环

观察配对位置 → 规划路径 → 滑动绘制连线 → 解决冲突 → 填满网格进入下一关

## 核心机制

- **路径连线**：核心玩法是连接配对圆点，路径不能交叉，这迫使玩家在有限空间内精妙规划
- **空间填满**：所有路径加起来必须填满整个网格，这意味着不仅要连接配对，还要确保路径覆盖所有格子
- **渐进难度**：从简单的小网格到复杂的大网格，谜题设计者通过增加配对数量、缩小可用空间来逐步提升难度

## 为什么好玩

PathPix的核心魅力在于"看起来简单但做起来难"——初期关卡几秒钟就能解开，但后期需要反复调整策略。这种"差一点就能解开"的感觉让人欲罢不能。

## 粘性来源

空间规划的"顿悟时刻"是核心粘性——当玩家突然想通了一条路径的走法，瞬间解开整个谜题时的快感非常强烈。99个关卡提供了充足的挑战内容。

## Meta 系统

无

## 实现难度

低 — 网格系统+路径绘制+碰撞检测，最大技术难点是路径绘制的流畅手势识别和冲突检测
