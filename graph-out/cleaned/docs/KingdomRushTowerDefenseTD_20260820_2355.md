# 王国保卫战（Kingdom Rush Tower Defense TD）

- **类型**: 塔防 / 策略
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: Ironhide S.A.
- **首次发布**: 2012
- **一句话描述**: 经典塔防游戏的标杆之作，玩家通过建造和升级防御塔来抵御敌人进攻。

## 玩法规则

游戏采用固定路径的关卡设计，地图上有清晰的敌人行进路线（从小路入口到城堡出口）。玩家可以在路边指定位置建造四种基础防御塔：箭塔（快速射击，对单体伤害）、炮塔（范围溅射伤害）、兵营（产出士兵阻挡敌人）、法师塔（减速+魔法伤害）。

每波敌人从固定入口出现，沿预设路径前进。不同敌人有不同属性：普通步兵（低血低防）、重装骑士（高血量）、飞行单位（只受箭塔和法师塔攻击）、Boss（超高血量+特殊技能）。

玩家通过击杀敌人获取金币，金币用于建造新塔、升级已有塔（每塔最多3级）、释放英雄技能。每关有固定波数敌人，最后一波通常是Boss战。如果敌人到达路径终点并扣除城堡生命值至零，则关卡失败。

每关还有额外目标：完成特定挑战（如无兵营通关、英雄不死通关）可获得星星奖励。

## 核心循环

观察敌人配置 → 建造/升级防御塔 → 击杀敌人获金币 → 强化防线应对更强波次

## 核心机制

- **四塔互补系统**: 四种塔各有所长（单体/范围/阻挡/减速），面对不同敌人组合需要灵活搭配，形成策略深度。没有万能塔，必须根据关卡动态调整
- **英雄即时操作**: 英雄单位可自由拖动到战场任意位置，玩家手动控制英雄拦截漏掉的敌人，增加实时操作感和策略灵活性
- **波次递进设计**: 每关敌人按波次逐步增强，从简单步兵到混合编队再到Boss，难度曲线平滑上升，给玩家学习→适应→精通的体验

## 为什么好玩

塔防类型中最平衡的设计之一：既有策略规划的深度，又有实时操作的手感。四塔系统简单易懂但组合无穷，英雄系统增加临场感。关卡设计精巧，每关都有独特挑战。

## 粘性来源

三星通关的收集驱动（每关有多个挑战目标）；新塔解锁带来的成长感；每关独特地形和敌人配置维持新鲜感；差一点就能三星的不甘心促使反复尝试。

- **成就系统**: 每关有多个隐藏成就（如"用箭塔击杀100个敌人"、"英雄单杀Boss"），收集成就提供长期目标
- **难度递进与特殊模式**: 通关后解锁"英雄模式"（敌人更强但奖励更多），为熟练玩家提供挑战空间

## Meta 系统

- **英雄升级与塔科技**: 通关获得英雄经验值升级技能，收集金币解锁特殊塔
- **对核心玩法的影响**: 英雄技能影响操作上限，特殊塔提供额外策略选项

## 实现难度

中 — 塔防逻辑成熟但需要精细的波次平衡和AI路径优化，最大技术难点是多敌人AI的实时计算和塔攻击优先级的策略性设计
