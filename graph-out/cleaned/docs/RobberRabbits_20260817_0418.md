# Robber Rabbits（Robber Rabbits）

- **类型**: 策略 / 潜行冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立游戏开发者
- **首次发布**: 约2012
- **一句话描述**: 一款以兔子为主角的潜行策略游戏，玩家指挥兔子团队潜入各种场所完成任务

## 玩法规则

游戏画面采用2D横版或俯视视角，展示需要潜入的场所（农场、仓库、实验室等）。场景中散布着巡逻的守卫（可能是农民、保安或其他动物角色）、监控摄像头和各种陷阱。玩家控制一支兔子小队，每只兔子有不同的特殊技能。

操作方式以点击和拖拽为主。玩家点击选择一只兔子，然后点击目标位置让它移动到该位置。在某些情况下，需要长按让兔子执行特殊动作（挖掘地道、跳跃、伪装等）。

每只兔子有独特的能力：挖掘兔可以挖地道通过墙壁；跳跃兔可以跳过障碍到达高处；伪装兔可以伪装成场景中的物品躲避守卫；力量兔可以搬动重物打开新的通道。玩家需要根据关卡特点选择合适的兔子组合。

潜行机制是游戏的核心。守卫有视野范围（通常用锥形区域表示），进入视野范围会被发现。玩家需要利用掩体（箱子、草丛、墙壁）来隐藏兔子，等待守卫转身或离开的时机再行动。某些关卡中，守卫有固定的巡逻路线，观察路线规律是成功潜入的关键。

任务目标多样化：偷取特定物品、解救被关押的同伴、在场景中放置炸药后安全撤离、或收集散落的胡萝卜。每个任务有多个完成方式，鼓励玩家探索不同的策略。

警报系统：如果兔子被发现，会触发警报。守卫进入警戒状态，巡逻范围扩大，部分通道被封锁。玩家需要在警报触发后尽快完成任务或撤退。某些关卡允许在触发警报的情况下强制完成任务，但评分会降低。

评分基于潜行完美度（是否被发现）、任务完成时间和收集品数量。完美潜行（全程不被发现）获得最高评价。

游戏结束条件：所有兔子被抓住或消灭则任务失败；超过时间限制也视为失败。任务失败后可以从最近的检查点重新开始。

## 核心循环

完成关卡或任务 → 获得评分和奖励 → 解锁新关卡、新角色或新道具 → 挑战更高难度的内容

## 核心机制

- **渐进难度设计**：关卡难度从简单到复杂逐步递增，每个新关卡引入1-2个新机制或变化，确保玩家在适应当前难度的同时学习新玩法。
- **即时反馈系统**：每次操作后系统立即给出视觉和音效反馈，强化操作的成就感和爽快感。
- **资源约束机制**：玩家的操作次数、时间或生命值有限，需要在约束条件下做出最优决策，增加了策略深度。
- **评价与重玩驱动**：1-3星评级系统鼓励玩家在通关后反复挑战以获得更高评价。

## 为什么好玩

这款游戏通过简洁直观的操作方式和逐步提升的难度曲线，让玩家在每次尝试中都能获得明确的进步感。关卡设计的多样性确保了长时间游玩不会感到重复乏味，而即时反馈系统则让每次操作都充满满足感。

## 粘性来源

具体到机制层面：1) 1-3星评分系统激发"再试一次拿到三星"的心理驱动力——玩家往往在2星时感到"差一点就完美"，这种不甘心是推动重复游玩的核心力量；2) 关卡逐步解锁的设计制造了持续的目标感和期待感；3) 收集元素（特殊道具、角色解锁、成就系统）提供了额外的长期目标。

## Meta 系统
