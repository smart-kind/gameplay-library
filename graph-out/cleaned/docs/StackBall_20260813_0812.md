# Stack Ball

- **类型**: 休闲/物理弹球
- **平台**: Mobile (iOS+Android)
- **开发商**: Azur Interactive Games Limited
- **首次发布**: 2019
- **一句话描述**: 4.79亿下载，弹球穿透螺旋塔平台的物理弹球游戏，与Helix Jump同源但机制不同

## 玩法规则

玩家控制一个弹球从螺旋塔顶垂直下落，螺旋塔由多层彩色平台环绕组成。
每层平台分为"可穿透"（深色）和"不可穿透"（浅色）两部分。
弹球下落时，如果落到可穿透区域，弹球会连续穿过该层及下方所有同色可穿透区域，直达下一个不可穿透区域。
玩家通过左右滑动旋转螺旋塔，控制弹球落点的横向位置。
弹球落到不可穿透区域时会弹起，需要重新调整方向继续下落。
游戏目标是让弹球尽可能快地到达塔底，部分关卡有层数目标。

## 核心循环

旋转螺旋塔引导弹球穿过可穿透区域 -> 连续穿透多层获得加速 -> 到达塔底完成关卡

## 核心机制

- **穿透加速**：弹球落入可穿透区域后自动加速穿过连续同色区域，带来强烈的视觉和速度反馈，穿透层数越多成就感越强
- **旋转引导**：玩家通过旋转控制弹球的横向落点，需要在弹球下落前预判并提前旋转到位
- **颜色分层**：可穿透/不可穿透区域以颜色区分，直观易懂，降低学习成本
- **弹起机制**：落到不可穿透区域时弹球弹起，给予玩家重新调整的机会，而非直接失败

## 为什么好玩

穿透连续多层时的速度感和视觉冲击力极强，给玩家带来"连击"般的爽快感。相比Helix Jump的逐层通过，Stack Ball的穿透机制让玩家一次可以穿过多个平台，节奏更快更刺激。弹起机制降低了失败惩罚，鼓励继续尝试。

## 粘性来源

穿透机制带来的"连击感"是核心粘性来源。玩家总是想要看到弹球能穿透多少层，而随机分布的穿透区域让每次尝试都充满不确定性。弹起机制让玩家在失败边缘获得重新开始的机会，减少挫败感。

## Meta 系统

关卡推进系统，每关的螺旋塔层数和穿透区域分布不同，提供渐进的难度曲线。部分关卡有特殊主题和视觉风格，提供新鲜感。

## 实现难度

低。与Helix Jump类似，核心玩法简单，技术难点在于3D渲染和物理碰撞。穿透机制的实现需要处理多层连续穿透的物理效果，但整体技术栈简单。
