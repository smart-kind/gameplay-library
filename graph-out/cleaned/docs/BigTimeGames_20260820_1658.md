# Big Time Games

- **类型**: 休闲合集（多品类迷你游戏集合）
- **平台**: Mobile (iOS+Android)
- **开发商**: WINR Games Inc.
- **首次发布**: 2014
- **一句话描述**: 一款包含15种不同休闲小游戏的合集应用，涵盖益智、跳跃、街机等多种玩法。

## 玩法规则

Big Time Games 是一个休闲游戏合集平台，内置15款独立小游戏。玩家打开应用后，主界面展示所有可用游戏的图标列表，每个图标代表一款独立游戏。点击任意游戏图标即可进入该游戏的独立关卡界面。

每款小游戏拥有各自独特的操作方式和规则。例如：益智类游戏通过点击、拖拽来完成目标；跳跃类游戏通过点击屏幕控制角色跳跃时机；街机类游戏需要快速反应操作。大多数小游戏使用单指触摸操作（点击、长按、滑动），界面简洁，没有复杂的多层菜单。

每款游戏通常有多达数十个关卡，难度逐步递增。玩家完成关卡后获得星星评分（1-3星），取决于通关速度或得分。

## 核心循环

选择游戏 → 游玩关卡获得评分 → 解锁更多游戏和关卡

## 核心机制

- **合集入口机制**：将所有小游戏集中在一个应用内，通过统一的UI门户入口，降低玩家的尝试成本——不喜欢当前游戏可立即切换，无需下载新应用。
- **评分驱动递进**：每关的1-3星评价系统鼓励玩家重复挑战以获得完美通关，增加游戏时长。
- **轻度操作统一性**：大多数小游戏采用单指触控（点击/长按/滑动），操作门槛极低，适合碎片化时间游玩。

## 为什么好玩

合集类应用的最大价值在于"选择权"——玩家随时可以切换玩法，避免了单一游戏可能带来的厌倦感。15款不同品类的游戏确保总有适合当前心情的一款，特别适合"不知道玩什么"的碎片化场景。

## 粘性来源

选择多样性是核心粘性——当玩家对某款游戏感到无聊时，立刻切换到另一款继续玩，形成"换个口味继续玩"的循环。1-3星评分系统鼓励重复挑战，追求完美通关的不甘心驱动继续尝试。

## Meta 系统

无。纯游戏合集，无角色成长或外围系统。

## 实现难度

低。核心是构建一个统一的应用框架，将多款独立小游戏集成到同一入口，每款小游戏本身规模较小（通常2-5个关卡即可完成基础版）。最大技术难点在于统一的UI框架设计和各小游戏之间的平滑切换体验。
