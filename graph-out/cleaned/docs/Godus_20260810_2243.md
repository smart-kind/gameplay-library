# 上帝视角的沙盒模拟游戏（Godus）

- **类型**: 模拟/策略
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: 22Cans
- **首次发布**: 2014
- **一句话描述**: 上帝视角的沙盒模拟游戏

## 玩法规则

玩家扮演上帝，通过改变地形（升起土地、降低水位等）来引导小人们生存和发展。小人会自动建造房屋、采集资源、繁衍后代。玩家可以使用神力帮助或惩罚小人。

## 核心循环

改变地形 → 引导小人 → 小人发展 → 解锁新神力 → 更大影响

## 核心机制

- 地形改造：升起/降低土地改变环境
- 小人引导：通过环境引导小人行为
- 神力系统：使用各种神力影响世界
- 文明发展：小人自动建造和发展

## 为什么好玩

扮演上帝的满足感，看着小人在你创造的世界中发展。

## 粘性来源

文明发展进度；神力解锁。

## Meta 系统

神力解锁+文明发展。

## 实现难度

中。地形改造和引导需要理解。最大技术难点：地形渲染和小人AI。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
