# Tile Scenery: Match Puzzle

- **类型**: 益智解谜 / 三消
- **平台**: Mobile (iOS+Android)
- **开发商**: 文婷 刘
- **首次发布**: 2024
- **一句话描述**: 在美丽风景背景中通过消除相同瓷砖来清理棋盘的经典三消益智游戏

## 玩法规则

Tile Scenery: Match Puzzle 是一款以风景画面为背景的三消益智游戏。

玩家需要在棋盘上通过滑动交换相邻瓷砖的位置，使三个或更多相同类型的瓷砖连成一线来消除它们。

每次消除会从上方掉落新的瓷砖补充棋盘，可能触发连锁消除。

游戏界面布局清晰：棋盘占据屏幕中央主要区域，顶部显示当前关卡目标，底部显示剩余步数或时间限制。

玩家通过手指滑动来交换两个相邻瓷砖的位置，如果交换后形成三个或更多同色瓷砖连线，则这些瓷砖被消除并计分。

每个关卡有独特的胜利条件：有的要求消除特定颜色的瓷砖达到一定数量，有的要求在限定步数内收集散布在棋盘上的特殊物品。

棋盘上还会出现各种障碍物，如锁住的瓷砖、冰块覆盖的瓷砖、需要多次消除的石头等，增加了策略深度。

## 核心循环

滑动交换瓷砖 → 消除获得分数 → 完成关卡目标 → 解锁新风景关卡

## 核心机制

- **三消匹配**：核心消除机制，三个或更多同色瓷砖连成一线即可消除，四个或五个可产生特殊效果瓷砖
- **特殊瓷砖**：四个连消产生行列清除瓷砖，五个连消产生万能消除球，特殊瓷砖组合可产生大范围清除效果
- **障碍系统**：冰块、锁链、石头等障碍需要多次消除才能清除，限制玩家可操作区域

## 为什么好玩

精美的风景背景画面为消除过程增添了视觉享受，每通过一个关卡就解锁新的风景图。

渐进式难度曲线让新手能快速上手，后期复杂的障碍组合又提供了足够的策略挑战。

## 粘性来源

主要来自关卡解锁的收集欲和风景图鉴的满足感。每日挑战活动提供额外奖励和限时目标。

特殊瓷砖的连锁消除效果带来的爽快感也构成了核心吸引力。

## Meta 系统

有基础的外围系统：通过完成关卡收集星星，用于解锁新章节和风景主题。对核心玩法没有直接影响。
