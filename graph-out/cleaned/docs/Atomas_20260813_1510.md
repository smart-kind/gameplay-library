# Atomas（原子消除）（Atomas）

- **类型**: 益智 / 合成消除
- **平台**: Mobile (iOS+Android)
- **开发商**: Max Gittel
- **首次发布**: 2015
- **一句话描述**: 一款以原子合成为主题的消除益智游戏，玩家通过放置元素使相邻同种原子融合得分，追求高分和连锁反应。

## 玩法规则

游戏画面中心是一个圆形轨道即环形区域，轨道上分布着不同种类的原子，用元素符号或不同颜色区分如H氢、C碳、O氧、Fe铁等。不同原子有不同的基础分值。

玩家每回合获得一个可放置的原子或特殊道具，点击轨道上的空位将其放入环形轨道。放置后如果两侧有相同的原子，它们会向中间融合成一个更重的原子并获得分数。

例如两个H氢原子融合成He氦，两个O氧原子融合成F氟。融合链可以继续触发，更重的原子相邻时会进一步融合，形成连锁反应。每次融合都获得分数并可能腾出新的空位。

特殊道具包括加号道具可融合任意相邻两个原子为更重元素，闪电道具可清除一整段原子，对称道具可在轨道对面镜像放置原子。这些道具是打破僵局和创造高分的关键。

## 核心循环

获得原子或道具 → 选择最佳放置位置 → 触发融合链式反应 → 获得高分并腾出空间 → 轨道出现新原子 → 继续循环

## 核心机制

- **机制1**：融合链式反应机制：放置一个原子可能触发一连串的融合反应，每个融合都会得分并腾出空间。一条长链可以一次性获得大量分数，这种连锁爆炸的爽快感是游戏的核心体验。玩家会为了制造更长的融合链而精心布局。
- **机制2**：空间管理谜题机制：环形轨道空间有限，每次放置都影响后续布局。玩家需要在快速融合腾出空间和等待更优融合机会之间权衡。放得太快可能浪费机会，等得太久可能轨道被填满。
- **机制3**：特殊道具机制：游戏中会随机出现特殊道具，加号可融合任意相邻原子，闪电可清除一行，对称道具可镜像放置。合理使用可以扭转局面或创造超长融合链，是高手与普通玩家的分水岭。

## 为什么好玩

看着自己精心布局的原子触发超长融合链，分数飞涨的瞬间极其爽快。它把化学元素周期表变成了一种优雅的益智体验，既有科学感又有游戏性。

## 粘性来源

融合链式反应的视觉数值爽感加上空间管理的持续挑战加上每局不同的高分追求，让玩家不断尝试新的放置策略来突破个人最高分。

## Meta 系统

高分排行榜加成就系统，有每日挑战模式用特定条件限制来获取额外奖励和成就徽章。部分版本有赛季排行榜竞争。

## 实现难度

低 -- 环形数组加融合规则，算法实现简洁明了。最大难点是视觉反馈设计让融合链有冲击感，以及合理的原子出现概率分布。

## 元素融合表（简化版）

H(氢)→He(氦)→Li(锂)→Be(铍)→B(硼)→C(碳)→N(氮)→O(氧)→F(氟)→Ne(氖)→...→Fe(铁)→Au(金)

融合链越长，单次得分越高。一条10连融合可以获得数千分，是冲击高分的关键。

## 高分策略提示

- 优先在轨道上维持对称布局，利用对称道具实现双倍融合
- 保留加号道具到关键时刻使用，可以融合任意相邻原子
- 不要急着融合，有时等待更好的道具出现更划算
- 注意轨道容量，预留至少2-3个空位作为操作空间
