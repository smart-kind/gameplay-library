# 怪物来袭！塔防（The Creeps! Tower Defense）

- **类型**: 塔防 / 策略
- **平台**: Mobile (iOS)
- **开发商**: Backflip Studios
- **首次发布**: 2009
- **一句话描述**: 经典2D塔防游戏——你的衣橱里爬出了怪物，用玩具武器筑起防线，保护你的家

## 玩法规则

游戏采用俯视2D视角，画面风格卡通可爱。怪物（Creeps）从地图上的"衣橱"入口出现，沿着蜿蜒的路径向目标前进。玩家在路径两侧放置防御塔，每座塔自动攻击进入射程的怪物。

塔的种类丰富：普通机枪塔、冰冻减速塔、范围爆炸塔、激光穿透塔等。每座塔可以升级2-3次，每次升级提升伤害、射速或范围。升级需要消耗游戏中获得的游戏货币。

怪物种类也很多样：普通小怪、快速移动的轻甲怪、高血量的重装怪、会分身的分裂怪等。不同怪物需要不同类型的塔来应对。游戏的目标是在所有怪物到达目标前消灭它们，每漏掉一个怪物就扣除一条命，命数归零则游戏失败。

## 核心循环

放置防御塔 → 怪物按波次进攻 → 获得消灭奖励 → 升级或新增塔 → 抵御更强的下一波 → 完成关卡

## 核心机制

- **路径防御机制**：怪物沿固定路径移动，玩家在路径两侧选择最优位置放置防御塔
- **塔的类型克制**：不同塔对不同怪物有优势（如对空、减速、群伤、穿透）
- **升级系统**：每座塔独立升级，合理分配升级资源是策略关键
- **波次递进**：每波怪物组合不同，需要玩家动态调整策略
- **玩具主题**：所有塔都是"玩具武器"，增加了趣味性和独特的美术风格

## 为什么好玩

玩具主题让塔防这个成熟品类有了新鲜感。怪物从"衣橱"爬出的设定既可爱又有代入感。塔的升级和布局让玩家感受到策略规划的乐趣。

## 粘性来源

**策略多样性**：每个关卡都有不同的路径和怪物组合，需要不同的防御布局。**升级成就感**：把一座低级塔逐步升级到满级的过程很满足。**收集欲**：解锁所有类型的塔和完成所有关卡是自然的目标。

## Meta 系统

外围成长系统：
- **关卡解锁**：完成一个区域后解锁下一个区域的新关卡
- **塔解锁**：随着进度解锁新的塔类型
- 对核心玩法的影响：新塔类型丰富了策略选择，但不改变核心塔防逻辑

## 实现难度

低。经典塔防的实现方案很成熟，2D俯视角的碰撞检测和弹道计算都不复杂。最大难点在于关卡设计——需要让每条路径都有独特的策略挑战，避免重复感。
