# 杜卡迪摩托（Ducati Moto）

- **类型**: 竞速
- **平台**: Mobile (iOS+Android)
- **开发商**: RAC1 Games
- **首次发布**: 2009
- **一句话描述**: 以杜卡迪摩托车为主题的街机竞速游戏，强调高速行驶和弯道操控。

## 玩法规则

游戏采用第三人称追尾视角，玩家驾驶杜卡迪摩托车在赛道上与其他选手竞速。屏幕显示速度表、当前位置（第几名）和赛道小地图。
操控方式：倾斜设备或使用虚拟按键控制摩托车的左右转向，点击加速按钮提高速度，点击刹车按钮减速。
赛道设计包括直道、弯道、起伏路段和障碍物。在弯道上需要适时减速并倾斜车身，否则容易冲出赛道。直道上可以全速前进。
比赛中会获得氮气加速道具（从赛道上收集或超越对手时获得），使用后可以短时间大幅提升速度。
赛道两旁有观众和景物，撞到障碍物会减速。游戏有多个赛道和不同难度级别，以及计时赛和锦标赛模式。
比赛排名基于到达终点的先后顺序。完成比赛后获得积分，积分用于解锁新赛道和新摩托车。

## 核心循环

选择赛道和难度 → 比赛竞速（加速/转弯/使用氮气） → 冲线获得排名和积分 → 解锁新内容继续挑战

## 核心机制

- 速度感营造：通过镜头拉远、速度线效果和引擎音效，在移动端尽可能还原高速行驶的刺激感
- 弯道操控系统：需要判断弯道角度提前减速，入弯时机和倾斜角度决定了过弯效率。完美过弯会获得加速奖励
- 氮气加速：收集氮气或在特定条件下（完美过弯、连续超越）获得加速，是逆转排名的关键

## 为什么好玩

高速行驶时紧贴弯道内侧超车的那种紧张刺激感，以及氮气加速冲过终点线反超第一名的逆转快感。
摩托车的操控感比汽车更灵敏，操作反馈更直接。杜卡迪品牌带来的真实感也增加了代入感。

## 粘性来源

'差0.1秒就能刷新纪录'的时间挑战、解锁新车/赛道的目标感、以及排行榜上的名次竞争。

## Meta 系统

解锁新杜卡迪摩托车型号、新赛道、涂装自定义。锦标赛积分系统。

## 实现难度

中 — 需要实现3D赛道渲染、车辆物理模拟、AI对手路径规划。主要技术难点在于移动端的操控精度和性能优化，以及物理手感调优。

游戏还包含计时赛模式：单独挑战一条赛道，不断刷新个人最佳纪录。某些赛道有隐藏的近道，需要在特定位置做出危险跳跃才能进入。游戏的物理引擎模拟了摩托车的真实惯性，转弯时需要提前减速。
