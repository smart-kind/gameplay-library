# Apparatus（Apparatus）

- **类型**: 物理益智 / 沙盒 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Bithouse
- **首次发布**: 2011
- **一句话描述**: 利用物理零件（木板、绳索、磁铁等）搭建装置，引导小球到达目标

## 玩法规则

游戏画面呈现一个物理沙盒场景，画面中有固定的起点（小球出发点）和终点（目标位置）。玩家需要在场景中放置各种物理零件来构建一条从起点到终点的路径。

工具栏提供多种零件：木板（支撑面）、绳索（悬挂）、磁铁（吸引/排斥金属球）、风扇（吹风）、弹簧（弹射）等。玩家拖拽零件到场景中，可以旋转和调整大小。

放置好零件后，点击"播放"按钮启动物理模拟。小球从起点出发，受重力和玩家搭建的装置影响，沿路径移动。如果小球到达终点则过关。

游戏目标是找到最简洁有效的装置方案。某些关卡有零件数量限制或步数限制，要求玩家用最少的零件完成任务。

## 核心循环

分析关卡 → 搭建装置 → 启动模拟 → 观察结果 → 调整改进 → 过关

## 核心机制

- **物理模拟**: 真实的重力、碰撞、摩擦力模拟，让玩家搭建的装置按真实物理规律运作
- **零件系统**: 多种零件各有功能——木板提供支撑，绳索实现悬挂，磁铁引导金属物体，风扇产生推力
- **自由搭建**: 没有唯一正确答案，玩家可以发挥创造力设计不同的解决方案
- **测试迭代**: 每次模拟后观察失败原因，调整零件位置或类型，直到找到可行方案
- **零件限制**: 高级关卡限制可用零件数量，增加策略性

## 为什么好玩

物理沙盒的自由度让玩家像工程师一样思考和创造。每次模拟的不可预测性（小球可能走意想不到的路径）带来了实验的乐趣。找到最优解时的成就感极强——因为解决方案是自己想出来的。

## 粘性来源

创造力和实验精神是核心粘性。每个关卡都是一个物理谜题，玩家享受"试错—发现—优化"的过程。看到自己设计的装置成功运作时的满足感驱动玩家不断挑战新关卡。

## Meta 系统

关卡解锁系统：完成当前关卡解锁下一关。某些版本包含玩家自制关卡分享功能，可以下载和游玩其他玩家设计的关卡。

## 实现难度

高。需要完整的 2D 物理引擎（碰撞检测、重力、摩擦力、关节连接）。最大的技术难点是物理模拟的稳定性和性能——大量零件同时作用时可能出现计算溢出或不稳定。
