# 世界征服者1945（World Conqueror 1945）

- **类型**: 策略 / 战争
- **平台**: Nintendo 3DS / Mobile
- **开发商**: EasyTech
- **首次发布**: 2011
- **一句话描述**: 以二战为背景的回合制战略游戏，在网格地图上指挥军队攻城略地

## 玩法规则

游戏采用六角格或方格地图，玩家扮演军事指挥官，在每个回合中移动各种军事单位（步兵、坦克、炮兵、飞机、军舰）到战略位置并进行攻击。每个单位有移动力、攻击力、防御力、射程等属性，地形对战斗结果有显著影响（山地增加防御力、平原利于坦克机动、河流阻碍移动但增加渡河后的防御加成）。

玩家需要占领敌方城市和资源点来获得资金，用于生产新单位。游戏包含多个历史战役（诺曼底登陆、斯大林格勒战役、中途岛海战等）和虚构的全球征服模式。在战役模式中，目标是完成特定的历史任务（如守住某座城市X回合、在Y回合内攻占某地）；在征服模式中，目标是在全球地图上消灭所有敌对势力。

单位之间有明显的克制关系和协同效应：步兵占据城市获得防御加成且成本低，坦克快速机动但需要补给线，炮兵远程打击但近战脆弱，飞机无视地形但需要机场，军舰控制海域和支援海岸攻击。玩家需要根据地图特点和敌军配置来组合兵种。补给系统也很重要——远离补给线的单位会逐渐削弱战斗力。

## 核心循环

选择战役 → 每回合移动单位并攻击 → 占领城市获取资源 → 生产新单位 → 完成战役目标

## 核心机制

- **兵种克制与协同系统**：步兵(低成本/占城/防守)、坦克(机动/突击/高攻)、炮兵(远程/AOE)、飞机(无视地形/高机动)、军舰(海域控制/海岸支援)。合理搭配兵种组合是取胜关键，单一兵种容易被克制
- **地形与补给系统**：不同地形对攻防有不同影响：山地+30%防御、森林+20%隐蔽、河流-50%移动但+25%渡河后防御。补给线决定单位战斗力，深入敌后但断补给的单位会逐渐衰弱
- **经济与生产系统**：占领城市获得资金和资源，用于在己方城市生产新单位。资源点(石油、铁矿、粮食)提供持续收入，争夺资源点是战略核心

## 为什么好玩

回合制策略的经典体验，每一步决策都有意义。历史战役的重现让玩家在虚拟世界中改写二战结局——如果德军攻下莫斯科、如果盟军提前开辟第二战场，这种'what if'的想象空间很吸引人。

## 粘性来源

战役解锁+征服模式的长期目标驱动反复游玩。不同难度级别和AI对手提供挑战梯度。收集历史名将（拥有特殊技能的将军）是长期追求。

## Meta 系统

将军系统——招募和培养拥有特殊技能（如装甲突击、炮火支援、战术防御、后勤管理）的将军，部署到部队上大幅提升战斗力。将军通过战斗获得经验升级，解锁更强技能。对核心玩法有显著影响。

## 实现难度

中高 —— 回合制策略需要规划多步、管理多兵种和多条战线，最大技术难点是AI设计和数值平衡，确保不同难度下有合理的挑战性。
