# Partybus Party Games

- **类型**: 派对迷你游戏合集
- **平台**: Mobile (iOS+Android)
- **开发商**: Panja
- **首次发布**: 2021
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

选择小游戏 -> 多人轮流参与 -> 获得积分 -> 最终排名

## 核心机制

- **多人派对模式**: 支持多人同时游玩，每个玩家轮流参与不同的小游戏。游戏适合朋友聚会或家庭娱乐场景。
- **迷你游戏合集**: 包含多种不同类型的迷你游戏，如反应力测试、记忆力挑战、趣味问答等。多样化的游戏类型确保不会单调。
- **积分排名系统**: 每轮游戏根据表现获得积分，最终按总分排名。竞争性的排名增加了重玩价值。

## 为什么好玩

多种迷你游戏的组合确保总有新鲜感。社交互动是最大的乐趣来源，和朋友一起玩的体验远超独自游玩。

## 粘性来源

粘性来源于社交互动和多样化的小游戏。每次聚会都可以玩不同的游戏组合。

## Meta 系统

- 积分排名系统：累计得分决定最终排名
- 对核心玩法的影响：竞争性的排名驱动重复游玩

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
