# Rogue with the Dead: Idle RPG

- **类型**: 放置
- **平台**: Mobile (iOS+Android)
- **开发商**: room6 LLC.
- **首次发布**: 2022
- **一句话描述**: 一款放置类移动游戏，由room6 LLC.开发

## 玩法规则

玩家在手机上通过点击、拖拽或滑动进行操作。游戏界面展示游戏核心元素，如棋盘、角色或叙事场景。

每个回合/操作中，玩家根据当前局势做出决策。操作产生即时反馈——消除方块、获得资源、推进剧情或击败敌人。

游戏目标因模式而异：在解谜模式中清空棋盘或达成特定条件；在放置模式中最大化资源产出和升级进度；在射击模式中消灭所有敌人并完成关卡。

游戏通过关卡递进、难度曲线或叙事章节推进。失败条件包括棋盘空间耗尽、生命值归零或做出错误的推理选择。

## 核心循环

放置核心循环：执行操作 → 获得资源/推进 → 升级/解锁 → 挑战更高难度

## 核心机制

- **放置点击 (Idle/Clicker)**: 通过点击或自动累积资源，购买升级提升产出效率。离线时持续获得收益，重玩时获得永久加成。
- **多人对战 (Multiplayer PvP)**: 玩家实时对抗，在同一场景中进行操作竞争。速度快、策略性强。
- **Roguelike肉鸽**: 每局随机生成关卡和敌人，死亡后保留部分永久升级。每次重玩有不同路线。
- **叙事互动 (Narrative)**: 通过对话选择和剧情推进来体验故事，玩家选择影响故事走向和结局。
