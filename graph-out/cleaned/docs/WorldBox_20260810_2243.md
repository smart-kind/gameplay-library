# 上帝视角的世界模拟沙盒游戏（WorldBox）

- **类型**: 模拟/沙盒
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Maxim Karpenko
- **首次发布**: 2018
- **一句话描述**: 上帝视角的世界模拟沙盒游戏

## 玩法规则

玩家在一个像素世界中放置各种元素（土地、水、生物、灾害等），观察文明的发展。可以放置人类、精灵、矮人、兽人等种族，他们会自动建立王国、发动战争、发展技术。玩家可以使用各种灾害（龙卷风、陨石、瘟疫等）影响世界。

## 核心循环

放置元素 → 文明发展 → 观察/干预 → 使用灾害 → 新世界

## 核心机制

- 世界创造：放置各种自然元素
- 种族系统：不同种族有独特行为
- 文明发展：自动建立王国、战争、技术
- 灾害系统：使用各种灾害影响世界

## 为什么好玩

创造世界并观察文明发展的满足感。各种灾害的破坏快感。

## 粘性来源

世界创造；文明观察；灾害实验。

## Meta 系统

种族解锁+灾害解锁。

## 实现难度

低。沙盒放置，操作简单。最大技术难点：多文明AI模拟。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
