# AR Defender 2

- **类型**: 塔防 / AR增强现实
- **平台**: iOS
- **开发商**: SkyVu Inc.
- **首次发布**: 2011
- **一句话描述**: 利用手机摄像头在现实环境中放置防御塔的AR塔防游戏

## 玩法规则

游戏利用iOS设备的摄像头功能，将塔防玩法与增强现实技术结合。玩家通过手机屏幕看到真实环境，然后在其中放置防御塔来抵御敌人入侵。

游戏界面通过摄像头实时显示玩家周围的真实场景。玩家需要移动手机来选择防御塔的放置位置，点击屏幕确认放置。每种防御塔有独特的攻击方式和射程范围。

敌人在游戏生成的虚拟路径上移动，路径会叠加在真实环境画面上。玩家需要根据敌人类型和路径调整防御塔的布局和升级。

游戏目标是阻止所有敌人通过关卡。如果敌人突破防线到达终点，玩家损失生命值。生命值耗尽则游戏结束。

## 核心循环

扫描环境 → 放置防御塔 → 观察敌人进攻 → 升级/调整防御 → 进入下一波

## 核心机制

- **AR定位系统**：利用设备摄像头和运动传感器在真实环境中定位虚拟元素，创造独特的沉浸感
- **塔防升级**：防御塔可通过消耗资源升级攻击力和射程，形成成长系统
- **波次设计**：每波敌人有不同的数量和类型，需要针对性的防御策略
- **环境融合**：防御塔位置与真实环境中的表面和物体位置相关联，增加策略深度

## 为什么好玩

AR技术让塔防游戏从俯视平面变成了"真实空间中的战斗"。看到虚拟敌人在自家客厅里行进的体验非常独特，同时保留了塔防游戏的核心策略乐趣。

## 粘性来源

AR新颖感 + 塔防策略深度 + 波次递进的成就感 + 收集不同防御塔的满足感

## Meta 系统

防御塔解锁系统 — 通过完成关卡获得新防御塔类型，增加战术多样性

## 实现难度

高 — 需要稳定的AR定位追踪技术，最大技术难点在于不同光照和环境条件下的定位精度，以及虚拟与现实元素的自然融合
