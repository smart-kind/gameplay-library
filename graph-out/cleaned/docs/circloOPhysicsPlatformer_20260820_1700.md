# circloO - Physics Platformer（circloO）

- **类型**: 物理平台跳跃 / 解谜 / 休闲
- **平台**: Mobile (iOS) / Web
- **开发商**: Florian van Strien
- **首次发布**: 2022
- **一句话描述**: 在一个不断扩大的圆形关卡中滚动收集圆圈的物理平台跳跃游戏，曾获Crazy Games开发者大赛冠军。

## 玩法规则

游戏画面是一个圆形区域，玩家控制一个小球在圆形关卡内滚动。关卡内部包含各种平台、障碍物和收集物（圆圈）。玩家只能左右移动小球——通过左右移动积累速度和角度来跳跃。

核心操作：按屏幕左侧向左滚动，按右侧向右滚动。小球受重力影响，站在平台上时不会掉落。当小球碰到关卡中的圆圈收集物时，整个圆形关卡会"长大"一圈——关卡边界向外扩展，原有的所有物体保持原位。

随着关卡扩大，原本有用的平台可能变成障碍，原本简单的路线变得复杂。例如，一个原本帮助你跳高的平台，在关卡扩大后可能变得遥不可及，或者挡住了你的路线。玩家需要不断适应变化中的关卡结构，利用物理特性（重力、弹力、惯性）来收集所有圆圈。

## 核心循环

左右移动收集圆圈 → 关卡边界扩大 → 原有物体相对位置变化 → 适应新结构继续收集 → 完成关卡

## 核心机制

- **动态成长关卡**：每次收集一个圆圈，整个关卡向外扩展。这是游戏最独特的机制——关卡不是静态的，而是随着玩家行动不断变化。原本的路径和策略在关卡扩大后可能完全失效，需要重新规划。
- **双向物理谜题**：关卡中的平台、弹簧、重力反转区域、行星引力场等物理元素构成了丰富的谜题。玩家不仅需要考虑当前位置，还要预判关卡扩大后这些元素的新位置和新作用。
- **无惩罚重试**：玩家不会因为失误而重新开始关卡——即使掉落或卡住，也可以快速重试当前状态。这个设计降低了挫败感，鼓励玩家在困难区域反复尝试。

## 为什么好玩

"关卡在成长"的概念极其新颖——它颠覆了传统平台游戏的静态关卡设计，让每一次收集都带来全新的挑战。物理谜题的深度和75+精心设计的关卡提供了充足的内容。完成困难关卡后的成就感极强。

## 粘性来源

核心是"动态变化"带来的持续新鲜感。每个关卡都是一个独特的物理谜题，关卡扩大机制让传统平台游戏的路径规划变得不可预测。此外，关卡编辑器和10000+玩家自制关卡提供了近乎无限的后续内容，Hard Mode的6个"几乎不可能"的关卡则是终极挑战。

## Meta 系统

关卡编辑器：玩家可以创建和分享自己的关卡。计时系统记录每关完成时间，支持竞速挑战。这些外围功能大大延长了游戏寿命，3-5小时通关主线后仍有海量内容可玩。

## 实现难度

高。核心挑战在于动态关卡边界扩展的物理模拟——当关卡扩大时，所有物体的位置、速度、碰撞都需要重新计算，同时保持物理一致性。重力反转、行星引力等特殊物理效果也需要精确实现。最大技术难点是确保关卡扩展过程中的物理模拟稳定性和性能。
