# 细胞HD（Cell HD）

- **类型**: 益智 / 策略
- **平台**: Nintendo 3DS / Mobile
- **开发商**: 独立开发者
- **首次发布**: 2011
- **一句话描述**: 在微观世界中操控细胞进行吞噬和进化的策略益智游戏

## 玩法规则

玩家控制一个初始细胞在微观环境（培养皿、人体组织、水域等）中游动。通过吞噬比自己小的细胞或食物颗粒来成长壮大，同时需要躲避比自己大的细胞的捕食。游戏采用虚拟摇杆或方向键控制移动方向，细胞会自动吞噬接触到的较小物体。

随着成长，细胞可以解锁特殊能力——加速冲刺（短时间内大幅提升移动速度）、短暂隐身（让附近的大细胞无法发现）、释放毒素（对范围内的较小细胞造成伤害）。关卡目标包括'达到指定体积'、'消灭所有敌对细胞'、'存活指定时间'、'收集特定数量的DNA片段'等。

环境中有多种元素：静态食物颗粒（提供少量成长值）、游动的小细胞（可吞噬但有逃跑行为）、大型捕食者（需要躲避）、特殊道具（临时护盾、加速药剂）。部分关卡还包含环境障碍如水流、电场、有毒区域，需要规划移动路径来规避。

## 核心循环

控制细胞移动 → 吞噬小物体成长 → 躲避大细胞 → 解锁能力 → 完成关卡目标

## 核心机制

- **体型差异生态链系统**：体积决定捕食关系，形成'大鱼吃小鱼'的生态链。但体型越大移动越慢，需要在成长和机动性之间权衡。小型细胞可以逃入狭窄通道躲避追捕
- **能力解锁与战术选择**：成长到特定体积阈值解锁新能力，每种能力改变战术可能性——加速用于追击或逃跑，隐身用于规避危险，毒素用于主动攻击。能力有冷却时间，需要合理使用
- **环境互动与路径规划**：不同环境有不同的食物分布密度、障碍物布局和危险区域，影响移动策略和资源收集效率

## 为什么好玩

简单直观的核心循环带来纯粹的吞噬快感，从小不点到庞然大物的成长过程令人上瘾。微观世界的视觉呈现（半透明细胞质、鞭毛摆动）很有特色，成长后的细胞形态变化也带来视觉满足。

## 粘性来源

成长数值带来的即时正反馈+每次新关卡不同的环境布局。'差一点就能吃掉那个大的'驱动反复尝试。DNA收集系统提供长期目标。

## Meta 系统

细胞进化系统——通过累积DNA解锁新的细胞类型（变形虫、草履虫、白细胞等）和皮肤外观，对核心玩法提供物种特性变化，不同细胞有基础属性差异。

## 实现难度

低 —— 核心操作简单直观（移动+吞噬），最大技术难点是大量细胞实体的实时AI行为计算和碰撞检测优化。
