# Spellwood

- **类型**: 文字解谜 / 冒险
- **平台**: PS Vita / Mobile
- **开发商**: Unknown
- **首次发布**: 2013
- **一句话描述**: 通过拼写单词来施放魔法的文字冒险解谜游戏

## 玩法规则

游戏将文字解谜和奇幻冒险结合。玩家通过拼写单词来施放魔法攻击敌人或解决谜题。

游戏界面显示一个字母网格和当前的魔法咒语需求。玩家需要从网格中选择相邻字母（横向、纵向或对角线）来拼出目标单词。

每关有不同的魔法咒语需要拼写。简单咒语可能是3-4个字母的常见词，复杂咒语需要更长的专业词汇。拼写正确后魔法自动施放，产生对应的效果（攻击、防御、治疗等）。

某些关卡包含限时挑战，需要在时间耗尽前拼出足够多的单词。单词长度和稀有度影响魔法威力。

## 核心循环

查看魔法需求 → 在字母网格中找词 → 拼写施法 → 观察效果 → 挑战下一关

## 核心机制

- **单词拼写**：从字母网格中选择相邻字母拼出单词，考验词汇量和观察力
- **魔法效果**：不同单词对应不同的魔法效果，增加玩法多样性
- **限时挑战**：部分关卡有时间压力，增加紧张感
- **词汇成长**：随着游戏推进，需要拼写的单词越来越复杂

## 为什么好玩

将文字游戏的益智感和魔法冒险的奇幻感结合，让玩家在拼词的同时体验施法的乐趣。每个单词都是一次魔法释放，很有成就感。

## 粘性来源

词汇量挑战的求知欲 + 魔法效果的视觉反馈 + "这个词我会拼"的自信感 + 限时挑战的紧张刺激

## Meta 系统

魔法解锁系统 — 通过完成关卡解锁新的魔法类型和更复杂的咒语

## 实现难度

中 — 需要词典数据和单词验证系统，最大技术难点在于字母网格的趣味性和魔法效果的视觉设计
