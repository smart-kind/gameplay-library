# 忍者刺客 (Ninja Striker!)

- **类型**: 动作/弹射解谜
- **平台**: Mobile (iOS)
- **开发商**: 未明确标注
- **首次发布**: 未明确标注
- **一句话描述**: 一款结合忍者在关卡中弹射移动与切割障碍的复古像素风动作游戏

## 玩法规则

玩家操控一名像素风格忍者，通过点击屏幕进行后空翻式移动，在关卡中前进。忍者的移动方式类似弹球——点击后忍者会翻滚跃起，撞到墙壁或障碍物后会反弹。

关卡中布满了各种敌人（幽灵、蛇、弹跳三角形等），忍者翻滚时会自动切割接触到的敌人。切割敌人会累积连击倍率，连击越高得分越多。

关卡中还分布着带有箭头的圆盘，这些圆盘会把忍者弹射向特定方向，利用它们可以让忍者在关卡中弹来弹去，同时收集金币。随着推进，会遇到发射投射物的敌人，增加躲避难度。

每过三关会遇到一个Boss战（如第一个世界的Boss是一个能投掷龙卷风的老忍者），Boss战难度明显提升，需要掌握躲避时机。

## 核心循环

点击弹射忍者 -> 切割敌人/收集金币 -> 用金币购买装备 -> 挑战更难的关卡和Boss

## 核心机制

- 弹射式移动系统：点击屏幕触发后空翻，忍者像弹球一样在关卡中反弹，利用箭头圆盘改变方向
- 连击切割系统：翻滚时自动切割接触的敌人，连续切割累积倍率，倍率越高得分越多
- 商店装备系统：用收集的金币购买装备（草鞋、编织帽等），部分装备提供通关优势
- Boss战机制：每三关出现一个Boss，拥有独特攻击模式，需要躲避和反击

- 难度递进机制：游戏采用阶段式难度提升，前期教学关卡简单引导操作，中后期引入更复杂的敌人组合和地形障碍，后期关卡需要精确利用箭头圆盘才能通过

## 为什么好玩

复古像素美术风格和音效营造出8位机时代的怀旧感，弹射式移动让每次操作都充满意外性和爽快感。连击切割带来的瞬间反馈非常解压，Boss战的突然难度提升也提供了成就感。

## 粘性来源

连击倍率驱动的爽感反馈是核心粘性——玩家不断想刷新自己的连击记录。加上装备收集和目标感（通关所有世界），以及差一点就过的不甘心感。

## Meta 系统

商店系统包含多种装备可购买，价格从便宜（草鞋）到昂贵不等。也提供1.99英镑的内购可以购买大量金币。装备对通关有帮助但非必需。

## 实现难度

中等 — 核心操控（点击弹射）很简单，但关卡难度曲线不均衡，有些区域极其简单而有些区域难度陡增。最大技术难点是物理弹射的精确判定和箭头圆盘的路径预测。
