# 经典无尽跑酷，逃离神庙被怪物追赶（Temple Run）

- **类型**: 跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: Imangi Studios
- **首次发布**: 2011
- **一句话描述**: 经典无尽跑酷，逃离神庙被怪物追赶

## 玩法规则

玩家角色在神庙遗迹的小路上奔跑，通过左右滑动转向、上滑跳跃、下滑滑行来躲避障碍。

路上有金币和道具（磁铁、隐身、加速）。跑过的距离越远分数越高。角色转弯时有方向选择，选错方向可能撞上障碍。

怪物在后面追赶，摔倒会被怪物追上导致游戏结束。

## 核心循环

自动奔跑 → 转向/跳跃/滑行躲避 → 收集金币 → 摔倒 → 刷新记录

## 核心机制

- 方向选择：转弯时有左右两个方向可选，增加策略性
- 道具系统：磁铁吸金币、隐身（无敌）、加速
- 金币收集：路上散落的金币和特定路线的金币链
- 角色解锁：通过金币和成就解锁不同角色

## 为什么好玩

被怪物追赶的紧张感和极速奔跑的快感结合。简单的操作但需要极高的反应速度。

## 粘性来源

高分驱动；角色解锁；金币收集的满足感；差一点就破纪录的不甘心。

## Meta 系统

角色解锁系统，通过金币和成就购买。

## 实现难度

低。滑动操作简单，但需要极快的反应速度。最大技术难点：3D跑酷的动态地图生成和流畅度。

## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
