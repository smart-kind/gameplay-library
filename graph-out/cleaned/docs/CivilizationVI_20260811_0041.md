# Civilization VI

- **类型**: 回合制策略
- **平台**: Mobile (iOS+Android) / PC / Switch / PlayStation / Xbox
- **开发商**: Firaxis Games / Aspyr (移动端)
- **首次发布**: 2016 (PC) / 2018 (移动端)
- **一句话描述**: 经典的文明系列最新作，从石器时代到信息时代，建立并发展你的文明，通过多种方式取得胜利。

## 玩法规则

玩家在随机生成的地图上选择一个领袖和文明，从一个定居点和一个勇士开始。

游戏以回合制进行，每个回合玩家可以：
- **移动单位** — 侦察兵探索地图、勇士攻击敌人、定居者建立新城
- **建造城市设施** — 农田、矿山、伐木场等资源改善设施
- **建造城市建筑** — 兵营、图书馆、市场等建筑提供不同加成
- **研究科技** — 在科技树中选择下一项研究（从制陶术到核物理）
- **发展文化** — 在文化树中选择政策和政策卡，解锁不同文明加成

胜利条件有五种：
1. **征服胜利** — 消灭所有其他文明
2. **科技胜利** — 完成科技树，发射火星殖民地
3. **文化胜利** — 文化影响力超过所有文明
4. **宗教胜利** — 你的宗教成为世界主流信仰
5. **外交胜利** — 在联合国投票中获得多数支持

每个领袖有独特的能力和单位（如罗斯福的美国有罗斯福推论加成），增加了重玩的差异化。

## 核心循环

探索 -> 扩张 -> 开发 -> 征服/发展 -> 胜利

## 核心机制

- 科技/文化双树系统 — 两条独立的进步路线，科技解锁单位和建筑，文化解锁政策和政体
- 区域系统 — 城市不再只是单个格子，而是可以建造多个区域（学院区、工业区等），增加城市规划深度
- 多胜利路径 — 五种完全不同的胜利方式，允许完全不同的策略

## 为什么好玩

时间黑洞，再一个回合的魔力。看着自己的文明从几个农民发展为全球超级大国，每一步决策都影响深远。与历史名人的对话增加了趣味性。

## 粘性来源

每局都是全新的随机地图；不同文明带来完全不同的体验；DLC 持续增加新文明和新内容；在线多人对战。

## Meta 系统

文明/领袖解锁系统；成就系统；游戏内排名（单人和多人）。移动端版本包含完整游戏内容但需要单独购买 DLC。

## 实现难度

高 — 系统极其庞大（数百个科技、数十种建筑、多文明多领袖），新玩家需要大量时间学习。移动端操作也增加了复杂度。最大技术难点在于在移动端适配如此复杂的游戏界面和操作。
