# Xenowerk

- **类型**: 射击
- **平台**: Mobile (iOS+Android)
- **开发商**: Pixelbite
- **首次发布**: 2015
- **一句话描述**: 俯视角双摇杆射击游戏，在地下科学设施中对抗变异生物，深入探索并完成任务。

## 玩法规则

游戏采用俯视角，玩家操作一名特工进入地下设施。左摇杆控制移动，右摇杆控制射击方向（双摇杆操作）。

画面风格黑暗，玩家的视野受手电筒照明限制，只能看到周围有限的区域，营造出紧张的氛围。

核心操作：
- **移动** — 左摇杆控制角色在地图上移动
- **射击** — 右摇杆瞄准，松开即射击。不同武器有不同射速、伤害和弹道
- **切换武器** — 在关卡中拾取新武器，可以切换使用
- **使用技能** — 冷冻弹（冻结敌人）、治疗包（恢复生命）等辅助能力

游戏目标：在设施中深入，完成特定目标（消灭所有敌人、收集样本、找到出口等），最终撤离。

敌人是各种变异生物，有些会近战攻击，有些会远程攻击，有些会产卵。关卡中还有可收集的物品（武器、弹药、生命恢复、任务物品）。

## 核心循环

进入关卡 -> 消灭敌人/收集物品 -> 深入下一层 -> 完成目标 -> 撤离

## 核心机制

- 手电筒视野限制 — 只能看到周围区域，增加未知感和紧张感
- 武器系统 — 多种武器（手枪、霰弹枪、步枪等），各有优劣，需要根据情况选择
- 任务多样性 — 每关有不同的目标类型，不仅仅是杀光敌人

## 为什么好玩

黑暗氛围加上双摇杆射击的爽快感加上变异生物的设计等于独特的动作体验。每次进入未知的黑暗区域都有紧张感，但消灭怪物后的满足感也很强。

## 粘性来源

多关卡递进；武器收集和升级；最高分挑战；续作（Xenowerk 2）扩展内容。

## Meta 系统

武器解锁和升级系统；关卡评级（时间和效率）；成就系统。

## 实现难度

中 — 双摇杆操作需要适应，但上手后很自然。黑暗环境增加了难度。最大技术难点在于在移动端实现流畅的双摇杆操作和照明渲染效果。
