# Tomb of the Mask（面具之墓）

- **类型**: 迷宫 / 跑酷 / 街机
- **平台**: Mobile (iOS+Android)
- **开发商**: Playgendary Limited
- **首次发布**: 2016
- **一句话描述**: 在随机生成的迷宫中快速上下左右滑动，吃掉所有金币并向上逃离

## 玩法规则

游戏画面是一个垂直迷宫，玩家控制一个戴着面具的角色。迷宫墙壁由像素方块构成，通道中有金币散布。

玩家操作极其简单：向任意方向（上/下/左/右）滑动或按住方向键，角色会沿着该方向一直移动，直到撞到墙壁才停下来。无法在中途改变方向——这就是"滑行"移动的核心特点。

目标是吃掉迷宫中的所有金币（或指定数量的金币），同时躲避陷阱（尖刺、火焰、移动障碍物等）和敌人。吃到所有金币后，出口出现，玩家到达出口即过关。

迷宫是程序随机生成的，每局布局不同。游戏分为两种模式：关卡模式（预设计的迷宫关卡，有特定主题和障碍组合）和无尽模式（不断向上爬升，迷宫随机生成，越往上越快）。

部分关卡有特殊道具：磁铁（自动吸附金币）、护盾（抵挡一次伤害）、加速鞋等。吃到这些道具后获得一次性增益效果。

## 核心循环

滑动方向 → 角色滑行直到撞墙 → 沿途吃金币 → 观察布局选择下一方向 → 吃完金币 → 前往出口

## 核心机制

- **惯性滑行移动**：角色一旦开始移动就不会停，只有撞墙才停止。这意味着每次方向选择都是一次"承诺"——你不能中途改变主意。这种移动方式让简单的上下左右操作充满策略性。
- **路径规划**：由于滑行特性，玩家需要预判路线。比如"先向右滑到底，再向上，再向左"是否能吃到所有金币而不碰到陷阱？好的路线能吃掉更多金币并避免危险区域。
- **随机迷宫生成**：无尽模式的迷宫是程序生成的，保证每局不同。墙壁布局、金币位置、陷阱位置都随机变化。
- **速度递增**：无尽模式中，随着爬升高度增加，角色滑行速度也会加快，反应时间缩短，难度自然上升。

## 为什么好玩

极简的操作（只需一个滑动方向）却带来丰富的策略深度——每次移动都是一次路径承诺，选择错误就可能卡死在死角或撞上陷阱。吃金币的"叮叮"声配合像素风格的画面，营造出复古街机般的爽快感。无尽模式的速度递增天然制造紧张感，让人不断挑战自己的反应极限。

## 粘性来源

- **高分挑战**：无尽模式追求更高分数和更远爬升距离
- **关卡收集**：关卡模式有大量预设计关卡，每个有独特的障碍组合
- **短局快节奏**：单局 1-3 分钟，随时可以"再来一局"
- **视觉风格**：复古像素风 + 霓虹色彩搭配，辨识度高

## Meta 系统

- **角色解锁**：使用金币解锁不同的面具/角色皮肤，纯外观变化
- **关卡解锁**：按章节推进，解锁新主题迷宫
- **每日挑战**：特殊条件的每日关卡，获得额外奖励

## 实现难度

低。核心是网格迷宫 + 惯性移动物理 + 碰撞检测。最大技术难点在于：(1) 程序化迷宫生成算法，确保生成的迷宫是可解的（存在吃掉所有金币的路径）；(2) 流畅的滑行移动动画和手感调优；(3) 无尽模式的动态难度调节。
