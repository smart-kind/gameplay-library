# Terraria

- **类型**: 沙盒 / 冒险
- **平台**: PC / Switch / Mobile / 多平台
- **开发商**: Re-Logic
- **首次发布**: 2011
- **一句话描述**: 独立游戏史上最伟大的价值 proposition 之一——内容密度和更新频率令人惊叹。

## 玩法规则

2D 沙盒冒险游戏，常被误认为是 2D Minecraft，但更接近带有生存建造元素的银河战士恶魔城。核心体验是探索、发现和战斗。

玩家在世界中挖掘、建造和战斗。探索发现新材料，逐步锻造更强的武器和装甲。Boss 会在最意想不到的时候出现，考验玩家的准备程度。战斗是游戏的核心——数百种武器（剑、弓、魔法、召唤）各有独特的使用方式。

建筑系统同样丰富——大量方块和装饰允许玩家建造家园并最终为 NPC 建立完整的城镇。游戏持续更新超过 10 年，内容量惊人。

## 核心循环

挖掘探索 → 发现材料 → 锻造装备 → 挑战 Boss → 建造家园

## 核心机制

- 银河战士恶魔城战斗：探索、发现、变强的循环
- Boss 系统：数十个 Boss 各有独特机制
- 武器多样性：数百种武器各有独特使用方式
- 建筑系统：大量方块和装饰建造城镇
- 持续更新：超过 10 年的免费内容更新

## 为什么好玩

内容密度之王。从简单的木剑到击败月球领主的旅程中，每次发现新材料和新武器都让人兴奋。

## 粘性来源

- 探索发现：每次挖掘都可能发现新矿物或宝箱
- Boss 挑战：每个 Boss 都是新的机制挑战
- 武器多样性：尝试不同武器类型的乐趣
- 持续更新：10 年以上持续免费更新

## Meta 系统

NPC 入住和装备解锁。建造房屋吸引 NPC，击败 Boss 解锁新装备和事件。

## 实现难度

中。2D 沙盒的核心系统成熟，难点在于内容量（数百种武器、数十个 Boss、大量生物和事件）的创作和平衡。
