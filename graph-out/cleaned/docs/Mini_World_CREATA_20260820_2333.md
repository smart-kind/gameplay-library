# 迷你世界：创造（Mini World: CREATA）

- **类型**: 沙盒 / 创造 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Miniwan Tech
- **首次发布**: 2021
- **一句话描述**: 一款方块沙盒游戏，玩家可以在开放世界中建造、探索、与其他玩家互动。

## 玩法规则

游戏世界由方块构成的3D开放世界。玩家以第一人称或第三人称视角探索世界，可以破坏和放置方块。

核心玩法分为创造和生存两种模式。创造模式中，玩家拥有无限资源，可以自由建造任何结构——房屋、城堡、雕塑、红石机械等。没有敌人威胁，纯粹发挥创造力。

生存模式中，玩家需要收集资源（砍树、采矿、种植）、制作工具和武器、建造庇护所抵御怪物。白天探索收集，夜晚回到庇护所防守，形成日夜循环。

游戏包含多种生物群落——森林、沙漠、雪地、海洋等，每个群落下有不同的资源和怪物。玩家可以探索这些区域寻找稀有材料。

多人模式支持玩家联机，共同建造或进行小游戏。游戏内置了迷你游戏系统，玩家可以在其他玩家创造的地图中游玩跑酷、对战、解谜等内容。
## 核心循环

收集资源 → 制作工具 → 建造结构/对抗怪物 → 探索新区域 → 发现更稀有资源 → 重复循环

## 核心机制

- **方块建造系统**：游戏世界完全由可破坏和放置的方块组成。这种'乐高式'的建造机制给玩家无限的创造自由度，是游戏最大的特色。
- **日夜循环+生存压力**：生存模式中，白天安全探索收集，夜晚怪物出没需要防守。这种循环创造了自然的节奏感——白天是扩张期，夜晚是防守期。
- **多人联机+用户创作**：玩家可以联机合作建造，也可以游玩其他玩家创建的迷你游戏地图。用户创作内容极大扩展了游戏的可玩性和生命周期。

## 为什么好玩

无限的创造自由度是最大的乐趣。从挖一个洞穴到建造一座城堡，每一步都是自我表达。多人联机让建造过程变成社交活动。

## 粘性来源

创造自由度是核心粘性——'我想建X'的冲动驱动持续游玩。生存模式的日夜循环提供天然的游戏节奏。多人联机的社交互动增加留存。用户创作内容（迷你游戏）提供无限的新鲜体验。收集稀有材料和完成建造项目的成就感驱动长期投入。

## Meta 系统

玩家等级和成就系统。通过建造、探索、击败怪物获得经验值升级。解锁新的方块类型和装饰物品。用户创作内容的发布和订阅系统。

## 实现难度

高 — 3D方块世界的渲染、多人联机同步、用户创作内容的存储和加载都有较高技术门槛。最大的技术难点在于大世界的流式加载和多人实时同步的性能优化。
