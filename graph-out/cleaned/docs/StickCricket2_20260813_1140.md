# 火柴人板球2（Stick Cricket 2）

- **类型**: 体育 / 街机
- **平台**: Mobile (iOS+Android) / Web
- **开发商**: Blue Wombat（原Stick Sports）
- **首次发布**: 2015（系列首作2007年Flash版）
- **一句话描述**: 一款火柴人风格的板球游戏，玩家通过精准时机控制击球手来击球得分

## 玩法规则

游戏画面简洁：一个火柴人击球手站在画面中央的击球线上，面对从屏幕另一端投来的板球。投球手在远处将球投出，球沿着一定的弧线飞向击球手。

玩家的核心操作是：在球到达击球区域的瞬间点击屏幕（或滑动）来挥棒击球。点击的时机决定了击球的质量：
- **完美时机**：球正好到达击球区的瞬间击中，打出六分球（SIX，球飞出界外，最高得分）
- **良好时机**：稍微偏早或偏晚，打出四分球（FOUR，球滚过边界线）
- **一般时机**：打出1-2分的短距离击球
- **失误时机**：打空或被对方接杀（OUT）

通过滑动方向可以控制击球的方向——向左滑动打向左侧，向右滑动打向右侧，向上滑动打出高飞球。不同的击球方向有不同的风险和回报。

游戏有多种模式：
- **限时得分赛**：在限定时间内尽可能多得分
- **追逐目标赛**：在限定回合内追平或超过目标分数
- **锦标赛模式**：多轮比赛累积积分

投球手会变化投球速度（快速球、慢速球）、旋转（左旋、右旋）和落点（内线、外线、短球、长球），玩家需要不断适应不同的球路。

## 核心循环

观察投球手的动作预判球路 → 在正确时机点击/滑动挥棒 → 根据击球质量获得分数（SIX/FOUR/1-2分/OUT） → 在限定回合或时间内最大化得分 → 面对不同类型的投球手继续挑战

## 核心机制

- **时机判定系统**：击球质量完全取决于点击时机与球到达击球区的匹配度。完美时机的窗口非常窄（大约0.1-0.2秒），需要极高的专注力和反应速度
- **方向控制**：滑动方向控制击球方向，增加策略维度。某些方向更容易得分但也更容易被接杀
- **投球变化系统**：投球手变化速度（快速球vs慢速球）、旋转（影响球的弧线）和落点（内线/外线/短球/长球），玩家需要阅读投球手的动作来预判球路
- **多模式系统**：限时赛、追逐赛、锦标赛等不同模式提供不同的挑战节奏

## 为什么好玩

板球运动的精髓被提炼为最简单的点击操作——不需要理解板球的所有复杂规则，只需要掌握"看准时机、挥棒击球"这一核心。完美时机击出六分球时的满足感极强——火柴人击球手优美的挥棒动画、球飞向天空的弧线、观众的欢呼声，反馈链条完整。火柴人风格简洁幽默，让体育游戏变得轻松有趣。

## 粘性来源

完美击球的时机快感让人上瘾——那种"刚刚好"的感觉形成强烈的正反馈。"再打一次就能破纪录"的驱动力很强，尤其是限时得分模式。不同投球模式和对手保持新鲜感。火柴人角色的幽默表现（打出SIX后的庆祝动作、被OUT后的搞笑反应）增加娱乐性。

## Meta 系统

角色解锁和装备系统。通过得分解锁新的火柴人角色皮肤和球拍外观。全球排行榜提供社交竞争动力。每日挑战模式提供特定条件的限时挑战。

## 实现难度

低 — 最大技术难点是投球AI的多样性（让不同类型的投球手有明显区别）和击球时机判定的精确度。球的物理轨迹需要看起来真实。时机窗口的设计需要让完美击球感觉公平且有成就感——太容易没有挑战，太难让人沮丧。
