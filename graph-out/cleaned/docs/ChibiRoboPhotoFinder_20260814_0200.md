# Chibi-Robo! Photo Finder（小小机器人！照片搜索者）

- **类型**: 冒险解谜 / 照片收集
- **平台**: Nintendo 3DS
- **开发商**: Skip Ltd. / Nintendo
- **首次发布**: 2014
- **评分**: Nintendo 3DS冒险游戏
- **一句话描述**: 操控只有10厘米高的小机器人Chibi-Robo，在微缩世界中通过拍照和探索解开谜题的温馨冒险游戏

## 玩法规则

玩家控制一个只有10厘米高的微型机器人Chibi-Robo，在一个按真实比例缩小的家庭环境中探险。房间里的日常物品——书本、杯子、家具——对Chibi-Robo来说都是巨大的障碍物和探索对象。

游戏的核心机制是"拍照"。Chibi-Robo携带一台微型相机，通过拍摄特定物体、场景或事件来推进游戏。某些谜题需要玩家从特定角度拍摄照片，或者找到隐藏的拍摄目标。

探索过程中，Chibi-Robo会遇到各种微型的居民和角色，每个角色都有自己的小任务或故事线。帮助这些角色是推进剧情的重要方式。

游戏节奏轻松舒缓，没有战斗或时间压力。重点在于发现环境中的秘密、完成角色的请求、以及收集照片来完成图鉴。

3DS的双屏设计也被巧妙利用——上屏显示3D游戏世界，下屏显示地图、物品栏和拍照界面。

## 核心循环

探索环境 → 发现可拍摄的目标或需要帮助的角色 → 拍照/完成任务 → 解锁新区域和新照片目标 → 继续探索

## 核心机制

- **微缩世界探索**：以10cm机器人的视角体验日常环境，熟悉的物品变得陌生而有趣
- **拍照解谜**：通过拍照来记录发现、推进剧情和完成收集目标
- **角色互动**：与微型世界中的各种角色对话和互动，每个角色都有自己的小故事
- **收集系统**：照片图鉴收集，记录发现的各种场景和事件
- **无障碍低压设计**：无战斗、无时间限制、无死亡惩罚，纯粹的探索乐趣

## 为什么好玩

Chibi-Robo系列的独特魅力在于"以小见大"——从一个微型机器人的视角重新审视日常生活中被忽视的细节。桌面上的一个茶杯变成了一座山，地板上的一条裂缝变成了一道深渊。这种视角的转换本身就充满了童趣和惊喜。拍照机制让"观察"成为游戏的核心玩法，培养了玩家对细节的关注力。

## 粘性来源

(1) **发现的惊喜**——在看似普通的房间角落找到隐藏的秘密；(2) **收集驱动**——完成照片图鉴的收集满足感；(3) **角色的故事**——每个微型角色都有自己的小故事，想要知道后续；(4) **放松治愈的体验**——低压力的游戏节奏适合放松

## Meta 系统

- **照片图鉴收集**：收集所有可能的照片是主要的收集目标
- **角色好感度**：通过完成任务提升与角色的关系

## 实现难度

**中** — 3D微缩场景的精细建模和交互设计是主要工作量。技术难点在于场景交互的丰富度（每个物品都可以互动）和拍照系统的实现
