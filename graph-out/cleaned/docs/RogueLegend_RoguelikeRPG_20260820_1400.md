# Rogue Legend（Rogue Legend - Roguelike RPG）

- **类型**: Roguelike RPG / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketHaven Games Ltd.
- **首次发布**: 2026
- **一句话描述**: 每次战斗都让英雄变强的动作Roguelike冒险

## 玩法规则

游戏从一个大厅（Lobby）开始，玩家点击开始后掷骰子进入一个随机的 Roguelike RPG 关卡。每个关卡是一个充满怪物、宝藏和强大 Boss 的世界。

玩家在关卡中探索不同区域，与独特敌人战斗，躲避弹幕攻击，使用多种武器和道具。每次战斗中获得的经验和物品会让英雄变强，为下一轮冒险积累力量。战斗是实时动作制的，需要玩家灵活走位和精准操作。

核心循环是：进入关卡 → 战斗获得资源 → 英雄成长 → 在下一轮中挑战更深的区域。每次死亡后回到大厅，但英雄保留了部分成长进度，下次出发时起点更高。

游戏包含多个世界区域，每个区域有独特的环境主题、怪物种类和 Boss。随着英雄等级提升，可以解锁新区域和新能力。每个区域的环境主题决定了遇到的敌人类型和可获得的道具种类。

## 核心循环

掷骰进入关卡 → 战斗获得成长 → 回到大厅强化 → 下一轮挑战更深层

## 核心机制

- **累积成长Roguelike**：与传统Roguelike的'死亡清零'不同，英雄在每次冒险中获得的成长会部分保留，降低了重复游玩的挫败感。这种设计让每次失败都不是白费，而是为下次成功积累基础
- **掷骰进入机制**：每次出发通过掷骰子决定进入哪种关卡，增加了随机性和期待感。掷骰的瞬间总让人期待'这次会进入什么样的世界？'
- **多区域Boss战**：每个世界区域有独特的Boss和战斗模式，需要玩家调整策略应对。Boss战的多样性是游戏长期吸引力的关键

## 为什么好玩

Rogue Legend 结合了Roguelike的重玩性和RPG的成长感——即使单次冒险失败，英雄也在变强，这种'每次都在进步'的正向反馈让人欲罢不能。

## 粘性来源

英雄成长的持续正反馈 + Boss战的挑战成就感 + 掷骰的随机期待感

## Meta 系统

英雄等级/装备成长系统 + 区域解锁 + 技能树升级

## 实现难度

中 — 随机关卡生成+战斗系统+成长曲线的平衡设计是难点，最大技术难点是保证每次生成的关卡既有随机性又有趣味性
