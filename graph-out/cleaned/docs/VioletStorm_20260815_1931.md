# Violet Storm

- **类型**: 弹幕射击 (Shoot 'em up) / 街机
- **平台**: Mobile (iOS + Android)
- **开发商**: SkyFire
- **首次发布**: 2011
- **一句话描述**: 操控太空战机在密集的弹幕中穿梭，消灭一波又一波的外星敌人。

## 玩法规则

游戏采用纵向卷轴视角，玩家操控一架太空战机从屏幕底部向上推进。敌人从屏幕顶部和两侧进入画面，发射各种形状的子弹（弹幕）。

操作方式：
- **虚拟摇杆**：位于屏幕左下方，控制战机上下左右移动。支持平滑的8方向移动。
- **自动射击**：战机持续自动发射子弹，玩家只需专注躲避。
- **炸弹/特殊武器按钮**：屏幕右下方有一个炸弹按钮，按下后清除屏幕上所有子弹并对敌人造成伤害。每局有限量（通常3-5个）。

屏幕上同时存在大量敌人子弹，形成复杂的弹幕图案（圆形扩散、螺旋、交叉线等）。玩家需要找到弹幕之间的"缝隙"穿过。战机有3条命（life），被击中一次失去一条命，全部失去则游戏结束。

游戏分为多个关卡（wave/stage），每关有固定的敌人编队出现顺序。关卡末尾出现 Boss 战，Boss 血量高、弹幕模式复杂，需要找到安全的躲避点并持续输出。

## 核心循环

消灭敌人 → 获得分数和道具 → 挑战更难的关卡和 Boss → 突破更高分数

## 核心机制

- **弹幕闪避**：核心体验是"在刀尖上跳舞"——子弹密集但存在可穿过的安全路径。玩家的移动精度和反应速度直接决定生存时间。
- **道具系统**：消灭特定敌人掉落道具（Power Up 升级火力、Score Up 加分、Life 加命、Bomb 补充炸弹）。
- **火力升级**：收集 Power Up 道具后，战机的子弹数量和威力逐步提升（最高几级），形成"收集→变强→更容易过关"的正反馈。
- **Boss 弹幕模式**：每个 Boss 有多个阶段的弹幕攻击，玩家需要记住模式或实时判断安全区域。

## 为什么好玩

弹幕射击游戏的核心乐趣在于"刀尖上跳舞"的刺激感——看着满屏子弹几乎无处可躲，但你恰好找到了那条安全通道穿过去。Violet Storm 在手机平台上重现了街机时代的弹幕射击体验，虚拟摇杆的精确操控让闪避过程充满成就感。

## 粘性来源

- **分数驱动**：高分排行榜驱动玩家反复挑战同一关卡以刷分。
- **弹幕美学**：复杂的弹幕图案本身就是一种视觉享受。
- **技巧验证**：每多活一秒都是对自身反应和判断力的证明。

## Meta 系统

无 — 经典街机模式，每局独立，无长期成长系统。

## 实现难度

**中** — 弹幕系统需要高效的碰撞检测和子弹管理（屏幕上同时存在数百发子弹）。最大技术难点在于性能优化（大量子弹的渲染和碰撞计算）以及弹幕图案的设计工具。
