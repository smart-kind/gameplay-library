# 僵尸好莱坞（Zombiewood）

- **类型**: 射击 / 动作冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: Gameloft
- **首次发布**: 2011
- **一句话描述**: 以好莱坞为背景的僵尸射击游戏，玩家扮演一位普通市民在僵尸爆发的加州寻找女友并完成任务。

## 玩法规则

玩家操控主角在多个场景之间移动，通过虚拟摇杆控制方向。游戏采用自动开火机制，子弹只向正前方发射，遇到身后敌人时需要转身跑入敌人范围才能射击。

每个关卡包含多个任务目标，玩家需要跟随场景中的标记找到任务点并执行。任务类型多样：包括单纯消灭涌来的僵尸群、驾驶车辆碾压僵尸、以及寻找并解救被困人员（如寻找失踪女演员）。

通关条件为完成当前区域的所有任务目标。每消灭一个僵尸可获得经验值和硬币，经验值用于提升等级解锁新武器，硬币用于在商店购买武器和特殊道具。

游戏提供炸药超级技能，可在僵尸群密集时清屏，也可作为近战武器使用。场景中还有可互动的环境元素，如射击消防栓盖子制造水柱击退僵尸群。
## 核心循环

完成关卡任务，获得硬币和经验值，购买新武器和提升等级，解锁更难关卡

## 核心机制

- **自动前向射击系统**：玩家只需控制移动方向，武器自动朝前开火。这种设计简化了操作但也带来转身困难的问题，身后敌人必须跑过去才能打到
- **等级成长系统**：消灭僵尸和完成任务获得XP，等级提升后解锁更强武器购买资格，形成持续的正向反馈循环
- **环境互动机制**：可射击场景中的消防栓等物体产生效果，增加战术维度
- **超级技能系统**：炸药清屏技能提供紧急逃生手段，同时具备近战功能

## 为什么好玩

好莱坞僵尸主题的幽默感和大量任务类型让游戏内容丰富，几十种武器和道具提供了足够的解锁目标。驾驶载具碾压僵尸等任务变化带来短暂的新鲜感。

玩家还可以驾驶载具（如汽车、坦克）在特定任务中使用，载具拥有独立的耐久度和特殊攻击方式。驾驶模式下操作方式略有不同，需要通过虚拟按钮加速、刹车和转向。

游戏设有多个场景主题，包括好莱坞影城、郊区住宅、废弃停车场等，每个场景有独特的建筑布局和互动元素。场景之间的切换通过加载动画过渡。

部分任务有时间限制，需要在倒计时结束前完成目标。超时未完成任务会导致关卡失败，需要重新尝试。

武器商店中除了常规枪械外，还提供火焰喷射器、冰冻枪、榴弹发射器等特殊武器，每种武器有其独特的清怪效果和范围。
## 粘性来源

等级提升带来的装备解锁欲望是主要粘性来源，差一点就完成任务的关卡失败不甘心感促使再来一局。但缺乏深度创新，通关后容易被遗忘。

## Meta 系统

XP等级系统。玩家通过消灭僵尸和完成任务获得经验值，提升等级后可解锁更高级武器购买权限。商店系统提供武器、特殊道具等多种消耗品。对核心玩法的影响：高等级武器显著提升清怪效率，形成数值成长驱动。

## 实现难度

中等。最大技术难点在于大量AI僵尸的同时渲染和寻路计算，以及自动射击方向判定与玩家移动控制的协调。
