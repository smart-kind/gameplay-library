# 触发英雄（Trigger Heroes）

- **类型**: Roguelike 射击 / 俯视角动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Lucky Kat Studios
- **首次发布**: 2018
- **一句话描述**: 俯视角 Roguelike 射击游戏，用单手触摸控制探索不同区域，战斗独特敌人，使用多种武器夺回被占领的星球。

## 玩法规则

玩家控制角色 Red，在被 Shogun Inc 雇佣军占领的 Planet Orbitus 上战斗。游戏采用俯视角，每个关卡是一个随机生成的房间，房间中有敌人、障碍物和可收集物品。

核心操作是单指触摸控制——触摸屏幕的某个位置，角色就会向该方向移动并自动射击。移动和射击是联动的：你的移动方向就是射击方向。这意味着你不能同时向一个方向移动和向另一个方向射击，需要策略性地选择位置和角度。

每个关卡有独特的主题和 Boss 敌人。击败 Boss 后可以进入下一个区域。死亡后需要从头开始，但可以解锁新的角色、武器和能力。

## 核心循环

探索房间 → 战斗消灭敌人 → 击败Boss进入下一区域 → 死亡后重新开始并解锁新内容

## 核心机制

- **移动即射击**：移动方向和射击方向绑定，简单直观但深度十足——你需要同时考虑走位和攻击方向
- **程序化关卡**：每次重新开始的关卡布局不同，保持新鲜感
- **多角色多武器**：6个不同角色各有独特能力，多种武器提供不同战斗风格
- **5个独特环境**：每个环境有独特的敌人和 Boss 设计

## 为什么好玩

单手操作的极简设计与 Roguelike 的深度完美结合。虽然操作只有一根手指，但"移动=射击"的机制让你在走位时必须同时考虑攻击，每一步都是决策。每次死亡后的重新开始因为关卡随机和解锁内容而不重复。

## 粘性来源

- **Roguelike 重玩价值**：随机关卡+多角色+多武器组合，每局体验不同
- **解锁进度**：死亡后仍能解锁新角色和武器，失败不白费
- **Boss 挑战**：每个 Boss 有独特攻击模式，攻克后的成就感

## Meta 系统

- **角色解锁**：通过游戏进度解锁新角色
- **武器收集**：解锁多种武器类型
- **能力升级**：永久解锁的能力增强

## 实现难度

中等。俯视角射击+程序化关卡生成+AI敌人行为。最大技术难点是关卡随机生成算法和敌人AI设计。
