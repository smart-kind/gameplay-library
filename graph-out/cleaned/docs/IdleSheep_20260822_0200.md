# 放置绵羊（Idle Sheep!）

- **类型**: 放置/模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2016
- **一句话描述**: 养羊场经营的放置游戏

## 玩法规则

玩家经营一个绵羊农场。绵羊自动产出羊毛，玩家收集后出售获得金币。金币用于购买更多绵羊、升级剪毛速度、解锁新羊品种。游戏界面简洁，以农场场景为主。离线时绵羊继续产毛。通过策略性升级最大化产出效率。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

绵羊产毛 → 收集出售 → 购买更多绵羊/升级 → 产出增加 → 继续经营

## 核心机制

- **自动产出**:  绵羊持续产出羊毛
- **收集机制**:  点击收集羊毛出售
- **升级系统**:  提升产量和效率

## 为什么好玩

可爱绵羊的视觉吸引力，经营农场的满足感

## 粘性来源

绵羊数量增长的成就感；新羊品种解锁的期待

## Meta 系统

羊品种收集和农场升级

## 实现难度

低 - 核心是简单的数值增长 - 大量绵羊同时存在时的渲染性能
