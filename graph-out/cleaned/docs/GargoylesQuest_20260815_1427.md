# 魔界村外传 加尔之 quest（Gargoyle's Quest）

- **类型**: 平台/动作冒险
- **平台**: Game Boy / NES / Mobile（移植版）
- **开发商**: Capcom
- **首次发布**: 1990
- **一句话描述**: Capcom经典《魔界村》系列的衍生作品，玩家扮演石像鬼Firebrand，在2D平台间飞行和战斗，探索地下城。

## 玩法规则

画面为横版2D平台。玩家控制石像鬼Firebrand，可以在空中短暂飞行（按住飞行键），在地面上行走和跳跃。游戏世界由多个区域组成，每个区域包含平台、敌人、谜题和Boss。

Firebrand的攻击方式是发射火球，可以攻击前方的敌人。飞行能力是核心机制——玩家可以在空中滑翔，从高处飞向低处，但不能无限上升。这要求在平台之间移动时仔细规划飞行路线。

游戏包含RPG元素：玩家可以在城镇中与NPC对话获取任务信息，购买装备和道具。击败Boss后解锁新的区域。

操作：方向键移动，A键发射火球，B键飞行。移动端适配为虚拟摇杆+双按钮。

## 核心循环

探索新区域 → 击败敌人和Boss → 获取道具和任务信息 → 解锁新区域

## 核心机制

- **飞行平台**：Firebrand的飞行能力让平台跳跃不同于传统2D平台——不是"跳多高"而是"滑多远"。玩家需要管理飞行时机和方向，在有限的飞行距离内到达下一个平台。
- **火球射击**：基础的远程攻击方式，对付不同类型的敌人需要不同的射击策略（有些敌人需要多次命中，有些需要特定角度）。
- **RPG式探索**：NPC对话、任务线、装备购买，这些RPG元素给平台动作增加了深度。
- **区域解锁**：击败Boss后通往新区域的路径打开，形成渐进式探索节奏。

## 为什么好玩

飞行能力让平台跳跃有了独特的节奏感——不是精确的跳跃时机，而是滑翔的角度和距离判断。这种"飞行的自由感"与"有限的飞行距离"之间的张力，创造出一种不同于超级马力欧的平台体验。

## 粘性来源

- **探索驱动**：新区域、新敌人、新Boss，持续的发现感
- **RPG进度**：装备升级、道具收集，提供成长感
- **Boss挑战**：每个Boss都有独特的攻击模式，需要学习并找到应对方法
- **系列情怀**：《魔界村》系列的衍生作品，自带IP认知度

## Meta 系统

- **装备系统**：购买更好的武器和防具，提升火球威力和防御力
- **道具收集**：恢复道具、增强道具
- **对核心玩法的影响**：装备升级让战斗更容易，但不改变核心的飞行+射击机制

## 实现难度

中 — 飞行物理（滑翔动力学）需要调试以达到手感舒适，2D平台关卡设计需要精心构造难度曲线。最大技术难点在于飞行控制的手感调优——飞得太灵活失去挑战性，太僵硬又令人沮丧。
