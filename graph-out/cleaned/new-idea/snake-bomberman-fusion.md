# 贪吃蛇 × 炸弹人 — 融合设计草案

**日期**: 2026-08-15
**状态**: 讨论中 / 未定稿

## 核心概念

将贪吃蛇的"吃食物长身体"与炸弹人的"放置炸弹"机制融合，形成一条闭合的策略循环。

## 操作方式

- **手机**: 虚拟方向舵（上下左右）
- **电脑**: WASD / 方向键，或鼠标点击蛇头周围 8 格中的任意一格转向
- 蛇沿设定方向持续前进，玩家可随时改变方向
- **快捷键（空格）**: 主动断尾 → 尾巴变为炸弹

## 移动与寻路

- 格子制地图，蛇每次移动一格
- 可向周围 8 个方向移动（含对角线 45°）
- 寻路基于 DDA 算法拟合，按格子步进逼近玩家指定的方向

## 核心循环

```
吃食物 → 长身体 → 主动断尾变炸弹 → 炸弹爆炸 → 炸断对手身体 → 掉落食物 → 吃食物长身体
```

## 食物与生长

- 吃 1 份食物 → 蛇身长 1 节
- 食物来源：
  - 地图初始散放的固定食物
  - 蛇被炸断后掉落的食物

## 断尾与炸弹

### 主动断尾（推荐方案）

- 按空格（或点击按钮）→ 蛇尾切断 4 节
- 这 4 节缩成一团聚合成一颗炸弹，留在切断位置
- 炸弹倒计时（如 3 秒）后爆炸
- **代价**: 自己变短 4 节（更灵活但也更脆弱）
- **收益**: 获得炸弹，可攻击对手、改变地形

### 被动断尾（备选讨论）

- 被对手撞到中间段 → 被撞断
- 断掉的身体段聚合为炸弹或食物
- 聚合结果取决于蛇的状态（"战斗状态"→炸弹 / "贪吃状态"→食物）
- ⚠️ 此方案因果关系被动，玩家掌控感弱，倾向放弃

## 炸弹效果

- **攻击**: 炸断爆炸范围内所有蛇的身体（含自己）
- **地形**: 炸开障碍物，改变路径格局
- **食物**: 被炸断的身体段变成食物散落在周围

## 关键设计取舍（待讨论）

1. **炸弹发射方向**: 原地放置（更像炸弹人）vs 向前方喷射（开路更直观）
2. **状态切换**: 是否保留"战斗/贪吃"双状态？→ 倾向砍掉，统一机制
3. **炸弹持有上限**: 是否限制同时持有的炸弹数量（如最多 3 颗）
4. **自伤**: 自己的炸弹是否会炸到自己？→ 建议会，增加风险意识

## 一句话总结

> 贪吃蛇吃食物长身体，主动断尾换炸弹，炸弹炸对手造食物，食物再吃长身体——策略体现在"何时断尾"与"炸弹放在哪"。
