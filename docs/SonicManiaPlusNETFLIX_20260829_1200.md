# 索尼克狂热 Plus（Sonic Mania Plus - NETFLIX）

- **类型**: 横版动作平台
- **平台**: Mobile (iOS+Android) — 需Netflix会员
- **开发商**: Netflix / SEGA
- **首次发布**: 2017
- **一句话描述**: 经典索尼克2D横版高速跑酷游戏，以现代画面重新演绎90年代经典关卡并加入新角色

## 玩法规则

游戏呈现经典2D横版卷轴画面，屏幕左下方为虚拟方向键或支持手柄，右下方为跳跃和攻击按钮。玩家可选择索尼克、塔尔斯或纳克鲁斯三个角色。

索尼克速度快且可旋转攻击，塔尔斯可飞行一段距离，纳克鲁斯可攀爬墙壁和滑翔。关卡中布满金环、弹簧、加速带、尖刺陷阱和敌人。

收集金环可以抵消一次伤害（被攻击时金环飞散），收集100个金环获得额外生命。每个关卡分为多个区域（Act），区域之间有检查点，末尾设有Boss。

关卡设计中包含大量隐藏路径和秘密区域，有些需要特定角色才能到达。例如索尼克可以通过高速冲刺打开隐藏墙壁。

特殊关卡（Special Stage）通过收集足够金环进入，是3D半管赛道，玩家需要收集蓝色球体同时避免红色球体。

## 核心循环

高速奔跑收集金环 → 通过精准操作避开陷阱和敌人 → 击败关卡Boss → 解锁新关卡

## 核心机制

- 高速移动机制：核心体验在于保持高速奔跑的流畅感，利用斜坡、加速带和弹跳板实现连续高速移动。速度不仅是移动方式，更是武器
- 角色差异化能力：三个角色各有独特移动方式（飞行/攀爬），改变关卡通关策略和路线选择
- 金环保护系统：金环既是分数也是护盾，被攻击时金环飞散的紧张感增加了刺激体验

## 为什么好玩

极致的高速移动带来无与伦比的爽快感，经典关卡的怀旧情怀与现代化改进完美结合。

每个角色的操作手感都经过精心调校。

游戏对90年代索尼克经典关卡的致敬和现代化改进让玩家在怀旧的同时也能体验到现代游戏的精致品质。

## 粘性来源

竞速挑战（时间排名）驱动反复通关追求更好成绩——每个关卡都有从D到S的评级。角色解锁和隐藏要素增加探索动力

## Meta 系统

纯关卡制游戏无外围成长系统，但包含隐藏关卡、特殊关卡和混沌翡翠收集系统

## 实现难度

中等 — 高速操作需要精确时机和肌肉记忆。最大的技术难点在于维持60fps流畅运行和精确的碰撞检测
