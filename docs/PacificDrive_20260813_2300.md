# Pacific Drive

- **类型**: 生存 / 驾驶 / 探索
- **平台**: PC (Windows) / PlayStation 5
- **开发商**: Ironwood Studios
- **发行商**: Kepler Interactive
- **首次发布**: 2024
- **一句话描述**: 在超自然现象肆虐的奥林匹克半岛上，驾驶改装汽车进行生存探索的第一人称驾驶生存游戏。

## 玩法规则

游戏采用第一人称驾驶视角，玩家坐在一辆改装汽车的驾驶舱内。仪表盘上显示着各种信息：油量、车辆状态（引擎、悬挂、轮胎、车身的损坏程度）、指南针、地图，以及检测超自然异常的仪器。

游戏的核心循环是：驾驶到安全区域 → 搜集资源 → 改装车辆 → 出发探索危险区域 → 搜集更多资源 → 返回。每次外出探索都有明确的目的地和物资清单，玩家需要在车辆资源和目标之间做出权衡。

车辆是玩家的生命线。玩家需要手动修理损坏的部件：换轮胎、修引擎、焊接车身、更换挡风玻璃。每个修理动作都是通过车库中的工作台手动完成的——不是点击一个按钮就完成，而是真正执行修理操作。这种物理化的修理过程增强了沉浸感。

超自然异常是游戏中的主要威胁。奥林匹克半岛被各种诡异的超自然现象笼罩：时间循环、重力异常、电磁风暴、未知实体等。玩家无法"打败"这些异常，只能避开、利用或承受它们。某些异常甚至会损坏车辆，迫使玩家紧急修理。

探索过程中，玩家需要收集各种材料：金属板用于焊接车身，燃料用于驱动，电子元件用于升级设备，稀有材料用于高级改装。资源管理是核心策略之一——装太多材料会影响车辆性能和行驶速度，装太少则无法完成探索目标。

## 核心循环

搜集资源 → 改装/修理车辆 → 探索危险区域 → 获取更多资源 → 应对超自然异常 → 返回

## 核心机制

- **车辆作为移动基地**：车辆不仅是交通工具，更是玩家的移动安全屋。它承载所有收集到的物资，是玩家在危险区域中唯一的庇护所。这种设计让"车就是家"的概念深入游戏体验。
- **超自然环境**：奥林匹克半岛上的异常现象既是威胁也是机会。某些异常区域产出稀有资源，玩家需要权衡风险与回报。这种"危险中蕴含价值"的设计驱动玩家不断深入。
- **物理化修理系统**：玩家亲手焊接车身、更换零件，而非简单的UI菜单修理。这种操作感让每次修理都有成就感，也让车辆损坏变得"真实"。
- **资源权衡决策**：每次出行前需要决定带什么物资——多带燃料还是多带备件？轻装快速还是满载而归？这种决策让每次出行都有策略性。

## 为什么好玩

Pacific Drive 将"驾驶"变成了"生存的核心"。大多数生存游戏中交通工具只是移动手段，但这里汽车就是你的家、你的仓库、你的生命线。每一次引擎故障、每一次轮胎爆裂、每一次在暴风雨中挣扎着回到车库，都会产生紧张和成就感交织的体验。

## 粘性来源

- **改装升级的正反馈**：每次从危险区域带回来的资源都用于让车辆变得更强——更好的引擎、更坚固的车身、更先进的扫描仪。这种"我的车越来越强"的成长感是核心粘性。
- **未知的好奇心**：奥林匹克半岛上总有新的异常现象等待被发现。"前面那个诡异的光是什么？""那个区域里藏着什么资源？"这种好奇心驱动玩家不断深入。
- **紧张-放松的节奏**：危险探索后的安全返回会带来强烈的放松感，这种节奏让人上瘾。

## Meta 系统

**车辆改装树**。玩家通过收集资源解锁和购买车辆改装选项，包括：引擎升级、悬挂系统改进、新增扫描设备、防护装置等。改装直接增强车辆在危险区域的生存能力，对核心玩法有显著影响。

## 实现难度

**高**。最大技术难点：1）第一人称驾驶手感的打磨——需要真实的物理反馈和舒适的操控性；2）超自然现象的AI和环境交互系统——每种异常都有独特的行为模式；3）开放世界中的动态事件系统；4）车辆损坏和修理系统的交互设计。这些系统需要高度协同，开发成本不低。
