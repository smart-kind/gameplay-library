# Temple Run（Temple Run）

- **类型**: 休闲 / 无尽跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: Imangi Studios
- **首次发布**: 2011
- **一句话描述**: 在被怪物追逐的冒险中奔跑、跳跃、滑行、转弯，尽可能跑得更远

## 玩法规则

游戏以第三人称后方视角呈现。玩家控制的角色在一条不断向前延伸的古老神庙道路上奔跑，身后有一只可怕的怪物在追赶。画面自动向前推进，玩家无法停止。

操作分为四种：
- **向上滑动**: 跳跃，跳过地面上的障碍物或悬崖缺口
- **向下滑动**: 滑行，从低矮障碍物下方穿过
- **向左滑动**: 向左转弯或切换到左侧道路
- **向右滑动**: 向右转弯或切换到右侧道路

道路上会随机出现各种障碍——倒下的石柱、火焰、树根、缺口等。同时道路上散落着金币，角色碰到自动收集。

如果撞到障碍物且没有使用护盾，角色会摔倒，怪物追上，游戏结束。随着距离增加，奔跑速度会逐渐加快，考验反应能力。

## 核心循环

奔跑收集金币 → 闪避障碍物 → 速度加快 → 跑得更远

## 核心机制

- **自动前进**: 角色持续奔跑，玩家无法停止或减速，只能选择如何移动。这创造了持续的紧迫感。
- **四种手势操作**: 上跳、下滑、左转、右转。每种操作对应特定类型的障碍，玩家需要快速识别障碍类型并做出正确反应。
- **多路径选择**: 道路经常分叉，玩家需要在瞬间选择左、中、右哪条路，增加了决策维度。
- **速度递增**: 随时间推移奔跑速度逐渐加快，同一反应时间在不同阶段的结果不同，创造了自然的难度曲线。
- **金币收集**: 金币散落在路径上，有些需要冒险跳跃才能吃到，形成了风险与回报的权衡。

## 为什么好玩

"浓缩版印第安纳·琼斯"体验——在神庙中逃亡的紧张感配合简单直观的操作，让人欲罢不能。每次失败都让人想"再跑一次试试"。

## 粘性来源

- **速度递增的成就感**: 随着熟练度提高，能在更高的速度下存活更久
- **风险回报**: 为了吃更多金币而冒险跳跃，成功有满足感，失败有不甘
- **怪物追赶的紧迫感**: 永远在身后追赶的威胁创造持续紧张
- **高分挑战**: 无尽模式天然激发"打破个人纪录"的欲望

## Meta 系统

游戏内有角色解锁和升级系统。收集的金币可用于购买新角色和强化道具（磁铁、加速、护盾、金币倍增器）。每个道具在一次游戏中生效，属于消耗型外围系统。

## 实现难度

低到中。核心是无尽地形生成 + 碰撞检测 + 手势输入。难点在于性能优化——需要在移动设备上流畅渲染3D场景和动态地形生成。
