# 墨西哥卷饼野牛：自由发射（Burrito Bison: Launcha Libre）

- **类型**: 弹射 / 放置
- **平台**: Web (Flash) / Mobile
- **开发商**: JuicyBeast
- **首次发布**: 2013
- **一句话描述**: 把墨西哥卷饼野牛弹射出去，一路碾压糖果敌人并收集金币的休闲弹射游戏

## 玩法规则

玩家通过拖拽蓄力将野牛弹射出去，野牛在空中飞行一段距离后着陆。
着陆后野牛会自动向前奔跑，玩家可以点击屏幕让野牛跳跃。
在奔跑过程中，野牛会碾压沿途的糖果敌人（Gummy Bears等），每个敌人提供金币。
金币用于购买升级：弹射力度、跳跃高度、特殊能力等。
游戏中有各种道具和障碍物，收集道具获得额外金币，碰到障碍物会减速或停止。
游戏的目标是一次飞行+奔跑的总距离和收集的金币数量最大化。
解锁新角色和新能力后可以获得不同的游戏风格。

## 核心循环

弹射 → 碾压敌人收集金币 → 升级 → 弹得更远碾压更多敌人

## 核心机制

- 二段式玩法：弹射阶段（角度和力度控制）+ 奔跑阶段（跳跃时机控制），两个阶段都需要操作技巧
- 金币升级循环：每次飞行收集的金币用于强化下一次飞行，形成渐进成长感
- 角色解锁系统：不同角色有不同的特殊能力和外观，提供收集和尝试的动力

## 为什么好玩

卡通风格的幽默感贯穿始终——野牛用墨西哥卷饼的身体碾压糖果小人的画面充满喜感。弹射时的抛物线飞行和落地后的疯狂奔跑形成节奏变化，让人停不下来。

## 粘性来源

金币升级系统提供清晰的成长路径。"再弹一次就能买那个新升级了"的想法极具诱惑力。角色收集也增加了长期目标。

## Meta 系统

完整的升级系统：弹射力量、弹跳力、磁铁范围、特殊能力等多维度升级。角色解锁系统提供长期收集目标。

## 实现难度

中 — 需要物理弹射+跑酷跳跃两种机制结合，升级平衡和数值设计是关键难点


特殊道具包括磁铁（自动吸引附近金币）、火箭（短暂飞行冲刺）、护盾（抵挡一次碰撞）。
每个角色有独特的特殊技能，如野牛的角撞、辣椒的火球等。
游戏中有隐藏关卡入口，需要特定角度弹射才能进入。
敌人种类超过20种，从普通软糖到巨大的Boss级糖果。
