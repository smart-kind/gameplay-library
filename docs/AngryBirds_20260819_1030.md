# 愤怒的小鸟（Angry Birds）

- **类型**: 物理弹射 / 解谜 / 休闲
- **平台**: Mobile (iOS+Android) / PC / 主机
- **开发商**: Rovio Entertainment
- **首次发布**: 2009
- **一句话描述**: 用弹弓发射各种小鸟，利用物理弹道摧毁猪猪们搭建的建筑物，救出被绑架的鸟蛋。

## 玩法规则

游戏画面中，猪猪们躲在由木头、玻璃和石头搭建的结构后面，鸟蛋被藏在其中。玩家通过触摸屏幕拉动弹弓，调整发射角度和力度后松开，小鸟沿抛物线飞出。

每种小鸟有特殊能力，在飞行中点击屏幕可以触发：红色小鸟无特殊能力（基础弹射）；黄色小鸟可以加速冲刺；蓝色小鸟分裂成三只；黑色小鸟可以爆炸；白色小鸟可以下蛋炸弹。玩家需要在发射前选择合适的鸟种和发射顺序。

建筑物的三种材质有不同强度：玻璃最脆弱、木头中等、石头最坚固。玩家的目标是用有限数量的小鸟摧毁所有建筑物并消灭所有猪猪。

游戏按关卡推进，每关有星级评分（1-3星，基于剩余小鸟数量和分数）。解锁新章节获得新鸟种和新场景。

## 核心循环

观察结构 → 选择鸟种和角度 → 发射 → 触发特殊能力 → 评估破坏效果 → 调整策略 → 通关

## 核心机制

- **物理引擎**：游戏核心是真实的物理模拟——建筑物的重力、碰撞、倒塌都遵循物理规则。这使得每次发射的结果都是可预测但需要计算角度的，既保证了公平性又提供了策略深度。
- **鸟种能力**：每种鸟的特殊能力在关键时刻可以扭转局面。何时触发能力、瞄准哪个弱点，是玩家需要思考的核心问题。
- **材质弱点**：不同材质对不同的鸟种有不同的脆弱性，玩家需要根据建筑材料选择合适的攻击策略。
- **连锁反应**：摧毁关键支撑结构可以引发整栋建筑的连锁倒塌，这种"找到支点一击必杀"的快感是游戏最大的乐趣来源。

## 为什么好玩

看着精心搭建的建筑在自己发射的小鸟撞击下轰然倒塌，那种破坏的快感和物理引擎带来的真实感完美结合。每关都有"差一点就三星"的遗憾感，驱动玩家反复尝试。

## 粘性来源

- **三星挑战**：每关的三星标准鼓励玩家反复尝试，寻找最优解
- **物理谜题**：找到最佳发射角度和时机像解谜一样令人上瘾
- **新鸟种解锁**：每章解锁新鸟种，带来全新的玩法体验
- **短关卡**：每关30秒-2分钟，随时可以玩一把

## Meta 系统

- **章节解锁**：完成一定关卡数解锁新章节和新鸟种
- **成就系统**：完成特定挑战解锁成就
- **每日挑战**（后期版本）：每日更新的特殊关卡

## 实现难度

中 + 需要集成物理引擎（如Box2D），实现碰撞检测和物理模拟。最大难点在于关卡设计和物理参数调优，确保每个关卡都有解且解法有趣。
