# Spy 间谍推理（Spy）

- **类型**: 社交推理 / 派对 / 本地多人
- **平台**: Mobile (iOS+Android)
- **开发商**: Matvey Kavtorov
- **首次发布**: 2018
- **一句话描述**: 一款极简的社交推理派对游戏——一部手机在朋友间传递，找出隐藏的间谍

## 玩法规则

游戏需要3人以上的面对面聚会。只需要一部手机，玩家在朋友间轮流传递。

**游戏流程**：
1. **设置**：选择玩家数量（3+）和回合数。
2. **地点分配**：手机显示一个秘密地点（如"海滩"、"医院"、"太空站"）。第一位玩家查看屏幕后按下"我看了"。
3. **传递手机**：手机传给下一位玩家。所有玩家看到的都是同一个地点——除了其中一位，他看到的屏幕是"你是间谍"。
4. **继续传递**：直到所有玩家都看过屏幕。
5. **提问阶段**：从第一位玩家开始，每人轮流问其他玩家一个问题（如"这个地方冷吗？"、"你会穿什么去？"）。目的是确认彼此知道地点，同时找出间谍。
6. **间谍提问**：间谍可以在任何时候按下"间谍按钮"，提出一个关于地点的问题。
7. **投票**：讨论结束后，所有人投票选出谁是间谍。
8. **结果**：如果多数票选中了间谍，好人方赢；如果间谍成功隐藏或被误判，间谍方赢。

**核心张力**：知道地点的玩家需要在"证明自己知道"和"不透露太多给间谍"之间找平衡。问题太模糊无法证明自己，问题太具体则帮助间谍猜出地点。

## 核心循环

传递手机分配角色 → 互相提问 → 分析回答 → 投票找出间谍 → 揭晓结果

## 核心机制

- **极简规则**：规则一句话就能说明白——"找出不知道地点的人"。这种极简设计让任何人都能立刻参与。
- **信息不对称**：所有好人共享同一信息（地点），间谍没有。但间谍需要通过观察别人的行为来推断地点，这创造了有趣的"逆向推理"过程。
- **提问策略**：问题的设计是核心策略——太明显的问题帮助间谍，太模糊的问题无法证明清白。这种平衡感让每轮讨论都充满策略性。
- **面对面社交**：游戏完全依赖面对面的非语言线索——眼神、犹豫、笑容——这些微表情让推理更加有趣。

## 为什么好玩

Spy的快感来自于观察和欺骗的双重乐趣。好人在努力证明自己的同时不泄露信息，间谍在努力伪装的同时暗中推断地点。当间谍在最后一秒猜出地点并反转局势时，全场的惊呼声是无价的。

## 粘性来源

- **社交聚会必备**：几乎不需要任何准备，一部手机就能开局。
- **每次不同**：不同地点、不同玩家组合产生完全不同的游戏体验。
- **零门槛**：规则简单到任何人都能立刻参与，跨越年龄和语言障碍。

## Meta 系统

- **地点解锁**：通过游玩解锁更多地点类别。
- **自定义地点**：允许玩家添加自定义地点。

## 实现难度

低 — 核心逻辑极其简单（随机地点+随机间谍+投票）。最大难点在于设计足够多且有趣的地点（需要考虑不同文化背景下的可理解性）。
