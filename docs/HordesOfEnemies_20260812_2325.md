# 群敌之战（Hordes of Enemies）

- **类型**: 街机清版动作 / 节奏格斗
- **平台**: Mobile (iOS + Android)
- **开发商**: Silver Dollar Games
- **首次发布**: 2018
- **一句话描述**: 一款节奏感极强的触屏清版格斗游戏，玩家通过左右攻击和特殊技消灭一波又一波的敌人。

## 玩法规则

游戏画面采用简洁的横版视角，中央是玩家操控的角色，左右两侧不断涌来敌人。屏幕上分布着三个交互区域：左侧攻击按钮负责消灭从左方来的敌人，右侧攻击按钮消灭右方敌人，中间的特殊技按钮触发范围攻击。

操作极为简单——只需点击左、右或中间三个区域即可。但游戏允许玩家自定义这三个按钮在屏幕上的位置，玩家可以根据自己的手型和操作习惯调整布局，将按钮移到最舒服的位置。

每个敌人被消灭后会掉落金币和贡献分数。金币用于解锁新关卡和内容，分数则用于在排行榜上竞争。游戏共有三个不同的关卡场景，分别以电影院的三部电影为题材：第一部是武士题材，玩家扮演武士对抗敌人；第二部是僵尸题材，场景变为阴森的僵尸末日；第三部是科幻题材，画面风格突变。每个关卡在敌人攻击方式上有细微差别，但主要是视觉风格的变化。

游戏难度曲线非常陡峭。初期敌人出现缓慢，玩家轻松应对；但随着波次推进，敌人数量和攻击频率急剧增加，需要极快的反应速度。要达到 200 分以上需要高度集中注意力，几乎达到"心流"状态。

游戏的操作反馈非常直接——点击即攻击，攻击即消灭。没有复杂的连招系统，没有需要 memorize 的出招表，所有注意力都集中在"敌人从哪来"这个核心判断上。

## 核心循环

消灭敌人 → 获得分数和金币 → 解锁新关卡 → 挑战更高分和更密集的敌人波次

## 核心机制

- **方向攻击**: 敌人从左右两侧出现，玩家需在正确方向点击攻击，训练反应速度和方向判断能力
- **特殊技能**: 中间按钮触发全屏或大范围攻击，在敌人密集时一次清场，但有冷却或限制
- **自定义布局**: 三个按钮位置可调，让不同手型和操作习惯的玩家都能找到最佳体验
- **关卡解锁**: 通过游戏内金币逐步解锁三个不同主题的关卡，也可选择付费提前解锁
- **难度递增**: 敌人波次越来越密集，速度和攻击模式也更多样化，形成持续的挑战曲线

## 为什么好玩

游戏将极简操作与高难度挑战完美结合。一局游戏可能只持续几十秒，但"差一点就破纪录"的不甘心让人忍不住再来一局。武士、僵尸、科幻三种主题让重复游玩保持视觉新鲜感。操作门槛极低——任何人都能上手，但精通需要极高的反应速度。

## 粘性来源

主要粘性来自分数驱动的挑战欲——每次失败都会觉得"下一次我能做得更好"。关卡解锁提供了短期目标，而排行榜则提供长期竞争动力。极简操作意味着随时可以开始一局，没有学习门槛。游戏的节奏感和打击反馈也让人上瘾——消灭敌人时的视觉和听觉反馈非常爽快。

## Meta 系统

游戏内金币系统：通过消灭敌人获得金币，用于解锁三个关卡（也可付费跳过）。解锁后为纯体验向，无数值成长或角色强化系统。

## 实现难度

低。核心逻辑只需处理三个输入方向和敌人的左右位置判定。最大技术难点在于大量敌人同屏时的性能优化和流畅的动画表现，以及自定义按钮位置的保存和加载。
