# Bejeweled（Bejeweled）

- **类型**: 三消匹配
- **平台**: Web (Flash/HTML5) / Mobile (iOS+Android) / PC
- **开发商**: PopCap Games
- **首次发布**: 2001（最初名 Diamond Mine）
- **一句话描述**: 交换相邻宝石实现 3+ 连消，在步数或时间耗尽前获得最高分——三消品类的开山鼻祖

## 玩法规则

游戏画面是 8x8 的网格，网格中随机填充 7 种颜色的宝石。玩家每次交换两个相邻宝石（上下左右）的位置。

如果交换后形成 3 个或以上相同颜色的宝石连成一线（横或竖），这些宝石消除，上方的宝石落下填补空格。新宝石从顶部随机生成落下。

消除 4 个 = 产生"火焰宝石"（消除后爆炸 3x3 区域），消除 5 个 = 产生"超级宝石"（消除后清除全棋盘同色宝石）。这些特殊宝石的制造和组合是高分的关键。

经典模式下，当无法再移动（没有可形成 3 连的交换）时，棋盘自动洗牌。玩家的目标是在步数耗尽或时间到之前获得尽可能高的分数。

## 核心循环

观察棋盘 → 寻找可交换的宝石 → 执行消除 → 触发连锁 → 获得分数 → 制造特殊宝石 → 冲击更高分

## 核心机制

- 机制1：基础三消——交换两个相邻宝石，3+ 同色连成一线即消除。规则极其简单，任何人 10 秒内就能理解
- 机制2：连锁反应（Cascading）——消除后上方宝石落下，可能自动形成新的匹配，产生连续消除。一次操作触发多次消除是高分来源
- 机制3：特殊宝石——4/5 连消产生威力更强的特殊宝石，玩家会有意去制造它们。特殊宝石的爆炸效果提供了额外的视觉爽感

## 为什么好玩

"消除"本身的爽感是人类大脑的天然奖励——整齐、秩序、清理。Bejeweled 把这种最简单的快感做到了极致。同时，"找到一步好棋"带来的成就感让游戏超越了纯运气，有了一定的策略性。

## 粘性来源

高分驱动（自我挑战：每次都想打破自己的纪录）+ 特殊宝石的视觉爽感 + 多模式选择（经典/禅/闪电/蝴蝶/扑克等）

## Meta 系统

多模式系统 + 等级经验（累积分数提升等级）+ 成就系统。没有复杂的养成线，核心就是"玩得越多，分数越高，等级越高"。

## 实现难度

低。网格匹配算法 + 简单的重力/填充逻辑。这是"最容易实现的休闲游戏"之一——核心代码可能不到 1000 行。难点在于关卡/模式设计和宝石落下的动画流畅度。
