# 深岩银河：幸存者（Deep Rock Galactic: Survivor）

- **类型**: 肉鸽生存 / 射击
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Ghost Ship Games / Funday Games
- **首次发布**: 2025
- **一句话描述**: 基于《深岩银河》IP的幸存者类游戏，玩家控制矮人在地下矿洞中对抗虫群。

## 玩法规则

玩家控制一名矮人矿工，在2D或俯视角的地下洞穴中自动射击靠近的虫群敌人。

屏幕上只有一个虚拟摇杆控制移动方向，角色的武器自动向最近的敌人开火。击杀敌人后掉落经验宝石，拾取后升级时从3个随机选项中选择一项升级。

升级选项包括：增加武器伤害、射速、弹道数量、暴击率、移动速度、生命回复、添加新武器类型等。

洞穴中会随机出现矿脉，靠近时可以自动采集矿物，矿物用于升级永久天赋（跨局成长）。

随着时间推移，虫群密度和强度递增，最终会在特定时间点（如5分钟、10分钟）出现Boss级虫群。存活到时间结束或击败Boss即通关。

## 核心循环

进入洞穴对抗虫群 → 击杀升级选择能力 → 采集矿物 → 通关或阵亡 → 用矿物升级永久天赋

## 核心机制

- 武器构建系统：通过每局的随机升级选项，可以构建出完全不同的武器流派（弹幕流、单发高伤流、召唤流等）
- 动态虫群系统：敌人从四面八方涌来，不同虫类有不同行为模式（自爆虫、飞行虫、重型甲壳虫），需要灵活走位
- 永久天赋树：用收集的矿物升级跨局天赋（初始武器、基础属性解锁），提供肉鸽游戏特有的长期成长感

## 为什么好玩

幸存者类游戏的'再来一局'魔力——每次升级选项不同，每局体验都不同。看着自己从一把小手枪成长为满屏弹幕的毁灭机器，成就感极强。虫海涌来的压迫感和火力全开的爽快感形成强烈对比。

## 粘性来源

随机升级选项带来的不可预测性；永久天赋树的长期成长目标；武器流派的探索欲望（'如果选这条路线会怎样'）；每局仅需10-15分钟的短时长适合碎片时间。

## Meta 系统

永久天赋树：用矿物解锁和升级天赋。角色解锁：通关后解锁新矮人职业，各有不同初始武器。武器图鉴：记录所有解锁过的武器和升级组合。

## 实现难度

中 — 幸存者类游戏框架已成熟，但需要处理大量同屏敌人和弹道。最大难点是性能优化——成百上千个敌人同时存在时的帧率保证。
