# Orbital Defender（Orbital Defender）

- **类型**: 休闲 / 街机
- **平台**: Mobile (iOS)
- **开发商**: Nakarda Richards
- **首次发布**: 2026
- **一句话描述**: 玩家通过旋转轨道上的陨石来偏转来袭威胁，保护中心核心的独特街机游戏

## 玩法规则

游戏画面中心有一个核心（星球或类似物体），周围有若干陨石沿着圆形轨道环绕旋转。屏幕上方的威胁物（小行星、敌机等）会从各个方向朝核心飞来。

玩家不能直接移动核心，而是通过触屏滑动来控制陨石的旋转方向和速度。当陨石与来袭威胁物碰撞时，威胁物被弹开或摧毁。每次成功拦截都获得分数。

游戏的目标是尽可能长时间地保护核心不被击中。随着游戏进行，威胁物的数量和速度会增加，轨道上可能需要管理多个陨石，使得拦截策略变得复杂。

当核心被威胁物击中一定次数（通常是生命值耗尽）后，游戏结束。玩家获得最终分数，可以尝试打破自己的最高分记录。

## 核心循环

旋转陨石拦截威胁 → 获得分数 → 面临更多更快威胁 → 继续拦截直到失败

## 核心机制

- **旋转轨道操控**：玩家只能控制陨石的旋转（而非直接移动陨石），这创造了一种间接操控的独特手感。玩家需要预判威胁物的飞行轨迹，提前调整陨石位置
- **动量碰撞**：陨石与威胁物的碰撞遵循简单的物理规则，弹射角度取决于碰撞时的相对位置和速度
- **渐进难度**：随时间推移，威胁物频率和速度递增，迫使玩家不断提升反应速度和预判能力

## 为什么好玩

这种"不能直接控制，只能通过旋转轨道间接干预"的设计非常新颖，给玩家一种"指挥天体运动"的爽快感。当陨石恰到好处地弹开一连串威胁物时，那种连锁反应带来的满足感很强。

## 粘性来源

核心粘性来自"差一点就能做得更好"的不甘心——每次游戏结束时玩家都会觉得"再多转半圈就能拦截那个"。分数驱动的重试欲望+简单直观的操作让再来一局变得非常容易。

## Meta 系统

无

## 实现难度

低 — 2D圆形轨道运动+简单碰撞检测，最大技术难点是流畅的手势识别和旋转响应，以及威胁物生成的难度曲线调校
