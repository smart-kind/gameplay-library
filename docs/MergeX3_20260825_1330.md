# Merge X3

- **类型**: 合并解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Funvent Studios DMCC
- **首次发布**: 2020
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

放置数字方块到棋盘 -> 三个相同数字相邻合并为更高数字 -> 清空棋盘获得高分

## 核心机制

- **三合一合并规则**: 与传统的两个合并不同，Merge X3要求三个相同数字相邻才能合并。这增加了策略难度，玩家需要精确规划才能触发合并。
- **连锁反应**: 合并产生的新数字可能与周围方块形成新的三合一组合，产生连锁反应。连锁反应带来大量分数和视觉快感。
- **棋盘空间管理**: 有限的棋盘空间要求玩家在放置方块时就考虑后续的合并可能。错误放置会阻塞关键位置，导致后续无法合并。

## 为什么好玩

三合一的规则比传统二合一更具挑战性，每次成功触发合并都有更强的成就感。连锁反应的设计让一次好的放置能带来连锁的爽快感。

## 粘性来源

粘性来源于三合一规则带来的策略深度和连锁反应的爆发快感。

## Meta 系统

- 得分系统：合并和连锁反应获得分数
- 对核心玩法的影响：高分目标驱动策略优化

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
