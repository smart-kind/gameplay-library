# Yarn Loop: Knit Puzzle（Yarn Loop: Knit Puzzle）

- **类型**: 益智解谜 / 休闲放松
- **平台**: Mobile (iOS+Android)
- **开发商**: Combo Yazilim Anonim Sirketi
- **首次发布**: 2025
- **一句话描述**: 以编织为主题的色彩匹配益智游戏

## 玩法规则

游戏画面中央展示一幅未完成的针织图案网格，网格中的每个格子代表一种颜色的针脚。画面底部或侧面有一条传送带，传送带上排列着不同颜色的线轴（Bobbin）。每个线轴上标注着容量数值（如5、8、10等）。

玩家的操作流程如下：将传送带上的线轴拖动到针织图案上，线轴会自动收集与其颜色相同的针脚。每收集一个针脚，线轴的容量值减1。当容量值归零时，该线轴消失；如果还有剩余容量，线轴会被送回架子，可以在后续关卡中再次使用。

游戏目标是使用正确的线轴顺序和颜色匹配，完成整幅针织图案。由于每个线轴的容量有限，玩家需要策略性地规划使用顺序——先用完小容量线轴，还是保留大容量线轴应对后续关卡。

## 核心循环

观察针织图案 -> 选择线轴收集同色针脚 -> 线轴容量归零消失 -> 完成整幅图案过关

## 核心机制

- 容量管理机制：每个线轴有有限的容量值，玩家需要在快速用完和保留备用之间做策略选择，增加了游戏的决策深度
- 色彩匹配加空间规划：不仅要匹配颜色，还要考虑线轴在传送带上的位置顺序和容量分配，是一个多维度的策略解谜
- 渐进式难度曲线：关卡从简单的2-3种颜色开始，逐步增加到多种颜色和复杂的线轴容量组合，难度自然递增

## 为什么好玩

将编织这一传统手工艺转化为数字益智游戏，色彩搭配本身具有视觉愉悦感，加上解谜的策略性，形成了一种安静的成就感。适合喜欢有条不紊解决问题的玩家。

## 粘性来源

色彩匹配的视觉满足感（完成图案后的成就感）、策略规划的深度（线轴容量管理增加决策层）、渐进式难度（从简单到复杂自然过渡）、单手操作友好（所有操作只需拖拽，适合放松场景）

## 操作细节补充

- 启动后直接进入游戏选择界面，无需强制注册或登录
- 部分游戏支持横竖屏切换，但大多数默认竖屏单手操作
- 网络依赖程度因游戏类型而异，纯单机小游戏可完全离线游玩

## Meta 系统

无传统外围成长系统。部分游戏可能包含社交分享、排行榜或成就系统，但核心体验围绕轻游戏集合。

## 实现难度

中 — 聚合平台本身不难，但需要独立设计多款不同的小游戏，每款都需要完整的玩法逻辑和交互设计。最大技术难点在于保持所有小游戏统一的操作范式和质量标准，同时确保App整体性能在低端设备上流畅运行。
