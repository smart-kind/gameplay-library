# Bullet Rush!

- **类型**: 动作射击
- **平台**: Mobile (iOS)
- **开发商**: Voodoo
- **首次发布**: 2020
- **评分**: ⭐ 4.6/5 (57,927 评价)
- **价格**: Free
- **一句话描述**: Voodoo出品的快节奏射击游戏，可爱的画面下是激烈的弹幕战斗，控制角色移动并消灭数百敌人。

## 玩法规则

游戏采用俯视角3D画面。玩家控制一个角色在场景中移动，角色会自动向最近的敌人射击（自动瞄准）。玩家通过虚拟摇杆控制移动方向。敌人从四面八方涌来，形成弹幕式的攻击。玩家需要躲避敌人子弹的同时消灭它们。消灭敌人后获得金币/经验，可以升级武器伤害、射速、移动速度等属性。场景中有障碍物可以作为掩体。界面包含：角色血量条、经验条、当前武器信息、金币计数。

## 核心循环

控制角色移动射击 → 消灭敌人获得金币 → 升级属性 → 面对更多敌人

## 核心机制

- 自动射击+手动移动：降低操作门槛，专注于走位和躲避
- 弹幕式敌人：敌人从四面八方涌来，需要灵活的走位
- 属性升级：金币可升级伤害、射速、移速等，提供成长感

## 为什么好玩

Voodoo标志性的"简单但上瘾"设计。可爱的画风与激烈的弹幕形成反差。走位躲避的紧张感让人停不下来。

## 粘性来源

属性升级的成长感、弹幕战斗的紧张感、关卡/波次渐进难度

## Meta 系统

角色/武器解锁系统、属性升级永久加成（roguelike元素）。

## 实现难度

低——Voodoo成熟的超休闲游戏模板，技术实现成熟
