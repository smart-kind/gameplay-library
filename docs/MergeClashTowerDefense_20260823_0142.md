# 合并塔防：冲突（Merge Clash: Tower Defense）

- **类型**: 塔防 / 合并策略
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 2020
- **一句话描述**: 将两个相同的防御塔合并成更高级的塔，用策略部署抵御无尽敌潮的多人塔防游戏

## 玩法规则

游戏界面中央是战场地图，敌人从入口沿固定路线走向终点。玩家在地图边缘或指定区域部署防御塔。每座塔都有等级（通常从1级开始），同等级相同的两座塔可以**合并**为一座高一级的塔。

合并是核心操作：两座1级塔→一座2级塔，两座2级塔→一座3级塔，依此类推。高等级的塔拥有更强的攻击力、更广的攻击范围和更特殊的能力。玩家需要在合并（追求质量）和分散部署（追求覆盖范围）之间做出策略选择。

敌人按波次进攻，每波数量和种类逐渐增加。特殊敌人包括高血量坦克型、快速移动型、飞行单位等。游戏目标是阻止敌人到达终点，漏掉过多敌人则游戏失败。

## 核心循环

获得防御塔 → 部署到战场 → 合并升级 → 抵御敌潮 → 获得奖励 → 解锁新塔和更多部署位

## 核心机制

- **合并升级机制**：两个相同等级的塔合并为一个高一级塔，减少了管理复杂度同时增强了战力
- **波次递增机制**：每波敌人数量和强度逐步提升，要求玩家不断优化防御布局
- **多人对战**：部分模式下与其他玩家竞争，比较谁能坚持更久或谁能突破对方防线
- **塔的类型多样性**：不同类型的塔有不同攻击方式（单体、范围、减速、穿透），组合策略丰富

## 为什么好玩

合并操作带来"合成进化"的满足感——看着两座弱小的塔合体变成强力武器，这种成长反馈非常直接且上瘾。同时需要不断在"合"与"分"之间做策略取舍。

## 粘性来源

**合并的爽感**：每次成功合成高级塔都有一次小高潮。**策略深度**：塔的排列、合并时机、资源分配都需要思考。**竞技对抗**：与其他玩家比较谁坚持得更久，激发竞争欲。

## Meta 系统

外围成长系统：
- **塔的收集**：解锁不同类型的防御塔（弓箭手、法师、炮台等）
- **玩家等级**：提升解锁更多部署位和新塔类型
- 对核心玩法的影响：收集更多塔类型让策略组合更加丰富多样

## 实现难度

中。塔防逻辑本身不复杂，但需要处理塔的AI寻路、攻击判定和大量敌人的性能优化。合并系统的UI交互需要流畅直观。最大难点是关卡难度曲线的精细调校。
