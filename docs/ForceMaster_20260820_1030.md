# Force Master

- **类型**: 物理动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2020
- **一句话描述**: 利用超能力抓取场景中的物体，将其掷向敌人，通过物理连锁反应解决关卡难题

## 玩法规则

游戏的核心界面是横向排列的关卡场景，玩家可以自由操控一个拥有"原力"能力的角色。场景中分布着敌人、可抓取物体（箱子、爆炸桶、平台碎片等）和障碍物。玩家通过按住屏幕选择目标物体，拖拽瞄准方向，松手将其掷出。

被掷出的物体按照物理引擎轨迹运动——击中敌人造成伤害，砸到爆炸桶引发爆炸，撞到平台使其崩塌。玩家可以在一个关卡中使用多个物体进行连锁攻击，也可以用敌人本身作为投掷武器去打倒其他敌人。

每个关卡有明确的过关条件——通常是消灭所有敌人或到达指定出口。失败后可以立即重试，没有等待时间。关卡由简入难，早期关卡教授基本操作，后期关卡需要利用物理连锁反应进行策略性攻击。

玩家的每次投掷力度和角度都影响最终效果，需要判断抛物线轨迹。场景中不同物体有不同的物理属性——爆炸桶被击中后会爆炸并影响周围区域，沉重的箱子可以压垮脆弱的地板，轻的木板可以被用来搭建临时桥梁。

## 核心循环

抓取场景物品 → 投掷攻击敌人 → 利用物理效果过关 → 获得星级评价解锁下一关

## 核心机制

- **物理抓取投掷**：按住屏幕抓取场景中的物体，松手将其掷向敌人或目标，利用物理引擎产生连锁反应
- **环境互动**：爆炸桶、可破坏平台、可移动障碍物等场景元素都是武器的一部分，玩家需要创造性地利用一切可用资源
- **连锁反应**：一次精准投掷可以引发多米诺骨牌式的连锁效果——炸倒一片敌人、砸塌平台、让敌人掉入陷阱等
- **抛物线预判**：投掷物沿抛物线轨迹运动，玩家需要在投掷前预判落点，考虑重力、物体重量和空气阻力的影响

## 为什么好玩

物理引擎带来的意外性和创造性——每次投掷都可能产生意想不到的连锁效果，让人兴奋。Voodoo标志性的简洁设计让操作毫无门槛，但关卡设计提供了足够的策略深度。

不同关卡中物体的种类和布局千变万化，玩家每次都需要重新思考最优解，保持了持续的新鲜感。

## 粘性来源

物理连锁反应的"爽感反馈"——当一次精心策划的投掷引发一连串爆炸和倒塌时，成就感极强；关卡短小精悍，适合碎片化游玩

## Meta 系统

关卡解锁系统——完成当前关卡解锁下一关；星级评分——根据通关效率和使用的投掷次数获得1-3星评价

## 实现难度

中 — 物理抓取和投掷需要稳定的物理引擎支持，最大技术难点是碰撞检测的准确性和连锁反应的性能优化。需要处理大量物体的同时物理模拟，确保帧率稳定
