# 聚光灯：密室逃脱（Spotlight: Room Escape）

- **类型**: 解谜 / 逃脱 / 找物
- **平台**: Mobile (iOS+Android)
- **开发商**: Aleksei Aro
- **首次发布**: 2016
- **一句话描述**: 在昏暗的房间中使用手电筒探索，寻找线索并解开谜题逃脱的沉浸式解谜游戏。

## 玩法规则

玩家置身于一个昏暗的房间中，视野受限——只有手电筒照射的区域是明亮的。手电筒跟随玩家的手指/鼠标移动，需要主动探索才能看清房间的各个角落。

在照亮区域中，玩家可以发现可交互的物品：抽屉、画框、保险箱、书架、地板等。点击物品可以检查细节——翻开抽屉、打开保险箱、移动家具等。

每个房间中隐藏着逃离所需的线索：密码数字、钥匙、机关触发器等。线索通常被巧妙隐藏——在书本之间、画框背后、地板缝隙中。部分线索需要组合使用：一个地方的数字提示+另一个地方的操作=解谜。

某些房间设有时间限制或资源限制（如手电筒电池有限），增加了紧张感。找到正确的逃离方式后，门打开进入下一关。

## 核心循环

用手电筒探索房间 → 发现可交互物品 → 收集线索 → 解开谜题逃脱

## 核心机制

- 有限视野机制：手电筒照明限制让探索变成'未知的冒险'。你不知道黑暗区域有什么，这种'看不见'的紧张感是传统找物/逃脱游戏所没有的。
- 线索拼图机制：不同位置发现的线索需要玩家自己建立关联——A处的数字可能是B处保险箱的密码，C处的图案暗示D处的操作方式。这种'拼图式'思维让解谜过程有参与感。
- 资源限制机制：手电筒电池、时间限制等资源约束增加了紧迫感，迫使玩家在'仔细搜索'和'快速行动'之间做权衡。
- 沉浸式氛围机制：昏暗环境+手电筒探索+安静音效营造了独特的沉浸氛围。这种氛围本身就是游戏体验的一部分，不同于明亮欢快的休闲游戏。

## 为什么好玩

手电筒探索的未知感让每个角落都可能藏着线索或惊喜，这种'发现'的快感被黑暗放大了。氛围营造出色——安静、昏暗、专注，像是在真正探索一个神秘房间。

## 粘性来源

未知驱动——黑暗中的未知感让人好奇'下一束光会照到什么'。每个房间逃脱后的'原来如此'满足感和对下一关的好奇形成持续动力。

## Meta 系统

房间/关卡解锁制，每完成一组房间解锁新主题（如废弃医院、古宅、地下室等）。无复杂外围系统，纯内容消耗型。

## 实现难度

中等到偏高。需要实现手电筒光照效果和阴影渲染，技术门槛高于普通2D解谜。最大难点在于氛围和难度的平衡——太恐怖不适合休闲玩家，太轻松又失去独特性。


手电筒机制从根本上改变了找物游戏的节奏——玩家不能一眼看到全貌，必须一寸一寸地探索。这种受限视野让每个发现都更有价值，因为你是'主动'找到的而不是'被动'看到的。黑暗中的探索还带来一种独特的紧张感，不同于传统找物游戏的轻松氛围。
