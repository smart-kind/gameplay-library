# Mewgenics

- **类型**: Roguelike / 怪物收集
- **平台**: PC
- **开发商**: ConcernedApe (Eric Barone)
- **首次发布**: 2026
- **一句话描述**: 星露谷物语作者的新作，首周销量百万，超越 Hades 2 的 Steam 同时在线峰值。

## 玩法规则

结合怪物收集和 Roguelike 元素——玩家捕捉、培养和使用各种生物进行战斗。每局游戏从选择初始生物开始，在程序生成的地牢中探索、战斗和收集新生物。

战斗系统结合回合制策略和实时元素——玩家需要选择合适的生物应对不同敌人，利用属性克制和技能组合取得优势。生物可以通过战斗获得经验升级，学习新技能。

作为 ConcernedApe 的作品，游戏预计继承了星露谷物语的精致打磨和深度内容——尽管是 Roguelike 类型，但生物收集和培养的 meta 系统提供了长期进度感。

## 核心循环

选择生物 → 探索地牢 → 战斗和收集新生物 → 培养和进化

## 核心机制

- 怪物收集：捕捉和培养各种生物
- Roguelike 地牢：程序生成的关卡，每次不同
- 属性克制：生物之间的属性相克系统
- 技能组合：生物学习多种技能，搭配策略丰富
- Meta 进度：生物收集和培养提供长期目标

## 为什么好玩

星露谷物语作者的 Roguelike 首秀，品质保证。生物收集 + Roguelike 的组合既有每局的新鲜感又有长期的收集目标。

## 粘性来源

- 生物收集欲：数百种不同生物等待发现和培养
- Roguelike 随机性：每局地牢和遭遇都不同
- 技能搭配策略：不同生物技能组合产生丰富战术
- 作者品质保证：ConcernedApe 的打磨水准

## Meta 系统

生物收集和培养。解锁新生物、提升生物等级、学习新技能。

## 实现难度

中。生物平衡和 Roguelike 关卡生成是主要难点。数百种生物的数值平衡需要大量测试。
