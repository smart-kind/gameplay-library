# Tiny Run 3D

- **类型**: 休闲跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: MondayOFF
- **首次发布**: 2021
- **一句话描述**: 极简3D平台跑酷，精准跳跃通过不断变化的平台阵列

## 玩法规则

游戏采用3D俯视角。小角色自动在各种平台上奔跑，玩家通过点击控制跳跃。

平台之间有间隙，需要精确把握跳跃时机才能安全通过。跳早或跳晚都会坠落导致失败。

关卡设计精巧，平台形状和位置不断变化。从简单的等间距平台到复杂的变间距、变高度平台阵列。

后期关卡有移动平台、旋转平台等增加难度。移动平台的位置随时间变化，需要预判落地时机。旋转平台的角度持续变化，增加了跳跃时机的不确定性。

每局约1-2分钟，操作简单（只需点击跳跃）但需要良好的时机把握。

## 核心循环

点击跳跃 → 精确通过平台间隙 → 到达终点 → 解锁新关卡

## 核心机制

- **跳跃时机系统**: 需要在恰当的时机点击跳跃，跳早或跳晚都会坠落。不同间距的平台需要不同的跳跃时机。掌握节奏感是过关的关键。
  （节奏感）
- **平台多样性设计**: 静止平台、移动平台、旋转平台等，每种需要不同的应对策略。移动平台需要预判位置，旋转平台需要把握角度。
  （变化性）
- **关卡递进设计**: 从简单到复杂，平台间距、数量、类型逐步增加。后期关卡综合运用多种平台类型，考验玩家的综合能力。
  （难度曲线）

## 为什么好玩

极简的操作和精巧的关卡设计形成对比。每次完美通过一连串平台都有很强的成就感。MondayOFF的关卡设计一贯精妙。

## 粘性来源

精准跳跃的技术成长感、关卡设计的精巧感、'差一点就成功'的不甘心。'再来一次我一定能过'的心理驱动持续游玩。

## Meta 系统

解锁新角色和关卡，无深度成长系统。

## 实现难度

低 — 3D平台跑酷，技术成熟。主要是关卡设计的工作量。
