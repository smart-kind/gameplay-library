# Tomb Breaker

- **类型**: 动作 / 冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款古墓探险主题的动作游戏，玩家在古墓中躲避陷阱、收集宝藏并逃离

## 玩法规则

游戏呈现一个横向滚动的古墓场景。玩家角色在墓穴中自动向前奔跑，速度恒定。

玩家通过点击屏幕执行操作：点击=跳跃，长按=蓄力高跳（跳过更宽深坑），下滑=滑铲（通过低矮通道）。需要在奔跑中躲避各种陷阱——地刺（跳避）、落石（滑铲或跳跃）、摆锤（把握时机通过）、深坑（跳跃）。

古墓中散布着宝藏和金币。收集宝藏获得分数，金币用于解锁新角色和皮肤。部分宝藏位于危险位置，需要精准操作才能安全获取。

部分关卡有BOSS战——需要按特定节奏躲避BOSS的攻击并找到反击机会。BOSS攻击有明显前摇提示。

游戏设有每日挑战模式，每天提供一条固定路线的墓穴，所有玩家面对相同的陷阱排列。每日挑战有独立排行榜。

## 核心循环

奔跑躲避陷阱 → 收集宝藏 → 逃离古墓获得分数

## 核心机制

- **跑酷操作**：跳跃/滑铲的时机判断，考验反应速度
- **陷阱多样性**：不同类型陷阱需要不同应对方式
- **BOSS战**：节奏性躲避+反击

- **每日挑战**：固定路线，独立排行榜


## 为什么好玩

古墓探险的紧张氛围配合快节奏的跑酷操作。成功通过一连串陷阱的成就感很强。

## 粘性来源

跑酷游戏的标准粘性：每次'差一点就跑完全程'驱动再来一局。收集目标提供长期动力。

## Meta 系统

角色解锁：用金币解锁不同探险角色和皮肤。

## 实现难度

中 — 需要良好的反应速度。最大技术难点是陷阱的时序生成和碰撞检测。
