# 王权：超越（Reigns: Beyond）

- **类型**: 卡牌/策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Nerial（Netflix）
- **首次发布**: 2026
- **一句话描述**: Reigns 系列太空主题新作，通过左右滑动卡牌做出决策来管理太空帝国。

## 玩法规则

卡牌决策游戏，玩家扮演太空帝国的统治者。每回合出现一张卡牌，上面有一个人物或事件向你提出请求或问题。你可以向左滑动（拒绝）或向右滑动（同意），每个选择会影响四个指标：国库、军队、民众和教会（太空版对应指标）。

任一指标归零或满值都会导致游戏结束（死亡），目标是尽可能长时间地维持平衡，同时推进故事线。太空主题引入了飞船、外星种族、星际政治等新元素。

## 核心循环

抽取事件卡牌 → 左右滑动做决策 → 平衡四项指标 → 推进故事 → 解锁新事件和角色

## 核心机制

- 滑动决策：每张卡牌左滑/右滑两种选择，影响不同指标
- 四维平衡：维持多个指标在安全范围内，任一极端即失败
- 叙事推进：特定卡牌序列触发故事事件和角色剧情

## 太空主题创新

相比前作的中世纪设定，本作将舞台搬到了太空。玩家管理的是一个星际帝国而非封建王国，决策涉及外星外交、太空探索、星际战争等主题。

卡牌内容包含太空时代的角色：外星大使、星际海盗、殖民地总督等。每个角色都有独特的请求和后果。

## 为什么好玩

Reigns 系列标志性的'一句话决定命运'玩法，太空主题带来全新故事和决策场景。简单易上手但决策充满张力。

## 粘性来源

追求更长的存活记录和解锁所有故事线/结局。每次死亡都是一次有趣的故事体验。
