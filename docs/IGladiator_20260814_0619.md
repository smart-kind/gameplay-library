# I, Gladiator

- **类型**: 格斗 / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: DeNA / Crescent Moon Games
- **首次发布**: 2012
- **一句话描述**: 一款古罗马角斗士主题的动作格斗游戏，玩家通过手势操控角斗士与各种敌人战斗

## 玩法规则

游戏呈现一个角斗场的3D视角。玩家控制一名角斗士，对手是另一名角斗士或怪物。

玩家通过在屏幕上划出特定手势来执行攻击：横向滑动=横斩，纵向滑动=劈砍，画圈=旋转攻击，双击=突刺。手势的方向、速度和准确度影响攻击效果和伤害。

对手有攻击、防御、闪避等AI行为。玩家需要观察对手动作前摇，在合适的时机发起攻击或举盾防御。防御成功可以反击，造成额外伤害。

战斗胜利获得金币和经验。金币用于购买更好的武器和护甲，经验用于提升角色等级和解锁新手势。游戏包含多种武器类型（剑、斧、矛等），每种有独特的手势系统和攻击范围。

游戏设有竞技场排名系统，玩家在PvP对战中提升排名可获得特殊奖励。赛季制排名每季度重置。

## 核心循环

划出手势攻击对手 → 胜利获得资源 → 升级装备解锁新手势

## 核心机制

- **手势识别**：通过屏幕滑动方向识别攻击类型，增加操作沉浸感
- **武器差异**：不同武器有不同手势系统，切换武器改变操作方式
- **AI对手**：敌人有不同行为模式，需要适应性策略

- **竞技场排名**：PvP对战提升赛季排名


## 为什么好玩

手势操控让格斗操作更有参与感。古罗马角斗场的氛围营造出色。

## 粘性来源

装备升级+角色成长的标准RPG粘性。解锁新手势和武器的目标感。

## Meta 系统

装备系统：购买和升级武器、护甲。角色等级：通过战斗提升等级解锁新能力。

## 实现难度

中 — 手势识别需要一定精度。最大技术难点是准确的手势识别和3D战斗动画。
