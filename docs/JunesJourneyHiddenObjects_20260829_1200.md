# 琼的旅程：寻物冒险（June's Journey: Hidden Objects）

- **类型**: 寻物解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: wooga
- **首次发布**: 2017
- **一句话描述**: 以1920年代为背景的寻物解谜冒险游戏，在精美场景中寻找线索揭开谋杀谜案

## 玩法规则

游戏呈现华丽的1920年代装饰艺术风格画面，每个场景都是一幅精心绘制的插画，包含大量物品和角色。

玩家需要在场景中找到列表中指定的隐藏物品——有些物品直接可见，有些需要与场景中的元素互动后才能出现（如打开抽屉、移开窗帘）。

除了寻物玩法，游戏还包含岛屿建设元素：使用解谜获得的星星来修复和装饰岛屿上的建筑。

剧情以1920年代谋杀案为故事主线，围绕主角June的家族秘密展开。每章揭示新线索和角色关系。

岛屿上每个区域有多个修复阶段，逐步恢复岛屿昔日的辉煌。修复的视觉反馈让玩家的努力有形的体现。

## 核心循环

在精美场景中寻找隐藏物品 → 收集星星 → 用星星修复和装饰岛屿建筑 → 推进剧情解锁新章节

## 核心机制

- 互动式寻物机制：不同于静态寻物，部分物品需要与场景互动才能发现（打开柜子、移动物品），增加了参与感
- 岛屿建设系统：解谜获得的星星可用于修复建筑、装饰花园、解锁新区域。从破败到修复完成的变化提供了强烈的视觉反馈
- 章节叙事：以1920年代谋杀案为故事主线，每章揭示新线索和角色关系

## 为什么好玩

1920年代的华丽视觉风格让人仿佛穿越到爵士时代，精美的手绘场景本身就是艺术享受。

悬疑故事驱动持续探索。

岛屿建设的视觉反馈让玩家的努力有形的体现——看着荒废的岛屿一步步变成繁荣的社区，这种从破败到繁荣的蜕变过程本身就是最大的乐趣来源。

## 粘性来源

岛屿建设的视觉反馈让玩家看到自己的进步成果——从荒岛到繁荣社区的转变过程令人满足

## Meta 系统

岛屿建设系统：修复和装饰岛上各区域，每个区域有多个升级层级。建设不仅是装饰，也是故事的一部分

## 实现难度

低 — 寻物玩法门槛低，适合休闲玩家。最大的技术难点在于场景美术质量和大量手绘内容制作
