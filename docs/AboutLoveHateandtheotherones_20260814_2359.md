# About Love, Hate and the other ones

- **类型**: 冒险/叙事解谜
- **平台**: Mobile (iOS)
- **开发商**: Black Pants Studio GmbH
- **首次发布**: 2012
- **一句话描述**: 一款探索情感主题的叙事冒险解谜游戏

## 玩法规则

游戏以情感（爱、恨等）为核心主题，玩家通过解谜和探索来推动故事。画面采用抽象艺术风格，场景设计充满象征意义。

玩家控制角色在不同场景中探索，收集线索并解决谜题。某些谜题需要操控角色的情感状态（爱/恨），影响可交互的对象。

游戏分为多个章节，每章探索一种情感。界面简洁，主要 focus 在场景和角色交互上。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

探索场景解谜 → 理解情感故事 → 进入新章节

## 核心机制

- 情感操控机制：切换角色情感状态来改变环境和交互
- 叙事解谜：谜题与故事紧密结合，解谜即理解故事
- 抽象艺术风格：画面和音乐营造独特的氛围

## 为什么好玩

深刻的情感主题搭配独特的艺术风格，是一次不同于常规游戏的体验。

## 粘性来源

故事悬念和情感共鸣。

## Meta 系统

无

## 实现难度

低 — 核心玩法以叙事为主，最大的技术难点是艺术表现力和情感传达。
