# Make It Meme（Make It Meme）

- **类型**: 社交 / 创意 / 派对
- **平台**: Web（浏览器）
- **开发商**: 浏览器游戏开发者
- **首次发布**: 2010s 末期
- **一句话描述**: 多人表情包创作游戏——玩家根据给定的图片创作文字，其他人投票选出最搞笑的

## 玩法规则

游戏房间容纳多名玩家（通常 4-8 人）。每轮系统展示一张图片（通常是 meme 模板、有趣的照片、或奇怪的场景），玩家需要为这张图片创作一段文字（caption）。

创作时间通常有限（30-60 秒）。时间到后，所有玩家的作品匿名展示，其他玩家投票选出最喜欢的。获得最多票数的玩家得分最高。

多轮后，总分最高的玩家获胜。

## 核心循环

观看图片 → 创作文字 → 投票评选 → 得分 → 下一轮

## 核心机制

- **创意表达**：核心玩法是为图片创作有趣的文字。这考验玩家的幽默感和创造力。
- **匿名投票**：投票是匿名的，确保公平。玩家不能看到谁创作了哪个作品。
- **轮次制**：每轮不同的图片，保持新鲜感。图片库涵盖各种类型——meme 模板、新闻照片、奇怪的场景等。

## 为什么好玩

Make It Meme 把"做 meme"变成了一个多人派对游戏——和朋友一起创作和投票，看谁的幽默感最强。好的作品带来的笑声和投票是直接的社交反馈。

## 粘性来源

- **社交娱乐**：和朋友一起玩的乐趣远大于单人玩
- **创意表达**：每次都有不同的图片和创作机会
- **投票反馈**：获得高票是直接的社交认可

## Meta 系统

无。纯派对游戏。

## 实现难度

低 + 图片展示、文字输入、投票系统、回合管理。最大技术难点是图片库的维护——需要足够多且有趣的图片。
