# 塔楼袭击者2（Tower Raiders 2）

- **类型**: 塔防 / 策略
- **平台**: Mobile (iOS)
- **开发商**: Fingersoft / 独立开发者
- **首次发布**: ~2010
- **一句话描述**: 一款经典的塔防游戏，玩家放置防御塔来阻挡一波波敌人的进攻路线

## 玩法规则

游戏画面采用俯视视角呈现战斗地图，敌人沿着预设的路径从地图一侧向另一侧移动，目标是到达路径终点。玩家需要在路径两侧放置各种防御塔来消灭敌人。

每波敌人由不同类型的单位组成——有的血量高、有的速度快、有的会飞行。每消灭一个敌人获得金币，金币用于购买和升级防御塔。

防御塔有多种类型：基础箭塔（单体攻击）、火炮（范围伤害）、冰冻塔（减速效果）等。每种塔有各自的攻击范围、伤害类型和特殊效果。玩家需要根据敌人的类型和行进路线，在关键位置放置合适的防御塔来最大化防守效果。

关卡通常有 10-20 波敌人，难度递增。最后的 Boss 波通常包含大量强力敌人，考验玩家的防御布局是否合理。

## 核心循环

观察地图和敌人路径 → 放置防御塔 → 敌人波次进攻 → 获得金币 → 购买/升级防御塔 → 抵御下一波

## 核心机制

- **多塔种协同**：不同类型的防御塔有不同的功能——伤害输出、减速控制、范围攻击等。合理搭配塔种比单纯堆砌同一种塔更有效
- **路径预测**：敌人沿固定路径移动，玩家可以预判敌人的行进路线，在关键位置（如路径拐角处）集中火力
- **波次递进**：每波敌人的数量和强度递增，后期的敌人可能对某些伤害类型有抗性，迫使玩家调整防御策略
- **塔升级系统**：防御塔可以升级来提升攻击力、射程或特殊效果，升级后的塔通常有视觉上的变化

## 为什么好玩

Tower Raiders 2 是塔防游戏的经典代表——它的核心循环"放塔→看敌人被消灭→获得金币→放更多塔"有着天然的成瘾性。看着敌人一波波被你的防御塔消灭，数字跳跃、爆炸效果交织在一起，提供了强烈的满足感。塔防游戏最核心的快感在于"我预判了你的预判"——你提前布局的防御阵型在敌人进攻时完美发挥作用，这种运筹帷幄的感觉是其他类型游戏难以提供的。

## 粘性来源

- **波次递进的成就感**：每成功抵御一波敌人都是一个小胜利，连续成功提供了持续的成就感
- **策略深度**：不同塔种的搭配、放置位置的选择、升级优先级，每关都有不同的策略空间
- **完美通关的追求**：三星评价或无损失通关驱动玩家反复优化防御布局
- **后期强力敌人的挑战**：Boss 波的高难度让玩家需要认真思考而非机械放置，增加了游戏的重玩价值

## Meta 系统

关卡进度是主要的元系统。通关后解锁新地图和新塔种。部分版本可能包含塔的永久升级系统，用通关获得的资源来提升塔的基础属性。

## 实现难度

低到中。塔防游戏的核心逻辑是路径规划、塔的射程检测、敌人移动和伤害计算，技术实现相对直接。最大技术难点在于大量单位和子弹同时渲染时的性能优化，以及 AI 敌人路径的动态计算（如果支持动态路径）。
