# The Denpa Men 2: Beyond the Waves

- **类型**: RPG / 收集
- **平台**: Nintendo 3DS / Mobile (iOS+Android)
- **开发商**: Nintendo / Genius Sonority
- **首次发布**: 2013
- **一句话描述**: 一款以收集和培养Denpa人为核心的RPG游戏，玩家通过扫描WiFi信号发现新的Denpa人并组建队伍探索世界

## 玩法规则

游戏世界中，Denpa人是小型彩色生物，拥有不同的颜色、能力和稀有度。每种颜色的Denpa人有独特的属性和技能倾向。

玩家通过在特定区域'扫描'来发现新的Denpa人。每个区域有不同概率出现不同颜色/稀有度的Denpa人。稀有颜色（金色、彩虹色）出现概率极低，需要大量扫描才能获得。

收集到Denpa人后，可以组建最多4人的队伍。每个Denpa人有不同的基础属性（攻击力、防御力、速度、HP）和技能。属性受颜色和稀有度影响。

队伍在迷宫中探索，遭遇敌人进行回合制战斗。攻击、防御、使用技能等标准RPG操作。胜利获得经验和扫描点，用于扫描新Denpa人。部分迷宫有隐藏区域和宝箱。

游戏设有隐藏迷宫，只有在特定条件下才能进入。隐藏迷宫中有极其稀有的彩色Denpa人等待发现。

## 核心循环

扫描发现Denpa人 → 组建队伍探索迷宫 → 战斗获得资源继续扫描

## 核心机制

- **扫描收集**：通过WiFi扫描发现随机Denpa人，稀有度决定收集难度
- **队伍组建**：不同颜色Denpa人有不同技能组合，需要策略搭配
- **回合制战斗**：标准RPG战斗系统，属性克制和技能释放

- **隐藏迷宫**：特殊条件解锁，内含稀有Denpa人


## 为什么好玩

收集稀有Denpa人的惊喜感是核心体验。每次扫描都是一次小赌注，可能发现极其稀有的彩色个体。

## 粘性来源

收集驱动是最大粘性。极低概率的稀有Denpa人让人不断扫描。完成图鉴的目标感极强。

## Meta 系统

Denpa人收集图鉴：发现并记录所有颜色和稀有度的Denpa人。队伍等级：通过战斗提升队伍整体等级。

## 实现难度

中 — RPG系统有一定复杂度。最大技术难点是WiFi扫描功能的实现。
