# 跳跃之王（Jump King）

- **类型**: 硬核平台跳跃
- **平台**: PC (Steam) / Mobile
- **开发商**: Nexile
- **首次发布**: 2019
- **一句话描述**: 通过蓄力跳跃攀登一座垂直高塔的硬核平台游戏，失误一次可能掉落很远

## 玩法规则

游戏画面是一个从底部到顶部的垂直高塔场景，玩家控制一个骑士角色，目标是从底部跳到顶部。

操作只有两个：左右移动和蓄力跳跃。按住跳跃键的时间决定跳跃力度和方向——按得越久跳得越高越远，但超过某个阈值后力道会减弱。

角色落在平台上后会固定站立，无法左右微调。这意味着每次落点都是"一锤定音"的——如果跳过了目标平台或没跳到，就会掉回下方。

游戏中存在各种特殊平台：弹簧板（强制弹跳）、移动平台、单向平台（只能从下方通过）、易碎平台（踩一次就碎）。

最大的特点是：如果你从高处失误掉落，你会一直掉落到第一个能接住你的平台为止。从高处掉落可能意味着失去数十分钟甚至数小时的进度。

到达顶部后可以随时返回重新开始，但每次都是从头开始。

## 核心循环

蓄力计算 → 跳跃 → 落在平台（继续向上）或掉落（回到之前的平台）→ 重复

## 核心机制

- **蓄力跳跃精度**：跳跃力度和时间窗口要求极高精度。玩家需要肌肉记忆来判断不同距离需要按多久。这是核心技巧。
- **坠落惩罚**：失误掉落可能回到很久之前的进度。这创造了极高的心理压力和紧张感。
- **检查点设计**：虽然没有传统检查点，但到达某些特殊平台后，就算掉落也不会掉得太远。这些"安全平台"给了玩家阶段性目标。

## 为什么好玩

极致的"再来一次"循环。每次掉落都让人咬牙切齿但又忍不住重新开始。成功跳过一个难点后的成就感是普通游戏无法比拟的。游戏本身的物理手感调校优秀，虽然难但每次失败都"怪自己"而不是"怪游戏"。

## 粘性来源

- **进步可见**：每次都能比以前多跳几层，进步感明确
- **社区挑战**：主播和速通社区的示范效应激发"我也能做到"的欲望
- **极限紧张感**：在关键跳跃前的蓄力阶段心跳加速
- **"差一点"效应**：最让人受不了的是"就差一点点"，这种不甘心驱动重复尝试

## Meta 系统

无。游戏没有外围系统，纯粹的挑战体验。通关后可以看通关动画和统计数据。

## 实现难度

低。核心就是一个物理跳跃系统，没有复杂的数值或AI。最大的技术难点是手感调校——蓄力曲线和弹跳反馈需要精确到帧的调校，确保每次跳跃的感觉一致且可学习。
