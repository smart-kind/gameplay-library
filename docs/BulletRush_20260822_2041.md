# Bullet Rush!

- **类型**: 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2020
- **一句话描述**: 一款休闲类手机游戏，The most modern and dynamic shooter with the cutest graphics you have ever seen!

## 玩法规则

Bullet Rush! 是一款动作类手机游戏。游戏以快节奏的战斗为核心体验。

玩家看到的画面/UI布局：第三人称或俯视角的战斗场景，屏幕上有角色模型、敌人、障碍物等元素。HUD显示生命值、弹药数量、得分等信息。

玩家操作方式：
- 虚拟摇杆/滑动：控制角色移动
- 自动瞄准/点击：对敌人进行射击
- 特殊技能按钮：释放特殊能力
- 躲避/掩体：利用场景中的障碍物规避攻击

游戏目标：在每关中击败所有敌人或到达终点。失败条件通常是生命值耗尽。游戏采用关卡制推进，每关难度递增。

## 核心循环

游玩关卡/对局 → 获得分数/奖励 → 解锁新内容/升级 → 回到起点继续挑战

## 核心机制

- **快节奏战斗**：战斗节奏快速，反应力决定胜负，带来紧张刺激的体验
- **自动射击/瞄准**：降低操作门槛，让玩家专注于走位和策略
- **关卡推进**：通过逐步推进的关卡设计，持续提供新的挑战

## 为什么好玩

快节奏战斗带来的紧张刺激感是这类游戏的核心吸引力。每次成功击败敌人带来的即时成就感，以及"再试一次就能通关"的不甘心，驱动玩家持续游玩。

## 粘性来源

1. **即时反馈**：每次操作都有视觉和数值的即时回应，形成正反馈循环
2. **"差一点就成功"效应**：失败时往往只差一点点，这种不甘心驱动"再来一次"
3. **碎片时间适配**：单局时间短，随时可以开始和结束，增加了游玩频次

## Meta 系统

轻度外围系统：
- 关卡进度：逐步解锁新关卡
- 成就系统：完成特定挑战获得成就
- 角色/皮肤解锁：通过游戏进度解锁新外观

## 实现难度

中 — 核心玩法实现相对直接，主要工作量在内容制作（关卡设计、美术资源）。最大技术难点是保持操作手感的流畅性和视觉反馈的即时性。
