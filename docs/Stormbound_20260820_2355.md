# 风暴对决（Stormbound）

- **类型**: 卡牌对战 / 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Stormbound Games
- **首次发布**: 2017
- **一句话描述**: 一款4王国背景的PVP卡牌对战游戏，结合卡牌收集和回合制战术对战。

## 玩法规则

游戏采用棋盘式战场（5x5或6x5网格），双方玩家各自拥有5张手牌和一副牌库。每回合玩家获得一定法力值，消耗法力值打出手牌到棋盘上的空位。

卡牌分为三类：单位卡（部署在棋盘上，具有攻击力和生命值）、技能卡（立即产生效果，如伤害、治疗、抽牌）、英雄卡（特殊单位，具有独特技能）。

单位在部署后可以沿棋盘移动并攻击相邻敌方单位或对方英雄。攻击时，攻击方造成伤害等于其攻击力，同时受到防御方攻击力的反击伤害。当一方英雄生命值降为零时游戏结束。

游戏的关键策略在于棋盘空间管理和资源规划：棋盘空间有限（每方最多12格可用），需要决定哪些单位该上、放哪里、何时进攻。卡牌的放置位置直接影响战斗结果。

每局游戏约3-5分钟，采用天梯排名制。

## 核心循环

收集卡牌组建牌组 → PVP对战获取积分 → 升级卡牌提升战力 → 冲击更高排名

## 核心机制

- **棋盘空间策略**: 不同于纯手牌对比的卡牌游戏，Stormbound 将单位放置在物理棋盘上，位置关系决定谁能攻击谁。前线推进/后撤、侧翼包抄等战术成为可能
- **三类卡牌协同**: 单位提供持续战场存在，技能提供即时战术变化，英雄提供独特战略方向。三类卡牌组合形成丰富的牌组构建空间
- **法力曲线管理**: 每回合递增的法力值（1→2→3→...）要求牌组有合理的费用分布，前期小单位铺场、后期大单位决胜，形成自然的节奏感

## 为什么好玩

将卡牌游戏的策略深度与棋盘游戏的空间感结合。每步决策都有意义：放哪张牌、放哪个位置、何时进攻。4个王国的不同风格（如北欧海盗的狂暴 vs 精灵的优雅）提供差异化体验。天梯对战的竞技性维持长期动力。

## 粘性来源

天梯排名的竞争性（差几颗星就升级段位）；卡牌收集的完整性驱动；牌组构建的试错乐趣（试试这个新套路）；每局短时长降低单局挫败感。

## Meta 系统

- **卡牌等级与天梯段位**: 重复卡牌转化为升级材料提升卡牌等级，胜利获得天梯积分
- **对核心玩法的影响**: 高等级卡牌有数值优势但不是决定性因素，段位影响匹配对手和赛季奖励

## 实现难度

中 — 卡牌数值平衡是核心难点，需要持续的数据分析和迭代调整；最大技术难点是匹配系统的ELO算法和卡牌平衡的自动化工具
