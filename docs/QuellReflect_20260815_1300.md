# Quell Reflect

- **类型**: 益智解谜 / 逻辑推理
- **平台**: Mobile (iOS + Android) / PC
- **开发商**: Fallen Tree Games
- **首次发布**: 2014
- **一句话描述**: 极简风格的逻辑解谜游戏，玩家通过滑动彩色小球来解决网格上的谜题

## 玩法规则

Quell Reflect在一个网格棋盘上运行。棋盘上有若干彩色小球（通常是白色），玩家需要通过滑动它们来消除。每次滑动，选中的小球会沿着一个方向一直移动，直到碰到墙壁或另一个小球才会停下。

游戏的核心操作是选择一个方向（上/下/左/右），所有未被固定的小球都会沿着这个方向滑动。当两个同色小球碰撞时，它们会融合消失。目标是在限定的移动次数内消除所有小球。

随着关卡推进，会出现各种新元素：带锁的小球（需要特定条件解锁）、传送门（小球进入一端从另一端出来）、颜色变化器（小球经过时改变颜色）、固定障碍物（小球无法穿过）、以及多种颜色的小球需要分别消除。

每个关卡都有"最少移动次数"的目标（金级评分），鼓励玩家寻找最优解法。

## 核心循环

观察棋盘 → 规划滑动顺序 → 执行滑动消除小球 → 完成关卡进入下一关

## 核心机制

- **全局滑动**: 选择一个方向后，所有可移动小球同时沿该方向滑动直到被阻挡
- **碰撞消除**: 同色小球碰撞后消除，不同颜色小球碰撞后会停在一起
- **移动次数限制**: 每关有最少移动次数目标，鼓励玩家寻找最优解
- **关卡元素递进**: 随着游戏进行逐步引入传送门、颜色变化器、锁等机制
- **极简美学**: 干净的黑白配色和柔和的音效，营造冥想般的解谜氛围

## 为什么好玩

Quell Reflect的魅力在于"啊哈！"时刻——当你盯着棋盘看了很久，突然发现一个精妙的滑动顺序能在一两步内消除所有小球时，那种顿悟感非常强烈。极简的设计没有多余的干扰，让玩家完全沉浸在纯粹的逻辑思考中。每个关卡都像是一个小小的思维体操。

## 粘性来源

粘性来自解谜游戏的天然循环——每个关卡都是一个待解决的谜题，解开一个就想立刻尝试下一个。金级评分（最少移动次数）为已经解开的关卡提供了再次挑战的理由。

## Meta 系统

关卡进度系统：线性关卡推进，每关有铜/银/金三级评分。无其他外围系统。

## 实现难度

低 — 核心逻辑简单（滑动+碰撞检测），最大技术难点在于关卡设计的质量和难度曲线的平滑度。
