# 方块逃脱：悖论（Cube Escape: Paradox）

- **类型**: 房间逃脱 / 解谜冒险
- **平台**: Mobile (iOS + Android) / PC
- **开发商**: Rusty Lake
- **首次发布**: 2018
- **一句话描述**: Rusty Lake 系列的房间逃脱解谜游戏，玩家扮演侦探 Dale Vandermeer 被困在一个充满神秘物品的房间里，需要解开层层谜题逃脱。

## 玩法规则

游戏画面呈现一个房间的多个面板，采用手绘风格的艺术表现。玩家以第一人称视角探索房间，点击各种物品进行交互。可以拾取物品、组合物品，用物品来解决环境中的谜题。

操作方式类似传统的点击式冒险游戏：点击物品拾取，在物品栏中选择物品后点击环境中的目标使用。某些物品可以组合使用——比如将A物品和B物品合成C物品，再用C物品解决某个机关。

随着谜题的推进，房间环境会发生变化，过去的黑暗事件逐渐浮出水面。游戏的谜题设计以"离奇"著称——很多解谜逻辑超越常理，需要玩家尝试各种组合或参考攻略才能理解其中的逻辑。

在 Cube Escape: Paradox 中，玩家扮演侦探 Dale Vandermeer，发现自己被困在一个充满神秘物品的布满灰尘的房间里。房间里有各种神秘和看似普通的物品，玩家需要按照传统点击式冒险游戏的方式，收集并组合这些物品来解决极其复杂的因果关系谜题。

## 核心循环

探索房间 → 拾取物品 → 组合物品 → 解开谜题 → 环境变化 → 继续探索更深层的秘密

## 核心机制

- **物品收集与组合**: 拾取房间中的物品，在物品栏中组合使用，创造新的工具
- **因果关系谜题**: 谜题之间存在因果关联，解开一个谜题会改变房间状态，影响后续谜题
- **环境变化**: 随着解谜推进，房间会发生诡异的变化，揭示故事线索和过去的事件
- **系列神话**: 游戏是 Rusty Lake 系列的一部分，包含对整个系列世界观的引用和暗示
- **点击式交互**: 经典的 point-and-click 操作方式，点击拾取、选择使用、拖拽组合

## 为什么好玩

诡异的手绘美术风格和超现实的谜题设计创造了独一无二的解谜体验。对于喜欢密室逃脱和 Rusty Lake 系列的玩家来说，这种"不合常理但自洽"的谜题逻辑正是吸引力所在。每次解开谜题后的成就感，加上环境变化带来的惊喜，构成完整的满足循环。

## 粘性来源

主要来自解谜的成就感和好奇心驱动——"解开这个谜题后房间会变成什么样？"系列粉丝还会被世界观的延续性吸引。谜题的高难度虽然有时令人沮丧，但解决后的成就感也更大。诡异氛围和神秘故事让人想要探索到底。

## Meta 系统

无。游戏为独立叙事体验，但属于 Rusty Lake 更大的世界观系列，与其他作品共享角色和背景设定。

## 实现难度

中。核心是物品管理和状态机系统，技术实现不复杂。最大难点在于设计层层递进的谜题链，确保谜题既有挑战性又不会完全不可解，以及美术风格的统一和氛围营造。
