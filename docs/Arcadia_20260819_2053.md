# Arcadia街机合集（Arcadia）

- **类型**: 街机合集
- **平台**: Mobile (iOS+Apple Watch+Apple TV)
- **开发商**: Raffaele D'Amato
- **首次发布**: 2019
- **一句话描述**: 23款经典街机游戏的合集，支持iPhone、iPad、Apple Watch、Apple TV和Vision Pro。

## 玩法规则

游戏主界面以网格形式展示全部23款街机游戏，每款游戏用独特的图标和名称标识。玩家点击任意游戏即可直接进入，无需加载等待。游戏界面根据平台自动适配：在iPhone上全屏显示，在iPad上居中显示并保留边距，在Apple Watch上以小屏幕优化布局，在Apple TV上以大画面呈现。

包含的游戏类型丰富多样。FastRun是躲避交通的赛车游戏，玩家需要左右滑动避开障碍物并尽可能跑得更远。Block Fit是放置方块游戏，需要将不同形状的方块放入网格中，填满行或列即可消除得分。RainBowling是保龄球游戏，通过滑动屏幕控制球的轨迹和力度，目标是击倒所有球瓶。Yarr是海盗射击游戏，控制海盗船消灭敌舰。Bricko是彩色砖块消除，将相同颜色的砖块连成一线消除。Fruity Snake是经典贪吃蛇的变种，收集水果并避免撞到自己。CandyBall是弹球游戏，用翻板击打球并消除目标。MineHound是经典扫雷。Bubble Mania是泡泡射击，瞄准并发射彩色泡泡，三个相同颜色即可消除。

每款游戏都有独立的每日、每周和总排行榜。游戏结束后显示本次得分和排名变化。操作方式因游戏而异，包括点击、滑动、长按和摇动（部分游戏利用设备的陀螺仪）。

整个合集没有广告、没有内购、没有用户追踪。一次下载即可体验全部23款游戏，提供纯净的游戏体验。支持iCloud存储，进度和高分可以在设备间同步。

## 核心循环

选择街机游戏 -> 挑战高分 -> 冲击排行榜 -> 尝试另一款游戏

## 核心机制

- **23合1街机**：涵盖躲避、射击、消除、保龄球、扫雷、弹球、贪吃蛇等多种经典街机类型，满足不同口味
- **多平台支持**：从Apple Watch到Apple TV全平台覆盖，随时随地可玩，不同设备有不同体验
- **无广告无内购**：纯净的游戏体验，一次下载全部游戏，没有打扰和付费墙
- **排行榜系统**：每日、每周和总排行榜三重维度，驱动竞争和反复挑战

## 为什么好玩

经典街机玩法的纯净呈现。没有广告和内购打扰，专注于游戏本身的乐趣。23款游戏涵盖了街机黄金时代最受欢迎的玩法类型。

## 粘性来源

经典街机的天然吸引力 + 23款游戏的多样性 + 排行榜竞争。Apple Watch的便携性增加了碎片时间游玩频率。"再试一次打破记录"的心理在每款游戏中都存在。

## Meta 系统

无。纯净街机体验，无外围成长系统。游戏纯粹依赖玩法本身的吸引力和排行榜的竞争驱动。

## 实现难度

低 - 每款街机游戏逻辑简单，主要是实现23款不同游戏。最大技术难点：多平台适配（尤其是Apple Watch小屏幕的操作优化和Apple TV的大画面视觉效果）。
