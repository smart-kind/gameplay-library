# Freeciv-Web（Freeciv-Web）

- **类型**: 回合制策略 / 4X / 城市建设
- **平台**: Web（浏览器）/ PC（桌面客户端）
- **开发商**: The Freeciv Project（开源社区）
- **首次发布**: 1996（Freeciv 原始版）；Freeciv-web 于 2010s 移植至浏览器
- **一句话描述**: 开源版《文明》系列，在浏览器中体验从远古部落到太空殖民的文明建设全过程

## 玩法规则

玩家扮演公元前4000年的部落领袖，在一个由六角格或方格组成的随机生成地图上开始游戏。画面主区域是俯视视角的世界地图，可以看到地形（平原、山地、河流、海洋）、己方城市、单位和敌方单位。底部有操作面板，显示当前选中单位的行动选项。

玩家每回合可以移动单位（战士、移民、工人等）、在城市中建造建筑（兵营、市场、图书馆等）或训练新单位。移动一个单位消耗一次行动，攻击敌方单位进入战斗（基于单位攻防值和随机骰子判定）。城市会自动产出食物、生产力、金币等资源——食物用于人口增长，生产力用于建造，金币用于维护和交易。

随着游戏推进，玩家通过"科技树"研究新技术（从制陶术、青铜到核能、太空飞行）。每项新技术解锁新的单位类型、建筑选项或政体。游戏目标是消灭所有其他文明，或完成"阿波罗计划"建造宇宙飞船殖民太空。如果设置了回合数上限，回合结束时得分最高的文明获胜（评分基于领土面积、财富、科技和文化）。

## 核心循环

探索地图 & 扩张领土 → 采集资源 & 研究科技 → 建造城市 & 训练军队 → 征服对手或科技胜利

## 核心机制

- **科技树系统**：线性+分支的科技研究路径，每个时代有多个可选研究方向，决定文明发展策略。每次只能研究一项科技，需要若干回合完成。
- **城市管理**：每座城市有独立的产出面板，玩家通过分配市民到不同地块（农场、矿山、贸易路线）来最大化资源产出。城市可建造的队列包含建筑、奇观和单位。
- **回合制战斗**：单位移动后进入攻击或防御状态，战斗结果由攻防值、地形加成、随机因素综合决定。支持海陆空多兵种协同。
- **外交系统**：可与其他文明建立贸易关系、宣战、缔结和平、组建联盟。AI根据实力差距和历史行为做出反应。

## 为什么好玩

Freeciv-Web 把《文明II》的核心体验完整搬到了浏览器里——从零开始建立文明、看着城市从小村落发展为帝国、科技树上每一次突破都带来新的可能性。一局完整的游戏可以跨越数千年，每一步决策都影响文明的走向。

## 粘性来源

- **"再来一回合"效应**：每回合结束都有新的事件触发（城市完成建造、科技解锁、敌军逼近），形成强烈的"再看一回合"心理循环
- **多线策略深度**：军事征服、科技胜利、文化胜利、外交胜利——每次可以选择完全不同的策略
- **随机性+策略性**：地图随机生成 + 科技研究存在不确定性，但长期决策决定胜负

## Meta 系统

无。纯核心玩法游戏，没有外围成长系统。所有进度都在单局游戏内完成。

## 实现难度

中 + 需要完整的4X游戏逻辑（回合制引擎、AI、地图生成、战斗系统、科技树）。最大技术难点是AI行为树的设计——让AI在不同文明间做出合理的策略决策，同时还要处理多人游戏的同步问题。浏览器版需要处理大量单位同时渲染的性能优化。
