# Wizardlings

- **类型**: 解谜 RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款融合三消解谜和 RPG 元素的游戏

## 玩法规则

游戏核心为三消玩法，玩家通过消除彩色宝石来施放魔法。消除特定颜色的宝石对应不同效果（红色攻击、蓝色治疗、绿色防御等）。

在解谜的基础上加入了 RPG 元素：角色有血量和等级，战斗中有不同敌人需要针对。某些关卡有特殊机制，如限时消除、特定颜色消除要求等。

画面采用魔法学院风格，角色和怪物设计可爱。界面下方为宝石网格，上方为战斗信息和角色状态。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

消除宝石施放魔法 → 击败敌人获取经验 → 升级解锁新关卡

## 核心机制

- 三消战斗：通过消除宝石发动攻击、治疗和防御
- RPG 成长系统：角色升级提升基础属性
- 关卡机制：特殊消除要求和限时挑战

## 为什么好玩

三消和 RPG 的融合让简单的消除玩法有了策略深度。

## 粘性来源

角色升级和关卡推进的双重驱动。

## Meta 系统

- 角色升级系统：战斗获得经验提升等级
- 装备系统：通过关卡奖励获得魔法装备

## 实现难度

中等 — 三消与 RPG 的融合需要精细设计，最大的技术难点是消除概率和战斗节奏的平衡。
