# 城堡秘密（Castle Secrets: Hidden Object）

- **类型**: 寻物冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: JoyBits Ltd.
- **首次发布**: 2012
- **一句话描述**: 在一个被兽人入侵的中世纪王国中，扮演预言中的英雄寻找隐藏物品和古代武器，拯救骑士团

## 玩法规则

游戏设定在一个中世纪奇幻世界中，画面采用精美的手绘风格。场景包括城堡、森林、地牢、村庄、战场等。

玩家需要在这些场景中找到指定的隐藏物品来推进故事。物品列表中有些是明显的大件物品（如剑、盾牌），有些则巧妙隐藏在环境细节中。

随着剧情推进，玩家逐渐揭示预言中的英雄使命——找到古代武器来对抗兽人入侵。

每个章节有新的场景和故事发展。章节之间的过渡动画展示了故事的发展。

部分关卡包含小游戏元素——拼图、物品配对等，用于获取关键道具或解锁新的寻物区域。

## 核心循环

在中世纪场景中寻找隐藏物品 → 收集线索和古代武器 → 推进奇幻故事 → 解锁新章节和新场景

## 核心机制

- 中世纪奇幻寻物：中世纪城堡和奇幻元素的结合为寻物场景提供了丰富的视觉内容
- 英雄叙事线：预言英雄的故事框架赋予寻物行为意义。每次找到物品都是在推进拯救世界的使命
- 多章节推进：故事按章节展开，每章有新的场景、角色和情节转折

## 为什么好玩

中世纪奇幻的美学风格让人沉浸在剑与魔法的世界中。

英雄叙事赋予寻物行为更强的使命感——你不是在找东西，你是在拯救世界。

预言英雄的叙事框架让简单的寻物有了史诗感，这是其他寻物游戏少有的体验。

## 粘性来源

奇幻故事的悬念驱动持续游玩。章节解锁提供阶段性成就感

## Meta 系统

章节解锁系统：完成章节解锁新故事和场景

## 实现难度

低 — 寻物玩法简单。最大的技术难点在于大量手绘场景美术制作
