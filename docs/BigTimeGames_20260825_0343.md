# 大时光游戏合集（Big Time Games）

- **类型**: 休闲合集/益智
- **平台**: Mobile (iOS+Android)
- **开发商**: WINR Games Inc.
- **首次发布**: 2014
- **一句话描述**: 15款精选休闲游戏合集，含每日挑战

## 玩法规则

Big Time Games 包含 15 款不同类型的休闲游戏。主界面以卡片形式展示所有可用游戏，每张卡片显示游戏名称和预览图。点击任意卡片即可进入对应游戏。

游戏类型涵盖：益智解谜（需要逻辑推理和思考）、跳跃类（需要时机把握和反应）、街机挑战（需要手速和精准度）等。

每款游戏都有精心设计的关卡系统，难度逐步递增。每日挑战提供限时的特殊关卡，完成可获得奖励。

玩家可以在设置中自定义游戏主题和视觉风格，打造个性化的游戏环境。

## 核心循环

选择游戏 → 完成关卡/挑战 → 获得奖励 → 解锁新关卡/主题

## 核心机制

- **机制1**：15款精选游戏：不是海量堆砌，而是精选 15 款各类型代表游戏。每款都经过精心打磨，质量高于数量。
- **机制2**：每日挑战系统：每天更新特殊关卡，提供额外奖励。激励玩家每天回来。
- **机制3**：个性化主题：玩家可以自定义游戏环境的视觉主题，增加归属感。

## 为什么好玩

Big Time 的核心理念是'精选而非海量'。15 款游戏每款都经过精心设计，关卡制作精良，图形美观。适合不想在海量游戏中做选择的玩家。每日挑战提供了固定的回归理由。

## 粘性来源

粘性来源：(1) 每日挑战系统提供固定的回归动机；(2) 15款游戏各有特色，可以轮换游玩避免疲劳；(3) 精心设计的关卡难度曲线提供持续的挑战感；(4) 个性化主题系统。

## Meta 系统

每日挑战奖励系统。主题自定义系统。可能有内购去广告。无复杂的付费养成系统。

## 实现难度

低。15款游戏的统一框架设计，每日挑战的内容生成是主要工作量。技术难度不高，但需要良好的游戏设计能力。
