# 死神：灵魂共鸣（BLEACH: Soul Resonance）

- **类型**: 动作 RPG / 卡牌收集
- **平台**: Mobile (iOS+Android)
- **开发商**: KLab Games / Pierrot
- **首次发布**: 2025
- **一句话描述**: 基于《死神/BLEACH》IP的动作RPG手游，收集动漫角色进行回合制战斗。

## 玩法规则

玩家收集《死神》动漫中的角色（如黑崎一护、朽木露琪亚、更木剑八等）组成队伍。

战斗采用回合制或半即时制，屏幕下方显示角色头像和技能按钮。每个角色有普通攻击、特殊技能（卍解/始解）和终极技能三种攻击方式。

玩家需要合理安排技能释放顺序：先用控制技能打断敌方，再用输出技能造成大量伤害。部分角色之间有连携效果（特定角色组合触发额外伤害）。

角色通过抽卡获得，分不同稀有度（R/SR/SSR）。升级角色需要消耗经验材料和金币，升星需要相同角色的碎片。

主线剧情模式重现动漫经典场景，PVP竞技场与其他玩家的队伍对战，公会战需要团队成员协作击败强力Boss。

## 核心循环

收集角色 → 升级强化 → 通关剧情/PVP → 获得新角色碎片和强化材料

## 核心机制

- 角色连携系统：特定角色组合（如同一番队成员、师徒关系）触发额外的连携攻击，鼓励玩家收集和培养角色群
- 卍解放大系统：积累灵魂能量后释放卍解，短时间内大幅提升攻击力并改变角色外观，提供爽快感爆发
- 属性克制：斩击/鬼道/虚三种属性互相克制，需要根据敌方阵容调整出战角色

## 为什么好玩

对粉丝而言，看到喜爱的角色和动漫场景在手机中重现本身就是吸引力。战斗中的卍解动画和技能特效非常华丽，连携系统的策略深度也让战斗有趣。

## 粘性来源

抽卡系统的随机性驱动持续投入（SSR角色的稀有性和强力效果）；角色收集图鉴提供完整收集目标；限时活动角色制造稀缺感和紧迫感；公会社交增加留存。

## Meta 系统

角色抽卡系统（核心付费点）。装备和魂玉系统：为角色装备魂石提升属性。主线剧情推进解锁新区域。公会系统：加入公会参与公会战和互助。

## 实现难度

中 — 卡牌RPG框架成熟，技术风险低。最大难点是角色美术资源量大（每个角色需要多套动画和卍解特效），以及平衡大量角色之间的战斗数值。
