# Lazy Raiders (懒惰的掠夺者)

- **类型**: 解谜 / 平台
- **平台**: PS Vita / Xbox Live Arcade
- **开发商**: Sarbakan / Microsoft Game Studios
- **首次发布**: 2010 (XBLA) / 2012 (PS Vita)
- **一句话描述**: 玩家预先规划角色移动路线来解谜的平台冒险游戏

## 玩法规则

游戏设定在古老遗迹中，玩家扮演探险家探索地下迷宫。游戏的核心机制是预先规划：玩家在执行前先用触控笔在地牢网格上画出移动路径。

游戏界面显示地牢的俯视图网格。玩家通过拖拽在网格上绘制角色的移动路线——可以直行、转向、跳跃和攻击。规划完成后点击执行，角色按照预设路线自动行动。

地牢中分布着敌人、陷阱、宝箱和机关。玩家需要在规划阶段预判所有危险并规划安全路径。某些关卡需要多步规划，角色执行完第一步后自动进入下一步。

游戏目标是在每个关卡中到达终点并收集宝箱。三星评价基于收集效率和规划步数。

## 核心循环

观察地牢布局 → 规划移动路径 → 执行路线 → 评估结果 → 调整规划重新尝试

## 核心机制

- **预先规划系统**：玩家先画路线再执行，考验空间预判和路径规划能力
- **网格移动**：基于网格的离散移动让规划更精确和可控
- **多阶段解谜**：某些关卡需要多个角色协作或分阶段规划
- **收集奖励**：宝箱和隐藏物品鼓励玩家优化路径

## 为什么好玩

"先想后做"的玩法给玩家充分的思考空间，没有反应速度的压力。看着角色按照自己的规划精准执行的成就感很强。

## 粘性来源

"就差一步"的不甘心 + 路径优化的重复挑战 + 每关新机制带来的新鲜感 + 收集所有宝箱的完成欲

## Meta 系统

关卡解锁系统 — 完成当前关卡解锁下一阶段

## 实现难度

低 — 基于网格的路径规划游戏，最大技术难点在于关卡设计的趣味性和多角色协调的复杂度
