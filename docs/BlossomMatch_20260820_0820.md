# 花朵配对（Blossom Match）

- **类型**: 三消 / 花园装饰
- **平台**: Mobile (iOS+Android)
- **开发商**: Tripledot Studios
- **首次发布**: 2023
- **一句话描述**: 通过三消关卡收集星星，用星星装饰和修复一座美丽的花园

## 玩法规则

游戏棋盘为 8×8 或更大的网格，铺满各种颜色的花朵。玩家交换相邻花朵实现三消或更多连消。

消除三个同色花朵获得基础分数，四消或五消产生特殊花朵（行消除炸弹、列消除火箭、彩色花朵等）。特殊花朵的消除范围更大，可以清除障碍物。

每个关卡有特定目标：在限定步数内消除指定数量的某色花朵、清除花园中的障碍物（枯树、石头、藤蔓）、或收集掉落到底部的花朵。

完成关卡后获得星星奖励（1-3星取决于表现）。星星用于花园的装饰和修复项目——如修复喷泉、种植花丛、搭建凉亭等。

每个装饰项目有明确的星星成本（如"修复喷泉需要30颗星"），玩家通过持续通关积累星星。

## 核心循环

三消通关收集星星 → 用星星装饰花园 → 花园变美丽 → 解锁新关卡区域

## 核心机制

- **三消匹配机制**: 经典交换匹配玩法，Tripledot Studios 在基础三消上加入了多样化的障碍物和关卡目标，保持玩法新鲜感
- **花园装饰系统**: 装饰项目以渐进方式展示（如喷泉从废墟到完整分多个阶段），每次投入星星都能看到可视化进展，提供强烈的成就感
- **特殊花朵组合**: 特殊花朵之间的组合消除产生更大范围的清除效果，鼓励玩家规划连续操作而非随机交换

## 为什么好玩

花园从无到有的建设过程提供了强烈的视觉成长反馈。每一关的消除快感叠加在"我的花园越来越美"的长期满足感上。Tripledot 一贯的精致美术让花园非常赏心悦目。

## 粘性来源

花园建设的渐进展示让人忍不住"再装饰一个项目"；三消关卡本身的短周期正反馈；装饰项目的"差几颗星就完成"效应驱动持续游玩；季节性活动和限时装饰增加新鲜感。

## Meta 系统

花园装饰系统：星星用于修复和装饰花园中的各种元素（喷泉、花坛、长椅等）。每个装饰项目分多个阶段，逐阶段解锁。装饰完全不影响三消玩法，是纯粹的长线目标。

## 实现难度

低。三消引擎+装饰UI。最大技术难点是大量关卡内容的配置和装饰系统的状态管理。
