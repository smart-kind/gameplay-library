# 骰子合并（Dice Merge by Staple Games）

- **类型**: 骰子放置 / 合并解谜 / 休闲策略
- **平台**: Mobile (iOS + Android)
- **开发商**: Staple Games
- **首次发布**: 2023
- **一句话描述**: 在棋盘上放置骰子块，通过相邻相同骰子合并升级的极简风格益智游戏。

## 玩法规则

游戏呈现一个网格状的棋盘区域（类似 2048 的格子布局）。每回合系统给出一个骰子块（带有 1-6 的点数），玩家需要将其放置到棋盘的任意空格中。

当两个相同点数的骰子在放置后变得相邻（上下左右），它们立即合并为一个点数+1 的骰子（两个 3 合并为 4，两个 5 合并为 6）。合并后腾出的格子可以继续放置。如果合并引发连锁反应（新生成的骰子与另一个相同点数的骰子相邻），连锁会继续进行。

游戏目标是通过策略性放置，最大化合并次数和骰子的最终数值。棋盘空间有限，当没有空位可以放置新骰子时，游戏结束。分数基于合并产生的骰子数值总和。

## 核心循环

获得骰子块 → 策略放置到棋盘 → 触发合并升级 → 腾出空间并获得分数 → 继续下一回合

## 核心机制

- **骰子合并机制**：相同数值相邻即合并为+1，类似 2048 的增长逻辑但发生在二维棋盘上，放置位置的选择直接影响合并可能性。
- **空间管理**：棋盘格数有限，需要平衡"制造合并机会"和"保留可用空间"。过早填满棋盘而没有足够合并意味着快速结束。
- **连锁反应**：一次合并可能引发连锁，产生意想不到的升级路径。这种不可预测性既是惊喜来源也是策略深度的来源。
- **预览机制**：玩家可以预览下一个骰子的数值，据此规划放置位置。

## 为什么好玩

极简的设计（只有骰子和网格）却产生了丰富的策略深度——每步放置都需要同时考虑当前合并、未来规划和空间利用。连锁反应带来的意外爽感让每次操作都充满期待。

## 粘性来源

"再来一局"的核心驱动来自于每局随机骰子序列带来的不同体验；试图突破自己的最高分；看到小数字骰子一路合并到 6 的成长满足感；每局时间短（1-3分钟），降低了重试成本。

## Meta 系统

无。纯分数驱动，无外围成长。

## 实现难度

低。核心为网格状态管理+相邻检测+合并连锁。最大技术难点是合并连锁的递归处理——需要按正确顺序处理级联合并并播放动画，避免状态不一致。
