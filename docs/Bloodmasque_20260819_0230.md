# Bloodmasque

- **类型**: ARPG / 吸血鬼主题
- **平台**: Mobile (iOS, iPad)
- **开发商**: Glu Mobile
- **首次发布**: 2013
- **一句话描述**: 以吸血鬼为主题的动作RPG，结合前置摄像头面部识别、闪避反击战斗和探索元素。

## 玩法规则

游戏画面呈现第三人称视角的动作场景。玩家控制角色在城市环境中与吸血鬼敌人战斗。画面中可见AI同伴在一旁协助作战，以及敌人的各种攻击动作提示。

战斗系统的核心机制是"闪避反击"：当敌人发动攻击时，玩家需要在恰当时机闪避，成功闪避后会创造反击机会。攻击操作本身没有节奏或技巧要求——在敌人攻击间隙快速点击屏幕即可。

游戏还包含独特的面部识别功能：玩家需要在iOS设备的前置摄像头前拍摄三张照片——一张休闲姿势、一张愤怒表情、一张开心表情。这些照片用于游戏中的角色定制或某种机制。

探索部分为漫游式"冒险"区域：玩家在基本街道中行走，点击场景中的角色和符号触发剧情。这些部分主要用于展示Unreal Engine的画面效果并引出下一段过场动画。

游戏中的敌人分为不同阵营，各有略微不同的攻击节奏和方式。主要吸血鬼敌人每个需要战斗两次——一次为人类形态，第二次变为更强壮的利爪野兽形态。

游戏包含时间限制机制，如果在规定时间内无法完成目标，进度会损失，除非玩家付费购买延长时间道具。

## 核心循环

闪避敌人攻击 → 获得反击机会输出伤害 → 击败敌人推进剧情 → 探索新区域

## 核心机制

- **闪避反击系统**：战斗的核心循环。玩家不需要掌握复杂的连招系统，只需要观察敌人攻击前摇并及时闪避。成功闪避后自动获得反击窗口。
- **双形态Boss设计**：每个主要敌人都需要战斗两次，第一次为人类形态，第二次变身更强的野兽形态，增加了重复挑战的新鲜感。
- **阵营差异化**：不同吸血鬼阵营有略微不同的攻击节奏，这是游戏中为数不多的变化元素。
- **面部扫描功能**：利用前置摄像头拍摄玩家三种表情照片，用于角色个性化，是当时iOS设备的创新尝试。

## 为什么好玩

闪避反击的即时反馈提供了一种"见招拆招"的紧张感，尤其是面对不同攻击节奏的敌人时需要保持专注。Unreal Engine驱动的画面在2013年的移动游戏中属于上乘水平。

## 粘性来源

粘性来源较弱。敌人循环重复（每个打两次，人形态→野兽形态），攻击模式变化有限。时间限制机制更多是付费诱导而非有意义的挑战。AI同伴虽然存在但无法进行战术互动，削弱了策略深度。探索部分被评价为"多余"，只是走过场。

## Meta 系统

有AI同伴系统：其他玩家创建的角色会出现在你的游戏中作为战斗伙伴。但由于无法对同伴进行任何有意义的战术指挥，这个系统的实际影响力有限。

## 实现难度

中。最大技术难点在于闪避判定的时机窗口调校——太宽容则无聊，太严格则令人沮丧。面部识别功能在iOS上实现难度不高但集成到游戏中需要额外设计。AI同伴的"跨玩家共享"机制在当时的技术条件下有一定实现门槛。
