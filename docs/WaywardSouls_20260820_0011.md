# 漂泊之魂（Wayward Souls）

- **类型**: 动作冒险 / Roguelike 地牢探索
- **平台**: Mobile (iOS+Android)
- **开发商**: Rocketcat LLC
- **首次发布**: 2014
- **一句话描述**: 受 Spelunky 和 Secret of Mana 启发的动作 Roguelike，六名角色各有独特玩法，程序化生成的随机关卡确保每次探险都是全新体验。

## 玩法规则

玩家从六名可选角色中选择一名，进入一个程序化随机生成的地牢。地牢由多个房间组成，每个房间包含敌人、宝箱、陷阱和秘密通道。

核心操作是虚拟摇杆移动+虚拟按钮攻击。每个角色有独特的攻击方式、技能和装备。战士使用近战武器，法师使用魔法，游侠使用弓箭等。不同角色的玩法风格差异巨大。

战斗强调战术、定位和时机。不是无脑冲杀，而是需要观察敌人攻击模式，找到合适的时机进行反击。敌人的攻击有前摇动作，玩家需要学会预判。

探索过程中可以收集金币、装备、钥匙和各种消耗品。每次死亡后地牢重新生成，但部分进度（如已解锁的角色）会保留。

## 核心循环

探索房间 → 战斗+收集 → 找到通往下一层的入口 → 继续深入 → 死亡后重新开始

## 核心机制

- **六角色系统**：每个角色有完全不同的攻击方式、技能树和装备偏好，相当于六个不同的游戏
- **程序化随机**：每次地牢布局、敌人配置、物品分布都不同
- **战术战斗**：强调走位、时机和位置判断，而非数值碾压
- **永久死亡+进度保留**：死亡后重新开始，但解锁的角色和成就永久保留
- **秘密通道**：隐藏房间和秘密通道鼓励探索

## 为什么好玩

Wayward Souls 将经典 ARPG 的深度与 Roguelike 的重玩价值完美结合。每个角色的独特性意味着你需要学习六种不同的玩法。程序化关卡确保你永远不知道下一扇门后是什么——可能是强力装备、致命陷阱，或者一个充满敌人的大厅。

## 粘性来源

- **六角色深度**：每个角色都值得完整探索一遍
- **随机性**：每次地牢不同，永远有新鲜感
- **掌控感提升**：随着熟练度提升，你能在更危险的情况下存活，成长感来自玩家自身而非角色数值
- **隐藏内容**：秘密通道和隐藏房间激发探索欲

## Meta 系统

- **角色解锁**：通过游戏进度解锁更多可玩角色
- **成就系统**：完成特定挑战解锁成就
- **无数值成长**：没有永久属性提升，每次从零开始（纯粹的 Roguelike 设计）

## 实现难度

高。程序化地牢生成+六套完全不同的角色系统+精细的战斗AI。最大技术难点是地牢随机生成的可玩性保证和六套角色系统的平衡。
