# Flip O（Flip O）

- **类型**: 益智 / 翻转 / 解谜
- **平台**: Web（浏览器）
- **开发商**: 浏览器游戏开发者
- **首次发布**: 2010s
- **一句话描述**: 翻转益智游戏——通过翻转方块来改变其状态，最终让所有方块达到目标状态

## 玩法规则

画面是一个网格，每个格子中有一个可以翻转的方块。方块通常有两种状态（正面/反面，或不同颜色）。点击一个方块会翻转它（同时可能影响相邻方块）。

目标是通过一系列翻转操作，让所有方块达到目标状态（全部正面朝上、全部同色、或形成特定图案）。

不同关卡有不同的翻转规则——有些是"点击一个翻转它和相邻方块"（类似 Lights Out），有些是"点击一行/一列全部翻转"，有些是"点击一个翻转它和对角方块"。

## 核心循环

观察当前状态 → 选择要翻转的方块 → 观察变化 → 继续直到达到目标

## 核心机制

- **翻转连锁**：点击一个方块不仅翻转它自己，还影响相邻方块。这种连锁效应增加了策略深度——每次翻转既是解决问题的步骤，也可能制造新的问题。
- **状态追踪**：方块只有两种状态，使得问题空间有限但策略复杂。玩家需要理解翻转规则并制定策略。
- **谜题求解**：每个关卡是一个数学谜题——找到最少的翻转次数达到目标状态。

## 为什么好玩

Flip O 是经典的"Lights Out"类益智游戏的变体——简单到任何人都能理解，但解决需要策略思维。找到最优解的满足感很强。

## 粘性来源

- **最优解挑战**：不仅要解开谜题，还要找到最少步数的最优解
- **规则变化**：不同关卡有不同的翻转规则，保持新鲜感
- **短时反馈**：一局几分钟，随时可以再来一局

## Meta 系统

无。纯益智游戏。

## 实现难度

低 + 网格渲染、翻转逻辑、目标状态检测。最大技术难点是关卡设计——确保每个关卡有解且难度合理。
