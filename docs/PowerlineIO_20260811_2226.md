# Powerline.io（Powerline.io）

- **类型**: .io 多人对战 / 街机 / 反应类
- **平台**: Web（浏览器）
- **开发商**: Unknown .io 开发者
- **首次发布**: 2016 左右
- **一句话描述**: .io 风格的多人贪吃蛇对战游戏，玩家控制一条光蛇在竞技场中与其他蛇竞争，通过截断对手的路线来消灭它们

## 玩法规则

画面是一个俯视视角的方形竞技场，玩家控制一条发光的光蛇在场地中移动。游戏开始时蛇较短，通过吃地图上散落的能量点来增长身体长度。

操作方式：鼠标控制方向（蛇始终向前移动，鼠标指向决定转弯方向）。蛇不能碰到自己的身体或其他蛇的身体，否则会爆炸死亡。死亡后蛇的身体变成能量点，其他蛇可以食用这些能量点来快速增长。

胜利策略：加速冲刺（消耗自身长度获得加速）来截断其他蛇的路径——当其他蛇撞上你的身体时就会爆炸。同时要避免自己撞到别人的身体或地图边界。游戏没有传统意义上的"胜利"，而是在限定时间内获得最高分（基于蛇的长度和击杀数）。

## 核心循环

吃能量点增长 → 加速冲刺截断对手 → 对手爆炸后吃残留 → 继续增长

## 核心机制

- **加速机制**：按住加速键（或鼠标点击）可以加速，但加速时会消耗蛇身长度。这是高风险高回报的策略——加速冲刺可以消灭对手，但如果操作失误会让自己变得更短。
- **身体即武器**：蛇的身体既是需要保护的部分，也是攻击武器。绕圈包围对手可以限制其移动空间。
- **多人实时竞争**：多名玩家同时在一个竞技场中，局势瞬息万变——可能你正在追别人，背后又有别人在追你。

## 为什么好玩

Powerline.io 把经典的"贪吃蛇"变成了多人竞技——不再是和电脑比谁活得久，而是和其他真人玩家斗智斗勇。加速截断对手的瞬间快感、被包围时的紧张感、以及"差一点就赢了"的不甘心，让它非常容易上瘾。

## 粘性来源

- **即时竞技**：每局几分钟，死亡后立刻重新开始，"再来一局"的门槛极低
- **心理博弈**：不仅是反应速度，还要预判对手的行动路线——是追还是逃？是加速冲刺还是稳扎稳打？
- **成长反馈**：看着自己的蛇从短短几格变成满屏幕的长龙，有直接的成就感

## Meta 系统

无。纯核心玩法。

## 实现难度

- **学习曲线**：新手可以立即上手，但精通需要数十小时的练习。每次游玩都能发现新的技巧或策略。
- **重玩价值**：高。每局游戏都有不同的体验，无论是随机的地图/敌人，还是玩家的策略选择。
- **社区生态**：作为经典浏览器游戏，它在玩家社区中有良好的口碑。
- **技术亮点**：在浏览器环境中实现流畅的交互体验，充分利用了现代 Web 技术的能力。
低 + 核心逻辑简单（蛇的移动、碰撞检测、多人同步）。最大技术难点是多人游戏的实时同步和低延迟——需要 WebSocket 服务器处理所有玩家的位置更新和碰撞判定。
