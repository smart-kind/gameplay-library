# Fieldrunners（Fieldrunners）

- **类型**: 塔防
- **平台**: Mobile (iOS+Android) / PC / Nintendo DS
- **开发商**: Subatomic Studios
- **首次发布**: 2008
- **一句话描述**: 在空地上布置防御塔，阻止敌人沿着路径冲向你的基地

## 玩法规则

玩家面对一块空白网格状的战场，右侧是敌人进攻的方向，左侧是玩家保护的基地。屏幕底部显示可购买的防御塔种类（加特林机枪、导弹发射器、冰冻塔等）和数量。

操作方式：点击屏幕上的空位放置防御塔，每种塔消耗不同金币。敌人从起点沿固定路径（或玩家阻挡形成的路径）向基地移动，防御塔自动开火攻击进入射程的敌人。击杀敌人获得金币，用于购买更多塔或升级已有塔。

游戏目标：阻止敌人到达基地。每个敌人到达基地扣一条命，总共20条命。坚持100波敌人进攻不被消灭即为胜利。玩家可通过巧妙布置塔位来改变敌人的行进路径，使其绕远路，从而争取更多输出时间。

游戏结束条件：20条命全部耗尽则失败；成功抵御100波则过关。

## 核心循环

放置防御塔 -> 击杀敌人获得金币 -> 用金币升级/购买更多塔 -> 抵御更多波敌人

## 核心机制

- 路径诱导：敌人会自动寻找最短路径到达基地，玩家可以通过放置塔来封路，迫使敌人走更长的路线，从而增加被击杀的机会
- 塔种搭配：不同塔有不同特性——加特林单体高射速、导弹范围伤害、冰冻塔减速敌人，合理搭配形成火力网
- 波次递进：100波敌人逐渐增强，从慢速弱怪到高速强怪再到BOSS，考验玩家的资源规划和塔位布局

## 为什么好玩

看着敌人被自己精心布置的火力网层层拦截、逐个消灭的爽快感非常强。每次波次间隙的几秒钟内紧张规划塔位，随后看着敌人如潮水般涌入陷阱，既有策略深度又有即时反馈。

## 粘性来源

每波结束后的差一点就守住的不甘心驱动再来一局；不同塔组合带来的策略多样性让每局体验不同；100波的超长流程提供了持续的挑战目标。

## Meta 系统

无复杂Meta系统。部分版本有成就系统和无尽模式。

## 实现难度

中 — 核心塔防逻辑清晰，但100波难度曲线设计需要精细平衡。最大技术难点是路径计算算法（A*寻路）和大量单位同时渲染的性能优化。
