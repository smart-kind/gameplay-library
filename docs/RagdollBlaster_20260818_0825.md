# Ragdoll Blaster

- **类型**: 物理弹射
- **平台**: Mobile (iOS)
- **开发商**: Gameloft
- **首次发布**: 2009
- **一句话描述**: 布娃娃物理破坏弹射

## 玩法规则

玩家使用弹射器或火炮将布娃娃角色发射出去，目标是摧毁建筑或击中特定目标。

游戏采用侧视2D视角，玩家看到弹射装置、布娃娃角色和远处的目标建筑。

操作方式为拖拽调整发射角度和力度，松手后布娃娃被发射。

弹道预测线帮助玩家预判飞行路径。

布娃娃在空中遵循物理定律飞行——重力、风力、碰撞都会影响轨迹。

击中建筑后，布娃娃的动能会摧毁结构物——物理破坏效果是游戏的核心看点。

建筑由多种材料组成（木板、玻璃、石块、金属），每种材料有不同的破坏阈值。

每关有特定的破坏目标（如全部倒塌、击中特定目标等）和发射次数限制。

过关条件：在限制次数内完成破坏目标。

失败条件：发射次数用完但目标未达成。

## 核心循环

调整发射 -> 观察破坏 -> 获得评分 -> 尝试更优解（一句话）

## 核心机制

- 物理弹射机制：角度和力度的精确控制决定飞行轨迹。弹道预测线提供直观的辅助。风向和风力在高级关卡中成为额外变量。
- 布娃娃物理：角色碰撞时的滑稽动作和建筑渐进式坍塌提供视觉反馈。布娃娃的无重心特性让碰撞效果不可预测，增加了趣味性。
- 弹数限制：有限的发射次数迫使玩家每次都要精确计算。不同关卡的发射次数不同，难度越高可用次数越少。
- 多材料破坏系统：木板、玻璃、石块、金属等不同材料有不同的破坏阈值和反应。玻璃易碎但重量轻，石块重但难摧毁。

## 为什么好玩

物理破坏的视觉满足感极强——看着建筑在冲击下逐渐坍塌是一种独特的快感。布娃娃的滑稽动作增加了娱乐性，每次碰撞都充满不确定性。

## 粘性来源

差一点就完美摧毁的不甘心驱使反复尝试。布娃娃的滑稽动作增加娱乐性。星级评分系统鼓励玩家用最少的发射次数完成目标。

## Meta 系统

关卡系统：逐步增加建筑复杂度和目标难度。部分版本含沙盒模式。解锁新的发射装置和布娃娃类型。

## 实现难度

低 — 2D物理引擎即可实现。最大技术难点是物理参数的调优和碰撞检测的稳定性——需要确保物理模拟既有趣又不会出现穿模等bug。
