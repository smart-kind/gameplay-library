# Can Knockdown 3

- **类型**: 休闲 / 弹射
- **平台**: Mobile (iOS+Android)
- **开发商**: Dreamgate / Cheetah Games
- **首次发布**: 2016
- **一句话描述**: 一款以弹弓击倒罐头为核心玩法的休闲游戏，玩家通过拉动弹弓瞄准并射击堆叠的罐头

## 玩法规则

游戏呈现一组堆叠的罐头，放置在平台、木箱、栏杆或其他支撑物上。罐头排列成各种形状——金字塔形、塔形、分散排列等。

玩家通过拉动弹弓来瞄准。拖拽屏幕调整弹弓拉伸角度（方向）和力度（拉伸距离），松手后弹丸沿抛物线飞出。有预测线辅助瞄准。

目标是击倒所有罐头。罐头受物理引擎控制，被击中后会倒塌并可能撞倒相邻罐头，产生连锁反应。连锁反应能大幅减少需要的弹丸数。

不同关卡有不同罐头排列方式、支撑结构和障碍物。部分关卡有特殊罐头：爆炸罐（被击中后爆炸清除周围罐头）、重罐（需要多次击中才倒）。部分关卡限制弹丸数量。

游戏设有创意关卡编辑器，玩家可以设计自己的罐头排列并分享给其他玩家。每日精选关卡展示社区最佳设计。

## 核心循环

拉伸弹弓瞄准 → 松手射出弹丸 → 击倒所有罐头过关

## 核心机制

- **物理弹射**：弹丸抛物线飞行，罐头物理倒塌，连锁反应带来额外满足感
- **关卡变化**：不同罐头排列和障碍物增加每关独特性
- **弹丸限制**：部分关卡限制次数，需要精确瞄准

- **关卡编辑器**：玩家设计罐头排列并分享


## 为什么好玩

物理倒塌的视觉反馈极其满足。连锁反应——一个罐头撞倒一串——是核心爽点。

## 粘性来源

物理弹射的不可预测性+连锁反应的爽感。每关新排列保持新鲜感。

## Meta 系统

关卡进度：逐步解锁新关卡和新场景。弹丸皮肤：收集不同外观的弹丸。

## 实现难度

低 — 拉动弹弓即可。最大技术难点是物理引擎的准确性和罐头倒塌动画。
