# 史诗点击者（Epic Clickers）

- **类型**: 放置 / 点击 / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Tiny Games srl
- **首次发布**: 2014
- **一句话描述**: 点击击杀怪物和泰坦，雇佣英雄加速战斗，体验从个位数到无穷大的数字狂欢

## 玩法规则

Epic Clickers 是一款经典的怪物击杀点击游戏。玩家通过点击或 tapping 屏幕上的怪物来造成伤害，击杀后获得金币用于购买英雄和升级。

游戏界面简洁：中央是怪物，点击它造成伤害。顶部显示当前金币和伤害数值。底部或侧面是英雄列表和升级选项。

每个英雄会自动攻击怪物，每秒造成固定伤害。购买更多英雄或升级现有英雄可以提高总DPS（每秒伤害）。当怪物血量归零时，击杀成功，获得金币奖励。

随着击杀数量增加，会遇到更强大的怪物和Titan（泰坦，更强的精英怪）。泰坦出现时会有倒计时，需要在规定时间内击杀。击杀泰坦获得大量金币和特殊奖励。

游戏没有区域或层级概念，而是通过怪物强度递增来推进。玩家可以无限点击和击杀，数字增长没有上限。

## 核心循环

点击怪物造成伤害 → 击杀获得金币 → 购买英雄和升级 → 击杀更强怪物和泰坦

## 核心机制

- 英雄DPS系统：每个英雄提供固定的每秒伤害，累积效果显著。英雄数量越多、等级越高，总DPS越高
- 泰坦倒计时：限时挑战增加紧张感，击杀奖励丰厚。这是游戏中少有的主动压力机制
- 指数级成长：怪物血量递增，英雄伤害也需要指数级增长。这种数值设计是放置游戏的核心

## 为什么好玩

简单直接的玩法配合指数增长的数字带来纯粹的快乐。泰坦战的倒计时增加了紧张感和成就感。看着DPS从几增长到几百万，满足感十足。适合放松时随便点点。

## 粘性来源

DPS增长的视觉反馈——数字越大越想看更大的数字。泰坦战的限时挑战刺激重复尝试。英雄收集提供短期目标。无限增长的潜力让人停不下来。

## Meta 系统

英雄升级系统：每个英雄有多个升级等级，升级后DPS显著提升。英雄可以觉醒或进化，提供额外加成。对核心玩法的影响是持续提供新的DPS增长点。

## 实现难度

低 — 经典的点击游戏框架。最大技术难点是数值平衡，确保怪物难度与玩家DPS增长匹配，保持合适的挑战节奏。
