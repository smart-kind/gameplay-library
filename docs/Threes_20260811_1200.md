#  Threes!（三消数字）

- **类型**: 解谜 / 滑动拼图
- **平台**: Mobile (iOS+Android)
- **开发商**: Sirvo LLC
- **首次发布**: 2014
- **一句话描述**: 在 4×4 的网格上滑动方块，将相同数字配对合并，追求尽可能大的数字。

## 玩法规则

游戏在一个 4×4 的小网格上进行。初始时网格中有若干数字方块（1、2、3）。玩家可以选择上、下、左、右任意方向滑动整个网格。滑动后，所有方块都会朝该方向移动一格。

当两个相同数字的方块相撞时，它们合并成一个新方块，数值翻倍（1+1=2，2+2=4，3+3=6，之后 6+6=12，12+12=24，以此类推）。不同数字的方块不能合并——1 和 2 碰撞不会变化，只有完全相同的数字才能配对。

每次滑动后，网格边缘会新出现一个方块。新方块的类型取决于网格上已有的数字：早期主要出现 1、2、3，后期会出现更大的数字以及特殊方块（如 1.5 倍的奖励方块）。

游戏结束条件：当网格被填满且无法再朝任何方向滑动使方块合并时，游戏结束。此时网格中所有方块数值之和即为最终得分。

游戏的目标是尽可能合并出更大的数字，同时保持网格有足够的空间继续操作。

## 核心循环

滑动网格合并方块 → 获得更大的数字和更高分 → 在有限空间内持续操作直到无法移动

## 核心机制

- **四向滑动合并**：每次滑动整个网格移动一格，而非单个方块。这种设计让每一步都需要考虑全局影响，增加了策略深度。
- **数字配对规则**：只有相同数字才能合并（1 只能和 1 合并，3 只能和 3 合并），而非像 2048 那样的 2 的幂次合并。这迫使玩家同时维护多个数字线。
- **新方块生成**：每次滑动后系统自动在边缘生成新方块，逐渐压缩可用空间，形成自然的难度曲线。
- **特殊奖励方块**：偶尔出现 1.5 倍数值或更高价值的方块，增加运气成分和惊喜感。

## 为什么好玩

Threes! 是数字合并类游戏的始祖，比 2048 更早诞生。它的魅力在于：规则极其简单（滑动、合并），但每一步决策都有连锁反应——你合并了某两个方块，可能同时改变了其他方块的相对位置，影响后续操作。这种"牵一发而动全身"的设计让人欲罢不能。

## 粘性来源

- **空间压缩的紧张感**：随着网格越来越满，每一步操作都可能成为最后一步，这种紧迫感驱动玩家不断重试
- **"差一点就成功"的不甘心**：每次游戏结束都感觉"再滑动一次就能救回来"，促使玩家再来一局
- **数字收集的成就感**：看到网格上出现越来越大的数字有直观的视觉满足感
- **单局时间短**：一局通常几分钟，适合碎片化时间游玩

## Meta 系统

无。游戏没有外围成长系统，每局都是全新的独立体验，纯粹的益智挑战。

## 实现难度

低。核心逻辑仅涉及网格操作和方块碰撞检测，最大技术难点在于滑动动画的平滑性和新方块生成的算法设计（如何平衡随机性和难度曲线）。
