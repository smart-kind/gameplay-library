# Fancade 迷你游戏创作（Fancade: Simple Mini Games）

- **类型**: 游戏创作 / 休闲合集
- **平台**: Mobile (iOS+Android)
- **开发商**: Fancade
- **首次发布**: 2020
- **一句话描述**: 一款结合了游戏游玩和创作的平台，玩家既可以玩别人创作的小游戏，也可以自己创作游戏分享给社区。

## 玩法规则

平台提供两种主要功能：游玩和创作。在游玩模式中，玩家可以浏览和搜索社区创作的海量小游戏。

在创作模式中，玩家使用可视化工具搭建游戏：选择游戏元素（角色、道具、场景）、设置行为规则（移动、碰撞、得分）、测试和发布。

创作工具使用方块化的逻辑编程，无需编写代码。发布后的游戏立即出现在社区中。

## 核心循环

浏览游戏库 -> 游玩小游戏 -> 获得灵感 -> 创作自己的游戏 -> 分享 -> 获取反馈

## 核心机制

- 可视化游戏创作: 拖拽式编辑器加方块化逻辑编程，让任何人都能创作游戏。无需编程经验即可创建完整的游戏体验。
- 社区驱动内容: 海量玩家创作的游戏，内容无限增长。社区审核机制保证内容质量。
- 即时发布: 创作完成后一键发布，其他玩家立即可以游玩。创作者可以获得点赞和评论反馈。

## 为什么好玩

既可以享受游玩的乐趣，又可以体验创作的快乐。

看到别人玩自己创作的游戏有巨大成就感。从玩家到创作者的身份转变是平台最独特的价值主张。

## 粘性来源

创作分享的循环让人停不下来。社区内容的无限增长保证了总有新游戏可玩。

创作者的成就感是强大的粘性来源。看到自己的游戏被点赞和评论的社交反馈也激励创作者持续产出。

## Meta 系统

创作者统计：展示游戏的游玩次数、点赞数。

成就系统：完成创作里程碑获得徽章。

社交：关注喜欢的创作者。

## 实现难度

高 - 可视化游戏编辑器是最大技术难点。需要处理游戏逻辑解析、物理引擎、网络同步等复杂功能。
