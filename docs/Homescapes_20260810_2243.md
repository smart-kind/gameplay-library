# 三消+装修结合的休闲游戏（Homescapes）

- **类型**: 三消
- **平台**: Mobile (iOS+Android)
- **开发商**: Playrix
- **首次发布**: 2017
- **一句话描述**: 三消+装修结合的休闲游戏

## 玩法规则

核心玩法与Candy Crush类似的三消，但加入了装修元素。通过完成三消关卡获得星星，星星用于装修豪宅的不同区域（客厅、花园、厨房等）。

每个装修区域有多个选项供玩家选择，可以自定义装修风格。游戏有剧情元素，围绕管家Austin修复家族豪宅的故事展开。

三消关卡有特殊道具：火箭（消除整行/列）、炸弹（消除3×3区域）、彩虹球（消除同色）。

## 核心循环

玩三消关卡 → 获得星星 → 装修房间 → 解锁新区域/剧情 → 更多三消关卡

## 核心机制

- 三消+装修：用关卡胜利获得星星来装修
- 剧情驱动：Austin的故事线贯穿始终
- 装修选择：每个区域有多个装饰风格可选
- 特殊道具：火箭、炸弹、彩虹球

## 为什么好玩

三消的爽快感和装修的成就感结合，看着破旧的豪宅一步步变美丽。剧情也增加了情感投入。

## 粘性来源

装修进度的可视化；剧情驱动的好奇心；三消关卡的挑战性。

## Meta 系统

装修进度+故事线推进。

## 实现难度

低。三消玩法简单直观。最大技术难点：关卡设计难度曲线和装修渲染。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
