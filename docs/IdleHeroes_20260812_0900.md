# Idle Heroes

- **类型**: 放置 RPG
- **平台**: Mobile
- **开发商**: DHGAMES
- **首次发布**: 2016
- **一句话描述**: RPG 风格点击游戏——升级英雄、探索地牢、击败 Boss。

## 玩法规则

玩家升级英雄、探索地牢并击败 Boss。自动战斗系统让进度轻松，同时离线也能推进。强调团队策略和被动进度，适合休闲和硬核玩家。

英雄系统提供深度——不同英雄有不同技能和定位，团队搭配影响战斗效率。地牢探索提供额外挑战和奖励。

## 核心循环

升级英雄 → 探索地牢 → 自动战斗 → 击败 Boss

## 核心机制

- 英雄升级：提升角色等级和技能
- 地牢探索：额外挑战和奖励
- 自动战斗：轻松的进度推进
- Boss 战：高难度挑战
- 团队策略：英雄搭配影响效率

## 为什么好玩

轻松的自动战斗加上英雄收集的策略深度。适合休闲玩家，同时提供足够的深度满足硬核玩家。

## 粘性来源

- 自动战斗的便利：无需持续操作
- 英雄收集：丰富的角色选择
- 地牢挑战：额外内容增加重玩价值
- 团队策略：英雄搭配的深度

## Meta 系统

英雄升级和装备。提升英雄能力、解锁技能和获取装备。

## 实现难度

低。放置 RPG 核心系统成熟，英雄平衡是难点。
