# Crazy John

- **类型**: 休闲
- **平台**: iOS
- **开发商**: Unknown
- **首次发布**: 2010
- **一句话描述**: 一款经典移动平台游戏。

## 玩法规则

游戏为休闲关卡制解谜小游戏合集，以"Crazy John"这个角色命名，包含多种不同机制的小关卡。

玩家能做什么操作：
- 在每关中选择操作方式，可能包括点击、拖拽、滑动、长按等多种触控手势，每关的操作方式不同
- 根据关卡目标调整策略：有些关卡要求消除所有方块，有些要求到达指定位置，有些要求收集特定物品
- 反复尝试不同的解法以获得更高评分，部分关卡有多个可行路径，最优路径需要多次试验才能发现
- 观察每关的机制提示，理解当前关卡的特殊规则（如重力方向、弹跳规则、连锁反应等）

游戏目标：完成所有关卡并获得最高星级评价。每个关卡有独特的机制和规则，需要灵活应对。
星级评价基于完成效率（步数、时间、收集度等），追求全三星是核心长期目标。关卡难度循序渐进。

## 核心循环

完成小关卡 -> 获得星级评分 -> 解锁新关卡 -> 追求完美三星

## 核心机制

- 多样化关卡机制：每个关卡有独特的玩法机制和胜利条件，可能涉及物理弹射、路径规划、物品消除、顺序解谜等不同玩法
- 星级评价系统：每关根据表现给予1-3星评价，追求全三星驱动反复挑战
- 难度渐进设计：从简单直观的教学关开始，逐步引入新的机制和复杂度
- 重复游玩价值：多解法设计，每关可能有多种通关路径

## 为什么好玩

简单易上手、关卡制的设计让游戏随时可以来一局。每关的目标明确，完成后的成就感直接。适合碎片化时间游玩，不需要长时间投入也能获得满足感。多样化的关卡机制保持了新鲜感。

## 粘性来源

低门槛高上限：任何人都能玩但要获得全三星需要反复练习。关卡解锁的驱动力：想知道下一关是什么。随时可玩的便利性适合碎片时间。

## Meta 系统

- 关卡解锁：完成当前关卡解锁下一关
- 星级评价：追求三星评价驱动反复游玩
- 每日挑战：特殊每日关卡提供额外内容和奖励
- 成就系统：完成特定挑战获得成就

## 实现难度

低 -- 关卡制设计、简单的触控操作、明确的胜利条件。最大的技术难点是关卡设计的多样性，确保每关都有新鲜感。需要设计多种不同的游戏机制并保证每种机制的趣味性和平衡性。
