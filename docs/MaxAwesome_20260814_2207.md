# 超炫滑板（Max Awesome）

- **类型**: 街机 / 躲避
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发者
- **首次发布**: 2013
- **一句话描述**: 操控角色在高速移动中躲避障碍物的街机游戏，考验反应速度和路线规划

## 玩法规则

游戏画面呈现俯视或斜视视角，角色在道路上高速前进，前方不断出现各种障碍物（车辆、路障、坑洞、行人等）。玩家需要控制角色左右移动和跳跃来避开障碍物。

随着游戏进行，速度逐渐加快，障碍物密度增加，同时出现组合障碍（需要连续躲避多个障碍）。画面中有金币或道具散落，玩家需要在躲避障碍的同时尽量收集。

操作方式：滑动屏幕向左/右移动、向上滑动跳跃、向下滑动滑行（低头通过上方障碍）、长按加速。不同操作组合可以应对不同类型的障碍物。

游戏目标是在不断加速的环境中尽可能存活更长时间并获得更高分数。撞到障碍物游戏结束，分数基于存活时间和收集物品数量。

## 核心循环

高速前进 → 发现障碍 → 选择操作 → 成功躲避 → 速度加快 → 收集道具 → 创造高分

## 核心机制

- **无尽模式**：游戏没有终点，速度和难度持续增加直到玩家失败，追求高分是核心驱动力
- **多操作系统**：左右移动、跳跃、滑行四种基本操作，不同障碍物需要不同操作组合，考验反应和判断
- **风险收益**：金币和道具通常出现在危险位置（靠近障碍物），玩家需要权衡收集风险和收益
- **渐进难度**：速度、障碍物密度和复杂度逐步提升，让高手和低手都能找到适合自己的挑战层级

## 为什么好玩

高速躲避带来的紧张刺激感是最直接的体验反馈——每次成功躲过一排障碍的爽感和失误时的懊恼形成强烈的情绪波动，让人想"再来一局证明自己"。

## 粘性来源

"差100分就破纪录"的竞争欲、速度突破后的肾上腺素飙升、不同操作组合的实验乐趣。无尽模式保证了每局都是全新的挑战。

## Meta 系统

角色解锁系统：累积分数解锁新角色和皮肤，部分角色有特殊能力（如额外一条命、更宽的收集范围）。

## 实现难度

低。核心逻辑是碰撞检测和障碍物生成，2D或简单3D即可实现。最大技术难点是障碍物生成的节奏控制——需要保证难度渐进且不会出现无法躲避的死局。
