# 闪避先生（Mr. Shifty）

- **类型**: 动作 / 瞬移战斗
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: Team Shifty
- **首次发布**: 2017
- **一句话描述**: 在拥挤的敌人中用瞬移能力穿梭战斗，每次瞬移都是进攻和躲避的双重操作

## 玩法规则

游戏采用俯视角画面，玩家控制Mr. Shifty被关在一个充满敌人的巨大设施中。

核心机制是瞬移——玩家可以在范围内瞬间移动到任意位置。瞬移既是移动手段也是攻击手段：瞬移到敌人所在位置会对其造成伤害。

敌人种类繁多：近战兵、远程射击兵、持盾兵、Boss等。需要用不同的瞬移策略对付不同类型的敌人。

每关结束时会获得升级选项（如增加伤害、缩短冷却、扩大范围等），类似Roguelite的Build系统。

## 核心循环

瞬移到敌人处攻击 → 消灭当前房间敌人 → 获得升级 → 进入下一关

## 核心机制

- 瞬移即攻击：瞬移不是单纯的位移工具，而是核心攻击手段。瞬移到敌人身上的伤害判定让每次瞬移都是进攻决策。
- 空间策略：敌人密度越高，瞬移攻击的价值越大。但被远程敌人包围时需要先处理远程威胁。
- Roguelite升级：每关获得升级选项，Build方向影响后续关卡的战斗风格。

## 为什么好玩

在敌人堆里瞬移穿梭的流畅感，像动作片主角一样优雅地消灭整屋敌人。Build系统的多样性让每次体验不同。

## 粘性来源

瞬移战斗的流畅爽感 + Roguelite Build的多样性（每次升级选择不同，战斗风格完全不同） + "下一关会更酷"的好奇心。

## Meta 系统

Roguelite升级系统：每关获得升级选项（伤害、冷却、范围等），Build影响后续战斗风格。死亡后保留部分进度。

## 实现难度

中。瞬移机制 + 敌人AI + Roguelite Build。最大技术难点：瞬移攻击的判定范围设计——太大会让游戏变简单，太小会让操作变得繁琐。
