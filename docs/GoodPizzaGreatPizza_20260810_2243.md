# 披萨店模拟经营，按照顾客要求制作披萨（Good Pizza Great Pizza）

- **类型**: 休闲/模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: TAPBLAZE
- **首次发布**: 2018
- **一句话描述**: 披萨店模拟经营，按照顾客要求制作披萨

## 玩法规则

玩家经营一家披萨店，顾客会来下单（有些订单描述模糊，需要猜测）。

玩家需要铺面团、加酱料、放配料、烘烤，然后递给顾客。配料包括奶酪、意大利香肠、蘑菇、橄榄、青椒等。

正确的订单获得更多小费。

## 核心循环

接单 → 制作披萨 → 服务顾客 → 获得金币 → 升级设备/配料

## 核心机制

- 订单系统：顾客有不同口味和模糊要求
- 制作流程：铺面、加酱、放料、烘烤
- 小费系统：正确订单获得更高小费
- 升级系统：购买新设备和配料

## 为什么好玩

治愈的手绘画风和轻松的节奏。猜顾客想要什么的挑战性和制作披萨的满足感。

## 粘性来源

剧情驱动的顾客故事；升级收集。

## Meta 系统

设备升级+剧情解锁。

## 实现难度

低。操作简单。最大技术难点：AI顾客行为设计。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
