# Beeing

- **类型**: 休闲 / Casual
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2012
- **一句话描述**: 一款在移动平台上发布的休闲类型游戏

## 玩法规则

休闲小游戏。画面呈现简单的 2D 卡通风格，玩家控制一只小蜜蜂。

玩家点击屏幕控制蜜蜂向上飞，松开则蜜蜂自然下落（类似 Flappy Bird 的竖版变种）。场景中散布着花朵（得分点）和障碍物（蜂箱、蛛网等），需要精准控制飞行高度来收集花朵并躲避障碍。

收集花朵获得积分，撞到障碍物则游戏结束。部分版本有道具系统——护盾、磁铁、双倍积分等。

游戏目标是尽可能飞行更远，收集更多花朵，创造最高分记录。典型的"再来一局"循环。

## 核心循环

点击飞行 → 收集花朵得分 → 碰撞游戏结束 → 刷新挑战更高分

## 核心机制

- **点击飞行**：极简操作，点击上升松开下落
- **随机生成**：障碍物和花朵位置随机排列
- **道具系统**：护盾、磁铁等临时增益改变游戏节奏

## 为什么好玩

极简操作但很难精通，每次只差一点就能刷新记录时那种不甘心驱动着'再来一局'。分数不断攀升的即时反馈也很上瘾。

## 粘性来源

纯粹的高分竞争——每次刷新记录的多巴胺奖励。极简操作降低了重试成本，'就再试一把'的心理陷阱。

## Meta 系统

- **道具解锁**：通过积分解锁护盾、磁铁等临时增益道具
- **皮肤收集**：不同蜜蜂外观
- **对核心玩法的影响**：道具降低难度曲线，皮肤纯装饰

## 实现难度

低——Flappy Bird 变体，实现难度极低。最大的技术难点可能是随机障碍物生成的难度曲线设计，确保'难但可通关'的平衡。
