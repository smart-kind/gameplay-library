# 梦幻家园（Homescapes: Match 3 Games）

- **类型**: 三消 / 模拟装修
- **平台**: Mobile (iOS+Android)
- **开发商**: Playrix
- **首次发布**: 2017
- **一句话描述**: 一款结合三消解谜和房屋装修模拟的休闲游戏，玩家通过三消关卡获取星星来装修管家奥斯汀的豪宅。

## 玩法规则

游戏分为两个主要部分：三消关卡和装修系统。在三消关卡中，玩家在一个网格上交换相邻的彩色方块，使三个或更多相同颜色的方块连成一行或一列来消除它们。

消除方块会产生特殊道具：四个连成一线产生横向或纵向条纹方块，L或T形消除产生炸弹，五个连成一线产生彩虹球。特殊道具之间可以组合产生更强大的效果。

每个关卡有特定的目标（如消除一定数量的特定颜色方块、解救被困角色、收集物品等）和步数限制。完成关卡后获得星星，星星用于装修故事模式中的房间。

## 核心循环

完成三消关卡获得星星 -> 用星星装修房间 -> 解锁新房间和剧情 -> 挑战更难关卡

## 核心机制

- 三消核心玩法: 通过交换相邻方块匹配消除，产生特殊道具（条纹、炸弹、彩虹球），策略性地使用这些道具可以连锁反应清除大量方块。特殊道具组合是高分通关的关键策略。
- 装修进度系统: 每个装修选项消耗固定数量的星星，玩家需要在多个装修方案中选择（颜色、风格、布局等），给予一定的自主权和代入感。
- 叙事驱动: 游戏有完整的故事线，管家奥斯汀回到老家发现豪宅破败，决定修复它。剧情推进与装修进度绑定。
- 辅助道具系统: 玩家可以使用火箭、炸弹、彩虹球等局外道具辅助通关，这些道具可以通过日常任务获取或购买。

## 为什么好玩

三消解谜的爽快感与装修成就感的完美结合。每次消除连锁反应带来视觉和心理上的满足。

看到破败豪宅一步步变成豪华宅邸的成就感极强。每次完成一个房间的装修，玩家都能直观地感受到自己的努力成果。

## 粘性来源

差一步就能完成装修的不甘心感是核心粘性。关卡难度曲线经过精心设计，让玩家偶尔卡关但又不完全绝望。

装修的渐进式展示让玩家想看到完整的房间效果。故事情节也吸引玩家继续推进。定期活动提供限时装饰和特殊关卡。

## Meta 系统

装修系统：玩家消耗星星选择装修方案（颜色、风格等），影响房间外观。

角色互动系统：与NPC对话推进剧情。

活动系统：定期举办限时活动，提供特殊奖励和独家装饰。

## 实现难度

低 - 三消游戏机制成熟，有大量开源实现可以参考。最大技术难点在于关卡难度平衡和内容生成。
