# Chef Merge - Fun Match Puzzle（Chef Merge）

- **类型**: 三消/合并解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: 未明确
- **首次发布**: 2021
- **一句话描述**: 一款轻松休闲的合并解谜游戏，玩家通过合并元素来装饰豪宅和农场。

## 玩法规则

游戏界面呈现一个棋盘式布局，包含各种蔬菜和水果元素。玩家从手牌区域选择卡片，将其拖拽到棋盘上相邻的相同元素上，触发合并操作。当三个或更多相同元素相邻时，它们会合并成一个更高等级的元素。

每次合并都会解锁新的装饰元素或解锁地图上的新区域。玩家的目标是完成关卡目标（如合并特定数量的元素、达到指定分数或解锁特定装饰）。游戏采用体力系统，每次操作消耗一定的移动步数，步数用尽后需要等待恢复或使用体力道具。

## 核心循环

合并元素 → 获得奖励和装饰 → 解锁新区域和更高等级元素 → 继续合并挑战更高级目标

## 核心机制

- **合并机制**：拖拽相同元素相邻合并，三个相同合并为一个更高等级元素，类似于2048的数值递增逻辑
- **装饰系统**：合并获得的奖励可用于装饰农场和豪宅，增加视觉满足感
- **关卡目标**：每个关卡有特定的完成条件，引导玩家有策略地进行合并操作

## 为什么好玩

游戏将合并玩法与装饰玩法结合，玩家在解谜过程中获得可见的农场建设成就感。轻松的音乐色彩和缓慢的游戏节奏适合碎片时间游玩。

## 粘性来源

装饰系统的渐进式满足感——看到自己的农场从荒芜到繁茂是核心驱动力。合并操作本身的简单直觉性让上手毫无门槛，而关卡目标的逐步升级则维持了长期挑战。

## Meta 系统

- **体力系统**：限制单次游玩时间，鼓励多次短时间登录
- **装饰收集**：通过关卡解锁各种装饰物品，形成收集驱动力
- **关卡进度**：线性关卡地图，每个关卡提供新的合并挑战和奖励

## 实现难度

低 — 合并逻辑和关卡设计都是成熟的休闲游戏模式。最大技术难点在于关卡平衡（确保每个关卡在限定步数内可完成且有一定挑战度）。
