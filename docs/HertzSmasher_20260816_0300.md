# Hertz Smasher

- **类型**: 声波解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 2011
- **一句话描述**: 声波解谜游戏，利用声波作为武器摧毁目标
- **PocketGamer评分**: 5/10

## 玩法规则

玩家利用声波作为武器，通过发射不同频率的声波来摧毁目标。游戏界面中，声波以可见的波纹形式从发射点向外扩散，触碰到目标时造成破坏。

玩家需要控制声波的发射方向、频率和强度。不同频率的声波对不同材质的目标有不同的破坏效果——某些目标只对特定频率产生共振响应。游戏中存在多种障碍物和反射面，声波可以在墙壁之间反弹，形成复杂的声波路径。

每个关卡给出需要摧毁的目标列表，玩家需要在有限的发射次数内完成所有目标。游戏的策略性在于利用声波的反射特性，通过一次发射摧毁多个目标。然而游戏的关卡设计相对简单，场景缺乏变化，这也是评分不高的原因。

## 核心循环

放置/操作 → 获得奖励/进展 → 升级/解锁新内容 → 挑战更高难度

## 核心机制

- **机制1**：声波解谜核心循环 — 通过声波解谜操作完成关卡目标，获得金币/分数奖励
- **机制2**：渐进式难度 — 每个关卡引入新的元素或增加复杂度，玩家需要调整策略
- **机制3**：资源管理 — 有限的建造材料/金币/时间，需要玩家做出取舍决策

## 为什么好玩

Hertz Smasher利用声波作为武器，但关卡设计相对简单，场景缺乏变化。 游戏的评分为5/10，说明这款游戏有一定亮点但也有明显不足。

## 粘性来源

具体到机制层面：核心循环的"完成关卡→获得奖励→解锁新内容"驱动玩家持续游玩；渐进式难度带来的挑战感让玩家想"再来一关"；解谜类游戏特有的"顿悟时刻"（想通了解法）提供强烈的成就感。

## Meta 系统

外围成长系统：通过关卡获得的金币/分数可以解锁新的塔类型/角色/赛道，或升级已有元件的性能。对核心玩法的影响：解锁内容提供了新的策略选择，但不改变核心操作方式。

## 实现难度

中 — 核心玩法基于成熟的声波解谜机制，最大技术难点在于流畅的手势识别和实时物理反馈。
