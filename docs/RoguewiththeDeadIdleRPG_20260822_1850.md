# 亡灵肉鸽（Rogue with the Dead: Idle RPG）

- **类型**: 放置 / Roguelike / RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: room6 inc.
- **首次发布**: 2022
- **一句话描述**: 在无尽的循环旅程中指挥队伍战斗——死亡不是结束，而是变强的开始

## 玩法规则

Rogue with the Dead 是一款结合了Roguelike和放置元素的RPG游戏。玩家指挥一支队伍在无尽的循环旅程中战斗、死亡、变强。

游戏采用2D像素风格画面。玩家控制一支由不同角色组成的队伍，在地图上自动前进并遭遇敌人。战斗是自动进行的，但玩家可以在战前布置队伍阵型和选择技能。

每次死亡后，队伍会保留部分经验和装备，以更强的姿态重新开始。死亡不是结束，而是变强的一部分——这是Roguelike的核心机制。

队伍中的每个角色有独立的等级、技能和装备。玩家通过战斗获得经验值和掉落物品，用于提升角色能力。随着旅程推进，会遇到越来越强的敌人和更稀有的装备。

游戏最终目标是击败魔王（Demon Lord），但每次旅程的路线和遭遇都是随机的。即使同一角色队伍，不同轮次的体验也会截然不同。

## 核心循环

布置队伍 → 自动战斗 → 获得经验和装备 → 死亡后保留进度 → 以更强姿态重新开始

## 核心机制

- 死亡变强机制：每次死亡后保留部分进度，下次旅程从更强的起点开始。消除了死亡挫败感，转化为动力
- 队伍组合策略：不同角色有不同技能和定位，玩家需要合理搭配。战士、法师、辅助的组合策略增加深度
- Roguelike随机性：每轮遇到的敌人和掉落物品都是随机的，确保体验不重复

## 为什么好玩

把Roguelike的'死亡也是进步'理念与放置游戏完美结合。每次死亡都不令人沮丧，因为你知道自己变强了。队伍组合提供了策略深度。像素风格的画面复古而可爱。

## 粘性来源

'死亡也是进步'的核心理念消除了挫败感。队伍养成提供了长期目标。Roguelike的随机性确保每轮体验不同。击败魔王的终极目标驱动持续游玩。

## Meta 系统

队伍养成系统：角色等级、技能和装备在死亡后部分保留。解锁新角色和技能。对核心玩法的影响是提供长期的养成目标和进度感。

## 实现难度

中等 — 需要实现战斗系统、角色养成、随机掉落等。最大技术难点是Roguelike随机性与进度保留之间的平衡设计。
