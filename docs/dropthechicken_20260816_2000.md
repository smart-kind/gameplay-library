# 放下那只鸡（Drop the Chicken）

- **类型**: 物理益智
- **平台**: Mobile (iOS+Android)
- **开发商**: Chillingo
- **首次发布**: 2012
- **一句话描述**: 画线引导鸡安全落入巢穴的物理益智游戏

## 玩法规则

画面中有一只鸡悬在空中，目标是画线（木头、绳索、弹簧等物理元素）引导鸡安全落入下方的巢穴。玩家用手指在屏幕上滑动画出线条，松手后线条变成物理实体。鸡在重力作用下开始下落，沿着画好的路径滑行。

鸡在下落过程中不能碰到尖刺、火焰等障碍物，也不能掉落太快摔伤。玩家需要在有限的材料预算内设计路径。材料类型影响行为：木头线条是刚性的，提供硬支撑和转向平台；绳索只能承受拉力，可以悬挂重物但不能推动物体；弹簧线条可以弹射鸡到更高位置。

部分关卡需要收集途中的星星或彩蛋，这要求设计额外的迂回路径。后期关卡引入风扇（产生向上的气流）、传送门（空间跳跃）、移动平台等元素，增加解题复杂度。物理引擎确保每次模拟的一致性，玩家可以预测线条的效果。

## 核心循环

观察关卡 → 画线设计路径 → 释放鸡观察物理模拟 → 成功或调整路径

## 核心机制

- **多材料物理系统**：木头（刚性支撑/可承重/可转向）、绳索（只能受拉/可悬挂/可摆动）、弹簧（弹射/可存储和释放弹性势能）各有独特物理行为。材料选择直接决定了解题策略
- **物理一致性与可预测性**：每次模拟遵循相同物理规律（重力、摩擦力、碰撞反弹），玩家可以学习并预测结果。这种一致性是游戏可玩性的基础——失败是因为设计问题而非随机因素
- **收集元素与路径优化**：部分关卡有隐藏星星需要额外路径设计才能收集。这迫使玩家在'安全通过'和'完美收集'之间做取舍，增加策略深度


## 为什么好玩

画线的自由度高，同一关卡可以有多种解法——没有'标准答案'，只有'能不能过'。鸡的可爱动画和失败时的搞笑效果（被弹飞、被扎成筛子）增添娱乐性，让失败也不那么沮丧。

## 粘性来源

'差一点就成功了'的心理+寻找完美解法（收集所有星星）的追求。关卡数量多且难度递进，持续提供新挑战。材料预算限制迫使每次尝试都需要思考。

## Meta 系统

关卡解锁制，无复杂外围系统。部分版本有成就系统和每日挑战。

## 实现难度

低 —— 画线操作直觉简单，老人小孩都能上手。最大技术难点是物理引擎的准确性和手绘线条到物理实体的转换精度。
