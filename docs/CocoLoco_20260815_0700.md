# 可可疯狂（Coco Loco）

- **类型**: 解谜 / 休闲 / 物理弹射
- **平台**: Mobile (iOS)
- **开发商**: Twiitch
- **首次发布**: 2012
- **一句话描述**: 受愤怒的小鸟启发但加入流体物理的创新益智游戏，玩家用棒球棒弹射棉花糖伙伴，利用巧克力洪流解救被困朋友。

## 玩法规则

游戏背景设定在巧克力国度，玩家的棉花糖朋友被绑架并被迫穿上难看的派对服装。

玩家操控一个手持棒球棒的超级棉花糖。向后拖动手指控制弹射力度，上下滑动调整弹射角度，松手后将棉花糖射出。

每个关卡是由方块和障碍物构成的谜题结构。玩家拥有限定数量的甜点弹射物，每种甜点有特殊能力：膨胀果冻、相扑棉花糖（肚皮砸击）、忍者棉花糖（挥剑切割）等。

游戏的核心创新在于巧克力液体系统。关卡中散布着巧克力池和管道，玩家需要利用弹射物堵住缺口、利用物理原理引导巧克力洪流淹没目标区域，或引爆巨大的凝胶结构让巧克力如海啸般倾泻。

通关条件为利用巧克力淹没所有被困棉花糖的牢笼，解放所有伙伴。
## 核心循环

规划弹射路线，射出甜点弹射物，触发巧克力流体连锁反应，淹没牢笼解放伙伴，解锁新关卡

## 核心机制

- **流体物理系统**：巧克力液体具有真实的流动、汇聚和波动效果，是游戏最大的创新点。玩家可以引导巧克力海啸淹没目标
- **弹射加特殊能力**：向后拖拽控制力度和角度的弹射机制，配合不同甜点的特殊能力（膨胀、砸击、切割）
- **结构破坏解谜**：通过弹射物破坏关卡中的方块和障碍物结构，创造巧克力流通的通道
- **堵洞引流**：用果冻等弹射物堵住管道缺口，利用物理引导巧克力流向目标方向

## 为什么好玩

巧克力流体的视觉效果令人惊艳，第一次翻转容器看着巧克力覆盖整个关卡时的快感难以言表。流体物理的加入让破坏的快感升级。

游戏的甜点角色设计各具特色：膨胀果冻会在落地后扩大体积堵住通道，相扑棉花糖的重力砸击可以压碎多层结构，忍者棉花糖则能精准切割特定目标。每种甜点都有其最佳使用场景。

关卡设计中融入了大量物理互动元素：倾斜的管道、可触发的阀门、多米诺式的连锁结构。玩家需要理解这些元素之间的因果关系才能制定有效方案。

巧克力流体的物理模拟是游戏的技术核心。液体需要表现出流动、汇聚、飞溅、滴落等多种物理效果，同时还要与固体障碍物产生合理的交互。

部分关卡引入了时间要素，如限时巧克力喷发或逐渐上升的巧克力液位，增加了紧迫感。
## 粘性来源

巧克力流体的视觉快感是主要粘性来源。看着自己精心策划的连锁反应最终引发巧克力海啸的满足感极强。但部分关卡回归传统弹射公式，缺乏创新变化，可能让人失望。

## Meta 系统

无成长系统。纯关卡制解谜体验，进度体现在解锁后续关卡和完成全部棉花糖解救上。

## 实现难度

中等。最大技术难点在于流体物理模拟的计算性能（巧克力的流动、汇聚、波动效果）以及与刚性碰撞体的交互。
