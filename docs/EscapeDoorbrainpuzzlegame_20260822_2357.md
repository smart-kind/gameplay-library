# 逃离之门：脑力解谜（Escape Door- brain puzzle game）

- **类型**: 解谜 / 逃脱
- **平台**: Mobile (iOS+Android)
- **开发商**: FTY LLC.
- **首次发布**: 2019
- **一句话描述**: 通过解开各种脑筋急转弯和逻辑谜题来打开门、逃离房间的益智解谜游戏。

## 玩法规则

每个关卡呈现一扇（或多扇）关闭的门，门上或周围有一个谜题需要解决。谜题类型多样：数学题、图形推理、找规律、文字游戏、视觉错觉、逻辑推理等。

玩家通过点击、拖拽、滑动等操作与谜题互动。例如：数学题需要输入数字答案；图形题需要旋转或拼接图形；文字题需要填入缺失的字母或词语；视觉题需要找出画面中的不同之处。

每解开一个谜题，门就会打开或前进到下一个谜题。部分关卡有多个门，需要依次解开所有门上的谜题才能通关。有些谜题设有误导性答案——看似合理但实际错误，考验玩家的思考深度。

游戏不提供教程，玩家需要自行摸索操作方式。这种'无引导'设计是游戏的核心体验之一——学会游戏规则本身就是解谜的一部分。

## 核心循环

观察谜题 → 尝试解法 → 获得反馈（对/错） → 调整思路 → 打开门进入下一关

## 核心机制

- 无引导设计机制：游戏不教玩家怎么玩，操作规则、交互方式都需要自己发现。这种设计让'学会玩'本身成为解谜的一环，增强了成就感。
- 多类型混合机制：数学、图形、文字、逻辑、视觉等谜题类型交替出现，防止玩家形成固定思维模式。每次开门都是新的认知挑战。
- 误导与反转机制：部分谜题的答案违反直觉，玩家需要跳出常规思维。解出反转答案时的'原来如此'顿悟感是游戏的核心爽点。
- 渐进复杂度机制：早期谜题简单直接（如'1+1=?'），后期谜题融合多种元素（数学+图形+文字），需要综合运用多种思维方式。

## 为什么好玩

每扇门都是一次'啊哈时刻'的机会。解谜成功的瞬间认知闭环带来强烈的智力满足感，而谜题类型的不断变化让大脑始终处于新鲜刺激中。

## 粘性来源

'就差一步'效应——很多谜题差一点就能想出来，这种认知张力让人停不下来。同时，多样化的谜题类型确保不会因为某一类不擅长而卡死。

## Meta 系统

纯关卡推进，无外围系统。完成全部关卡即通关。部分版本设有'提示系统'，通过看广告获取解谜线索。

## 实现难度

中等。单个谜题逻辑简单，但设计大量有趣且不重复的谜题需要强大的创意。最大难点在于谜题难度的平滑递增——太简单无挑战，太难则令人沮丧。


游戏中的谜题设计有意违反玩家的预期——例如看似是数学题但实际需要观察图形，看似要点击但实际需要长按或滑动。这种'反预期'设计是游戏的核心趣味来源：当你以为你懂了规则的时候，游戏会告诉你'不是这样'。这种不断的认知颠覆让大脑保持活跃和好奇。
