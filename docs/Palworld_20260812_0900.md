# Palworld

- **类型**: 生存 / 怪物收集
- **平台**: PC / Xbox
- **开发商**: Pocketpair
- **首次发布**: 2024
- **一句话描述**: 怪物收集 + 生存建造的独特混合——捕捉"Pal"让它们为你工作。

## 玩法规则

玩家在开放世界中生存，捕捉名为"Pal"的生物并利用它们进行战斗、采集、建造和农业生产。游戏结合了怪物收集（类似 Pokemon）和生存建造（类似 Ark）两种类型。

核心循环是探索世界、捕捉 Pal、建造基地、让 Pal 工作。Pal 可以自动采矿、种植、制造物品和守卫基地。战斗中玩家可以骑乘 Pal 或使用武器与 Pal 并肩作战。

游戏支持多人合作——最多 32 名玩家可以在同一服务器上建立各自的基地并互动。

## 核心循环

探索世界 → 捕捉 Pal → 建造基地 → 让 Pal 工作 → 继续探索

## 核心机制

- Pal 捕捉：使用 Pal Sphere 捕捉野生生物
- 基地建设：建造自动化设施让 Pal 工作
- 开放世界生存：采集资源、制造物品、应对威胁
- 多人合作：最多 32 人服务器
- 战斗系统：骑乘 Pal 或使用武器

## 为什么好玩

怪物收集和生存建造的巧妙结合。让 Pal 替你工作的设定既有趣又有效，自动化带来的满足感极强。

## 粘性来源

- Pal 工作的满足感：看到自动化基地运转的成就感
- 收集欲：数百种 Pal 等待捕捉
- 基地建设：从简陋营地到自动化帝国的成长
- 多人互动：与好友合作的乐趣

## Meta 系统

Pal 解锁和科技研究。捕捉新 Pal、研究新科技、扩建基地。

## 实现难度

高。开放世界生存 + 怪物收集 + 多人服务器需要整合多个复杂系统。Pal AI 和网络同步是技术难点。
