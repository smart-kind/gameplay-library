# 潜行逃脱3D（Sneak Out 3D）

- **类型**: 超休闲/潜行
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2021
- **一句话描述**: 3D潜行逃脱小游戏

## 玩法规则

玩家控制角色在3D场景中潜行移动，避开守卫和障碍物到达终点。通过拖拽或虚拟摇杆控制角色移动方向和速度。需要观察守卫的巡逻路线和视线范围，在安全时机通过。部分关卡有掩体可供躲藏，有警报系统需要避开。被守卫发现则游戏失败。关卡逐渐增加守卫数量和巡逻复杂度。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

观察巡逻路线 → 规划路径 → 潜行通过 → 到达终点 → 下一关

## 核心机制

- **潜行机制**:  避开守卫视线和巡逻路线
- **时机把握**:  在安全窗口通过危险区域
- **关卡递增**:  守卫数量和路线逐渐复杂

## 为什么好玩

紧张的潜行氛围和成功逃脱的成就感

## 粘性来源

关卡难度递增带来的挑战欲；完美通关的追求

## Meta 系统

关卡解锁和星级评价系统

## 实现难度

中 - 需要AI巡逻路径和视线检测 - 3D场景中守卫AI的视野计算和路径规划
