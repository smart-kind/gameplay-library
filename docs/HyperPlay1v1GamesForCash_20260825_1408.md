## 核心循环

匹配对手 → 选择游戏 → 1v1对战 → 获得积分 → 提升排名

## 核心机制

- **1v1匹配系统**：根据实力匹配对手，确保公平性和紧张感
- **多游戏池**：多种类型可选，选择擅长领域
- **实时对战**：真人而非AI对手，增加不可预测性
- **积分排名系统**：胜得负扣，长期积累形成排名

## 为什么好玩

真人对战的紧张感——对手是真实的人，每一局都是独特挑战。多种游戏类型可选，总有擅长或喜欢的。快节奏对局，几分钟一局，适合碎片时间。

## 粘性来源

- **排名竞争**：不断提升排名是最大驱动力
- **真人对战不可预测**：每局对手不同体验不重复
- **快速对局**：几分钟一局门槛极低

## Meta 系统

- **积分排名系统**：ELO机制计算排名
- **赛季系统**：定期重置排名
- **成就/徽章系统**：完成特定成就解锁

## 实现难度

中 — 匹配系统和实时网络同步是技术难点，需处理延迟、掉线等。游戏内容实现难度视具体游戏而定。
