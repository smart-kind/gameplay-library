# Lifeline（生命线）（Lifeline）

- **类型**: 文字冒险 / 叙事
- **平台**: Mobile (iOS+Android)
- **开发商**: 3 Minute Games, Inc.
- **首次发布**: 2015
- **一句话描述**: 一款实时叙事文字冒险游戏，玩家通过文字对话帮助一位身处陌生星球的宇航员Taylor做出生存决策。

## 玩法规则

游戏界面类似即时通讯聊天应用，以纯文字对话的形式呈现整个游戏体验。玩家收到来自角色Taylor的消息，对方描述当前处境、感受并征求玩家的意见和建议。

玩家的操作是阅读消息并从给出的选项中选择回复。选项通常是二选一的建议，例如先探索周围环境还是留在原地等待救援，或者走左边的小路还是右边的山路。

游戏采用独特的实时机制，角色的行为与真实时间同步。Taylor走路需要几分钟，睡觉需要几小时，建造庇护所可能需要更久。玩家可能在白天收到消息，晚上才收到Taylor行动后的回复。

游戏目标是通过一系列正确的选择帮助Taylor存活并最终获救。不同选择分支会导致完全不同的故事走向和结局，包括多个好结局和坏结局。

## 核心循环

收到求救消息 → 分析情况做出选择 → 等待角色执行行动 → 收到新消息和结果反馈 → 循环推进故事

## 核心机制

- **机制1**：实时叙事机制：角色的行为与真实时间同步进行，走路需要几分钟，睡觉需要几小时。这创造了独特的期待感和真实感，你确实在等待一个真实人物的行动。推送通知让Taylor的消息随时可能出现，打破了游戏与现实的边界。
- **机制2**：分支叙事机制：每个选择点都会影响后续故事走向和角色命运。看似小的决定可能产生蝴蝶效应，导向完全不同的故事结局。某些选择会永久关闭某些故事线，增加了选择的分量。
- **机制3**：信息不对称机制：Taylor只描述他能看到的东西和当前的感受，玩家需要从碎片化信息中推理全貌。这种盲人摸象式的解谜增加了沉浸感和参与感，玩家像是一个远程顾问。

## 为什么好玩

它把文字冒险做出了真实感，当你收到深夜推送通知说我找到了一扇门时，那种代入感是传统游戏很难提供的。每个决定都像在拯救一个真实的人，这种责任感让游戏体验格外独特。

## 粘性来源

叙事悬念驱动想知道接下来发生什么加上实时等待机制制造期待加上多结局鼓励重玩探索不同分支，叙事类游戏中罕见的强重复游玩设计。

## Meta 系统

成就系统解锁不同结局和章节，系列有多部续作推进不同角色的故事。角色有隐藏的生命值、饥饿度、精神状态等指标影响故事走向。

## 实现难度

中 -- 技术实现不难，核心挑战在于编写高质量的分支叙事内容和维护多条故事线的一致性。需要专业的叙事设计师和大量的文案工作量。

## 叙事结构说明

游戏采用三幕式叙事结构：第一幕Taylor在陌生星球坠毁并建立基本生存，第二幕发现神秘建筑并深入探索，第三幕面临关键抉择决定最终命运。每个幕之间有明确的时间跳跃和情节点转折。

## 角色状态系统

虽然Taylor不会直接显示数值，但游戏中有隐藏的状态指标：生命值（受伤会降低）、饥饿度（长时间未进食会影响判断力）、精神状态（孤独和恐惧会影响消息内容）。这些状态会影响可选择的选项和最终结局。
