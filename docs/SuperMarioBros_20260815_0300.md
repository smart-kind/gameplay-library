# 滑雪大冒险（Ski Safari）

- **类型**: 无尽跑酷 / 休闲
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Sleepy Giant
- **首次发布**: 2012
- **一句话描述**: 控制滑雪者在雪山中疯狂下滑，躲避雪崩，骑上各种动物加速前进的无尽跑酷游戏。

## 玩法规则

游戏采用横版卷轴视角，画面从左向右滚动。玩家控制一位穿着睡衣的滑雪者从山顶急速下滑，身后是不断追赶的雪崩。操作方式非常简单——点击屏幕跳跃，长按屏幕后空翻。在空中时向左/右滑动可以调整飞行方向。

滑雪者在滑行过程中会自动加速，坡度越陡速度越快。途中会遇到各种障碍物：树木、岩石、雪堆、冰块、悬崖等，需要通过跳跃来躲避。撞到障碍物会减速，连续减速过多会被雪崩追上，游戏结束。

游戏的核心亮点是可以"骑乘"途中遇到的动物——企鹅、雪人、驯鹿、老鹰、yeti等。每种动物有不同的特性：企鹅在雪地上滑行快但不能飞，老鹰可以带玩家短暂飞行越过悬崖，驯鹿可以跳跃更高更远。骑乘状态下撞障碍只会失去动物而不会减速太多，相当于额外的保护盾。

沿途散布着金币、宝箱和特殊道具。金币可以在商店购买新的滑雪服（每种服装有不同属性加成）。宝箱中可能开出特殊道具或金币。关卡没有明确终点，追求的是滑行距离和收集的金币数。

## 核心循环

下滑收集金币 → 购买新服装提升属性 → 滑行更远、速度更快 → 挑战更高分数

## 核心机制

- **地形自适应滑行**：坡度决定速度，上坡减速、下坡加速，玩家需要根据地形预判跳跃时机
- **骑乘系统**：骑上动物获得不同能力，每种动物有独特移动方式和特殊技能
- **后空翻加分**：在空中长按完成空翻动作可获得额外分数和加速，但时机掌握有难度
- **雪崩追赶机制**：雪崩从后方不断推进，速度逐渐加快，给玩家持续的时间压力
- **道具收集系统**：金币、宝箱、磁铁道具、加速道具等增加游戏变数

## 为什么好玩

Ski Safari将"逃跑"的紧张感和"滑雪"的畅快感完美结合。雪崩从背后追赶的画面制造了天然的时间压力，而骑上企鹅滑行、骑老鹰飞越悬崖的瞬间又带来了极大的视觉满足感。操作简单但精通有难度——何时跳跃、何时后空翻、何时利用动物特殊能力，每个决策都在毫秒之间。

## 粘性来源

- **距离挑战**：每次都想突破自己的最远距离记录
- **服装收集**：不同外观的滑雪服提供属性加成和视觉变化
- **动物收集**：解锁新动物带来全新的玩法体验
- **"差一点"的不甘心**：雪崩追上的瞬间往往只差几秒，驱动再来一局

## Meta 系统

金币商店系统——通过滑行收集的金币可以购买不同滑雪服（提升速度、护盾时间、金币加成等属性）和解锁新动物。服装分为不同稀有度，高级服装需要积累大量金币。

## 实现难度

低 — 无尽跑酷+2D卷轴是成熟的游戏类型。最大技术难点在于地形生成的平衡性——需要保证难度曲线平滑，不能突然出现过难的障碍组合，也不能过于简单。雪崩追赶速度的动态调节也是关键。
