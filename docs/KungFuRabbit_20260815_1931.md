# Kung Fu Rabbit

- **类型**: 平台跳跃 / 动作 / 解谜
- **平台**: Mobile (iOS) / Wii U / Nintendo 3DS
- **开发商**: Pastagames
- **首次发布**: 2012
- **一句话描述**: 控制一只兔子在各种平台间跳跃穿梭，利用墙壁反弹和特殊能力通过关卡。

## 玩法规则

游戏画面为3D视角的平台关卡，玩家控制一只可爱的功夫兔子在三维空间中移动。关卡由各种平台、墙壁、弹跳点和障碍物组成。

操作方式：
- **虚拟摇杆/方向键**：控制兔子的移动方向（前后左右）。
- **跳跃按钮**：兔子向前跳跃。核心机制是**墙壁反弹**——兔子撞到墙壁后会自动反弹，玩家可以利用这个特性在两面墙壁之间连续反弹来攀升高度。
- **二段跳**：部分版本支持空中再次跳跃，增加移动灵活性。

关卡的核心挑战是**路径规划**——玩家需要观察关卡结构，找到正确的墙壁反弹序列和跳跃时机来从起点到达终点。错误的反弹角度可能让兔子掉入深渊或撞到障碍物。

某些关卡有特殊机关：移动平台、旋转风扇、传送门、开关等。部分关卡还有限制条件（时间限制、收集品数量要求等）。

## 核心循环

观察关卡 → 规划反弹路线 → 执行跳跃 → 到达终点/收集物品 → 解锁新关卡

## 核心机制

- **墙壁反弹系统**：这是游戏最核心的机制。兔子碰到墙壁会自动以一定角度反弹。玩家需要利用反弹来跨越鸿沟、到达高处或绕开障碍。反弹角度由入射角度决定，需要预判。
- **关卡解谜**：每个关卡本质上是一个空间解谜——如何从A到B？答案不是唯一的，但最优路径往往需要多次尝试才能发现。
- **收集系统**：每个关卡有胡萝卜（collectibles）散布在难以到达的位置，收集全部胡萝卜增加挑战性。
- **难度递增**：后续关卡引入更多机关和更复杂的空间布局，要求更精准的反弹操作。

## 为什么好玩

Kung Fu Rabbit 的独特之处在于它把"失败"变成了学习过程——每次撞墙反弹都是对关卡结构的一次探索。可爱的兔子形象和搞笑的物理反弹动画让失败也变得有趣。当玩家终于找到正确的反弹路径时，会有强烈的解谜成就感。

## 粘性来源

- **解谜快感**：发现正确路径后的"啊哈！"时刻。
- **全收集挑战**：每关的隐藏收集品驱动重复游玩。
- **可爱的角色和物理反馈**：兔子的反弹动画有趣，即使失败也不会太沮丧。

## Meta 系统

无 — 独立关卡制，无成长或解锁系统。

## 实现难度

**中** — 墙壁反弹的物理计算是核心难点，需要确保反弹角度可预测但又不太过简单。最大技术难点在于关卡设计和物理调校之间的平衡——太简单缺乏挑战，太难则令人沮丧。
