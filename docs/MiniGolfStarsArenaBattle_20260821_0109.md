# Mini Golf Stars (迷你高尔夫竞技对战)

- **类型**: 休闲竞技 / 体育模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: Game Masons, LLC
- **首次发布**: 2012
- **一句话描述**: 一款3D迷你高尔夫模拟游戏，提供精确的推杆控制和丰富的障碍球场

## 玩法规则

玩家在一个3D高尔夫球场中进行推杆比赛。游戏界面显示球道、障碍物（风车、水塘、沙坑等）和球洞位置。玩家通过滑动屏幕控制击球方向、力度和旋转。

操作分三步：第一步，拖拽确定击球方向，屏幕上出现一条瞄准线，拖动调整角度。第二步，滑动力度条设定击球力度，力度越大球飞得越远，但可能越过球洞。第三步，可选择加上旋或下旋影响球的滚动轨迹。

球击出后受物理引擎影响，会因坡度减速、碰墙反弹、落入障碍区等。每个球洞有标准杆数（par），用少于标准杆的杆数把球打进洞即为好成绩。

游戏目标是完成全部球洞，总杆数最少者获胜。每关有3星评分系统：1星完成即可，2星需要在标准杆内完成，3星需要低于标准杆。

游戏支持多人对战模式，多名玩家在同一个球场上轮流击球。每人完成当前洞后，进入下一洞，最终比较总杆数排名。多人模式下可以看到其他玩家的球的位置和击球路线，增加竞争感。

## 核心循环

观察球道布局 -> 设定方向/力度/旋转击球 -> 球进洞或停在新的位置 -> 调整策略继续击球直到入洞

## 核心机制

- **三阶段击球系统**：方向瞄准、力度设定、旋转选择，将高尔夫的核心操作分解为可精确控制的步骤，让玩家感受每一杆都是自己的选择
- **物理引擎模拟**：真实的球体碰撞、坡度减速、墙面反弹，让每次击球结果可预测但需要经验积累
- **多障碍设计**：风车、水塘、沙坑等障碍物增加策略性，需要规划击球路线而非简单瞄准
- **多人轮流竞技**：多名玩家在同一球场轮流击球，总杆数最少者获胜，增加社交竞争感

## 为什么好玩

每一杆都是策略与技巧的结合，打出一记完美的一杆进洞带来的成就感无可替代。多人对战时看着对手失误而自己精准入洞的快感让人上瘾。

## 粘性来源

精准击球带来的完美一杆爽感反馈，多人对战的社交竞争，3星评分系统的收集驱动。每次看到差一点就进洞的不甘心让人想再试一次。

## Meta 系统

角色皮肤和球场解锁系统。玩家通过完成关卡获得硬币，用于购买新角色皮肤和解锁特殊球场。对核心玩法无影响，但提供收集动力。

## 实现难度

中等 -- 三阶段击球系统需要一定学习成本，物理引擎的可预测性需要经验积累。最大技术难点是3D物理模拟的精确性和跨设备一致性。
