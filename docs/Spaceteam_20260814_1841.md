# Spaceteam（Spaceteam）

- **类型**: 社交合作 / 派对
- **平台**: Mobile (iOS+Android)
- **开发商**: Cooperica
- **首次发布**: 2013
- **一句话描述**: 2-8名玩家合作操作一艘太空飞船的搞笑多人派对游戏

## 玩法规则

每位玩家在自己的手机屏幕上看到一组不同的控制面板，面板上有多个开关、滑块、按钮和输入框。每个控制项目都有特定的科幻名称（如"Hyperdrive Flux Capacitor"、"Laser Cannon Calibration"、"Subspace Receptor"）。

游戏开始后，某个玩家的屏幕上会出现操作指令（如"Set Hyperdrive to 7!"、"Toggle Quantum Flux Switch"），但执行该指令的控件可能在另一个玩家的屏幕上。

玩家必须大声喊出指令（"谁有Hyperdrive？设为7！"），拥有对应控件的玩家找到并操作该控件后确认。指令需要在限定倒计时内完成。

飞船会不断受到损害，指令出现频率和数量随时间持续增加。如果未能在倒计时结束前完成所有当前指令，飞船就会爆炸，全员Game Over。

游戏中随机出现特殊事件：陨石雨（需要全员快速点击）、黑洞（需要特定操作序列）、外星人入侵（需要特定玩家执行操作）等，增加混乱度。

## 核心循环

接收指令 → 大声沟通找到对应控件 → 完成操作 → 更多更复杂的指令涌来

## 核心机制

- **信息不对称合作**：指令出现在A的屏幕上，但执行控件在B的屏幕上。玩家必须通过语言沟通来匹配指令和控件。信息分散在多个设备上，天然产生混乱和搞笑场面。这是游戏最核心的设计，也是乐趣的源泉。
- **压力递增系统**：随着游戏进行，指令数量从每轮1个增加到3-4个，倒计时从15秒缩短到5秒。同时出现的新控件类型让玩家需要记住更多名称和功能。时间压力是核心体验，玩家在慌乱中出错是最搞笑的时刻。
- **事件驱动特殊机制**：随机出现的全船事件要求所有玩家同时参与或按特定顺序操作。这些事件打破常规节奏，制造高潮时刻和额外混乱。

## 为什么好玩

这是少数真正需要面对面大声沟通的游戏。玩家之间大喊"谁有Quantum Flux？！"的场面极其搞笑。适合3-6人聚会，是完美的派对破冰游戏。即使不懂游戏的旁观者也会被氛围感染。

## 粘性来源

社交乐趣（每次游戏体验因玩家互动而完全不同）+ 难度递增（更高难度需要更好的团队协作和沟通能力）。游戏不依赖数值成长，而是依赖玩家之间的默契提升。

## Meta 系统

无 — 纯核心玩法游戏，无外围成长系统。游戏价值完全来自核心体验本身。

## 实现难度

中 — 需要完善的多人设备同步机制和实时通信。最大的技术难点是确保所有玩家设备的指令同步、低延迟通信，以及处理网络中断的优雅降级。
