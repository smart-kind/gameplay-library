# Shift 2（重力翻转2）

- **类型**: 平台跳跃 / 解谜
- **平台**: Mobile (iOS+Android) / Web
- **开发商**: Armor Games / Nitrome
- **首次发布**: 2011
- **一句话描述**: 通过翻转重力改变角色行走方向，在充满障碍的关卡中到达终点

## 玩法规则

玩家控制一个在平台上移动的角色。核心操作只有一个：翻转重力。按下按钮后，角色会从天花板掉落（或从地面浮起），原来在脚下的平台变到头顶。

关卡中布满各种障碍物：尖刺、陷阱、移动平台、敌人。玩家需要在正确的时机翻转重力来避开障碍，同时收集关卡中的星星或道具。

重力翻转不仅改变角色的行走方向，也改变所有物理效果——掉落物、移动平台、水流等都会受重力影响。这意味着翻转重力不仅是移动手段，更是解谜工具。

部分关卡有时间限制，需要在限定时间内到达出口。

## 核心循环

观察关卡布局 → 翻转重力改变行走方向 → 躲避障碍收集道具 → 到达出口 → 下一关

## 核心机制

- **重力翻转（Gravity Flip）**：唯一操作按钮，按下后整个世界的重力方向反转。角色从天花板掉落或从地面浮起，所有物体都受重力影响
- **物理解谜（Physics Puzzles）**：关卡设计利用重力变化创造解谜元素——翻转时机、落点预判、障碍物躲避都需要精确计算
- **时机掌握（Timing）**：很多关卡要求在特定时刻翻转重力，早一秒晚一秒都会失败，需要精确的操作
- **收集要素（Collectibles）**：每关散布星星/道具，增加挑战性和重玩价值

## 为什么好玩

单一操作按钮（翻转重力）创造了极其丰富的玩法变化。每次翻转都是一次"世界倒转"的体验，视觉和操作上的反差感很强。

## 粘性来源

具体到机制层面：1）翻转重力带来的"世界颠倒"视觉冲击和新鲜感；2）"差一点就过"的关卡设计让人忍不住再试一次；3）收集星星的完美主义驱动；4）随着关卡推进，翻转与时机的配合越来越精妙。

## Meta 系统

关卡解锁系统。完成一定数量的关卡后解锁新区域，新区域引入新的障碍类型和机制。

## 实现难度

中。最大的技术难点是物理系统的实现——重力翻转后所有物体的运动状态需要正确重新计算，包括速度、加速度、碰撞检测。平台碰撞和角色动画也需要适配双向重力。
