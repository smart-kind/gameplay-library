# 酒吧问答（PubQuizwithFriends）

- **类型**: 社交问答
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer 收录独立游戏
- **首次发布**: 2012
- **一句话描述**: 一款可以与朋友一起玩的问答游戏，模拟酒吧问答比赛的社交体验

## 玩法规则

游戏界面模拟酒吧问答的氛围，有温暖的灯光、木质桌面等视觉元素。主界面提供创建房间和加入房间的选项。

游戏支持多种模式：
- 好友对战：创建房间邀请朋友加入，进行实时问答对抗
- 随机匹配：与陌生人随机配对进行问答
- 单人挑战：独自完成题库中的问题，挑战个人最高分
- 团队模式：组队对抗，队员可以讨论答案

问题涵盖多个领域：科学、历史、地理、娱乐（电影/音乐/电视）、体育、文学、艺术等。每个问题有四个选项，玩家需要在限定时间内（通常15-30秒）选择答案。

计分规则通常是：答对得分，答错不扣分。速度越快得分越高（有些版本有时间加成）。游戏结束后显示排名、正确答案和每题的用时统计。

游戏支持聊天功能，玩家可以在房间中交流。部分版本有自定义题库功能，可以添加个人问题。

## 核心循环

创建或加入问答房间 → 在限定时间内回答问题 → 获得积分 → 查看排名和统计 → 再来一局

## 核心机制

- **多人实时对战系统：支持2-8人同时进行问答，实时显示答题进度和排名，营造竞争氛围**
- **丰富题库系统：涵盖科学、历史、地理、娱乐、体育、文学等多个领域的数千道问题，定期更新补充**
- **限时答题机制：每道题15-30秒的答题时间限制，增加紧张感和刺激感。速度加成鼓励快速作答**
- **社交互动功能：房间聊天、战绩分享、好友排行榜等社交功能，增强游戏的社交属性**

## 为什么好玩

将传统的酒吧问答体验搬到手机上，可以随时随地与朋友比拼知识。涵盖多领域的题库让每个人都有擅长和不擅长的领域，增加了趣味性和话题性。

## 粘性来源

社交竞争和知识展示的双重满足感。好友间的问答竞争天然具有很强的重复游玩动力。每周更新的题库保持内容新鲜度。

## Meta 系统

积分排名系统、成就系统、好友排行榜。部分版本有赛季模式和段位系统。

## 实现难度

低，知识问答为主，操作简单。最大技术难点在于题库的维护更新和反作弊机制。
