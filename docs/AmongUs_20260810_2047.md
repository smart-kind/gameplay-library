# Among Us（Among Us）

- **类型**: 社交推理 / 多人派对
- **平台**: Mobile (iOS+Android) / PC (Steam) / Switch / PS / Xbox
- **开发商**: Innersloth
- **首次发布**: 2018（2020年疫情期间爆红）
- **一句话描述**: "太空狼人杀"——伪装成船员完成任务，同时找出藏在你们中的内鬼

## 玩法规则

4-15 名玩家在一艘太空飞船/空间站内，每人扮演两种身份之一：船员（Crewmate）或内鬼（Impostor）。船员占大多数（如 10 人中 2 个内鬼）。

船员的目标：完成分布在飞船各房间的任务（接线、刷卡、倒垃圾、扫描等小操作），全部任务完成后船员获胜。

内鬼的目标：悄悄击杀船员 + 破坏飞船系统（关灯、断氧、反应堆等制造混乱），让内鬼人数 >= 船员人数时内鬼获胜。

游戏核心在于"会议机制"——任何人发现尸体可以报警，所有人聚集开会讨论。通过语音/文字交流，分析谁的行为可疑、谁的不在场证明有漏洞。讨论结束后投票投票处决嫌疑人。

## 核心循环

各自分散活动（船员做任务 / 内鬼杀人搞破坏）→ 发现尸体开会 → 讨论推理投票 → 处决或跳过 → 继续 → 某方满足胜利条件

## 核心机制

- 机制1：信息不对称——内鬼知道所有内鬼身份并能穿过通风管道快速移动，船员只能通过观察行为、不在场证明和逻辑推理来揪出内鬼
- 机制2：社交表演——内鬼需要假装做任务（实际上站在任务点前读进度条）、编造不在场证明、嫁祸他人；船员需要观察、推理、说服投票
- 机制3：任务小游戏——船员的任务是各种简单的迷你操作（记忆密码、对齐管线、监控摄像头等），让玩家有事可做而非纯等待

## 为什么好玩

这是一场"说谎的艺术"。内鬼在"骗到所有人"时获得极大的社交快感，船员在"识破谎言"时获得推理的满足感。每局都是不同的人际动态和心理博弈，重复可玩性极高。

## 粘性来源

社交竞争（和朋友玩停不下来）+ 随机身份分配（每局体验不同）+ 人际动态变化（同样的人在不同局扮演不同角色）+ 新地图和新任务持续更新

## Meta 系统

皮肤/帽子/宠物/颜色收集——纯装饰性，通过游戏内货币解锁。不影响游戏性。后续加入了排位模式和更多地图。

## 实现难度

中。技术难点在于：（1）多人网络同步——所有玩家状态、位置、任务进度需要实时同步；（2）房间和匹配系统；（3）反作弊（内鬼外挂是实际问题）。MVP 可以先做本地多人或简化版房间制。核心逻辑本身不难，难的是网络层的稳定性。
