# 滚球大师（Going Balls）

- **类型**: 跑酷 / 物理平衡
- **平台**: Mobile (iOS+Android)
- **开发商**: Supersonic Studios
- **首次发布**: 2019
- **一句话描述**: 控制球在狭窄的3D赛道上滚动，躲避障碍、收集金币，挑战速度和平衡

## 玩法规则

玩家看到的是一条蜿蜒曲折的3D赛道，赛道由各种材质的平台拼接而成——木板、玻璃、金属、传送带等。一颗球位于赛道上，自动向前滚动。屏幕左右两侧是虚空（掉下去即失败），赛道宽度有限，有时窄到仅容球通过。

玩家用手指左右滑动屏幕来控制球的左右移动，目的是保持在赛道中央不掉落。赛道上散布着收集品（金币、钻石）和特殊道具（加速、护盾）。同时赛道上会出现各种障碍：移动的挡板、旋转的风扇、突然消失的平台段、弹跳板等。

游戏的目标是尽可能远地前进，到达赛道终点即过关。掉落赛道外则本关失败，需要重新开始。每关赛道设计不同，有些赛道会倾斜、旋转或分段连接，增加了操作难度。

## 核心循环

左右滑动控球 → 收集金币+躲避障碍 → 到达终点/掉落后重来

## 核心机制

- **自动滚动+手动偏移**：球自动向前滚，玩家只负责左右偏移。这种半自动设计降低了上手门槛，但赛道的复杂性保证了持续挑战。
- **赛道材质多样性**：木板赛道较稳，冰面赛道球会打滑，弹簧板会把球弹起，传送带会加速或减速。不同材质改变球的运动物理参数。
- **动态障碍物**：移动的挡板需要预判其运动轨迹，旋转的风扇需要找到间隙通过，突然断裂的桥段需要加速冲过。这些障碍不是固定的，而是随时间变化。
- **收集品激励**：金币可以解锁新球皮肤（纯外观），给玩家额外的收集动机。
- **速度递增机制**：随着关卡推进，球的滚动速度逐渐加快，反应时间窗口越来越短。高级关卡中球速快到几乎需要"盲操"。

## 为什么好玩

Going Balls 的核心乐趣在于"惊险边缘"的刺激感——球在窄道上摇摇欲坠、几乎要掉下去的瞬间又被拉回来。这种紧张和释放的交替循环制造了强烈的心流体验。赛道设计创意十足，从简单的直道到复杂的多层立体赛道，每关都有新花样。

## 粘性来源

速度感+收集欲+挑战欲的三重驱动。每关的赛道都在变化，玩家不知道下一个弯道后面是什么。金币收集提供了短期目标，皮肤解锁提供了中长期目标。"差一点就过"的不甘心推动重复尝试。全球排行榜和每日挑战模式增加了竞争维度。

## Meta 系统

金币收集 → 解锁球皮肤（外观变化，不影响玩法）。皮肤种类繁多，从经典球到各种主题造型（水果、动物、星球等），满足收集癖。部分皮肤需要看广告获取。赛季通行证提供限时皮肤。

## 实现难度

中 — 需要完整的3D物理引擎（球体滚动、碰撞、重力、摩擦力），赛道生成和相机跟随系统。最大的技术难点是精确的碰撞检测和流畅的相机运动，尤其是在球在复杂赛道上高速滚动时保持相机稳定。

赛道环境会随时间变化——白天/夜晚、晴天/雨天，影响能见度和赛道摩擦力。不同的天气条件还会影响赛道材质的物理属性。
