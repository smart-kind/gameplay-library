# Squad Alpha (特种小队射击)

- **类型**: 休闲射击 / 动作闯关
- **平台**: Mobile (iOS+Android)
- **开发商**: SayGames LTD
- **首次发布**: 2021
- **一句话描述**: 一款横版休闲射击游戏，自动射击但方向由玩家控制

## 玩法规则

玩家控制一个小队角色在横版场景中向前推进，自动射击前方的敌人。界面下方是移动控制杆，角色面向屏幕右侧前进。

核心操作是滑动调整射击方向：向上滑动，枪口朝上射击；向下滑动，枪口朝下射击；不滑动则水平射击。角色自动向前移动，遇到敌人时自动开火，但射击方向由玩家控制。

场景中有不同类型的敌人：普通士兵（直线行走）、盾牌兵（需要绕后射击）、直升机（空中飞行，需要向上射击）、炮塔（固定位置，需要优先摧毁）。击败敌人后掉落金币和装备碎片。

游戏目标是完成每个关卡，击败关底Boss。Boss有血条和多种攻击模式，需要躲避弹幕的同时找准时机输出。收集金币可升级武器、解锁新角色。

部分关卡有特殊机制：移动平台（需要跳跃时机）、炸药桶（可引爆造成范围伤害）、医疗包（恢复生命值）。这些元素要求玩家不仅要射击，还要利用环境取得优势。

## 核心循环

控制射击方向消灭敌人 -> 收集金币和装备 -> 升级武器解锁新角色 -> 挑战更强的关卡和Boss

## 核心机制

- **自动射击加方向控制**：降低瞄准门槛，保留策略选择（打哪个、往哪打）
- **敌人类型差异化**：盾牌兵、直升机、炮塔等需要不同应对策略，增加战斗深度
- **Boss战弹幕躲避**：在射击的同时需要走位躲避，制造紧张感
- **环境互动元素**：炸药桶、移动平台、医疗包等增加战斗策略维度

## 为什么好玩

自动射击降低门槛，但精准控制射击方向仍能展现技巧。Boss战的弹幕躲避让人肾上腺素飙升。

## 粘性来源

武器升级的数值成长，Boss战胜利的成就感，角色收集解锁。差一点就过的不甘心驱动重复尝试。

## Meta 系统

武器升级系统加角色收集。收集金币升级武器伤害、射速、弹夹，解锁新角色（不同武器和外观）。装备系统直接影响战斗效率。

## 实现难度

中等 -- 自动射击加方向控制的核心机制不难。最大技术难点是弹幕系统的性能和多种敌人AI的行为设计。
