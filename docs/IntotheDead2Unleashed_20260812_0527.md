# 勇闯死人谷 2：解放（Into the Dead 2: Unleashed）

- **类型**: 动作/生存
- **平台**: Mobile (iOS+Android)
- **开发商**: PikPok（Netflix）
- **首次发布**: 2023（Netflix版）
- **一句话描述**: 僵尸生存动作游戏，玩家穿越僵尸群拯救家人。

## 玩法规则

无尽跑酷与第一人称射击的结合。玩家在僵尸肆虐的环境中自动前进，瞄准并射击威胁，同时收集武器和弹药。目标是生存并到达安全地带保护家人。

玩家通过滑动瞄准和点击射击来控制，需要在奔跑中应对从四面八方涌来的僵尸。不同武器有不同射速、伤害和弹药量。

## 核心循环

穿越关卡 → 射击僵尸 → 收集武器/弹药 → 躲避障碍 → 到达检查点 → 升级装备 → 下一关

## 核心机制

- 自动跑酷战斗：角色自动前进，玩家专注于瞄准和射击
- 武器收集：寻找并切换不同威力的枪械
- 家人保护：以拯救家人为驱动的故事推进

## 装备与升级系统

武器系统包含手枪、霰弹枪、步枪等多种类型，每种有多个变体。升级包括伤害、射速、弹匣容量等属性。

狗狗伙伴系统允许玩家携带一只忠诚的犬类同伴，狗狗可以预警危险并协助战斗。狗狗也可以升级技能。

## 为什么好玩

紧张的僵尸射击与自动跑酷结合，创造了反射性玩法和生存张力的独特融合。

## 粘性来源

武器升级、故事推进和持续应对越来越难的僵尸群的挑战。
