# Asura Cross

- **类型**: 动作 RPG
- **平台**: Mobile (iOS)
- **开发商**: Unknown
- **首次发布**: 未知
- **一句话描述**: 一款休闲/解谜类手机游戏

## 玩法规则

玩家在游戏中控制一名角色在战场上移动和战斗。屏幕下方通常显示技能按钮，点击按钮释放不同的攻击技能或法术。敌人会按波次出现，玩家需要合理安排攻击顺序，优先消灭威胁最大的敌人。

战斗过程中角色会获得经验值，升级时可以选择提升攻击力、防御力或解锁新技能。游戏关卡通常以章节形式组织，每关有最终 Boss 等待挑战。

游戏画面采用卡通风格，角色设计融合东方神话元素。界面布局清晰，上方显示角色血量和关卡进度，下方为操作区。


## 核心循环

战斗获取经验 → 升级强化角色 → 挑战更难关卡

## 核心机制

- 波次战斗系统：敌人分多波出现，每波难度递增，考验玩家的资源管理能力
- 技能升级树：通过战斗获得技能点，分配到不同技能路线，形成独特的战斗风格
- Boss 战机制：每关末尾有 Boss 战，Boss 有特殊攻击模式，需要观察并找到应对策略

## 为什么好玩

融合了角色养成和即时战斗的快感，看着角色从弱小成长为强大的过程有很强的成就感。

## 粘性来源

数值成长带来的持续正反馈，配合收集新角色/装备的驱动力。

## Meta 系统

- 角色收集与养成系统：通过抽卡或关卡奖励获得新角色，提升等级和装备

## 实现难度

中等 — 战斗系统设计不复杂，但角色养成和关卡策略需要一定投入，最大的技术难点是技能系统的平衡性。
