# 口袋政治（Pocket Politics: Idle Money）

- **类型**: 放置 / 策略 / 模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: Kongregate, Inc.
- **首次发布**: 2016
- **一句话描述**: 自动化竞选筹款，雇佣说客，从基层一路晋升到世界总统

## 玩法规则

Pocket Politics 是一款政治主题的放置经营游戏。玩家从底层政治职员起步，通过赚取竞选资金、游说政客、获得背书，最终竞选世界总统。

游戏界面以政治层级为垂直进度条：从基层职员到市长、州长、总统，层层递进。每个层级需要达到一定资金目标才能晋级。界面上方显示当前职位和资金，中部是收入来源和升级选项，底部是特殊功能。

核心操作是点击或自动化收集竞选资金，用资金雇佣游说者、购买广告、获得政客背书。每个职位解锁新的资金来源和升级选项。游说者会自动为你赚钱，无需手动点击。

玩家可以获得著名政治家的背书，这些背书提供额外的资金加成。不同政治家提供不同类型的加成，需要策略性选择。当资金积累到一定程度后，可以竞选更高职位。

游戏最终目标是成为'世界总统'，但过程中每个职位晋升都会带来新的挑战和机遇。高级职位需要管理更复杂的资金网络和更多的说客。

## 核心循环

收集竞选资金 → 雇佣游说者和购买升级 → 获得政客背书 → 晋升更高职位 → 解锁新内容

## 核心机制

- 政治层级晋升：从基层到总统的清晰进度线，每晋升一层解锁全新内容。这种阶梯式设计提供了明确的阶段性目标
- 自动化游说网络：雇佣的游说者持续产生收入，逐渐减少对手动点击的依赖。游说者网络是收入自动化的核心
- 背书加成系统：获得政治家背书提供百分比加成，鼓励收集不同类型背书。不同背书的组合策略增加了深度

## 为什么好玩

把枯燥的政治竞选变成有趣的放置游戏，题材新颖。看着自己从无名小卒一路升到世界总统，成就感满满。政治家的背书收集增加了策略元素，需要权衡不同背书的加成效果。

## 粘性来源

晋升目标驱动——'再攒一点就能竞选市长了'。背书收集系统提供明确的短期目标。自动化收入让玩家享受'躺赚'的快乐。每个新职位都带来新的收入来源和升级选项，保持新鲜感。

## Meta 系统

职位晋升系统：每个职位是独立的进度关卡，晋升后解锁新的收入来源和升级选项。对核心玩法的影响是不断引入新的游戏元素，防止后期单调。背书系统提供跨职位的长期收集目标。

## 实现难度

低 — 经典放置游戏框架，加入政治主题包装。最大技术难点是数值设计和题材平衡，确保政治内容有趣但不冒犯，同时保持放置游戏的核心乐趣。
