# Elminage: Original (埃尔米纳奇：原版)

- **类型**: 地牢探索RPG / 回合制
- **平台**: PS Vita / PSP / DS / PC
- **开发商**: Starfish SD / drimsoft
- **首次发布**: 2008 (原作) / 2013 (PS Vita版)
- **一句话描述**: 经典第一人称地牢探索RPG，以高难度和深度角色定制著称

## 玩法规则

游戏是第一人称视角的地牢探索RPG。玩家创建并组建一支冒险队伍，在地牢中逐步深入探索，与怪物战斗并寻找宝藏。

游戏界面呈现第一人称的迷宫视图。玩家通过方向键控制队伍在地牢网格中移动。遇到怪物时进入回合制战斗界面，显示敌方信息和队伍成员状态。

战斗采用回合制，每个角色可以选择攻击、魔法、防御或使用道具。角色有职业（战士、法师、盗贼等）和等级系统，通过战斗获得经验值升级。

地牢中分布着宝箱、陷阱和隐藏通道。玩家需要使用特定道具或技能来解除陷阱和打开隐藏区域。

## 核心循环

探索地牢 → 与怪物战斗 → 获得经验值和物品 → 升级角色 → 深入地牢更深层

## 核心机制

- **职业系统**：多种职业各有独特技能和属性成长，队伍搭配影响战术
- **回合制战斗**：指令式回合制，需要考虑行动顺序和属性克制
- **地牢探索**：第一人称网格移动，地图需要玩家自行记录或使用道具绘制
- **物品合成**：收集材料合成更强大的装备和道具
- **永久死亡机制**：角色死亡不可恢复（取决于模式），增加紧张感和策略性

## 为什么好玩

高难度带来的成就感和复古的地牢探索体验，让玩家想起早期CRPG的黄金时代。深度的角色定制和队伍搭配提供了丰富的策略空间。

## 粘性来源

高难度挑战带来的成就感 + 深度角色养成的投入感 + 地牢探索的好奇心驱动 + "下一层会有什么"的未知吸引力

## Meta 系统

角色养成系统 — 多职业多路线的角色成长，每次创建角色都是一次新体验

## 实现难度

中 — 回合制RPG系统相对成熟，最大技术难点在于平衡性设计和地牢生成的趣味性
