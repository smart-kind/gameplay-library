# 丹哥平台冒险（Dan The Man Platformer）

- **类型**: 横版动作平台
- **平台**: Mobile (iOS+Android)
- **开发商**: Halfbrick Studios
- **首次发布**: 2015
- **一句话描述**: 由水果忍者开发商Halfbrick打造的复古横版动作游戏，融合平台跳跃和格斗元素，支持双人合作

## 玩法规则

游戏采用像素风格的2D横版画面，屏幕左侧为虚拟方向键，右侧为攻击和跳跃按钮。玩家操控主角Dan在多个关卡中前进。

Dan可以使用拳脚近战攻击，也可以拾取场景中的武器（如枪械、爆炸物）。近战攻击有连击系统——连续点击攻击按钮可以打出combo。

关卡中包含可破坏的环境元素和隐藏的收集品。某些墙壁可以被炸开露出隐藏的房间和宝箱。

游戏最大特色是支持双人合作模式（本地分屏或在线匹配），两名玩家可协同作战——一人吸引敌人注意力，另一人从背后攻击。

每关末尾设有Boss战，Boss有多种攻击阶段，需要找到攻击模式并针对性反击。

## 核心循环

闯关战斗 → 收集金币和道具 → 升级角色能力 → 挑战新关卡和Boss

## 核心机制

- 格斗与平台跳跃融合：既需要精确的跳跃来跨越障碍，又需要近身格斗技巧来消灭敌人。连击系统增加了战斗深度
- 合作模式：支持本地和在线双人合作，两名玩家可以互相配合、分担伤害。合作模式下关卡难度会自动调整
- 武器和环境互动：可拾取多种武器增加战斗变化，部分环境元素可被破坏

## 为什么好玩

Halfbrick标志性的流畅手感和丰富动画让每次战斗都充满视觉冲击。

合作模式带来双倍乐趣，两个玩家互相配合互相调侃的社交体验是游戏最大的卖点。

Boss战设计精巧令人印象深刻，每个Boss都有多阶段攻击模式，需要玩家不断调整策略。

## 粘性来源

合作模式天然具有社交粘性——和朋友一起玩的乐趣远超单人。关卡收集品和成就系统提供长期目标

## Meta 系统

角色升级系统：收集金币升级生命值、攻击力和特殊技能。服装和皮肤收集系统满足个性化需求

## 实现难度

中等 — 动作和平台跳跃的融合需要一定技巧。最大的技术难点在于双人同步和网络延迟处理
