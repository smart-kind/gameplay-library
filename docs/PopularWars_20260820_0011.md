# 人气大战（Popular Wars）

- **类型**: io 竞技 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Lion Studios
- **首次发布**: 2018
- **一句话描述**: 在地图上收集追随者并抢夺其他玩家的人群，以人数最多者获胜的 io 竞技游戏。

## 玩法规则

游戏在一个开放的二维地图中进行，地图上有建筑物、道路和各种障碍物。玩家控制一个角色在地图上移动，沿途会碰到分散的 NPC 追随者（可爱的小人），这些追随者会自动加入你的队伍。追随者会紧紧跟随在你身后，形成一条长长的人链。

玩家的核心操作是滑动屏幕控制角色移动。触碰地图上的散点追随者即可招募他们。当你遇到其他玩家时，如果你的追随者数量比对方多，你可以"吞噬"对方的追随者——从对方队伍末尾逐个抢夺过来。反之，如果你的数量更少，你的追随者会被对方抢走。

游戏目标是在规定时间内成为拥有最多追随者的玩家。游戏过程中地图是可破坏的，追随者会帮你推开小障碍物。当人数达到数百时，你就像一条巨大的蛇在地图上横扫。

## 核心循环

收集追随者 → 人数变多 → 攻击小队伍抢夺更多 → 保持领先直到时间结束

## 核心机制

- **追随者收集**：地图上随机分布追随者，触碰即自动加入队伍，是游戏的基础资源来源
- **人数压制**：通过比较双方追随者数量来决定抢夺方向，大吞小的机制天然制造紧张感和策略性——何时进攻、何时躲避
- **环境互动**：追随者数量足够多时可推开障碍物，人数越多机动性越受限，形成规模与灵活性的权衡

## 为什么好玩

人数从零星几个滚雪球到几百人的过程极具成就感，而随时可能被更大的队伍吞噬的威胁让游戏保持高度紧张。跟随你的一群小人的视觉效果也很可爱，形成"带兵打仗"的满足感。

## 粘性来源

- **滚雪球效应**：一旦领先就越来越强的正向反馈让人上瘾
- **翻盘刺激**：大队伍也可能被更大的队伍瞬间吞并，失败者可以快速重新开始再战
- **社交竞争**：多人实时对战，排行榜激发竞争欲

## Meta 系统

无

## 实现难度

低。核心是 2D 地图上的角色跟随逻辑和简单的碰撞检测。最大技术难点在于大量追随者（数百个）的跟随算法优化，需要确保流畅不卡顿。

## 补充：视觉反馈

追随者跟随时的群体行为使用简单的 flocking 算法（类似 Boids），每个人有独立的微小运动差异，整体看起来像一条有生命力的人龙。这种视觉反馈是游戏吸引力的重要组成部分。
