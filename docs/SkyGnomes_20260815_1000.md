# Sky Gnomes

- **类型**: 益智解谜 / Puzzle
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2012
- **一句话描述**: 一款在移动平台上发布的益智解谜类型游戏

## 玩法规则

益智解谜游戏。画面呈现天空主题的 2D 平台场景，玩家控制小矮人角色。

玩家通过点击/拖拽控制小矮人移动和跳跃，需要在浮空平台之间穿梭。关卡中有弹簧垫、风向装置、移动平台等机关辅助通过。

每个关卡有收集品（星星或宝石），部分需要特定路线或时机才能获取。角色有有限的生命值，掉落深渊或碰到障碍物会扣血。

游戏目标是通过所有关卡并尽可能收集更多物品。后期关卡加入时间挑战和更多机关组合。

## 核心循环

操控小矮人 → 通过平台关卡 → 收集宝石 → 解锁新关卡

## 核心机制

- **平台跳跃**：精准控制跳跃时机和距离
- **机关互动**：弹簧、风向、移动平台等辅助元素
- **收集品布局**：星星/宝石分布在危险位置增加挑战性

## 为什么好玩

天空主题的场景设计清新可爱，平台跳跃的精准操作带来挑战性和成就感。收集品的布局鼓励探索每条路线。

## 粘性来源

收集品全收集的强迫症驱动+关卡解锁的进度感。'差一个星星就完美'驱动反复挑战。

## Meta 系统

- **关卡解锁**：通过当前关卡解锁后续内容
- **收集品系统**：星星/宝石全收集提供额外成就感
- **对核心玩法的影响**：收集品不影响核心玩法，提供额外挑战目标

## 实现难度

中等——平台跳跃的核心逻辑清晰。最大的技术难点是精准的平台碰撞检测和流畅的角色动画过渡，以及关卡设计的趣味性。
