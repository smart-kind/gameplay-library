# 八卦港（Gossip Harbor）

- **类型**: 合成 / 剧情
- **平台**: Mobile (iOS+Android)
- **开发商**: Microfun Limited (Merge Games)
- **首次发布**: 2023
- **一句话描述**: 合成玩法与剧情故事结合的手游，玩家经营一家海边餐厅并揭开家族秘密。

## 玩法规则

主界面是一个合成棋盘，上面散布着各种物品（食材、工具、装饰品等）。

玩家拖拽两个相同等级的物品到彼此上，它们会合成一个更高等级物品。例如：两个1级番茄合成1个2级番茄酱，两个2级番茄酱合成3级披萨。

合成棋盘上方是剧情画面——一段对话或动画场景，讲述餐厅经营中发生的故事和角色之间的关系。

合成获得的物品可以用于完成订单（顾客需要的菜品）、修复设施（餐厅的桌椅、装饰）、推进剧情（解锁新的故事章节）。

棋盘上会定期刷新新的基础物品（从'发电机'或'宝箱'中产出），发电机有冷却时间，需要等待或看广告加速。

剧情中充满戏剧性元素：失散的家庭成员、神秘的访客、浪漫关系、商业竞争等。

## 核心循环

收集基础物品 → 合成升级 → 完成订单推进剧情 → 解锁新区域和故事 → 继续合成

## 核心机制

- 合成升级链：物品有多个等级（通常5-7级），玩家需要规划合成路径——是急着合成高级物品完成订单，还是保留低级物品为后续合成做准备
- 剧情驱动：每完成一定数量的订单或合成目标，就解锁一段新剧情，让合成不再是无意义的数值增长，而是有故事目标
- 能量限制系统：合成棋盘的空间有限，基础物品的产出受发电机冷却限制，需要管理库存和时间

## 为什么好玩

合成玩法的直觉爽快感（看到物品升级的满足感）与剧情的悬念感结合得很好。想知道'接下来会发生什么'驱动玩家持续合成，而合成的简单操作让大脑可以同时追剧情。

## 粘性来源

剧情悬念（'到底谁是反派'、'家人什么时候相认'）是核心留存动力；合成升级的收集满足感；每日登录奖励和限时活动提供持续回归理由；社交元素（好友互助、排行榜）。

## Meta 系统

角色等级和设施修复系统（核心进度）。每日任务和限时活动。能量/体力系统（限制单次游戏时长，鼓励多次返回）。可选广告加速（看广告获得额外基础物品）。内购选项：购买钻石加速合成和补充能量。

## 实现难度

低 — 合成机制是成熟的玩法框架，实现简单。最大挑战是剧情内容制作（需要大量对话和美术资源）和经济系统设计（合成链的数值平衡）。
