# Amaze!（Amaze!）

- **类型**: 休闲 / 益智 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Crazy Labs
- **首次发布**: 2019
- **一句话描述**: 滑动控制小球在3D迷宫中滑行，涂满所有路径即可过关

## 玩法规则

画面展示一个3D视角的迷宫网格。迷宫中的路径是空白的方块，玩家需要控制一个小球在这些路径上滑动。小球从起点开始，通过上下左右滑动来改变方向。

当小球滑过一条路径时，路径会被涂上颜色。目标是在不重复走已经涂过的路径的前提下，涂满迷宫中所有的路径方块。这类似于经典的"一笔画"谜题概念。

操作是通过滑动屏幕来改变小球的前进方向。小球会沿着当前方向持续滑动，直到遇到墙壁或边缘。玩家可以随时改变方向，但小球只能在未涂色的路径上转弯。

随着关卡推进，迷宫变得更复杂——路径更多、分叉更多、死胡同更多。后期的关卡需要仔细规划路线才能完成。

## 核心循环

滑动改变方向 → 涂色路径 → 规划路线 → 涂满所有路径 → 过关

## 核心机制

- **惯性滑动**: 小球沿当前方向持续滑动，不能中途停止。玩家需要在交叉点提前判断转向时机。
- **一笔画逻辑**: 每条路径只能涂一次，这意味着玩家需要找到一条能覆盖所有路径的路线。这种约束创造了强烈的解谜感。
- **视觉反馈**: 涂色后的路径有鲜艳的颜色变化，随着进度推进，整个迷宫逐渐被"点亮"，有很强的成就感。
- **渐进复杂度**: 迷宫从小到复杂，从简单到需要规划，自然的学习曲线。

## 为什么好玩

涂满迷宫时的视觉满足感极强——看着空白网格被一点点染上颜色，最后完成的那一刻有种"完美"的感觉。操作简单但策略深度充足。

## 粘性来源

- **完成感**: 涂满整个迷宫的视觉完成感极强
- **规划挑战**: "一笔画"的约束让每次移动都有意义，需要思考路线
- **渐进难度**: 从简单到困难的平滑过渡，保持挑战感
- **流畅操作**: 滑动控制的流畅性和即时响应创造舒适的交互体验

## Meta 系统

关卡推进系统——完成关卡解锁新迷宫。部分版本有主题皮肤和角色选择。

## 实现难度

低。核心是网格迷宫 + 路径涂色逻辑 + 滑动输入。最大难点在于关卡设计——需要确保每个关卡都有解，同时难度逐步增加。
