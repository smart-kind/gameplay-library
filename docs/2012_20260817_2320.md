# 2012末日求生（2012）

- **类型**: 冒险生存
- **平台**: Mobile (iOS+Android) / PC / Console
- **开发商**: Fuzzy Pixel (基于Roland Emmerich电影)
- **首次发布**: 2009
- **一句话描述**: 基于2012年末日灾难电影改编的动作冒险游戏，在各种灾难场景中求生。

## 玩法规则

游戏画面是第三人称视角，玩家控制电影中的角色在各种灾难场景中逃生。场景包括地震中的城市、洪水中的街道、火山爆发等。
操控：移动（方向键/虚拟摇杆）、跳跃（跳过障碍）、冲刺（短距离加速）、互动（拾取物品、开门、拉人）。
每个场景有时间限制或追逐机制——地震导致建筑物倒塌、洪水上涨、岩浆逼近等。玩家需要在灾难追上自己之前到达安全点。
场景中有需要解救的NPC（家人、其他幸存者），解救他们是关卡目标之一。某些路段需要推动障碍物或找到特定路径才能通过。
游戏有QTE（Quick Time Event）环节：在关键时刻屏幕上出现按键提示，需要在短时间内按对正确的键，否则角色会受伤或死亡。
关卡基于电影情节设计，按电影时间线推进。每个关卡的灾难场景不同（地震、海啸、火山、冰冻等）。

## 核心循环

在灾难场景中前进 → 躲避障碍物和危险 → 解救NPC → 到达安全点 → 进入下一个灾难场景

## 核心机制

- 环境灾难追逐：灾难元素（地震波、洪水、岩浆）从后方逼近，制造持续的时间压力和紧张感。回头看一眼灾难追到哪儿了
- QTE关键时刻：在特定节点需要快速反应按对按键，失败会导致角色受伤或需要重试。成功时的'好险'感很强
- 场景解谜：某些路段需要找到正确的路径或解决简单谜题（推动石块、打开机关）才能通过

## 为什么好玩

在灾难中逃生的紧张刺激感是核心体验。
QTE环节让过场动画变成了互动体验，'差一点就被砸到'的惊险感和成功逃脱的释然感很强烈。

## 粘性来源

电影情节推进的好奇心（'接下来会发生什么'）、关卡通关的成就感、以及隐藏要素的收集。

## Meta 系统

关卡解锁、成就系统、电影情节回顾。

## 实现难度

中 — 需要实现3D场景、动态灾难效果（地震、洪水）、QTE系统。主要技术难点在于场景的实时变化和物理碰撞，以及QTE节奏设计。


游戏还包含一些收集要素：在逃生过程中可以找到电影相关的纪念品和隐藏文件，收集它们可以解锁额外内容。某些关卡有多条逃生路线，探索不同路线会发现不同的挑战。
