# Asterix: Megaslap

- **类型**: 休闲 / 物理弹射
- **平台**: Mobile (iOS+Android)
- **开发商**: Ubisoft
- **首次发布**: 2013
- **一句话描述**: 用手指划圈给 Asterix 蓄力出拳，把罗马士兵打飞并砸中其他敌人

## 玩法规则

游戏画面中，Asterix 站在左侧，一排罗马士兵站在右侧瑟瑟发抖。屏幕布局简洁明了。

操作分为两步：首先用手指在屏幕上划圆形来给 Asterix 的拳头蓄力，然后向目标罗马士兵滑动方向挥拳。被击中的罗马士兵会飞上天空，最终撞击地面。

如果飞在空中的罗马士兵撞击到其他敌人，可以获得额外金币奖励。你的拳打距离也会转化为金币奖励。

赚到的金币可以用来购买特殊道具：披风（改善空气动力学，增加飞行距离）、鸟群（携带罗马士兵飞得更远）、缓冲垫（帮助弹跳更高，增加总距离）。这些道具随等级提升解锁，并可以通过升级来提高效果。

## 核心循环

划圈蓄力 → 挥拳打出罗马士兵 → 获得金币 → 购买/升级道具 → 打得更远

## 核心机制

- **蓄力方向系统**：划圈蓄力决定力量大小，滑动方向决定击打方向，需要同时控制两个变量
- **连锁碰撞**：飞出的罗马士兵撞击其他敌人可获得额外奖励，鼓励精准瞄准
- **道具升级系统**：披风、鸟群、缓冲垫三种道具各自影响飞行物理效果，组合升级形成数值成长

## 为什么好玩

划圈蓄力的操作在触屏上有一种独特的物理感——你能感受到拳头力量的积累。看到罗马士兵飞上天的场景本身就带有喜剧效果，配合 Asterix 这个经典漫画角色的加成，轻松有趣。但评测指出当拳力达到 100% 后，成绩更多取决于道具配置而非玩家技术，可能影响长期可玩性。

## 粘性来源

数值成长驱动——通过升级道具来不断刷新最高距离记录。道具解锁带来的"新玩具"效应也有一定粘性。但过度依赖道具而非技术可能削弱长期吸引力。

## Meta 系统

- **道具升级系统**：披风、鸟群、缓冲垫三种道具可分别升级，影响空气动力学、飞行弹性和携带能力
- **等级解锁**：随等级提升解锁新道具，驱动反复游玩
