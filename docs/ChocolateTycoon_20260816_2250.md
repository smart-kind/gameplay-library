# 巧克力大亨（Chocolate Tycoon）

- **类型**: 模拟经营 / 放置
- **平台**: Web / Mobile
- **开发商**: PopCap Games
- **首次发布**: 2004
- **一句话描述**: 经营一家巧克力工厂，从购买可可豆到制作各种巧克力产品，逐步扩大生意规模

## 玩法规则

玩家扮演巧克力工厂老板，核心玩法是购买原材料（可可豆、糖、牛奶等），在工厂中加工成各种巧克力产品（巧克力棒、夹心巧克力、巧克力蛋糕等），然后以更高价格出售赚取利润。

游戏流程：1）选择要购买的原材料数量；2）选择要生产的巧克力类型；3）等待生产完成；4）将产品运送到商店出售；5）用利润扩大工厂规模和生产线。

随着游戏推进，可以解锁更多巧克力配方、升级设备（提高产量和质量）、开设更多商店、雇佣员工。最终目标是建立全球最大的巧克力帝国。

市场价格会波动，玩家需要把握买卖时机——原材料便宜时囤货，巧克力需求高时大量出售。

## 核心循环

购买原材料 → 生产巧克力 → 出售获利 → 升级设备/扩大规模 → 生产更高价值的巧克力

## 核心机制

- **生产管理（Production Management）**：选择原材料组合、生产线数量、产品类型，不同组合影响产量和利润
- **市场交易（Market Trading）**：原材料和产品价格实时波动，需要把握买卖时机。低买高卖是核心策略
- **升级系统（Upgrades）**：用利润升级设备（更快生产）、解锁新配方（更高价值产品）、扩大规模（更多商店）
- **目标驱动（Goal-Driven）**：游戏设有里程碑目标（如赚取100万、解锁全部配方），给经营提供方向感

## 为什么好玩

模拟经营的满足感——看着自己的小作坊一步步变成巧克力帝国。价格波动的市场机制让每次买卖都有决策的乐趣。

## 粘性来源

具体到机制层面：1）数字增长的快感——看着资金从几百增长到几百万；2）新配方的解锁带来新鲜感；3）市场价格波动带来的"抄底"和"高位出货"的策略乐趣；4）目标达成后的成就感。

## Meta 系统

无。游戏为一次性经营体验，达到目标金额后游戏结束。部分版本有无尽模式。

## 实现难度

低。核心逻辑简单：购买→生产→出售→升级。最大的难点是经济平衡——需要确保游戏进程既不会太快（缺乏挑战）也不会太慢（玩家失去耐心），价格波动曲线需要精心调试。
