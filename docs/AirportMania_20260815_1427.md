# 机场大亨（Airport Mania: First Flight）

- **类型**: 时间管理/模拟
- **平台**: PC / Mobile (iOS/Android)
- **开发商**: Lunagames / SouthWind Software
- **首次发布**: 2008
- **一句话描述**: 玩家管理一个小型机场，调度飞机起降、加油、维修，在有限时间内服务所有航班并获得好评。

## 玩法规则

画面为俯瞰视角的机场地图，包含跑道、停机坪、航站楼、加油站和维修站。不同类型的飞机（客机、货机、私人飞机）从屏幕外飞入，需要降落、滑行到停机位、接受服务、然后起飞离开。

每种飞机有不同的服务需求：客机需要加油和乘客登/下机，货机需要装卸货物，VIP飞机需要额外的贵宾服务。每种服务都需要时间——飞机停在加油位上加油时不能做其他事。玩家需要决定让飞机在哪个停机位等待，什么时机开始加油，什么时机允许起飞。

关卡目标是在规定时间内服务所有航班，并获得至少一定数量的硬币。超时或服务质量太低（让飞机等待太久）会导致扣分甚至关卡失败。

操作：点击飞机选择服务，拖拽飞机到指定停机位，点击按钮开始/结束服务。

## 核心循环

飞机到达 → 安排停机位 → 提供所需服务（加油/维修/装卸） → 飞机起飞 → 获得收入

## 核心机制

- **资源调度**：有限的停机位和服务设施（加油站、维修站），需要优化分配。当多架飞机同时到达时，玩家需要决定优先级。
- **时间压力**：每架飞机有可接受的等待时间上限，等待太久会减少收入。玩家需要在"等服务设备空闲"和"让飞机等待"之间权衡。
- **连锁效应**：一架飞机延误会影响后续飞机的调度，形成连锁反应。好的调度需要全局规划。
- **收入管理**：收入用于升级设施（更多停机位、更快的加油设备），升级后能处理更复杂的航班组合。

## 为什么好玩

多任务管理的紧张感和"调度大师"的成就感完美结合。当你成功让8架飞机无缝衔接、没有一架等待过久时，那种运筹帷幄的感觉让人上瘾。每次升级设施后面对更复杂的航班组合，难度曲线设计精妙。

## 粘性来源

- **关卡递进**：每关航班更多、类型更复杂、设施限制更严格
- **升级系统**：用收入升级设施，解锁新能力和新关卡
- **星级评价**：每关根据服务质量给出1-3星评级，驱动追求完美
- **短局节奏**：每关2-3分钟，适合碎片时间

## Meta 系统

- **设施升级**：永久升级（更多停机位、更快服务速度、新航站楼）
- **新机场解锁**：达到一定条件解锁新机场（不同布局和规则）
- **对核心玩法的影响**：升级让后期关卡可玩，但不改变核心的调度循环

## 实现难度

中 — 核心是事件调度+资源管理+UI交互。最大技术难点在于调度算法的平衡——需要确保每个关卡都有解（可完成），但解法不唯一（给玩家策略空间）。
