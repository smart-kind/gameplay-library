# Hairy Tales

- **类型**: 冒险/平台跳跃
- **平台**: Mobile (iOS)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款童话风格的冒险平台游戏

## 玩法规则

玩家控制一个毛茸茸的角色在童话世界中冒险。通过虚拟按键控制移动和跳跃，在精心设计的关卡中收集物品并躲避敌人。

关卡设计融合了经典童话元素（如小红帽、三只小猪等），每个场景有独特的主题和机制。某些关卡需要利用环境道具来解谜。

画面采用手绘风格，色彩温暖。界面左侧为方向键，右侧为跳跃按钮。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

闯关收集物品 → 解锁新场景 → 探索更多童话世界

## 核心机制

- 平台跳跃：经典的左右移动和跳跃操作
- 环境互动：利用场景中的道具解决谜题
- 童话主题：每个关卡基于不同的经典童话故事

## 为什么好玩

精美的手绘画面和温馨的童话主题，适合所有年龄段。

## 粘性来源

全收集挑战和探索新场景的驱动力。

## Meta 系统

- 收集品系统：每个关卡有隐藏收集物
- 场景解锁：完成关卡解锁新童话世界

## 实现难度

低 — 2D 平台跳跃技术成熟，最大的技术难点是关卡设计和美术资源。
