# Need for Speed Most Wanted (2005 edition)

- **类型**: 竞速
- **平台**: Mobile (iOS+Android)
- **开发商**: EA
- **首次发布**: 2005
- **一句话描述**: 经典赛车游戏《极品飞车：最高通缉》的移动端版本

## 玩法规则

玩家驾驶高性能赛车在城市街道上竞速。通过倾斜设备或虚拟按键控制方向和加速/刹车。赛道上有警车追逐，需要躲避路障和直升机追踪。

游戏包含多个赛事和黑名单挑战。每场比赛前可以选择赛车和升级部件。碰撞会影响车辆速度和外观损伤。

画面采用写实 3D 风格，城市环境和车辆模型精细。界面下方为油门和刹车控制，中间为速度表和迷你地图。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

比赛获取奖金 → 升级赛车 → 挑战更强对手和更高黑名单排名

## 核心机制

- 警车追逐系统：比赛过程中有警车干扰，需要躲避路障
- 车辆改装：消耗奖金升级引擎、轮胎、氮气等部件
- 黑名单挑战：击败排行榜上的对手解锁新区域和赛车

## 为什么好玩

紧张刺激的警车追逐和精美的赛车画面，移动端最接近主机的竞速体验。

## 粘性来源

车辆收集升级和黑名单排名的竞争驱动。

## Meta 系统

- 车辆收集系统：解锁和购买不同品牌赛车
- 改装系统：引擎、外观、性能多维度改装

## 实现难度

高 — 3D 赛车需要大量资源和优化，最大的技术难点是移动端 3D 渲染性能和操控手感。
