# 戳青蛙2（Tap The Frog 2 (Pocket Frogs)）

- **类型**: 养成 / 收集 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: NimbleBit LLC
- **首次发布**: 2010
- **一句话描述**: 一款经典的青蛙收集和养成游戏，发现、收集、交易和繁殖超过35000种独特的青蛙。

## 玩法规则

游戏画面展示多个青蛙栖息地（池塘），每个池塘中可以放置不同种类的青蛙。屏幕底部有功能按钮：商店、繁殖、交易、探索等。

玩家通过以下方式操作：点击青蛙查看信息，在繁殖菜单中选择两只青蛙进行交配产生新品种。探索池塘可以发现稀有青蛙和道具。与其他玩家交易青蛙和栖息地装饰。

每只青蛙有独特的颜色、花纹和大小组合，通过不同品种交配可以产生新的变种。栖息地可以装饰各种物品，提升青蛙幸福度和繁殖效率。

游戏没有明确结束条件，目标是收集尽可能多的青蛙品种，打造美丽的栖息地。

## 核心循环

玩什么 → 得到什么 → 用来做什么：繁殖和收集青蛙装饰栖息地，探索发现稀有青蛙与朋友交易，继续收集更多品种

## 核心机制

- **青蛙繁殖系统**：两只不同品种青蛙交配可以产生新品种，颜色、花纹、大小随机组合。35000种以上组合提供巨大的收集空间，每次繁殖都像开盲盒
- **交易互动**：可以与朋友交易青蛙和装饰物，社交元素增强粘性。稀有青蛙的交易价值很高
- **栖息地装饰**：大量装饰物品可以自定义每个池塘的外观，不同装饰影响青蛙幸福度和产出。装饰风格可以完全个性化

## 为什么好玩

像集邮一样收集青蛙的满足感。每次繁殖都像开盲盒，不知道会诞生什么新品种的青蛙。离线也能玩的设计很贴心，随时上线都有收获。

## 粘性来源

收集欲（35000种以上青蛙）+ 繁殖随机性（每次都是惊喜）+ 社交交易（和朋友互通有无）+ 装饰自由度。图鉴填满的成就感极强。

## Meta 系统

- **青蛙收集图鉴**：记录和展示已收集的青蛙品种，图鉴完成度是核心追求目标
- **栖息地等级**：装饰提升栖息地等级，增加青蛙产出效率。高等级栖息地吸引更多稀有青蛙
- **对核心玩法影响**：高等级栖息地加快繁殖速度，但不改变核心机制。收集进度不影响操作方式

## 实现难度

低 — 纯点击操作，无时间压力，适合任何年龄层。最大技术难点在于大量组合数据的生成和管理。需要确保35000种以上的青蛙组合都能正确显示和交互。
