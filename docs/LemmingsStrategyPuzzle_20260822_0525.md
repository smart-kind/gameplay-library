# Lemmings（Lemmings: Strategy & Puzzle）

- **类型**: 策略解谜 / 经典移植
- **平台**: Mobile (iOS+Android), PC, 多平台
- **开发商**: DMA Design (原版) / Nicalis (移植版)
- **首次发布**: 1991 (原版) / 2020s (移动版)
- **一句话描述**: 经典策略解谜游戏的移动移植版，玩家需要指挥一群无脑前进的小人通过危险的关卡到达安全出口。

## 玩法规则

游戏画面采用2D横版视角，关卡中包含平台、墙壁、陷阱、悬崖等各种地形障碍。一群被称为"Lemmings"的小人会持续从入口点出现并沿着当前方向前进——他们不会思考、不会转弯、不会躲避危险，只会一路向前直到遇到障碍或陷阱。

玩家拥有一组有限的"技能工具"，可以赋予特定小人特殊能力来帮助队伍通过关卡：
- **挖掘者（Digger）**：向下挖穿平台
- **建造者（Builder）**：向前搭建阶梯
- **阻挡者（Blocker）**：站立不动阻挡其他小人
- **攀爬者（Climber）**：攀爬垂直墙壁
- **漂浮者（Floater）**：撑伞减缓下落速度
- **爆破者（Bomber）**：定时爆炸清除障碍

每个关卡设定了"最低救出数量"（如"救出10/50个小人"）。玩家需要合理分配有限的技能工具，让足够数量的小人避开陷阱、穿过障碍、到达出口。

## 核心循环

观察关卡地形 → 分配技能给特定小人 → 观察行进结果 → 调整策略重试

## 核心机制

- **群体路径规划**：玩家不是控制单个角色，而是为整个群体制定"策略方案"。每个技能的使用都像在群体行为中插入一个"干预点"——让挖掘者挖通地下通道、让建造者搭建过桥阶梯。这种从"控制"到"引导"的玩法在当时极具创新。
- **时机与资源管理**：技能工具数量有限，每个技能只能在特定时刻对特定小人使用。需要精确判断"什么时候给谁用什么技能"。过早使用可能浪费，过晚使用可能错过时机。
- **多米诺效应**：一个小人的行动会影响其他小人的路径——阻挡者改变了行进方向，挖掘者创造了新通道。玩家需要预判整个群体的行为链条。
- **失败宽容设计**：不需要救出所有小人，只需达到最低数量。这允许玩家"牺牲"一部分小人来为其他人开辟道路，增加了策略的灵活性和道德趣味。

## 为什么好玩

Lemmings的魅力在于它创造了一种独特的"上帝视角"体验——你不是在扮演某个英雄，而是在指挥一群"完全不需要你指挥就会自己走"的小人。当看到你自己设计的技能分配方案让整个群体顺利通过险境时，那种"我设计了一个系统并看着它运转"的成就感非常独特。游戏的幽默感（小人掉下悬崖时的表情和音效）也增加了趣味性。

## 粘性来源

- **策略深度带来的反复优化**：即使通关了，玩家也常想"能不能用更少的技能救出更多人"，驱动反复尝试
- **关卡设计的巧妙性**：每个关卡都是一道精心设计的地形谜题，从简单通道到复杂多层迷宫，难度递增但始终有新意
- **经典情怀**：作为1991年的经典游戏，对于老玩家有强烈的情怀吸引力

## Meta 系统

- **关卡解锁系统**：完成一关解锁下一关，关卡按主题分组（Fun, Tricky, Taxing, Mayhem难度递增）。
- **救出数量评级**：根据救出小人的数量给予不同评级。

## 实现难度

低。2D横版场景、简单角色AI（直线行走+遇到障碍停止）、预设技能效果——这些在现代游戏开发中都是基础功能。最大难点是忠实还原原版的物理行为和关卡设计。移植版的主要工作是适配触屏操作（点击赋予技能）和调整UI布局。
