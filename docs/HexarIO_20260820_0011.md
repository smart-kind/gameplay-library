# 六边形领地（Hexar.io）

- **类型**: io 策略 / 领地占领
- **平台**: Mobile (iOS+Android)
- **开发商**: MochiBits, LLC
- **首次发布**: 2017
- **一句话描述**: 在六边形网格地图上绘制领地，通过封闭区域来占领土地，同时防止其他玩家入侵你的领土。

## 玩法规则

游戏地图由密集的六边形网格组成。玩家控制一个在地图上移动的光标，移动时会在身后留下轨迹。当你画出的轨迹最终连接到自己的领地（已占领的六边形区域）时，轨迹围成的区域就会被你占领，变成你的领地。

核心操作是单指滑动控制移动方向。你需要在冒险圈出更大领地的同时，保护自己的轨迹不被其他玩家切断。如果其他玩家碰到你的移动轨迹（未封闭的部分），你会被消灭。

地图上散落着金币和能量道具。收集金币可以升级喷气背包，让你在关键时刻飞跃一段距离而不留下轨迹，从而快速安全返回领地。完成每日任务可获得额外奖励。

## 核心循环

移动绘制轨迹 → 连接领地封闭区域 → 获得新领地 → 继续扩张

## 核心机制

- **轨迹封闭**：借鉴 Paper.io 的划线围地机制，但使用六边形网格，视觉更独特且策略维度更丰富
- **风险与回报**：画出的轨迹越长，围成的面积越大，但被攻击的暴露面也越长
- **喷气背包**：消耗资源快速返回领地，是保命和战术突袭的关键工具
- **道具系统**：金币收集和皮肤自定义增加长期目标

## 为什么好玩

在画线围地的过程中，你需要时刻关注周围其他玩家的动向，判断何时冒险扩张、何时收缩防守。每一次成功围出一大块领地都带来强烈的成就感，而一次被截杀又让人立刻想再来一局。

## 粘性来源

- **领地占有欲**：看着自己的颜色在地图上扩散，满足占有欲
- **风险博弈**：长线围地的紧张感和被截杀的瞬间反转
- **收集系统**：皮肤和喷气背包升级提供长期追求

## Meta 系统

- **金币收集与升级**：升级喷气背包速度和容量
- **皮肤解锁**：通过完成任务解锁不同的角色外观和领地颜色
- **每日任务**：提供持续的游戏目标

## 实现难度

中等。六边形网格的封闭区域判定算法比矩形网格更复杂。最大技术难点是高效的区域填充算法和多人实时碰撞检测。
