# Build a Lot 4: Power Source HD (建造大亨4：能源高清版)

- **类型**: 模拟经营 / 时间管理
- **平台**: PC / Mac / iOS
- **开发商**: HipSoft
- **首次发布**: 2010
- **一句话描述**: 建造、升级并出售房产获取利润的城市建造模拟游戏

## 玩法规则

玩家扮演房地产开发商，需要在限定的地块上建造房屋、商店和社区设施来赚取利润。游戏以网格地图为基础，每个格子可以放置不同建筑。

游戏界面显示可用资金、当前关卡目标和时间限制。玩家通过点击地块选择要建造的建筑类型，包括住宅、公园、商店和特殊设施。

每个建筑有建造时间和成本。建造完成后，住宅会产生持续的租金收入，商店提供一次性利润。玩家需要购买原材料（木材、金属等）来建造和升级建筑。

游戏目标是在规定时间内达到特定金额或完成特定数量的建造任务。升级房屋可以大幅提高售价和租金收入。

## 核心循环

购买地块 → 建造房屋 → 升级设施 → 出售获利 → 购买更多地块

## 核心机制

- **网格建造系统**：在固定网格上放置建筑，需要考虑相邻效应和空间利用率
- **资源管理**：资金、时间和原材料三种资源需要平衡管理
- **建筑升级链**：从基础房屋逐步升级到豪宅，每次升级提高价值和吸引力
- **关卡目标系统**：每关有明确的资金或数量目标，提供清晰的进度指引
- **时间压力**：部分关卡有时限，增加紧迫感

## 为什么好玩

简单易上手的网格建造加上明确的关卡目标，让玩家有持续的目标感。看着荒芜地块变成繁荣社区的成就感极强，同时每关都有新的挑战。

## 粘性来源

关卡递进带来的挑战感 + "再试一关"的目标驱动 + 看着社区逐步壮大的视觉满足感 + 升级系统的即时反馈

## Meta 系统

关卡解锁系统 — 完成当前关卡解锁新区域和新建筑类型

## 实现难度

低 — 基于网格的2D模拟经营游戏，最大技术难点在于关卡设计的平衡性和经济系统的数值调优
