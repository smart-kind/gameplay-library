# Jelly Splash（Jelly Splash: Fun Puzzle Game）

- **类型**: 连线匹配 / 三消变体
- **平台**: Mobile (iOS+Android)
- **开发商**: Wooga
- **首次发布**: 2013
- **一句话描述**: 通过连接3个或更多同色果冻方块来消除的经典连线益智游戏，以流畅的动画和轻松的氛围著称。

## 玩法规则

游戏画面呈现一个网格棋盘，每个格子中有一个彩色果冻方块（通常5-6种颜色）。玩家用手指从一个方块拖动到相邻的同色方块，形成一条连接线。当连接3个或更多同色方块并松手后，这些方块被消除，上方的方块下落填充空位，新方块从顶部补充。

与传统的"交换两个方块"的三消游戏不同，Jelly Splash允许连接任意长度的同色链条——连接4个、5个甚至更多同色方块可以获得更高的分数和特殊效果（如炸弹、彩虹方块等）。连接线不能交叉或经过不同颜色的方块。

每个关卡有特定的目标：达到目标分数、消除特定类型的方块、清除障碍物（如果冻层、冰块、链条锁等）或在限定步数内完成任务。棋盘布局和障碍物位置经过精心设计，形成不同的挑战。

## 核心循环

扫描棋盘寻找连接机会 → 拖拽连接同色方块 → 观察消除和连锁反应 → 评估剩余步数并寻找新机会

## 核心机制

- **自由连线匹配**：与传统三消的"交换两格"不同，玩家可以连接任意数量的同色方块（至少3个）。这种机制允许更长的连锁和更高的策略自由度——连接5个同色方块产生的特殊效果远超连接3个。
- **连锁反应系统**：消除后上方方块下落可能形成新的匹配（"级联消除"），好的开局选择可能触发多轮自动消除，最大化每步的价值。
- **特殊方块生成**：连接4个以上同色方块会生成特殊效果方块（如十字炸弹、彩虹方块），这些特殊方块可以消除更大范围的方块或清除特定颜色的所有方块。
- **步数约束下的效率优化**：有限步数要求玩家每一步都追求最大效果，而非随意消除。寻找"能触发级联消除的连接"是核心技巧。

## 为什么好玩

拖拽连线比交换两格的直觉性更强——"连成一串就消除"的规则简单明了，新手30秒就能上手。但要在有限步数内完成目标则需要认真规划。当一次连接触发级联消除、满屏果冻同时消失时，视觉和听觉反馈极其满足。Wooga在动画细节上的打磨（果冻的Q弹感、消除时的飞溅效果）让简单的匹配操作变得"手感极佳"。


- **长链匹配的视觉奖励**：连接5个以上同色方块时，消除动画更加华丽（更大的爆炸、更多的飞溅效果、独特的音效），这种视听奖励强化了"寻找长链"的行为。
- **特殊道具的策略深度**：不同道具组合产生的效果差异极大——火箭+彩虹球可以消除整行同色方块，炸弹+火箭可以清空大面积区域。学会识别和利用道具组合是进阶的关键。

## 粘性来源

- **级联消除的随机奖励感**：每次消除后都可能触发意外的级联反应，这种不可预测的正反馈类似于"抽奖"体验
- **步数效率的不断优化**：玩家逐渐学会"看三步"——不仅看当前能消除什么，还看消除后掉落会形成什么新匹配
- **关卡目标的多样性**：从单纯得分到清除特定障碍物，每10-20关就换一种挑战类型，防止单调

## Meta 系统

- **世界地图进度系统**：关卡按世界地图排列，完成一个世界解锁下一个。每个世界有不同的主题和视觉风格。
- **任务系统**：每日任务和成就目标提供额外的游玩动力和奖励。
- **社交排行榜**：与好友比较关卡进度和最高分。

## 实现难度

低。连线匹配的逻辑和动画在手游开发中属于成熟品类。主要工作量在关卡设计和数值平衡——需要确保数百个关卡的难度曲线平滑且每个关卡都有可行解。特效动画（果冻弹跳、消除飞溅）需要细致的美术工作。
