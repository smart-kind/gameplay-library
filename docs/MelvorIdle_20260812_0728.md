# 梅尔沃放置 (Melvor Idle)

- **类型**: 放置 / RPG / 模拟
- **平台**: Mobile (iOS+Android) / PC (Browser, Steam)
- **开发商**: Games by Malcs
- **首次发布**: 2021
- **一句话描述**: 受RuneScape启发的深度放置RPG，将经典MMORPG的23种技能简化为离线也能成长的放置玩法

## 玩法规则

游戏界面为多面板的数值化管理界面，没有3D画面或动作元素。玩家选择一项技能进行训练，如攻击、力量、防御、钓鱼、烹饪、伐木、生火、采矿、锻造等23种技能。

每项技能都有进度条，随时间自动增长。例如攻击技能需要玩家装备武器后持续战斗，每次攻击获得攻击经验值；钓鱼技能需要选择鱼饵和钓点，随时间自动钓到鱼。大多数技能都可以离线运行——关闭游戏后，技能继续以一定速率增长。

技能之间形成依赖链：钓鱼获得的鱼需要生火烹饪，采矿获得的矿石需要锻造，伐木获得的木材可以生火制作弓箭等。这种相互关联的技能系统构成了游戏的核心深度。

战斗系统采用回合制自动战斗，玩家装备武器和护甲后选择怪物进行战斗，角色自动攻击和使用技能。可以通过调整装备、使用药水、祈祷等来优化战斗效率。

## 核心循环

选择技能训练 → 获得经验升级 → 解锁新内容/提高效率 → 训练关联技能 → 形成技能网络

## 核心机制

- **23种技能系统**：每种技能独立升级（1-99级），涵盖战斗、采集、制造三大类。技能之间深度关联——例如要制作好的装备，需要采矿、锻造、锻造等多个技能达到一定等级。
- **离线进度**：所有技能都可以离线运行，关闭游戏后继续获得经验。这是放置游戏的核心——进度不会因为离开而停止。离线进度有上限（通常为数小时），防止玩家长期不登录。
- **装备系统**：通过锻造、制作等技能生产装备，装备提升战斗效率，从而更快地获取战斗经验和材料。装备品质从普通到传奇，稀有装备需要高技能等级和稀有材料。
- **成就与目标**：游戏提供明确的里程碑（某技能达到99级、全技能80级等）作为长期目标。这些目标给放置进度赋予了意义和方向感。

## 为什么好玩

将RuneScape等MMORPG中需要数百小时 grind 的内容浓缩为放置游戏——你可以在上班/睡觉时让角色自动练级。技能之间的网状依赖关系让玩家总有"下一个目标"，不会出现不知道做什么的情况。

游戏尊重玩家的时间——不需要盯着屏幕，不需要重复操作，但依然提供了MMORPG级别的内容深度。这种"尊重时间但不简化内容"的设计理念在放置游戏中非常少见。

付费DLC（"战斗区域"、"雾中战斗"等扩展）增加了大量新内容，但核心免费游戏已经提供了数百小时的内容。

## 粘性来源

进度积累的沉没成本是最强驱动力——已经投入数百小时的角色不可能放弃。技能树的网状结构确保玩家永远有"差一点就达到"的目标。每日登录检查离线进度和收获形成了稳定的日常习惯。

## Meta 系统

无传统Meta系统。游戏本身就是Meta——所有进度都是永久累积的。付费DLC（如"战斗区域"扩展）增加新内容和技能，但核心游戏免费。

## 实现难度

中等。放置游戏的数值平衡是核心挑战——23种技能的经验曲线、离线进度速率、装备属性等需要精密计算。最大的技术难点在于长时间跨度的离线进度模拟的准确性和防作弊。
