# 连接同色敌人进行攻击的益智动作游戏（Grindstone）

- **类型**: 解谜/动作
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: Capybara Games
- **首次发布**: 2019
- **一句话描述**: 连接同色敌人进行攻击的益智动作游戏

## 玩法规则

玩家在网格上连接同色敌人进行攻击。连接一条同色路径后，角色沿路径移动并消灭所有连接的敌人。

不同颜色的敌人需要分开攻击。有障碍物和特殊敌人增加复杂度。

## 核心循环

连接同色敌人 → 攻击消灭 → 清除所有敌人 → 过关

## 核心机制

- 路径连接
- 颜色匹配
- 特殊敌人

## 为什么好玩

流畅的连击感和策略性。

## 粘性来源

关卡驱动。

## Meta 系统

关卡解锁。

## 实现难度

中。需要策略思考。最大技术难点：关卡设计。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
