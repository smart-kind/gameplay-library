# 超级柠檬工厂（Super Lemonade Factory）

- **类型**: 解谜 / 平台跳跃
- **平台**: Mobile (iOS)
- **开发商**: Initials Games
- **首次发布**: 2011
- **一句话描述**: 以战后经济背景下的柠檬饮料工厂为舞台的双角色解谜平台游戏，玩家需要操控一对新婚夫妇穿越工厂完成36个关卡。

## 玩法规则

玩家控制两个角色Liselot和Andre，一对继承家族饮料生意的新婚夫妇。通过点击屏幕上的左右箭头移动角色，使用跳跃按钮和角色特殊能力按钮进行操作。

游戏核心是角色切换机制：通过滑动屏幕在两个角色之间切换。Andre可以推箱子，Liselot可以进行二段跳。每个角色还有各自独特的技能。

每个关卡都是精心设计的谜题，需要玩家结合两个角色的能力来解决。例如让Andre推开障碍物，然后切换到Liselot进行二段跳通过高台。

隐藏要素包括散布在工厂各处的瓶子和可对话的工人。收集所有瓶子解锁硬核模式，该模式将原本悠闲的关卡变成充满尖刺和限时跳跃的紧张挑战。

通关条件是两个角色都到达关卡出口。
## 核心循环

解决关卡谜题，收集隐藏瓶子和与工人对话，解锁硬核模式和彩蛋，挑战更难的关卡

## 核心机制

- **双角色切换系统**：滑动屏幕在Andre和Liselot之间切换，每个角色拥有独特能力（推箱子、二段跳等），谜题设计围绕能力互补展开
- **能力互补解谜**：某些障碍只能由特定角色通过，迫使玩家频繁切换角色并规划操作顺序
- **隐藏收集系统**：关卡中隐藏瓶子和NPC对话内容，收集全部瓶子解锁硬核模式，激励探索
- **硬核模式**：将原本休闲的节奏变为紧张刺激的限时挑战，为通关后的玩家提供高难度内容

## 为什么好玩

像素风格的画面和复古美术与奇特主题完美契合，角色切换解谜机制增添了有趣的思考层次。虽然关卡后期略显同质化，但整体体验轻松愉快。

游戏的像素美术风格刻意追求复古感，角色设计简洁可爱，背景中的工厂设备以精细的像素细节呈现。这种视觉选择与游戏的奇异叙事主题相得益彰。

配乐方面，游戏采用了轻快的芯片音乐风格，与工厂环境和角色动作完美配合。音效设计也值得一提，角色跳跃、推箱子、收集瓶子都有独特的音效反馈。

36个关卡的难度呈渐进式上升。前几关主要用于教学，让玩家熟悉基本操作和角色切换。中段关卡开始引入复杂谜题，需要多次尝试才能找到正确解法。

游戏没有生命值系统，角色不会死亡，这降低了挫败感，让玩家可以专注于解谜本身而非躲避危险。
## 粘性来源

角色切换解谜带来的顿悟时刻是核心粘性来源，当你终于想通如何用两个角色配合过关时的满足感。隐藏瓶子收集驱动探索，硬核模式为完成主线后提供额外挑战。

## Meta 系统

无外围成长系统。游戏为纯关卡制解谜体验，进度体现在关卡推进和隐藏内容解锁上。硬核模式的解锁是唯一的额外目标。

## 实现难度

低至中等。最大技术难点在于双角色状态管理和物理碰撞检测的精确性，以及谜题关卡的手动设计工作量。
