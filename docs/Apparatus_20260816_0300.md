# Apparatus

- **类型**: 物理构建解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Bithack
- **首次发布**: 2011
- **一句话描述**: 物理构建解谜游戏，类似The Incredible Machine，玩家建造机械装置完成任务
- **PocketGamer评分**: 8/10

## 玩法规则

玩家需要在给定的场景中搭建各种机械装置（木板、绳索、滚珠、风扇等），利用物理引擎让一个小球从起点到达终点。游戏属于"建造机械完成目标"的解谜类型，灵感源自经典的The Incredible Machine系列。

游戏界面中，玩家可以看到起点、终点、以及可用的建筑材料。通过拖拽操作，玩家可以在场景中放置木板搭建桥梁、安装风扇产生气流、放置滚珠传递动能、连接绳索制造摆动等。每种元件都遵循真实物理规则。

每个关卡给出有限的材料数量和类型，玩家需要思考如何用最少的资源完成任务。游戏包含多个难度递增的关卡，后期的谜题需要更复杂的连锁反应设计。游戏的亮点在于自由度——同一个关卡可能有多种解决方案，玩家可以用创意方式达成目标。

## 核心循环

放置/操作 → 获得奖励/进展 → 升级/解锁新内容 → 挑战更高难度

## 核心机制

- **机制1**：物理构建解谜核心循环 — 通过物理构建解谜操作完成关卡目标，获得金币/分数奖励
- **机制2**：渐进式难度 — 每个关卡引入新的元素或增加复杂度，玩家需要调整策略
- **机制3**：资源管理 — 有限的建造材料/金币/时间，需要玩家做出取舍决策

## 为什么好玩

Android Market上已有多款类似Bithack的Apparatus的游戏——物理构建套装，但从木板、绳索到滚珠，玩家建造装置让小球从A到B。 游戏的评分为8/10，说明这款游戏质量不错，有独特的玩法乐趣。

## 粘性来源

具体到机制层面：核心循环的"完成关卡→获得奖励→解锁新内容"驱动玩家持续游玩；渐进式难度带来的挑战感让玩家想"再来一关"；解谜类游戏特有的"顿悟时刻"（想通了解法）提供强烈的成就感。

## Meta 系统

外围成长系统：通过关卡获得的金币/分数可以解锁新的塔类型/角色/赛道，或升级已有元件的性能。对核心玩法的影响：解锁内容提供了新的策略选择，但不改变核心操作方式。

## 实现难度

中 — 核心玩法基于成熟的物理构建解谜机制，最大技术难点在于物理引擎的精确模拟和关卡设计的平衡性。
