# Secret Cat Forest（秘密猫咪森林）

- **类型**: 放置 / 收集 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: PONOS
- **首次发布**: 2019
- **一句话描述**: 在森林中放置各种家具和装饰品吸引猫咪来访，收集不同品种猫咪的治愈系放置游戏。

## 玩法规则

游戏场景是一片空旷的森林。玩家可以使用"小鱼干"货币购买并放置各种家具到森林中：帐篷、秋千、餐桌、火炉等。每种家具对不同类型的猫咪有不同的吸引力。

放置好家具后，猫咪会逐渐被吸引前来。每种猫咪有独特的品种、颜色和外观特征。玩家可以看到猫咪在场景中活动：在帐篷里睡觉、在秋千上摇晃、在餐桌旁吃东西。

游戏采用实时时间系统，猫咪的来访和活动在玩家离线时也会继续。玩家上线后可以查看哪些猫咪来过了，拍照收集图鉴。

小鱼干通过猫咪来访和完成任务获得。小鱼干用于购买新的家具，新家具吸引更多种类的猫咪。某些稀有猫咪只在特定季节或特定家具组合下出现。

## 核心循环

购买并放置家具 → 等待猫咪来访（离线也有效）→ 与猫咪互动/拍照 → 获得小鱼干 → 购买更多家具 → 收集更多猫咪品种

## 核心机制

- **家具吸引力矩阵**：每种家具对不同猫咪有不同的吸引概率，形成一张大型的吸引力矩阵，鼓励玩家尝试不同组合
- **季节系统**：游戏与现实季节同步，不同季节有不同猫咪出现，增加时间维度的收集要素
- **离线收益**：完全支持离线游玩，猫咪在玩家不在时也会来访，上线后查看即可
- **图鉴系统**：所有发现的猫咪都收录在图鉴中，包含品种信息和可爱插画

## 为什么好玩

Secret Cat Forest 是"云养猫"类游戏的优秀代表。它不需要玩家投入大量时间或精力，只需要偶尔上线看看有哪些新猫咪来过了。游戏的魅力在于那种"打开游戏，发现一只从没见过的猫咪在帐篷里睡觉"的惊喜感。美术风格温馨治愈，猫咪设计可爱到让人忍不住多看几眼。

## 粘性来源

- **收集驱动**：图鉴系统提供明确的长期目标，"全收集"是很多玩家的动力
- **零压力体验**：没有任何任务截止、竞争或失败惩罚，纯粹放松
- **季节限定猫咪**：特定季节出现的稀有猫咪制造了"错过了就要等一年"的紧迫感
- **社交分享**：可爱的猫咪截图天然适合分享到社交媒体

## Meta 系统

小鱼干货币与家具商店系统。家具分为不同类别（户外、室内、装饰等），每类有多个选项。稀有家具需要更多小鱼干或特定条件解锁。季节活动会推出限时家具。

## 实现难度

低。核心逻辑与同类放置游戏类似：计时器 → 随机事件（猫咪来访） → 奖励。最大技术难点在于美术资源量大（大量猫咪插画和动画），技术实现本身不复杂。
