# 古惑狼：变异岛（Crash Bandicoot Mutant Island）

- **类型**: 横版动作 / 跑酷
- **平台**: Mobile (iOS)
- **开发商**: Vicarious Visions
- **首次发布**: 2009
- **一句话描述**: 古惑狼系列在iPhone上的横版过关动作游戏

## 玩法规则

玩家控制古惑狼Crash在热带岛屿环境中横向移动，通过跑、跳、旋转攻击等方式穿越关卡。

操作方式：点击屏幕左侧控制移动方向，点击右侧控制跳跃；滑动或双击发动旋转攻击（Crash的标志性招式）。部分版本支持倾斜控制。

游戏目标：从关卡起点到达终点，沿途收集漂浮的苹果（收集品）和破坏木箱（奖励道具）。某些木箱内有额外生命或特殊能力。敌人会从四面八方出现，用旋转攻击或踩踏击败。

游戏结束条件：生命值耗尽则Game Over；到达关卡终点则过关。部分关卡有Boss战需要击败特定敌人。

## 核心循环

跑跳穿越关卡 -> 收集苹果/破坏木箱 -> 击败敌人 -> 到达终点

## 核心机制

- 旋转攻击：Crash的标志性360度旋转攻击，既可消灭敌人也可破坏木箱，是主要进攻手段
- 平台跳跃：精确的跳跃时机要求，部分平台是移动或会消失的，考验反应速度
- 箱子系统：Wumpa水果收集满一定数量获得额外生命；不同颜色木箱有不同内容（TNT箱需快速离开、Nitro箱触碰即连锁爆炸）

## 为什么好玩

将经典主机IP适配到手机平台，保留了古惑狼系列一贯的快节奏和幽默风格。旋转攻击破坏木箱的爽快感，加上收集Wumpa水果的满足感，让游戏在手机上也有不错的体验。

## 粘性来源

关卡制提供了明确的进度目标；收集完整关卡的Wumpa水果和所有隐藏物品驱动重复挑战；系列IP的情怀加成。

## Meta 系统

关卡进度解锁系统，通关后解锁新区域。

## 实现难度

中 — 需要将主机级平台跳跃体验适配到触屏。最大技术难点是触屏手势的精准度和关卡设计在移动端的可行性。
