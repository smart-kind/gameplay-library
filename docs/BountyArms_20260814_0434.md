# Bounty Arms

- **类型**: 射击 / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: 
- **首次发布**: 2014
- **一句话描述**: 三位风格各异的赏金猎人深入敌营，在十场任务中扫射机器人大军

## 玩法规则

游戏采用俯视角或等角视角呈现战斗场景。玩家从三位赏金猎人中选择一位开始任务：Drake Mass（持散弹枪的太空陆战队员）、Flux Helix（激光眼悬浮机器人）、Goober（戴着焊工护目镜的块状外星人）。

进入关卡后，你需要尽可能多地收集金币，同时击杀随机出现的机器人敌人。画面流畅精美，角色动画细腻，即使屏幕中大量弹幕横飞、敌人被击杀时彩纸四溅，游戏依然保持流畅响应。

操作包括常规射击按钮和强力武器——在射击按钮旁边滑动可触发。每个角色都有独特的强力武器，但弹药有限且消耗很快。

敌人倾向于近距离围攻玩家，迫使玩家频繁使用近战攻击。关卡中分布着宝箱和门，可以用收集的金币打开，里面可能装有额外能力、生命或升级所需徽章。

任务中可以召唤宠物提供临时增益（恢复生命值或将敌人变成金像供玩家敲碎换钱），但召唤需要时间且增益持续时间短。

## 核心循环

进入关卡 → 收集金币 + 击杀机器人 → 打开宝箱 → 通关获取徽章 → 升级/解锁新内容

## 核心机制

- **三角色切换**：每位角色有独特武器和战斗风格（散弹枪近战型、激光远程型、近战肉搏型）
- **宠物召唤系统**：消耗金币召唤宠物获得临时增益，但召唤有前摇时间需要谨慎选择时机
- **宝箱开门经济**：关卡内的宝箱和门需要消耗金币打开，但奖励通常远超成本（徽章、能力、生命）

## 为什么好玩

Bounty Arms 的画面和手感在移动端射击游戏中属上乘——角色设计有趣（特别是戴着焊工护目镜的 Goober），战斗流畅度高，击杀反馈感强烈（彩纸爆散的特效）。三角色的差异化也提供了重玩价值。但评测指出关卡设计缺乏创意（10 关中有 3 关是工厂场景且几乎一模一样），且关卡结束过于突兀，没有任何过渡。

## 粘性来源

角色差异化带来的重玩欲——用不同角色体验同一关卡可能有不同感受。宠物系统和宝箱开启也提供了一定的收集动力。但关卡内容的匮乏限制了长期粘性。

## Meta 系统

- **宠物养成系统**：用金币购买和培育宠物，在任务中召唤获得临时增益
- **徽章收集**：通过打开宝箱获得徽章，用于解锁更高排名和成就
- **关卡内经济**：收集金币 → 开宝箱/门 → 获得能力/生命/徽章
