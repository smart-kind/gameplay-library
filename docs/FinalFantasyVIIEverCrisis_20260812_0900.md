# Final Fantasy VII Ever Crisis

- **类型**: 回合制 RPG / 叙事
- **平台**: Mobile (iOS+Android)
- **开发商**: Square Enix
- **首次发布**: 2023
- **一句话描述**: Square Enix 将最终幻想 VII 传奇以精美移动端格式重新演绎，F2P 体验意外慷慨。

## 玩法规则

游戏以回合制战斗重现 FFVII 系列的经典故事。玩家在不同时间线上扮演多个角色——年轻的克劳德、赛菲罗斯、年轻的扎克斯等。每个角色有独特的攻击、技能和终极技。

战斗系统采用 ATB（Active Time Battle）变体——角色的行动槽随时间填充，满了即可行动。玩家可以选择攻击、技能、道具或防御。终极技在积累满能量后释放，伴随华丽的动画。

游戏涵盖 FFVII、FFVII: Crisis Core 和 FFVII: First Soldier 的故事线，让玩家以全新视角体验这些经典叙事。装备系统允许玩家收集和升级武器，每种武器改变角色的外观和技能。

## 核心循环

推进故事 → 回合制战斗 → 收集装备和角色 → 解锁新时间线

## 核心机制

- ATB 回合制战斗：行动槽随时间填充，策略性行动选择
- 多角色时间线：扮演 FFVII 系列多个经典角色
- 装备系统：收集武器改变角色外观和技能
- 故事驱动：涵盖 FFVII 三部曲的叙事
- 合作多人模式：与其他玩家组队挑战 Boss

## 为什么好玩

FF 粉丝的移动盛宴——将经典叙事以现代 F2P 模式呈现，且氪金压力远低于同类游戏。

## 粘性来源

- FF 情怀：经典故事和角色在移动端重生
- 慷慨的 F2P 体验：相比同类 Gacha 游戏更友好
- 叙事深度：FFVII 系列故事本身就极具吸引力
- 多时间线视角：以不同角色视角重新体验经典

## Meta 系统

武器收集和角色解锁。通过抽卡获取武器，武器决定角色外观和部分技能。

## 实现难度

中。ATB 战斗系统成熟，难点在于叙事内容的本地化和 Gacha 数值平衡。
