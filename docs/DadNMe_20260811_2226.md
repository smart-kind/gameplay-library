# 爸爸和我（Dad 'n Me）

- **类型**: 动作格斗 / 横版过关
- **平台**: Web（浏览器）/ Flash
- **开发商**: Tom Fulp / Dan Paladin（The Behemoth 成员）
- **首次发布**: 2005
- **一句话描述**: Flash 时代的经典横版格斗游戏——玩家扮演一个小男孩，在街头和坏人打架为爸爸报仇

## 玩法规则

游戏采用横版卷轴视角，画面是卡通风格的火柴人/简单角色。玩家控制一个小男孩在街头场景中移动和战斗。

操作方式：方向键移动，攻击键出拳，特殊键使用特殊攻击（飞踢、回旋踢等）。游戏支持连招——连续按键可以打出组合攻击。

关卡是线性的——从左向右推进，沿途消灭所有敌人。敌人有不同类型（小混混、壮汉、持械敌人等），每种有不同的攻击模式和血量。

游戏有 Boss 战——面对强大的敌人，需要掌握其攻击模式并找到反击机会。

## 核心循环

推进关卡 → 连招攻击敌人 → 收集生命和能量 → 打败 Boss → 进入下一关

## 核心机制

- **连招系统**：连续按键可以打出组合攻击（如拳-拳-飞踢）。连招的伤害和效果优于单独按键。
- **敌人多样性**：不同类型的敌人有不同的攻击模式——小混混直接冲过来、壮汉攻击慢但伤害高、持械敌人需要躲避其武器。
- **Boss 战**：每个关卡有一个 Boss，有独特的攻击模式和弱点。需要观察和学习 Boss 的行为模式。

## 为什么好玩

Dad 'n Me 是 Flash 时代最好的横版格斗游戏之一——流畅的动作、丰富的连招、有趣的敌人设计，加上幽默的剧情（小男孩为爸爸报仇），让它成为经典。

## 粘性来源

- **连招 mastery**：掌握连招系统需要练习，从乱按到流畅连招的进步过程很有成就感
- **Boss 挑战**：每个 Boss 都有独特的攻击模式，需要学习和适应
- **幽默剧情**：小男孩为爸爸报仇的设定很有趣

## Meta 系统

无。纯核心玩法。

## 实现难度

- **学习曲线**：新手可以立即上手，但精通需要数十小时的练习。每次游玩都能发现新的技巧或策略。
- **重玩价值**：高。每局游戏都有不同的体验，无论是随机的地图/敌人，还是玩家的策略选择。
- **社区生态**：作为经典浏览器游戏，它在玩家社区中有良好的口碑。
- **技术亮点**：在浏览器环境中实现流畅的交互体验，充分利用了现代 Web 技术的能力。
中 + 需要格斗系统、连招逻辑、敌人 AI、Boss 战模式。最大技术难点是连招系统的流畅性——要让连招输入窗口合理、动画流畅、伤害计算准确。
