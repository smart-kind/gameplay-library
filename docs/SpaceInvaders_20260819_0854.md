# Space Invaders

- **类型**: 射击 / Shoot em up
- **平台**: Arcade / Mobile (iOS+Android) / PC / Console
- **开发商**: Taito
- **首次发布**: 1978
- **一句话描述**: 玩家控制底部左右移动的激光炮，抵御从屏幕顶部逐步下降的外星人舰队

## 玩法规则

游戏画面中，玩家控制一个只能左右水平移动的激光炮台位于屏幕底部。屏幕上方排列着多行外星人（通常为5行x11列），它们会整体左右移动并逐步向下降落。

玩家操作：
- 左右移动：控制炮台在屏幕底部左右平移
- 发射：向上方发射激光子弹，每次只能有一发子弹在屏幕上

游戏目标：在所有外星人到达屏幕底部之前将它们全部消灭。每消灭一个外星人获得相应分数（越靠近底部的外星人分数越高）。

外星人会随机向玩家发射子弹，玩家必须躲避这些攻击。随着游戏进行，外星人移动速度会逐渐加快，音乐节奏也随之加速，营造越来越紧张的氛围。

游戏结束条件：
- 外星人到达屏幕底部（玩家所在行）
- 玩家失去所有生命值（通常3条命）

特殊元素：
- 神秘UFO：偶尔从屏幕顶部飞过，击中可获得高额奖励分数
- 掩体：屏幕底部有4个可被双方子弹破坏的防护掩体
- 入侵者：偶尔出现一个快速移动的特殊外星人

## 核心循环

瞄准射击 → 获得分数 → 外星人加速 → 更紧张刺激

## 核心机制

- **水平移动射击**: 玩家只能左右移动不能上下，操作极简但要求精准瞄准和时机把握
- **渐进难度**: 外星人每被消灭一个，剩余外星人的移动速度就会加快，形成自然的难度递增曲线
- **双向弹幕**: 外星人会随机射击，玩家既要瞄准又要躲避，形成攻防一体的体验
- **掩体系统**: 4个可被破坏的防护墙提供临时保护，但会被双方子弹逐步摧毁，需要策略性使用

## 为什么好玩

简单操作下隐藏着极高的技巧上限。看着外星人越来越快地逼近，配合越来越快的音效节奏，产生强烈的紧迫感。消灭一整行外星人的视觉反馈和分数增长带来持续的成就感。

## 粘性来源

分数竞争（高分榜）是主要粘性来源。差一点就能破纪录的不甘心让人不断重试。渐进难度曲线让每次游戏都有不同的紧张体验。

## Meta 系统

无。原始版本没有外围成长系统，纯街机体验。

## 实现难度

低。核心玩法只需左右移动加射击，技术难点在于外星人移动节奏的调优和难度曲线的平衡。
