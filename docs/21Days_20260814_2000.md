# 21 Days

- **类型**: 解谜 / 冒险
- **平台**: PS Vita / iOS
- **开发商**: Sony Computer Entertainment Europe
- **首次发布**: 2012
- **一句话描述**: 一个21天倒计时生存冒险游戏，玩家需要在有限时间内完成特定目标

## 玩法规则

游戏设定在一个21天的倒计时框架内。玩家每天会面临不同的情境和挑战，需要在24小时游戏时间内做出关键决策。

游戏界面以日历/时间轴为核心UI，每一天作为一个关卡或场景。玩家通过点击和拖拽与场景中的物品和角色互动。

玩家在每个场景中需要探索环境、收集线索、与NPC对话。每次互动都会消耗时间，而时间总量是固定的21天。

游戏目标是在21天内完成所有必要的任务链条，最终达成结局。如果时间耗尽而未能完成关键任务，游戏将进入失败结局。

## 核心循环

探索场景 → 收集线索/资源 → 做出决策推进剧情 → 消耗时间 → 进入下一天

## 核心机制

- **时间管理系统**：21天倒计时是核心机制，每个操作消耗游戏内时间，玩家必须在有限时间内做出优先级判断
- **多线叙事**：游戏包含多条故事线，玩家的选择影响剧情走向，增加重玩价值
- **资源分配**：玩家需要在不同任务间分配有限的时间资源，形成策略性挑战
- **环境探索**：每个场景包含可互动元素，通过探索发现隐藏线索和可选任务

## 为什么好玩

时间压力与叙事驱动的巧妙结合让玩家始终处于紧张状态。每个选择都有意义，因为时间不可再生。多结局设计鼓励玩家反复尝试不同的时间分配策略。

## 粘性来源

时间有限性带来的紧迫感 + 多结局驱动的重复游玩 + "如果我那天做了不同选择会怎样"的好奇心

## Meta 系统

无

## 实现难度

低 — 基于2D场景的时间管理叙事游戏，最大技术难点在于多线叙事的分支管理和时间系统的平衡设计
