# Zen Bound 2

- **类型**: 物理益智 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: Secret Exit
- **首次发布**: 2010
- **一句话描述**: 玩家通过拖拽绳索缠绕各种3D木质雕塑，用色彩填满指定区域，在禅意氛围中完成目标。

## 玩法规则

游戏画面中心是一个悬浮的3D木质雕塑（如动物、几何形状等），雕塑表面分布着若干彩色目标区域。玩家手持一根彩色绳索，通过手指拖拽操作让绳索在雕塑表面缠绕。

玩家看到的画面包括：中央的3D雕塑（可旋转视角）、底部或侧面的绳索控制区、当前关卡的目标分数显示、以及剩余颜料量指示器。

操作方式是单手拖拽：手指在屏幕上滑动时，绳索会跟随手指移动并缠绕在雕塑的凸起部位。缠绕过程中，绳索接触到的目标区域会被逐步填充颜色。玩家需要在有限的绳索长度和颜料量内，尽可能覆盖更多的目标区域。

游戏的目标是达到指定分数，分数由缠绕覆盖目标区域的精确度决定。当颜料耗尽且无法再获得分数时，当前关卡结束。如果分数达到过关标准，则解锁下一关卡。

游戏设有多个世界主题（如动物、建筑等），每个世界包含若干关卡，难度递增体现在雕塑形状越来越复杂、目标区域越来越分散。

## 核心循环

拖拽绳索缠绕雕塑 → 覆盖目标区域获得分数 → 解锁新关卡和新造型

## 核心机制

- **物理绳索缠绕**：绳索遵循真实物理规律，当绕过雕塑的突起时会自然缠绕固定，这是游戏的核心交互。绳索在雕塑表面的滑动和缠绕手感经过精细调校，产生了独特的触觉反馈。
- **颜料填充系统**：绳索经过目标区域时会将颜料"涂"在雕塑上，覆盖率直接决定分数。玩家需要规划最优缠绕路径来最大化覆盖。
- **视角旋转**：玩家可自由旋转雕塑查看不同角度，这对于复杂形状的缠绕至关重要，因为某些目标区域可能隐藏在雕塑背面。

## 为什么好玩

Zen Bound 2 将简单的"用绳子绑东西"概念做到了极致。每一次成功将绳索完美缠绕在复杂雕塑上的瞬间，都伴随着极强的成就感。配合宁静的氛围音乐和木质纹理的视觉效果，创造出一种独特的"禅意"游戏体验。

## 粘性来源

主要粘性来自"差一点就能覆盖那个区域"的反复尝试冲动，以及每完成一个复杂雕塑造型时的视觉满足感。关卡递进式的难度曲线让玩家不断回到游戏中挑战更复杂的缠绕任务。无时间限制的压力机制也降低了挫折感。

## Meta 系统

无。游戏本身是纯关卡递进式，没有外围成长系统。所有进度都体现在已解锁的关卡和雕塑收藏上。

## 实现难度

中。最大技术难点在于3D物理绳索缠绕的精确模拟——需要处理绳索与复杂3D模型表面的碰撞检测、缠绕固定和滑动摩擦，同时保持流畅的手感和稳定的性能。2D绳索物理常见但映射到可旋转3D表面是另一个级别。
