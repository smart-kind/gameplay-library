# 极速逃脱（Sprint Escape）

- **类型**: 跑酷 / 反应 / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: GenITeam LLC（iTunes 匹配）
- **首次发布**: 约 2012
- **一句话描述**: 在危险环境中快速奔跑，通过精确的时机操作逃脱追杀

## 玩法规则

游戏画面呈现横向卷轴的追逐场景，玩家角色自动向前奔跑，身后有危险（敌人、追兵、崩塌的建筑等）在逼近。

玩家通过点击或滑动屏幕执行操作：点击屏幕跳跃（越过障碍或沟壑）、向下滑动蹲下（躲过低矮障碍）、向左/右滑动转向（在岔路口选择方向）。

场景中散布着可收集的金币或能量道具。收集金币增加分数，能量道具可以提供短暂的无敌、加速或磁铁效果。

随着游戏进行，奔跑速度逐渐加快，障碍物出现频率增加，操作窗口变窄。如果角色撞到障碍物或被身后的危险追上，游戏结束。

## 核心循环

奔跑 → 躲避障碍 → 收集道具 → 加速 → 挑战更远距离

## 核心机制

- **自动奔跑**: 角色自动前进，玩家只需关注时机操作（跳、蹲、转向）
- **障碍多样性**: 不同类型的障碍需要不同的操作来应对——地面障碍需要跳跃，空中障碍需要蹲下，岔路需要快速选择
- **速度递增**: 游戏速度随时间增加，反应窗口越来越短
- **道具系统**: 磁铁（自动吸附金币）、护盾（抵消一次碰撞）、加速（短暂提速甩开追兵）
- **路线分支**: 某些关卡有可选路线——危险但奖励多的捷径 vs 安全但奖励少的主路

## 为什么好玩

跑酷游戏的"一心多用"刺激感——同时处理多种障碍类型让大脑保持高度专注。速度递增带来的紧张感让每次游戏都像一场生死逃亡。失误后立刻重来的低门槛让"再来一次"变得容易。

## 粘性来源

"差一点就破纪录"的心理是核心粘性。每次游戏距离都比上次远一点点，让玩家相信自己下次能做得更好。收集金币解锁新角色和场景提供了长期目标。

## Meta 系统

角色解锁系统：用收集的金币解锁新的可玩角色，每个角色有不同的外观和特殊能力。场景解锁系统：达到特定距离后解锁新场景。

## 实现难度

低。核心是自动卷轴、碰撞检测、简单的输入响应。最大的技术难点是障碍生成的随机性和公平性——需要确保每次生成的障碍组合都是可应对的，不会出现无法躲避的死局。
