# Block Jam - 3D Block Puzzle

- **类型**: 休闲合集 / 合并消除 / 解谜
- **平台**: Mobile (iOS)
- **开发商**: Voodoo
- **首次发布**: 2022
- **一句话描述**: Block Jam 3D – Relaxing Match-3 Puzzle Fun

## 玩法规则

Block Jam - 3D Block Puzzle 是一款面向手机平台的休闲合集 / 合并消除 / 解谜类游戏。打开游戏后，玩家进入主界面，可以看到游戏模式选择、关卡进度和得分排行榜等元素。整体UI设计简洁明快，色彩鲜明，图标清晰易辨识。

游戏的核心交互方式以点击和滑动为主。在匹配消除模式下，玩家通过滑动手指连接相同类型的元素，当三个或更多相同元素连成一线时即可消除，消除后上方的元素会自然掉落填补空位，可能产生连锁反应，一次消除触发更多消除，形成连击效果。在合并模式下，玩家需要将两个相同等级的物品拖拽到一起，合并后生成更高级的物品，通过不断重复这一操作逐步产生更高级的物品。

游戏的目标是在限定步数或时间内获得尽可能高的分数，或完成特定的关卡目标（如消除指定数量的某类元素、达到某个分数等）。如果玩家在限制条件用完时仍未达成目标，则游戏结束，需要消耗体力或重新开始。成功通关后可以获得星星评价和奖励道具，用于解锁后续关卡。

## 核心循环

匹配消除 → 获得分数/道具 → 解锁新关卡/获得奖励

## 核心机制

- **匹配消除**: 玩家通过滑动或点击将相同类型的元素进行匹配连接，三个或更多相同元素连成一线即可消除，消除后上方元素会掉落补充，产生连锁反应。
- **分数/目标驱动**: 每局游戏有明确的得分目标或通关条件，玩家通过不断优化策略获得更高分数或完成更多关卡。

## 为什么好玩

匹配或合并操作带来的即时满足感极强，连锁消除产生的视觉和音效反馈让人欲罢不能。关卡设计层层递进，既有轻松的入门体验也有烧脑的后期挑战。

## 粘性来源

数值成长（解锁更高级物品）+ 连锁爽感（大规模消除的多巴胺刺激）+ 关卡递进（"再玩一关"心理）

## Meta 系统

部分游戏包含等级系统和收集要素。玩家通过累积游戏币或星星解锁新关卡、新角色或装饰物品。

## 实现难度

低 — 核心操作简单（点击/滑动），主要复杂度来自关卡设计而非操作门槛。最大技术难点在于关卡生成的平衡性和难度曲线控制。
