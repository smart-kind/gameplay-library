# 吉他英雄5（Guitar Hero 5）

- **类型**: 节奏 / 音乐
- **平台**: PS2 / PS3 / Wii / Xbox 360
- **开发商**: Neversoft
- **首次发布**: 2009
- **一句话描述**: 吉他英雄系列的第五部正统作品，支持最多四人乐队体验，包含大量流行摇滚曲目。

## 玩法规则

游戏画面模拟现场演唱会，玩家看到的是一支乐队在舞台上表演的3D场景。屏幕上方有从上到下滚动的音符轨道，不同颜色的按键代表不同的弦。音符轨道的颜色与吉他控制器上的按键颜色一一对应。

玩家需要用吉他控制器（或按键）在音符到达判定线时按下对应的按键/拨弦。准确命中获得高分，连续命中触发连击（Multiplier），分数倍增。Miss会减少分数并可能导致演出失败。

游戏支持四种乐器角色：主音吉他、贝斯吉他、鼓、主唱。最多四名玩家组队演出。每个角色有不同的难度和判定方式。吉他有5个颜色按键，鼓有4个踏板+1个踩镲，主唱需要麦克风跟唱。

游戏目标是完成歌曲并获得高分。完成一定数量的歌曲后解锁新的曲目和角色外观。Rockfest模式包含多种特殊的计分规则和比赛方式，如连击淘汰赛、分数争夺战等。

## 核心循环

跟随音符节奏演奏 -> 获得分数/连击 -> 解锁新歌曲 -> 挑战更高难度

## 核心机制

- Drop-in/Drop-out系统：任何玩家可以在任何时刻加入或退出乐队，无需返回菜单。这大大增强了游戏的社交性和即兴乐趣。
- Rockfest竞技模式：包含多种变体规则，如分数争夺战、连击竞赛、生存模式等，增加了多人游戏的策略维度。
- Challenge系统：每首歌有特定的挑战目标（如完美演奏某段Solo、保持20连击等），完成后解锁外观和奖励。

## 为什么好玩

吉他英雄5的乐趣在于摇滚明星的代入感——和朋友一起组队演奏，看着屏幕上的虚拟演唱会，配合真实的吉他控制器，真的有种在舞台上表演的感觉。Drop-in/Drop-out系统让派对变得即兴而有趣，任何人随时可以加入。

## 粘性来源

粘性来自歌曲收集和挑战完成的双重驱动。每首新歌都是一次新的演奏体验，而挑战系统提供了超越通关的额外目标。社交层面的乐队合作也让玩家愿意反复组织演出。

## Meta 系统

角色外观与歌曲解锁系统。通过比赛分数和挑战完成解锁新的虚拟形象、服装、吉他和大量额外曲目。歌曲库从基础的80+首可扩展到数百首。

## 实现难度

中。最大的技术难点在于音符判定系统——需要精确到毫秒级别的输入判定，同时要处理多人模式的同步和音频延迟补偿。
