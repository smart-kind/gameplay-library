# Go Home Dinosaurs

- **类型**: 塔防 / 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Iron Galaxy Studios
- **首次发布**: 2013
- **一句话描述**: 一款恐龙主题的塔防游戏，玩家通过设置陷阱和障碍阻止恐龙入侵野餐桌

## 玩法规则

游戏呈现一个露营场景，中央有一张摆满食物的野餐桌。恐龙从地图边缘向餐桌进发，试图偷吃食物。

玩家可以在恐龙行进路径上放置各种陷阱：弹射器（将恐龙弹飞远离餐桌）、胶水陷阱（减速并粘住恐龙一段时间）、网（短暂困住恐龙）、弹簧板（改变恐龙行进方向）。

陷阱需要资源购买，资源通过完成小游戏或随时间积累获得。每种陷阱有不同的效果和持续时间。陷阱可以升级提升效果或延长持续时间。

恐龙有不同种类：小型恐龙（速度快但血量低）、大型恐龙（速度慢但血量高，能破坏部分陷阱）、飞行恐龙（无视地面陷阱，需要防空陷阱）。目标是在限定波次内保护餐桌不被恐龙破坏。

游戏设有无尽波次模式，恐龙波次无限递增，考验玩家陷阱布置的极限。无尽模式有独立排行榜。

## 核心循环

放置陷阱阻止恐龙 → 获得资源升级陷阱 → 保护餐桌

## 核心机制

- **陷阱组合**：不同类型陷阱配合使用效果更佳
- **恐龙多样性**：不同恐龙需要不同陷阱应对
- **波次挑战**：每波恐龙数量和种类递增

- **无尽波次**：无限递增恐龙波次


## 为什么好玩

恐龙主题的幽默呈现让塔防更有乐趣。看着恐龙被各种陷阱弹飞的搞笑场面是核心体验。

## 粘性来源

塔防进度系统：完成波次解锁新陷阱和新场景。

## Meta 系统

陷阱解锁：通过游戏进度解锁新陷阱类型。关卡解锁：完成所有波次解锁更高难度。

## 实现难度

中 — 需要策略性放置陷阱。最大技术难点是陷阱的物理效果和AI寻路。
