# Disco Elysium: The Final Cut

- **类型**: RPG / 叙事
- **平台**: PC / PS / Xbox / Switch
- **开发商**: ZA/UM
- **首次发布**: 2019
- **一句话描述**: 没有战斗的 RPG，以 24 种技能人格对话和深刻的叙事重新定义角色扮演游戏。

## 玩法规则

玩家扮演一位失去记忆的侦探，在虚构城市 Revachol 调查一起谋杀案。游戏没有传统战斗——所有冲突通过对话、技能检定和选择来解决。

24 种技能（逻辑、共情、内陆帝国、戏剧性等）各自具有人格化的声音，在关键时刻给玩家提供建议。这些声音有时互相矛盾，玩家需要决定相信哪个。

游戏的选择系统极为丰富——几乎每个对话选项都会影响剧情走向和角色关系。技能检定（骰子掷点）决定某些行动的成功率，失败也会推动剧情发展而非 Game Over。

## 核心循环

调查线索 → 与角色对话 → 技能检定 → 做出选择推进剧情

## 核心机制

- 24 种技能人格：每个技能有独立的声音和观点
- 对话驱动：所有冲突通过对话和选择解决
- 技能检定：骰子掷点决定行动成功率
- 选择后果：每个决定影响剧情走向
- 无战斗设计：纯粹依靠叙事和对话

## 为什么好玩

文学级的叙事深度。24 种技能人格的内心对话创造了一种独特的心理体验，让玩家真正"扮演"一个有复杂内心世界的角色。

## 粘性来源

- 叙事深度：文学级的对话和角色塑造
- 技能人格的内心冲突：24 种声音互相辩论的独特体验
- 选择的影响力：每个决定都有真实后果
- 失败也有趣：检定失败推动剧情而非 Game Over

## Meta 系统

无传统 Meta 系统。技能升级通过经验值分配，影响对话选项和检定成功率。

## 实现难度

中。技术难点不大，核心在于叙事创作——数十万字的对话文本、分支剧情和角色塑造需要大量写作投入。
