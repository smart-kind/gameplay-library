# 古德斯（Guidus）

- **类型**: 像素风 Roguelike / 动作RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: izzle Inc.
- **首次发布**: 2021
- **一句话描述**: 一款像素风Roguelike动作游戏，玩家操控各种英雄角色深入地牢，利用独特技能和超级力量击败深渊怪物，夺回被占领的王宫。

## 玩法规则

游戏采用俯视视角的地牢探索布局，画面以精美的像素点阵风格呈现。玩家从地牢底层开始，需要逐层向上探索，击败沿途的怪物和Boss。

屏幕左侧是虚拟摇杆控制角色移动，右侧是攻击和技能按钮。每个英雄有独特的基本攻击和一个或多个强力技能（如冲击波、雷神之锤、新星爆发等）。

地牢中分布着各种怪物，每种怪物有独特的攻击模式和移动方式。Boss战是游戏的核心挑战——Boss拥有多种攻击阶段和特殊技能，需要玩家观察其攻击规律并找到安全的输出窗口。

地牢中还有隐藏的宝藏和危险的陷阱。宝藏可以提供强力装备和增益效果，但陷阱可能对角色造成伤害。有时陷阱甚至可以被巧妙利用来对付敌人。

角色死亡后，部分成长进度保留（英雄等级和技能升级），但当前地牢探索进度重置。玩家可以重新选择英雄再次挑战。

## 核心循环

选择英雄深入地牢 → 战斗收集装备 → 击败Boss进入下一层 → 角色死亡后带着永久成长重新开始

## 核心机制

- **多英雄系统**：持续更新的英雄阵容，包括剑士、弓箭手、法师、精灵和武僧等。每个英雄有独特的技能组合和战斗风格，玩家可以收集不同外观和玩法的英雄。
- **超级技能系统**：每个英雄拥有独特的强力技能，如冲击波、雷神之锤、新星爆发等。这些技能有冷却时间，需要在关键时刻使用，是击败Boss和清理大量敌人的关键。
- **陷阱与宝藏机制**：地牢中隐藏的陷阱和宝藏增加了探索的不确定性。玩家需要权衡风险与收益——有时冒险踩陷阱反而能利用它对敌人造成伤害。
- **永久成长系统**：虽然每次探索的进度会重置，但英雄的等级、技能和解锁内容永久保留。这让每次失败都带有进步的意义，而非完全的惩罚。

## 为什么好玩

像素风的精美画面配合流畅的动作战斗，营造出一种经典的Roguelike体验但又充满现代游戏的精致感。每个英雄的独特技能让战斗风格变化丰富，从剑士的近战砍杀到法师的远程轰炸，每种玩法都有新鲜感。Boss战的设计有挑战性但不令人沮丧——每次失败都能学到新的应对策略。

## 粘性来源

英雄收集是核心粘性来源——新英雄的解锁让人兴奋，想要尝试不同战斗风格的冲动驱动持续游玩。"就差一层就能通关"的不甘心和永久成长系统（每次死亡都在变强）让玩家很难放下手机。各种Boss的独特攻击模式也让每次挑战都有学习曲线，成功后成就感巨大。

## Meta 系统

游戏包含英雄解锁和升级系统。通过游戏进程解锁新英雄，每个英雄可以独立升级技能和属性。游戏内设有排行榜和成就系统。无复杂的付费成长系统，核心进度完全通过游玩获得。

## 实现难度

中。像素美术和动作战斗都是成熟的技术方案。主要挑战在于Boss AI的模式设计和多英雄的技能平衡。最大的技术难点在于程序生成地牢与预设Boss战区域的结合——需要确保随机生成的地牢在遇到Boss时有合理的空间布局和战斗体验。
