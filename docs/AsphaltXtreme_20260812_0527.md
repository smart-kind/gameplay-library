# 狂野飙车：越野极限（Asphalt Xtreme）

- **类型**: 竞速
- **平台**: Mobile (iOS+Android)
- **开发商**: Gameloft（Netflix）
- **首次发布**: 2023（Netflix版）
- **一句话描述**: Gameloft 越野竞速系列最新作，Netflix 订阅用户独享。

## 玩法规则

高速越野竞速，穿越峡谷、山脉、沙漠等极限环境。玩家控制各类越野车，进行跳跃、漂移和特技表演，与 AI 或其他玩家竞赛。

操控采用倾斜或触控方式，在复杂地形上保持车辆平衡的同时超越对手。特技系统允许空中翻转和漂移获得加速。

## 核心循环

选择车辆 → 赛道竞速 → 表演特技/漂移 → 获得奖励 → 升级车辆 → 解锁新赛道

## 核心机制

- 车辆多样性：多种越野车型，各有不同操控特性
- 特技系统：跳跃、桶滚和漂移获得加速和积分
- 赛道多样性： diverse 极限环境，各有独特障碍

## 赛事与多人模式

游戏包含多种赛事类型：传统竞速、淘汰赛、计时挑战等。每种模式有不同的目标和奖励结构。

多人模式支持与全球玩家实时竞速，排行榜系统记录最佳成绩。每日赛事提供特殊奖励和限时车辆。

## 为什么好玩

快节奏街机竞速配合令人满意的漂移机制和壮观的越野环境。

## 粘性来源

车辆收集、赛道多样性和高速越野竞速的刺激感。

## Meta 系统

Netflix Games — 包含在订阅中，无内购

## 实现难度

低-中等 — 街机式竞速，休闲玩家易上手
