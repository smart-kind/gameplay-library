# Eternal Descent: Heavy Metal Heroes

- **类型**: 动作 / 横版过关
- **平台**: Mobile (iOS+Android)
- **开发商**: Slightly Mad Studios / 改编自同名漫画
- **首次发布**: 2013
- **一句话描述**: 横版自动奔跑的金属摇滚战士，用吉他当武器痛击地狱生物

## 玩法规则

游戏画面采用横版自动奔跑视角，玩家扮演一位穿着牛仔布、手持吉他的金属摇滚战士（形象类似北欧神话中的索尔），从左向右自动奔跑。

屏幕操作简洁：点击屏幕左侧发动上勾拳（用吉他把敌人击飞到空中）；点击屏幕右侧发动直拳攻击。按住对应按键可以蓄力，释放更强力的攻击，将敌人打飞并撞向其同伙。

敌人从地狱中涌现，包括各种小型怪物和 Boss 角色。游戏还邀请了现实中的摇滚音乐人客串出场，如 Joe Satriani 和 Andrew W.K.，他们以临时增益或 Boss 的形式出现。

游戏在初始版本发布后已通过更新修复了操作延迟问题，但整体手感仍然偏粗糙。

## 核心循环

自动奔跑 → 击打/上勾拳消灭敌人 → 通过蓄力打出更强力攻击 → 推进关卡

## 核心机制

- **左右拳双控系统**：左勾上勾（击飞），右勾直拳（击退），两种攻击形成简单的连招可能性
- **蓄力机制**：按住攻击键可以蓄力，释放更强力的击飞效果，可以连锁撞倒多个敌人
- **摇滚客串系统**：现实摇滚明星作为特殊 Boss 或增益出现，为金属乐迷带来惊喜

## 为什么好玩

吉他当武器的设定本身就很有创意，金属摇滚主题与横版动作的结合在移动端比较少见。蓄力击飞后看着敌人连锁撞倒其他敌人的场面带来一定的爽快感。但评测也指出战斗手感粗糙，重复性较高，可能只适合金属乐迷或原著漫画粉丝。

## 粘性来源

摇滚明星客串的收集新鲜感——每次遇到新的摇滚音乐人都会带来短暂的兴奋。但整体机制深度有限，粘性主要来自对金属摇滚文化的喜爱而非玩法本身。

## Meta 系统

无明显的成长系统，主要依赖关卡推进和 Boss 战推进剧情。
