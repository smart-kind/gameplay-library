# Stick War

- **类型**: 策略/塔防/即时战略
- **平台**: Web / Mobile (iOS+Android)
- **开发商**: Max Games
- **首次发布**: 2009
- **一句话描述**: 终极火柴人王国防御游戏——采矿、训练军队、摧毁敌方国王雕像

## 玩法规则

Stick War 是一款火柴人主题的即时战略+塔防游戏。玩家扮演"Stick King"（火柴人国王），需要保卫己方国王雕像的同时，摧毁敌方的国王雕像。

游戏画面为2D横向卷轴布局，玩家基地在屏幕左侧，敌方基地在右侧。屏幕下方是操作面板，显示当前拥有的金币数量和可购买的兵种选项。屏幕上方显示双方雕像的生命值。

玩家的核心操作包括：
- 购买矿工（Miner）：矿工自动在基地附近采集金币，是经济基础
- 购买战斗单位：包括剑士（Swordwr）、弓箭手（Archidon）、长矛兵（Spearton）等，每种兵种有不同的攻击方式和属性
- 控制进攻/防守模式：可以命令部队集体进攻敌方基地，或者在己方雕像前防守
- 在部分模式下可以直接控制单个单位进行操作（手动控制移动和攻击）

游戏目标是摧毁敌方的国王雕像，同时保护自己的雕像不被摧毁。随着关卡推进，敌人会越来越强，兵种组合也会越来越复杂。失败条件：己方国王雕像被摧毁。

## 核心循环

矿工采矿获得金币 → 用金币购买战斗单位 → 指挥部队进攻或防守 → 摧毁敌方雕像通关 → 解锁新兵种 → 挑战更强的敌人

## 核心机制

- **经济管理系统**: 矿工自动采集金币，金币是所有军事行动的资源基础。矿工数量和采集效率直接决定了你能多快地组建军队。在进攻和采矿之间找到平衡是核心策略。
- **兵种克制系统**: 不同兵种之间存在克制关系——剑士近战能力强但怕远程，弓箭手可以远程攻击但近战脆弱，长矛兵防御高但移动慢。合理搭配兵种是胜利的关键。
- **手动/自动双模式**: 玩家既可以让AI自动指挥部队，也可以在关键时刻手动控制单个单位进行精准操作（如用弓箭手狙杀关键目标），增加了操作深度。
- **雕像攻防机制**: 双方雕像既是目标也是生命线——摧毁敌方雕像即胜利，己方雕像被毁则失败。雕像有独立生命值，单位可以对其造成持续伤害。

## 为什么好玩

看着自己组建的火柴人军队浩浩荡荡向敌方推进的成就感极强。兵种搭配带来的策略深度——什么时候该多出弓箭手，什么时候该上长矛兵顶前排——每场战斗都像在下一盘即时战略的棋。手动控制单个单位进行微操的瞬间也带来了RTS级别的爽快感。

## 粘性来源

解锁新兵种带来的成长感是主要粘性来源——每通关几关就会获得一个全新的兵种，让你可以用新的策略组合重新挑战。关卡难度的渐进式提升让你觉得"就差一点点"，忍不住想再试一次。火柴人的简洁画风和搞笑的死亡动画也让重复游玩不枯燥。

## Meta 系统

兵种解锁系统——随着关卡推进，逐步解锁新的兵种类型（从最基础的剑士到弓箭手、长矛兵、法师等）。每次解锁新兵种都会改变核心玩法的策略空间，让玩家用全新的思路重新打之前的关卡。

## 实现难度

中——需要实现RTS基础架构（单位AI、路径寻路、碰撞检测、群体行为控制），最大技术难点是大量单位同时存在的性能优化和兵种AI的智能程度（需要让电脑对手表现得有策略性而非无脑冲锋）。
