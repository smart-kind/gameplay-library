# 迷你游戏 - 放松舒缓（Mini Games: Calm & Chill）

- **类型**: 休闲/放松
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2024
- **一句话描述**: 以放松舒缓为主题的迷你游戏合集

## 玩法规则

玩家在主界面选择各类放松小游戏，如涂色、拼图、种植等。每款游戏节奏缓慢，没有时间压力。玩家通过简单的触屏操作（点击、滑动、拖拽）完成游戏目标。游戏配以舒缓音乐和柔和色彩，营造放松氛围。没有失败条件，所有操作都是正向反馈。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

选择放松游戏 → 缓慢操作 → 获得平静体验 → 继续游玩

## 核心机制

- **无压力设计**:  没有时间限制和失败条件
- **舒缓美学**:  柔和色彩、舒缓音乐、流畅动画
- **多样化放松活动**:  涂色、拼图、种植等多种选择

## 为什么好玩

在快节奏生活中提供一片宁静绿洲，简单操作即可体验放松感

## 粘性来源

放松体验本身就是粘性来源；新活动定期更新保持兴趣

## Meta 系统

活动解锁系统，随着游玩解锁更多放松活动

## 实现难度

低 - 单款小游戏实现简单，核心在于美术和音效设计 - 保持低压力体验与足够趣味性的平衡
