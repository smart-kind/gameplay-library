# Log Thrower (Log Thrower)

- **类型**: 超休闲物理弹射 / 精准瞄准
- **平台**: Mobile (iOS+Android)
- **开发商**: Playgendary Limited
- **首次发布**: 2020
- **一句话描述**: 将各种日常物品变成武器，装上投石机瞄准发射的物理弹射游戏

## 玩法规则

游戏呈现一个固定的投石机（Cannon）装置，玩家的任务是将各种日常物品（木头、石头、家具等任何能找到的东西）磨尖后装上投石机，瞄准远处的目标并发射。

操作方式：拖拽调整投石机的角度和力度——通常是拖拽屏幕上的投石臂来设定角度，松开后发射。发射后物品沿抛物线飞行，击中目标得分。

每次发射的射击次数有限（"Shots are limited"），因此需要仔细瞄准，确保每次发射都尽可能得分。评分系统（"jury"）会根据击中效果给出分数——可能考虑精准度、力度、特殊效果等因素。

游戏的目标是在有限的射击次数内获得最高分。关卡可能设置不同的目标距离、大小和环境障碍，需要调整策略。

## 核心循环

选择物品 → 磨尖/准备 → 调整角度和力度 → 发射 → 获得评分 → 进入下一关

## 核心机制

- **物理弹射系统**：基于真实物理的抛物线投射，角度和力度决定落点，提供可学习的技能曲线
- **有限射击次数**：每次关卡的射击次数受限，迫使玩家认真瞄准而非随意乱射，增加策略深度
- **物品多样化**：把"各种和平的东西变成武器"——从木头到家具到任何日常物品，幽默感和新鲜感并存
- **评分反馈**：由"评审团"（jury）打分，可能基于精准度、力度等维度，提供量化反馈

## 为什么好玩

将日常物品变成投射武器的设定本身就很有趣——"把沙发扔出去"的荒诞感带来欢乐。物理弹射的精准瞄准提供了"我能做到"的掌控感和命中时的满足感。有限射击次数让每次发射都有意义，不会变成无脑点击。

## 粘性来源

"差一点点就满分"的精准度挑战是核心粘性——每次失败都让人觉得"角度再调小一点就行"。物品的多样性和幽默感（各种奇怪的东西被发射出去）提供持续的娱乐价值。物理弹射游戏的天然特性是"掌握了就能玩得很好"，技能成长感驱动持续练习。

## Meta 系统

无典型的成长系统。可能有订阅制的去广告或解锁特殊物品功能（根据iTunes描述的订阅条款提示）。

## 实现难度

低。核心是2D物理引擎（角度+力度→抛物线轨迹）+碰撞检测。Playgendary作为成熟的超休闲游戏开发商，这类物理弹射是他们最擅长的品类。最大技术难点在于确保物理模拟在不同设备上的表现一致性，以及设计有趣的关卡变化（距离、风向、障碍物等）。
