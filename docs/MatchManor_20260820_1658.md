# Match Manor

- **类型**: 3D匹配解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: IMAGINITE STUDIOS TEKNOLOJI ANONIM SIRKETI
- **首次发布**: 2023
- **一句话描述**: 一款3D匹配消除游戏，玩家在杂乱的3D物品堆中寻找并匹配相同的3D物件。

## 玩法规则

游戏界面展示一堆杂乱的3D物品，包含各种造型可爱的小物件。玩家需要在物品堆中找到3个完全相同的物品并依次点击它们来完成匹配消除。被消除的物品消失后，后方的物品显露出来，玩家需要不断翻找和匹配，直到清除整个物品堆。

关卡设计中，物品堆分为多层，玩家需要先清除表层物品才能接触到下层物品。某些关卡设置了时间限制，需要在限定时间内完成所有匹配。有些关卡包含特殊物品，如无法直接匹配的锁住物品，需要先完成特定条件才能解锁。

每关的物品数量和种类随进度递增，物品堆的复杂程度也随之提高。玩家需要运用记忆力和观察力来高效完成匹配。

## 核心循环

观察物品堆 → 找到3个相同物品并消除 → 逐步清除 → 解锁新关卡

## 核心机制

- **3D堆叠视觉系统**：物品以3D形式堆叠，从杂乱的表面中识别相同物品需要一定的观察力。物品的可爱造型和3D渲染提供了视觉上的吸引力。
- **记忆+匹配双重要求**：不同于传统三消只需关注相邻方块，3D匹配需要玩家在多个物品之间进行记忆和识别，增加了认知挑战。
- **渐进式难度曲线**：从简单的少量物品堆到复杂的多层堆叠，难度逐步提升，每关提供新的视觉挑战。

## 为什么好玩

"翻找"带来的探索感和发现感是核心乐趣——在杂乱的3D物品堆中突然找到3个相同物品的瞬间有种"寻宝"的满足感。可爱的3D物件本身就有观赏价值，清除物品堆的过程类似"整理"一样有治愈感。

## 粘性来源

"就差最后几个物品了"的完成欲是核心粘性。清除整个物品堆带来的成就感非常强烈，尤其是面对复杂的关卡时。物品的可爱造型和3D效果也提供了视觉层面的持续吸引力，让人想看看下一个关卡有什么新物品。

## Meta 系统

包含庄园/庭院装饰元素，通过完成关卡获得的奖励来装饰和修复庄园。玩家的选择影响庄园的最终外观，提供了长期目标感。

## 实现难度

中。核心挑战在于3D物品的渲染和交互设计——需要在移动设备上流畅渲染大量3D物件，同时确保点击识别的准确性。最大技术难点在于3D堆叠层级的遮挡处理和物品识别的用户体验优化。
