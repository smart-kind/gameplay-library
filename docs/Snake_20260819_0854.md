# Snake

- **类型**: 休闲 / 街机
- **平台**: Mobile (iOS+Android) / Feature Phone / Web
- **开发商**: Various (最早由Taneli Armanto为诺基亚开发)
- **首次发布**: 1997
- **一句话描述**: 玩家控制一条蛇在屏幕上移动，吃食物让蛇变长，不能撞到墙壁或自己的身体

## 玩法规则

游戏画面通常是一个矩形区域（可能有网格线）。玩家控制一条蛇在区域内移动。蛇初始只有几节长度，从屏幕中央或一侧开始移动。

食物随机出现在屏幕上的空位，每次出现一个。

玩家操作：
- 方向控制：上下左右改变蛇的移动方向
- 持续移动：蛇会持续朝当前方向移动，不能停止

游戏目标：吃食物让蛇变长，同时避免碰撞。

核心规则：
- 每吃一个食物，蛇的身体增加一节长度，得分增加
- 蛇不能撞到墙壁（游戏区域边界）
- 蛇不能撞到自己的身体
- 蛇不能反向移动（不能直接掉头）

游戏结束条件：
- 撞到墙壁
- 撞到自己的身体

进阶版本：
- 随着蛇变长，移动速度可能加快
- 有些版本有障碍物、多个食物、或特殊食物

## 核心循环

移动吃食物 → 蛇变长 → 空间变小 → 更需谨慎 → 更高分

## 核心机制

- **自碰撞检测**: 蛇越长越容易撞到自己，形成自然的难度递增，每吃一个食物都增加风险
- **方向锁定**: 不能反向移动防止作弊，但增加了策略性，需要规划路线
- **空间压缩**: 蛇变长意味着可用空间减少，迫使玩家做出更精确的操作
- **速度递增**: 某些版本中蛇越长速度越快，增加紧张感

## 为什么好玩

极简规则下的深度策略。当蛇很长时，每一次转弯都需要精确计算路线。差一点就撞到的惊险感和成功规划路线后的成就感形成强烈对比。随时随地都能玩一局。

## 粘性来源

再来一次效应极强，每局游戏短（1-5分钟），输了立刻想重试。高分竞争和自我挑战是核心驱动力。蛇越来越长时的紧张感让人上瘾。

## Meta 系统

通常无。部分手机版本有皮肤解锁或速度选择。

## 实现难度

低。核心技术是蛇的数据结构（通常用队列）和碰撞检测。难点在于手感调优，移动速度要恰到好处。
