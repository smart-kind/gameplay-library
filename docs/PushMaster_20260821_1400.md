# Push Master

- **类型**: 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: tatsumaki games
- **首次发布**: 2023
- **一句话描述**: 一款超休闲推挤游戏，玩家释放大量人群推碎沿途障碍物

## 玩法规则

游戏采用竖屏单指操作。屏幕下方会不断出现人群，玩家点击屏幕后人群向前推进，撞碎沿途的障碍物。每关有不同形状和大小的障碍物，玩家需要合理安排人群的推进方向和时机。

障碍物被撞碎后会有爽快的粉碎效果，碎片飞溅的视觉效果带来强烈的满足感。关卡设计从简单的单一障碍物到复杂的多层障碍阵列。

游戏目标是清除关卡中所有障碍物。部分关卡有步数限制，需要用最少的推挤次数完成。

每局比赛通常只需30秒到1分钟，非常适合碎片时间游玩。

## 核心循环

点击释放人群 → 撞碎障碍物 → 获得金币 → 解锁新关卡

## 核心机制

- **人群物理模拟**: 大量独立个体组成人群向前推进，每个个体有简单的物理行为，整体呈现出流体般的推进效果。人群的密度和推力随关卡变化。
  （物理模拟）
- **障碍物破坏系统**: 不同类型的障碍物有不同的生命值和破坏效果。小型障碍物一击即碎，大型障碍物需要多次推挤。破坏时的粉碎特效提供即时爽感反馈。
  （即时反馈）
- **关卡递进设计**: 从单一障碍物到多层复合障碍阵列，从固定障碍到移动障碍，难度曲线平滑上升。每关都是一个新的空间解谜挑战。
  （难度曲线）

## 为什么好玩

人群推挤时的物理效果非常爽快，看着障碍物被一点点推碎有强烈的满足感。操作简单但关卡设计精妙，每次推挤都需要考虑角度和力度。

## 粘性来源

破坏带来的即时视觉爽感、'差一点就过关'的不甘心、解锁新关卡的好奇心。每关都是独立的空间谜题，解开的成就感推动继续游玩。

## Meta 系统

金币解锁新关卡和人群皮肤，无深度数值成长系统。核心驱动力是关卡解锁。

## 实现难度

低 — 核心机制只需简单的点击和基础2D物理模拟。技术难点在于人群物理的自然感和破坏效果的视觉表现。
