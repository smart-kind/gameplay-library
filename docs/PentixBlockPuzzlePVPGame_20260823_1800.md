# Pentix - Block Puzzle PVP Game

- **类型**: 方块益智
- **平台**: Mobile (iOS)
- **开发商**: AkaTek LLC
- **首次发布**: 2018-2024
- **一句话描述**: New twist in classic Falling Blocks game

## 玩法规则

游戏开始时，玩家面对一个核心游戏区域（棋盘/房间/战场），其中包含各种互动元素。

在方块益智类模式中，屏幕中央显示一个网格或空白区域，底部或侧边提供待放置的方块/图形。玩家通过拖拽操作将方块放入游戏区域，当填满一行或一列时自动消除并计分。游戏持续生成新方块直到无法放置为止。

在卡牌对战模式中，玩家手中有数张卡牌，每回合从牌库抽取新牌。每张卡牌有费用、攻击力和特殊效果。玩家需要合理分配资源点（法力/能量）来出牌，攻击敌方单位或释放技能。敌方也会在自己回合行动，形成回合制对抗。

在逃脱解谜模式中，玩家被放置在一个封闭场景中，需要通过点击探索来寻找线索。场景中包含可互动的物品、隐藏的密码和道具。找到钥匙解开锁、组合物品触发机关、输入正确密码打开门——这些都是通关的必要步骤。

游戏目标：在益智模式中尽可能获得高分或清除所有方块；在卡牌模式中击败所有敌人到达终点；在逃脱模式中解开所有谜题成功逃脱。游戏在无法继续操作（方块无处可放/生命耗尽）或完成目标时结束。

## 核心循环

放置/匹配方块 → 清除行或列 → 获得分数 → 解锁新关卡/道具 → 继续挑战

## 核心机制

- 空间规划：玩家需要在有限空间内合理安排方块或图形的位置，目标是填满行或列来消除它们。
- 实时竞争/计时：部分游戏支持多人对战或限时挑战，增加紧张感和竞技性。
- 连锁消除：一次消除可能引发连锁反应，带来额外的分数奖励和视觉满足感。


## 为什么好玩

这款游戏在同类中找到了独特的切入点。方块益智的核心体验被精炼到极致，每一次操作都有明确的反馈。多人模式增加了社交维度，让原本单人的益智体验变成了一场智力的较量。

## 粘性来源

方块益智游戏的'差一点就成功'心理让人忍不住再来一局；无计时模式的放松体验适合碎片化游玩；多人对战增加社交竞争。

## Meta 系统

皮肤和装饰系统：通过游戏内货币解锁方块外观、背景主题等装饰内容。

## 实现难度

低 — 核心在于UI交互和关卡设计，技术门槛不高，难点在于关卡平衡性和解谜逻辑设计
