# Merge Mayor

- **类型**: 合并+城镇建造
- **平台**: Mobile (iOS+Android)
- **开发商**: Starberry Games GmbH
- **首次发布**: 2021
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

匹配两个相同物品进行合并 -> 完成任务和建造城镇 -> 解锁新区域和功能

## 核心机制

- **Merge-2合并机制**: 在棋盘上匹配两个相同的物品（如木材、花朵、工具）进行合并，生成更高级的物品。这是游戏的核心操作，所有建造和任务都依赖于合并产出。
- **城镇建造系统**: 使用合并产出的物品来修复和建造城镇设施。每个设施需要特定类型的物品，玩家需要有目的地进行合并。建造完成后解锁新区域和新物品，形成正向循环。
- **任务驱动推进**: 每个关卡设有明确任务（如合并特定物品、建造特定设施）。完成任务获得奖励和进度推进。任务系统提供了清晰的目标感和阶段性成就感。

## 为什么好玩

合并+建造的双重满足感。既有解谜的策略性，又有建造的成长感。看着小镇从废墟中恢复的过程带来强烈的成就感。

## 粘性来源

粘性来源于城镇建设的长期成长感和任务完成的即时满足。每个新区域的解锁都是一个小里程碑。

## Meta 系统

- 城镇建造系统：使用合并物品修复和建造设施，解锁新区域
- 任务系统：每关提供特定任务目标
- 对核心玩法的影响：任务目标引导合并策略，建造系统提供长期成长目标

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
