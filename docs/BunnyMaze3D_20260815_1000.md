# Bunny Maze 3D

- **类型**: 益智解谜 / Maze Puzzle
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2012
- **一句话描述**: 一款在移动平台上发布的益智解谜类型游戏

## 玩法规则

3D 迷宫益智游戏。画面呈现立体迷宫场景，玩家控制一只兔子在迷宫中寻找出口。

玩家通过滑动屏幕控制兔子移动方向（上下左右四个方向），兔子沿选定方向持续移动直到撞到墙壁。迷宫中有胡萝卜收集品，部分关卡有传送门、活动墙壁、机关陷阱等元素。

每次滑动操作有流畅的移动动画和碰撞音效。找到所有胡萝卜后出口大门打开，兔子走出即过关。

游戏目标是找到迷宫出口并收集所有胡萝卜。后期关卡迷宫复杂度增加，加入时间限制和更多机关。

## 核心循环

探索迷宫 → 收集胡萝卜 → 找到出口过关 → 解锁更复杂迷宫

## 核心机制

- **惯性移动**：一旦选定方向持续滑行，需要预判墙壁位置
- **收集驱动**：胡萝卜收集作为过关条件和额外奖励
- **机关互动**：传送门、活动墙壁增加解谜维度

## 为什么好玩

3D 迷宫的视觉新鲜感加上惯性移动的独特操控方式，每次找到隐藏路线都很有成就感。收集胡萝卜的满足感也驱动探索。

## 粘性来源

每关收集胡萝卜的完成驱动+更复杂迷宫的好奇心。'差一点就能全收集'驱动反复尝试同关。

## Meta 系统

无

## 实现难度

低——迷宫生成和惯性移动是基础算法。最大的技术难点是 3D 迷宫的生成算法（保证连通性和趣味性）以及碰撞检测的精度。
