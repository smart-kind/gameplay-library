# Peggle（Peggle）

- **类型**: 弹球消除 / 休闲
- **平台**: Mobile (iOS+Android) / PC / DS
- **开发商**: PopCap Games
- **首次发布**: 2007
- **一句话描述**: 发射弹球击落所有橙色钉子即可过关的经典休闲游戏

## 玩法规则

屏幕上布满大量彩色钉子（蓝色普通钉和橙色特殊钉），顶部有一个可左右移动的发球器。

操作方式：左右移动发球器瞄准，点击发射弹球。弹球在重力作用下下落，碰到钉子会弹起并改变方向（类似弹珠台物理），被弹球碰到的钉子会亮起并消失。

游戏目标：每关需要清除所有橙色钉子（蓝色钉子是干扰物）。发射次数有限（通常10球），用尽前清除所有橙钉即过关。碰到特殊能力钉（绿色钉）可触发角色特殊能力，如多球、慢动作、火焰球等。

游戏结束条件：弹球全部用完且仍有橙钉残留则失败；清光所有橙钉则过关，并根据得分给出狂热(Fever)评价。

## 核心循环

瞄准发射 -> 弹球碰钉子得分并消除 -> 清除所有橙色钉子过关

## 核心机制

- 物理弹射：弹球与钉子碰撞遵循真实物理反射，每次弹射轨迹不可完全预测，产生惊喜感
- 特殊能力系统：每个关卡对应一个角色，触发绿色钉后激活该角色的独特能力（如多球发射、球体变大、自动瞄准等）
- 狂热模式(Fever)：清除最后一颗橙钉后进入狂热模式，剩余所有球变成金球，每个球价值5000分，极大提升得分上限

## 为什么好玩

弹球在钉子间疯狂弹跳的视觉效果配合欢快的音乐，带来极强的感官愉悦。每一次看似不可能的弹射角度都可能带来意外收获，这种随机性与可控性的平衡让人上瘾。清除最后一颗橙钉时进入狂热模式的高潮体验尤其令人满足。

## 粘性来源

狂热模式的爽感反馈是核心粘性来源——即使前面打得不好，最后的狂热模式也能带来巨大满足感；10关x5个角色共50关提供了充足的通关目标；每关追求更高分和Extreme Fever评价增加了重玩价值。

## Meta 系统

成就系统（完成特定条件解锁）、角色收集（通关解锁新角色）。

## 实现难度

低 — 核心玩法极其简单，物理引擎是关键。最大技术难点是2D物理碰撞的精确计算和大量弹球同时运动时的性能表现。
