# 神秘物品：犯罪谜案（Hidden Objects: Mystery Crimes）

- **类型**: 找物解谜 / 推理
- **平台**: Mobile (iOS+Android)
- **开发商**: Storm8 Studios
- **首次发布**: 2013
- **一句话描述**: 在犯罪现场寻找隐藏线索，结合剧情推进的找物解谜冒险游戏。

## 玩法规则

玩家进入一个犯罪案件场景（如案发现场、嫌疑人房间、办公室等），画面以精美的2D手绘风格呈现。屏幕底部显示当前需要寻找的物品清单，这些物品通常与案件调查相关——凶器、可疑物品、证物等。

玩家通过点击/拖拽方式在场景中搜索物品。找到正确物品时，物品被标记为"已发现"并加入证据栏；点错则扣除时间或出现错误提示。部分物品需要组合使用——例如先找到钥匙才能打开抽屉，再从抽屉中获取关键证物。

每个案件由多个场景组成，玩家需要在不同场景中收集足够线索才能推进剧情。部分关卡设有"推理环节"——玩家需要从已收集的线索中选出正确答案，选对则案件告破，选错则需重新收集线索。

## 核心循环

搜索场景找线索 → 收集证物 → 推进剧情推理 → 解锁新案件

## 核心机制

- 证据链机制：物品之间存在逻辑关联，找到A才能获取B，形成探索路径。让玩家从'漫无目的寻找'变成'有目标的调查'。
- 剧情推进机制：每个案件是一个独立故事，完成推理后解锁下一章。剧情碎片化的呈现方式（通过场景和物品暗示）让玩家有'参与破案'的代入感。
- 限时调查机制：部分紧急场景有倒计时，营造破案紧迫感。倒计时结束后案件难度上升或失败。

## 为什么好玩

找物+推理的结合让单纯的'找东西'有了意义——你不是在随机点击，而是在破案。每个案件的故事给了物品收集以叙事框架，找到关键证据时的成就感远超普通找物游戏。

## 粘性来源

案件悬念驱动——'凶手是谁'的好奇心是最大粘性。每个案件完成后解锁下一章，形成追剧式的持续游玩动机。此外，限时场景的'差一点就破案'的不甘心也促使玩家反复尝试。

## Meta 系统

章节解锁系统，每完成一个案件章节解锁新主题（如都市犯罪、密室谋杀等）。无复杂数值成长，以内容解锁为主。部分版本设有每日案件挑战，保持日常活跃度。

## 实现难度

低。2D静态场景+热区检测+简单剧情分支。最大难点在于案件剧情编写和场景美术的协调——需要让每个场景的线索分布既合理又有趣。


玩家在每个案件中扮演的角色是侦探助手，随着案件推进，会逐渐发现案件背后的更大阴谋。某些案件之间存在叙事联系——一个案件的证物可能成为另一个案件的关键线索，形成跨案件的叙事网络。游戏在找物之外，还加入了简单的推理判断环节：玩家需要从多个嫌疑人中选择正确的罪犯，选择依据就是在场景中收集到的证物。
