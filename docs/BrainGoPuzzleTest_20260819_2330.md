# Brain Go: Puzzle Test

- **类型**: 益智解谜 / 脑筋急转弯 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: WONDER GROUP HOLDINGS LIMITED
- **首次发布**: 2020
- **一句话描述**: 一款集合多种脑筋急转弯谜题的休闲解谜游戏，以"引导解谜家族"为核心主题，考验玩家的非常规思维

## 玩法规则

游戏画面以卡通风格展示各种谜题场景，每个场景都有明确的目标（如"帮助角色到达目的地"、"找到隐藏的物品"、"解决矛盾"等）。

玩家需要用非常规的方式与场景互动来找到答案。操作方式包括但不限于：点击看似无关的背景元素、拖拽物品进行非常规组合、长按等待某个变化发生、擦除屏幕上的特定区域、旋转或翻转设备等。

例如：关卡提示"让灯亮起来"，不是找开关而是把灯泡"拧"到另一个插座上；提示"找到钥匙"，不是到处找而是把画面"倒过来"看；提示"过河"，不是造桥而是把角色"变小"直接走过去。

屏幕通常分为三个区域：顶部的关卡目标和进度提示、中央的主要交互场景、底部的功能按钮（提示、重置、关卡选择）。玩家通过尝试各种交互方式逐步缩小正确答案的范围，直到找到那个"出人意料但合情合理"的解法。

## 核心循环

阅读关卡目标 -> 尝试各种非常规交互 -> 发现隐藏的解谜路径 -> 完成目标解锁下一关

## 核心机制

- **隐藏交互触发系统**: 场景中看似"装饰性"的元素往往是解谜关键——一个不起眼的按钮、一段可以擦除的文字、一个可以翻转的相框。玩家需要通过试错发现这些隐藏的可交互元素
- **多层谜题嵌套**: 部分关卡需要完成多个步骤才能通关——第一步发现隐藏元素，第二步利用该元素触发新变化，第三步在新场景中找到最终答案。这种嵌套结构增加了谜题的深度
- **主题化谜题系列**: 游戏围绕"解谜家族"的主题，将谜题按场景或故事线分组（如"家庭篇"、"冒险篇"、"节日篇"等）。每个系列有统一的视觉风格和叙事线索，增强沉浸感

## 为什么好玩

每次"灵光一闪"找到正确答案时的满足感是核心乐趣。这类游戏的妙处在于——答案揭晓后你会觉得"我怎么没想到"，这种"既意外又合理"的认知体验让人欲罢不能

## 粘性来源

具体来说：1）"就再玩一关"效应——每个谜题都很短，完成一个后自然想继续下一个；2）好奇心驱动——"下一关会出什么怪招？"；3）低挫败感——即使解不出来也可以看提示，不会卡在某个关卡无法前进；4）社交属性——和朋友比谁先解出来或看谁的解法更"离谱"

## Meta 系统

提示货币系统：通过日常登录、观看广告或通关获得提示币，用于查看多级提示。部分版本包含每日挑战和限时活动关卡

## 实现难度

低（技术实现）。主要难点是创意设计和谜题质量把控——需要确保每个谜题既有趣味性又有合理的解法逻辑。技术实现相对简单，主要是交互检测和场景切换

## 关卡设计趋势

游戏关卡通常遵循由浅入深的设计原则：前期关卡（1-50关）主要让玩家熟悉基本操作和规则，圆点种类少、网格小、步数充裕；中期关卡（50-200关）开始引入多目标并行的挑战，如同时消除两种颜色的圆点、在步数限制内达到分数目标等；后期关卡（200关以上）则加入特殊元素——如不可消除的"石头"圆点、会随步数增加而"冻结"的圆点、需要多次消除才能清除的"多层"圆点等，大幅提升策略复杂度。

这种渐进式难度设计确保了玩家在每个阶段都能感受到"略有挑战但可克服"的心流体验，既不会因为太简单而无聊，也不会因为太难而放弃。
