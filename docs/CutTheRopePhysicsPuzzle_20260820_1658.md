# Cut the Rope: Physics Puzzle（割绳子）

- **类型**: 物理益智解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: ZeptoLab UK Limited
- **首次发布**: 2015
- **一句话描述**: 一款经典的物理益智游戏，玩家通过切割绳索让糖果掉入绿色小怪兽Om Nom的嘴里。

## 玩法规则

游戏画面中央有一个可爱的小怪兽Om Nom，糖果通过一根或多根绳索悬挂在空中。玩家通过手指滑动屏幕来"切割"绳索——手指划过绳索所在位置即完成切割操作。

切割绳索后，糖果受重力和物理引擎的影响自由下落或摆动。目标是让糖果顺利掉入Om Nom的嘴巴。每关散布着3颗星星，糖果经过星星位置时可以收集它们，获得更高评分。

游戏包含425个物理谜题关卡，分布在17个主题盒子中。每个主题引入新的机关和玩法元素：玩具盒子有弹跳平台；魔法盒子有传送帽；蒸汽盒子有阀门和蒸汽装置；宇宙盒子有太空物理特性；气泡盒子有浮力气泡。此外还有气泡、弹簧、吹风机等多种辅助道具帮助引导糖果路径。

## 核心循环

观察关卡布局 → 规划切割顺序 → 切割绳索让糖果掉落 → 收集星星 → 解锁新关卡

## 核心机制

- **切割物理模拟**：切割绳索后糖果的轨迹由精确的物理引擎计算，包括重力、摆动惯性、碰撞反弹等。玩家需要预判糖果的运动轨迹来规划切割时机。
- **主题递进机制**：每17个关卡组成一个主题盒子，每个盒子引入全新的机关和规则。这种渐进式的内容设计确保玩家始终面对新的挑战，不会因重复而感到无聊。
- **三星收集系统**：每关的3颗星星通常分布在不同难度位置，鼓励玩家在通过关卡的基础上追求完美收集。

## 为什么好玩

Om Nom的可爱形象为物理谜题注入了情感连接——玩家不只是在解决谜题，而是在"喂一个饥饿的小怪兽"。切割绳索的瞬间带来极大的满足感，糖果按照预期轨迹落入嘴中的那一刻尤其令人愉悦。

## 粘性来源

三星收集的完美主义驱动和物理谜题"差一点就成功"的不甘心是核心粘性。每个新主题的机关变化提供了持续的新鲜感——即使玩家觉得当前主题通关困难，新机制的出现也让他们想继续尝试。Om Nom的可爱动画反馈（吃到糖果后的满足表情）也是一种强烈的情感奖励。

## Meta 系统

无明确的外围成长系统。游戏的核心吸引力完全来自谜题设计和角色魅力。

## 实现难度

中。需要精确的2D物理引擎支持绳索物理、碰撞检测和重力的组合模拟。最大技术难点在于绳索切割后的动态物理计算——绳索断裂点的确定、糖果初速度的计算、以及多个绳索同时作用时的物理状态同步。
