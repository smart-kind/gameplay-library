# Build a Lot 3: Passport to Europe（Build a Lot 3: Passport to Europe）

- **类型**: 模拟经营 / 时间管理
- **平台**: PC / Mobile
- **开发商**: Hipsoft
- **首次发布**: 2010
- **一句话描述**: 在欧洲各地建造和管理房产的模拟经营游戏

## 玩法规则

游戏画面为俯视角的城镇建设场景，每个关卡占据一片有限大小的地块。地块上有空地、已建建筑和资源建筑三种状态。

玩家需要在每个关卡中完成特定的房产建设目标（如"建造3栋维多利亚式住宅"、"升级2家商店到3级"、"在30天内赚取50000金币"）。目标信息始终显示在画面顶部。

操作为点击式：点击空地弹出建筑菜单选择要建造的建筑类型，点击已建建筑进行升级或出售。每个操作需要消耗时间（显示为进度条）和建材，并花费金钱。

资源管理是核心玩法：木材、砖块和电力是三种基础资源。玩家需要建造对应的资源建筑（伐木场产出木材、砖窑产出砖块、发电厂产出电力）来持续供应，或在资源不足时花费金钱直接购买。

每个关卡有金钱目标和时间限制。在限定时间内达成所有目标即可过关，评价基于剩余时间和金钱余额。失败条件为时间耗尽或破产（金钱为负）。

## 核心循环

规划建筑布局 → 获取资源 → 建造和升级房产 → 出售赚取利润 → 完成关卡目标

## 核心机制

- **时间压力资源管理**：每个操作都有时间成本（建造需要几秒到十几秒），玩家需要在有限时间内做出最优决策。关键问题包括：先建资源建筑保证长期供应，还是直接购买建材节省时间？先升级高价值建筑还是先满足关卡条件？
- **房产经济循环**：建造→升级→出售赚取差价是核心经济循环。不同建筑类型的造价、升级成本和售价差异巨大。住宅造价低但升级后价值增长稳定，商业建筑造价高但出售利润更大。
- **连锁解锁系统**：某些建筑需要前置建筑才能解锁。例如需要先有住宅区达到一定人口才能建造商业建筑，需要有商业建筑才能建造高级娱乐设施。这形成了建设顺序的依赖链。

## 为什么好玩

时间压力下的规划决策很有趣。看着荒地变成繁荣城镇的成就感很强。欧洲各地的建筑风格（法国、意大利、英国等）增添了视觉多样性和文化氛围。

## 粘性来源

关卡推进（解锁新城市和建筑风格）+ 效率挑战（追求更快通关时间和更高评级）。每个城市的建筑风格独特，驱动玩家探索不同地区。

## Meta 系统

关卡解锁系统：完成一个城市的所有关卡后解锁下一个欧洲城市。每个城市有独特的建筑风格和关卡目标。城市解锁顺序大致遵循地理路线（如从法国到意大利到西班牙）。

## 实现难度

低 — 点击建造的核心玩法简单。最大技术难点是关卡难度曲线设计和经济平衡，确保玩家感觉挑战适中而非过于简单或不可完成。
