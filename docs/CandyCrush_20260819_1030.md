# 糖果传奇（Candy Crush Saga）

- **类型**: 三消 / 解谜 / 休闲
- **平台**: Mobile (iOS+Android) / PC / Web
- **开发商**: King
- **首次发布**: 2012
- **一句话描述**: 在网格中交换相邻糖果，三个或以上相同颜色的糖果连成一线即可消除，完成关卡目标。

## 玩法规则

游戏画面是一个矩形网格，网格中填充了不同颜色的糖果。玩家通过交换相邻两个糖果的位置，使三个或以上相同颜色的糖果连成一线（横向或纵向）。消除后上方的糖果会下落填补空缺，新的糖果从顶部进入。

游戏的核心目标是完成每关的特定条件：达到目标分数、消除指定颜色的糖果、释放被困的果冻、运送食材到底部等。每关有移动步数限制，在步数用完前完成目标即可过关。

特殊糖果通过匹配4个或以上获得：4个连成一线产生条纹糖果（消除整行或整列）；L形或T形匹配产生包装糖果（消除周围3x3范围）；5个连成一线产生彩色炸弹（消除所有同色糖果）。特殊糖果之间的组合消除产生更强的效果（如条纹+包装消除3行3列）。

## 核心循环

交换糖果 → 匹配消除 → 获得特殊糖果 → 组合消除 → 完成目标 → 通关

## 核心机制

- **三消核心**：交换相邻糖果使3个同色糖果连线消除，是Bejeweled模式的直接继承。简单直观，几乎不需要学习成本。
- **特殊糖果系统**：匹配4个或5个糖果产生不同效果的特殊糖果，特殊糖果之间的组合消除产生连锁反应。这是游戏策略深度的主要来源——玩家需要规划如何制造和利用特殊糖果组合。
- **关卡目标多样性**：不同关卡有不同目标（分数、果冻、收集等），避免单调。随着关卡推进，目标越来越复杂。
- **步数限制**：步数而非时间作为限制，让玩家有时间思考。但步数限制也意味着每次移动都需要精打细算，增加了策略性。

## 为什么好玩

特殊糖果组合消除时的视觉效果非常壮观——屏幕上一大片糖果同时消除，分数飞速上涨，这种爽快感是游戏最大的吸引力。

## 粘性来源

- **关卡进度**：数千个关卡的线性推进，每过一关都想继续下一关
- **"差一点就过"心理**：经常在最后一两步差一点就能过关，促使玩家重试或购买道具
- **社交元素**：向好友请求生命值、在Facebook上分享进度
- **每日奖励**：每日登录奖励和旋转轮盘提供持续参与的动力

## Meta 系统

- **生命值系统**：每局消耗一条命，每30分钟恢复一条，最大5条。这限制了单次游戏时长但也创造了回归动力。
- **关卡解锁**：线性推进，每关通关解锁下一关
- **道具系统**：使用金币购买游戏内道具（额外步数、特殊糖果开局等）
- **赛季活动**：定期推出限定关卡和奖励

## 实现难度

低 + 三消算法成熟（如flood fill匹配检测），技术实现有大量现成方案。最大难点在于关卡设计和平衡，确保每关既有趣又可解。
