# Word Swipe 单词滑动（Word Swipe - Word Search Games）

- **类型**: 文字解谜 / 休闲 / 益智
- **平台**: Mobile (iOS+Android)
- **开发商**: Eternus Games
- **首次发布**: 2016
- **一句话描述**: 经典的字母连接单词搜索游戏，支持水平、垂直、对角线、正向和反向滑动

## 玩法规则

游戏呈现一个字母网格（通常4×4到7×7），玩家需要在网格中找到并连接字母组成单词。

**操作方式**：
- 手指从一个字母开始滑动
- 可以水平、垂直、对角线、正向或反向移动
- 连接到有效单词后松手，单词消除并获得分数
- 每关需要找到一定数量的单词才能过关

**难度递增**：
- 初级关卡：小网格（4×4），3-4字母单词
- 中级关卡：中等网格（5×5-6×6），4-6字母单词
- 高级关卡：大网格（7×7+），5-8字母单词

**辅助功能**：
- 提示系统：高亮一个未找到的单词
- 洗牌功能：重新排列字母网格（不改变可组成的单词集合）
- 主题关卡：特定主题的单词集合

## 核心循环

观察字母网格 → 滑动连接字母组成单词 → 单词消除获得分数 → 找到足够数量过关 → 进入下一关

## 核心机制

- **多方向滑动**：支持8个方向的滑动连接（水平4个+对角线4个），增加了搜索空间和策略复杂度。玩家需要系统性地扫描网格。
- **单词消除反馈**：每次成功找到单词都有视觉消除动画和音效，提供即时满足感。
- **字母重用**：同一字母可以参与多个不同单词的组成，增加了发现新单词的可能性。
- **渐进挑战**：从小网格到大网格，从短单词到长单词，难度曲线平滑。

## 为什么好玩

Word Swipe的快感来自于"模式识别"——当你的眼睛在混乱的字母中突然捕捉到一个隐藏的单词时，那种发现感是核心驱动力。多方向的搜索方式让每次扫描都有新的发现。

## 粘性来源

- **关卡进度**：数百关卡的线性推进。
- **每日挑战**：保持日常活跃度。
- **词汇量增长**：在玩乐中扩展词汇量，有附加价值。

## Meta 系统

- **关卡系统**：线性关卡推进。
- **提示货币**：通过游玩或内购获得提示。

## 实现难度

低 — 字母网格+字典匹配的核心逻辑成熟。最大难点在于确保每个网格布局都有合理的单词密度和可解性。
