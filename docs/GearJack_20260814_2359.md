# Gear Jack

- **类型**: 动作/平台跳跃
- **平台**: Mobile (iOS+Android)
- **开发商**: BoomBit, Inc.
- **首次发布**: 2021
- **一句话描述**: 一款卡通风格的动作平台跳跃游戏

## 玩法规则

玩家控制主角 Jack 在精心设计的关卡中前进。通过虚拟按键控制移动和跳跃，点击攻击按钮使用武器。关卡中包含平台、陷阱、敌人和收集品。

敌人有固定的行动模式，观察后可以找到安全的通过路线。Boss 关卡中，Boss 有独特的攻击模式，需要学习并找到应对方法。

画面采用 2D 卡通风格，角色设计可爱。界面左侧为方向控制，右侧为跳跃和攻击按钮。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

闯关收集金币 → 解锁新区域 → 面对更复杂的关卡设计

## 核心机制

- 平台跳跃机制：精确的跳跃手感是核心，包含二段跳、蹬墙跳等技巧
- 敌人行为模式：每种敌人有固定行动路线，考验观察力
- 收集品系统：关卡中隐藏收集品，增加探索乐趣

## 为什么好玩

经典平台跳跃玩法的现代演绎，关卡设计精巧，操作手感流畅。

## 粘性来源

收集全收集品的驱动力和解锁新区域的探索欲。

## Meta 系统

- 收集品系统：每个关卡有隐藏收集品
- 角色升级：收集金币提升生命值和攻击力

## 实现难度

中等 — 平台跳跃对关卡设计精度要求高，最大的技术难点是操作手感调优和关卡难度曲线。
