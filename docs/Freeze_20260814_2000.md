# Freeze!

- **类型**: 平台跳跃 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Global Action Software / Exient
- **首次发布**: 2010
- **一句话描述**: 通过控制重力来解谜的平台跳跃游戏

## 玩法规则

玩家操控一个小球在充满障碍的关卡中滚动前进。游戏的核心机制是重力翻转——点击屏幕可以让重力上下颠倒，小球从天花板掉落或从地面升起。

游戏界面以横版卷轴形式呈现。关卡中布满尖刺、移动平台和障碍物。玩家不能触碰尖刺和障碍物，否则角色会碎裂。

通过点击屏幕切换重力方向，小球会向相反方向掉落。玩家需要在合适的时机翻转重力来躲避障碍、跨越间隙和到达出口。

每关有多个检查点，失败后从最近的检查点重新开始。游戏目标是用最少的时间到达出口。

## 核心循环

滚动前进 → 翻转重力 → 躲避障碍 → 到达出口 → 挑战下一关

## 核心机制

- **重力翻转系统**：点击切换重力方向，改变小球运动轨迹，是游戏唯一的核心操作
- **平台解谜**：关卡设计利用重力机制创造各种谜题，需要时机把握和空间判断
- **检查点系统**：多检查点降低挫败感，让每次失败成本较低
- **计时挑战**：通关后显示用时，鼓励玩家优化路线和时间

## 为什么好玩

极简的操作（只需点击翻转重力）和精巧的关卡设计形成鲜明对比。重力翻转带来的空间感变化让简单的平台跳跃有了全新的解谜维度。

## 粘性来源

极简操作+高技巧上限 + "差一秒就过了"的不服输 + 关卡递进的新鲜感 + 计时优化的重复挑战

## Meta 系统

无

## 实现难度

低 — 2D物理平台游戏，最大技术难点在于关卡设计的趣味性和重力切换时物理模拟的流畅性
