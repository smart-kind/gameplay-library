# 美女餐厅：弗洛在路上（Diner Dash: Flo on the Go）

- **类型**: 时间管理
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: PlayFirst
- **首次发布**: 2010
- **一句话描述**: 经典美女餐厅系列的旅行版，玩家扮演弗洛在各种临时场地开设餐厅服务顾客。

## 玩法规则

游戏画面是俯视视角的餐厅平面图，包含厨房、餐桌、收银台等区域。顾客会从门口进入，头上显示他们的耐心值（心形气泡）和座位偏好。
玩家需要快速点击空桌安排顾客入座，然后点击餐桌为顾客点餐。菜单会自动发送到厨房，完成后菜品出现在厨房区域，需要再点击送回餐桌。
顾客用餐后会留下餐盘（需要清理）、支付餐费和小费。小费金额取决于顾客等待时间——等待越短，小费越高。
每关有明确的目标收入要求，达到目标金额即过关。如果太多顾客因等待时间过长而离开（耐心值归零），游戏失败。
旅行版本增加了多种临时场地场景（海滩、滑雪场、游轮等），每个场景有独特的装饰风格和顾客类型。某些场景还增加了特殊挑战。
顾客类型多样：普通顾客、带小孩的（需要额外关注）、VIP（给更多小费但耐心更低）、匆忙型（要求更快服务）等。

## 核心循环

迎接顾客安排座位 → 接受点餐送往厨房 → 取餐送回餐桌 → 收款清理餐盘 → 循环直到达成收入目标

## 核心机制

- 多任务管理：同时处理入座、点餐、上菜、收款、清理多个环节，需要合理排序和路径优化。高峰期可能同时有5-6个顾客需要服务
- 耐心倒计时系统：每个顾客的耐心值随等待时间递减，耐心耗尽会愤怒离开，制造持续的时间压力和优先级排序挑战
- 小费加成机制：服务速度直接决定小费多少，鼓励玩家在效率上不断精进。VIP顾客的小费倍数更高，优先服务VIP可以更快达成目标

## 为什么好玩

同时处理多项任务的紧张感和'一个都没让顾客失望'的完美成就感形成强烈对比。
当你在高峰期有条不紊地服务所有顾客时，那种流水线般的流畅体验非常上瘾。
每个新场景带来的视觉新鲜感和顾客类型变化，让重复的操作模式保持趣味。

## 粘性来源

关卡递进带来的难度爬坡（'下一关肯定更难但我想试试'）、追求满星评价的完美主义冲动、以及小费数字增长带来的即时正向反馈。

## Meta 系统

解锁新场景、新餐厅装饰、弗洛的新服装。每关星级评价系统驱动重复挑战。

## 实现难度

低 — 核心是任务队列管理和简单的状态机。主要技术难点在于多角色AI路径规划和触控操作的精准度优化，以及高峰期多任务状态的视觉呈现清晰度。


游戏还包含升级系统：使用收入升级厨房设备（加快出餐速度）、增加座位数、改善餐厅装饰（提高顾客初始耐心）。每个场景有多个难度等级，三星评价需要完美服务所有顾客。
