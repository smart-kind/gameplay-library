# MOUSE: P.I. For Hire

- **类型**: 解谜 / 叙事 / 冒险
- **平台**: PC (Steam)
- **开发商**: [独立开发]
- **首次发布**: 2024
- **一句话描述**: 你是一只老鼠侦探，在一个充满黑色电影风格的微缩世界中破解案件、收集线索并揭开真相

## 玩法规则

游戏采用经典的第一人称视角，玩家扮演一名老鼠私人侦探，在一个精心设计的微缩侦探世界中承接各种案件。画面风格借鉴了 1940 年代黑色电影（Film Noir）的美学——阴暗的办公室、百叶窗投下的光影条纹、打字机和老式电话构成了你的工作台。

玩家的核心操作围绕"调查-推理-解决"循环展开。在案发现场，玩家需要仔细观察环境，点击并调查各种线索物品（文件、信件、照片、物证等）。每个物品都可能包含隐藏的线索，需要放大、旋转或组合查看才能发现关键信息。

游戏的 UI 布局模拟了一个真实侦探的桌面：左边是笔记本（记录已发现的线索），中间是当前的调查物品，右边是案件档案。玩家通过拖拽和组合线索来推导出新的推理结论。例如，将一张照片与一份文件结合起来，可能揭示出某个角色的不在场证明是伪造的。

当收集到足够的线索后，玩家可以进入"推理阶段"，在笔记本中串联线索链条，最终指向嫌疑人和作案动机。正确的推理推进剧情，错误的推理会导致游戏给出提示并引导玩家重新检查遗漏的线索。

游戏内设有"侦探日志"系统，自动记录玩家已发现的所有线索和人物关系。当玩家卡关时，日志中的灰色条目提示尚未激活的线索组合，帮助玩家找到方向而不直接给出答案。

## 核心循环

调查现场找线索 → 组合线索推理 → 解开案件真相 → 承接下一个案件

## 核心机制

- **线索调查机制**：玩家可以自由检查场景中的每个物品，通过点击、旋转、缩放发现隐藏细节。某些线索需要组合其他物品才能完全解读（如用紫外光灯查看信件上的隐形墨水）。
- **线索板（Corkboard）机制**：类似真实侦探用图钉和红线连接线索，玩家将相关线索在"侦探板"上连线，形成推理链。当推理链完整时，自动触发剧情推进。
- **叙事驱动机制**：每个案件都是一个完整的迷你故事，包含角色介绍、冲突、转折和结局。案件之间存在暗线联系，最终串联成一个大叙事。
- **黑色电影氛围机制**：游戏通过视觉风格（低饱和度配色、光影对比）、旁白叙述和爵士配乐营造沉浸式黑色电影体验。
- **侦探日志辅助机制**：自动记录线索和人物关系，用颜色标记（白色=已确认，灰色=待验证）帮助玩家追踪推理进度。

## 为什么好玩

老鼠侦探的设定本身就充满趣味——在一个巨大的世界中，微小的线索被放大到主角尺度来审视。黑色电影的叙事风格配合解谜元素，给玩家带来类似《L.A. Noire》但更轻量、更风格化的体验。每次正确推理时的"顿悟感"是核心爽点。案件的节奏设计恰到好处，不会让玩家在单个谜题上卡太久，同时又能保持足够的挑战性。

## 粘性来源

具体到机制层面：案件本身的悬疑叙事驱动玩家想"知道真相"，而线索板连线的推理过程提供了类似填字游戏的智力满足感。每完成一个案件解锁新案卷的进度条，加上案件间隐藏的主线剧情线索，让玩家想继续追查更大的谜团。线索板连线时的视觉反馈（红线自动连接、图钉弹出的动画）和音效（纸张摩擦声、打字机的嗒嗒声）强化了侦探沉浸感。

## Meta 系统

无传统外围成长系统。游戏的核心 Meta 是"案件档案库"——每完成一个案件，该案件的完整档案（线索、推理过程、结局）被归档到玩家的侦探档案中，可以随时回顾。后续案件会引用之前案件的人物或事件，形成跨案件的叙事网络。这种设计让游戏的"进度"不是数值成长，而是叙事深度的积累。

## 实现难度

中。最大的技术难点在于线索与线索之间的关联逻辑设计——需要确保每条推理链既合理又有唯一解，同时避免玩家因为找不到某个关键线索而卡关。此外，黑色电影风格的视觉呈现（光影效果、材质渲染）也需要一定的美术功底。3D 场景的交互检测（哪些物品可点击、哪些需要特定条件触发）也需要精细的场景标记和状态管理。
