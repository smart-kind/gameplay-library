# Winter Rush（Winter Rush）

- **类型**: 跑酷 / 滑雪 / 反应类
- **平台**: Web（浏览器）
- **开发商**: 浏览器游戏开发者
- **首次发布**: 2010s
- **一句话描述**: 滑雪跑酷游戏，玩家控制滑雪者从雪山坡道上冲下，躲避树木和障碍物，尽可能滑得更远

## 玩法规则

画面是俯视或斜视角的雪山坡道，玩家控制一名滑雪者向下滑行。操作方式：方向键或 A/D 键控制左右移动。

坡道上散布着各种障碍物——树木、岩石、雪人、栅栏等。碰到障碍物游戏结束。坡道上还有收集品（金币、星星）提供额外分数。

随着滑行距离增加，速度会逐渐加快，障碍物密度也会增加。玩家需要快速反应，在障碍物之间穿梭。部分版本中有特技元素——从跳台起跳可以做出空中旋转获得额外分数。

## 核心循环

向下滑行 → 左右躲避障碍 → 收集物品 → 速度加快 → 持续滑行直到碰撞

## 核心机制

- **自动加速**：滑雪者会持续加速（模拟重力加速度），速度越快反应时间越短，难度自然递增。
- **障碍躲避**：障碍物随机分布在滑行路径上，玩家需要快速判断并改变方向。部分障碍物可以通过特技动作跳过。
- **收集系统**：金币和星星散布在滑行路径上，收集后增加分数。收集品通常位于较危险的位置（靠近障碍物或坡道边缘），鼓励冒险。

## 为什么好玩

Winter Rush 把滑雪的刺激感浓缩到了简单的左右移动操作中——不需要复杂的控制，只需要快速反应。速度越来越快的紧张感让每次游戏都充满挑战。

## 粘性来源

- **高分挑战**：和自己的最高分竞争
- **速度感**：加速带来的速度感让人兴奋
- **短时反馈**：一局几十秒，随时可以再来一局

## Meta 系统

无。纯核心玩法。

## 实现难度

- **学习曲线**：新手可以立即上手，但精通需要数十小时的练习。每次游玩都能发现新的技巧或策略。
- **重玩价值**：高。每局游戏都有不同的体验，无论是随机的地图/敌人，还是玩家的策略选择。
- **社区生态**：作为经典浏览器游戏，它在玩家社区中有良好的口碑。
- **技术亮点**：在浏览器环境中实现流畅的交互体验，充分利用了现代 Web 技术的能力。
低 + 2D 卷轴、碰撞检测、随机障碍生成。最大技术难点是障碍生成的难度曲线——要确保难度平滑上升而不是突然变得不可能。
