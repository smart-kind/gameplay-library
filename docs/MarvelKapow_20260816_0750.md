# Marvel Kapow!（Marvel Kapow!）

- **类型**: 动作 / RPG / 卡牌收集
- **平台**: Mobile (iOS + Android)
- **开发商**: Disney / Kabam
- **首次发布**: 2013
- **一句话描述**: 结合卡牌收集与回合制战斗的漫威主题动作RPG

## 玩法规则

玩家组建一支由漫威超级英雄组成的队伍，在回合制战斗中与敌人对抗。游戏画面采用精美的漫画风格，角色以卡牌形式呈现。

战斗采用回合制系统——玩家在自己的回合选择英雄发动攻击、使用特殊技能或防御。每个英雄有独特的攻击模式和能力，合理搭配队伍是胜利关键。

卡牌收集是游戏的重要组成部分。玩家通过游戏进程或内购获得新的英雄卡牌，每个卡牌有不同的稀有度和属性。升级卡牌可以提升英雄的战斗力。

关卡以关卡地图形式呈现，每个关卡有不同的敌人和挑战。完成关卡获得奖励，用于获取新卡牌和升级现有卡牌。

## 核心循环

战斗获得奖励 → 收集/升级英雄卡牌 → 组建更强队伍 → 挑战更难关卡

## 核心机制

- **卡牌收集与养成**：收集不同稀有度的漫威英雄卡牌，通过升级提升属性
- **回合制战术战斗**：在回合中选择英雄攻击、防御或使用技能，队伍搭配影响战斗策略
- **漫威IP深度**：大量漫威角色和故事线，让粉丝有强烈的代入感和收集欲望

## 为什么好玩

漫威IP的吸引力+卡牌收集的成瘾性+回合制战斗的策略性，三者的结合让玩家既有情感连接又有游戏深度。

## 粘性来源

卡牌收集的"收集欲"是核心粘性——玩家想要集齐所有漫威英雄。英雄升级的数值成长也提供了持续的目标感。

## Meta 系统

英雄卡牌收集与养成系统 — 玩家收集漫威英雄卡牌，通过升级、突破等方式提升卡牌属性和技能，直接影响战斗能力

## 实现难度

中 — 回合制战斗系统+卡牌数据管理是核心，最大技术难点是卡牌平衡和大量角色数据的维护
