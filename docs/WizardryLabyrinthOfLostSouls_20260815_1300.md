# Wizardry: Labyrinth of Lost Souls

- **类型**: 地牢探索 RPG
- **平台**: Mobile (iOS) / PS3 / PS Vita / PC
- **开发商**: Acquire
- **首次发布**: 2009
- **一句话描述**: 经典第一人称地牢探索RPG，组建冒险者小队在随机生成的迷宫中战斗和寻宝

## 玩法规则

Wizardry: Labyrinth of Lost Souls是第一人称视角的地牢探索RPG。玩家组建一支最多6人的冒险者队伍，进入随机生成的迷宫进行探索。

游戏采用回合制战斗：在迷宫中行走时可能遭遇敌人，进入战斗后玩家为每个队伍成员选择行动（攻击、施法、使用物品、防御、逃跑）。每个角色有职业（战士、法师、牧师、盗贼等）和属性（力量、智力、敏捷、体质等）。

迷宫探索是第一人称网格化移动——每次移动一个格子，可以转身90度或向前走。迷宫中散布着宝箱、陷阱、传送门和通往下一层的楼梯。玩家需要管理队伍的资源：生命值（HP）、魔法值（MP）、食物补给等。

角色死亡是永久性的——如果一个角色在地牢中阵亡，就永久失去了。这使得每次决策都非常关键。

## 核心循环

组建队伍 → 探索迷宫 → 回合制战斗 → 获取经验和装备 → 返回城镇休整 → 进入更深层

## 核心机制

- **回合制队伍战斗**: 每回合为6名队员分别选择行动，需要考虑职业搭配和资源管理
- **永久死亡**: 角色在迷宫中死亡后无法复活，极大提高了决策的严肃性
- **随机迷宫生成**: 每层迷宫结构、敌人分布和宝物位置都是随机生成的
- **职业系统**: 战士、法师、牧师、盗贼等经典职业各有专长

## 为什么好玩

Wizardry的魅力在于它纯粹的地牢探索体验——没有花哨的剧情和过场动画，只有你和你的队伍面对未知的迷宫。每次打开一扇未知的门、踩到一个未知的陷阱时的紧张感是其他RPG难以复制的。

## 粘性来源

粘性来自Roguelike式的随机性和永久死亡带来的紧张感。每次失败后重新组队进入迷宫都是一种“再来一次”的冲动。

## Meta 系统

城镇系统：在迷宫之间的安全区域可以招募新冒险者、购买装备、存储物品、转职升级。装备收集系统。

## 实现难度

高 — 最大的技术难点在于随机迷宫生成的可玩性保证和回合制战斗的AI设计。
