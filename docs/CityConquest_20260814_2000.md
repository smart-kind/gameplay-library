# City Conquest (城市征服)

- **类型**: 策略 / 塔防
- **平台**: Nintendo 3DS
- **开发商**: Nintendo / Intelligent Systems
- **首次发布**: 2013
- **一句话描述**: 基于网格地图的回合制领土占领策略游戏

## 玩法规则

游戏在一个网格化的城市地图上进行。玩家和AI对手各自拥有起始据点，轮流派遣单位占领相邻地块。

游戏界面显示当前回合、可用资源和地图上的领土分布。每个地块有不同的产出（金钱、人口等）。玩家通过触屏选择己方单位并指定移动方向。

单位移动规则简单：从己方领土出发，占领相邻的无主或敌方地块。占领过程中可能与敌方单位交战。每个单位的战斗力决定了占领效率。

游戏目标是占领地图上超过一半的地块或消灭所有敌方单位。特殊建筑（如工厂、军营）提供额外资源和单位增强。

## 核心循环

选择单位 → 移动占领 → 获取资源 → 生产新单位 → 扩大领土

## 核心机制

- **领土扩张系统**：从己方据点向外推进，占领的地块越多，资源产出越高
- **回合制决策**：每回合有限的行动次数，需要策略性地选择最优移动
- **单位类型差异**：不同单位有各自擅长和克制的关系，影响战术选择
- **资源经济**：占领地块产生收入，用于生产更多单位，形成正反馈循环

## 为什么好玩

规则简单但策略深度丰富。每次扩张都面临"先占哪个地块"的战术选择，加上对手的反制，让每局都有独特的棋局体验。

## 粘性来源

每局地图不同的重玩价值 + "差一点就赢了"的不甘心 + 简单规则下的策略深度 + 快速对局带来的高频次游玩

## Meta 系统

地图解锁系统 — 完成初始地图后解锁更多不同布局的关卡

## 实现难度

低 — 回合制网格策略游戏，最大技术难点在于AI对手的决策智能和不同地图的平衡性设计
