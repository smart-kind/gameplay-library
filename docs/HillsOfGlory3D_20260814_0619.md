# Hills of Glory 3D

- **类型**: 塔防 / 3D
- **平台**: Mobile (iOS+Android)
- **开发商**: Fun Games For Free / Ilyon
- **首次发布**: 2012
- **一句话描述**: 一款3D视角的塔防游戏，玩家在山丘地形上布置防御塔，阻止敌人沿路径进攻

## 玩法规则

游戏呈现一个3D山丘场景，敌人沿固定路径从屏幕一侧向另一侧移动。路径蜿蜒穿过地形，有多个转弯和分支。

玩家可以在路径两侧的空白区域放置防御塔。防御塔有多种类型：射手塔（快速单目标射击）、炮塔（范围伤害，对群体有效）、冰冻塔（减速敌人，为其他塔争取时间）、导弹塔（高伤害慢射速，对BOSS有效）。

放置和升级防御塔消耗金币。消灭敌人获得金币。每波敌人数量和强度递增，从几个普通步兵到成群的坦克和飞行单位。

部分关卡有地形变化——某些区域可放置塔，某些不可（山坡、河流）。BOSS关卡出现血量极高的首领敌人，需要集中火力攻击或使用特殊塔组合。

游戏设有无尽模式，敌人波次无限递增，考验玩家防御布局的极限。无尽模式有独立排行榜。

## 核心循环

分析敌人行进路线 → 布置和升级防御塔 → 击退所有波次

## 核心机制

- **塔类型搭配**：不同塔有不同功能，需要组合应对不同敌人
- **波次递增**：敌人数量和强度逐步增加，考验防御布局
- **BOSS战**：首领敌人需要特殊策略应对

- **无尽模式**：无限递增波次挑战防御极限


## 为什么好玩

3D视角让塔防布局更有空间感。不同类型塔的组合搭配提供策略深度。

## 粘性来源

塔防进度系统：完成一关解锁下一关。塔升级系统：提升塔的属性解锁新能力。

## Meta 系统

塔升级系统：提升防御塔的攻击力、射速、范围。关卡解锁：完成所有关卡后解锁更高难度。

## 实现难度

低 — 塔防玩法成熟易懂。最大技术难点是3D场景渲染和大量子弹追踪。
