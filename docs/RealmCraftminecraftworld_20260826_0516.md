# RealmCraft: mine & craft world

- **类型**: 沙盒建造 / 生存冒险
- **平台**: Mobile (iOS)
- **开发商**: Tellurion mobile, Limited Liability Company
- **首次发布**: 2016
- **一句话描述**: RealmCraft是一款免费方块建造和生存游戏。玩家可以在开放世界中采集方块、制作物品、建造建筑，体验类似Minecraft的创造乐趣。

## 玩法规则

游戏采用3D方块风格的世界，所有物体都由立方体构成。玩家以第一人称或第三人称视角在方块世界中行动。生存模式下，玩家需要采集木材、石材等资源，制作工具和武器，建造庇护所，与怪物战斗，需要管理饥饿值和生命值。创造模式下，玩家拥有无限资源，可以自由建造任何想要的建筑，不受生存限制。游戏包含100多种方块类型，可用于建造和制作各种物品。可以驯服狼、豹猫和马等动物，种植植物建立农场。多人模式支持与朋友一起建造、聊天、分享技巧。还包含4个小游戏供休闲娱乐。

## 核心循环

采集方块 -> 制作工具和物品 -> 建造建筑 -> 探索新生物群落 -> 驯服动物 -> 重复

## 核心机制

- 方块采集与放置：破坏和放置方块是核心交互方式
- 100多种方块类型：提供丰富的建造和制作可能性
- 双模式系统：生存模式有挑战性，创造模式自由无限制
- 多人联机：与朋友一起建造和冒险
- 驯兽系统：驯服狼、豹猫、马等动物作为伙伴

## 为什么好玩

沙盒建造游戏的魅力在于你可以做任何事的自由度。RealmCraft在移动端提供了接近Minecraft的体验，100多种方块、多种生物群落、多人联机让创造空间无限。

## 粘性来源

无限建造自由让创造力成为最大驱动力；多人合作建造提供社交乐趣；新生物群落探索保持新鲜感

## Meta 系统

有驯兽系统（狼、豹猫、马）、多人联机社区、小游戏系统（4个小游戏）。支持创造模式和生存模式切换。

## 实现难度

中。核心难点在于沙盒建造玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
