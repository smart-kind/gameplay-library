# 围攻（Besiege）

- **类型**: 物理建造 / 解谜
- **平台**: PC / Mobile (iOS+Android)
- **开发商**: Spiderling Studios
- **首次发布**: 2020
- **一句话描述**: 中世纪风格的物理攻城机器建造游戏，用模块搭建战争机械完成关卡目标。

## 玩法规则

每个关卡给出一个目标（如'摧毁城堡'、'消灭所有士兵'、'跨越峡谷'），玩家需要用提供的模块搭建一台机器来完成任务。

建造界面是3D视角，玩家从工具栏中拖拽模块到工作台上：木质框架、车轮、螺旋桨、火炮、弩炮、锯片、炸弹、活塞、铰链等。

模块之间通过连接点组合，形成一个完整的机械结构。玩家可以调整模块的位置、角度和触发条件（如按下空格键开火、按下W键前进）。

搭建完成后点击'启动'，物理引擎会模拟机器的运作。如果机器结构不稳，可能会在启动时散架；如果设计合理，机器会执行预定动作。

没有预算限制或材料限制，玩家可以用任意数量的模块。关卡只关心结果——目标是否被摧毁。

## 核心循环

理解关卡目标 → 选择模块搭建机器 → 启动测试 → 失败则调整设计 → 成功后进入下一关

## 核心机制

- 开放式建造系统：没有固定的建造路径，玩家可以用完全不同的方案解决同一关卡——可以用轰炸机飞过去炸，也可以造陆地战车冲过去，甚至可以造投石机远程打击
- 真实物理模拟：每个模块都有质量、摩擦力和连接强度，机器必须符合物理原理才能运作，倒塌、翻滚、爆炸都是自然结果
- 触发器逻辑系统：可以设置条件触发（如'当检测到敌人时发射火炮'），实现简单的自动化机械

## 为什么好玩

创造的自由度极高——'我能想到就能造出来'的感觉。看到自己设计的机器成功运作时，成就感爆棚。失败也很有趣——机器散架、飞上天、原地爆炸都是欢乐时刻。

## 粘性来源

开放式的'沙盒'特性让人上瘾——解决一个关卡后可以不断优化和尝试更好的方案；玩家社区分享的设计提供灵感；'差一点就成功'的物理调试过程本身就很吸引人。

## Meta 系统

关卡递进系统：解锁新关卡获得新模块。沙盒模式：无目标自由建造。社区工坊：分享和下载其他玩家的设计。

## 实现难度

中 — 物理引擎集成（如Unity PhysX）是核心，模块系统和触发器逻辑需要精心设计。最大难点是物理模拟的稳定性——复杂结构的碰撞检测和性能优化。
