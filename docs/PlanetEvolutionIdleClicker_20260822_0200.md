# 行星进化 - 放置点击（Planet Evolution: Idle Clicker）

- **类型**: 放置/模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2022
- **一句话描述**: 行星进化的放置点击游戏

## 玩法规则

玩家从一个原始星球开始，通过点击产生生命并推动进化。生命自动繁衍生息，玩家点击加速进化过程。解锁新的生命形态，从单细胞到复杂生物。随着进化推进，行星环境发生变化。最终可解锁太空探索阶段。游戏以生命进化为核心体验。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

点击加速进化 → 解锁新生命形态 → 环境变化 → 继续进化

## 核心机制

- **生命进化**:  从简单到复杂的渐进进化
- **环境互动**:  生命影响行星环境
- **阶段解锁**:  解锁新的进化阶段

## 为什么好玩

见证生命从无到有的过程，进化的不可预测性

## 粘性来源

新生命形态解锁的期待；行星环境变化的视觉反馈

## Meta 系统

生命形态进化和行星环境升级

## 实现难度

中 - 需要多阶段进化和视觉效果 - 进化过程的视觉效果和阶段衔接
