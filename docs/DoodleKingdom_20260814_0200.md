# Doodle Kingdom（涂鸦王国）

- **类型**: 元素合成解谜 / 益智
- **平台**: Mobile (iOS + Android)
- **开发商**: JoyBits Co Ltd.
- **首次发布**: 2014
- **评分**: 4.28/5 (iOS 用户评分)
- **一句话描述**: 通过组合不同元素创造中世纪王国的一切——从城堡、骑士到龙，是Doodle God系列的奇幻续作

## 玩法规则

游戏画面呈现为一个工作台界面，玩家可以看到自己已经发现的各种元素图标散布在屏幕下方。初始时玩家只有少数几个基础元素。玩家通过拖拽两个元素到中间的合成区域来尝试组合它们。

如果两个元素可以合成新元素，它们会融合并产生一个全新的元素图标，同时显示该元素的名称和简短描述。如果两个元素无法组合，它们会弹回原位并显示合成失败的提示。

游戏的目标是发现并合成所有可能的元素，构建完整的奇幻王国元素树。元素按照类型分类：建筑（城堡、塔楼等）、生物（骑士、巫师、龙等）、自然元素（火、水、土等）和物品（武器、工具等）。

游戏中包含四个不同类型的龙可以培育和养育，玩家可以选择不同的发展路线——既可以恢复家族城堡的繁荣（光明路线），也可以作为死灵法师腐化大地（黑暗路线）。

此外还有一个特殊的"骑士战斗"模式——武装你的骑士，在跑酷式的战斗中穿越怪物群，挑战强大的Boss。这是Doodle系列中首次加入的动作元素。

## 核心循环

拖拽两个元素合成新元素 → 发现新元素解锁更多合成可能 → 发现全部元素完成王国构建

## 核心机制

- **元素合成系统**：核心玩法。玩家需要逻辑推理和试错来发现元素之间的合成关系。每次成功合成都有"恍然大悟"的满足感
- **元素分类树**：所有元素按主题分类，帮助玩家追踪进度和组织思路
- **双路线选择**：光明（建设王国）vs 黑暗（死灵法师），给玩家不同的目标感
- **骑士跑酷战斗**：额外的动作小游戏，在解谜疲劳时提供玩法变化
- **龙培育系统**：四种不同类型的龙可以培育和养育，增加收集深度

## 为什么好玩

Doodle Kingdom的乐趣在于"发现"的快感——每次成功合成都像解开一个小谜题。从中世纪元素（骑士、城堡、龙）出发，玩家需要创造性地思考"骑士+火=？"、"城堡+龙=？"这样的组合。148Apps评价它"令人上瘾，疯狂地上瘾"，GameZebo称其概念"独特且 deeply satisfying"。

## 粘性来源

(1) **发现的惊喜感**——每次合成都可能产生一个从未见过的新元素，这种不确定性驱动"再试一次"；(2) **进度可视化**——元素列表逐步填充的收集满足感；(3) **逻辑推理的乐趣**——不是纯随机，而是可以通过逻辑推理预测合成结果；(4) **系列惯性**——Doodle God/Doodle Devil的粉丝自然延续到本作

## Meta 系统

- **元素收集进度**：追踪已发现/总元素数量，提供明确的目标完成度
- **骑士战斗模式解锁**：随着元素合成推进解锁额外游戏内容

## 实现难度

**低** — 核心是元素对(pair)的组合查找表。技术实现简单，难点在于内容设计——设计合理的元素树，让每个合成既不太明显也不太隐晦，保持玩家的推理乐趣
