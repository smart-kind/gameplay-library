# 文明：革命（Civilization Revolution）

- **类型**: 4X/策略/回合制
- **平台**: Mobile (iOS/Android) / Nintendo DS / PS3 / Xbox 360
- **开发商**: Firaxis Games / 2K Games
- **首次发布**: 2008
- **一句话描述**: 《文明》系列的移动端精简版，玩家从远古时代发展到现代，通过科技、文化、军事或外交方式赢得胜利。

## 玩法规则

画面为策略地图视角，显示玩家的领土、城市、单位和资源。游戏从远古时代（公元前4000年）开始，每个回合玩家可以执行多个行动：移动单位、建造城市设施、研究科技、外交谈判等。

玩家从建立一个开拓者单位开始，找到合适的位置建立第一座城市。城市自动产生人口和资源，人口可以分配到不同的工作中（生产、科技、文化、金钱）。玩家需要决定优先发展什么：是造兵扩张领土？还是研究科技提升生产力？或是投资文化争取文化胜利？

胜利方式有四种：
1. **统治胜利**：消灭所有其他文明的首都
2. **科技胜利**：第一个发射飞船到半人马座阿尔法星
3. **文化胜利**：建造并填满大奇观，获得最多文化点数
4. **经济胜利**：购买并控制所有世界奇观

操作：点击地图选择城市或单位，点击行动按钮执行操作。移动端优化为触屏操作，回合制节奏适合移动设备。

## 核心循环

探索地图 → 建立城市 → 分配资源 → 研究科技/造兵/发展文化 → 争取胜利条件

## 核心机制

- **科技树**：线性的科技 progression，每个科技解锁新的单位、建筑或能力。科技选择决定了文明的发展方向——是走军事路线还是文化路线。
- **资源分配**：每回合产生的资源需要在生产、科技、文化、金币之间分配。这是核心的策略决策——什么都想要但资源有限。
- **四种胜利路径**：不像传统《文明》只有单一胜利目标，革命版提供四条不同路线，每局可以换不同的策略。
- **AI对手**：电脑控制的AI文明会扩张、研究、攻击，增加竞争压力。

## 为什么好玩

将《文明》"再来一回合"的经典循环浓缩到移动端。每次"再研究一个科技就睡觉"、"再打一场仗就退出"的自我欺骗，是这个游戏最上瘾的地方。四种胜利路径让每局都有不同体验。

## 粘性来源

- **"再来一回合"循环**：回合制策略的经典粘性来源——"完成这个回合就睡"的循环永无止境
- **多胜利路径**：统治/科技/文化/经济四条路线，每局可以尝试不同策略
- **AI对抗**：电脑对手的行为不可完全预测，增加变数和挑战性
- **文明多样性**：不同文明有不同的加成，鼓励多周目

## Meta 系统

- **文明解锁**：通过达成特定条件解锁新文明
- **成就系统**：完成特定目标解锁成就
- **对核心玩法的影响**：无实质影响，主要是解锁和成就展示

## 实现难度

高 — 回合制策略游戏的AI（多文明决策系统）、科技树、资源分配、地图生成都是复杂系统。最大技术难点在于AI设计——需要让多个AI文明在多条胜利路径上做出有竞争力的决策，同时保持性能（移动端资源有限）。
