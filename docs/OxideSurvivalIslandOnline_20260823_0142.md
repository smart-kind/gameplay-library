# 氧化物：多人荒岛求生（Oxide: Survival Island Online）

- **类型**: 多人在线生存 / 沙盒建造
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 2021
- **一句话描述**: 残酷荒岛上的多人联机生存模拟器——采集、制作、建造，在与其他玩家的互动或竞争中存活下来

## 玩法规则

玩家被投放到一座开放的荒岛环境中，初始只有一把石斧。屏幕布局为第三人称视角，可以自由移动和环顾四周。环境中分布着树木、岩石、动物、水源等自然要素。

玩家需要采集基础资源（木头、石头、纤维、食物），然后通过制作台合成工具和武器——石斧升级石镐，石镐升级铁镐，以此递进。建造系统允许玩家搭建住所、围墙、储物箱等设施来保护自己。

游戏的目标是在恶劣环境中存活尽可能久。危险来自多个方面：饥饿、口渴、天气变化、野生动物，以及最不可控的因素——其他玩家。多人模式下，玩家可以选择合作建立部落，也可以抢劫其他玩家的资源。

## 核心循环

探索环境采集资源 → 制作工具提升采集效率 → 建造庇护所抵御危险 → 探索更远区域 → 与其他玩家互动（合作或竞争）

## 核心机制

- **开放世界采集**：全岛自由探索，资源分布随区域不同而差异明显
- **动态制作系统**：工具分级明确，每个阶段的制作物都显著提升生存能力
- **多人互动机制**：可以选择合作或对抗，社交选择决定了游戏的走向
- **日夜循环**：夜晚更加危险，需要照明和安全的住所
- **永久死亡/损失**：部分版本中死亡会导致资源损失，增加了紧张感

## 为什么好玩

生存本能的紧张感与其他玩家的不可预测性结合，让每一局游戏都充满戏剧性。合作建立营地的成就感与被突袭的惊险感交替出现，体验非常丰富。

## 粘性来源

**社交竞争**：与其他玩家的互动（无论是合作还是对抗）创造了独特的故事和体验。**建造成就感**：从小茅屋到坚固堡垒的视觉变化带来强烈满足。**"再来一局"**心理：每次死亡或失去一切后都想重新挑战。

## Meta 系统

外围成长系统：
- **皮肤/外观系统**：解锁不同的角色外观和建筑皮肤
- **部落系统**：组建部落、管理成员、部落间的竞争
- 对核心玩法的影响：部落提供了更大的合作框架，改变了生存策略

## 实现难度

高。多人在线同步是最大技术难点——需要同步所有玩家的位置、物品、建筑状态，处理网络延迟和断线重连。地图资源和事件的服务器端管理也很复杂。
