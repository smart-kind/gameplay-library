# 毁灭人类：克里普多闯拉斯维加斯（Destroy All Humans! Crypto Does Vegas）

- **类型**: 动作射击 / 科幻喜剧
- **平台**: Mobile (N-Gage)
- **开发商**: THQ / Digital Eclipse
- **首次发布**: 2008
- **一句话描述**: 扮演外星杀手克里普多，在拉斯维加斯大开杀戒收集DNA的科幻动作游戏。

## 玩法规则

游戏采用3D俯视角画面，玩家操控外星杀手克里普多在拉斯维加斯街道上移动和攻击。UI布局简洁——左上角显示生命值，右上角显示DNA收集进度条，底部有武器切换按钮。

玩家使用虚拟摇杆控制角色移动方向，点击屏幕发射武器攻击人类。长按可以蓄力释放特殊技能。武器系统包含多种外星科技：主武器持续射击，副武器有特殊效果如冰冻、爆炸等。被击中的人类会逃跑或反击，需要灵活走位躲避。

游戏目标是在限定时间内收集足够的DNA配额。关卡失败条件是DNA收集不足或生命值归零。随着进程推进，敌人数量和种类增加，场景中出现更多障碍物。

## 核心循环

击杀人类 → 收集DNA → 解锁新武器和区域

## 核心机制

- **开放探索**：拉斯维加斯街道可以自由行，寻找人类目标
- **武器切换**：多种外星武器各有特色，针对不同类型的敌人
- **DNA收集**：击杀人类后自动收集DNA，达到配额才能通关
- **喜剧叙事**：穿插搞笑过场动画，增强娱乐性

## 为什么好玩

科幻题材+拉斯维加斯背景的搭配本身就有趣，夸张的暴力喜剧风格带来独特的娱乐体验。操作简单直观，适合碎片时间游玩。

## 粘性来源

DNA配额机制驱动玩家不断尝试——每次都想收集更多。武器系统的多样性让人想尝试不同组合。过场动画的喜剧内容也吸引玩家继续推进剧情。

## Meta 系统

无。线性推进的动作游戏，没有外围成长系统。

## 实现难度

中。需要3D场景渲染和AI路径寻找系统。最大技术难点在于多人NPC的AI行为和同屏渲染性能优化。
