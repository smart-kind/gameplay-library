# Idle Game 1

- **类型**: 放置 / 策略
- **平台**: Mobile (iOS)
- **开发商**: Cem Kamiloglu
- **首次发布**: 2020
- **评分**: ⭐ 4.7/5 (8,309 评价)
- **价格**: Free
- **一句话描述**: 专为有经验的放置游戏玩家设计，特别强调随机升级系统。每轮给予随机声望加成。

## 玩法规则

游戏采用极简的UI设计（主要是数字和按钮）。通过点击或放置产生资源。与其他放置游戏不同，本游戏强调随机性——每轮prestige（声望重置）时获得随机加成，增加重玩价值。玩家需要在随机加成和策略选择之间做决策。界面极简：数字计数器、升级按钮、prestige菜单。

## 核心循环

产生资源 → 购买升级 → 获得声望 → 重置获得随机加成 → 新一轮

## 核心机制

- 随机声望：每轮prestige获得随机加成，增加重玩价值
- 策略决策：在随机加成之间做最优选择
- 极简设计：专注于数字和决策，减少视觉干扰

## 为什么好玩

随机性让每轮prestige都有新鲜感。为有经验的放置玩家设计，策略深度更高。

## 粘性来源

随机性的重玩价值、策略决策深度、数值增长

## Meta 系统

完整的放置经济+随机声望系统。核心玩法即meta。

## 实现难度

低——极简UI+数值系统，实现简单
