# 超级弓箭（Hyper Arrow）

- **类型**: 超休闲/射击
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2026
- **一句话描述**: 弓箭射击闯关游戏

## 玩法规则

玩家拉弓射箭，目标是射中关卡中的各种目标。通过拖拽调整射箭角度和力度，松手后箭矢射出。目标包括气球、水果、靶心等。箭矢受重力影响呈抛物线飞行。部分关卡有障碍物需要绕过。通关条件通常是射中指定数量的目标或在限定箭数内完成。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

瞄准拉弓 → 射箭飞行 → 命中目标 → 下一关

## 核心机制

- **抛物线射击**:  箭矢受重力影响的抛物线轨迹
- **目标多样**:  不同形状和位置的目标增加变化
- **箭数限制**:  有限箭数增加策略性

## 为什么好玩

精准的抛物线射击带来成就感，命中目标的即时反馈令人满足

## 粘性来源

关卡难度递增；追求完美通关的欲望

## Meta 系统

关卡解锁和弓箭皮肤

## 实现难度

低 - 核心是抛物线物理计算 - 精确的抛物线轨迹计算和碰撞检测
