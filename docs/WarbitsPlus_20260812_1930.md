# Warbits+（战争比特+）

- **类型**: 回合制策略 / 战术
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: Risky Lab
- **首次发布**: 2016（原版）/ 2024（Warbits+）
- **一句话描述**: 向 Advance Wars 致敬的回合制策略游戏，在六角网格地图上指挥各兵种进行战术对决

## 玩法规则

游戏画面为俯视的六角网格（Hex Grid）战场地图。地图上分布着各种地形：平原、山地、森林、河流、道路、城市等。每种地形对单位的移动力和防御力有不同影响——山地增加防御但降低移动，道路提升移动速度，城市可以提供补给和收入。

玩家在每个回合中可以操作所有己方单位：选择单位并移动它（移动范围用蓝色高亮显示），然后选择攻击目标（攻击范围用红色高亮显示）。每个单位有生命值（HP）、攻击力、防御力和移动距离等属性。不同类型的单位有相克关系：步兵克制反坦克兵，坦克克制步兵，炮兵在远距离攻击。

战斗开始前，玩家需要部署初始单位到指定的部署区域。回合开始时，占领的城市会产生金币，用于购买新单位。每个单位的购买成本和战斗力成正比——坦克贵但强，步兵便宜但脆弱。

游戏的目标因模式而异：战役模式中击败所有敌方单位或占领敌方总部；某些特殊关卡需要在规定时间内完成特定目标。

## 核心循环

部署单位 → 回合制战斗 → 占领城市获取收入 → 购买新单位 → 扩大优势

## 核心机制

- **六角网格战术地图**：使用六角网格而非传统方格，每个格子有6个相邻方向，移动和包围的几何关系更加丰富。地形系统增加了策略深度——利用森林隐藏部队、利用道路快速机动、利用山地建立防线。
- **兵种相克系统**：不同兵种之间存在明确的相克关系。步兵→反坦克兵→坦克→步兵的经典循环。加上炮兵（远程攻击）、空军（无视地形）、海军（水域专属），形成了丰富的兵种组合策略。
- **天气与地形影响**：不同天气条件下单位的视野和移动能力会变化。例如雨天降低能见度，雪地影响移动速度。
- **指挥官系统**：不同的指挥官有独特的被动技能（如增加某类单位的攻击力、降低某类单位的成本）。选择合适的指挥官可以改变整体战术风格。
- **补给线机制**：远离城市或补给线的单位无法获得生命恢复，需要在推进前线时保持补给线的连续性。

## 为什么好玩

Warbits+ 是 Advance Wars 精神续作中最完整的移动端实现。每回合的决策都有深度——不是简单的"打就完了"，而是需要预判对手的行动、计算伤害、规划走位。六角网格带来的策略复杂度让每场战斗都像在下棋，但节奏更快、反馈更直接。

## 粘性来源

"再来一个回合"的回合制策略成瘾性。每场战斗的变量很多（兵种组合、地形利用、天气变化），重玩价值高。战役模式的剧情推进和新指挥官的解锁提供了长线目标。多人对战模式让高手有持续竞技的动力。

## Meta 系统

- **指挥官解锁**：完成战役关卡解锁新指挥官，每个有独特的战术加成。
- **战役模式**：完整的剧情战役，讲述一场因模拟 glitch 而失控的虚拟战争。
- **自定义地图**：部分版本支持玩家自制地图和场景。

## 实现难度

中等。回合制策略的核心逻辑（移动范围计算、攻击范围判定、伤害公式）是成熟的算法。最大的技术难点在于 AI 设计——让电脑对手表现得"聪明"而非"作弊"（即不依赖信息优势，而是靠真正的战术思考）。六角网格的碰撞检测和路径计算也比方格略复杂。
