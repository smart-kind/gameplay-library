# Idle Wizard: Magic Realm

- **类型**: 放置 / RPG
- **平台**: Mobile
- **开发商**: Various
- **首次发布**: 2025
- **一句话描述**: 魔法主题的放置 RPG——学习法术、升级能力、探索魔法领域。

## 玩法规则

玩家扮演一位巫师，通过学习法术、升级魔法能力和探索魔法领域来推进游戏。放置机制允许离线施法和收集资源。

法术系统提供深度——不同法术有不同效果和升级路径。魔法领域探索提供额外挑战和奖励。

## 核心循环

学习法术 → 升级能力 → 探索领域 → 收集资源

## 核心机制

- 法术系统：多种法术和升级路径
- 魔法领域探索：额外挑战
- 离线施法：持续获得资源
- 能力升级：提升魔法力量
- 领域解锁：逐步探索新世界

## 为什么好玩

魔法主题让放置游戏有了独特的氛围。法术组合和能力升级的策略深度保持长期参与感。

## 粘性来源

- 法术多样性：不同法术组合创造多样玩法
- 领域探索：新区域的新挑战
- 能力成长：从学徒到大师的成长
- 魔法氛围：独特的主题体验

## Meta 系统

法术解锁和能力升级。学习新法术、提升魔法力量、解锁新领域。

## 实现难度

低。放置 RPG 核心系统简单，法术平衡是难点。
