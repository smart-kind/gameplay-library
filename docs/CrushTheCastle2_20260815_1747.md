# 城堡粉碎2（Crush The Castle 2）

- **类型**: 物理弹射 / 策略
- **平台**: Web (Flash/HTML5)
- **开发商**: Armor Games (Joey Betz)
- **首次发布**: 2010
- **一句话描述**: 操控攻城器械投射巨石，摧毁敌方城堡并消灭所有敌人的物理弹射游戏

## 玩法规则

玩家面对一座由木块、石块、金属块搭建的城堡，城堡内有各种敌人（骑士、法师等）。
玩家使用弹射器（类似投石机），通过鼠标拖拽调整投射角度和力度，松开后发射巨石。
石头遵循真实物理抛物线飞行，击中城堡后会破坏方块结构。
城堡崩塌时，掉落的石块和碎片可以砸死内部的敌人。
每关有固定的弹药数量限制，需要在弹药耗尽前消灭所有敌人。
部分关卡提供特殊弹药（爆炸弹、冰冻弹等），每种弹药有不同的破坏效果。
过关条件是消灭关卡内所有敌人，有些关卡还有额外挑战（如限定弹药数内完成）。

## 核心循环

瞄准发射 → 破坏城堡结构 → 消灭敌人 → 解锁新关卡/新弹药

## 核心机制

- 物理弹射系统：鼠标拖拽控制角度和力度，石头飞行轨迹遵循重力物理，每次发射结果难以完全预测
- 结构破坏引擎：城堡由可独立破坏的方块组成，破坏关键支撑点会导致连锁崩塌，产生爽快的多米诺效应
- 弹药多样化：普通弹、爆炸弹、冰冻弹、炸弹等不同弹种针对不同结构类型，增加策略深度

## 为什么好玩

看着精心搭建的城堡在一击之下轰然倒塌的满足感无可替代。物理引擎带来的不可预测性让每次发射都有惊喜——有时一发入魂团灭全关，有时差之毫厘需要调整策略。

## 粘性来源

"差一点就全灭"的不甘心感驱动反复尝试。每关三星评价体系（弹药数、时间、特殊成就）鼓励玩家追求完美通关。新弹药解锁提供了阶段性成长目标。

## Meta 系统

关卡解锁系统：完成当前章节解锁下一章。弹药类型随进度解锁（爆炸弹、冰冻弹等），增加战术多样性。

## 实现难度

中 — 物理弹射引擎和结构破坏逻辑是技术难点，需要良好的碰撞检测和物理模拟


城堡中的敌人包括持盾骑士（需要多次击中）、弓箭手（远程反击）、法师（释放火球）。
特殊弹药需要在新关卡开始时选择，不能中途切换。
某些关卡有保护目标（如被困平民），需要小心避免误伤。
游戏包含超过100个关卡，分布在多个章节中。
