# 宝石探秘纸牌（Jewel Quest Solitaire）

- **类型**: 纸牌/解谜
- **平台**: PC / Mobile (iOS+Android) / Web / Nintendo DS
- **开发商**: iWin
- **首次发布**: 2004
- **一句话描述**: 将经典接龙纸牌玩法与宝石消除结合，在解谜过程中完成纸牌匹配和宝石收集

## 玩法规则

游戏界面分为两个区域：上方是宝石消除棋盘，下方是接龙纸牌区域。玩家需要交替操作两个区域来推进游戏进程。

纸牌区域遵循经典接龙规则。屏幕底部有7列纸牌，每列最上面一张面朝上。玩家可以将牌按花色降序排列（红牌只能放在黑牌上，反之亦然），将K放到空列中，将A到K按同花色顺序放到右上角的回收区。每次成功放置一组纸牌，玩家获得宝石奖励——宝石的颜色和数量与消除的纸牌组相关。

宝石区域是一个棋盘，上面布满不同颜色的宝石。玩家可以交换相邻宝石，使三个或更多同色宝石连成一条直线（横或竖）即可消除。消除后上方的宝石会下落填补空位，新的宝石从顶部掉落。棋盘通常有预设的图案目标或需要清除的障碍物（如覆盖在宝石上的冰块或锁链）。

两个区域的关联是：纸牌区域提供宝石资源，宝石区域推进解谜进度。当纸牌区域无法继续出牌时，可以使用有限的提示次数或重置功能（每局有限次数）。部分关卡还有时间限制，增加了挑战性。

## 核心循环

打接龙纸牌 → 获得宝石奖励 → 交换消除宝石 → 推进解谜目标 → 解锁新章节

## 核心机制

- **双区域交替玩法**：纸牌区和宝石区相互依存但操作独立，纸牌提供资源，宝石推进进度。这种设计让玩家在两个系统之间切换，避免单一玩法的疲劳感
- **资源管理系统**：提示次数、重置次数、特殊道具都是有限资源。玩家需要判断何时使用提示、何时冒险尝试、何时保存资源应对后续难关
- **障碍消除机制**：棋盘上的冰块需要相邻消除才能打破，锁链需要两次消除才能清除，特殊障碍物有独特的消除方式，增加解谜深度和策略性
- **连锁宝石消除**：消除宝石后上方宝石下落可能自动形成新的匹配，产生连锁反应。连锁消除获得更多分数和额外宝石奖励

## 为什么好玩

两种经典玩法的巧妙融合创造了独特的游戏体验。纸牌的策略性和消除的爽快感交替出现，节奏感极佳。每次打出好牌获得宝石时的正反馈很强，宝石消除的视觉效果也令人满足。双系统的设计避免了单一玩法的单调感。

## 粘性来源

纸牌策略的智力挑战提供持续思考空间、宝石消除的即时爽感提供情绪释放、关卡目标的明确性提供短期动力、双系统交替带来的节奏变化防止疲劳感、收集宝石和解锁新章节的长期目标驱动持续游玩

## Meta 系统

章节推进系统——完成一定数量关卡解锁新章节，每个章节有独特的主题和障碍类型；装饰系统允许玩家使用收集的宝石解锁新的棋盘主题和纸牌背面图案；每日挑战模式提供额外的可玩内容

## 实现难度

低 — 两种玩法各自成熟且被广泛理解，上手门槛低。最大的技术难点在于双系统的平衡设计——确保纸牌产出宝石的速率与宝石消除消耗相匹配，以及难度曲线的平滑过渡
