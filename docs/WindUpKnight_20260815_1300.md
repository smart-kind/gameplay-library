# Wind-up Knight

- **类型**: 横版跑酷 / 自动跑步
- **平台**: Mobile (iOS + Android)
- **开发商**: Robot Invader
- **首次发布**: 2011
- **一句话描述**: 自动奔跑的横版跑酷游戏，玩家控制一个上发条的骑士在城堡中躲避危险并收集物品

## 玩法规则

在Wind-up Knight中，骑士自动向右奔跑，玩家无法控制其移动方向，只能通过触摸操作来改变其动作。游戏采用横向滚动的视角，骑士在城堡的走廊和房间中不断前进。

玩家可用的操作：向上滑动使骑士跳跃（可二段跳），向下滑动使骑士滑行（蹲下躲避上方障碍），点击攻击键使用武器攻击敌人。玩家需要在恰当的时机做出正确的操作——跳跃躲避地刺和深渊，滑行躲避悬挂的障碍物，攻击阻挡道路的敌人。

游戏的核心资源是“发条”——骑士需要不断收集齿轮来给发条上劲，如果发条走完骑士就会停下来，游戏结束。同时还有金币可以收集，用于解锁新装备和道具。

游戏结束条件：发条耗尽骑士停下、掉入深渊、被敌人或陷阱击中致死。

## 核心循环

自动奔跑 → 躲避障碍/收集齿轮 → 存活更久 → 获得金币解锁装备

## 核心机制

- **自动奔跑**: 骑士持续向右移动，玩家专注于时机判断而非方向控制
- **发条机制**: 需要持续收集齿轮维持运动，创造紧迫感——不收集就会死
- **滑行躲避**: 向下滑动触发滑行动作，可以躲过上方障碍同时穿过狭小空间
- **装备系统**: 用收集的金币购买头盔、武器等装备，不同装备影响生存能力

## 为什么好玩

Wind-up Knight的乐趣在于“在刀尖上跳舞”的紧张感——你必须不断前进的同时做出精确的反应。发条机制是天才设计：它迫使你在安全路线和危险路线之间做抉择，每次贪婪地冲向一个远处的齿轮然后差点死掉都令人兴奋。

## 粘性来源

粘性来源于发条机制创造的持续紧张感，以及“差一点就拿到更多金币”的懊恼。装备解锁系统提供了长期目标——收集足够金币购买更好的头盔或武器。

## Meta 系统

装备系统：金币用于购买头盔（增加生命值）、武器（增加攻击力）和盾牌（格挡伤害）。装备有等级之分，高等级装备提供更好的防护。

## 实现难度

低 — 最大的技术难点在于流畅的跑酷动画过渡（跳跃/滑行/攻击之间的无缝切换）和程序化关卡生成的合理性。
