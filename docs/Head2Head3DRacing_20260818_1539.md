# Head2Head 3D赛车（Head2Head 3D Racing）

- **类型**: 赛车
- **平台**: Mobile (iOS) / Palm OS / Symbian
- **开发商**: Unknown (cross-platform port)
- **首次发布**: 2008
- **一句话描述**: 一款早期iPhone上的3D赛车游戏，因质量低劣而被评价为App Store最差游戏之一

## 玩法规则

玩家驾驶赛车在3D赛道上竞速。游戏提供快速比赛和生涯模式两种。

操作方式：通过倾斜设备控制转向和加速。生涯模式中有3辆车和4个级别。

游戏目标：在赛道上超越对手车辆完成比赛。完成比赛获得奖金用于购买新车或升级。

游戏结束条件：比赛中无法获胜（对手永远比你快至少10秒每圈），无法赚取足够资金升级车辆，在生涯模式中输掉比赛则失去车辆，无法继续。

## 核心循环

倾斜控制赛车 -> 尝试在赛道上竞速 -> 无法获胜 -> 无法获得升级资金

## 核心机制

- 倾斜控制：通过倾斜iPhone控制赛车转向，手感可管理但需要适应
- 不可战胜的AI：对手车辆始终比玩家快10秒每圈，形成无法逾越的差距
- 简陋的3D画面：赛道模型粗糙，建筑突然出现（pop-in），贴图简陋，碰撞箱延伸至赛道上

## 为什么好玩

这款游戏几乎没有可玩性——它被评价为App Store上最差的游戏之一。如果硬要说有什么趣味，那就是作为反面教材观察早期App Store质量把控缺失的案例。

## 粘性来源

无粘性来源。游戏设计本身存在致命缺陷（无法获胜的AI）导致玩家没有继续游玩的动力。

## Meta 系统

生涯模式有3辆车4个级别，但无法推进因为无法赢得比赛获得资金。

## 实现难度

低 — 技术实现简陋，画面和控制都很原始。最大问题是缺乏基本的游戏设计——对手速度设置不合理导致游戏无法进行。
