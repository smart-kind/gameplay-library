# 爆裂弹球（Blast Ball (Ball Blast Cannon Blitz)）

- **类型**: 弹幕射击 / 生存
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2018
- **一句话描述**: 一款弹幕射击生存游戏，控制大炮在无尽敌人波次中生存，通过升级武器和能力构建独特Build。

## 玩法规则

游戏画面为竖屏，大炮位于屏幕底部中央，敌人从屏幕上方不断涌来。玩家滑动屏幕控制大炮的瞄准方向，点击自动发射子弹。

敌人有各种类型：普通球体（需要特定次数射击才能消灭）、快速移动球、大球（血量高）等。消灭敌人后掉落经验值，升级时可以选择新的武器、能力、无人机或被动加成。

每次升级从3到4个选项中选择一项：新武器（改变弹道和伤害类型）、无人机（自动攻击敌人）、被动加成（射速提升、伤害增加、弹道数量翻倍等）。

游戏结束条件为大炮生命值归零。尽可能存活更长时间并获得高分。

## 核心循环

玩什么 → 得到什么 → 用来做什么：射击敌人获得经验升级，选择能力和武器构建更强Build来应对更多敌人

## 核心机制

- **Build构建系统**：每次升级选择不同能力组合，武器、无人机、被动加成可以自由搭配。弹道数量翻倍加热量提升的组合可以产生毁天灭地的效果。每次游戏的Build都不同
- **弹幕生存**：敌人数量随时间递增，从几十到几百甚至上千。需要不断移动和瞄准来最大化输出，后期场面极其壮观
- **物品收集**：游戏中有数十种独特物品（武器、无人机、被动技能），每次游戏可以尝试不同组合。不同物品的协同效果是核心乐趣

## 为什么好玩

Build成型后的视觉冲击力极强——满屏子弹飞舞、无人机四处攻击的壮观场面。从零开始到毁天灭地的成长弧线令人上瘾。每次升级都有明确的正反馈。

## 粘性来源

Build组合的多样性（每次尝试新搭配）+ 成长爽感（从弱小到无敌）+ 高分挑战（看看能撑多久）。一局接一局停不下来。

## Meta 系统

- **永久升级**：通过游戏内货币解锁新的武器、无人机和被动技能，在每局游戏中可选择。解锁内容越多Build可能性越大
- **每日挑战**：特殊条件的每日挑战模式提供额外奖励，鼓励每天上线
- **对核心玩法影响**：解锁更多物品增加了Build组合的多样性，但不改变核心操作。新手和老手都能享受游戏

## 实现难度

低 — 滑动瞄准加自动射击操作简单，策略体现在Build选择而非操作。最大技术难点在于大量敌人和子弹同时存在时的性能优化。需要确保在低端设备上也能流畅运行满屏弹幕。
