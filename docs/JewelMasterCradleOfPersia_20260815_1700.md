# Jewel Master: Cradle of Persia

- **类型**: 三消 / 解谜
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Sandlot Games
- **首次发布**: 2010
- **一句话描述**: 一款以古波斯为背景的三消益智游戏，玩家通过消除宝石来重建波斯古城的标志性建筑，结合了三消玩法和城市建设元素。

## 玩法规则

游戏画面呈现一个三消棋盘，棋盘上布满各种颜色的宝石。玩家通过交换相邻的两个宝石来制造三连或更多连线，被消除的宝石从棋盘上移除。

与经典三消游戏不同，本作中每次消除宝石都会获得资源（如金币、建材）。这些资源用于重建波斯古城的各种建筑，包括花园、宫殿、神庙和雕像。

棋盘上的宝石有多种类型：普通宝石（红蓝绿黄）、特殊宝石（消除整行或整列）、炸弹宝石（消除周围区域）、彩虹宝石（可以匹配任何颜色）。

游戏的关卡目标多样化：在限定步数内达到目标分数、清除特定数量的某种宝石、在棋盘上制造特定数量的特殊宝石等。

随着关卡推进，棋盘上会出现各种障碍：锁住的宝石（需要先消除相邻宝石解锁）、冰块覆盖的宝石（需要多次消除才能清除）、移动的宝石等。

通关每个关卡后，获得资源用于建造和装饰波斯古城。建成的建筑为古城增添视觉内容，并提供一定的加成效果。

## 核心循环

消除宝石 → 获得资源和分数 → 完成关卡目标 → 收集建造资源 → 重建波斯建筑 → 解锁新关卡

## 核心机制

- 三消+建造双循环：消除宝石获得资源，资源用于建造城市。消除是即时反馈（得分），建造是长期反馈（城市逐渐繁荣），两种反馈相互补充。
- 特殊宝石连锁：制造特殊宝石（炸弹、彩虹球等）并触发它们产生连锁反应，是游戏的核心策略。玩家需要在'快速消除'和'规划大招'之间做选择。
- 障碍系统：锁、冰、移动障碍等增加了关卡的难度维度，玩家需要找到消除障碍的方法来继续游戏。

## 为什么好玩

古波斯文明的视觉风格非常精美——宝石消除的华丽特效与波斯建筑的异域风情相得益彰。'看着一座废墟慢慢变成华丽的城市'的成就感很强。

## 粘性来源

建造驱动是核心粘性——'再过一个关卡就能建那座神庙了'的目标感让玩家持续游玩。三消本身的即时反馈加上建造的长期目标，形成了强大的复合驱动。

## Meta 系统

波斯古城建设系统是主要外围成长。通关获得的资源用于建造和装饰城市，城市等级也影响部分游戏加成。

## 实现难度

低。最大技术难点在于关卡难度曲线的精细调校——确保每关都有'可解性'同时保持挑战性，需要大量的关测试和数据调整。
