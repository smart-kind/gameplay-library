# 合成离开（Merge Away）

- **类型**: 合成消除 / 数字递增
- **平台**: Mobile (iOS+Android)
- **开发商**: Payge Ltd
- **首次发布**: 2024
- **一句话描述**: 点击棋盘生成物品，拖拽相同物品合成更高级别，在有限空间内追求最高数值

## 玩法规则

游戏在一个有限的网格棋盘上进行。玩家通过点击生成器或从底部弹出的物品来获得低级物品（通常是数字1或基础形状）。

操作方式是将两个相同数字/等级的物品拖拽到一起。合成规则：两个等级 N 的物品合并为一个等级 N+1 的物品。例如两个1合成2，两个2合成3，依次递增。

棋盘空间有限，新物品不断产生。如果棋盘被填满且没有可合成的相同物品对，游戏结束。

目标是合成出尽可能高的数字。每次合成获得的分数与产物等级成正比，高级合成（如从10到11）产生大量分数。

部分版本中，合成特定等级会解锁新物品外观或特殊效果。某些高级物品具有范围消除能力，可以帮助清理低等级物品腾出空间。

## 核心循环

生成物品 → 合成升级 → 腾出空间 → 追求更高数字

## 核心机制

- **数字递增合成**: 两个相同数字合成为下一个更高数字，数值从1开始递增。这种简单规则降低了理解门槛，同时"追求更大数字"的目标清晰且成瘾
- **空间管理博弈**: 有限棋盘迫使玩家在"立即合成腾空间"和"保留物品等更好组合"之间做出选择，每个操作都是空间博弈
- **随机生成机制**: 新物品的出现位置或类型有一定随机性，增加了不确定性和重玩价值

## 为什么好玩

看到数字从1一直增长到几十甚至上百的成就感非常直接。每次"两个变大"的满足感简单而有效。棋盘紧张时突然找到一个完美合成机会的惊喜感也很强。

## 粘性来源

数字递进的天然成瘾性——永远想合成更大的数字；"差一个就升级"的心理驱动；每局时间短，"再来一局可以合成更高"的冲动强烈；部分版本有排行榜竞争。

## Meta 系统

无复杂外围系统。主要是分数驱动的重复游玩。部分版本有每日挑战和成就系统。

## 实现难度

低。合成逻辑和棋盘管理都是成熟模式。最大技术难点是物品拖拽动画流畅度和合成效果的视觉反馈。
