# 耶兔2（Yeah Bunny 2）

- **类型**: 单指平台跳跃
- **平台**: Mobile (iOS+Android)
- **开发商**: Adrian Zarzycki
- **首次发布**: 2019
- **一句话描述**: 一款复古像素风格的单指点击跳跃平台游戏，用极简操作体验丰富的关卡冒险

## 玩法规则

游戏采用精致可爱的复古像素画风，色彩温暖柔和。每个关卡都是一个独立的场景，包含多个平台、弹簧、门、收集品和各种机关元素。

操作极其简单：整个游戏只需要一根手指。点击屏幕控制兔子跳跃，点击的时机决定跳跃的落点。长按屏幕可以让兔子跳得更高，连续点击可以在空中进行二段跳。

关卡中的机关设计丰富多样：弹簧可以将兔子弹向高处但需要精确的落点；门可以连接不同区域；移动平台需要预判位置。

有些关卡还包含危险区域——尖刺、岩浆、深渊等，触碰即失败。收集品散布在关卡中难以到达的位置。

每个世界包含约10个关卡，难度逐渐递增，从简单的跳跃练习到需要精确时机和多段操作的复杂路线。

## 核心循环

观察关卡布局 → 精确控制跳跃节奏 → 到达终点 → 解锁新关卡和世界

## 核心机制

- 单指跳跃控制：只需点击屏幕即可控制跳跃，长按决定跳跃高度，极简操作降低了入门门槛但精通需要精确时机把握
- 二段跳机制：空中再次点击可实现二次跳跃，增加了操作深度和路线多样性。有些收集品只有通过二段跳才能到达
- 环境互动系统：弹簧、门、移动平台、旋转平台等元素丰富关卡变化。每种机关都有独特行为模式

## 为什么好玩

复古像素画面搭配可爱兔子角色营造温馨治愈的氛围，让人忍不住想要帮助小兔子完成冒险。

精确的跳跃时机掌握带来强烈的成就感，每个关卡都像一个小谜题。

游戏还有一个有趣的爱情故事穿插在关卡之间，通过复古风格的过场动画讲述，为单纯的跳跃冒险增添了叙事趣味。

## 粘性来源

关卡的精妙设计让人产生差一点就过了的不甘心心理——你明知道路线是对的只是时机差了一点点，这种不甘心驱动你一次次重新尝试

## Meta 系统

世界解锁系统：完成关卡解锁新世界，每个世界有独特视觉主题（森林、沙漠、冰雪、火山等）和新的关卡机制

## 实现难度

中等 — 操作极其简单但关卡需要精确时机和路线规划。最大的技术难点在于物理引擎的手感调校和输入响应延迟控制
