# 化解危机：精英（Time Crisis Elite）

- **类型**: 轨道射击
- **平台**: Mobile (iOS+Android) / Arcade
- **开发商**: Namco
- **首次发布**: 2010
- **一句话描述**: 经典街机轨道射击游戏的移动移植版，玩家沿着预设路线前进射击消灭敌人。

## 玩法规则

游戏采用第一人称视角，玩家的移动路径是预设的（轨道射击/Rail Shooter），不需要控制移动方向，只需要控制瞄准和射击。
屏幕上会出现各种敌人（士兵、车辆、直升机等），玩家用手指或光枪瞄准并点击射击消灭他们。命中敌人得分，爆头获得额外加分。
躲避系统：当敌人反击时，屏幕上会出现红色的'Danger'提示，玩家需要点击掩蔽按钮或移动到掩蔽物后面。掩蔽时无法射击但不会受到伤害。
某些场景有保护目标（平民或队友），如果保护目标被敌人击中会扣分或任务失败。
每个关卡有Boss战，Boss有特定的攻击模式和弱点。需要利用掩蔽躲避Boss的攻击，然后在Boss露出弱点时集中火力射击。
弹药有限，屏幕上的弹药数归零时需要 reload（重新装弹）。装弹期间无法射击。

## 核心循环

沿预设路线前进 → 瞄准射击消灭敌人 → 闪避反击 → 装弹补充 → 面对Boss → 通关进入下一关

## 核心机制

- 掩蔽-射击节奏：掩蔽躲避和射击进攻交替进行，形成紧张的动作节奏，掩蔽时间过长会影响通关评价
- 精准射击奖励：爆头和射击特定弱点获得额外分数，鼓励精准瞄准而非乱射
- Boss战模式：每个Boss有独特的攻击模式和弱点暴露时机，需要观察-躲避-反击的循环

## 为什么好玩

掩蔽-射击的节奏就像一场动作电影，玩家从旁观者变成了参与者。
Boss战中'抓住弱点一顿猛射'的爽快感，以及完美闪避所有攻击的成就感都很强。

## 粘性来源

通关评级的追求（S/A/B/C）、隐藏要素的发现（击破特定目标解锁内容）、以及'我要无伤通关'的自我挑战。

## Meta 系统

解锁新武器、新关卡、评分排行榜。

## 实现难度

中 — 需要实现3D场景渲染、预设路径动画、敌人AI和弹幕系统。主要技术难点在于掩蔽判定和射击精度在移动端的实现。


游戏还包含评级系统：每关结束后根据命中率、闪避次数和保护目标存活情况给出评级（S/A/B/C/D）。高评级解锁隐藏武器和额外关卡。游戏的'foot pedal'经典机制在移动版中简化为点击按钮。
