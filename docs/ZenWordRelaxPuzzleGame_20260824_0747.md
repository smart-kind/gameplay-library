# 禅词（Zen Word®）

- **类型**: 文字解谜 / 单词连接 / 休闲脑力
- **平台**: Mobile (iOS + Android)
- **开发商**: Oakever Games
- **首次发布**: 2019
- **一句话描述**: 在禅意氛围中通过连接字母来拼写单词的放松型文字游戏。

## 玩法规则

游戏画面呈现一组排列成圆环或不规则形状的字母节点。玩家通过手指从一个字母滑动到相邻字母，连接形成单词。每次滑动路径覆盖的字母组合成一个候选单词——如果该单词在词库中存在，它被标记为"已找到"并从字母板中消除或高亮。

每关给出固定数量的字母（通常 5-8 个），需要找出所有可能的有效单词。字母节点之间的连线在滑动时可视化显示，玩家可以在任意字母开始、任意字母结束，路径长度至少为 2 个字母。

游戏的目标是找出关卡中隐藏的所有单词。完成后进入下一关，字母组合和排列方式会变化。游戏过程中背景播放舒缓的轻音乐或自然音效。

## 核心循环

观察字母组合 → 滑动连接形成单词 → 消除已找到的单词 → 找齐所有单词进入下一关

## 核心机制

- **单词发现机制**：给定字母组合中可能隐藏多个单词，玩家需要在有限的字母中排列组合找出所有可能。短单词容易发现，长单词需要更深入的思考。
- **滑动输入**：手指在字母间滑动创建路径，支持斜向和环形连接，操作直观且适合触屏。
- **提示系统**：当玩家卡住时，可以使用提示来揭示一个未发现的单词。部分字母可能作为"万能字母"出现在多个单词中。

## 为什么好玩

文字游戏天然适合碎片时间——一局可能只需要 1-2 分钟。禅意的美术和音效设计让脑力锻炼变成一种放松体验而非压力。每找到一个隐藏单词的"啊哈！"瞬间是核心快感。

## 粘性来源

词汇量的自我挑战——玩家不断发现"原来这个字母组合还能拼出这个词"；连续完成关卡的进度感；每日新关卡提供持续内容；"差一个单词就找齐了"的强迫心理驱动完成欲。

## Meta 系统

轻度收集系统：每关完成的星星评价（基于发现单词的百分比/速度），可解锁新的视觉主题（背景色、字体样式）。对核心玩法无影响。

## 实现难度

低。核心是字母图遍历+词典匹配。最大技术难点在于高效词典查询——需要在前端存储大量有效单词并快速判断玩家滑动路径形成的字符串是否为有效单词。
