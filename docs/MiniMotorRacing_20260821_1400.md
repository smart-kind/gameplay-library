# Mini Motor Racing

- **类型**: 休闲竞速
- **平台**: Mobile (iOS+Android)
- **开发商**: The Binary Mill
- **首次发布**: 2011
- **一句话描述**: 一款俯视角微型赛车竞速游戏，掌握漂移过弯技巧是关键

## 玩法规则

游戏采用竖屏俯视角画面，赛道呈环形或曲折路线。玩家通过点击屏幕左右侧控制赛车转向，长按可加速。

赛车有惯性漂移效果，入弯时需要提前转向并控制速度。漂移过弯时赛车会损失速度但能更好地通过急弯。掌握漂移时机是取得好成绩的关键。

赛道上散布着加速带和减速陷阱，玩家需要记忆赛道布局并规划最佳路线。加速带可以大幅提升速度，但利用加速带的同时也要控制好入弯角度。

每场比赛通常1-2分钟完成。比赛后根据名次获得金币奖励，用于解锁新车和新赛道。

## 核心循环

点击转向加速 → 漂移过弯冲线 → 获得金币 → 解锁新车新赛道

## 核心机制

- **漂移物理系统**: 赛车有惯性漂移效果，掌握入弯时机和漂移角度是过关关键。漂移时赛车会损失速度但能更好地通过急弯，需要在速度和过弯精度之间找到平衡。
  （赛车手感）
- **赛道道具系统**: 赛道上分布加速带和减速陷阱，玩家需要记忆赛道布局并规划最佳路线。合理利用加速带可以大幅缩短比赛时间。
  （路线优化）
- **车辆多样性**: 通过比赛获得金币可以购买新车，不同车辆有不同的速度、操控和漂移特性。选择合适的车辆应对不同赛道。
  （数值成长）

## 为什么好玩

赛车虽小但物理手感出色，漂移过弯的操控感非常爽快。赛道设计紧凑，每局1-2分钟非常适合碎片时间。获得App Store Best of - Casual Games奖项说明品质出色。

## 粘性来源

漂移过弯的技术成长感、赛道记忆带来的路线优化快感、收集不同车辆的成就感。'差一点就赢'的竞技不甘心也很强。

## Meta 系统

金币系统用于解锁新车和赛道。车辆有不同的速度和操控属性，玩家通过不断比赛积累金币，逐步解锁全部内容。

## 实现难度

中 — 需要实现流畅的2D俯视角赛车物理和漂移手感调校。赛道编辑和碰撞检测也有一定复杂度。
