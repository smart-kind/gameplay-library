# 割绳子（Cut the Rope）

- **类型**: 物理解谜 / 休闲
- **平台**: Mobile (iOS+Android) / PC / 主机
- **开发商**: ZeptoLab
- **首次发布**: 2010
- **一句话描述**: 通过切割绳子让糖果沿正确路径落入小怪物Om Nom的嘴里，收集星星并获得高分。

## 玩法规则

游戏画面中，一只可爱的小怪物Om Nom仰望着悬挂在绳子上的糖果。糖果通过一根或多根绳子固定在场景中，玩家需要用手指滑动切割绳子，让糖果在重力和物理作用下沿着特定路径移动，最终落入Om Nom的嘴中。

除了切割绳子，玩家还可以利用场景中的各种道具：气泡可以让糖果漂浮上升；风扇可以吹动糖果改变方向；弹簧可以将糖果弹射到空中；管道可以引导糖果移动。这些道具需要玩家在正确的时间点激活。

每关有三颗星星可以收集，星星分布在不同的位置，糖果必须经过星星所在位置才能收集到。这意味着玩家不仅要让糖果到达Om Nom，还要设计经过星星的路径。

游戏按章节推进，每章有15-25个关卡，难度逐步递增。解锁新章节获得新的游戏机制和道具。

## 核心循环

观察场景 → 规划切割顺序 → 执行切割 → 收集星星 → 糖果落入Om Nom嘴中 → 解锁新关卡

## 核心机制

- **物理模拟**：糖果的摆动、碰撞、滚动都遵循真实物理规律。切割绳子后，糖果会像钟摆一样摆动，玩家需要预判摆动轨迹来规划切割时机。
- **切割时机**：同样的切割顺序在不同时机执行会产生完全不同的结果。玩家需要掌握"什么时候切"的时机感，这是游戏的核心技巧。
- **多绳系统**：高级关卡中糖果可能被多根绳子同时悬挂，需要按特定顺序切割才能让糖果走向正确路径。这增加了策略深度。
- **道具互动**：气泡、风扇、弹簧等道具增加了游戏的变数和可玩性。玩家需要考虑道具的激活时机和位置关系。

## 为什么好玩

简单的操作（只需滑动切割绳子）配合精心设计的物理谜题，创造出"易于上手、难于精通"的完美体验。看着糖果沿着你设计的完美路径落入Om Nom嘴里，那种成就感无与伦比。

## 粘性来源

- **三星收集**：每关三颗星星的位置设计精巧，让玩家反复尝试不同的切割方案
- **物理谜题**：找到最优解的过程像解谜一样令人上瘾
- **Om Nom的魅力**：小怪物可爱的形象和吃糖果后的满足表情是持续的动力
- **关卡设计**：每章引入新机制，保持新鲜感

## Meta 系统

- **章节解锁**：收集足够星星解锁新章节
- **Om Nom装扮**：通过关卡获得奖励为Om Nom解锁新外观
- **每日任务**：完成每日挑战获得额外奖励

## 实现难度

中 + 需要物理引擎支持绳子的悬挂、摆动、切割和碰撞检测。最大难点在于绳子切割后的物理模拟准确性和流畅度，以及关卡设计的平衡性。
