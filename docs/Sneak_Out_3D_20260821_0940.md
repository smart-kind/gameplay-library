# Sneak Out 3D

- **类型**: 潜行 / 益智
- **平台**: Mobile (iOS)
- **开发商**: MondayOFF
- **首次发布**: 2021
- **评分**: ⭐ 4.6/5 (5,685 评价)
- **价格**: Free
- **一句话描述**: 一款简单但比想象中难的3D潜行游戏，玩家需要悄悄溜出去而不被发现。

## 玩法规则

游戏以3D俯视角呈现。玩家控制一个角色在关卡中移动，目标是到达出口而不被守卫/摄像头发现。点击屏幕让角色移动，长按可以加快速度但噪音更大。关卡中有各种障碍物：巡逻的守卫（有固定路线）、摄像头（有扫描范围）、可以藏身的柜子/箱子。角色移动时会发出声音，声音范围以圆圈显示。如果角色进入守卫/摄像头的探测范围就会被发现，关卡失败。界面简洁：3D场景、小地图（可选）、提示图标。

## 核心循环

观察关卡布局 → 规划路线 → 潜行通过 → 到达出口 → 解锁下一关

## 核心机制

- 噪音系统：移动速度影响噪音大小，快速移动更容易被发现
- 守卫AI：守卫有固定巡逻路线和视野范围，需要观察规律
- 藏身机制：可以躲在柜子/箱子中避开搜索

## 为什么好玩

规则极简但关卡设计精巧，"比想象中难"的设计让每次失败都想再来一次。3D视角增加沉浸感。

## 粘性来源

"差一点就成功"的不甘心、观察规律的成就感、关卡渐进难度

## Meta 系统

角色皮肤解锁。不影响核心玩法。

## 实现难度

低——单指控制+简单AI，实现容易，难点在于关卡设计
