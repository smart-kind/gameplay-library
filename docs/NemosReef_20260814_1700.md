# 尼莫的珊瑚礁（Nemo's Reef）

- **类型**: 模拟经营 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Disney / Gameloft
- **首次发布**: 2012
- **一句话描述**: 基于皮克斯《海底总动员》IP的珊瑚礁建造模拟游戏，玩家种植珊瑚、收集鱼类、装饰海底世界

## 玩法规则

游戏画面呈现一片海底场景，玩家拥有一片初始的珊瑚礁区域。通过点击屏幕放置珊瑚、海草、贝壳等装饰物，逐步扩展和美化自己的海底世界。每种装饰物需要消耗游戏内货币（贝壳或珍珠）。

核心操作是点击和拖拽：选择装饰物类别后点击海底空地放置。不同的珊瑚和装饰物会吸引不同的鱼类——例如橙色小丑鱼会被特定颜色的珊瑚吸引。鱼类自动在珊瑚礁中游动，增加场景的生动感。

游戏的目标是创建一个美丽且充满活力的珊瑚礁生态系统，吸引尽可能多的稀有鱼类。鱼类有等级系统——当特定鱼类达到一定数量后，它们会"升级"，变成更稀有的变体。游戏包含任务系统，完成特定目标（如"种植10棵海草"或"收集5种小丑鱼"）可获得奖励货币。

## 核心循环

种植珊瑚装饰 → 吸引鱼类 → 鱼类升级获得稀有品种 → 解锁新装饰物 → 扩展珊瑚礁

## 核心机制

- **吸引力系统**：不同装饰物吸引不同鱼类。珊瑚的颜色和类型决定了哪些鱼类会被吸引到玩家的珊瑚礁中。这种对应关系鼓励玩家策略性地选择装饰物。
- **鱼类进化机制**：当一种鱼类的数量达到阈值时，它们有概率进化为更稀有的变体（颜色变化或特殊外观）。这为重复种植同一类珊瑚提供了动力。
- **货币系统**：游戏使用贝壳作为基础货币，珍珠作为高级货币。种植装饰物、加速成长、购买特殊物品都需要消耗货币。
- **任务引导系统**：持续出现的任务为玩家提供明确目标，同时奖励货币用于进一步扩展。

## 为什么好玩

海底世界的视觉效果——五彩斑斓的珊瑚和游动的鱼群——本身就令人放松和愉悦。《海底总动员》IP的加持让尼莫和多莉等角色的出现充满亲切感。不需要快速反应或精确操作，随时可以打开玩几分钟，是典型的放松型游戏体验。

## 粘性来源

鱼类收集的核心驱动——每种新稀有鱼的出现都像抽卡一样令人兴奋。鱼类进化机制让"再多种一棵看看"成为持续的冲动。任务系统提供了结构化的短期目标，而珊瑚礁的整体美观度是长期的满足感来源。

## Meta 系统

鱼类收集图鉴：记录已发现和已进化的所有鱼类品种。珊瑚礁等级系统随装饰物数量增加而提升，解锁更多高级装饰物和特殊鱼类。

## 实现难度

低。核心是2D/2.5D场景管理和物品放置系统。最大技术难点在于鱼类的AI路径规划——让鱼群在珊瑚礁中自然游动而不显得机械或穿模。但整体技术门槛较低，是入门级移动游戏开发的良好范例。
