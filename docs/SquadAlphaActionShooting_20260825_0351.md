# Alpha小队 动作射击（Squad Alpha - Action Shooting）

- **类型**: 动作射击/俯视角
- **平台**: Mobile (iOS+Android)
- **开发商**: SayGames LTD
- **首次发布**: 2023
- **一句话描述**: 俯视角小队射击闯关游戏

## 玩法规则

Squad Alpha 是一款俯视角小队射击游戏。玩家控制一个小队（通常 2-4 名队员），在俯视角地图中移动、射击、躲避敌人。

操作方式：左手虚拟摇杆控制移动方向，右手点击屏幕自动射击（或滑动瞄准射击）。队员会自动攻击范围内的敌人。

每个关卡是一个独立的小型地图，包含敌人波次、掩体、障碍物和最终 Boss。玩家需要利用掩体躲避敌人火力，同时找到最佳射击位置消灭所有敌人。

游戏有角色升级系统：通关后获得金币，用于提升队员的攻击力、生命值、射速等属性。

## 核心循环

选择关卡，控制小队移动射击，消灭所有敌人和Boss，获得金币升级角色，挑战更高难度关卡

## 核心机制

- 自动射击加手动走位：队员自动攻击范围内的敌人，玩家专注于走位和躲避。这种半自动设计降低了操作门槛，让玩家可以专注于策略和位置选择。
- 小队系统：控制多个队员而不是单个角色。队员有不同的武器和能力，增加了策略深度，需要分配队员位置和利用不同武器组合。
- 升级系统：通关获得的金币用于升级角色属性。提供明确的进度感和成长目标。

## 为什么好玩

Squad Alpha 把射击游戏的爽快感简化为移动加自动射击的低门槛体验。俯视角提供了全局视野，让战术走位变得直观。小队系统增加了策略性，需要管理多个队员的位置和能力搭配。升级系统提供了持续的目标感。

## 粘性来源

粘性来源：（1）关卡难度递增提供持续挑战；（2）升级系统提供明确的成长目标；（3）小队角色多样化增加收集欲望；（4）自动射击降低了挫败感，让失败后更容易再来一局。

## Meta 系统

角色升级系统（攻击力、生命值、射速等属性提升）。金币经济系统（通关获得、升级消耗）。角色和武器解锁。

## 实现难度

低到中。2D俯视角射击的碰撞检测和AI路径寻路是主要技术点。自动射击的命中判定需要精确。
