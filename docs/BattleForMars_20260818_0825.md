# Battle For Mars

- **类型**: 策略 / 塔防
- **平台**: Mobile (iOS)
- **开发商**: Gameloft
- **首次发布**: 2009
- **一句话描述**: 火星殖民地防御战，部署防御塔抵御敌人入侵

## 玩法规则

玩家扮演火星殖民地的指挥官，需要在不断来袭的敌人进攻中保护基地。

游戏采用俯视角，玩家看到自己的基地建筑和从不同路径涌来的敌人。火星的荒凉地貌上，敌人沿着固定的路径向基地核心推进。

玩家可以在战场上放置防御塔和军事单位——不同类型的防御塔有不同攻击方式（机枪、导弹、激光、电磁脉冲等）。

敌人按照预设路径前进，每种敌人有不同的血量、速度和特殊能力（如盾牌、隐身、飞行等）。

玩家通过消灭敌人获得资源，用来建造更多防御设施或升级现有建筑。

在波次之间，玩家有短暂的准备时间来调整布防——移动、升级或拆除防御塔。

每关有若干波敌人，最后一波通常有强力Boss，需要集中多种防御塔才能击败。

过关条件：成功抵御所有敌人波次，基地核心未被摧毁。

失败条件：基地核心被敌人摧毁。

## 核心循环

部署防御 -> 击退敌人 -> 获取资源 -> 升级设施（一句话）

## 核心机制

- 塔防布局机制：玩家需要在有限空间和预算内选择最优的防御塔组合和放置位置。不同地形区域对防御塔的效果有不同影响（如高地增加射程）。
- 敌人波次机制：每波敌人的类型、数量和路径不同，考验应变和预判能力。早期波次简单，后期波次可能包含多路同时进攻。
- 资源管理：击杀奖励与建造成本的平衡，玩家需要在进攻间隙快速决策。资源可以用于新建、升级或维修防御塔。
- 塔升级树：每种防御塔有独立的升级路径，玩家可以根据当前战场情况选择升级方向（如提升伤害、增加攻击范围、添加特殊效果）。

## 为什么好玩

科幻题材的塔防体验，火星荒凉地貌与高科技武器的对比营造独特氛围。多种防御塔和敌人类型提供了丰富的策略组合。每关的地形和路径设计都不同，保持了长期的新鲜感。

## 粘性来源

数值成长带来的满足感——看着自己的防御体系从简陋到精密。每关新敌人类型保持新鲜感。失败后很容易调整布局再次挑战，低磨损的尝试成本让玩家愿意反复挑战。

## Meta 系统

科技树系统：解锁新型防御塔和升级选项。部分版本含永久升级，跨关卡生效。星级评分系统鼓励玩家以最优布防通关。

## 实现难度

中 — 需要路径寻找AI、波次管理、多塔协同逻辑。最大技术难点是大量单位同时存在的性能优化——需要使用对象池和空间分割来保证流畅。
