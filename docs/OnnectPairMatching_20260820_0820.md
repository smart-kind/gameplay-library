# 连连配对（Onnect Pair Matching）

- **类型**: 配对消除 / 连线解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Rollic Games
- **首次发布**: 2018
- **一句话描述**: 在棋盘上找到相同的两张卡片并用不超过两个弯折的路径连接它们，消除所有配对

## 玩法规则

游戏棋盘上排列着多对相同的图标（如水果、动物、花朵等）。每个图标在棋盘上出现恰好两次。

玩家的操作是选择两个相同的图标。如果这两个图标之间可以用一条不超过两个弯折（最多三段直线）的路径连接（路径可以经过空白格子但不能穿过其他图标），则配对成功，两个图标被消除。

配对成功后图标消失，露出空白格子。后续配对的路径可以经过这些空白区域。目标是消除棋盘上的所有图标对。

如果棋盘上没有可配对的图标（所有相同图标对之间都被其他图标阻挡），游戏失败。部分关卡提供"重排"道具，重新排列剩余图标。

关卡难度通过增加棋盘尺寸、图标种类数量、以及初始布局的复杂度来提升。时间模式要求在限定时间内完成所有配对。

## 核心循环

找到相同图标对 → 用不超过两弯的路径连接 → 消除配对 → 清除所有图标通关

## 核心机制

- **路径连接规则**: 核心规则是两个相同图标必须能用不超过两个弯折的路径连接。这个规则既限制了配对的自由度（不能任意配对），又保证了可解性（总有路径可走）
- **空间消除策略**: 消除图标后腾出的空白格子为后续配对创造路径。消除顺序直接影响后续难度——先消除边缘图标还是中间图标，会产生完全不同的后续局面
- **渐进式关卡设计**: 从小的棋盘和少量图标开始，逐步增加尺寸和图标种类。时间模式增加紧迫感

## 为什么好玩

寻找配对的过程类似"找不同"的反向版——需要扫描和记忆图标位置。每次找到一对可行配对并连线消除的瞬间有解谜成功的满足感。消除顺序的策略选择增加了思考深度。

## 粘性来源

消除顺序的策略性让每局都有思考空间；"眼看就要通关"的进度感驱动继续；时间模式的紧迫感增加刺激；每日关卡和挑战模式提供持续内容。

## Meta 系统

关卡递进：线性推进的关卡系统。道具系统（重排、提示、撤销）帮助玩家通过难关。对核心玩法有辅助作用。

## 实现难度

低到中。路径搜索算法（BFS限制最多两弯）是核心技术点，图标排列和可解性验证需要设计。最大技术难点是高效的路径可达性检测。
