# 破碎像素地牢 (Shattered Pixel Dungeon)

- **类型**: Roguelike / 地牢探索 / 回合制
- **平台**: Mobile (iOS+Android) / PC (Linux, Mac, Win)
- **开发商**: Shattered Pixel
- **首次发布**: 2014
- **一句话描述**: 经典像素风回合制地牢Roguelike，随机生成的地牢、职业、道具，每次冒险都独一无二

## 玩法规则

游戏画面为俯视角的像素风格地牢，每层地牢由程序随机生成。玩家从地牢入口出发，逐层向下探索，最终目标是到达第26层击败最终Boss。

玩家在每回合可以执行一个动作：移动到相邻格子、攻击敌人、使用物品、投掷道具、打开门或容器、阅读卷轴、饮用药水等。敌人同样在玩家行动后移动和攻击。游戏是严格的回合制——玩家不动，敌人也不动，这给了玩家充足的时间思考策略。

玩家的资源管理非常关键：食物有限（饥饿会持续扣血直到饿死），药水、卷轴、种子、矿石等都需要合理分配。商店NPC出现在特定楼层，可以用金币购买装备和补给。

当角色死亡时，所有进度清零，必须从第一层重新开始。但游戏提供了解锁机制——通过达成特定条件（如用特定职业通关），可以解锁新的起始物品或角色。

## 核心循环

探索地层（发现房间/敌人/物品）→ 收集装备和资源 → 强化角色 → 前往下一层更危险的地牢

## 核心机制

- **程序化生成**：每一层地牢的布局、敌人分布、物品位置都随机生成，确保每次游玩体验完全不同。房间类型包括普通房间、密室、商店、陷阱房、Boss房等。
- **职业系统**：5个起始职业（战士、法师、盗贼、猎人、术士），各有独特天赋。战士每回合自动回复生命，法师升级时获得充能，盗贼能发现隐藏物品等。
- **物品鉴定**：卷轴和药水初始为未鉴定状态（显示为随机名称），玩家通过尝试使用或阅读鉴定卷轴来发现其真实效果。这个机制增加了探索和策略深度。
- **装备升级**：使用升级卷轴可以强化武器和护甲，但有一定失败概率。过度升级的装备可能会碎裂。
- **种子系统**：种植水果种子可以长出食物，玫瑰种子长出治疗花，盲目藤种子产生致盲效果等。善用种子是高级策略。

## 为什么好玩

极高的重玩价值——每次进入都是全新的地牢、不同的物品组合、不可预测的事件。回合制让每一步都像在下棋，充满了"再试一次"的冲动。免费开源、无内购的良心设计让它成为手机平台上最优秀的Roguelike之一。

## 粘性来源

"差一点就通关"的不甘心是最强的驱动力。每次死亡都能学到新东西（某药水的效果、某敌人的行为模式、某种道具组合），渐进式的解锁系统让每次失败都有意义。职业和起始物品的组合多样性保证了长期重玩性。

## Meta 系统

解锁系统：通过达成成就（如用特定职业通关、击败特定Boss）解锁新的起始物品和角色选项。这些解锁是永久性的，为后续游戏提供不同的起点。无付费内容，完全免费。

## 实现难度

中等。回合制网格移动和程序化地牢生成是成熟技术，但物品系统的深度、平衡性调校（100+种物品的相互作用）以及5个职业的差异化设计需要大量时间。最大技术难点在于随机生成算法的质量保证和物品交互系统的复杂度管理。
