# 巴巴是你（Baba Is You）

- **类型**: 解谜 / 规则操作 / 逻辑
- **平台**: PC (Steam) / Nintendo Switch / iOS / Android / itch.io
- **开发商**: Hempuli
- **首次发布**: 2019
- **一句话描述**: 通过移动文字方块来改变游戏规则本身——文字即法则的颠覆性解谜游戏。

## 玩法规则

游戏画面是像素风格的网格关卡。每个关卡中有各种物体（角色、墙壁、旗帜等）和文字方块（"BABA"、"IS"、"YOU"、"WALL"、"STOP"、"FLAG"、"WIN" 等）。

玩家控制 Baba（默认情况下），在网格中上下左右移动，推动物体和文字方块。

游戏的核心创新在于：文字方块组成的句子就是当前关卡的运行规则。例如：
- "BABA IS YOU" 表示 Baba 是玩家可以控制的角色
- "WALL IS STOP" 表示墙壁是不可穿越的障碍
- "FLAG IS WIN" 表示碰到旗帜即可过关

玩家的关键操作是推动文字方块来重新组合句子，从而改变规则。比如把 "BABA IS YOU" 拆开，改成 "WALL IS YOU"，玩家就能控制墙壁移动；或者改成 "ROCK IS WIN"，碰到石头就能过关。

如果一条规则的句子被破坏（文字方块不再连成一行），规则就失效。玩家需要在有限的空间内，巧妙地排列文字来创造通关条件。

## 核心循环

观察关卡中的文字和物体 → 推动文字重新组合规则 → 利用新规则找到通关路径 → 进入下一关

## 核心机制

- **规则即对象**：文字方块既是规则的载体，也是可以被推动的物理对象。"规则"和"物体"是同一层级的东西
- **逻辑推导**：每个关卡都是一个逻辑谜题，需要推导出如何通过重新排列文字来创造通关条件
- **多规则交互**：一个关卡中可能同时存在多条规则，改变一条会影响其他规则的运作
- **递归思维**：后期的关卡会出现 "X IS PUSH"、"Y IS MOVE" 等元规则，让文字本身也能被"规则化"

## 为什么好玩

Baba Is You 的颠覆性在于它让玩家不只是在规则内解决问题，而是可以修改规则本身。当你第一次意识到可以把 "BABA IS YOU" 改成 "WALL IS YOU"，从而控制墙壁时，那种"规则被打破"的顿悟感是其他游戏无法提供的。每一个关卡都像是一个逻辑上的"尤里卡时刻"。

## 粘性来源

1. **顿悟快感**——每解开一关都会有一次"原来如此！"的顿悟体验，这种认知上的满足感极强
2. **层层递进**——从简单的规则修改到复杂的多规则交互，难度曲线设计精妙
3. **自由度**——每个关卡通常有多个解法，玩家可以用自己喜欢的方式通关
4. **认知挑战**——这不是反应力或操作技巧的游戏，而是纯粹的脑力挑战

## Meta 系统

无。游戏没有外围系统，核心就是关卡解谜。通关后解锁隐藏关卡。

## 实现难度

高。虽然看起来是简单的 2D 网格游戏，但底层需要实现一个完整的规则解析引擎。文字方块的组合需要实时解析成规则并应用到游戏世界中，同时还要处理规则的冲突和优先级。最大技术难点是确保规则系统的稳定性——在数千种可能的文字组合中，每一条都必须有明确且一致的行为。
