# Squad Alpha - Action Shooting

- **类型**: 横版射击
- **平台**: Mobile (iOS+Android)
- **开发商**: SayGames LTD
- **首次发布**: 2021
- **一句话描述**: 一款包含多种玩法的games类型游戏

## 玩法规则

- 横版或纵向卷轴视角，玩家角色位于屏幕下方或左侧，敌人从对侧涌入。屏幕上散布掩体和可破坏的障碍物。
- 操作通常为单手——点击/长按射击，滑动控制角色位置。部分游戏提供自动瞄准辅助，玩家只需专注走位躲避弹幕。
- 不同敌人有不同的攻击模式：直线冲锋、抛物线投掷、扇形弹幕等。击败敌人掉落金币、血包或临时增益道具（如无敌、双倍伤害）。
- 游戏目标是清除关卡中所有敌人并击败Boss。Boss有多个阶段，每个阶段攻击模式不同，需要调整策略应对。


玩家控制一个角色从左向右（或从上向下）自动前进，需要消灭沿途的敌人和障碍物。画面通常采用横版或纵向卷轴视角。

操作方式多为单手控制——点击或长按屏幕射击，滑动控制角色位置。部分游戏支持自动瞄准，玩家只需专注走位躲避弹幕。

敌人在固定位置出现或沿预设路径移动，会向玩家发射子弹或投掷物品。不同类型的敌人有不同的攻击模式和血量。击败敌人掉落金币或道具。

游戏目标是尽可能多地消灭敌人，清除关卡中的所有威胁，或在限时内达到目标分数。Boss关会出现大型敌人，需要特定策略应对。

## 核心循环

进入关卡 → 消灭敌人 → 获取奖励 → 升级装备 → 挑战更强关卡

## 核心机制

- 自动射击/手动瞄准：根据游戏设计，射击可以是全自动的或需要手动瞄准
- 武器系统：多种武器可供选择，每种有不同的射速、伤害和特殊效果
- 弹幕躲避：玩家需要在密集的攻击中穿梭，考验反应速度和走位能力
- 关卡递进：难度逐步提升，敌人种类和数量增加

## 为什么好玩

爽快的射击打击感配合丰富的武器选择，让玩家在快节奏战斗中体验纯粹的乐趣

## 粘性来源

武器升级和收集系统提供长期目标；关卡难度递进保持挑战性

## Meta 系统

武器解锁与升级系统，收集资源解锁更多枪械

## 实现难度

低 — 标准横版射击框架，最大难点是设计丰富的敌人AI和子弹弹幕模式
