# Save the grandmother

- **类型**: 益智 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: MondayOFF
- **首次发布**: 2022
- **评分**: ⭐ 4.7/5 (2,909 评价)
- **价格**: Free
- **一句话描述**: MondayOFF出品的简单休闲游戏，玩家通过触控操作拯救老奶奶。

## 玩法规则

游戏以轻松幽默的风格呈现。每个关卡中，老奶奶处于某种危险或困境中（如掉落、被困等）。玩家需要通过点击、拖拽、划线等操作来改变环境，拯救老奶奶。操作方式简单：单指触控即可。关卡设计包含物理元素——重力、弹跳、滑动等。每个关卡的解法通常不止一种，鼓励玩家尝试不同方案。界面简洁：关卡场景、老奶奶角色、操作提示。

## 核心循环

观察关卡 → 尝试操作 → 拯救老奶奶 → 解锁下一关

## 核心机制

- 物理谜题：利用重力、弹跳等物理规则解谜
- 多种解法：每个关卡允许多种解决方案
- 幽默风格：轻松搞笑的场景设计增加趣味

## 为什么好玩

拯救老奶奶的主题本身就很有趣，物理谜题的"啊哈"时刻让人满足。

## 粘性来源

解谜成就感、关卡渐进难度、幽默内容

## Meta 系统

关卡解锁系统。无复杂经济系统。

## 实现难度

低——物理谜题+简单触控，实现容易
