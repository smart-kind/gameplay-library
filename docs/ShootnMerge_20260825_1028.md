# Shoot n Merge

- **类型**: 射击合成 / 数字益智
- **平台**: Mobile (iOS+Android)
- **开发商**: Metajoy Limited
- **首次发布**: 2018-05-26
- **一句话描述**: 射击砖块+数字合成的创新解谜，射击相同数字的砖块合并升级

## 玩法规则

Shoot n Merge 融合了弹球射击和数字合并两种玩法。屏幕下方有一个可左右移动的发射器，屏幕上方是排列好的数字砖块。玩家点击屏幕发射球体，球体击中砖块后会粘在上面。

当两个相同数字的砖块相邻时，它们会合并成这两个数字之和（例如2+2=4，4+4=8）。合并后的砖块数字变大，分数也更高。目标是通过不断射击和合并，获得尽可能高的数字和分数。

操作很简单：左右移动瞄准，点击发射。但策略性在于：射击位置决定了球体粘附的位置，从而影响合并的可能性。有时需要故意射击错误位置来"搭桥"，让远处的相同数字靠拢。

没有时间限制，玩家可以慢慢思考每一步。

## 核心循环

瞄准 → 射击砖块 → 触发合并 → 获得更高级数字 → 挑战更高分数

## 核心机制

- **射击定位+合并升级**：射击决定了球体的位置，合并决定了数字的增长。两个机制相互依赖——好的射击位置才能创造好的合并机会。这种"操作+策略"的结合让游戏既有动作感又有思考深度。
- **指数增长反馈**：数字按2的幂次增长（2→4→8→16→32→...），每次合并都带来指数级的分数增长，后期的合并有强烈的"爽感"。
- **无时限压力**：没有时间限制，玩家可以充分思考最佳射击位置，降低了操作门槛，提高了策略空间。

## 为什么好玩

Shoot n Merge 把弹球的"瞄准乐趣"和2048的"数字合并快感"结合在一起。每次成功合并后的数字跳动和音效反馈非常 satisfying。和朋友比谁的数字更大也是一个自然的社交竞争点。

## 粘性来源

具体到机制层面：追求更高级数字的目标驱动（"这次我一定要合成2048"）让人不断重来；射击位置的选择自由度让每局都有不同体验；与朋友比分的社交竞争增加了重复游玩的动力。

## Meta 系统

好友排行系统是主要的外围系统。玩家可以看到朋友的最高分数并尝试超越。无其他养成或收集系统。

## 实现难度

低 — 物理碰撞、弹道计算和合并逻辑都是成熟的技术方案。最大的技术难点是物理引擎的精确性（球体粘附位置的精确计算）和不同屏幕尺寸上的瞄准适配。

球体的物理运动增加了策略的不确定性——球体在棋盘上的弹跳轨迹不完全可控，有时会出现"幸运的弹跳"让本来不合适的球体找到了完美的合并位置，有时也会出现"不幸的弹跳"破坏了精心布置的局面。这种随机性既增加了趣味性也降低了挫败感。

合成策略的核心是"搭桥"——有时需要故意射击到一个不理想的位置，以便在下一轮创造更好的合并机会。这种"牺牲当前利益换取未来机会"的思维方式让游戏超越了简单的反应力挑战。

好友排名系统让纯粹的单人游戏增加了社交维度。看到朋友的最高数字（比如他合到了4096），你会自然产生"我也要试试看"的冲动。排名不设时限，随时可以挑战和超越。
