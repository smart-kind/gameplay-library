# 触发英雄（Trigger Heroes）

- **类型**: 俯视角射击 / Roguelike / 动作
- **平台**: Mobile (iOS)
- **开发商**: Lucky Kat Studios
- **首次发布**: 2018
- **一句话描述**: 一款单指操控的俯视角Roguelike射击游戏，玩家控制英雄在五个独特环境中对抗外星雇佣军，每局体验都不相同。

## 玩法规则

游戏采用俯视角（Top-down）画面布局，玩家控制角色在一个充满敌人和障碍物的封闭区域中移动。操作极其简单：只需单指点击屏幕，角色会自动朝点击方向移动并射击。

玩家面对的敌人包括多种类型的敌对佣兵和每关独特的Boss。每个环境（共5个）都有独特的视觉风格、敌人配置和地形障碍。玩家在探索过程中可以拾取各种武器，每种武器有不同的射速、伤害和攻击范围。

角色在战斗中会自动射击范围内的敌人，玩家需要专注于走位躲避敌方子弹。当角色被敌人击中并失去所有生命值时，当前回合结束，玩家返回大厅重新开始。

游戏的目标是清除当前区域的所有敌人，击败关底Boss，然后进入下一个环境。每个环境完成后会解锁新的挑战内容。

## 核心循环

移动躲避并射击 → 击败敌人获取进度 → 解锁新武器/区域 → 挑战更强Boss

## 核心机制

- **单指操控系统**：所有操作通过单指点击完成，角色自动向点击方向移动并射击。降低了操作门槛，但要求精准的走位判断，因为角色同时承担移动和瞄准。
- **Roguelike随机性**：敌人配置、武器掉落和关卡布局带有随机元素，每局游戏体验不同，重玩价值高。
- **武器多样化**：游戏中有多种武器可供拾取和使用，每种武器有不同的弹道模式、射速和伤害输出。玩家需要根据当前敌人类型灵活切换策略。
- **Boss战机制**：每个环境都有独特的Boss，拥有特定的攻击模式和弱点。玩家需要观察Boss的攻击规律并找到安全的输出窗口。

## 为什么好玩

单指操作让游戏极易上手，但俯视角弹幕射击的深度体现在走位决策上——什么时候该进攻、什么时候该撤退，每一秒都在做选择。五个风格迥异的环境和多样的武器库保证了长时间游玩不会感到重复。

## 粘性来源

Roguelike的"再来一局"机制是核心粘性来源：每局随机性+逐渐提升的操作熟练度，让玩家觉得"这次我能走更远"。Boss战的成功反馈（躲避全部弹幕后击败Boss的爽感）和武器收集的成就感也持续驱动玩家。

## Meta 系统

游戏包含角色解锁和成就系统。通过多周目游玩，玩家可以解锁新的可操作角色，每个角色有独特的属性和能力。Game Center集成提供成就和排行榜功能。无复杂的付费成长系统。

## 实现难度

低。俯视角2D游戏的技术栈成熟，单指操控的输入逻辑简单。最大的技术难点在于弹幕系统的性能和碰撞检测优化——当屏幕上同时存在大量子弹时，需要高效的检测算法来保证流畅性。
