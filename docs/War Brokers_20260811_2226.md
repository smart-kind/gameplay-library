# War Brokers（War Brokers）

- **类型**: FPS 多人对战 / 载具战斗 / 大逃杀
- **平台**: Web（浏览器）/ Mobile
- **开发商**: TreSena / Voxel Games 风格
- **首次发布**: 2018 左右
- **一句话描述**: 基于体素风格的浏览器 FPS 游戏，玩家可以选择步兵或驾驶各种载具进行团队对战

## 玩法规则

游戏采用第一人称视角，画面为方块体素风格（类似 Minecraft 的视觉风格）。主界面有模式选择（团队死亡竞赛、大逃杀、夺旗等），匹配后进入战场地图。

玩家在战场上可以使用多种武器（步枪、狙击枪、火箭筒等）与敌方玩家交火。地图中散布着各种载具——坦克、直升机、装甲车、战斗机——玩家可以进入驾驶座操作。载具有独立的血量和弹药系统，被击毁后需要重新寻找。

团队死亡竞赛模式中，两队互相击杀，先达到目标击杀数的队伍获胜。大逃杀模式则类似 PUBG，玩家在一个逐渐缩小的安全区内战斗，最后存活的玩家/队伍获胜。夺旗模式需要夺取敌方基地的旗帜并带回己方基地。

## 核心循环

选择武器/载具 → 与敌方交战 → 击杀/被击杀 → 重生/下一局

## 核心机制

- **载具系统**：地图上有多种可操作的载具（坦克、直升机、战斗机），每种载具有独特的操控方式和火力。载具需要寻找、进入、驾驶，被击毁后重新出现。
- **体素破坏**：部分地图场景中的方块体素可以被武器破坏，创造新的掩体或通道。
- **多模式匹配**：支持团队死亡竞赛、大逃杀、夺旗等多种玩法模式，每种模式有不同的胜利条件。

## 为什么好玩

War Brokers 把 FPS 和载具战斗结合在一起，而且完全在浏览器中运行——不需要下载几百兆的游戏客户端，打开网页就能玩。体素风格的画面虽然不写实，但流畅的战斗手感和多样的载具选择让对战充满乐趣。

## 粘性来源

- **低门槛+快节奏**：浏览器即开即玩，一局几分钟，死亡后快速重生，随时可以再来一局
- **载具多样性**：坦克的重火力、直升机的机动性、战斗机的空中优势——每种载具带来完全不同的战斗体验
- **社交对战**：多人实时对战带来不可预测的对手行为，每局都是新体验

## Meta 系统

无。纯对战游戏，没有外围成长系统。

## 实现难度

中 + 需要多人网络同步（位置、射击判定、载具状态）、3D渲染引擎、碰撞检测。最大技术难点是多人游戏的低延迟同步和反作弊——FPS 游戏对网络延迟非常敏感，浏览器环境下的性能优化也是挑战。
