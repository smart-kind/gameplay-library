# Offline Games - No Wifi Games

- **类型**: 离线游戏合集
- **平台**: Mobile (iOS+Android)
- **开发商**: Moreno Maio
- **首次发布**: 2023
- **评分**: ⭐ 4.8/5 (356,713 评价)
- **价格**: Free
- **一句话描述**: 包含20+款无需网络即可游玩的迷你游戏合集，适合飞行、地铁、户外等无网络场景。

## 玩法规则

应用打开后展示所有可用游戏的图标列表，每款游戏旁标注类型标签。点击进入任意游戏，无需网络连接即可开始。游戏类型涵盖：拼图、记忆、数学、反应力、策略等。每款游戏的规则在首次进入时通过简短视频或图文教程展示。操作以单指触控为主。游戏内包含本地高分记录，可以追踪个人进步。界面简单明了，无广告弹窗干扰（或可离线去除）。

## 核心循环

选择游戏 → 离线游玩 → 刷高分 → 挑战自我/换游戏

## 核心机制

- 完全离线：所有游戏数据和逻辑本地运行，零网络依赖
- 多品类覆盖：20+款不同类型小游戏，满足不同需求
- 本地高分：追踪个人最佳成绩，提供自我挑战动力

## 为什么好玩

解决"没有网的时候玩什么"这个真实痛点。20+款游戏确保不会很快腻。适合通勤、旅行、排队等碎片时间。

## 粘性来源

离线场景刚需、刷高分自我挑战、游戏品类多样性、轻量安装

## Meta 系统

无——纯离线游戏合集，无社交/经济系统。依赖游戏本身趣味性。

## 实现难度

低——单款小游戏技术简单，合集主要是数量优势
