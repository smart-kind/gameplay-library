# 杀戮尖塔（Slay the Spire+）

- **类型**: 肉鸽 / 卡牌 / 策略
- **平台**: Mobile (iOS) / PC / Switch
- **开发商**: Humble Bundle (原 MegaCrit)
- **首次发布**: 2023
- **一句话描述**: 肉鸽卡牌游戏的标杆之作，通过爬塔过程中构建卡组、击败敌人、最终征服尖塔。

## 玩法规则

游戏画面分为左右两部分：左侧是战斗场景，显示敌人和玩家的意图指示器；右侧是手牌区域和能量显示。

每个回合，玩家抽取一定数量的手牌，使用能量打出卡牌执行行动——攻击、防御、施加状态效果等。每回合的能量上限固定（通常3点），卡牌有不同的能量消耗。

敌人会显示下一回合的意图（攻击X点伤害、施加Y层负面状态、治疗等），玩家需要根据敌人意图选择合适的卡牌应对——是进攻还是防御。

爬塔过程中，玩家会经过多个节点：战斗（获取卡牌奖励）、精英怪（高风险高回报）、商店（用金币购买卡牌和遗物）、篝火（休息升级或升级卡牌）、宝箱。

每次冒险开始时选择一个角色，每个角色有独特的初始卡组和机制。铁甲战士侧重防御和力量叠加，静默猎手侧重毒药和多段攻击，故障机器人侧重充能和自动化。
## 核心循环

选择角色 → 爬塔经过各种节点 → 战斗中打出卡牌 → 获取新卡牌和遗物 → 构建 synergistic 卡组 → 挑战楼层Boss → 死亡后重新开始

## 核心机制

- **意图预判系统**：敌人会提前显示下回合的行动意图，玩家需要根据信息做出决策。这给卡牌游戏增加了'解谜'元素——'敌人要打10点伤害，我有5点格挡和一张6点攻击牌，是先防还是先攻？'
- **卡组构建(Carding)**：爬塔过程中从三张随机卡牌中选择一张加入卡组。每次选择都影响后续的策略。好的卡组构建是通关的关键。
- **遗物系统**：遗物是被动加成道具，提供各种效果——'每回合多抽1张牌'、'攻击时附加3点伤害'、'每打出10张牌触发一次特殊效果'等。遗物与卡组的协同是深度策略的核心。

## 为什么好玩

每次爬塔的卡牌选择和遗物收集都不同，构建出独特的卡组组合。当一套卡牌和遗物产生'化学反应'（如无限循环、一击必杀）时，成就感爆棚。

## 粘性来源

肉鸽的随机性+卡牌构建的策略深度是核心粘性。每次失败的'如果选了那张牌就能过'心理驱动再次尝试。不同角色的机制差异鼓励多周目。解锁新卡牌和新遗物提供长期目标。

## Meta 系统

角色解锁和卡牌/遗物图鉴系统。通过通关和达成条件解锁新角色（初始只有1个）。收集到的所有卡牌和遗物永久记录在图鉴中。高分排行榜提供竞技目标。

## 实现难度

高 — 卡牌游戏的数值平衡和内容设计极其复杂。数百张卡牌和遗物之间的相互作用需要大量测试。技术难点在于意图系统的AI设计和大量卡牌效果组合的正确性保证。

## 同类游戏

与此游戏类似的推荐：放置类可参考 Clicker Heroes 和 Idle Slayer；肉鸽类可参考 Slay the Spire 和 Vampire Survivors。
