# Stumble Guys

- **类型**: 派对竞技 / 障碍闯关
- **平台**: Mobile (iOS+Android) / PC (Steam)
- **开发商**: Kitka Games / Scopely
- **首次发布**: 2021
- **一句话描述**: 一款最多32人同场竞技的派对闯关游戏，玩家控制圆滚滚的角色在充满障碍和陷阱的赛道中奔跑，淘汰赛制直到决出唯一胜者。

## 玩法规则

32名玩家同时进入一个色彩鲜艳的3D竞技场，每轮随机选择一个迷你游戏关卡。游戏自动匹配玩家，无需组队即可开始。

游戏包含四种关卡类型：竞速关中玩家从起点跑到终点，最后几名被淘汰；生存关中玩家在逐渐缩小的平台上保持平衡，掉落即淘汰；团队关中两队对抗完成特定目标如抢球占地；最终关由剩余少数玩家进行最终对决。

操作方式非常简单：虚拟摇杆控制角色移动方向，跳跃按钮跳过障碍物，飞扑按钮向前飞扑。飞扑可以加速通过短距离，也可以推开其他玩家。但使用飞扑也有风险——可能把自己扑出赛道。

淘汰规则是每轮淘汰固定数量的玩家，通常是剩余人数的一半。掉出赛道、被陷阱击中或时间耗尽都会被淘汰。通过所有轮次的最后一名玩家获胜。

角色有布娃娃物理效果，碰撞时会摔倒、滚动。关卡中的旋转锤、摆锤、弹跳板等机关都有真实的物理反馈。被其他玩家碰撞也会产生连锁反应，常常一人摔倒牵连一片。

## 核心循环

进入关卡 → 跑跳飞扑闯关 → 通过或被淘汰 → 下轮继续或观战

## 核心机制

- **布娃娃物理加碰撞互动**: 角色的物理模拟是核心乐趣来源。玩家不仅会被关卡机关击飞，还会被其他玩家碰撞、推挤、绊倒。主动飞扑可以推开挡路对手，但也可能把自己送出赛道。这种混乱物理创造大量搞笑和不可预测的瞬间，是社交传播的天然素材。

- **多轮淘汰赛制**: 32进16进8进4进1的淘汰结构让每局都有明确进度感。每轮关卡随机抽取，玩家永远不知道下一关是什么。淘汰后观战系统让失败玩家不会无聊，可以继续看朋友出糗。大逃杀加派对游戏混合设计是品类开创者。

- **随机机关加动态赛道**: 每关机关布局固定，但其他玩家行为引入巨大随机性。被人群裹挟前进时，不知道谁会突然摔倒连累你。旋转锤、弹跳板、移动地板等机关要求判断时机，而人群存在让时机判断变得极其困难。

## 为什么好玩

色彩鲜艳的卡通画风配合滑稽的布娃娃物理，让失败也变得有趣。32人大混战的混乱场面永远充满笑料，和朋友一起玩更是欢乐翻倍。每局2-5分钟，随时可以开始或结束。即使被淘汰，观战其他玩家的搞笑失误也是一种娱乐。

## 粘性来源

大逃杀淘汰赛的紧张感加上物理搞笑的娱乐性和皮肤收集的成长感，构成忍不住再来一局的循环。随机关卡保证每局体验不同，永远不会腻。赛季通行证和特殊活动维持长期活跃。

## Meta 系统

皮肤系统：通过游戏内货币或赛季通行证解锁角色外观、表情、飞行特效等。皮肤不影响数值，纯外观收集。赛季通行证提供阶段性奖励目标。排行榜系统记录玩家的历史最佳成绩。

## 实现难度

中。3D物理引擎和多人同步是技术难点。关卡机关碰撞检测需要精准调优。32人实时对战的服务器架构也有挑战。布娃娃物理在低端设备上的性能优化需要特别注意。
