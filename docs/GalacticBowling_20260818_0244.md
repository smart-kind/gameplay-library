# Galactic Bowling（Galactic Bowling）

- **类型**: 体育/保龄球
- **平台**: Mobile (iOS)
- **开发商**: 待确认
- **首次发布**: 2010
- **一句话描述**: 一款以太空入侵为背景的保龄球游戏，用保龄球拯救地球

## 玩法规则

游戏采用分屏对战布局，上方为玩家视角，下方为CPU对手视角。画面展示一条保龄球道，球道尽头有十个球瓶。

**操作方式**：
- 沿屏幕底部横向滑动控制角色左右移动
- 沿屏幕右侧纵向滑动控制旋转角度
- 反复点击力量条蓄力，在力量条耗尽前点击角色投球
- 倾斜设备给球施加旋转，使球曲线进入球瓶

**核心玩法**：
- 选择力量、角度和旋转后投出保龄球
- 球击中球瓶后计分，击倒全部球瓶为全中（strike）
- 故事模式中对抗CPU对手进行一对一比赛
- 快速模式可以单独练习投球

**胜利/结束条件**：
- 比赛胜利：总分高于对手
- 故事模式：击败外星入侵者拯救地球

## 核心循环

选择力量和角度 → 投球 → 计分 → 与对手对抗 → 推进故事模式

## 核心机制

- **力量条系统**：反复点击蓄力，在适当时机投球控制力度
- **旋转控制**：倾斜设备给球施加曲线旋转
- **分屏对战**：屏幕分为两部分展示双方投球，增强对抗感
- **故事驱动**：外星入侵者企图用保龄球摧毁地球，玩家用保龄球反击
- **多环境**：不同关卡有不同风格的保龄球道和环境

## 为什么好玩

将保龄球与太空入侵的荒诞设定结合，外星首领选择地球作为目标，而玩家的唯一武器是保龄球。这种 tongue-in-cheek 的幽默感让一款普通保龄球游戏有了独特的叙事魅力。

## 粘性来源

- **故事推进**：拯救地球的动机让人继续玩下去
- **对抗感**：分屏对战增强竞争意识
- **技术挑战**：精确控制力量和旋转的技巧提升
- **环境变化**：不同球道环境提供新鲜感

## Meta 系统

- **故事模式推进**：击败对手解锁新的保龄球道
- **快速模式**：单独练习投球

## 实现难度

低 — 保龄球物理模拟成熟，主要技术难点在于力量条投球系统的精确手感调校和球道环境设计。
