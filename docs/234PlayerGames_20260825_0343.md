# 234人游戏合集（2 3 4 Player Games）

- **类型**: 多人派对/本地同屏
- **平台**: Mobile (iOS+Android)
- **开发商**: Penji Games B.V.
- **首次发布**: 2017
- **一句话描述**: 40款本地多人小游戏，同设备2-4人同时玩

## 玩法规则

2 3 4 Player Games 的核心卖点是：2到4个玩家可以在同一台设备上同时玩。每个玩家使用屏幕的不同区域进行操作，互不干扰。

主界面展示所有 40 款小游戏的列表，玩家可以选择单个游戏玩，也可以进入'4人杯赛'模式（连续进行多款小游戏，总分最高者获胜）。

操作方式极简：所有游戏都使用'单指单按钮'控制。比如：快速点击加速（滑板比赛）、点击发射（坦克大战）、控制方向躲避（贪吃蛇）等。

每局游戏时间很短（30秒到2分钟），非常适合快速轮换。

## 核心循环

选择游戏/杯赛模式 → 2-4人同设备对战 → 即时结算分数 → 下一款游戏

## 核心机制

- **机制1**：同屏多人机制：2-4人在同一台设备上同时操作，每人控制屏幕的一个区域。无需联网，随时随地开局。
- **机制2**：极简单按钮操作：所有游戏只需一个按键（或点击/长按），规则一目了然。零学习成本。
- **机制3**：40款游戏多样性：涵盖赛车、格斗、体育、反应力、策略等多种类型，确保不会重复。

## 为什么好玩

这款游戏的核心乐趣在于'和朋友面对面一起玩'的快乐。不需要联网，不需要各自准备设备，一台手机/平板就能让2-4个人一起玩。40款游戏确保每轮都有不同的体验，'再来一局'的冲动非常强烈。

## 粘性来源

粘性来源：(1) 本地多人是独特的社交体验，无法被在线游戏替代；(2) 40款游戏提供丰富的选择；(3) '4人杯赛'模式让多轮游戏形成完整的竞技体验；(4) 极简操作适合任何年龄段；(5) 每局极短，适合碎片时间。

## Meta 系统

4人杯赛模式：连续进行多款小游戏，累计积分决定最终排名。无付费养成系统。纯娱乐导向。

## 实现难度

中。主要技术难点：(1) 同屏多人触控的精准识别（防止误触）；(2) 40款不同游戏类型的统一框架；(3) 小屏幕上的多玩家UI布局优化。
