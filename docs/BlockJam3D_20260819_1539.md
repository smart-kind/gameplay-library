# Block Jam 3D

- **类型**: 益智 / 三消 / 3D方块匹配
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2022
- **一句话描述**: 点击堆叠的 3D 方块收集到栏位中，凑齐 3 个相同方块消除并清理整个关卡

## 玩法规则

游戏画面是一个由多层 3D 方块堆叠而成的关卡场景。方块有多种类型（不同颜色/图案），每个方块上标有特定图标。方块层层叠放，上层的方块会遮挡下层的方块，被遮挡的方块无法点击。

玩家点击一个未被遮挡的方块，该方块会被收集到屏幕底部的收纳栏位中（栏位容量有限，通常为 5-7 格）。当栏位中有 3 个相同类型的方块时，它们立即消除并腾出栏位空间。

关卡目标是消除所有方块，清空整个堆叠结构。如果栏位被填满且没有可以消除的 3 个同色方块，游戏失败（类似羊了个羊的核心机制）。

每关有特定的方块布局和难度递进。部分关卡有辅助道具可用（如提示高亮可点击方块、撤销一步、移出栏位中的方块等）。通关后获得星星评价，用于解锁后续章节。

## 核心循环

观察堆叠 → 点击可获取方块 → 收集到栏位 → 凑齐3个消除 → 腾出空间继续获取 → 清空全部方块过关

## 核心机制

- **3D堆叠遮挡**：方块不是平铺在平面上的，而是多层堆叠。上层方块挡住下层方块，玩家必须先消除上层才能获取下层。这增加了空间规划的维度——不仅要管理栏位，还要规划消除顺序。
- **栏位资源管理**：栏位容量有限是核心约束。每次点击都消耗一个栏位格子，凑齐 3 个消除才能释放 3 格空间。不当的收集顺序会导致栏位满而失败。
- **方块匹配消除**：3 个相同方块在栏位中自动消除。玩家需要判断：是先凑齐一种方块消除，还是先收集多种方块等待后续匹配？
- **关卡布局多样性**：从简单的单层平铺到复杂的多层立体结构，每关的方块排列方式不同，需要不同的消除策略。

## 为什么好玩

"看得见但摸不着"的挫败感与"终于拿到那个关键方块"的满足感交替出现。层层剥离方块的进程感让人停不下来——每次消除都让关卡"变薄"一层，距离胜利更近一步。而栏位即将填满时的紧张感又让每个点击都充满决策重量。

## 粘性来源

- **渐进解锁感**：每消除一组方块，新的方块从上层"暴露"出来，这种持续发现的反馈循环
- **关卡递进**：难度逐步增加，新机制（特殊方块、障碍物）逐步引入
- **收集驱动**：部分版本有装饰收集或章节解锁
- **短局节奏**：单局 5-15 分钟，适合碎片时间

## Meta 系统

- **道具系统**：提示、撤销、移出等辅助道具，通过看广告或内购获得
- **章节解锁**：按章节递进，每章有不同主题和视觉风格
- **每日挑战**：特殊关卡模式，限制栏位容量或时间

## 实现难度

中。核心难点在于 3D 方块的遮挡关系计算（需要维护每个方块的 z-index 层级和遮挡判定）以及流畅的 3D 动画（方块弹出、消除、层间掉落）。Unity 引擎可以较好处理，但需要精心设计关卡编辑器来生成平衡的堆叠布局。
