# Pinball Arcade（弹球街机）

- **类型**: 街机 / 弹球
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: FarSight Studios
- **首次发布**: 2012
- **一句话描述**: 收录大量经典实体弹球机的数字版模拟器，还原真实的物理弹球体验。

## 玩法规则

游戏界面模拟真实的弹球机。玩家通过屏幕两侧的挡板（flippers）控制弹球的反弹方向。弹球从发射器射出后，在倾斜的弹球台上向下弹跳，碰到各种障碍物、目标、坡道和特殊机关。

核心操作只有两个：点击左侧屏幕控制左挡板，点击右侧屏幕控制右挡板。部分版本支持长按发射器控制发射力度。高级操作包括：在弹球落到挡板前轻晃手机改变弹球方向（Nudge），以及在特定情况下弹起挡板让球弹得更高（Slam Save）。

弹球台上的不同区域和机关对应不同分数。完成特定目标组合可以触发特殊模式（Multiball 多球模式、Wizard Mode 高级模式等），获得大量分数。

每局开始有 3-5 条命（ball），球掉入底部排水口就失去一条命。所有命用完游戏结束，总分即为成绩。

## 核心循环

发射弹球 → 用挡板控制弹球 → 击中目标获得分数 → 触发特殊模式 → 球掉落失去命 → 用完所有命后结算总分

## 核心机制

- **真实物理模拟**：基于真实弹球机的物理参数建模，包括重力、摩擦力、弹性系数、碰撞角度等，追求与实体弹球机一致的体验
- **多球模式（Multiball）**：触发后同时出现多个弹球，大幅增加游戏复杂度和刺激感
- **任务/目标系统**：每台弹球机有独特的任务链，完成一系列目标可以解锁高级模式
- **真实授权弹球机**：游戏中收录的都是历史上真实存在的经典弹球机，如 The Addams Family、Twilight Zone 等

## 为什么好玩

Pinball Arcade 的魅力在于它完美还原了街机弹球的经典体验。物理手感经过精细调校，挡板的响应、球的弹跳、机关的触发都尽可能接近真实弹球机。对于经历过街机时代的玩家，这是情怀满满的作品。对于年轻玩家，这种简单而纯粹的游戏机制本身就极具吸引力。

## 粘性来源

- **高分挑战**：每次游戏结束都能看到自己的分数，自然产生"刷新个人纪录"的动力
- **收集弹球机**：游戏内提供大量经典弹球机解锁，每台都有独特的布局和目标
- **物理手感的满足**：成功的多球操作和精准的挡板控制带来强烈的操作满足感
- **单局时长适中**：一局 5-10 分钟，适合碎片化时间

## Meta 系统

弹球机解锁系统。游戏采用"基础免费 + 付费解锁弹球机"的模式，玩家可以购买单台弹球机或打包购买。部分版本有每日挑战和在线排行榜。

## 实现难度

中。物理模拟是核心技术，需要精确建模弹球的运动轨迹、碰撞响应、摩擦力等参数。最大技术难点在于如何让数字版的手感接近真实弹球机——这需要大量的物理调校和玩家测试。
