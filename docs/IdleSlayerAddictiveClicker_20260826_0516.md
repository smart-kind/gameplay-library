# Idle Slayer: Addictive Clicker

- **类型**: 放置RPG / 点击冒险
- **平台**: Mobile (iOS)
- **开发商**: Pablo Leban
- **首次发布**: 2020
- **一句话描述**: Idle Slayer是一款由独立开发者制作的放置RPG游戏，全球超过1000万玩家。玩家控制英雄自动战斗、收集金币、升级技能，在无尽的冒险中不断变强。

## 玩法规则

游戏以横版自动滚动画面呈现，英雄角色自动向前移动并攻击沿途的怪物。屏幕上方显示金币、等级和进度信息。英雄自动战斗，无需手动操作，角色会持续攻击遇到的怪物，击杀怪物获得金币。金币用于升级英雄的攻击力、速度和解锁新技能，技能树庞大，包含数百种升级选项。游戏包含转生系统，达到一定进度后可以转生，保留部分加成重新开始，变得更强。支持离线进度：英雄在玩家不玩游戏时继续战斗和收集金币。跨平台云存档支持手机和PC之间的进度同步。

## 核心循环

英雄自动战斗 -> 收集金币 -> 升级技能和装备 -> 击败Boss -> 转生变强 -> 探索新世界 -> 重复

## 核心机制

- 自动战斗：英雄自动移动和攻击，玩家可以专注于升级决策
- 巨型技能树：700多种升级选项、650多种成就、200多个任务
- 转生系统：重置进度获取永久加成，指数级变强
- 随机迷你游戏：意外的挑战和奖励保持游戏新鲜感
- 跨平台云存档：手机和PC间无缝切换

## 为什么好玩

由独立开发者一人制作却有1000万加玩家，证明了游戏设计的优秀。自动战斗让玩家无需紧张操作，专注于策略性的升级决策。庞大的技能树提供了深度的自定义空间。

## 粘性来源

700多种升级选项提供极深的策略维度；转生系统让每次重新开始都更强；离线进度让每天回归都有收获；跨平台支持增加便利性

## Meta 系统

有转生系统（Ascension）、巨型技能树（700多种升级）、成就系统（650多种成就）、任务系统（200多个任务）、排行榜、跨平台云存档。27种语言支持。

## 实现难度

中。核心难点在于放置RPG玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
