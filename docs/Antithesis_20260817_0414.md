# Antithesis（Antithesis）

- **类型**: 物理益智 / 弹射
- **平台**: Mobile (iOS)
- **开发商**: Antithesis Design LLC
- **首次发布**: 2012
- **一句话描述**: 由Antithesis Design LLC开发的物理益智游戏，以物理模拟和弹射机制为核心玩法，利用真实物理引擎解决关卡难题

## 玩法规则

游戏画面展示一个2D物理模拟场景，包含各种形状和材质的物体。场景中散布着目标物体、障碍物和可利用的环境元素（斜坡、弹跳面、旋转平台等）。物理引擎实时计算重力、碰撞、摩擦和弹性。

操作方式主要是通过触屏选择发射点、设定发射角度和力度，然后发射物体。界面底部有一个力度条，拖动可以调整发射力度；角度通过滑动发射器来调节。发射后物体沿抛物线飞行，与其他物体碰撞时产生真实的物理反应。

每个关卡有明确的目标：可能是用有限次数的发射击倒所有目标物体（目标通常有特殊标记），或者让特定物体到达指定位置（例如将球推入球洞）。某些关卡中，目标物体被障碍物保护，需要先清除障碍。

场景中的物理元素包括：弹簧（弹射物体）、传送带（水平移动物体）、风扇（产生风力影响飞行轨迹）、磁铁（吸引或排斥金属物体）。这些元素的组合使用是解决复杂关卡的关键。

玩家需要理解不同物体的物理属性（重量、弹性、摩擦力）以及它们之间的相互作用。重物体难以推动但惯性大，轻物体容易被推动但也容易被弹飞。通过反复尝试，玩家可以找到最优的发射角度和力度组合。

游戏结束条件：在规定的发射次数内完成目标即过关；如果次数用完仍未达成目标，则挑战失败，需要重新开始。部分关卡还设有时间限制。

## 核心循环

完成关卡或日常任务 → 获得评分、经验或游戏货币 → 升级角色能力或解锁新内容 → 挑战更高难度的关卡或模式

## 核心机制

- **渐进难度设计**：关卡难度从简单到复杂逐步递增，每个新关卡引入1-2个新机制或变化，确保玩家在适应当前难度的同时学习新玩法。
- **即时反馈系统**：每次操作后系统立即给出视觉和音效反馈（命中特效、得分弹出、连击计数），强化操作的成就感和爽快感。
- **资源约束机制**：玩家的操作次数、时间或生命值有限，需要在约束条件下做出最优决策，增加了策略深度。
- **评价与重玩驱动**：1-3星评级系统鼓励玩家在通关后反复挑战以获得更高评价。

## 为什么好玩

这款游戏通过简洁直观的操作方式和逐步提升的难度曲线，让玩家在每次尝试中都能获得明确的进步感。关卡设计的多样性确保了长时间游玩不会感到重复乏味，而即时反馈系统则让每次操作都充满满足感。

## 粘性来源

具体到机制层面：1) 1-3星评分系统激发"再试一次拿到三星"的心理驱动力——玩家往往在2星时感到"差一点就完美"，这种不甘心是推动重复游玩的核心力量；2) 关卡逐步解锁的设计制造了持续的目标感和期待感；3) 排行榜或成就系统引入了社交竞争元素，让玩家与他人的成绩比较。

## Meta 系统

无核心外围成长系统。游戏以关卡通关和评分提升为主要进度驱动，可能包含基础的道具购买、角色解锁或外观收集机制。
