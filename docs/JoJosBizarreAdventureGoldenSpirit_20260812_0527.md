# JOJO的奇妙冒险：黄金之魂（JoJo's Bizarre Adventure: Golden Spirit）

- **类型**: 动作/格斗
- **平台**: Mobile (iOS+Android)
- **开发商**: Bandai Namco
- **首次发布**: 2026
- **一句话描述**: 基于《JOJO的奇妙冒险》系列的手机动作格斗游戏。

## 玩法规则

以 JOJO 系列角色为主角的动作格斗游戏，玩家可选择不同角色进行对战。每个角色拥有独特的替身能力（Stand），战斗系统融合了格斗游戏的连招系统和 JOJO 特色的替身战斗机制。

战斗场景包含场景互动要素，部分战斗包含剧情演出。角色技能还原了原作中的经典招式和替身能力。

## 核心循环

选择角色 → 进行战斗 → 使用连招和替身能力 → 赢得胜利 → 解锁新角色和招式

## 核心机制

- 替身系统：每个角色有独特的替身能力，改变战斗风格
- 连招系统：格斗游戏式的连续技，需要精确的按键时机
- 剧情模式：跟随原作故事线的单人战役

## 替身能力系统详解

每个角色的替身能力在战斗中提供独特机制：有的改变战斗场地，有的创造分身，有的操控时间。这些能力不仅仅是攻击技能，还会影响整个战斗流程。

替身能力有冷却时间管理，需要在关键时刻使用。部分替身可以切换形态，适应不同战斗场景。

## 为什么好玩

JOJO 粉丝可以在手机上体验操控喜爱角色的快感，替身能力的视觉表现和战斗系统还原了原作风格。

## 粘性来源

角色收集、连招精通和剧情模式推进。

## Meta 系统

中等 — 格斗游戏需要练习连招和时机
