# Realm Grinder

- **类型**: 放置 / 策略
- **平台**: PC / Mobile
- **开发商**: Divine Games
- **首次发布**: 2015
- **一句话描述**: 深度放置策略游戏——选择阵营、升级设施、征服王国。

## 玩法规则

玩家选择一个阵营（精灵、人类、恶魔等），每个阵营有独特的升级路径和玩法风格。核心是设施升级和征服——建造建筑、升级设施、征服新领土。

转生系统（Reincarnation）允许重置进度以获得永久加成，大幅增加后期游戏深度。数十种阵营和数百种升级选项确保数百小时的游戏内容。

## 核心循环

选择阵营 → 建造升级 → 征服领土 → 转生重置

## 核心机制

- 阵营系统：每个阵营独特玩法
- 设施升级：建造和升级建筑
- 征服系统：扩张领土
- 转生系统：重置获得永久加成
- 深度策略：数百种升级选项

## 为什么好玩

阵营选择和转生系统创造的深度远超一般放置游戏。每个阵营都有完全不同的策略和玩法。

## 粘性来源

- 阵营多样性：每个阵营完全不同的体验
- 转生深度：重置后更强的满足感
- 策略复杂度：数百种升级的组合
- 长期目标：数百小时的内容

## Meta 系统

转生和阵营解锁。通过转生获得永久加成，解锁新阵营和升级选项。

## 实现难度

低。数值计算和 UI 设计是主要工作，核心循环简单。
