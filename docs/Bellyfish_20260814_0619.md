# Bellyfish

- **类型**: 解谜 / 叙事
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款以海洋为背景的叙事解谜游戏，玩家通过探索水下世界解开故事谜题

## 玩法规则

游戏呈现一个2D水下场景，玩家控制一条小鱼在海洋中自由探索。水下环境有浮游生物、水草、珊瑚礁等装饰。

通过触摸屏幕移动小鱼到不同区域。每个区域包含故事片段（以文字或插画形式）或环境谜题。

谜题类型包括：寻找隐藏物品（在场景中找到特定物体）、解开环境机关（按照特定顺序激活元素）、跟随洋流到达隐藏区域等。解开谜题后推进故事。

故事围绕海洋生物和环境主题展开，以碎片化叙事方式呈现。玩家需要将不同区域获得的故事片段拼凑出完整故事。部分故事线有分支选择。

游戏设有隐藏区域，通过特定条件解锁。隐藏区域中有额外的故事片段和独特的海洋生物。

## 核心循环

探索水下区域 → 解开谜题 → 收集故事片段推进叙事

## 核心机制

- **环境解谜**：利用水下环境元素（水流、气泡、光影）解决谜题
- **碎片叙事**：故事分散在不同区域，需要主动探索收集
- **探索驱动**：自由探索而非线性推进

- **隐藏区域**：特殊条件解锁的额外内容


## 为什么好玩

水下世界的宁静氛围配合碎片化叙事，带来沉浸式的探索体验。

## 粘性来源

故事驱动的探索粘性：想知道'接下来发生了什么'驱动继续探索。

## Meta 系统

无。纯叙事解谜。

## 实现难度

低 — 操作简单。最大技术难点是水下氛围的视觉呈现。
