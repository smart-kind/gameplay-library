# 愤怒的小鸟：进化（Angry Birds Evolution）

- **类型**: 弹射 RPG / 收集
- **平台**: Mobile (iOS+Android)
- **开发商**: Rovio Entertainment
- **首次发布**: 2017
- **一句话描述**: 愤怒的小鸟RPG化，弹射攻击+角色养成+队伍组合的混合玩法

## 玩法规则

游戏融合了愤怒小鸟经典的弹弓射击和RPG养成元素。玩家组建一支小鸟队伍，每只鸟有不同的职业（战士、法师、治疗者、坦克）和特殊技能。

战斗中，玩家用弹弓瞄准并射出小鸟攻击猪猪军团。弹射角度和力度由玩家手动控制，命中后造成物理伤害并可能触发特殊技能。

每只小鸟可以升级、进化、装备饰品。通过收集材料、金币和经验值来提升队伍实力。

游戏包含PvE关卡、Boss战、PvP竞技场等多种模式。不同队伍组合和战术搭配是策略核心。

## 核心循环

弹射攻击 → 消灭敌人 → 获得经验/金币 → 升级进化小鸟 → 挑战更强关卡

## 核心机制

- 弹射物理+RPG数值融合：传统愤怒小鸟的纯物理伤害叠加了角色等级、装备、技能的数值加成。
- 职业搭配系统：战士/法师/治疗者/坦克的组合要求玩家根据敌人类型调整队伍构成。
- 收集养成循环：抽取/解锁新小鸟、升级、进化、装备饰品，提供了长线目标。

## 为什么好玩

愤怒小鸟经典弹射手感+RPG养成的长线目标。每次弹射命中时的物理爽感和养成带来的数值成就感叠加。

## 粘性来源

收集欲（解锁新小鸟） + 数值成长（升级进化） + PvP竞争（排行榜）三重粘性叠加。

## Meta 系统

完整的RPG养成Meta：小鸟等级/进化/装备/技能升级。赛季活动提供限时内容。金币/钻石双货币系统。

## 实现难度

高。弹射物理 + RPG数值系统 + 技能系统 + 多模式（PvE/PvP）。最大技术难点：物理伤害和数值伤害的平衡融合，不让任何一方失效。
