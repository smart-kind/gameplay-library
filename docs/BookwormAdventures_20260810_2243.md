# 拼字+RPG，用字母拼词攻击敌人（Bookworm Adventures）

- **类型**: 解谜/角色扮演
- **平台**: PC / Mobile
- **开发商**: PopCap Games
- **首次发布**: 2006
- **一句话描述**: 拼字+RPG，用字母拼词攻击敌人

## 玩法规则

玩家在6×10的字母网格中选择相邻字母拼成单词。拼出的单词越长、越稀有，造成的伤害越高。

敌人也有攻击力，玩家需要一边攻击一边防御。击败敌人获得宝石，可以镶嵌在装备上获得额外能力。

游戏有多个章节，每个章节有不同主题的敌人和Boss。

## 核心循环

从网格选字母拼词 → 攻击敌人 → 获得宝石 → 升级装备 → 下一章

## 核心机制

- 拼字攻击：单词长度和稀有度决定伤害
- 宝石系统：击败敌人获得宝石，装备获得能力
- HP系统：敌人也会攻击，需要平衡攻击和防御
- 章节进度：不同主题和Boss

## 为什么好玩

拼字游戏和RPG的巧妙结合，词汇量大的人有天然优势。

## 粘性来源

词汇挑战和宝石收集。

## Meta 系统

宝石装备+章节进度。

## 实现难度

中。需要词汇量和策略。最大技术难点：词库和平衡性。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
