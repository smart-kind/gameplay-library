# 飞贼钩索（Hooky Crook）

- **类型**: 街机动作 / 物理摆荡
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发
- **首次发布**: 2019
- **一句话描述**: 扮演飞贼利用钩索在关卡中摆荡前进，躲避激光陷阱，到达终点的绿色宝石。

## 玩法规则

玩家扮演一个需要偷取绿色宝石的飞贼。每个关卡底部都有粉红色激光陷阱，碰到就会触发警报并回到关卡起点。关卡中有多个钩索点，玩家需要利用这些钩索摆荡前进。

核心操作是点击钩索点进行摆荡——钩索点只能使用一次，松手后就会消失。玩家不能停下来思考太久，因为激光陷阱就在下方。除了钩索，关卡中还有阻挡去路的平台和弹跳表面等障碍物。

关卡设计精巧，通常只需要几步就能到达终点，但每一步都需要正确选择。有时抓住所有钩索反而会错过宝石，玩家需要规划最优路径。关卡很短，失败后可以立即重试。

游戏的关键在于让玩家在有限的操作中选择正确的路径。虽然每关只有三四步操作，但让玩家可以尝试不同的组合。有时抓住所有钩索反而是错误的，需要学会结合不同的移动方式和可能性。

## 核心循环

观察关卡 → 规划摆荡路径 → 执行摆荡 → 到达宝石/失败重试

## 核心机制

- **一次性钩索**: 每个钩索点只能使用一次，松手即消失，需要谨慎选择使用时机
- **激光陷阱**: 关卡底部的激光增加紧迫感，碰到就回到起点，不能犹豫
- **路径规划**: 有限的几步操作中找到正确的路径到达终点，不是抓住所有钩索就对了
- **障碍物系统**: 平台和弹跳表面增加路径规划的复杂度，需要灵活应对
- **短关卡设计**: 每关只需几步，失败重试成本极低，鼓励不断尝试

## 为什么好玩

Hooky Crook 的精髓在于"小关卡大选择"——虽然每关只有几步操作，但选择正确路径需要思考。摆荡的物理手感很好，成功通过关卡时的成就感很强。短关卡设计让人"再来一次"毫无压力。

## 粘性来源

主要来自关卡挑战的满足感和物理摆荡的爽快感。"差一点就成功"的感觉让人忍不住重试。短关卡意味着随时可以来一把，碎片化体验极佳。逐渐解锁的新障碍类型保持游戏新鲜感。

## Meta 系统

无。游戏为纯关卡体验驱动，没有外围成长系统。

## 实现难度

中。核心是物理摆荡系统和钩索机制的实现，需要流畅的物理模拟和精确的碰撞检测。最大难点是让摆荡手感自然且响应灵敏，同时确保关卡设计既有趣又不会过于困难。
