# 懒惰突袭者（Lazy Raiders）

- **类型**: 物理解谜 / 平台
- **平台**: Xbox Live Arcade / Mobile (iOS+Android)
- **开发商**: Sarbakan
- **首次发布**: 2010
- **一句话描述**: 通过触屏拖拽操作，帮助一支笨拙的探险小队利用绳索和物理惯性在古墓和遗迹中穿梭

## 玩法规则

游戏画面呈现一个2D横版场景，包含平台、陷阱、障碍物和可收集物品。玩家扮演一支探险小队，通过拖拽屏幕上的绳索来操控角色的移动和摆动。

核心操作是拖拽绳索：玩家点击一个固定点，拉出绳索连接到角色身上，角色会像钟摆一样摆动。通过控制绳索的释放时机，让角色飞跃间隙、避开陷阱、抓住远处的固定点。游戏利用物理引擎模拟摆锤运动——绳索长度、摆动角度和释放时机决定了角色飞行的轨迹和距离。

每个关卡的目标是让小队的成员安全到达终点。关卡中散布着金币、宝石等收集品。陷阱包括尖刺、落石、深坑等障碍物，碰到即需重新尝试。

## 核心循环

拖拽绳索摆荡 → 利用惯性飞跃 → 收集物品 → 到达终点 → 解锁新关卡

## 核心机制

- **绳索摆锤机制**：玩家通过触屏拖拽创建绳索，角色以固定点为圆心摆动。绳索的固定点可以是场景中的任何稳固物体。摆动遵循真实物理规律，需要掌握节奏和释放时机。
- **惯性跳跃系统**：在摆动到最高点时释放绳索，角色会沿切线方向飞出。飞行距离取决于摆动速度和释放角度，需要精确计算。
- **小队成员管理**：部分关卡涉及多个角色，可能需要分别操控或协调行动，增加了解谜的复杂度。
- **环境互动**：场景中的弹簧、弹板、风扇等辅助工具可以与绳索系统配合，创造更复杂的过关路径。

## 为什么好玩

摆锤操控的"手感"极佳——一旦掌握节奏，连续摆荡飞越的感觉非常流畅和爽快。物理解谜带来的"顿悟时刻"让人上瘾：看似不可能的间隙，找到正确的摆动路线后轻松通过。关卡设计巧妙，每个新关卡都引入新的物理互动元素。

## 粘性来源

物理解谜的"差一点"效应——只差几厘米就能碰到下一个固定点，这种不甘心驱使反复尝试。收集品分布在难以到达的位置，为已通关关卡提供重玩动力。关卡逐步从简单摆荡演变为复杂的多段物理连锁反应，技能成长感明显。

## Meta 系统

无传统Meta成长系统。游戏通过关卡解锁和收集要素（金币、宝石）提供长线目标。

## 实现难度

中。核心需要实现2D物理引擎（摆锤运动、惯性投射）和精确的碰撞检测。最大技术难点在于让物理模拟既真实又可预测——玩家需要能够"学会"物理规律并据此制定策略，而不是感到随机和不可控。
