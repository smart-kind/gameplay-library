# 1000 Tiny Claws

- **类型**: 动作休闲 / 击退敌人
- **平台**: Mobile (PSP / iOS)
- **开发商**: Mediatonic
- **首次发布**: 2011
- **一句话描述**: 扮演海盗在悬浮小岛上用剑击退昆虫入侵的快节奏动作游戏

## 玩法规则

在1000 Tiny Claws中，玩家扮演一名海盗，站在一个悬浮在空中的小岛上。成群的昆虫从四面八方涌来，企图占领小岛。玩家用剑将它们一一击落。

游戏采用俯视视角，小岛位于屏幕中央。昆虫从各个方向向小岛爬来，玩家需要快速判断威胁方向并挥剑击退它们。挥剑操作通过触屏滑动或按钮点击实现，可以控制挥剑的方向和力度。

游戏的核心挑战在于同时应对多个方向的敌人——随着波次推进，昆虫的数量和种类会增加。有些昆虫有坚硬的外壳需要多次攻击，有些会飞跃障碍直接攻击小岛中心，有些则成群结队地从同一方向涌来。

玩家需要保护小岛不被昆虫占领——当足够多的昆虫到达小岛中心时，游戏结束。

## 核心循环

挥剑击退昆虫 → 清除波次获得分数 → 下一波更多昆虫 → 坚持更久获得更高分

## 核心机制

- **方向性挥剑**: 玩家控制挥剑的方向来击退特定方位的昆虫，需要快速判断威胁优先级
- **波次递增**: 每波昆虫数量和种类递增，难度曲线自然上升
- **昆虫多样性**: 不同类型昆虫有不同特性（硬壳、飞行、群聚），增加策略深度
- **连击系统**: 连续击退昆虫获得连击加分，鼓励流畅的挥剑节奏

## 为什么好玩

1000 Tiny Claws的乐趣在于纯粹的动作快感——快速挥剑击退一波又一波昆虫的满足感。游戏的卡通美术风格和滑稽的昆虫设计让紧张的战斗也变得有趣。

## 粘性来源

粘性来自高分挑战和连击系统的追求。每次游戏结束你都知道自己“可以做得更好”——连击断了一次、漏了一只昆虫。

## Meta 系统

无复杂外围系统。有分数排行榜和成就系统。

## 实现难度

低 — 最大的技术难点在于流畅的剑挥动画和大量敌人同时存在时的性能优化。
