# 无尽漫游（Endless Wander - Roguelike RPG）

- **类型**: Roguelike RPG / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: First Pick Studios
- **首次发布**: 2023
- **一句话描述**: 像素风离线Roguelike RPG，通过武器能力和魔法符文组合打造最优构建

## 玩法规则

故事背景是一个被封印多年的神秘传送门重新开启，主角 Novu 必须进入传送门拯救被困在里面的妹妹，并重建漫游者公会。

游戏采用像素艺术风格的离线 Roguelike RPG 玩法。玩家在一个随机生成的地下城中探索，每个房间都有敌人、宝箱或特殊事件。战斗是实时动作制——玩家控制角色移动、攻击、释放技能。

核心 Build 系统是：收集不同的武器能力（每种武器有独特的攻击模式）和魔法符文（提供各种增益效果），将它们组合成最优的 Build。不同的能力之间有协同效应，好的组合可以产生强大的连锁反应。

游戏中有多个独特角色可以解锁，每个角色有不同的初始能力和成长方向。角色之间的差异不仅是数值上的，更是玩法风格上的——有的适合近战猛攻，有的适合远程风筝，有的适合召唤流。

## 核心循环

探索随机房间 → 战斗获得能力和符文 → 组合Build → 挑战Boss → 死亡后重新开始

## 核心机制

- **武器能力+符文组合**：玩家收集不同武器的攻击能力和魔法符文效果，自由组合成独特Build，协同效应产生超出单个能力之和的效果。比如火焰武器+符文可以产生爆炸效果，闪电武器+符文可以连锁攻击多个敌人
- **多角色系统**：解锁多个独特角色，每个角色有不同的初始能力和成长方向，鼓励重复游玩体验不同风格。每个角色的战斗节奏和策略完全不同
- **离线可玩**：不需要网络连接即可完整游玩，适合随时随地的碎片化游戏。这是独立游戏相比网游的一大优势


## 为什么好玩

Endless Wander 的乐趣在于发现完美的 Build 组合——当你找到武器能力和符文之间隐藏的协同效应时，那种'我变强了！'的成就感无与伦比。像素风也带来了复古的独立游戏味道。

## 粘性来源

Build 发现的惊喜感 + 多角色的重复游玩价值 + 像素艺术的美学吸引力

## Meta 系统

角色解锁 + 能力/符文收集 + Build 图鉴 + 成就系统

## 实现难度

中 — 随机房间生成+实时战斗+Build 平衡，最大难点是确保不同 Build 之间有足够的差异化且没有绝对最优解
