# 神庙逃亡2（Temple Run 2）

- **类型**: 跑酷 / 动作 / 无尽
- **平台**: Mobile (iOS+Android)
- **开发商**: Imangi Studios
- **首次发布**: 2013
- **一句话描述**: 在弯曲的神庙道路上疯狂奔跑、跳跃、滑铲躲避障碍的经典跑酷游戏。

## 玩法规则

游戏以第三人称视角呈现，角色在一条不断延伸的神庙道路上向前奔跑。道路会有转弯（左转、右转）、上坡、下坡等变化。道路上散布着各种障碍物：树根需要跳跃越过，火堆需要滑铲通过，断崖需要跳跃跨越。

道路两侧有金币排列成不同的路径，有些在高处需要跳跃收集，有些在低处需要滑铲时收集。道路上还会出现磁铁道具（自动吸附附近金币）、加速道具（短时间内加速飞行）和护盾道具（抵挡一次碰撞）。

玩家通过四种操作控制角色：
- **向上滑动**：跳跃（越过障碍或跳上高处道路）
- **向下滑动**：滑铲（从低矮障碍下方通过）
- **向左滑动**：左移（切换到左侧道路）
- **向右滑动**：右移（切换到右侧道路）

游戏的目标是跑得越远越好。速度会随着奔跑距离逐渐增加，后期反应时间越来越短。碰撞到障碍物或掉入悬崖，游戏结束。

## 核心循环

奔跑躲避障碍 → 收集金币和道具 → 速度逐渐加快 → 直到失误结束

## 核心机制

- **三轨跑酷**：道路有三条轨道（左中右），通过滑动切换。转弯时必须在正确方向滑动，否则撞墙
- **四种动作**：跳跃、滑铲、左移、右移，覆盖所有跑酷需求
- **渐进加速**：随着距离增加，奔跑速度持续加快，难度自然上升
- **道具系统**：磁铁、加速、护盾等道具为每局游戏增加变数
- **转弯机制**：道路会随机转弯，玩家必须及时滑向转弯方向

## 为什么好玩

Temple Run 2 的核心体验是"在失控边缘保持控制"的紧张感。随着速度越来越快，玩家的反应时间被压缩到极限，但同时又觉得"我还能再跑一段"。这种在失控和掌控之间的张力让每局游戏都令人肾上腺素飙升。

## 粘性来源

1. **渐进加速**——速度越来越快，玩家总想挑战"我能跑多快"的极限
2. **道具变数**——每局拾取到的道具不同，带来不同的策略（加速冲刺 vs 收集金币）
3. **分数排行榜**——全球和好友排行榜激发竞争心理
4. **角色解锁**——用金币解锁新角色和升级能力，提供长期目标

## Meta 系统

金币可用于：
- 解锁新角色（不同外观，部分有特殊能力加成）
- 升级道具效果（磁铁持续时间更长、加速距离更远、护盾可多次触发）
- 购买分数加成（开局携带额外分数倍率）
这些升级不影响核心操作，但让玩家有明确的成长感。

## 实现难度

中。核心技术是 3D 跑酷的轨道生成和碰撞检测。道路需要随机生成但有合理的障碍间距。最大技术难点是转弯时的平滑过渡和碰撞判定的公平性——玩家需要在高速中仍然感到控制是精准的。
