# Squad Alpha - Action Shooting

- **类型**: 俯视角射击 / 动作休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: SayGames LTD
- **首次发布**: 2021-07-20
- **一句话描述**: 俯视角动作射击游戏，闪避跑位+自动射击，升级武器完成无尽关卡

## 玩法规则

Squad Alpha 是一款俯视角射击游戏。玩家在屏幕上看到一个角色（特工）和周围不断涌来的敌人。角色会自动向最近的敌人射击，玩家的主要操作是控制角色移动——在屏幕上拖拽角色进行走位，躲避敌人的子弹和攻击。

每关有明确的敌人波次和目标。完成关卡后获得金币和奖励，用来升级武器（更强的火力、更快的射速、特殊弹道）和装备（护甲、技能）。随着进度推进，敌人种类增多、密度增大、攻击模式更复杂，需要更好的走位策略。

UI布局：屏幕中央是玩家角色，周围是敌人和障碍物。屏幕底部可能有武器切换和特殊技能按钮。顶部显示当前关卡进度和生命值。

## 核心循环

操控走位+自动射击 → 完成关卡 → 获得奖励 → 升级武器/装备 → 挑战更难的关卡

## 核心机制

- **走位即策略**：自动射击简化了操作，把策略重心转移到移动上。玩家需要在躲避弹幕的同时保持对敌人的火力压制，这种"移动射击"的体验类似 bullet hell 但门槛更低。
- **武器升级系统**：不同武器有独特的攻击模式（扇形散射、穿透弹、追踪弹等），升级路线多样，玩家可以根据自己的风格选择。
- **关卡渐进难度**：敌人波次逐步增加复杂度，从单一类型的慢速敌人到多种敌人组合攻击，难度曲线平滑但持续有挑战。

## 为什么好玩

Squad Alpha 在"无脑爽快"和"需要思考"之间找到了很好的平衡。自动射击让你不用操心瞄准，专注于躲闪和走位带来的紧张感。升级武器后的火力质变（从单发变散射、从普通变穿透）带来强烈的成长反馈。

## 粘性来源

具体到机制层面：武器升级的数值成长让人想继续刷资源；"差一点就通关"的不甘心驱动再来一局；新武器解锁带来的玩法变化（不同武器的攻击节奏完全不同）保持新鲜感。

## Meta 系统

武器升级和装备系统是核心外围成长。玩家通过关卡获得的金币和钻石升级武器属性（伤害、射速、弹道类型）和角色属性（生命、护甲）。这些升级直接影响核心玩法的效率和生存能力。

## 实现难度

中 — 需要处理大量弹幕的物理计算、碰撞检测、敌人AI和关卡设计。最大的技术难点是在低端设备上保持流畅的帧率同时渲染大量弹幕和敌人。

武器的多样性是游戏的核心吸引力之一。初始武器是基础手枪，随着进度可以解锁冲锋枪（高射速低伤害）、霰弹枪（扇形散射）、狙击枪（穿透弹）、激光枪（持续伤害）等。每种武器有独特的操作手感和适用场景。

敌人种类也随关卡增加：基础的近战敌人、远程射击敌人、会冲锋的重甲敌人、会分身的特殊敌人、以及每关末尾的 Boss 敌人。不同敌人组合产生了丰富的战术变化。

特殊技能系统提供主动能力——如短暂隐身、范围爆炸、时间减缓等。这些技能有冷却时间限制，需要在关键时刻使用。技能的选择和升级路线进一步丰富了游戏的策略深度。
