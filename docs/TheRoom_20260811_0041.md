# The Room

- **类型**: 解谜
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Fireproof Games
- **首次发布**: 2012
- **一句话描述**: 第一人称 3D 解谜游戏，玩家通过旋转、观察和操作各种精巧的机关盒来推进故事。

## 玩法规则

游戏的核心体验围绕机关盒展开，一个又一个精巧的多层盒子，每层都隐藏着开启下一层的秘密。

操作完全基于触屏手势：
- **旋转** — 用手指拖动盒子 360 度旋转，从不同角度观察
- **滑动/推拉** — 拉开抽屉、滑动面板、推开隐藏的隔层
- **点击/长按** — 按下按钮、旋转钥匙、操作开关
- **放大** — 双指放大观察细节，发现隐藏的文字、符号和机关

每个机关盒都有多个锁和机关，需要按正确顺序解开。解谜的关键在于仔细观察，注意文字提示、符号图案、缝隙和凸起等细节。

目镜是一个关键道具：通过目镜可以看到肉眼不可见的符号和线索，这是推进谜题的核心工具。

游戏有故事线：一位神秘工匠留下了这些机关盒，玩家通过解开盒子逐渐了解背后的故事。

## 核心循环

观察盒子 -> 发现线索 -> 解开机关 -> 进入下一层 -> 发现更大的谜题

## 核心机制

- 多层嵌套谜题 — 每个盒子内部还有盒子，层层递进的结构带来持续的惊喜
- 触觉交互反馈 — 机关操作有真实的机械感反馈（滑动声、咔嗒声、震动），增强沉浸感
- 目镜透视系统 — 通过特殊视角发现隐藏线索，是解谜的核心机制

## 为什么好玩

机关盒设计的精巧程度令人惊叹，每个机关都让人觉得设计太妙了。完全依靠物理交互的解谜方式，没有任何文字提示或箭头引导，纯靠观察力和逻辑推理。

## 粘性来源

系列有四部作品（The Room、The Room Two、The Room Three、Old Sins），每部都有多个章节和多个大型机关盒。想看看下一个盒子有多精巧的好奇心是主要驱动力。

## Meta 系统

无 — 纯线性解谜体验，没有成长系统。系列续作提供更多内容。

## 实现难度

中等 — 谜题设计精巧但线索足够，大多数玩家通过仔细观察都能解开。最大技术难点在于 3D 交互的自然流畅性和机关设计的创意密度。
