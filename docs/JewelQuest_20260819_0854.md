# Jewel Quest

- **类型**: 三消 / 益智
- **平台**: Mobile (iOS+Android) / PC / DS / Xbox 360
- **开发商**: iWin
- **首次发布**: 2004
- **一句话描述**: 玩家交换相邻宝石，三个或更多相同宝石连成一线时消除，目标是清除棋盘上所有宝石

## 玩法规则

游戏画面是一个8x8或类似的方格棋盘，上面随机排列着不同颜色的宝石。游戏目标通常是消除棋盘上所有宝石或达到特定分数。

玩家操作：
- 交换：选择相邻的两个宝石，交换它们的位置
- 匹配：交换后如果三个或更多相同颜色的宝石连成一线（横或竖），这些宝石被消除
- 填补：消除后上方的宝石下落，新的宝石从顶部补充

游戏目标：每关有特定目标，如达到分数、消除特定宝石、或清除棋盘。

特殊机制：
- 连锁反应：一次交换可能触发多组消除，连锁消除分数更高
- 特殊宝石：四个或五个宝石连成线时产生特殊宝石（炸弹、彩虹球等）
- 关卡障碍：某些版本有石头、冰块等障碍物需要消除

游戏结束条件：
- 达到目标则过关
- 移动次数用完未达到目标则失败

## 核心循环

交换宝石 → 匹配消除 → 获得分数或进度 → 达到目标过关

## 核心机制

- **三消核心**: 交换相邻宝石使三个或更多同色宝石连成一线，最基础的消除机制但变化无穷
- **连锁消除**: 一次交换触发多组消除，连锁分数递增，鼓励玩家寻找最优解
- **棋盘填充**: 消除后宝石自动下落补充，新宝石的随机性带来不确定性
- **目标驱动**: 每关有明确目标（分数、特定消除次数等），提供清晰的进度反馈

## 为什么好玩

找到完美交换位置时的顿悟感很强。连锁消除的视觉效果和分数增长带来即时正反馈。解谜元素（在有限步数内找到最优解）增加思考深度。

## 粘性来源

关卡递进（目标更难、障碍更多）和完美通关是主要粘性。特殊宝石的收集和使用增加策略深度。

## Meta 系统

通常无外围成长系统。部分版本有道具商店或生命值系统。

## 实现难度

低。核心是匹配算法和棋盘状态管理。难点在于确保每关有解（死锁检测）和难度曲线设计。
