# 2048（2048）

- **类型**: 数字拼图 / 逻辑推理
- **平台**: Web / Mobile (iOS+Android)
- **开发商**: Gabriele Cirulli
- **首次发布**: 2014
- **一句话描述**: 在4×4网格中滑动合并相同数字，目标是拼出2048

## 玩法规则

游戏在一个4×4的方格网格中进行。初始时网格中有两个数字（通常是2或4）。玩家通过上下左右四个方向滑动，所有数字方格会沿滑动方向移动到最远可能的位置。

当两个相同数字的方格碰撞时，它们合并成一个数字是两者之和的新方格（2+2=4，4+4=8，依此类推）。每次滑动后，系统在空白位置随机生成一个新的2或4。

如果网格被填满且没有任何相邻的相同数字可以合并，游戏结束。主要目标是达到2048这个方格，但玩家可以继续挑战更大的数字。

每次合并成功时，新方格的数字会加到得分中。得分越高说明操作越优。

## 核心循环

滑动合并数字 → 新数字出现 → 继续合并到2048 → 挑战更高数字或重新开始

## 核心机制

- **滑动+合并**: 极简操作但蕴含深层策略——每次滑动不仅合并数字，还改变了整个棋局的布局
- **随机生成**: 每次滑动后新数字的随机位置增加了不确定性，玩家需要灵活调整策略
- **空间管理**: 核心挑战是保持网格有足够空间，避免过早填满。高手通常将最大数字固定在一个角落
- **连锁反应潜力**: 一次好的滑动可能同时触发多个合并，产生"combo"般的爽快感

## 为什么好玩

2048用最简单的规则创造了最纯粹的策略体验。没有道具、没有时间限制、没有花哨的画面——只有数字、网格和决策。每局只需几分钟，但策略深度远超预期。

## 粘性来源

"差一个就合成"的不甘心和"终于合成2048"的成就感形成了强烈的重试驱动。每次游戏只需要几分钟，非常适合碎片时间。排行榜竞争（最高分/最大数字）提供了额外的长期目标。

## Meta 系统

无。纯分数驱动，目标是达到2048并追求更高分数。

## 实现难度

低 — 核心逻辑只需处理4×4矩阵的滑动合并和随机数生成。算法复杂度低，最大技术难点可能是确保随机生成的公平性和动画的流畅性。UI只需简单的网格渲染。
