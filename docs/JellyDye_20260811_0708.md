# Jelly Dye（Jelly Dye）

- **类型**: 休闲 / 益智 / ASMR
- **平台**: Mobile (iOS+Android)
- **开发商**: Good Job Games
- **首次发布**: 2021
- **一句话描述**: 将彩色液体注入透明果冻中，用颜色填满关卡

## 玩法规则

画面中央有一个透明的果冻状物体（形状多样，从简单的球体到复杂的动物、物体形状）。屏幕底部有几种不同颜色的注射器，每种注射器装有不同颜色的液体。

玩家通过拖拽操作将颜色注入果冻：按住屏幕选择颜色，然后在果冻上滑动绘制。颜色在透明果冻内部扩散，形成美丽的色彩效果。

每个关卡有不同的目标——有些要求用特定颜色填满特定区域，有些要求混合颜色创造特定色调，有些只是自由填色。颜色注入后会逐渐扩散，不同的颜色相遇会产生混合效果。

游戏没有失败条件，主要是放松和满足感的体验。完成关卡后进入下一关。

## 核心循环

选择颜色 → 注入果冻 → 颜色扩散填满 → 完成关卡

## 核心机制

- **颜色注入与扩散**: 颜色在透明果冻内部的扩散效果是核心视觉体验。颜色相遇时自然混合，创造出美丽的渐变效果。
- **自由创作**: 除了关卡目标，玩家也可以随意尝试不同颜色组合，纯粹为了美感而玩。
- **3D透明材质**: 果冻的透明质感和颜色的半透明叠加，创造出独特的视觉效果。
- **ASMR体验**: 颜色注入时的"咻咻"声和扩散时的缓慢动画，具有放松和解压效果。

## 为什么好玩

看着颜色在透明果冻中扩散、混合、填满空间的过程本身就是一种视觉享受。不需要紧张或快速反应，是一种纯粹的放松体验。

## 粘性来源

- **视觉满足感**: 颜色扩散填满空间的过程有极强的视觉满足感
- **无压力体验**: 没有失败条件，随时可以放下手机
- **创意自由**: 除了关卡目标，可以自由尝试颜色组合
- **收集新形状**: 每关有不同的果冻形状，保持好奇心

## Meta 系统

关卡推进系统——完成关卡解锁新形状和新颜色组合。无额外消耗系统。

## 实现难度

低到中。核心是3D渲染 + 颜色扩散模拟 + 触控输入。最大难点在于颜色扩散算法——需要既美观又性能高效。
