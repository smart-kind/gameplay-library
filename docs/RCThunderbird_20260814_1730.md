# 遥控雷鸟（RCThunderbird）

- **类型**: 竞速飞行
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer 收录独立游戏
- **首次发布**: 2013
- **一句话描述**: 一款遥控飞机竞速游戏，在多样化的赛道上操控遥控飞机争夺冠军

## 玩法规则

游戏采用第三人称追尾视角或俯视视角，画面呈现精致的3D或2.5D赛道环境。赛道设计多样，包括城市公园、山区峡谷、海滩码头、室内场馆等。

操控方式：
- 虚拟摇杆：控制飞机的飞行方向（左转/右转/上升/下降）
- 油门控制：滑动屏幕调整飞行速度，油门过大容易失控，过小则速度不够
- 特技操作：部分版本支持翻滚、桶滚等特技动作，完成特技可获得加速奖励

赛道上设置多个检查点，玩家必须按顺序通过所有检查点才能完成比赛。赛道中还有各种障碍物：树木、建筑、桥梁、气球等，碰撞会减速甚至坠毁。

比赛模式包括：
- 计时赛：独自完成赛道，追求最快圈速
- 竞速赛：与AI对手或多个玩家同场竞技，争夺名次
- 挑战赛：在限定条件下完成特殊目标（如不使用加速、收集所有金币等）

不同飞机有不同的飞行特性：速度型、灵活型、稳定型等。选择合适的飞机应对不同赛道是策略的一部分。

完成比赛后获得经验值和货币，用于解锁新飞机和升级现有飞机的性能。

## 核心循环

选择飞机和赛道 → 操控飞机通过检查点 → 躲避障碍 → 完成比赛获得名次 → 解锁新内容

## 核心机制

- **飞行控制系统：模拟遥控飞机的操作手感，包括方向控制、油门管理和特技动作。手感调优是游戏的核心**
- **多样化赛道设计：每个赛道有独特的地形、障碍物和检查点布局。赛道设计影响最佳飞行路线和策略**
- **飞机性能差异：速度、灵活性、稳定性等不同特性的飞机，适应不同赛道和玩家风格**
- **特技加速系统：完成翻滚、桶滚等特技动作可获得短暂加速，增加操作深度和观赏性**

## 为什么好玩

遥控飞行的模拟感和竞速的紧张刺激感结合。多样化的赛道和飞机提供丰富的游玩体验。特技系统增加了操作上限和观赏性。

## 粘性来源

操控技巧的提升和赛道完成度的竞争。计时赛的个人最佳成绩和竞速赛的排名竞争形成双重驱动力。

## Meta 系统

飞机解锁系统、性能升级系统、赛道解锁系统。成就系统记录各种里程碑。

## 实现难度

中，飞行控制需要练习和手感。最大技术难点在于操控手感的调优和AI对手的难度平衡。
