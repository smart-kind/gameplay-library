# Chronicles of Mystery: The Secret Tree of Life（神秘编年史：生命之树之谜）

- **类型**: 冒险 / 寻物解谜
- **平台**: Nintendo DS / DSi
- **开发商**: City Interactive
- **首次发布**: 2011
- **一句话描述**: 一款混合寻物解谜与 DS 触控操作的冒险游戏，跟随考古学家 Sylvie Leroux 揭开古代邪教组织的秘密。

## 玩法规则

游戏采用寻物解谜（Hidden Object）的核心玩法。玩家扮演熟练的考古学家 Sylvie Leroux，她在一次探险中偶然发现了古代邪教的秘密。

游戏画面以 2D 场景呈现，每个场景是一个充满各种物品的画面。玩家需要在场景中找到指定的物品列表——这些物品巧妙地融入场景中，需要仔细观察才能发现。找到的物品用于推进剧情，例如获得关键道具打开新的区域或解锁下一段剧情。

除了寻物，游戏还包含需要解决的谜题。这些谜题利用 Nintendo DS 的触控屏幕特性——玩家需要用触控笔在屏幕上执行特定操作，比如旋转、拼接或拖拽物品。DS 的独特能力（如麦克风、双屏幕）在某些谜题中被巧妙运用。

游戏分为多个区域场景，每个场景包含寻物环节和解谜环节。玩家需要在一个区域中找到足够的物品、解决谜题后才能解锁通往下一区域的路径。故事线贯穿整个游戏，通过找到的线索逐步揭开邪教组织的阴谋。

## 核心循环

在场景中寻找隐藏物品 → 用物品解开谜题 → 推进剧情进入新区域 → 继续探索寻找更多线索

## 核心机制

- **寻物玩法**：在精心设计的场景中寻找指定物品，物品融入背景需要仔细观察
- **DS 触控解谜**：利用 DS 触控屏的独特能力进行解谜，包括拖拽、旋转、麦克风等操作
- **故事驱动**：通过收集到的线索逐步推进剧情，故事讲述考古学家对抗古代邪教
- **区域解锁**：解开当前区域的谜题后获得通往下一区域的权限

## 为什么好玩

评测认为这是"被低估的遗珠"——虽然 Hidden Object 类型通常被认为无聊，但这款游戏通过巧妙地利用 DS 硬件特性（触控屏、双屏、麦克风）和有趣的谜题设计，让这个经典类型焕发了新的生命力。故事线也足够吸引人。

## 粘性来源

故事驱动的探索欲——玩家想知道邪教组织的秘密和 Leroux 的命运；解谜完成后的成就感；以及 DS 触控操作带来的新鲜互动感。

## Meta 系统

无。游戏是线性叙事驱动，没有外围成长系统，通关即结束。

## 实现难度

低 — 寻物游戏的核心技术（物品随机放置、碰撞检测）很成熟。最大技术难点是谜题设计和 DS 触控交互的精准调校，以及场景美术的制作量。
