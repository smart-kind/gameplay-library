# 疯狂农场（Farm Frenzy）

- **类型**: 时间管理/模拟经营
- **平台**: PC / Mobile (iOS/Android)
- **开发商**: Alawar Entertainment
- **首次发布**: 2007
- **一句话描述**: 玩家经营一个农场，饲养动物、生产商品、完成订单，在有限时间内最大化收益。

## 玩法规则

画面为俯瞰视角的农场地图，分布着多个功能区域：动物围栏、生产设施、仓库和出货区。每个关卡开始前会显示目标：在限定时间内生产并交付指定数量的产品（如"生产10个鸡蛋+5瓶牛奶+3件毛衣"），同时赚取最低金额。

操作流程：先购买动物（鸡、牛、羊、猪等）放入围栏，动物会定时产出原材料（鸡蛋、牛奶、羊毛等）。玩家需要及时点击收集这些产物，否则仓库满了就无法继续产出。收集到的原材料可以送到加工厂制成成品（鸡蛋→蛋糕、牛奶→奶酪、羊毛→毛衣）。成品送到出货区换钱，钱用来购买更多动物和升级设施。

核心紧张感来自时间压力——动物产出不等人，仓库容量有限，订单有倒计时。玩家需要在多个任务间快速切换：收集鸡蛋、送牛奶到加工厂、取成品去出货、购买新动物。手忙脚乱但又乐在其中。

操作：点击/拖拽。点击动物收集产物，点击设施进行加工，点击商店购买物品。

## 核心循环

饲养动物产原料 → 加工成成品 → 出货赚钱 → 买更多动物和升级 → 完成关卡目标

## 核心机制

- **时间压力管理**：每个关卡有严格的时间限制和明确目标。动物持续产出，仓库容量有限，玩家必须在"先做什么"上做出快速决策。
- **生产链**：动物→原材料→加工→成品→出货。每条生产链有不同耗时和收益，需要优化组合。
- **仓库管理**：仓库容量有限，满了就停止产出。玩家需要及时清空仓库，平衡"等更多产品"和"腾出空间"的决策。
- **事件系统**：随机事件（熊来偷食物、龙卷风、特殊订单等）增加变数，需要即时应对。

## 为什么好玩

"什么都要管"的多任务管理带来肾上腺素飙升。当仓库快满了、加工机在转、新订单来了、熊在偷吃时，那种手忙脚乱但又有条不紊的节奏感让人欲罢不能。每次成功在最后一秒完成目标时的成就感极强。

## 粘性来源

- **关卡递进**：每关目标更复杂、时间更紧、新设施解锁，持续提供新挑战
- **升级系统**：用钱升级动物产出速度、仓库容量、加工效率，提供成长感
- **即时反馈**：每次点击都有视觉和音效反馈，正反馈循环紧密
- **"就差一点"效应**：经常差几秒或几块钱完成目标，驱动立刻重试

## Meta 系统

- **农场升级**：永久性升级（动物产出速度+、仓库容量+、加工时间-）
- **成就系统**：完成特定目标解锁成就
- **对核心玩法的影响**：升级让后期关卡更容易，但不改变核心的时间管理循环

## 实现难度

低 — 核心是定时事件触发+资源管理+UI交互，逻辑清晰简单。最大技术难点在于多动物同时产出时的性能优化，以及确保移动端触控交互流畅、不误触。
