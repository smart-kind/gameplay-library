# Bix Challenge

- **类型**: 休闲 / 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Padadaz
- **首次发布**: 2008
- **一句话描述**: 在屏幕上画线围住弹跳球，填满75%面积来捕获球并释放特殊能力

## 玩法规则

Bix Challenge 是一款极具创意的触摸屏原生游戏。

游戏界面中有一个或多个弹跳的彩色球在屏幕上不断反弹运动。

玩家通过在屏幕上画线来尝试围住这些弹跳球。

当玩家绘制的封闭图形面积占屏幕总面积的75%或以上时，图形闭合，被围在内部的球被捕获。

捕获球后会触发该球的特殊能力，帮助玩家应对后续更复杂的情况。

绘制过程中需要注意避开弹跳球的运动路径。

如果在绘制过程中球穿过了正在绘制的线条，则绘制失败需要重新开始。

不同颜色的球被捕获后会释放不同的特殊效果，比如清除屏幕上的障碍物、获得额外时间等。

游戏采用无尽模式设计，没有固定的关卡概念。

随着捕获球的增多，球的数量和速度逐渐增加，难度自然提升。

游戏目标是尽可能长时间地存活并捕获更多球。

## 核心循环

绘制封闭区域 → 捕获弹跳球 → 释放特殊能力 → 难度递增 → 追求更高分数

## 核心机制

- **面积填充**：需要填满75%屏幕面积才能成功捕获，考验空间规划和精确绘制能力
- **弹球规避**：绘制过程中必须避开运动的球，增加了动态挑战和反应力要求
- **特殊能力释放**：不同颜色的球对应不同能力，策略性地选择先捕获哪个球影响游戏走向
- **无尽递增**：球的数量和速度随时间增加，游戏自然产生紧张感和难度曲线

## 为什么好玩

这是一款充分利用触摸屏特性的游戏，画线围球的操作简单却充满策略性。

在动态运动的球之间找到合适的绘制时机和路径，既需要空间思维又需要手眼协调。

成功围住球的瞬间有很强的成就感。

## 粘性来源

主要来自高分挑战和"差一点就成功"的不甘心。

每次绘制失败都会让玩家觉得下次一定能成功。

无尽模式让每次尝试都是独特的体验。

游戏的极简美学和流畅的弹球动画也提供了良好的视觉反馈。

## Meta 系统

无。游戏采用极简设计，没有复杂的外围系统。

2008年发布时曾登上法国免费榜第2、德国第3、英国第4、美国前50。
