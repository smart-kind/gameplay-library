# Fancade: Simple Mini Games

- **类型**: 小游戏合集/创作平台
- **平台**: Mobile (iOS+Android)
- **开发商**: WebVentures B.V.
- **首次发布**: 2020
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

玩迷你游戏 -> 收集星星 -> 解锁新世界 -> 创作自己的游戏

## 核心机制

- **迷你游戏合集**: 包含100+个迷你游戏，涵盖多种类型（平台跳跃、解谜、动作等）。每个游戏都有独特的操作方式和规则。
- **星星收集系统**: 在每个迷你游戏中收集星星，星星用于解锁新的世界和游戏。这种收集机制提供了清晰的进度感。
- **游戏创作平台**: 玩家可以使用内置工具创作自己的迷你游戏并分享给其他玩家。这个功能将游戏从单纯的消费工具变成了创作平台。

## 为什么好玩

100+迷你游戏提供了巨大的内容量，永远玩不腻。创作功能让游戏从消费变成了创造。

## 粘性来源

粘性来源于内容量的巨大和创作功能的无限可能。收集星星驱动玩家探索所有游戏。

## Meta 系统

- 星星收集系统：玩游戏收集星星，解锁新内容
- 游戏创作工具：玩家可创作和分享自己的游戏
- 社区分享：其他玩家的游戏可以下载和游玩
- 对核心玩法的影响：创作功能极大扩展了游戏的内容边界

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
