# Monopoly Millionaire（Monopoly Millionaire）

- **类型**: 棋牌 / 大富翁 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Marmalade Game Studio / Hasbro
- **首次发布**: 2014
- **一句话描述**: 经典大富翁规则的手机版本，掷骰子买地建房，通过收取租金让对手破产的派对棋盘游戏。

## 玩法规则

游戏画面呈现经典的大富翁棋盘，玩家控制自己的棋子在棋盘上移动。每回合掷两个六面骰子，根据点数沿棋盘移动相应格数。

当落在未被购买的地产上时，可以选择购买该地产。拥有完整颜色组的地产后可以建造房屋和酒店，大幅提高租金。落在别人的地产上需要支付租金，租金金额取决于地产等级（空地/房屋/酒店）。

棋盘上还有"机会"和"公益金"格子，抽取随机卡片获得奖励或惩罚。"入狱"格子会将玩家送入监狱，需要掷出双数或支付罚金才能离开。

游戏的目标是通过收取租金让所有其他玩家破产，成为最后的赢家。手机版提供了与朋友在线对战、与AI对战等多种模式，每局游戏时长通常在30-60分钟。

## 核心循环

掷骰子移动 → 购买地产 → 建房升级 → 收取租金 → 让对手破产

## 核心机制

- **掷骰移动**：随机性带来不可预测性，每个骰子结果都改变玩家的策略选择
- **地产投资**：购买地产形成垄断（同一颜色组），然后投资建房提高回报率，是核心的经济策略
- **随机事件**：机会卡和公益金卡提供随机奖励和惩罚，增加变数和戏剧性

## 为什么好玩

经典规则的熟悉感加上手机端的便利性，随时和朋友来一局，每局都有独特的故事。

## 粘性来源

具体到机制层面：经典大富翁规则本身就是经过数十年验证的粘性设计——随机性确保每局体验不同，经济策略的深度让老玩家总有进步空间，"差一点就赢"或"逆转翻盘"的戏剧性时刻让人想再来一局。

## Meta 系统

- **多人匹配系统**：可以和朋友或随机对手对战
- **主题棋盘解锁**：不同版本的棋盘和棋子
- **对核心玩法的影响**：不影响核心规则，主要为视觉变化

## 实现难度

低——大富翁规则是公开的，核心逻辑（掷骰、移动、购买、收取租金）实现简单。最大的技术难点是AI对手的难度平衡——太简单没挑战，太难又违反游戏的休闲本质。
