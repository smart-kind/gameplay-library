# Sneak Out 3D

- **类型**: 潜行解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: MondayOFF LLC
- **首次发布**: 2021
- **一句话描述**: 一款适合碎片时间的休闲娱乐游戏

## 玩法规则

- 玩家以俯视或等距视角观察关卡，可以看到控制角色的位置、敌人的巡逻路线和视野范围。视野范围通常用半透明的锥形区域表示，一目了然。
- 操作方式包括滑动控制角色移动、点击互动点执行动作（如开锁、躲在掩体后）、长按蓄力投掷物品等。玩家需要精确规划每一步移动。
- 敌人沿固定路线巡逻，带有周期性停顿和转向。如果玩家进入敌人视野区域会触发警报，需要重新开始关卡或从检查点继续。部分敌人带有特殊能力如手电筒照明或巡逻犬。
- 过关条件是在限定被发现次数内（通常0-3次）完成关卡目标——可能是潜入指定位置、窃取目标物品、或安全护送NPC。每关有多个检查点和隐藏收集品。


玩家控制一个潜行角色，关卡中有巡逻的敌人和监控设备。玩家视角通常为俯视或等距视角，可以看到敌人的巡逻路线和视野范围。

主要操作包括滑动控制角色移动、点击互动点执行动作（如开锁、躲在掩体后）、长按蓄力投掷物品等。玩家需要在不被发现的情况下穿越关卡，收集目标物品或到达指定位置。

敌人有固定的巡逻路线和扇形视野区域，如果玩家进入视野范围会触发警报。部分关卡有特殊机制如摄像头、激光探测器、声音感应器等，需要额外注意。

过关条件是在未被发现（或限定被发现次数内）的情况下完成关卡目标。评价系统通常根据被发现次数、用时和收集品数量给出星级评分。

## 核心循环

观察关卡 → 规划路线 → 执行潜行 → 解锁新区域 → 面对更复杂挑战

## 核心机制

- 视野规避：敌人有可视化的视野范围（通常用锥形区域表示），玩家需要利用掩体和时机穿越
- 声音系统：跑步和碰撞会发出声音，可能引起附近敌人警觉
- 道具互动：可以使用道具如烟雾弹、干扰器等暂时消除威胁
- 关卡重玩：三星评价体系鼓励玩家追求完美通关

## 为什么好玩

紧张刺激的潜行体验，每次成功穿越敌人警戒都带来巨大成就感

## 粘性来源

关卡设计精巧，失败时'差一点就成功'的不甘心驱使玩家反复尝试

## Meta 系统

皮肤和外观解锁系统，通过收集金币解锁不同角色造型

## 实现难度

中 — 需要设计AI巡逻路径和视锥，最大难点是让AI行为看起来智能且可预测
