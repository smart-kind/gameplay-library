# 神子（Kamiko）

- **类型**: 动作冒险 / 解谜
- **平台**: Mobile (iOS) / Switch
- **开发商**: Skipmore
- **首次发布**: 2017
- **一句话描述**: 扮演女忍者Kamiko，用魔法武器探索神庙、击败Boss、解开机关的2D动作冒险

## 玩法规则

游戏采用俯视角2D画面，玩家控制身穿白色忍者服的女忍者Kamiko在神庙和洞穴中探索。

Kamiko可以使用多种魔法武器：弓（远程射击）、爪（近战连击）、法杖（魔法攻击）。切换武器对应不同战斗策略。

关卡中布满了敌人、陷阱和需要解开的机关。部分区域需要特定武器才能通过。

Boss战是游戏的核心挑战——每个Boss有独特的攻击模式，需要观察规律、选择合适的武器和走位来击败。

## 核心循环

探索神庙 → 战斗/解谜 → 击败Boss → 获得新能力/武器 → 进入下一区域

## 核心机制

- 武器切换策略：弓/爪/法杖各有适用场景，根据敌人类型和地形实时切换是战斗核心。
- Boss模式识别：每个Boss有明确的攻击前摇和规律，通过观察-学习-执行的循环来攻略。
- 环境解谜：部分区域需要特定武器与环境互动（如用弓射击开关、用法杖点燃火把）才能通行。

## 为什么好玩

流畅的武器切换和Boss战中的"我懂了"时刻。每次学会一个Boss的攻击模式后，从被虐到反杀的成就感。

## 粘性来源

Boss战的"学会规律后反杀"的成就感 + 新武器解锁的收集欲 + 关卡探索的好奇心。

## Meta 系统

武器解锁：击败Boss后获得新魔法武器。无等级系统，能力增长来自获得新武器。

## 实现难度

中。2D俯视角动作 + 武器切换 + Boss AI + 机关解谜。最大技术难点：Boss的攻击模式设计和判定框的精确度。
