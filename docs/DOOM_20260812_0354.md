# 毁灭战士（1993）（DOOM）

- **类型**: 第一人称射击 / 动作
- **平台**: PC / Mobile (iOS+Android) / 全平台
- **开发商**: id Software
- **首次发布**: 1993
- **一句话描述**: 史上最具影响力的FPS游戏之一。玩家扮演一名太空陆战队员，在火星基地被地狱恶魔入侵后杀出一条血路。以

## 玩法规则

游戏采用第一人称视角，玩家在迷宫般的关卡中探索、战斗、寻找出口。每个关卡都是一个相互连接的空间网络，包含钥匙门、隐藏区域和大量敌人。

武器系统从弱到强排列：拳套 → 手枪 → 电锯 → 霰弹枪 → 机枪 → 火箭筒 → 等离子枪 → BFG9000。武器管理是关键——不同敌人需要不同武器应对，弹药有限。

战斗极度快节奏。玩家需要不断移动以避免被包围，在怪物群中穿梭，利用地形和武器切换求生。'边走边射'（strafing）是核心技巧。

## 核心循环

进入关卡 → 战斗 → 收集钥匙/物品 → 找到出口 → 进入下一关

## 核心机制

- 快速移动战斗：与传统FPS的'躲掩体'不同，DOOM鼓励进攻——最好的防守就是不断移动。玩家需要在怪物群中穿梭，利用空间获得射击角度。

- 武器层次递进：武器从弱到强排列，BFG9000作为最终武器具有压倒性威力。找到新武器时的爽快感是游戏设计的核心情感设计之一。

- 关卡设计：每个关卡都是精心设计的迷宫，包含主线通道和隐藏区域。秘密区域（按下墙壁进入的隐藏房间）提供额外的补给和成就感。

- 资源管理：生命值和弹药在战斗中持续消耗，玩家需要在'冒险探索寻找补给'和'谨慎通关'之间做出选择。

## 为什么好玩

极致的快节奏战斗——从踏入关卡的那一刻起就不停地战斗，没有喘息的机会。武器的威力反馈（特别是霰弹枪和BFG）带来纯粹的爽快感。

## 粘性来源

爽快感（连续击杀的满足感）+ 探索欲（这个区域有没有秘密房间？）+ 挑战性（更高难度下的生存考验）。短关卡设计让'再玩一局'的门槛极低。

## Meta 系统

无。纯粹的关卡通关体验。

## 实现难度

低 — 作为1993年的游戏，其核心系统在现代看来相对简单。技术难点在于关卡设计——如何在有限的3D空间中创造有趣的战斗和探索体验。对于复刻到移动平台，触屏操作适配是主要技术挑战。
