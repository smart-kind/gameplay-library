# Push Battle ! - Cool Game

- **类型**: 超休闲竞技 / 反应力对战
- **平台**: Mobile (iOS+Android)
- **开发商**: FTY LLC.
- **首次发布**: 2019-09-19
- **一句话描述**: 极简1v1推挤对战，向右滑动攻击，向左滑动躲避，掉下去就输

## 玩法规则

Push Battle 是一款极其简洁的1v1对战游戏。两名玩家（真人或AI）站在一个平台上，目标是把对手推下去。操作只有两个方向：向右滑动 = 攻击（向前推），向左滑动 = 躲避（后退闪避）。

游戏界面极简：中间是共享平台，两侧各有一个角色。平台可能有不同的形状和大小，有些关卡平台边缘不规则，有些会旋转或缩小。

核心判断很简单——攻击时机和躲避时机的博弈。如果你攻击时对手在躲避，你的角色会向前冲一段距离但不会碰到对手，此时如果冲过头就可能自己掉下去。如果攻击命中对手，对手会被向后推动，连续命中可以逐步将对手推下平台。

## 核心循环

匹配对手 → 滑动攻防博弈 → 一方掉落 → 结算 → 再来一局

## 核心机制

- **攻防时机博弈**：只有攻击和躲避两个动作，但时机决定一切。攻击过早会被躲开并暴露破绽，攻击过晚会被对手先手。这是一个纯粹的反应力和心理博弈。
- **平台物理**：角色在平台上移动有惯性，攻击动作也有前冲位移。这意味着攻击不是"打了就中"，而是需要预判对手位置和自己的运动轨迹。
- **极简设计**：没有血条、没有技能、没有道具。唯一规则是"不要掉下去"，规则越简单，博弈越纯粹。

## 为什么好玩

Push Battle 把格斗游戏的核心（距离控制、时机判断、心理博弈）压缩到了最简单的两个操作里。一局只需要10-30秒，但每一秒都在做决策。赢了有"我预判了你的预判"的成就感，输了有"下次我一定行"的不甘心。

## 粘性来源

具体到机制层面：博弈深度的"易学难精"特性——3秒学会规则，但要掌握攻击节奏、假动作和心理战需要大量练习；短局时长天然鼓励"再来一局"；不同平台的形状变化（旋转、缩小、不规则）增加了变数。

## Meta 系统

无显著外围系统。纯竞技游戏，无养成、无收集、无升级。

## 实现难度

低 — 物理引擎+简单AI即可实现。最大的技术难点是多人实时同步的延迟控制（如果是联网对战），但本作主要是本地/简单AI对战，技术门槛不高。

平台的设计随关卡推进而变化：有的平台边缘不规则，增加了站位策略的复杂性；有的平台会缓慢旋转，需要玩家动态调整站位；有的平台会逐渐缩小，迫使玩家越来越靠近边缘，紧张感逐步升级。

游戏的视觉风格简洁明快，角色设计夸张可爱，攻击和躲避的动作都有夸张的动画效果。角色被推下平台时的坠落动画增加了戏剧性和喜剧效果，让失败也不会太沮丧。

音效系统也很关键——攻击命中时有清脆的撞击声，躲避成功时有轻松的滑动声，角色掉落时有搞笑的尖叫声。这些音效虽然不是核心机制，但极大地增强了游戏的娱乐性和情感反馈。
