# Hunter Assassin

- **类型**: 休闲/潜行策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Ruby Game Studio
- **首次发布**: 2019
- **一句话描述**: 4.85亿下载，俯视角潜行射击超休闲游戏，控制刺客利用视野盲区消灭敌人

## 玩法规则

玩家控制一个刺客角色在俯视角2D关卡中移动，目标是消灭关卡中所有敌人。
刺客自动向视野范围内的敌人开火，玩家只需控制移动方向。
敌人有固定的巡逻路线和视野范围（通常以扇形光锥表示），进入敌人视野会被发现并受到攻击。
玩家需要利用掩体和暗处隐藏自己，绕到敌人背后或侧面进行攻击。
每个关卡有固定数量的敌人，全部消灭即通关。
部分关卡中敌人会在被消灭后发出警报，触发其他敌人的追击反应。
关卡中散落的墙壁、箱子等掩体提供战术规划空间。

## 核心循环

控制刺客移动 -> 利用视野盲区接近敌人 -> 自动射击消灭敌人 -> 清除关卡所有敌人 -> 解锁下一关

## 核心机制

- **视野系统**：敌人有固定的扇形视野范围，玩家必须避开视野区域进行潜行，被光锥照射到即被发现，直观可见的威胁范围让策略规划成为可能
- **自动射击**：玩家只需控制移动，射击由系统自动完成，大幅降低操作门槛，让注意力集中在路线规划上
- **掩体利用**：关卡中设置墙壁、箱子等掩体作为安全区域，提供战术路径选择的深度
- **警报连锁**：部分关卡中消灭一个敌人会触发周围敌人的警戒状态，增加动态难度

## 为什么好玩

将传统潜行游戏的紧张感简化到单手操作级别。"被发现了怎么办"的紧迫感与"我完美绕过了所有人"的成就感形成鲜明对比，让每局都有挑战和解谜的双重体验。路线规划的自由度和多种通关方式让重复游玩仍有新意。

## 粘性来源

关卡难度递增的阶梯设计驱动持续游玩。"差一点就完美通过"的挫败感促使玩家尝试更优路线。每关固定数量的敌人和固定路线提供了可优化的空间，玩家会反复尝试找到最完美的通关方式。

## Meta 系统

角色收集系统。通关获得宝石，用于解锁不同刺客角色，每个角色有不同的射速和生命值属性。影响战斗难度但非必需，提供长期的进度目标和收集动力。

## 实现难度

中。需要设计合理的关卡布局、敌人AI路径和视野系统。技术难点在于俯视角碰撞检测和敌人AI状态机的设计。2D网格碰撞+简单的扇形视野算法，实现难度可控。
