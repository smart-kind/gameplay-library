# 双月之谜（Twin Moons®）

- **类型**: 找物 / 解谜 / 冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: G5 Entertainment AB
- **首次发布**: 2016
- **一句话描述**: 穿越神秘门户到半世界，通过找物和匹配解开跨维度谜团

## 玩法规则

玩家扮演一位研究神秘门户的著名学者的子女，父亲在半世界失踪后必须踏上一场跨维度的冒险。游戏画面以精美的手绘场景呈现不同维度的环境。

核心玩法有两种模式：隐藏物品搜索和宝石匹配消除。在隐藏物品模式中，玩家需要在复杂场景中找出列表上的物品——有些直接可见，有些隐藏在抽屉后面，有些需要互动才能发现。找到所有物品后推进剧情。

在宝石匹配模式中，玩家需要将相同颜色的宝石连成行来消除，通过消除来推进剧情线索。匹配消除的进度直接影响故事发展。

游戏中包含大量谜题——从机械拼图到密码破译，每个谜题都与剧情线索相关联。找到关键道具后可以解锁新区域，推动故事发展。

游戏过关条件：完成当前章节的所有找物和谜题，推进剧情到下一章节。整个故事有多个章节，每个章节都有独特的视觉主题和谜题类型。

## 核心循环

探索场景 → 找物/解谜获得线索 → 解锁新区域 → 推进剧情

## 核心机制

- **双模式切换**：玩家可以在找物模式和宝石匹配模式之间自由切换，适应不同玩家偏好和场景需求。想找物时专注找物，想放松时玩匹配消除
- **互动式找物**：物品不只是静态可见的——需要打开抽屉、移动窗帘、组合道具等互动操作才能发现，增加探索深度。这种互动让找物过程更像真正的探索而非简单的视觉搜索
- **跨维度叙事**：剧情在多个维度间切换，每个维度有独特的视觉风格和谜题类型，保持新鲜感。半世界这个概念本身就充满了神秘感和探索欲望


## 为什么好玩

Twin Moons 将找物游戏与跨维度冒险故事结合，让每次找物都有明确的目标感和叙事驱动力。精美的手绘场景和神秘的剧情氛围让人沉浸其中。

## 粘性来源

剧情悬念驱动（想知道父亲下落和半世界秘密）+ 精美场景的视觉享受 + 多种玩法模式交替减少疲劳

## Meta 系统

章节制推进 + 成就系统，无数值成长

## 实现难度

中 — 场景互动逻辑和物品隐藏算法需要精心设计，最大难点是平衡难度让玩家有挑战感但不会卡关
