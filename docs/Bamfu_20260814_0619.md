# Bam fu

- **类型**: 休闲 / 弹射对战
- **平台**: Mobile (iOS+Android) / Switch
- **开发商**: Studio Fizbin
- **首次发布**: 2015
- **一句话描述**: 一款2-4人的本地多人弹射对战游戏，玩家操控小球在竞技场中互相碰撞，将对手击出平台即得分

## 玩法规则

游戏呈现一个分层的竞技场，由多个平台和连接通道组成。2-4名玩家各控制一个彩色小球，颜色各不相同。

每位玩家通过简单的点击/按键让自己的球弹射。弹射方向是垂直向上或向特定方向，取决于球当前所在的平台位置和朝向。

当球落到较低平台时会弹起。玩家通过控制弹射时机和位置来瞄准其他玩家。碰撞到对手会将其击飞，击飞距离取决于碰撞速度和角度。

将球击落到最低层（淘汰区）的玩家得分。先达到目标分数（通常3-5分）的玩家获胜。竞技场可能随时间变化——平台移动、新障碍出现、平台消失等。

游戏设有多种竞技场变体，每个变体有独特的平台布局和物理规则变化。部分竞技场有重力反转机制。

## 核心循环

弹射小球瞄准对手 → 碰撞击飞对手 → 得分获胜

## 核心机制

- **弹射物理**：球的弹跳和碰撞遵循物理规律，结果不可完全预测
- **本地多人**：2-4人同屏对战，社交互动是核心
- **动态竞技场**：平台移动和变化增加不确定性

- **重力反转**：部分竞技场重力方向会周期性反转


## 为什么好玩

简单到极致的操作（只需一个按钮）配合混乱的多人碰撞，带来纯粹的派对欢乐。物理的随机性让每局都充满意外。

## 粘性来源

社交聚会的核心粘性：简单易学让任何人都能加入，物理随机性让每局都新鲜。

## Meta 系统

无。纯派对游戏。

## 实现难度

低 — 单按钮操作。最大技术难点是多人本地输入处理和物理同步。
