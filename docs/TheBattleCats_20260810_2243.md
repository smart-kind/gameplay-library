# 可爱风格的塔防游戏，派遣猫咪单位进攻敌方基地（The Battle Cats）

- **类型**: 塔防/放置
- **平台**: Mobile (iOS+Android)
- **开发商**: PONOS
- **首次发布**: 2012
- **一句话描述**: 可爱风格的塔防游戏，派遣猫咪单位进攻敌方基地

## 玩法规则

玩家消耗能量派遣各种猫咪单位，猫咪会自动向右侧敌方基地前进。敌方也会派出单位。

目标是摧毁敌方基地。猫咪有多种类型：近战、远程、坦克、特殊等。

## 核心循环

派遣猫咪 → 自动推进 → 摧毁敌方基地 → 获得经验 → 升级猫咪 → 下一关

## 核心机制

- 能量管理
- 猫咪收集
- 自动战斗

## 为什么好玩

可爱的猫咪和搞笑的攻击动画。

## 粘性来源

猫咪收集；关卡驱动。

## Meta 系统

猫咪升级+收集。

## 实现难度

低。点击派遣简单。最大技术难点：单位AI。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
