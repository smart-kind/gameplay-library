# Tetris

- **类型**: 益智 / 方块消除
- **平台**: Mobile (iOS+Android) / PC / Console / Web / 几乎所有平台
- **开发商**: Alexey Pajitnov
- **首次发布**: 1984
- **一句话描述**: 玩家旋转和移动不断下落的七种方块形状，在底部拼出完整横排来消除得分

## 玩法规则

游戏画面是一个垂直的矩形游戏区域（通常10列x20行）。七种不同形状的方块（称为Tetrominoes）从顶部随机出现并匀速下落。

七种方块：I（长条）、O（正方形）、T（T形）、S（S形）、Z（Z形）、J（J形）、L（L形）

玩家操作：
- 左右移动：水平调整方块位置
- 旋转：90度旋转方块方向
- 软降：加速方块下落
- 硬降：瞬间将方块落到底部

游戏目标：通过旋转和移动方块，在底部拼出完整的横排。完整的一行会被消除，上方所有方块下落一行。消除行数越多，得分越高。

特殊消除：
- 单行消除：消除1行
- 双行消除（Double）：消除2行
- 三行消除（Triple）：消除3行
- 四行消除（Tetris）：消除4行（使用I方块），得分最高

游戏结束条件：新出现的方块无法放置（方块堆到顶部）

## 核心循环

放置方块 → 消除横排 → 获得分数 → 速度加快 → 更大挑战

## 核心机制

- **七种Tetromino**: 7种固定形状的方块，每种有独特的几何特性。I方块能消4行，O方块不旋转，T方块适合T-Spin技巧
- **速度递增**: 随着消除行数增加，方块下落速度逐步加快，从悠闲到极快的节奏变化是核心挑战来源
- **T-Spin**: 高级技巧：利用T方块的旋转特性在狭窄空间放置，获得额外分数奖励
- **Hold功能**: 现代版本允许保存一个方块稍后使用，增加策略深度

## 为什么好玩

规则简单到极致但精通极难。看着自己用巧妙旋转把看似不行的局面救回来的成就感无与伦比。Tetris效果（消除一行的视觉加声音反馈）本身就是令人上瘾的正反馈循环。

## 粘性来源

再玩一把效应极强，每局游戏都是独立挑战，输了立刻想重来。高分竞争和自我超越是主要驱动力。Tetris效应（闭上眼睛看到方块）证明其认知层面的成瘾性。

## Meta 系统

现代版本包含等级系统、每日挑战和在线对战。核心版本无成长系统，纯技术驱动。

## 实现难度

低。核心算法简单（方块生成、碰撞检测、行消除），技术难点在于手感调优（旋转系统SRS/ARS）和节奏曲线设计。
