# Kingdom Rush（Kingdom Rush）

- **类型**: 塔防
- **平台**: Mobile (iOS+Android) / Web / PC / Switch
- **开发商**: Ironhide Game Studio
- **首次发布**: 2011
- **一句话描述**: 经典的奇幻风格塔防游戏，玩家在多条路径上布置防御塔、释放英雄技能来抵御一波波敌人进攻城堡。

## 玩法规则

游戏画面呈现为横向滚动的奇幻地图，地图上有蜿蜒的路径，敌人会从一端沿路径走向另一端的城堡。玩家屏幕底部显示可用的防御塔类型（箭塔、法师塔、兵营、炮塔）和金币数量，顶部显示敌人波数和城堡生命值。

玩家通过点击地图上的空地放置防御塔，每种塔有3-4种升级路线。箭塔射速快适合打小兵，法师塔能穿透护甲打重甲敌人，兵营生成士兵阻挡敌人前进，炮塔造成范围伤害对付密集敌人。敌人按波次出现，每波敌人类型和数量递增。

除了防御塔，玩家还可以控制一个英雄单位在地图上自由移动和攻击，英雄有独立技能树。玩家还可以释放两个全局技能（如火雨、士兵增援），每局有使用次数限制。

当敌人突破防线到达城堡终点时，城堡会失去生命值。城堡生命值归零则游戏失败。完成每波敌人后，玩家获得金币用于建造新塔或升级现有塔。三星评价要求城堡生命值和击杀数量达标。

## 核心循环

击杀敌人获得金币 → 用金币建造/升级防御塔 → 抵御更强的敌人波次 → 通关解锁新关卡

## 核心机制

- **多路线塔防**：每张地图有多条敌人路径，玩家需要分析敌人类型和路径来合理布局。不同塔对不同敌人类型有克制关系（如法师克制重甲，箭塔克制轻甲）。
- **英雄系统**：可操控的英雄单位可以在关键位置堵截敌人或集火精英怪，英雄可升级并解锁主动/被动技能，增加了策略灵活性。
- **主动技能系统**：火雨（范围伤害）、援军（临时路障）、冰封（减速）三个全局技能在关键时刻使用可以扭转战局，但有冷却和次数限制。

## 为什么好玩

每一波敌人都像解一道塔防谜题——你需要预判敌人类型、选择正确的塔组合、在关键时刻释放技能。当看到密集的敌人被你精心布置的防御阵型逐一消灭时，那种规划成功的满足感极强。

## 粘性来源

- **策略深度**：每关有多种通关方式，尝试不同塔组合和英雄搭配带来新鲜感
- **成就系统**：每关有多个成就（如无伤通关、特定塔通关），鼓励重复游玩
- **"差一点就三星"的不甘心**：城堡剩1滴血通关让人想重来刷完美评价
- **关卡解锁**：通关解锁新地图和新塔，持续的新鲜内容

## Meta 系统

- **科技树**：通关获得星星，星星用于解锁全局科技（防御塔伤害加成、英雄属性提升等）
- **英雄收集**：解锁多个不同能力的英雄，每个英雄有独立的升级树
- **对核心玩法的影响**：科技升级让后续关卡更容易，但核心策略不变，保持平衡

## 实现难度

中 + 塔防逻辑本身不难实现，但需要精心设计关卡、敌人种类和数值平衡。最大的技术难点是AI路径规划和多敌人同时移动的性能优化，以及确保每种塔和敌人的平衡性让游戏有策略深度而非单纯数值碾压。
