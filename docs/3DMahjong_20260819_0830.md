# 3D 麻将（3D Mahjong）

- **类型**: 益智 / 三消 / 麻将消除
- **平台**: Mobile (iOS + Android)
- **开发商**: LIHUHU PTE. LTD.（及其他类似产品开发商）
- **首次发布**: 2020
- **一句话描述**: 在 3D 立体场景中匹配相同麻将牌面的经典麻将消除游戏，比传统平面版本更具空间感

## 玩法规则

3D 麻将是经典麻将消除（Mahjong Solitaire / Mahjong Connect）的三维进化版本。游戏将麻将牌以立体结构堆叠摆放，形成多层次的金字塔、阶梯或其他几何形状。

**核心操作**：玩家点击或触摸屏幕上的麻将牌来选中它们。规则与经典麻将消除一致——只有两张完全相同的、且都没有被其他牌遮挡的牌才能被选中配对消除。

**空间判定**：与传统 2D 麻将不同，3D 版本中牌面的遮挡关系更加复杂。一块牌可能在 X-Y 平面上是暴露的，但在 Z 轴（高度）上仍被更高层的牌遮挡。玩家需要不断旋转或调整视角来确认哪些牌是可选择的。

**关卡目标**：消除所有牌面即可过关。部分变体版本设有计时模式，要求在限定时间内完成消除。

**道具辅助**：当玩家陷入无法继续的局面时，可使用提示道具高亮可匹配的一对牌，或使用洗牌道具重新排列剩余牌面。

## 核心循环

选择可匹配牌面 → 消除一对 → 解锁更多被遮挡的牌 → 清除整个牌堆

## 核心机制

- **立体遮挡判定**：3D 结构增加了遮挡关系的复杂度，玩家需要从不同角度判断哪些牌是"自由"的，考验空间想象力
- **匹配消除**：两张相同且自由的牌配对消除，这是所有麻将消除游戏的核心机制
- **提示系统**：在僵局时提供可选辅助，降低挫败感
- **计时挑战**：部分模式加入时间限制，增加紧迫感

## 为什么好玩

3D 视角让传统麻将消除游戏焕然一新。玩家需要不断旋转视角来寻找可匹配的牌，这种空间探索本身就构成了一种有趣的解谜体验。相比平面版本，3D 麻将更考验空间思维能力，过关后的成就感也更强。

## 粘性来源

主要来自"差一点就解开"的解谜快感——当最后一块牌被成功消除时，整个结构崩塌的视觉效果提供强烈的爽感反馈。同时，3D 关卡的设计天然具有递增难度，每过一关都解锁更复杂的结构。

## Meta 系统

部分版本包含星星评价系统——根据通关速度和剩余提示次数给予 1-3 星评价，鼓励玩家反复挑战以获得满分。

## 实现难度

中 — 3D 遮挡判定逻辑需要处理三维空间中的可见性计算，比 2D 版本的邻居判定复杂得多。最大技术难点在于确保 3D 视角下的点击选择精度和遮挡判定的正确性，同时保持流畅的 3D 渲染。
