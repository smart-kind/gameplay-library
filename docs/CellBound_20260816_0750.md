# Cell Bound（Cell Bound）

- **类型**: 休闲 / 策略
- **平台**: Mobile (iOS)
- **开发商**: N/A
- **首次发布**: 2011（PocketGamer收录）
- **一句话描述**: 以细胞为主题的策略休闲游戏，玩家操控细胞在微观世界中生存和扩张

## 玩法规则

游戏将玩家置于一个微观的细胞世界中。画面展示一个充满各种细胞和有机物的2D环境，玩家控制自己的细胞在这个世界中移动和互动。

玩家通过触屏滑动来控制细胞的移动方向。细胞可以通过吞噬比自己小的物体来获得质量和能量。同时需要躲避比自己大的细胞，避免被吞噬。

随着细胞质量的增加，体积也会变大，可以吞噬更大的物体。但体型过大也会降低移动速度，需要在进攻和防守之间做出取舍。

游戏的目标是尽可能增大自己的细胞，同时存活足够长的时间。某些版本可能包含关卡或波次系统，每一关有特定的目标和限制条件。

## 核心循环

吞噬小物体增大体积 → 获得吞噬更大物体的能力 → 面临更大的威胁 → 继续吞噬或躲避

## 核心机制

- **吞噬增长**：通过吞噬比自己小的物体来增加质量和体积，这是游戏最核心的循环
- **大小权衡**：体型越大吞噬能力越强但速度越慢，玩家需要在攻击性和机动性之间平衡
- **风险规避**：遇到比自己大的细胞时需要及时躲避，判断何时进攻何时撤退是策略核心

## 为什么好玩

"吃东西变大"这个概念简单直观但极其上瘾。细胞世界的微观视角和流畅的移动手感让游戏有很强的沉浸感。

## 粘性来源

数值成长（细胞越来越大）和风险回报的紧张感是核心粘性。每次变大后的"无敌感"和遇到更大细胞时的"危机感"形成鲜明对比。

## Meta 系统

无

## 实现难度

低 — 2D移动+碰撞检测+大小比较，最大技术难点是流畅的手势控制和物理手感
