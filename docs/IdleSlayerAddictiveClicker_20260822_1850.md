# 闲置杀手（Idle Slayer: Addictive Clicker）

- **类型**: 放置 / RPG / 点击
- **平台**: Mobile (iOS+Android)
- **开发商**: Pablo Leban
- **首次发布**: 2020
- **一句话描述**: 英雄自动战斗冒险，你只需专注升级——从新手到传奇的无尽成长之路

## 玩法规则

Idle Slayer 是一款结合了横版动作和放置点击元素的RPG游戏。英雄会自动前进并攻击遇到的怪物，玩家需要通过升级来提升英雄的战斗力。

游戏画面是横版卷轴风格：英雄在左侧自动向右前进，途中遇到各种怪物。英雄自动攻击，但攻击力取决于玩家的升级投资。顶部显示金币、等级和当前区域名称。

玩家用击杀怪物获得的金币购买升级：武器伤害、攻击速度、暴击率、自动攻击伤害等。每次升级都会显著提高战斗效率。随着英雄前进，会遇到越来越强的怪物和Boss。

当英雄无法击败当前区域的怪物时，会自动后退到能应对的区域继续战斗积累金币。击败区域Boss后解锁新区域，进入新环境面对更强的敌人和更丰厚的奖励。每个新区域有独特的视觉风格和怪物设计。

游戏后期引入了宠物系统和转生系统，提供额外的加成和策略维度。宠物可以自动收集金币或增加伤害，转生则重置进度获得永久加成。

## 核心循环

英雄自动战斗 → 获得金币 → 购买升级 → 推进到新区域 → 面对更强敌人 → 循环

## 核心机制

- 自动战斗系统：英雄自行前进和攻击，玩家专注于升级决策而非操作。这降低了操作门槛，让放置元素成为主导
- 区域推进机制：每区域有独立难度曲线和Boss，提供明确的进度里程碑。解锁新区域带来视觉新鲜感和更强的成就感
- 多维度升级：伤害、速度、暴击等多个升级维度，增加策略深度。玩家需要权衡资源分配到哪个维度

## 为什么好玩

把放置点击和横版RPG完美结合，英雄的自动冒险提供了视觉反馈和故事感。看着英雄从弱小到无敌的成长过程非常有成就感。每次升级都立竿见影，反馈直接。

## 粘性来源

角色成长感——英雄变强的过程直观可见。区域Boss提供了阶段性目标。多维度升级系统让玩家不断调整策略，追求最优配置。宠物收集增加了长期目标。

## Meta 系统

区域解锁和Boss系统：每个区域是一个独立的挑战关卡，击败Boss后永久解锁。宠物系统提供额外加成和收集乐趣。转生系统重置进度获得永久加成。这些系统共同构成了丰富的后期内容。

## 实现难度

中等 — 需要实现自动战斗AI、怪物行为、升级系统。最大技术难点是战斗平衡，确保升级曲线与怪物难度匹配，既不无聊也不挫败。
