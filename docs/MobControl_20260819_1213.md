# Mob Control（暴民控制）

- **类型**: 休闲 / 策略 / 塔防
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2023
- **一句话描述**: 从发射器射出小人，穿过倍增门增加数量，淹没敌方炮塔和防线。

## 玩法规则

屏幕底部是玩家的发射器，顶部是敌方的防线（炮塔和防御墙）。玩家的操作是**拖拽发射器**——左右移动发射器的位置，然后发射出一队蓝色小人。

小人在向上行进的过程中会经过各种**倍增门**（标有 x2、x3、x5、x10 等数字的彩色门）。穿过倍增门后，小人的数量会按倍数增加。例如，发射5个小人穿过x3的门后变成15个。

小人的目标是**淹没敌方的炮塔和士兵**。每个炮塔有一定数量的生命值，需要足够多的小人同时攻击才能击毁。敌方炮塔会发射红色小人来拦截玩家的小人——当蓝色和红色小人相遇时，会互相抵消（一对一消耗）。

部分关卡中还有**减倍门**（标有 ÷2 的红色门）和**合并门**，增加了路线选择的策略性。玩家需要规划小人穿过哪些倍增门，以最大化数量来突破敌方防线。

## 核心循环

观察倍增门布局 → 拖拽选择发射位置 → 发射小人穿过倍增门 → 数量倍增后冲击敌方防线 → 击毁炮塔 → 进入下一关

## 核心机制

- **倍增路线规划**：选择穿过哪些倍增门是核心策略。玩家需要权衡"倍增倍数"和"到达路径"——倍数最高的门不一定在最优路径上。
- **数量对冲**：蓝色和红色小人一对一抵消的机制，让"数量"成为唯一的战斗资源。这简化了战斗系统，将注意力集中在倍增策略上。
- **发射位置控制**：拖拽发射器决定了小人的初始行进方向，是玩家唯一的直接操作。
- **关卡地形变化**：不同关卡的倍增门排列、炮塔位置和数量各不相同，每次都是新的解谜挑战。

## 为什么好玩

Mob Control 的核心吸引力在于"小人海淹没一切"的视觉爽快感。当你精心规划了一条倍增路线，看到小人的数量从几个暴增到上百个，然后像潮水一样淹没敌方防线时，那种满足感非常强烈。同时，倍增门的选择又带有解谜元素——找到最优路线本身就是一种成就感。

## 粘性来源

- **倍增的数学快感**：看到数字翻倍的瞬间提供强烈的正反馈。
- **视觉满足感**：大量小人涌向敌方防线的画面极具冲击力。
- **路线解谜**：每关的倍增门布局不同，寻找最优解本身就有吸引力。
- **短时局**：每局只需几十秒，失败后可以立即重试。

## Meta 系统

- **关卡进度解锁**：线性推进，完成一关解锁下一关。
- **皮肤系统**：解锁不同颜色/外观的小人和发射器。
- **每日奖励和广告道具**：通过观看广告获得临时增益。

## 实现难度

低到中。核心是大量小人的物理移动和碰撞检测。最大技术难点是当小人数量达到上百个时的性能优化（大量单位的移动、碰撞、抵消计算），以及倍增门和炮塔的路径AI设计。
