# 气球塔防（Bloons Tower Defense）

- **类型**: 塔防 / 策略
- **平台**: Web (Flash) / Mobile (iOS+Android) / PC
- **开发商**: Ninja Kiwi
- **首次发布**: 2007
- **一句话描述**: 在猴子塔的帮助下，阻止彩色气球沿着固定路径飘过

## 玩法规则

游戏在一张2D地图上进行，地图上有一条蜿蜒的路径。彩色气球会沿着路径从起点向终点移动。气球有不同的颜色和类型，代表不同的难度：红色气球最弱（1点生命值），蓝色气球包含两个红色气球，绿色包含两个蓝色，依此类推。

玩家可以在地图上的非路径区域放置防御塔（各种类型的猴子）。每种塔有不同的攻击方式和范围：
- **飞镖猴**: 基础攻击，射程有限
- **炸弹塔**: 范围伤害，对陶瓷气球有效
- **冰冻塔**: 减速气球
- **超级猴**: 后期强力塔

通过击杀气球获得游戏内货币，用于购买和升级防御塔。每波气球数量递增，种类增多，包括带有护盾的铅气球和需要多次击破的陶瓷气球。

目标是防止任何气球到达路径终点，气球到达终点会扣除生命值。

## 核心循环

气球出现 → 塔自动攻击 → 获得货币 → 购买/升级塔 → 面对更强的气球波次

## 核心机制

- **气球嵌套系统**: 打破一个气球会释放更小的气球（如绿色→2蓝色→4红色），增加了深度
- **塔的组合策略**: 不同塔有独特的克制关系（如对铅气球需要特定塔），需要组合搭配
- **路径优化**: 塔的放置位置决定了攻击覆盖面，优秀的路径布局可以最大化效率
- **升级路线**: 每座塔有多条升级路线，玩家需要在早期做出长期投资决策

## 为什么好玩

Bloons TD把塔防做到了极致——规则简单（放塔→打气球），但策略深度极深。气球的嵌套系统（大变小、小变小小）创造了"看起来打完了其实还没完"的意外感。

## 粘性来源

关卡的递增难度 + 塔的多样性和升级路线的分支选择 = 极高的重玩价值。气球塔防系列每代都有新塔和新气球类型，保持了系列的新鲜感。成就系统也鼓励玩家用不同组合完成关卡。

## Meta 系统

系列作品间的进化：从最初的Flash小游戏发展出Bloons TD 5、Bloons TD 6等完整作品，增加了英雄系统、猴子知识树等meta元素。

## 实现难度

中 — 塔防核心逻辑成熟（路径跟随、碰撞检测、弹道计算），但气球嵌套系统和塔的多样性需要精心设计。最大技术难点是平衡性——确保每种塔在不同场景下都有价值。
