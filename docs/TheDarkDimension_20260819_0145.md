# 黑暗维度（The Dark Dimension）

- **类型**: 解谜 / 益智
- **平台**: Mobile (iOS)
- **开发商**: Pocket Gamer 收录的移动端游戏
- **首次发布**: 2008
- **一句话描述**: 一款基于空间变换和光影操作的解谜游戏，玩家需要在黑暗环境中找到出路。

## 玩法规则

游戏呈现一个暗色调的迷宫或场景，玩家看到的画面大部分被黑暗笼罩。玩家通过点击或拖拽屏幕来操控光源、旋转视角或改变场景中的物体位置。

游戏的核心机制围绕"黑暗"展开——某些区域在黑暗中是不可见的，玩家必须通过激活光源（如火把、灯泡或手电筒）来揭示隐藏的路径。每个关卡都有特定的目标，比如到达出口、收集物品或解开机关。

玩家的操作包括点击激活光源、滑动移动角色、拖拽旋转平台或镜子以改变光线路径。某些关卡还涉及时间限制，需要在光源耗尽前完成目标。

过关条件通常是：到达指定出口、收集所有隐藏物品、或解开所有机关。失败条件包括：被黑暗中的障碍物阻挡、超时、或掉入陷阱。

## 核心循环

操作光源/机关 → 揭示隐藏路径 → 找到出口/收集物品 → 进入下一关

## 核心机制

- **光影解谜机制**：通过控制光源照亮隐藏区域，光线的传播方向和范围直接影响可见区域。这创造了"先看见才能通过"的探索体验。
- **空间变换**：部分关卡包含可旋转的平台或可移动的墙壁，改变场景布局来创造新路径。
- **资源管理**：光源可能有使用次数或时间限制，玩家需要在照亮关键区域和节约资源之间做出权衡。

## 为什么好玩

黑暗与光明的对比天然制造紧张感和探索欲——每次点亮新区域都像一次小小的惊喜。解谜难度逐步递增，从简单的"照亮路"到需要多步规划光源路径，保持了持续的挑战感。

## 粘性来源

- **"差一点就看见"的好奇心**：黑暗区域隐藏了什么？这种未知感驱使玩家不断尝试。
- **逐步揭示的满足感**：每个关卡解锁后，玩家获得短暂的成就感，同时被新关卡的未知感吸引。
- **短关卡设计**：每关几分钟即可通关，适合碎片化时间，"再来一关"的诱惑很强。

## Meta 系统

无。游戏专注于纯粹的解谜体验，没有外围成长系统。

## 实现难度

中。最大的技术难点是光影效果的实时计算——需要实现动态光源照亮/遮蔽的逻辑，以及在2D环境中正确处理遮挡关系。如果是基于像素或tile的静态关卡，难度可以降低为预先计算每个tile的可见性，大幅减少运行时开销。

## 变体设计

可以加入"黑暗侵蚀"机制——光源会随时间逐渐衰弱，玩家需要不断寻找新的光源。或者"合作模式"——两名玩家各自控制不同的光源，必须协作才能照亮整条路径。
