# 经典3D平台跳跃游戏，Crash在各种场景中冒险（Crash Bandicoot）

- **类型**: 平台跳跃
- **平台**: Mobile (iOS+Android) / PS / Xbox / Switch / PC
- **开发商**: Activision / Toys for Bob
- **首次发布**: 1996
- **一句话描述**: 经典3D平台跳跃游戏，Crash在各种场景中冒险

## 玩法规则

玩家控制袋狸Crash在3D平台场景中奔跑、跳跃、旋转攻击。场景多为线性前进，包含跳跃平台、旋转障碍物、敌人和收集品。

Crash可以跳跃踩扁敌人、旋转攻击、滑动躲避障碍。收集场景中的水果和箱子有额外奖励。

移动版本保留了核心玩法，适配触屏操作。

## 核心循环

平台跳跃 → 收集 → 躲避/击败敌人 → 到达终点 → 下一关

## 核心机制

- 3D平台跳跃：在固定路线上前进，考验跳跃时机
- 旋转攻击：Crash的标志性旋转攻击
- 收集系统：水果、宝箱、宝石
- Boss战：每关末尾有Boss战斗

## 为什么好玩

经典平台跳跃的爽快操作和有趣的关卡设计。Crash的搞笑表情和动作增加了娱乐性。

## 粘性来源

关卡驱动；收集宝石的完美主义挑战。

## Meta 系统

关卡解锁+收集系统。

## 实现难度

中。平台跳跃需要精准操作。最大技术难点：3D场景的碰撞检测和流畅度。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
