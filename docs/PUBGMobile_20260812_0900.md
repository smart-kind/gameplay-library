# PUBG Mobile

- **类型**: 大逃杀 / 射击
- **平台**: Mobile (iOS+Android)
- **开发商**: Tencent Games / Krafton
- **首次发布**: 2018
- **一句话描述**: 移动端大逃杀的黄金标准，完美还原 PC 版体验，拥有全球电竞生态。

## 玩法规则

100 名玩家从飞机上跳伞到一座大型岛屿地图上，落地后搜寻武器、装备和补给品。随着游戏进行，安全区（蓝圈外的毒圈）不断缩小，迫使玩家相遇并交战。最后存活的玩家或队伍获胜。

游戏支持单人、双人和四人组队模式。操作采用双摇杆虚拟控制：左摇杆移动，右摇杆瞄准和射击。屏幕上有各种按钮用于跳跃、蹲伏、趴下、换弹、切换武器等。游戏提供了丰富的自定义按键布局选项。

地图包含多种地形——城市、乡村、山地、水域——每种地形提供不同的战术选择。武器系统包含手枪、冲锋枪、突击步枪、狙击枪、霰弹枪和近战武器，每种武器有独特的射速、伤害和后坐力特性。

## 核心循环

跳伞搜寻 → 搜集装备 → 在缩圈中生存并战斗 → 最后存活获胜

## 核心机制

- 大逃杀缩圈机制：安全区不断缩小，强制玩家遭遇
- 搜刮系统：随机分布的武器和装备，每次落地体验不同
- 多武器系统：数十种武器各有独特手感和战术定位
- 载具系统：车辆提供快速移动和战术选择
- 排名系统：排位赛提供长期竞技目标

## 为什么好玩

PC 级的大逃杀体验被完美移植到移动端。优化的触控操作让激烈的枪战变得可行，庞大的玩家基数确保匹配速度快，赛季内容更新保持游戏活力。

## 粘性来源

- 每局独特性：随机跳伞点、装备分布和安全区位置确保没有两局完全相同
- 紧张感递进：从早期轻松的搜刮到后期高强度的遭遇战，情绪曲线设计出色
- 赛季内容：定期更新地图、武器和模式，保持长期兴趣
- 电竞生态：全球赛事体系为高水平玩家提供竞技舞台

## Meta 系统

通行证和排位系统。每赛季通过排位赛提升等级，通行证提供奖励和装饰物品。不影响核心战斗平衡。

## 实现难度

高。大逃杀游戏需要处理百人同局的网络同步、反作弊、地图设计和性能优化。移动端还需要额外的触控优化和设备适配。
