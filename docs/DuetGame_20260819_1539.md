# Duet Game

- **类型**: 益智 / 动作 / 反应力
- **平台**: Mobile (iOS+Android)
- **开发商**: Kumobius
- **首次发布**: 2013
- **一句话描述**: 同时控制两个旋转的球，在障碍物阵中穿梭求生

## 玩法规则

游戏画面中央，两个彩色小球（红色和蓝色）围绕一个中心点做轨道运动，一个在中心点左侧，一个在右侧，处于相对位置（相隔 180 度）。

玩家通过触摸屏幕左半部分让两个球逆时针旋转，触摸右半部分让两个球顺时针旋转。不触摸时，球保持在当前位置不动。

屏幕上方不断向下（或向中心）移动各种障碍物——横条、旋转的方块、移动的平台等。障碍物通常只覆盖中心区域的一部分，两个球需要在障碍物之间的空隙中穿过。

核心难点在于：两个球同时运动且位置相对，当你在躲避一个障碍时，另一个球可能正冲向另一个障碍。你需要同时照顾两个球的安全。

球碰到任何障碍物即游戏结束。游戏采用无尽模式，障碍物越来越密集，旋转速度要求越来越高。部分关卡有"切换"机制——点击可以让两个球交换颜色/轨道位置。

## 核心循环

触摸旋转 → 双球同步移动 → 穿过障碍物空隙 → 避开碰撞 → 难度递增 → 存活更久

## 核心机制

- **双体同步控制**：两个球的运动完全同步——你旋转一个方向，两个球同时向该方向移动相同的角度。这意味着你的每次操作同时影响两个球，需要在两者之间找到平衡。
- **空间感知挑战**：玩家需要同时关注屏幕两侧的障碍分布，在脑海中预判两个球各自将要面临的路径。这种"双线程"注意力挑战是游戏难度的核心来源。
- **渐进难度**：障碍物的出现频率、复杂度和移动速度逐步增加。从简单的静态横条到旋转的十字、移动的方块，再到多层次的复合障碍。
- **颜色/轨道切换**：部分版本允许两个球交换轨道位置（红球从外圈换到内圈，蓝球反之），增加了一层策略维度。

## 为什么好玩

极简的操作（只分左右两个方向）却带来极高的技巧上限。当你在密集障碍物中连续穿梭、两个球惊险擦边而过的瞬间，那种紧张感和成就感是难以言喻的。而失败后的"差一点点就过了"的不甘心感，正是驱动你不断重试的最强动力。加上电子音乐风格的配乐和简洁的视觉设计，整体氛围极具沉浸感。

## 粘性来源

- **技巧成长感**：每次重试都能明显感受到自己对节奏和时机的把握在进步
- **分数挑战**：不断刷新个人最高分的驱动力
- **关卡模式**：除无尽模式外，还有预设计的关卡，每个有独特的障碍序列
- **音乐同步**：部分障碍物的节奏与背景音乐同步，形成音游般的体验

## Meta 系统

- **关卡解锁**：完成特定分数解锁新关卡
- **角色/颜色解锁**：收集成就解锁不同的球颜色和视觉效果
- **成就系统**：完成特定挑战（如"存活60秒"、"通过100个障碍"）

## 实现难度

低。核心是圆形轨道运动 + 碰撞检测 + 障碍物生成。最大技术难点在于：(1) 流畅的圆形运动动画和精确的碰撞检测（需要考虑球的半径和障碍物的精确边界）；(2) 障碍物生成的节奏控制——需要确保生成序列是可通过的，而不是纯粹随机；(3) 手感调优，旋转的加速度和减速度需要精细调整以获得最佳操作感。
