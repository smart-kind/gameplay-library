# WipEout

- **类型**: 竞速 / 未来科幻
- **平台**: Mobile (iOS)
- **开发商**: Sony / Studio Liverpool (授权移动端)
- **首次发布**: 2008
- **一句话描述**: 一款未来风格的反重力赛车游戏，玩家驾驶高速悬浮飞行器在科幻赛道上竞速。

## 玩法规则

玩家看到的画面是一条悬浮在空中的未来主义赛道，赛道由光滑的金属管道、能量护栏和各种科幻建筑构成。玩家操控一艘反重力飞船，以极高的速度在赛道上飞驰。

操控方式包括：倾斜设备控制左右转向、触摸加速/刹车按钮。赛道上有加速带（boost pad）和武器拾取点。触碰加速带获得瞬间加速，拾取武器可以攻击前方对手。

游戏支持多种模式：竞速模式（跑完固定圈数比时间）、时间挑战（单人计时赛）、淘汰赛（每圈最后一名被淘汰）。飞船在高速行驶时靠近赛道墙壁可以获得额外加速（wall ride机制）。

## 核心循环

操控飞船在赛道上高速行驶 → 收集加速/攻击对手 → 冲线获得排名 → 解锁新飞船和赛道

## 核心机制

- **反重力竞速**：飞船不受地面摩擦力限制，可以在赛道的任何表面行驶（包括侧壁和天花板），带来传统赛车游戏无法实现的立体竞速体验。
- **武器系统**：赛道上拾取的武器包括导弹、电磁脉冲、护盾等，增加了竞速的策略性和变数。
- **加速链（Turbo Chain）**：连续触碰多个加速带可以累积加速效果，速度越高画面越模糊、操控越刺激，形成"速度即奖励"的正反馈。

## 为什么好玩

极高的速度感是核心吸引力——当飞船在管道中全速飞行时，那种眩晕又兴奋的感觉是其他竞速游戏难以复制的。加上电子音乐风格的配乐和科幻视觉美学，整体氛围非常沉浸。

## 粘性来源

- **速度快感**：不断突破自己的最快圈速记录，追求完美路线带来的纯粹速度快感。
- **武器博弈**：落后时获得更强武器的补偿机制让比赛充满悬念，不到最后一刻不知道谁赢。
- **赛道精通**：每条赛道有最优路线和加速点，反复练习找到最佳跑法本身就是一种成就感。

## Meta 系统

- **飞船解锁**：完成关卡或达到特定成绩解锁不同性能的飞船（速度型、操控型、均衡型）。
- **赛道解锁**：每场比赛的胜利解锁新赛道，赛道难度递增。

## 实现难度

高。最大技术难点在于高速运动下的渲染优化和碰撞检测——当物体以极高速度移动时，需要防止穿模（tunneling）问题。另外，反重力物理的实现（允许在任意表面行驶）比传统赛车物理更复杂。

## 变体设计

可以加入"自定义赛道"模式，允许玩家设计自己的科幻赛道。也可以加入"团队竞速"——两支队伍各自控制多艘飞船，以团队总分决定胜负，增加策略协作维度。
