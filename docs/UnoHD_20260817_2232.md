# UNO HD（Uno HD）

- **类型**: 卡牌 / 休闲 / 社交
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Mattel / Gameloft
- **首次发布**: 2010
- **一句话描述**: 经典 UNO 卡牌游戏的数字高清版，支持多人对战的家庭卡牌游戏

## 玩法规则

UNO 使用一副 108 张的专用卡牌，包含四种颜色（红、黄、绿、蓝），每种颜色有数字 0-9 各两张，以及特殊功能牌：跳过（Skip）、反转（Reverse）、+2（Draw Two）、万能牌（Wild）、+4 万能牌（Wild Draw Four）。

游戏开始时，每位玩家发 7 张牌，牌堆剩一张翻开作为起始牌。玩家轮流出牌，必须出与桌面牌颜色相同或数字相同的牌。如果手中没有可出的牌，必须从牌堆抽一张。如果抽到的牌刚好可以出，可以选择立即出牌。

当玩家手中只剩一张牌时，必须喊出"UNO！"。如果没有喊 UNO 被其他玩家发现，需要罚抽两张牌。第一个出完所有手牌的玩家获胜。

特殊功能牌的作用：跳过让下一位玩家失去本轮出牌机会；反转改变出牌顺序方向；+2 让下一位玩家抽两张牌并跳过回合；万能牌可以选择任意颜色继续；+4 万能牌选择颜色并让下一位玩家抽四张牌（规则上只能在没有匹配颜色时使用）。

## 核心循环

出牌匹配颜色或数字 → 手牌越来越少 → 第一个出完所有牌获胜

## 核心机制

- **颜色/数字双重匹配**：每手牌有两个维度可以匹配（颜色和数字），提供了出牌灵活性。玩家可以选择出哪个维度来控制局面。例如，手中红色 3 和绿色 3 都可以接在红色 7 后面，选择出哪张决定了下一张牌的颜色走向。
- **功能牌策略**：+2 和 +4 是攻击性牌，可以让对手手牌暴增；跳过和反转可以打乱对手节奏。何时使用功能牌是策略核心——早用可能被反制，留到最后可能被抽完牌堆。功能牌之间的互动（如 +2 叠加规则）增加了博弈深度。
- **UNO 喊叫机制**：只剩一张牌时必须喊 UNO 的规则增加了紧张感和社交互动。忘记喊 UNO 被罚牌是游戏中最经典的"翻车"时刻，也是 UNO 区别于其他卡牌游戏的标志性规则。
- **多人社交互动**：UNO 本质上是社交游戏，玩家之间的"针对"（连续对某人使用 +4）、联盟和背叛是核心乐趣。数字版通过在线匹配和好友对战延续了这一体验。UNO Wonder 等变体还加入了新的游戏模式和规则变化。

## 为什么好玩

UNO 的规则简单到 5 岁小孩都能理解，但策略深度足够让成年人也投入。+4 的戏剧性、忘记喊 UNO 的尴尬、最后一张牌翻盘的刺激——这些都是 UNO 让人欲罢不能的原因。数字版 UNO HD 带来了高清画面和流畅的动画效果。

## 粘性来源

- **社交驱动**：和朋友玩的乐趣远大于 AI，多人对战是核心粘性来源
- **戏剧性时刻**：+4 反杀、最后一张牌翻盘等"名场面"让人想再来一局
- **规则简单**：零学习成本，随时可以开始一局
- **快节奏**：一局 5-15 分钟，适合碎片时间

## Meta 系统

数字版加入了在线排行榜、每日挑战、主题卡牌皮肤等。经典 UNO 本身没有成长系统，但数字版本体提供了锦标赛模式和成就系统。UNO Wonder 等变体加入了新的游戏模式如 cruise adventure。

## 实现难度

低 — 规则极简。HD 版的亮点是触屏操作的流畅度和 HD 画面。最大技术难点是网络对战的延迟处理和反作弊机制，以及多平台同步。
