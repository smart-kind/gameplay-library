# 拼字之友 2（Words With Friends 2）

- **类型**: 文字/社交
- **平台**: Mobile (iOS+Android)
- **开发商**: Zynga
- **首次发布**: 2017
- **一句话描述**: 多人在线拼字游戏，类似 Scrabble 的社交文字游戏。

## 玩法规则

玩家在字母网格上放置字母组成单词，每个字母有不同分值，特殊格子提供倍分奖励。每回合放置一个单词，交替进行直到所有字母用完或无法组词。

支持与朋友对战或随机匹配。游戏节奏自由，玩家可以在方便时回应。词库检查确保所有单词有效。

## 核心循环

查看字母 → 组成有效单词 → 放置在棋盘上获得分数 → 等待对手回应 → 继续下一回合

## 核心机制

- 字母棋盘：7x7 网格，包含倍分格子（双倍字母、三倍单词等）
- 社交对战：与朋友或随机玩家进行异步对战
- 词库系统：内置词典验证单词有效性

## 单人模式与挑战

除多人对战外，游戏还提供单人解谜模式：Word Boggle（单词拼图）、Solo Challenge（单人挑战）等。这些模式不需要等待对手回应。

每日谜题和每周锦标赛提供持续的内容更新，让玩家每天都能获得新的挑战。

## 为什么好玩

经典 Scrabble 玩法的数字化版本，社交属性让文字游戏更加有趣。可以在碎片时间随时进行。

## 粘性来源

与朋友的持续对战、词汇量展示的竞争心理、轻松休闲的节奏。

## Meta 系统

免费下载，有广告和可选内购

## 实现难度

低 — 取决于词汇量，无时间压力
