# 卸下螺栓：螺丝解谜（Take Off Bolts: Screw Puzzle）

- **类型**: 螺丝解谜 / 逻辑推理 / 物理益智
- **平台**: Mobile (iOS + Android)
- **开发商**: Topsmart Mobile Ltd.
- **首次发布**: 2024
- **一句话描述**: 通过卸下正确顺序的螺栓来解锁木板和零件的逻辑解谜游戏。

## 玩法规则

游戏画面展示一块或多块木板，上面用螺栓（带有不同颜色或形状的螺帽）固定着各种形状的金属/木质板块。每个螺栓穿过一个或多个层叠板块上的孔洞。

玩家点击一颗螺栓可以将其卸下。卸下的螺栓会移动到画面上方的"螺栓槽"中暂存——螺栓槽有容量限制（通常 3-5 个位置）。当槽位满时，玩家必须先将某个螺栓放回原处才能卸下新的。

核心规则：卸下一个螺栓后，检查所有穿过该螺栓的板块。如果某个板块的所有固定螺栓都被卸下（且该板块不再被其他螺栓固定），该板块会因重力掉落。掉落板块后，原本被其遮挡的螺栓变得可操作。

关卡目标是卸下所有必要的螺栓，让所有板块全部掉落。每关的板块形状、孔洞位置、螺栓数量和颜色各不相同，难度逐步递增。

## 核心循环

选择螺栓卸下 → 螺栓暂存到槽位 → 板块因重力掉落 → 暴露新螺栓 → 继续拆卸直到全部清空

## 核心机制

- **螺栓槽限制**：有限的暂存空间是核心约束条件。玩家必须规划拆卸顺序，确保在槽位满之前能释放板块并回收槽位空间。
- **层叠遮挡**：上层板块可能遮挡下层螺栓，必须先处理上层。但某些上层板块的螺栓又被更上层遮挡，形成依赖链。
- **重力释放**：板块失去所有固定后自然掉落，提供直观的物理反馈和"解锁"的视觉爽感。
- **颜色编码**：部分关卡使用彩色螺栓来提示拆卸优先级或分组关系，辅助玩家理解空间结构。

## 为什么好玩

"看一遍觉得简单，动手才发现没那么容易"——这是此类解谜的核心魅力。每个关卡像是一个 3D 的鲁布·戈德堡机械，玩家需要在脑海中模拟整个拆卸链条。每成功卸下一个关键螺栓、看到板块如多米诺般掉落，都带来强烈的成就感。

## 粘性来源

空间推理的挑战递进——从简单的单层 3 螺栓到复杂的多层交叉结构；"差一步就全掉了"的遗憾驱动重试；大量关卡提供持续的解谜内容；螺栓槽容量的约束让每步决策都有意义。

## Meta 系统

轻度进度系统：关卡地图、星星评价（基于拆卸次数或用时）。可能包含提示购买和去广告选项。

## 实现难度

中。需要处理层叠关系判断、重力模拟、螺栓槽的状态管理。最大技术难点是确保每关可解——关卡生成器需要验证存在至少一条从初始状态到全部清空的有效路径。
