# Gnu's Revenge

- **类型**: 塔防 / 策略
- **平台**: PC (Linux/Windows/Mac)
- **开发商**: no_tux (开源)
- **首次发布**: 2011
- **一句话描述**: 一款反套路塔防游戏——玩家不是放置防御塔来阻止敌人，而是放置障碍物和陷阱来引导敌人进入自己挖的迷宫，最终到达终点消灭它们。

## 玩法规则

游戏画面是一个网格地图。与普通塔防不同，玩家不建造'塔'来射击敌人，而是在地图上挖掘通道和放置陷阱，人为制造一条蜿蜒曲折的迷宫路径，引导敌人沿着你设计的路线前进。

敌人会沿着你创建的最短路径（按照游戏的路径寻找算法）移动。玩家的目标是通过巧妙设计迷宫，让敌人的路径尽可能长，从而在你放置的陷阱和障碍物上消耗它们的生命值。

可放置的元素包括：墙壁（阻挡通行，强制敌人绕行）、陷阱（对经过的敌人造成伤害）、减速带（降低敌人移动速度，延长暴露时间）以及终点处的最终防御设施。

每一波敌人从地图一侧进入，沿玩家创造的路径移动到达另一侧。如果敌人到达终点，玩家的生命值减少。敌人全部被消灭则通过关卡。

随着关卡推进，敌人类型多样化：有的免疫特定陷阱，有的移动速度极快，有的生命值极高，迫使玩家不断调整迷宫设计策略。

## 核心循环

分析敌人特性 → 设计迷宫路径 → 放置陷阱 → 观察敌人通过效果 → 下一波调整设计

## 核心机制

- 逆向塔防设计：传统塔防是'建塔打怪'，本作是'造路困怪'。玩家不直接攻击敌人，而是通过空间设计来控制敌人的移动路线。这种角色反转创造了全新的策略维度。
- 路径寻找利用：游戏使用标准的路径寻找算法（类似A*），玩家通过放置墙壁来'欺骗'算法，制造出对敌人不利但对玩家有利的绕行路线。理解并利用算法的行为是通关的关键。
- 陷阱协同效应：不同类型的陷阱有不同的效果（伤害、减速、燃烧等），将它们按特定顺序排列在迷宫路径上可以产生连锁效果。例如先减速、再伤害、再燃烧的组合效率远高于单独使用。

## 为什么好玩

'我设计的迷宫把敌人都困住了'的满足感是无与伦比的。每关都是一次空间解谜——既要困住敌人，又要确保它们最终能到达终点被消灭。这种'引导式'的塔防体验与传统的'射击式'塔防截然不同。

## 粘性来源

每一关都有'最优解'的追求——'我的迷宫能不能更高效？能不能让敌人在陷阱上多转几圈？'这种优化冲动驱动反复尝试。开源社区还持续贡献自定义关卡。

## Meta 系统

无外围系统。游戏通过关卡解锁和自定义关卡支持提供内容消耗。

## 实现难度

低。最大技术难点在于路径寻找算法与玩家放置障碍的实时交互——需要确保路径计算高效且结果可预测（玩家能'读懂'为什么敌人走某条路）。
