# 英雄财富（Heroes of Fortune）

- **类型**: 三消 + 放置 + 角色扮演
- **平台**: Mobile (iOS+Android)
- **开发商**: Pocket Games
- **首次发布**: 2024
- **一句话描述**: 在奇幻世界中通过三消战斗收集英雄、升级装备的放置RPG

## 玩法规则

游戏界面分为上下两部分：上方是战斗区域，显示敌人和己方英雄角色；下方是7×7的三消棋盘，棋盘上有不同颜色的宝石方块。

玩家在棋盘上进行滑动操作，每次交换相邻两个宝石的位置。当三个或更多同色宝石连成一线时，它们会被消除。消除宝石会触发对应的英雄攻击：红色宝石触发近战攻击，蓝色宝石触发远程攻击，绿色宝石触发治疗，黄色宝石触发特殊技能，紫色宝石触发全屏大招。

消除四个或更多宝石会产生特殊宝石（炸弹宝石或彩虹宝石），这些特殊宝石可以消除更大范围或任意颜色。

游戏的目标是通过三消触发英雄攻击，在限定回合内击败敌人。每个关卡有明确的回合数限制，回合用完但敌人未击败则失败。

胜利后获得金币、经验材料和英雄碎片。这些资源用于升级英雄等级、解锁新英雄和强化装备。

## 核心循环

三消战斗 → 获得金币和材料 → 升级英雄 → 挑战更高难度关卡

## 核心机制

- **颜色-职业映射**：每种颜色的宝石对应一种英雄职业，消除特定颜色宝石等于给对应英雄充能。玩家需要根据当前队伍构成选择优先消除的颜色，策略性在于资源分配。
- **特殊宝石系统**：四连产生行/列消除炸弹，五连产生彩虹宝石（可指定任意颜色全部消除）。特殊宝石可以连锁反应，带来巨大的爽快感。
- **回合制压力**：每个关卡的回合数是硬限制，玩家必须在有限步数内完成击杀。这创造了"差一步就成功"的张力。

## 为什么好玩

三消的低门槛和RPG的成长感完美结合。消除宝石带来的即时反馈（英雄攻击动画）让每次操作都有意义。看着自己的英雄从弱变强、通关越来越难的关卡，有持续的成就感。

## 粘性来源

- **数值成长**：英雄等级、装备、技能树提供长线目标
- **随机掉落**：每次战斗的棋盘布局不同，掉落英雄碎片有随机性
- **"差一点"效应**：回合数限制让玩家在"就差一步"时强烈想再来一次

## Meta 系统

- **英雄收集**：通过碎片解锁新英雄，每个英雄有独特技能
- **装备系统**：通关掉落装备图纸，收集材料制作
- **日常任务**：每日登录、完成指定关卡获得额外奖励
- **公会系统**：加入公会参与团队Boss战

## 实现难度

中。三消逻辑本身成熟，难点在于英雄AI与消除事件的联动设计——需要确保颜色消除到英雄攻击的映射在复杂战斗场景下仍然清晰、有反馈感。最大的技术难点是设计一个平衡的数值系统，让付费玩家和非付费玩家都有良好的体验。
