# 托尼·霍克：垂直极限（Tony Hawk VERT）

- **类型**: 体育街机
- **平台**: Mobile (iOS+Android) / Console
- **开发商**: Activision
- **首次发布**: 2010
- **一句话描述**: 滑板运动的街机版，玩家在U型场地（Vert Ramp）上完成各种空中特技。

## 玩法规则

游戏画面是第三人称视角，玩家操控滑板选手在U型滑道（半管）上来回滑行。屏幕显示得分、剩余时间和连击倍数。
基本操作：在U型坡道底部加速，冲到对面坡道顶部时在空中做特技动作。特技包括翻转（Kickflip/Heelflip）、抓板（Grab）、旋转（Spin/Flip）等。
每种特技有对应的按键组合。空中特技做得越多、组合越复杂，得分越高。落地成功获得分数，落地失败则摔倒失去时间和连击倍数。
连击系统：连续成功完成特技会累积连击倍数（x2, x3, x4...），连击越高每个特技的得分加成越大。一旦摔倒或落地不稳，连击清零。
游戏有时间限制，需要在限定时间内尽可能获得高分。某些关卡有目标分数要求，达到分数即过关。
游戏有多个场地（不同形状的U型坡道、街式滑板场等）和不同滑板选手（各有特殊技能）。

## 核心循环

加速冲上坡道 → 空中输入特技指令 → 成功落地得分 → 继续下一次冲刺 → 累积连击 → 时间耗尽结算

## 核心机制

- 特技输入系统：空中短暂窗口内输入正确的按键组合，考验反应力和操作精准度。组合越复杂得分越高
- 连击倍增器：连续成功特技累积倍数，鼓励玩家冒险尝试更难的特技组合来获取更高得分。连击越高风险越大——一次失误全部归零
- 时间压力：限定时间内最大化得分，制造'最后10秒我还能再冲一次'的紧张感

## 为什么好玩

空中连击的特技组合成功时，那种'我做到了'的成就感极强。
连击倍数不断攀升带来的兴奋感和'差几秒就能再得一次'的紧迫感让人停不下来。

## 粘性来源

特技连击的高分追求（'我要突破那个分数'）、解锁新特技的动作收集感、以及排行榜竞争。

## Meta 系统

解锁新滑板选手、新特技动作、新场地、滑板自定义。

## 实现难度

中 — 需要实现3D角色动画、特技输入检测、物理模拟。主要技术难点在于空中特技的动画流畅度和输入窗口判定。


游戏还包含特殊挑战关卡：要求在限定时间内完成特定特技组合，考验对特技系统的精通程度。某些版本支持在线排行榜，可以看到全球玩家的最高分记录。游戏的配乐以朋克和摇滚为主，与滑板文化完美契合。
