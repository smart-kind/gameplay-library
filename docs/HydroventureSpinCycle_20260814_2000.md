# Hydroventure: Spin Cycle (水之力量：旋转循环)

- **类型**: 物理解谜 / 动作
- **平台**: PS Vita
- **开发商**: Curve Studios
- **首次发布**: 2012
- **一句话描述**: 通过旋转和倾斜设备来控制水流方向到达终点的物理解谜游戏

## 玩法规则

玩家控制一股水流通过各种障碍到达终点。游戏利用PS Vita的重力感应和触屏功能来操控水流的方向和速度。

游戏界面以俯视视角呈现关卡布局。关卡中包含管道、闸门、障碍物和需要水流推动的机关。玩家通过倾斜设备改变重力方向，让水流向目标方向流动。

水流遇到障碍物会分流或停止。玩家需要利用旋转设备调整水流方向，使其通过正确路径到达终点。某些关卡需要收集散布在关卡中的水滴来获得更高评价。

游戏目标是将足够的水量引导至终点。三星评价系统基于收集的水滴数量和通关速度。

## 核心循环

倾斜设备引导水流 → 调整方向绕过障碍 → 收集水滴 → 到达终点 → 挑战评价

## 核心机制

- **重力感应控制**：通过倾斜设备改变水流方向，操作直觉且精准
- **流体物理模拟**：水的流动、分流和汇集基于真实物理规则，增加真实感
- **机关解谜**：关卡中的闸门、风扇和障碍物需要特定水流条件才能激活或绕过
- **收集系统**：隐藏水滴鼓励玩家探索关卡的各个角落

## 为什么好玩

重力控制水流的玩法非常直觉和独特，看着水流在精巧关卡中蜿蜒前行的过程充满满足感。流体物理的真实模拟让每次操作都有可预测又有趣的结果。

## 粘性来源

流体物理的观赏性 + 关卡解谜的成就感 + 三星评价的收集驱动 + "再试一次收集所有水滴"的追求

## Meta 系统

关卡解锁系统 — 完成当前关卡解锁下一阶段

## 实现难度

中 — 需要流体物理模拟和重力感应控制，最大技术难点在于流体渲染的性能优化和物理模拟的稳定性
