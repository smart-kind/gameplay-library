# 3Style

- **类型**: 益智 / 连线
- **平台**: Mobile (iOS)
- **开发商**: Unknown
- **首次发布**: 2008
- **一句话描述**: 一款三消连线益智游戏，玩家通过连接三个或更多相同元素来消除得分。

## 玩法规则

游戏界面是一个网格棋盘，上面随机分布着各种颜色或图案的元素。玩家通过手指滑动来连接三个或更多相同元素，被连接的同色元素会被消除并计分。

消除后上方的元素会下落填补空位，新的元素从顶部生成。游戏持续进行直到棋盘没有可用的移动，或者达到关卡目标（如指定分数、消除特定数量、或完成限时挑战）。

部分关卡包含特殊元素或障碍物：被锁定的方块需要多次消除、炸弹元素可以消除周围方块、彩虹元素可以消除同色全部方块。玩家需要策略性地规划消除顺序来最大化得分或完成目标。

## 核心循环

滑动连接同色元素 → 消除得分 → 新元素下落 → 达成目标/进入下一关

## 核心机制

- **路径连线消除**：区别于传统三消的交换机制，3Style使用"画线连接"的方式——玩家可以一次连接超过3个同色元素，连接数量越多得分越高。这种机制鼓励玩家寻找更长的连锁路径。
- **连锁反应**：消除后下落的新元素可能触发二次消除，形成chain combo，给予额外分数加成。
- **特殊道具**：长连线（5+）会生成特殊道具，如行/列消除炸弹、颜色清除器等，增加策略维度。

## 为什么好玩

"画线连接"的操作比传统"交换相邻元素"更自由、更灵活，玩家可以一次消除大量方块，产生强烈的视觉反馈和爽快感。同时寻找最优路径本身也是一种有趣的智力挑战。

## 粘性来源

- **连锁combo的爽快感**：一次连接多个元素并触发chain反应的即时反馈非常上瘾。
- **分数挑战**：每局结束后显示得分，激发玩家"下一次能连更多"的冲动。
- **短时间对局**：一局几分钟，随时可以开始一局新的。

## Meta 系统

无。专注于纯粹的核心消除玩法。

## 实现难度

中。网格匹配游戏的核心逻辑成熟且开源方案丰富。最大技术难点是路径识别算法——需要高效地检测玩家画出的路径是否全部为同色元素且连续，同时支持多点触控的流畅滑动输入。

## 变体设计

可以加入"限时挑战"模式，玩家在限定时间内尽可能多地消除方块；或者"无尽模式"，方块持续下落直到无法消除为止。这两种变体都能显著增加游戏的重玩价值。
