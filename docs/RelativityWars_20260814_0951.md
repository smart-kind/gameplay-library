# 相对论战争 (Relativity Wars)

- **类型**: 太空殖民模拟/物理策略
- **平台**: Mobile (iOS+Android)
- **开发商**: 未明确标注
- **首次发布**: 未明确标注
- **一句话描述**: 一款融入复杂物理定律的太空殖民模拟游戏，引导Toodian种族走向星辰大海

## 玩法规则

玩家扮演Toodian种族的领导者，引导他们踏上星际探索之旅。游戏开始时，Toodian的家园星球周围有许多宜居行星等待殖民。

导航和UI设计简洁——点击行星弹出菜单，发射飞船时点击目标位置即可。随着殖民进程推进，会遇到敌对的Squishian种族，冲突不可避免。

游戏的核心特色是融入了相对论物理定律。这使得游戏中的重力效果围绕行星呈现出独特的表现——飞船在行星附近的飞行轨迹会受到引力影响。

玩家可以通过建造队列来制造飞船和研究科技革新（如激光武器、地球化改造等）。大多数建造项目需要等待一定时间才能完成。在某些任务中，Squishian的部队会持续攻击已殖民的星球，玩家需要紧急建造防御力量。

有些任务过于简单，只需投资几项科技革新并派出几艘飞船就能轻松完成；而另一些任务则因为敌人的持续进攻而变得极其困难。

## 核心循环

点击殖民行星 -> 建造飞船/研究科技 -> 应对Squishian攻击 -> 扩大殖民版图

## 核心机制

- 相对论物理系统：飞船在行星附近飞行时受到真实引力影响，创造出独特的导航挑战
- 点击式殖民：简洁的点击交互——选择行星、发射飞船、设定目标，降低了入门门槛
- 建造队列系统：飞船和科技需要在队列中等待建造完成，增加了时间管理的策略维度
- 攻防对抗：Squishian种族会持续攻击已殖民星球，需要平衡扩张和防御

## 为什么好玩

相对论物理的融入让太空模拟有了独特性——引力影响飞船轨迹的效果在视觉上很新颖。看着自己的种族从一颗星球扩展到整个星系的成就感。

## 粘性来源

科技树的逐步解锁和殖民版图的不断扩大提供长期目标。但任务难度不均衡（太简单或太难）可能影响持续游玩的动力。

## Meta 系统

科技研发系统（激光、地球化改造等）和飞船制造队列。科技革新需要等待时间，飞船也需要排队建造。

## 实现难度

中等 — 操作简洁但物理系统增加了复杂性。最大技术难点是相对论物理引擎的准确实现和性能优化（实时计算引力轨迹）。
