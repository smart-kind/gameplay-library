# 推推推高尔夫 3D（Putt Putt Golf 3D）

- **类型**: 体育 / 休闲 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立开发者
- **首次发布**: 2010
- **一句话描述**: 3D 迷你高尔夫游戏，在精心设计的迷你球场上进行推杆挑战

## 玩法规则

游戏采用 3D 视角呈现迷你高尔夫球场。每个球场有独特的主题和障碍物设计：风车、水坑、斜坡、隧道、移动障碍等。

操作方式分三步：拖动屏幕调整瞄准方向（显示一条预测线），拖动力度条或向后拉控制击球力度，释放后高尔夫球沿预测轨迹运动。

球碰到障碍物会反弹或改变方向，玩家需要利用这些物理特性将球打进洞。部分球场设计需要球经过多次反弹才能入洞。

每个球场有标准杆数（Par），低于标准杆完成获得更高评价：小鸟球（Birdie）为 -1 杆，老鹰球（Eagle）为 -2 杆。超过标准杆则评价降低。

游戏通常有 18 个或更多球场，按难度递进排列。

## 核心循环

瞄准加控制力度 → 击球 → 球进洞或调整再次击球 → 完成球场进入下一关

## 核心机制

- **物理模拟**：3D 球体物理是游戏的核心——球的滚动、反弹、坡度影响都需要精确模拟。好的物理引擎让每次击球都有可预期的结果，这是迷你高尔夫游戏"公平感"的基础。玩家需要理解物理规律来规划击球路线。
- **障碍关卡设计**：每个球场都是一个小谜题——如何利用反弹角度、风力、坡度等因素让球进洞。有些球场的标准杆是 1 杆进洞，但需要精确的角度和力度。障碍物如风车叶片、移动平台增加了动态难度。
- **力度控制**：从轻度推杆到全力击球，力度控制决定了球的移动距离。力度过大球会飞出球场或撞到障碍物，力度不足则到不了洞口。力度条的精确控制是核心技能。
- **多人对战**：部分版本支持多人轮流击球，谁先用最少杆数完成所有球场获胜。

## 为什么好玩

迷你高尔夫的魅力在于"看似简单实则精巧"——每个球场的障碍设计都像一个物理谜题，找到正确的击球角度和力度时的成就感很强。3D 视角让空间感更强，也增加了判断难度。

## 粘性来源

- **解谜感**：每个球场都是一个小谜题，找到最优解的成就感
- **杆数挑战**：追求低于标准杆的完美表现
- **关卡数量**：大量球场提供持续的新鲜感
- **短局设计**：每个球场只需几杆，适合碎片时间

## Meta 系统

解锁新球场是主要进度。部分版本有球杆/球皮肤收集和在线排行榜。

## 实现难度

低到中 — 操作简单，但精确的力度和角度控制需要练习。最大技术难点是 3D 物理模拟的精确性和不同设备的性能适配。
