## 玩法规则

Tiki Towers 是一款塔防类移动端小游戏。

游戏界面简洁直观，核心操作区域清晰展示当前游戏状态。

玩家通过触屏点击或拖拽进行交互。每种操作都有即时的视觉反馈。

游戏的目标是完成设定的挑战条件。随着进度推进，难度逐步提升。

游戏结束条件：完成当前目标即过关，未能在限制条件下完成则失败。
