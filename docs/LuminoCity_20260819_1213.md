#  Lumino City（光影之城）

- **类型**: 解谜 / 冒险
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: State of Play Games
- **首次发布**: 2014
- **一句话描述**: 在一个由真实纸板手工搭建的微缩城市中探索、解谜，修复城市的电力系统。

## 玩法规则

游戏设定在一个完全由纸板、纸张和微型灯光搭建的微缩城市中。玩家控制主角 Lumi 在多个场景中移动探索。操作方式因平台而异：触屏版本通过**点击和拖拽**与场景中的物体交互；桌面版使用鼠标点击。

每个场景都是一个独立的解谜关卡。玩家需要观察场景中的各种机械装置、电路、机关和线索，通过点击、拖拽、旋转等操作来解决谜题。常见谜题类型包括：连接电路恢复供电、旋转齿轮启动机械、调整镜子反射光线、排列管道引导水流等。

游戏的核心目标是找到并修复城市中被切断的电力线路，最终恢复整座城市的光明。解谜过程中，玩家需要收集线索、阅读NPC的对话、发现隐藏通道。场景切换通过翻页式的动画实现，仿佛翻开一本书。

## 核心循环

进入场景 → 观察环境和机关 → 点击/拖拽解谜 → 恢复部分电力 → 解锁新场景 → 继续探索

## 核心机制

- **真实手工微缩世界**：所有场景都由真实的纸板、灯光和微型模型搭建后拍照而成，带来独一无二的视觉体验。
- **逻辑解谜**：每个谜题都有明确的因果关系——玩家操作某个机关，会直接影响场景中的其他元素（如通电后灯亮起、齿轮转动后门打开）。
- **叙事驱动**：通过NPC对话和环境叙事推动故事前进，解谜与剧情紧密交织。
- **多步骤解谜**：许多谜题需要玩家先完成前置步骤（如找到钥匙、接通电源），才能解锁最终解决方案。

## 为什么好玩

Lumino City 的最大魅力在于它的"手工感"——每个场景都是真实的物理模型，光影效果真实到让人想去触摸。解谜过程节奏舒缓但逻辑严密，每次成功解开一个机关时的成就感很强。同时，游戏讲述了一个关于城市断电、主角寻父的温馨故事，解谜和叙事完美结合。

## 粘性来源

- **叙事驱动**：玩家想知道故事结局，有强烈的继续探索动机。
- **手工美学**：独一无二的纸质微缩世界本身就是一种收集体验——每个场景都想看完。
- **解谜的"啊哈"时刻**：每个谜题解开时的顿悟感带来强烈的满足。
- **无失败惩罚**：解谜没有倒计时或生命值，玩家可以按照自己的节奏思考。

## Meta 系统

无。纯线性叙事解谜游戏，无成长或收集系统。

## 实现难度

高。核心难点在于真实微缩场景的拍摄和数字化（需要实际搭建物理模型并拍摄），以及谜题逻辑的设计（需要确保每个谜题都有合理的线索引导）。如果纯数字建模模拟手工质感，技术难度更高。
