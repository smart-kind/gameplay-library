# Genshin Impact（原神）

- **类型**: 开放世界动作RPG / 抽卡
- **平台**: Mobile (iOS+Android) / PC / PS
- **开发商**: miHoYo / HoYoverse
- **首次发布**: 2020
- **一句话描述**: 开放世界探索+元素反应战斗+角色收集，玩家在提瓦特大陆上冒险、解锁新区域、收集角色并组建队伍挑战各种内容。

## 玩法规则

游戏以第三人称视角展示一个广阔的奇幻开放世界。玩家可以在地图上自由跑动、攀爬、滑翔、游泳，探索城镇、山脉、森林和地下洞穴。

战斗系统基于四人队伍和元素反应。玩家控制一名角色进行即时战斗，可以随时切换队伍中的其他角色。七种元素（火、水、风、雷、冰、岩、草）之间存在反应关系：水+冰=冻结、火+水=蒸发、火+雷=超载、风+火=扩散等。通过组合不同元素的角色打出元素反应是战斗的核心策略。

每个角色有普通攻击、元素战技（E键）和元素爆发（Q键，需要积攒能量）三种攻击方式。角色通过抽卡（祈愿）获得，分为4星和5星稀有度。

探索过程中，玩家解开各种谜题（元素方碑、机关锁、宝箱机关）、收集资源、完成主线/支线任务、挑战Boss和秘境。

## 核心循环

探索世界 → 打怪获得经验和材料 → 升级角色和武器 → 挑战更难内容 → 抽卡获取新角色 → 继续探索

## 核心机制

- **元素反应系统**：七种元素之间的组合反应创造了丰富的战斗策略。例如水冻结敌人后破冰打出高额伤害，或用风扩散火元素造成范围燃烧。队伍搭配的核心就是围绕元素反应构建。
- **开放世界探索**：地图充满隐藏宝箱、解谜、收集品和传送点。使用"元素视野"可以发现隐藏的物品和机关，攀爬和滑翔系统让移动变得有趣。
- **树脂体力系统**：每日刷取角色升级材料和武器材料需要消耗"原粹树脂"（体力），体力随时间恢复。这限制了玩家每天的进度，但也创造了日常登录习惯。

## 为什么好玩

探索未知区域的惊喜感——每翻过一座山就可能发现隐藏的宝箱或风景绝美的地标。战斗中元素反应的combo带来爽快感，不同角色组合产生完全不同的战斗风格。

## 粘性来源

- **日常任务**：每天15分钟的日常委托，稳定但不耗时的日常循环
- **版本更新**：每6周一个大版本更新，新地图、新角色、新剧情持续吸引
- **抽卡欲望**：限定角色池和时间窗口制造FOMO（害怕错过）
- **探索完成度**：想100%探索每个区域、收集所有宝箱和神瞳

## Meta 系统

- **冒险等级**：账号整体等级，解锁新内容和提高世界等级
- **角色养成**：角色等级、武器等级、天赋等级、圣遗物（装备）四个养成维度，深度极高
- **深境螺旋**：每两周重置的高难度挑战，检验队伍强度，奖励丰厚
- **对核心玩法的影响**：养成系统是长期目标，深境螺旋提供挑战目标，但核心探索玩法不受养成影响

## 实现难度

高 + 开放世界游戏开发难度大，需要大量的地图设计、谜题设计、剧情内容和优化工作。元素反应系统的平衡、多平台适配（尤其是移动端性能优化）、实时联机功能都是技术挑战。最大的难点是持续的内容产出——每6周更新一个新版本需要巨大的开发团队支撑。
