# Factorio

- **类型**: 工厂建造 / 自动化
- **平台**: PC / Switch
- **开发商**: Wube Software
- **首次发布**: 2020
- **一句话描述**: 自动化流水线设计的终极游戏——建造、优化、扩展，停不下来。

## 玩法规则

玩家在外星球上建立自动化工厂，从手动采集资源开始，逐步构建传送带、组装机、冶炼炉等自动化系统。目标是在保持工厂高效运转的同时，研究科技并最终建造火箭发射。

游戏的核心循环是"瓶颈识别 → 解决方案 → 新瓶颈"。玩家铺设传送带连接采矿机到冶炼炉，组装机到仓库，形成自动化的生产和物流链。随着科技解锁，新的生产线和更高效的机器可用，需要重新规划整个工厂布局。

敌人（虫子）会攻击玩家的工厂，迫使他在自动化和防御之间平衡。游戏没有强制时间限制，玩家可以按自己的节奏建设。

## 核心循环

采集资源 → 建造自动化产线 → 识别瓶颈 → 扩展和优化

## 核心机制

- 自动化流水线：传送带、组装机、冶炼炉构建生产链
- 科技树：通过研究解锁新机器和配方
- 物流系统：火车、无人机和机器人运输
- 敌人威胁：虫子攻击迫使建设防御
- 自由节奏：无时间压力，按自己节奏建设

## 为什么好玩

"再来一条传送带"的上瘾感。每个优化都带来效率提升，每个瓶颈的解决都创造新的优化空间，永无止境。

## 粘性来源

- 持续优化循环：总有更好的布局方式等待发现
- 效率提升的满足感：看到自动化产线完美运转的成就感
- 科技解锁的期待：新配方和机器改变生产方式
- 自由建设：没有失败压力，纯粹的创造乐趣

## Meta 系统

科技研究和太空平台扩展。通过研究解锁新科技，最终目标是建造火箭。DLC 中扩展到太空平台。

## 实现难度

高。大规模自动化系统的性能优化（数千个实体同时运行）是核心难点。物流路径规划和敌人 AI 也需要精心设计。
