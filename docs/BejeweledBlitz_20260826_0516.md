# Bejeweled Blitz

- **类型**: 益智消除 / 限时挑战
- **平台**: Mobile (iOS)
- **开发商**: PopCap
- **首次发布**: 2011
- **一句话描述**: Bejeweled Blitz是PopCap Games的经典限时消除游戏。玩家在60秒内尽可能多地匹配宝石，创造连击和特殊宝石来获取高分。

## 玩法规则

游戏屏幕显示8x8的宝石网格，每种宝石有不同的颜色和形状。顶部显示倒计时（60秒）和当前得分。玩家通过滑动交换相邻的宝石位置。如果交换后形成3个或更多相同颜色的宝石连成一线，这些宝石消除并获得分数。消除宝石时可能产生特殊宝石：火焰宝石（消除一行或一列）、星星宝石（消除周围区域）、超魔方块（消除整屏同色宝石）。稀有宝石系统提供额外加成：太阳石、羽毛爆裂等稀有宝石配合加速器可以创造惊人高分。加速器系统包含Scrambler（打乱棋盘）、Detonator（引爆所有特殊宝石）等，最多可升级10次。

## 核心循环

滑动交换宝石 -> 匹配消除 -> 产生特殊宝石 -> 使用加速器 -> 60秒结束 -> 查看排名 -> 重复

## 核心机制

- 60秒限时：紧张的时间限制让每局充满刺激感
- 特殊宝石：火焰/星星/超魔方块，产生连锁消除效果
- 加速器系统：Scrambler/Detonator等，可升级10次
- 稀有宝石：太阳石、羽毛爆裂等提供额外高分机会
- Blitz Champions：全球玩家实时排名竞赛

## 为什么好玩

PopCap的经典设计：60秒的紧张感让每局都充满刺激。特殊宝石的连锁消除和加速器的组合使用创造了一发入魂的爽快感。全球排名让简单的消除游戏有了竞技维度。

## 粘性来源

60秒限时让再来一局的冲动极强；特殊宝石和加速器的组合创造无限可能；全球排名提供竞争动力；每周新比赛任务保持新鲜感

## Meta 系统

有加速器升级系统（最多10次）、稀有宝石收集（太阳石/羽毛爆裂等）、Blitz Champions全球排名、每周竞赛任务。内购虚拟货币可购买物品。

## 实现难度

中。核心难点在于益智消除玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
