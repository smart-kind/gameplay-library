# 我是刹那（I Am Setsuna）

- **类型**: JRPG / 回合制
- **平台**: Mobile (iOS) / PC / Switch / PS4
- **开发商**: Tokyo RPG Factory
- **首次发布**: 2016
- **一句话描述**: 致敬经典JRPG的回合制RPG，以刹那为情感核心，讲述护送少女走向终点的旅程

## 玩法规则

游戏采用回合制战斗系统，画面为3D场景配合回合制指令选择。

战斗中，每个角色有一个行动条，行动条满后可以执行指令：攻击、使用魔法、使用道具、防御。魔法系统以光和影为核心。

游戏最大的特色是Moment系统——在战斗中按下Moment键可以发动强力特殊攻击，但需要消耗有限的资源。

探索部分在3D地图中进行，玩家队伍从起点走向终点，沿途遇到敌人、宝箱和故事事件。

## 核心循环

探索3D地图 → 触发回合制战斗 → 使用魔法/技能击败敌人 → 推进剧情至终点

## 核心机制

- Moment系统：有限资源下的强力技能释放时机选择，是战斗的最大策略点。
- 光与影魔法：魔法系统分为光（恢复/增益）和影（攻击/减益），组合使用产生连锁反应。
- 线性叙事+回合制：地图探索是线性的（从A点到B点），但在过程中穿插回合制战斗，节奏紧凑。

## 为什么好玩

古典JRPG的氛围感——回合制战斗的仪式感、线性旅程的叙事张力、Moment系统释放时的震撼感。

## 粘性来源

叙事驱动——想看到故事结局 + Moment系统的爽感释放 + 古典JRPG情怀。

## Meta 系统

无传统Meta。角色能力提升来自剧情推进中获得的被动技能和新魔法。线性体验。

## 实现难度

中高。3D回合制战斗 + Moment系统 + 光暗魔法连锁 + 线性地图探索。最大技术难点：回合制AI的行为树设计和Moment系统的资源管理。
