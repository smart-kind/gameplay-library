# Quell（水滴谜境）

- **类型**: 解谜
- **平台**: Mobile (iOS+Android)
- **发行商**: Fallen Tree Games
- **首次发布**: 2011
- **一句话描述**: 一款优雅的滑动解谜游戏，玩家操控水滴在越来越复杂的迷宫中滑行，收集所有水滴后过关。

## 玩法规则

游戏画面设定在一个奇特的"客厅"场景中。核心玩法是引导一颗水滴穿过精心设计的迷宫。

操作方式非常简洁：玩家在屏幕上向左、右、上或下滑动，水滴就会朝对应方向持续滑动。水滴不会在中途停止——它会一直滑动直到撞到墙壁或障碍物才会停下来。

关卡中散布着多颗小水滴（目标水滴）。玩家需要用滑动手法操控主水滴，在迷宫中穿行并收集所有小水滴。每次滑动都需要深思熟虑，因为一旦开始滑动就无法中途改变方向。

随着关卡推进，迷宫变得越来越复杂。障碍物布局更加精巧，需要的滑动序列也更长。某些关卡可能需要在脑海中预演多步滑动序列才能找到正确的收集路径。

游戏的"客厅"场景设定有些古怪——评测提到这种呈现方式有时会分散解谜的注意力，但游戏本身的解谜质量非常高，制作精良。

## 核心循环

观察迷宫布局 → 滑动主水滴方向 → 收集路径上的水滴 → 规划下一步滑动 → 收集完所有水滴过关

## 核心机制

- **单向滑动**：水滴朝滑动方向持续运动，撞到墙壁才停止，无法中途转向
- **迷宫探索**：每关是一个独特设计的迷宫，障碍物布局逐步复杂化
- **全收集目标**：需要收集关卡内所有小水滴才能过关
- **逐步递增难度**：后续关卡需要更长的滑动序列和更精确的路线规划

## 为什么好玩

极简的操作（四方向滑动）配合深度递增的关卡设计，创造了经典的"易于上手、难于精通"解谜体验。游戏制作精良，打磨到位。虽然客厅场景设定有些古怪，但解谜本身的质量足以支撑体验。

## 粘性来源

解谜突破后的顿悟快感——"原来要这样滑"的顿悟时刻；逐步递增的难度曲线带来的持续挑战；简洁优雅的美术风格。

## Meta 系统

关卡递进——通过解锁新关卡群作为成长驱动。

## 实现难度

低 — 滑动逻辑和碰撞检测技术上很直接。最大难点是关卡设计——需要手工设计大量有趣的迷宫布局，确保每关都有独特的解题思路。
