# Celeste（蔚蓝）

- **类型**: 平台跳跃 / 独立游戏
- **平台**: PC / Mobile (iOS+Android) / Switch / PS / Xbox
- **开发商**: Maddy Makes Games
- **首次发布**: 2018
- **一句话描述**: 高难度精准平台跳跃游戏，玩家控制女孩玛德琳攀登塞莱斯特山，通过精确的操作和不断重试克服越来越难的障碍。

## 玩法规则

游戏为2D横向卷轴视角，玩家控制像素风格的角色玛德琳在充满障碍的山路上向上攀登。操作极其精简：移动、跳跃、冲刺和攀墙。冲刺可以向8个方向进行，在空中使用后可以短暂滑翔。

每个关卡由多个小房间组成，每个房间有特定的障碍和平台。玩家需要通过精确的跳跃、冲刺、攀墙、反弹等动作穿过房间。失败后立刻在房间起点重生，无死亡惩罚。

随着游戏推进，新的机制逐步引入：空中冲刺、攀墙、反弹水晶、移动平台、传送带、风区等。后期关卡需要玩家组合多种技巧才能通过。

草莓收集是可选挑战——每个关卡隐藏草莓分布在危险位置，收集草莓不推进进度但提供额外的挑战目标。B面和C面是每个关卡的高难度变体，需要解锁。

## 核心循环

尝试通过房间 → 失败 → 立刻重生 → 调整策略再尝试 → 通过后进入下一房间 → 完成章节

## 核心机制

- **精准操作**：游戏对输入精度要求极高，跳跃和冲刺的时机差几帧就会失败。但输入响应极其灵敏，每次失败你都知道是自己的操作问题而非游戏判定不公。
- **即时重生**：死亡后0.1秒内重生在房间起点，没有加载画面或动画。这种"零摩擦"重试机制让失败不再是挫折而是学习过程——你立刻就知道刚才哪里做错了，马上再试。
- **辅助模式**：游戏内置辅助选项（无敌、无限体力、游戏减速等），让任何水平的玩家都能体验完整故事。这体现了游戏的核心信息——"攀登"对每个人意义不同。

## 为什么好玩

当一个看似不可能的房间在第50次尝试后终于通过时，那种纯粹的成就感无与伦比。游戏把"失败-学习-成功"的循环做到了极致，每次死亡都让你变得更强。

## 粘性来源

- **"再来一次"的魔力**：即时重生+无惩罚设计让玩家不断想再试一次
- **B面/C面**：每关的高难度变体为高手提供终极挑战
- **草莓收集**：分布在危险位置的草莓给愿意冒险的玩家额外目标
- **速度跑社区**：全球玩家比拼通关时间，持续的挑战社群

## Meta 系统

无 + Celeste没有外围成长系统，每次通关都是从零开始。这种纯粹的设计正是其魅力所在——进步只存在于玩家自身的技术提升，而非角色数值。

## 实现难度

中 + 平台跳跃的核心机制实现不难，但最大难点在于关卡设计——每个房间的障碍排列需要精心设计，既要难到让玩家反复失败，又要让成功路径清晰可循（不是乱试运气）。手感调校（跳跃高度、冲刺距离、输入响应）需要大量微调。
