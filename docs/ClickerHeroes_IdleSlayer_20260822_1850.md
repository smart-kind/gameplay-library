# 点击英雄（Clicker Heroes - Idle Slayer）

- **类型**: 放置 / RPG / 点击
- **平台**: Mobile (iOS+Android)
- **开发商**: Playsaurus, Inc.
- **首次发布**: 2015
- **一句话描述**: 放置点击游戏的标杆之作——雇佣英雄、击杀怪物、转生获得古神力量

## 玩法规则

Clicker Heroes 是放置点击游戏的经典之作，最初在Steam和浏览器上大获成功后移植到移动端。玩家扮演英雄，通过点击和自动攻击击杀怪物，获得金币来雇佣和升级更多英雄。

游戏界面分为几个区域：左侧是当前战斗场景，英雄自动攻击怪物；右侧是英雄列表和升级按钮；顶部显示当前金币、击杀数和层级。

玩家可以通过点击屏幕手动攻击怪物，每次点击造成伤害。击杀怪物获得金币，用金币雇佣英雄（英雄会自动攻击）或升级已有英雄的伤害。每击杀一定数量的怪物后，进入下一个层级，面对更强的怪物。

每10个层级会有一个Boss战，Boss有倒计时限制。如果在限定时间内无法击杀Boss，层级会回退。击杀Boss后解锁新区域和更强大的英雄。

游戏后期可以转生（ascension），重置进度获得古神（Ancients）提供永久加成。古神系统极大增加了游戏的深度和策略性。

## 核心循环

击杀怪物获得金币 → 雇佣/升级英雄 → 推进层级 → 击杀Boss → 转生获得古神加成

## 核心机制

- 英雄雇佣系统：每个英雄有独立的攻击力和升级成本，需要合理分配资源。不同英雄有不同特色，增加策略选择
- Boss倒计时机制：每10层有Boss战，增加紧迫感和策略考量。需要在有限时间内最大化伤害输出
- 古神转生系统：转生后获得古神，提供永久性的全局加成。每个古神有不同的加成类型，需要策略性升级

## 为什么好玩

放置点击游戏的标杆之作，玩法成熟且深度十足。英雄系统和古神系统提供了丰富的策略选择。从弱小到强大的成长过程令人满足。庞大的玩家社区和攻略文化增加了社交维度。

## 粘性来源

英雄收集乐趣——每个新英雄都有独特外观和能力。古神系统提供深度策略。Boss战的紧迫感让玩家想'再试一次'。转生后的加速进程让每次重开都更高效。

## Meta 系统

古神系统：转生后解锁的古神提供各种永久加成（如增加金币产出、提高英雄伤害等）。古神可以升级，消耗灵魂石。对核心玩法的影响是提供深度的后期内容和策略选择。

## 实现难度

中等 — 成熟的放置游戏框架，需要平衡多个英雄和古神的数值。最大技术难点是庞大的数值体系设计，确保从前期到后期都有合适的节奏。
