# Idle Miner Tycoon

- **类型**: 放置 / 管理
- **平台**: Mobile
- **开发商**: Kolibri Games
- **首次发布**: 2017
- **一句话描述**: 经营矿井、最大化利润的放置管理游戏。

## 玩法规则

玩家管理多个矿井，雇佣经理自动化运营。核心是扩张——开新矿井、升级电梯和矿工、优化生产效率。自动化系统允许离线期间持续产出。

多矿场多元化收入来源，每个矿场有独立的升级路径。经理系统是关键——雇佣经理后该矿场完全自动化运行。

## 核心循环

升级矿井 → 雇佣经理 → 开新矿场 → 优化生产效率

## 核心机制

- 多矿场管理：每个矿场独立升级
- 经理系统：自动化单个矿场
- 离线收益：持续产出资源
- 扩张系统：不断开新矿场
- 优化策略：资源分配最大化利润

## 为什么好玩

将简单的点击转化为复杂的多矿场管理系统。看到多个矿井同时运转产生收入的满足感极强。

## 粘性来源

- 多线管理：多个矿场同时运转的满足感
- 经理雇佣：从手动到自动的转型快感
- 扩张驱动力：总有新矿场等待开发
- 优化空间：持续寻找更优资源配置

## Meta 系统

矿场解锁和经理雇佣。通过收益升级设施、雇佣经理、开新矿场。

## 实现难度

低。放置管理核心系统简单，难点在于多矿场的数值平衡和 UI 设计。
