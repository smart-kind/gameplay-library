# 寻物神秘协会（Hidden Objects Mystery Society）

- **类型**: 寻物解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Rolltower Studios Inc
- **首次发布**: 2014
- **一句话描述**: 加入秘密神秘协会，在欧洲各大名城中寻找隐藏物品、解开谜题、成为最伟大的侦探

## 玩法规则

游戏场景设定在欧洲各大名城（巴黎、伦敦、威尼斯、雅典、柏林等），每个城市包含多个精美的寻物场景。

玩家需要在场景中找到列表中指定的隐藏物品，部分物品需要与环境互动才能发现——打开博物馆的展柜、移开巴黎咖啡馆的桌布。

随着案件推进，玩家解锁新城市和新场景。同时提升在神秘协会中的等级——从新手会员到高级侦探。

游戏包含多个案件线，每个案件有独立的故事和角色。案件涉及各种神秘事件——失踪的文物、神秘的符号。

每个案件需要综合运用寻物技能和逻辑推理来解决。案件的难度逐渐递增。

## 核心循环

在欧洲名城中寻找隐藏物品 → 解开案件谜题 → 提升协会等级 → 解锁新城市和新案件

## 核心机制

- 城市主题寻物：每个欧洲城市有独特的视觉风格和地标建筑，场景变化丰富避免重复感
- 等级晋升系统：完成案件获得经验值提升等级，等级提升解锁新案件和奖励
- 多案件线叙事：多个独立案件并行推进，每个案件有完整的故事线和角色发展

## 为什么好玩

欧洲名城的美景和历史文化背景为寻物游戏增添了旅行体验感。

每个城市都有独特的氛围和故事，让玩家在寻物的同时仿佛在进行一次欧洲文化之旅。

神秘协会的设定让每次寻物都有了身份认同感——你不是在盲目找东西，而是在执行秘密任务，这种角色扮演元素大大增强了代入感。

## 粘性来源

等级晋升和城市解锁提供长线目标。多个案件线让玩家可以交替推进避免疲劳

## Meta 系统

等级晋升系统：通过完成案件获得经验升级，解锁新城市和案件

## 实现难度

低 — 寻物玩法简单直观。最大的技术难点在于大量高质量场景美术制作
