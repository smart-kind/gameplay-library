# Boom Beach: War Strategy（海岛奇兵）

- **类型**: 策略 / 塔防 / 建设
- **平台**: Mobile (iOS+Android)
- **开发商**: Supercell
- **首次发布**: 2014
- **一句话描述**: 在热带群岛上建立军事基地，训练军队，进攻敌方岛屿掠夺资源。

## 玩法规则

玩家拥有一座位于热带群岛中的岛屿基地。基地包含司令部（核心建筑）、兵营、防御塔、资源库、战舰等设施。游戏采用俯视视角，所有建筑和地形以2D等距投影呈现。

**建设阶段（在自己的基地）**：玩家可以建造和升级各种建筑——兵营解锁新兵种、防御塔（加农炮、狙击塔、火焰塔等）保护基地、资源库储存金币和木材、司令部决定可解锁的建筑等级。基地布局由玩家自由设计，防御建筑的摆放位置直接影响防守效果。

**进攻阶段（攻击敌方岛屿）**：玩家在地图上选择一个敌方岛屿（NPC或玩家），部署军队。进攻时的操作包括：①**拖拽部署**——将士兵从战舰上拖拽到敌方岛屿的登陆点；②**引导弹**——发射烟雾弹（让士兵潜行通过）、震爆弹（短暂冻结防御塔）、火炮（直接轰炸目标）、多管火箭（范围伤害）；③士兵会自动行进并攻击最近的敌方建筑。

资源通过金矿和锯木厂随时间产出，也可通过攻击敌方岛屿掠夺。资源用于升级建筑和训练军队。

## 核心循环

建设基地 → 训练军队 → 选择目标岛屿 → 部署兵力并使用技能 → 胜利获得资源 → 升级基地和军队 → 解锁新内容

## 核心机制

- **实时策略进攻**：进攻不是自动战斗，玩家需要实时使用引导弹和震爆弹来辅助部队，操作水平直接影响战斗结果。
- **非对称防守布局**：玩家自由摆放防御建筑，形成不同的防守策略（如外围密集防御保护司令部，或故意引诱敌人进入陷阱区）。
- **战舰能量系统**：每场进攻有有限的战舰能量（随司令部等级提升），引导弹和震爆弹消耗能量，要求玩家在"直接轰炸"和"战术引导"之间做资源分配决策。
- **任务特遣队（社交协作）**：玩家加入特遣队后可以参与团队任务——共同进攻高难度NPC基地，需要协调进攻顺序和分工。

## 为什么好玩

Boom Beach 将"基地建设"和"实时进攻操作"巧妙结合。防守时你是建筑师，进攻时你是指挥官。震爆弹冻结敌方防御塔的"战术时刻"让每次进攻都充满紧张感——什么时候冻？冻哪个塔？兵力怎么分散？这些决策让战斗充满策略深度。

## 粘性来源

- **基地建设的长期投入感**：每个升级都需要时间和资源，玩家有持续的动力返回查看进度。
- **复仇机制**：被攻击后可以立即反击攻击者，激发玩家的竞争心理。
- **特遣队社交协作**：团队任务需要多人配合，社交关系是强粘性来源。
- **资源管理的稀缺性焦虑**：资源不够升级哪个建筑的决策焦虑让玩家持续返回游戏。

## Meta 系统

- **英雄系统**：解锁和升级英雄角色，每个英雄有特殊能力（如远程治疗、范围伤害增强）。
- **雕像系统**：收集资源制作雕像，为基地提供永久加成（资源产出增加、防御力提升等）。
- **特遣队等级**：团队共同完成任务获得积分，提升特遣队等级解锁更高难度任务。

## 实现难度

高。核心难点是实时战斗中的AI路径寻路（多单位在复杂地形中的行进路线）、网络同步（PvP攻防的实时数据一致性）、以及经济系统的数值平衡（资源产出/消耗的长期平衡）。
