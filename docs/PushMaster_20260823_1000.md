# Push Master

- **类型**: 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: TATSUMAKI GAMES INC.
- **首次发布**: 2023
- **一句话描述**: PushMaster is an exhilarating hyper-casual game where you launch people into oncoming vehicles and watch them fly!

## 玩法规则

Push Master是一款休闲类移动游戏。游戏的核心体验围绕简单直观的触控操作展开，玩家通过屏幕互动来完成游戏目标。

游戏启动后，玩家看到主界面，通常包含开始按钮、设置选项和可能的进度展示区域。进入游戏后，画面中央是主要游戏区域，四周分布着操作按钮和状态信息。

玩家的操作方式以单指触控为主——点击、滑动或拖拽，具体取决于当前游戏模式。每次操作都会产生即时的视觉和物理反馈，让操作结果一目了然。

游戏的目标因模式而异：在竞速模式中需要比其他玩家更快到达终点；在解谜模式中需要找到正确的解决方案；在放置模式中则是持续积累资源并解锁新的升级。

游戏结束或过关的条件取决于具体模式：竞速模式以到达终点或时间耗尽为结束条件；解谜模式以完成当前关卡的谜题为过关条件；放置模式则没有明确的结束点，而是以不断解锁新内容为持续目标。

## 核心循环

休闲 → 获得分数/进度 → 用于推进关卡和解锁新模式

## 核心机制

- **推力物理谜题**：玩家控制角色向前奔跑，利用推力将敌人或障碍物推入指定区域或陷阱
- **连锁反应**：一个推力可能触发连锁反应，将多个物体推入目标区域，获得更高分数
- **关卡难度递增**：后续关卡加入更多障碍和更复杂的地形，需要更精准的时机把握

## 为什么好玩

操作极简但节奏紧凑，每局只需几十秒就能获得完整的游戏体验。随时随地都能开一局的设计让它成为完美的碎片时间伴侣。

## 粘性来源

极短的局时意味着"再来一局"的心理成本几乎为零。多样化的内容让每次游玩都有新鲜感。

## Meta 系统

成就系统：完成特定目标解锁成就徽章，提供持续的目标感。对核心玩法无直接影响。

## 实现难度

低 — 核心逻辑简单，主要工作量在于内容设计和UI打磨

每款独立小游戏的设计都遵循易于上手、难于精通的原则——入门只需几秒钟理解规则，但要达到高分需要反复练习和熟练掌握操作技巧。
