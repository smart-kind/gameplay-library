# 侠盗猎车手：三部曲（Grand Theft Auto: The Trilogy）

- **类型**: 开放世界/动作冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: Rockstar Games（Netflix 移植版）
- **首次发布**: 2023（Netflix版）
- **一句话描述**: 三款经典开放世界动作游戏的合集，Netflix 订阅用户可在手机上体验 GTA III、罪恶都市和圣安地列斯。

## 玩法规则

玩家在虚构城市中自由探索，完成任务、驾驶车辆、参与战斗。三款游戏各有不同主角和故事线，分别设定在自由城、罪恶都市和圣安地列斯三个标志性地点。玩家通过接取任务获得报酬，购买武器和房产，逐步扩大势力范围。游戏采用第三人称视角，包含射击、驾驶、近战等多种操作方式。

游戏世界充满互动元素：NPC 有日常行为模式，车辆可驾驶或窃取，建筑可进入。通缉系统根据犯罪程度升级，从一颗星到六颗星，警察响应逐渐从巡逻车到军队。玩家需要在完成任务的同时管理通缉等级。

## 核心循环

探索开放世界 → 完成任务赚取金钱 → 购买武器/房产/车辆 → 解锁新区域和故事线

## 核心机制

- 开放世界探索：三个不同时代的 3D 城市环境，各有独特的建筑风格、音乐和文化氛围
- 通缉系统：犯罪后警察追捕强度逐步升级，需要逃跑或对抗
- 任务多样性：主线剧情任务、支线任务、隐藏包裹收集等

## 游戏特色与历史意义

GTA III（2001）开创了3D开放世界游戏的先河，Vice City（2002）以80年代迈阿密为原型，San Andreas（2004）则以前所未有的规模呈现了整个加州。三款游戏在各自发布时代都定义了游戏工业的新标杆。

Netflix 移植版保留了原始游戏的全部内容和体验，并针对触屏进行了操作优化：虚拟摇杆控制移动，按钮控制射击和驾驶。游戏还包含原版的经典配乐和电台系统。

## 为什么好玩

三款定义了开放世界游戏的经典之作，现在可在手机上免费体验（Netflix 订阅）。从 90 年代的自由城到 80 年代的罪恶都市再到 90 年代初的加州，每个时代都有独特的魅力。

## 粘性来源

庞大的开放世界提供数百小时内容，标志性配乐，以及逐步建立犯罪帝国的成就感。三款游戏三种完全不同的氛围和故事。

## Meta 系统
