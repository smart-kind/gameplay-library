# 小小塔楼（Tiny Tower）

- **类型**: 模拟经营 / 放置 / 增量游戏
- **平台**: Mobile (iOS+Android)
- **开发商**: NimbleBit
- **发行商**: NimbleBit
- **首次发布**: 2011
- **一句话描述**: 建造和管理一座多层高楼，吸引虚拟居民入住各楼层商铺，通过经营产生收入来扩建更多楼层

## 玩法规则

游戏画面以像素风格呈现一座垂直的高楼，玩家从地面开始逐层向上建造。每层楼可以选择不同的功能类型——住宅层、商铺层（如咖啡店、书店、花店、健身房等），每种楼层类型有其独特的经营机制。

玩家通过点击电梯来移动楼内居民（称为"bitizen"）到指定楼层。居民会自动在商铺楼层工作，并在住宅楼层休息。商铺会随着时间自动产生金币，玩家可以点击电梯快速运送货物来加速商铺运营。

每一层楼的建造需要花费金币，楼层越高建造成本越高。玩家还需要通过"BitBook"社交功能来拜访朋友的塔楼，互送礼物。游戏还包含"梦幻楼层"（Dream Job）机制——当居民被分配到与其梦想职业匹配的商铺时，会获得额外奖励。

## 核心循环

建造楼层 → 招募居民 → 居民工作产生金币 → 用金币建造更多楼层 → 扩建更高

## 核心机制

- **楼层类型多样化**：商铺层有不同的经营类型（餐饮、零售、服务等），每种类型的金币产出速度和所需货物不同，玩家需要平衡搭配
- **梦幻职业匹配**：每个居民有隐藏的梦想职业，当被分配到对应楼层时，玩家获得奖励金币。这个机制鼓励玩家不断尝试不同的楼层组合
- **电梯管理系统**：电梯是玩家与楼内互动的核心工具，需要手动操作运送居民和货物，给放置类游戏增加了一定的操作参与感
- **异步社交**：可以拜访朋友的塔楼并互赠礼物，增加了社区互动性

## 为什么好玩

Tiny Tower 完美抓住了"放置+管理"的核心乐趣——你不需要时刻盯着屏幕，但每次打开游戏都有新的金币收入可以投资。像素风格的塔楼看着自己一层层建高，有强烈的成就感。梦幻职业匹配机制像是开盲盒，猜中时的小惊喜让人上瘾。

## 粘性来源

- **渐进式扩建**：每建一层都有可见的进度反馈，塔楼越来越高是持续的正向激励
- **放置收益**：离线期间商铺仍在产生金币，玩家每次回来都有"收租"的快感
- **梦幻职业收集的随机性**：不确定哪个居民的梦想职业是什么，驱动玩家不断尝试新组合
- **社交拜访**：看朋友的塔楼获得灵感，互赠礼物增加社区归属感

## Meta 系统

金币是唯一的货币系统，用于建造楼层和升级。没有付费墙，但可以通过内购获得金币加速。整体是轻量级的进度系统，核心乐趣在于建造和管理过程本身。

## 实现难度

低。像素风格 2D 画面，核心逻辑是楼层管理和金币产出的数值系统。电梯动画和居民移动是简单的状态机。最大技术难点在于数值平衡——确保金币产出和消耗的节奏让玩家有持续的成长感而不会过快或过慢。
