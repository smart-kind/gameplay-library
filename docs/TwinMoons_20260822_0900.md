# Twin Moons (Twin Moons)

- **类型**: 隐藏物品寻物 / 冒险解谜 / 叙事冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: G5 Entertainment AB
- **首次发布**: 2016
- **一句话描述**: 穿越维度之门到"半世界"，在精美的场景中寻找隐藏物品并解开跨维度谜团的冒险解谜游戏

## 玩法规则

游戏以一个失踪科学家父亲的故事为开端，玩家扮演子女穿越到一个被称为"半世界"（Halfworld）的维度交叉点——这里是多个宇宙交汇的神秘之地。

每个关卡呈现一幅精心绘制的场景画面，玩家需要在其中寻找隐藏物品。物品以经典的隐藏物品游戏方式分布：部分被遮挡、伪装、缩小或融入背景。玩家找到物品后可以推进剧情或解锁新区域。

操作方式：在场景中浏览寻找目标物品，点击找到后可获得线索或推进道具。某些物品需要与其他物品组合使用，或需要在特定剧情节点才能发现。

游戏还包含迷你解谜环节——找到物品后可能需要完成拼图、密码破解或其他小型益智挑战才能继续推进。

## 核心循环

寻找隐藏物品 → 获得线索/道具 → 解开谜题 → 推进剧情 → 穿越新场景 → 发现更多维度秘密

## 核心机制

- **维度穿越叙事**：故事跨越多个平行世界，每个世界的视觉风格和谜题类型不同，保持新鲜感
- **物品组合系统**：找到的物品不是终点，部分物品需要组合使用或在特定场景中使用
- **多角色互动**：旅途中遇到各种鲜明角色，他们的对话和任务推动故事发展
- **迷你解谜穿插**：在寻物之外穿插拼图、密码破解等不同类型的解谜，避免玩法单一

## 为什么好玩

将传统的寻物游戏包装在一个"跨维度冒险"的科幻/奇幻叙事中，让每一次寻找物品都有故事意义——你不是在"找钥匙"，而是在"寻找打开维度之门的远古遗物"。G5 Entertainment在隐藏物品领域的成熟工艺保证了场景美术质量和谜题设计的精良。

## 粘性来源

叙事悬念是核心粘性——"父亲到底去了哪里？半世界的秘密是什么？"驱动玩家持续游玩。G5标志性的精美手绘场景本身就值得探索，每到一个新场景都有"哇"的视觉冲击。迷你解谜的多样性确保不会因单一玩法疲劳。

## Meta 系统

- **剧情收集系统**：收集日记、信件、照片等叙事物品，逐步揭开故事全貌
- **道具背包**：玩家收集的物品存储在背包中，在后续场景中使用，提供资源管理维度
- **成就系统**：完成特定挑战（如无提示通关、快速完成等）获得成就徽章

## 实现难度

中。寻物核心引擎技术上不难，但需要大量高质量美术场景、复杂的叙事分支和道具交互系统。最大技术难点是构建一个跨多场景的道具使用系统——确保玩家在不同场景间携带的道具逻辑一致且不会导致进度卡死。
