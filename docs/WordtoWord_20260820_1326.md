# 单词对单词（Word to Word: Fun Brain Games）

- **类型**: 文字 / 益智 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: MochiBits, LLC
- **首次发布**: 2014
- **一句话描述**: 经典的词汇联想游戏——找到一个词连接上下两个单词，测试你的词汇量、同义词掌握和联想能力。

## 玩法规则

游戏画面简洁：上方显示一个单词，下方显示另一个单词，中间有一个空白格需要填入连接词。玩家的挑战是找到一个词，使得它既与上方的词有关联，又与下方的词有关联。

例如：上方显示 "Hot"，下方显示 "Dog"，正确答案可能是 "Chocolate"（Hot Chocolate 和 Chocolate Dog）。或者上方 "Sea"，下方 "Food"，答案是 "Food"（Sea Food 本身就是一个词）。

玩家操作：在虚拟键盘上输入猜测的单词，系统实时判断是否正确。输入错误的单词会消耗一次机会或增加计时。部分模式支持"提示"功能，显示连接词的字母数量或首字母。

游戏有多种模式：限时模式需要在倒计时内完成尽可能多的配对；经典模式没有时间限制；挑战模式则是找到最短的连接链条将两个完全不相关的词连接起来。

## 核心循环

观看上下两个单词 → 思考联想连接词 → 输入答案 → 正确则进入下一题/错误则重试或跳过

## 核心机制

- **词汇联想桥接**：核心玩法是找到连接两个词的"桥梁词"，考验玩家的语义网络广度和联想能力
- **多词链挑战**：高级模式中需要找到多个中间词将两个完全不相关的词连接，类似"六度分隔"的文字版
- **难度自适应**：系统根据玩家表现动态调整题目难度，保持挑战性和成就感的平衡

## 为什么好玩

Word to Word 的迷人之处在于它激活了大脑中平时不太使用的"词汇联想"能力。找到一个巧妙的连接词时的"灵光一闪"体验极其令人满足。而且它不需要任何专业知识——只需要你有一定的英语词汇量和愿意动脑思考的态度。多人对战模式下，看着对手比你先答出答案的紧迫感也增加了额外刺激。

## 粘性来源

- **知识拓展**：每局游戏都接触到新的词组和表达方式，持续扩充词汇量
- **每日挑战**：每日一组新题目，保持长期参与度
- **多人竞技**：实时与其他玩家比赛谁先找到连接词，增加竞争快感

## Meta 系统

包含玩家等级和经验值系统。完成题目获得积分，积分提升等级并解锁新的题目分类（如科学、历史、流行文化等）。还有成就系统记录"连续答对X题""找到最短连接链"等里程碑。

## 实现难度

低。核心是一个词典匹配引擎，技术实现相对简单。最大难点在于词库建设和题目质量——需要大量高质量的词对数据，并且确保每个题目有合理的唯一答案或少数几个可接受答案。
