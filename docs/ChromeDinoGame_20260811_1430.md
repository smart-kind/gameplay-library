# 谷歌恐龙游戏（Chrome Dino Game / T-Rex Runner）

- **类型**: 横版跑酷 / 无限生存
- **平台**: Web (Chrome浏览器离线页面)
- **开发商**: Google Chrome团队
- **首次发布**: 2014
- **一句话描述**: 在没有网络连接时，Chrome浏览器中隐藏的像素风恐龙跑酷游戏

## 玩法规则

游戏画面是一条简单的水平线（地面），一只像素风格的小霸王龙在左侧奔跑。障碍物（仙人掌、翼龙）从右侧向玩家方向移动。

玩家只有两个操作：按空格键/上箭头让恐龙跳跃，按下箭头让恐龙低头（躲避翼龙）。仙人掌有不同高度——有的低需要跳跃，有的高可能需要精确时机。翼龙有高低两种飞行高度，低飞翼龙需要跳跃躲避，高飞翼龙需要低头通过。

游戏速度会随着时间逐渐加快，障碍物出现频率也随之增加。得分以奔跑距离计算，每100分会伴随音效提示。

没有终点——目标是尽可能活得久、跑得更远。

## 核心循环

跳跃/躲避障碍物 → 速度加快 → 更密集的障碍 → 撞上结束 → 重新开始

## 核心机制

- **渐进加速**: 游戏速度从慢到快持续递增，自然地将玩家推向极限
- **模式识别**: 障碍物按固定模式组合出现，熟练玩家可以记住节奏
- **极简操作**: 只需要跳和低头两个动作，上手零门槛
- **隐藏可及性**: 它不是一个主动打开的游戏，而是在断网时"被发现"的彩蛋

## 为什么好玩

Chrome Dino的魅力在于它的可及性和意外性——你不需要下载任何东西，不需要找游戏网站，只需要断网就能看到它。这种"在无聊时刻出现的小惊喜"本身就很有吸引力。游戏本身也很精良，难度曲线平滑，像素画风可爱。

## 粘性来源

速度的持续增加创造了"挑战自我极限"的驱动。100分的音效提示提供了阶段性成就感。由于游戏可以在任何断网时刻出现，它成为了"无聊时的默认选择"，形成了使用场景驱动的粘性。

## Meta 系统

无。纯分数驱动。

## 实现难度

低 — 横版卷轴+碰撞检测+简单的物理跳跃。最大的技术难点可能是精确的碰撞盒调优（确保玩家觉得碰撞是公平的），以及随着速度增加时障碍物生成的节奏控制。
