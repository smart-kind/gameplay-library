# Bacterial Takeover - Idle game

- **类型**: 放置点击 / 科幻策略
- **平台**: Mobile (iOS)
- **开发商**: Fufla SIA
- **首次发布**: 2017
- **一句话描述**: Bacterial Takeover是一款独特的细菌主题放置点击游戏。玩家扮演致命细菌的大亨，通过不断繁殖和进化细菌来占领宇宙中的各个星球。

## 玩法规则

游戏以宇宙星空为背景，屏幕中央显示当前正在感染的星球和细菌数量。底部有点击按钮和升级选项。玩家通过点击屏幕来繁殖细菌，每次点击增加细菌数量。细菌数量足够多时可以感染一个星球。感染星球后获得矿物资源，用于购买纳米技术升级、进化超级细菌等。升级后每次点击产生的细菌数量大幅增加。游戏包含大量升级选项和成就系统，每种升级有不同的效果和成本。超级细菌可以突变出更强的能力。游戏支持离线模式，无需网络连接即可游玩。

## 核心循环

点击繁殖细菌 -> 感染星球 -> 获取矿物 -> 购买升级 -> 进化更强细菌 -> 感染更多星球 -> 重复

## 核心机制

- 点击繁殖：通过点击增加细菌数量，是基础交互方式
- 星球感染：细菌数量达标后感染星球，获得矿物资源
- 升级系统：纳米技术、超级细菌突变等大量升级选项
- 离线模式：无需网络连接即可游玩，适合碎片时间

## 为什么好玩

独特的细菌主题让放置游戏有了新鲜感：不是常规的点击赚钱，而是用细菌征服宇宙。看着细菌数量从个位数增长到天文数字的指数增长过程非常解压。

## 粘性来源

天文数字的细菌增长带来强烈的满足感；大量升级选项提供持续目标；离线模式让随时都能玩

## Meta 系统

有成就系统（记录感染星球数、细菌总数等）、升级树（纳米技术、超级细菌）、社区运营（Facebook/Twitter/Discord活跃社区）。

## 实现难度

中。核心难点在于放置点击玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
