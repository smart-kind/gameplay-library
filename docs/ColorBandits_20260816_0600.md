## 玩法规则

游戏画面由各种谜题元素组成，玩家通过逻辑推理和操作来解决谜题。

1. **观察分析**: 仔细观察当前谜题的布局，识别可用元素和规则
2. **交互操作**: 通过点击、拖拽、滑动或旋转来移动/改变游戏中的元素
3. **连锁反应**: 某些操作会触发连锁反应，一个元素的改变会影响相邻元素
4. **目标达成**: 每个关卡有明确的解谜目标（如将所有元素归位、消除所有障碍等）
5. **步数/时间限制**: 部分关卡有步数或时间限制

游戏难度逐步递增，引入新的机制和元素组合，考验玩家的逻辑思维和空间想象力。

## 核心循环

观察谜题 → 操作解谜 → 通关获得新机制 → 挑战更复杂谜题

## 核心机制

- **基础交互**: 触屏操作，根据解谜类型的核心玩法进行点击/滑动/拖拽
- **关卡递进**: 通过逐步增加难度的关卡设计，让玩家在学习和精通之间保持平衡
- **即时反馈**: 每次操作都有明确的视觉和音效反馈，增强操控感

## 为什么好玩

解谜类游戏的核心魅力在于操作的即时反馈和不断突破自我的成就感。玩家在碎片时间内可以快速进行一局，失败后可以立即重开，"差一点就成功"的不甘心理是驱动重复游玩的关键。

## 粘性来源

- **短期粘性**: 每局时间短（1-3分钟），心理成本低，"再来一局"的冲动强烈
- **中期粘性**: 关卡难度递增提供持续的成就感和明确的挑战目标
- **长期粘性**: 分数排行榜、成就解锁或收集元素驱动长期目标

## Meta 系统

无 — 游戏聚焦于核心玩法本身

## 实现难度

低 — 解谜类游戏的核心机制相对简单，主要挑战在于关卡设计和手感调优。最大技术难点在于实现流畅的操作反馈和合理的难度曲线。
