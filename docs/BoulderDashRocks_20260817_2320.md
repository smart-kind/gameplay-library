# 推石头（Boulder Dash Rocks）

- **类型**: 挖掘解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: First Star Software
- **首次发布**: 2010
- **一句话描述**: 经典Boulder Dash的移动版本，玩家在地下洞穴中收集宝石同时躲避掉落的岩石。

## 玩法规则

游戏画面是俯视视角的2D网格地下洞穴，包含泥土、岩石、宝石、墙壁等不同元素。玩家角色是一个小矿工。
操控：方向键或滑动控制角色向四个方向移动。角色可以挖掘泥土向前移动，但不能穿过岩石和墙壁。
物理规则：岩石和宝石会受重力影响下落。如果角色挖掉了岩石下方的泥土，岩石会掉落。如果角色正好在岩石正下方，会被压到损失一条命。
目标：在每个关卡中收集一定数量的宝石（屏幕左上角显示需要收集的数量），然后找到出口逃离。
策略要素：可以利用岩石的下落来'砸'开某些障碍（岩石砸到泥土上会将其破坏），也可以利用岩石形成临时的支撑结构。但必须小心不被掉落的岩石压到。
关卡有时间限制，超时失败。某些关卡有特殊元素：传送门、开关、会移动的敌人等。

## 核心循环

观察关卡布局 → 挖掘泥土前进 → 收集宝石 → 利用/躲避岩石 → 到达出口 → 进入下一关

## 核心机制

- 重力物理谜题：岩石和宝石的下落行为既是危险也是工具，利用它们砸开道路或保护自己需要精确计算。'我挖了这块土，石头会掉下来砸开下面的墙'——这种推理过程很有趣
- 路径规划：需要规划收集宝石的顺序和路径，确保不被困在死胡同或被岩石压到
- 时间压力：倒计时制造紧迫感，不能无限期地谨慎探索

## 为什么好玩

在'贪婪多挖一颗宝石'和'赶紧逃命'之间的拉扯非常紧张刺激。
利用岩石下落砸开障碍的聪明解决方案带来智力满足感，仿佛自己是个物理学家。

## 粘性来源

'差一颗宝石就过关但不敢冒险'的紧张感、解谜成功后的成就感、以及关卡递进的探索欲。

## Meta 系统

关卡递进、隐藏关卡解锁。

## 实现难度

低 — 核心是网格移动和重力物理模拟。主要技术难点在于物理行为的稳定性和关卡设计，以及岩石下落的动画流畅度。


某些高级关卡引入了连锁反应设计——一块石头下落触发另一块石头下落，形成多米诺效应。理解并利用这种连锁是通关高级关卡的关键。游戏还包含隐藏通道，需要特定的挖掘顺序才能发现。
