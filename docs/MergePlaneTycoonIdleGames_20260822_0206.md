# Merge Plane Tycoon: Idle Games

- **类型**: 放置
- **平台**: Mobile (iOS+Android)
- **开发商**: Cool GamApp Limited
- **首次发布**: 2018
- **一句话描述**: 一款放置类手机游戏，核心玩法围绕合成放置展开

## 玩法规则

玩家在Entertainment, Simulation, Strategy类型的游戏界面中，主要进行合成放置的操作。

将两个相同等级的物品合并为更高等级，产生持续收益。离线时也能积累资源，形成数值成长循环。合成链设计让玩家不断追求更高级别的物品，解锁新设施和生产线。

游戏的目标是合成物品升级，当合成到目标等级时即可过关。

每局游戏的画面布局清晰，UI元素分布合理，玩家可以轻松识别可操作区域和当前状态。操作方式以点击和拖拽为主，符合移动端用户的操作习惯。

游戏通过精心设计的视觉效果和音效反馈，让每个操作都有明确的响应。随着关卡推进，游戏逐步引入新的元素和机制，保持新鲜感的同时不会让玩家感到信息过载。

游戏的难度曲线经过精心设计，前期关卡主要帮助玩家熟悉操作和基本规则，随着进度推进逐步引入新的挑战和限制条件。每个关卡都有明确的成功条件和失败条件，让玩家清楚知道自己需要达成什么目标。

游戏界面中的关键信息（如当前进度、剩余资源、可用道具等）始终清晰可见，确保玩家随时掌握游戏状态。在关键时刻提供适当的视觉和听觉反馈，增强操作的满足感。

## 核心循环

合成物品升级 -> 获得更高产出和资源 -> 解锁新设施和合并项

## 核心机制

- **合成放置**: 将两个相同等级的物品合并为更高等级，产生持续收益。离线时也能积累资源，形成数值成长循环。合成链设计让玩家不断追求更高级别的物品，解锁新设施和生产线。

## 为什么好玩

合成升级带来明确的数值成长快感，放置收益让每次回归都有收菜的喜悦。策略性的合成顺序和空间管理让游戏有深度而非纯自动。

## 粘性来源

数值成长曲线——合成到更高等级物品的渴望驱动持续操作；离线收益机制让人定时回来收菜；新物品解锁带来的新鲜感。

## Meta 系统

设施升级与离线收益——用合成产出的资源升级生产线和仓库容量，解锁新的可合成物品线，离线期间自动积累资源，形成回归驱动力。

## 实现难度

中 — 核心合成逻辑简单，但需要设计合理的数值曲线、离线收益平衡和多种合成线，最大难点是数值调优。
