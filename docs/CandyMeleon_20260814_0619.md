# CandyMeleon

- **类型**: 街机 / 变色
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款控制变色龙通过变色来通过障碍的街机游戏，玩家需要根据背景颜色实时改变角色颜色

## 玩法规则

游戏呈现一个不断变化的彩色背景。玩家控制一只变色龙在屏幕上移动（自动向前或可操控方向）。

背景颜色周期性变化（红、绿、蓝等）。当变色龙颜色与背景相同时，可以安全通过对应颜色的区域。当颜色不匹配时，触碰即失败。

玩家通过点击屏幕来切换变色龙的颜色。不同颜色通道需要不同的操作时机。变色龙的移动速度和背景颜色变化速度会随关卡递增。

关卡中散布着糖果，收集可获得分数。目标是收集所有糖果并到达终点，同时保持变色龙颜色与环境匹配。部分关卡有多个颜色通道交替出现。

游戏设有速度模式，背景颜色变化速度大幅提升，考验玩家的反应极限。速度模式有独立排行榜。

## 核心循环

观察背景颜色 → 切换变色龙颜色 → 通过障碍收集糖果

## 核心机制

- **颜色匹配**：变色龙颜色必须与当前区域匹配才能通过
- **节奏切换**：背景颜色按规律变化，需要掌握切换节奏
- **糖果收集**：在颜色匹配的同时收集分散的糖果

- **速度模式**：背景颜色变化速度大幅提升


## 为什么好玩

颜色匹配的机制简单但有挑战性。变色龙主题可爱，视觉反馈清晰。

## 粘性来源

节奏掌握的成就感+收集目标的驱动。

## Meta 系统

无。纯关卡挑战。

## 实现难度

低 — 单按钮切换颜色。最大技术难点是颜色变化的节奏设计和视觉反馈。
