# Candy Crush Saga（Candy Crush Saga）

- **类型**: 三消匹配 / 关卡制解谜
- **平台**: Mobile (iOS+Android) / Web (Facebook/浏览器)
- **开发商**: King
- **首次发布**: 2012
- **一句话描述**: 交换相邻糖果实现连消，完成各种目标，关卡数超过 15000 关的三消王者

## 玩法规则

游戏画面是 9x9 的网格（各关卡尺寸不同），网格中随机填充各种颜色的糖果。玩家每次交换两个相邻糖果的位置，如果交换后形成 3 个或以上相同颜色的连线，这些糖果消除，上方糖果落下填补空格。

消除 3 个 = 普通消除，消除 4 个 = 产生条纹糖（消除整行或整列），消除 L/T 形 = 产生包装糖（爆炸消除 3x3 区域），消除 5 个 = 产生彩色糖（消除所有同色糖果）。

特殊糖果之间还可以组合：条纹糖+包装糖=大面积爆炸，彩色糖+条纹糖=全屏同色消除，彩色糖+彩色糖=消灭全棋盘所有糖果。

每关有特定目标：达到目标分数、消除指定数量的某种糖果、清除巧克力、拯救被困动物等。每关有步数限制，步数用完未完成目标 = 失败。

## 核心循环

观察棋盘 → 规划交换 → 执行消除 + 触发特殊糖果 → 完成目标过关 → 解锁下一关

## 核心机制

- 机制1：特殊糖果系统——4+连消产生的特殊糖果是游戏策略深度的核心，玩家需要主动制造特殊糖果而非随机等待
- 机制2：连锁反应——消除后新糖果落下可能自动触发新的匹配（combo），产生额外的分数和爽感
- 机制3：步数限制——不是无限消除，而是有步数约束的优化问题，需要规划而非运气

## 为什么好玩

"连锁消除"的视觉和听觉反馈极其满足——屏幕炸开、糖果飞舞、音效清脆。同时"差一步就过关"的不甘心是最强的再玩驱动力。关卡设计从简单逐步过渡到需要策略规划，学习曲线平滑。

## 粘性来源

关卡进度驱动（15000+ 关的超长内容）+ 社交竞争（Facebook 好友排行榜）+ Lives/体力系统（用完等恢复，恢复后想玩）+ 限时活动 + booster 收集

## Meta 系统

Lives/体力系统（每 30 分钟恢复 1 条命，最多 5 条）+ booster 道具收集（锤子、彩虹糖等辅助道具）+ 世界地图分区推进 + 赛季活动。

## 实现难度

低。核心的网格匹配算法非常成熟。技术难点不在引擎，而在：（1）关卡设计量——需要设计 15000+ 个各有特色的关卡；（2）数值平衡——保证关卡难度曲线合理，让玩家"偶尔失败但愿意重试"。
