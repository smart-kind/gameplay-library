# Valheim

- **类型**: 生存 / 沙盒冒险
- **平台**: PC / Linux / macOS / Xbox
- **开发商**: Iron Gate Studio
- **首次发布**: 2021
- **一句话描述**: 维京幻想的巅峰——每个生物群系都是一次冒险，每个 Boss 都是一个里程碑。

## 玩法规则

玩家在程序生成的维京世界中求生，从简陋的木棚开始，逐步建立堡垒、锻造武器、建造船只探索海洋。世界分为多个生物群系（草原、黑森林、沼泽、山脉、平原等），每个群系有不同资源和敌人。

核心循环是探索新群系 → 收集资源 → 锻造新装备 → 挑战 Boss → 解锁新区域。Boss 是各群系的守护者，击败后获得关键物品用于解锁下一阶段。

多人合作是游戏的核心体验——最多 10 名玩家在同一服务器上合作建设、探索和战斗。建筑系统允许玩家建造从简陋小屋到宏伟城堡的各种结构。

## 核心循环

探索生物群系 → 收集资源 → 锻造装备 → 挑战 Boss → 解锁新区域

## 核心机制

- 生物群系递进：从草原到平原的难度递增
- 锻造系统：用收集的材料锻造武器和工具
- Boss 系统：各群系守护者提供关键物品
- 建筑系统：自由建造各种结构
- 多人合作：最多 10 人合作

## 为什么好玩

每个生物群系都是一次全新的冒险。从木石工具到钢铁盔甲的成长过程让人上瘾，和好友一起建造维京堡垒的体验独一无二。

## 粘性来源

- 探索驱动力：每个新群系都有新资源和挑战
- Boss 里程碑：击败 Boss 的成就感极强
- 建筑自由：从简陋小屋到宏伟城堡的创造空间
- 多人合作：与好友一起生存的乐趣

## Meta 系统

Boss 进度和科技解锁。击败 Boss 获得关键物品，解锁新配方和能力。

## 实现难度

高。程序生成的开放世界、多人同步、物理建筑和 Boss AI 需要整合多个复杂系统。
