# 合成客栈（Merge Inn - Tasty Match Puzzle）

- **类型**: 合成消除 / 模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: Original Games Pte. Ltd.
- **首次发布**: 2021
- **一句话描述**: 将相同等级的食材或道具合成升级，经营一家充满美食的客栈

## 玩法规则

游戏棋盘为网格布局（通常 7×8 或更大），上面散布着各种等级的物品——从低级食材（如小麦、鸡蛋）到高级料理（如蛋糕、牛排）。玩家操作方式是将两个相同等级的物品拖拽到一起进行合成。

合成规则：两个等级 N 的物品合成一个等级 N+1 的物品。例如两个一级小麦合成二级面粉，两个二级面粉合成三级面包。低级物品可以通过点击生成器或完成订单获得。

屏幕侧边会显示客人的订单需求（如"需要一份三级蛋糕"），玩家需要在棋盘上合成出对应等级的物品并提交给客人完成订单。完成订单获得金币和星星，用于装饰和扩建客栈。

棋盘空间有限，如果物品堆满无法操作则游戏失败。需要合理规划合成路径，优先消除低等级物品腾出空间。

## 核心循环

拖拽合成物品升级 → 完成客人订单 → 获得金币/星星 → 装饰扩建客栈 → 解锁新区域

## 核心机制

- **合成升级机制**: 核心驱动力是两个相同物品合成为更高级别，形成清晰的递进链条。每次合成都是视觉上的满足（新物品出现），同时为更高级目标铺路
- **订单任务系统**: 客人的订单为合成提供方向性目标，避免盲目操作。订单有倒计时或数量限制，增加紧迫感
- **空间管理**: 有限棋盘格迫使玩家做出取舍——是立即合成低级物品腾空间，还是等待更高级合成

## 为什么好玩

合成行为本身具有天然的解压感（两个变一个，数字递增），配合客栈经营的视觉成长反馈（破店变美食天堂），形成双层满足感。每次合成出高级料理时的"哇"感和客栈逐渐变漂亮的视觉变化紧密结合。

## 粘性来源

数值递进成瘾性：永远有下一个更高级的物品等待合成；订单系统提供短期目标循环；客栈装饰提供长期进度可视化；"再合成一个就升级"的心理陷阱让人欲罢不能。

## Meta 系统

客栈经营系统：通过订单获得金币，用于购买装饰和扩建区域。装饰提升客栈美观度，扩建解锁新合成链和更多订单类型。区域解锁也推进简单的剧情线（如"客栈逐渐出名"）。对核心合成的影响是解锁新物品链和更大的棋盘。

## 实现难度

中。核心合成逻辑（拖拽匹配、升级链）简单，但需要设计合理的物品升级树、订单生成算法、以及棋盘空间管理逻辑。最大技术难点是合成动画流畅度和物品状态同步。
