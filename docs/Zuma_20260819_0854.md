# Zuma

- **类型**: 弹珠射击 / 益智
- **平台**: Mobile (iOS+Android) / PC / PDA / iPod
- **开发商**: PopCap Games
- **首次发布**: 2003
- **一句话描述**: 玩家控制屏幕中央的青蛙发射器，射出彩色弹珠来匹配轨道上移动的弹珠链

## 玩法规则

游戏画面中，一条蜿蜒的轨道从屏幕一端延伸到另一端的洞穴入口。一串彩色弹珠沿着轨道向洞穴移动。屏幕中央有一个青蛙形状的发射器，可以360度旋转。

玩家操作：
- 瞄准：移动鼠标或手指控制发射方向（有瞄准辅助线）
- 发射：点击射出弹珠
- 颜色切换：当前发射的弹珠颜色显示在青蛙口中，下一个弹珠颜色显示在旁边

游戏目标：在弹珠链到达洞穴之前，通过匹配消除来清除所有弹珠。

核心规则：
- 射出的弹珠插入弹珠链中
- 三个或更多相同颜色的弹珠相连时被消除
- 消除后弹珠链断开，两侧重新连接
- 连锁消除（消除后新连接的同色弹珠继续消除）分数更高

游戏结束条件：
- 弹珠链到达洞穴入口
- 通关：清除所有弹珠

## 核心循环

瞄准射击 → 匹配消除 → 弹珠链缩短 → 防止到达终点

## 核心机制

- **移动弹珠链**: 弹珠沿固定轨道持续移动，速度可能变化，增加时间压力
- **精确瞄准**: 需要将弹珠射入弹珠链中的精确位置，考验瞄准技巧
- **连锁消除**: 消除一组后两侧弹珠连接，如果新连接的同色弹珠达到三个则继续消除
- **颜色管理**: 每次射击后青蛙口中的弹珠颜色切换，需要管理颜色顺序来规划策略
- **道具系统**: 连续精准射击获得奖励：减速、倒退、炸弹、颜色筛选等

## 为什么好玩

精确命中目标时的满足感很强。看着一长串弹珠因为连锁消除瞬间消失的视觉效果非常爽快。弹珠越来越近的时间压力制造紧张感。

## 粘性来源

关卡递进（轨道变复杂、速度加快、颜色增多）和完美通关是主要粘性。连续精准射击的奖励系统鼓励技巧提升。

## Meta 系统

通常无外围成长系统。部分版本有关卡解锁或得分排名。

## 实现难度

中。核心技术是弹珠在弯曲轨道上的运动模拟和碰撞检测。难点在于瞄准辅助线的准确计算和连锁消除的判定逻辑。
