# 奥比冒险（Oby Adventure）

- **类型**: 平台解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Pocket Games
- **首次发布**: 2025
- **一句话描述**: 扮演可爱的球形角色Oby，通过变形能力解决谜题、穿越关卡的冒险游戏

## 玩法规则

游戏采用2D横版视角，玩家控制一个名叫Oby的球形角色。Oby可以通过点击按钮在不同的形态之间切换：球形态（可以滚动，速度快但不能跳跃）、方块形态（可以堆叠、压住开关）、三角形态（可以卡住齿轮机关）。

每个关卡中有各种机关和障碍：开关门需要方块形态压住开关，狭窄通道需要球形态快速通过，旋转齿轮需要三角形态卡住。

玩家需要在关卡中灵活运用形态切换来解决谜题。有些谜题需要多个形态配合，比如先用方块压住开关打开门，再用球形态快速通过。

关卡中收集金币用于解锁新区域和装饰。有些隐藏区域需要特定的形态组合才能到达。

## 核心循环

探索关卡 → 遇到谜题 → 切换形态解决 → 收集奖励 → 解锁新关卡

## 核心机制

- **三形态切换**：球/方块/三角三种形态各有独特能力，是解谜的核心。形态切换是即时完成的，没有冷却时间，考验玩家的反应速度和判断力。
- **环境交互**：关卡中的机关与形态深度绑定——开关、齿轮、传送带、弹簧等都需要特定形态才能互动。
- **连锁解谜**：高级关卡中，解决一个谜题会触发下一个谜题的条件，形成连锁反应。需要玩家在脑中预演多个步骤。

## 为什么好玩

形态切换的机制简单但组合丰富。每次遇到新机关时"啊，用这个形态"的顿悟感很有成就感。关卡设计循序渐进，从单一形态使用到多形态配合，自然引导玩家学习。

## 粘性来源

- **解谜成就感**：每个谜题解决时的"顿悟"是核心驱动力
- **收集元素**：金币和隐藏房间激发探索欲
- **短关卡设计**：每关1-3分钟，适合碎片时间
- **三星评价**：用最少形态切换次数通关获得高评价

## Meta 系统

- **区域解锁**：完成一个区域的所有关卡解锁下一区域
- **外观解锁**：收集足够金币解锁Oby的新皮肤
- **时间挑战**：通关后解锁计时模式，竞速排行

## 实现难度

中。平台跳跃和碰撞检测是成熟技术，难点在于三形态切换时的物理状态管理——需要确保切换瞬间不会出现穿模或卡关。最大的技术难点是谜题设计，需要保证每个谜题的解法是唯一或有限的，避免玩家无方向尝试。
