# 恐龙快跑（Dino Run）

- **类型**: 跑酷 / 躲避 / 反应类
- **平台**: Web（浏览器）/ Flash
- **开发商**: PixelJAM Games
- **首次发布**: 2008
- **一句话描述**: 横版跑酷游戏——玩家控制一只小恐龙在不断崩塌的地形上奔跑，躲避各种灾难（陨石、地震、洪水）来生存

## 玩法规则

画面是横版卷轴的像素风格场景。玩家控制一只小恐龙在屏幕上自动向右奔跑。

操作方式：空格键或上方向键跳跃，下方向键蹲下/低头。恐龙会持续奔跑，速度逐渐加快。

场景中有各种灾难——陨石从天而降、地面裂开形成悬崖、洪水从后方涌来、翼龙从空中俯冲。玩家需要跳跃躲避陨石和悬崖，蹲下躲避翼龙，在洪水追上之前跑得足够快。

游戏没有终点——目标是尽可能跑得远。随着距离增加，灾难的频率和密度增加，难度持续上升。

## 核心循环

奔跑 → 跳跃/蹲下躲避灾难 → 速度加快 → 持续奔跑直到被追上

## 核心机制

- **自动加速**：恐龙会持续加速，速度越快反应时间越短，难度自然递增。
- **灾难多样性**：多种灾难类型（陨石、悬崖、洪水、翼龙），每种需要不同的应对方式（跳跃、蹲下、加速）。
- **像素风格**：精致的像素艺术画面和动画，恐龙的奔跑动作流畅自然。

## 为什么好玩

Dino Run 是 Flash 时代最好的跑酷游戏之一——精致的像素画面、多样的灾难设计、流畅的操作手感，加上"后面有洪水在追"的紧迫感，让它非常容易上瘾。

## 粘性来源

- **高分挑战**：和自己的最高分竞争
- **灾难多样性**：不同灾难需要不同的应对方式，保持新鲜感
- **视觉享受**：精致的像素画面和动画

## Meta 系统

无（Flash 版）。移动端版本有解锁恐龙品种和成就系统。

## 实现难度

低-中 + 2D 卷轴、碰撞检测、灾难生成。最大技术难点是灾难生成的难度曲线——要确保难度平滑上升。
