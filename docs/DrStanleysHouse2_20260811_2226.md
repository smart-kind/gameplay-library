# 斯坦利博士的家 2（Dr. Stanley's House 2）

- **类型**: 解谜 / 点击冒险 / 密室逃脱
- **平台**: Web（浏览器）/ Flash
- **开发商**: Rober 或 Flash 游戏社区开发者
- **首次发布**: 2000s 中期
- **一句话描述**: 点击式解谜冒险游戏——玩家进入斯坦利博士的神秘房子，通过寻找物品和解谜来推进故事

## 玩法规则

游戏画面是一个房间的内部视角。玩家用鼠标点击房间中的物品来互动——查看、拾取、组合、使用。

核心玩法是"找物品 + 解谜"——在房间中搜索有用的物品（钥匙、工具、线索），然后用这些物品解决谜题（开锁、触发机关、组合物品）。

游戏有叙事驱动——随着谜题的解开，斯坦利博士的秘密逐渐被揭示。场景通常有多个房间或区域，每个区域有自己的谜题链。

## 核心循环

搜索房间 → 发现物品和线索 → 解开谜题 → 进入新区域 → 推进故事

## 核心机制

- **物品互动**：点击房间中的物品可以查看、拾取、使用。某些物品需要在特定的场景中使用。
- **物品组合**：部分谜题需要将两个或多个物品组合起来使用（如用电池 + 手电筒 = 可用手电筒）。
- **叙事驱动**：游戏的核心驱动力是故事——想知道斯坦利博士的秘密。

## 为什么好玩

Dr. Stanley's House 系列是 Flash 时代经典的密室逃脱/点击冒险游戏——精致的画面、巧妙的谜题设计、引人入胜的故事，让它成为该类型的代表作。

## 粘性来源

- **解谜满足感**：解开谜题后的"原来如此"时刻
- **故事好奇心**：想知道斯坦利博士的秘密
- **物品发现**：找到隐藏物品和新线索的惊喜感

## Meta 系统

无。

## 实现难度

低-中 + 场景渲染、物品互动、谜题逻辑。最大技术难点是谜题设计——要让谜题有趣但不会太难。
