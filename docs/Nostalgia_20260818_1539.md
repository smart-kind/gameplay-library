# 怀旧之旅（Nostalgia）

- **类型**: 角色扮演 RPG
- **平台**: Nintendo DS / Mobile (iOS)
- **开发商**: Matrix Software
- **首次发布**: 2008
- **一句话描述**: 以19世纪末蒸汽时代为背景的复古风格回合制冒险RPG

## 玩法规则

玩家扮演年轻冒险家Eddie，在全球范围内旅行寻找失踪的父亲。游戏世界以19世纪大英帝国时期为背景，融合了蒸汽朋克和古代文明元素。

操作方式：DS版使用触控笔进行移动和战斗操作，触屏点击选择菜单指令。玩家在城市间乘坐飞艇移动，探索古代遗迹和城市。

游戏目标：主线任务跟随线索寻找父亲，支线任务包括寻找古代文物、探索失落文明遗址、收集资源等。战斗采用回合制，玩家选择攻击、防御、使用魔法等指令。

游戏结束条件：队伍全灭则Game Over（可重新加载存档）；完成主线剧情即通关。

## 核心循环

探索世界 -> 回合制战斗 -> 获取资源和线索 -> 推进剧情和角色成长

## 核心机制

- 飞艇空战：驾驶飞艇进行大炮和魔法球的空中战斗，是区别于传统RPG的独特系统。玩家操作炮台射击敌方飞艇或空中敌人
- 探索系统：在全球真实地理基础上融合虚构古代文明遗址，玩家在探索中发现历史遗迹和隐藏道具
- 回合制战斗：经典JRPG回合制，队伍成员各有专长（枪手、魔法师、海盗），策略组合应对不同敌人

## 为什么好玩

将JRPG的冒险感与19世纪蒸汽时代背景相结合，飞艇空战是独特的创新点。探索失落文明的神秘感加上回合制战斗的成熟框架，提供了完整的RPG体验。

## 粘性来源

主线剧情的悬念驱动（寻找父亲）；收集古代文物和探索隐藏区域的探索欲；角色成长和飞艇升级的数值反馈。

## Meta 系统

飞艇升级系统（升级火炮、魔法球等装备）；角色等级成长和技能学习。

## 实现难度

高 — 完整RPG系统移植到移动端需要大量工作。最大技术难点是庞大的剧情内容、地图系统和回合制AI的移植和优化。
