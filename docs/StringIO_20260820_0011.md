# 绳索圈地（String.io）

- **类型**: io 策略 / 领地占领
- **平台**: Mobile (iOS+Android)
- **开发商**: Metajoy
- **首次发布**: 2017
- **一句话描述**: 用绳索在地图上围出领地来占领领土的 io 游戏，同时可以攻击其他玩家的绳索来阻止他们圈地。

## 玩法规则

游戏在一个平面上进行，玩家控制一个光标点，移动时会在身后拉出一条绳索。当你画出的绳索最终连接回你已占领的领地时，绳索围成的区域就会变成你的新领地。

核心操作是拖动光标移动。你可以选择 4 种不同的控制方式（如摇杆、跟随手指等）。地图上有其他玩家也在同时圈地。

攻击机制：如果你碰到其他玩家正在拉出的绳索（未封闭的部分），对方的绳索会被切断，对方会被消灭。因此，在冒险围出大块领地的同时，你的绳索暴露在其他玩家的攻击路径下。

## 核心循环

拉动绳索画线 → 封闭区域获得领地 → 攻击他人或躲避攻击 → 继续扩张

## 核心机制

- **绳索围地**：与 Paper.io 类似的划线围地机制，但使用绳索视觉表现，攻击方式是切断绳索而非直接碰撞
- **攻防一体**：你的绳索既是扩张工具，也是致命弱点——碰到别人的绳索能消灭对方，被别人碰到也会被消灭
- **极简美术**：低多边形极简风格，视觉清晰，性能开销小
- **角色解锁**：超过30种彩色角色可供解锁，提供收集动力

## 为什么好玩

圈地的成就感和被截杀的紧张感交替出现。当你成功围出一大块领地时非常满足，但如果你为了更大的面积而冒险拉出很长的绳索，随时可能被对手切断。这种"贪婪 vs 谨慎"的博弈是游戏的核心乐趣。

## 粘性来源

- **领地扩张的满足感**：看着地图被自己的颜色覆盖
- **社交竞争**：全球玩家实时对战
- **角色收集**：30+种角色解锁
- **极简易上手**：规则简单，任何人看一眼就懂

## Meta 系统

无

## 实现难度

低。核心是 2D 平面上的线段封闭区域判定和碰撞检测。最大技术难点是高效的区域填充算法。

## 补充：控制方案

游戏提供 4 种不同的控制方法，包括虚拟摇杆、跟随手指、点触移动和重力感应。这种设计让不同习惯的玩家都能找到最舒适的操作方式，降低上手门槛。
