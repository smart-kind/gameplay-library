# 无尽版青蛙过河，控制角色穿越马路、河流和铁轨（Crossy Road）

- **类型**: 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Hipster Whale
- **首次发布**: 2014
- **一句话描述**: 无尽版青蛙过河，控制角色穿越马路、河流和铁轨

## 玩法规则

玩家通过点击/滑动控制角色向前移动。场景随机生成，包含多条车道（有各种车辆行驶）、河流（需要踩着浮木跳过）和铁轨（有火车经过）。

角色只能向前、左、右移动，不能后退。被车辆撞到或落水即游戏结束。

游戏计分基于穿越的街道数量，还有收集硬币的额外挑战。游戏采用体素风格的3D画面，角色是可爱的方块造型。

## 核心循环

点击/滑动移动 → 躲避车辆和河流 → 计分 → 死亡 → 解锁新角色 → 重来

## 核心机制

- 随机场景生成：每次游戏的道路、河流、铁轨布局不同
- 时间限制：站在同一位置太久会被老鹰抓走，强制玩家持续前进
- 角色收集系统：通过硬币和完成特定挑战解锁数百种角色
- 主题世界：不同环境（城市、河流、雪山等）有不同障碍物

## 为什么好玩

简单易上手但极其难精通，再来一次的冲动极强。每次只差一点点就破纪录的不甘心让人欲罢不能。

## 粘性来源

高分驱动；角色收集；每日挑战；与好友竞争最高分。

## Meta 系统

角色解锁系统，通过硬币购买或完成特定条件解锁。数百种角色各有独特造型。

## 实现难度

低。单指点击操作极简，但反应速度和节奏感需要练习。最大技术难点：随机场景生成的多样性和平衡性。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
