# 波斯王子（Prince of Persia）

- **类型**: 动作冒险 / 平台跳跃 / 战斗
- **平台**: PC / 主机（多平台）/ 移动 / Web（部分浏览器版本）
- **开发商**: Jordan Mechner（原版）/ Ubisoft（现代版）
- **首次发布**: 1989（原版）；系列延续至今
- **一句话描述**: 经典的动作冒险游戏系列，以流畅的跑跳动画和剑术战斗为特色，玩家扮演波斯王子在宫殿和遗迹中冒险

## 玩法规则

原版《波斯王子》（1989）是横版平台跳跃游戏。画面中，波斯王子在一个多层的宫殿/地牢环境中移动。操作包括：奔跑、跳跃、攀爬、蹲伏、拔剑战斗。

玩家需要在限时内（原版为 60 分钟）穿越多个关卡，每一关都是一个充满陷阱（尖刺、活板门、摆斧、落石）和敌人的迷宫。碰到陷阱立即死亡，需要重新来过。敌人有剑士、骷髅、守卫等，战斗基于节奏——攻击、格挡、闪避需要在正确的时机执行。

现代版（如《时之砂》）加入了 3D 元素和时间操控能力——王子可以倒转时间、减缓时间、冻结时间。战斗系统也变得更加复杂——连击、闪避、终结技等。

## 核心循环

奔跑跳跃穿越关卡 → 躲避陷阱 → 与敌人战斗 → 解谜/找路 → 到达下一区域

## 核心机制

- **流畅动画系统**：原版波斯王子的革命性特点是其流畅的角色动画（rotoscoping 技术，基于真实运动员的动作）。王子的奔跑、跳跃、攀爬动作非常自然，这在 1989 年是突破性的。
- **限时生存**：原版游戏有 60 分钟的总时间限制，增加了紧迫感。每次死亡不会重新开始计时，时间继续流逝。
- **陷阱设计**：各种致命陷阱（尖刺地板、会关闭的墙壁、摆动的斧头、落石）需要玩家在正确的时机通过。记忆和学习陷阱位置是通关的关键。
- **节奏战斗**：战斗不是无脑按键，而是有节奏的攻防——观察敌人的攻击动作，在正确的时机格挡或反击。

## 为什么好玩

波斯王子系列的核心魅力在于"动作的优雅"——看着王子流畅地奔跑、跳跃、攀爬、战斗，本身就是一种视觉享受。加上精心设计的陷阱和敌人，以及（在现代版本中）引人入胜的故事，它是一款既有挑战性又有艺术感的游戏。

## 粘性来源

- **动作 mastery**：掌握流畅的移动和战斗需要练习，每次进步都带来满足感
- **关卡设计**：精心设计的关卡让玩家在多次尝试后终于通过时感到极大的成就感
- **故事驱动**：现代版本（如《时之砂》系列）有引人入胜的故事，推动玩家继续游玩

## Meta 系统

无（原版）。现代版本可能有角色升级、技能解锁等系统。

## 实现难度

中-高 + 需要流畅的角色动画系统、精确的碰撞检测、战斗 AI。最大技术难点是角色动画的流畅性——要让动作看起来自然而不僵硬，需要大量的动画数据和精确的帧间过渡。
