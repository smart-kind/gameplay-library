# 小游戏合集+游戏创作平台（Fancade）

- **类型**: 休闲/创造
- **平台**: Mobile (iOS+Android)
- **开发商**: Martin Magni
- **首次发布**: 2019
- **一句话描述**: 小游戏合集+游戏创作平台

## 玩法规则

包含大量由社区创建的小游戏，玩家也可以自己用内置编辑器创建小游戏。每个小游戏有独特的玩法和规则。

## 核心循环

选择小游戏 → 游玩 → 获得金币 → 解锁/创建新游戏

## 核心机制

- 小游戏合集
- 创作编辑器
- 社区分享

## 为什么好玩

无限的小游戏内容，总有新的体验。

## 粘性来源

社区创作内容。

## Meta 系统

游戏解锁+创作。

## 实现难度

低。不同小游戏有不同操作。最大技术难点：UGC平台搭建。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
