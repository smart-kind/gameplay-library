# Tiny Run 3D

- **类型**: 休闲跑酷
- **平台**: Mobile (iOS)
- **开发商**: MondayOFF
- **首次发布**: 2021
- **评分**: ⭐ 4.5/5 (1,610 评价)
- **价格**: Free
- **一句话描述**: 一款简单休闲的3D跑酷游戏，比想象中难，召集朋友一起变得更大。

## 玩法规则

游戏采用3D画面，角色自动向前奔跑。玩家通过点击或滑动控制角色左右移动和跳跃。赛道上有障碍物需要躲避或跳过。沿途可以收集"朋友"（其他小角色）让队伍变大。队伍越大，可以撞开的障碍越多。赛道设计包含弯道、跳台、移动障碍等元素。如果撞到无法撞开的障碍则游戏结束。界面简洁：3D赛道、角色、队伍大小显示。

## 核心循环

自动奔跑 → 躲避障碍 → 收集朋友壮大队伍 → 到达更远

## 核心机制

- 队伍收集：沿途收集角色壮大队伍，提供可见的成长反馈
- 自动奔跑+手动躲避：降低操作门槛，专注于时机判断
- 障碍分级：不同大小的障碍需要不同队伍规模才能通过

## 为什么好玩

"比想象中难"的设计让每次失败都想再来。收集朋友壮大队伍的视觉反馈让人满足。

## 粘性来源

"差一点"的不甘心、队伍壮大的视觉反馈、渐进难度

## Meta 系统

角色皮肤解锁。不影响核心玩法。

## 实现难度

低——3D跑酷模板成熟，实现容易
