# Heroll：骰子肉鸽（Heroll : Dice Roguelike）

- **类型**: 肉鸽 / 骰子 / 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: 111%
- **首次发布**: 2025
- **一句话描述**: 以骰子为核心的肉鸽策略游戏，通过掷骰子和组合骰面来决定战斗结果。

## 玩法规则

游戏的核心界面是一个骰子操作台。玩家拥有若干骰子，每个骰子的六个面上有不同的符号（攻击、防御、治疗、魔法等）。

每回合开始时，玩家掷出所有骰子。骰子朝上的面决定了本回合可用的行动。例如：3个攻击面 = 可以发动3次攻击；2个防御面 = 获得2点护盾。

玩家可以选择保留某些骰子（lock）并重新掷其他骰子，类似Yahtzee的机制。这给骰子游戏增加了策略性——是保留当前的好结果赌更多，还是全部重掷追求更好的组合？

战斗是回合制的。敌人也有类似的骰子系统，但使用不同的骰面组合。玩家需要根据敌人的骰子情况制定策略——如果敌人这回合主要是攻击，你可能需要锁住防御面。

游戏采用肉鸽结构，每次冒险从起点出发，经过多个房间（战斗、事件、商店、宝箱），最终挑战Boss。死亡后重新开始，但可能解锁新的骰子类型。
## 核心循环

掷骰子 → 根据骰面组合制定策略 → 执行战斗行动 → 推进到下一个房间 → 死亡后解锁新骰子重新开始

## 核心机制

- **骰子锁定重掷**：这是游戏的核心策略机制。玩家需要在'保底当前结果'和'赌更好的结果'之间做选择。这个决策每回合都在发生，提供了持续的思考乐趣。
- **骰面组合效应**：某些骰面组合会产生额外效果——比如3个相同面触发'三连'bonus，攻击+治疗面组合触发'吸血'效果。组合多样性让简单的骰子产生丰富的战术变化。
- **肉鸽房间系统**：每次冒险经过不同类型的房间，房间顺序和内容随机。战斗房考验骰子组合，商店房消耗金币购买新骰子，事件房提供选择。随机性保证每局不同。

## 为什么好玩

骰子的随机性+锁定的策略性完美结合。每次掷骰子既有悬念感（不知道结果），又有控制感（可以选择保留）。这种'受控的随机'让人上瘾。

## 粘性来源

骰子掷出时的悬念感是核心粘性。锁定/重掷的决策让每回合都有思考价值。肉鸽的随机房间顺序确保不会重复体验。解锁新骰子类型提供长期目标。'再玩一局就解锁新骰子'的心理驱动持续游玩。

## Meta 系统

骰子收集与解锁系统。通过累计游玩解锁新的骰子类型（不同骰面组合），每种骰子有独特的功能。新骰子可以在后续冒险中使用，扩展策略可能性。

## 实现难度

中 — 骰子物理模拟和随机数生成是基础需求。技术难点在于骰子组合效果系统的平衡性和肉鸽内容的多样性保证。
