# 特技赛车99赛道（Stunt Car Racing 99 Tracks）

- **类型**: 赛车 / 街机
- **平台**: Mobile (iOS+Android)
- **开发商**: Mighty Games
- **首次发布**: 2009
- **一句话描述**: 2D横版视角的特技赛车游戏，在悬浮赛道上飞跃翻转

## 玩法规则

赛道从右向左横向滚动，玩家驾驶赛车在充满起伏和障碍的赛道上飞驰。

操作方式：倾斜设备或点击屏幕前后部分控制赛车在空中的姿态——向后倾斜使车头抬起，向前倾斜使车头压低。自动加速，玩家只需控制空中姿态。

游戏目标：在赛道上完成比赛，利用飞跃和空中特技获得加速。赛道上的障碍物包括跳跃坡道、沟壑、障碍物等。合理利用飞跃获得加速，同时避免碰撞减速或翻车。

游戏结束条件：赛车严重损坏或翻车则比赛失败；完成赛道到达终点则获胜。99条赛道提供大量挑战。

## 核心循环

加速飞跃 -> 空中翻转获取加速 -> 避开障碍 -> 完成赛道

## 核心机制

- 姿态控制：飞跃空中时通过调整赛车前后倾角度来控制落地姿态——正确角度落地获得加速，错误角度碰撞减速甚至翻车
- 特技系统：在空中完成360度翻转等特技动作可获得额外加速奖励
- 99赛道：大量不同设计的赛道提供持续挑战，每条赛道有独特的障碍布局和难度

## 为什么好玩

简约的2D画风反而让gameplay更加纯粹——速度感、飞跃的紧张感、翻转成功的爽快感都非常直接。相比追求3D画质的赛车游戏，这种回归游戏本质的设计反而更有趣。

## 粘性来源

99条赛道提供了充足的挑战目标；每次飞跃的成败带来的刺激感；追求更快完成时间的竞速精神。

## Meta 系统

赛道解锁系统；部分版本有车辆升级。

## 实现难度

中 — 2D赛车技术相对简单。最大技术难点是99条赛道的关卡设计和物理手感调优。
