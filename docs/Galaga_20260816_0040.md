# 大蜜蜂（Galaga）

- **类型**: 固定射击 / 街机
- **平台**: 街机 / 多平台移植
- **开发商**: Namco
- **发行商**: Midway (北美) / Namco (日本)
- **首次发布**: 1981
- **一句话描述**: 操控星际战机在屏幕底部移动，射击不断俯冲攻击的敌方外星舰队，是经典街机射击游戏 Galaxian 的续作

## 玩法规则

游戏画面为一个静态的太空场景，底部是玩家控制的星际战机，顶部是排列成阵型的敌方外星舰队（Galaga 部队）。敌舰分为多个编队，每种类型有不同的颜色和行为模式。

玩家通过摇杆控制战机左右移动，按射击键发射子弹。敌人会分批次从屏幕顶部以编队形式飞入，然后停留在上方区域。停留期间，单个敌人会脱离编队向玩家俯冲攻击，玩家需要躲避敌机及其发射的子弹，同时射击消灭它们。

每消灭一波敌人后，下一波以更快的速度进入，难度递增。游戏的核心挑战在于同时处理多个俯冲敌人——有些直线俯冲，有些会释放子弹，有些还会改变轨迹。

Galaga 最具标志性的机制是"Boss Galaga"——一种特殊的敌机，会用牵引光束捕获玩家的战机。如果被捕获，玩家暂时失去一条命，但如果用另一条命射击牵引光束，可以救回被捕获的战机，获得"双战斗机"状态，拥有双倍的火力输出。

## 核心循环

射击俯冲敌人 → 清除一波 → 下一波进入（速度更快） → 追求双战斗机状态 → 挑战更高分数

## 核心机制

- **双战斗机系统**：这是 Galaga 最具创新性的机制。Boss Galaga 用牵引光束捕获玩家战机后，玩家可以用第二条命射击光束来救回，获得双机编队。双机火力翻倍但中弹风险也翻倍，是一个高风险高回报的策略选择
- **敌人阵型与俯冲模式**：敌人不是随机出现，而是以固定编队进入，每种类型有独特的俯冲轨迹。熟练掌握每种敌人的移动模式是高分的关键
- **Challenging Stage（挑战关卡）**：每隔几关会出现特殊挑战关，敌人不按常规模式攻击，而是排成特定阵型飞过屏幕，玩家需要在限定时间内尽可能多地击落它们
- **分数倍增**：连续消灭同一编队的敌人会获得递增的分数奖励，鼓励玩家保持连击节奏

## 为什么好玩

Galaga 在 Galaxian 的基础上增加了双战斗机系统这一革命性机制，让射击游戏从单纯的"打飞机"变成了有策略深度的体验。Boss Galaga 的牵引光束机制创造了一种反直觉的体验——被敌人抓住不一定是坏事，反而可能是获得更强火力的机会。挑战关卡打破了常规节奏，给玩家提供短暂但紧张的高分机会。

## 粘性来源

- **分数驱动**：连击倍增和挑战关卡是高分的核心来源，驱动玩家反复练习
- **双战斗机的诱惑**：获得双机状态后火力大增的爽快感，以及"被捕获→救出"的反转体验，让人上瘾
- **街机文化的竞争**：在街机厅竞争最高分是 80 年代的核心社交体验
- **挑战关卡的紧张感**：特殊关卡的限时射击模式与常规关卡形成节奏对比，增加了游戏的多样性

## Meta 系统

无。作为 1981 年的街机游戏，没有外围成长系统，分数是唯一的进度记录。

## 实现难度

低。固定视角的 2D 射击游戏，精灵动画和碰撞检测都是基础技术。最大技术难点在于敌人编队移动的流畅性和俯冲轨迹的精确计算，以及双战斗机状态下的碰撞检测（两架战机需要分别判定）。
