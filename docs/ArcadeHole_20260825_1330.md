# Arcade Hole

- **类型**: 街机/IO竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: Rollic Games
- **首次发布**: 2022
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 游戏主界面通常包含多个操作按钮和信息显示区域。顶部可能显示分数、计时器或关卡进度。
- 中央区域是主要的游戏操作区域，显示游戏元素（泡泡、宝石、角色、地图等）。
- 底部或侧边显示可用操作、手牌或待放置元素。

玩家的操作方式包括：
- 点击/拖拽：选择并放置游戏元素，进行匹配或移动操作
- 滑动：在某些游戏中进行方向控制或瞄准
- 长按：在某些游戏中蓄力或执行特殊操作

## 核心循环

控制角色在地图上移动 -> 吞噬资源成长 -> 与其他玩家竞争

## 核心机制

- **吞噬成长**: 玩家控制角色在地图上移动，吞噬资源点来增长体型。体型越大，能吞噬的范围越大。
- **实时多人竞技**: 多个玩家在同一张地图上实时对战。需要策略性地选择目标和逃避威胁。
- **排行榜**: 实时显示排名，激励玩家争夺第一。

## 为什么好玩

吞噬成长的爽快感结合多人竞技的紧张感。每次对局都是全新的体验。

## 粘性来源

粘性来源于真人对抗的不可预测性和成长爽感。

## Meta 系统

- 实时排行榜：按当前对局表现排名
- 对核心玩法的影响：排行榜提供竞争目标

## 实现难度

低 -> 核心逻辑实现难度不大。最大难点在于：对于消除类游戏，需要处理好匹配算法和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性。
