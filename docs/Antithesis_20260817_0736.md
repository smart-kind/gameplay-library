# Antithesis (Tractor Pull)

- **类型**: 模拟竞速
- **平台**: Mobile (iOS)
- **开发商**: Antithesis Design, LLC
- **首次发布**: 2012
- **一句话描述**: 一款拖拉机拉力赛模拟游戏，玩家操控拖拉机拖动雪橇完成300英尺的全程拉力

## 玩法规则

玩家进入游戏后，会选择一个赛事和一辆拖拉机。核心操作是模拟真实的拖拉机拉力赛过程：首先需要预热引擎（通过滑动或点击让涡轮增压器旋转起来），然后在恰当的时机松开离合器开始拉力。

松离合的时机至关重要——太早会导致引擎熄火或失去动力，太晚则会错过最佳加速窗口。成功起步后，玩家需要控制油门力度，让拖拉机尽可能地拖动沉重的雪橇向前行驶。雪橇的重量会随着前进距离逐渐增加，模拟真实比赛中雪橇阻力递增的机制。

拖动雪橇超过300英尺即为"full pull"（全程拉力），这是每个赛事的最高目标。玩家通过比赛获得现金奖励，用于购买新的拖拉机和卡车，以及升级现有车辆的引擎、轮胎、变速箱等部件。

## 核心循环

参赛拉力 → 获得现金 → 购买/升级拖拉机 → 挑战更高组别赛事 → 收集更多车辆

## 核心机制

- 核心机制：离合器控制与时机判定 — 预热引擎后在最佳时机松离合，决定了拉力成绩的上限，需要精确的时机把握
- 渐进阻力系统：雪橇重量随距离递增，越往后越难推动，在极限边缘操作的紧张感是核心体验
- 车辆收集与升级：90款拖拉机和卡车可供收集，通过比赛现金升级引擎、轮胎、传动系统
- 赛事体系：81个锦标赛，按组别递进（从新手组到专业组），完成组别晋升后解锁更高难度

## 为什么好玩

拖拉机拉力赛这种看似小众的竞技运动，被转化为手机上极具挑战性的迷你游戏。"差一点就能拖到300英尺"的不甘心感让人欲罢不能。90款车辆的收集目标和81个锦标赛提供了明确的长期驱动力，而每场比赛只需几分钟，非常适合碎片时间。

## 粘性来源

- "差一点就成功"的不甘心：290英尺 vs 300英尺的差距让人忍不住再来一局
- 收集驱动：90款拖拉机和卡车的完整收集目标
- 车辆升级的数值成长：每次升级都能感受到性能提升的即时反馈
- 竞技对比：与朋友的拉力成绩直接对比，形成社交竞争

## Meta 系统

车辆收集与锦标赛进度系统 — 玩家通过比赛积累现金，解锁90款不同的拖拉机和卡车，每辆车有独特的性能参数。锦标赛分为多个组别，逐步晋升。升级系统影响核心的拉力表现，让策略性的资源分配成为Meta层面的核心玩法。

## 实现难度

低 — 核心玩法本质上是单维度的力量/阻力模拟，技术实现简单。最大难点在于手感调校——离合器的松放时机和油门控制需要在触屏上提供足够的操作精度，同时保持流畅的体验。
