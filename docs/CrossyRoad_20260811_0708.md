# Crossy Road（Crossy Road）

- **类型**: 休闲 / 无尽跑酷 / 街机
- **平台**: Mobile (iOS+Android)
- **开发商**: Hipster Whale
- **首次发布**: 2014
- **一句话描述**: 帮助各种角色穿越车流、河流、铁轨等障碍，尽可能走得更远

## 玩法规则

游戏采用等距视角的3D像素风格画面。玩家控制的角色从屏幕底部开始，需要不断向前方移动。画面中有多条平行的车道、河流、铁轨和草地交错排列。

玩家通过滑动屏幕操作——上/下/左/右四个方向滑动，角色就朝对应方向跳一步。每次跳跃算一步，也会计入总得分（每步1分）。

车道上有各种车辆（汽车、卡车等）不断驶过，撞到车游戏结束。河流上有漂浮的原木或荷叶，角色必须跳到这些漂浮物上过河，如果跳入水中则结束。铁轨上有火车经过，被撞到也结束。

游戏会随进度逐渐增加难度——车辆更快、河流更宽、障碍物更多。每次失败后显示得分，并解锁新的可选角色。

## 核心循环

滑动跳一步 → 得分+1 → 继续向前穿越新障碍

## 核心机制

- **四向跳跃**: 玩家可以上下左右移动，但只有向前（上）才得分。这允许玩家横向躲避或后退重新定位。
- **动态障碍**: 车辆和火车持续移动，玩家需要判断时机跳跃。河流上的漂浮物也在移动，需要精确计算落点。
- **计时死亡**: 如果长时间不移动，老鹰会飞来把角色叼走。这防止玩家过度等待"完美时机"。
- **角色解锁**: 每次游戏结束后根据得分解锁新角色，每个角色有不同的外观和微妙的尺寸差异。

## 为什么好玩

操作简单但节奏紧凑——需要快速判断和反应。每次游戏只有几秒钟到几分钟，但"再来一局"的冲动极强。丰富的角色收集元素增加了额外动力。

## 粘性来源

- **即时重开**: 失败到重新开始只需一秒，零等待
- **角色收集**: 大量可解锁角色（像素动物、名人、流行文化角色）提供持续目标
- **节奏感**: 掌握节奏后有种行云流水的快感
- **分数挑战**: "再走远一点"的目标永无止境

## Meta 系统

角色解锁系统——通过每局游戏的得分累计，逐步解锁新角色。角色主要影响外观，部分角色有微妙的碰撞体积差异。

## 实现难度

低。核心是网格跳跃 + 动态障碍碰撞检测 + 伪3D等距渲染。最大难点在于平衡——车辆速度、间距、河流宽度需要精心调校以保证"难但公平"。
