# Spring Ninja（弹簧忍者）（Spring Ninja）

- **类型**: 弹跳 / 平台
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer收录
- **首次发布**: 2015
- **一句话描述**: 一款极简弹跳游戏，玩家控制忍者角色利用弹簧在各种平台间弹跳上升，目标是达到尽可能高的高度。

## 玩法规则

游戏画面是竖版场景，忍者角色初始站在一个平台上。屏幕中分布着多个不同高度和位置的平台，形成从下到上的攀爬路线。

操作只有点击屏幕一个动作：忍者会垂直向上弹跳到空中。弹跳高度取决于玩家按下的时机和弹簧的弹力系数。忍者落到平台上后会自动停住，玩家可以再次点击弹跳到下一个平台。

平台类型多样化：普通平台可以安全着陆，弹簧平台接触后会额外弹起更高的高度，危险平台如尖刺碰到会失去生命或游戏结束，移动平台会水平移动增加着陆难度。

目标是弹跳到尽可能高的位置。如果从平台滑落掉出屏幕底部，游戏立即结束。高度越高，分数越高。

## 核心循环

选择目标平台 → 点击弹跳 → 着陆到平台 → 选择下一个更高的平台 → 追求更高高度

## 核心机制

- **机制1**：弹道控制机制：每次弹跳的轨迹由物理引擎决定，玩家需要预判落点并选择目标平台。这种一锤子买卖式的决策增加了紧张感，每次弹跳都是一次小小的冒险。
- **机制2**：平台多样化机制：普通平台、弹簧平台、移动平台、危险平台交替出现，要求玩家动态调整策略。弹簧平台可以一次跳很远但落点更难控制，移动平台增加了时间压力。
- **机制3**：高度递进机制：随着高度增加，平台间距变大、移动平台速度加快、危险平台比例上升，形成自然的难度曲线。同时高度本身就成为可视化的进度条，让玩家清楚自己的表现。

## 为什么好玩

极简操作只有一个点击却蕴含丰富的策略选择，选择哪个平台作为跳板、何时弹跳、是否冒险使用弹簧平台。每次弹跳都有不确定性带来的兴奋感。

## 粘性来源

就差一点到那个平台的不甘心加上每次弹跳的不确定性刺激加上竖版视觉带来的越爬越高的成就感，三因素叠加让人不断重开。

## Meta 系统

简单分数系统加忍者皮肤收集，最高分排行榜。部分版本有基于高度的成就解锁系统。

## 实现难度

低 -- 核心是物理弹跳加平台碰撞检测，实现相对简单。最大难点是手感调优如弹力系数、摩擦力、忍者下落速度等参数的精细调整。

## 平台类型详细说明

- **普通平台**：标准大小，安全着陆，是最可靠的跳板
- **弹簧平台**：接触后额外弹起更高，但落点更难精确控制，适合跨越大间距
- **移动平台**：水平匀速移动，需要预判移动轨迹来着陆，增加了时间压力
- **危险平台**：表面有尖刺或火焰，碰到即死，必须避开
- **易碎平台**：着陆后几秒内碎裂，不能停留太久，需要快速决策下一步
