# 离线游戏合集（Offline Games - No Wifi Games）

- **类型**: 休闲 / 合集 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Moreno Maio
- **首次发布**: 2016
- **一句话描述**: 一个包含20多款不同类型小游戏的合集，无需网络连接即可畅玩，涵盖益智、动作、策略等多种品类。

## 玩法规则

游戏主界面以"玩具箱"风格展示所有小游戏的图标和名称，玩家点击任意图标即可进入对应游戏。每个小游戏有独立的规则和玩法：

- **记忆翻牌**：在网格中找到配对的卡片
- **滑动消除**：通过滑动匹配相同颜色的方块
- **反应测试**：在信号变化后尽快点击屏幕
- **接球游戏**：移动篮子接住掉落物体
- **颜色匹配**：快速识别并选择正确的颜色组合
- **迷宫逃脱**：找到从起点到终点的正确路径

每个小游戏操作简单，通常只需要单指点击、滑动或拖拽。游戏没有统一的进度系统，每个小游戏独立计分，部分小游戏有难度递增机制。

## 核心循环

选择小游戏 → 游玩并挑战高分 → 切换其他小游戏继续 → 不断突破自我记录

## 核心机制

- **多游戏合集模式**：20+款独立小游戏满足不同场景需求——打发时间、锻炼脑力、训练反应力
- **无广告离线体验**：所有游戏无需网络连接即可完整游玩，没有强制广告打断
- **即时开始**：没有加载界面或冗长教程，点击即玩

## 为什么好玩

Offline Games 的核心理念是"随时随地有得玩"——在飞机上、地铁里、等待朋友的间隙，掏出手机就能立即开始。合集中包含足够多的游戏类型，总有一款适合当下的心情。简单纯粹的设计没有内购、没有社交压力，只有纯粹的游戏乐趣。

## 粘性来源

- **多样性**：20+款游戏覆盖不同玩法，避免单一游戏的审美疲劳
- **高分挑战**：每个小游戏都有个人最佳记录，激发玩家不断尝试突破
- **无门槛**：不需要网络连接、不需要账号注册、不需要学习复杂规则，零门槛进入

## Meta 系统

无。游戏采用纯单机模式，没有成长系统或收集要素。每个小游戏的进度独立保存，玩家下次打开可以继续游玩。这种极简设计恰恰是其卖点之一。

## 实现难度

低。每个小游戏都是经典玩法的简化实现，技术门槛不高。最大挑战在于在有限空间内整合20+款游戏而不让应用体积过大，以及确保每款游戏的手感都达到"好玩"的基本标准。
