# 强力地下城 (Mighty Dungeons)

- **类型**: RPG/桌面棋盘冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: 未明确标注
- **首次发布**: 未明确标注
- **一句话描述**: 一款致敬经典桌面RPG的地下城探险游戏，融合棋盘移动与第一人称回合制战斗

## 玩法规则

游戏开始时，玩家从六种奇幻英雄职业中选择一个（包括战士、刺客、法师等）。选择后，玩家进入一个个独立的冒险任务。

每个关卡呈现为类似桌面棋盘的样子。玩家的英雄用一个小棋子表示，通过触摸屏幕上的任意位置，英雄就会移动到那个格子，同时驱散笼罩在关卡上的战争迷雾。

当英雄在移动中遭遇敌人（骷髅、兽人、巨型蜘蛛、魔像等）时，游戏切换到第一人称视角的战斗画面。战斗系统非常简洁：玩家点击攻击按钮进行攻击。根据英雄的攻速属性，攻击间隔不同，玩家需要持续点击来进行连续攻击。

战斗菜单位于屏幕下半部分，提供了使用治疗药水、切换武器等功能。每种武器有自己的耐久度，当耐久耗尽时武器失效。

任务之间的间隙，玩家回到主菜单的铁匠处，可以购买新武器和装备，使用在战斗中获得的金币进行升级。游戏采用成就式成长系统而非传统等级制——击杀特定数量的敌人或完成特定里程碑获得成就奖励。

## 核心循环

在棋盘上探索移动 -> 遭遇敌人进入战斗 -> 点击攻击击败怪物 -> 获得金币/成就 -> 回铁匠升级 -> 进入下一个任务

## 核心机制

- 棋盘式探索：英雄以小棋子形式在棋盘状关卡上移动，触摸屏幕即可移动到目标格，同时揭开战争迷雾
- 第一人称点击战斗：遭遇敌人后切换到第一人称视角，通过反复点击攻击按钮进行战斗，节奏取决于角色攻速
- 武器耐久系统：每种武器有独立的耐久值，耗尽后失效，迫使玩家在战斗中切换武器或回到铁匠购买新武器
- 成就式成长：不采用传统等级制，而是通过达成里程碑（如击杀200个某种敌人）获得成就奖励来逐步强化角色

## 为什么好玩

复古桌面RPG的怀旧感贯穿始终，棋盘探索和第一人称战斗的切换节奏清晰明了。选择不同英雄职业带来不同的战斗体验。

## 粘性来源

成就驱动的渐进式成长让玩家持续有目标追求。但成长速度较慢，成就感回馈不够及时，可能影响长期粘性。

## Meta 系统

成就系统代替传统等级制——击杀特定数量的敌人、完成特定任务等里程碑会给予奖励。铁匠处可购买武器和装备，使用金币消费。

## 实现难度

低到中等 — 战斗操作极其简单（反复点击），策略深度有限。最大技术难点是战斗节奏的平衡——既要避免过于简单重复，又不能过于复杂。
