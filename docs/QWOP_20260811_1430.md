# QWOP（QWOP）

- **类型**: 物理模拟 / 搞笑 / 动作
- **平台**: Web (Flash/HTML5)
- **开发商**: Bennett Foddy
- **首次发布**: 2008
- **一句话描述**: 用四个按键控制一个短跑运动员的四肢，尝试跑完100米

## 玩法规则

游戏画面显示一条标准的田径100米跑道，玩家控制的角色"QWOPer"站在起跑线上。屏幕底部显示Q、W、O、P四个字母提示，分别对应运动员的四个身体部位。

玩家通过键盘按键操作：Q键控制左大腿（向前/后摆动），W键控制右大腿，O键控制左小腿（屈伸），P键控制右小腿。四个按键各自独立控制一个关节，没有任何协调辅助。

每次按键会立即改变对应肢体的运动状态——大腿按键控制髋关节角度，小腿按键控制膝关节角度。由于物理引擎模拟了真实的惯性和重力，不当的按键组合会导致角色摔倒、翻滚、甚至向反方向移动。

游戏目标是用QWOP四键操控角色跑完100米赛道。角色必须保持直立并向前移动，一旦长时间倒地不起或偏离赛道太远，就算失败。

没有关卡、没有分数上限——唯一的挑战就是尽可能远地跑。

## 核心循环

按键控制肢体 → 角色产生动作 → 前进或摔倒 → 重新开始

## 核心机制

- **四键独立控制**: 每个键控制一个关节，玩家需要同时管理大腿和小腿的协调，模拟了人体跑步时多关节协同的复杂性
- **真实物理引擎**: 角色的身体遵循牛顿力学，有重心、惯性、摩擦力，按键不当会真实地摔倒
- **极低的容错率**: 一个错误的按键时机就可能导致角色翻倒，制造了强烈的"差一点就成功"的挫败感

## 为什么好玩

QWOP的魅力在于它把简单的"跑步"这个日常行为变成了极度困难的操作挑战。每次摔倒都以滑稽的动画呈现，既让人沮丧又让人发笑。它的难度曲线极陡，但每次多跑一米都带来巨大的成就感。

## 粘性来源

"差一点就成功"的不甘心感——每次摔倒都让你觉得"下次一定能跑更远"。加上滑稽的失败动画在朋友间传播，形成了极强的社交分享驱动。物理引擎的不可预测性也让每次尝试都有新鲜感。

## Meta 系统

无

## 实现难度

中 — 物理引擎是核心技术难点。需要精确模拟多刚体关节的力学交互（大腿、小腿、躯干的约束关系），以及地面的摩擦力和碰撞检测。控制方案的精妙平衡（既难到搞笑，又不至于完全不可能）需要大量调参。
