# Stick RPG（Stick RPG）

- **类型**: 模拟人生 / RPG / 沙盒
- **平台**: Web (Flash)
- **开发商**: XGen Studios
- **首次发布**: 2003
- **一句话描述**: 控制一个火柴人在城市中生活，通过工作、学习、社交提升各项能力

## 玩法规则

游戏以一个俯视视角的2D城市为舞台，玩家控制一个火柴人角色在地图上自由移动。城市中有各种设施：学校、健身房、赌场、工作场所、商店等。

火柴人有三项核心属性：力量（Strength）、魅力（Charm）、智力（Intelligence）。每项属性通过不同的活动来提升：
- **力量**: 去健身房锻炼
- **魅力**: 参加社交活动、购买时尚服装
- **智力**: 去学校上课学习

玩家需要赚钱来支持各项消费。赚钱方式包括打工（低薪工作）和赌博（高风险高回报）。钱用于支付学费、健身费、购买道具和房产。

游戏有时间系统（天数流逝），玩家需要在有限的天数内最大化各项属性。

## 核心循环

行动（工作/学习/社交）→ 属性提升/获得金钱 → 解锁新活动 → 继续提升 → 成为最厉害的火柴人

## 核心机制

- **三属性平衡**: 力量、魅力、智力三条成长线，不同组合解锁不同的生活选项
- **时间管理**: 每天能做的行动有限，需要规划最优路线
- **开放世界探索**: 城市地图可以自由探索，隐藏了各种互动点和彩蛋
- **经济循环**: 赚钱 → 消费 → 提升 → 赚更多钱的正反馈循环

## 为什么好玩

Stick RPG将"模拟人生"浓缩到了一个极简的2D火柴人世界中。它捕捉到了RPG成长的核心快感——看着数值一点一点上涨，解锁新的能力。简单的画面反而让想象力填补了空白。

## 粘性来源

属性成长的即时反馈 + 城市探索的未知感 + 不同属性组合带来的多周目价值。时间限制（天数）创造了紧迫感，促使玩家不断优化效率路线。

## Meta 系统

无传统Meta系统，但属性成长本身就是meta——每次游玩都是重新开始，但玩家积累了"怎样玩更好"的策略知识。

## 实现难度

中 — 需要实现开放世界地图、NPC交互、经济系统和属性成长系统。技术难点在于游戏内容的丰富度设计（各种活动和互动的实现），以及数值平衡。
