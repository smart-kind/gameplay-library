# 微光（Hyperlight）

- **类型**: 解谜 / 休闲
- **平台**: Nintendo 3DS
- **开发商**: 独立开发者
- **首次发布**: 2011
- **一句话描述**: 利用光线反射和折射原理引导光束到达目标的益智游戏

## 玩法规则

游戏画面中有一道发射光源和若干个目标接收器。玩家需要在场景中放置和旋转各种光学元件——平面镜（反射光线改变方向）、棱镜（折射光线并改变颜色）、滤光片（改变光线颜色）、分束器（将一道光分成两道）——使光束最终到达指定目标。

关卡逐步引入新机制：早期只需放置一面镜子将光束折射90度就能到达目标，中期需要多面镜子的连锁反射来绕过障碍物，后期需要同时用不同颜色的光束激活多个目标。光线传播是实时的，放置或旋转元件后可以看到光束立即改变路径，直观展示光学效果。

部分关卡还引入移动光源、可旋转的反射面、透明障碍物等额外元素。3DS双屏设计允许上屏显示光束传播的全局效果，下屏放置元件和调整参数。某些关卡有步数限制，要求在有限的元件数量内完成目标，增加了规划难度。

## 核心循环

观察关卡布局 → 放置光学元件引导光束 → 验证光束路径 → 过关获得新元件

## 核心机制

- **光学元件系统**：每种元件有独特的光学行为：镜子反射90度或45度，棱镜将白光分解为彩色光谱，滤光片只允许特定颜色通过，分束器将光束一分为二。元件之间的组合产生丰富的解题可能性
- **颜色匹配机制**：某些目标需要特定颜色的光束才能激活（如红色目标需要红光），需要先通过棱镜分光或滤光片转换。多色目标同时存在时需要分束器同时服务
- **多光束同步规划**：后期关卡需要同时满足多个不同颜色的目标，考验空间规划能力和对光学原理的理解深度


## 为什么好玩

物理光学原理与解谜完美结合，每次成功引导光束穿过复杂元件阵列到达目标时的'aha moment'带来强烈满足感。光束传播的实时动画效果赏心悦目。

## 粘性来源

关卡难度渐进式设计让玩家在'刚好能解'和'有些挑战'之间保持心流状态。收集星星评分（基于步数）和寻找最优解的冲动驱动重复游玩同一关卡。

## Meta 系统

无复杂Meta系统。关卡解锁和星级评定作为基础进度机制。部分版本有每日挑战关卡。

## 实现难度

低到中 —— 核心机制是空间逻辑推理和基础光学知识，最大技术难点是光线传播的实时渲染计算和多元素交互的碰撞检测。
