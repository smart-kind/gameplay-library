# Sunset Bike Racer（Sunset Bike Racer）

- **类型**: 竞速 / 物理模拟 / 摩托车
- **平台**: Web（浏览器）
- **开发商**: 浏览器游戏开发者
- **首次发布**: 2010s
- **一句话描述**: 横版摩托车竞速游戏，玩家控制摩托车在日落风景的赛道上行驶，利用物理特性完成跳跃和特技

## 玩法规则

游戏画面为横版卷轴视角。玩家控制一辆摩托车在赛道上行驶，赛道上有坡道、障碍物、跳跃台等元素。操作方式：方向键控制加速/减速，前倾/后仰。

摩托车受物理引擎控制——加速过坡道会飞出空中，空中调整车身角度影响落地。落地角度不正确（前轮或后轮先着地且角度过大）会导致翻车。翻车后需要重新开始本段赛道。

关卡设计通常包含多个坡道和跳跃点，玩家需要在保持速度的同时控制好落地角度。部分关卡有时间要求——在限定时间内到达终点。赛道背景通常是日落/黄昏风格的风景（橙红色天空、山丘轮廓）。

## 核心循环

加速行驶 → 飞跃坡道 → 调整空中姿态 → 安全落地 → 继续下一段

## 核心机制

- **物理模拟**：摩托车的运动完全基于物理引擎——重力、惯性、摩擦力、角动量。加速时前轮抬起，减速时后轮抬起，空中可以调整车身角度。物理模拟的真实感是游戏的核心体验。
- **落地判定**：落地时两个车轮同时着地且角度接近平行为最佳。角度过大或单轮先着地会导致翻车。
- **速度管理**：加速过快容易在跳跃时失控，太慢则无法越过障碍。玩家需要在速度和稳定性之间找到平衡。

## 为什么好玩

Sunset Bike Racer 把摩托车特技的紧张感浓缩到了简单的横版画面中——不需要复杂的控制，只需要掌握好加速和平衡的时机。每次成功飞跃并安全落地的满足感，和翻车后"差一点就成功了"的不甘心，让它非常容易上瘾。

## 粘性来源

- **物理 mastery**：掌握物理引擎的规律需要大量练习，从经常翻车到流畅通过需要时间
- **"差一点"效应**：每次翻车都感觉"就差一点点"，促使玩家不断重试
- **视觉反馈**：日落风格的画面和流畅的摩托车动画提供了良好的视觉享受

## Meta 系统

无。纯核心玩法。

## 实现难度

- **学习曲线**：新手可以立即上手，但精通需要数十小时的练习。每次游玩都能发现新的技巧或策略。
- **重玩价值**：高。每局游戏都有不同的体验，无论是随机的地图/敌人，还是玩家的策略选择。
- **社区生态**：作为经典浏览器游戏，它在玩家社区中有良好的口碑。
- **技术亮点**：在浏览器环境中实现流畅的交互体验，充分利用了现代 Web 技术的能力。
低-中 + 2D 物理引擎、碰撞检测、赛道设计。最大技术难点是物理引擎的稳定性——确保摩托车在各种速度下都能有可预测的行为。
