# Bubble Shooter

- **类型**: 益智 / 消除
- **平台**: Mobile (iOS+Android) / Web
- **开发商**: Ilyon Dynamics (原Absolutist)
- **首次发布**: 2002
- **一句话描述**: 玩家发射彩色泡泡，三个或更多相同颜色的泡泡相连时消除

## 玩法规则

游戏画面中，屏幕上方悬挂着大量彩色泡泡（通常排列成蜂窝状网格）。屏幕底部中央有一个发射器，发射器中有一个彩色泡泡，旁边显示下一个泡泡的颜色。

玩家操作：
- 瞄准：滑动或移动鼠标调整发射角度（通常有瞄准辅助线）
- 发射：点击松开将泡泡射出

游戏目标：通过匹配三个或更多相同颜色的泡泡来消除它们，清除所有泡泡即可过关。

核心规则：
- 发射的泡泡碰到天花板或其他泡泡时会停住
- 三个或更多相同颜色的泡泡相连时会被消除
- 被消除的泡泡如果悬挂在空处（不再连接到天花板），也会掉落
- 泡泡堆会逐步向下推进，到达底部线则游戏结束

游戏结束条件：
- 泡泡堆到达底部线
- 用尽所有可发射的泡泡仍未清除

## 核心循环

瞄准发射 → 匹配消除 → 泡泡掉落 → 清除关卡

## 核心机制

- **蜂窝网格**: 泡泡排列成蜂窝状（六边形网格），每个泡泡最多有6个相邻位置，增加空间策略性
- **连锁消除**: 消除一组泡泡后，与其相连的异色泡泡如果失去支撑会掉落，产生连锁反应
- **颜色预览**: 显示下一个泡泡的颜色，让玩家可以规划发射策略
- **反弹射击**: 泡泡可以碰到墙壁反弹，利用反弹角度可以击中直接瞄准不到的位置

## 为什么好玩

瞄准和命中时的满足感很强。利用反弹角度精准命中目标的技巧感令人上瘾。连锁消除一大片泡泡的视觉效果非常爽快。

## 粘性来源

关卡递进（泡泡颜色增多、布局变复杂）和三星评价系统是主要粘性。每日挑战和新关卡更新保持长期吸引力。

## Meta 系统

现代版本有体力系统、关卡地图、每日奖励等。核心玩法无成长系统。

## 实现难度

低。碰撞检测和网格计算是核心技术点。难点在于反弹物理的准确模拟和蜂窝网格的邻接计算。
