# 粉末游戏（Powder Game）

- **类型**: 沙盒模拟 / 粒子物理
- **平台**: Web (Flash) → 现通过 Flashpoint/HTML5 存档游玩
- **开发商**: DAN-BALL
- **首次发布**: 2007
- **一句话描述**: 在空白画布上放置各种粉末和材料，观察它们之间的物理和化学反应的互动沙盒

## 玩法规则

游戏画面是一个空白画布。玩家从工具栏中选择不同的"粉末"类型，然后在画布上点击或拖动来放置。

粉末类型包括：沙子（受重力影响下落）、水（流动）、火（燃烧并蔓延）、木材（可燃）、油（可燃且流动）、火药（遇火爆炸）、石头（不可燃、坚硬）、酸（腐蚀其他材料）、冰（冻结）、种子（接触水生长成植物）、病毒（感染并扩散）等。

放置不同材料后，它们会根据各自的物理和化学规则互动：火会点燃木材和油，水会熄灭火，酸会腐蚀金属，种子遇到水会长出植物，病毒会感染一切生物材料。

游戏没有明确的目标或胜利条件——它是一个纯粹的沙盒玩具。玩家自己设定目标：创造一场森林大火、建造一个生态系统、模拟火山爆发、制作烟花表演等。

游戏还有预设的"关卡"模式，在特定条件下完成任务（如"用火点燃目标"）。

## 核心循环

选择材料 → 放置在画布上 → 观察互动 → 添加更多材料 → 创造新效果

## 核心机制

- **粒子模拟**：每个像素是一个独立的粒子，有自身的物理属性（重力、密度、可燃性等）。粒子间的互动规则简单但组合效果复杂。
- **化学反应链**：不同材料之间有反应关系——火+油=大火、水+种子=植物、酸+金属=腐蚀。这些反应可以触发连锁效应。
- **开放创造**：没有固定目标，玩家自由发挥想象力创造各种场景。

## 为什么好玩

简单到极致但也有趣到极致。倒一堆沙子看它堆积，点火看它蔓延，放水看它淹没一切——这些基础的物理模拟有天然的吸引力。不同材料组合出的意外效果（比如病毒+火药的连锁反应）让人惊喜。

## 粘性来源

- **实验驱动**："如果我放这个再放那个会怎样"的好奇心
- **连锁反应**：一个简单的操作可能触发壮观的连锁效果
- **创造力释放**：没有规则限制，可以自由发挥
- **教育价值**：直观展示物理和化学原理

## Meta 系统

无。纯沙盒体验，没有外围系统。有预设关卡模式和保存/加载功能。

## 实现难度

高。像素级粒子模拟对性能要求极高。画布上的每个粒子都需要在每一帧更新状态，当粒子数量达到数万甚至数十万时，性能优化是关键。最大的技术难点是高效的粒子更新算法——需要使用空间分区和批量处理来保持帧率。
