# 猎户座熔炉 (Orion's Forge)

- **类型**: 物理益智/策略
- **平台**: Mobile (iOS+Android)
- **开发商**: 未明确标注
- **首次发布**: 未明确标注
- **一句话描述**: 一款以太空为主题的物理益智游戏，通过引导能量流来建造新星

## 玩法规则

游戏核心玩法是引导能量流到达星星发射器（Star Launcher）。每一关，能量团会从屏幕上一个固定点释放出来，玩家需要用手指点击并拖动塔楼，将它们放置在合适的位置来引导能量流的路线。

塔楼分为两种类型：推塔（将能量流推开）和拉塔（将能量流吸引过来）。玩家需要巧妙组合这两种塔楼，为能量流创建一条安全的路径，使其避开障碍物，最终到达不断增长的星星发射器。当星星发射器积累了足够的能量后，它会脉动并爆发，向天空发射一颗星星。

随着关卡推进，会引入新的机制元素：传送门（让能量流穿过空间传送到另一个位置）和转换光束（改变塔楼的极性，推变拉或拉变推）。这些新增元素增加了策略深度，但也让谜题的解法变得更加难以预测。

游戏的叙事方面采用了独特的故事讲述方式——每个章节讲述一个银河系主题的童话式故事，而不是好莱坞式的宏大叙事。

## 核心循环

放置推/拉塔楼引导能量流 -> 到达星星发射器积累能量 -> 爆发新星解锁故事 -> 进入下一关

## 核心机制

- 推拉塔楼系统：两种塔楼分别产生排斥力和吸引力，玩家通过组合它们来引导能量流的路线
- 触摸拖动操控：直接在屏幕上拖动塔楼调整位置，操控直观但效果难以精确预测
- 传送门机制：能量流进入传送门后从另一个出口出现，增加了路径规划的维度
- 转换光束：改变塔楼的极性（推变拉、拉变推），在后期关卡中创造更复杂的连锁反应


- 能量可视化反馈：能量流以发光粒子效果呈现，在塔楼的推拉作用下产生流畅的曲线运动，视觉上直观展示物理力的作用方向和强度

## 为什么好玩

看着能量流沿着你设计的路径流动，最终到达目标并触发星星爆发的过程非常有成就感。推拉力的物理效果在视觉上很吸引人。

## 粘性来源

每个星星爆发都是一个小高潮，推动玩家继续解锁更多故事。但部分关卡过于随机和缺乏逻辑性，可能削弱重复游玩的动力。

## Meta 系统

通过积累能量建造新星来推进故事。故事以银河系童话风格呈现，需要建造足够多的新星才能阅读完整故事。

## 实现难度

中等 — 基础概念简单（推和拉），但塔楼效果难以精确预测，很多时候需要反复试错。最大技术难点是物理模拟的准确性和能量流路径的实时渲染。
