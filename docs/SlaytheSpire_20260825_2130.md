# Slay the Spire+

- **类型**: 肉鸽卡牌
- **平台**: Mobile (iOS+Android)
- **开发商**: Humble Bundle
- **首次发布**: 2023
- **一句话描述**: 一款将卡牌构筑与肉鸽探索完美结合的策略游戏，每次冒险构筑独一无二的牌组

## 玩法规则

游戏主界面以卡牌桌面对战界面，手牌、敌人和遗物清晰可见为核心视觉元素，整体布局简洁直观。屏幕上方/中央区域展示手牌区域、敌人信息、生命值和能量指示器，玩家一眼即可了解当前的核心状态。屏幕下方或侧边排列手牌拖拽区域、结束回合按钮和遗物栏，这些是玩家可以交互的按钮或操作区域。

玩家通过拖拽手牌出牌、选择目标和使用遗物效果进行核心操作。具体而言，每回合开始时抽取固定数量的手牌，玩家消耗能量打出卡牌对敌人造成伤害或获得增益效果。卡牌分为攻击、防御、技能和状态四类，各有不同的能量消耗和效果。敌人回合中，敌人按照预定的意图执行攻击或施加负面效果。击败敌人后可以选择一张卡牌加入牌组。每次操作后，系统会即时给出卡牌打出的动画效果、伤害结算和遗物触发提示，确保玩家对操作结果有清晰的感知。

游戏的核心目标是穿越层层关卡，击败最终Boss。为了达成这一目标，玩家需要管理手牌和能量，根据敌人意图做出最优出牌决策，在奖励中选择增强牌组的卡牌或遗物。当击败最终Boss通关时，玩家进入下一阶段或解锁新内容。反之，如果生命值归零，冒险结束，则需要重新开始或调整策略。

随着游戏进程的推进，随着关卡深入，敌人强度和模式复杂度增加，但玩家的牌组也越来越强大。玩家需要逐步掌握牌组优化、遗物选择和能量管理，才能在更高难度下持续进步。游戏的深度在于每局构筑独一无二的牌组，找到关键卡牌和遗物组合时的"啊哈"时刻让人欲罢不能。四角色体系保证了数百小时的重玩价值。卡牌之间的协同效应和遗物的被动加成创造出近乎无限的可能性，这让简单的操作框架下蕴含着丰富的策略空间。

游戏中的敌人意图会在回合开始时明确显示，玩家需要根据敌人的行动（如"攻击15点伤害"或"施加两层虚弱"）来制定应对策略，这种"明牌博弈"是策略深度的重要来源。

## 核心循环

出牌造成伤害 → 获得金币购买卡牌或遗物 → 构建更强力的牌组继续深入

## 核心机制

- **卡牌构筑系统**: 每场战斗后可以从随机提供的卡牌中选择加入牌组，逐步构建独特的战斗体系。卡牌选择受到角色职业的限制，每个职业有独特的核心卡牌池。玩家需要根据当前战况和长期策略做出选择
- **遗物增益网络**: 遗物提供被动加成效果，如"每次出牌额外抽一张牌"或"生命值低于50%时攻击力翻倍"。不同遗物之间可能产生协同，也可能互相冲突，需要策略性选择。遗物的积累是牌组之外的重要战力来源
- **多角色体系**: 4个角色各有独特的卡牌池、起始遗物和特殊机制。例如某个角色可以修改手牌，另一个角色可以通过消耗生命值获得力量。每次选择不同角色都是一次全新的构筑体验

## 为什么好玩

每局构筑独一无二的牌组，找到关键卡牌和遗物组合时的"啊哈"时刻让人欲罢不能。策略深度极高——不仅是打出卡牌，更是在构建一个精密运转的系统。"这个combo太妙了"的智力满足感是核心吸引力。

敌人意图的透明显示让战斗变成一场智力博弈，玩家需要读懂敌人的下一步并做出最优应对。

## 粘性来源

遗物与卡牌的协同效应发现是最大的粘性——"这个遗物配这张牌居然这么强"的惊喜时刻。四角色×无限牌组组合保证了极高的重玩价值。每次失败都能学到新的策略思路。

每日挑战模式提供了固定的种子和特殊规则，玩家之间可以比较同一条件下的通关表现。

## Meta 系统

卡牌收藏与遗物图鉴：解锁新卡牌加入公共卡池，收集遗物了解其效果。对核心玩法的影响是扩大构筑可能性和降低学习门槛。图鉴系统也提供了明确的收集目标。

某些高级卡牌需要通关特定角色后才能解锁，形成了交叉解锁的进度结构。

## 实现难度

高。卡牌逻辑引擎、遗物交互系统和AI对战逻辑非常复杂。最大技术难点：卡牌×遗物的组合爆炸问题——需要测试海量组合确保游戏平衡，避免某些组合过度强势或完全无用。
