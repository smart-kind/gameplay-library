# 从字母中拼出正确单词的休闲文字游戏（Word Yard）

- **类型**: 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: PlaySimple Games
- **首次发布**: 2019
- **一句话描述**: 从字母中拼出正确单词的休闲文字游戏

## 玩法规则

屏幕上一组字母随机排列，玩家需要从中找出所有正确的英文单词。字母可以组合成不同长度的单词。

每个关卡有特定的单词列表需要找出。找到所有单词即可过关。

较长的单词获得更高分数。游戏帮助玩家扩展词汇量。

## 核心循环

观察字母 → 拼出单词 → 找出所有单词 → 过关 → 下一关

## 核心机制

- 字母组合：从给定字母中找出所有有效单词
- 长度计分：单词越长得分越高
- 关卡递增：字母数量和复杂度逐渐增加
- 词汇扩展：遇到不认识的单词可以学习

## 为什么好玩

简单的文字游戏但有深度，找到隐藏长单词的成就感很强。同时可以学习新单词。

## 粘性来源

词汇挑战；关卡驱动；学习新单词的成就感。

## Meta 系统

关卡解锁。

## 实现难度

低。字母连线拼词简单，但需要词汇量。最大技术难点：词库和关卡生成。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
