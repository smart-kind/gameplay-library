# Busted!（Busted!）

- **类型**: 益智解谜 / 逻辑推理
- **平台**: Mobile (iOS)
- **开发商**: 独立开发者
- **首次发布**: 2010
- **一句话描述**: 通过逻辑推理和模式识别，在有限的线索中找出正确答案

## 玩法规则

游戏采用简洁的界面设计，每个关卡呈现一个谜题场景。玩家需要根据给定的线索和规则，通过逻辑推理来解决问题。

具体玩法因关卡而异——可能是找出隐藏的图案、破解密码、完成逻辑序列等。操作主要是点击、拖拽和选择——点击选择答案、拖拽排列元素、在网格中标记信息。

每个关卡都有明确的规则和目标。玩家需要在有限的尝试次数或时间内找到正确答案。失败条件：用尽尝试次数或超时。过关条件：找到正确答案。

游戏通常有多个关卡，难度逐步递增，从简单的逻辑题到需要多步推理的复杂谜题。

## 核心循环

阅读线索 → 分析逻辑关系 → 做出推断 → 提交答案 → 成功/失败 → 下一关

## 核心机制

- **逻辑推理**：每道谜题都需要运用逻辑推理能力，从有限信息中推导出正确答案。
- **渐进难度**：关卡从简单的单步推理到复杂的多步逻辑链，难度曲线合理。
- **线索系统**：每关提供有限线索，玩家需要学会如何利用和组合线索。
- **试错机制**：允许有限次数的错误尝试，玩家可以在失败中学习和调整。

## 为什么好玩

Busted!满足了人们对逻辑解谜的纯粹享受。不需要反应速度或操作技巧，只需要冷静思考。每解开一道谜题都带来"我做到了"的成就感，特别是那些看似无解的难题。

游戏的谜题类型多样——从经典的数独变体到图形推理、从密码破解到模式匹配。这种多样性确保了不同类型的思考者都能找到适合自己的挑战。有些谜题考验模式识别能力，有些考验逻辑推理能力，有些考验空间想象能力。

简洁的界面设计让玩家可以专注于谜题本身，没有任何干扰元素。这种"少即是多"的设计理念让游戏体验更加纯粹。

## 粘性来源

逻辑谜题的粘性来自"啊哈！"时刻——当复杂的线索突然拼凑起来，答案变得清晰时的那种顿悟感。关卡的渐进难度让每个解谜成功都带来适度的成就感，同时下一关的挑战又在召唤。每日挑战（如果有）也提供持续的动力。

此外，逻辑解谜游戏的一个独特优势是"可以随时暂停"——玩家可以在地铁上、午休时或睡前玩几关，不需要长时间专注。这种碎片化的游玩方式非常契合现代人的生活节奏，也增加了游戏的长期粘性。
