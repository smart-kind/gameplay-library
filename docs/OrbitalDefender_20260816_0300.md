# Orbital Defender

- **类型**: 轨道塔防
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 2011
- **一句话描述**: 轨道塔防游戏，保护人造卫星免受陨石威胁
- **PocketGamer评分**: 8/10

## 玩法规则

玩家负责保护绕轨道运行的人造卫星免受陨石和其他太空碎片的威胁。游戏采用塔防玩法的变体——不是在地面上建塔，而是在轨道上部署防御设施。

游戏界面中，卫星沿着固定的轨道运行，陨石从各个方向飞向轨道。玩家可以部署防御卫星（拦截器）来击碎来袭的陨石。不同类型的防御卫星有不同的拦截范围和攻击方式。

玩家需要根据陨石的飞行轨迹和速度，在恰当的位置部署防御设施。随着关卡推进，陨石的数量、速度和大小都会增加，还可能出现在多个方向。游戏的核心策略是预测陨石的飞行路径，在关键位置部署防御，用最少的资源覆盖最大的威胁范围。当卫星被陨石击中后，玩家失去生命值，生命值归零则游戏结束。

## 核心循环

放置/操作 → 获得奖励/进展 → 升级/解锁新内容 → 挑战更高难度

## 核心机制

- **机制1**：轨道塔防核心循环 — 通过轨道塔防操作完成关卡目标，获得金币/分数奖励
- **机制2**：渐进式难度 — 每个关卡引入新的元素或增加复杂度，玩家需要调整策略
- **机制3**：资源管理 — 有限的建造材料/金币/时间，需要玩家做出取舍决策

## 为什么好玩

Orbital Defender属于塔防类型，玩家需要保护绕轨道运行的人造卫星免受太空碎片威胁。 游戏的评分为8/10，说明这款游戏质量不错，有独特的玩法乐趣。

## 粘性来源

具体到机制层面：核心循环的"完成关卡→获得奖励→解锁新内容"驱动玩家持续游玩；渐进式难度带来的挑战感让玩家想"再来一关"；解谜类游戏特有的"顿悟时刻"（想通了解法）提供强烈的成就感。

## Meta 系统

外围成长系统：通过关卡获得的金币/分数可以解锁新的塔类型/角色/赛道，或升级已有元件的性能。对核心玩法的影响：解锁内容提供了新的策略选择，但不改变核心操作方式。

## 实现难度

中 — 核心玩法基于成熟的轨道塔防机制，最大技术难点在于AI路径规划和实时响应。
