# Skribbl.io（Skribbl.io）

- **类型**: 社交派对 / 画画猜词 / 多人在线
- **平台**: Web（浏览器）
- **开发商**: ticedev / skribbl.io 团队
- **首次发布**: 2017 左右
- **一句话描述**: 多人在线画画猜词游戏——一个玩家画画，其他人在聊天框里猜画的是什么词，猜对得分

## 玩法规则

游戏房间通常容纳 8 名玩家。每轮随机选择一名玩家作为"画手"，系统从三个随机词中选择一个让画手来画。画手有画布和绘画工具（画笔、橡皮擦、颜色选择器、填充工具），需要在限时内画出所选词汇。

其他玩家（"猜手"）在聊天框中输入自己的猜测。第一个猜对的玩家获得最高分，后续猜对的玩家得分递减。如果所有玩家都猜对或时间耗尽，本轮结束。

每轮结束后轮换画手，所有玩家都有机会画画和猜词。最终得分最高的玩家获胜。游戏有自定义房间选项——房主可以设置轮数、时间限制、自定义词库等。

## 核心循环

轮流画画/猜词 → 根据画作猜测词汇 → 得分累积 → 最终排名

## 核心机制

- **限时绘画系统**：画手有固定的时间（通常 60-80 秒）来完成画作。时间压力增加了游戏的紧张感和喜剧效果——画得越抽象，猜的人越困惑。
- **分数递减系统**：第一个猜对的人得分最高，后面猜对的人得分越来越少。这鼓励玩家快速思考并输入猜测，同时也让画手的"画技"成为关键变量。
- **随机词库**：系统从预定义的词库中随机选择三个词让画手选择。词库涵盖简单（"苹果"）到困难（"量子力学"）的不同难度。自定义房间可以使用自定义词库。
- **社交互动**：游戏的核心乐趣很大程度上来自聊天框中的互动——玩家之间的调侃、错误的搞笑猜测、画手的"灵魂画作"。

## 为什么好玩

Skribbl.io 的本质是一个数字化的"你画我猜"派对游戏，但在线多人模式让它突破了物理空间的限制。灵魂画手的抽象作品、猜错词的搞笑场面、以及限时作画的压力感，共同构成了一个让人停不下来的社交游戏体验。

## 粘性来源

- **社交娱乐**：和朋友一起玩时，画技差反而更搞笑——失败比成功更有趣
- **词库多样性**：不同难度的词汇让游戏有变化——有时候画"太阳"很简单，有时候画存在主义就很难
- **低门槛**：不需要任何游戏经验，会画画（或不会画画）就能玩

## Meta 系统

无。纯派对游戏，没有外围成长系统。可能有自定义房间和词库的保存功能。

## 实现难度

低 + 核心是画布同步（WebSocket 传输绘画指令）、聊天系统、回合管理。最大技术难点是多玩家画布的实时同步——需要高效地传输绘画指令（而不是每帧传输整个画布图像）。
