# 迷你游戏 - 平静放松（Mini Games: Calm & Relax）

- **类型**: 休闲/放松
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2025
- **一句话描述**: 以放松为主题的迷你游戏合集

## 玩法规则

玩家选择各类放松小游戏进行体验。游戏设计强调无压力、慢节奏，没有时间限制。操作方式简单直观：点击、滑动、拖拽。每款游戏配以舒缓的音乐和柔和的视觉效果。玩家没有失败的概念，所有操作都产生正向反馈。涵盖涂色、拼图、园艺、冥想等多种活动。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

选择放松活动 → 缓慢操作 → 获得平静感 → 尝试新活动

## 核心机制

- **无压力体验**:  无时间限制和失败条件
- **舒缓美学**:  柔和色彩配舒缓音乐
- **多样化活动**:  涵盖多种放松方式

## 为什么好玩

在忙碌日常中提供放松空间，简单操作即可获得平静感

## 粘性来源

放松体验本身具有吸引力；新活动定期更新

## Meta 系统

活动解锁系统

## 实现难度

低 - 单款小游戏实现简单 - 美术和音效质量要求高，需要专业设计
