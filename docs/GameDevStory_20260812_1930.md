# 游戏开发物语（Game Dev Story）

- **类型**: 模拟经营 / 像素风
- **平台**: Mobile (iOS+Android) / PC / Switch / PS4 / Xbox
- **开发商**: Kairosoft
- **首次发布**: 1997（Windows）/ 2010（Mobile）
- **一句话描述**: 经营一家游戏开发公司，从车库小团队成长为行业巨头，研发各种类型的游戏

## 玩法规则

游戏画面为俯视角的像素风办公室场景。画面中可以看到办公桌、电脑、会议室等办公室布局，员工在各自的工位上工作。整体色调温暖，典型的 Kairosoft 像素美学。

玩家的主要操作是点击屏幕进行各种管理决策。你可以：招聘员工（每个员工有不同的技能和属性）、分配开发任务（选择游戏类型和主题组合）、升级办公室和设备、培训员工提升能力。

游戏的核心循环是开发游戏：选择一个游戏类型（如 RPG、动作、射击）和一个主题（如奇幻、科幻、历史），指派员工开始开发。开发过程中员工会积累"创意点数"和"BUG点数"。开发完成后游戏进入销售阶段，销量取决于游戏质量、市场趋势和你的公司声誉。

每个开发周期持续游戏中的数周时间。玩家需要平衡多个项目、管理员工状态（避免过度加班导致士气下降）、关注行业趋势（什么类型正在流行）。

## 核心循环

开发游戏 → 销售获得收入 → 招聘/升级 → 开发更好的游戏

## 核心机制

- **类型×主题组合系统**：每个游戏由"类型"和"主题"组合定义。某些组合有天然相性（如"RPG+奇幻"是经典搭配），某些组合出人意料地成功（如"射击+烹饪"）。发现黄金组合是游戏的核心乐趣。
- **员工成长系统**：每个员工有四项属性——创造力、速度、技术和经验。通过培训和项目实践提升属性。员工还会"转职"获得特殊能力（如从"程序员"变成"游戏设计师"）。
- **行业趋势模拟**：游戏内有一个模拟的游戏行业发展时间线，从 8 位机时代到现代主机时代。不同时代流行的游戏类型不同，玩家需要适应时代变化。
- **竞赛与会展**：定期举办游戏评选活动，提交你的游戏参赛。获奖能大幅提升公司声誉和销量。
- **隐藏内容解锁**：随着公司成长，会解锁特殊游戏类型（如"网络游戏"）、特殊员工和隐藏平台。

## 为什么好玩

Game Dev Story 把经营模拟的满足感压缩成了口袋大小的体验。每个决策都有明确的反馈——你做了一个"射击+西部"的游戏，销量出来了，评分出来了，赚了多少一目了然。加上 Kairosoft 特有的"再开发一个就睡"的成瘾性设计，让人停不下来。

## 粘性来源

"下一款游戏一定会更好"的期待感。发现新类型组合、解锁隐藏内容的惊喜感。看着小公司从 2 人车库团队变成百人游戏帝国的成长感。每种机制都服务于"再来一局"的核心驱动力。

## Meta 系统

- **公司等级**：从"小作坊"到"游戏巨头"的多级晋升，每级解锁新功能。
- **员工培训**：培训中心、研讨会等提升员工能力的设施。
- **办公室扩建**：从单间办公室到多层大楼，每次扩建增加可容纳员工数。
- **平台授权**：解锁新的游戏发布平台（从 PC 到主机到掌机），扩大市场覆盖。

## 实现难度

低到中等。核心是数值模拟+事件系统，不需要复杂的图形或物理引擎。最大的技术难点在于平衡性——确保不同类型/主题组合的销量分布合理，员工成长曲线有趣，不会过早失去挑战感。Kairosoft 用一套成熟的模板框架实现了多款类似游戏，证明这套系统可以高效复用。
