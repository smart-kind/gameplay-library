# Johnny HotShot

- **类型**: 竞速
- **平台**: Mobile (iOS+Android)
- **开发商**: SayGames LTD
- **首次发布**: 2020
- **一句话描述**: 一款卡通风格的赛车竞速手游

## 玩法规则

玩家驾驶赛车在色彩丰富的赛道上竞速。通过左右滑动切换跑道，点击加速按钮提升速度。赛道上散布着道具箱，拾取后获得临时增益效果如加速、护盾或武器。

每场比赛有 3-6 名对手，目标是获得第一名。赛道包含跳台、环形轨道、shortcuts 等特技元素。碰撞障碍物会减速，碰撞其他赛手会互相干扰。

画面采用 3D 卡通风格，赛道设计充满想象力。界面底部为方向控制和加速按钮，上方显示当前排名和圈数。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

比赛获取金币和奖杯 → 解锁新赛道和赛车 → 挑战更高难度赛事

## 核心机制

- 道具赛系统：赛道上随机分布道具箱，获得加速/护盾/攻击等临时增益
- 特技赛道设计：跳台、环形轨道等元素增加视觉冲击力和操作乐趣
- 排位赛机制：每场比赛有排名，获得不同数量的奖杯和金币奖励

## 为什么好玩

快节奏的赛车体验搭配卡通风格的赛道设计，道具赛模式让每场比赛都有不确定性。

## 粘性来源

解锁新赛车和赛道的收集驱动，以及排位挑战的竞争心理。

## Meta 系统

- 赛车收集系统：不同赛车有不同性能属性（速度/加速/操控）
- 赛道解锁：通过比赛获得奖杯解锁新赛事和赛道

## 实现难度

中等 — 3D 赛车物理和道具系统设计有一定复杂度，最大的技术难点是赛道碰撞检测和物理手感调优。
