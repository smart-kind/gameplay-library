# Pocket Pool（口袋台球）

- **类型**: 体育 / 街机 / 台球
- **平台**: Mobile (iOS + Android)
- **开发商**: Ketchapp
- **首次发布**: 2017
- **一句话描述**: 极简风格的街机台球游戏，一杆接一杆连续进球挑战最高分

## 玩法规则

Pocket Pool 不是传统的 8 球或 9 球台球模拟游戏，而是一种极简化的街机式台球体验。

**核心操作**：玩家通过拖拽屏幕来瞄准和设定击球力度。拖拽方向决定击球方向，拖拽距离决定力度大小。松开手指即可击球。

**一局制设计**：每局只有一杆球的机会。玩家的目标是用这一杆球将尽可能多的球打进袋中。每进一球获得一分。

**连续挑战**：完成一杆后，立即进入下一局。球堆重新排列，玩家继续挑战。系统记录连续进球总数，目标是在尽可能多的连续进球中保持纪录。

**画面风格**：采用极简主义设计，球台和球的造型干净利落，没有多余的 UI 元素。这种设计风格让玩家的注意力完全集中在击球本身。

**全球排行榜**：玩家的最高连续进球数被提交到全球排行榜，与其他玩家竞争。

## 核心循环

拖拽瞄准 → 击球 → 计算进球数 → 重置球堆 → 继续挑战

## 核心机制

- **一杆定胜负**：每局只有一次击球机会，迫使玩家仔细规划瞄准角度和力度
- **极简物理**：球的反弹、碰撞和滚动遵循简化物理规则，确保操作直觉化
- **无失败惩罚**：即使一杆未进球也不会 Game Over，只是本轮分数为零并继续下一轮，保持节奏流畅
- **拖拽力度映射**：拖拽距离线性映射到击球力度，形成简单直观的操作逻辑

## 为什么好玩

"一杆入魂"的设计让每次击球都充满期待。极简的视觉风格配合精确的物理反馈，创造出一种禅意般的沉浸体验。不需要复杂的台球规则知识，任何人只需拖拽就能上手。

## 粘性来源

主要来自连续进球的累积快感——每次多进一个球都推动着玩家"再来一杆"。全球排行榜提供了外部竞争动力，而极简的操作降低了尝试门槛，形成"随手来一局"的习惯。

## Meta 系统

无

## 实现难度

低 — 核心就是一个 2D 物理碰撞引擎加拖拽输入映射。最大技术难点在于物理参数的调校——需要让球的运动感觉"真实但不复杂"，碰撞反馈既准确又不过于精确导致游戏变得太容易。
