# Bacterial Takeover - Idle Game（Bacterial Takeover）

- **类型**: 放置 / 模拟 / 策略
- **平台**: Mobile (iOS)
- **开发商**: Digital Media Technology SLU
- **首次发布**: 2024
- **一句话描述**: 一款以细菌繁殖和扩张为主题的放置游戏，从单个细菌开始逐步进化，适应不同环境，最终占领整个世界。

## 玩法规则

Bacterial Takeover 的画面呈现一个培养皿或微观世界的俯视角场景。初始状态下一个细菌在中央分裂繁殖。画面分为：中央是细菌群落的实时画面（可以看到细菌分裂、移动、感染的动态过程），下方是进化和升级按钮，上方是细菌总数和感染进度统计。

细菌自动分裂繁殖，数量呈指数增长。玩家通过消耗细菌资源来解锁新的进化方向：增强分裂速度（更快的繁殖）、提高生存能力（抵抗环境威胁）、获得新的感染方式（如空气传播、水传播、接触传播）。每种进化都有明确的成本和收益。

每种进化方向解锁后，细菌的扩张效率提升。游戏场景也从培养皿扩展到培养箱、实验室、医院、城市、全球，感染范围不断扩大。不同环境对细菌的挑战不同——医院有抗生素，城市人口密集但免疫系统更强。

玩家可以选择不同的进化路线：专注于快速繁殖（数量优势）、增强抵抗力（生存能力）、获得特殊能力（如抗药性、环境适应性、跨物种传播）。不同的进化路线影响最终的游戏体验和结局。

## 核心循环

细菌自动分裂 → 积累细菌资源 → 选择进化方向 → 扩张到新区域 → 继续进化 → 适应新环境

## 核心机制

- **指数繁殖增长模型**：细菌数量自然增长，形成自我强化的循环，后期数量极其庞大
- **多路线进化树系统**：多条进化路线可选（速度/生存/特殊能力），增加策略性和重玩价值
- **渐进式区域解锁**：从小环境到全球的渐进式扩张，提供清晰的进度感和目标感
- **环境互动适应**：不同区域（医院、城市、野外）对细菌的挑战不同，需要针对性的进化策略

## 为什么好玩

看着细菌从一个变成两个、两个变成四个、最终数以亿计的指数增长过程本身就很有冲击力。进化系统的策略性让简单的繁殖过程变得有趣——你需要决定是快速扩张还是稳扎稳打，每次选择都影响后续发展。



游戏采用了微观视角来呈现宏观的进化过程，这种尺度的反差本身就很有趣味。当你看到自己培养的一小群细菌最终遍布全球，会产生一种"从微小到伟大"的成就感。进化路线的选择也让每次游玩都有不同的体验——有人喜欢快速繁殖的"人海战术"，有人偏好抗药性的"精英路线"。

## 粘性来源

"感染下一个区域"的目标驱动 + 进化路线的选择策略。每次打开游戏看到细菌数量的增长都是一次正面反馈。解锁新区域和新进化方向也提供了持续的新鲜感，以及"如果走另一条路线会怎样"的重玩动力。

## Meta 系统

感染进度系统（百分比显示全球感染程度）+ 进化图鉴（记录所有已解锁的进化方向及其效果）+ 细菌总数统计（衡量细菌种群规模）。

## 实现难度

低 — 核心是指数增长模型和简单的进化树逻辑。最大难点是进化路线的平衡设计，确保每条路线都有独特的价值和挑战，以及后期大量细菌单位的渲染性能优化。
