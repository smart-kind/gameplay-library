# 黎明前的20分钟 (20 Minutes Till Dawn)

- **类型**: Roguelike / 弹幕生存 / 克苏鲁
- **平台**: Mobile (iOS+Android) / PC / Nintendo Switch
- **开发商**: flanne
- **首次发布**: 2022
- **一句话描述**: 在克苏鲁风格的弹幕地狱中生存20分钟，通过升级和角色选择构筑独特的战斗build

## 玩法规则

游戏画面为俯视的黑暗场景，玩家角色站在中央，四面八方不断涌来怪物。玩家自动射击（或手动射击，取决于角色），需要移动躲避密集的弹幕。

游戏目标是在不断升级的怪物浪潮中生存20分钟。随着时间推移，怪物数量越来越多，种类越来越强。每消灭一个怪物，它掉落经验球。收集足够经验后角色升级，从三个随机升级选项中选择一个。

升级选项包括新武器、武器升级、属性提升（伤害、射速、移动速度、生命值等）和特殊能力。玩家需要根据当前的build做出最优选择。

如果角色生命值归零，游戏结束。每局约5-20分钟。

## 核心循环

消灭怪物 → 收集经验 → 升级选择 → 变得更强 → 应对更多怪物

## 核心机制

- **角色系统**：多个可选角色，每个角色有独特的武器和被动技能。例如有的角色使用霰弹枪（近距离高伤害），有的使用魔法书（法术伤害），有的使用弓箭（远程精准）。
- **升级构筑**：每级从三个随机选项中选择，形成独特的build。升级之间可能产生协同——例如"子弹穿透"加上"额外投射物"可以产生强大的清场效果。
- **克苏鲁主题**：怪物设计灵感来自克苏鲁神话，包括触手怪、眼球怪、暗影生物等。黑暗的氛围和诡异的音乐增强了紧张感。
- **时间压力**：20分钟的倒计时既是目标也是压力源。前几分钟相对轻松，最后几分钟则是弹幕地狱，考验玩家的build和走位。游戏中途会有检查点提示（如"还剩10分钟"），让玩家了解自己的进度。不同的角色和难度会改变20分钟的目标时间。

## 为什么好玩

将Vampire Survivors的核心公式与克苏鲁主题结合，形成了独特的氛围。紧凑的20分钟节奏让人无法放下——"就差一点就能活到最后"的感觉驱动着一次又一次尝试。

## 粘性来源

构建多样性是核心——不同角色 × 不同升级路径的组合产生了大量可能的build。每次失败都能发现新的有效组合。解锁新角色和成就也提供了长期目标。

## Meta 系统

角色解锁：通过达成条件解锁新角色。难度递增：通关后解锁更高难度。成就系统提供额外的挑战和奖励。

## 实现难度

低到中。弹幕生存游戏的核心技术（碰撞检测、大量实体渲染、自动射击）比较成熟。最大难点在于性能优化——后期屏幕上可能有数百个怪物和弹幕同时存在。

需要在移动设备上保持稳定的帧率，这意味着需要使用对象池、批量渲染、空间分割等技术来管理大量实体。克苏鲁主题的美术风格（黑暗氛围、诡异怪物）也需要精心设计的视觉效果。
