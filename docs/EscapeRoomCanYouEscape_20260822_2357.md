# 密室逃脱：你能逃脱吗（Escape Room: Can You Escape）

- **类型**: 解谜 / 逃脱 / 找物
- **平台**: Mobile (iOS+Android)
- **开发商**: 龙威 杨 / Zhihao Ma
- **首次发布**: 2016-2020
- **一句话描述**: 经典逃脱游戏系列，在封闭房间中寻找线索、解开谜题、打开门逃出的益智解谜。

## 玩法规则

每个关卡是一个封闭的房间，玩家需要找到逃离的方法。房间内有各种可交互物品：门（通常是出口但被锁住）、家具（可以打开或移动）、物品（可以拾取和使用）、机关（密码锁、颜色开关等）。

玩家通过点击物品进行交互：打开柜子查看内容、拾取地上的物品、操作墙上的机关等。拾取的物品会进入'背包'，可以在其他地方使用。例如，在书架上找到钥匙，用来打开抽屉；在抽屉中找到密码提示，用来解开保险箱。

谜题之间形成依赖关系——解开A获得B，用B解开C，用C打开出口。部分谜题需要观察环境细节：墙上的数字序列、书架上书籍的颜色顺序、挂钟的指针位置等都可能是密码的一部分。

游戏难度循序渐进：早期房间物品少、线索直接；后期房间更复杂、线索更隐蔽、谜题更抽象。部分版本设有提示系统，卡关时可以获得线索但会扣分或消耗资源。

## 核心循环

搜索房间找线索 → 收集和使用道具 → 解开连锁谜题 → 打开门逃脱

## 核心机制

- 道具使用机制：拾取物品后在正确的地方使用，这是逃脱游戏最核心的循环。'在背包中找到对的物品并用在对的地方'的顿悟感是游戏的核心乐趣。
- 环境观察机制：线索隐藏在环境细节中——墙上的画、桌面的图案、地毯的纹理都可能是密码或提示。训练玩家的观察力和联想能力。
- 连锁解谜机制：谜题形成依赖链——A→B→C→出口，玩家需要理解整个链条才能高效通关。解开一个谜题后获得下一个谜题的线索，形成'解谜流水线'。

## 为什么好玩

逃脱游戏最经典的形式——在封闭空间内通过智慧和观察力找到出路。每解开一个谜题都离自由更近一步，这种'逐步接近目标'的进程感极其吸引人。

## 粘性来源

每个房间是一个独立的智力挑战，完成后的'我逃脱了'满足感很强。同时，'差一点就想出来了'的张力驱动反复尝试。房间数量的积累也形成'收集完成'的目标。

## Meta 系统

房间解锁制，每完成一组房间解锁新系列。无付费数值成长，以内容消耗为主。部分版本有提示积分系统。

## 实现难度

低到中等。2D静态场景+道具背包+点击交互，技术实现简单。最大难点在于谜题设计的多样性和逻辑性——每个房间的谜题链需要既有趣又合理。


游戏的核心设计理念是'环境即谜题'——房间里的每一件物品、每一处细节都可能是解谜的关键。这种设计让玩家养成'仔细观察一切'的习惯，培养了空间感知力和联想能力。成功的逃脱不是靠运气，而是靠对环境细节的全面理解和逻辑推理。
