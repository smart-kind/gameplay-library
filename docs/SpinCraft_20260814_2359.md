# SpinCraft

- **类型**: 模拟/休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款以旋转和制作为核心的休闲模拟游戏

## 玩法规则

玩家通过旋转操作来制作和装饰各种物品。旋转速度和方向影响最终成品的形状和效果。点击添加材料或装饰元素。

游戏包含多个制作模式，如陶艺旋转、蛋糕装饰等。每个模式有不同的操作方式和目标。完成后可以给作品打分并分享到社交网络。

画面采用 3D 建模风格，制作过程有流畅的动画效果。界面底部为工具和材料选择栏。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

旋转制作物品 → 获得评分 → 解锁新制作模式和材料

## 核心机制

- 旋转操作：通过控制旋转速度和方向来塑造物品
- 多模式系统：陶艺、蛋糕装饰等多种制作模式
- 评分反馈：系统根据制作精度给出评分

## 为什么好玩

模拟真实制作过程的满足感，看着一个普通材料变成精美作品。

## 粘性来源

解锁新制作模式的驱动力和社交分享的成就感。

## Meta 系统

- 材料解锁系统：通过游戏进度解锁新材料
- 工具升级：提升工具精度和效率

## 实现难度

中等 — 3D 旋转建模和物理模拟有一定复杂度，最大的技术难点是旋转操作的精确映射和视觉效果。
