# 弹猪：武装与美味（Ammo Pigs: Armed and Delicious）

- **类型**: 像素射击 / 平台动作
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发
- **首次发布**: 2019
- **一句话描述**: 一款像素风格的横版射击游戏，玩家操控愤怒的猪对抗邪恶AI，在平台关卡中边跑边射。

## 玩法规则

游戏采用像素美术风格的横版平台视角。玩家操控一只猪在粗犷的平台关卡中移动，射击沿途遇到的所有敌人。屏幕顶部有心形生命值显示，生命值耗尽则游戏结束。

游戏提供三种难度选择，直接影响死亡后的惩罚程度。简单模式下死亡后从当前关卡起点重新开始；中等模式下死亡后从游戏开头重新开始，丢失当前关卡的进度；困难模式下不仅从游戏开头重新开始，还会清除已收集的进度和强化，一切归零。

控制方式为触屏操作——虚拟摇杆控制移动方向，射击按钮开火。关卡设计包含平台跳跃、敌人遭遇和物品收集等元素，需要在移动和射击之间找到平衡。

游戏的难点在于某些关卡设计会在新手第一次尝试时就给出极高的挑战。即使你可以选择难度，但在某些关卡中第一次玩几乎必然会被彻底击败。这不是缺点，而是一种设计理念——让玩家在失败中学习。

## 核心循环

通过关卡 → 射击敌人 → 收集物品 → 面对Boss或更难关卡

## 核心机制

- **多难度系统**: 三种难度影响死亡惩罚程度，让不同水平的玩家都能找到合适的挑战
- **平台射击**: 横版移动加射击的经典组合，在平台关卡中边跑边打
- **像素美术**: 粗犷的像素风格，虽然不够独特但扎实可靠，符合射击游戏的视觉需求
- **永久死亡惩罚**: 困难模式下的永久进度清除为追求极限的玩家提供终极挑战
- **生命值系统**: 心形生命值直观显示，耗尽即死亡，但难度不同后果不同

## 为什么好玩

游戏提供了扎实的平台射击体验，多难度系统让新手和老手都能享受。困难模式的永久死亡惩罚为硬核玩家提供了真正的挑战，每一次通过都来之不易。像素美术虽然不算独特，但整体游戏品质值得肯定。

## 粘性来源

主要来自挑战欲——"下一次我能通关吗？"多难度系统意味着每次失败后可以选择降低难度继续，或者在困难模式下赌上一切。关卡中的物品收集和进度积累也提供了短期动力。

## Meta 系统

无复杂外围系统。进度积累主要体现在困难模式下的永久清除机制中，其他模式下为关卡解锁。

## 实现难度

中。需要实现横版平台物理、敌人AI、射击系统和多难度逻辑。最大难点是关卡设计的平衡——既要足够挑战又不能让人完全无法通过，以及触屏操控的优化。
