# Stickman Rush（火柴人大冲锋）（Stickman Rush）

- **类型**: 跑酷 / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer收录
- **首次发布**: 2015
- **一句话描述**: 一款以火柴人为主角的横版跑酷游戏，通过简单的点击和滑动操作完成跳跃、滑行、攻击等动作来越过障碍。

## 玩法规则

游戏画面是横版卷轴场景，火柴人角色自动向前奔跑。场景中会出现各种类型的障碍物：地面上的尖刺和火坑、空中的摆锤和落石、需要攻击消灭的敌人等。

操作方式简单直观：点击屏幕跳跃，点击时间长短决定跳跃高度，长按跳得更高。向下滑动实现翻滚或滑行动作，点击特定敌人目标进行攻击。部分版本支持二段跳能力。

障碍物需要不同的应对方式，地面上的陷阱需要跳跃越过，空中的障碍需要滑行通过，迎面而来的敌人需要攻击消灭或躲避。有些障碍组合需要连续操作才能通过。

游戏目标是到达关卡终点或尽可能远地奔跑。碰到障碍物则损失一条生命，生命耗尽后游戏结束。部分版本有检查点系统，死亡后从最近的检查点重新开始。

## 核心循环

自动奔跑 → 识别障碍类型并选择对应操作 → 成功越过或消灭 → 继续前进 → 追求更远或通关

## 核心机制

- **机制1**：节奏化跑酷机制：障碍物的排列有内在节奏感，玩家需要像演奏乐器一样在正确时机按下正确操作。熟练后形成流畅的舞蹈体验，整个跑酷过程变成了一种节奏游戏。
- **机制2**：多操作应对机制：不同障碍物要求不同操作即跳跃、滑行、攻击，玩家需要在高速移动中快速识别障碍类型并做出正确反应。这种多样性保持了游戏的新鲜感。
- **机制3**：二段跳扩展机制：随着游戏推进，玩家可以解锁二段跳能力，空中机动性大幅提升，可以跨越更复杂的障碍组合。这种能力成长形成了明确的进度感。

## 为什么好玩

火柴人的简约风格配合流畅的动作设计，让整个跑酷过程像看一场精彩的杂技表演。一次完美通过复杂障碍序列的成就感极强，让人想要反复尝试以达到完美。

## 粘性来源

肌肉记忆形成的手熟感加上每次刷新纪录的成就感加上火柴人风格降低了失败时的挫败感，死亡不心疼反而想再来一次。

## Meta 系统

角色皮肤解锁系统加关卡进度，收集金币解锁新的火柴人外观和特殊能力如二段跳、磁力吸附金币、无敌护盾等。

## 实现难度

中 -- 横版卷轴动画和流畅的动作状态机是核心挑战，需要精细调校每个操作的帧数据。最大难点是让火柴人的动作看起来流畅自然且有重量感。

## 关卡设计示例

- **第1-5关**：基础教学，只有单一类型障碍（地刺），让玩家掌握跳跃操作
- **第6-15关**：引入空中障碍和敌人，需要组合跳跃和攻击
- **第16-30关**：加入移动平台和连续障碍组合，需要节奏感
- **第31关+**：全类型障碍混合，出现需要精确二段跳才能通过的极难段落
