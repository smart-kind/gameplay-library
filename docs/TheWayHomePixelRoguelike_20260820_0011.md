# 回家之路（The Way Home: Pixel Roguelike）

- **类型**: Roguelike 地牢探索 / 像素 RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: Concode Corp.
- **首次发布**: 2021
- **一句话描述**: 被困在陌生岛屿上的凯文和芝士（一只狗）需要通过各种随机生成的地牢战斗，组合15种以上不同技能来击败80种独特怪物，最终安全回家。

## 玩法规则

游戏采用像素风格的俯视角画面。玩家控制凯文（和他的狗芝士）在程序化生成的地图中探索。地图由多个房间和通道组成，每次进入都会重新生成。

每个房间中会出现怪物，玩家需要使用技能组合进行战斗。游戏提供超过15种不同的技能，玩家可以在每次升级时选择和组合不同的技能，形成独特的战斗风格。

游戏的核心特色是"自动战斗+技能组合"系统：玩家主要策略在于技能选择和搭配，战斗过程中角色会自动攻击，但玩家需要把握技能释放的时机和走位来躲避怪物攻击。

击败区域 Boss 后可以进入下一个区域。目标是穿越8个区域，最终帮助凯文和芝士回家。

## 核心循环

探索房间 → 战斗获得经验 → 升级选择技能 → 击败Boss前进 → 死亡后重新开始

## 核心机制

- **技能组合**：15种以上技能自由搭配，每次选择都影响战斗风格，提供巨大的策略空间
- **自动战斗**：角色自动攻击，玩家专注于走位和技能释放时机，降低操作门槛
- **程序化地图**：每次重新生成，确保每局体验独特
- **80种怪物**：每种怪物有独特的攻击模式，需要不同的应对策略
- **派对模式**：支持多人组队游玩

## 为什么好玩

像素风格的可爱画风与 Roguelike 的硬核玩法形成有趣的对比。技能组合系统让每次升级都充满期待——"这次我要试试什么流派？"。自动战斗机制让不擅长动作游戏的玩家也能享受策略乐趣。

## 粘性来源

- **流派探索**：不同技能组合创造不同玩法，激发尝试欲
- **80种怪物**：丰富的敌人种类让战斗保持新鲜感
- **宠物陪伴**：芝士（狗）的存在增加情感连接
- **派对模式**：社交合作增加重玩价值

## Meta 系统

- **技能解锁**：通过游戏进度解锁新技能
- **角色成长**：永久属性提升
- **成就系统**：完成特定挑战解锁成就

## 实现难度

中等。程序化地图生成+技能系统+AI怪物行为。最大技术难点是技能组合的平衡性和关卡生成的可玩性保证。
