# 红色派系：游击战（Red Faction: Guerrilla）

- **类型**: 第三人称射击 / 开放世界
- **平台**: PS3 / Xbox 360 / PC / Switch
- **开发商**: Volition
- **首次发布**: 2009
- **一句话描述**: 以破坏为核心的开放世界第三人称射击游戏，玩家扮演火星殖民地的游击队员对抗独裁统治。

## 玩法规则

游戏设定在火星的开放世界地图中。画面以红色沙漠、工业建筑和殖民地设施为背景。玩家可以自由探索整个区域，接受任务或自行发起游击行动。

核心操作是射击和破坏。玩家使用各种武器（步枪、火箭筒、炸药等）攻击敌人和建筑物。游戏的独特之处在于几乎所有建筑物都可以被部分或完全摧毁——墙壁可以被炸开，楼层可以坍塌，整个建筑可以被夷为平地。

游戏目标是完成游击队的任务：破坏敌方设施、消灭敌军、解放被占领区域。完成任务后获得声望值，声望越高，可使用的武器和资源越高级。

当某个区域的敌军威胁降低到一定程度，该区域被解放。但敌军会派出增援部队重新占领，玩家需要持续维护解放区域。

## 核心循环

执行游击任务/破坏设施 -> 获得声望/武器 -> 提升战斗力 -> 解放更多区域

## 核心机制

- Geo-Mod 2.0破坏引擎：游戏的核心技术，允许玩家实时破坏几乎所有建筑结构。墙壁、柱子、地板都可以被炸出缺口，破坏方式会影响建筑的承重和坍塌方式。
- 开放世界游击战：与线性射击游戏不同，玩家可以自由选择攻击目标和方式——正面突击、伏击、狙击、爆破等。
- 声望与威胁系统：玩家的行动会影响各区域的势力平衡。解放区域后敌军会增援，形成持续的拉锯战。

## 为什么好玩

Red Faction: Guerrilla最大的乐趣在于想炸什么就炸什么的自由度。看到一栋建筑因为炸掉了关键承重柱而轰然倒塌，这种物理破坏的爽快感是其他射击游戏无法提供的。游击战术的多样性也让每次行动都有不同的策略选择。

## 粘性来源

粘性来自持续的区域解放循环和破坏带来的爽感反馈。每次炸毁敌方基地后的成就感，以及看到地图上一个又一个区域被解放的进度感，都驱使玩家不断前进。

## Meta 系统

声望与武器解锁系统。完成任务获得声望，解锁更高级的武器、载具和能力。武器有不同的升级路径（威力、射速、弹匣容量等）。

## 实现难度

高。最大的技术难点是实时建筑破坏物理——需要模拟建筑结构的承重关系、坍塌动力学和碎片物理，同时还要保持游戏流畅运行。这是业界最具挑战性的物理系统之一。
