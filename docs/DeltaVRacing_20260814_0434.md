# Delta-V Racing

- **类型**: 竞速 / 射击
- **平台**: Mobile (iOS+Android)
- **开发商**: Pixelbite
- **首次发布**: 2012
- **一句话描述**: 俯视角科幻飞船竞速射击，融合赛道战斗与武器系统

## 玩法规则

游戏以俯视角呈现科幻赛车场景，玩家操控未来飞船在赛道上竞速。画面中可以看到赛道、对手飞船以及各种道具图标。

游戏包含 36 个赛事，分布在四个联盟中。比赛类型包括传统竞速（争夺第一名）、淘汰赛（Elimination）和计时赛（Hot Lap）等多种模式，每种模式对规则做了微调。

每场比赛根据表现颁发金、银、铜奖牌，解锁新赛事通常需要你在之前的挑战中获得更好的奖牌以赚取更多积分。比赛中获得的现金可以用来购买更高级的飞船。

比赛过程中，屏幕上会出现各种图标：加速图标提升飞船速度，减速图标则需要躲避（但在特殊的"生存"模式中反而需要主动碰撞减速）。武器包括导弹、机枪、激光和地雷，通过点击屏幕上的对应按钮来激活使用。

## 核心循环

参赛赚取奖金/奖牌 → 购买更好飞船 → 挑战更高联盟赛事

## 核心机制

- **武器系统**：四种武器（导弹、机枪、激光、地雷），各自有不同的攻击距离和伤害类型，需要合理使用来干扰对手
- **奖牌晋级制**：金银铜牌系统强制玩家回刷低难度关卡获取更好成绩，形成自然的难度曲线
- **赛道道具互动**：速度/减速图标分布在赛道上，玩家需要选择路线来最大化收益或最小化风险

## 为什么好玩

Delta-V Racing 将俯视角竞速与轻度射击结合得恰到好处。四种武器各有特色，导弹适合远程打击，机枪适合近身缠斗，激光穿透力强，地雷可用来封锁路线。在高速竞速中还要兼顾武器瞄准和赛道道具收集，形成紧张刺激的多任务体验。

## 粘性来源

数值成长驱动——从初级联盟一路打到高级联盟的成就感，以及收集现金升级飞船的持续动力。奖牌系统也鼓励反复挑战以获取更好成绩。

## Meta 系统

- **现金经济系统**：比赛赚取现金 → 购买更高级飞船 → 获得速度/武器优势 → 挑战更难赛事
- **奖牌收藏**：金、银、铜三种奖牌作为完成度指标，驱动玩家反复游玩
