# 搏击之夜4（Fight Night Round 4）

- **类型**: 格斗 / 体育模拟
- **平台**: PS3 / Xbox 360 / Mobile (Windows Mobile, BlackBerry)
- **开发商**: EA Sports
- **首次发布**: 2009
- **一句话描述**: EA Sports出品的拳击模拟游戏，是搏击之夜系列的第四部作品，以穆罕默德·阿里和迈克·泰森为封面拳手。

## 玩法规则

游戏画面以写实风格的3D拳击擂台为核心，采用第一人称或第三人称视角。玩家可以看到擂台四周的观众、灯光效果以及两位拳手在擂台中央对峙。UI元素包括双方的体力条、回合计时器和当前的比分。

玩家操作分为进攻和防守两大类。进攻包括直拳（Jab）、勾拳（Hook）、上勾拳（Uppercut）和身体击打（Body Shot）。每种拳击的力度和角度通过右摇杆或滑动方向控制，按键决定出拳类型。防守包括格挡（按住防御键减少伤害）、闪避（左摇杆侧移躲开攻击）和摇闪（低头躲过上方来拳）。

游戏的核心判定基于体力条和伤害累积系统。每次有效命中会削减对手体力和健康值。当一方被击倒后，需要在裁判读秒内站起。被击倒三次即判TKO（技术击倒）。如果打满全部回合，则由裁判按得分判定胜负。

游戏目标是在比赛中击败对手，赢得头衔。Legacy模式是游戏的核心特色，玩家创建一个自定义拳手，从底层比赛开始逐步提升排名，最终挑战世界冠军。在Legacy模式中，玩家需要在训练、比赛和媒体活动之间做出选择。

## 核心循环

训练/比赛 -> 获得经验/金钱 -> 提升拳手属性 -> 参加更高水平比赛

## 核心机制

- Legacy Mode（传奇模式）：创建自定义拳手，通过比赛积累经验和名气，逐步从地下拳击赛打到世界冠军。每次比赛后可分配技能点提升力量、速度、耐力、防御等属性。
- Total Punch Control（全拳击控制系统）：通过精确的摇杆方向+按键组合，控制出拳的角度、力度和类型，实现高度拟真的拳击体验。
- Champion Challenge（冠军挑战）：使用真实历史拳手（如阿里、泰森）重演经典比赛，还原真实比赛的条件和策略。

## 为什么好玩

拟真拳击体验的核心吸引力在于一击定胜负的紧张感。每次出拳都有真实的物理反馈，击倒对手时的慢动作回放极具震撼力。Legacy模式让玩家长期投入一个拳手的成长历程，从无名小卒到世界冠军的蜕变过程充满成就感。

## 粘性来源

粘性来自Legacy模式的长期成长系统——看着自己创建的拳手从默默无闻到世界冠军，属性提升的数值成长和排名变化提供了持续动力。差一点就KO的挫败感也让人忍不住再来一局，尝试不同的战术组合。

## Meta 系统

拳手属性成长系统（Legacy模式）。玩家通过比赛获得经验值，分配给力量、速度、耐力、防守等属性。属性直接影响拳击伤害、出拳速度、抗打击能力。此外还有名气系统，影响比赛收入和媒体关注度。

## 实现难度

中。最大的技术难点在于拳击物理碰撞的真实感模拟——需要处理两个角色的骨骼动画、碰撞检测、击倒物理和伤害计算的实时同步。
