# Water Sort Puzzle（水排序谜题）

- **类型**: 益智 / 排序 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: IEC GLOBAL PTY LTD
- **首次发布**: 2020
- **一句话描述**: 将不同颜色的液体层倒入试管中，最终让每支试管只含一种颜色

## 玩法规则

游戏画面展示若干支透明玻璃试管，每支试管中装有分层的彩色液体（通常 4 层）。同一支试管内的液体颜色各不相同。此外还有若干空试管。

玩家点击一支试管选中它，再点击另一支试管作为目标。如果满足条件，源试管最顶层的液体会倒入目标试管顶层。倒入条件：
- 目标试管不是满的
- 目标试管为空，或目标试管顶层液体颜色与源试管顶层液体颜色相同
- 源试管顶层液体下方必须是同色液体（即不能把部分颜色的液体倒出，必须倒完整的一叠同色液体，除非是最上面一层）

游戏目标是让所有试管中的液体都变成单一颜色——即每支试管要么为空，要么全装同一种颜色的液体。当所有颜色都归位，关卡通过。

关卡难度由试管数量、颜色种类数量、初始混合程度决定。部分高级关卡使用"锁定"机制（某些液层被锁定不能移动）或增加颜色种类。

## 核心循环

观察试管状态 → 选择可倒入的颜色组合 → 执行倒水操作 → 状态更新 → 继续规划 → 所有颜色归位过关

## 核心机制

- **分层液体排序**：核心是经典的排序问题变体。每个试管是一个栈，只能操作栈顶元素。液体只能倒入相同颜色的栈顶或空栈。这本质上是一个带有约束的排序算法游戏化。
- **空管资源管理**：空试管是最宝贵的资源——它们是"中转站"。合理利用空管来暂存不同颜色的液体，是解决复杂关卡的关键策略。
- **颜色归位策略**：先完成一种颜色释放一支试管变为空管，可以为后续操作提供更大灵活性。但过早完成某种颜色可能浪费空管资源。
- **撤销机制**：允许无限次撤销，降低挫败感。玩家可以尝试不同的操作顺序，找到最优解。

## 为什么好玩

看着五颜六色的液体在试管间流转，最终每支试管变得干净整齐的过程，天然地满足人类对"秩序感"的追求。每一次成功的倒水操作都是一次小小的秩序建立，而当最后一滴液体归位时的成就感，是对耐心规划的最高奖励。

## 粘性来源

- **秩序感满足**：从混乱到整齐的视觉变化带来深层心理满足
- **关卡数量庞大**：数千关卡，难度递进，长期可玩性极高
- **无压力节奏**：无计时器、无失败惩罚（无限撤销），适合放松
- **"差一步"效应**：经常在最后几步发现走错了路，想重新开始

## Meta 系统

- **关卡解锁**：按序号递进，通过当前关卡解锁下一关
- **提示系统**：广告或内购获取提示（高亮下一步最优操作）
- **皮肤/主题**：部分版本可更换试管和液体外观主题

## 实现难度

低。核心数据结构是多个栈数组，操作逻辑简单（栈顶元素转移 + 约束检查）。最大技术难点在于液体动画的自然表现——倒入时的流体效果和颜色混合的视觉呈现，需要粒子系统或 Shader 来实现流畅的液体动画。
