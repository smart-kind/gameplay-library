# 怒火之翼（Wings of Fury）

- **类型**: 射击 / 模拟
- **平台**: Mobile (iOS)
- **开发商**: The Android Machine
- **首次发布**: 2011
- **一句话描述**: 二战题材2D横向卷轴射击游戏，玩家驾驶Thunderbolt战斗机执行轰炸和攻击任务，致敬Apple II时代的经典同名游戏。

## 玩法规则

每关任务开始前，玩家需要执行起飞程序，加大油门让飞机加速，控制仰角离开跑道。起飞操作借鉴传统飞行模拟，物理感较重。

空中移动使用虚拟摇杆，可向上爬升、向下俯冲或左右倾斜转弯。没有花式特技动作，操作相对简洁。

武器系统包括：炸弹（用于轰炸地面目标）、机枪和火箭弹（需倾斜飞行对角射击）。投弹时需考虑飞行速度对落点的影响。

每架飞机受到损伤会漏油，必须返航维修。每关分配三架飞机，用完则任务失败。

任务目标从最初的轰炸单个防空炮，逐步扩展到攻击混凝土碉堡、消灭敌方士兵（会修复防御工事）、以及击落敌方战机。

通关条件为消灭关卡内所有敌方目标（All hostiles eliminated）。
## 核心循环

起飞，执行轰炸和攻击任务，受损返航维修，用剩余飞机继续，消灭所有敌方目标通关

## 核心机制

- **物理起飞系统**：模拟真实飞机起飞过程，需要控制油门和仰角，失败则飞机坠毁
- **有限资源管理**：每关仅三架飞机，受伤漏油必须返航，迫使玩家在进攻和保全之间权衡
- **多武器系统**：炸弹用于地面轰炸（需考虑飞行速度对落点的抛物线影响），机枪和火箭弹用于空中交战
- **渐进难度系统**：每关增加更多目标和更复杂的防御，高难度下弹药量受限需频繁返航补给

## 为什么好玩

对经典游戏的怀旧致敬，重量感十足的飞行物理让每次起飞都像在与重力搏斗。虽然画面只是给原作加了层闪光漆，但操作手感保持了原作的厚重感。

## 粘性来源

成功完成一次长途突袭并毫发无损返航的成就感是核心粘性来源。但极高的重复通关需求（同一关卡反复尝试数十次）可能让休闲玩家望而却步。老派玩家则会乐在其中数周。

## Meta 系统

无成长系统。纯关卡制体验，进度体现在解锁后续关卡上。难度选择（简单或困难）影响弹药量和敌人数。

## 实现难度

高。最大技术难点在于飞行物理模拟的精确性（起飞、降落、投弹抛物线）以及2D横向卷轴下碰撞检测的可靠性。
