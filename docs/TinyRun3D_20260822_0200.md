# 迷你跑酷3D（Tiny Run 3D）

- **类型**: 超休闲/跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2021
- **一句话描述**: 3D无尽跑酷小游戏

## 玩法规则

玩家控制角色在3D跑道上自动向前奔跑。通过左右滑动切换跑道，向上滑动跳跃，向下滑动滑行。跑道上散布着金币需要收集，同时有需要躲避的障碍物。撞到障碍物则游戏结束。跑道会逐渐加速，难度递增。收集的金币可用于解锁新角色和皮肤。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

自动奔跑 → 滑动躲避+收集金币 → 碰撞结束 → 重新开始

## 核心机制

- **自动奔跑**:  角色自动前进，玩家只需躲避
- **三跑道设计**:  左右切换是最核心的操作
- **速度递增**:  逐渐加速增加紧张感

## 为什么好玩

高速奔跑带来的紧张刺激，简单操作的易上手性

## 粘性来源

追求更高分数的冲动；角色和皮肤收集的欲望

## Meta 系统

金币收集和角色/皮肤解锁

## 实现难度

低 - 核心是跑道生成和碰撞检测 - 无限跑道生成的随机性和可玩性平衡
