# Block Blast

- **类型**: 休闲/消除解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Hungry Studio
- **首次发布**: 2021
- **一句话描述**: 2024-2025年下载量领先的方块消除解谜游戏，结合经典拼块与现代节奏机制

## 玩法规则

玩家面对一个8x8的网格棋盘，屏幕下方每次提供3个不同形状的方块组合。
玩家需要将这些方块拖放到棋盘上，填满整行或整列即可消除得分。
消除行或列后，被消除的行或列消失，上方方块不变（非重力下落式），棋盘保持静态。
每次放置一个方块后，下方提供新的方块组合，直到3个全部放置完毕后刷新下一组。
当棋盘上无法放置当前提供的任何方块时，游戏结束。
游戏目标是在有限空间内尽可能消除更多行和列，获得更高分数。
连续消除（Combo）会带来额外加分和特效反馈。

## 核心循环

放置方块到棋盘 -> 填满行列消除得分 -> 刷新新方块 -> 持续消除挑战高分

## 核心机制

- **方块拖放**：玩家从底部提供的3个方块中选择并拖放到棋盘任意空位，自由度高，需要空间规划能力
- **行列消除**：填满整行或整列即可消除，同时消除多行多列时触发Combo特效和额外加分
- **静态棋盘**：与俄罗斯方块不同，方块放置后位置固定不移动，消除只影响被填满的行列，降低不可预测性
- **三连刷新**：每次提供3个方块，全部放置后刷新，玩家需要规划3个方块的最佳放置顺序

## 为什么好玩

Block Blast将经典拼块解谜的节奏放慢，给玩家充足时间思考每一步。消除行和列时的视觉特效和音效反馈带来满足感，而"棋盘快要满了"的紧张感驱动玩家追求更优解。Combo连续消除的正向反馈极强。

## 粘性来源

核心粘性来自空间规划的解谜乐趣和消除Combo的爽感反馈。每次游戏都是独特的棋盘状态，没有固定解法。追求高分和连续消除记录提供持续的动力。关卡目标和每日挑战进一步增加重玩价值。

## Meta 系统

关卡/任务系统。游戏包含不同关卡和每日挑战目标，完成特定消除任务获得奖励。对核心玩法无直接影响，提供进度感和新鲜感。

## 实现难度

低。核心是网格放置+行列检测消除，算法简单。技术难点在于方块形状的随机生成平衡性（确保不会过早出现无解局面）和拖放交互的流畅性。
