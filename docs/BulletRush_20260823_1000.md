# Bullet Rush!

- **类型**: 动作射击
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2020
- **一句话描述**: The most modern and dynamic shooter with the cutest graphics you have ever seen!

## 玩法规则

Bullet Rush!是一款动作射击类移动游戏。游戏的核心体验围绕简单直观的触控操作展开，玩家通过屏幕互动来完成游戏目标。

游戏启动后，玩家看到主界面，通常包含开始按钮、设置选项和可能的进度展示区域。进入游戏后，画面中央是主要游戏区域，四周分布着操作按钮和状态信息。

玩家的操作方式以单指触控为主——点击、滑动或拖拽，具体取决于当前游戏模式。每次操作都会产生即时的视觉和物理反馈，让操作结果一目了然。

游戏的目标因模式而异：在竞速模式中需要比其他玩家更快到达终点；在解谜模式中需要找到正确的解决方案；在放置模式中则是持续积累资源并解锁新的升级。

游戏结束或过关的条件取决于具体模式：竞速模式以到达终点或时间耗尽为结束条件；解谜模式以完成当前关卡的谜题为过关条件；放置模式则没有明确的结束点，而是以不断解锁新内容为持续目标。

## 核心循环

动作射击 → 获得分数/进度 → 用于推进关卡和解锁新模式

## 核心机制

- **自动射击前进**：角色自动向前奔跑并射击，玩家只需控制移动方向和射击目标，简化操作的同时保留动作感
- **敌人波次清除**：每关出现多波敌人，玩家需要在限定时间内全部消灭，时间压力和爽快感并存
- **武器升级与解锁**：通过关卡获得金币，解锁更强力的武器和特殊技能，提升战斗效率

## 为什么好玩

自动射击+手动走位的组合降低了操作门槛，同时保留了足够的技巧空间。清除敌人的爽快感和关卡递进的节奏感让人欲罢不能。

## 粘性来源

关卡递进的挑战感和武器升级的成就感形成双重粘性。"再过一关就能解锁新武器"的心理让人难以放下。

## Meta 系统

武器解锁与升级系统：通过关卡获得金币和星星，解锁新武器并升级现有武器的伤害、射速等属性。对核心玩法的影响：武器升级显著提升战斗效率，让玩家感受到成长感。

## 实现难度

中 — 需要物理引擎支持射击和碰撞检测，自动瞄准和移动逻辑相对简单，最大的技术难点是多关卡设计和性能优化

每款独立小游戏的设计都遵循易于上手、难于精通的原则——入门只需几秒钟理解规则，但要达到高分需要反复练习和熟练掌握操作技巧。
