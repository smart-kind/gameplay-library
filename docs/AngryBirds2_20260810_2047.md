# Angry Birds 2（Angry Birds 2）

- **类型**: 物理弹射 / 解谜破坏
- **平台**: Mobile (iOS+Android)
- **开发商**: Rovio Entertainment
- **首次发布**: 2015
- **一句话描述**: 用弹弓发射各种能力的小鸟，利用物理碰撞摧毁猪的防御建筑

## 玩法规则

画面中，右侧是用各种材料（木头、玻璃、石头、冰块）搭建的建筑，里面有绿色的猪（敌人）。左侧有一个弹弓和待发的小鸟。

玩家点击弹弓上的小鸟，拖拽调整发射角度和力度（屏幕显示预测弹道弧线），松手发射。小鸟沿抛物线飞行，撞击建筑结构。

不同材质有不同的物理特性：木头中等强度、玻璃脆、石头坚硬、冰块易碎。小鸟也有不同种类和能力：
- 红鸟（Red）：无特殊能力，直接撞击
- 蓝鸟（Blue）：点击分裂成三只小鸟
- 黄鸟（Chuck）：点击加速冲刺
- 黑鸟（Bomb）：点击或撞击后爆炸
- 白鸟（Matilda）：点击下抛蛋，自身加速上升

每关给定的小鸟数量有限，用尽所有小鸟后仍有猪存活 = 失败。消灭所有猪 = 过关，根据剩余小鸟数量和建筑破坏率评分（1-3星）。

## 核心循环

观察建筑 → 选择小鸟 → 拖拽弹弓瞄准 → 发射 + 触能力 → 观察物理破坏 → 过关收集羽毛 → 升级小鸟

## 核心机制

- 机制1：物理破坏——建筑结构受真实物理模拟，撞击点、角度、力度都会影响倒塌方式。同一关卡可以有无数种解法
- 机制2：小鸟能力释放——每只小鸟在飞行中可以点击触发特殊能力，时机选择决定效果（过早浪费、过晚打空）
- 机制3：羽毛升级系统——过关获得对应小鸟的羽毛，集齐一定数量提升等级，增强该小鸟的能力

## 为什么好玩

"拉满弹弓—看建筑轰然倒塌—猪飞出去"的破坏快感是核心体验。物理引擎带来的不确定性意味着每次发射都有惊喜——有时候完美一击全灭，有时候差一点功亏一篑。

## 粘性来源

卡片收集（羽毛升级系统提供长线目标）+ 每日挑战 + 竞技场（PvP 分数排名，有限时间内尽可能多杀猪）+ 新关卡持续更新

## Meta 系统

羽毛/卡片收集系统 + 小鸟等级提升（永久属性加成）+ 竞技场赛季排名 + 帽子装扮 + 每日宝箱。

## 实现难度

中。需要物理引擎（Box2D 等成熟方案）+ 弹道计算 + 关卡编辑器。技术上有现成解决方案，难点在于关卡设计——如何让建筑布局既有趣又有唯一或少数最优解。
