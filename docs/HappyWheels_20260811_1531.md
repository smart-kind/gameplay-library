# 快乐轮子（Happy Wheels）

- **类型**: 物理障碍赛 + 恶搞
- **平台**: Web (Flash) → 现通过 Flashpoint/HTML5 存档游玩
- **开发商**: Fancy Force (James Bonacciello)
- **首次发布**: 2010
- **一句话描述**: 控制各种角色骑乘载具穿越障碍赛道，角色会在碰撞中四肢断裂，画面血腥但搞笑

## 玩法规则

游戏采用2D横版侧视视角。玩家选择一个角色（每个角色有独特载具：轮椅大叔、商务摩托车、独轮车小人等），在一条充满障碍的赛道上前进。

操作包括：加速（右键/右箭头）、减速/刹车（左键/左箭头）、前倾/后仰（上/下键）。部分角色还有特殊能力，如轮椅大叔可以发射火箭跳。

赛道上布满了致命陷阱：钉板、电锯、落石、悬崖、爆炸桶等。角色在这些障碍面前非常脆弱，碰到后会断开四肢、头部飞出，但游戏不会结束——玩家需要控制残缺的躯体继续前进，用仅剩的身体部位（比如只有一个头在滚动）到达终点。

到达终点线即为过关。每个关卡有一个目标人数（如"至少2人到达终点"），需要多次尝试解锁不同角色来达成。

游戏内置关卡编辑器，玩家可以创建和分享自己的关卡。社区关卡数量远超官方关卡。

## 核心循环

选择角色 → 操控载具穿越障碍 → 被撞碎 → 用残躯继续 → 到达终点或全灭重来

## 核心机制

- **物理 ragdoll（布娃娃物理）**：角色在碰撞时的肢体断裂基于物理模拟，每次断肢的方式和角度都不同，带来了不可预测的喜剧效果。
- **多角色多载具**：每个角色有完全不同的操控手感。轮椅灵活但脆弱，摩托车速度快但难控制，独轮车平衡要求极高。玩家需要适应不同角色。
- **社区关卡**：关卡编辑器是游戏长寿的核心原因。玩家创作的关卡千奇百怪，从简单障碍到复杂解谜都有。

## 为什么好玩

血腥和搞笑的荒诞结合让失败本身变得有趣——看到角色被电锯切成几段后还在用头往前滚，既恶心又好笑。每个角色的操控手感差异大，适应新角色本身就是乐趣。社区关卡提供了几乎无限的内容。

## 粘性来源

- **失败即娱乐**：即使失败也好看，降低了挫败感
- **角色解锁**：需要完成特定条件解锁新角色，驱动重复游玩
- **社区关卡**：海量玩家自制内容，永远不会玩完
- **"我也能做一个"效应**：关卡编辑器低门槛，激发创作欲

## Meta 系统

- **关卡编辑器**：玩家可以创建关卡并分享给社区
- **关卡收藏/评分**：对社区关卡进行评分和收藏
- **成就解锁**：完成特定条件解锁角色和奖杯

## 实现难度

中。2D物理引擎（如Box2D）可以处理布娃娃物理，但需要大量调校让断肢效果看起来"搞笑"而不是"恶心"。最大的技术难点是关卡编辑器——需要设计一套可视化编辑工具，让玩家能轻松创建关卡并测试。
