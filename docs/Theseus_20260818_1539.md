# 忒修斯（Theseus）

- **类型**: 解谜 / 策略
- **平台**: Mobile (iOS)
- **开发商**: Infinite Monkeys
- **首次发布**: 2009
- **一句话描述**: 利用米诺陶的行动规律引导其入陷阱的回合制益智游戏

## 玩法规则

玩家在俯视视角的迷宫中控制主角忒修斯（Theseus），目标是从起点移动到出口。迷宫中有一只米诺陶（Minotaur）会追击玩家。

操作方式：点击忒修斯移动到的相邻格子。每次玩家移动一步，米诺陶会移动两步。

游戏目标：到达出口而不被米诺陶追上。米诺陶有两个关键弱点：它倾向于水平移动；它无法绕墙壁移动。利用这两条规则，玩家可以精确预测米诺陶的每一步行动。

游戏结束条件：米诺陶追上忒修斯则失败；忒修斯成功到达出口则过关。共有87个迷宫关卡。

## 核心循环

观察迷宫布局 -> 移动忒修斯引诱米诺陶 -> 利用墙壁将米诺陶困住 -> 前往出口

## 核心机制

- 行为预测：米诺陶始终向忒修斯的方向移动，且优先水平方向，这使得其每一步都可以被精确预测。玩家需要在脑中模拟多步之后的局面
- 空间陷阱：利用迷宫的墙壁和拐角，将米诺陶引入死胡同。关键是让米诺陶在墙边卡住——因为墙边没有水平移动空间时它不会后退
- 风险评估：有时需要故意让忒修斯暂时靠近米诺陶，诱使其走入陷阱，然后再冲向出口。这种引蛇出洞的策略考验玩家的胆量和计算能力

## 为什么好玩

表面上是简单的追逐游戏，实质上是高度抽象的逻辑推理挑战。每一步都需要在脑中模拟米诺陶的后续行动，找到那条唯一的安全路径。当精心设计的一步将米诺陶完美困入死角时，成就感极强。

## 粘性来源

87个关卡难度递增，每关都像学习新语言一样需要调整思维模式；差一点就被追到的紧张感和成功困住的顿悟感交替出现，形成强烈的心理驱动。

## Meta 系统

关卡解锁系统，87关逐步解锁。

## 实现难度

中 — 核心逻辑简单但关卡设计复杂度极高。最大技术难点是87个迷宫关卡的关卡设计——每关都需要确保有唯一解且难度递进合理。
