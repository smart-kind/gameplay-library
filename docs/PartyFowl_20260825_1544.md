# Party Fowl 派对闯关（Party Fowl）

- **类型**: 休闲竞技 / 派对游戏
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2022
- **一句话描述**: 一款多人派对闯关游戏，玩家控制小鸡角色通过各种障碍关卡，最后存活的玩家获胜。

## 玩法规则

多名玩家（通常4-8人）同时在一个充满障碍的关卡中竞技。每个玩家控制一只小鸡角色，通过点击、滑动、长按等操作移动、跳跃、躲避障碍。

关卡包含旋转锤、移动平台、陷阱、弹射器等机关。被撞出平台的玩家被淘汰。

支持本地多人和在线多人模式。每局比赛包含多轮关卡，难度递增。每轮淘汰部分玩家，直到最后一轮决出胜者。

## 核心循环

加入比赛 -> 控制角色闯关 -> 躲避障碍淘汰对手 -> 存活到最后 -> 解锁新角色

## 核心机制

- 物理碰撞淘汰: 基于物理的碰撞系统，玩家之间可以互相推挤，增加混乱和乐趣。
- 递增难度关卡: 每轮关卡难度增加，淘汰更多玩家，最后决出胜者。
- 角色自定义: 解锁不同外观的小鸡角色，增加收集元素。

## 为什么好玩

混乱的多人闯关场景充满欢笑。看着朋友一个个掉下平台是最大乐趣。

物理碰撞的不可预测性让每局都不同。角色的可爱外观和滑稽的动作设计也增加了娱乐性。

## 粘性来源

差一点就赢了的不甘心感让人想再来一局。角色收集提供长期目标。

多人在线匹配保证了新鲜的对战体验。赛季通行证和限时活动提供了额外的游玩动力。

## Meta 系统

角色解锁：通过比赛获得金币解锁新外观。

赛季通行证：完成赛季任务获得限定奖励。

排行榜：记录最佳成绩。

## 实现难度

中 - 多人物理碰撞同步是主要技术难点。关卡设计需要平衡趣味性和公平性。
