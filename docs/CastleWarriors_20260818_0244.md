# Castle Warriors（Castle Warriors HD）

- **类型**: 塔防/策略
- **平台**: Mobile (iOS)
- **开发商**: SayGames LTD
- **首次发布**: 2010
- **一句话描述**: 一款塔防游戏，玩家选择不同战士保卫城堡抵御敌人进攻

## 玩法规则

游戏采用竖屏布局，主画面展示城堡防御战场。玩家在战场上部署不同类型的战士单位。

**操作方式**：
- 点击屏幕下方的单位栏选择战士类型
- 拖拽选中的战士到战场指定位置部署
- 点击已部署的战士查看状态并升级
- 点击屏幕顶部的下一波按钮开始敌人进攻

**核心玩法**：
- 选择不同类型的战士单位部署在防御位置
- 每种战士有不同攻击方式和防御能力
- 敌人沿固定路径进攻城堡
- 击败敌人获得金币
- 用金币购买更多战士或升级现有单位
- 随着波次推进，敌人数量和强度递增

**胜利/结束条件**：
- 胜利：成功抵御所有波次的敌人进攻，保护城堡
- 失败：城堡被敌人攻破

## 核心循环

部署战士 → 击退敌人波次 → 获得金币 → 升级战士 → 应对更强敌人

## 核心机制

- **塔防部署**：在战场指定位置部署不同类型的战士
- **兵种搭配**：近战、远程、法术等不同兵种配合
- **波次系统**：敌人按波次进攻，每波递增难度
- **升级系统**：单个战士可升级提升属性
- **金币经济**：击败敌人获得金币用于购买和升级

## 为什么好玩

塔防是移动端最受欢迎的游戏类型之一。Castle Warriors 通过战士类型的多样化和波次递增的难度曲线，为玩家提供了经典的塔防体验。选择不同战士组合的策略深度让游戏有重复游玩的价值。

## 粘性来源

- **波次挑战**：每波敌人递增难度带来的挑战感
- **策略深度**：不同兵种搭配的策略思考
- **数值成长**：战士升级带来的即时满足感
- **关卡推进**：完成当前关卡解锁新内容

## Meta 系统

- **关卡解锁**：完成当前关卡解锁后续关卡
- **战士升级**：提升战士的属性和能力

## 实现难度

低 — 塔防核心框架成熟，主要技术难点在于兵种平衡设计和波次难度曲线。
