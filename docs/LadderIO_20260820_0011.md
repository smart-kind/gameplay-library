# 梯子赛跑（Ladder.io）

- **类型**: io 跑酷 / 休闲竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: EpiCoro d.o.o.
- **首次发布**: 2020
- **一句话描述**: 在赛道上放置梯子跨越障碍，到达终点后利用喷气背包飞跃，以最终飞跃距离决定排名的休闲竞技游戏。

## 玩法规则

游戏开始后，玩家角色在一条笔直的赛道上自动向前奔跑。赛道上散布着金币和梯子碎片。玩家通过左右滑动控制角色移动，收集赛道上的梯子碎片。

赛道中会出现各种高度的缺口（沟壑）。玩家需要将收集到的梯子碎片组合成完整梯子，放置在地面上跨越缺口。梯子越高，能跨越的缺口越大，但消耗的碎片也越多。

当所有玩家到达赛道终点时，会根据各自剩余的梯子数量转换为喷气背包燃料。燃料越多，喷气背包飞得越远。最终飞跃距离决定比赛排名。

## 核心循环

收集梯子碎片 → 跨越赛道障碍 → 到达终点 → 喷气背包飞跃 → 按距离排名

## 核心机制

- **梯子资源管理**：碎片既要用于跨越障碍（消耗），又要留着换取喷气背包燃料（投资），需要在过程中做取舍
- **滑翔升级**：用金币升级滑翔速度和山谷深度，提升最终飞跃距离的倍率，提供长期成长目标
- **实时竞速**：多名玩家同时在一条赛道上奔跑，可以直观看到谁领先谁落后

## 为什么好玩

前半段的跑酷收集紧张刺激，后半段的喷气背包飞跃带来释放感。整个过程节奏明快，一局只需1-2分钟。梯子放置的时机选择增加了策略深度——是用掉碎片保命过关，还是省下来换更远的飞跃？

## 粘性来源

- **短平快节奏**：1-2分钟一局，随时能玩
- **排名竞争**：直观的最终飞跃距离排名激发竞争欲
- **升级系统**：滑翔速度和山谷深度的持续升级提供成长感
- **随机赛道**：每次赛道布局略有不同

## Meta 系统

- **金币收集**：赛道中收集金币
- **升级系统**：用金币升级滑翔速度和山谷深度属性
- **外观解锁**：解锁不同的角色外观和梯子皮肤

## 实现难度

低。核心是 3D 跑酷+简单的物理飞跃计算。最大技术难点是多人实时位置同步和碰撞检测。
