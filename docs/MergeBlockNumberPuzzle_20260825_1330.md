# Merge Block - Number Puzzle

- **类型**: 合并解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Puzzle1Studio,inc.
- **首次发布**: 2019
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 合并类游戏：棋盘占据屏幕中央，显示数字方块/气泡/骰子等元素。顶部显示当前关卡目标和进度条。底部或侧边显示可用手牌/待放置元素。
- 派对游戏类：主菜单显示多个可选择的迷你游戏图标。进入具体游戏后，屏幕中央显示游戏操作区域，顶部显示计时器或回合信息，底部显示玩家操作按钮。

玩家的操作方式包括：
- 拖拽：将方块/骰子/手牌从待放置区域拖入棋盘指定位置
- 点击：选择合并对象、放置元素、回答问题等
- 滑动：在某些迷你游戏中进行方向控制

每个操作产生对应的游戏效果：
- 合并操作触发数字升级和连锁反应
- 放置操作改变棋盘布局并可能触发新的合并
- 派对游戏中的操作直接影响得分和排名

游戏的目标是在有限的步数/时间/空间内达到目标分数或完成指定任务。合并类游戏的目标是通过不断合并获得更高的数字或清除棋盘；派对游戏的目标是在每款小游戏中获得最高分。

## 核心循环

拖拽数字方块到棋盘 -> 相同数字接触合并升级 -> 获得更高分和空间

## 核心机制

- **数字方块合并**: 玩家将数字方块拖入有限的棋盘空间。当两个相同数字的方块接触时，它们合并为更高一级的数字。例如两个3合并成4，两个4合并成5。方块越大占用的格子越多，需要谨慎管理空间。
- **空间管理挑战**: 棋盘空间有限，大方块会占用更多格子。玩家需要不断合并来腾出空间，同时避免棋盘被填满。这种空间压力创造了持续的紧张感，类似于经典俄罗斯方块但节奏更慢。
- **星级目标系统**: 每关设有星级评价体系，要求玩家在限定步数或时间内达到特定分数。星级目标提供了额外的挑战维度，鼓励重复游玩以获得完美评价。

## 为什么好玩

合并操作简单但空间管理充满策略性。数字递增的逻辑让人欲罢不能，每合并一次都有明确的正反馈。

## 粘性来源

粘性来自空间管理的策略深度和数字递增的成就感。每次'差一点就能合成更大数字'的遗憾感驱动继续尝试。星级评价系统提供了重玩价值。

## Meta 系统

- 关卡解锁系统：完成当前关卡解锁后续关卡
- 道具辅助：提供炸弹、重排等一次性辅助道具
- 对核心玩法的影响：道具增加容错率但不改变核心合并逻辑

## 实现难度

低 -> 核心逻辑是数字合并或简单的派对问答/小游戏集合，技术实现难度不大。最大难点在于：对于合并类游戏，需要处理好棋盘状态管理和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性和同步。
