# League of Heroes

- **类型**: 卡牌 RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: Riot Games
- **首次发布**: 2021
- **一句话描述**: 一款英雄收集卡牌对战游戏

## 玩法规则

玩家收集各种英雄卡牌，组建最强阵容进行回合制战斗。通过抽卡获得新英雄，每种英雄有独特的技能和定位（坦克、输出、治疗）。

战斗中，英雄按照速度顺序行动。玩家可以选择释放技能、普通攻击或使用物品。界面分为战斗区域和手牌/技能区。

画面采用欧美卡通风格，英雄设计各具特色。战斗有华丽的技能动画效果。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

抽卡收集英雄 → 组建阵容战斗 → 获取更多资源抽卡

## 核心机制

- 抽卡系统：消耗钻石或金币抽取英雄卡牌
- 回合制战斗：英雄按速度顺序行动，策略体现在技能释放时机
- 英雄养成：升级、升星、装备提升英雄战力

## 为什么好玩

丰富的英雄种类和策略搭配，满足不同玩家喜好。

## 粘性来源

抽卡的随机性快感和全英雄收集的长期目标。

## Meta 系统

- 英雄养成：升级/升星/装备三位一体
- 公会战：加入公会参与团队对战

## 实现难度

中等 — 卡牌战斗和养成系统设计成熟，最大的技术难点是英雄平衡性和经济系统设计。
