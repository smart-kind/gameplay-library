# Canabalt

- **类型**: 横版跑酷 / 无尽奔跑
- **平台**: Mobile (iOS + Android) / Web / PC
- **开发商**: Semi Secret Software (Adam Saltsman)
- **首次发布**: 2009
- **一句话描述**: 无尽跑酷游戏的开山之作，玩家在城市屋顶上不断奔跑逃离未知灾难

## 玩法规则

Canabalt采用极简的单按钮操作。玩家控制一个穿着深色衣服的剪影角色，在城市的天际线上从左向右奔跑。画面是侧视视角，建筑物以像素化的黑色轮廓呈现，背景显示灾难场景（爆炸、崩塌的建筑）。

玩家唯一的操作是按一个按钮让角色跳跃。角色会自动奔跑，遇到屋顶间的空隙时需要跳跃才能跨过。跳跃的时机至关重要——按得太早会落在屋顶边缘，按得太晚会掉入深渊。角色跳跃的高度和距离是固定的，玩家只能通过控制起跳时机来调整落点。

游戏过程中会不断出现新的障碍：屋顶间的空隙越来越高、越来越宽；角色需要跳过空调外机、天线、通风管道等障碍物。部分场景需要连续跳跃（从一个窄屋顶跳到另一个）。速度也会逐渐加快，留给玩家的反应时间越来越短。

游戏结束条件：角色未能成功跳跃，掉入建筑物之间的深渊，游戏结束并显示得分（以米为单位，记录奔跑的距离）。

## 核心循环

自动奔跑 → 判断时机跳跃 → 跨过障碍 → 速度加快 → 坚持更远距离

## 核心机制

- **单按钮操作**: 整个游戏只有一个操作——跳跃。极简设计降低了门槛，但精确的时机要求创造了深度
- **程序化关卡生成**: 建筑物和障碍物的布局是随机生成的，每次游戏的体验都不同
- **速度递增**: 奔跑速度随时间逐渐加快，玩家面临的反应窗口越来越小
- **像素剪影美学**: 黑白剪影风格的角色和建筑，配合灾难性的背景氛围
- **距离计分**: 以米为单位的距离记录，简洁直观的分数系统

## 为什么好玩

Canabalt的乐趣在于纯粹的反应挑战——没有复杂的操作、没有装备系统、没有成长曲线，只有一个按钮和你的反应速度。每一次失败都能立刻重来，没有加载时间，这种即时反馈让人停不下来。游戏速度越来越快时的紧张感，加上在生死边缘完美跳跃的刺激，创造了极强的沉浸感。

## 粘性来源

粘性来自极简规则下的纯粹挑战——"差一米就能破纪录"的不甘心。单按钮操作意味着失败完全是你自己的责任，不会归咎于操作复杂。距离计分的简洁性让目标清晰明了：跑得更远。

## Meta 系统

无外围成长系统。游戏纯粹依赖技能提升——玩家的反应速度和模式识别能力随游戏时长自然增长。

## 实现难度

低 — 规则极其简单，最大的技术难点在于程序化关卡生成的合理性（确保空隙宽度在可跳跃范围内）和流畅的角色动画。
