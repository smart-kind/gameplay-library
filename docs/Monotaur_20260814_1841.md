# Monotaur（Monotaur）

- **类型**: 动作冒险 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立开发
- **首次发布**: 2014
- **一句话描述**: 以希腊神话半人马为灵感的单人视角冒险解谜游戏

## 玩法规则

游戏采用2D横版视角，玩家控制半人马角色在充满机关和敌人的迷宫中探索。画面风格偏暗色调，带有希腊神话氛围。

左半屏幕虚拟摇杆控制移动方向，右半屏幕按钮用于攻击和互动。半人马可以冲撞（快速前冲攻击）、踢击（近战攻击）和使用特殊能力。冲撞是主要攻击手段，需要预判距离和方向。

关卡中布满各类机关：移动平台（需要在恰当时机跳跃）、陷阱（尖刺、火焰，触碰扣血）、隐藏通道（被可破坏墙壁遮挡）和激活机关（需要推动石块或踩踏压力板）。

敌人类型包括小型怪物（一次攻击即可消灭）、弓箭手（远程攻击，需要利用掩体接近）和Boss。Boss战通常需要利用环境机关来击败——例如引诱Boss踩碎脆弱地板、推动石柱砸中Boss等。

通关条件为到达关卡终点并击败守门Boss。关卡中散布着金币和符文，金币用于购买消耗品，符文用于解锁新能力。

## 核心循环

探索迷宫 → 战斗/解谜 → 收集符文 → 解锁新能力 → 深入下一层

## 核心机制

- **环境解谜战斗**：Boss战不依赖单纯的数值对抗，而是要求玩家利用关卡中的环境元素。例如将Boss引到特定位置触发机关、利用冲撞推倒石柱、踩碎地板让Boss掉落等。这种设计让战斗更有趣味性和智力挑战。
- **能力解锁进度（Metroidvania）**：通过收集符文解锁新的移动和攻击能力（如二段跳、蓄力冲撞、破坏特定材质墙壁）。新能力同时解锁之前无法到达的区域，鼓励玩家返回探索。
- **冲撞物理系统**：半人马的冲撞具有物理惯性，可以撞碎特定材质的墙壁和推倒柱子。冲撞的方向和力度需要玩家精确控制，过度冲撞可能导致撞入陷阱。

## 为什么好玩

将动作战斗和解谜巧妙结合。利用环境击败Boss的设计很有成就感，需要观察和思考。半人马角色的设定本身就很有趣，冲撞的爽快感十足。

## 粘性来源

能力解锁（Metroidvania式探索动力——"我之前去不了的地方现在能去了"）+ Boss挑战（利用环境智取的成就感）。每层迷宫的新能力解锁推动玩家继续前进。

## Meta 系统

符文收集系统：散布在关卡中的符文用于解锁新能力。每个符文对应一个具体的能力提升，解锁后永久生效。能力解锁遵循固定的顺序，确保难度递增。

## 实现难度

中 — 需要精细的碰撞检测和物理系统。最大技术难点是平衡冲撞物理的可控性和爽快感，确保玩家感觉操作精准而非随机。
