# Disney Dreamlight Valley（Disney Dreamlight Valley）

- **类型**: 模拟经营 / 生活模拟
- **平台**: Mobile (iOS+Android) / PC / Switch / PS / Xbox
- **开发商**: Gameloft
- **首次发布**: 2022
- **早期体验**: 2022
- **一句话描述**: 迪士尼IP驱动的种田模拟游戏，玩家在一个被"遗忘"笼罩的奇幻山谷中重建家园、结识迪士尼角色、完成任务和装饰空间。

## 玩法规则

游戏开场时山谷被黑暗"遗忘"笼罩，迪士尼经典角色被困其中失去记忆。玩家扮演"守护者"来到山谷，通过完成任务、种植、钓鱼、挖矿、烹饪等活动逐渐恢复山谷的生机。

画面为第三人称3D视角，玩家可以在山谷的各个区域（广场、Peaceful Meadow、海滩、森林等）自由移动。每个区域有独特的资源和NPC。屏幕左下角显示快捷栏（工具、物品），右上角显示任务指引。

玩家核心操作包括：用锄头开垦土地种植并浇水收获作物，用钓鱼竿在池塘边钓鱼（有小型QTE小游戏），用镐子在矿点挖矿获取矿石和宝石，收集食材后在烹饪锅组合食谱制作料理。

每个迪士尼角色有自己的好感度系统，通过赠送他们喜欢的物品、完成他们的"友谊任务"来提升好感。好感度提升后解锁新的任务和故事线。

## 核心循环

收集资源（种植/钓鱼/挖矿/采集）→ 完成任务和赠送礼物提升角色好感 → 解锁新区域和新食谱 → 装饰家园和推进故事

## 核心机制

- **角色好感度系统**：每个迪士尼角色有10级好感度，通过对话、送礼和完成任务提升。不同好感度等级解锁不同的奖励（表情、服装、家具配方）。
- **时间管理**：作物生长需要现实时间，钓鱼和挖矿是即时操作。玩家需要规划时间——哪些作物今天种、哪些任务优先做。
- **区域解锁**：初始只开放广场和草地，用"梦境之光"（游戏内货币）消耗解锁新区域，每个区域引入新的资源、NPC和任务。

## 为什么好玩

迪士尼IP的强大号召力加上轻松的种田玩法，让玩家在"和米奇一起种菜"、"帮艾莎完成任务"这样的情境中获得情感满足。没有战斗压力，只有温馨的日常节奏。

## 粘性来源

- **每日任务**：每天都有新的梦境任务和角色请求，保持日常登录动力
- **收集欲望**：数百种家具、服装和装饰品等待收集，装饰自己的小屋是长期目标
- **角色羁绊**：想解锁每个迪士尼角色的完整故事线，好感度系统驱动持续游玩
- **限时活动**：季节性活动推出限定物品和任务，制造紧迫感

## Meta 系统

- **星币系统**：通过完成任务和出售物品获得星币，用于解锁区域和购买物品
- **梦境之光**：高级货币，通过完成主要任务和活动获得，用于解锁大型内容
- **对核心玩法的影响**：货币获取是推进游戏的主要动力，但不会造成付费压力，所有内容都可以通过游玩获得

## 实现难度

中 + 模拟经营的核心机制（种植、钓鱼、任务系统）技术上不复杂，但最大难点在于内容量——需要设计大量任务、对话、物品和角色互动。Disney IP的整合也需要授权和内容审核。
