# Helix Jump（Helix Jump）

- **类型**: 休闲 / 物理弹射 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2018
- **一句话描述**: 控制弹球通过旋转螺旋塔，打破平台落向底部

## 玩法规则

画面中心是一个垂直的圆柱形螺旋塔，塔的每一层都有一圈带缺口的平台。一个弹球在塔的外侧持续上下弹跳。玩家不能直接控制弹球，而是通过左右滑动屏幕来旋转整个螺旋塔。

目标是通过旋转塔，让塔的缺口转到弹球所在的位置，使弹球能够穿过缺口落到下一层。每一层可能有多个缺口，有些缺口较大容易通过，有些缺口较小需要精确对齐。

某些层是"危险区域"（通常用红色标记），弹球碰到这些区域会失去一颗生命。生命耗尽后游戏结束。有些层有额外的障碍物，如移动挡板、旋转障碍等。

每穿过一层得 1 分。越到底部得分越高，最终目标是让弹球到达最底层。

## 核心循环

旋转塔对齐缺口 → 弹球穿过落下 → 进入下一层 → 重复

## 核心机制

- **间接控制**: 玩家不直接控制球，而是控制环境（塔）。这种间接控制创造出独特的解谜感——需要预判球的弹跳轨迹和时机。
- **物理弹跳**: 弹球在塔的侧壁上来回弹跳，弹跳频率和幅度相对固定，玩家需要观察弹跳节奏来选择旋转时机。
- **旋转惯性**: 塔有轻微的旋转惯性，松开手指后不会立即停止，这增加了精确对齐的难度和深度。
- **危险区域惩罚**: 碰到红色区域扣生命，增加了"差一点"的紧张感——缺口旁边可能就是陷阱。

## 为什么好玩

操作简单（只需左右滑动），但掌握节奏需要技巧。看着弹球穿过一连串缺口的过程有种连锁反应般的满足感。

## 粘性来源

- **连锁快感**: 当连续穿过多个缺口时产生的连锁满足感
- **节奏掌握**: 找到弹跳节奏后有种心流般的体验
- **极简反馈**: 每穿过一层都有视觉和音效的正反馈
- **低门槛高上限**: 任何人都能玩，但精通需要精确的时机判断

## Meta 系统

无核心Meta系统。部分版本有主题皮肤（不同塔的外观和球的外观），但不影响玩法。

## 实现难度

低。核心是3D圆柱旋转 + 物理弹跳模拟 + 碰撞检测。最大难点在于调整物理参数——弹跳力度、旋转灵敏度、缺口大小——使游戏既公平又有趣。
