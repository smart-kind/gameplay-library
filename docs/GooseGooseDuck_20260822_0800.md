# Goose Goose Duck（Goose Goose Duck）

- **类型**: 社交推理 / 多人派对
- **平台**: Mobile (iOS+Android) / PC (Steam)
- **开发商**: Gaggle Studios, Inc.
- **首次发布**: 2021
- **一句话描述**: 一款社交推理游戏，鹅完成任务，鸭子暗中搞破坏并试图消灭鹅

## 玩法规则

游戏支持多人在线游玩，玩家被随机分配为两种角色：鹅（好人阵营）或鸭（坏人阵营）。游戏开始时，所有玩家出现在同一张地图中，地图上分布着各种可交互的任务点。

**鹅的任务**：在限定时间内完成地图上标记的各种小任务，如修理设备、种植作物、收集物品等。每个任务都是一个简单的迷你操作——点击交互点，完成进度条填充、顺序点击、滑动匹配或时序判定。鹅需要一边做任务，一边观察其他玩家的行为，找出可疑的鸭子。

**鸭的任务**：暗中破坏设施（关闭灯光、切断通讯、制造紧急情况），趁机消灭鹅。鸭子使用击杀技能时需要在鹅背后近距离触发，击杀后有冷却时间。鸭子也可以伪装成在做任务，或故意出现在错误的位置误导他人。

**会议机制**：当玩家发现尸体时可以按下报告键召集所有人投票；紧急情况下任何一方都可拉响警报。会议期间所有玩家通过语音聊天讨论，投票选出嫌疑人。得票最多的玩家被驱逐出飞船。

**游戏结束条件**：鹅方胜利——所有任务完成或所有鸭子被驱逐/投票出局；鸭方胜利——鸭子数量≥鹅数量，或超时未完成任务。

## 核心循环

完成任务/搞破坏 → 收集信息/制造混乱 → 会议讨论投票 → 淘汰玩家 → 继续游戏

## 核心机制

- **角色分配与隐藏身份**：每局随机分配鹅或鸭身份，只有鸭子知道自己人的身份。这种信息不对称创造了持续的紧张感和猜疑链，是社交推理的核心驱动力。
- **空间任务系统**：地图上的任务点分布迫使玩家移动到不同区域，增加了遭遇和观察的机会。任务设计简单但不无脑，需要玩家分配注意力在"做任务"和"看人"之间。
- **语音 proximity chat**：近距离语音聊天让交流更加真实。你能听到附近玩家的对话，远处则听不到，这创造了丰富的信息层次和社交动态。
- **击杀与冷却机制**：鸭子的击杀需要近距离且在鹅的背后，加上冷却限制，迫使鸭子谨慎选择时机而非无脑杀人。

## 为什么好玩

鹅的体验像是在玩解谜+推理的混合体——既要关注自己的任务进度，又要留意每个人的行为模式。鸭的体验则是一种"狼人杀"的实时升级版，紧张刺激。语音聊天带来的社交互动让每局体验都独一无二。

## 粘性来源

- **社交竞争**：每局不同的玩家组合产生完全不同的互动故事，朋友间的"互相怀疑"本身就是乐趣。
- **随机性**：角色分配、地图事件、玩家行为全部不可预测，重玩价值极高。
- **"差一点就成功"的不甘心**：鹅方只剩一个任务时被发现、鸭方最后时刻差一点就能赢，这种紧张感让人想再来一局。

## Meta 系统

无核心Meta系统。游戏提供不同地图、角色皮肤等收集要素，但不影响核心玩法平衡。

## 实现难度

中 — 多人联机同步和网络延迟处理是主要技术难点。Proximity语音需要基于玩家坐标实时计算音量衰减。任务系统相对简单，但不同地图的任务设计需要大量内容工作。
