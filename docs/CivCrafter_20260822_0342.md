# CivCrafter

- **类型**: 放置模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: Naquatic LLC
- **首次发布**: 2015
- **一句话描述**: 用一句话说清楚这个游戏是什么

## 玩法规则

游戏界面展示玩家当前拥有的设施/领地的总览视图，各区域标注当前的产出速率和资源存量。顶部显示总资源量和关键指标，底部为操作菜单。

玩家通过点击设施进行升级、扩建或部署。不同设施有不同的功能和产出类型，需要合理搭配以形成有效的生产链。例如：基础资源设施 → 加工设施 → 高级产出设施。

随着游戏推进，会解锁新的设施类型和功能模块。玩家需要决定将有限的资源优先投入到哪个方向——是提升现有设施效率，还是解锁新设施拓展产出维度。

游戏目标是建立尽可能庞大高效的产出体系，解锁所有可用内容，并在排行榜上取得好成绩。

## 核心循环

布置设施 → 产生资源 → 升级扩展 → 解锁新区域 → 建立更大体系

## 核心机制

- 设施建设与升级：核心操作，投入资源提升设施等级以增加产出
- 生产链：不同设施之间形成依赖关系，上游设施产出作为下游设施的原料
- 自动化：达到一定阶段后，生产过程完全自动化，玩家只需要定期上线收取和升级
- 解锁里程碑：达到特定条件时解锁新区域、新设施类型或新功能

## 为什么好玩

从无到有建立自己的世界或帝国，看着一切运转带来极大的满足感

## 粘性来源

离线收益+持续成长曲线，每次回归都有新内容解锁；长期目标链让玩家不断追求下一个里程碑

## Meta 系统

深度升级树与天赋系统。除了基础设施升级，还有全局加成天赋、特殊事件加成、赛季排行榜等外围系统。prestige机制允许玩家在达到一定进度后重置并获取永久加成。

## 实现难度

低 — 放置类核心逻辑清晰，最大难点是数值体系设计和多层级解锁节奏
