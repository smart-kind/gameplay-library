# 怪物吃了我的公寓（Monsters Ate My Condo）

- **类型**: 消除/策略
- **平台**: iOS / Android / Mobile
- **开发商**: PikPok（原 Sidhe Interactive）
- **首次发布**: 2011
- **一句话描述**: 巨型怪物从底部攻击玩家的公寓楼，玩家通过三消匹配楼层来消除怪物威胁，保护建筑。

## 玩法规则

画面展示一栋多层公寓楼，每层由不同颜色/类型的方块组成。屏幕底部不断有巨型怪物出现，它们会从底部开始一层层啃食公寓楼——每过几秒就"吃掉"最底层的一层楼，楼整体下移。

玩家的操作是交换相邻的两个楼层方块，当三个或更多相同颜色的方块连成一线时，这些方块被消除，该楼层消失，上面的楼层自动下落。消除楼层的同时也对底部的怪物造成伤害——消除的楼层越多，对怪物的伤害越大。

如果怪物吃光了所有楼层，游戏结束。玩家需要在怪物到达顶部之前，通过不断消除来消灭一波波怪物。

操作：点击一个楼层方块，再点击相邻方块进行交换。匹配3个或更多同色方块即可消除。

## 核心循环

匹配消除楼层 → 对怪物造成伤害 → 怪物被消灭 → 新怪物出现 → 继续消除

## 核心机制

- **下沉压力**：怪物不断从底部吞噬楼层，整栋楼持续下移。这种"倒计时"不是数字，而是可见的楼层减少——视觉压力极强。
- **三消匹配**：经典的三消核心玩法，但与传统三消不同——消除的不是方块，而是整层楼。消除楼层直接影响怪物的生命值。
- **连击系统**：消除产生的"掉落"可能引发连锁反应，形成连击。连击造成额外伤害，鼓励玩家规划消除策略。
- **怪物多样性**：不同怪物有不同的血量、速度和特殊能力（有些吃得更快，有些会跳过某些楼层）。

## 为什么好玩

将传统三消的"悠闲"变成了"生死存亡"的紧张感。看着怪物一口口吃掉你的楼层，而你拼命在上面匹配消除来反击——这种"被追"的紧迫感让三消有了全新的体验维度。

## 粘性来源

- **视觉威胁**：怪物啃食楼层的画面比任何倒计时都更有压迫感
- **连击快感**：连锁消除带来的屏幕震动和特效反馈强烈
- **怪物收集**：解锁不同外观的怪物（虽然是敌人，但收集欲仍在）
- **短局节奏**：每局2-3分钟，适合碎片时间

## Meta 系统

- **怪物图鉴**：记录遇到过的所有怪物类型
- **高分榜**：全球排名，驱动追求更高分
- **对核心玩法的影响**：无实质影响，主要是收集和高榜展示

## 实现难度

低 — 三消逻辑成熟且开源方案多，楼层下沉和怪物AI逻辑简单。最大技术难点在于动画流畅度——楼层消除、下落、怪物啃食的动画需要无缝衔接，否则体验会显得粗糙。
