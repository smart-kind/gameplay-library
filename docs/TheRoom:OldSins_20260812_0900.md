# The Room: Old Sins

- **类型**: 密室逃脱 / 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Fireproof Games
- **首次发布**: 2018
- **一句话描述**: Fireproof Games 标志性的密室逃脱系列第四作，在一个神秘娃娃屋中揭开隐藏的机制和秘密。

## 玩法规则

玩家在一个精致的娃娃屋（实际上是缩小的房间模型）中探索，通过点击、拖动、旋转和滑动来操作各种机关。每个房间都有多个隐藏的隔层、暗门和机械装置等待发现。

游戏的核心是物理交互——玩家可以打开抽屉、转动钥匙、按下按钮、滑动面板，所有这些操作都有精致的触觉反馈和动画。谜题的解决方案通常需要多步骤操作：找到一个线索，用它解锁另一个区域，再用新发现的工具解决下一个谜题。

叙事通过收集的文件、照片和环境细节碎片化展开，讲述了一个关于失踪工程师和他诡异发明的故事。

## 核心循环

探索房间 → 发现和操作机关 → 解谜逐步深入 → 揭开故事真相

## 核心机制

- 物理交互谜题：点击、拖动、旋转、滑动操作真实机械装置
- 多层次空间：每个房间有隐藏隔层、暗门和秘密通道
- 碎片化叙事：通过文件、照片和环境细节拼凑故事
- 触觉反馈：精致的动画和振动反馈增强沉浸感
- 眼镜道具：特殊视角揭示隐藏线索

## 为什么好玩

解谜游戏的触觉设计巅峰。每一个机关的操作都感觉真实可信，发现隐藏隔层的瞬间充满惊喜。黑暗、神秘的氛围让人沉浸其中。

## 粘性来源

- 触觉满足感：每一个机关的操作都有精致的反馈
- 发现的惊喜：隐藏隔层和暗门让人欲罢不能
- 氛围营造：黑暗、神秘的维多利亚哥特风格
- 碎片化叙事：通过环境讲故事，让玩家主动探索

## Meta 系统

无。游戏是纯粹的线性解谜体验。

## 实现难度

高。精致的 3D 模型、物理交互系统和多步骤谜题设计需要大量美术和设计投入。
