# 幽灵赛车手（Ghost Racer）

- **类型**: 竞速 / 战斗赛车
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发者
- **首次发布**: 2012
- **一句话描述**: 在充满陷阱和武器的赛道上与其他赛车手竞速并互相攻击的 combat racing 游戏

## 玩法规则

游戏画面呈现3D赛道俯视角或跟随视角，玩家控制一辆赛车在封闭赛道上竞速。赛道上有各种障碍物、道具箱和危险区域。多名AI赛车手同时竞速，玩家需要超越对手并到达终点。

玩家可以在赛道上收集武器道具（导弹、地雷、油渍、加速剂等），用来攻击前方对手或防御后方追击。赛道中有跳跃坡道、急转弯和狭窄路段，需要精准操控才能通过。

操作方式：倾斜设备或虚拟摇杆控制方向、点击加速按钮、点击武器按钮使用收集到的道具、点击刹车减速过弯。不同赛车有不同属性——速度、操控、耐久，影响驾驶手感。

游戏目标是在多圈比赛中取得第一名。如果赛车耐久度归零（被多次攻击或撞墙），需要等待几秒钟才能重新回到赛道，损失大量时间。

## 核心循环

起步加速 → 收集道具 → 攻击对手/躲避攻击 → 过弯超越 → 冲线获胜 → 解锁新赛道

## 核心机制

- **道具系统**：赛道上的道具箱随机给予不同武器，位置靠后的玩家更容易获得强力道具（追赶机制），保证落后者也有翻盘机会
- **战斗赛车机制**：不只是比速度，还可以用武器干扰对手，策略性地选择攻击目标（领先者还是紧追者）
- **赛道设计**：包含直线加速段、急弯段、跳跃段和危险区域，不同赛车属性在不同赛道段有优劣
- **名次动态平衡**：落后玩家获得更好道具的机制防止比赛过早失去悬念

## 为什么好玩

竞速与战斗的结合——不仅要开得快，还要打得准。用导弹击中前方领先者的瞬间快感和被后方偷袭的不甘心形成强烈的体验循环。

## 粘性来源

"差一名就夺冠"的竞争欲、不同赛道和赛车的收集解锁、道具使用的随机性保证每局都有新变数。战斗赛车的混乱场面本身就充满乐趣。

## Meta 系统

赛车解锁系统：完成比赛获得金币，用于购买新车和升级现有车辆属性（速度、操控、耐久）。新赛道通过通关解锁。

## 实现难度

中等。3D赛车物理、AI对手行为、碰撞检测和道具系统需要一定开发量。最大技术难点是AI赛车的智能程度——需要足够有挑战性但又不会让玩家感到被不公平对待。
