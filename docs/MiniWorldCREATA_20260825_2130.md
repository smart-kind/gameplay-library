# Mini World: CREATA

- **类型**: 沙盒/创造
- **平台**: Mobile (iOS+Android)
- **开发商**: Miniwan Tech
- **首次发布**: 2020
- **一句话描述**: 一款自由度极高的沙盒建造游戏，玩家可以在无限世界中创造任何想象中的结构

## 玩法规则

游戏主界面以广阔的方块世界，各种建材和生物散布其中为核心视觉元素，整体布局简洁直观。屏幕上方/中央区域展示第一人称或第三人称视角的游戏世界，玩家一眼即可了解当前的核心状态。屏幕下方或侧边排列虚拟摇杆、物品栏和建造菜单，这些是玩家可以交互的按钮或操作区域。

玩家通过点击放置方块、滑动旋转视角和菜单选择建材进行核心操作。具体而言，玩家通过虚拟摇杆在世界中自由移动，滑动屏幕旋转视角。打开物品栏选择要放置的方块类型，点击屏幕在目标位置放置。长按可以破坏已有方块并回收材料。世界中有各种生物（友好的和被动的，以及敌对的），它们有自己的行为模式。在创造模式下资源无限，在生存模式下需要采集资源。每次操作后，系统会即时给出方块放置/破坏的音效和动画，生物交互反馈，确保玩家对操作结果有清晰的感知。

游戏的核心目标是自由创造或完成生存目标。为了达成这一目标，玩家需要探索世界收集资源，建造庇护所或创意建筑，与生物互动或战斗，在创造模式和生存模式之间切换。当沙盒游戏没有固定胜利条件，目标是玩家自己定义的时，玩家进入下一阶段或解锁新内容。反之，如果生存模式下生命值归零会重生并失去部分物品，则需要重新开始或调整策略。

随着游戏进程的推进，探索更远的区域发现新的生物群系和稀有材料。玩家需要逐步掌握建造技巧、资源管理和生存策略，才能在更高难度下持续进步。游戏的深度在于无限创造自由度让每个人都能实现自己的想象力。从简单的火柴盒到复杂的机械装置，从微型花园到完整城市，创造的上限只受限于玩家的想象力。生存模式提供目标导向的玩法，创造模式提供纯粹的表达空间，这让简单的操作框架下蕴含着丰富的策略空间。

游戏中的红石系统（或类似的逻辑电路系统）允许玩家创建复杂的自动化装置，从简单的门控系统到完整的计算机，创造了极高的技术深度。

## 核心循环

收集材料 → 建造结构 → 探索更多区域获取稀有材料

## 核心机制

- **自由建造系统**: 玩家可以在广阔世界中放置和移除任何方块，没有固定目标，创造力是唯一限制。方块类型涵盖建材、装饰、功能性方块（如红石电路元件），支持从简单结构到复杂机械的各种创作
- **生物与生态**: 世界中有各种独特的可爱生物，它们有自己的行为模式。被动生物可以被驯服或繁殖，敌对生物需要战斗或躲避。生物群系决定哪些生物和材料出现在特定区域
- **生存模式**: 在创造之外提供生存模式，需要收集资源、对抗怪物、维持生命值的经典生存循环。饥饿值、生命值和装备耐久度等要素增加了挑战性，让建造不仅仅是装饰而是生存必需

## 为什么好玩

无限创造自由度让每个人都能实现自己的想象力。看到别人的作品激发的"我也想做"的冲动，以及完成自己作品后的分享欲望。生存模式的紧张感和创造模式的自由感形成互补。

社区分享功能让玩家可以展示和下载其他玩家的作品，形成创意灵感的正向循环。

## 粘性来源

创造自由度带来的无限可能性和社区分享的正向循环。看到其他玩家的精彩作品后产生"我也可以"的动力，完成作品后分享到社区获得认可的满足感。持续的内容更新和新生物群系也保持新鲜感。

季节性活动和限时材料为创造提供了新的灵感和目标，让老玩家也有回归的理由。

## Meta 系统

材质包与世界模板：解锁新的材质、生物群系和预制建筑模板。对核心玩法的影响是扩展建造素材库，激发新的创意灵感。社区创作的内容库也提供了持续的新鲜内容来源。

玩家可以创建和分享自定义材质包和世界模板，社区生态是游戏长期生命力的重要保障。

## 实现难度

高。方块世界的渲染优化、生物AI和多人同步需要大量技术工作。最大技术难点：大规模世界的性能优化——在移动设备上流畅渲染和交互，同时维持足够大的视野范围和复杂的物理计算。
