# 简易物理（SimplePhysics）

- **类型**: 物理益智 / 建造
- **平台**: Nintendo 3DS
- **开发商**: 独立开发者
- **首次发布**: 2011
- **一句话描述**: 利用简单物理原理建造结构来解决各种工程挑战的益智游戏

## 玩法规则

每个关卡给出一个工程挑战：建造一座桥让车辆通过峡谷、搭建塔楼到达指定高度、设计过山车轨道让小球到达终点、建造起重机吊起重物等。玩家在有限的材料和预算下，在画面上绘制或放置结构组件（梁、缆绳、滑轮、弹簧、铰链等）。

放置完成后启动物理模拟，观察结构是否能承受重量或实现功能。物理引擎模拟重力、拉力、压力、弹性等真实物理效应——梁会弯曲变形，缆绳只能承受拉力不能承受压力，弹簧会压缩和伸长，铰链允许旋转但不能移动位置。如果结构崩塌或无法实现功能，可以调整组件位置、数量或类型后再次尝试。

材料有各自的颜色和物理属性标识：红色梁（刚性材料，抗弯曲能力强但重）、蓝色缆绳（只能承受拉力）、绿色弹簧（可压缩和伸长）、黄色铰链（允许旋转连接）。预算限制要求玩家用最少的材料实现目标。部分关卡还有环境因素：风力影响结构稳定性、水流冲击力、地震晃动等。

## 核心循环

阅读工程挑战 → 用有限材料搭建结构 → 运行物理模拟 → 根据结果调整优化 → 用最少的材料完成目标

## 核心机制

- **材料属性与成本系统**：每种材料有固定成本和物理属性，需要权衡使用。刚性梁最贵但最可靠，缆绳便宜但只能拉不能推，弹簧可以存储和释放弹性势能，铰链可以创造活动关节。材料选择直接影响结构方案
- **物理模拟引擎**：实时计算重力、张力、压缩、弹性、摩擦力等物理效应。结构中的每个连接点和材料都有独立的物理计算，模拟结果真实可预测。失败时的结构崩塌动画直观展示薄弱点
- **迭代优化机制**：模拟失败后可以看到哪些材料断裂或变形最大（用颜色高亮），帮助玩家识别设计弱点。每次迭代都是学习物理规律的过程


## 为什么好玩

将真实物理原理融入游戏，每次成功让结构立住时的成就感极强。失败时结构崩塌的视觉效果也有娱乐性——看着自己搭的桥轰然倒塌既沮丧又好笑。

## 粘性来源

物理规律的一致性让玩家'学到了什么'，每次失败都是学习过程而非随机挫折。寻找最优解（最少材料）的冲动驱动反复尝试。挑战模式的额外约束（限时、限材料）提供变体玩法。

## Meta 系统

无复杂Meta系统。关卡解锁和挑战评级（材料效率评分）作为基础进度。部分版本有玩家自建关卡分享功能。

## 实现难度

中 —— 需要理解基础物理概念（力的分解、力矩、材料强度），最大技术难点是物理引擎的数值稳定性和大量节点连接关系的实时求解性能。
