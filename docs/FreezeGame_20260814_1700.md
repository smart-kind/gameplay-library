# 冰冻（Freeze!）

- **类型**: 物理解谜 / 平台
- **平台**: Mobile (iOS+Android)
- **开发商**: Andreas von Lepel / Colopl
- **首次发布**: 2010
- **一句话描述**: 通过触屏改变重力方向，让小球在迷宫中躲避不断上涨的黑暗吞噬，最终到达出口

## 玩法规则

游戏画面展示了一个封闭的2D迷宫场景，迷宫中包含墙壁、通道和收集品。一个彩色小球在迷宫中受重力影响自由下落。玩家需要通过点击或滑动屏幕来翻转重力方向——从向上变为向下或反之。

核心操作是重力翻转：小球会持续向当前重力方向坠落。玩家需要在小球撞击障碍物之前翻转重力，使其向相反方向运动。迷宫中存在各种机关——风扇可以吹动小球横向移动，弹簧可以弹射小球，传送门可以将小球瞬间转移到另一个位置。

最关键的威胁是不断上涨的黑暗——一种从迷宫底部（或重力反方向）蔓延的黑色物质，会吞噬所经之处的一切。如果小球被黑暗碰到，游戏结束。玩家需要在黑暗追上的时间内找到通往出口的路径，同时收集沿途的星星。

## 核心循环

翻转重力操控小球 → 躲避黑暗吞噬 → 收集星星 → 到达出口 → 解锁新关卡

## 核心机制

- **重力翻转机制**：玩家通过触屏点击翻转重力方向，小球立即向新的重力方向坠落。翻转操作本身简单，但需要在复杂的迷宫结构中预判小球的运动轨迹。
- **黑暗追逐压力**：持续上升的黑暗制造了紧迫感，迫使玩家在压力下快速决策。黑暗速度会随关卡推进而加快。
- **机关互动系统**：迷宫中的风扇、弹簧、传送门等机关可以改变小球的运动方式。掌握机关的使用时机是通关关键。
- **星星收集**：每关散布着若干星星，部分位于难以到达的位置。全收集为已通关关卡提供重玩动力。

## 为什么好玩

重力翻转的操作极度简单（只需点击），但由此产生的物理运动却充满变化和惊喜。在迷宫中连续翻转制造出"弹珠台"般的节奏感——左弹右跳地在通道中穿梭，同时躲避身后追来的黑暗，紧张刺激。

## 粘性来源

黑暗追逐带来的持续压力是核心粘性来源——每次都是"差一点就成功了"的刺激感。关卡从简单的重力翻转逐步演变为需要精密时序的多机关配合，学习曲线平滑。星星收集为速通和高完成度提供目标。

## Meta 系统

无传统Meta成长系统。游戏通过关卡解锁和星星收集提供进度感。

## 实现难度

中。核心需要2D物理引擎（重力系统、碰撞检测）和机关互动逻辑。最大技术难点在于让重力翻转的响应速度达到帧级别——任何延迟都会让玩家感觉操作不跟手，破坏游戏体验。同时黑暗追逐的速度曲线需要精细调校以维持紧张感而非纯粹的挫败。
