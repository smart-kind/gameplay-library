# Drag Racing

- **类型**: 竞速 / 放置升级
- **平台**: Mobile (iOS + Android)
- **开发商**: Creative Mobile Games
- **首次发布**: 2011
- **一句话描述**: 直线加速赛车游戏，通过精确的换挡时机和车辆升级来赢得比赛

## 玩法规则

Drag Racing是一款极简的直线竞速游戏。每场比赛只有两个参与者，在一条直线上比赛谁先到达终点。

操作极其简单：比赛开始时按住油门按钮让车加速，在正确的时机点击换挡按钮（从1挡到2挡到3挡...直到最高挡）。换挡时机决定了加速效率——换得太早会导致转速不足，换得太晚则浪费引擎动力。完美换挡窗口很窄，需要练习才能掌握。

比赛之外的核心玩法是车辆升级和收集。玩家用赢得的奖金购买新的性能部件（引擎、变速箱、轮胎、氮气加速等）来升级车辆。也可以购买全新的车辆——从经济型轿车到超级跑车和改装车。

游戏中还有在线多人模式，玩家匹配其他真实玩家进行直线竞速对决。

## 核心循环

比赛赚取奖金 → 升级车辆 → 挑战更高等级对手 → 解锁新车

## 核心机制

- **换挡时机**: 核心操作——在最佳转速区间换挡，过早或过晚都会损失速度
- **氮气加速(NOS)**: 部分车辆配备氮气系统，在直线中段按下可提供额外爆发加速
- **车辆升级**: 用比赛奖金购买引擎、变速箱、轮胎等部件升级，直接影响加速曲线和最高速度
- **等级匹配**: 车辆有等级系统，升级后进入更高等级组别

## 为什么好玩

Drag Racing的乐趣在于看似简单的操作下隐藏的精确性——每次换挡时机的微妙差别都可能在终点线决定胜负。当你完美掌握了一辆车的换挡节奏，那种行云流水的感觉非常爽。

## 粘性来源

粘性来源是多层次的：短期是“下一次换挡就能赢”的不甘心；中期是升级车辆的数值成长快感；长期是收集全部车辆和达到最高等级的成就感。

## Meta 系统

车辆收集与升级系统是核心Meta：玩家收集数十款真实授权车辆，每辆车有多个可升级部件。等级系统提供阶段性目标。

## 实现难度

低 — 最大的技术难点在于精确的换挡窗口判定和不同车辆的物理参数平衡。
