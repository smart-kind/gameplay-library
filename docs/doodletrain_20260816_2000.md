# 涂鸦列车（Doodle Train）

- **类型**: 益智 / 绘图
- **平台**: Nintendo 3DS
- **开发商**: 独立开发者
- **首次发布**: 2011
- **一句话描述**: 绘制铁轨引导列车安全到达目的地的绘图益智游戏

## 玩法规则

画面中有一列起点处的火车和一个或多个终点车站。玩家用触控笔或手指在屏幕上绘制铁轨线路，火车会沿着画好的轨道自动行驶。画轨时需要考虑物理约束：铁轨不能交叉重叠、转弯半径不能太小（否则火车脱轨）、不能穿过障碍物（墙壁、河流、山脉等）。

部分关卡有多个目的地，需要设计分岔路线让火车经过所有车站。还有桥梁和隧道等特殊轨道类型，用于跨越河流或穿山。桥梁需要消耗额外材料点数，隧道需要选择正确的入口和出口。画完线路后点击'发车'按钮，观察火车是否能安全到达所有目的地。

游戏还提供轨道装饰元素（信号灯、道岔、车站建筑）用于美化路线，但不影响核心玩法。某些关卡有时间限制，要求在规定时间内画完轨道。后期关卡引入多列火车，需要设计不冲突的路线——如果两列火车在同一轨道上相向而行会碰撞，需要通过道岔和信号灯协调。

## 核心循环

观察起点终点和障碍物 → 绘制铁轨线路 → 启动火车测试 → 成功或调整路线

## 核心机制

- **手绘轨道物理系统**：火车沿绘制的曲线行驶，转弯角度受物理限制（最小转弯半径）。手绘线条会自动平滑处理，但玩家仍需注意不要画出过急的弯。轨道的曲率直接影响火车速度——急弯需要减速
- **多目的地与分岔规划**：后期需要同时服务多个车站，考验路线规划能力。道岔允许一条轨道分叉为两条，需要决定哪条路线通向哪个目的地
- **特殊轨道与障碍物交互**：桥梁（跨越河流/峡谷/公路）、隧道（穿山/地下）、道岔（分路选择）增加策略维度。每种特殊轨道有成本和放置限制


## 为什么好玩

手绘铁轨的自由度高，看着自己画的轨道让火车安全运行有很强的成就感——尤其是画出蜿蜒曲折、穿过各种地形的优美路线时。火车行驶的动画和音效也很可爱。

## 粘性来源

'找到更短/更优雅的路线'的追求驱动反复优化。关卡递进式设计持续提供新挑战（更多目的地、更多障碍物、多列车协调）。时间挑战模式提供变体玩法。

## Meta 系统

关卡解锁制。部分版本有火车皮肤和轨道主题（如蒸汽朋克、现代高铁、未来磁悬浮）解锁，提供视觉变化。

## 实现难度

低 —— 手绘操作简单直观，核心挑战在于路径规划和空间想象。最大技术难点是手绘曲线的平滑处理算法和火车沿任意曲线行驶的碰撞检测。
