# Heads Up! Hot Dogs

- **类型**: 休闲/街机
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 未知
- **一句话描述**: 一款以热狗制作为主题的休闲游戏

## 玩法规则

玩家扮演热狗摊主，按照顾客订单制作热狗。点击选择面包、香肠和配料，拖放到正确位置完成制作。

订单有时间限制，需要在顾客耐心耗尽前完成。连续正确完成订单获得连击加分。不同顾客有不同的口味偏好和耐心值。

画面采用卡通风格，热狗和配料造型可爱。界面上方为订单显示区，中间为操作台，下方为材料选择栏。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

制作热狗服务顾客 → 获得金币 → 解锁新配料和装饰

## 核心机制

- 订单系统：顾客下订单，玩家按配方制作
- 时间压力：订单有倒计时，考验手速和记忆力
- 连击奖励：连续正确完成获得额外金币

## 为什么好玩

轻松愉快的制作体验，适合碎片时间。

## 粘性来源

解锁新配料的收集驱动和高分挑战。

## Meta 系统

- 配料解锁系统：通过游戏进度解锁新配料种类
- 摊位装饰：消耗金币装饰热狗摊

## 实现难度

低 — 核心玩法简单直观，最大的技术难点是操作响应速度和 UI 布局。
