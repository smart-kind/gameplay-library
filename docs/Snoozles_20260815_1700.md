# Snoozles

- **类型**: 休闲放置 / 宠物模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer listed
- **首次发布**: 未知
- **一句话描述**: 一款以可爱生物为主题的休闲放置游戏，玩家通过收集和照顾各种Snoozles生物，在轻松的氛围中体验养成乐趣。

## 玩法规则

游戏的核心玩法围绕照顾和收集可爱的生物角色（Snoozles）。玩家在屏幕上看到各种形态各异的生物，它们有不同的习性和外观特征。

玩家的主要操作包括：为生物提供食物和休息场所、抚摸互动、收集生物产出的资源。每种生物有独特的行为和产出，需要玩家根据其特性进行针对性照顾。

游戏界面采用柔和的色调和可爱的角色设计，营造轻松休闲的氛围。操作以点击和拖拽为主，不需要复杂的操作技巧。

生物之间存在羁绊关系，特定组合的生物放在一起会产生额外的互动效果和产出加成。玩家需要考虑生物的放置位置和组合搭配。

游戏采用放置模式，即使玩家不在线，生物也会自行活动和产出资源。再次上线时收集离线收益即可。

## 核心循环

收集生物 → 照顾互动 → 收集产出 → 解锁新生物 → 优化组合搭配

## 核心机制

- 放置产出系统：生物自动产生资源，玩家上线收集即可。这种低压力设计让游戏适合碎片时间游玩。
- 羁绊组合加成：不同生物的组合产生协同效应，鼓励玩家收集更多种类并思考最优搭配。
- 收集图鉴系统：每种生物都有详细的图鉴介绍，满足收集癖玩家的需求。

## 为什么好玩

可爱生物+轻松氛围=零压力的游戏体验。不需要紧张操作，只需要享受收集和养成的过程。

## 粘性来源

收集驱动是核心粘性——'还差几种就能全收集'的冲动让人持续回归。放置产出机制让每次上线都有收获感。

## Meta 系统

生物收集和图鉴完成度是唯一的成长维度。

## 实现难度

低。最大技术难点在于生物AI行为的多样性和随机性实现，确保每种生物都有独特的行为模式。
