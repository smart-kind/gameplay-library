# El Shaddai Vol 1

- **类型**: 动作冒险 / Action Adventure
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2012
- **一句话描述**: 一款在移动平台上发布的动作冒险类型游戏

## 玩法规则

基于同名主机游戏的移动版动作冒险游戏。画面呈现独特的视觉风格，融合日本神话元素。

玩家通过虚拟摇杆控制主角移动，点击攻击按钮发动近战攻击，滑动屏幕释放特殊技能。场景中有敌人、平台跳跃障碍和收集品。

战斗系统有连击机制——连续点击可打出组合技，不同武器类型有不同攻击范围。部分关卡有解谜元素——推动箱子、激活机关、寻找隐藏路径。

游戏目标是完成关卡挑战，击败 Boss，推进故事线。作为章节式发布的第一卷，包含多个关卡和一个最终 Boss。

## 核心循环

战斗/探索 → 击败敌人获取经验 → 升级装备技能 → 挑战更强 Boss

## 核心机制

- **连击战斗**：连续按键触发组合技
- **多武器系统**：不同武器有不同攻击范围和特殊效果
- **章节式推进**：按卷发布，每卷包含多个关卡

## 为什么好玩

独特的视觉风格和动作系统让它在移动游戏中脱颖而出。连击战斗的爽快感和章节式推进的进度感结合得很好。

## 粘性来源

章节式推进的故事驱动+装备升级的数值成长。Boss 战的挑战性和通过后的成就感形成强反馈循环。

## Meta 系统

- **装备/技能升级**：通过战斗获得经验升级角色能力
- **章节解锁**：完成当前卷解锁下一卷内容
- **对核心玩法的影响**：角色能力提升降低后续关卡难度，但也可能降低挑战感

## 实现难度

高——动作游戏需要复杂的动画系统、碰撞框、状态机。最大的技术难点是连击系统的输入缓冲和判定、多敌人 AI 同时运作的性能优化。
