# Merge Away（Merge Away! - Puzzle Adventure）

- **类型**: 合成解谜 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Payge Ltd
- **首次发布**: 2024
- **一句话描述**: 一款极简放松型合成游戏，合并相同物品发现新元素和精美背景。

## 玩法规则

屏幕中央展示一个合成区域，底部有多个可合并的物品图标（如石头、木头、水晶等基础元素）。玩家点击选择两个相同物品即可自动合并为高阶物品。每次合并后新物品出现在合成区域，同时解锁新的合并配方。

游戏的核心界面由三个区域组成：底部托盘（存放待合并物品）、中央合成台（当前活跃物品）、顶部展示区（已合成的最高级物品图鉴）。操作仅为点击和拖拽，无复杂手势。

游戏目标是从基础物品一路合并到终极物品（合成链末端）。游戏不设置步数或时间限制，纯粹以探索发现为导向。完成一条合成链后解锁新的背景主题和合成系列。

游戏结束条件：无失败机制，只有进度完成。当玩家合并出当前系列最终物品时，该系列标记为完成。

## 核心循环

合并相同物品 → 发现新物品/配方 → 解锁新背景 → 开始新合成系列

## 核心机制

- **发现驱动合成**: 每次合并前不显示结果，合并后才揭示新物品，利用好奇心驱动持续操作——下一个会是什么？的心理机制
- **背景解锁奖励**: 合成进度推进到节点时解锁精美静态背景，作为视觉奖励，增强完成感和审美满足
- **无失败设计**: 没有步数限制、没有体力消耗、没有失败条件，纯正向反馈循环，消除焦虑感

## 为什么好玩

极简操作下隐藏着丰富的发现乐趣。每次合并都是一次小惊喜，合成链的终点像拆盲盒一样有期待感。精美的背景插画提供视觉享受，整体氛围放松治愈。


每次合并都是一次未知的探索——玩家不知道合并两个石头后会出现什么新东西。这种"盲盒"式体验持续激活好奇心。精美的背景插画本身就是奖励，合成进度条的缓慢推进反而成为放松体验的一部分。极简设计让注意力完全集中在发现和欣赏上，没有分数焦虑或时间压力。

## 粘性来源

差一个就能合成出什么的发现欲是最核心的粘性来源；无压力设计让玩家在无聊时自然想起打开；背景收集的完整性驱动全收集玩家。

## Meta 系统

- **背景图鉴系统**: 合成进度自动解锁新背景，可在图鉴中回看
- **对核心玩法的影响**: 不影响核心玩法，仅提供视觉奖励和收集目标

## 实现难度

低 — 合并逻辑最简单，最大技术难点是合成链数据结构和大量美术素材的资源优化
