# Bus and Subway Runner

- **类型**: 跑酷 / 休闲
- **平台**: Web (浏览器)
- **开发商**: CrazyGames 平台
- **首次发布**: 2019
- **一句话描述**: 巴士和地铁跑酷

## 玩法规则

巴士和地铁跑酷。玩家在浏览器中直接打开游戏即可开始游玩。

玩家控制角色自动向前奔跑，通过点击或滑动来跳跃、滑行、左右移动，躲避前方障碍物并收集沿途物品。游戏目标是尽可能跑得更远，获得更高分数。

## 核心循环

奔跑 → 躲避障碍 → 收集道具 → 刷新记录 → 再来一局

## 核心机制

- **程序化生成赛道**：每次游戏的障碍和地形组合不同，保证新鲜感

## 为什么好玩

简单的操作和快速的节奏带来流畅的体验。'差一点就过了'的不甘心感驱使玩家不断重来。

## 粘性来源

'差一点就过'的不甘心感 + 角色/皮肤收集系统。短时间一局的低门槛让人很容易说'再来一把'。

## Meta 系统

- **皮肤/角色解锁**：通过游戏内成就或货币解锁新外观
- **排行榜**：最高分排名
- 对核心玩法无直接影响，主要提供收集动力

## 实现难度

低 — 滑动和点击操作，逻辑简单。最大的技术难点是赛道生成的算法优化和手感调校。

### 详细操作说明

游戏界面简洁直观，主要操作区域占据屏幕大部分空间。玩家需要：

1. **观察当前状态**：注意屏幕上显示的游戏元素、得分、剩余时间或生命值
2. **做出决策**：根据当前形势选择最佳操作时机和方式
3. **执行操作**：通过点击、滑动或按键来完成游戏动作
4. **获得反馈**：操作成功或失败都有明确的视觉和声音提示
5. **持续调整**：根据游戏节奏的变化不断调整策略

### 游戏流程

游戏开始时，系统会生成初始的游戏场景。玩家进入游戏后：

- **前期**：熟悉基本操作和游戏规则，这个阶段节奏较慢
- **中期**：游戏节奏逐渐加快，需要更快的反应速度和更精准的判断
- **后期**：难度达到顶峰，只有最专注的玩家才能突破
- **结算**：游戏结束后显示得分、排名等信息，并提供重新开始选项

### 得分机制

游戏通过以下方式进行计分：

- 完成基本操作获得基础分数
- 连续成功操作会触发连击加成
- 特殊操作或高难度动作有额外分数奖励
- 部分游戏内道具可以倍增得分
