# Idle Planet Miner

- **类型**: 模拟经营/放置
- **平台**: Mobile (iOS+Android)
- **开发商**: Tech Tree Games LLC
- **首次发布**: 2018
- **一句话描述**: 一款模拟经营类放置游戏，玩家通过建设自动化系统实现资源的指数级增长

## 玩法规则

游戏主界面以不断运作的产业界面为核心视觉元素，整体布局简洁直观。屏幕上方/中央区域展示各项资源数值和设施运转状态，玩家一眼即可了解当前的核心状态。屏幕下方或侧边排列各类升级按钮和资源分配滑块，这些是玩家可以交互的按钮或操作区域。

玩家通过点击升级按钮、分配资源和选择投资方向进行核心操作。具体而言，点击某个设施可以查看其详细信息，包括当前等级、产出速率和下一级升级成本。点击升级按钮后，如果资源足够，设施等级立即提升，产出速率按预设倍率增长。玩家还可以在不同设施之间分配资源投入比例，形成不同的发展路线。随着等级提升，新设施类型逐步解锁，从单一产线扩展到复杂的产业网络。每次操作后，系统会即时给出视觉上的升级动画和数值增长的即时反馈，每次升级都有明确的数字变化，确保玩家对操作结果有清晰的感知。

游戏的核心目标是最大化整体产出效率，解锁更高级的产业层级。为了达成这一目标，玩家需要监控各项资源的生产情况，合理分配升级资金，在关键节点做出战略性的投资选择。当达到特定里程碑数值时，玩家进入下一阶段或解锁新内容。反之，如果资源分配严重失衡导致增长停滞，则需要重新开始或调整策略。

随着游戏进程的推进，系统会逐步解锁新的产业类型和更高效的产出渠道。玩家需要逐步掌握多层级资源管理和跨产业协同效应，才能在更高难度下持续进步。游戏的深度在于多层级资源管理——从基础的单一产线到复杂的跨产业联动网络，每个节点的选择都会影响全局效率，形成自洽的经济系统，这让简单的操作框架下蕴含着丰富的策略空间。

游戏中的资源分为基础资源（如金币、原材料）和高级资源（如科技点数、声望值），两者之间通过特定的设施相互转化，玩家需要找到最优的转化比例。

## 核心循环

投入资源升级设施 → 获得更高产出效率 → 解锁新产业并继续投入

## 核心机制

- **自动化流水线**: 玩家投资建设自动化设施后，即使离线也能持续获得收益。系统按照预设的优先级和效率自动分配资源，形成指数级增长曲线。设施之间可能存在上下游关系，上游设施的产出是下游设施的原料
- **转生/声望系统**: 达到特定里程碑后可以选择重置进度，获得永久声望加成。声望可以解锁全局倍率加成、新设施类型或起始优势。每次转生后，玩家从更强大的起点重新开始，但增长速度远超前一轮
- **多维资源网络**: 不同类型的资源相互关联和转化，形成复杂的经济网络。有些资源通过点击直接产出，有些通过设施自动产出，还有些需要通过资源转换获得。玩家需要找到最优的资源转换路径以最大化最终目标资源

## 为什么好玩

看着数字不断跳动、自动化系统高效运转，产生一种"我在躺着也能赚钱"的满足感。多层级资源管理带来的策略深度让简单的点击行为变得富有意义，每次升级都能感受到实质性的效率提升。

每次打开游戏都能看到产业比上次更繁荣，这种持续成长的确定性在随机性充斥的世界中尤为珍贵。

## 粘性来源

数值成长的指数曲线是核心粘性来源——每次转生后更高的起始效率让成长速度越来越快，形成强烈的正向循环。离线收益机制也促使玩家定期打开游戏查看成果，"看看我赚了多少钱"成了日常习惯。

里程碑目标（如"解锁第10种设施"或"累计赚够1亿金币"）提供了阶段性的成就感和短期目标。

## Meta 系统

转生声望系统：每次转生获得声望点数，用于解锁永久加成（初始资源倍率、自动化效率提升、新设施解锁）。对核心玩法的影响是加速新轮次的成长曲线，使后期发展更快，同时也为硬核玩家提供深度追求。

声望等级还附带特殊称号和视觉装饰，满足玩家的社交展示需求。

## 实现难度

中等。核心点击和升级逻辑简单，但多层资源网络和数值平衡需要精心设计。最大技术难点：数值模型的平衡——确保增长曲线既令人满足又不失控，需要在开发阶段进行大量的数值测试和调整。
