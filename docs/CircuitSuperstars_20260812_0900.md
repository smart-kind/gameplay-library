# Circuit Superstars

- **类型**: 竞速 / 多人
- **平台**: PC / PS4 / Switch / Xbox
- **开发商**: Original Fire Games
- **首次发布**: 2021
- **一句话描述**: 可爱的俯视赛车外表下是硬核的竞速物理——纯粹的赛车运动。

## 玩法规则

俯视视角的竞速游戏，但不要被可爱的外表欺骗——这是真正的硬核赛车。游戏使用精确的物理引擎，每个弯道、碰撞和漂移都反映真实的物理效果。

赛道短小精悍，充满急转弯和大弧度弯道，需要玩家掌握物理系统才能领先。资源管理是另一半——燃料会耗尽， careless 驾驶会损坏健康和轮胎。玩家需要在进站维修和继续比赛之间做出战术选择。

游戏支持多人对战——本地分屏和在线多人模式。

## 核心循环

掌握赛道 → 管理资源 → 进站策略 → 赢得比赛

## 核心机制

- 物理引擎：真实的碰撞、漂移和赛道物理
- 资源管理：燃料、健康、轮胎的战术选择
- 短小赛道：紧凑的赛道设计考验精确驾驶
- 进站策略：维修和保持领先的战术决策
- 多人模式：本地分屏和在线对战

## 为什么好玩

不要被可爱的外表欺骗——这是需要尊重的硬核赛车。掌握物理系统后的流畅驾驶体验令人满足。

## 粘性来源

- 物理掌握的成就感：从笨拙到流畅的进步曲线
- 进站策略深度：维修 vs 领先的战术决策
- 赛道精通：记住每个弯道的最佳路线
- 多人竞争：与好友对战的乐趣

## Meta 系统

无传统 Meta 系统。解锁新车辆和赛道提供长期目标。

## 实现难度

中。物理引擎的精确调优是核心难点。多人同步和赛道设计也需要投入。
