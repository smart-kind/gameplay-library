# 花样方块（Motley Blocks）

- **类型**: 益智 / 消除
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发者
- **首次发布**: 2014
- **一句话描述**: 经典的方块下落拼图游戏，通过旋转和摆放不同形状的方块来填满行并获得分数

## 玩法规则

游戏呈现一个矩形棋盘区域（通常为10x20网格），不同形状的方块从顶部依次下落。玩家需要控制每个方块的左右移动、旋转和下落速度，将它们放置在棋盘上最合适的位置。

当某一行被方块完全填满时，该行会被消除并增加分数，上方的方块会自然下落填补空位。如果方块堆叠到棋盘顶部无法放置新方块，游戏结束。

操作方式：点击屏幕左右两侧移动方块、点击旋转按钮改变方块方向、长按加速下落、点击底部区域快速放置。游戏通常提供"下一个方块"预览，帮助玩家提前规划布局。

游戏目标是尽可能长时间地存活并获得高分，同时消除尽可能多的行。消除多行（同时消除2-4行）会获得额外奖励分数。

## 核心循环

方块下落 → 旋转放置 → 填满行并消除 → 获得分数 → 方块加速，难度递增

## 核心机制

- **方块旋转系统**：7种标准方块形状（I、O、T、S、Z、J、L），每种可旋转4个方向，考验空间想象力和预判能力
- **行消除机制**：完全填满一行即可消除，多行同时消除产生连击倍率奖励，鼓励玩家规划布局制造多行同时消除
- **渐进加速**：随着消除行数增加，方块下落速度逐渐加快，提升紧张感和反应力要求
- **预览系统**：显示当前方块和下一个方块形状，让玩家有策略地安排位置

## 为什么好玩

方块类游戏的魅力在于简单易懂但精通困难——任何人都能玩，但要做到高分需要极高的空间规划能力和快速决策能力。"再消一行就破纪录"的冲动让人无法放下。

## 粘性来源

高分排行榜竞争、自我突破的成就感、"差几百分就超越纪录"的不甘心。方块游戏的随机性保证每局都是全新挑战，不会因背板而失去新鲜感。

## Meta 系统

无。纯单机益智游戏，无外围成长系统。

## 实现难度

低。核心逻辑非常简单：网格管理、碰撞检测、行消除判定。最大技术难点在于方块旋转的碰撞边界处理需要精确的坐标计算。
