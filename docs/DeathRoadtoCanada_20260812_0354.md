# 通往加拿大的死亡之路（Death Road to Canada）

- **类型**: Roguelike / 生存 / 驾驶
- **平台**: PC / Mobile (iOS+Android) / Switch / PlayStation
- **开发商**: Rocketcat Games / Madgarden
- **首次发布**: 2016
- **一句话描述**: 一款末日生存Roguelike游戏，玩家驾驶车辆穿越被僵尸占领的美国，一路向北前往加拿大。途中需要收

## 玩法规则

游戏以俯视视角呈现，玩家控制一个小队在僵尸横行的美国各地探索。每个地点（加油站、超市、废弃房屋等）都是一个随机生成的微型探索关卡。玩家在场景中移动，使用武器对抗僵尸，搜刮物资。

探索采用回合制节奏——玩家每执行一个动作，周围的僵尸会靠近一步。武器包括近战（棒球棍、刀具）和远程（手枪、猎枪），弹药有限。每次探索后，玩家需要决定继续前进还是返回车辆。

车辆管理是核心要素之一：需要监控燃油、食物、药品等资源的消耗。在营地和城镇之间，玩家会遇到随机事件——招募新队员、交易、道德抉择等。

## 核心循环

探索建筑 → 收集物资 → 对抗僵尸 → 返回车辆 → 前往下一个地点 → 管理资源

## 核心机制

- 随机事件驱动叙事：每次游戏流程中会遇到大量随机事件——遇到受伤的幸存者需要决定是否救助、发现藏有大量物资但被重兵把守的建筑等。这些选择直接影响队伍构成和资源状况。

- 资源管理张力：燃油、食物、弹药始终处于紧缺状态。玩家需要在'冒险搜索更多物资'和'节省资源继续赶路'之间做出选择，制造持续的紧张感。

- 永久死亡（Permadeath）：队员一旦死亡就永久失去，包括他们携带的独特技能。这让每次死亡都有真实的情感冲击，同时也激励玩家谨慎决策。

- Roguelike进程解锁：虽然单次旅程中队员会死亡，但解锁的新武器、角色类型和事件会永久保留，让后续旅程有更多可能性。

## 为什么好玩

每个决定都有重量——救不救这个陌生人？冒险进去还是直接走？这种持续的道德和战略抉择让简单的'打僵尸'变得有趣。随机事件的丰富性和不可预测性保证了每局游戏都是全新的体验。

## 粘性来源

Roguelike的'再来一局'驱动：每次失败后，解锁的新内容和新出现的随机组合让人忍不住想试试'如果选另一条路会怎样'。资源管理的紧张感和'差一点就到加拿大了'的不甘心是主要粘性来源。

## Meta 系统

解锁系统——通过完成旅程（无论成功失败），解锁新的起始角色、武器类型和特殊事件。这些解锁不直接提升数值，而是扩展游戏的可能性空间，确保每局游戏都有新鲜感。

## 实现难度

中 — 随机事件系统和资源管理的结合需要良好的数值平衡。最大的技术难点是设计足够多样化的随机事件池，同时确保游戏难度随进程合理递增。
