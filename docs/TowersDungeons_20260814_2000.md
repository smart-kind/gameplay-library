# Towers & Dungeons (塔楼与地下城)

- **类型**: 策略 / 塔防 / RPG
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2012
- **一句话描述**: 在地下城中建造防御塔抵御怪物入侵的策略游戏

## 玩法规则

玩家在一个地下城场景中建造和管理防御塔来抵御一波又一波的怪物入侵。

游戏界面显示一个地下城地图，包含预设的路径和可建造区域。玩家通过点击空地区域选择要建造的塔类型。每种塔有不同的攻击方式、射程和伤害值。

怪物沿着固定路径从地图边缘向中心目标前进。不同类型的怪物有不同的速度、生命值和特殊能力（如飞行、隐身、护甲等）。玩家需要根据怪物类型调整塔的种类和位置。

塔的升级系统允许玩家消耗资源提升塔的攻击力、射程或特殊效果。合理升级可以应对后期更强大的怪物。

## 核心循环

建造防御塔 → 观察怪物波次 → 升级/调整塔 → 抵御进攻 → 进入下一波

## 核心机制

- **塔防建设**：在有限空间内 strategically 放置不同类型的防御塔
- **怪物波次**：每波怪物有不同组成和强度，需要针对性防御
- **塔升级系统**：通过资源升级塔的能力，形成成长感
- **资源管理**：金币在杀敌和建造/升级间分配，需要权衡

## 为什么好玩

地下城主题给经典塔防玩法增加了新的氛围感。看着怪物一波波涌来，自己的防御塔层层阻击的场面很有成就感。

## 粘性来源

塔防策略深度 + 怪物波次递进的挑战感 + 塔升级的成长感 + 地下城主题的氛围吸引力

## Meta 系统

塔解锁和升级系统 — 通过关卡进度解锁新塔类型，通过资源升级塔属性

## 实现难度

低 — 经典塔防玩法，最大技术难点在于关卡设计的趣味性和怪物AI的路径规划
