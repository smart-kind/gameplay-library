# Merge Mayor（Merge Mayor）

- **类型**: 合并三消/模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: Tactile Games
- **首次发布**: 2020
- **一句话描述**: 一款结合合并解谜与城镇建设的休闲游戏，玩家扮演市长通过合并物品来重建小镇。

## 玩法规则

游戏主界面展示一个待重建的小镇地图，各个建筑和设施以锁定状态分布在场景中。棋盘区域是玩家进行合并操作的主要场所，棋盘上随机生成各种物品卡片（如建材、工具、农产品等）。玩家通过拖拽两个相同的物品使它们合并，产生一个更高等级版本的物品。

每次合并完成的物品会被用于修复或建造小镇中的对应建筑。例如，合并出锤子可以修复工具店，合并出砖块可以建造住宅。修复建筑会解锁新的棋盘格子和新的合并物品类型，形成正向循环。每个关卡有特定的建筑修复目标，完成后推进故事剧情。

## 核心循环

合并物品 → 获得建筑材料 → 修复小镇建筑 → 解锁新物品类型 → 继续合并修复更多建筑

## 核心机制

- **合并机制**：两个相同物品合并为更高等级版本，采用递进式等级系统，从基础物品到高级物品需要多次合并
- **城镇建设**：修复建筑是核心目标驱动，每个建筑修复后改变小镇的视觉面貌，提供即时视觉反馈
- **关卡进度**：通过完成建筑修复任务推进，每个区域有独立的建筑集合和解锁条件
- **故事驱动**：角色对话和剧情线索穿插在建筑修复过程中，增加叙事动机

## 为什么好玩

合并操作本身的满足感与城镇建设的成就感形成双重正反馈。小镇从破败到繁荣的视觉变化是最核心的动力——玩家每完成一个建筑都能立即看到小镇变得更美好，这种"看得见的进步"极具粘性。

## 粘性来源

城镇建设的渐进式视觉反馈是核心——看到荒芜小镇逐渐变成繁荣社区。合并操作的简单直觉性降低了入门门槛，而建筑修复的顺序规划和资源管理则提供了策略深度。故事驱动的任务目标让玩家持续有"再修复一个建筑"的冲动。

## Meta 系统

- **能量系统**：限制单次游戏时长，恢复后可继续游玩
- **装饰道具**：部分稀有物品可用于小镇装饰
- **角色系统**：NPC助手提供任务和提示
- **活动系统**：限时活动和季节性事件提供额外奖励和挑战

## 实现难度

中 — 合并逻辑本身简单，但需要设计完整的关卡系统、建筑解锁树、物品等级平衡。最大技术难点在于关卡难度曲线的设计，确保每个关卡在有限资源下既有挑战性又不会让玩家卡关太久。
