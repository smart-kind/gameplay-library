# Finger Tied

- **类型**: 解谜/益智
- **平台**: Mobile (iOS)
- **开发商**: Devnex
- **首次发布**: 2020
- **一句话描述**: 一款考验空间思维的益智解谜游戏

## 玩法规则

游戏画面中有多条彩色绳索/线条交叉缠绕，玩家需要通过拖拽绳结来解开缠绕，使每条绳索都不与其他绳索交叉。

某些关卡有固定绳结（不能移动），增加了难度。每关目标是将所有绳索完全解开来。界面简洁，主要是绳索和节点。

游戏从简单的 2-3 条绳索开始，逐渐增加到十几条绳索的复杂缠绕。

游戏还支持排行榜系统，玩家可以与全球玩家比较分数和通关进度。每日挑战模式提供随机生成的关卡，增加重玩价值。

在部分关卡中，环境因素会影响玩法，如风向、重力变化或时间减速。这些元素要求玩家调整策略，不能简单套用固定套路。

## 核心循环

解开绳索谜题 → 解锁更复杂的关卡 → 挑战更难的缠绕布局

## 核心机制

- 拖拽解谜：通过拖拽节点解开交叉的绳索
- 渐进难度：绳索数量和固定节点逐渐增加
- 即时验证：解开后自动检测并显示成功

## 为什么好玩

简单的概念但极具挑战性的谜题设计，解开瞬间的成就感很强。

## 粘性来源

"差一点就解开"的心理驱动和关卡递进。

## Meta 系统

无

## 实现难度

低 — 核心逻辑简单，最大的技术难点是谜题生成算法和交叉检测。
