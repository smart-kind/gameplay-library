# Super Mega Mini Party

- **类型**: 多人派对 / 超休闲竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: RED GAMES CO, LLC
- **首次发布**: 2019
- **评分**: ⭐ 4.7/5 (6,929 评价)
- **价格**: Free
- **一句话描述**: 包含20款多人迷你游戏的派对合集，支持与全球玩家对战或与朋友同屏游玩。

## 玩法规则

游戏提供两种模式：全球匹配对战和朋友聚会模式。在全球模式中，玩家被随机匹配到其他玩家，依次进行多款迷你游戏对决。每款迷你游戏有独立规则，但都基于简单的单指操作（点击、长按、滑动）。聚会模式支持多人在同一设备轮流操作，类似马里奥派对的本地多人体验。每局迷你游戏持续30-60秒，快速决出胜负。最终根据所有迷你游戏的总分排名。界面简洁，游戏开始前会短暂展示规则说明。

## 核心循环

进入匹配 → 玩多款迷你游戏 → 获得总分排名 → 提升段位/解锁内容

## 核心机制

- 随机迷你游戏池：每局从20款游戏中随机选取，确保每场体验不同
- ELO匹配系统：根据玩家水平匹配对手，保证竞技公平性
- 段位晋升机制：连续胜利可提升段位，提供长期目标

## 为什么好玩

20款不同风格的迷你游戏确保每局体验新鲜。全球匹配让社交对战触手可及，聚会模式适合线下朋友一起玩。

## 粘性来源

段位系统提供竞技目标、新游戏不定期更新、好友系统、全球排行榜

## Meta 系统

段位/等级系统——通过比赛积累积分提升段位。皮肤/外观自定义——解锁角色外观。不影响核心玩法。

## 实现难度

低——核心是简单的触控操作+多款小游戏轮换，技术难点在于网络同步和匹配算法
