# Zero Escape: Virtue's Last Reward（Zero Escape: Virtue's Last Reward）

- **类型**: 视觉小说 / 密室逃脱 / 解谜
- **平台**: Nintendo 3DS / PlayStation Vita / PC
- **开发商**: Chunsoft / Spike Chunsoft
- **首次发布**: 2012
- **一句话描述**: 9名陌生人被困在神秘设施中，通过密室逃脱和信任投票游戏来决定命运的科幻悬疑冒险。

## 玩法规则

游戏分为两个交替进行的部分：密室逃脱和视觉小说叙事。

在密室逃脱部分，玩家以第一人称视角探索房间，点击屏幕调查物品、收集线索、解谜。谜题包括密码锁、逻辑推理、物品组合等类型。解开所有谜题后可以离开房间，推进剧情。

在叙事部分，游戏采用视觉小说形式展示角色对话和剧情发展。9名参与者被困在一个名为"Nonary Game"的设施中，每90分钟必须参与一次"信任投票"——选择与另一位参与者"结盟"或"背叛"。结盟的两人各得3分，互相背叛各得1分，一方结盟一方背叛则背叛者得6分、结盟者得0分。

累积分数达到9分才能打开通往自由的门。多分支剧情和不同结局取决于玩家的选择。

密室逃脱部分通常包含5-8个相互关联的谜题，需要收集的物品线索分布在整个房间中。部分谜题需要使用从其他房间获得的道具来解开，形成跨房间的挑战链条。

## 核心循环

密室逃脱解谜 → 推进剧情 → 信任投票决策 → 影响故事走向 → 解锁新路线

## 核心机制

- **密室解谜**：每个房间包含多个相互关联的谜题，需要观察环境、收集物品、运用逻辑推理才能解开
- **信任投票博弈**：经典的囚徒困境变体，玩家需要在合作与背叛之间做出选择，每次投票的结果直接影响角色关系和剧情走向
- **多路线分支**：玩家的选择将故事引向不同分支，需要多次通关才能了解完整剧情

## 为什么好玩

将密室逃脱的智力挑战与悬疑叙事的沉浸感完美结合，每个房间解锁后展开的新剧情都让人欲罢不能。

## 粘性来源

具体到机制层面：悬疑叙事驱动的"想知道真相"的强烈好奇心——剧情中不断抛出的谜团和反转让玩家忍不住继续推进。多路线设计鼓励重复游玩，每次通关只揭示部分真相，收集所有结局的收集欲是重要驱动。

## Meta 系统

- **流程图系统**：游戏内置流程图显示已解锁和未解锁的剧情分支
- **结局收集**：共6个主要结局，需要多次通关
- **对核心玩法的影响**：流程图帮助玩家规划需要重玩的路线

## 实现难度

中高——视觉小说引擎本身技术难度不高，但多分支叙事的逻辑复杂度高，需要精心设计每个选择节点的因果关系。密室谜题的设计需要与剧情紧密结合，最大的难点是叙事与解谜两种体验的无缝衔接。
