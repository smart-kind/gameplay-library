# Pawnbarian

- **类型**: Roguelike / 棋类策略 / 卡牌
- **平台**: Mobile (iOS+Android)
- **开发商**: Jan Wojtecki
- **首次发布**: 2022
- **一句话描述**: 在国际象棋棋盘上用棋子作为卡牌进行战斗，每次移动一个棋子攻击敌人

## 玩法规则

游戏画面是一个棋盘（通常是 5×5 到 8×8 不等），上面分布着玩家的棋子（国际象棋棋子：兵、车、马、象、后、王）和敌方单位（各种怪物）。

每回合玩家从手中选择一张"卡牌"——每张卡牌代表棋盘上的一个棋子类型。打出棋子卡牌意味着移动棋盘上对应类型的棋子：按照该棋子的国际象棋走法规则（如马走日、象走斜线、车走直线），移动到目标格并攻击该格上的敌人。

每次移动/攻击后，如果该棋子吃掉了敌人，该棋子会获得经验并可能升级。棋子升级后，其攻击力或移动范围会增强。

敌方也会行动——在玩家回合结束后，存活的敌人会攻击附近的棋子或向棋子移动。某些敌人有特殊能力（如远程攻击、召唤、范围伤害等）。

游戏目标是消灭所有敌人（或到达指定目标格）。如果所有棋子被消灭，游戏失败。部分关卡有特殊条件（如保护王、在N回合内完成等）。

## 核心循环

选择棋子卡牌 → 按棋子走法规则移动并攻击 → 敌人回合反击 → 棋子升级变强 → 消灭所有敌人过关

## 核心机制

- **国际象棋走法卡牌化**：将国际象棋的棋子移动规则转化为卡牌行动。每种棋子有独特的移动模式（马的L形、象的对角线、车的直线），这本身就是丰富的策略空间。打出不同棋子卡牌 = 执行不同的战术机动。
- **棋盘战术布局**：不仅是卡牌选择，棋子在棋盘上的位置也至关重要。好的位置可以让一个棋子在后续回合连续攻击多个敌人，坏的位置则让棋子陷入被围攻的危险。
- **棋子升级系统**：棋子通过击杀获得经验并升级。升级后的棋子变得更强，但也意味着你在棋盘上投入了"资产"——如果升级后的棋子被击杀，损失更大。
- **敌人意图预测**：与 Slay the Spire 类似，部分敌人会显示下一步意图。玩家需要据此决定是进攻还是让棋子退到安全位置。

## 为什么好玩

国际象棋的策略深度与 Roguelike 的随机重玩性完美融合。每次遇到的棋子组合、敌人配置都不同，需要不断调整战术。看着自己的棋子从弱小的初始状态一步步成长为强力单位，再配合精妙的走位连续击杀敌人，带来独特的"棋盘指挥官"满足感。

## 粘性来源

- **棋类+卡牌的独特融合**：市场上极少有将国际象棋与 Roguelike 结合的游戏，新鲜感强
- **每局不同**：随机抽取的棋子卡牌和敌人配置保证每局体验独特
- **升级成就感**：棋子从弱变强的成长感
- **智力挑战**：需要同时考虑棋盘位置和卡牌选择的双重策略

## Meta 系统

- **永久解锁**：通关后解锁新棋子类型、新棋子皮肤、新关卡模式
- **每日挑战**：固定种子的每日关卡
- **成就系统**：完成特定挑战（如"用兵消灭100个敌人"）获得成就

## 实现难度

中。核心是棋盘网格系统 + 国际象棋走法规则 + 卡牌回合制战斗。技术难点在于：(1) 棋子移动合法性判定（包括阻挡检测）；(2) 敌人AI的行为逻辑（移动、攻击优先级）；(3) 棋盘上多单位的状态管理和动画同步。
