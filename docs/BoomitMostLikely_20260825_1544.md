# Boomit 最可能投票（Boomit - Most Likely）

- **类型**: 社交派对 / 问答游戏
- **平台**: Mobile (iOS+Android)
- **开发商**: Boomit
- **首次发布**: 2020
- **一句话描述**: 一款以Most Likely To为主题的社交派对游戏，适合朋友聚会时游玩。

## 玩法规则

3-10名玩家围坐一圈，每人手持一部手机并打开游戏。系统给出一个问题，如谁最可能在聚会上迟到。

所有玩家同时在自己的手机上选择他们认为最符合描述的人。倒计时结束后，所有人同时举起手机展示选择。

得票最多的人需要完成一个小挑战或接受惩罚。问题库包含数百个不同类别的问题。

## 核心循环

设置玩家 -> 系统出题 -> 同时投票 -> 展示结果 -> 执行挑战 -> 下一轮

## 核心机制

- 同步投票: 所有玩家同时选择，同时展示结果，制造惊喜和欢笑。
- 问题分类库: 问题按类别分组（搞笑、深入、尴尬等），玩家可以选择适合的类别。
- 挑战系统: 得票最多的人需要完成小挑战，增加互动性。

## 为什么好玩

看到朋友的选择结果往往出人意料，制造大量欢笑和话题。

每轮投票后的讨论环节往往比投票本身更有趣，因为大家可以解释自己选择的原因。

## 粘性来源

社交场景的天然粘性。问题库的持续更新保持新鲜感。自定义问题功能让玩家可以添加专属内容。

统计数据也增加了回访动机，玩家想看看自己累计被投了多少次。

## Meta 系统

问题库扩展：持续添加新问题。

自定义功能：玩家创建自己的问题包。

统计：记录谁被投票最多的有趣数据。

## 实现难度

低 - 核心是内容库和简单的投票机制。技术实现简单，难点在于内容质量和本地化。
