# 疯狂游戏 - 1500+游戏（CrazyGames: Play 1500+ Games）

- **类型**: 游戏平台/合集
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2025
- **一句话描述**: 集成1500多款网页小游戏的平台应用

## 玩法规则

应用作为游戏平台，浏览分类后选择小游戏。游戏通过内嵌浏览器或H5引擎运行，玩家直接在应用内游玩。每款小游戏有自己的操作方式（点击、拖拽、键盘/触屏）。玩家可收藏喜欢的游戏、查看热门排行。游戏加载后即可游玩，无需额外下载。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

浏览游戏 → 选择游玩 → 收藏/评分 → 继续探索

- **海量游戏库**:  1500+款游戏覆盖多种类型
- **分类浏览**:  按类型、热门、新上线分类筛选
- **即时游玩**:  点击即玩，无需等待下载
