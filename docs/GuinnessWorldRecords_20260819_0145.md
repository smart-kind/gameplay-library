# 吉尼斯世界纪录（Guinness World Records）

- **类型**: 益智 / 迷你游戏集合
- **平台**: Mobile (iOS)
- **开发商**: Warner Bros / TT Games
- **首次发布**: 2008
- **一句话描述**: 一款基于真实世界纪录的迷你游戏合集，玩家挑战各种奇怪有趣的纪录目标。

## 玩法规则

游戏包含多个不同的迷你游戏，每个游戏对应一项真实的吉尼斯世界纪录挑战。例如：叠硬币最高纪录、快速吃披萨、最长保龄球连击等。

每个迷你游戏有独特的操控方式：有的需要快速点击屏幕、有的需要精确计时、有的需要平衡操控。游戏界面会显示当前挑战的纪录目标（比如"在30秒内叠20个硬币"），玩家需要通过操作来尝试打破纪录。

成功打破纪录会解锁新的挑战和成就。某些挑战有星级评分系统，达到不同分数获得不同星级。

## 核心循环

选择挑战项目 → 执行操作尝试破纪录 → 查看结果 → 解锁新挑战/重试

## 核心机制

- **多样化迷你游戏**：每个挑战都是不同的游戏类型，从节奏点击到物理平衡到快速反应，保持新鲜感。
- **真实纪录对照**：每个挑战都基于真实的吉尼斯世界纪录数据，增加了"我在挑战真实纪录"的代入感。
- **即时反馈**：每次尝试后立即显示成绩与世界纪录的差距，清晰明了。

## 为什么好玩

"你能做到吗？"的好奇心是核心驱动力。每个迷你游戏都基于一个真实存在的奇怪纪录，这种"原来世界上有人真的在做这个"的惊讶感加上"我也试试"的挑战欲，形成很强的吸引力。

## 粘性来源

- **成就收集**：每个挑战的星级和破纪录成就构成收集目标。
- **朋友竞争**：和朋友比较谁能在某个挑战上做得更好，天然适合社交分享。
- **多样性**：几十个不同类型的迷你游戏，总有一个适合你的口味。

## Meta 系统

- **成就系统**：完成特定数量的挑战、打破特定数量的纪录获得成就徽章。
- **挑战解锁**：完成一定数量的挑战后解锁新类别的挑战项目。

## 实现难度

中。最大难点是开发大量不同类型的迷你游戏——每个都需要独立的玩法逻辑、UI和物理规则。但每个单独迷你游戏的技术难度都不高。另外，需要一个统一的迷你游戏框架来管理加载、切换和分数统计。

## 变体设计

可以加入"在线排行榜"模式，玩家在全球范围内比拼每个迷你项目的最高分。也可以加入"自定义挑战"——允许玩家用游戏内工具创建自己的纪录挑战并分享给朋友。
