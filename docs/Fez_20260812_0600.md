# 菲兹（Fez）

- **类型**: 解谜 / 平台跳跃 / 像素
- **平台**: Steam / Nintendo Switch / PlayStation / Xbox / itch.io
- **开发商**: Polytron
- **首次发布**: 2012
- **一句话描述**: 通过旋转 2D/3D 视角来改变平台结构，在美丽像素世界中探索和解谜的创意平台游戏。

## 玩法规则

游戏画面是精美的像素风格世界。主角 Gomez 是一个戴着 Fez 帽子的小人，在 2D 平台上行走、跳跃、攀爬。

游戏的核心创新在于视角旋转。虽然画面看起来是 2D 的侧视图，但整个世界实际上是 3D 的。玩家可以按按钮将视角旋转 90 度（前、后、左、右四个方向）。旋转后，原来不可达的平台可能会连通，新的路径可能出现。

例如：两个在 2D 视图中分开的平台，在旋转视角后可能会发现它们在 3D 空间中是相连的；一堵墙在某个视角下是不可穿越的障碍，但旋转后变成了地面上的一个小凸起，可以直接走过。

游戏世界中散布着各种收集品：六角星碎片（Hexahedrons）、反物质核心、密码门等。找到所有碎片是通关的关键。

玩家操作：
- **方向键**：左右移动
- **跳跃键**：向上跳跃（可二段跳）
- **攀爬**：抓住墙壁边缘并攀爬
- **旋转视角**：按旋转按钮，世界在 3D 中旋转 90 度

## 核心循环

在 2D 平台上移动 → 旋转视角发现新路径 → 解决谜题获得收集品 → 解锁新区域

## 核心机制

- **视角即工具**：旋转视角不是视觉特效，而是核心解谜工具。同一个场景在四个视角下有完全不同的可通行性
- **2D/3D 转换**：世界在 3D 中存在，但玩家始终以 2D 视角观察。理解 2D 表现和 3D 实际的关系是解谜的关键
- **密码系统**：游戏中有基于字母/符号的密码谜题，需要玩家在探索中收集线索来破译
- **隐藏区域**：大量隐藏路径和秘密区域需要特定的视角和操作组合才能发现

## 为什么好玩

Fez 的魔力在于它把"换个角度看问题"变成了字面意义上的游戏机制。当你卡在一个关卡中，旋转视角后发现"原来这条路一直就在那里"，这种体验既有趣又让人反思。游戏的像素美术和音乐也非常出色，创造了一个既美丽又神秘的世界。

## 粘性来源

1. **视角顿悟**——旋转后发现隐藏路径的惊喜感不断重复但不会腻
2. **探索深度**——每个区域都有多层秘密，第一次通关后仍有大量未发现的内容
3. **美学沉浸**——精美的像素美术和氛围音乐让玩家享受在游戏中的每一分钟
4. **密码谜题**——需要真实世界知识的密码谜题增加了额外层次的挑战

## Meta 系统

无。收集品是纯进度标记，没有角色升级或能力解锁。

## 实现难度

中。核心是 2D 平台游戏逻辑加上 3D 视角旋转。最大技术难点是碰撞检测和路径连通性——旋转后需要实时重新计算平台的碰撞关系，确保玩家体验流畅且不会卡在错误的位置。
