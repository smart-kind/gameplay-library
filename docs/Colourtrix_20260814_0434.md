# Colourtrix

- **类型**: 三消 / 堆叠
- **平台**: Mobile (iOS+Android)
- **开发商**: 
- **首次发布**: 2013
- **一句话描述**: 俄罗斯方块变种——不旋转方块，而是旋转颜色顺序来匹配三消

## 玩法规则

游戏画面采用类似俄罗斯方块的下落方块布局。屏幕底部不断有方块向上堆叠（与传统俄罗斯方块相反）。

每个下落方块由多种颜色组成，但与传统三消游戏不同——你不能旋转方块来适应空间，而是可以旋转方块中颜色的排列顺序。通过调整颜色顺序，让三个相同颜色连成一行来消除并获得分数。

随着时间推移，无法移动的灰色方块会从屏幕底部不断升起，逐渐压缩可用空间。等级越高，方块下落速度越快，压力越大。

## 核心循环

观察下落方块的颜色组成 → 旋转颜色顺序 → 匹配三消消除 → 腾出空间 → 阻止灰色方块堆叠到顶

## 核心机制

- **颜色旋转机制**：核心创新点——不旋转方块形状，而是旋转颜色排列顺序，在固定的空间内寻找匹配可能性
- **反向堆叠压力**：灰色方块从底部向上堆叠（与传统下落方块方向相反），持续压缩操作空间
- **渐进加速**：等级提升后方块下落速度加快，考验玩家决策速度和颜色规划能力

## 为什么好玩

将俄罗斯方块的"空间适配"概念转化为"颜色适配"是一个聪明的变体。旋转颜色顺序的操作简单但需要前瞻性思维——你需要同时考虑当前消除和为后续方块留出空间。灰色方块从底部升起的设定改变了传统方块游戏的节奏感，带来独特的压迫感。

## 粘性来源

"差一点就能消除"的空间规划紧张感。每次旋转颜色顺序时都在做微妙的权衡：这次消除是解了燃眉之急还是制造了更糟糕的局面？这种策略深度是主要的粘性来源。

## Meta 系统

无外围成长系统。纯分数驱动的高分挑战模式。
