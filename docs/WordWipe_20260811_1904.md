# Word Wipe

- **类型**: 文字 / 益智
- **平台**: Web (浏览器) / Mobile
- **开发商**: CrazyGames 平台
- **首次发布**: 2019
- **一句话描述**: 经典单词消除游戏

## 玩法规则

经典单词消除游戏。玩家在浏览器中直接打开游戏即可开始游玩。

游戏在一个字母网格中进行。玩家通过拖拽连接相邻字母组成有效英文单词。组成的单词会从网格中消除，上方的字母落下填补空格。目标是消除尽可能多的字母并获得高分。

## 核心循环

找字母 → 组单词 → 消除得分 → 新字母落下 → 继续组词

## 核心机制

- **字母网格消除**：连接相邻字母形成单词，消除后重力下落

## 为什么好玩

同时考验词汇量和空间思维，找到长单词的快感让人欲罢不能。重力消除机制带来连锁反应的爽感。

## 粘性来源

找到稀有长单词的快感 + 重力消除的连锁爽感。词汇量的自我挑战让人想不断刷新分数。

## Meta 系统

无

纯粹的益智体验，没有外围成长系统。

## 实现难度

中 — 需要词典库和有效的单词验证系统。最大的技术难点是词典数据管理和单词查找算法。

### 详细操作说明

游戏界面简洁直观，主要操作区域占据屏幕大部分空间。玩家需要：

1. **观察当前状态**：注意屏幕上显示的游戏元素、得分、剩余时间或生命值
2. **做出决策**：根据当前形势选择最佳操作时机和方式
3. **执行操作**：通过点击、滑动或按键来完成游戏动作
4. **获得反馈**：操作成功或失败都有明确的视觉和声音提示
5. **持续调整**：根据游戏节奏的变化不断调整策略

### 游戏流程

游戏开始时，系统会生成初始的游戏场景。玩家进入游戏后：

- **前期**：熟悉基本操作和游戏规则，这个阶段节奏较慢
- **中期**：游戏节奏逐渐加快，需要更快的反应速度和更精准的判断
- **后期**：难度达到顶峰，只有最专注的玩家才能突破
- **结算**：游戏结束后显示得分、排名等信息，并提供重新开始选项

### 得分机制

游戏通过以下方式进行计分：

- 完成基本操作获得基础分数
- 连续成功操作会触发连击加成
- 特殊操作或高难度动作有额外分数奖励
- 部分游戏内道具可以倍增得分
