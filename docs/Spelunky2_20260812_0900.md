# Spelunky 2

- **类型**: 平台动作 / Roguelike
- **平台**: PC / PS4 / Switch / Xbox
- **开发商**: Mossmouth / BlitWorks
- **首次发布**: 2020
- **一句话描述**: 极致精确的平台动作 Roguelike，每次死亡都让你变得更强。

## 玩法规则

玩家在随机生成的洞穴中探索，收集宝藏、击败敌人、寻找出口。游戏采用横版平台跳跃——跑、跳、攀爬、绳索摆荡、炸弹爆破。每个动作都需要精确的时机和位置判断。

洞穴分为多层——每层有不同主题和敌人，最终目标是找到通往下一层的入口并到达最终 Boss。游戏中的物品和敌人都有明确的物理规则——炸弹会炸毁墙壁和敌人，绳索可以摆荡跨越间隙，商店可以购买道具但打破商店会招致商店老板追杀。

死亡是永久的——每次游戏从起点重新开始。但通过反复尝试，玩家学习洞穴的生成规律、敌人的行为模式和道具的使用时机。

## 核心循环

探索洞穴 → 收集宝藏 → 找到下一层入口 → 面对最终 Boss

## 核心机制

- 程序生成洞穴：每次游戏的洞穴布局都不同
- 精确平台跳跃：跑、跳、攀爬、绳索摆荡
- 物理规则：炸弹、绳索、商店等物品有真实物理效果
- 永久死亡：每次死亡从头开始，但知识保留
- 隐藏路径和秘密：多层探索发现隐藏区域

## 为什么好玩

极致精确的平台跳跃配合随机生成的洞穴，每次探索都是全新的挑战。死亡后的"再来一次"冲动极强。

## 粘性来源

- 知识即进度：虽然角色死亡，但玩家对游戏机制的理解在增长
- 精确操作的满足感：完美跳跃和躲避带来的成就感
- 随机洞穴的新鲜感：每次探索都是未知的
- 隐藏内容深度：多层秘密等待发现

## Meta 系统

无。Spelunky 2 没有传统的外围进度系统，纯粹的"知识即进度"设计。

## 实现难度

高。程序生成需要确保每局都有可行的通关路径。物理系统和精确碰撞检测需要大量调优。
