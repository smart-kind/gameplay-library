# 铀业公司（UraniumInc）

- **类型**: 经营策略
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer 收录独立游戏
- **首次发布**: 2012
- **一句话描述**: 一款铀矿开采和经营管理的策略游戏，从勘探到销售全流程模拟

## 玩法规则

游戏画面采用俯视角的经营管理界面，地图显示矿脉分布、地形和设施布局。色彩以工业风格为主，偏暗色调。

游戏流程分为几个核心阶段：

勘探阶段：购买勘探设备，在地图上选择区域进行勘探。勘探结果揭示铀矿的储量和品质。不同区域的勘探成本和成功率不同，需要权衡风险。

开采阶段：雇佣矿工、购买开采设备，建立采矿场。开采速度受设备等级、矿工数量和矿脉品质的影响。开采过程会产生运营成本。

加工阶段：原铀矿需要加工才能出售。建设加工厂，升级加工设备可以提高加工效率和产出品质。

销售阶段：将加工后的铀产品销售给买家。市场价格会波动，选择合适的时机出售可以最大化利润。不同的买家有不同的价格和采购量。

扩张阶段：用利润投资新矿场、升级设备、雇佣更多员工，扩大经营规模。同时需要管理现金流，避免资金链断裂。

游戏还提供政策变化、环境法规、市场竞争等外部因素，增加策略深度。

## 核心循环

勘探矿脉 → 建立采矿场开采 → 加工铀矿 → 销售获利 → 投资扩张 → 发现更大矿脉 → 赚取更多利润

## 核心机制

- **资源管理系统：需要平衡资金、人力、设备、库存等多种资源。合理分配资源是经营成功的关键**
- **市场模拟系统：铀价随市场供需波动，受政策、国际形势等因素影响。把握买卖时机是利润最大化的关键**
- **勘探风险评估：不同区域的勘探成本和成功率不同，高风险高回报的决策增加策略深度**
- **产业链管理：从勘探、开采、加工到销售的完整产业链模拟，每个环节都需要投入和优化**

## 为什么好玩

将工业经营模拟浓缩在移动平台上，策略深度足够。完整的产业链模拟让玩家体验从一个小矿场到铀业巨头的成长过程。

## 粘性来源

经营成长的满足感和市场变化带来的策略挑战。公司规模不断扩大，解锁新的经营选项，形成持续的目标感。

## Meta 系统

公司等级系统、设施升级系统、市场份额竞争。解锁新的地区和市场是主要长期目标。

## 实现难度

中，需要理解资源管理和市场规律。最大技术难点在于市场模拟的平衡性和AI竞争对手行为。
