# 间谍猎人（Spy Hunter）

- **类型**: 动作 / 射击 / 街机赛车
- **平台**: Arcade / Mobile / 多平台
- **开发商**: Bally Midway
- **首次发布**: 1983
- **一句话描述**: 1983年的经典街机游戏，灵感来源于007电影。玩家驾驶装备武器的特工车辆，在公路上消灭敌方车辆。

## 玩法规则

游戏采用俯视视角的公路场景。画面中有一条蜿蜒的道路，玩家的车辆在道路中央行驶，两侧有敌方车辆出现。背景是经典的James Bond风格配乐。

玩家操作包括转向（左右移动车辆）、加速、射击（发射机枪/导弹）。玩家的车辆装备有武器，可以消灭前方的敌方车辆。敌方车辆会试图阻挡或攻击玩家。

游戏的目标是尽可能长时间地存活并消灭更多敌方车辆。每消灭一辆车获得分数。游戏没有终点——难度会随时间逐渐增加，敌方车辆更多、更激进。

道路中途有武器站（加油站外观），进入后可以获得新武器：油 slick（油膜使敌车打滑）、烟雾弹（隐藏玩家）、导弹（一击必杀）等。武器站是游戏节奏的关键节点。

## 核心循环

驾驶消灭敌方车辆 -> 获得分数 -> 在武器站获取新装备 -> 应对更强的敌人

## 核心机制

- 武器切换系统：通过访问武器站获得不同的特殊武器，每种武器有不同的战术用途——油膜用于减速、烟雾用于逃脱、导弹用于一击必杀。
- 道路动态变化：公路的弯道和宽度会随时间变化，增加了驾驶的难度。
- 敌方AI行为：敌方车辆有不同的行为模式——有些试图撞你，有些试图阻挡，有些从后方接近，需要不同的应对策略。

## 为什么好玩

Spy Hunter的乐趣在于高速公路上孤胆特工的刺激感——一边驾驶一边消灭四面八方涌来的敌人。007式的武器设定（隐藏在车里的机枪和导弹）满足了间谍幻想。简单的操作让任何人都能上手，但想要高分需要极高的反应速度和路线规划能力。

## 粘性来源

粘性来自街机游戏的经典高分挑战模式。差一点就打破纪录的心理驱使你不断投币/再来一局。简洁的操作和即时的爽感反馈也让它成为一款完美的碎片时间游戏。

## Meta 系统

无。经典街机游戏，纯分数挑战。部分移植版本增加了关卡和Boss。

## 实现难度

低。最大的技术难点在于敌方AI的路径规划——需要让多辆敌车在有限的道路空间内同时行动而不显得不自然。
