# 疯狂地下城（Dungeon of Madness）

- **类型**: 动作RPG / 地下城探险
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立开发
- **首次发布**: 2015
- **一句话描述**: 一款地下城探险动作游戏，玩家在随机生成的地牢中战斗、探索和收集装备

## 玩法规则

玩家操控一个角色进入随机生成的地下城。地下城由多个房间通过走廊连接而成，每个房间包含不同类型的怪物、宝箱或陷阱。

通过虚拟摇杆控制角色移动，点击攻击按钮进行近战或远程攻击（取决于角色职业）。不同房间有不同配置：普通房间有2-4只普通怪物，精英房间有一个强力的精英怪，宝箱房间有补给品和装备，Boss房间有该层的最终Boss。

击败怪物获得经验值和金币。经验值累积到一定程度后角色升级，提升生命值、攻击力、防御力等基础属性。金币可以在商店购买药水、装备或特殊道具。

探索过程中需要注意：某些房间有陷阱（地刺、毒气、落石），宝箱可能触发陷阱怪物。到达每层地下城的最终房间后击败Boss，可以选择进入更深层（难度更高但奖励更好）或返回地面整理装备。

## 核心循环

探索随机生成的房间 → 与怪物战斗获得经验和金币 → 升级提升基础属性 → 收集更好的装备 → 击败Boss进入下一层地下城 → 越来越深入的挑战

## 核心机制

- **随机地图生成**：每次进入地下城的布局、敌人配置、宝箱位置和陷阱分布都不同，保证重复游玩性。地图按照预设规则生成，确保所有区域可达
- **角色成长系统**：击败敌人获得经验值，升级后提升攻击力、防御力、生命值等基础属性，可能解锁新技能。成长是累积性的
- **装备收集系统**：怪物和宝箱掉落不同类型的武器、护甲和饰品。不同品质的装备（普通、稀有、史诗）有不同的属性加成，组合不同装备改变战斗风格
- **多层难度递增**：每深入一层地下城，怪物更强、数量更多、陷阱更致命，但奖励也更好。玩家需要权衡风险与回报

## 为什么好玩

随机生成的地下城每次都是新体验——你永远不知道下一个房间会遇到什么。战斗系统的即时操作感和角色成长的成就感相结合，让人停不下来。探索未知房间的紧张感和发现宝藏的惊喜感交替出现。

## 粘性来源

随机性和角色成长的双重驱动。"下一层可能会捡到更好的装备"和"再升一级就能挑战Boss"的期待感让人持续游玩。每次死亡后重新开始，虽然失去部分进度但保留角色等级，形成Roguelike-lite的体验循环。

## Meta 系统

角色等级永久保留（即使死亡也不会丢失）。装备在每次进入地下城时重置。通过多轮游玩累积金币，可以在地面商店购买永久性的属性加成或特殊道具。成就系统记录各种里程碑（首次通关第N层、首次获得史诗装备等）。

## 实现难度

中 — 最大技术难点是随机地图生成算法的合理性（确保地图可达性、房间连通性和难度平衡）。战斗AI需要区分不同类型怪物的行为模式。装备系统的属性平衡和掉落概率设计需要大量测试。性能优化确保大量怪物同时存在时的流畅运行。
