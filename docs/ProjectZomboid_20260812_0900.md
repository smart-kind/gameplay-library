# Project Zomboid

- **类型**: 生存 / 沙盒
- **平台**: PC / Linux / macOS
- **开发商**: The Indie Stone
- **首次发布**: 2013
- **一句话描述**: 最真实的丧尸生存模拟——你注定死亡，但能活多久？

## 玩法规则

玩家在丧尸末日中的开放世界求生。游戏采用等距视角，模拟真实生存需求——饥饿、口渴、疲劳、体温、情绪。玩家需要寻找食物、水源、庇护所，同时防御丧尸。

核心机制是深度模拟——每个物品都有重量和用途，车辆可以驾驶但需要维护，建筑可以加固或改造，技能通过实践提升（阅读提升智力，木工制作家具，烹饪改善食物）。

游戏没有胜利条件——"你注定死亡"。目标是在丧尸末日中尽可能久地生存，同时保持角色健康和心理状态。

## 核心循环

搜寻物资 → 维持生存需求 → 建造和防御 → 技能提升 → 继续生存

## 核心机制

- 生存模拟：饥饿、口渴、疲劳、体温、情绪全面模拟
- 技能系统：通过实践提升各项技能
- 车辆系统：可驾驶、改装和维护的车辆
- 建筑改造：加固和改造建筑作为安全基地
- 永久死亡：角色死亡后从新角色开始

## 为什么好玩

深度模拟带来的真实感。每个决定都有后果，每次出门搜寻都是生死攸关的冒险。"你注定死亡"的设计反而让每次存活都值得骄傲。

## 粘性来源

- 真实模拟的深度：每个系统都细致到令人惊讶
- "你注定死亡"的挑战：每次存活都是成就
- 技能成长的满足感：看到角色从新手变成生存专家
- 自由沙盒：没有固定目标，按自己方式生存

## Meta 系统

无传统 Meta 系统。技能通过实践永久提升（在当前存档中）。多人模式支持合作生存。

## 实现难度

高。大规模开放世界的模拟系统（每个物品的物理属性、NPC AI、生态循环）需要极高的技术能力。
