# 超级泡泡龙（Super Puzzle Bobble）

- **类型**: 三消/弹射
- **平台**: Mobile (iOS+Android) / Web / PC / 多平台
- **开发商**: Taito
- **首次发布**: 2000
- **一句话描述**: 经典泡泡消除游戏，通过调整发射角度将彩色泡泡射向天花板，三个以上同色泡泡相连即可消除

## 玩法规则

游戏画面顶部悬挂着大量彩色泡泡组成的阵列，屏幕底部是玩家控制的泡泡发射器。玩家通过拖拽或滑动调整发射角度，屏幕上会显示一条虚线预判轨迹，帮助瞄准目标位置。发射出的泡泡沿直线飞行，碰到天花板或已有泡泡后会停在接触点。

当三个或更多相同颜色的泡泡在接触点相连时，它们会一起消除并掉落。消除时会产生漂亮的爆破动画和音效反馈，给玩家强烈的正反馈。如果有泡泡因为下方支撑被消除而悬空，它们也会随之掉落，形成连锁反应。

关卡包含多种特殊元素：炸弹泡泡被击中后会消除周围一圈所有泡泡，无视颜色；彩虹泡泡可以与任意颜色匹配；石头泡泡无法被消除，只能通过消除其周围泡泡使其悬空掉落。部分关卡有天花板缓慢下压的机制，迫使玩家在有限步数内完成目标。

玩家需要达成的目标通常有：消除所有泡泡、消除特定数量的指定颜色泡泡、或在限定步数内完成清理。每一步都需要权衡——是直接消除眼前的泡泡，还是先打掉关键支撑点引发连锁反应。

## 核心循环

瞄准发射泡泡 → 消除同色泡泡群 → 触发连锁掉落 → 清理关卡目标 → 解锁下一关

## 核心机制

- **弹道瞄准系统**：玩家通过拖拽控制发射角度，泡泡沿直线飞行并在左右墙壁间反弹。预判轨迹线帮助瞄准，但实际弹道会受到墙壁反弹和已有泡泡的影响，精确计算弹道是核心技巧
- **连锁消除机制**：消除一组泡泡后，与其相连的其他泡泡若失去支撑会自由掉落。一次精妙射击可以触发数十个泡泡的连锁掉落，带来巨大的满足感。连锁规模取决于射击位置的选择
- **特殊泡泡系统**：炸弹泡泡消除周围一圈所有泡泡，彩虹泡泡匹配任意颜色，石头泡泡无法消除只能悬空掉落。这些特殊元素增加了策略维度，合理利用可以事半功倍
- **步数压力机制**：每关有步数限制，天花板缓慢下压增加紧迫感。玩家需要在有限步数内规划最优消除路径，过度浪费步数会导致游戏失败

## 为什么好玩

简单易上手的操作配合精妙的关卡设计，每次射击都充满期待感。当一颗泡泡命中关键位置触发连锁反应、大片泡泡如瀑布般掉落时，视觉和听觉的双重反馈带来极强的满足感。精妙的关卡设计让'差一点就成功'的心理持续驱动玩家再来一次。

## 粘性来源

连锁消除的爽感反馈是核心驱动力——每次触发大规模连锁都会产生强烈的正反馈；关卡逐步推进提供明确的短期目标；精确射击命中后的'好球'体验让人上瘾；'再试一次就能过'的心理驱动形成游戏循环

## Meta 系统

关卡解锁系统——完成当前关卡解锁下一关，形成线性推进；部分版本包含星级评价系统，根据步数使用效率给予1-3星评级；全球排行榜展示通关时间和步数排名；收集系统让玩家解锁新泡泡皮肤和特效

## 实现难度

低 — 核心玩法简单直观，上手门槛极低。最大的技术难点在于物理弹道计算的准确性和碰撞检测的稳定性，以及关卡设计中步数压力与可玩性的平衡
