# 大富翁主题的休闲手游，掷骰子走格子建设地产（MONOPOLY GO!）

- **类型**: 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Scopely
- **首次发布**: 2023
- **一句话描述**: 大富翁主题的休闲手游，掷骰子走格子建设地产

## 玩法规则

玩家掷骰子在棋盘上移动，落在不同格子上触发不同事件。落在空地可以建造建筑（需要金币），落在他人地产上会被收取过路费。

有攻击功能可以破坏其他玩家的建筑。游戏通过掷骰子获得金币和卡片。

卡片收集系统可以完成套装获得奖励。玩家有能量系统限制掷骰子次数。

## 核心循环

掷骰子 → 移动/建建筑/收取过路费 → 收集金币和卡片 → 升级建筑 → 解锁新棋盘

## 核心机制

- 掷骰子移动：随机性决定位置和事件
- 建筑系统：在每个地产上建造和升级建筑
- 攻击机制：可以破坏其他玩家的建筑
- 卡片收集：完成卡片套装获得大量奖励

## 为什么好玩

经典大富翁的简化版，操作更轻松。掷骰子的随机快感和建筑升级的成就感结合。

## 粘性来源

随机奖励的成瘾性；建筑进度的可视化成长；社交竞争（排行榜、攻击他人）；卡片收集的收集欲。

## Meta 系统

建筑升级+卡片收集。玩家通过完成套装和升级建筑解锁新内容。

## 实现难度

低。掷骰子+建设操作极简。最大技术难点：多人交互和经济系统平衡。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
