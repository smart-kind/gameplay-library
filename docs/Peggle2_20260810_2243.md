# Peggle续作，新增更多角色和机制（Peggle 2）

- **类型**: 物理弹射
- **平台**: PC
- **开发商**: PopCap Games
- **首次发布**: 2013
- **一句话描述**: Peggle续作，新增更多角色和机制

## 玩法规则

与一代Peggle相同的核心玩法，新增了更多角色、更多关卡和新的游戏机制（如桶可以改变弹珠方向、传送门等）。

目标仍然是消除所有橙色钉子，但关卡设计更加复杂和有趣。

## 核心循环

瞄准 → 发射弹珠 → 消除橙色钉子 → 过关

## 核心机制

- 新角色和新能力
- 桶和传送门等新机制
- 更多关卡和挑战模式

## 为什么好玩

一代的升级版，更多内容和机制。Extreme Fever的庆祝依然令人上瘾。

## 粘性来源

关卡驱动和挑战模式。

## Meta 系统

关卡解锁。

## 实现难度

低。同Peggle。最大技术难点：物理模拟。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
