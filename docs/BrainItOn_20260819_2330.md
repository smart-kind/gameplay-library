# Brain It On!

- **类型**: 益智解谜 / 物理绘制 / 脑力挑战
- **平台**: Mobile (iOS+Android)
- **开发商**: Orbital Nine Games Inc
- **首次发布**: 2015
- **一句话描述**: 一款通过绘制形状解决物理谜题的游戏，每个谜题看似简单但实际需要精确的物理直觉和创造性思维

## 玩法规则

游戏画面展示一个清晰的物理场景，包含目标元素（如让球落入容器、让两个物体碰撞、打破玻璃等）和场景中的固定物体（墙壁、平台、支架等）。

玩家用手指在屏幕空白区域绘制任意形状——线条、圆形、矩形或不规则图形。绘制完成后，这些形状立即变成具有物理属性的实体：有质量、受重力影响、可以碰撞和旋转。与Touch Physics不同的是，Brain It On的关卡设计更加结构化，每个关卡有明确的最佳解法方向。

屏幕上方显示关卡编号和目标提示（如"让球到达底部"），中央是物理场景，下方可能有重试图标和当前绘制次数。部分关卡限制绘制次数或时间。

玩家绘制后需要观察物理效果——如果形状未能达成目标，可以清除并重新绘制。当场景中的目标条件满足时（如球落入正确位置、物体被推到指定区域），关卡通过。游戏通常要求在一定绘制次数内完成，超过次数则判失败。

## 核心循环

观察物理场景和目标 -> 绘制形状利用重力/碰撞达成目标 -> 验证效果 -> 获得星级评价

## 核心机制

- **物理绘制解谜系统**: 玩家绘制的形状具有真实物理属性，但与Touch Physics不同，Brain It On的谜题更注重"精确性"——需要画出特定形状（如特定角度的斜坡、特定大小的重物）才能解决问题。这要求玩家具备一定的物理直觉
- **关卡星级评价系统**: 每个关卡根据绘制次数和完成效率给予1-3星评价。一星只需要通关，二星需要更少次数，三星需要最优解。这一系统鼓励玩家反复挑战同一关卡以追求完美
- **多样化目标系统**: 关卡目标类型丰富——让物体移动、打破障碍、收集物品、保持平衡、触发机关等。不同目标需要不同的物理策略，保持玩法新鲜感

## 为什么好玩

每个谜题的"顿悟时刻"——当你盯着屏幕看了30秒后突然想到"啊！画个这个就行了！"——这种智力上的"啊哈"体验是游戏最核心的乐趣。绘制后的物理效果验证了你的想法是否正确，正确时的满足感极强

## 粘性来源

具体来说：1）星级追求驱动——即使通关了也想拿到三星，反复尝试最优解法；2）"差点成功"效应——物理效果往往只差毫厘，微调形状就能成功，这种"再试一次"的驱动力极强；3）谜题类型多样化——不同关卡需要不同策略，不会感到重复；4）每日挑战模式（部分版本）持续提供新内容

## Meta 系统

轻度外围系统：通过关卡获得分数/金币，可用于解锁提示功能。提示功能展示部分绘制方案，帮助卡关玩家。部分版本包含用户自定义关卡创作和分享系统

## 实现难度

较高。核心难点在于物理谜题的难度曲线设计——既要让谜题"看起来有解"（否则玩家会放弃），又要让解法不"太明显"（否则没有顿悟乐趣）。技术上最大的难点是物理模拟的精确性和一致性——确保同一解法在不同设备上表现一致

## 关卡设计趋势

游戏关卡通常遵循由浅入深的设计原则：前期关卡（1-50关）主要让玩家熟悉基本操作和规则，圆点种类少、网格小、步数充裕；中期关卡（50-200关）开始引入多目标并行的挑战，如同时消除两种颜色的圆点、在步数限制内达到分数目标等；后期关卡（200关以上）则加入特殊元素——如不可消除的"石头"圆点、会随步数增加而"冻结"的圆点、需要多次消除才能清除的"多层"圆点等，大幅提升策略复杂度。

这种渐进式难度设计确保了玩家在每个阶段都能感受到"略有挑战但可克服"的心流体验，既不会因为太简单而无聊，也不会因为太难而放弃。
