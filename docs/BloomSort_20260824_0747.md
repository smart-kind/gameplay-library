# 花开排序（Bloom Sort）

- **类型**: 排序解谜 / 合并休闲 / 放置装饰
- **平台**: Mobile (iOS + Android)
- **开发商**: Lion Studios Plus
- **首次发布**: 2024
- **一句话描述**: 以花店为主题的休闲排序合并游戏，在平静氛围中完成花朵分类与装饰。

## 玩法规则

游戏画面呈现多个花瓶/容器，每个容器中混装了不同种类和颜色的花朵（或花朵碎片）。玩家的点击操作是选中一个容器中的花朵，然后将其移动到另一个容器中。

核心规则是"同类归集"——只有当目标容器中已有相同种类的花朵时，才能放入。每个容器有容量上限（通常是 4-5 朵同种花）。当一个容器被同一种类的花朵完全填满时，该容器"完成"，花朵转化为装饰元素（如花束、花园景观等），并解锁新的关卡元素。

游戏目标是逐步将所有混装的花朵分类归集到各自的容器中。随着关卡推进，花朵种类增多，容器数量变化，还可能出现特殊花朵需要特定组合。背景播放轻松音乐，整体节奏舒缓。

## 核心循环

选择花朵移动 → 归类到同种容器 → 填满容器获得装饰奖励 → 进入下一关

## 核心机制

- **排序归集机制**：经典"倒水排序"类玩法的变体，将水替换为花朵。每次移动需要思考容器的容量限制和花朵种类的匹配。
- **容量限制机制**：每个容器有上限，迫使玩家在有限空间内做出优先级选择——哪些种类先填满，哪些暂时搁置。
- **视觉奖励机制**：每完成一个容器，花朵转化为美观的装饰（花束/花园），提供强烈的视觉满足感，与游戏的治愈主题一致。

## 为什么好玩

在排序解谜的脑力挑战之上叠加了治愈系的美术和音乐，让紧张的思考过程被舒缓的氛围包裹。每完成一个容器的视觉反馈既是成就感也是一种"创作"——你在逐渐布置一个美丽的花园。

## 粘性来源

排序类玩法天然的"几乎完成"效应——当你看到某个容器只差一朵就满时，强烈的完成欲驱动你继续；关卡难度递进带来持续的认知挑战；装饰收集的可视化进度提供长期目标。

## Meta 系统

轻度装饰收集。完成关卡获得的花束/花园装饰会保留在个人花园中，作为进度展示。对核心玩法无影响。

## 实现难度

低。核心是数组/栈的移动操作+状态检测。最大技术难点在于关卡设计——如何生成既有趣又可解的初始配置，需要确保每关有唯一解或至少可解。
