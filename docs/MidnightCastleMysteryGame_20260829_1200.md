# 午夜城堡（Midnight Castle - Mystery Game）

- **类型**: 寻物冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: BFG Entertainment Inc.
- **首次发布**: 2013
- **一句话描述**: 探索神秘的午夜城堡，在黑暗的通道和诡异的场景中寻找隐藏物品，揭开城堡深处的秘密

## 玩法规则

游戏呈现哥特式暗黑幻想风格的画面，场景包括城堡内部、地下通道、森林、魔法房间等。

玩家需要在场景中找到指定物品列表中的项目，部分物品需要解谜或使用道具后才能获得。

游戏还包含迷你游戏元素：某些关卡需要完成拼图、物品分类、记忆配对等小游戏来获取关键道具。

随着剧情推进，玩家会遇到各种奇幻角色——从贵族到龙和巨魔，每个角色都有自己的故事和任务。

城堡的秘密逐渐被揭开，每个区域的新发现都推动着故事向更深层发展。

## 核心循环

在暗黑场景中寻找隐藏物品 → 完成迷你游戏获取道具 → 解开谜题推进剧情 → 探索新区域

## 核心机制

- 哥特式场景寻物：暗黑奇幻风格的精美场景本身就是一种视觉享受。隐藏物品与环境融为一体增加挑战性
- 迷你游戏系统：拼图、分类、记忆配对等多种小游戏为寻物玩法增加变化
- 角色和剧情线：丰富的奇幻角色网络推动故事发展。每个角色都有背景故事和任务

## 为什么好玩

哥特式暗黑美学营造了独特的冒险氛围，精美的场景细节让人忍不住仔细探索每个角落。

奇幻故事引人入胜。

暗黑美学不仅仅是装饰——它直接影响了寻物的体验，在昏暗的场景中寻找物品需要更敏锐的观察力，这种紧张感是普通寻物游戏无法提供的。

## 粘性来源

剧情悬念驱动持续探索——城堡的秘密是什么？迷你游戏的变化性保持新鲜感

## Meta 系统

角色和道具收集：解锁新角色和魔法道具，部分道具可辅助寻物

## 实现难度

中等 — 暗黑场景增加了寻物难度。最大的技术难点在于在暗黑美学中保持物品的可辨识度
