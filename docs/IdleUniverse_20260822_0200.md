# 放置宇宙（Idle Universe）

- **类型**: 放置/模拟
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2017
- **一句话描述**: 宇宙演化的放置游戏

## 玩法规则

玩家从宇宙大爆炸开始，逐步演化宇宙。初始产生基本粒子，逐渐形成原子、恒星、行星、星系。每个阶段自动进行，玩家通过升级加速演化。解锁新的天体类型和物理现象。随着宇宙演化，可发现新的文明和科技。游戏以宏大的宇宙视角呈现演化过程。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

宇宙演化 → 产生新天体 → 升级加速 → 解锁新阶段 → 继续演化

## 核心机制

- **阶段演化**:  从粒子到星系的渐进演化
- **自动进行**:  宇宙演化自动推进
- **天体解锁**:  逐步解锁新的天体类型

## 为什么好玩

宏大宇宙视角带来的震撼感，见证宇宙诞生的成就感

## 粘性来源

新天体和新文明的解锁期待；宇宙不断扩展的视觉反馈

## Meta 系统

宇宙阶段解锁和天体收集

## 实现难度

中 - 需要多阶段演化和天体系统 - 大规模天体系统的渲染和计算
