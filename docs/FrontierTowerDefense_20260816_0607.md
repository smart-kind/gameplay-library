# 前线塔防（Frontier Tower Defense）

- **类型**: 塔防 / 策略
- **平台**: Mobile (iOS+Android)
- **开发商**: Celadon Wolves（iTunes 匹配）
- **首次发布**: 2012
- **一句话描述**: 在前线阵地布置防御塔，阻止敌军波次的推进

## 玩法规则

游戏画面呈现一张战术地图，上面有从起点到终点的固定路径。玩家在路径两侧的空地上放置防御塔，每种塔有不同的攻击范围和伤害类型。

屏幕下方是塔的选择面板，显示可建造的塔类型、费用和升级状态。屏幕上方显示当前波次、剩余敌人数量和玩家的生命值。

每波敌人从地图起点出发，沿固定路径向终点移动。玩家需要在敌人到达之前用塔的攻击消灭它们。不同类型的塔对付不同类型的敌人效果不同——箭塔速度快伤害低，炮塔伤害高但射速慢，冰冻塔减缓敌人速度。

敌人波次逐渐增加难度，敌人类型从普通步兵到重装坦克不等。如果敌人到达终点，玩家生命值减少。生命值归零则游戏失败。

## 核心循环

查看敌人波次 → 布置/升级防御塔 → 观察战斗 → 获得金币 → 继续下一波

## 核心机制

- **塔位策略**: 有限的空地上选择最优塔位布局，转角处通常是最有效的射击点
- **塔的多样化**: 箭塔、炮塔、冰冻塔、魔法塔等各有专长，需要针对不同敌人组合
- **升级系统**: 用金币升级已有塔的攻击力、射程和特殊效果，而非一味建造新塔
- **波次递增**: 每波敌人数量和强度增加，迫使玩家不断调整策略
- **特殊敌人**: 装甲敌人、快速敌人、飞行敌人需要针对性防御

## 为什么好玩

塔防游戏的核心魅力在于"规划—执行—观察结果"的满足感。看到自己精心布置的防线成功挡住一波波敌人，会产生强烈的成就感。不同塔的组合创造了丰富的策略空间。

## 粘性来源

关卡递增难度和三星评级系统让玩家反复挑战最优解。解锁新塔和新地图提供了长期目标。"如果那一关换个布局会不会更好"的想法驱动玩家不断重玩。

## Meta 系统

金币经济系统：每击杀一个敌人获得金币，金币用于建造和升级塔。通关后获得总金币奖励，可以在全局商店中解锁新塔类型。

## 实现难度

中。需要寻路算法（敌人沿路径移动）、碰撞检测（子弹命中）、波次管理。最大的技术难点是性能优化——后期屏幕上可能有数百个敌人和子弹，需要高效的渲染和物理计算。
