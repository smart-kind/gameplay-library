# Arcade Heaven

- **类型**: 街机合集 / 多模式迷你游戏
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立开发者
- **首次发布**: 2024
- **一句话描述**: 一款包含多个独立街机小游戏的合集应用，每个游戏都有独特的玩法和高分挑战。

## 玩法规则

Arcade Heaven是一个街机游戏合集，包含多个独立的迷你游戏。每个游戏有自己的规则，但都遵循高分驱动的街机哲学。

合集包含多种游戏类型：弹球类游戏中控制挡板反弹球击碎目标，射击类游戏中瞄准射击移动目标，躲避类游戏中在障碍物中穿行，反应类游戏中在正确时机点击，解谜类游戏中在限定步数内完成目标。

统一机制：每个游戏独立计分，高分可以解锁新游戏，总分用于排行榜竞争，部分游戏有连击和倍数系统。

操作方式：每个游戏操作不同，但都设计为1-2个按钮。触屏操作包括点击、滑动、按住。游戏开始前有简短教学。

游戏结束条件各不相同：生命值耗尽、时间用完、目标达成等。结束后显示分数和评级。

## 核心循环

选择游戏 → 挑战高分 → 失败或成功 → 查看分数 → 选择下一个游戏

## 核心机制

- **多游戏合集架构**: 将多个独立小游戏打包成一个应用，玩家可以在不同游戏间切换。这种设计优势是内容丰富度高。一个游戏玩腻了可以换另一个。统一的高分系统让不同游戏之间有比较价值。合集形式也降低了单个游戏的设计压力。

- **极简操作设计**: 每个游戏都设计为1-2个按钮操作，确保即时可玩性。不需要教程也能上手，但精通需要练习。简单操作加深精通的设计是街机游戏的黄金法则。

- **解锁驱动**: 高分解锁新游戏，形成目标链。玩家不只是玩游戏，还在解锁游戏。这种设计将游戏内容本身变成了奖励，增加了长期目标。

## 为什么好玩

一个应用里包含多种不同类型的街机游戏，永远不会无聊。每个游戏都有独特的挑战方式，从反应速度到策略规划，满足不同心情。适合不知道玩什么的时候打开随便挑一个。

## 粘性来源

多游戏的多样性加上高分解锁的目标感和排行榜的竞争欲，构成合集类游戏的粘性。玩家总有一个正在攻克的游戏。成就系统提供额外目标。

## Meta 系统

游戏解锁系统：高分解锁新游戏。总分排行榜：跨游戏的综合排名。成就系统：特定条件下的挑战目标。

## 实现难度

中。需要开发多个独立游戏，每个都有自己的逻辑和美术。合集架构的管理和更新有一定复杂度。单个游戏实现难度低，但数量多了总工作量不小。
