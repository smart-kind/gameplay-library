# Infinity Loop (无限循环)

- **类型**: 休闲益智 / 逻辑连线
- **平台**: Mobile (iOS+Android)
- **开发商**: INFINITY GAMES, LDA
- **首次发布**: 2017
- **一句话描述**: 一款极简风格的逻辑解谜游戏，通过旋转管道片段形成封闭循环

## 玩法规则

游戏界面是一个点阵网格，每个点上有一个弯曲的管道片段。这些片段需要被旋转，使它们连接形成封闭的循环回路。

操作：点击管道片段，每次点击旋转90度。旋转后观察管道两端的连接情况，如果相邻管道端口对齐，它们会发光显示已连接。目标是让所有管道都连接上，没有断开的端口。

游戏有多个难度等级：简单（小网格、少量管道）、中等、困难（大网格、复杂布局）。部分特殊管道有3个或4个端口，增加连接复杂度。

游戏目标是完成当前关卡的所有管道连接。没有时间限制，无限关卡。每完成一局，系统自动生成一个新的布局。连续完成获得连击计数。

某些特殊关卡引入了固定管道（不可旋转的锚点），这些管道作为连接的起点和约束条件，大幅增加了推理的路径数量。玩家需要从锚点出发，逐步推导每个管道应有的旋转角度。

## 核心循环

旋转管道片段使其对齐 -> 所有管道连通形成闭环 -> 系统生成新关卡

## 核心机制

- **闭环连接**：所有管道必须形成封闭回路，提供明确的成功标准
- **无限关卡生成**：每局自动生成新布局，永不重复
- **多端口管道**：3到4端口的特殊管道增加连接复杂度，提升思维挑战
- **固定锚点管道**：不可旋转的锚点作为连接约束条件，增加推理路径数量

## 为什么好玩

当所有管道突然连通发光的那一刻，大脑获得顿悟快感。无限关卡让人停不下来。

## 粘性来源

闭环连通的顿悟快感，无限关卡的永不重复，连击计数。简单操作让人随时可以玩一局。

## Meta 系统

无外围系统。纯无限关卡生成，没有等级、货币或收集元素。极简设计是其核心特色。

## 实现难度

低 -- 管道旋转连接的核心机制极其简单。最大技术难点是无限关卡的算法生成，确保每局有唯一解。
