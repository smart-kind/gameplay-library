# Beejumbled

- **类型**: 三消 / 休闲益智
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款以蜜蜂为主题的消除游戏，玩家通过连接相同颜色的花朵来帮助蜜蜂采集花蜜

## 玩法规则

游戏棋盘由不同颜色的花朵方块组成，排列成6x6或更大的网格。每种颜色代表一种花蜜类型，蜜蜂会根据消除的花蜜类型飞向对应位置采集。

玩家用手指在屏幕上滑动，连接相同颜色的相邻花朵（水平或垂直相邻）。连接的花朵被消除，蜜蜂飞到对应位置采集花蜜。连接的方块越多，获得的分数和花蜜量越高，连锁反应范围越大。

消除后上方方块会下落填补空缺，新的花朵方块从顶部随机生成。部分关卡设有特殊方块：锁定方块需要先消除相邻方块解锁，炸弹方块消除后清除周围3x3区域，彩虹方块消除后清除所有同色方块。

每关有目标分数或特定花蜜收集量。在限定步数内完成目标即过关。部分关卡有障碍物（石头、藤蔓）阻挡路径，需要额外消除才能清理。

游戏中设有蜂蜜收集系统，每关收集的蜂蜜可用于解锁特殊蜜蜂皮肤和棋盘主题。连续消除5个以上方块时，会出现蝴蝶特效。

## 核心循环

连接相同颜色花朵消除 → 收集花蜜获得分数 → 完成关卡目标

## 核心机制

- **连锁消除**：消除后新方块可能自动形成新的连线，产生连锁反应获得额外分数
- **特殊方块**：炸弹方块提供大范围清除能力，关键时刻改变局面
- **步数限制**：限定操作次数，需要规划最优消除路径

- **蝴蝶特效**：消除大量方块时出现蝴蝶动画，提供额外的视觉反馈和分数加成


## 为什么好玩

经典三消玩法加入蜜蜂主题让操作更有目的性——不是在消除方块，而是在帮助蜜蜂采蜜。连锁反应的爽快感是核心体验。

## 粘性来源

三消游戏的标准粘性模型：随机方块生成带来变化性，连锁反应提供即时正反馈，逐步解锁的关卡提供进度感。

## Meta 系统

无复杂外围系统。主要通过关卡进度和分数排行提供目标。

## 实现难度

低 — 三消玩法上手简单。最大技术难点是流畅的消除动画和下落物理。
