# Tower Bloxx

- **类型**: 物理堆叠 / 解谜
- **平台**: Mobile (iOS+Android) / Feature Phone
- **开发商**: Digital Chocolate
- **首次发布**: 2005
- **一句话描述**: 一款以建造摩天大楼为核心的堆叠益智游戏，玩家需要在摇晃的吊车下精准释放楼层，将其准确叠放在已有建筑顶部。

## 玩法规则

游戏画面中央有一座正在建造中的大楼。每一轮，一块新的楼层从画面上方的吊钩上悬挂着，像钟摆一样左右摇晃。玩家需要选择一个时机点击屏幕释放楼层，使其垂直下落。

楼层下落的位置完全取决于释放时机。如果楼层精准落在已有建筑的顶部中心，建筑会完美加高一层，获得最高分。如果偏离中心，楼层会部分悬空，建筑开始倾斜。

随着楼层越堆越高，吊车摆动的速度和幅度可能增加，增加了判断难度。已堆好的建筑如果有悬空楼层，整体重心会偏移，后续楼层需要补偿这种偏移。

游戏结束条件：建筑倾斜角度超过临界值而倒塌。玩家的目标是在倒塌前堆出尽可能高的摩天大楼。

游戏设有完美堆叠（Perfect）判定，当楼层中心对齐时触发，连续完美堆叠获得额外加分。

## 核心循环

等待时机 → 释放楼层 → 评估结果 → 下一块楼层难度增加 → 建筑越来越高

## 核心机制

- 钟摆定时释放：楼层像钟摆一样摆动，玩家需要判断最佳释放时机。这是游戏的核心机制，简单但考验节奏感和空间直觉。
- 物理重心模拟：每块楼层的偏移都会影响建筑的整体重心。偏离中心会导致建筑倾斜，后续楼层必须补偿重心偏移，否则最终倒塌。这种物理反馈让每次失误都有累积后果。
- 完美堆叠连击：精准居中放置触发'Perfect'判定并连击加分，鼓励玩家追求精度而不仅仅是速度。

## 为什么好玩

每次释放楼层的紧张感是核心体验——看着楼层缓缓下落，'到底能不能放准'的悬念在落地瞬间释放。完美堆叠的爽快感和建筑逐渐倾斜的危机感交替出现，形成强烈的情绪波动。

## 粘性来源

'差一点就完美'的不甘心是最大粘性来源。每次倒塌都让人觉得'下次我一定能更高'，一局只需1-3分钟，非常适合碎片时间反复尝试。

## Meta 系统

无。游戏没有外围成长系统。

## 实现难度

低。最大技术难点在于物理重心模拟的真实感——倾斜角度、重心偏移和倒塌判定需要让玩家感觉'合理'而非'随机'。
