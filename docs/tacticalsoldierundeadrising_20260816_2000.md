# 战术士兵：不死崛起（Tactical Soldier: Undead Rising）

- **类型**: 策略塔防 / 射击
- **平台**: Nintendo 3DS
- **开发商**: 独立开发者
- **首次发布**: 2011
- **一句话描述**: 在僵尸末日的背景下指挥小队进行战术防御的策略游戏

## 玩法规则

玩家在网格地图上部署士兵小队（步枪手、狙击手、机枪手、医疗兵、工程兵等），每类士兵有独特的攻击方式、射程和属性。僵尸从地图边缘的固定路径涌来，玩家需要利用地形和士兵的协同来阻挡它们。游戏采用3DS双屏设计：上屏显示战场全景，下屏显示士兵详细状态、操作界面和可用资源。

每波攻击结束后获得资源，用于招募新士兵、升级武器、建造防御工事（路障减速僵尸、铁丝网困敌、炮塔自动攻击、地雷区域伤害）。士兵可以手动瞄准特定目标，也可以设置为自动攻击最近敌人。医疗兵可以治疗受伤的士兵，工程兵可以修理防御工事。

僵尸有多种类型：普通行尸（慢速/低血量）、奔跑者（快速/低血量）、坦克僵尸（慢速/超高血量/能破坏防御工事）、喷吐者（远程攻击/降低士兵视野）。波次之间有时间窗口，玩家需要快速决定是补充兵力还是升级工事。某些关卡有特殊目标：保护幸存者撤离、在特定时间内守住关键建筑、护送车辆通过等。

## 核心循环

部署士兵和防御工事 → 抵御僵尸波次 → 获得资源 → 升级和补充兵力 → 进入下一波

## 核心机制

- **兵种协同与定位系统**：不同兵种有独特作用：狙击手(远距离/单体高伤/需要保护)、机枪手(近距离/AOE/弹药消耗快)、步枪手(中距离/均衡)、医疗兵(治疗/无攻击)、工程兵(修工事/建造)。合理的兵种搭配和站位是防守成功的关键
- **波次递进与僵尸多样性**：每波僵尸数量、种类、速度递增。前期只有普通行尸，中期出现奔跑者和坦克僵尸，后期加入喷吐者和集群攻击。特殊僵尸需要特定兵种应对——坦克僵尸需要集中火力或地雷阵
- **防御工事多层体系**：路障(减速30%)、铁丝网(困住僵尸使其停滞)、炮塔(自动攻击/需要工程兵维护)、地雷(区域伤害/一次性)。多层防线叠加效果显著，但每层都有成本和维护需求


## 为什么好玩

塔防+射击策略的经典组合，僵尸题材增加紧张感和氛围。合理布置防线后看着僵尸被层层消灭——路障减速、铁丝网困住、机枪扫射、狙击手点名——的爽快感极强。

## 粘性来源

波次递进+士兵升级系统驱动反复挑战。解锁新兵种（如火箭筒手、火焰喷射手）和防御工事（如电网、冰冻陷阱）的成就感维持长期游玩。高难度模式提供极限挑战。

## Meta 系统

士兵等级和技能树系统——士兵通过战斗获得经验升级，解锁更强武器（步枪→自动步枪→突击步枪）、特殊技能（狙击手的穿甲弹、机枪手的压制射击）。将军/指挥官系统提供全局加成。对核心玩法有显著影响。

## 实现难度

中 —— 需要策略规划（兵种搭配/工事布局/资源分配）和实时操作（手动瞄准/紧急调兵），最大技术难点是大量单位（士兵+僵尸）的AI计算和波次难度曲线设计，确保既不过于简单也不令人绝望。
