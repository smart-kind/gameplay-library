# 微型矿工（Micro Miners）

- **类型**: 策略 / 塔防 / 挖矿
- **平台**: Mobile (iOS + Android)
- **开发商**: Gamelion
- **首次发布**: 2012
- **一句话描述**: 在地下矿洞中挖掘矿石、建立防御塔抵御外星生物入侵的策略游戏

## 玩法规则

游戏画面呈现地下洞穴的俯视角场景，玩家操控矿工在地层中挖掘矿石。洞穴由不同材质的方块组成（泥土、石头、铁矿、金矿等），每种材质有不同的挖掘时间和价值。

玩家点击方块让矿工前往挖掘，挖出的矿石转化为金币，用于建造防御塔保护矿区。外星生物会从洞穴的特定入口不断涌出，试图破坏矿工的采集工作。玩家需要在地层中合理布置防御塔（机枪塔、炮塔、冰冻塔等）来抵御这些入侵者。

操作方式：点击矿石方块进行挖掘、点击空地建造防御塔、拖拽矿工到不同位置。矿工会自动移动到目标位置并持续挖掘，玩家需要同时管理挖掘方向和防御布局。

游戏目标是在一波波外星生物的攻击下保护矿工安全，同时尽可能多地采集珍贵矿石来升级防御系统。如果所有矿工被消灭，游戏结束。

## 核心循环

挖掘矿石 → 获得金币 → 建造防御塔 → 抵御入侵 → 挖掘更深层矿石 → 升级装备

## 核心机制

- **挖矿经济系统**：不同矿石有不同价值（泥土便宜、铁矿中等、金矿和钻石稀有昂贵），引导玩家规划挖掘路线优先高价值矿脉
- **塔防防御系统**：多种防御塔各有特色——机枪射速快、炮塔范围伤害、冰冻减速敌人，需要组合使用应对不同敌人
- **矿工管理**：可以同时拥有多个矿工，分配到不同矿脉同时开采，但需要注意安全区域，避免矿工在危险区域被敌人击杀
- **波次敌人设计**：敌人一波比一波更强，包括小型快速怪、大型重甲怪和飞行单位，考验防御塔的合理搭配

## 为什么好玩

挖矿的收集欲和塔防的策略性完美结合——挖到稀有矿石的惊喜感和成功抵御敌人进攻的成就感交替出现。地下洞穴的未知探索让人充满好奇心。

## 粘性来源

稀有矿石的收集欲（"再挖一层说不定有钻石"）、防御塔升级带来的成长感、不同敌人波次的策略挑战。"差一点就守住"的不甘心驱动反复尝试。

## Meta 系统

升级系统：用累积金币升级矿工挖掘速度、防御塔威力和生命值、解锁新塔类型。升级效果在后续游戏中持续有效，提供长期成长感。

## 实现难度

中等。需要实现网格化地图系统、路径寻找（矿工移动和敌人进攻路线）、塔防战斗模拟和资源经济系统。最大技术难点是多单位同时行动的性能优化和寻路算法效率。
