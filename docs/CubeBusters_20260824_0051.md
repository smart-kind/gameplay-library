# Cube Busters

- **类型**: 解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Spyke Games
- **首次发布**: 2025
- **一句话描述**: 一款解谜类移动游戏，由Spyke Games开发

## 玩法规则

玩家在手机上通过点击、拖拽或滑动进行操作。游戏界面展示游戏核心元素，如棋盘、角色或叙事场景。

每个回合/操作中，玩家根据当前局势做出决策。操作产生即时反馈——消除方块、获得资源、推进剧情或击败敌人。

游戏目标因模式而异：在解谜模式中清空棋盘或达成特定条件；在放置模式中最大化资源产出和升级进度；在侦探模式中收集足够线索破解案件。

游戏通过关卡递进、难度曲线或叙事章节推进。失败条件包括棋盘空间耗尽、资源不足或做出错误的推理选择。

## 核心循环

解谜核心循环：执行操作 → 获得资源/推进 → 升级/解锁 → 挑战更高难度

## 核心机制

- **方块/瓷砖解谜 (Block/Tile Puzzle)**: 将不同形状的方块/瓷砖放置在网格中，填满整行或整列后消除。需要预判形状序列和空间利用。
- **合并消除 (Merge)**: 核心玩法机制。
- **排行榜/锦标赛 (Leaderboard/Tournament)**: 核心玩法机制。
- **离线休闲 (Offline/Zen)**: 简单易上手的操作，适合碎片化时间游玩。

## 为什么好玩

该游戏在App Store获得4.8/5.0的用户评分，适合4+及以上年龄玩家。游戏通过精心设计的解谜机制和流畅的操作反馈，提供了令人满足的游戏体验。

## 粘性来源

粘性主要来自解谜核心循环的"再来一次"驱动力：解谜游戏中消除的爽感和连锁反应、放置游戏中数值成长的满足感、或侦探游戏中揭开真相的好奇心驱动。每次操作都有明确的正向反馈，让玩家持续投入。

## Meta 系统

解谜外围系统：通过升级、解锁和收集元素提供长期目标。玩家通过积累游戏内货币或资源，解锁新内容、提升基础属性或获得永久加成。

## 实现难度

中。解谜机制在移动端有成熟的实现模式。主要技术难点在于关卡生成的平衡性和趣味性。
