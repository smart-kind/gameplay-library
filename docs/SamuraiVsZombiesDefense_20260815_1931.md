# Samurai vs Zombies Defense

- **类型**: 塔防 / 动作 / 策略
- **平台**: Mobile (iOS + Android)
- **开发商**: Glu Games
- **首次发布**: 2010
- **一句话描述**: 扮演日本武士，在村庄周围布置防御工事，亲自上阵砍杀一波波来袭的僵尸。

## 玩法规则

游戏采用俯视角画面，中央是玩家保护的村庄，四周有若干条路径通向村庄。僵尸从屏幕边缘沿路径向村庄移动。

玩家有两种操作模式：

**防御布置模式**：
- 点击路径旁的空地，放置防御设施（箭塔、陷阱、路障等）。
- 每种防御设施有不同的功能和成本，需要合理分配资源。
- 防御设施会自动攻击经过的僵尸。

**战斗模式**：
- 玩家直接操控武士在战场上移动。
- **虚拟摇杆**：控制武士移动方向。
- **攻击按钮**：挥刀攻击靠近的僵尸。武士有连击系统，连续攻击伤害递增。
- **特殊技能按钮**：消耗能量释放范围攻击（如旋风斩、飞镖雨等）。
- 武士可以收集僵尸掉落的金币和道具。

每波僵尸有不同的数量和种类（普通僵尸、快速僵尸、重装僵尸等）。全部波次防御成功即过关。如果僵尸到达村庄并摧毁了村庄的核心，则游戏失败。

## 核心循环

布置防御 → 参与战斗 → 获得金币 → 升级防御和技能 → 面对更强的波次

## 核心机制

- **双模式玩法**：这是游戏最大的特色——既有传统塔防的策略布置，又有动作游戏的亲身战斗。玩家可以在两种模式间切换，灵活应对战局。
- **金币经济**：金币用于购买新防御、升级已有设施、解锁武士技能。金币来源包括战斗中获得和波次间固定收入。
- **技能树/升级系统**：武士和防御设施都可以升级，提升攻击力、范围、耐久等属性。
- **僵尸类型多样性**：不同僵尸有不同的速度和防御力，需要针对性的防御策略。

## 为什么好玩

Samurai vs Zombies Defense 的独特之处在于"你不仅是指挥官，还是战士"。传统塔防游戏中你只能旁观防御设施自动战斗，而这里你可以亲自下场砍僵尸，体验从策略家到武士的双重角色。亲手斩杀一波僵尸的爽快感，加上策略布置的成就感，创造了混合类型的独特乐趣。

## 粘性来源

- **角色成长**：武士的等级、技能、装备逐步提升，驱动玩家持续游玩。
- **防御升级**：解锁和升级更多防御设施，增加策略深度。
- **波次递增难度**：每波僵尸更多更强，需要不断优化防御策略。

## Meta 系统

- **角色升级**：武士通过击杀获得经验，升级后提升基础属性并解锁新技能。
- **防御设施解锁**：随着进度解锁更多类型的防御塔和陷阱。
- **装备系统**：可以装备不同的武器和盔甲，影响武士的战斗力。

## 实现难度

**中高** — 需要同时实现塔防AI和动作战斗两套系统，并确保它们无缝衔接。最大技术难点在于同屏大量单位（僵尸+防御设施+玩家角色）的碰撞检测和性能优化。
