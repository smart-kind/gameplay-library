# ProgressBar95 - retro arcade

- **类型**: 休闲/街机
- **平台**: Mobile (iOS+Android) / PC (Steam)
- **开发商**: Spooky House Studios UG
- **首次发布**: 2019
- **一句话描述**: 致敬 Windows 95 时代的怀旧进度条填充小游戏合集

## 玩法规则

ProgressBar95 将经典的 Windows 95 进度条界面转化为一系列有趣的迷你游戏。玩家的核心操作是通过触摸/点击/拖拽来填充进度条，每个关卡对应不同的操作系统元素（启动画面、文件复制、磁盘扫描等）。

画面采用完整的复古 Windows 95 视觉风格——灰色窗口、像素图标、经典字体和配色方案。每个游戏模式都有独特的进度条交互方式：有的需要快速点击，有的需要精准拖拽，有的需要躲避障碍物来保护进度条不被中断。

游戏的核心目标是尽快将进度条填充至 100%。填充过程中会遇到各种干扰——弹窗广告、系统错误提示、恶意软件等——玩家需要及时处理这些障碍才能顺利完成进度。

不同关卡引入新机制：BSOD（蓝屏死机）需要快速点击跳过、弹窗轰炸需要逐个关闭、磁盘碎片需要重新排列等。每次成功完成进度条都会获得积分和解锁新的游戏模式。

## 核心循环

选择游戏模式 → 通过特定操作填充进度条 → 处理中途干扰障碍 → 完成进度获得积分 → 解锁新关卡/皮肤

## 核心机制

- 进度条填充机制：每种模式有独特的填充方式（点击、拖拽、躲避），操作手感各异但都简单直观
- 干扰障碍系统：弹窗、错误提示、病毒等障碍模拟真实电脑使用体验，增加紧张感和策略维度
- 怀旧主题贯穿：所有视觉元素、音效和关卡设计都围绕 Windows 95 的复古美学展开

## 为什么好玩

将枯燥的"等待进度条加载"转化为主动参与的趣味体验本身就是极大的创意亮点。复古的 Windows 95 视觉风格对经历过那个时代的玩家是情怀暴击，对年轻玩家则是新鲜有趣的复古体验。

## 粘性来源

"再玩一关就好"的关卡制天然成瘾性，加上收集系统（解锁不同操作系统主题的进度条皮肤——从 Win3.1 到 WinXP 到 macOS），让重复游玩有了明确目标。每个新皮肤都改变了视觉主题，保持新鲜感。

## Meta 系统

皮肤解锁系统：完成特定关卡或达到分数里程碑可解锁不同操作系统的进度条主题（Windows 3.1/95/98/XP/Vista/7、macOS Classic 等）。每种皮肤改变整体视觉风格但不影响核心玩法，纯粹为收藏和审美享受。

## 实现难度

低 + 核心逻辑是进度条填充+简单障碍处理，技术实现直接。最大难点在于复古美术风格的精确还原和大量关卡/皮肤的内容设计工作量，而非技术复杂度。
