# 克伦克射击（Krunker.io）

- **类型**: 第一人称射击 (FPS)
- **平台**: Web (浏览器)
- **开发商**: Sidney de Vries
- **首次发布**: 2018
- **一句话描述**: 像素风格的网页FPS，支持多人对战，无需下载即开即玩

## 玩法规则

游戏采用第一人称视角，像素化的方块风格画面。玩家进入后自动匹配到多人对战房间（通常8-16人）。

操作是标准FPS：WASD移动，鼠标瞄准和射击，空格跳跃，数字键切换武器。支持滑铲（滑行）和快速转身，是高手的核心操作。

游戏有多种模式：自由对战（FFA）、团队死斗、夺旗、抢占要点等。每种模式有不同的胜利条件。

每个玩家开局选择一种职业（狙击手、突击兵、侦察兵等），不同职业有不同的武器和移动速度。狙击手移动慢但一枪致命，突击兵射速快但伤害低。

击杀敌人获得积分和武器升级。连续击杀可以解锁更强武器。游戏结束后根据积分结算，获得KR币用于购买武器皮肤和箱子。

## 核心循环

进入匹配 → 击杀敌人获得积分 → 结算获得KR币 → 购买外观 → 继续匹配

## 核心机制

- **滑铲射击**：按下特定键可以进入滑行状态，滑行中仍然可以射击。这是核心移动技巧，高手可以在滑行中精准瞄准，让对手难以命中。
- **职业差异化**：不同职业有不同的移动速度和武器。狙击手慢但致命，突击兵快但需要多发命中。玩家需要在不同职业间切换适应。
- **开箱系统**：用KR币购买箱子，随机获得武器皮肤。有稀有度分级，稀有皮肤有交易价值。

## 为什么好玩

浏览器即开即玩的便利性是最大卖点——不需要下载几十GB的游戏，打开网页就能打。像素风格降低了硬件要求，但射击手感并不差。滑铲射击的爽快感让人上瘾。

## 粘性来源

- **即开即玩**：零下载门槛，随时来一局
- **皮肤收集**：开箱系统驱动持续游玩
- **竞技成长**：从菜鸟到能熟练滑铲射击，进步感明显
- **社区地图**：玩家可以创建自定义地图

## Meta 系统

- **KR币经济**：击杀获得KR币，用于购买箱子、皮肤
- **开箱系统**：随机开出不同稀有度的武器皮肤
- **等级系统**：累积经验升级，解锁新职业

## 实现难度

中。WebGL/Three.js可以实现3D FPS，但网络同步是最大难点。多人FPS需要低延迟的服务器架构，这在纯网页环境下挑战更大。最大的技术难点是网络延迟补偿——需要在浏览器中实现预测和回滚机制来保证射击手感。
