# 放置废车场大亨（Idle Scrapyard Tycoon）

- **类型**: 放置经营 / 制造
- **平台**: Mobile (iOS+Android)
- **开发商**: IsCool Entertainment
- **首次发布**: 2021
- **一句话描述**: 管理废车场，回收汽车零件，制作物品赚取利润。

## 玩法规则

汽车被送到停车场，起重机将汽车移动到拆解区，工人从汽车上拆除零件。

零件被送到粉碎机和仓库。

玩家可以解锁制作工作台（如轮胎工作台），购买蓝图来制作不同物品。

需要完成客户订单，管理仓库空间，扩大废车场规模。

## 核心循环

接收汽车拆解零件 -> 制作物品 -> 完成客户订单赚取利润 -> 扩建废车场

## 核心机制

- **拆解流水线**：汽车到达后起重机移动、工人拆零件、粉碎入库，形成自动化流水线
- **制作系统**：购买蓝图，在工作台制作轮胎、玻璃、导航仪等物品
- **订单系统**：客户订单驱动生产目标，完成订单获得奖励
- **仓库管理**：需要管理仓库空间，合理安排零件存储

## 为什么好玩

拆解汽车的爽快感加上制作系统的策略性，变废为宝的满足感。

## 粘性来源

流水线自动化带来的满足感 + 制作系统的多样性 + 订单完成的目标驱动。

## Meta 系统

废车场扩展系统。解锁新的工作台和区域，提高生产效率和产品种类。

## 实现难度

中 - 需要设计拆解流水线、制作系统、订单系统的三层架构。最大技术难点：流水线可视化效果和制作系统的复杂度平衡。
