# 折磨大厅（Halls of Torment: Premium）

- **类型**: Roguelike / 弹幕射击 / 吸血鬼幸存者like
- **平台**: Mobile (iOS+Android) / PC / Switch / PS5 / Xbox
- **开发商**: Chasing Carrots（移动端由 Erabit Studios 移植）
- **首次发布**: 2024（正式版）
- **一句话描述**: 暗黑风格的吸血鬼幸存者类游戏——在成群的恶魔中存活，用自动攻击和被动升级碾压一切

## 玩法规则

游戏画面为俯视角的暗黑奇幻地牢场景，采用像素美术风格。画面整体偏暗，以棕褐色调为主，营造出压抑而复古的地下城氛围。

玩家控制一个角色在地牢地图中移动。攻击是自动的——角色会根据当前装备的武器自动攻击范围内的敌人。玩家只需要控制移动方向，躲避敌人弹幕，拾取经验宝石，选择升级选项。

敌人从四面八方涌来，数量随时间增加。每种敌人有独特的攻击模式：近战怪会追逐你，远程怪会发射弹幕，Boss 有复杂的攻击套路。玩家需要在移动中走位，避开敌人的攻击，同时让自动武器尽可能多地消灭敌人。

每升一级会出现 3 个升级选项供选择：新武器、现有武器升级、被动加成（增加生命、速度、攻击范围等）。某些升级组合会产生"协同效应"——例如火焰武器 + 燃烧范围加成 = 更大的火焰伤害区域。

游戏的目标是在每一波敌潮中存活尽可能长的时间。某些模式有明确的波数目标，存活到最终波次后击败 Boss 即可通关。

## 核心循环

杀怪获得经验 → 升级选择新能力 → 能力增强杀更多怪 → 存活更久/击败Boss

## 核心机制

- **自动攻击系统**：玩家不需要手动攻击，武器自动寻找并攻击敌人。这使得游戏的核心挑战从"操作精度"转移到"位置选择"——你站的位置决定了你能打多少怪、能躲多少攻击。
- **升级协同效应**：武器和被动升级之间存在 synergies。例如，某个武器升级后改变攻击模式（从单体变为范围），搭配另一个被动升级可以进一步扩大范围。发现和利用这些组合是高分的关键。
- **暗黑像素美术风格**：游戏刻意采用了类似 Diablo 初代的暗黑像素风格——阴暗的地牢、扭曲的怪物、血腥的战斗效果。这在同类游戏中独树一帜，大多数吸血鬼幸存者类游戏都走可爱或科幻路线。
- **多角色解锁**：通关后解锁新角色，每个角色有独特的起始武器和被动技能。不同角色的玩法风格完全不同——有的偏近战爆发，有的偏远程风筝。
- **波次系统**：敌人按波次刷新，每波有特定的敌人组合和 Boss。了解每波的敌人构成可以提前规划走位和升级路线。

## 为什么好玩

Halls of Torment 把"割草"的爽感和暗黑奇幻的压抑氛围完美结合。看着成群的恶魔被你的火焰、闪电和剑刃碾碎，配合沉重的金属配乐和血腥的像素画面，形成了一种独特的暴力美学。不同于同类游戏的轻松卡通风格，这款游戏认真对待它的暗黑主题。

## 粘性来源

"下一次升级组合会更好"的期待感。每局游戏都是新的随机升级体验，不会重复。多角色解锁和不同武器组合提供了极高的重玩价值。暗黑像素风格和金属配乐形成了独特的辨识度，同类游戏中少有竞争者。

## Meta 系统

- **角色解锁**：完成特定条件解锁新角色，每个角色有独特的武器和被动技能。
- **成就系统**：完成各种挑战（如"不用特定武器通关"）获得成就。
- **难度递进**：通关后解锁更高难度模式，敌人更强，奖励更丰厚。

## 实现难度

低到中等。自动攻击、碰撞检测、弹幕运动都是成熟的 2D 游戏技术。最大的技术难点在于性能优化——当屏幕上同时存在数百个敌人和弹幕时，保持流畅的帧率。这需要高效的对象池管理和渲染优化。
