# Bejeweled Blitz（Bejeweled Blitz）

- **类型**: 三消/休闲益智
- **平台**: Mobile (iOS+Android) / Web (Facebook)
- **开发商**: PopCap Games / Electronic Arts
- **首次发布**: 2010
- **一句话描述**: Bejeweled系列的快节奏版本，玩家在一分钟内尽可能多地进行宝石匹配，追求高分。

## 玩法规则

游戏界面是一个8×8的棋盘，布满各种颜色和形状的宝石（钻石、火球、星形等）。玩家通过交换相邻两个宝石的位置来创建三个或更多相同宝石的连线。成功匹配后，宝石消除，上方宝石下落填充空位，新的宝石从顶部补充。

与经典Bejeweled不同，Blitz模式不限制步数，而是限制时间（通常为60秒）。玩家在限定时间内尽可能多地匹配宝石。每次匹配获得基础分数，连续匹配（Cascades）产生额外加分。特殊宝石包括火焰宝石（消除整行/整列）、星爆宝石（消除周围区域）、超新星宝石（消除全屏同色宝石）。

## 核心循环

匹配宝石 → 获得分数和特殊宝石 → 利用特殊宝石产生连锁反应 → 在时限内最大化分数

## 核心机制

- **匹配交换**：交换相邻宝石创建三消或更多，四消产生火焰宝石（十字消除），五消产生超新星（消除同色），L/T型消除产生星爆宝石
- **连锁反应(Cascades)**：消除后宝石下落可能自动触发新的匹配，连锁消除获得指数加分
- **限时竞速**：60秒倒计时制造紧迫感，匹配成功可增加额外时间（通常+1秒），鼓励连续操作
- **特殊宝石**：通过特定匹配模式产生，具有强大的范围消除能力，是高分的关键

## 为什么好玩

一分钟的快节奏对局让游戏随时可以开始和结束，完美适配碎片时间。"差几秒就破纪录"的不甘心感极强——每次游戏结束后看到差一点就刷新个人最佳分数，让人忍不住立即再开一局。连锁消除带来的视觉冲击和分数爆炸提供即时的爽快感。

## 粘性来源

限时竞速模式的核心粘性在于"再试一次就能破纪录"的心理——60秒的短对局让每次失败的成本极低，而高分排行榜和个人最佳分数的追踪创造了持续超越自我的驱动力。特殊宝石产生的连锁爆炸提供强烈的视觉和分数反馈，每次游戏都在追求"更大规模的连锁反应"。

## Meta 系统

- **个人最佳分数**：追踪历史记录，鼓励自我超越
- **成就系统**：完成特定挑战解锁成就（如单次消除N个宝石、达成特定分数等）
- **每周挑战**：限时活动和排行榜竞争
- **每日任务**：完成日常目标获得奖励

## 实现难度

低 — 三消逻辑是成熟的算法（棋盘检测、重力下落、新宝石生成）。最大技术难点在于连锁反应的检测效率和特殊宝石的逻辑处理，但现有游戏引擎已有成熟的解决方案。
