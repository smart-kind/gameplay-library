# 外星蜂巢 (Alien Hive)

- **类型**: 三消/进化益智
- **平台**: Mobile (iOS+Android)
- **开发商**: 未明确标注
- **首次发布**: 未明确标注
- **一句话描述**: 一款受Triple Town启发的进化式三消游戏，目标是培育并进化外星生物

## 玩法规则

游戏遵循与Triple Town相似的进化消除逻辑，但将目标从建造城镇转变为进化外星种族。

棋盘上分布着各种元素：基础物质团块、晶体、植物，以及捣乱的机器人。玩家的目标是将三个相同的元素匹配，它们会合并进化成一个更高级的元素。

最终目标是形成外星生物发展的各个阶段——从基础物质团块一直进化到完全体的最高级外星生物。

匹配操作方式与传统的交换消除不同：棋盘上始终只有一个空格，玩家需要选择一个元素并将其移动到空格中。如果移动后形成了三个相同元素相邻的排列，它们就会合并进化。

这种空格移动的机制比传统的交换更具挑战性——玩家不仅要思考匹配什么，还要思考如何创造移动空间。

晶体和植物匹配可以获得额外回合（初始100回合）。机器人则是捣蛋鬼——它们会占据棋盘空间，增加匹配难度。

随着关卡推进，晶体块的数量逐渐减少，使得补充回合变得更加困难。同时，机器人的数量逐渐增加，当屏幕上出现两个以上机器人时，棋盘会变得非常拥堵。

## 核心循环

移动元素到空格 -> 三个相同元素合并进化 -> 培育外星生物 -> 获得新回合 -> 继续进化到更高级

## 核心机制

- 空格移动消除：棋盘上只有一个空格，通过移动元素到空格来创造匹配，比传统交换式三消更具策略深度
- 进化链系统：匹配三个基础元素进化成一级元素，再匹配三个一级元素进化成二级，直到最终的外星生物
- 晶体/植物辅助：匹配这些元素可以补充回合数，延长游戏时间
- 机器人干扰：机器人在棋盘上占据空间并阻碍匹配，数量随关卡递增而增加

## 为什么好玩

进化链带来的渐进式满足感——看着基础物质一步步进化成复杂的外星生物。空格移动的机制让每一步都需要深思熟虑。

## 粘性来源

进化链的终极目标是强力驱动——玩家不断想看到下一个进化阶段的生物长什么样。但后期机器人增多导致的棋盘拥堵和回合不足可能产生挫败感。

## Meta 系统

关卡制推进，每个关卡有特定的进化目标。使用内购可以获取更多回合或移除机器人。

## 实现难度

中等偏高 — 空格移动机制要求精确规划，后期机器人增多和回合减少使难度陡增。最大技术难点是进化链的平衡设计——确保每个阶段都有适当的挑战性。
