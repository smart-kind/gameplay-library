# Pyramus

- **类型**: 解谜 / 几何
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款以金字塔为核心元素的几何解谜游戏，玩家需要通过旋转和组合不同形状的金字塔块来完成目标图案

## 玩法规则

游戏呈现各种几何金字塔形状的拼图块，散布在操作面板上。每个金字塔块有不同的面数、颜色标记和可旋转轴。

玩家通过触摸屏幕拖拽金字塔块进行旋转操作。每次旋转90度或180度，具体取决于关卡设置。旋转后金字塔的不同面会朝向玩家，展示不同的颜色或符号标记。

目标是将所有金字塔块旋转到正确的位置和朝向，使所有标记面按指定图案排列。部分关卡要求从特定视角观察时，金字塔的投影呈现特定形状或轮廓。

随着关卡推进，金字塔数量增加，旋转轴变得复杂（不再是简单的上下轴，可能有倾斜轴或万向轴）。游戏在限定步数内完成即过关，超出步数则失败。部分高难度关卡引入多个视角同时验证。

后续关卡引入镜像模式——两个金字塔块需要呈现镜像对称的图案。最高难度关卡要求从三个不同视角同时满足条件。

## 核心循环

观察目标图案 → 旋转金字塔块到正确朝向 → 完成关卡解锁新谜题

## 核心机制

- **多维度旋转**：金字塔可绕不同轴旋转，每次旋转改变多个面的朝向
- **投影解谜**：从特定视角观察时，金字塔组合需呈现目标轮廓
- **步数限制**：限定操作次数，考验解题效率而非蛮力尝试

- **视角验证**：部分关卡需要从俯视、侧视、正视三个角度同时验证图案正确性


## 为什么好玩

将熟悉的金字塔形状转化为旋转解谜工具，空间思维挑战恰到好处。每次找到正确的旋转序列时的顿悟感很强。

## 粘性来源

空间谜题的'灵光一现'时刻是核心粘性来源。解不开时反复思考，解开后的成就感极强。

## Meta 系统

无。纯解谜体验，无外围成长系统。

## 实现难度

中 — 需要良好的空间想象力。最大技术难点是3D几何体的正确渲染和旋转物理模拟。
