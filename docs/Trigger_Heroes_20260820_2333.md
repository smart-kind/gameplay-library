# 触发英雄（Trigger Heroes）

- **类型**: 动作 / 射击 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Lucky Kat Studios
- **首次发布**: 2018
- **一句话描述**: 一款快节奏的动作射击游戏，玩家控制英雄角色在横版关卡中自动射击、躲避弹幕。

## 玩法规则

游戏采用横版卷轴视角。玩家控制一个英雄角色，角色在屏幕中自动左右移动，玩家可以控制角色的上下位置。

角色自动向右侧发射子弹/攻击。玩家需要操控角色躲避敌人的攻击和障碍物，同时让角色的自动射击命中敌人。

每个关卡有固定的敌人配置和Boss。Boss通常有特定的攻击模式——弹幕、冲撞、召唤小怪等。玩家需要观察模式、找到安全位置。

游戏包含多个英雄角色，每个角色有不同的武器类型和特殊技能。有些角色发射扇形弹幕，有些角色有穿透弹，有些角色可以释放护盾。

关卡之间可以收集金币和道具，用于解锁新英雄、升级武器和购买辅助道具。游戏整体节奏快，单局时长3-5分钟。
## 核心循环

操控角色躲避弹幕 → 自动射击消灭敌人 → 通关获取金币 → 解锁/升级英雄 → 挑战更高难度关卡

## 核心机制

- **单轴操控+自动射击**：玩家只需要控制角色的上下移动，射击自动完成。这种简化操作降低了门槛，让玩家专注于走位和躲避。
- **弹幕躲避机制**：敌人的攻击有清晰的弹道和范围，玩家需要找到'缝隙'穿越。这种设计借鉴了弹幕射击游戏（STG），但在手机上简化了操作。
- **英雄多样性**：不同英雄有不同的攻击模式和特殊技能，改变英雄可以显著改变游戏体验。收集全英雄是中期目标。

## 为什么好玩

快节奏的躲避+自动射击组合带来紧张刺激的体验。成功穿越弹幕的'差一点'瞬间非常刺激。不同英雄的攻击模式变化保持新鲜感。

## 粘性来源

弹幕躲避的'差一点就过'心理是核心粘性。每次失败都让人觉得'下次能过'。英雄收集提供中期目标。短局时长（3-5分钟）让玩家很容易'再来一局'。

## Meta 系统

英雄解锁和武器升级系统。通过金币解锁新英雄，每个英雄有独立的升级路径。武器升级提升攻击力、射速和特殊效果。进度永久保留。

## 实现难度

中 — 弹幕系统的碰撞检测和弹道计算需要一定复杂度。技术难点在于弹幕性能的优化（大量子弹同时存在时的帧率保持）和Boss攻击模式的公平性设计。

## 同类游戏

与此游戏类似的推荐：放置类可参考 Clicker Heroes 和 Idle Slayer；肉鸽类可参考 Slay the Spire 和 Vampire Survivors。
