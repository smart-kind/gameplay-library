# Blue Prince

- **类型**: 解谜 / Roguelike
- **平台**: PC
- **开发商**: Dogwood Games
- **首次发布**: 2025
- **一句话描述**: 最佳独立解谜冒险——在程序生成的豪宅中探索、解谜和发现秘密。

## 玩法规则

玩家探索一座程序生成的神秘豪宅，每层房间布局随机生成。核心机制是通过解谜推进——每个房间都有独特的谜题需要解决，解开后才能进入下一层。

游戏结合了 Roguelike 元素——每次进入豪宅的布局都不同，但某些机制和道具是持久的。玩家需要学习豪宅的规则和秘密，利用发现的工具解决越来越复杂的谜题。

叙事通过环境细节和发现的物品逐步展开，讲述豪宅主人的故事和秘密。

## 核心循环

进入豪宅 → 解谜推进 → 发现新区域 → 面对更复杂谜题

## 核心机制

- 程序生成豪宅：每次进入布局不同
- 房间解谜：每个房间有独特谜题
- Roguelike 元素：永久知识但每局随机
- 环境叙事：通过物品和细节发现故事
- 渐进复杂度：谜题难度逐步提升

## 为什么好玩

随机生成的豪宅确保每次探索都新鲜，解谜的智力挑战和环境叙事的结合让人欲罢不能。

## 粘性来源

- 每局随机性：豪宅布局每次都不同
- 解谜的智力满足感：找到解决方案的成就感
- 环境叙事：通过探索发现故事的参与感
- 渐进学习：每次尝试学到新规则

## Meta 系统

部分道具和知识是持久的。通过多次探索发现豪宅的深层秘密和机制。

## 实现难度

中。程序生成需要确保谜题可解且有趣。房间模板和谜题库的创作需要大量设计工作。
