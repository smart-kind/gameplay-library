# 斯卡蒂之塔（Skadi Tower）

- **类型**: 塔防 + 策略
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Pocket Games
- **首次发布**: 2024
- **一句话描述**: 在北欧神话背景下，通过放置防御塔和召唤英雄来抵御一波波敌人进攻的塔防游戏

## 玩法规则

游戏界面是一张俯视角的地图，敌人从地图边缘的入口进入，沿着固定或半固定的路径向地图中心的基地前进。

玩家在战斗前选择要使用的防御塔和英雄角色（有数量限制），然后在战斗中将它们拖放到地图上的空位。防御塔会自动攻击范围内的敌人。

防御塔分为四种类型：箭塔（单体高伤害）、冰塔（减速效果）、炮塔（范围伤害）和魔法塔（穿透护甲）。每种塔有3个升级等级。

英雄是可以由玩家手动操控的特殊单位，拥有独特的主动技能。英雄可以在地图上移动，但受到伤害会暂时退出战斗冷却。

敌人分为普通兵、重装兵、飞行兵和Boss。每波敌人的组合和强度递增。全部波次防御成功即过关，基地生命值归零则失败。

## 核心循环

设计防御布局 → 观看战斗 → 根据结果调整策略 → 挑战下一关

## 核心机制

- **塔的组合策略**：四种塔各有专长，单一塔种无法应对所有敌人类型。冰塔减速+箭塔输出的组合是基础策略，玩家需要根据每波敌人调整塔的配比。
- **英雄手动操控**：英雄不仅是被动单位，玩家需要主动使用技能。技能有冷却时间，使用时机影响战局。这增加了操作维度，让塔防不只是"摆好就完事"。
- **波次压力递增**：每波敌人数量和强度递增，后期Boss需要集中火力。玩家需要在早期节省资源还是全力防御之间做出选择。

## 为什么好玩

北欧神话的美术风格和音效氛围出色。塔防的策略深度加上英雄操作的即时反馈，让游戏既有动脑又有动手的乐趣。每关的敌人组合不同，需要重新思考防御布局，不会一成不变。

## 粘性来源

- **策略多样性**：同一关可以有多种过关方式，激发实验欲
- **角色解锁**：通关获得新英雄和塔皮肤，有收集目标
- **难度阶梯**：普通→困难→地狱三档难度，满足不同类型玩家
- **波次紧张感**：最后一波Boss战往往决定成败，心跳加速

## Meta 系统

- **英雄收集**：通过关卡掉落或任务解锁新英雄
- **天赋树**：全局天赋系统，升级后所有关卡中塔和英雄获得加成
- **每日挑战**：每日特殊规则关卡，奖励丰厚

## 实现难度

中。塔防的路径搜索和碰撞检测是成熟技术，难点在于英雄AI和玩家手动操作的无缝切换。最大的技术难点是波次平衡——每波敌人的强度需要精确调校，确保有挑战但不过于挫败。
