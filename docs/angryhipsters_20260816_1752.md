# Angry Hipsters（愤怒的嬉皮士）

- **类型**: 休闲 / 桌面弹射
- **平台**: Mobile (iOS)
- **开发商**: Colin Tulloch
- **首次发布**: 2011
- **一句话描述**: 一款明显模仿愤怒鸟物理弹射机制的戏仿游戏，用弹弓将嬉皮士角色投掷向星巴克咖啡杯、设计师服装等"主流文化"目标。

## 玩法规则

游戏采用经典的物理弹射机制。画面呈现一个类似愤怒鸟的 2D 横版场景，左侧有一个弹弓装置。

玩家操作弹弓：用手指拖拽嬉皮士角色（放在弹弓上），调整拉拽角度和力度后松手，角色以抛物线飞出。目标是摧毁场景中由各种"主流文化"元素构成的结构——星巴克咖啡杯、设计师服装、高端品牌标志等。

嬉皮士角色具有不同的特性。每个角色被投掷后，会撞击并破坏场景中的结构块。结构块遵循物理规律——被撞击后会倒塌、滚动，连锁摧毁其他部分。游戏的目标是用有限数量的嬉皮士角色，摧毁场景中所有指定的目标物品。

评测指出，虽然概念本身是对愤怒鸟的直接模仿，但游戏的讽刺性主题设计（嬉皮士 vs 主流文化）为其增添了一些独特的幽默感。

## 核心循环

拖拽弹弓瞄准 → 松手发射嬉皮士 → 观察物理碰撞和结构倒塌 → 用剩余角色清除所有目标

## 核心机制

- **物理弹射**：经典愤怒鸟式弹弓机制，拖拽角度和力度决定飞行轨迹
- **物理结构破坏**：场景结构遵循真实物理规律，撞击后连锁倒塌
- **角色差异**：不同嬉皮士角色可能具有不同的物理特性（重量、特殊能力）
- **目标摧毁**：需要摧毁场景中所有指定的"主流文化"物品才能过关

## 为什么好玩

对愤怒鸟的讽刺性戏仿本身就是卖点——用"反主流"的嬉皮士来摧毁星巴克等主流文化符号，带有黑色幽默。物理破坏的爽快感也继承自愤怒鸟的经典设计。

## 粘性来源

物理破坏带来的爽感反馈——结构倒塌的连锁反应；"差一点就成功"的不甘心感驱动重试；讽刺主题的趣味性。

## Meta 系统

无。游戏是纯关卡制，没有外围成长或收集系统。

## 实现难度

低 — 物理弹射引擎（如 Box2D）是成熟方案。最大技术难点是物理参数的精细调校，让倒塌效果既真实又有趣。
