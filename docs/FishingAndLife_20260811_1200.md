# Fishing and Life（钓鱼与生活）

- **类型**: 休闲 / 钓鱼 / 治愈
- **平台**: Mobile (iOS+Android)
- **开发商**: Hunt Studio
- **首次发布**: 2019
- **一句话描述**: 在美丽的手绘风景中安静地钓鱼，收集鱼类图鉴，体验慢节奏的治愈时光。

## 玩法规则

游戏画面是一幅精美的手绘风景画：湖面、远山、天空、季节变化。玩家坐在岸边，通过点击屏幕抛竿。鱼漂落入水中后，玩家需要等待鱼上钩。

当鱼咬钩时，鱼漂会下沉，此时需要点击屏幕收杆。收杆后有一个小游戏：通过控制拉力让鱼进入绿色区域，鱼被成功钓起。拉力过大线会断，拉力过小鱼会逃走。

钓到的鱼会被收入水族箱（图鉴）。每种鱼有独特的外观和出现条件（特定季节、特定时间段、特定天气）。收集到的鱼可以放归自然，也可以保留用于完成图鉴。

游戏没有竞争元素、没有倒计时、没有失败惩罚。钓不到鱼也没关系，下次再来就好。游戏的核心体验是"在美丽的风景中安静地等待"。

## 核心循环

选择钓点 → 抛竿等待 → 鱼上钩时收杆 → 完成拉力小游戏 → 钓到鱼收入图鉴 → 解锁新钓点/鱼种

## 核心机制

- **拉力小游戏**：收杆后的拉力控制是游戏唯一的操作挑战，需要在合适时机调整力度，简单但有技巧空间
- **条件触发鱼种**：不同鱼种的出现取决于季节、时间（白天/夜晚）、天气等现实条件，增加了探索的深度
- **手绘美术**：游戏最大的亮点是精美绝伦的手绘风景，每个场景都像一幅水墨画
- **环境音效**：水声、鸟鸣、风声构成了一幅完整的声音画面，配合耳机体验极佳

## 为什么好玩

Fishing and Life 不是关于"赢"的游戏，而是关于"体验"的游戏。它的魅力在于营造了一个远离喧嚣的宁静空间。当你戴上耳机，看着湖面上的涟漪，听着远处的鸟鸣，等待鱼漂下沉的那一刻——这种体验本身就是一种享受。钓鱼只是载体，真正的核心是慢下来的生活态度。

## 粘性来源

- **收集图鉴**：每种鱼都有精美插画，收集全部图鉴是长期目标
- **季节变化**：不同季节有不同的风景和鱼种，鼓励玩家长期游玩
- **情绪治愈**：游戏提供了一种数字化的"冥想"体验，帮助玩家放松
- **无压力设计**：没有失败惩罚，什么时候玩都不会有压力

## Meta 系统

图鉴与场景解锁系统。通过收集鱼类解锁新的钓点和场景，每个场景有独特的美术风格和鱼种。无付费压力，所有场景都可以通过游戏进度解锁。

## 实现难度

低到中。钓鱼机制简单，核心难点在于美术资源（大量手绘风景和鱼类插画）和环境音效的设计与集成。技术实现本身不复杂。
