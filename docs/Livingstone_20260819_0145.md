# 活着的（Livingstone）

- **类型**: 冒险 / 平台跳跃
- **平台**: Mobile (iOS)
- **开发商**: Unknown
- **首次发布**: 2008
- **一句话描述**: 一款以非洲探险为主题的2D横版平台冒险游戏，玩家控制探险家在危险环境中生存。

## 玩法规则

玩家看到的画面是一个横版卷轴的非洲丛林/洞穴场景，主角是探险家Livingstone，需要在充满危险的关卡中前进。场景中包含悬崖、陷阱、敌人、以及可收集的物品。

操控方式：方向键或虚拟摇杆控制移动和跳跃、按钮进行攻击。玩家需要跳跃跨越深渊、躲避敌人的攻击、击败拦路的敌人，同时收集关卡中的宝藏和钥匙。

关卡设计包含多个检查点，玩家死亡后从最近的检查点重新开始。某些关卡需要收集特定钥匙才能打开门或激活机关，增加了探索元素。

## 核心循环

探索关卡 → 躲避陷阱/击败敌人 → 收集物品 → 到达终点/解锁下一关

## 核心机制

- **平台跳跃**：核心的跳跃和移动机制，需要精确判断跳跃距离和时机。悬崖和陷阱的分布要求玩家观察模式并找到安全路径。
- **战斗系统**：简单的近战攻击，可以击退小型敌人。面对大型敌人时需要利用环境（如陷阱或落石）来间接击败。
- **收集驱动**：关卡中隐藏的宝藏和收集品激励玩家探索非主路线区域。

## 为什么好玩

非洲探险主题结合经典的横版平台跳跃，营造了一种"印第安纳·琼斯"式的冒险氛围。在危险的丛林中寻找隐藏宝藏的探索感和克服障碍的成就感是核心乐趣。

## 粘性来源

- **探索未知的好奇心**：每个关卡都有隐藏区域和秘密收集品，激发反复探索。
- **技术精进**：高难度跳跃需要反复练习才能掌握，成功后的成就感很强。
- **短关卡**：每关时间不长，失败后快速重开，"再来一次"循环流畅。

## Meta 系统

无。游戏专注于关卡闯关体验。

## 实现难度

低。经典的2D横版平台游戏，技术成熟。最大难点是关卡设计——需要平衡难度和乐趣，确保每个关卡既有挑战性又不会让玩家感到沮丧。关卡编辑器的集成可以降低设计成本。

## 变体设计

可以加入"速通模式"记录通关时间，激发玩家挑战自己的最快记录。另外，随机生成关卡的Roguelike模式也能大幅增加重玩价值——每次进入丛林都有完全不同的地形和挑战。
