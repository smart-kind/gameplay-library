# ArcadeBall: The Ramp Challenge

- **类型**: 街机滚动 / 物理平衡
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立开发者
- **首次发布**: 2024
- **一句话描述**: 一款滚球街机游戏，玩家控制小球在倾斜坡道上滚动，保持平衡、收集奖励、避开陷阱，尽可能走得远。

## 玩法规则

玩家控制一个小球在一个不断延伸的3D坡道上滚动。球自动向前移动，速度逐渐增加。

操作方式：左右滑动或倾斜设备控制球的左右移动。点击可以短暂加速或跳跃。球自动向前滚动，速度逐渐增加。

坡道逐渐变窄，增加操控难度。两侧是深渊，掉下去即游戏结束。坡道上有各种障碍和机关：旋转障碍物需要判断时机通过，弹跳板将球弹到不同高度，加速带突然提高球速，减速带需要保持动力，转弯处坡道方向突然改变。

收集系统：坡道上散落金币和宝石，收集越多分数越高。某些收集物有特殊效果如临时护盾、减速、磁力吸引。连续收集有连击加分。

掉出坡道即死。速度越快操控越困难。一局通常持续30秒到2分钟。死亡后立即可以重新开始。

## 核心循环

控制球滚动 → 收集金币 → 避开障碍 → 速度加快 → 失误掉落 → 重试

## 核心机制

- **自动加速加平衡控制**: 球自动向前滚动且速度递增，玩家只需要控制左右平衡和避让。自动前进设计让游戏节奏自然加快。初期悠闲后期紧张。速度递增也是天然难度曲线。核心挑战是在加速中保持精准控制，控制感逐渐流失的体验制造持续紧张感。

- **坡道宽度递减**: 坡道随距离逐渐变窄，容错空间越来越小。结合速度递增，形成双重难度曲线：不仅球跑得快了，路也变窄了。这种设计让每个玩家都有明确的极限距离。我上次跑了200米，这次要跑250米，推动反复尝试。

- **收集与风险权衡**: 金币和特殊道具分布在坡道的不同位置。有些在安全区，有些在边缘危险区。玩家需要在安全前进和冒险收集之间做选择。这种权衡让游戏不只是不犯错，还需要主动决策。

## 为什么好玩

滚球游戏的经典魅力。简单操作下的精准控制需求，配合速度递增带来的持续紧张感。坡道上的各种机关增加了变化性，不会单调。3D视觉效果让滚动体验更直观。

## 粘性来源

街机游戏差一点的不甘心感加上速度递增的自然紧张曲线和收集的满足感，构成经典跑酷循环。每局时间短，适合碎片化游玩。球皮肤和坡道主题解锁提供长期目标。

## Meta 系统

球皮肤解锁系统：收集金币解锁不同外观的球。坡道主题解锁：达到一定距离解锁新的视觉主题。每日挑战：特殊条件的关卡。

## 实现难度

低。3D物理引擎（球体滚动和碰撞）是核心技术。坡道生成需要程序化设计。主要难点是物理手感调优。球不能太滑也不能太粘。
