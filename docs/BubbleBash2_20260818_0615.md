# 泡泡龙2（Bubble Bash 2）

- **类型**: 三消 / 弹射 / 休闲
- **平台**: PC / Mobile
- **开发商**: Alawar Entertainment
- **首次发布**: 2010
- **一句话描述**: 经典泡泡龙游戏的续作，玩家通过弹射彩色泡泡来匹配消除，保护村庄免受怪物入侵。

## 玩法规则

游戏画面中，上方悬挂着大量彩色泡泡，排列成各种形状。画面底部中央有一个发射器，可以发射不同颜色的泡泡。发射器旁边显示下一个泡泡的颜色。

玩家操作是瞄准和发射：移动鼠标/手指控制发射角度，点击/释放射出泡泡。射出的泡泡会沿直线飞行，碰到墙壁会反弹。当泡泡碰到相同颜色的泡泡群（至少3个）时，所有相连的同色泡泡消除。

消除的泡泡中可能关着被解救的小动物。游戏的叙事目标是消灭所有悬挂的泡泡，拯救被泡泡困住的村民。每个关卡有特定的救援目标。

如果泡泡群下降到触底线以下，游戏失败。某些特殊泡泡（炸弹、彩虹等）有特殊效果：炸弹消除周围所有泡泡，彩虹可以匹配任何颜色。合理利用特殊泡泡是通关的关键。

## 核心循环

瞄准弹射泡泡 -> 匹配消除 -> 解救村民 -> 解锁新关卡

## 核心机制

- 反弹瞄准系统：泡泡碰到墙壁会反弹，玩家需要利用墙壁反弹到达难以直接瞄准的位置。这增加了策略深度。
- 连锁消除：消除一组泡泡后，如果其他泡泡失去了所有连接支撑，它们也会掉落消除，形成连锁反应。
- 特殊泡泡：炸弹泡泡（消除周围所有泡泡）、彩虹泡泡（匹配任意颜色）、乌云泡泡（遮挡视线）等，增加了关卡的变化和挑战。

## 为什么好玩

Bubble Bash 2的乐趣在于瞄准的艺术——找到那个能引发连锁反应的关键位置，一炮清场。反弹瞄准需要一定的空间想象力，成功时的成就感很强。可爱的画面和解救小动物的叙事也给简单的消除玩法增添了趣味。

## 粘性来源

粘性来自关卡的逐步升级和新机制的引入。每几关就会出现新的泡泡类型或布局挑战，保持了新鲜感。差一泡泡就能过关的不甘心也让人忍不住再来一次。

## Meta 系统

关卡进度系统。完成关卡获得星星评分（基于分数和解救的动物数量），达到一定星星数解锁新的世界和关卡主题。

## 实现难度

低。最大的技术难点在于泡泡的物理模拟——需要处理泡泡的碰撞检测、群集连接关系判断和连锁消除的递归计算。
