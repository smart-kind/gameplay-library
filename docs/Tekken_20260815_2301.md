# Tekken（铁拳移动版 / Tekken Mobile）

- **类型**: 格斗
- **平台**: Mobile (iOS+Android)
- **开发商**: Bandai Namco
- **首次发布**: 2013 (移动版)
- **一句话描述**: 经典3D格斗游戏的移动版本，使用虚拟摇杆和技能按钮进行对战

## 玩法规则

游戏采用经典的3D格斗视角，两个角色在擂台上面对面。玩家控制其中一个角色，使用连招、特殊技能和防御来击败对手。

操作方式：屏幕左侧的虚拟摇杆控制移动（前、后、下蹲、跳跃），右侧按钮负责攻击（拳、脚、特殊攻击）和防御（格挡、闪避）。部分移动版使用简化操作——滑动屏幕释放特定连招。

每个角色有独特的招式列表和连招系统。通过组合不同方向的输入和攻击按钮，可以释放各种连段和特殊技。防御系统包括格挡（减少伤害）、闪避（完全躲避攻击）和下段防御。

对战目标：将对手HP降至零。比赛通常为3局2胜制。移动版可能包含PvE剧情模式和PvP在线对战。

## 核心循环

对战 → 获得金币/经验 → 解锁角色/升级 → 挑战更强的对手

## 核心机制

- **3D格斗**：区别于2D格斗的关键在于左右移动（侧移），增加了空间维度的策略深度。
- **连招系统**：不同角色有复杂的连招列表，需要精确的输入时机和顺序。高技巧上限。
- **防御与反击**：格挡、闪避和反击形成石头剪刀布式的博弈关系。
- **角色收集**：移动版通常包含大量可解锁角色，每个角色有独特的招式和玩法风格。

## 为什么好玩

铁拳系列是格斗游戏黄金标准的代表之一。移动版本让经典的3D格斗体验可以随时随地享受。每个角色都有独特的战斗风格和连招系统，提供了巨大的探索空间。与真人对战的紧张刺激感是单人游戏无法替代的。

游戏的角色设计是铁拳系列的标志性特色——每个角色不仅招式独特，还有完整的背景故事和动机。三岛家族的血缘恩怨、武术家的修行之路、机器人的觉醒之旅……这些故事让角色不仅仅是战斗工具，而是有血有肉的个体。

3D格斗相比2D格斗多了一个维度（侧移），这意味着玩家需要同时关注前后左右四个方向的威胁。这种空间意识的建立需要时间，但一旦掌握，战斗的战术深度远超2D格斗。

## 粘性来源

格斗游戏的核心粘性来自技巧成长——每次对战都在学习和进步，从被打到能反击再到主动进攻，成长曲线清晰。角色收集的欲望（解锁所有角色）驱动持续游玩。排位赛/锦标赛提供了长期竞争目标。"再来一局"的心理——每次失败都觉得"下一局我能赢"——是格斗游戏最强大的驱动力。

此外，连招系统的深度也是一个巨大的粘性来源——铁拳的连招可以非常复杂，从基础的几段连击到高级的弹墙连段、崩地连段，学习空间几乎没有上限。每次掌握一套新的连招都会带来巨大的满足感。

## Meta 系统

角色解锁和升级系统——通过战斗获得资源解锁新角色、升级技能或购买外观。排位赛系统提供竞争性成长目标。
