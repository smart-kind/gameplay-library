# 色彩迷宫（Chromaticon）

- **类型**: 益智解谜 / 色彩混合
- **平台**: Mobile (iOS+Android)
- **开发商**: 独立开发
- **首次发布**: 2015
- **一句话描述**: 一款以色彩混合为主题的益智游戏，玩家需要通过调配和引导颜色来解谜

## 玩法规则

游戏界面呈现一个由管道、阀门和颜色方块组成的网格。每种颜色（红、绿、蓝三原色）有各自的源头，玩家需要通过旋转管道、打开或关闭阀门来引导颜色流向正确的目标输出端。

基础机制：三原色（红R、绿G、蓝B）可以通过混合产生次级颜色——红+绿=黄、红+蓝=紫、绿+蓝=青、红+绿+蓝=白。每个关卡都有特定的颜色目标——比如"在输出端产生黄色"，玩家需要引导红色和绿色的源头通过管道汇合。

玩家的主要操作是点击管道来旋转它们（每次旋转90度），以及点击阀门来打开或关闭。旋转管道改变颜色的流向，阀门控制颜色是否通过。

高级关卡引入新机制：
- **颜色过滤器**：只允许特定颜色通过
- **颜色分流器**：将一种颜色分成两路
- **颜色合并器**：将两种颜色混合
- **定时阀门**：按时间开关，增加时间维度

每个关卡都有步数或时间限制，需要在限制内完成颜色匹配。

## 核心循环

观察颜色目标和可用资源 → 旋转管道改变颜色流向 → 混合基础颜色产生目标颜色 → 匹配到正确的输出端 → 完成关卡解锁新机制

## 核心机制

- **颜色混合系统**：RGB三原色按照真实的色彩理论混合，红色+绿色=黄色，红色+蓝色=紫色等。这让游戏不仅是谜题，也是一个有趣的色彩理论学习工具
- **管道旋转机制**：点击管道每次旋转90度，改变颜色流动的方向。这是核心交互方式，需要预判旋转后的整体流向变化
- **渐进式复杂度**：每几关引入新机制（过滤器、分流器、定时阀门等），保持新鲜感的同时逐步增加策略深度
- **步数/时间限制**：有限的操作次数或时间要求玩家高效规划，不能随意尝试

## 为什么好玩

将色彩理论变成游戏机制是一个天才设计。每次成功匹配颜色时的视觉反馈非常赏心悦目——管道中流动的色彩、混合时的渐变效果都经过精心设计。难度曲线合理，新机制的引入节奏恰到好处，让玩家在每个阶段都感到"有挑战但可解"。

## 粘性来源

解谜成功后的"啊哈"时刻是核心驱动力——当你终于看透了管道的最优旋转方案、所有颜色同时流向正确出口时，那种智力上的满足感非常强烈。颜色混合的视觉变化本身就是一种奖励。逐步解锁新机制保持了持续的惊喜感。

## Meta 系统

关卡解锁系统。完成章节解锁新的颜色机制和主题皮肤（不同颜色主题、管道样式等）。可能有每日挑战模式提供额外的解谜内容。

## 实现难度

低 — 最大技术难点是颜色混合算法的正确性（确保符合真实的RGB色彩理论）和管道连接逻辑的精确判定。需要确保每个关卡有解且解的难度符合设计预期。颜色流动的视觉效果（管道中的色彩动画）需要流畅且美观。
