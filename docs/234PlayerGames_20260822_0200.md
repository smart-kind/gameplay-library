# 234人游戏（2 3 4 Player Games）

- **类型**: 派对/多人合集
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2017
- **一句话描述**: 支持2-4人同屏游玩的迷你游戏合集

## 玩法规则

应用内含多款适合多人同屏游玩的小游戏。每款游戏支持2-4名玩家在同一设备上操作。屏幕被分割为多个区域，每个玩家控制自己的区域。操作方式简单：快速点击、滑动或拖拽。游戏节奏快速，每局持续30秒到1分钟。玩家通过比较得分决定胜负。涵盖赛车、射击、益智、反应等多种类型。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

选择人数 → 选择游戏 → 同屏对战 → 比较得分 → 再来一局

## 核心机制

- **多人同屏**:  2-4人在同一设备上同时操作
- **快速对局**:  每局30秒到1分钟，适合碎片时间
- **多样玩法**:  涵盖多种游戏类型

## 为什么好玩

与朋友同屏竞技的社交乐趣，规则简单上手快，竞争激烈

## 粘性来源

社交互动是核心驱动力；多游戏选择保持新鲜感

## Meta 系统

无

## 实现难度

低 - 每款小游戏规则简单，核心在于多人输入处理 - 多人同时触屏输入的区域划分和冲突处理
