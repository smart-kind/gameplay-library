# 自动格斗象棋：大逃杀（Auto Brawl Chess: Battle Royale）

- **类型**: 自动战斗 / 策略 RPG / 大逃杀
- **平台**: Mobile (iOS + Android)
- **开发商**: Panoramik Games
- **首次发布**: 2020
- **一句话描述**: 5 分钟一局的快节奏自动战斗象棋，融合自动棋机制与大逃杀玩法。

## 玩法规则

每局比赛有多名玩家（通常 8 人）同时参与。游戏分为两个交替阶段：准备阶段和战斗阶段。

**准备阶段**：玩家在商店中购买角色棋子，花费金币从随机刷新的角色池中选择。购买的角色放置在个人棋盘（8x8 网格）上的战略位置。角色拥有不同的职业和种族标签，相同标签的角色在场上会触发羁绊加成（如 3 个战士获得额外护甲，2 个法师获得额外伤害）。

**战斗阶段**：玩家的棋子自动与另一名玩家的队伍进行战斗。玩家无需在战斗中操作——角色自动攻击、释放技能、移动。战斗持续直到一方所有棋子被击败。失败的队伍对玩家造成生命值伤害。

每轮战斗结束后，玩家根据排名获得金币奖励，用于下一轮的购买和升级。三个相同等级和星级的角色可以合成一个更高级的版本（星级+1，属性大幅提升）。

随着回合推进，可用金币和商店等级提升，出现更强大的角色。最后存活或排名最高的玩家获胜。

## 核心循环

购买棋子 → 布阵激活羁绊 → 自动战斗 → 获得金币和排名 → 升级强化 → 决战到最后

## 核心机制

- **自动战斗机制**：玩家在准备阶段完成所有策略部署，战斗阶段完全由 AI 执行。胜负取决于棋子选择、站位和羁绊搭配，而非实时操作技巧。
- **羁绊系统**：角色按职业和种族分类，场上满足数量条件时激活团队加成。这要求玩家在"买需要的角色"和"买最强的角色"之间做权衡。
- **合成升级**：三合一的升星机制提供了明确的成长路径和收集目标。看到 3 个一星合成一个二星的瞬间是核心爽点。
- **经济运营**：金币管理是深层策略——何时存钱吃利息，何时花钱买经验升级商店，何时 D 牌刷新角色池。

## 为什么好玩

自动战斗降低了操作门槛（不需要手速和反应），但保留了策略深度（阵容搭配、经济管理、站位调整）。5 分钟一局的快节奏让它在手机上非常友好，每局体验紧凑且充满变数。

## 粘性来源

每局随机角色刷新带来的不同体验；尝试新阵容组合的好奇心；排名竞争（"我差一名就前三了"）；棋子收集和羁绊图鉴的完成欲；赛季通行证和皮肤收集提供长期目标。

## Meta 系统

赛季通行证系统：完成每日/每周任务获取经验，提升通行证等级解锁角色皮肤、表情和头像框。不影响战斗平衡性。棋子收藏图鉴记录已遇到的所有角色。

## 实现难度

高。需要实现自动战斗 AI（路径寻找、目标选择、技能释放逻辑）、多人同步、经济系统、羁绊计算、以及大逃杀的多人匹配和排名逻辑。最大技术难点是自动战斗 AI 的平衡性和观赏性——AI 行为要足够智能且可预测，让玩家能理解战斗结果的原因。
