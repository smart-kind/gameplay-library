# Clicker Heroes 2

- **类型**: 放置 / 点击
- **平台**: PC
- **开发商**: Playsaurus
- **首次发布**: 2018
- **一句话描述**: 经典点击者游戏的续作——雇佣英雄、升级能力、击败怪物。

## 玩法规则

玩家雇佣英雄自动攻击怪物，通过升级提升伤害。转生系统允许重置获得永久加成。相比一代，二代增加了更多策略元素和进度系统。

英雄系统提供多样性——每个英雄有独特能力和升级路径。Boss 战提供阶段性目标和挑战。

## 核心循环

雇佣英雄 → 升级伤害 → 击败 Boss → 转生重置

## 核心机制

- 英雄雇佣：自动攻击怪物
- 升级系统：提升伤害和能力
- 转生系统：重置获得永久加成
- Boss 战：阶段性目标
- 英雄多样性：独特能力和升级

## 为什么好玩

经典点击者玩法的进化。转生系统增加了策略深度，不再是单纯的数字递增。

## 粘性来源

- 转生策略：何时重置的决策深度
- 英雄多样性：不同英雄提供不同体验
- Boss 挑战：阶段性目标的满足感
- 数值增长：看到数字变大的满足感

## Meta 系统

英雄升级和转生。提升英雄能力，转生获得永久加成。

## 实现难度

低。点击者核心系统简单，数值平衡是关键。
