# Tricky Blocks - Block Puzzle（Tricky Blocks）

- **类型**: 物理堆叠 / 解谜 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: Blue Bag Gaming And Publishing - FZCO
- **首次发布**: 2025
- **一句话描述**: 从三个方块中选择并堆叠到越来越高的塔上，利用物理平衡挑战极限堆叠高度的益智游戏。

## 玩法规则

屏幕中央有一个不断升高的方块塔。屏幕底部显示一个托盘，托盘上同时呈现三个不同形状的方块。玩家需要从这三个方块中选择一个，放置到塔顶。

核心操作：点击选择方块，然后在塔顶区域点击放置位置。游戏提供阴影预览——在放置前会显示方块的落点和可能的稳定状态，帮助玩家判断放置位置是否合理。放置后方块会根据物理引擎自然落下，可能滑动、倾斜、或与已有方块产生碰撞。

游戏没有时间压力——玩家可以随时思考，不需要快速反应。每次放置后，塔的高度增加，重心变化，后续放置的难度也随之增加。当方块因为重心不稳从塔上掉落时，游戏结束。目标是堆到尽可能高的高度。

## 核心循环

从三个候选方块中选择 → 放置到塔顶 → 物理引擎结算平衡状态 → 塔变高 → 继续选择下一个方块

## 核心机制

- **三选一决策系统**：每次同时提供三个方块，形状各不相同。玩家需要预判哪个方块在当前的塔顶状态下最稳定。这个机制增加了策略性——不是简单的"能放就放"，而是需要在三个选项中权衡最优解。
- **真实物理平衡**：方块的重量、摩擦力、重心都经过真实物理模拟。堆得越高，塔越不稳定，小偏差也可能导致倒塌。物理模拟的真实性让每次放置都有真实的紧张感。
- **阴影预览辅助**：放置前显示方块落点的阴影预览，让玩家在放置前就能看到可能的结果。这个设计降低了挫败感——玩家不是在"盲放"，而是在有信息的情况下做决策。

## 为什么好玩

没有时间压力的物理堆叠游戏节奏舒缓，但物理平衡的紧张感又带来足够的刺激。每次从三个方块中选择最优解的决策过程让人沉浸，"再放一个就结束"的心理让游戏极易上瘾。

## 粘性来源

物理平衡的不确定性是核心驱动力——即使做了最优决策，物理模拟的微妙差异也可能导致意外倒塌。这种"差一点就能更高"的不甘心驱动玩家反复尝试。同时，三选一的决策深度让每步都有思考空间，不是纯运气游戏。

## Meta 系统

无。游戏专注于纯粹的物理堆叠挑战。

## 实现难度

中。需要稳定的物理引擎（2D或3D）来模拟方块的堆叠、碰撞和平衡。最大技术难点在于物理模拟的一致性——同样的操作应该产生可预测的结果，不能出现随机性导致的意外倒塌，否则玩家会感到不公平。
