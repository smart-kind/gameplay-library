# 异形人（Alien Hominid）

- **类型**: 横版射击 / 动作 / 街机
- **平台**: Web（浏览器）/ Flash（原始版）/ PC / 主机（重制版）
- **开发商**: Tom Fulp / Dan Paladin（The Behemoth）
- **首次发布**: 2002（Flash 版）
- **一句话描述**: 卡通风格的横版射击游戏——玩家扮演一个被政府追捕的小外星人，用各种武器反击

## 玩法规则

游戏采用横版卷轴视角，画面是精致的卡通风格。玩家控制一个小外星人角色在多个关卡中移动和战斗。

操作方式：方向键移动，射击键开火。外星人可以蹲下、跳跃、使用特殊武器（激光、炸弹、冰冻等）。

关卡设计多样——城市街道、实验室、军事基地、外星飞船等。每个关卡有独特的敌人和 Boss。敌人类型丰富——士兵、坦克、直升机、机器人等。

特殊武器系统：外星人可以使用多种特殊武器，每种有独特的效果。特殊武器有使用次数限制，需要在关卡中收集补充。

## 核心循环

推进关卡 → 射击敌人 → 收集特殊武器 → 打败 Boss → 进入下一关

## 核心机制

- **特殊武器系统**：多种特殊武器（激光、炸弹、冰冻、电击等），每种有独特的攻击效果。特殊武器有使用次数限制，需要策略性使用。
- **Boss 战**：每个关卡有独特的 Boss，有复杂的攻击模式和弱点。需要观察 Boss 的行为并找到反击机会。
- **关卡多样性**：每个关卡有不同的主题、敌人配置和场景元素。从城市到实验室到外星飞船，视觉和玩法都有变化。

## 为什么好玩

Alien Hominid 是 Flash 时代最好的横版射击游戏之一——精致的画面、丰富的武器系统、有趣的 Boss 战，加上幽默的剧情（小外星人对抗强大的政府），让它成为经典。

## 粘性来源

- **Boss 挑战**：每个 Boss 都有独特的攻击模式，需要学习和适应
- **武器多样性**：不同武器带来不同的战斗体验
- **关卡多样性**：每个关卡都有不同的主题和挑战

## Meta 系统

无（Flash 版）。重制版有解锁角色和成就系统。

## 实现难度

中 + 需要横版射击系统、Boss AI、特殊武器效果、碰撞检测。最大技术难点是 Boss 战的设计——要让 Boss 有挑战性但不会让玩家感到不公平。
