# Gun Sprint

- **类型**: 休闲 / 竞速
- **平台**: Mobile (iOS)
- **开发商**: KAYAC Inc.
- **首次发布**: 2021
- **评分**: ⭐ 4.6/5 (43,877 评价)
- **价格**: Free
- **一句话描述**: 一把枪会自己射击、旋转和奔跑——点击向后退射击来向前走，因为枪和子弹往反方向飞！

## 玩法规则

游戏画面中一把拟人化的枪在赛道上奔跑。枪的射击方向与移动方向相反——点击屏幕时枪向后退方向射击，后坐力推动枪向前移动。赛道上有各种障碍物（墙壁、敌人、平台）。玩家需要通过精准点击来控制枪的前进速度和方向。射击可以消灭路径上的敌人。赛道设计有跳台、弯道、移动平台等元素。如果枪掉下赛道或撞到障碍物则失败。界面极简：赛道、枪角色、距离/时间显示。

## 核心循环

观察赛道 → 精准点击射击 → 利用后坐力前进 → 到达终点 → 下一关

## 核心机制

- 反向射击机制：子弹向后飞，后坐力推动前进——反直觉但有趣的控制方式
- 精准时机：点击时机和频率决定前进速度，需要节奏感
- 赛道障碍：敌人和障碍物需要射击消灭或躲避

## 为什么好玩

"向后退射击来向前走"这个反直觉机制本身就充满趣味。精准的点击时机带来节奏感。

## 粘性来源

反直觉机制的新鲜感、精准操作的学习曲线、关卡设计渐进难度

## Meta 系统

角色皮肤解锁。不影响核心玩法。

## 实现难度

低——核心机制新颖但实现简单，难点在于赛道设计
