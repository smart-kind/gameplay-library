# Rhythm Hive

- **类型**: 音乐节奏
- **平台**: Mobile (iOS)
- **开发商**: DRIMAGE Co., Ltd
- **首次发布**: 2021
- **评分**: 4.53212/5.0 (Free)
- **一句话描述**: 一款音乐节奏类型的手游，下落式音游界面，音符从上方沿轨道下落至判定线。支持BTS、TXT、ENHYPEN...

## 玩法规则

下落式音游界面，音符从上方沿轨道下落至判定线。支持BTS、TXT、ENHYPEN、SEVENTEEN、LE SSERAFIM、NewJeans等HYBE旗下艺人的歌曲。

操作包括：单点（点击）、长按（按住不放）、滑动（横向快速滑动）。根据精准度分为Perfect/Great/Miss三种判定。

每首歌支持完整版本和短版本（Short Ver.），降低入门门槛。同一首歌可切换不同难度。

除了演奏，游戏还有角色卡牌系统——收集艺人卡片，在演奏时编入阵容可以获得属性加成（得分倍率提升、生命值恢复等）。

## 核心循环

进行游戏操作 → 获得分数/资源/进度 → 解锁新内容/提升能力 → 继续挑战更高难度

## 核心机制

- **偶像卡牌养成**：通过活动和抽卡获取艺人卡，每张卡有稀有度、属性和专属技能。培养卡牌提升等级和突破等级，直接影响演奏得分。
- **Solo/Unit/团体曲**：歌曲分三种类型：Solo（个人）、Unit（小分队）、团体（全体成员），满足粉丝对不同组合的偏好。
- **活动系统**：定期举办限时活动，完成指定曲目获得限定卡牌和道具，制造紧迫感和参与感。

## 为什么好玩

音乐与操作的完美同步带来强烈的沉浸感。每次完美击中都像是一次即兴演奏，配合不同难度的曲库，既能让新手轻松上手，也能让高手不断挑战自我。节奏游戏特有的心流体验——当你进入状态时，手指几乎自动跟随音乐节拍，这种'人机合一'的感觉是其他类型游戏难以替代的。

## 粘性来源

曲目解锁的收集欲和排行榜竞争是主要粘性来源。每次练习一首曲子直到从失败到完美的过程产生强烈的'再来一次'冲动。连击中断的不甘心和突破新高分的爽感交替驱动。此外，新歌曲持续更新，给玩家'还有新歌要听'的期待。

## Meta 系统

曲目解锁系统。玩家通过演奏歌曲获得金币或经验，用于解锁新歌、新难度等级、角色皮肤和特殊主题。部分游戏还有角色养成系统，提升角色属性可以获得额外得分加成或特殊技能。定期更新的曲库也是重要的留存机制。

## 实现难度

中等。最大难点在于音频同步——需要确保音符生成与音乐节拍精确对齐，同时处理不同设备的音频延迟差异。不同iOS设备的音频管线延迟可能相差数十毫秒，需要在代码中校准。还需要大量曲库内容的制作和版权授权。

## 同类游戏对比

与该类型其他游戏相比，本作在操作简化/内容量/美术风格等方面有自身特色，适合喜欢该类型的玩家尝试。
