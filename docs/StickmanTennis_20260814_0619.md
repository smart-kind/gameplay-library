# Stickman Tennis

- **类型**: 体育 / 网球
- **平台**: Mobile (iOS+Android)
- **开发商**: Djinnworks
- **首次发布**: 2012
- **一句话描述**: 一款火柴人风格的网球游戏，通过滑动控制火柴人的击球方向和力度

## 玩法规则

游戏呈现一个标准网球场，两名火柴人选手分列球网两侧。球场有草地、硬地和红土等不同类型，影响球的弹跳速度和角度。

玩家通过在屏幕上滑动来控制击球。滑动方向决定球的飞行方向，滑动速度决定力度。上滑=上旋球（弧线高落地后弹跳大），平滑=平击球（速度快但容易出界），下滑=下旋球（球速慢但落点精准）。

网球比赛采用标准计分规则（15-30-40-Game）。发球时滑动屏幕确定方向和力度，接球时根据来球位置滑动回击。需要预判对手回球路线并提前移动。

不同击球方式影响球的轨迹和速度。球员有不同属性：速度（移动快慢）、力量（击球力度）、耐力（比赛后期是否疲劳）。

游戏设有职业生涯模式，玩家从初级赛事逐步晋级到顶级锦标赛。每个赛事有不同的场地类型和对手。

## 核心循环

观察来球 → 滑动击球 → 得分赢得比赛

## 核心机制

- **滑动操控**：方向决定落点，速度决定力度，旋转类型影响球路
- **球员属性**：不同球员有不同速度和力量，影响比赛风格
- **标准计分**：真实网球计分规则增加竞技感

- **职业生涯**：从初级赛事晋级到顶级锦标赛


## 为什么好玩

火柴人风格的简洁呈现让网球运动的本质得以保留。滑动操控直观且有技巧深度。

## 粘性来源

体育游戏的竞技粘性：提升技术排名、解锁新球员、挑战更高难度对手。

## Meta 系统

球员解锁：通过比赛解锁不同属性的火柴人球员。锦标赛：参加系列比赛获取排名和奖励。

## 实现难度

中 — 滑动操控需要练习掌握。最大技术难点是球的物理模拟和AI对手行为。
