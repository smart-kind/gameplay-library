# 滚筒狂奔（Barrel Roller）

- **类型**: 休闲 / 物理 / 跑酷
- **平台**: Mobile (iOS+Android)
- **开发商**: Tummy Games
- **首次发布**: 2024
- **一句话描述**: 控制滚筒在轨道上滚动、跳跃、收集物品的物理跑酷游戏。

## 玩法规则

游戏画面中，一个圆桶/滚筒在一条起伏的轨道上向前滚动。轨道上有各种坡道、环道、跳台和障碍物。轨道两侧分布着金币和星星等收集物。

玩家通过点击屏幕控制滚筒跳跃。长按会让滚筒跳得更高（按住时间 = 跳跃高度），短按则是小跳。滚筒在空中时可以利用惯性完成空中翻转。

游戏的核心挑战是保持滚筒在轨道上。如果滚筒速度过快飞出轨道、或者没有跳过障碍物，就会掉落失败。轨道设计中包含加速带（让滚筒获得额外速度）、弹跳板（将滚筒弹向空中收集高处的物品）和危险区域（需要精准跳跃才能通过）。

每局游戏有时间限制或距离目标，在规定时间内/距离内收集尽可能多的金币和完成关卡目标。

## 核心循环

控制滚筒滚动 → 点击跳跃躲避障碍/收集物品 → 完成关卡目标 → 用金币解锁新外观或轨道

## 核心机制

- **长按跳跃**：按住时间决定跳跃高度，是一个力度/时机的组合机制
- **惯性翻滚**：滚筒在空中保持惯性，可以通过时机控制完成空翻等动作
- **轨道设计**：坡道、环道、跳台等多样轨道元素让每次滚动都有不同的体验
- **收集系统**：金币和星星分布在轨道各处，有些需要精准跳跃才能获取

## 为什么好玩

Barrel Roller 的乐趣在于物理模拟带来的不可预测性和成就感。看着滚筒在轨道上完美地完成一个 360 度环道翻滚，或者精准地跳到高处的金币上，会产生强烈的满足感。长按跳跃的力度控制让玩家觉得"是我在操控这个滚筒"，而不是简单的自动跑酷。

## 粘性来源

1. **物理爽感**——滚筒的惯性、翻滚、弹跳等物理反馈非常直观和有趣
2. **精准操作成就感**——成功完成一个困难的跳跃或环道会让人感到自豪
3. **收集驱动**——金币、星星、成就等多维度收集目标
4. **关卡多样性**——不同的轨道设计让每次都有新体验

## Meta 系统

金币收集后可用于解锁不同的滚筒外观（皮肤）和新的轨道主题。不影响核心玩法，纯外观奖励。

## 实现难度

中。核心难点是物理引擎的稳定性和轨道碰撞检测。滚筒在复杂轨道上的运动需要精确的物理模拟，特别是在加速带和弹跳板上的行为。最大技术难点是确保在不同设备上物理表现的一致性。
