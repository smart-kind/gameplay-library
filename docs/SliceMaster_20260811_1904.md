## 玩法规则

Slice Master is a casual one-person game whose goal is to slice everything in sight, well, almost everything.

This one-button game is driven by precision, timing, and discernment to rack up a high score. ## 核心循环

操作 → 获得反馈 → 挑战升级 → 刷新记录 → 再来一局

## 核心机制

- **即时反馈**：每次操作都有明确的视觉和音效反馈
- **渐进式挑战**：难度随时间或分数递增，保持紧张感

## 为什么好玩

简单易上手但难以精通，快节奏的游戏体验适合碎片时间游玩，每次失败都让人想立刻再试一次。

## 粘性来源

'差一点就成功'的不甘心感 + 简单易上手的低门槛 + 短时间一局的高节奏反馈循环，让人容易陷入'再来一把'的循环。

## Meta 系统

- **皮肤/角色解锁**：通过游戏内成就或货币解锁新外观
- **排行榜**：最高分排名
- 对核心玩法无直接影响，主要提供收集动力

## 实现难度

低 — 核心玩法简单直观。最大的技术难点是游戏手感和反馈的精细调校。

### 详细操作说明

游戏界面简洁直观，主要操作区域占据屏幕大部分空间。玩家需要：

1. **观察当前状态**：注意屏幕上显示的游戏元素、得分、剩余时间或生命值
2. **做出决策**：根据当前形势选择最佳操作时机和方式
3. **执行操作**：通过点击、滑动或按键来完成游戏动作
4. **获得反馈**：操作成功或失败都有明确的视觉和声音提示
5. **持续调整**：根据游戏节奏的变化不断调整策略

### 游戏流程

游戏开始时，系统会生成初始的游戏场景。玩家进入游戏后：

- **前期**：熟悉基本操作和游戏规则，这个阶段节奏较慢
- **中期**：游戏节奏逐渐加快，需要更快的反应速度和更精准的判断
- **后期**：难度达到顶峰，只有最专注的玩家才能突破
- **结算**：游戏结束后显示得分、排名等信息，并提供重新开始选项

### 得分机制

游戏通过以下方式进行计分：

- 完成基本操作获得基础分数
- 连续成功操作会触发连击加成
- 特殊操作或高难度动作有额外分数奖励
- 部分游戏内道具可以倍增得分
