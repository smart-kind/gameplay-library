# Save the grandmother

- **类型**: 休闲解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: MondayOFF
- **首次发布**: 2022
- **一句话描述**: 搞笑解谜游戏，通过创意方式拯救处于危险中的老奶奶

## 玩法规则

游戏采用卡通风格的2D画面。每个关卡呈现一个场景，老奶奶正处于某种危险中（如被野兽追赶、从高处坠落、被困等）。

玩家通过点击、拖拽、划线等操作来改变场景元素，为老奶奶开辟安全通道。解题方式往往出人意料，不是传统的逻辑解谜。

场景中有可交互的元素和误导性元素。玩家需要找到正确的互动对象和操作顺序。有时候看似无关的元素反而是关键。

关卡从简单到复杂，后期需要多步操作才能完成拯救。每个关卡的答案都带有幽默感。

## 核心循环

观察场景寻找线索 → 点击/拖拽解谜 → 成功拯救老奶奶 → 解锁新关卡

## 核心机制

- **场景互动系统**: 场景中的元素可以交互，玩家需要找到正确的互动对象和顺序。有些元素是误导项，有些是关键道具。试探和试错是主要玩法。
  （探索解谜）
- **创意非传统解题**: 解谜方式不遵循传统逻辑，需要创造性思维。有时候最荒谬的方法反而是正确答案。这种反预期设计带来惊喜感。
  （创意性）
- **关卡递进设计**: 从单一操作到多步组合，从明显提示到隐藏线索，难度逐步提升。每个关卡的场景和危险情况都不同。
  （难度曲线）

## 为什么好玩

搞笑的场景和出人意料的答案让人忍俊不禁。每次想到'原来如此'的解谜瞬间都很满足。MondayOFF擅长做这种搞笑休闲游戏。

## 粘性来源

创意解谜的新鲜感、搞笑场景的娱乐性、'原来这么简单'的顿悟快感。收集全部关卡答案的完成欲。每个答案都像一个小笑话。

## Meta 系统

解锁新关卡，无深度成长系统。核心驱动力是解锁新场景和新笑话。

## 实现难度

低 — 2D场景+简单交互逻辑，主要是关卡设计和美术的工作量。
