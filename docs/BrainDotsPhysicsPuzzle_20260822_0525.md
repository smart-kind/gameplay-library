# Brain Dots（Brain Dots）

- **类型**: 物理绘图解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Translimit
- **首次发布**: 2015
- **一句话描述**: 通过在屏幕上画线来让红球和蓝球相撞的极简物理益智游戏，下载量超过5000万次。

## 玩法规则

游戏界面极其简洁——一个白色的画布上有一个红色球和一个蓝色球，以及可能的障碍物（墙壁、平台、斜坡等）。规则只有一个："让红球和蓝球相撞"。玩家用手指在屏幕上画出线条，这些线条获得物理属性后参与物理模拟。

画出的线条可以是各种形状：斜坡（让球滚动）、墙壁（阻挡或引导球的运动）、杠杆（利用力矩传递运动）、容器（接住掉落的球并改变方向）等。线条画完后，物理模拟开始——球受重力影响沿线条滚动，如果线条的角度和形状设计得当，两个球就会在某处相撞。

游戏没有任何操作次数限制，也没有步数约束。画完线条后，球会自动开始运动，相撞即过关。如果球没有相撞，玩家可以直接重画，不需要等待或承担惩罚。

## 核心循环

观察球和障碍物的位置 → 画出引导线条 → 启动物理模拟 → 观察球的运动 → 调整线条重新尝试

## 核心机制

- **极简规则约束**：整个游戏只有"让两个球相撞"一个规则，没有任何复杂的说明或教程。这种极简主义降低了认知负担，让玩家完全专注于"想办法"。
- **自由绘图物理**：玩家画出任意线条，线条立即成为物理世界中的刚体。可以画斜坡让球加速滚动，画墙壁改变球的方向，画凹槽接住球并引导到特定路径。每个解决方案都是玩家独创的，没有"标准答案"。
- **物理引擎的精确性**：球的运动遵循真实的物理规律（重力、摩擦力、碰撞反弹），这意味着玩家需要有一定的物理直觉——太陡的坡球会飞出去，太平的坡球不会动，墙壁的角度决定了反弹方向。
- **无限试错**：没有失败惩罚、没有次数限制、没有时间压力。玩家可以反复尝试直到找到正确的线条形状和位置。

## 为什么好玩

Brain Dots的魅力在于"规则极简但解法无限"——5000万下载量的秘诀就是任何人都能在一秒内理解规则，但要找到解法可能需要几分钟的思考。当两个球按照你画的线路最终相撞时，会有"我设计的系统工作了"的成就感。不同玩家的画法差异极大——有人用精确的几何线条，有人画出复杂的迷宫结构，有人只用一根简单的斜线就搞定。


- **画笔的自由度**：玩家可以画出任意形状，没有预设模板或限制。一条线、一个圆、一个多边形——都可以成为解决方案的一部分。这种自由度让每个关卡都有无数种可能的解法。
- **物理规律的一致性**：球的运动始终遵循相同的物理规则，这意味着玩家学到的知识可以跨关卡复用。一旦理解了"什么样的角度能让球滚到那里"，后续关卡只是这个知识的应用。

## 粘性来源

- **"啊哈！"顿悟时刻**：每道关卡的解法都有一种"原来如此"的顿悟感——找到那个关键的角度或形状时，满足感极强
- **观看他人解法的好奇心**：游戏允许观看其他玩家的解法（尤其是那些只用极少线条就过关的"天才方案"），这会激发"我也能想出来"的动力
- **难度递增的节奏**：早期关卡非常简单，建立信心后逐步引入障碍物、多球体、运动平台等复杂元素

## Meta 系统

- **关卡解锁系统**：完成当前关卡解锁下一关。
- **解法分享**：玩家可以分享自己的过关方案供他人参考。
- **创意评分**：社区对不同的解法进行点赞和评分。

## 实现难度

低。与Brain It On!类似，核心是2D物理引擎+自定义形状碰撞体。由于规则更简单（只需让两个球相撞，不需要考虑复杂的目标类型），关卡设计的工作量也较小。最大挑战是确保每个关卡的解法不是唯一的——需要验证关卡既不太容易也不太不可能。
