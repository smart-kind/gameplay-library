# Pinball（弹珠台）

- **类型**: 街机 / 弹珠台 / 休闲
- **平台**: Mobile (iOS + Android) / 街机
- **开发商**: 多个开发商（ZEN Studios / BrainVault Games 等）
- **首次发布**: 1930s（街机起源），移动版 2010s
- **一句话描述**: 经典街机弹珠台的移动版本，通过弹球击打目标得分

## 玩法规则

弹珠台是最古老的街机游戏类型之一，其核心机制在移动平台上得到了忠实再现。

**核心操作**：玩家通过屏幕两侧的虚拟按钮控制左右弹板（flipper）。弹板向上弹起时可以击打弹球，阻止其掉落到底部出球口。

**得分机制**：弹球在球台上弹跳时，会触发各种得分目标——bumper（圆形碰撞器）、target（目标板）、ramp（坡道）、spinner（旋转器）等。每种目标提供不同的分数奖励。

**特殊机制**：一些弹珠台变体在球台上加入了彩色显示屏，展示小游戏挑战——例如无尽太空射击游戏、赛车游戏、导弹防御等，将弹珠台与传统街机小游戏融合。

**多球模式**：达到特定条件后进入多球模式（multiball），同时有多个弹球在场，大幅增加得分机会但也增加操控难度。

**出球**：弹球从底部掉落即结束当前球。每局通常有 3-5 条命。

## 核心循环

发射弹球 → 用弹板操控 → 击打目标得分 → 触发特殊事件/多球 → 弹球掉落 → 重复

## 核心机制

- **弹板物理**：弹板的击打时机和角度控制是核心技能，需要精确判断弹球轨迹
- **bumper 反弹**：圆形碰撞器提供随机的弹球方向改变，增加不可预测性
- **连击倍率**：连续击打相同目标可以提升分数倍率，鼓励精准操作
- **小游戏融合**：现代弹珠台变体将传统弹球机制与数字小游戏结合，增加了玩法维度

## 为什么好玩

弹珠台的魔力在于物理引擎的不可预测性与玩家精准操控之间的平衡。每次弹球碰撞都产生不同的轨迹，让每局游戏都独一无二。多球模式的混乱感和高分追逐提供了强烈的爽感反馈。

## 粘性来源

主要来自物理随机性带来的"再来一局"冲动——每次弹球的轨迹都不同，玩家总觉得"差一点就能打出更好的分数"。同时，解锁新弹珠台和达成特殊事件目标提供了长期的收集动力。

## Meta 系统

部分版本包含弹珠台收集系统——完成特定挑战解锁新的弹珠台设计。ZEN Studios 的 Williams Pinball 系列还提供了多人在线对战功能。

## 实现难度

高 — 精确的 2D 物理引擎是核心挑战，需要模拟真实的球-挡板碰撞、重力、摩擦力等物理参数。最大技术难点在于确保物理模拟在所有设备上的确定性——同样的操作应该产生相同的结果，这对多人对战尤为重要。
