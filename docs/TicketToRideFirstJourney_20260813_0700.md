# 车票之旅：初次旅行（Ticket to Ride: First Journey）

- **类型**: 桌游 / 路线规划
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Days of Wonder / Asmodee Digital
- **首次发布**: 2016
- **一句话描述**: 简化版车票之旅，收集彩色车票卡片连接城市路线完成旅行目标

## 玩法规则

游戏画面展示一张地图（北美或欧洲版图），上面布满了连接不同城市的铁路线。每个城市是一个圆点，线路有不同颜色。

玩家手中有彩色车票卡（红、蓝、绿、黄、橙、黑/灰等颜色）。回合中可以执行三个操作之一：从牌堆抽取两张彩色车票卡、在铁路上放置火车车厢（需要对应颜色的车票卡）、抽取新的目的地车票。

放置火车时，需要打出与线路颜色相同数量的车票卡。灰色线路可以匹配任意颜色。每完成一条路线，获得对应长度的分数。

游戏结束条件是某位玩家用完手中的火车（简化版为12节车厢）。然后计算目的地车票完成奖励，总分最高者获胜。

## 核心循环

抽车票卡 → 兑换铁路线路 → 获得分数 → 连接更多城市

## 核心机制

- 资源收集与消耗循环：车票卡既是货币也是筹码。收集需要运气，使用需要规划。
- 线路竞争：多玩家共享同一张地图上的线路，关键路线可能被对手抢先占据。
- 目的地车票的风险回报：选择更远的目的地获得更高分数，但完不成会扣分。

## 为什么好玩

规划路线时的"拼图感"和线路被抢时的"竞争焦虑"交替出现。简单的规则下藏着丰富的策略空间。

## 粘性来源

"就差一条线就能完成目的地"的不甘心 + 线路被抢的竞争感 + 每局路线规划都不同（随机抽卡）的重玩价值。

## Meta 系统

无外围成长。每局游戏完全独立，靠随机生成的目的地车票保证重玩性。

## 实现难度

中。需要设计线路图数据结构、车票卡管理、路径连通性检查。最大技术难点：高效的线路占用检测和终点判定算法。
