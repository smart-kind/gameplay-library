# 时空幻境（Braid）

- **类型**: 平台跳跃 / 解谜 / 叙事
- **平台**: PC / Switch / PlayStation / Xbox
- **开发商**: Number None, Inc.（Jonathan Blow）
- **首次发布**: 2008
- **一句话描述**: 一个可以倒转时间的平台跳跃游戏，每次倒转都会揭示新的解谜可能性

## 玩法规则

游戏采用横版2D卷轴视角，玩家控制一个穿着风衣的男人（Tim），在多个主题世界中探索。基础操作和传统平台游戏一样：左右移动、跳跃。但Braid有一个颠覆性的能力——**时间倒流**。

按下特定按键，时间会倒流——玩家角色的移动、敌人的行动、甚至已收集的碎片都会回到之前的状态。松手后时间恢复正常。这意味着：
- 你可以跳过一个深渊，然后倒流回来，让"过去的你"和"现在的你"同时存在
- 你可以让一个怪物走过陷阱，然后倒流，利用怪物触发机关
- 你可以"撤回"一个已做的操作，但某些元素不受倒流影响（这是谜题的关键）

每个世界有独特的时间规则：
- **世界2**：时间正常倒流，基础教学
- **世界3**：某些物品不受时间倒流影响（如绿色物品）
- **世界4**：时间流逝与玩家位置相关（向右走时间前进，向左走时间倒流）
- **世界5**：时间分裂（"影子"角色重复你之前的所有动作）
- **世界6**：时间流速差异（不同区域时间流速不同）

收集拼图碎片是主要目标，集齐一个世界的所有碎片可以进入Boss关卡。

## 核心循环

探索关卡 → 利用时间能力解谜 → 收集拼图碎片 → 解锁新区域/新时间规则 → 通关Boss

## 核心机制

- **时间倒流机制**：Braid的核心创新。与传统"时间停止"或"时间加速"不同，Braid的时间倒流是**完全可逆**的——所有元素都会精确地回到之前的状态。这意味着玩家可以用倒流来"试错"，也可以用它来创造平行时间线。
- **时间规则变体**：每个世界引入一种新的时间规则变体，在基础倒流机制上增加一层限制或变化。世界3的"不可逆物品"、世界4的"位置驱动时间"、世界5的"影子重放"——每种变体都打开了全新的解谜维度。
- **影子系统**（世界5）：你的所有操作都被记录下来，当你按下"影子"键时，一个"影子"角色会重放你之前的所有动作。你需要与"过去的自己"协作解谜——比如让影子踩住开关，你趁机通过。
- **叙事碎片**：拼图碎片收集后，会解锁一段故事文本（关于Tim和他的"公主"）。文本的顺序是反向排列的——你从结局开始读，越往后越接近开始。

## 为什么好玩

Braid 把"时间"这个概念玩到了极致。传统平台游戏的解谜是"怎么跳过去"，Braid的解谜是"怎么利用时间"。每个新时间规则的引入都是一次认知冲击——你以为你已经掌握了时间倒流，然后世界5告诉你"等等，还有影子"。解谜的设计极其精巧，很多谜题的解法需要你跳出惯性思维。

## 粘性来源

"我还没想通"的执着——Braid的谜题不是反应速度的挑战，而是"你怎么还没想到"的智力挑战。一旦想通，那种"啊！"的顿悟感是无与伦比的。反向叙事的悬念也推动玩家继续——Tim和公主的故事到底是怎么回事？

## Meta 系统

无传统Meta系统。进度是拼图碎片收集量。通关后有隐藏结局（需要完成所有谜题，包括隐藏谜题）。

## 实现难度

中 — 时间倒流机制需要完整的状态记录和回放系统（保存所有游戏对象在每个时间点的状态）。技术难点是高效的状态存储（不能无限存）和精确的回放（物理、动画、AI都需要完美复现）。
