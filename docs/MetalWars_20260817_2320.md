# 金属战争（MetalWars）

- **类型**: 俯视角射击
- **平台**: Mobile (iOS+Android)
- **开发商**: Chillingo
- **首次发布**: 2010
- **一句话描述**: 俯视角坦克战斗游戏，玩家操控金属机甲在各种战场上消灭敌方单位。

## 玩法规则

游戏画面是俯视角2D战场，玩家操控一台机甲/坦克在地图上移动和射击。虚拟摇杆控制移动，点击屏幕或自动瞄准射击。
地图上有障碍物（建筑残骸、岩石、树木）可以掩蔽，也有开阔地带需要快速通过。敌人分布在地图各处，有不同的类型：步兵（血量低、数量多）、坦克（血量高、火力强）、炮台（固定位置、高伤害）。
玩家的机甲有生命值条和弹药/能量系统。使用主武器消耗能量，能量随时间恢复。收集地图上的补给品可以恢复生命值或补充能量。
关卡目标是消灭所有敌人或到达指定撤离点。某些关卡有Boss战，需要利用掩蔽和走位躲避Boss的攻击模式。
游戏支持升级系统：使用关卡奖励升级机甲的武器威力、装甲厚度、移动速度和能量恢复速率。

## 核心循环

进入战场 → 移动走位躲避攻击 → 瞄准射击消灭敌人 → 收集补给 → 完成关卡目标 → 升级机甲 → 进入下一关

## 核心机制

- 掩蔽战术：利用地图障碍物掩蔽躲避敌人火力，寻找射击窗口进行反击，增加了战术深度。不同障碍物有不同的耐久度
- 能量管理系统：主武器消耗能量需要管理释放节奏，不能无脑连射，增加了策略性。需要权衡'现在就开火'和'等一下能量恢复'
- 升级系统：每关结束后可以选择升级不同属性，让玩家根据自己的玩法风格定制机甲。偏进攻就升武器，偏防守就升装甲

## 为什么好玩

操控一台全副武装的机甲在战场上横冲直撞，配合升级后越来越强的火力，带来一种'我就是战场主宰'的爽快感。
Boss战的紧张感和胜利后的成就感形成鲜明对比，每次升级后的火力提升都能感受到明显变化。

## 粘性来源

升级系统的数值成长（'升级装甲就更能扛'）、关卡递进的未知挑战、以及Boss战的成就感。

## Meta 系统

机甲属性升级系统、新武器解锁、关卡递进。

## 实现难度

低 — 核心是2D移动+射击+碰撞检测。主要技术难点在于AI敌人的行为多样性和关卡设计，以及能量系统的数值平衡。


游戏还包含成就系统：完成特定挑战（如无伤过关、限时过关、不使用某类武器）获得成就奖励。某些成就解锁特殊的机甲涂装或武器皮肤。游戏的关卡设计包含解谜要素，需要找到特定开关才能打开前进的道路。


游戏还包含计时挑战模式：在限定时间内消灭所有敌人获得更高评价。某些关卡有多个完成路径（潜行路线或正面突击路线），提供不同的游戏体验。收集所有关卡的隐藏要素是长期目标。
