# Vainglory

- **类型**: MOBA
- **平台**: Mobile (iOS+Android)
- **开发商**: Super Evil Megacorp
- **首次发布**: 2014
- **一句话描述**: 移动端 MOBA 游戏，类似《英雄联盟》和《DOTA2》的 5v5 竞技对战。

## 玩法规则

两支队伍（各 5 名玩家）在对称地图上对战，目标是摧毁敌方基地的水晶。

游戏开始前，玩家选择一名英雄（角色），每个英雄有独特的技能组合和定位（坦克、输出、辅助等）。

每局开始，玩家从基地出发，拥有初始金币购买起始装备。游戏过程中：
- **击杀小兵** — 地图上自动生成的小兵，击杀获得金币和经验
- **击杀敌方英雄** — 获得大量金币，敌方英雄需要等待复活
- **击杀野怪** — 地图中的中立怪物，提供金币和增益效果
- **购买装备** — 回基地或在地图商店用金币购买装备，提升英雄能力

操作方式：左手虚拟摇杆控制移动，右手点击目标进行普通攻击，点击技能按钮释放技能（3 个常规技能 + 1 个终极技能）。

游戏节奏约 20-30 分钟一局，需要团队配合和个人操作技巧。

## 核心循环

对线发育 -> 击杀/推塔 -> 回城买装备 -> 团战争夺优势 -> 摧毁敌方基地

## 核心机制

- 每局重置系统 — 不管之前水平如何，每局从零开始，公平竞技
- 装备构建多样性 — 同一英雄可以出不同装备适应不同局势
- 团队协作机制 — 需要分工（上单、打野、中单、辅助），团队配合决定胜负

## 为什么好玩

移动端最接近主机 MOBA 体验的游戏，精美的画面、深度的策略、紧张团战带来的肾上腺素飙升。每一次团灭和翻盘都极具戏剧性。

## 粘性来源

排名天梯系统；英雄收集（解锁新英雄）；皮肤/外观收集；赛季奖励；与好友组队的社交驱动。

## Meta 系统

英雄解锁系统 — 通过游戏内货币或真实货币购买新英雄。排名天梯（青铜、白银、黄金、铂金、钻石、传奇）提供段位目标。皮肤等外观物品可购买。

## 实现难度

高 — 需要掌握英雄技能、装备搭配、地图意识、团队配合等多方面知识。学习曲线陡峭，新手需要大量时间适应。最大技术难点在于移动端实现精确的操作和实时多人同步。
