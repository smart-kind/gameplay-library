# 放置类商业帝国经营游戏（AdVenture Capitalist）

- **类型**: 放置
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: Hyper Hippo
- **首次发布**: 2014
- **一句话描述**: 放置类商业帝国经营游戏

## 玩法规则

玩家从一个小柠檬水摊开始，逐步建立各种生意（柠檬水摊、报纸配送、洗车店、披萨店等）。每个生意自动产生收入，玩家可以雇佣经理自动管理。用收入解锁新生意和升级现有生意。游戏有天使投资者机制，重置后获得永久加成。

## 核心循环

购买生意 → 自动产生收入 → 升级/解锁新生意 → 雇佣经理 → 建立商业帝国

## 核心机制

- 自动产出：每个生意自动产生收入
- 经理系统：雇佣经理后生意自动运行
- 多生意系统：从柠檬水摊到银行等多种生意
- 天使重置：重置获得永久加成，加速下次进度

## 为什么好玩

看着商业帝国从一个小摊发展到全球企业的满足感。数字增长的快感。

## 粘性来源

数值成长驱动；天使重置的永久进度感；多生意解锁。

## Meta 系统

生意解锁+经理系统+天使投资者重置。

## 实现难度

低。纯放置点击，操作极少。最大技术难点：数值平衡和大数计算。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
