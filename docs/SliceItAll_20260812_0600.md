# 切切切（Slice It All）

- **类型**: 休闲 / 飞刀切割
- **平台**: Mobile (iOS+Android)
- **开发商**: Tummy Games
- **首次发布**: 2024
- **一句话描述**: 翻转飞刀切割空中一切物体的超休闲游戏，单指操作、爽快解压。

## 玩法规则

游戏画面中，各种物体（水果、家具、乐器、甚至马桶等日常物品）悬浮在空中缓慢旋转。玩家屏幕底部有一个飞刀投掷区域。

玩家的操作只有一个：点击屏幕。每次点击，一把飞刀从底部向上飞出，穿过旋转的物体将其切割成两半。飞刀的投掷时机至关重要——需要在物体旋转到合适角度时点击，让刀刃穿过物体的中心线，产生最大的切割效果。

切割完成后，被切开的两半物体会向两侧分离并掉落，同时显示该物体的横截面（这是游戏的核心卖点之一）。每个关卡有 3-5 个物体等待切割，全部切完后关卡结束。

游戏的目标是尽可能干净利落地切割物体。如果飞刀没有切中物体（从旁边飞过），或者切得太偏，得分会降低。连续精准切割会获得连击加分。

## 核心循环

点击投掷飞刀 → 切割物体获得爽快感 → 查看物体内部结构 → 进入下一个关卡

## 核心机制

- **单指投掷**：极简操作，只需点击屏幕。飞刀直线飞行，没有角度或力度控制，考验的是时机的精准度
- **360度旋转物体**：每个物体缓慢旋转，玩家需要观察其结构，找到最佳切割时机和角度
- **横截面展示**：切割后展示物体内部结构（如水果的种子、乐器的内部构造等），满足好奇心，是游戏最大的吸引力
- **渐进式关卡**：从简单的单个物体到多个物体组合切割，难度逐渐上升

## 为什么好玩

Slice It All 的核心乐趣在于"一刀两断"的瞬间爽快感——物体被干净切开时产生的视觉满足和音效反馈极强。同时，看到各种物品被切开后内部的隐藏结构（比如一把吉他里面长什么样），满足了人类天生的好奇心。每个关卡只需几秒钟，但"再看一个"的冲动让人停不下来。

## 粘性来源

具体到机制层面：
1. **好奇驱动**——"这个东西切开里面是什么样的？"这种悬念让人想继续玩
2. **精准反馈**——干净利落的一刀切割带来的视觉和听觉满足感
3. **收集心态**——想要切到所有不同类型的物体
4. **短局设计**——每关 10-20 秒，随时可以开始，随时可以放下

## Meta 系统

无。游戏没有成长系统、升级或角色养成。纯体验驱动，没有数值累积。

## 实现难度

低。核心技术是物理引擎中的切割/布尔运算，加上 3D 模型的旋转和动画。最大技术难点是高质量的 3D 模型制作（每个物体都需要精确的内外两层模型来展示切割后的横截面效果），以及流畅的切割物理效果。
