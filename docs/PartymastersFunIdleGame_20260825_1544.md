# 派对大师 放置游戏（Partymasters - Fun Idle Game）

- **类型**: 放置 / 模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2021
- **一句话描述**: 一款以经营派对为主题的放置类模拟游戏，玩家通过管理各种派对设施来赚取金币。

## 玩法规则

玩家从一个小型派对场地开始，通过放置和升级各种设施来吸引更多客人。设施包括舞台、吧台、舞池、游戏区、餐饮区等。

每个设施自动产生收入，玩家可以升级设施提高收入效率。客人有满意度指标，满意度越高，停留时间越长，消费越多。

随着游戏进展，可以解锁新的设施类型和装饰选项。满意度取决于设施种类和等级的平衡。

## 核心循环

放置设施 -> 自动产生收入 -> 升级设施 -> 吸引更多客人 -> 解锁新内容

## 核心机制

- 放置收益: 设施自动产生收入，离线期间也持续积累，适合碎片化游玩。离线收益按时间计算，上线后可一次性收取。
- 设施升级树: 每个设施有多个升级等级，升级后提升收入效率或解锁新功能。升级需要消耗金币且时间递增。
- 客人满意度系统: 通过平衡不同设施的比例来最大化客人满意度和收入。设施种类越丰富，满意度越高。

## 为什么好玩

看着自己的派对场地从小变大、从冷清到热闹的过程有强烈的成就感。

放置机制让游戏无压力，玩家可以随时上线收取收益然后下线做其他事情。这种低投入高回报的设计非常适合碎片化时间。

## 粘性来源

离线收益让人想定期检查攒了多少钱。升级的渐进式解锁让玩家想再升一级看看效果。

设施种类的不断解锁和装饰选项的丰富化提供了长期的目标感。限时活动和特殊设施也促使玩家定期回归。

## Meta 系统

设施升级系统：消耗金币升级设施。

解锁系统：达到里程碑解锁新设施。

活动系统：限时活动提供特殊奖励。

## 实现难度

低 - 放置游戏机制成熟，核心难点在于数值平衡和长期内容规划。
