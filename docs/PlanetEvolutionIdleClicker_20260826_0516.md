# Planet Evolution: Idle Clicker

- **类型**: 放置点击 / 宇宙建造
- **平台**: Mobile (iOS)
- **开发商**: Leek & Ribs Games UG haftungsbeschraenkt
- **首次发布**: 2022
- **一句话描述**: Planet Evolution: Idle Clicker是一款放松的宇宙主题放置游戏。玩家通过点击收集金币，在太空中建造和装饰自己独一无二的星球。

## 玩法规则

游戏以太空为背景，屏幕中央显示玩家正在建造的星球。周围漂浮着各种可以放置到星球上的物体。通过点击星球收集金币，也可以用多指点击提高效率。金币用于购买太空中的漂浮物体并将其放置到星球上。每个物体对星球有吸引力，吸引更多物体飞向星球。随着星球上物体增多，星球变得越来越壮观。游戏提供大量升级选项、特殊加速器和独特的声望系统，可以大幅加快进度。支持完全离线游玩，无需网络连接。

## 核心循环

点击收集金币 -> 购买太空物体 -> 装饰星球 -> 升级加速器 -> 声望重置 -> 探索新宇宙区域 -> 重复

## 核心机制

- 点击收集：单手点击星球收集金币，多指点击提高效率
- 星球装饰：购买并放置太空物体到星球上，创造独特外观
- 升级系统：大量升级选项和特殊加速器加快进度
- 声望系统：重置进度获取永久加成，探索新宇宙区域

## 为什么好玩

这款游戏在放置游戏中主打放松而非竞争：看着自己设计的星球逐渐变美是纯粹的审美享受。宇宙主题和美丽的视觉效果让它像是一个可以互动的数字艺术品。

## 粘性来源

星球视觉成长提供强烈的审美满足；新宇宙区域的解锁保持新鲜感；离线收集让回归总有惊喜；实时排行榜为竞争型玩家提供目标

## Meta 系统

有声望系统（重置探索新宇宙区域）、升级树（加速器和加成）、实时排行榜（竞争元素）。完全免费，可离线游玩。

## 实现难度

中。核心难点在于放置点击玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
