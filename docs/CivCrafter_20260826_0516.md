# CivCrafter

- **类型**: 放置点击 / 文明建设
- **平台**: Mobile (iOS)
- **开发商**: Naquatic LLC
- **首次发布**: 2015
- **一句话描述**: CivCrafter是一款经典的文明建设放置游戏。玩家通过点击手指从原始部落开始，逐步建造一个完整的文明帝国，包括组建军队、与其他氏族战斗。

## 玩法规则

游戏以简化的文明演进画面呈现，从原始部落到现代文明。屏幕上显示当前文明等级、资源数量和可用操作。玩家通过点击屏幕收集资源（木材、石材、食物等），每种资源用于不同的建设和升级。资源可用于建造建筑、训练军队、研究技术。建筑提供持续的被动收入，军队用于对抗其他氏族。玩家可以选择做仁慈的统治者还是暴虐的独裁者，不同的管理风格影响文明的发展路径。

## 核心循环

点击收集资源 -> 建造建筑/训练军队 -> 研究技术 -> 对抗其他氏族 -> 推进文明时代 -> 重复

## 核心机制

- 文明演进：从原始部落到现代文明的多阶段发展
- 资源管理：多种资源类型，各自有不同的用途和重要性
- 军队系统：训练军队与其他氏族战斗，争夺世界霸权
- 统治选择：仁慈或暴虐两种管理风格，影响游戏体验

## 为什么好玩

从一根手指建立整个文明的成就感是放置游戏中最宏大的主题之一。文明从原始到现代的演进过程提供了清晰的进度感，用一根手指创造历史的概念本身就很有吸引力。

## 粘性来源

文明演进的宏大叙事提供持续目标；与氏族的战斗增加竞争维度；全球1亿加玩家的社交证明

## Meta 系统

有氏族对战系统：训练军队与其他玩家的氏族战斗。社交媒体集成让玩家可以关注开发商Naquatic的更新。

## 实现难度

中。核心难点在于放置点击玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
