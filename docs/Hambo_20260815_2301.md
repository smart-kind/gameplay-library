# Hambo（Hambo）

- **类型**: 物理益智 / 弹射解谜
- **平台**: Mobile (iOS+Android) / PC
- **开发商**: 独立开发者
- **首次发布**: 2011
- **一句话描述**: 扮演一只装备了武器的小猪，利用弹道物理射击敌人并完成关卡目标

## 玩法规则

游戏采用2D横版画面，每个关卡展示一个充满敌人和障碍物的场景。玩家控制一只名叫Hambo的小猪，使用各种武器（主要是枪炮）射击敌人。

操作方式：拖拽瞄准——从Hambo位置拉出一条弹道线，松开发射。弹道线显示射击的方向和力度（类似愤怒的小鸟的弹弓机制）。调整角度和力度来击中目标。

场景中有各种敌人（僵尸、怪物等），需要被全部消灭才能过关。部分关卡有保护目标（需要保护NPC不被敌人攻击）、收集品（需要射击获取）和特殊机关（可爆炸物、移动平台等）。

过关条件：消灭所有敌人或完成特定任务目标。失败条件：保护目标被摧毁或用尽弹药/射击次数。

## 核心循环

观察关卡布局 → 规划射击角度和顺序 → 发射 → 观察结果 → 调整 → 清除敌人

## 核心机制

- **弹道射击**：基于物理的弹道模拟，需要考虑抛物线、重力和障碍物反弹。直觉化操作但需要精确计算。
- **连锁反应**：射击爆炸物可以引发连锁爆炸，一次性消灭多个敌人。鼓励创造性思维。
- **弹药管理**：部分关卡限制射击次数，需要高效利用每次射击。
- **环境互动**：利用墙壁反弹、重力、爆炸连锁等环境因素来解决谜题。

## 为什么好玩

Hambo结合了愤怒的小鸟式的弹射玩法和塔防式的敌人清除目标。小猪拿枪的荒诞形象与精准的物理弹射形成有趣的对比。每次成功的连锁爆炸都带来强烈的爽快感，而需要多步规划的关卡又提供了策略深度。

游戏的场景设计充满创意——从农场到城市到太空，每个主题都有独特的视觉风格和机关设置。农场里有草垛可以燃烧引爆，城市里有汽车可以当作掩体，太空站里有重力异常区域。这些环境变化让弹射解谜的玩法在不同关卡中有不同的感受。

连锁反应是Hambo最让人上瘾的机制——一枪击中油桶引发爆炸，爆炸波及旁边的炸药箱，炸药箱的爆炸又触发了机关……最终一整片敌人被连锁反应清除。这种"一石多鸟"的快感是物理弹射游戏的终极奖励。

## 粘性来源

弹射解谜的粘性来自"差一点就命中"的体验——看到弹道偏了一点点，玩家会立刻调整角度重试。连锁爆炸的爽快感让人上瘾——用最少的射击消灭最多的敌人。三星评价系统（用最少射击次数通关）驱动完美主义者反复优化。

隐藏关卡和收集品也是驱动长期游玩的重要因素。有些关卡的出口非常隐蔽，需要特定的射击角度才能发现。有些收集品位于几乎不可能到达的位置，需要精妙的多步弹射才能获取。这些隐藏内容让玩家在通关后仍有足够的动力继续探索。
