# 战锤40K：爆弹枪轰鸣（Warhammer 40,000: Boltgun Boom）

- **类型**: 射击/动作
- **平台**: Mobile (iOS+Android)
- **开发商**: 基于 Warhammer 40K IP
- **首次发布**: 2026
- **一句话描述**: 基于 Warhammer 40,000 宇宙的射击动作游戏。

## 玩法规则

以 Warhammer 40K 宇宙为背景的射击游戏，玩家扮演星际战士，使用标志性的爆弹枪等武器对抗异形和混沌势力。游戏采用俯视角或横版视角，包含射击、近战和技能系统。

战斗场景中充满 Warhammer 40K 的标志性元素：星际战士盔甲、异形敌人、哥特式建筑环境。武器系统以爆弹枪为核心，辅以链锯剑近战和其他专用武器。

## 核心循环

进入战场 → 射击异形敌人 → 使用链锯剑近战 → 收集弹药/补给 → 完成关卡目标 → 解锁新武器和技能

## 核心机制

- 爆弹枪核心：标志性武器的射击手感，高伤害大范围攻击
- 近战系统：链锯剑等近战武器用于近距离战斗
- Warhammer 40K 宇宙：忠于原作的设定和敌人类型

## 武器与战斗深度

除爆弹枪外，游戏还包含等离子枪、热熔枪、动力武器等 Warhammer 40K 标志性武器。每种武器对不同类型的敌人有不同效果。

敌人的护甲和弱点系统要求玩家根据敌人类型切换武器。星际战士的动力甲可以逐步升级，提供额外防护和特殊能力。

## 为什么好玩

Warhammer 40K 粉丝可以在手机上体验成为星际战士的快感，标志性的爆弹枪射击和链锯剑近战还原了桌游和电子游戏中的经典体验。

## 粘性来源

武器解锁、关卡推进和 Warhammer 40K 宇宙的丰富内容。

## Meta 系统

2026年8月新游发布

中等 — 射击动作需要反应和瞄准技巧
