# 经典三消游戏，匹配糖果完成关卡目标（Candy Crush Saga）

- **类型**: 三消
- **平台**: Mobile (iOS+Android) / Web
- **开发商**: King
- **首次发布**: 2012
- **一句话描述**: 经典三消游戏，匹配糖果完成关卡目标

## 玩法规则

玩家在8×8的网格上交换相邻糖果，使3个或更多同色糖果连成一行或一列来消除。消除后上方的糖果会下落填补空缺，产生连锁反应。

游戏有数千个关卡，每个关卡有不同的目标（达到分数、清除果冻、收集特定物品等）。

特殊消除组合：4个一排产生条纹糖果（消除整行/列），L或T形产生包装糖果（爆炸消除3×3区域），5个连珠产生彩虹球（消除所有同色糖果）。玩家有5条命，失败扣一条，随时间恢复。

## 核心循环

交换糖果消除 → 达成关卡目标 → 获得星级评价 → 解锁下一关

## 核心机制

- 特殊糖果合成：4个/5个连珠产生强力消除道具，策略性极强
- 连锁反应：消除后下落可能触发自动消除，形成爽快感
- 关卡目标多样化：分数、果冻清除、成分收集等不同机制保持新鲜感
- 步数限制：需要在有限步数内达成目标，增加策略思考

## 为什么好玩

极简的规则配合丰富的关卡变化，每次消除的视觉和听觉反馈极其满足。特殊糖果的合成和爆炸效果让人上瘾。

## 粘性来源

关卡驱动的进度感（再过一关就睡觉）；步数限制带来的差一点不甘心；社交竞争（好友排行榜）；每日奖励和限时活动。

## Meta 系统

关卡进度系统，玩家逐关解锁。有辅助道具系统（锤子、彩虹球+条纹组合等），可通过真实货币购买。

## 实现难度

低。三消核心玩法极其简单直观，适合所有年龄层。最大技术难点：关卡设计和难度曲线，以及消除算法的高效实现。


## 适合人群

- 喜欢碎片时间快速游玩的休闲玩家
- 偏好轻松无压力体验的玩家
- 对游戏类型有兴趣但不想投入大量时间的新手

## 同类游戏对比

- 与同类游戏相比，该游戏在操作简洁性和核心循环的吸引力方面表现突出
- 适合借鉴其核心机制用于小游戏开发
