# Cling Thing

- **类型**: 动作 / 物理攀爬
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款物理驱动的攀爬游戏，玩家控制一个能粘附在墙面上的小球状角色，在各种障碍物之间攀爬前进

## 玩法规则

游戏呈现一个垂直滚动的关卡画面。主角是一个球形小生物，可以粘附在任何接触到的平坦表面上。

玩家点击屏幕让主角从当前表面弹射出去，松手后主角沿抛物线飞行，直到粘附到另一个表面上。弹射方向由主角当前位置和弹射力度决定，可以通过滑动调整角度。

关卡中布满各种可粘附的平台、墙壁和障碍物。部分表面是危险的（尖刺、火焰、旋转刀片），粘附上去即失败。部分关卡有移动平台和旋转障碍，需要把握时机弹射。

目标是从关卡底部攀爬到顶部出口。在有限时间内完成即过关。部分关卡收集隐藏星星可获得额外评价。高难度关卡要求在所有星星收集完毕后才开启出口。

部分关卡设有风向系统，弹射后的飞行轨迹会受到风力影响，需要调整弹射角度。隐藏关卡通过收集所有星星后解锁，难度大幅提升。

## 核心循环

弹射→粘附→再弹射 → 向上攀爬通过关卡 → 收集星星

## 核心机制

- **弹射物理**：每次弹射有角度和力度，需要预判落点
- **危险表面**：尖刺和火焰区域增加紧张感，考验精准度
- **限时挑战**：部分关卡有倒计时，增加紧迫感

- **风向系统**：风力影响弹射轨迹，需要预判风偏


## 为什么好玩

简单的一键操作带来丰富的物理变化，每次弹射都是一次小型赌注。成功找到完美路径的成就感很强。

## 粘性来源

物理攀爬的随机性+'差一点就够到'的遗憾感驱动重复尝试。每关收集星星的额外目标增加重玩价值。

## Meta 系统

无。纯关卡挑战。

## 实现难度

中 — 简单操作但需要良好的物理预判能力。最大技术难点是稳定的物理引擎和碰撞检测。
