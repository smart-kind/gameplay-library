# 攻击洞洞（Attack Hole）

- **类型**: 物理弹射 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Homa Games
- **首次发布**: 2022
- **一句话描述**: 玩家发射小球穿过各种障碍物，收集沿途的洞口，体验物理碰撞的爽快感

## 玩法规则

游戏画面是一个俯视或略带角度的3D场景，场景中散布着各种几何形状的障碍物（方块、圆柱、三角锥等），每个障碍物上都有若干"洞"。屏幕底部有一个球台/发射器，玩家控制球台左右移动来调整发射方向。

玩家点击屏幕发射小球，球会以一定速度飞向障碍物。球穿过障碍物上的洞时会"吸收"洞，障碍物上的洞数量逐渐减少。当障碍物上所有洞都被穿过后，障碍物碎裂消失。有些障碍物需要多次撞击才能完全摧毁。

每个关卡有固定数量的球，玩家需要在球用完之前清除所有障碍物。球的数量限制构成了核心策略——玩家需要选择最优的发射角度，让一个球尽可能多地穿过多个洞。

游戏的目标是在限定球数内清除场景中的所有障碍物，过关后解锁下一个关卡。

## 核心循环

瞄准发射 → 球穿过洞收集/摧毁障碍物 → 清除所有障碍物进入下一关

## 核心机制

- **物理弹射机制**：球遵循真实的物理反弹规律，碰到障碍物边缘会弹开，这增加了策略性——玩家可以利用反弹让球穿过原本够不到的洞。
- **多层障碍设计**：不同形状的障碍物有不同的"硬度"，有的需要穿一次就碎，有的需要穿多次。方块、圆柱等不同形状带来不同的物理反馈。
- **洞口分布策略**：洞在障碍物上的位置不是均匀分布的，玩家需要找到最佳角度让球串过尽可能多的洞，类似台球中的"一杆清台"快感。
- **有限球数限制**：每关球数有限，制造了资源管理压力，让玩家思考而非盲目发射。
- **连锁反应设计**：某些关卡中，摧毁一个障碍物会引发连锁反应，导致相邻障碍物倒塌或移位，创造额外得分机会。

## 为什么好玩

Attack Hole 的爽感在于球穿过多个洞时一连串"啵啵啵"的清脆反馈，配合碎片飞溅的视觉效果，每次成功串洞都是一次多巴胺释放。关卡由简到难递进，前期很容易过，后期需要精确计算角度。物理碰撞带来的随机性让每次发射都有微妙的不同体验。

## 粘性来源

"差一个就通关"的不甘心是核心驱动力——明明只差最后一个洞，但怎么都穿不过去。这种"就差一点点"的感觉让人忍不住再来一局。同时每关球数刚好够用但容错率低，激发了"我明明可以做得更好"的心理。全球排行榜和好友分数比较进一步增强了竞争动力。

## Meta 系统

关卡制推进，每关独立无累积数值。解锁新关卡作为主要成长反馈，无外围数值系统。部分关卡需要收集一定数量的星星解锁。有简单的成就系统记录玩家的里程碑表现。

## 实现难度

低 — 核心是简单的3D物理碰撞检测（球-障碍物-洞的相交判断）。最大的技术难点是精确的碰撞判定和流畅的物理反弹计算，需要处理球同时穿过多层障碍物的情况。移动端性能优化是另一个考虑点。


游戏有多个章节，每章节有独特的视觉主题和障碍物设计风格。
