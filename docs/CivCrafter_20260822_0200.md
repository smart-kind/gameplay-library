# 文明工匠（CivCrafter）

- **类型**: 放置/策略
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2015
- **一句话描述**: 文明发展的放置类游戏

## 玩法规则

玩家放置工人进行资源采集和文明建设。工人自动执行任务，产出资源。资源用于升级工具、解锁新工人、建造建筑。随着文明进步，可解锁新的技术和建筑类型。游戏节奏缓慢，适合长时间放置。离线时工人仍继续工作并积累资源。玩家通过策略性选择升级路径来优化资源产出。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

放置工人 → 产出资源 → 升级工具/解锁新内容 → 效率提升 → 继续发展

## 核心机制

- **自动生产**:  工人自动采集资源
- **升级系统**:  资源用于提升效率和解锁新内容
- **离线收益**:  离线时继续积累资源

## 为什么好玩

见证文明从小到大的成就感，数值成长的满足感

## 粘性来源

持续升级的数值成长；离线收益降低回归门槛

## Meta 系统

文明升级系统，从原始到现代的多阶段发展

## 实现难度

低 - 核心是数值计算和资源管理 - 数值平衡，确保长期可玩性
