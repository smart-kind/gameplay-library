# 谁是？脑力激荡与谜语（Who is? Brain Teaser & Riddles）

- **类型**: 解谜 / 脑力 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: UNICO STUDIO
- **首次发布**: 2020
- **一句话描述**: 通过观察场景细节、发挥创意思维解答各种脑筋急转弯和谜语，挑战你的逻辑推理和跳出框架思考的能力。

## 玩法规则

游戏画面展示一个2D卡通场景，包含人物、物体和互动元素。每个关卡提出一个问题或谜题，玩家需要在场景中寻找线索并通过各种操作找到答案。

操作方式多样且充满创意：点击场景中的物体进行互动、拖拽角色或物品、摇晃设备、吹麦克风、甚至需要把手机倒过来看。答案往往不在"显而易见"的地方，需要玩家跳出常规思维——比如把两样不相关的物品组合起来、改变场景的视角、或者利用"第四面墙"打破游戏本身的规则。

每个关卡有提示系统（消耗虚拟道具），如果实在想不出可以点击提示获得方向性引导。部分关卡的答案故意设置得很"无厘头"，解开后会让人会心一笑。

## 核心循环

观察场景和谜题 → 尝试各种操作和思路 → 找到答案过关 → 遇到难题使用提示 → 进入下一关

## 核心机制

- **反常规思维**：答案往往违背玩家的直觉预期，需要"跳出盒子思考"，这是游戏最大的魅力所在
- **多样化交互**：不局限于点击——拖拽、摇晃、吹气、倒转、甚至关闭屏幕都可能成为解题手段
- **场景线索隐藏**：关键线索隐藏在场景细节中，培养玩家的观察力和耐心

## 为什么好玩

Who is? 系列的乐趣在于那种"我怎么没想到"的顿悟时刻。每个谜题的答案在揭晓后都显得"理所当然"，但在揭晓前却怎么也想不出来——这种认知落差带来了极大的满足感。游戏的幽默风格也让失败变得有趣而非挫败。

## 粘性来源

- **海量关卡**：数百个精心设计的谜题提供持续的挑战内容
- **解谜满足感**：每解开一个谜题都是一次小小的智力胜利，产生强烈的成就感
- **社交分享**：有趣的答案和"被套路"的经历天然适合分享给朋友

## Meta 系统

包含提示道具系统和关卡解锁。玩家通过过关获得金币，用于购买提示。没有竞争性排行，纯粹的单人解谜体验。部分版本包含每日挑战和社区投票。

## 实现难度

中。单个关卡的技术实现简单，但谜题设计是核心难点——每个谜题需要独特、有趣、有逻辑的答案，且不能与之前的谜题重复。最大挑战在于确保谜题既有创意又不让大多数玩家感到"不公平"。
