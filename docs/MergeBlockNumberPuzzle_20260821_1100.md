# 合并方块 - 数字谜题（Merge Block - Number Puzzle）

- **类型**: 益智 / 数字合并 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: LIHUHU PTE. LTD.
- **首次发布**: 2019
- **一句话描述**: 一款射击式数字合并益智游戏，玩家发射数字方块与棋盘上相同数字碰撞合并，目标合成2048及更高数字。

## 玩法规则

游戏画面中央是一个网格状棋盘，棋盘上分布着各种数字方块（2、4、8、16等）。屏幕下方是发射器，显示当前可发射的数字方块。

玩家点击屏幕瞄准并发射数字方块。方块沿直线飞行，落入棋盘上的空位或落在已有方块之上。当发射的方块与棋盘上相邻的相同数字方块接触时，两者合并为一个数字翻倍的方块。

每次合并后，系统会在棋盘上生成新的数字方块，保持棋盘上的方块数量。玩家需要策略性地选择发射位置，让相同数字的方块尽可能相邻，以便后续合并。

游戏没有步数限制，玩家随时可以暂停并保存进度。当无法继续有效合并时，玩家可以使用锤子道具移除方块或使用扳手道具交换两个方块的位置。

## 核心循环

瞄准发射 → 数字方块合并翻倍 → 收集钻石 → 使用道具备战 → 挑战2048及更高数字

## 核心机制

- **射击式合并机制**：不同于传统拖拽合并游戏，本作采用射击方式放置方块。玩家需要预判方块的落点和弹道，增加了操作技巧和策略深度。
- **多主题视觉**：游戏提供多种视觉主题，玩家可以根据喜好切换不同的方块外观和背景风格。这让长期游玩保持新鲜感。
- **道具辅助系统**：锤子可以移除任意一个方块，扳手可以交换两个方块的位置。这些道具帮助玩家清理棋盘或创造合并机会，但数量有限，需要合理使用。
- **自动保存系统**：玩家可以随时暂停游戏，系统自动保存当前进度。适合碎片化时间的休闲玩家，可以在任何时间继续游戏。

## 为什么好玩

射击式方块放置比拖拽式更有操作感和技巧性——每次发射都是一次小小的瞄准挑战，命中合并时产生满足感。游戏的节奏由玩家完全控制，没有时间压力，适合想要放松又需要动脑的玩家。

## 粘性来源

2048的数字目标是最直接的粘性来源——玩家总想着"再合并一次就达到了"。每日挑战和钻石收集系统提供了额外的短期目标。多主题切换让玩家在视觉疲劳时有新的体验。

## Meta 系统

游戏包含每日挑战和钻石收集系统。通过完成每日目标获得钻石奖励，钻石可用于购买道具和解锁主题。无复杂的付费成长系统。提供付费去广告订阅选项。

## 实现难度

低。方块合并逻辑和射击物理都是成熟的技术方案。最大的技术难点在于棋盘状态管理和合并检测算法——需要准确判断相邻方块并处理连续合并的情况。
