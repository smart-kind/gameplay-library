# 传送门2（Portal 2）

- **类型**: 解谜 / 第一人称 / 物理
- **平台**: Steam / Xbox / Nintendo Switch
- **开发商**: Valve
- **首次发布**: 2011
- **一句话描述**: 用传送门枪创造空间通道来解决物理谜题，在荒诞幽默的科幻世界中探索的传奇解谜游戏。

## 玩法规则

游戏以第一人称视角呈现。玩家手持一把"传送门枪"，可以在特定的表面（通常是白色墙壁）上创建两个传送门——蓝色入口和橙色出口。从蓝色传送门进入的物体会从橙色传送门出来，反之亦然。

游戏的核心物理规则是动量守恒："速度进，速度出"（Speedy thing goes in, speedy thing comes out）。如果你从一个高处跳入传送门，你会以同样的速度从另一个传送门飞出。这个简单的规则是整个游戏所有谜题的基础。

关卡中散布着各种机关和物体：
- **按钮**：需要放置物体压住来激活
- **方块**：可以搬运、推动，用于压按钮、挡激光等
- **激光**：可以被重定向、反射或阻挡
- **凝胶**：蓝色凝胶让表面弹跳，橙色凝胶让表面加速，白色凝胶让表面可以创建传送门
- **炮塔**：会射击的移动障碍物，需要规避或利用

每个房间都是一个谜题，需要利用传送门和各种机关的组合来找到通往出口的路径。

## 核心循环

进入房间 → 观察所有机关和可用表面 → 放置传送门创造路径 → 利用动量守恒和机关解决谜题 → 进入下一房间

## 核心机制

- **传送门创造**：在两个白色表面之间创建双向通道，是解决所有谜题的基础工具
- **动量守恒**：从传送门进出时保持速度，是创造"传送门弹射"等高阶技巧的核心
- **凝胶系统**：三种凝胶（弹跳、加速、传送）为谜题增加了额外的维度
- **时间挑战**：部分关卡有时间限制，增加了紧迫感
- **叙事驱动**：游戏有完整的剧情线，通过环境叙事和角色对话推进

## 为什么好玩

Portal 2 的伟大之处在于它把简单的物理概念（动量守恒、空间通道）发挥到了极致。当你第一次成功利用传送门完成一个长距离弹射时，那种"我理解了这个世界"的感觉是无与伦比的。游戏的幽默也是一大亮点——GLaDOS 的讽刺性旁白和 Wheatley 的笨拙性格让解谜过程充满笑声。

## 粘性来源

1. **物理顿悟**——每次掌握一个新的传送门技巧都会打开全新的解谜可能性
2. **叙事驱动**——剧情和角色让人想要知道"接下来会发生什么"
3. **创意解谜**——每个房间都有多种解法，鼓励玩家尝试不同的思路
4. **社区挑战**——社区创造的测试房间提供了无限的额外内容

## Meta 系统

无传统 Meta 系统。但有成就系统和合作模式的双人解谜。

## 实现难度

高。核心技术是传送门的空间渲染和物理模拟——物体穿过传送门时的速度、角度和方向需要精确计算。最大技术难点是渲染引擎：传送门需要实时渲染另一个视角的场景，这在技术上非常复杂。Valve 为此专门开发了自定义的渲染管线。
