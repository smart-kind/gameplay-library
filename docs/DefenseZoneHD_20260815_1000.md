# Defense Zone HD

- **类型**: 塔防 / Tower Defense
- **平台**: Mobile (iOS+Android)
- **开发商**: ARTEM KOTOV
- **首次发布**: 2010
- **一句话描述**: 一款在移动平台上发布的塔防类型游戏

## 玩法规则

经典塔防游戏。画面呈现俯视地图，敌人沿固定路线前进，玩家在路边放置防御塔进行拦截。

玩家点击屏幕底部的防御塔图标（机枪塔、炮塔、冰冻塔、导弹塔等不同类型），再点击地图空白区域放置。每种塔消耗不同金币，升级需要更多投入。敌人波次从屏幕一侧出现，沿预设路径移动到达终点即扣除生命值。

每个操作有即时视觉反馈：机枪塔射出弹道，炮塔范围爆炸，冰冻塔减速区域。不同防御塔有独特优势——机枪射速快但伤害低，炮塔范围伤害但射速慢，冰冻塔不杀敌但减速辅助。

游戏目标是在限定生命值内防守所有波次敌人，每关通过后获得金币用于下一关购买和升级防御塔。生命值归零则游戏失败。

## 核心循环

放置防御塔 → 消灭敌人获得金币 → 升级/新增防御塔 → 防守更难波次

## 核心机制

- **多类型防御塔**：4-6 种塔各有特色，需要针对不同敌人类型搭配
- **升级系统**：每个塔可多次升级，提升射程/伤害/射速
- **波次递增**：敌人数量和种类逐步增加，考验布局策略

## 为什么好玩

每次成功防守一波敌人后的快感很强烈，尤其是用精心布置的防御塔配合消灭大量敌人时。升级防御塔看到战力提升的正反馈也很到位。

## 粘性来源

策略深度——每关需要不同的塔配置，失败后重新调整布局的欲望很强。'差一点就能守住'的不甘心感驱动反复挑战。

## Meta 系统

- **防御塔升级**：每个塔可多次升级提升属性，消耗金币
- **解锁新塔**：通过关卡解锁新类型防御塔，增加策略维度
- **对核心玩法的影响**：新塔类型直接改变防守策略，从单一输出到组合搭配

## 实现难度

低——塔防是成熟的游戏类型，有标准实现范式。最大的技术难点是大量单位同时存在时的性能优化（弹道计算、碰撞检测）。路径查找算法（A*）是基础需求。
