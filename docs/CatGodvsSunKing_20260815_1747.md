# 猫神 vs 太阳王（Cat God vs Sun King）

- **类型**: 塔防 / 策略
- **平台**: Web (Flash)
- **开发商**: nerdook
- **首次发布**: 2011
- **一句话描述**: 扮演猫神，运用各种神力阻止太阳王的仆从建造神庙的塔防游戏

## 玩法规则

玩家在屏幕上方扮演猫神，太阳王的仆从从下方不断涌来试图建造神庙。
猫神可以使用多种神力：闪电劈击、地震、召唤猫咪、降下火球等。
每种神力有不同的冷却时间和效果范围，需要合理分配使用时机。
仆从会搬运建材到神庙工地，神庙建到100%时游戏失败。
用神力击杀仆从、破坏建材来延缓神庙建造进度。
连续击杀获得连击奖励，提高神力的威力。
多个关卡难度递增，仆从种类增多（盾兵、快速搬运工、建筑师等）。

## 核心循环

观察敌人路线 → 选择神力攻击 → 击杀仆从破坏建材 → 应对更强的敌人波次

## 核心机制

- 多神力切换系统：多种神力各有特点（单体高伤/群体低伤/持续效果），需要根据敌人类型灵活切换
- 神庙建造倒计时：与传统塔防的"到达终点"不同，这里用神庙建造百分比作为失败条件，增加了紧迫感
- 连击奖励机制：连续击杀提高神力威力，鼓励玩家保持攻击节奏

## 为什么好玩

扮演神明施展各种神力的感觉非常爽快。闪电劈中一群敌人的瞬间满足感爆棚。猫神可爱的形象和毁灭性的神力形成有趣的反差萌。

## 粘性来源

连击系统让每次游玩都有"这次我要保持更高连击"的目标。关卡难度曲线设计合理，每关都有新的挑战点。

## Meta 系统

神力解锁系统：随进度获得新神力。关卡评价系统（基于连击数和剩余时间）鼓励重复挑战。

## 实现难度

中 — 多神力系统需要良好的UI设计和平衡调校，敌人AI的路径规划也是技术难点


神力包括：闪电链（弹射多个目标）、地震波（范围伤害）、猫雨（召唤猫群攻击）、火柱（持续伤害）。
仆从种类包括普通搬运工、盾兵（免疫正面攻击）、工程师（加速建造）、巨人（大量建材）。
连击系统最高可达50连击，每10连击解锁一个临时神力增强。
游戏有多个场景主题：沙漠、火山、海底等，每个场景有独特的仆从类型。
