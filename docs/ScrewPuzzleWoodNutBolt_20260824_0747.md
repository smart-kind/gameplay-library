# 螺丝解谜：木螺母与螺栓（Screw Puzzle: Wood Nut & Bolt™）

- **类型**: 螺丝解谜 / 物理益智 / 逻辑推理
- **平台**: Mobile (iOS + Android)
- **开发商**: FALCON GAMES
- **首次发布**: 2023
- **一句话描述**: 通过按正确顺序拧下螺丝钉来释放木板上零件的益智解谜游戏。

## 玩法规则

游戏画面中呈现一块木板，上面用螺丝钉（螺栓）固定着若干形状的木块/金属板。每个螺丝钉穿过一个或多个层叠的板材孔洞。玩家点击一颗螺丝钉可以将其拧下，螺丝钉会从木板上脱落。

关键规则是：螺丝钉的拆卸顺序决定了解谜的成败。当一颗螺丝钉被拧下后，穿过该螺丝的板材如果不再被其他螺丝固定，就会因重力脱落。但如果板材仍被其他螺丝固定，它们会保持在原位。

玩家的目标是找出正确的螺丝拆卸顺序，让所有板材全部脱落。部分螺丝可能被其他板材遮挡，需要先拆掉上层板材才能接触到被遮挡的螺丝。每个关卡的板材形状、孔洞位置和螺丝数量各不相同。

## 核心循环

观察板材层叠关系 → 选择螺丝拧下 → 判断板材是否脱落 → 逐步解锁所有零件 → 通关

## 核心机制

- **层叠遮挡机制**：螺丝和板材形成多层结构，玩家必须理解空间上的前后关系——上层板材可能遮挡下层螺丝的拆卸路径。
- **重力脱落机制**：当板材的所有固定螺丝被移除后，重力使其自然落下，提供直观的物理反馈。
- **顺序依赖**：错误的拆卸顺序可能导致螺丝被永久锁定无法取出（被其他板材卡住），迫使玩家重思考。

## 为什么好玩

"看一眼就知道大概但真正动手才发现没这么简单"——这种认知落差是核心乐趣。每解开一个关卡都有"原来如此"的顿悟感，螺丝拧下的物理反馈（旋转动画、金属音效）也极具满足感。

## 粘性来源

空间推理的挑战性——从简单的2-3层板材到后期复杂的多层交叉结构；"差一步就解开了"的遗憾驱动重试；关卡数量大且难度递进，提供了明确的进度感。

## Meta 系统

轻度外围系统：关卡解锁进度图、星星评价（根据步数或时间评级）。无数值成长。

## 实现难度

中。核心难点在于物理引擎的精确模拟——需要判断每颗螺丝拆卸后哪些板材会因重力脱落，同时处理板材之间的碰撞和遮挡关系。如果使用真实物理引擎，性能优化和确定性（保证每关可解）是最大挑战。
