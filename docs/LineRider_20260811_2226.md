# 线骑士（Line Rider）

- **类型**: 创意沙盒 / 物理模拟 / 解谜
- **平台**: Web（浏览器）/ Windows / Flash（已淘汰）
- **开发商**: Boštjan Čadež（fšk）
- **首次发布**: 2006
- **一句话描述**: 玩家在画布上绘制线条轨道，然后让一个骑雪橇的小人沿着轨道滑行——轨道就是你的关卡设计

## 玩法规则

游戏画面是一个空白画布，玩家可以自由绘制线条（直线段）。绘制完成后，点击"播放"按钮，一个骑着小雪橇的卡通小人从起点出发，沿着你绘制的线条轨道滑行。

物理引擎模拟重力、惯性、摩擦力——小人会沿着线条的斜度加速或减速，在转弯处有离心力效果。如果轨道不连续（线条之间有断点），小人会从断点处飞出并坠落。如果轨道形成闭环或死路，小人会在上面停下来。

游戏没有预设关卡或目标——完全是一个创意沙盒。玩家可以设计简单的斜坡让小人飞越障碍，也可以设计复杂的过山车式轨道，甚至利用物理引擎的"漏洞"创造出超现实的轨道效果。社区中有很多精心设计的作品——从简单的滑行轨道到利用物理特性实现的"永动机"。

## 核心循环

绘制线条轨道 → 播放观察滑行效果 → 调整轨道 → 重新播放

## 核心机制

- **物理模拟引擎**：基于重力和惯性的小人运动模拟。线条的斜度决定加速度，转弯处有离心力，断点处会自由落体。物理引擎有一定的"宽容度"——小人可以在轨道上轻微弹跳而不坠落。
- **自由绘制系统**：玩家用鼠标绘制线段，线条连接在一起形成连续轨道。没有预设形状限制——你可以画任何你能想到的轨道形状。
- **无目标沙盒**：游戏不提供关卡或挑战，完全依靠玩家的创造力驱动。社区中形成的"挑战"包括：设计最长的连续轨道、最复杂的循环、利用物理引擎特性实现的效果等。

## 为什么好玩

Line Rider 的魅力在于"创造即玩法"——你不需要高超的反应速度或解谜能力，只需要想象力和耐心。看到自己设计的轨道让小人流畅滑行时的满足感，和发现物理引擎带来的意外效果时的惊喜感，是它最大的乐趣。

## 粘性来源

- **创造性表达**：每个人设计的轨道都不同，分享和比较作品是持续的动机
- **物理引擎的意外性**：即使是有经验的玩家，也经常会发现物理引擎带来的意外效果（比如小人在某个角度会弹飞）
- **社区挑战**：社区中有人设计"不可能轨道"、"最长轨道"等挑战，激发创作欲

## Meta 系统

无。纯沙盒创意工具。

## 实现难度

中 + 核心难点是物理引擎的精确模拟（重力、惯性、碰撞、摩擦力）和线段连接的连续性检测。最大技术难点是物理引擎的稳定性——要避免小人在高速运动时穿模或出现不自然的弹跳。
