# Bloxd.io

- **类型**: 沙盒建造 / 多人竞技 / 跑酷
- **平台**: Web (浏览器)
- **开发商**: Arthur
- **首次发布**: 2021
- **一句话描述**: Minecraft风格的IO多人游戏，融合跑酷、建造、战斗等多种模式，支持全球玩家实时对战

## 玩法规则

Bloxd.io 是一款 IO 风格的多人冒险游戏，采用类似 Minecraft 的方块像素视觉风格。进入游戏后，玩家可以选择多种不同的游戏模式，每种模式有独立的玩法规则和目标。

游戏主界面提供模式选择入口。玩家进入某个模式后，会与其他全球玩家分配到同一服务器。游戏支持最多 19 人的多人房间，即时匹配，无需等待。

### BloxdHop.io（跑酷模式）

玩家需要在限时内通过跳跃穿越各种形状和大小的方块平台，从起点到达终点。平台间距不等，有些平台很小或会移动，增加了跳跃难度。时间用尽则挑战失败。

### DoodleCube（创意模式）

类似 Gartic.io 的玩法。系统给出一个主题，玩家需要用方块搭建出符合主题的物品或场景。其他玩家可以投票评分，决定谁的作品最符合主题。

### EvilTower（高塔跑酷）

受 Tower of Hell 启发的垂直跑酷挑战。玩家需要从塔底一路向上跳跃攀爬，每一层都有不同难度的障碍和平台。没有检查点，失败后需要从头开始。

### BedWars（起床战争）

经典的起床战争玩法。团队保护己方的床同时摧毁对手的床。资源收集、购买装备、团队配合是关键。

### Controls（操作方式）

- WASD 键移动角色
- Shift 键或双击 W 键跑步
- C、Z、\ 或 Caps Lock 键蹲下
- T 或 Enter 键打开聊天
- B 键打开商店
- / 键输入命令
- O 键打开菜单

## 核心循环

选择模式 → 加入多人服务器 → 完成模式目标 → 获得经验/奖励 → 解锁新内容 → 尝试不同模式

## 核心机制

- **多模式系统**：一个游戏入口包含跑酷、建造、PvP、创意等多种模式，每种模式有独立规则
- **方块建造/破坏**：类似Minecraft的放置和破坏方块机制，是多个模式的基础
- **多人实时对战**：最多19人同服竞技，匹配快速，支持即时加入
- **资源收集与制作**：在生存类模式中收集木材、石材、铁矿等资源，制作工具和装备
- **进度保存**：云端保存玩家进度，跨设备可继续

## 为什么好玩

多模式设计让一个游戏提供了多种完全不同的体验——想挑战反应力就玩跑酷，想发挥创意就去DoodleCube，想社交对战就玩BedWars。低门槛的方块操作加上丰富的内容，无论是Minecraft老手还是新玩家都能找到乐趣。

## 粘性来源

多模式切换是最大的粘性来源——跑酷玩累了可以换建造，社交玩多了可以来单人挑战。此外，角色外观解锁系统（通过游戏内货币）提供长期收集目标。多人社交的不确定性——你永远不知道会遇到什么玩家、什么局面——每局都是全新的。

## Meta 系统

- **角色/外观解锁**：通过游戏内货币或成就解锁新皮肤和特效
- **经验等级系统**：持续游玩获得经验，提升等级解锁新内容
- **多人社交系统**：聊天、好友、组队功能
- **排行榜**：各模式的最高分排名
- 对核心玩法有辅助作用——高等级可能解锁新的游戏模式入口

## 实现难度

中 — 多模式系统的架构复杂度较高，需要为每种模式实现独立的游戏逻辑。最大的技术难点是多人实时同步（状态同步、延迟补偿、反作弊）以及方块世界的性能优化（大量方块的渲染和物理计算）。
