# Classic Bubble Pop-Ball Games

- **类型**: 益智消除 / 泡泡射击
- **平台**: Mobile (iOS)
- **开发商**: Angel Interactive Limited
- **首次发布**: 2018
- **一句话描述**: Classic Bubble Pop是一款经典的泡泡消除游戏，包含300加关卡。玩家通过匹配彩色泡泡来完成挑战，目标是获得3星评价。

## 玩法规则

游戏屏幕上方是彩色泡泡阵列，下方是发射器。底部显示当前泡泡颜色（可通过点击切换）。瞄准并发射泡泡，匹配3个或更多相同颜色的泡泡使其消除。消除泡泡获得分数。特殊机制：可以无限制地交换泡泡颜色：点击当前泡泡即可切换颜色，这给了玩家更多策略选择。每个关卡有特定的挑战目标，完成关卡后根据得分获得1到3星评价。游戏包含300加关卡，逐步增加难度。

## 核心循环

选择泡泡颜色 -> 瞄准发射 -> 匹配消除 -> 获得分数和星级 -> 解锁新关卡 -> 重复

## 核心机制

- 颜色切换：无限制切换泡泡颜色，增加策略灵活性
- 星级评价：每个关卡1到3星，追求完美通关
- 300加关卡：逐步增加难度的关卡设计
- 特殊奖励：完成挑战获得特殊奖励

## 为什么好玩

无限制颜色切换是这款游戏区别于其他泡泡射击的独特机制：你不再受限于随机给出的下一个泡泡颜色，可以主动选择最有利的颜色。300加关卡提供了充足的游玩时间。

## 粘性来源

300加关卡提供长期内容；星级评价系统追求完美通关的动力；颜色切换机制增加策略深度

## Meta 系统

有星级评价系统（每关1到3星）、特殊奖励系统。无其他外围系统。

## 实现难度

中。核心难点在于益智消除玩法的平衡性设计和UI交互优化。移动端的触控适配需要精细调校。
