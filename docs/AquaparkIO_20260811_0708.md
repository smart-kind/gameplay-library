# Aquapark.io（Aquapark.io）

- **类型**: 休闲 / 竞速 / 多人竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2019
- **一句话描述**: 在水上乐园滑梯上竞速，通过摆动身体和跳跃Shortcut超越对手

## 玩法规则

游戏以一个水上乐园的滑梯赛道为场景。玩家控制一个滑梯上的小人，从高处向下滑行。画面是第三人称后方视角，可以看到前方蜿蜒曲折的滑道和周围的对手。

操作很简单：左右滑动屏幕控制滑行方向。当滑到弯道时，小人会自然减速。但如果玩家在弯道处按下屏幕并滑动，小人会从滑梯上跳起来，在空中做特技动作，然后落在前方更远的位置——这就是游戏的核心"捷径"机制。

赛道上有多个弯道和分叉点。捷径跳跃如果成功落地，可以大幅缩短距离；但如果跳跃角度不对，可能落在滑梯外面导致失败。

游戏支持多人同时竞技（通常是8-10人），最先到达终点的获胜。

## 核心循环

滑行 → 弯道加速 → 捷径跳跃 → 落地继续滑行 → 到达终点

## 核心机制

- **捷径跳跃（Shortcut）**: 在弯道处按住屏幕跳跃，角色离开滑梯在空中飞行。跳跃时机和方向决定了落地位置——完美的跳跃可以大幅缩短距离，失败的跳跃会落到滑梯外。
- **物理摆动**: 角色在滑梯上会自然左右摆动，玩家需要微调方向保持在轨道上。这种摆动感创造了"水上乐园"的真实体验。
- **多人竞争**: 与多个对手同时比赛，可以看到前后位置的变化，增加了紧张感。
- **赛道多样性**: 不同关卡有不同的滑梯布局——有的更弯曲需要更多捷径，有的有分叉路需要选择。

## 为什么好玩

捷径跳跃的成功瞬间有极强的快感——看着自己飞越弯道甩开对手的感觉令人上瘾。多人竞争让每次比赛都有变数。

## 粘性来源

- **捷径快感**: 成功跳出完美shortcut的成就感极强
- **多人竞争**: 实时与其他玩家排名对比，激发好胜心
- **关卡解锁**: 完成关卡解锁新赛道，保持新鲜感
- **低门槛**: 只需左右滑动+跳跃，任何人都能玩

## Meta 系统

角色外观解锁系统——通过游戏进度解锁不同的泳装、配饰等。不影响核心玩法，主要提供收集乐趣。

## 实现难度

中。核心是3D滑梯物理 + 捷径跳跃物理 + 多人同步。最大难点在于捷径跳跃的物理调校——需要让成功的跳跃有成就感，同时不至于太难或太容易。
