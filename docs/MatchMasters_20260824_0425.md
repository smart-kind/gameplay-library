# Match Masters

- **类型**: 三消对战 / 多人竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: Candivore
- **首次发布**: 2020
- **一句话描述**: 一款将三消玩法改造为1v1实时对战的创新游戏，两个玩家轮流在同一个棋盘中消除，消除不仅得分还能给对方制造障碍。

## 玩法规则

两个玩家进入同一场对战，共享一个消除棋盘，轮流进行操作。每局对战有明确的开始和结束，胜负分明。

每个玩家有独立的生命值（HP条）。轮到你回合时，你在棋盘上做一次消除。消除的分数转化为对对手的伤害，分数越高伤害越大。先将对方HP归零的玩家获胜。

连续消除（combo）累积加成倍率。消除同色元素激活该颜色的特殊技能。每种颜色对应一个boost增益效果：红色直接攻击造成更高伤害，蓝色防御盾减少受伤，绿色治疗恢复HP，黄色连击加成让下次消除翻倍，紫色特殊效果可以冻结对手或偷取分数。

每回合只能激活一个boost，需要在消除前选择。boost之间可形成协同组合。比赛前玩家选择一组boost组成卡组，类似卡牌游戏的卡组构建。

比赛模式包括1v1实时对战、异步对战（对方不在线时进行）、锦标赛多轮淘汰赛制和团队赛组队对抗。

## 核心循环

选择boost → 消除得分 → 攻击对手或防御 → 对手回合 → 循环直到一方HP归零

## 核心机制

- **消除即攻击**: 将三消分数直接转化为对战伤害，彻底改变三消玩法本质。传统三消是消除越多分越高，这里是消除是为了打人。这种转换让每次消除都有明确的对手反馈。消除的不仅是方块，还在给对方放血。

- **Boost卡组策略**: 赛前选择boost组成卡组，比赛中激活boost获得特殊能力。不同boost有不同效果：攻击型增加伤害，防御型减少受伤，功能型干扰对手。boost的选择和使用时机构成策略深度。什么时候进攻？什么时候防守？什么时候保留boost等更好消除机会？

- **共享棋盘博弈**: 两个玩家共享同一个棋盘，你的消除会改变棋盘布局，影响对手下一次操作。你可以故意消除某些元素让对手无法形成好消除，也可以利用对手消除后留下的布局来形成自己的combo。棋盘即战场设计让三消变成真正博弈游戏。

## 为什么好玩

三消爽感加上对战紧张感，构成独特混合体验。看到自己的消除直接变成对手掉血，这种即时反馈极其满足。boost的策略选择让游戏有深度，不是纯运气。异步对战让你随时可以进行比赛。

## 粘性来源

1v1对战的竞争欲加上boost收集的收集欲和锦标赛的成就感，构成高粘性。每局3-5分钟，适合碎片时间。异步对战不用等待对手在线。段位排名系统让家长期有目标追求。

## Meta 系统

Boost收集系统：解锁和升级各种boost。段位排名系统：从新手到大师多级段位。赛季通行证和特殊活动。角色头像等外观自定义。每日任务和挑战维持日常活跃。

## 实现难度

中。实时对战网络同步和棋盘状态一致性是技术难点。匹配系统和反作弊也是挑战。boost平衡性需要大量数据支撑。异步对战的存储和回放机制也需要设计。
