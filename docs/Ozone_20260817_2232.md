# 臭氧（Ozone）

- **类型**: 街机 / 休闲 / 隧道飞行
- **平台**: Mobile (iOS)
- **开发商**: 独立开发者
- **首次发布**: 2010
- **一句话描述**: 控制飞行器在狭窄管道中穿行的街机反应游戏

## 玩法规则

游戏采用类似"管道飞行"的核心玩法——玩家控制一架小型飞行器在狭窄的管道或隧道中穿行。管道不断向前推进（自动滚动），玩家需要左右/上下移动来避开管道壁上的障碍物和突然出现的障碍块。

随着游戏进行，管道会越来越窄，障碍物会越来越密集，速度也会加快。触碰障碍物会导致飞行器爆炸，游戏结束。生存越久，分数越高。

部分版本可能有收集要素——在管道中收集能量球或道具可以获得额外分数或特殊能力（护盾、减速等）。管道有各种几何变化：弯曲、分叉、突然收窄等。

管道形状的设计是游戏的核心挑战来源。弯曲管道要求玩家提前预判转弯角度；分叉管道给玩家选择——哪条路更安全或哪条路有更多收集品；突然收窄的管道段需要玩家快速减速或调整位置。这些几何变化让每条管道都像一条"空中赛道"。

部分版本可能有多种管道主题：科幻风格的金属管道、自然风格的洞穴隧道、未来风格的霓虹光管等。不同主题有不同的视觉反馈和障碍物风格。

## 核心循环

控制飞行器躲避障碍 → 在管道中存活 → 获得高分 → 挑战更高速度

## 核心机制

- **管道约束**：管道的几何形状本身就是最大的挑战。玩家需要精确控制飞行器在狭窄空间中的位置，稍有偏差就会撞上管壁。这种空间约束创造了持续的紧张感。管道形状随时间变化，增加了预判难度。
- **速度递增**：随着时间推移，管道推进速度越来越快，玩家的反应时间越来越短。这是经典的街机难度曲线设计，让玩家在"还能应付"和"完全失控"之间找到刺激点。
- **障碍物模式**：不同障碍物有不同的出现模式——固定障碍、移动障碍、突然出现的障碍。记住和预判这些模式是提高分数的关键。部分障碍物可以被收集或消除。
- **收集要素**：管道中散布的收集品给飞行路径增加了额外的目标——是冒险靠近收集，还是保守地保持在安全区域？这种风险/回报选择增加了策略性。

## 为什么好玩

Ozone 的紧张感来自于"在越来越窄的空间中越来越快地穿行"这种体验。它类似于经典的隧道飞行游戏，但加入了独特的视觉风格和逐步加压的难度曲线。简单操作下的极限反应挑战让人欲罢不能。

## 粘性来源

- **高分挑战**：街机游戏的经典驱动力——不断刷新自己的最高分
- **难度递增**：每次死亡后都想"这次我能走更远"
- **短局快玩**：一局通常只有几十秒到几分钟，适合反复尝试
- **收集追求**：追求收集所有能量球的完美路线

## Meta 系统

纯街机模式，以最高分为目标。可能有多个飞行器皮肤或主题解锁。无成长系统。

## 实现难度

中 — 需要快速反应和精确操控。最大技术难点是管道几何形状的随机生成算法和碰撞检测的精确度，以及高速移动时的画面流畅度。
