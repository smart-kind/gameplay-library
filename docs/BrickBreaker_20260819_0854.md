# Brick Breaker

- **类型**: 打砖块 / 弹球
- **平台**: Mobile (iOS+Android) / BlackBerry / Web
- **开发商**: Ali Asaria / Various
- **首次发布**: 2002
- **一句话描述**: 玩家控制底部挡板反弹球，击碎屏幕上方的砖块阵列

## 玩法规则

游戏画面中，屏幕上方排列着多行多列的彩色砖块。屏幕底部有一个可左右移动的挡板（paddle），挡板上有一个弹球。

玩家操作：
- 左右移动：控制挡板在屏幕底部水平移动（触屏滑动或键盘左右键）
- 发射：将球发射出去开始游戏

游戏目标：用挡板反弹球，击碎所有砖块即可过关。

核心规则：
- 球碰到砖块会弹回，砖块被击碎（部分砖块需要多次击打）
- 球碰到墙壁（左右和顶部）会弹回
- 球从底部漏出（未被挡板接住）则失去一条命
- 挡板需要精准接住球并控制反弹角度

特殊砖块：
- 普通砖块：一击即碎
- 强化砖块：需要多次击打
- 不可碎砖块：球会弹回但不会碎
- 掉落道具：某些砖块击碎后掉落道具（加长挡板、多球、激光等）

游戏结束条件：失去所有生命值

## 核心循环

反弹球击碎砖块 → 获得分数 → 可能掉落道具 → 清除所有砖块过关

## 核心机制

- **反弹角度控制**: 球碰到挡板不同位置会以不同角度反弹，边缘反弹角度大，中间反弹角度小，玩家需要精准控制
- **道具系统**: 击碎特定砖块掉落道具：加长挡板、多球模式、激光挡板、慢球等，增加策略和运气元素
- **多关卡设计**: 每关砖块布局不同，从简单到复杂，部分关卡有特殊砖块组合
- **多球模式**: 某些道具让球分裂成多个，同时管理多个球增加挑战和乐趣

## 为什么好玩

看着球在砖块间弹来弹去，一次性击碎多个砖块的连锁反应非常爽快。道具掉落带来惊喜感，多球模式让混乱变成乐趣。每关新布局保持新鲜感。

## 粘性来源

关卡递进和完美通关（不漏球）的成就感是主要粘性。收集所有道具和三星评价提供额外目标。

## Meta 系统

通常无外围成长系统。部分版本有关卡解锁或得分排名。

## 实现难度

低。物理反弹模拟和碰撞检测是核心技术点。难点在于球的物理手感调优，反弹角度要真实且可控。
