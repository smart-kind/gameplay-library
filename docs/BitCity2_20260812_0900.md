# Bit City 2

- **类型**: 放置 / 建造
- **平台**: Mobile
- **开发商**: NimbleBit
- **首次发布**: 2025
- **一句话描述**: 像素风格城市建设放置游戏——从小镇到大都市。

## 玩法规则

玩家从一个小城镇开始，逐步建造和升级建筑，最终发展为大都市。放置机制允许离线期间城市继续发展。

建筑升级和税收系统提供收入来源。决策在于资源分配——优先升级哪些建筑、何时扩展新区域。像素艺术风格简洁可爱。

## 核心循环

建造建筑 → 升级设施 → 收取税收 → 扩展城市

## 核心机制

- 城市建设：从小镇到大都市
- 建筑升级：提升收入和效率
- 税收系统：主要收入来源
- 放置自动化：离线期间发展
- 像素风格：简洁可爱的视觉

## 为什么好玩

从空地块到繁华都市的成长过程令人满足。每次升级建筑都看到收入增长，决策简单但有策略性。

## 粘性来源

- 城市成长的满足感：从小到大的可见进步
- 建筑升级：每次升级都有收入提升
- 资源分配：优先级的策略决策
- 像素美学：简洁可爱的视觉风格

## Meta 系统

建筑解锁和升级。通过收入建造新建筑、升级现有设施、扩展城市区域。

## 实现难度

低。城市建设放置核心系统简单，数值平衡是关键。
