# 神探鼠标（Danger Mouse）

- **类型**: 动作冒险 / 解谜
- **平台**: Nintendo 3DS
- **开发商**: D3 Publisher
- **首次发布**: 2011
- **一句话描述**: 基于经典英国动画改编的横版动作解谜游戏，玩家操控特工鼠完成各种任务

## 玩法规则

游戏采用横版卷轴视角，玩家操控Danger Mouse（特工鼠）在各种关卡中前进。核心操作包括跑、跳、攀爬、使用特殊道具。每个关卡都有特定的任务目标：潜入敌营、拆除炸弹、营救人质、收集线索等，任务类型多样化。

游戏结合动作平台跳跃和解谜元素——需要找到隐藏通道、解除机关陷阱、在限定时间内完成任务。3DS的触控屏用于操作小解谜环节，比如破解密码锁（旋转数字盘）、组拼图（拖动碎片）或绘制电路图（连接节点）。这些解谜环节穿插在平台跳跃流程中，调节游戏节奏。

关卡中散布着各种特工道具：绳索钩（用于跨越深沟）、烟雾弹（暂时迷惑敌人）、万能钥匙（解锁特殊门）、放大镜（发现隐藏线索）。合理使用道具是过关的关键。敌人在场景中巡逻，有视野范围和巡逻路径，玩家可以选择潜行绕过或正面解决。

## 核心循环

进入任务关卡 → 平台跳跃+解谜 → 完成目标 → 获得评分和解锁新关卡

## 核心机制

- **多任务类型系统**：潜入、拆除、救援、收集等不同任务类型要求不同策略。潜入任务需要避开敌人巡逻路线，拆除任务需要在限时内完成解谜，救援任务需要找到被关押的人质并护送撤离
- **特工道具系统**：收集和使用各种特工工具来通过障碍。道具有使用次数限制，需要在关卡中收集补充。不同道具组合可以创造出新的过关方式
- **时间压力与评分系统**：部分任务有倒计时，增加紧张感。通关后根据时间、收集物品数量和是否被发现来评定星级


## 为什么好玩

经典动画IP的魅力+横版动作解谜的经典组合。特工鼠的各种 gadgets 让过关方式多样化——同一条路可以用绳索飞越、用烟雾弹潜行、或用万能钥匙开门，每次找到新路线都有成就感。

## 粘性来源

关卡评级系统（时间/收集/无伤三星）驱动反复挑战。动画还原度高的角色和场景对粉丝有吸引力。隐藏道具的探索增加重玩价值。

## Meta 系统

无复杂Meta系统。关卡解锁和评级收集作为基础进度机制。部分版本有角色皮肤解锁。

## 实现难度

中 —— 平台跳跃+解谜的组合需要操作技巧和策略思维并重，最大技术难点是关卡设计和难度曲线控制，确保平台跳跃和解谜环节的难度平衡。
