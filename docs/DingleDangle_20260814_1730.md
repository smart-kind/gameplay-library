# 摇摆冒险（DingleDangle）

- **类型**: 休闲益智
- **平台**: Mobile (iOS+Android)
- **开发商**: PocketGamer 收录独立游戏
- **首次发布**: 2012
- **一句话描述**: 一款基于物理钟摆机制的休闲解谜游戏，通过控制绳索摆动来收集物品和通关

## 玩法规则

游戏画面采用横版2D视角，主角（通常是一个可爱的小角色）悬挂在一根绳索上，像钟摆一样在场景中来回摆动。背景色彩丰富，关卡设计风格各异。

核心操作非常简单：点击屏幕缩短绳索（使摆动加快、摆幅变小），松开手指延长绳索（使摆动减慢、摆幅变大）。通过精准控制绳索长度，玩家可以调整摆动的节奏和幅度。

每个关卡的目标是收集场景中散布的星星或其他收集品，并最终到达出口位置。收集品分布在需要特定摆动幅度和时机才能到达的位置，有些需要大幅摆动飞出去，有些需要在小幅度摆动时精准摘取。

场景中存在各种障碍物和危险元素：尖刺、移动平台、弹簧、风扇等。触碰障碍物会导致失败，需要重新开始关卡。部分关卡有时间限制，增加了紧张感。

物理引擎模拟了真实的重力和摆动效果，绳索的长度变化会实时影响摆动的物理参数。掌握摆动的物理规律是通关的关键。

## 核心循环

观察关卡布局和收集品位置 → 通过控制绳索长度调整摆动 → 收集物品 → 到达出口 → 进入下一关

## 核心机制

- **物理钟摆模拟：基于真实物理公式的钟摆运动，绳索长度直接影响摆动频率和幅度，是游戏的核心机制**
- **时机判断系统：需要在正确的时机缩短或延长绳索，以收集特定位置的物品或避开障碍。精准的时机把握是通关的关键**
- **渐进难度设计：从简单的单一摆动到需要多次节奏变化的复杂操作，难度逐步提升。后期关卡加入移动障碍和限时挑战**
- **场景互动元素：弹簧、风扇、移动平台等辅助或干扰元素，增加关卡的变化性和策略性**

## 为什么好玩

物理摆动的直观性和时机掌握的成就感。操作简单（只有点击和松开），但精通有难度，适合各种技能水平的玩家。可爱的角色和明亮的画面增加了亲和力。

## 粘性来源

基于物理的玩法每次尝试都有微妙不同，'差一点就完美'的感觉驱动重复游玩。收集品的全收集目标和关卡三星评价系统增加重玩价值。

## Meta 系统

关卡解锁和收集品追踪系统，部分版本有每日挑战模式。

## 实现难度

中，物理时序判断需要练习。最大技术难点在于物理引擎的准确性和手感调优。
