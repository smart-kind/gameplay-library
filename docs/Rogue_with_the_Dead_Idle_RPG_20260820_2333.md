# 僵尸生存：放置RPG（Rogue with the Dead: Idle RPG）

- **类型**: 放置 / RPG / 肉鸽
- **平台**: Mobile (iOS+Android)
- **开发商**: room6 LLC.
- **首次发布**: 2022
- **一句话描述**: 结合放置RPG和肉鸽元素，在僵尸末日中自动战斗、收集装备、不断变强。

## 玩法规则

游戏画面呈现俯视角的战斗场景。玩家控制一个幸存者角色，角色自动向前移动并攻击遇到的僵尸。

战斗是自动进行的——角色自动寻找最近的敌人、发动攻击、使用技能。玩家不需要实时操作，但可以在战斗前配置角色的装备、技能和属性加点。

击败僵尸后掉落金币、装备和经验值。金币用于升级角色基础属性（力量、敏捷、智力），装备可以直接穿戴或分解获取材料。

游戏采用肉鸽（Roguelike）结构：每次'跑图'从起点出发，经过多个房间/关卡，最终挑战Boss。如果在关卡中死亡，本次获得的临时增益全部丢失，但永久升级保留。

在安全区域（营地），玩家可以管理装备库存、升级技能树、查看任务进度。每次出发前可以选择不同的难度等级和奖励倍率。
## 核心循环

自动战斗击杀僵尸 → 收集金币和装备 → 升级属性和技能 → 挑战更高难度关卡 → 死亡后保留永久升级再次挑战

## 核心机制

- **自动战斗+肉鸽结构**：每次跑图的路径、敌人配置和掉落都是随机生成的，保证每次体验不同。但角色的永久升级跨局保留，降低挫败感。
- **装备收集与构建**：击杀掉落的装备有不同品质（普通、稀有、史诗、传说）和不同词缀。搭配不同装备可以构建不同的战斗风格。
- **难度阶梯与奖励倍率**：玩家可以选择从简单到极难的不同难度。难度越高，掉落越好，但死亡风险越大。这种风险/回报平衡驱动玩家不断挑战更高难度。

## 为什么好玩

肉鸽的随机性+放置的轻松感完美结合。每次死亡不是结束而是新的开始，'下次我能走更远'的心理让失败也充满期待。

## 粘性来源

肉鸽的随机掉落和每次不同的路线是核心粘性。永久升级系统确保即使死亡也有收获。装备收集和build构建提供长期追求。难度挑战的'就差一点'心理驱动反复尝试。

## Meta 系统

永久角色升级系统。通过累计获得的资源解锁技能树节点、提升基础属性、解锁新角色。这些升级跨局永久保留，是游戏的核心长期进度。

## 实现难度

中 — 自动战斗AI和肉鸽随机生成的组合需要一定复杂度。技术难点在于装备系统的平衡性和随机生成的内容多样性。

## 同类游戏

与此游戏类似的推荐：放置类可参考 Clicker Heroes 和 Idle Slayer；肉鸽类可参考 Slay the Spire 和 Vampire Survivors。
