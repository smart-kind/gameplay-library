# 口袋舰队多人版 (Pocket Fleet Multiplayer)

- **类型**: 太空射击/多人对战
- **平台**: Mobile (Android)
- **开发商**: 未明确标注
- **首次发布**: 未明确标注
- **一句话描述**: 一款多人在线太空射击游戏，融合合作模式与对战模式

## 玩法规则

玩家选择阵营——正义方或反派（Omnitron），然后进入多人对战匹配。每场比赛允许最多12名玩家同时参与。

操控方面：左侧的图标控制飞船推进器（持续向前飞行），右侧的图标控制武器——从基础的激光射击到致命的导弹。飞船会自动向前移动，玩家主要控制射击和规避。

每场胜利可以获得游戏内货币，用于购买飞船升级或武器升级。不过积累足够的货币需要大量游戏时间。

游戏主要模式包括合作模式（所有玩家联合对抗共同敌人）和PvP模式（死亡竞赛、团队死亡竞赛等）。但实际情况中，大多数玩家都选择了合作模式，导致PvP模式匹配困难。

画面风格类似自上而下的浴火银河，激光战斗的视觉效果令人满意。

## 核心循环

进入战斗 -> 操控飞船射击 -> 获得胜利 -> 赚取货币升级 -> 参与更高级别的战斗

## 核心机制

- 双控件操作：左侧推进器控制（保持前进），右侧武器控制（激光和导弹），简洁的移动端操控方案
- 合作PvE模式：多名玩家联合对抗AI敌人，是社区最受欢迎的模式
- PvP模式：死亡竞赛、团队死亡竞赛等对抗模式，但参与人数较少
- 升级经济系统：胜利获得游戏内货币，用于购买飞船和武器升级，但积累速度较慢

## 为什么好玩

多人合作模式的团队感和快节奏的太空射击战斗提供了即时的娱乐性。激光和导弹的视觉效果在移动端表现不错。

## 粘性来源

升级系统的渐进目标驱动反复游玩。但PvP模式匹配困难和升级速度慢可能影响长期留存。

## Meta 系统

游戏内货币经济系统——通过战斗获得货币，购买飞船升级和武器升级。升级需要大量战斗积累。

## 实现难度

低 — 操控简洁（两个图标控制前进和射击），容易上手。最大技术难点是多人网络同步和低延迟要求。
