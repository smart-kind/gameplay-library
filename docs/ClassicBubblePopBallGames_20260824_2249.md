# Classic Bubble Pop-Ball Games

- **类型**: 泡泡射击
- **平台**: Mobile (iOS+Android)
- **开发商**: Angel Interactive Limited
- **首次发布**: 2018
- **一句话描述**: 一款泡泡射击类手机游戏，Special Rewards 
Beat all the challenges and win hard levels

## 玩法规则

游戏采用经典的泡泡射击玩法。屏幕底部有一个发射器，玩家可以控制发射角度和方向。屏幕上布满了各种颜色的泡泡（或球体）。

玩家每次发射一个彩色球体，球体沿直线飞行，碰到墙壁会反弹。当球体碰到相同颜色的已存在球体群时会附着上去。

当三个或更多相同颜色的球体连在一起时，它们会同时消除并掉落，玩家获得分数。如果消除导致下方有其他球体失去支撑（不再与顶部相连），这些悬空球体也会一并掉落。

游戏目标：在球体群到达屏幕底部之前，清空所有泡泡。失败条件：新泡泡群推进到屏幕底部警戒线。

## 核心循环

瞄准发射彩色球体 → 匹配消除获得分数 → 清空关卡推进进度

## 核心机制

- 角度瞄准与弹射：玩家通过滑动屏幕调整发射角度，球体碰到墙壁会反弹，需要一定的空间几何预判能力
- 三消匹配机制：三个及以上相同颜色球体连接在一起触发消除，这是核心消除逻辑
- 悬空掉落：消除后不再与顶部相连的球体会自动掉落，这是策略深度的来源——消除关键支撑点可以引发大规模掉落
- 推进机制：每隔若干次发射，屏幕上的泡泡群会整体向下推进一格，增加紧迫感

## 为什么好玩

瞄准和弹射的物理反馈让人上瘾，每次精确命中目标颜色时的满足感很强。悬空掉落时的大规模消除带来额外的视觉爽感。

## 粘性来源

弹射瞄准的技巧性（每次发射都有"差一点就打中"的刺激）；大规模掉落时的视觉爽感；关卡逐步增加的难度曲线；收集不同主题的皮肤

## Meta 系统

- 关卡系统：数百个预设关卡，每个有不同泡泡排列和特殊障碍
- 道具系统：可使用的特殊球体（如彩虹球、炸弹球等）
- 每日挑战：特殊限时关卡，奖励额外道具

## 实现难度

低 — 核心是2D弹射物理+颜色匹配，最大技术难点是弹射角度的精确计算和悬空检测的BFS算法
