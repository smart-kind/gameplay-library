# 35款小游戏合集（35JuniorGames）

- **类型**: 休闲合集
- **平台**: Nintendo DS / Nintendo DSi
- **开发商**: Nintendo
- **首次发布**: 2006
- **一句话描述**: 一款包含35款小游戏的合集，专为儿童设计的任天堂DS游戏，充分利用触控屏特性

## 玩法规则

游戏主界面以地图或菜单形式展示35款小游戏，每款游戏都有图标和简短说明。玩家通过DS触控笔点击选择想要游玩的小游戏，无需复杂的设置即可开始。

35款小游戏涵盖多种类型：
- 益智类：拼图、找不同、记忆配对、数独简化版等
- 运动类：桌上乒乓球、保龄球简化版、飞镖等
- 音乐类：节奏敲击、音符匹配、简单乐器演奏等
- 绘画类：涂鸦、填色、连线画图、创意画板等
- 反应类：打地鼠、接物品、快速点击等
- 知识类：简单的算术题、文字游戏、常识问答等

每款小游戏都有极简的操作方式，主要通过DS下屏的触控笔完成操作。点击、拖拽、画线是最常用的操作方式，部分小游戏需要上屏显示游戏画面，下屏显示控制界面。

游戏规则简单明了，通常有教学引导。没有严厉的失败惩罚，失败后可以立即重试。游戏进度自动保存，方便儿童随时继续。

## 核心循环

选择感兴趣的小游戏 → 完成游戏目标 → 获得分数或评价 → 返回主菜单选择其他游戏

## 核心机制

- **多样化小游戏集合：35款不同类型的小游戏覆盖益智、运动、音乐、绘画等多个领域，确保不同兴趣的儿童都能找到喜欢的内容**
- **触控操作适配：每款小游戏都针对DS触控屏进行了专门设计，操作简单直观，适合儿童的手部精细动作能力**
- **儿童友好设计：简单易懂的规则、明亮的色彩、可爱的角色形象、无严厉的失败惩罚，降低儿童的游戏挫折感**
- **进度自动保存：每款小游戏的进度和最高分自动保存，方便儿童随时中断和继续**

## 为什么好玩

丰富多样的游戏类型，适合不同年龄段儿童。每款小游戏都有独特的乐趣，合集形式提供了超值的内容量。任天堂一贯的高品质设计确保每款小游戏都经过精心打磨。

## 粘性来源

合集形式提供了丰富的内容量，儿童可以在不同小游戏间自由切换，保持新鲜感。每款小游戏的最高分记录激发反复挑战的欲望。

## Meta 系统

无复杂的成长系统。主要是各小游戏的最高分记录和完成度追踪。

## 实现难度

低，专为儿童设计的简单游戏合集。最大技术难点在于35款不同小游戏的统一框架和DS双屏适配。


### 游戏分类详情

益智类（约12款）：拼图、找不同、记忆配对、迷宫、数独简化版、七巧板等。运动类（约6款）：桌上乒乓球、飞镖、保龄球简化版、套圈等。音乐类（约4款）：节奏敲击、音符匹配、简单乐器、音乐记忆等。

绘画类（约5款）：涂鸦画板、填色本、连线画图、像素画、自由创作等。反应类（约4款）：打地鼠、接物品、快速点击、反应测试等。知识类（约4款）：简单算术、文字游戏、常识问答、动物认知等。

### DS双屏设计

上屏显示游戏画面或提示信息，下屏显示操作区域或控制界面。大部分小游戏以下屏触控操作为主，上屏作为视觉反馈。部分小游戏双屏联动，需要同时关注两个屏幕。
