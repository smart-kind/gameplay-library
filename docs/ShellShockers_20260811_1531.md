# 壳弹（Shell Shockers）

- **类型**: 第一人称射击 (FPS)
- **平台**: Web (浏览器)
- **开发商**: Blue Wizard Digital
- **首次发布**: 2017
- **一句话描述**: 扮演一颗手持武器的鸡蛋，与其他鸡蛋对战的多人FPS，被打中会碎裂成蛋黄和蛋壳

## 玩法规则

游戏采用第一人称视角，玩家控制一颗拟人化的鸡蛋，在各种场景中进行多人对战。

操作是标准FPS：WASD移动，鼠标瞄准和射击，空格跳跃，E键切换武器，R键装弹。游戏支持滑铲和二段跳。

武器包括：散弹枪（近距离高伤害）、狙击步枪（远程精准）、冲锋枪（高射速）、火箭发射器（范围伤害）等。不同武器适合不同距离和战术。

角色被击中后会碎裂——蛋壳碎片和蛋黄四散，视觉效果搞笑但不血腥。这个设计让死亡本身变得有趣而非沮丧。

游戏模式包括：自由对战（FFA）、团队死斗、夺旗、占点等。匹配快速，无需下载即开即玩。

每局结束后根据击杀数获得经验，升级后解锁新的鸡蛋皮肤和武器。

## 核心循环

选择武器 → 击杀敌人 → 死亡碎裂 → 重生 → 继续战斗 → 升级解锁

## 核心机制

- **碎裂死亡**：角色被打碎成蛋壳和蛋黄的设计让失败变得搞笑而非沮丧。这是降低挫败感的巧妙设计——看到自己碎成一地反而想笑。
- **武器差异化**：不同武器有不同手感，从近战散弹枪到远程狙击步枪，满足不同玩家偏好。
- **即开即玩**：浏览器FPS的便利性是核心竞争力——不需要下载和安装，打开网页就能打。

## 为什么好玩

鸡蛋碎裂的视觉效果既搞笑又解压。多人对战的快节奏让人停不下来。浏览器即开即玩的便利性让"来一局"的门槛极低。

## 粘性来源

- **搞笑死亡动画**：碎裂效果让失败也变得有趣
- **快速匹配**：几秒内进入对战，节奏紧凑
- **皮肤收集**：解锁不同鸡蛋外观
- **低门槛**：不需要高端PC或下载，任何人都能玩

## Meta 系统

- **经验等级**：击杀获得经验，升级解锁新皮肤
- **武器解锁**：达到特定等级解锁新武器
- **每日任务**：完成指定条件获得额外经验

## 实现难度

中。WebGL 3D渲染和网络同步是主要技术挑战。最大的难点是多人FPS的网络延迟处理——需要在浏览器中实现流畅的射击判定和移动预测。
