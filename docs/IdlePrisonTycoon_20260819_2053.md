# 放置监狱大亨（Idle Prison Tycoon）

- **类型**: 放置经营
- **平台**: Mobile (iOS+Android)
- **开发商**: Codigames
- **首次发布**: 2021
- **一句话描述**: 管理监狱设施，满足囚犯需求，扩展业务成为全球监狱大亨。

## 玩法规则

玩家从低安全级别的小监狱开始，通过升级设施、雇佣员工和管理囚犯的基本需求来扩大业务。

需要决定投资方向：扩建院子、升级宿舍、雇佣厨师医生保安等。

每个决策都会影响监狱的运营。

## 核心循环

赚取被动收入 -> 升级设施满足需求 -> 雇佣更多员工 -> 扩展更大规模的监狱

## 核心机制

- **需求管理系统**：囚犯有舒适度、娱乐、营养、卫生等指标，需要持续投资满足
- **员工雇佣**：雇佣厨师、医生、建筑工、保安、清洁工等不同职能的员工
- **设施升级**：升级宿舍、食堂、浴室、院子等设施提升囚犯满意度
- **放置收益**：离线期间也能获得收入，降低游玩压力

## 为什么好玩

独特的监狱管理题材，不同于常见的餐厅或商店经营。满足囚犯需求的系统设计有趣。

## 粘性来源

数值成长 + 设施解锁的进度感 + 管理复杂性带来的策略深度。

## Meta 系统

全球扩张系统。在不同城市建立新监狱，每个监狱有不同的挑战和收益。

## 实现难度

中 - 多层需求系统和员工管理系统增加了复杂度。最大技术难点：多变量需求系统的平衡（避免某些需求过于容易或困难满足）。
