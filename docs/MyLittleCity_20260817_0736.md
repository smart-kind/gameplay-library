# My Little City

- **类型**: 模拟经营
- **平台**: Mobile (iOS)
- **开发商**: NimbleBit LLC
- **首次发布**: 2012
- **一句话描述**: NimbleBit出品的像素风格城市建造模拟游戏，玩家从零开始规划和管理自己的小城市

## 玩法规则

玩家进入游戏后，会看到一个像素风格的城市建造界面。核心操作是通过点击和拖拽来放置建筑物和设施。城市以网格形式布局，玩家可以在空地上放置住宅区、商业区、公共设施等不同类型的建筑。

每种建筑都有其独特的功能和外观。住宅区吸引市民入住，商业区提供就业和税收，公共设施（如公园、学校、医院）提升市民满意度和城市等级。玩家需要合理规划建筑的位置，让城市运转更加高效。

游戏的核心目标是不断扩大城市规模，解锁新的建筑类型和功能。随着城市等级提升，会逐步开放更高级的建筑和装饰选项。玩家需要平衡财政收支，合理分配资源来维持城市的健康发展。

## 核心循环

收集金币 → 建造/升级建筑 → 吸引更多市民 → 获得更多金币和税收 → 扩大城市规模

## 核心机制

- 核心机制：网格建造系统 — 在有限的城市网格上选择最优的建筑布局，不同类型的建筑之间会产生协同效应
- 渐进解锁：随着城市等级提升，逐步解锁更多建筑类型和装饰选项，保持长期的新鲜感
- 时间管理：建筑建造需要时间，玩家需要合理安排建造顺序，最大化利用等待时间
- 财政平衡：通过税收和商业收入维持城市运转，避免因过度扩张导致财政崩溃

## 为什么好玩

像素风格的视觉效果简洁可爱，城市从无到有的建设过程充满成就感。每放置一栋建筑都能看到城市的直观变化，这种即时反馈让人欲罢不能。游戏节奏由玩家自己掌控，没有紧迫的时间压力，非常适合休闲放松。

## 粘性来源

- 渐进式解锁：每次升级都能获得新的建筑类型，"再升一级看看有什么"的心理驱动持续游玩
- 视觉成长：城市从一片荒地到繁华都市的视觉变化，提供强烈的成就感
- 自由度高：没有唯一的"正确答案"，每个玩家的城市布局都是独一无二的
- NimbleBit生态：与NimbleBit其他游戏的联动彩蛋增加趣味性

## Meta 系统

城市等级系统 — 通过放置建筑和收集资源提升城市等级，等级越高可解锁的建筑类型越多，对核心玩法的影响是直接扩展可用的建造选项。

## 实现难度

中 — 网格建造系统本身不难实现，但需要设计合理的经济平衡系统、多种建筑类型的交互逻辑，以及保存/加载城市状态的数据结构。最大技术难点在于确保大规模城市的流畅运行和合理的性能优化。
