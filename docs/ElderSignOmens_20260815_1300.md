# Elder Sign: Omens

- **类型**: 桌面改编 / 骰子推理
- **平台**: Mobile (iOS + Android)
- **开发商**: Fantasy Flight Games / Cipher Prime
- **首次发布**: 2012
- **一句话描述**: 基于克苏鲁神话的桌面游戏改编，玩家通过掷骰子完成任务、阻止古神复苏

## 玩法规则

Elder Sign: Omens是经典桌面游戏的数字版本。游戏中，玩家扮演调查员在博物馆或神秘地点中探索，通过掷骰子来完成各种任务。

核心玩法：每回合玩家面对一个任务面板，上面列出了需要完成的符号要求（如需要2个放大镜符号、1个书本符号等）。玩家投掷一组骰子，骰子的每个面上有不同的符号。玩家需要选择保留哪些骰子、重掷哪些骰子，以凑出任务所需的符号组合。

如果成功完成任务，玩家获得冒险卡牌（奖励）。如果失败，可能会受到负面效果（失去生命值、理智值，或让古神复苏进度增加）。古神复苏进度条满时，游戏结束。

游戏中还有多种元素：商店系统（用金币购买道具）、怪物战斗（用骰子结果对抗怪物）、以及调查员的能力差异。

## 核心循环

掷骰子 → 匹配任务要求 → 获得奖励/承受惩罚 → 阻止古神复苏

## 核心机制

- **骰子匹配**: 游戏核心机制——通过策略性地选择和重掷骰子来完成任务要求
- **古神复苏倒计时**: 全局压力机制，失败会推动进度条，制造紧迫感
- **调查员差异化**: 每个调查员有独特的骰子和能力，影响游戏策略
- **冒险卡牌系统**: 完成任务获得的卡牌提供被动加成或特殊能力

## 为什么好玩

Elder Sign的魅力在于骰子博弈的刺激感——每次掷骰子都是一次小小的赌博，你需要在“保留现有的”和“冒险重掷追求更好的”之间做决定。克苏鲁主题也增添了氛围感，古神一步步逼近的压迫感让每个决策都更有分量。

## 粘性来源

粘性来自骰子游戏的随机性和克苏鲁叙事的吸引力。每次游戏的骰子结果不同，任务组合也不同，保证了重复游玩价值。

## Meta 系统

调查员解锁系统：通过游戏进程解锁新的调查员。冒险卡牌收集系统：完成任务获得不同卡牌。

## 实现难度

低 — 最大的技术难点在于将桌面游戏的物理体验转化为流畅的触屏体验。
