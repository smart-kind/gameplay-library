# 疯狂企鹅弹弓2（Crazy Penguin Catapult 2）

- **类型**: 物理弹射
- **平台**: Mobile (iOS+Android)
- **开发商**: Chillingo
- **首次发布**: 2010
- **一句话描述**: 物理弹射益智游戏，玩家用弹弓将企鹅发射到冰墙上，利用角度和力度突破障碍。

## 玩法规则

游戏画面是横版2D场景，右侧有由冰墙、木箱、雪球等组成的障碍物，后面有北极熊敌人需要被击败。左下角是弹弓发射点。
玩家用手指拖动弹弓上的企鹅来调整发射角度和力度（拖拽距离越远力度越大），松手后企鹅沿抛物线飞出。
企鹅击中障碍物后会产生碰撞效果：冰墙碎裂、木箱崩塌、雪球滚动。这些物理反应会产生连锁效应，一个精准的发射可以引发大范围破坏。
目标是消灭所有北极熊敌人。北极熊通常躲在障碍物后面，玩家需要利用物理连锁或弹道迂回来击中它们。
每个关卡有步数限制（企鹅数量），需要在限定次数内消灭所有敌人。某些关卡有特殊道具：炸弹企鹅（爆炸范围更大）、火箭企鹅（加速飞行）等。

## 核心循环

观察敌人位置和障碍物结构 → 调整角度和力度发射企鹅 → 观察物理碰撞连锁 → 评估结果继续发射 → 消灭所有北极熊过关

## 核心机制

- 物理弹道估算：拖拽距离和方向决定抛物线轨迹，需要预判落点和碰撞效果，制造'算得真准'的成就感
- 连锁破坏：击中关键支撑点引发大范围坍塌，一个精妙的设计让少量企鹅产生巨大破坏效果。发现关键一击（一个角度解决全局）时的顿悟快感极强
- 步数约束：有限的企鹅数量要求玩家精确计算每次发射，增加策略深度而非纯运气游戏

## 为什么好玩

看着一只企鹅飞出去后引发整个冰墙崩塌、连带所有北极熊被砸飞的连锁反应，那种'一个精妙的多米诺骨牌'的满足感极强。
每次发射都是一次小小的物理学实验，'如果从这个角度打过去会怎么样'的好奇心驱动反复尝试。

## 粘性来源

'差一点就差一点'的遗憾感驱动反复尝试，发现关键一击（一个角度解决全局）时的顿悟快感，以及新关卡带来的未知挑战。

## Meta 系统

解锁特殊企鹅类型（炸弹、火箭等）、星级评分系统、关卡递进。

## 实现难度

低 — 核心是物理引擎+弹道计算。主要技术难点在于碰撞检测的精确性和物理连锁效果的自然度，以及移动端拖拽操作的灵敏度调整。


游戏的关卡设计循序渐进，前几关主要教学基本物理原理，后续关卡引入移动目标、多层结构和特殊障碍。某些关卡有隐藏收集品（星星），找到它们需要特殊的弹射角度和力度组合。


游戏还包含计时挑战模式：在限定步数内尽可能多地消灭北极熊，获得更高评分。某些关卡有隐藏通道，需要通过特定的弹射顺序才能发现。收集所有关卡的三星评价是游戏的长期目标。
