# Bullet Rush!（Bullet Rush!）

- **类型**: 超休闲 / 射击 / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2020
- **一句话描述**: 一款快节奏的俯视射击游戏，玩家操控角色在战场上移动并射击数百名敌人，积累火力触发火神模式进行大规模清屏。

## 玩法规则

Bullet Rush! 采用俯视角画面，玩家的角色位于屏幕中央偏下位置。敌人从屏幕上方和两侧不断涌来，数量从几十个到几百个不等，以群体形式推进。

玩家通过虚拟摇杆或滑动控制角色移动，自动射击持续进行，无需手动瞄准。当消灭足够多的敌人后，角色的武器会触发"火神模式"（firemode），在一段时间内射速和威力大幅提升，可以一次性消灭成片的敌人，形成壮观的视觉效果。

屏幕上方显示当前关卡进度条、剩余敌人数量和分数。屏幕下方是移动控制区域。角色周围有一个小型的"安全区域"指示器，显示当前火力覆盖范围。被敌人碰到会减少生命值，需要不断移动躲避。

游戏目标是消灭关卡中的所有敌人。如果被敌人碰到，角色失去生命值，生命值归零则游戏结束。部分关卡包含 boss 敌人，拥有更多生命值和特殊攻击模式，需要不同的应对策略。

## 核心循环

移动躲避 → 自动射击消灭敌人 → 积累进度触发火神模式 → 大规模清屏 → 进入下一关 → 解锁新武器

## 核心机制

- **自动射击+手动移动**：射击自动进行，玩家专注于走位和躲避，降低操作复杂度，让注意力集中在战术决策上
- **火神模式奖励循环**：消灭敌人积累的进度条满后触发强力模式，提供爆发性的爽快感和视觉冲击
- **敌人波次设计**：敌人分批出现，每波有不同数量、类型和攻击模式，维持持续的战斗节奏和紧张感
- **可爱画风与暴力内容的反差**：Q版角色和敌人搭配大规模射击，形成独特的视觉体验和轻松的基调

## 为什么好玩

火神模式触发的那一刻——几百个敌人同时被消灭的视觉冲击——是这款游戏的灵魂。它完美地利用了"压抑-释放"的心理节奏：先是在敌人群中小心走位（压抑），然后触发火神模式清屏（释放），循环往复让人上瘾。



游戏的节奏设计堪称教科书级别——前期的压抑（在敌群中小心走位）和后期的释放（火神模式清屏）形成强烈对比。这种节奏感让玩家始终处于"紧张-放松"的循环中，既不会太无聊也不会太紧张。每关的敌人群体设计和火力反馈都经过精心调校。

## 粘性来源

火神模式的"爽感反馈"是核心粘性。每次触发都是一次强烈的多巴胺刺激，让人想不断再来一局追求这种感觉。关卡进度和最高分也提供了持续的目标，新武器解锁增加了长期动力。

## Meta 系统

关卡解锁和武器升级：消灭敌人获得金币，用于解锁新角色皮肤和升级武器属性（射速、伤害、火神模式持续时间）。部分版本包含每日挑战和成就系统。

## 实现难度

低 — Voodoo 成熟的超休闲游戏框架。核心难点是大量敌人的渲染优化（同时处理数百个敌人的移动和碰撞检测），以及火神模式的视觉特效设计，确保低端设备也能流畅运行。
