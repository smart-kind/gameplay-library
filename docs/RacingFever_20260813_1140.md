# 竞速狂热（Racing Fever）

- **类型**: 赛车跑酷 / 街机
- **平台**: Mobile (iOS+Android)
- **开发商**: Gameguru
- **首次发布**: 2015
- **一句话描述**: 一款竖屏赛车跑酷游戏，玩家控制汽车在高速公路上躲避交通，以close call机制获取最高分

## 玩法规则

游戏采用竖屏显示，玩家视角在车后方，前方是不断延伸的高速公路。道路上有多条车道，布满了行驶中的其他车辆（小轿车、卡车、公交车等）和路障。

玩家通过左右滑动屏幕来变换车道，点击屏幕下方的加速按钮提升车速，点击刹车按钮减速（但在高分追求中通常不会刹车）。核心玩法是在车流中穿梭，尽可能贴近其他车辆驶过以触发"Close Call"——当你的车辆与另一辆车的距离极近但刚好没有碰撞时，系统会判定为Close Call并给予额外的分数倍率奖励。

路上散布着金币，玩家需要变换车道去收集它们。金币用于在车库中解锁和升级不同型号的汽车。随着行驶时间增加，车速会自动提升，交通也会更加密集，难度呈递增趋势。任何与车辆或障碍物的碰撞都会导致游戏结束。

游戏中还有速度表显示当前车速，以及实时分数计数器。当触发Close Call时，屏幕上会出现慢动作回放效果和分数倍率提示（如"2x Close Call!"）。分数越高，玩家的排名越高，全球排行榜让玩家与其他玩家竞争。

## 核心循环

在车流中穿梭躲避 → 贴车行驶触发Close Call获得倍率加分 → 收集路上的金币 → 用金币解锁新车和升级 → 挑战更高的单次得分纪录

## 核心机制

- **Close Call加分系统**：当玩家极其贴近其他车辆驶过时（通常判定距离在车身宽度的10-15%以内），触发Close Call特效并获得额外分数倍率，这是高分的核心来源，鼓励玩家进行高风险的贴车操作
- **渐进自动加速机制**：车速随时间自动提升，玩家无法选择永久减速，只能不断适应越来越快的速度和越来越密集的交通，形成天然的难度曲线
- **车辆收集与解锁系统**：通过收集金币解锁不同型号的汽车，不同车辆在操控性、最高速度和外观上有所区别，提供收集和尝试的动力
- **金币收集路径规划**：金币分布在不同的车道上，玩家需要权衡"走金币多的车道但更危险"还是"走安全的车道但金币少"

## 为什么好玩

竖屏单手操作的赛车游戏，地铁上、排队时随时随地都能玩一局。Close Call机制让每次惊险擦肩而过都带来极大的爽感——屏幕震动、慢动作回放、分数跳动，反馈链条完整而有力。随着车速越来越快，紧张感呈指数级增长，"再试一次就破纪录"的冲动非常强烈。

## 粘性来源

"差一点就破了最高分"的不甘心感是核心粘性来源。Close Call的即时爽感反馈（视觉震动+音效+分数倍率跳动）形成强烈的操作性条件反射。车辆收集提供长期目标——每辆新车都像是解锁了一种新的游戏体验。无尽跑酷模式天然适合碎片化游玩。

## Meta 系统

金币收集与车辆解锁系统。不同车辆有不同的操控手感、最高速度和外观风格。部分车辆需要达到特定分数才能解锁。无内购外的深度成长系统。

## 实现难度

低 — 竖屏无尽跑酷玩法技术门槛较低。最大难点是碰撞检测的精确性和Close Call判定窗口的调优（太宽没有成就感，太窄让人感到不公平）。流畅的60帧性能表现和车辆/道路的渲染优化也是关键。交通AI（其他车辆的变道、加减速行为）需要看起来自然但不刻意针对玩家。
