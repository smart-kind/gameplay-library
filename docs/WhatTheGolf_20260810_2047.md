# What the Golf?（What the Golf?）

- **类型**: 物理恶搞 / 创意解谜
- **平台**: Mobile (iOS Apple Arcade) / PC (Epic) / Switch
- **开发商**: Triband
- **首次发布**: 2019
- **一句话描述**: 一个"你以为打的是高尔夫，但其实什么都有"的反预期解谜游戏

## 玩法规则

游戏画面采用简洁的 3D 俯视角，每个关卡呈现为一个高尔夫球场景——有发球点、障碍物和目标洞。玩家的操作极其简单：点击球，拖拽出一个方向和力度箭头，松手发射。

但核心乐趣在于——"高尔夫球"根本不是球。第一关你打的是一个正常的高尔夫球；第二关你打的是一个挥杆的高尔夫球手本人（球变成了球手被发射出去）；第三关草地突然活了，变成一条跑道的起点；后面的关卡里你会发射螃蟹、汽车、甚至一整个房子。

每个关卡只有一杆或几杆的机会，目标是将"球"打入洞中或到达指定终点。如果没打中，可以无限重打。过关后自动进入下一关，每关都是全新的玩法变体。

## 核心循环

拖拽瞄准 → 发射 → 观察荒诞结果 → 过关 → 体验下一个完全不同的关卡变体

## 核心机制

- 机制1：反预期物理——每次发射的"物体"和"规则"都在变化，玩家永远不知道下一杆会发生什么，这种"惊喜感"是游戏的核心驱动力
- 机制2：关卡变体轰炸——游戏包含数百个关卡，每个关卡本质上是不同类型的迷你游戏（平台跳跃、赛车、潜行、射击、Portal致敬关卡等），用高尔夫包装串起来
- 机制3：低惩罚重试——失败无成本，随时可以重来，保持轻松节奏

## 为什么好玩

"我以为是高尔夫，结果我发射了一辆汽车"——这种认知被颠覆的瞬间带来了极强的喜剧效果。玩家不是在"玩高尔夫"，而是在"看开发者能有多疯狂"。每过一关都有"这次又能整出什么花活"的期待感。

## 粘性来源

随机性 + 惊喜感 + 大量关卡内容量（数百关）+ 物理恶搞的喜剧效果 + "想看下一个关卡会是什么"的好奇心驱动

## Meta 系统

无传统外围系统。关卡制一次性体验，但有隐藏关卡和彩蛋等待发现。后期有排行榜模式比拼最少杆数通关。

## 实现难度

中。技术难点在于需要设计大量创意关卡（每个关卡本质是一个独立小游戏），以及处理多变的物理交互逻辑。但每个关卡本身的代码不复杂，难的是创意量和关卡打磨。
