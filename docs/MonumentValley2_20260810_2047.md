# Monument Valley 2（Monument Valley 2）

- **类型**: 视觉错位解谜 / 艺术步行模拟
- **平台**: Mobile (iOS Apple Arcade+) / Android
- **开发商**: ustwo games
- **首次发布**: 2017
- **一句话描述**: 在不可能的几何建筑中操控角色，利用视觉错觉找到隐藏的通路

## 玩法规则

游戏画面采用等距视角，展示由各种几何体组成的建筑结构。这些建筑在视觉上遵循埃舍尔式的"不可能图形"原理——潘洛斯三角、不可能楼梯等。

玩家用手指点击角色让它移动，或者拖拽建筑部件（旋转平台、推拉滑块、翻转墙壁）。当你改变视角或移动部件后，原本不相连的道路会神奇地连接在一起——这就是游戏的核心谜题机制。

游戏有叙事线，讲述母亲 Ro 和女儿之间的关系。每个章节是一个独立的谜题场景，完成后自动进入下一关。

## 核心循环

观察建筑 → 发现视觉错觉 → 旋转/移动部件创造通路 → 引导角色通过 → 推进故事

## 核心机制

- 机制1：视觉错位解谜——利用等距投影的特性，让 3D 空间中实际不相连的路径在 2D 屏幕上看起来是连通的，改变视角后"不可能"变成"可能"
- 机制2：建筑操控——玩家可以旋转圆盘、推拉滑块、翻转墙壁，每个操作都可能解锁新的通路线路
- 机制3：双角色协作——第二部增加了母亲和女儿两个角色，需要分别操作、互相创造通路

## 为什么好玩

"眼睛被骗了"的惊喜感是第一驱动力。当你发现某个结构旋转后断开的路径重新连接，那种"哇！"的瞬间是传统解谜游戏难以提供的。加上极简的美学风格和安静的叙事节奏，整体体验更像"互动的艺术品"而非游戏。

## 粘性来源

推进故事的好奇心 + 视觉奇观的期待（"下一关还能怎么骗我的眼睛？"）+ 美学体验

## Meta 系统

叙事驱动（母亲与孩子的情感故事章节）+ 额外关卡 DLC。无外围养成系统。

## 实现难度

中。技术难点在于：（1）等距 3D 渲染 + 路径连通性计算——需要判断在某个视角下哪些路径是"视觉上连通"的；（2）精美的 3D 美术资产制作；（3）谜题设计本身需要大量手工打磨。
