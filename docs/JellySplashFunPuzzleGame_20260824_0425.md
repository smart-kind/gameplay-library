# Jelly Splash: Fun Puzzle Game

- **类型**: 三消 / 休闲解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Wooga
- **首次发布**: 2013
- **一句话描述**: 一款以果冻为主题的消除游戏，通过滑动连接相同颜色的果冻来消除它们，在步数限制内完成关卡目标。

## 玩法规则

游戏在充满彩色果冻的网格中进行，玩家通过滑动连接相同颜色的果冻来消除它们。操作方式与传统三消不同，不是交换而是画线连接。

从一个果冻开始，滑向相邻的同色果冻，连接3个或更多。连接路径必须是连续的，不能跳跃。连接的果冻越多，分数越高，消除范围越大。连接4个以上果冻会生成特殊果冻，如爆炸果冻或条纹果冻。

每个关卡有不同类型目标：基础目标是达到指定分数，特殊目标是收集指定数量的特定颜色果冻，清除目标是消除所有障碍物包括锁链冰块和多层果冻，拯救目标是将被困的小动物移动到指定位置。

每关有固定的步数上限，每次滑动连接算一步。特殊果冻的触发不算额外步数。步数用完后未达到目标则失败。

特殊果冻有多种类型：炸弹果冻消除周围3x3区域，条纹果冻消除整行或整列，彩虹果冻消除所有同色果冻。两种特殊果冻相连可产生组合效果，实现全屏消除。

## 核心循环

滑动连接同色果冻 → 消除得分 → 生成特殊果冻 → 完成关卡目标

## 核心机制

- **滑动连接消除**: 与传统三消的交换两个元素不同，要求玩家从一个果冻开始滑动连接3个以上同色果冻。这种操作方式更直观像画线一样，也更容易形成大规模消除。一次连接7-8个果冻的爽感远超传统三消。滑动操作也更符合触屏设备直觉。

- **特殊果冻组合**: 连接4个以上果冻生成特殊果冻，两个特殊果冻相连产生组合爆炸效果。组合系统增加策略层：是消除眼前3个果冻，还是等待更好连接机会。特殊果冻位置和类型决定关卡解题思路。

- **渐进式障碍系统**: 关卡中引入各种障碍物（锁链、冰块、传送门、多层果冻），每种障碍需要不同消除策略来清除。障碍物的组合和排列让每个关卡都有独特解题路径。随着关卡推进，障碍物种类和密度递增，挑战不断提升。

## 为什么好玩

滑动连接操作比传统交换消除更流畅、更有满足感。果冻Q弹动画和消除特效非常精致，视觉上令人愉悦。关卡设计巧妙，每个关卡都有不同的解谜时刻。Wooga的美术品质一贯出色。

## 粘性来源

三消上瘾循环加上精美果冻动画反馈和数千关卡的长期内容，构成经典消除游戏成功配方。每日挑战和活动关卡维持活跃。生命值系统控制游玩节奏，避免沉迷同时保持回归欲。

## Meta 系统

关卡解锁系统：线性关卡地图，逐步解锁新区域。每日挑战：每天更新一个特殊关卡。活动关卡：限时主题活动。生命值系统：失败消耗生命，随时间恢复。

## 实现难度

低。成熟消除游戏框架，技术实现相对简单。主要工作量在关卡设计和美术资源。滑动连接的碰撞检测需要精确实现。
