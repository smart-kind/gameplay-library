# 恐怖之眼 (Eyes: Scary Thriller)

- **类型**: 恐怖/潜行收集
- **平台**: Mobile (iOS+Android)
- **开发商**: 未明确标注
- **首次发布**: 未明确标注
- **一句话描述**: 一款在阴森豪宅中收集钱袋并躲避鬼魂追杀的手机恐怖游戏

## 玩法规则

游戏的目标是潜入一栋废弃的豪宅，收集指定数量的钱袋，然后安全逃到出口。

豪宅内部光线昏暗，走廊和房间都笼罩在阴影中。某些区域突然被闪电照亮，营造出紧张恐怖的氛围。玩家操控角色在房子中移动，寻找藏有钱袋的地方。

钱袋可能藏在柜子或锁着的保险箱中。有些区域需要找到钥匙才能进入。玩家需要在有限的时间内尽可能多地收集钱袋，同时躲避游荡在房子中的鬼魂。

鬼魂的存在会通过家具的颤抖和令人毛骨悚然的声音来暗示。当鬼魂接近角色时，唯一的生存方式是向相反方向逃跑，直到鬼魂放弃追击。逃跑时的操控比较笨拙（可能是有意为之的设计，让玩家在恐慌中更难逃脱）。

每次重新开始游戏时，钱袋的放置位置都会变化（但房子布局保持不变）。地图是重要的辅助工具，帮助玩家规划收集路线。

游戏还提供眼睛图标——收集后可以从鬼魂的视角看到房子内部，了解鬼魂的位置和动向，帮助规划安全的收集路线。

## 核心循环

潜入豪宅收集钱袋 -> 躲避鬼魂追踪 -> 安全逃离 -> 解锁更高难度（更多钱袋要求）

## 核心机制

- 随机化收集品放置：每次游戏钱袋位置不同，但房子布局固定，要求玩家每次重新探索
- 鬼魂追逐系统：鬼魂随机游荡，接近时通过声音和视觉线索警告，被抓到即游戏结束，唯一对策是逃跑
- 钥匙与锁机制：部分区域需要找到钥匙才能进入，这些区域通常藏着更多钱袋
- 鬼魂视角系统：收集眼睛图标后可以切换到鬼魂视角，看到鬼魂的位置和朝向，用于战术规划

## 为什么好玩

在黑暗房间中带着耳机玩时，恐怖氛围极强。鬼魂突然出现时的惊吓感和紧张逃跑的肾上腺素飙升是核心体验。

## 粘性来源

随机化的钱袋位置确保每次游戏体验不同。恐怖刺激感和再来一局证明自己不害怕的心理驱动重复游玩。高难度模式（更多钱袋要求）提供渐进挑战。

## Meta 系统

难度通过要求的钱袋数量递增来调整。基础模式只需收集少量钱袋即可通关，更高难度要求更多。

## 实现难度

低 — 核心操作简单（移动+收集+逃跑），恐怖感大于操作难度。最大技术难点是3D环境中的氛围渲染和音效的空间定位。
