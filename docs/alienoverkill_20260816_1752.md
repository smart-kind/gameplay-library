# Alien Overkill（异形杀戮）

- **类型**: 射击 / 动作
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2011
- **一句话描述**: 一款固定方向射击的异形塔防游戏，玩家在三个主题关卡中抵御来自四面八方的外星人波次攻击。

## 玩法规则

游戏采用固定视角的俯射击模式。玩家控制一个孤独的士兵角色，置身于三个不同主题的地图中——太空飞船、冰雪世界以及异形巢穴。敌人从四面八方涌来，以精确的追踪路径向玩家逼近。

玩家的操作极其受限：射击方向被锁定为正向，无法自由瞄准任何角度。这意味着你不能像传统双摇杆射击游戏那样 360 度开火，只能朝前方直射。游戏中包含五种武器——基础步枪、霰弹枪（威力极大，射击可以跨越整个地图）、火焰喷射器和 RPG 火箭筒。武器切换和射击共用一个按钮，这个按钮恰好位于如果有第二摇杆会所在的位置。

移动依赖虚拟摇杆，但这个摇杆经常在不方便的时候卡住，让移动像"用一条履带操控坦克"一样不流畅。大多数敌人会精准追踪玩家位置，不过有些会卡在场景物件上，被迫绕行。游戏节奏异常缓慢——移动、子弹、敌人全部以极慢速度推进，整个体验被形容为"地图上涂了糖浆"。

游戏没有过关/失败条件的复杂设定，核心就是在每一波敌人攻击中存活下来。

## 核心循环

在地图中移动躲避 → 射击消灭外星敌人 → 拾取更强武器 → 继续抵御下一波敌人

## 核心机制

- **固定方向射击**：武器只能朝正向发射，无法调整射击角度，这是游戏最具争议的设计选择
- **多武器系统**：五种武器各有特色，霰弹枪威力巨大但火焰喷射器和 RPG 因操控笨拙反而更伤己
- **敌人追踪 AI**：大多数敌人能精确定位玩家位置并追踪，部分会被场景障碍物阻挡
- **虚拟摇杆移动**：摇杆存在锁定问题，移动流畅度低

## 为什么好玩

坦白说，根据评测，这款游戏几乎不好玩。固定方向射击+笨拙摇杆的组合让操作体验极度挫败。但作为一种"反面教材"，它展示了射击游戏中方向自由度的重要性——失去 45 度角射击都能让游戏从有趣变成无聊。

## 粘性来源

几乎没有。评测明确指出游戏缺乏魅力、原创性和刺激感，缓慢的节奏和笨拙的操控让它产生的肾上腺素"和草坪保龄球比赛差不多"。

## Meta 系统

无。游戏没有外围成长系统，每局都是独立的游戏体验。

## 实现难度

低 — 技术上就是固定视角 2D 射击，敌人追踪 AI 和碰撞检测都很成熟。最大技术难点是虚拟摇杆的流畅手感调优，而这款游戏恰好在这方面失败了。
