# 拼字游戏：混音版（Scrabble Remix）

- **类型**: 文字益智
- **平台**: Mobile (iOS+Android)
- **开发商**: EA (Hasbro授权)
- **首次发布**: 2010
- **一句话描述**: 经典Scrabble拼字游戏的移动增强版，增加了新的游戏模式和视觉效果。

## 玩法规则

游戏界面是一个15x15的棋盘，与经典Scrabble相同。玩家从字母袋中抽取7个字母牌。
标准模式：两名玩家轮流在棋盘上放置字母组成英语单词。首个词必须经过中心格，后续词需要与已有单词相连。每个字母有分值（常用字母如E/A=1分，稀有字母如Q/Z=10分），放置位置影响得分（DL/TL/DW/TW加成格）。
Remix版本增加了新模式：闪电模式（限时内尽可能多组词）、解谜模式（给定字母和棋盘布局，找到最高分方案）、以及多人在线对战。
放置单词时，所有用到的字母牌分值求和，再乘以单词倍率。新组成的所有单词同时计分。
当字母袋空且某玩家用完手中所有字母时游戏结束，该玩家获得剩余对手字母分值作为加分。总分高者获胜。
游戏内置词典验证，放置的单词必须是有效英语单词。

## 核心循环

观察手中字母和棋盘格局 → 寻找最优单词组合 → 放置在加成格上最大化得分 → 抽取新字母 → 等待对手回合

## 核心机制

- 词汇策略：利用高价值字母（Q/X/Z/J）放在三倍字母格上实现分数爆发，同时要考虑为后续回合留出空间
- 棋盘控制：占据关键加成格不仅为了本回合得分，也为了阻止对手使用这些位置。高手会'封堵'对手可能的最佳路线
- 字母概率管理：了解字母袋中剩余字母的分布，推测对手可能拿到的字母并做出针对性布局

## 为什么好玩

每次发现一个能同时利用多个加成格的绝佳单词时的智力满足感是独特的。
与朋友对战时'我知道你想占那个格子但我先占了'的心理博弈很有趣。
闪电模式下的限时组词带来了与标准模式完全不同的紧张刺激体验。

## 粘性来源

词汇量的自我展示欲（'我知道一个你们都不知道的词'）、排行榜竞争、以及限时模式下的'再试一次我能找到更好的词'的冲动。

## Meta 系统

每日词汇挑战、成就系统、排行榜、单词学习功能。

## 实现难度

低 — 核心是棋盘状态管理和词典验证。主要技术难点在于AI对手的词汇选择算法和多人对战的同步。


游戏还包含单词学习功能：每次放置单词后会显示单词的释义和分值计算，帮助玩家扩大词汇量。某些版本支持每日挑战模式，每天一个特定的棋盘布局和字母组合。
