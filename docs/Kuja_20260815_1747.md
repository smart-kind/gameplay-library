# 古惑狼醉拳（Kuja）

- **类型**: 动作格斗 / 休闲
- **平台**: Web / Mobile (iOS+Android) / PC
- **开发商**: filthsu (Rusty Moyher)
- **首次发布**: 2013
- **一句话描述**: 醉酒后在酒吧门口一路狂殴敌人的横版动作小游戏

## 玩法规则

玩家控制一个醉酒的角色，在横版卷轴的街道上自动向右行走。
玩家只需点击屏幕即可发动攻击——左拳、右拳或飞踢，每种攻击有不同的攻击范围和伤害。
敌人会从四面八方涌来，包括醉汉、保安等各种路人角色。
游戏画面采用像素风格，角色摇摇晃晃的醉酒步态配合滑稽的打击动作营造出喜剧效果。
玩家需要在不被打倒的前提下尽可能走远，血量归零时游戏结束。
随着行进距离增加，敌人的数量和种类会逐渐增多，难度递增。

## 核心循环

前进 → 消灭敌人 → 走得更远 → 面对更强的敌人

## 核心机制

- 单键操作系统：整个游戏只需要点击一个按钮，自动区分近战和远程攻击，极简操作降低了门槛
- 醉酒物理效果：角色走路摇摇晃晃，攻击动作带有随机偏移，增加了不确定性和喜剧感
- 渐进难度曲线：敌人从少到多、从弱到强，玩家在不断失败中追求更远的距离记录

## 为什么好玩

醉拳格斗的荒诞喜剧风格让人忍俊不禁，单指操作适合碎片时间游玩。被打飞时的夸张物理效果和角色台词（如"I need a kebab"）带来持续的新鲜感和分享欲。

## 粘性来源

核心粘性来自"再试一次就能走更远"的不甘心感。每次死亡后几乎零等待即可重新开始，加上滑稽的死亡动画让玩家愿意不断尝试刷新最远记录。

## Meta 系统

无内置成长系统。游戏主要靠高分排行榜驱动重复游玩。

## 实现难度

低 — 单按钮操作，最大技术难点是醉酒物理效果的调校（既要随机又不能失控）


游戏场景从酒吧门口开始，逐步扩展到街道、停车场等多个区域。
每个区域有独特的背景元素和敌人组合。
角色攻击时会有特殊的屏幕震动效果和打击音效反馈。
击杀敌人后偶尔掉落酒瓶，拾取后可以恢复少量生命值。
