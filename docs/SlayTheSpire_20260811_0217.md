# Slay the Spire（杀戮尖塔）

- **类型**: Roguelike卡牌 / 策略
- **平台**: PC / Mobile (iOS+Android) / Switch / PS / Xbox
- **开发商**: MegaCrit
- **首次发布**: 2017
- **一句话描述**: 爬塔过程中收集卡牌构建卡组，回合制战斗中运用卡牌组合击败敌人，每次死亡后重新开始但保留解锁内容。

## 玩法规则

游戏画面为竖屏（移动端适配）或横屏，上方显示敌人及其意图图标（即将攻击/防御/施法），中间是战场区域，下方是玩家手牌。玩家每回合抽取固定数量的手牌，每回合获得3点能量，打出卡牌消耗能量。

卡牌分为四类：攻击牌（造成伤害）、技能牌（获得格挡或特殊效果）、能力牌（永久增益，消耗能量但持续整场战斗）、状态牌（负面牌，占手牌位置无效果）。玩家需要用攻击牌击败敌人，用技能牌获得格挡来抵消敌人伤害。

爬塔过程呈现为一张分支路线图，每个节点代表一场战斗、精英战、休息点（回血或升级卡牌）、商店或宝箱。玩家选择前进路线，在节点间做出取舍——走安全路线但奖励少，还是挑战精英获得更好奖励。

每次战斗胜利后获得金币和卡牌奖励（三选一），玩家逐步构建自己的卡组。死亡后重新开始，但解锁新卡牌、新角色和新内容供下次使用。

## 核心循环

战斗获得卡牌 → 选择路线前进 → 构建卡组 → 击败Boss进入下一层 → 死亡后重新开始，利用解锁内容尝试新策略

## 核心机制

- **卡牌构建（Deckbuilding）**：核心机制。从初始小卡组开始，通过战斗奖励逐步添加卡牌。优秀的卡组需要协同性——卡牌之间互相增益形成combo。删卡（移除不需要的卡牌）和卡组精简同样重要。
- **意图系统**：敌人头顶显示下一步行动的图标和数值，玩家可以预判并做出应对。这让战斗从"盲打"变成了"解谜"——如何用有限的能量和手牌应对敌人下回合的动作。
- **遗物系统**：每场战斗后或特殊节点获得遗物（被动效果），如"每回合抽更多牌"、"攻击附带额外伤害"、"获得格挡时反击"等。遗物与卡牌的协同是构建强大build的关键。

## 为什么好玩

每一局都是全新的体验——随机路线、随机卡牌奖励、随机遗物让你永远无法完全复制上一次的build。当你抽到关键牌打出combo时那种"这局有戏"的兴奋感，和差一步就能赢的遗憾感交织在一起，让人忍不住再来一局。

## 粘性来源

- **Roguelike重玩性**：每局不同的路线和奖励组合，策略空间极大
- **解锁进度**：每次死亡后解锁新卡牌/遗物/角色，让"失败"也有意义
- **成就挑战**：每角色有不同的解锁挑战（如无伤通关、特定组合通关），增加目标感
- **每日挑战**：每天一个种子所有玩家相同，可以和全球玩家比较成绩

## Meta 系统

- **角色解锁**：初始一个角色，通关后解锁新角色，每个角色有完全不同的卡牌池和玩法
- **卡牌解锁**：通过游玩逐步解锁更多卡牌进入公共卡池，丰富构建选择
- **对核心玩法的影响**：解锁内容扩展了策略空间，但不改变核心规则，新老玩家起点公平

## 实现难度

中 + 卡牌游戏的核心逻辑（抽牌、出牌、回合制战斗）实现不难，但最大难点在于数值平衡和内容设计。4个角色、数百张卡牌、数十种遗物之间的协同需要大量测试和调整，确保没有绝对无敌的build也没有完全无用的卡牌。
