# Hades

- **类型**: 动作 Roguelike
- **平台**: PC / Switch / PS / Xbox
- **开发商**: Supergiant Games
- **首次发布**: 2020
- **一句话描述**: 超过 100 个年度游戏的动作 Roguelike 标杆，完美融合紧张的动作战斗和丰富的叙事。

## 玩法规则

玩家扮演冥王之子 Zagreus，试图逃离冥界。每次死亡后回到起点，但可以保留部分强化效果。游戏采用俯视角动作战斗——玩家使用武器攻击、闪避和释放特殊能力。

六种武器（剑、盾、弓、拳套、鱼叉、枪）各有四种变体，配合奥林匹斯众神赐予的祝福（Boon），创造出近乎无限的战斗风格组合。每次逃离尝试获得的资源可以永久强化角色属性和解锁新内容。

叙事是 Hades 的独特之处——每次死亡和回归都有新的对话和故事进展，角色塑造丰富，死亡不再是挫败而是叙事推进。

## 核心循环

选择武器 → 战斗获取祝福 → 面对 Boss → 死亡或逃离 → 永久强化后再试

## 核心机制

- 武器系统：6 种武器 × 4 种变体 = 24 种基础玩法
- 祝福系统（Boon）：奥林匹斯众神赋予的被动和主动能力
- 死亡进度：每次死亡保留部分资源用于永久强化
- 叙事驱动：每次死亡推进故事，角色对话丰富
- 预言系统：提供挑战和奖励的长期目标

## 为什么好玩

动作战斗的精确感和流畅度在 Roguelike 中无与伦比。死亡不再是失败而是故事的一部分，这种设计彻底改变了玩家对失败的感受。

## 粘性来源

- 死亡即叙事：每次死亡都有新的对话和故事进展
- 战斗手感：精确的攻击、闪避和技能释放反馈
- 祝福组合：不同神的祝福组合创造无限玩法
- 渐进式解锁：每次逃离尝试都获得新内容

## Meta 系统

永久强化系统（房屋装修、武器解锁、属性提升）。使用暗银和宝石永久增强角色能力，解锁新武器和外观。

## 实现难度

高。动作战斗系统需要精确的碰撞检测、动画同步和网络同步（如果有合作模式）。叙事分支和内容量需要大量创作。
