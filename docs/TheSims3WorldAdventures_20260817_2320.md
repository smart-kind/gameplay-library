# 模拟人生3：世界冒险（The Sims 3: World Adventures）

- **类型**: 生活模拟
- **平台**: Mobile (iOS+Android) / PC / Console
- **开发商**: EA / Maxis
- **首次发布**: 2009
- **一句话描述**: 模拟人生系列的扩展包，为模拟角色增加了跨国旅行、古墓探险和技能成长系统。

## 玩法规则

玩家控制一个虚拟角色（模拟市民），需要管理其基本需求：饥饿、精力、卫生、社交、膀胱和娱乐。这些需求会随时间下降，玩家需要安排角色吃饭、睡觉、洗澡等活动来维持。
世界冒险扩展增加了三个可旅行的国家（中国、埃及、法国），每个国家有独特建筑、NPC和冒险任务。购买机票后可以飞往目的地。
在冒险地点，玩家可以探索古墓和遗迹，解决谜题（如推动石碑、点燃火炬、排列机关），发现宝藏和古代遗物。古墓中有陷阱和危险。
角色可以获得新技能：武术（中国）、摄影（法国）、花蜜酿造（法国）。技能等级通过练习提升，高等级解锁新能力和更好的冒险成功率。
冒险过程中会遇到陷阱和危险，角色可能受伤、中毒或被困。需要合理准备补给品（食物、急救包）才能深入探索更深层的遗迹。
游戏是开放式的，没有强制的通关目标，玩家自由决定角色的生活方向和冒险路线。

## 核心循环

维持角色需求 → 提升技能 → 前往异国他乡探险 → 解决古墓谜题获取宝藏 → 带回遗物充实生活

## 核心机制

- 需求管理：六大需求条构成持续的时间压力系统，玩家需要平衡日常生活和冒险计划，需求归零会导致角色行为异常甚至晕倒
- 技能成长：练习特定行为提升技能等级，高等级解锁新交互和更高的冒险成功率。技能成长是可见的数值进度，带来持续的正反馈
- 古墓探索：随机生成的遗迹地图，包含可互动机关、陷阱和隐藏房间，提供解谜和发现的乐趣。深层古墓有更高价值的宝藏但也更危险

## 为什么好玩

看着自己的模拟市民从一个普通人成长为能独闯古墓的冒险家，这种角色养成感很强。
在异国他乡发现隐藏密室时的惊喜感，以及带回珍贵遗物的成就感，都是独特的体验。
在法国酿造花蜜、在中国练武术、在埃及探险——每个国家都有独特的活动，保持游戏新鲜感。

## 粘性来源

角色成长系统的数值粘性（'再升一级就好'）、未完成的冒险任务（'还有一间密室没探索'）、以及收集遗物图鉴的收集欲。

## Meta 系统

技能等级系统、冒险家等级、遗物收集图鉴、房屋建造与装修、人际关系网络。

## 实现难度

高 — 需要实现完整的AI生活模拟系统（需求管理、路径规划、行为树）、动态地形生成（古墓）、多技能系统和物品系统。技术难点在于多系统耦合的稳定性，以及大量交互对象的状态管理。


游戏还包含房屋建造系统：使用冒险获得的资源和金钱建造和装修房屋。某些遗物可以用于装饰房屋，增加房屋价值。冒险过程中结识的NPC可以成为朋友甚至浪漫对象，增加社交维度。
