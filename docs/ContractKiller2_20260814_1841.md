# Contract Killer 2（Contract Killer 2）

- **类型**: 射击 / 潜行
- **平台**: Mobile (iOS+Android)
- **开发商**: Chillingo (EA)
- **首次发布**: 2012
- **一句话描述**: 第一人称狙击暗杀游戏，玩家扮演精英杀手完成各种暗杀任务

## 玩法规则

游戏以第一人称视角呈现，玩家通过狙击镜观察目标场景。画面为3D渲染，场景包括城市天台、港口仓库、豪华别墅、军事基地等不同地点，每个地点有独特的视觉风格和布局。

每个任务开始时给出目标人物的照片、姓名和简要信息。目标在场景中会按照固定路线来回移动，有时身边有保镖巡逻。玩家需要选择合适的时机和目标位置开枪。

操作方式：单指滑动屏幕调整瞄准镜方向，双指捏合缩放调整倍率，点击屏幕开枪。高难度关卡中，风力、距离和目标移动速度会影响弹道，玩家需要预判提前量。

任务目标通常是击杀特定目标而不被发现。如果第一枪未击杀，保镖会进入警戒状态并搜索射击者位置。后续目标会寻找掩体躲避或试图逃跑。

评分系统根据三个维度评定星级：精准度（是否一枪毙命）、隐蔽性（是否被保镖发现）、完成任务时间。三星评价获得最高报酬。

## 核心循环

接受暗杀合同 → 观察目标行动模式 → 选择时机射击 → 获得评分和报酬 → 解锁新合同和武器

## 核心机制

- **狙击弹道系统**：距离、风速、目标移动速度共同影响弹道落点。近距离目标几乎无偏差，远距离目标需要考虑风偏和重力下坠。高级狙击镜会显示风力和距离读数，辅助玩家计算。玩家需要综合判断并预判射击提前量。
- **潜行评分系统**：是否被保镖发现、是否一枪致命、任务耗时都影响最终星级评价。游戏鼓励玩家耐心观察而非盲目射击——等待目标走到开阔地带、确保一击致命、选择没有保镖巡逻的时机。
- **武器升级系统**：使用任务报酬购买更好的狙击步枪、配件和弹药。配件包括：高倍瞄准镜（增加放大倍率）、消音器（降低被发现概率）、穿甲弹（对付有防弹衣的目标）、稳定器（减少手抖影响）。

## 为什么好玩

狙击镜中观察目标、等待最佳时机、屏息射击的体验感很强。一枪毙命的成就感和紧张感是核心吸引力。每个任务的场景和目标行为模式不同，保持新鲜感。

## 粘性来源

数值成长（武器升级带来的实际能力提升）+ 星级挑战（追求完美三星通关的强迫症）+ 任务多样性（不同场景、不同目标、不同难度）。武器升级系统让每笔报酬都有明确用途。

## Meta 系统

武器购买与升级系统：完成任务获得金钱，可购买新狙击步枪、配件和弹药。武器属性包括伤害、精准度、射速和弹匣容量。不同武器适合不同任务类型——有的适合远距离狙杀，有的适合近距离快速射击。

## 实现难度

低 — 基于瞄准和射击的核心玩法技术成熟。最大技术难点是AI目标的行为路径设计和弹道物理计算，确保射击反馈公平可预期。
