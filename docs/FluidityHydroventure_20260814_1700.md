# 流体冒险（Fluidity / Hydroventure）

- **类型**: 物理解谜
- **平台**: Wii / Wii U / Mobile (iOS+Android)
- **开发商**: Curve Studios
- **首次发布**: 2010
- **一句话描述**: 玩家控制一小团水，通过改变水的三种物理形态（液体、冰、蒸汽）来解决各种环境和通道障碍

## 玩法规则

游戏画面展示了一个横向或斜向的2D场景，包含各种管道、坡道、障碍物和机关。玩家通过重力感应或方向键控制水流的移动方向——水会自动向低处流动。

核心操作是让水流经各个关卡中的障碍。玩家有三个关键能力：切换水的形态。液态水可以流动、穿过狭窄管道、推动开关；冰形态可以将水面冻结成固体平台，用于踩踏或通过特定区域；蒸汽形态可以让水变成气体上升，穿越上方的通道或避开障碍物。

每个关卡的目标是让水从起点到达终点收集容器。途中需要收集彩虹碎片、解锁新的通道，并避开火苗、电击、干燥区域等会让水蒸发的危险元素。游戏还包含时间挑战和收集要素。

## 核心循环

控制水的形态 → 通过特定路径 → 到达终点收集 → 解锁新关卡和新能力

## 核心机制

- **三态切换机制**：水可以在液态、固态（冰）、气态（蒸汽）之间切换，每种形态对应不同的物理行为和过关路径。液态受重力流动，冰态固定成形，蒸汽态逆重力上升。这个机制要求玩家在行进中不断切换，形成策略性的路径规划。
- **重力感应操控**：通过倾斜设备或利用重力控制水流方向，操作直觉但需要精准时机。
- **元素交互系统**：火会让水蒸发，冰可以冻结水面形成平台，蒸汽可以穿过狭窄缝隙。环境与水的形态产生不同反应。

## 为什么好玩

三种物理形态的切换创造了独特的解谜体验——玩家需要不断切换视角，从"水流怎么走"到"冰怎么搭桥"到"蒸汽怎么飘上去"，每秒钟都在做形态决策。重力操控带来的即时反馈让操作很有手感。

## 粘性来源

物理解谜的"啊哈时刻"——当你终于找到正确的形态切换顺序通过一个复杂障碍时，成就感极强。关卡逐步引入新的元素组合，难度曲线设计让每个新关卡都是对已有技能的新考验。收集彩虹碎片的额外目标让已经通过的关卡也有重玩价值。

## Meta 系统

无传统Meta成长系统。游戏通过关卡解锁和收集要素（彩虹碎片）提供长线目标。

## 实现难度

中。核心物理模拟需要实现流体动力学简化模型和三种状态的切换逻辑。最大技术难点在于让水的物理行为既真实可控又有趣——太真实会难操作，太简化会失去物理谜题的乐趣。2D场景下的碰撞检测和形态变换动画也需要精细调校。
