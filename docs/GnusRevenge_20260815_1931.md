# Gnu's Revenge

- **类型**: 物理益智 / 弹射 / 解谜
- **平台**: Mobile (iOS + Android) / Nintendo 3DS
- **开发商**: Tantalus
- **首次发布**: 2011
- **一句话描述**: 弹射角马冲破围栏，收集星星，找到每关的最佳路径完成目标。

## 玩法规则

游戏画面为一个被围栏围起来的区域，里面有一只角马（Gnu）和散布的星星。围栏由木头、金属等不同材质的方块组成。

操作方式：
- **拖拽弹射**：用手指点击角马并向反方向拖拽，松开后角马沿拖拽反方向弹射出去。
- 拖拽距离决定弹射力度，拖拽角度决定弹射方向。屏幕上通常会显示预测轨迹线。
- 角马弹射出去后沿物理轨迹移动，撞到围栏方块后会破坏方块并继续前进。
- 收集关卡中所有星星即可通关。部分星星位于难以到达的位置，需要特定的弹射角度和力度才能收集到。
- 如果角马在收集所有星星前停下（速度为零）或飞出屏幕外，则尝试失败。

每个关卡有弹射次数限制（通常有限），需要在限制次数内收集所有星星。

围栏方块的材质不同：木质方块容易破坏，金属方块需要多次撞击，有些方块不可破坏需要绕开。

## 核心循环

观察关卡布局 → 规划弹射路线 → 执行弹射 → 收集星星 → 找到最优解

## 核心机制

- **弹射物理**：核心机制与愤怒的小鸟类似——拖拽弹射、物理碰撞、破坏方块。但 Gnu's Revenge 的重点不是消灭敌人，而是收集星星和找到路径。
- **路径解谜**：每个关卡本质上是一个路径谜题——如何用有限的弹射次数收集所有星星？答案可能需要利用墙壁反弹、连锁破坏等技巧。
- **材质系统**：不同材质的方块有不同的耐久度，玩家需要根据方块材质调整弹射力度和角度。
- **连锁破坏**：破坏一个方块可能引发连锁反应（方块倒塌、其他方块暴露），善用连锁可以高效通关。

## 为什么好玩

Gnu's Revenge 在"弹射物理"这个类型中提供了新鲜的体验——你不是在消灭猪，而是在收集星星。这种目标转换改变了玩法思路：愤怒的小鸟关注的是精确命中目标，而 Gnu's Revenge 关注的是找到一条能收集所有星星的路径。角马可爱的形象也让游戏体验更加轻松愉快。

## 粘性来源

- **解谜挑战**：每关都需要找到最优路径，三星评价驱动反复挑战。
- **物理随机性**：物理模拟的微妙差异让每次弹射都有不确定性。
- **关卡数量**：大量关卡提供持续的解谜内容。

## Meta 系统

无 — 独立关卡制。

## 实现难度

**中** — 物理引擎（弹射、碰撞、破坏）是核心。最大技术难点在于物理模拟的稳定性和方块破坏的视觉效果。
