# 放置猎手 - 上瘾点击（Idle Slayer: Addictive Clicker）

- **类型**: 放置/点击
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2020
- **一句话描述**: 英雄自动战斗的放置点击游戏

## 玩法规则

英雄角色自动攻击沿途的怪物。玩家点击屏幕可发动特殊攻击或加速。击杀怪物获得金币，用于升级英雄的攻击力、速度和技能。随着进度推进，遇到更强的怪物和Boss。解锁新的英雄和武器类型。离线时英雄继续战斗并积累资源。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

英雄自动战斗 → 击杀获得金币 → 升级装备 → 挑战更强怪物

## 核心机制

- **自动战斗**:  英雄自动攻击怪物
- **点击辅助**:  玩家点击增强攻击力
- **装备升级**:  金币用于提升英雄能力

## 为什么好玩

英雄不断变强的成就感，击杀Boss的满足感

## 粘性来源

持续升级的数值成长；新英雄和装备解锁

## Meta 系统

英雄、装备和技能升级系统

## 实现难度

低 - 核心是自动战斗和数值增长 - 战斗动画的流畅性和数值平衡
