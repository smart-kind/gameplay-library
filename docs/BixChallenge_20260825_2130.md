# Bix Challenge

- **类型**: 休闲解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Padadaz
- **首次发布**: 2009
- **一句话描述**: 一款通过绘制图形捕获球体的休闲解谜游戏，考验空间推理和预判能力

## 玩法规则

游戏主界面以简洁的游戏画布，玩家可以在上面自由绘制图形为核心视觉元素，整体布局简洁直观。屏幕上方/中央区域展示画布区域、当前填充率和球体运动轨迹，玩家一眼即可了解当前的核心状态。屏幕下方或侧边排列手指绘制区域和关卡信息面板，这些是玩家可以交互的按钮或操作区域。

玩家通过手指绘制和图形操作进行核心操作。具体而言，玩家用手指在画布上绘制封闭图形，将移动中的球体包围。当图形闭合时，被包围的球体被捕获并触发特殊能力。绘制需要预判球体的运动轨迹，选择合适的起始点和路径。如果绘制过程中被球体碰到未闭合的线段，则绘制失败需要重新尝试。随着关卡推进，球体数量增加、速度变快，对预判精度的要求不断提高。每次操作后，系统会即时给出图形闭合时的捕获动画、填充率增长指示和特殊能力释放特效，确保玩家对操作结果有清晰的感知。

游戏的核心目标是填满75%以上的屏幕区域。为了达成这一目标，玩家需要观察球体运动轨迹，规划绘制路径，在合适的时机开始绘制并闭合图形，捕获球体获得特殊能力辅助后续绘制。当屏幕填充率达到75%以上时，玩家进入下一阶段或解锁新内容。反之，如果绘制过程中被球体碰到未闭合的线段，则需要重新开始或调整策略。

随着游戏进程的推进，球体数量和速度逐渐增加，可用绘制空间减少。玩家需要逐步掌握空间预判、路径规划和时机把握，才能在更高难度下持续进步。游戏的深度在于空间推理的层层递进——随着球体数量和速度的增加，需要同时考虑多个移动物体的轨迹并找到最优解。简单的绘制操作下蕴含着深刻的几何思维和策略规划，这让简单的操作框架下蕴含着丰富的策略空间。

游戏中的球体有不同的运动模式：直线运动、弹性碰撞和曲线运动，每种模式都需要不同的预判策略。后期关卡会混合多种运动模式，大幅提升难度。

## 核心循环

绘制图形捕获球体 → 获得特殊能力 → 挑战更高难度关卡

## 核心机制

- **绘制包围机制**: 玩家通过手指绘制封闭图形来捕获球体，需要预判球的运动轨迹并选择合适的包围时机。绘制路径的选择直接影响捕获效率和安全性——最短路径风险最大但收益最高
- **填充率目标**: 核心目标是填满75%以上的屏幕区域，在有限空间内最大化覆盖面积是主要挑战。填充率的实时显示给玩家明确的进度反馈，"还差多少"的信息驱动持续尝试
- **球体特殊能力**: 被捕获的球体会释放特殊能力，如清除已填充区域、改变剩余球体的运动方向或提供短暂的无敌时间。这些能力可以作为策略工具，帮助玩家突破困境

## 为什么好玩

看着自己绘制的图形成功捕获球体的瞬间非常满足，随着难度提升需要同时规划多个移动物体的轨迹，空间推理的智力挑战与即时反馈结合得很好。每次成功捕获都带来"我真聪明"的正向反馈。

游戏的视觉反馈非常精致——每次捕获都有独特的粒子效果，填充区域的渐变色彩也给玩家直观的成就感。

## 粘性来源

空间推理的智力满足感和"我画得越来越好了"的技巧成长。每关球体行为的微妙变化带来持续的挑战新鲜感。"差一点就成功了"的不甘心和"这次我想到新方法了"的顿悟交替驱动。

关卡难度曲线设计得非常平滑，每次失败后玩家都能清晰地知道"哪里可以做得更好"，而不是感到挫败。

## Meta 系统

关卡解锁与主题系统：完成目标关卡解锁新主题和特殊球体类型。对核心玩法的影响是引入新的球体行为模式（如变速、分裂、反弹），增加解谜维度和策略复杂度。

每个主题有独特的视觉风格和背景音乐，增强了关卡之间的差异化体验。

## 实现难度

中等。绘制识别算法和球体物理需要一定技术实现。最大技术难点：图形绘制的手势识别准确性和球体碰撞的物理模拟精度——需要确保玩家的意图被精确理解，同时物理反馈看起来自然流畅。
