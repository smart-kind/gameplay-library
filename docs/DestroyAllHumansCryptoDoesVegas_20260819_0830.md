# Destroy All Humans! Crypto Does Vegas

- **类型**: 横版射击 / 动作
- **平台**: Mobile (Java 功能机)
- **开发商**: Universomo
- **首次发布**: 2008
- **一句话描述**: 外星人 Crypto 在拉斯维加斯执行 DNA 收集任务的横版射击游戏，拥有独特的环形瞄准系统

## 玩法规则

游戏采用横版卷轴场景，玩家控制外星入侵者 Crypto 在拉斯维加斯进行破坏和 DNA 收集任务。但与传统射击游戏不同，玩家并不直接控制 Crypto 的移动。

**核心操作**：按住"4"或"6"键时，一个瞄准十字准星会围绕 Crypto 以固定距离旋转。准星指示射击方向，而非实际命中点。玩家释放按键时，Crypto 朝准星所在方向开火。

**距离判定**：近距离的目标比远处的更容易命中。屏幕较小且碰撞检测较为宽松，所以消灭普通人类并不困难。

**敌人威胁**：随着关卡推进，会出现赌场安保人员——他们持枪射击。安保人员每隔几秒开火一次，一发子弹即可消灭 Crypto。玩家需要在安保开火前将其消灭或躲避。由于移动范围被限制在准星旋转的小圆圈内，躲避空间有限。

**武器系统**：通过搭档空投，玩家依次获得不同武器——初始的"zap-o-matic"电击枪，更强的"plasma blaster"等离子炮，以及可群体攻击的手榴弹。随着 17 个章节推进，基础激光会升级，从一次击杀一人升级到三人。

**绑架机制**：使用"gloom gun"暂时麻痹人类，搭档将其传送到飞船上进行调查。这是推进剧情的核心机制。

## 核心循环

移动准星瞄准 → 射击消灭人类/安保 → 获得新武器 → 绑架人类收集 DNA → 推进章节

## 核心机制

- **环形瞄准系统**：准星围绕角色旋转而非跟随手指/摇杆，这是一个独特的设计。它既增加了瞄准难度，也创造了策略性的射击角度选择
- **受限移动**：玩家几乎无法主动移动 Crypto，只能在准星旋转的小圆圈内定位，这种限制迫使玩家用射击而非移动来解决威胁
- **武器轮换**：搭档按关卡节奏空投武器，玩家在 zap-o-matic、plasma blaster 和手榴弹之间切换，形成节奏感

## 为什么好玩

将"射击方向由准星旋转决定"这一核心创意发挥到极致，在功能机上创造了一种前所未有的操控体验。17 个章节虽然玩法重复但视觉风格统一，Flash 动画与手绘精灵的混合画面在手机游戏中算得上精致。

## 粘性来源

主要来自独特的环形瞄准操控感——这种设计在射击游戏中极为罕见，给玩家带来新鲜感。但随着关卡推进，核心机制被拉伸过薄，重复感会削弱长期粘性。

## Meta 系统

无

## 实现难度

中 — 环形准星的旋转物理和射击方向计算需要一定数学逻辑，碰撞检测和 AI 射击时机也需精细调校。最大技术难点在于平衡准星旋转速度与射击精度，确保操控既有趣又不过于挫败。
