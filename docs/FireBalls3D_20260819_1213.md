# 火焰球3D（Fire Balls 3D）

- **类型**: 休闲 / 物理弹射
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2019
- **一句话描述**: 点击屏幕发射火焰球，击碎沿途的方块障碍物，同时避免触碰黑色方块。

## 玩法规则

屏幕中央有一列从上往下排列的彩色方块障碍物，每个方块上都标有一个数字（通常是1-3），代表该方块需要被击中的次数才能被击碎。屏幕底部有一个固定的火焰发射器。

玩家操作极其简单：**点击屏幕**，发射一颗火焰球，火焰球垂直向上飞行。火焰球击中彩色方块时，方块数字减1；减到0时方块被击碎。火焰球穿过被击碎的方块后继续向上飞行，直到碰到未击碎的方块或飞出屏幕顶部。

**黑色方块**是障碍物——火焰球碰到黑色方块会熄灭，游戏结束。随着关卡推进，方块的数量和排列方式变得更复杂，黑色方块的出现频率也会增加。

某些特殊方块被击碎后会掉落道具（如多球发射、穿透球等），增强玩家的能力。

## 核心循环

观察方块排列 → 点击发射火焰球 → 球击碎方块 → 方块减少 → 继续发射直到清场或失败 → 进入下一关

## 核心机制

- **弹射角度控制**：部分版本中玩家可以拖拽控制发射角度，增加了策略性。
- **连锁反应**：击碎一个方块后，火焰球可以继续飞行击碎上方的多个方块，形成连锁爽快感。
- **方块数字递增**：越往后的关卡，方块需要的击碎次数越多（从1次到5次甚至更多），要求玩家更高效地利用每颗球。
- **特殊道具系统**：击碎特定方块获得的临时道具（多球、大球、穿透球）让玩家在关键时刻获得逆转能力。

## 为什么好玩

Fire Balls 3D 的爽快感来自于"一颗球连消多个方块"的连锁反应。每次看到火焰球一口气击碎三四个方块时的满足感极强。同时，随着关卡推进，方块排列越来越像谜题，玩家需要在"效率"和"安全"之间权衡——既要快速击碎方块，又要避免撞到黑色方块。

## 粘性来源

- **关卡递进**：数百个精心设计的关卡，每个关卡的方块排列不同，提供持续的新鲜感。
- **连锁快感**：一颗球击碎多个方块的瞬间带来强烈的正反馈。
- **短时局**：每个关卡只需几十秒，非常适合碎片时间。
- **差一点就过的不甘心**：在最后一两个方块处失败会让人立刻重试。

## Meta 系统

无核心Meta系统。部分版本包含皮肤解锁和关卡选择进度。

## 实现难度

低。核心是简单的弹道物理和碰撞检测。最大难点是连锁击碎的动画流畅度和不同道具效果的视觉区分。
