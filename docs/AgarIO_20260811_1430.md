# Agar.io（Agar.io）

- **类型**: 多人在线 / 生存 / 动作
- **平台**: Web
- **开发商**: Matheus Valadares
- **首次发布**: 2015
- **一句话描述**: 控制一个细胞，吃小颗粒变大，吞噬比你小的玩家，躲避比你大的玩家

## 玩法规则

玩家进入一个巨大的二维开放世界地图，初始为一个微小的圆形细胞。地图上散布着大量静止的彩色小颗粒。玩家用鼠标控制细胞的移动方向——细胞会持续向鼠标光标位置移动。

核心操作只有一个方向：移动。通过吃掉地图上的小颗粒，细胞逐渐增大。当玩家接触到比自己小的其他玩家细胞时，可以将其整个吞噬，获得其全部质量。如果被比自己大的玩家接触到，自己就会被吃掉。

细胞越大，移动速度越慢，这使得大细胞容易被小细胞灵活躲避。玩家可以通过按空格键将自己的细胞一分为二，快速弹射出去捕捉远处的小玩家；也可以按W键向某个方向喷射质量，用于加速或减轻体重。

游戏目标是在排行榜上尽可能爬升排名，最终成为地图上最大的细胞。被吃掉后立刻重生为新的小细胞。

## 核心循环

吃颗粒变大 → 吞噬小玩家 → 成为最大 → 被更大玩家吃掉 → 重新开始

## 核心机制

- **大小-速度反比**: 细胞越大移动越慢，创造了"强者反而容易被弱者戏耍"的动态平衡
- **分裂弹射**: 将自身一分为二可以瞬间加速追击，但也增加了被攻击的风险
- **质量喷射**: 主动减小体重来加速逃脱，但喷射出的质量可能被对手吸收
- **实时多人**: 所有玩家在同一个服务器上竞争，排行榜实时刷新

## 为什么好玩

Agar.io用最简单的规则创造了最紧张的生存博弈。你永远不知道屏幕外会不会突然出现一个比你大十倍的不速之客，也可能下一秒你就猎杀了排行榜上的头号玩家。那种"猎手与猎物身份瞬间转换"的刺激感是它最大的魅力。

## 粘性来源

即时反馈的吞噬快感 + 排行榜竞争驱动 + 每局都是全新的开始。分裂与合并的操作深度让高手可以玩出花式操作（如假合并诱敌、分裂骗吃等），形成技术天花板。一局只需几分钟，随时可以再开一局。

## Meta 系统

无。纯竞技场模式，无等级或装备成长。

## 实现难度

低 — 游戏逻辑相对简单：圆形碰撞检测 + 物理移动 + 多人同步。技术难点在于实时多人服务器的优化（处理大量玩家的位置同步）和防止作弊。但对于单机版或小游戏实现来说，是一个入门级的多人游戏原型。
