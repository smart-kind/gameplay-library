# 杀戮营地（Slayaway Camp）

- **类型**: 解谜 / 推箱子变体 / 黑色幽默
- **平台**: Mobile (iOS+Android) / PC / Switch / PS4
- **开发商**: Blue Wizard Digital（由 PopCap Games 联合创始人 Jason Kapalka 领导）
- **首次发布**: 2016
- **一句话描述**: 以 80 年代砍杀电影为背景的推箱子式解谜游戏——你扮演杀手，在网格中规划路线猎杀受害者

## 玩法规则

游戏画面为俯视的二维网格地图，类似于经典的 Sokoban（推箱子）解谜。网格中分布着各种元素：杀手（玩家控制）、受害者（NPC）、障碍物（树木、栅栏、帐篷、河流等）和特殊道具。

玩家通过滑动屏幕控制杀手移动方向（上/下/左/右）。杀手一旦选定方向，会持续朝该方向移动，直到撞到障碍物才会停下来——这是游戏的核心移动规则。你不能在移动中途停下来。

每个关卡的目标是在限定步数内杀死所有受害者。杀手移动到受害者所在的格子即可完成猎杀。但障碍物会改变你的移动路线，你需要利用障碍物来精确控制杀手最终停下的位置。

部分关卡包含特殊机制：可以推动的箱子、可以踩踏的桥梁、需要按顺序击杀的目标等。随着关卡推进，障碍物的排列越来越复杂，需要多步预判才能规划出正确的击杀路线。

## 核心循环

观察关卡布局 → 规划移动路线 → 执行猎杀 → 解锁新关卡

## 核心机制

- **惯性滑动移动**：杀手一旦选择方向就会一直滑下去直到撞墙。这是从推箱子游戏中继承的核心机制，但在血腥主题下产生了全新的策略感——每次选择方向都是在赌博。
- **环境障碍利用**：障碍物既是阻碍也是工具。你可以利用障碍物来改变杀手的方向、缩短移动距离，或者将杀手引导到特定位置击杀目标。
- **步数限制**：每个关卡有最大步数限制，迫使玩家寻找最优解。不是"能杀光就行"，而是"要用最少步数杀光"。
- **血腥美学与幽默感**：游戏刻意采用了 80 年代 B 级砍杀电影的视觉风格——像素化的血腥效果、复古的配乐、夸张的死亡动画。这种荒诞感让一个关于杀戮的游戏变成了黑色喜剧。

## 为什么好玩

Slayaway Camp 把枯燥的推箱子解谜包装成了一场 B 级恐怖片狂欢。每次成功规划出一条"完美杀戮路线"时的成就感，配上夸张的血腥动画和复古配乐，形成了独特的游戏魅力。开发者自称这是"给讨厌解谜游戏的人做的解谜游戏"——用主题和幽默降低了传统推箱子的门槛。

## 粘性来源

"差一步就完美"的挫败感驱动玩家不断重试。每关的步数限制创造了一种智力挑战——找到最优解的满足感远大于"随便杀杀"。关卡之间的进度解锁和新机制的持续引入保持了新鲜感。血腥喜剧风格的叙事元素让玩家想看下一个关卡的"电影场景"。

## Meta 系统

- **关卡解锁**：完成一个区域的所有关卡解锁下一个区域，每个区域有不同的场景（露营地、学校、医院等）。
- **道具收集**：部分关卡隐藏特殊物品，收集后有视觉奖励。
- **评分系统**：每关根据使用步数给予星级评价。

## 实现难度

低。核心机制是经典的推箱子算法，只需要在网格上做碰撞检测和路径计算。最大的技术难点在于设计关卡——确保每个关卡都有合理的解，同时难度递进自然。这更像是设计谜题而非编写复杂代码。
