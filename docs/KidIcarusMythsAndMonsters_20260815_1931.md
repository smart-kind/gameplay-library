# Kid Icarus: Of Myths and Monsters

- **类型**: 平台射击 / 动作冒险
- **平台**: Game Boy
- **开发商**: TOSE
- **首次发布**: 1991
- **一句话描述**: 操控 Pit 在希腊神话风格的世界中飞行射击，对抗各种神话怪物。

## 玩法规则

游戏画面为横向卷轴平台关卡，分为两种模式交替进行：

**平台模式**（地面战斗）：
- 画面显示平台、悬崖、障碍物和敌人。
- 玩家使用方向键控制 Pit 左右移动、攀爬梯子、蹲下。
- **A 按钮**：射箭（向前方发射弓箭）。
- **B 按钮**：跳跃。可以跳上平台或跳过障碍物。
- 地面上有多种敌人（蛇、蝙蝠、独眼巨人等），各有不同的移动模式和攻击方式。
- 击败敌人后掉落能量心（Heart Container），用于提升生命值上限或补充生命。
- 需要到达关卡末端的传送门才能进入下一区域。

**飞行模式**（空中射击）：
- 视角变为俯视，Pit 展开双翼向上飞行。
- 画面自动向上滚动，玩家需要快速向上移动。
- 空中有敌人和障碍物，需要躲避并发射弓箭反击。
- 触碰到敌人或障碍物会损失生命值。

游戏有多个世界（World），每个世界包含多个关卡。关卡之间有商店（Palutena's Temple），可以用收集的 Hearts 购买道具和升级。

## 核心循环

地面战斗（射击+平台跳跃） → 到达传送门 → 飞行射击 → 收集 Hearts → 升级装备 → 挑战下一关

## 核心机制

- **双模式交替**：平台射击与飞行射击交替进行，为游戏增加了节奏变化。地面关卡注重精确跳跃和瞄准，飞行关卡注重快速反应和弹幕躲避。
- **弓箭升级**：在商店购买弓箭升级，提升射程、射速和伤害。
- **Heart 收集经济**：Hearts 既是货币（在商店购买道具）也是资源（提升生命值），需要权衡消费与积累。
- **密码系统**：Game Boy 无电池存档功能，使用密码系统记录进度。

## 为什么好玩

Kid Icarus: Of Myths and Monsters 是 Game Boy 上难得的横向动作射击游戏。希腊神话主题让敌人和环境设计丰富有趣。飞行模式的紧迫感和地面模式的精确操控形成了良好的互补，使游戏节奏张弛有度。虽然是黑白屏幕，但角色和敌人的辨识度很高。

## 粘性来源

- **关卡递进挑战**：每个世界难度递增，通关成就感强。
- **装备收集**：不同弓箭和道具提供不同的玩法风格。
- **经典平台动作的乐趣**：跳跃、射击、探索的组合永远不会过时。

## Meta 系统

- **商店系统**：Palutena's Temple 作为关间商店，提供弓箭升级、道具购买等服务。
- **密码存档**：通过密码记录进度，允许玩家在下次游戏中继续。

## 实现难度

**低** — 经典的2D平台+射击机制，技术实现成熟。最大技术难点在于飞行模式的自动滚动与碰撞检测的流畅性。
