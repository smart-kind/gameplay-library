# 汉堡猫（Burger Cat (Cat Burger Simulator)）

- **类型**: 模拟经营 / 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Unimy Studio
- **首次发布**: 2025
- **一句话描述**: 一款以猫咪为主角的汉堡餐厅模拟经营游戏，雇佣可爱猫咪员工烹饪和服务顾客。

## 玩法规则

画面呈现一个卡通风格的汉堡店场景，有厨房操作台、食材存放区、顾客等候区等区域。屏幕下方有菜单面板，显示当前可用的食材和工具。

玩家通过点击和拖拽来操作：点击食材将其放入锅中煎烤，拖拽面包片组合成汉堡，点击完成品递给等候的顾客。每只猫咪员工有独立的工作动画，玩家可以指派它们到不同岗位（煎肉、切菜、收银）。

游戏目标是满足顾客订单需求，在规定时间内完成足够多的汉堡。每个订单有倒计时，超时会导致顾客离开并扣分。连续完成订单获得连击加成，赚取更多金币。

游戏过关条件为达到指定星级评价（基于完成速度、连击数、顾客满意度）。随着关卡推进，顾客类型增多、订单复杂度上升（多层汉堡、特殊配料组合），猫咪员工也会出现搞笑失误动画。

## 核心循环

玩什么 → 得到什么 → 用来做什么：接订单做汉堡赚取金币，升级厨房和解锁新猫咪来应对更复杂订单

## 核心机制

- **猫咪员工系统**：每只猫咪有独特外观和工作动画，分配到不同岗位效率不同。高级猫咪有被动加成（加快煎烤速度、减少失误率），玩家通过抽卡或任务解锁新猫咪
- **订单组合机制**：从单层汉堡逐步升级到多层复杂组合，考验玩家的记忆力和操作速度。特殊食材有独特烹饪时间，需要精确把握火候
- **连击评分系统**：连续成功完成订单不中断获得连击倍率，鼓励玩家保持节奏。失误打断连击增加紧张感，形成紧张与放松的节奏交替

## 为什么好玩

猫咪员工的可爱动画与紧张的烹饪节奏形成反差萌。看着手忙脚乱的小猫咪们认真工作的样子本身就很有趣，同时经营升级带来的成就感也很扎实。不同猫咪的搞笑失误动画让每次失败都变得有趣而不是沮丧。

## 粘性来源

收集欲（解锁各种造型的猫咪）+ 经营成长（餐厅从小摊变连锁）+ 操作挑战（高难度订单的通关执念）。差一点就能三星的不甘心驱动反复尝试，每只新猫咪的解锁都是强烈的正反馈。

## Meta 系统

- **猫咪收集与升级**：通过游戏内货币抽取或完成任务获得新猫咪，每只猫咪有等级系统，升级后工作效率提升。猫咪品质分为普通、稀有、史诗等级别
- **餐厅装饰**：用金币购买装饰物美化店面，不影响核心玩法但提供收集满足感。装饰物分为家具、墙纸、地板等类别
- **对核心玩法影响**：猫咪等级影响操作容错率，但不改变核心操作逻辑。高等级猫咪减少失误但不会自动完成操作

## 实现难度

低 — 核心玩法为简单的点击和拖拽组合，任何人都能快速上手。最大技术难点在于多角色动画同步和流畅的拖拽物理反馈。需要保证在低端设备上也能流畅运行所有猫咪动画和烹饪特效。
