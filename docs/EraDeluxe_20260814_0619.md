# Era Deluxe

- **类型**: 解谜 / 时间
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款以时间旅行为主题的解谜游戏，玩家需要在不同时代之间切换来解决谜题

## 玩法规则

游戏场景同时呈现两个时代——通常是过去和现在。两个时代的场景有重叠但状态不同，通过不同的色调和视觉风格区分。

玩家可以在这两个时代之间切换（点击切换按钮）。在某个时代的操作会影响另一个时代的状态——比如在过去的时代种下一棵树，在现在的时代这棵树已经长成并可以作为桥梁使用。

谜题需要玩家在两个时代之间来回切换，利用时代差异来解决。比如：过去有一扇关闭的门，现在门已经腐烂可以进入；过去需要移开石头，现在石头风化消失。

目标是通过利用两个时代的差异，找到通往出口的路径。部分关卡有物品需要在特定时代拾取，然后在另一个时代使用。

游戏设有三时代模式，玩家需要在过去、现在、未来三个时代之间切换解谜。三个时代的因果关系更加复杂。

## 核心循环

在两个时代之间切换 → 利用时代差异解决谜题 → 找到出口

## 核心机制

- **时代切换**：在两个时代间切换，每个时代场景状态不同
- **因果关联**：在过去年代的行动影响现在状态
- **物品收集**：在特定时代找到关键物品

- **三时代模式**：过去/现在/未来三个时代的复杂因果关系


## 为什么好玩

时间切换的机制新颖有趣。发现'原来在那个时代是这样'的顿悟感很强。

## 粘性来源

时间谜题的新鲜感+每关新机制的惊喜。

## Meta 系统

无。纯解谜。

## 实现难度

中 — 需要理解时代间的因果关系。最大技术难点是双时代场景的同步渲染。
