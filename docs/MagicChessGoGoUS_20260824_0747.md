# 魔法棋：出发（Magic Chess: Go Go US）

- **类型**: 策略自走棋 / 休闲竞技 / MLBB 衍生
- **平台**: Mobile (iOS + Android)
- **开发商**: Skystone Games Pte. Ltd.（Moonton）
- **首次发布**: 2024
- **一句话描述**: 基于 Mobile Legends 英雄体系的轻量级自走棋策略游戏。

## 玩法规则

游戏采用经典的自走棋框架，每局 8 名玩家参与，轮流进行准备和战斗。

**准备阶段**：玩家使用金币在商店购买"小小英雄"（代表 Mobile Legends 中的英雄角色）。每个英雄有职业和阵营标签。玩家购买后将英雄放置在个人棋盘上，相同英雄可以合成升星（3 个 1 星合成 1 个 2 星，属性翻倍）。

**战斗阶段**：系统随机匹配两名玩家的队伍进行自动对战。英雄自动移动、攻击、释放技能。被击败的一方扣除生命值（根据存活英雄数量决定伤害）。

**核心策略**：
1. **阵容搭配**：凑齐特定数量同职业/同阵营的英雄激活羁绊加成（如 3 法师增加全队法术伤害，4 射手增加攻击速度）。
2. **经济管理**：金币可用于购买英雄、刷新商店、购买经验值提升商店等级。存钱可获得利息收益。
3. **站位调整**：英雄在棋盘上的位置影响战斗结果——前排坦克吸收伤害，后排输出安全输出，刺客需要跳到敌方后排。

**独特机制**：Game 的特色"伙伴系统"——每局开始前选择一个伙伴（宠物），伙伴在整局战斗中提供持续的全局加成（如额外金币、伤害增益、回复效果）。

## 核心循环

选择伙伴 → 购买英雄布阵 → 自动战斗 → 金币奖励 → 升级强化阵容 → 淘汰对手 → 存活到最后

## 核心机制

- **MLBB 英雄复用**：直接使用 Mobile Legends 的英雄池和技能设计，降低了玩家的学习门槛——玩过 MLBB 的人天然了解这些角色。
- **伙伴系统**：每局一个全局 buff 的选择，相当于给自走棋加了一层"开局策略"。不同伙伴适合不同流派。
- **羁绊连锁**：多英雄标签的交叉组合产生丰富的阵容可能性，鼓励玩家探索不同的搭配方案。
- **小小英雄**：玩家的操作角色本身可以升级和更换外观，是主要的个性化表达渠道。

## 为什么好玩

对 MLBB 玩家来说是零学习成本的自走棋体验——所有英雄和技能都已经熟悉。相比硬核自走棋（如 Teamfight Tactics），Go Go 的节奏更快、操作更简化，更适合手机上的碎片时间。同时它保留了自走棋的核心乐趣：阵容构建的成就感和"天胡"开局的爽快感。

## 粘性来源

MLBB 玩家基数的天然导流；赛季更新带来新英雄和新羁绊，每赛季阵容 meta 不同；排位赛竞争驱动反复游玩；小小英雄外观收集；与 MLBB 主游戏的联动活动（特定时间解锁奖励）。

## Meta 系统

排位赛系统（青铜到传奇段位）；小小英雄外观商店（使用游戏内货币或真实货币购买）；赛季通行证（完成每日/每周任务获取奖励）；好友系统和观战功能。排位不影响游戏平衡，仅提供段位标识和赛季奖励。

## 实现难度

中-高。核心自走棋框架（自动战斗、羁绊、经济）已有成熟模板，但需要处理 MLBB 英雄技能的移植和平衡、多人实时匹配、以及伙伴系统的独特机制。最大技术难点是自动战斗 AI 与 MLBB 英雄技能的适配——MOBA 级别的技能需要简化为自走棋环境中的自动释放逻辑。
