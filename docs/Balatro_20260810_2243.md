# 扑克牌Roguelike，用各种Joker牌组建高分牌组（Balatro）

- **类型**: 卡牌/Roguelike
- **平台**: Mobile (iOS+Android) / PC / Switch
- **开发商**: LocalThunk
- **首次发布**: 2024
- **一句话描述**: 扑克牌Roguelike，用各种Joker牌组建高分牌组

## 玩法规则

玩家使用标准扑克牌玩德州扑克式的牌型（对子、三条、顺子、同花等），但加入了Joker卡牌系统。

每个Joker有独特效果（如每次打出对子+4倍、每次出牌+20分等），可以组合出惊人的倍率。

游戏是Roguelike结构，每轮（Ante）需要达到目标分数，失败则重新开始。玩家可以用获得的金钱购买新Joker、升级牌型倍率。

## 核心循环

出牌得分 → 达到目标分数 → 购买Joker/升级 → 下一轮更高目标

## 核心机制

- Joker系统：独特效果的可叠加卡牌
- 牌型倍率：每种牌型有基础分数和倍率
- 商店系统：每轮之间购买Joker或升级
- Roguelike随机性：每局Joker和牌出现随机

## 为什么好玩

简单的扑克规则结合Joker的无限组合，打出天文数字分数时的快感无与伦比。

## 粘性来源

Roguelike的随机性让每局都不同；追求更高倍数的成长感；解锁新Joker的收集欲。

## Meta 系统

Joker解锁系统，通过完成挑战解锁。

## 实现难度

中。需要理解扑克牌型和Joker策略组合。最大技术难点：数值平衡，防止倍率爆炸或过难。
