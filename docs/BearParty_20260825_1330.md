# Bear Party

- **类型**: 派对/休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: DEVGEIM
- **首次发布**: 2022
- **一句话描述**: 从iTunes获取的游戏描述摘要

## 玩法规则

玩家看到的主界面是一个包含多个操作区域的屏幕。根据游戏类型不同，具体布局有所差异：

- 游戏主界面通常包含多个操作按钮和信息显示区域。顶部可能显示分数、计时器或关卡进度。
- 中央区域是主要的游戏操作区域，显示游戏元素（泡泡、宝石、角色、地图等）。
- 底部或侧边显示可用操作、手牌或待放置元素。

玩家的操作方式包括：
- 点击/拖拽：选择并放置游戏元素，进行匹配或移动操作
- 滑动：在某些游戏中进行方向控制或瞄准
- 长按：在某些游戏中蓄力或执行特殊操作

## 核心循环

选择派对游戏 -> 多人参与 -> 获得乐趣/积分 -> 排名

## 核心机制

- **派对模式**: 适合多人一起游玩的派对游戏。操作简单，规则易懂。
- **多人互动**: 强调玩家之间的互动和竞争。适合聚会场景。
- **多样化小游戏**: 包含多种不同类型的派对小游戏。

## 为什么好玩

多人派对的乐趣是最大的卖点。和朋友一起玩的体验远超独自游玩。

## 粘性来源

粘性来源于社交互动的乐趣。每次聚会都是新的体验。

## Meta 系统

- 积分系统：每游戏计分，总分排名
- 对核心玩法的影响：竞争性排名驱动重复游玩

## 实现难度

低 -> 核心逻辑实现难度不大。最大难点在于：对于消除类游戏，需要处理好匹配算法和连锁反应的计算；对于派对游戏类，需要确保多人交互的流畅性。
