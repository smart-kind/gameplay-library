# 迷你足球（Mini Football）

- **类型**: 街机足球
- **平台**: Mobile (iOS+Android)
- **开发商**: Miniclip SA
- **首次发布**: 2020
- **一句话描述**: 快节奏的街机风格足球游戏，支持组队对战和联赛排名。

## 玩法规则

玩家控制球员进行快节奏的足球比赛。

操作包括跑动、传球、射门。

游戏没有复杂的机制，易于上手。

玩家可以加入或创建俱乐部，与全球俱乐部对战，通过赢得比赛提升联赛排名。

定期有活动和独占奖励。

## 核心循环

参加比赛 -> 赢得胜利和奖励 -> 升级球员和球队 -> 冲击更高联赛

## 核心机制

- **快节奏街机操作**：简化的足球操作，跑动、传球、射门，无需复杂战术
- **俱乐部系统**：加入或创建俱乐部，与好友组队对抗全球俱乐部
- **联赛排名**：通过比赛积分攀升联赛等级，从新手到传奇
- **球员收集**：收集不同能力的球员，组建最强阵容

## 为什么好玩

足球运动的简化版，去除了复杂战术，保留了进球的爽快感。与朋友组队增加了社交乐趣。

## 粘性来源

社交竞争（俱乐部对战和联赛排名）+ 球员收集（随机抽卡）+ 定期活动。

## Meta 系统

球员收集系统。通过比赛和活动获得球员卡，提升球队实力。包含随机物品（loot boxes）。

## 实现难度

中 - 需要多人对战同步和联赛系统设计。最大技术难点：实时多人足球物理同步和反作弊是最大难点。
