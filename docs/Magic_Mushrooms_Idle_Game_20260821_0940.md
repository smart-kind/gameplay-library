# Magic Mushrooms - Idle Game

- **类型**: 放置 / 模拟经营
- **平台**: Mobile (iOS)
- **开发商**: Solitaire Games Studio
- **首次发布**: 2018
- **评分**: ⭐ 4.9/5 (17,792 评价)
- **价格**: Free
- **一句话描述**: 唤醒你内心的炼金术士，把蘑菇变成药水来拯救世界！解锁各种有趣的蘑菇和能力。

## 玩法规则

游戏开始时玩家有一个蘑菇园。通过点击蘑菇收集资源（孢子/金币），用资源种植更多蘑菇、升级生产速度。不同蘑菇有不同特性：有的产出更多资源，有的有特殊能力。随着游戏进展，解锁药水制作系统——将蘑菇组合成不同类型的药水，每种药水有独特效果。药水可以出售获得更多资源，或用于加速生产。界面包含：蘑菇园主视图、资源计数器、升级菜单、药水制作台。

## 核心循环

收集蘑菇资源 → 种植/升级蘑菇 → 制作药水 → 出售获利 → 扩展蘑菇园

## 核心机制

- 放置生产：蘑菇自动产出资源，离线也能积累
- 蘑菇多样性：不同蘑菇有不同产出特性和特殊能力
- 药水合成：蘑菇组合成药水，增加策略深度

## 为什么好玩

蘑菇+炼金术的设定新颖有趣。放置玩法让游戏不占时间，适合忙碌玩家。

## 粘性来源

数值成长（指数级增长）、解锁新蘑菇/药水的期待感、离线收益

## Meta 系统

完整的放置经济系统：资源产出→升级→加速→新解锁。核心玩法本身就是meta。

## 实现难度

低——放置游戏模板成熟，数值平衡是关键
