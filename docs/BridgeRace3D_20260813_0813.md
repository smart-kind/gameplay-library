# Bridge Race 3D

- **类型**: 休闲/竞速收集
- **平台**: Mobile (iOS+Android)
- **开发商**: Supersonic Studios
- **首次发布**: 2021
- **一句话描述**: 4.37亿下载，在赛道上收集彩色积木搭桥竞速的超休闲游戏

## 玩法规则

玩家控制角色在3D赛道上自动向前奔跑，沿途散落着不同颜色的积木块。
每个角色头顶实时显示当前持有的各颜色积木数量，让竞争态势一目了然。
到达赛道终点的桥缺口处时，需要用对应颜色的积木搭建桥梁才能通过。
积木颜色必须严格匹配，红色积木只能搭建红色缺口，蓝色积木只能搭蓝色缺口。
赛道上有多个玩家同时竞赛，玩家需要选择最优路径收集所需颜色的积木。
玩家之间可以互相碰撞抢夺对方已收集的积木，增加了直接对抗。
先搭完所有桥梁到达终点的玩家获胜。
赛道中还会出现加速带（提高移动速度）、障碍物（阻挡路径）等动态元素。

## 核心循环

奔跑收集彩色积木 -> 到达缺口处搭桥 -> 率先完成所有桥梁到达终点获胜

## 核心机制

- **颜色匹配搭桥**：积木颜色必须与缺口匹配，增加了策略性而非单纯的收集速度竞争，玩家需要在不同颜色的积木间做取舍，选择最优收集路线
- **玩家抢夺**：可以抢夺其他玩家已收集的积木，增加了直接竞争和对抗性，让领先的玩家也成为目标，形成动态的追逐关系
- **赛道动态元素**：加速带和障碍物增加随机性和操作乐趣，让每局都有不同的路线选择和战术考量
- **头顶显示**：玩家头顶实时显示持有的积木数量和颜色，让竞争态势一目了然，便于制定针对性策略

## 为什么好玩

将简单的"跑步收集"升级为有策略的"收集+搭桥"竞赛。颜色匹配机制让每局都有不同的路线选择，而玩家之间的抢夺让比赛充满变数和紧张感。短时竞速带来的即时反馈让每局都有明确的胜负判定，输赢立判。

## 粘性来源

短时竞速带来的即时反馈是核心粘性。每局只需几十秒，输赢立判，自然驱动"再来一局"。颜色匹配和玩家抢夺的组合让每局都有不同的策略体验，而非单纯的反应速度比拼。解锁新角色外观提供长期的收集动力。

## Meta 系统

角色皮肤解锁系统。通过累计获胜次数解锁不同角色外观和特效。对核心玩法无影响，提供成就感和视觉多样性。部分特殊皮肤需要通过特定成就解锁。

## 实现难度

低。核心是3D移动+碰撞收集+简单的颜色匹配，技术难度低。难点在于多人同步和物理碰撞的流畅性，以及赛道和桥梁的动态生成。使用Unity等成熟引擎可以快速搭建原型。
