# Flick Nations Rugby

- **类型**: 体育 / 街机 / 弹射
- **平台**: Mobile (iOS)
- **开发商**: Full Fat
- **首次发布**: 2012
- **一句话描述**: 用手指滑动控制橄榄球的飞行轨迹，完成射门、传球和达阵。

## 玩法规则

游戏采用3D视角展示橄榄球场，玩家通过"滑动/弹射"操作来控制橄榄球的飞行。游戏包含多种模式：

**射门模式（Conversions）**：
- 画面显示球门和橄榄球，球放在踢球点上。
- 玩家用手指从球的位置滑动到球门方向，滑动速度决定力量，滑动方向决定角度。
- 球在空中飞行时，可能受到风力影响（部分关卡）。
- 球穿过球门上方即得分。

**踢球模式（Kick to Touch）**：
- 目标是将球踢出边线（touch line），同时让球飞得越远越好。
- 滑动操作同上，需要调整力量和角度让球落在最佳位置。

**击柱模式（Hit the Posts）**：
- 目标是用球击中球门的立柱，精度要求极高。
- 需要找到力量与角度的精确平衡。

**传球/达阵模式**：
- 部分版本支持将球传给队友或直接达阵。
- 需要考虑防守球员的位置和移动。

每种模式有目标分数或通关条件，完成所有模式即可赢得比赛。

## 核心循环

选择模式 → 滑动控制球的飞行 → 达成目标 → 解锁新挑战/更高难度

## 核心机制

- **弹射物理**：核心机制是"滑动即控制"——滑动的方向、速度和长度决定了球的飞行轨迹。球的飞行遵循物理规律（重力、空气阻力、旋转），玩家可以利用这些物理特性做出弧线球。
- **风力系统**：部分关卡有风力影响，需要补偿风对球轨迹的影响。
- **精度挑战**：不同模式对精度的要求不同，从简单的射门到极端的击柱挑战。
- **多模式切换**：一场比赛中包含多种不同的踢球挑战，增加了游戏的多样性和节奏变化。

## 为什么好玩

Flick Nations Rugby 的"滑动即控制"机制非常简单直观——任何人都能立刻上手。但要做到精准却需要大量练习，形成了"易上手、难精通"的经典街机体验。橄榄球主题让游戏在同类弹射游戏中独树一帜，Full Fat 标志性的物理手感和精准反馈让每次射门都有满足感。

## 粘性来源

- **精度挑战的驱动**："差一点就中了"的感觉驱使玩家反复尝试。
- **模式多样性**：多种踢球模式避免了单调感。
- **国家/队伍选择**：不同队伍可能有不同的外观和属性。

## Meta 系统

- **解锁模式**：完成基础模式后解锁更高级的挑战模式。
- **成就系统**：各种踢球成就（如连续命中、最远距离等）提供额外目标。

## 实现难度

**中** — 物理模拟（弹道计算、风力影响、旋转效果）是核心难点。最大技术难点在于让物理模拟既真实又有趣——完全真实的物理可能让游戏太难。
