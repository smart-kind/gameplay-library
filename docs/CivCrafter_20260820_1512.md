# CivCrafter（CivCrafter）

- **类型**: 放置 / 策略 / 模拟经营
- **平台**: Mobile (iOS)
- **开发商**: Digital Media Technology SLU
- **首次发布**: 2023
- **一句话描述**: 一款文明建设主题的放置类游戏，通过收集资源、建造设施和升级科技来逐步发展你的文明，从原始部落到繁荣帝国。

## 玩法规则

CivCrafter 呈现一个文明发展的俯视角或斜视角画面。初始状态下，你有一个小型定居点和少量村民。画面分为几个区域：中央是文明主场景（建筑、地形、村民活动），下方是资源面板（木材、石材、食物等），侧边是行动按钮和科技树入口。

村民自动执行分配的工作：采集资源、建造建筑、耕种食物。玩家通过点击分配村民到不同工作岗位，决定资源产出的优先级。例如：将更多村民分配到伐木场会增加木材产出，但会减少食物采集。村民数量有限，需要做出战略性分配决策。

随着资源积累，玩家可以建造新建筑（住房、市场、兵营、图书馆等），每种建筑解锁新功能或提升资源产出效率。科技树系统允许玩家研究新技术，解锁更高级的建筑和单位。科技研究需要时间和资源投入。

游戏目标是不断发展文明规模，解锁新的时代和建筑类型。文明等级越高，可建造的建筑越复杂，资源种类越多，管理策略也越丰富。从原始时代的简单木屋到工业时代的复杂设施，视觉和功能同步升级。

## 核心循环

分配村民工作 → 自动采集资源 → 建造新建筑 → 研究科技 → 解锁新时代 → 扩大文明规模 → 重复循环

## 核心机制

- **多维资源管理**：多种资源（木材、石材、食物等）的产出和消耗需要平衡，增加策略深度和决策乐趣
- **村民分配策略**：有限的村民需要在不同岗位间分配，做出优先级决策，类似微型经济调度
- **科技树解锁系统**：逐步研究新技术，解锁更高级的建筑和文明能力，提供清晰的长期目标
- **时代演进视觉反馈**：文明从原始时代逐步发展到更高级的时代，场景视觉和建筑风格同步升级

## 为什么好玩

文明建设的"从小到大的成长感"是核心吸引力。看着一片荒地变成繁荣的定居点，每一步都有明确的进展反馈。资源管理的策略性和科技解锁的期待感形成了良好的循环，让人持续想看看"下一步能建什么"。



文明建设的魅力在于每一个决策都会影响最终结果——是先建住房增加人口，还是先建市场提升经济？这种"每个选择都重要"的设计让玩家持续思考。看着自己的文明从几个原始人发展到拥有复杂设施的繁荣社会，每一步都有明确的进展和反馈。

## 粘性来源

"再研究一个科技""再建一栋建筑"的渐进式目标驱动。每个新解锁的内容都带来新的可能性和视觉变化，让人持续想看看"下一步是什么"。文明等级的数字增长也提供直观的成就感，以及"再升一级就解锁X"的期待。

## Meta 系统

科技树系统（解锁新建筑和时代）+ 文明等级系统（综合评估文明发展程度）+ 建筑图鉴（记录所有已解锁建筑及其功能）。

## 实现难度

中 — 需要实现多资源管理系统、科技树依赖关系、村民AI分配逻辑。最大难点是经济系统的平衡——确保各资源的产出和消耗节奏合理，不会出现某一资源严重过剩或短缺，以及科技树的解锁节奏设计。
