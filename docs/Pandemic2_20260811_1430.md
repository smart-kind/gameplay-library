# Pandemic 2（Pandemic 2）

- **类型**: 策略模拟 / 世界征服
- **平台**: Web (Flash)
- **开发商**: Dark Realm Studios
- **首次发布**: 2008
- **一句话描述**: 设计一种病原体，通过进化传播能力和致死率，感染并消灭全世界

## 玩法规则

玩家控制一种自定义病原体，初始时只感染了一个人。屏幕显示世界地图，可以看到各个国家和地区被感染的状态（颜色深浅代表感染程度）。

核心操作是"进化"：通过积累的进化点数，为病原体添加新的特性。进化方向包括：
- **传播方式**: 空气传播、血液传播、水源传播等——决定病原体扩散的速度和范围
- **症状**: 咳嗽、发烧、内出血等——增加病原体的可见性和致死率
- **抗性**: 抗热、抗冷、抗药——让病原体能在不同环境中存活

游戏内各国政府会采取措施对抗病原体：关闭边境、研发药物、建立医院等。玩家需要平衡传播速度和致死率——如果病原体太早杀死宿主，反而不利于传播。

胜利条件是感染并杀死全世界所有人口。

## 核心循环

病原体传播 → 获得进化点 → 选择进化方向 → 扩大感染 → 对抗各国政府措施 → 最终感染全世界

## 核心机制

- **传播-致死平衡**: 核心策略悖论——杀得太快不利于传播，传播太慢会被治愈
- **多路径进化**: 不同的进化路线组合（如高传播低致死 vs 高致死慢传播）创造不同的游戏体验
- **地理传播模拟**: 不同国家有不同的人口密度、医疗水平和边境政策，影响传播路径
- **政府AI反制**: 各国政府会根据疫情发展采取措施，玩家需要动态调整策略

## 为什么好玩

Pandemic 2把"成为反派"的体验做得引人入胜。你需要冷静地权衡：要不要现在增加致死率？要不要先让病原体变得抗寒以便传播到北欧？每一个进化决策都充满策略性。

## 粘性来源

多周目重玩价值高——不同的进化路线带来完全不同的体验。尝试"完美策略"（既快又难以治愈）的挑战性驱动反复游玩。看着感染地图从零星几个红点扩散到全红，有独特的成就感。

## Meta 系统

成就系统：完成不同进化路线（如纯细菌、纯病毒、纯真菌）和不同胜利条件解锁成就。

## 实现难度

中 — 需要实现简单的流行病学传播模型（SIR模型的简化版）、世界地图的地理数据、以及政府AI的行为逻辑。对于小游戏来说，最大的难点是平衡性调优——让所有进化路线都有可玩性。
