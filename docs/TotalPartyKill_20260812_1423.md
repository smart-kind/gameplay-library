# 全员阵亡（Total Party Kill）

- **类型**: 解谜 / 策略 / 黑色幽默
- **平台**: Mobile (iOS+Android)
- **开发商**: Fastone Games
- **首次发布**: 2018
- **一句话描述**: 一款黑色幽默风格的解谜游戏，玩家需要让队伍中的角色'牺牲'自己来帮助队友通过关卡。

## 玩法规则

游戏画面是一个卡通风格的2D横版关卡，每关有2-3个冒险者角色需要到达终点。
核心机制：某些角色需要牺牲自己才能让其他角色通过。例如站在陷阱上当桥梁，或挡住旋转的刀片。
操作：点击角色使其移动到指定位置；点击触发机关；拖拽物品。
策略核心在于理解每个角色的'牺牲'如何为其他角色创造通路。不是所有角色都能到达终点。
关卡中有各种致命机关：尖刺、刀片、落石、毒液、悬崖等。
通关条件：至少指定数量的角色到达终点（通常不是全部）。
黑色幽默体现在角色的表情和死亡动画——即使被碾碎也保持微笑。

## 核心循环

观察关卡布局和机关 → 决定谁牺牲谁前进 → 安排角色行动顺序 → 执行牺牲策略 → 通关

## 核心机制

- **牺牲机制**：核心创意——让角色主动牺牲（充当桥梁、挡住机关、触发陷阱）来为他人创造通路。这颠覆了传统游戏'保全所有角色'的目标。
- **行动顺序策略**：角色的行动顺序决定了谁能牺牲、谁能在牺牲后通过。顺序错误可能导致所有角色死亡且无人到达终点。
- **黑色幽默**：角色以卡通方式'死亡'——被压扁、切碎、烧焦，但始终保持搞笑表情，消解了死亡的沉重感。
- **关卡多样性**：每关引入新的机关类型或角色能力，保持新鲜感。

## 为什么好玩

黑色幽默与解谜策略的有趣结合。'让队友去死'的反直觉玩法带来新鲜感，每次想到牺牲方案并成功执行时有策略解谜的满足感。

## 粘性来源

黑色幽默的娱乐性；'牺牲谁'的策略选择带来重玩价值；关卡难度递增保持挑战感；每关新的机关类型保持新鲜。

## Meta 系统

关卡解锁系统——完成关卡后获得星星评级，积累星星解锁新区域。

## 实现难度

低 — 2D横版关卡和简单角色移动，技术实现不复杂。最大技术难点在于死亡动画的流畅性和关卡逻辑的bug-free实现。

## 游戏变体

多数游戏在不同平台上发布了HD版、重制版或移植版本，核心玩法保持不变。
