# 列车危机高清版（Train Crisis HD）

- **类型**: 解谜 / 策略
- **平台**: Mobile (iOS)
- **开发商**: U-Play Online
- **首次发布**: 2012
- **一句话描述**: 列车调度解谜游戏，玩家需要通过切换轨道和控制信号灯来引导不同颜色的列车安全到达对应侧线，避免碰撞。

## 玩法规则

屏幕上有多条轨道交叉，不同颜色的列车从一端驶出，需要到达另一端对应颜色的侧线。

列车以固定速度运行，点击开始按钮后立即启动，玩家无法控制列车速度。唯一能控制列车移动的方式是：在交叉点切换轨道方向、或在信号灯处临时停车。

玩家需要在列车运行前或运行中迅速做出决策，规划好每个交叉点的轨道切换时机和信号灯的使用。

如果两列火车相撞、列车脱轨或在后期关卡中与其他车辆发生碰撞，则游戏失败。

后续关卡难度急剧上升，需要在极短时间内做出多个精确操作。部分关卡要求特定的操作组合才能通关。

通关评价以星星系统呈现，完成关卡获得星星，积累足够星星可解锁奖励关卡。
## 核心循环

观察关卡布局，规划轨道切换方案，启动列车并实时操作，避免碰撞通关，获得星星解锁新关卡

## 核心机制

- **轨道切换机制**：在交叉点切换轨道方向来改变列车行驶路线，是核心操作手段
- **信号灯控制**：通过信号灯临时停车来调节列车通过时间窗口，增加时间维度的策略性
- **不可逆执行**：列车一旦启动就无法停止或撤销操作，要求玩家提前规划并在执行中保持精确
- **多颜色匹配**：不同颜色列车需到达对应颜色侧线，增加了路线规划的复杂度

## 为什么好玩

Unity引擎打造的精美画面让蒸汽火车和隧道轨道栩栩如生，色彩鲜明的机车和细腻背景令人赏心悦目。类似Trainyard的玩法但增加了实时操作元素。

## 粘性来源

解谜成功时的豁然开朗感是核心粘性来源。但极高的难度曲线和偶尔不可靠的触屏操作可能导致挫败感。需要在失败后反复尝试，差一点就成功的不甘心推动继续。

## Meta 系统

星星评分系统。每个关卡根据表现获得1-3颗星，积累星星解锁奖励关卡。无其他成长系统。

## 实现难度

高。最大技术难点在于实时操作下多列车轨迹的碰撞检测和精确时机计算，以及触屏操作响应延迟对游戏体验的影响。
