# Diner DASH Adventures

- **类型**: 休闲
- **平台**: Mobile (iOS+Android)
- **开发商**: Glu Games LLC
- **首次发布**: 2019
- **一句话描述**: 一款休闲类游戏，This game includes optional in-game purchases of virtual currency that can be us

## 玩法规则

- 玩家经营餐厅，需要快速接待客人、安排座位、点单、上菜和结账
- 通过触摸屏幕点击客人来接待，拖拽食物到对应客人的桌上
- 客人的耐心值会随时间下降，超时会导致不满和小费减少
- 游戏目标是在限定时间内获得足够的金钱和好评
- 需要合理规划座位和服务顺序，提高服务效率
- 客人有不同菜品偏好，需要准确记忆并及时上菜

## 核心循环

服务客人 → 获得金钱和小费 → 升级餐厅 → 解锁新关卡和菜品

## 核心机制

- 时间管理系统：每位客人有耐心倒计时，需要高效安排服务流程
- 资源管理：有限的工作台位和菜品需要合理分配，最大化服务效率
- 升级系统：使用赚取的金钱升级餐厅设施，解锁新菜品和装饰

## 游戏特色

- **易于上手**：核心操作简单直观，新玩家无需教程即可理解基本玩法
- **渐进难度**：关卡设计遵循"简单引入→逐步加深→挑战极限"的节奏，让每个水平的玩家都能找到乐趣
- **视觉反馈**：每次操作都有清晰的视觉和音效反馈，让交互体验更加直观和满足
- **碎片化友好**：单局游戏时长控制在2-5分钟，适合通勤、排队等碎片时间游玩

## 为什么好玩

快节奏的餐厅经营让人紧张又上瘾，时间压力下的高效服务带来巨大成就感。随着餐厅升级，玩法深度不断增加。

## 粘性来源

关卡解锁驱动持续游玩；餐厅装修和升级的养成感；连击服务和高分记录的挑战欲；时间压力下的高压快感。

## Meta 系统

餐厅升级系统：用赚取的金钱升级设施、解锁新菜品和装饰
关卡系统：每个区域有多个关卡，达成目标后解锁新区域
角色换装：解锁不同的餐厅外观和服装

## 实现难度

低 — 核心是触摸点击和时间管理，技术上没有难点，最大挑战是平衡游戏难度曲线
