# Street Skater（Street Skater）

- **类型**: 体育模拟 / 动作 / 跑酷
- **平台**: Web（浏览器）
- **开发商**: 浏览器游戏开发者
- **首次发布**: 2010s
- **一句话描述**: 网页版滑板游戏，玩家控制滑板运动员在街道场景中进行各种特技动作并收集分数

## 玩法规则

游戏画面为横版或伪3D视角的街道场景。玩家控制一名滑板运动员，通过键盘按键（方向键+功能键）操控角色在坡道、栏杆、台阶等地形上进行滑行和特技表演。

基本操作包括：跳跃（Ollie）、翻转（Kickflip/Heelflip）、磨杆（Grind）、空中旋转（Spin）等。每个特技动作根据其难度和完成度获得相应分数。连击系统鼓励玩家连续做出多个动作而不落地——落地越完美，连击倍率越高。

关卡通常有限时或目标分数要求。玩家需要在时间耗尽前达到目标分数，或在自由模式下尽可能获得高分。场景中散布着收集品（硬币、星星等）提供额外分数。

## 核心循环

滑行 & 寻找特技点 → 执行特技动作 → 获得分数 & 连击倍率 → 挑战更高难度关卡

## 核心机制

- **特技输入系统**：不同特技需要不同的按键组合和时机。简单动作如跳跃按一个键，复杂动作如翻转+旋转需要组合键。输入窗口有限，时机错误会导致摔倒。
- **连击系统**：连续完成特技不落地会累积连击倍率。倍率越高，后续特技的分数加成越大。落地失败则连击清零。
- **场景互动**：坡道、栏杆、台阶、半管（half-pipe）等地形元素与特技系统互动——在栏杆上自动进入磨杆状态，从坡道起跳可以做出空中动作。

## 为什么好玩

Street Skater 把现实中的滑板运动简化成了可操作的网页游戏——不需要真实的平衡感和勇气，就能体验做出高难度特技的成就感。连击系统的分数追逐让人不断尝试"再来一次做得更好"。

## 粘性来源

- **技巧 mastery**：从只会跳跃到掌握连招需要练习，掌握新技巧的过程本身就是乐趣
- **分数挑战**：高分排行榜和自我突破的动力——"上次得了5000分，这次一定能更高"
- **短时反馈**：一局几十秒到几分钟，随时可以停下来或继续

## Meta 系统

无。纯核心玩法，可能有解锁新角色或场景的进度系统。

## 实现难度

- **学习曲线**：新手可以立即上手，但精通需要数十小时的练习。每次游玩都能发现新的技巧或策略。
- **重玩价值**：高。每局游戏都有不同的体验，无论是随机的地图/敌人，还是玩家的策略选择。
- **社区生态**：作为经典浏览器游戏，它在玩家社区中有良好的口碑。
- **技术亮点**：在浏览器环境中实现流畅的交互体验，充分利用了现代 Web 技术的能力。
低-中 + 2D物理模拟、动画系统、碰撞检测。最大技术难点是特技动作的流畅动画和输入时机的精确判定。
