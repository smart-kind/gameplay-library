# Draw Slasher（Draw Slasher）

- **类型**: 休闲 / 动作
- **平台**: Mobile (iOS)
- **开发商**: SUPERSONIC STUDIOS LTD
- **首次发布**: 2021
- **一句话描述**: 通过自由绘制涂鸦来创建武器并战斗的创意休闲动作游戏

## 玩法规则

游戏的核心操作非常简单——玩家在屏幕上用手指自由绘制线条。这些绘制的线条会立刻变成游戏中的实体（武器、障碍物等），与游戏世界中的其他物体产生物理交互。

玩家面对不断出现的敌人或障碍物，通过快速绘制不同的形状来创建武器攻击它们。例如，绘制一个圆形可以生成回旋镖，绘制一条直线可以生成刀刃。

游戏通常有波次（wave）系统——每波敌人数量和种类递增。玩家需要在限定时间内消灭所有敌人才能进入下一波。

当敌人的攻击耗尽玩家生命值时，游戏结束。每波通关获得分数或奖励，可以用来解锁新的绘制工具或特殊能力。

## 核心循环

绘制武器 → 消灭敌人 → 获得分数 → 面对更强的敌人波次 → 继续绘制

## 核心机制

- **自由绘制生成**：玩家绘制的任何线条都会被识别并实体化，这种"画什么得什么"的机制让游戏充满创造性
- **物理交互**：绘制出的武器遵循物理规则（重力、碰撞、动量），增加了不可预测性和趣味性
- **波次递进**：随着波次增加，敌人的类型、数量和攻击方式变化，迫使玩家不断调整绘制策略

## 为什么好玩

"在屏幕上画画就能战斗"这个概念本身就很有趣。每次绘制的结果都带有不确定性——线条的形状、落点、旋转方向都会影响战斗效果，这种创意+随机的组合非常吸引人。

## 粘性来源

创造性是核心粘性——玩家总想尝试画出不同的形状看看效果。波次挑战的"再试一波"冲动也很强，因为每次绘制的结果都不可完全预测。
