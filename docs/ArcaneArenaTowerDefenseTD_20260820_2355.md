# Arcane Arena（Arcane Arena: Tower Defense TD）

- **类型**: 塔防 / PVP竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: Panteon
- **首次发布**: 2025
- **一句话描述**: 一款实时PVP塔防游戏，双方玩家各自布防，看谁的防线能坚持更久。

## 玩法规则

游戏采用对称竞技场设计，左右两侧各有一名玩家的防线。双方同时收到一波波敌人进攻，需要各自放置防御塔。

战斗界面分为三个区域：左侧（对手的防线和敌人进度）、中央（双方比分和倒计时）、右侧（自己的防线）。

每回合双方获得相同数量的法力值和一组塔卡牌。玩家需要将塔放置在自己的一侧，同时可以选择释放技能卡干扰对手（如增加对手侧敌人的血量、减少对手的防御塔攻击力等）。

胜利条件：当一方的防线被完全突破（敌人到达底线），该方失败。如果双方都撑过了所有波次，则比较剩余生命值，高者获胜。

塔分为攻击型（直接伤害）、防御型（给其他塔加buff）、控制型（减速/冻结敌人）三类。卡牌系统允许玩家在战前构建牌组，影响每局可抽到的塔类型。

每局约2-4分钟，采用天梯匹配制。

## 核心循环

收到敌人波次 → 消耗法力放置防御塔 → 释放技能干扰对手 → 坚持到对手先崩溃

## 核心机制

- **同步PVP对抗**: 双方同时面对相同的敌人波次，胜负取决于谁的防御效率更高。这种同题竞技模式比传统PVP更纯粹地考验策略水平
- **干扰卡牌系统**: 除了防御塔，玩家还可以打干扰卡来削弱对手（如让对手侧出现额外敌人、降低对手塔的攻击力），增加直接对抗的紧张感
- **三塔职能互补**: 攻击型（伤害主力）、防御型（buff增益）、控制型（减速冻结）各司其职，需要合理搭配。单一类型无法应对所有情况

## 为什么好玩

将塔防的单人策略体验升级为竞技对抗，每局都是与真人玩家的智力较量。同时布防的紧张感和我能比对手撑得更久的好胜心驱动持续对战。干扰卡增加直接对抗的刺激感。

## 粘性来源

天梯段位的竞争驱动；上一局差点赢了的不甘心；牌组构建的试错乐趣；每局短时长降低单次挫败感。

## Meta 系统

- **天梯段位与卡牌收集**: 胜利获得天梯积分，收集卡牌解锁新塔和干扰卡
- **对核心玩法的影响**: 更多卡牌提供更多策略选项，天梯段位影响匹配对手和赛季奖励

## 实现难度

高 — 实时PVP需要处理网络延迟、匹配平衡、反作弊等复杂问题，最大技术难点是双端同步的延迟补偿和卡牌平衡的持续迭代
