# 大时间游戏（Big Time Games）

- **类型**: 休闲/合集
- **平台**: Mobile (iOS+Android)
- **开发商**: iTunes Store Developer
- **首次发布**: 2014
- **一句话描述**: 休闲小游戏合集平台

## 玩法规则

应用提供多种休闲小游戏供玩家选择。每款游戏有独立的操作界面和规则，从益智解谜到动作反应。玩家点击图标即可开始游戏，通过触屏操作完成游戏目标。游戏通常设有分数记录和进度保存，玩家可随时返回继续。部分游戏支持离线游玩。

玩家在游戏界面中看到清晰的操作区域和目标指示。屏幕上方显示当前分数或进度，下方或侧边有操作按钮和控件。

主要操作方式包括：
- **点击**: 执行核心动作（射击、收集、选择等）
- **滑动**: 控制方向或调整参数
- **拖拽**: 精确控制物体移动或瞄准

游戏的目标根据具体关卡或模式有所不同，但核心是最大化得分、完成关卡目标或在竞争中获胜。

游戏结束条件通常为：时间耗尽、生命值归零、或碰撞障碍物。过关条件则是完成关卡设定的目标任务。

## 核心循环

选择游戏 → 游玩获得分数 → 保存进度 → 返回选择

## 核心机制

- **多游戏集合**:  涵盖益智、动作、解谜等多种类型
- **离线支持**:  多数游戏无需网络即可游玩
- **进度保存**:  自动保存游戏进度

## 为什么好玩

多款游戏集合满足不同心情，随时可玩的便利性

## 粘性来源

游戏多样性降低厌倦感；进度保存激励回归

## Meta 系统

分数记录和成就系统

## 实现难度

低 - 每款小游戏实现简单 - 多款小游戏在单一应用中的性能管理
