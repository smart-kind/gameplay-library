# Gun Sprint

- **类型**: 休闲竞速
- **平台**: Mobile (iOS+Android)
- **开发商**: KAYAC Inc.
- **首次发布**: 2021
- **一句话描述**: 独特的赛车游戏——向后射击产生反冲力推动赛车前进

## 玩法规则

游戏采用3D视角。赛道上有各种障碍物和转弯。玩家点击屏幕开枪，子弹向后发射产生的反冲力推动赛车前进。

这是一个非常创新的机制：射击既提供动力又消灭前方的敌人。每次射击都同时影响赛车的速度和方向，需要精确控制。

赛车需要控制前进方向和射击时机。射击太频繁会偏离赛道（因为反冲力方向会变化），射击太少速度不够。转弯时需要调整射击方向来配合转向。

赛道设计紧凑，敌人分布在各处。前方的敌人会阻挡去路，射击既提供动力又消灭障碍，一举两得。

每局比赛约1-2分钟，操作只需单指点击。

## 核心循环

点击射击 → 反冲力推动前进 → 消灭敌人清除障碍 → 率先冲线

## 核心机制

- **反冲力动力系统**: 射击产生的反冲力是推动赛车的唯一动力。每次射击都同时影响速度和方向，射击角度决定了前进方向。这个机制将射击和竞速两种类型完美结合。
  （创新物理）
- **敌我双重互动**: 前方的敌人既是要消灭的目标，也是推动前进的'燃料'。射击消灭敌人获得反冲力，一举两得的设计非常巧妙。
  （双重目的）
- **赛道精细控制**: 需要在赛道范围内控制赛车，过度射击会飞出赛道，射击不足会速度不够。转弯时需要精确控制射击方向和力度。
  （平衡控制）

## 为什么好玩

射击=动力的创新机制让每次操作都有双重意义，非常有创意。反冲力的物理手感令人上瘾，KAYAC一贯的精巧设计让这个游戏脱颖而出。

## 粘性来源

创新的核心机制（射击=动力）带来新鲜感、反冲力物理手感的独特性、赛道控制的精确挑战。每次射击都是一次微妙的平衡决策。

## Meta 系统

解锁新赛车和新赛道，无深度数值成长。核心驱动力是机制的新鲜感和赛道挑战。

## 实现难度

中 — 反冲力物理系统需要精细调校，3D赛道渲染有一定复杂度。创新机制的实现和手感调校是主要难点。
