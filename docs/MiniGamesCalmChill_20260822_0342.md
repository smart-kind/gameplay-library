# Mini Games: Calm & Chill

- **类型**: 休闲合集/迷你游戏
- **平台**: Mobile (iOS+Android)
- **开发商**: CTC TECHNOLOGY LIMITED
- **首次发布**: 2024
- **一句话描述**: 一款包含多种玩法的games类型游戏

## 玩法规则

- 玩家进入游戏后首先看到主界面，这里以网格或轮播形式展示所有可用的小游戏图标。每个图标下方标注小游戏名称和当前进度（如最高分或通关状态）。
- 点击任意小游戏图标即可进入该游戏，每款小游戏有独立的界面和操作方式。操作涵盖点击消除、滑动切割、长按蓄力、拖拽放置等多种手势，每种手势对应不同的游戏机制。
- 玩家在每款小游戏中需要在限定时间或步数内达成目标——可能是消除特定数量的方块、将球投入洞中、躲避障碍物到达终点等。完成关卡后获得星星评价和金币奖励。
- 游戏目标是收集所有小游戏的三星评价，解锁隐藏小游戏，或在多人模式中击败好友。全局成就系统追踪玩家在所有小游戏中的总进度。


游戏主界面展示所有可用小游戏的图标或缩略图，玩家可以自由点击选择想要游玩的项目。每个小游戏有独立的入口和进度记录。

每个小游戏的操作方式各不相同——有些需要点击、有些需要滑动、有些需要长按控制力度。玩家在每款小游戏中都有明确的目标（如达到一定分数、完成特定动作、在限时内通关等）。

作为合集类游戏，每款小游戏都是独立体验，进度不会互相影响。但合集本身可能有全局的成就系统或等级系统，通过游玩各款小游戏来积累整体进度。

游戏目标是在每款小游戏中取得更好的成绩，解锁隐藏内容，或在与好友的比拼中获胜。

## 核心循环

选择小游戏 → 完成挑战 → 获得分数/奖励 → 解锁新内容或继续挑战

## 核心机制

- 多合一架构：将多种不同类型的迷你游戏整合到一个应用中，覆盖解谜、反应、动作、策略等品类
- 独立进度：每款小游戏有独立的最高分记录和解锁状态
- 快速匹配：大部分小游戏支持秒开局，无需加载等待
- 成就系统：全局成就追踪玩家在各个小游戏中的总体表现

## 为什么好玩

一个App内包含多种玩法，随时可以切换不同类型的挑战，满足碎片化娱乐需求

## 粘性来源

多品类覆盖降低厌倦感；好友对战或排行榜提供社交竞争动力；每款小游戏都有独立进度和收集要素

## Meta 系统

全局等级和经验值系统。玩家通过游玩任意小游戏获得经验值，提升全局等级可以解锁新的小游戏或特殊外观。部分合集游戏还包含每日挑战和限时活动，提供额外奖励。

## 实现难度

中 — 需要开发多款独立小游戏并整合到统一框架中，最大难点是每款小游戏都需要精心设计且保持一致的UI/UX水准
