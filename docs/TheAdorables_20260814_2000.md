# The Adorables

- **类型**: 策略塔防 / 实时对战
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2013
- **一句话描述**: 操控可爱生物进行实时对战的策略塔防游戏

## 玩法规则

玩家在一条分道的战场上部署可爱的小生物来对抗对手。游戏的核心是实时策略——同时管理进攻和防守。

游戏界面以俯视视角呈现分道战场。左右两侧分别是玩家和对手的基地，中间有多个通道连接。玩家通过点击屏幕选择并部署不同类型的生物。

每种生物有独特的能力：有的擅长近战攻击，有的擅长远程射击，有的可以建造防御工事。生物自动沿着通道向对手基地前进，遇到敌方生物会发生战斗。

游戏目标是摧毁对手的基地或阻止对手摧毁自己的基地。资源随时间自动产生，用于部署更多生物。

## 核心循环

收集资源 → 部署生物 → 观察战况 → 调整策略 → 推进/防守

## 核心机制

- **多通道战场**：多个通道让战斗有横向和纵向的策略维度
- **生物类型差异**：近战、远程、防御等不同类型生物各有克制关系
- **实时决策**：需要在战斗中实时调整部署，考验反应和策略
- **资源管理**：有限的资源需要在进攻和防守间合理分配

## 为什么好玩

可爱的生物形象和紧张的战略对战形成有趣反差。看着自己的小生物们勇敢地冲向敌阵，既有策略深度又有视觉趣味。

## 粘性来源

可爱生物形象的吸引力 + 实时对战的紧张感 + 生物类型搭配的战术深度 + PvP竞争的刺激性

## Meta 系统

生物收集系统 — 通过游戏进度解锁新生物类型，增加战术多样性

## 实现难度

中 — 需要实时对战网络和AI系统，最大技术难点在于PvP延迟控制和生物AI的平衡性
