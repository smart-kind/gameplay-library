# Oddworld: Abe's Oddysee（Oddworld: Abe's Oddysee）

- **类型**: 平台解谜 / 动作冒险
- **平台**: PC / PlayStation / Mobile (iOS+Android) / 多平台移植
- **开发商**: Oddworld Inhabitants
- **首次发布**: 1997
- **一句话描述**: 扮演被奴役的工人Abe，利用潜行、解谜和策略拯救同伴逃离工厂

## 玩法规则

游戏采用2.5D横版卷轴视角，玩家控制主角Abe在一个充满工业机械和敌人的工厂环境中移动。画面左侧或右侧可以移动，每个区域都有独特的谜题布局。

玩家可以使用多种操作：行走和跑步（方向键）、蹲伏（躲避敌人视线）、跳跃（跨越障碍）、说话/唱歌（吸引同伴跟随）以及最重要的"游戏之魂"能力（附身控制敌人）。

每个操作都有明确的效果——跑步更快但发出更多噪音容易被发现；蹲伏可以躲在掩体后面；跳跃用于跨越平台和陷阱；唱歌可以让附近的Mudokon同伴跟随你；附身能力让你短暂控制敌人，利用他们打开门或射击其他敌人。

游戏的目标是尽可能多地拯救Mudokon同伴——通过唱歌让他们跟随，引导他们到安全区域。每个关卡都有隐藏的同伴等待被发现，拯救数量直接影响结局。

游戏失败条件：Abe被敌人发现并击杀，或者让同伴陷入危险。游戏结束或过关取决于是否成功引导同伴到达出口。

## 核心循环

探索关卡 → 解谜并拯救同伴 → 到达出口 → 解锁新区域

## 核心机制

- **潜行系统**：Abe战斗力极弱，必须躲避敌人视线。利用掩体、阴影和声音管理来通过危险区域。为什么有效——创造了紧张感和策略性思考。
- **附身控制（GameSpeak）**：通过唱歌附身敌人，短暂控制他们的行动。可以用来开门、消灭其他敌人或解决环境谜题。这是游戏最独特的机制。
- **同伴救援**：唱歌让Mudokon跟随，引导他们到安全出口。拯救数量越多，结局越好。增加了重玩价值。
- **环境解谜**：利用开关、传送带、移动平台等环境元素前进。每个区域都有独特的谜题设计。

## 为什么好玩

Oddworld: Abe's Oddysee将平台跳跃与深度解谜和潜行元素独特融合。Abe无法战斗的设计迫使玩家思考而非反应，每次成功拯救同伴都带来成就感。黑暗幽默的故事和独特的艺术风格让这款游戏在平台游戏中脱颖而出。

游戏的世界观设定在一个反乌托邦式的工业世界，玩家扮演的Abe原本是流水线上的工人，偶然发现自己的同伴将被屠宰做成食品。这种"觉醒—反抗—拯救"的叙事弧线让玩家在游玩过程中产生强烈的情感共鸣——你不仅仅是在解谜，你是在拯救生命。

每一关中隐藏的Mudokon同伴数量各不相同，有些藏在几乎看不见的暗处，有些需要特定的顺序才能安全救出。这种"探索式收集"与核心解谜流程自然融合，不会让人感到刻意。

## 粘性来源

拯救同伴的数量直接决定结局（好/坏结局），这种"差一点就能拯救全部"的不甘心感让人反复尝试。每个区域都隐藏着几个难以发现的Mudokon，收集欲和完美主义驱动玩家重玩。附身机制的巧妙使用让每次通关都有不同的解谜方式。

此外，游戏对操作精度的要求也制造了粘性——有时需要在毫厘之间控制附身的时机，或者在敌人巡逻的间隙中穿梭。每次失误都让人觉得"差一点就能做到"，从而触发再试一次的冲动。

## Meta 系统

无。游戏是纯粹的单机体验，没有外围成长系统或在线元素。
