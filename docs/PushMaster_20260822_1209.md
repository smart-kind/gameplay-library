# Push Master

- **类型**: 物理/解谜
- **平台**: Mobile (iOS+Android)
- **开发商**: Independent
- **首次发布**: 2023
- **价格**: Free
- **一句话描述**: A physics puzzle game where players push blocks and objects to solve spatial challenges and clear paths.

## 玩法规则

游戏类型为物理/解谜，玩家通过简单的触摸操作与游戏互动。

玩家进入游戏后看到主界面，展示当前状态和可操作选项。根据游戏类型，操作方式可能包括点击、拖拽、滑动或长按。

## 核心循环

完成单局小游戏/任务 → 获得分数和奖励 → 解锁新内容 → 挑战更高难度 → 提升排行榜排名

## 核心机制

- **简化操作**：以点击、拖拽为主，降低上手门槛，适合广泛用户群体。
- **即时反馈**：每次操作都有视觉和音效反馈，增强游戏爽感。
- **进度追踪**：记录个人最佳成绩和历史数据，让进步可量化。
- **多样内容**：合集内包含多种小游戏，避免单一玩法的审美疲劳。

## 为什么好玩

合集类游戏的优势在于多样性——玩腻了一个可以立刻切换到另一个，不会感到单调。每款小游戏都是精心设计的短体验，适合碎片时间快速来一局。

## 粘性来源

游戏合集的多样性避免了审美疲劳——总有一款小游戏适合当前的心情。排行榜和成就系统提供了社交竞争元素，激发好胜心。短平快的单局设计让"再来一局"变得毫无负担。

## Meta 系统

典型的进度系统包含等级、成就和收集要素。玩家通过完成游戏局获得经验值提升账号等级，解锁新的小游戏或外观定制选项。成就系统提供额外的挑战和奖励目标。部分游戏支持皮肤和外观的收集，满足玩家的个性化需求。

## 实现难度

低-中。合集类游戏的难点在于内容整合和统一管理框架，单个小游戏本身复杂度不高。最大技术难点在于保持多个小游戏之间的统一体验质量，以及高效的资源管理和加载策略。
