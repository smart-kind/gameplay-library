# 欲罢不能：恋爱游戏（Too Hot to Handle: Love Is a Game）

- **类型**: 休闲/叙事
- **平台**: Mobile (iOS+Android)
- **开发商**: Fusebox Games / Netflix
- **首次发布**: 2022
- **一句话描述**: 基于 Netflix 真人秀《欲罢不能》的恋爱叙事游戏。

## 玩法规则

互动叙事游戏，玩家管理参赛者之间的恋爱关系。做出对话选择、解决冲突、引导恋爱故事线，同时管理会因参赛者违规而减少的'恋爱基金'。

玩家阅读剧情场景后选择对话回应，不同的选择会影响角色关系发展和恋爱基金金额。多角色关系线同时进行。

## 核心循环

阅读剧情场景 → 做出对话选择 → 管理关系 → 影响恋爱基金 → 解锁新故事分支

## 核心机制

- 选择驱动叙事：对话决定影响关系结果
- 关系管理：同时平衡多个角色关系
- 恋爱基金机制：违规减少奖金池，制造紧张感

## 角色与社交元素

游戏包含多季参赛者的故事线，每个角色有自己的性格和偏好。玩家的对话选择会影响角色之间的关系发展。

社交功能允许玩家分享自己的剧情选择和结局，与社区讨论最佳攻略和隐藏剧情。

## 为什么好玩

热门真人秀格式的互动版，让玩家亲身体验戏剧性和关系动态。

## 粘性来源

多故事分支、角色关系和真人秀戏剧性的成瘾性。

## Meta 系统

Netflix Games — 包含在订阅中

## 实现难度

低 — 以叙事为主，无技能挑战
