# Royal Smash! - Physics Puzzle（Royal Smash!）

- **类型**: 物理弹射 / 解谜 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: CYPHER GAMES YAZILIM PAZARLAMA ANONIM SIRKETI
- **首次发布**: 2026
- **一句话描述**: 用皇家大炮瞄准并击碎塔楼，体验物理连锁破坏的益智游戏。

## 玩法规则

屏幕中央摆放着各种3D物体搭建的塔楼结构——可能是陶罐堆、石柱塔、或者木箱和瓶子混合的陈列。玩家控制一门大炮，位于屏幕下方。

玩家操作分为三个步骤：第一步，拖拽屏幕调整射击角度，屏幕上会出现瞄准线预览弹道轨迹；第二步，按住屏幕蓄力，蓄力条显示当前力度；第三步，松开手指发射炮弹。炮弹沿抛物线飞行，命中目标后产生物理碰撞效果。

被击中的物体会碎裂、弹飞或倒塌，并撞击相邻的物体，产生连锁反应。关卡目标通常是清除所有指定物品——例如击碎所有陶罐、或让所有物品掉出屏幕边界。部分关卡有特殊要求，如保护某些物品不被破坏、或在限定射击次数内完成。

## 核心循环

瞄准蓄力发射 → 击碎目标触发连锁倒塌 → 清空关卡获得评价 → 解锁更复杂的塔楼结构

## 核心机制

- **单指射击系统**：拖拽瞄准+按住蓄力+松开发射，三合一操作简洁流畅。瞄准线预判弹道让玩家可以精确计算，蓄力条控制力度增加操作深度。这个机制降低了上手门槛但保留了精确操作的上限。
- **真实3D物理破坏**：不同材质（陶罐、石柱、木箱）有不同的重量、硬度和碎裂方式。一发射击可能只击碎单个目标，也可能引发整座塔楼的连锁倒塌。物理模拟的真实感是核心体验来源。
- **完美射击奖励**：一发清除全场的"完美射击"带来最大的满足感。游戏鼓励玩家反复尝试找到最优解，而非随便乱射。

## 为什么好玩

物理破坏的视觉反馈极其爽快——看着精心搭建的结构在一击之下轰然倒塌，这种破坏感本身就是一种奖励。瞄准、蓄力、发射的节奏感让人沉浸，"差一点就全清"的心理驱动促使玩家反复尝试。

## 粘性来源

核心是"连锁反应"的视觉+物理复合爽感。每一关都像是一个物理谜题，玩家追求用最少射击次数达成最大破坏效果。3D物理模拟带来的微妙差异让每次尝试都有新鲜感，同时完美射击的追求提供持续挑战动力。

## Meta 系统

无。游戏专注于纯粹的关卡挑战体验。

## 实现难度

中。需要3D物理引擎（如Unity Physics或Bullet）支持刚体碰撞、碎裂效果和重力模拟。最大技术难点在于性能优化——当大量物体同时发生碰撞和碎裂时，需要保持流畅的帧率，这对移动设备的物理计算优化要求较高。
