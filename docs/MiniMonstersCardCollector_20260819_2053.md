# 迷你怪兽：卡牌收藏家（Mini Monsters: Card Collector）

- **类型**: 卡牌收集 / 迷你游戏
- **平台**: Mobile (iOS)
- **开发商**: Homa Games
- **首次发布**: 2024
- **一句话描述**: 结合卡牌收集与迷你游戏的CCG冒险。通过完成迷你游戏挑战赚取金币，开启卡包收集稀有怪兽卡牌，并进行策略卡牌对战。

## 玩法规则

玩家进入游戏后可以看到一个主世界地图界面，地图上分布着多个迷你游戏关卡节点。每个关卡以图标形式展示游戏类型（记忆、解谜、反应等），玩家可以自由选择想要挑战的关卡。

游戏界面顶部显示当前金币数量和已收集的卡牌数量。点击任意关卡后进入迷你游戏，每种迷你游戏有独特的操作方式和规则。例如记忆游戏需要玩家记住卡片位置并配对，解谜游戏需要完成逻辑推理。完成每个迷你游戏后，系统根据表现结算金币奖励。

获得金币后，玩家可以在商店界面购买卡包。卡包分为普通、稀有和传奇三个等级，价格递增。购买卡包后通过开包动画随机获得怪兽卡牌。每张卡牌展示怪兽的名称、稀有度、攻击力、防御力和特殊技能描述。

收集到足够怪兽卡牌后，玩家可以进入对战模式。对战界面中，玩家选择已收集的怪兽组建卡组（最多5只怪兽），然后与对手（AI或其他玩家）进行回合制卡牌对战。每回合玩家可以选择一只怪兽出战，怪兽根据属性相克和技能效果进行战斗，最终消灭对方所有怪兽即获胜。

## 核心循环

玩迷你游戏赚金币 -> 开卡包收集怪兽 -> 用怪兽卡牌进行策略对战 -> 解锁更多内容

## 核心机制

- **迷你游戏挑战**：多种类型的迷你游戏（记忆、解谜、反应、排序等），每种游戏有独立规则，既是娱乐也是赚取资源的主要途径
- **卡包收集系统**：通过金币购买卡包，随机获得不同稀有度的怪兽卡牌，开包动画增强期待感和满足感
- **策略卡牌对战**：每只怪兽有独特属性（攻击、防御、速度）和技能（火焰、冰冻、治愈等），需要组建卡组并制定对战策略
- **稀有度分级**：从普通到传奇的五级稀有度阶梯，传奇卡牌出现率极低，驱动持续收集欲望

## 为什么好玩

将卡牌收集的收集欲与迷你游戏的即时满足感巧妙结合。每次玩迷你游戏都有机会获得稀有卡牌，形成正向循环。对不喜欢纯卡牌或纯休闲的玩家都有吸引力。

## 粘性来源

卡牌收集的随机性（开包快感）+ 迷你游戏的多样性（不会无聊）+ 稀有度阶梯带来的持续目标感。'差一张就集齐'的不甘心驱动反复游玩。

## Meta 系统

卡牌收集图鉴系统。玩家可查看已收集的怪兽，图鉴按稀有度、属性、系列分类。对核心玩法的影响：收集的怪兽用于对战，更强的怪兽提高胜率；图鉴完成度也提供额外奖励。

## 实现难度

中 - 需要设计迷你游戏系统、卡牌收集系统、对战系统的三层架构。最大技术难点：卡牌平衡性设计（确保没有绝对强势的卡牌组合）和迷你游戏多样性（保持新鲜感）。
