# Lost Jewels - Match 3 Puzzle（失落的宝石）

- **类型**: 三消解谜冒险
- **平台**: Mobile (iOS+Android)
- **开发商**: Peak Games
- **首次发布**: 2013
- **一句话描述**: 一款经典三消益智游戏，玩家通过匹配彩色宝石帮助神谕者找回失落的宝藏。

## 玩法规则

游戏界面展示一个充满彩色宝石的网格（通常为8x8或更大的矩形网格）。玩家通过交换相邻的两颗宝石（只能上下左右滑动交换）来形成3颗或更多相同颜色宝石的连线。匹配成功后，这些宝石从网格中消失，上方的宝石下落填补空位，新宝石从顶部补充。

匹配4颗或更多宝石可以触发特殊消除效果：匹配4颗产生直线消除的魔法宝石，匹配5颗产生全屏同色消除的终极宝石。此外还有"魔法护符"系统，使用特定宝石组合可以释放强力消除技能，帮助清除障碍物。

关卡中散布着各种障碍物：锁住的宝石需要多次消除才能解锁，冰层覆盖的宝石需要先消除冰层，锁链连接需要同时消除。每种关卡有明确的目标：收集指定数量的宝石、在限定步数内清除所有障碍物、或在时间结束前达到目标分数。

## 核心循环

选择关卡 → 交换宝石进行匹配 → 消除宝石达成目标 → 解锁新关卡

## 核心机制

- **连锁反应系统**：消除宝石后，上方宝石下落可能产生新的匹配，形成连锁反应（Combo）。连锁次数越多，得分越高，并可能触发放大技能。
- **魔法护符系统**：通过特殊匹配产生的强力道具，提供额外的消除能力。玩家需要在关键时刻合理使用，以应对高难度关卡。
- **渐进式障碍设计**：关卡中不断增加的障碍物类型（锁、冰层、锁链等）迫使玩家改变策略，从单纯的匹配进化为有针对性地消除特定区域。

## 为什么好玩

经典三消的核心循环本身就具有强烈的节奏感和即时反馈——每次匹配都能看到宝石消失、新宝石补充、可能触发连锁。这种"消除-填补-新消除"的连续反馈循环让人难以停下来。

## 粘性来源

连锁反应的爽感和"只差一步"的不甘是核心粘性。每次消除都可能意外触发连锁，带来意想不到的惊喜。社交系统（朋友系统和全球排行榜）增加了竞争维度——看到朋友的进度超越自己时，产生"我也要赶上"的冲动。

## Meta 系统

包含社交系统，玩家可以添加好友、查看好友进度、互相赠送生命值。无基地建设或角色成长等深度外围系统，主要依赖关卡推进提供持续目标。

## 实现难度

低。三消游戏的网格逻辑和匹配算法是成熟的技术方案。最大技术难点在于优化大量宝石动画的流畅度，以及设计足够多样的关卡和障碍物组合以维持长期吸引力。
