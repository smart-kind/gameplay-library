# Six-sided Streets（Six-sided Streets）

- **类型**: 益智 / 道路连接 / 拼图
- **平台**: Web（浏览器）
- **开发商**: 浏览器游戏开发者
- **首次发布**: 2010s
- **一句话描述**: 六边形网格上的道路连接益智游戏——旋转六边形地块，让道路连通形成完整路线

## 玩法规则

画面是一个六边形网格地图，每个六边形地块上有一段道路（直线、弯道、交叉口等）。初始状态下，所有地块的道路方向是随机的（互相不连通）。

操作方式：点击六边形地块旋转它（每次旋转 60 度）。目标是通过旋转所有地块，让道路连通——形成从一个点到另一个点的完整路径。

有些关卡有起点和终点——需要从起点连接到终点。有些关卡要求所有道路都连通（形成闭环）。有些关卡有额外约束——不能有断头路、需要连接特定数量的点等。

## 核心循环

观察当前布局 → 旋转六边形地块 → 检查道路是否连通 → 继续调整直到完成

## 核心机制

- **旋转系统**：每个六边形地块有 6 个可能的旋转角度（0°、60°、120°、180°、240°、300°）。点击一次旋转 60 度。
- **连通检测**：系统实时检测道路是否连通——当相邻地块的道路端点对齐时，它们就连通了。连通的道路会改变颜色或高亮显示，提供视觉反馈。
- **渐进难度**：早期关卡地块少、道路简单。后期关卡地块多、道路复杂（有交叉口、分叉等）。

## 为什么好玩

Six-sided Streets 把道路连接益智游戏的难度提升了一个层次——六边形比正方形有更多的连接可能性，需要更多的空间思维能力。每次成功连通所有道路后的满足感很强。

## 粘性来源

- **空间思维挑战**：六边形的连通比正方形更复杂，需要更多的空间思维
- **渐进难度**：从简单到复杂的关卡设计让难度曲线合理
- **视觉反馈**：道路连通时的高亮效果提供了即时反馈

## Meta 系统

无。纯益智游戏。

## 实现难度

低 + 六边形网格渲染、旋转逻辑、连通检测算法。最大技术难点是连通检测——需要高效地判断相邻地块的道路是否对齐。
