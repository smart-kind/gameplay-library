# 广阔天空（WideSky）

- **类型**: 休闲探索
- **平台**: Web / Mobile (iOS+Android)
- **开发商**: PocketGamer 收录独立游戏
- **首次发布**: 2012
- **一句话描述**: 一款以飞行探索为主题的休闲游戏，玩家在广阔的天空中自由翱翔，发现隐藏的秘密和美丽的风景

## 玩法规则

游戏画面呈现开阔的蓝天白云场景，色彩明快清新，营造出宁静放松的氛围。玩家控制一架小型飞行器，通过简单的触屏操作实现飞行控制：上下滑动调整飞行高度，左右滑动改变飞行方向。

游戏世界中散布着各种可收集元素，包括云朵碎片、彩虹结晶、阳光碎片等。这些收集品通常隐藏在特定的飞行路径上或需要特定的飞行技巧才能到达。部分收集品位于需要穿越狭窄通道或绕行障碍物的位置。

游戏没有严格的时间限制和失败条件，玩家可以按照自己的节奏探索。场景中存在一些动态元素，如飘动的云朵、飞翔的鸟群、变化的风向等，这些元素会增加探索的趣味性。某些区域需要玩家达到一定的收集进度才能解锁，形成隐性的进度引导。

游戏的视觉设计强调开阔感和自由感，远景的山脉、海洋和城市轮廓为探索提供了视觉锚点。飞行过程中会有轻柔的背景音乐和环境音效，增强沉浸感。

## 核心循环

自由探索天空区域 → 发现并收集隐藏元素 → 解锁新的空域和风景 → 继续探索

## 核心机制

- **自由飞行控制：通过简单的触屏滑动实现流畅的飞行体验，没有复杂的按键组合，降低操作门槛**
- **隐藏收集系统：各类收集品分布在场景的角落和难以到达的位置，鼓励玩家改变飞行路线进行探索**
- **开放区域设计：无边界限制的开放式空域，玩家可以自由决定探索方向，没有线性流程的限制**
- **动态环境系统：风向变化、云层移动、天气切换等动态元素为每次飞行带来不同的体验**

## 为什么好玩

在快节奏、高压力的手游市场中，这款游戏提供了难得的放松体验。开放式的探索设计让每次飞行都有不同的发现，没有失败压力，纯粹享受飞行的乐趣。视觉和音效的配合营造出宁静而美丽的氛围。

## 粘性来源

收集完整性的满足感驱动玩家反复探索。开放式设计中'我是不是错过了什么'的心理让人忍不住再多飞一会儿。加上动态环境的变化，即使在同一区域重复飞行也会有新的发现。

## Meta 系统

无复杂的成长系统。主要依靠收集品解锁新的空域和飞行器外观，属于轻度Meta设计。

## 实现难度

低，核心是简单的飞行控制和场景渲染。最大技术难点在于大面积开放场景的性能优化和流畅渲染。


### 操作细节

上下滑动调整飞行高度，滑动的幅度和速度影响高度变化的速率。左右滑动改变飞行方向，持续滑动可以转弯。不操作时飞行器会保持当前姿态缓慢滑翔。

### 收集品类型

游戏中有多种收集品：普通云朵碎片（白色，数量最多）、彩虹结晶（彩色，分布在较高空域）、阳光碎片（金色，需要特定时间段的飞行）、隐藏宝箱（需要穿越特定路径才能发现）。所有收集品收集后可在主界面查看进度。

### 空域解锁条件

初始只开放中心空域，收集一定数量的云朵碎片后解锁周边空域。每个新空域有独特的风景和新的收集品类型。全部空域解锁需要收集大部分云朵碎片。
