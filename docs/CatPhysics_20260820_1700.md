# Cat Physics（Cat Physics）

- **类型**: 物理弹射 / 解谜 / 休闲
- **平台**: Mobile (iOS)
- **开发商**: Donut Games
- **首次发布**: 2010
- **一句话描述**: 利用物理弹射让球在猫咪之间传递的益智游戏，250个关卡，曾获App Store Game Of The Week。

## 玩法规则

游戏画面呈现一个午夜小巷场景，多只猫咪分布在不同位置。画面中还有各种物理机关——翻板、玻璃窗、活板门、弹簧、斜坡等障碍物。

玩家操作：用手指拖拽瞄准并弹射一颗球。球沿物理轨迹飞行，碰到机关后产生相应效果（翻板翻转、弹跳、穿过玻璃等）。目标是将球从一只猫传到另一只猫——球需要依次接触每只猫，最终传到目标猫手中。

每关的猫咪位置和机关布置各不相同。玩家需要计算弹射角度和力度，让球在机关之间穿梭，避开障碍，依次经过每只猫。部分关卡有多条可行路径，玩家可以尝试不同的弹射方案。

## 核心循环

观察猫咪和机关布局 → 规划球的传递路径 → 弹射球 → 观察球的物理运动轨迹 → 成功传递到下一只猫或重新尝试

## 核心机制

- **物理弹射传递**：核心是精确的物理弹射。球的弹道、弹跳、滚动都受物理引擎控制。玩家需要考虑角度、力度、以及机关的触发时机。这个机制之所以有效，是因为物理模拟带来的不确定性——即使同样的操作，微小的差异也会导致不同的结果。
- **互动机关系统**：翻板会翻转改变球的方向，玻璃窗会碎裂让球通过，活板门会在特定时刻打开或关闭。这些机关增加了关卡的复杂度和策略性——玩家需要理解每个机关的行为模式。
- **多解设计**：大多数关卡允许多种解决方案。不同的弹射角度和顺序可能都能完成关卡，这增加了重玩价值——玩家可以探索不同的路径来找到最优解或最优雅的解法。

## 为什么好玩

午夜小巷的温馨美术风格和爵士乐背景营造出轻松愉快的氛围，与物理解谜的紧张感形成有趣的对比。250个关卡提供了充足的挑战内容，多解设计让每个关卡都有探索空间。

## 粘性来源

核心是"找到正确路径"的解谜满足感。当球按照预期轨迹穿过一系列机关，最终到达目标猫咪时，那种"我算准了"的成就感极强。Donut Games的三星评价系统鼓励玩家追求更优解——不是"过就行"，而是追求完美三星。

## Meta 系统

三星评价系统：每关根据表现给予1-3星评价。Game Center成就系统提供额外的长期目标。Collectors Icon #22是该游戏在Donut Games收藏系列中的编号。

## 实现难度

低到中。2D物理引擎即可完成全部功能，机关逻辑相对简单。最大技术难点在于确保物理模拟的精确性和可重复性——玩家需要感到结果是"可计算的"而非随机的，这对物理参数的调校要求较高。
