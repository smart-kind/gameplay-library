# 字谜接龙（Wordscapes Solitaire Word Game）

- **类型**: 文字解谜 / 接龙 / 词汇拼写
- **平台**: Mobile (iOS+Android)
- **开发商**: PeopleFun, Inc.
- **首次发布**: 2023
- **一句话描述**: 将Wordscapes的词汇解谜与经典接龙纸牌结合，用找到的单词作为卡牌来消除牌堆

## 玩法规则

游戏结合了两种经典玩法：词汇解谜和纸牌接龙。

在词汇解谜阶段，玩家在字母圆盘中滑动连接字母组成单词（类似 Wordscapes 的核心玩法）。每找到一个有效单词，该单词会转化为一张"卡牌"。

在接龙阶段，这些单词卡牌以类似纸牌接龙的方式排列。玩家需要按照特定规则（如字母顺序、词长递减等）放置和消除卡牌。例如，可以用一个较长的单词覆盖较短的单词，或将相同字母开头的单词配对消除。

当所有卡牌被成功消除时，该关卡完成。如果卡牌堆积到无法继续操作，则关卡失败。

每个关卡提供一组特定的字母，用这些字母可以组成多个不同长度的单词。找到的单词越多，后续接龙阶段的选择就越丰富。

## 核心循环

滑动字母找单词 → 单词转化为卡牌 → 按规则消除卡牌 → 清空牌堆通关

## 核心机制

- **词汇发现机制**: 从有限的字母集合中组合出有效英文单词，考验词汇量和联想能力。找到的单词越多，接龙阶段的策略选择越丰富
- **卡牌消除规则**: 单词卡牌按照词长、字母匹配等规则进行配对消除，将文字游戏与接龙策略结合，形成独特的混合玩法
- **双重策略层**: 解谜阶段决定"找到哪些单词"，接龙阶段决定"如何消除卡牌"，两层策略相互影响，增加思考深度

## 为什么好玩

将两种独立的休闲玩法巧妙融合，每种玩法单独玩已经很有趣，组合后产生新的策略维度。"我找到的单词越多，接龙就越容易"的因果关系让两个阶段形成有意义的连接。

## 粘性来源

词汇量成长感——随着游戏进行，玩家自然记住更多单词组合；卡牌消除的策略选择提供每局不同的体验；关卡递进提供持续目标；"找到稀有长词"的惊喜感驱动持续探索。

## Meta 系统

关卡递进制：线性推进的关卡系统，每关使用不同的字母组合。每日挑战提供额外词汇任务。无角色养成或货币系统，对核心玩法无影响。

## 实现难度

中。需要整合词汇解谜引擎和接龙逻辑两套系统。最大技术难点是单词卡牌的消除规则设计（既要有策略性又不能太复杂）以及两个阶段之间的数据流转。
