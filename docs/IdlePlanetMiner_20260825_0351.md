# 星球矿工 放置（Idle Planet Miner）

- **类型**: 放置点击/模拟经营
- **平台**: Mobile (iOS+Android)
- **开发商**: Tech Tree Games LLC
- **首次发布**: 2023
- **一句话描述**: 星球采矿主题的放置经营游戏

## 玩法规则

Idle Planet Miner 是一款以星球采矿为主题的放置经营游戏。玩家经营一支采矿队伍，在多个星球上开采资源。

核心操作：点击启动采矿设备，获得初始资源。用资源购买更多采矿设备和工人，实现自动化生产。

多星球系统：解锁新星球后可以在多个星球同时采矿。每个星球有不同的矿产类型和开采效率。

升级系统：可以升级采矿设备效率、工人数量、运输能力等。升级后整体产出提升。

## 核心循环

启动采矿，获得资源，购买设备和工人，解锁新星球，升级效率，继续扩张

## 核心机制

- 多星球采矿：在多个星球同时采矿，每个星球有不同的矿产。扩张到新星是核心进度。
- 自动化生产：从手动点击到完全自动化的渐进过程。
- 升级系统：设备、工人、运输的全面升级。

## 为什么好玩

星球采矿的设定提供了独特的视觉体验，看着矿工在不同星球上工作，资源不断积累。多星球系统提供了明确的长期目标（解锁所有星球）。自动化过程的渐进感也很有满足感。

## 粘性来源

粘性来源：（1）多星球解锁提供长期目标；（2）自动化过程的渐进满足感；（3）离线收益降低回归门槛；（4）星球主题的视觉吸引力。

## Meta 系统

多星球系统。设备和工人升级。自动化生产链。离线收益。

## 实现难度

低。放置游戏基础逻辑，多星球管理增加了一些复杂度。
