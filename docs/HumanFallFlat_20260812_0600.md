# 人类一败涂地（Human: Fall Flat）

- **类型**: 解谜 / 物理 / 平台 / 合作
- **平台**: Steam / Nintendo Switch / PlayStation / Xbox / Android / iOS
- **开发商**: No Brakes Games
- **首次发布**: 2016
- **一句话描述**: 控制一个软绵绵的物理小人在荒诞的世界中攀爬、搬运、摆弄物体的搞笑解谜游戏。

## 玩法规则

游戏画面是一个超现实的梦境世界，由多个关卡组成。每个关卡是一个开放的环境，充满了各种可交互的物体和谜题。

玩家控制的角色 Bob 是一个没有骨骼的"软体人"——他的手臂、腿和身体都可以被直接操控。操作方式是：
- **左键/右键**：分别控制左右手抓取和释放
- **移动键**：控制角色行走
- **跳跃键**：跳跃（但因为身体是软的，跳跃非常笨拙）

核心操作是"抓取"——用左手或右手抓住任何可交互的物体（门把手、箱子、杠杆、绳子等），然后通过移动和跳跃来操作它们。双手可以同时使用，实现攀爬、搬运、投掷等复杂动作。

每个关卡的目标是找到出口。但到达出口的方式不是线性的——玩家需要利用环境中的各种物体和物理特性来解决谜题。比如用箱子垫高来够到高处的平台，用杠杆打开门，用绳子荡过深谷。

## 核心循环

探索环境 → 抓取和操作物体 → 利用物理特性解决谜题 → 找到出口进入下一关

## 核心机制

- **物理抓取**：每只手都可以独立抓取和释放物体，模拟真实的物理互动
- **软体角色**：角色没有骨骼，动作笨拙但有趣，这本身就是游戏的一部分
- **环境交互**：几乎每个物体都可以被抓取和操作，物理模拟贯穿整个游戏
- **多人合作**：支持本地和在线多人，两个软体人一起解谜会产生意想不到的搞笑效果
- **开放解谜**：每个谜题通常有多个解法，玩家可以自由尝试

## 为什么好玩

Human: Fall Flat 的乐趣很大程度上来自它的"失败"——角色的笨拙操作让最简单的动作都变得滑稽。你想爬上一堵墙，但手没抓稳，整个人以一种搞笑的姿势滑落；你想搬一个箱子，但两只手不协调，箱子掉在地上滚远了。这些"失败"不是挫折，而是笑点。当玩家终于成功时，成就感会因为之前的笨拙而加倍。

## 粘性来源

1. **物理搞笑**——角色的笨拙操作本身就很好玩，每次失败都是娱乐
2. **合作乐趣**——和朋友一起玩时，两个笨拙的角色互相"帮助"（或者说"添乱"）是极大的娱乐来源
3. **自由解谜**——每个谜题都有多种解法，鼓励实验和创意
4. **关卡多样性**——每个关卡都有独特的环境和谜题类型

## Meta 系统

可通过游戏内货币解锁不同的角色皮肤和服装。纯外观，不影响玩法。

## 实现难度

高。核心技术是物理引擎的角色控制——一个软体角色的抓取、攀爬、搬运等动作需要精确的物理模拟。最大技术难点是确保物理模拟的稳定性和趣味性之间的平衡：太真实会太笨拙（不可玩），太简化会失去物理搞笑的精髓。
