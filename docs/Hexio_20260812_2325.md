# 六边形连线（Hexio）

- **类型**: 解谜 / 连线逻辑
- **平台**: Mobile (iOS + Android)
- **开发商**: 独立开发
- **首次发布**: 2018
- **一句话描述**: 一款极简风格的连线解谜游戏，玩家需要用不交叉的线条连接相同颜色的节点。

## 玩法规则

游戏界面是一个由节点组成的平面图，节点有不同的颜色。玩家的任务是通过画线将相同颜色的节点连接起来。连线有严格规则：线条不能相互交叉，只能连接相同颜色的节点。

当游戏中出现锚点（黑色圆点）时，玩家的连线必须绕过它——就像用一根真实的线缠绕在一个钉子上。这个机制让游戏从抽象的逻辑题变得更加具象和触觉化，仿佛真的在用线缠绕实物。

谜题的复杂度逐渐递增，以合理可控的节奏引入新元素和更高难度。游戏整体风格极简，没有花哨的视觉效果，专注于纯粹的逻辑解谜体验。配色方案柔和，不刺眼，适合长时间游玩。

锚点绕行机制是 Hexio 最令人满意的特性。当这个机制引入后，游戏从抽象的逻辑谜题变得更加具体和有触感，几乎就像你真的在用一根线绕过实物一样。这种触觉反馈是游戏最大的亮点。

## 核心循环

观察谜题布局 → 规划连线路径 → 执行连线 → 进入下一关

## 核心机制

- **同色连线**: 只能连接相同颜色的节点，需要逻辑推理找出正确的配对方式
- **不可交叉**: 线条不能相互交叉，这大大增加了空间规划的挑战性，需要全局思考
- **锚点绕行**: 连线必须绕过锚点，增加了物理直觉层面的趣味，让解题更像操作实物
- **渐进难度**: 谜题复杂度逐步提升，新元素以合理的节奏引入，不会让人感到突兀
- **极简视觉**: 没有多余的装饰，让玩家专注于谜题本身，减少视觉干扰

## 为什么好玩

Hexio 的魅力在于它创造了一种安静的冥想式体验——解谜过程介于正念和无意识之间，有时你能轻松连续通过几关，有时又需要认真思考。锚点绕行机制带来类似缠绕毛线的触觉满足感。极简风格让大脑可以专注于逻辑本身。

## 粘性来源

主要来自解谜的满足感和冥想式体验的放松感。谜题难度曲线平缓，不会因为太难而让人沮丧，也不会因为太简单而无聊。极简的视觉风格让大脑可以专注于逻辑本身，适合在碎片时间或需要放松时游玩。

## Meta 系统

无。纯解谜游戏，没有外围成长系统。所有动力来自解谜本身的满足感。

## 实现难度

低。核心是图论中的路径规划和碰撞检测。最大技术难点是实现流畅的连线绘制和优雅的锚点绕行算法，确保玩家操作手感自然。连线不能有毛刺或断裂，需要平滑的曲线渲染。
