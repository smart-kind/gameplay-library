# 高塔：放置塔防（The Tower - Idle Tower Defense）

- **类型**: 放置 / 塔防 / 增量
- **平台**: Mobile (iOS+Android)
- **开发商**: 未知
- **首次发布**: 2021
- **一句话描述**: 增量放置塔防游戏——你只控制一座塔，通过不断升级和进化，构建完美的防御体系

## 玩法规则

游戏界面中央是一座垂直生长的塔，敌人从塔的底部涌入，试图到达塔顶。玩家只能控制这一座塔——但可以为其添加各种攻击模块、升级属性和解锁特殊能力。

屏幕布局简洁：中央是塔的可视化展示（随着升级会越来越华丽），周围显示当前属性（攻击力、攻速、范围、暴击率等），底部是操作按钮。玩家通过击败敌人获得金币，金币用于升级塔的各项属性。

每次升级可以选择不同的方向：增加攻击力、扩大攻击范围、提升攻速、解锁新攻击模式（如穿透弹、连锁闪电、范围爆炸等）。塔会逐渐"进化"成完全不同的形态。

## 核心循环

升级塔的属性 → 敌人自动进攻 → 获得金币 → 继续升级/进化 → 突破新层级 → 解锁更多升级选项

## 核心机制

- **单塔深度进化**：不同于传统多塔布局，本游戏深度挖掘"一座塔"的可能性，属性组合和进化路径非常丰富
- **放置挂机**：即使玩家离线，塔也会自动战斗并积累资源
- **永久升级**：部分升级在重置后依然保留（ prestige 机制），鼓励玩家重复挑战
- **属性分支**：每次升级提供多个方向选择，不同选择造就完全不同的塔
- **层级递进**：敌人按层数递增，每层敌人类型和数量不同

## 为什么好玩

"一座塔"的限制反而创造了更深的策略空间——每次升级都是关键决策。看着自己的塔从简陋变得无比强大，成就感很强。放置机制让游戏节奏轻松，适合碎片时间。

## 粘性来源

**数值成长**：攻击力从几十增长到数百万的指数级增长曲线极具吸引力。**"再升一级"**心理：每次升级都立刻能看到效果，促使玩家不断继续。**离线奖励**：重新上线获得大量资源，激发继续游玩的欲望。

## Meta 系统

外围成长系统：
- **天赋树**：永久升级的天赋系统，跨局生效
- **成就系统**：达成特定目标解锁特殊奖励
- **排行榜**：比较最高到达层数
- 对核心玩法的影响：天赋系统提供了永久的成长目标，让每局游戏都更有意义

## 实现难度

中。单塔逻辑相对简单，但需要处理大量敌人的渲染和计算（后期可能有数百个敌人同时存在）。数值平衡是关键难点——升级成本和收益的曲线必须精确，否则游戏会变得无聊或不可能。
