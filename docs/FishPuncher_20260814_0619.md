# Fish Puncher!

- **类型**: 动作 / 点击
- **平台**: Mobile (iOS+Android)
- **开发商**: N/A
- **首次发布**: 2013
- **一句话描述**: 一款搞笑风格的点击动作游戏，玩家控制一只拳击手套在水下世界里击打各种鱼类

## 玩法规则

游戏画面中，各种鱼类从不同方向游过屏幕。玩家通过点击屏幕发射拳击手套击打鱼类。

点击位置决定拳击手套的打击方向和时机。不同类型鱼类有不同的生命值和移动速度。小型鱼类一击即碎，中型需要2-3次，大型鱼需要多次击打且移动速度快。

击中鱼类获得分数和金币。金币可用于升级拳击手套的威力（减少击打次数）、速度（飞得更快）和连击倍率上限。部分鱼类掉落特殊道具：时间减速（放慢所有鱼的速度）、范围爆炸（清除屏幕内所有鱼）、自动追踪（自动锁定最近的目标）。

游戏采用波次制，每波鱼类数量和种类递增，最终出现BOSS鱼。在时间耗尽前尽可能获得高分。连击系统：连续击中鱼类不断叠加连击倍率，漏击或超时则倍率归零。

游戏设有每日挑战模式，每天提供不同的鱼类组合和规则变化。完成每日挑战可获得限定手套皮肤。

## 核心循环

点击击打游过的鱼类 → 获得分数和金币 → 升级手套挑战更强波次

## 核心机制

- **连击系统**：连续命中叠加倍率，漏击清零，高风险高回报
- **手套升级**：用金币提升威力、速度、连击倍率等属性
- **特殊道具**：掉落的能力增强道具改变单局体验

- **每日挑战**：每天不同规则变化，提供新鲜体验


## 为什么好玩

搞笑的打击反馈配合夸张的鱼类表情，让重复的点击操作充满娱乐性。连击系统的节奏感让人上瘾。

## 粘性来源

连击倍率的追求+数值升级的正反馈循环。每次'差点就破记录'的感觉驱动再来一局。

## Meta 系统

手套升级系统：永久性的属性提升。鱼类图鉴：解锁并收集所有鱼类种类。

## 实现难度

低 — 单指点击即可。最大技术难点是大量鱼类实体的流畅动画和碰撞处理。
