# Reflec Beat +（Reflec Beat +）

- **类型**: 音乐节奏 / 对战 / 街机
- **平台**: Mobile (iOS+Android) / Arcade
- **开发商**: Konami
- **首次发布**: 2011（街机），2012（移动端）
- **一句话描述**: 两个玩家在分屏界面上互相弹射节奏方块，根据音乐节奏击中目标的对战音乐游戏。

## 玩法规则

游戏画面被水平分割为上下两部分，上方是对手的区域，下方是自己的区域。屏幕中央有一条分界线，各种方块从分界线两侧出现并向各自区域移动。方块按照音乐的节拍出现，玩家需要在其到达底部判定线时准确点击。

点击的时机会影响得分：Perfect（精确命中）、Great（轻微偏差）、Good（较大偏差）和Miss（未命中）。连续命中会积累Combo数，Combo越高单次得分越多。

同时，成功的Perfect判定会向对手区域弹射干扰方块，增加对手的难度。比赛通常持续一首歌曲的时间（2-4分钟），最终得分高者获胜。

干扰方块分为不同类型：有些会缩小判定窗口，有些会遮挡部分屏幕，有些会在对手区域内制造额外的点击目标。被干扰方块命中的玩家如果未能及时处理，会扣除自己的分数。

## 核心循环

跟随节奏点击方块 → 积累Combo和得分 → 向对手发送干扰 → 赢得对战

## 核心机制

- **节奏判定系统**：根据点击时机与音乐节拍的精确度给出不同评价，需要玩家对音乐节奏有良好的感知和反应速度
- **双向干扰机制**：完美判定不仅为自己得分，还会给对手增加额外的干扰方块，将个人表现直接转化为对对手的压力
- **难度分级**：从简单到困难多个难度级别，不同级别方块密度和速度不同，适合不同水平的玩家

## 为什么好玩

将传统音乐游戏的自我挑战升级为玩家间的直接对抗，节奏感与竞争感双重驱动。

## 粘性来源

具体到机制层面：对战带来的竞争压力是核心粘性——每次"只差一点就赢了"的挫败感驱动立刻再来一局。音乐游戏的技能成长曲线也是重要因素，玩家能清晰感受到自己节奏判断能力的提升。不同歌曲和难度级别的组合提供了丰富的内容变化。

## Meta 系统

- **歌曲解锁系统**：通过游玩解锁更多曲目
- **玩家等级和段位**：根据对战成绩提升等级
- **对核心玩法的影响**：新歌曲提供不同的节奏模式和难度

## 实现难度

中高——音频同步是最大难点，需要确保方块出现时机与音乐节拍精确同步，同时网络对战需要考虑延迟补偿。判定窗口的校准系统也需要精心设计以适应不同设备的触摸延迟。
