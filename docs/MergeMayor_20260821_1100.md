# 合并市长（Merge Mayor）

- **类型**: 合并 / 城镇建造 / 益智
- **平台**: Mobile (iOS+Android)
- **开发商**: Starberry Games GmbH
- **首次发布**: 2021
- **一句话描述**: 一款将合并解谜与城镇建造融合的游戏，玩家扮演新市长，通过合并物品赚取奖励来修复、建造和升级自己的小镇，将其发展为繁华大都市。

## 玩法规则

游戏画面分为上下两部分：上方是城镇视图（展示玩家当前的小镇状态，包括建筑、道路和装饰），下方是合并棋盘（玩家进行合并操作的区域）。

合并棋盘上分布着各种日常物品（工具、材料、装饰品等）。玩家将两个相同的物品拖拽到一起进行合并，生成更高级的物品。这些高级物品可以用来修复或建造城镇中的建筑。

当玩家收集到足够的物品后，回到城镇视图，点击需要修复或建造的建筑，消耗对应物品来推进工程进度。建筑修复后解锁新的区域、故事内容和更多可合并的物品。

游戏包含助手Olivia这一NPC角色，她会为玩家提供任务指引和故事推动。随着城镇的发展，玩家会结识镇民，了解他们的故事，并建立关系。

## 核心循环

合并物品 → 赚取奖励 → 修复/建造城镇建筑 → 解锁新区域和故事 → 合并更高级物品

## 核心机制

- **Merge 2合并系统**：基础合并机制是将两个相同物品合并为一个更高级的物品。这种简单的二合一规则易于理解，但随着物品种类增多，策略深度也相应增加。
- **城镇建造进度系统**：合并的产出直接用于城镇建设。每修复一栋建筑、每解锁一个新区域都是视觉上的明确反馈。小镇从破败到繁荣的渐进变化是游戏最核心的驱动因素。
- **多游戏模式**：游戏提供休闲模式和挑战模式。休闲模式下合并节奏较慢但容错率高，挑战模式下需要更精准的合并策略和更快的反应速度。
- **限时活动与事件**：定期推出限时活动，提供特殊物品、季节性装饰和独特游戏模式。这些活动为游戏注入新鲜内容，鼓励玩家回归。

## 为什么好玩

合并物品看着小镇一点点变好的过程有一种治愈感——每次合并都在为城镇添砖加瓦，这种"我的每一步都在让世界变得更好"的正向反馈非常有吸引力。3D画面精美，建筑修复的动画效果让每次进度推进都有仪式感。NPC角色的故事也增添了情感投入，让小镇不再是冷冰冰的建筑群。

## 粘性来源

城镇完成度是核心粘性来源——看着小镇从几栋破房子变成繁华都市，每个阶段的视觉变化都是巨大的奖励。限时活动提供了回归动力，而NPC角色的故事线索让玩家想要继续推进以了解完整的剧情。"再修复一栋建筑"的心理让人很难停下来。

## Meta 系统

游戏包含市长积分系统（通过合并日常物品解锁大升级来增加）、镇民关系系统和限时活动。城镇中有隐藏世界和独家奖励等待发现。季节性活动和限时游戏模式定期更新。无付费卡点，所有内容可通过正常游玩解锁。

## 实现难度

中。合并逻辑和城镇建造系统都是成熟方案，但大量的建筑模型、动画和故事内容制作工作量巨大。最大的技术难点在于合并棋盘与城镇视图之间的状态同步——需要确保合并产出能准确反映到城镇进度上，同时处理多个并行建筑项目的资源分配。
