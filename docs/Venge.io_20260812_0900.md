# Venge.io

- **类型**: IO / FPS
- **平台**: Web / Mobile
- **开发商**: Venge
- **首次发布**: 2020
- **一句话描述**: 快节奏的第一人称射击 IO 游戏，在紧凑地图中快速击杀。

## 玩法规则

Venge.io 是一款 IO 类型的多人在线游戏。玩家打开浏览器即可立即开始游戏，无需下载安装。

核心玩法是在一个共享的在线竞技场中与其他玩家实时竞争。游戏采用极简的控制方案——通常只需鼠标或简单的键盘操作即可上手。

IO 游戏的标志性特征是：即时加入（无需注册）、每局时间短（通常 2-10 分钟）、简单的核心机制但通过与其他玩家的互动产生深度。

每局游戏开始时，玩家从一个基本状态开始（小尺寸、低等级、简单装备），通过收集资源、击败对手或完成任务来成长和变强。随着游戏进行，竞争加剧，最终只有一个或少数玩家能够获胜。

死亡后立即重新开始，保持快节奏和重复游玩的动力。

## 核心循环

加入游戏 → 收集资源/成长 → 对抗其他玩家 → 获胜或死亡 → 立即重开

## 核心机制

- 即时加入：无需注册，打开网页即玩
- 实时多人：在同一服务器中与其他玩家竞争
- 成长系统：通过收集或击败对手变强
- 简洁控制：鼠标或简单键盘操作
- 短局设计：每局几分钟，快速重开

## 为什么好玩

IO 游戏的核心魅力在于"零门槛"——任何人都可以立即加入并开始竞争。与其他真人的互动（合作、对抗、伏击）让简单的机制产生无限的可能性。

## 粘性来源

- 即时满足：打开即玩，无需等待
- 社交竞争：与真人的对抗比 AI 更有趣
- 快速重开：死亡后立即开始下一局
- 进步感：即使在单局内也能感受到成长
- 排行榜竞争：追求高分和排名

## Meta 系统

大多数 IO 游戏没有传统的外围系统。部分游戏提供皮肤解锁或外观自定义作为长期目标。

## 实现难度

低。IO 游戏的核心技术是 WebSocket 实时通信和简单的游戏逻辑。难点在于服务器优化（同时处理数百名玩家）和反作弊。
