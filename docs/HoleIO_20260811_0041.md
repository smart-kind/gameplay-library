# Hole.io

- **类型**: 休闲竞技
- **平台**: Mobile (iOS+Android)
- **开发商**: Voodoo
- **首次发布**: 2018
- **一句话描述**: 多人在线竞技游戏，玩家控制一个黑洞在城市中吞噬一切，比赛谁吞噬的物体最多最大。

## 玩法规则

俯视角的城市地图，玩家控制一个黑色圆形空洞。手指滑动/拖动来移动黑洞的位置。

游戏开始时，黑洞只能吞噬很小的物体（行人、路灯、垃圾桶）。每吞噬一个物体，黑洞变大一点，就能吞噬更大的物体。

吞噬进度大致是：
1. 行人、小动物、路灯
2. 汽车、公交站牌
3. 建筑、树木
4. 高楼大厦

每局限时约 2 分钟，结束时吞噬物体总质量最高的玩家获胜。地图上有多个玩家同时竞争，需要抢在对手之前吞噬目标。

部分物体需要黑洞达到一定大小才能吞噬，屏幕上会显示可吞噬和不可吞噬的物体提示。

## 核心循环

吞噬小物体 -> 黑洞变大 -> 吞噬大物体 -> 在限时内获得最高分

## 核心机制

- 成长竞赛 — 吞噬到变大的正反馈循环，越吃越快，但对手也在成长
- 限时压力 — 2 分钟的倒计时制造紧迫感，迫使玩家不断行动
- 多人实时竞争 — 多个黑洞在同一地图上争夺资源，需要策略性地抢大目标

## 为什么好玩

极简的操作（只需拖动）加上极大的满足感（看着整栋大楼被吸进去）加上极短的局时（2 分钟）等于完美的碎片时间杀手。视觉上的吞噬效果非常爽快。

## 粘性来源

极短的单局时间（2 分钟）让再来一局几乎没有阻力；排行榜竞争；不同地图场景轮换；皮肤解锁。

## Meta 系统

皮肤解锁系统 — 通过游戏获得积分或观看广告解锁不同的黑洞外观。排行榜系统记录最高分。

## 实现难度

低 — 操作极其简单，只需拖动控制方向。策略性在于优先吞噬能让自己最快变大的目标。最大技术难点在于多玩家实时同步和物理碰撞计算。
