# Coma（Coma）

- **类型**: 冒险 / 解谜 / 叙事
- **平台**: Web（浏览器）
- **开发商**: 浏览器游戏开发者
- **首次发布**: 2010s
- **一句话描述**: 浏览器端冒险解谜游戏，玩家在昏迷的梦境/潜意识世界中探索，通过解谜推进故事

## 玩法规则

游戏画面通常为 2D 横版或等距视角，呈现一个超现实的梦境世界。玩家控制角色在场景中移动、与环境互动、收集物品、解开谜题。

操作方式：点击或键盘控制移动，点击场景中的物品进行互动。谜题类型通常包括：找到正确的物品组合、按正确顺序操作机关、解读符号或线索、记忆和模式识别等。

游戏有叙事驱动——随着谜题的解开，故事逐渐展开，揭示主角昏迷的原因和梦境世界的含义。场景通常有超现实的视觉风格——扭曲的建筑、不合逻辑的物理、象征性的符号。

## 核心循环

探索场景 → 发现线索和物品 → 解开谜题 → 推进故事 → 进入新区域

## 核心机制

- **物品互动**：点击场景中的物品可以查看、拾取或使用。某些物品需要在特定的场景中使用特定的方式。
- **逻辑解谜**：谜题基于逻辑推理——观察环境中的线索，推断出正确的操作方式。谜题难度适中，不会让玩家卡关太久。
- **叙事驱动**：游戏的核心驱动力是故事——玩家想知道"发生了什么"、"主角为什么昏迷"、"梦境中的符号意味着什么"。

## 为什么好玩

Coma 把冒险解谜和叙事结合在一起——解谜不是为了分数，而是为了推进故事。超现实的梦境世界提供了独特的视觉体验，每个场景都像一幅超现实主义画作。

## 粘性来源

- **故事好奇心**：想知道故事的发展和结局是最大的驱动力
- **解谜满足感**：解开谜题后的"原来如此"时刻
- **视觉体验**：超现实的画面风格本身就值得体验

## Meta 系统

无。纯叙事驱动游戏。

## 实现难度

低-中 + 2D 场景、物品互动系统、谜题逻辑。最大技术难点是关卡设计和叙事节奏的平衡——要让谜题有趣但不会太难，故事引人入胜但不会太拖沓。
