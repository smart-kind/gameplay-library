# 口袋版迷你派对（Minigame Party: Pocket Edition）

- **类型**: 休闲合集 / 多人派对
- **平台**: Mobile (iOS+Android)
- **开发商**: Unknown
- **首次发布**: 2023
- **一句话描述**: 一款便携式的多人小游戏合集，包含多种经典派对游戏的手机版。

## 玩法规则

游戏包含数十种不同类型的迷你游戏，支持单人练习和多人对战模式。

每款小游戏有独立的规则和操作方式，但都以简单直观为原则。记忆翻牌游戏需要记住卡片位置并配对。节奏游戏需要按节拍点击屏幕。

多人模式支持本地同屏对战或在线匹配。每局游戏时间短，适合快速游玩。

## 核心循环

选择小游戏 -> 单人练习或多人对战 -> 获得分数 -> 解锁新游戏 -> 继续挑战

## 核心机制

- 多样小游戏库: 涵盖记忆、反应、节奏、益智等多种类型，每款都有独特的玩法和挑战。
- 双模式支持: 单人练习模式提升技能，多人对战模式享受竞技乐趣。
- 渐进式解锁: 通过获得高分解锁更多小游戏，保持长期目标感。

## 为什么好玩

每款小游戏都是经过精心设计的经典玩法，简单易上手但有深度。

多人对战增加了竞争乐趣。游戏的便携性让随时随地都能来一局成为可能。

## 粘性来源

解锁系统提供了再玩一局就能解锁新游戏的动机。

多人对战的不可预测性让人想再来一局。成就系统为每种游戏类型设定了挑战目标。

## Meta 系统

解锁系统：通过高分解锁新游戏。

排行榜：每款游戏有独立的排行榜。

成就系统：完成特定挑战获得徽章。

## 实现难度

低 - 每款小游戏实现简单，核心难点在于内容多样性和平衡性。
