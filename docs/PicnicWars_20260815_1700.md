# Picnic Wars

- **类型**: 策略 / 塔防
- **平台**: PC (Steam)
- **开发商**: Lukas Navratil
- **首次发布**: 2016
- **一句话描述**: 一款以蚂蚁为主角的策略塔防游戏，玩家指挥蚁群保卫野餐食物免受其他昆虫和敌人的侵袭，结合资源收集和基地建设元素。

## 玩法规则

游戏画面为一个俯视视角的野餐场景，散布着各种食物（面包屑、水果、甜点等）。玩家扮演蚁群的指挥者，需要保护这些食物不被敌人抢走。

游戏开始时，玩家拥有一个蚁后和少量工蚁。工蚁可以执行多种任务：搬运食物回巢穴、建造防御工事、攻击敌人、侦察周围区域。

食物是游戏的核心资源。工蚁将食物搬运回巢穴后，玩家可以消耗食物来孵化更多蚂蚁、升级蚁后能力、建造防御设施（如路障、陷阱）。

敌人从地图边缘进入，包括其他种类的昆虫、蜘蛛、甲虫等，它们的目标是抢夺食物。每种敌人有不同的攻击力和速度，需要不同的防御策略。

蚂蚁可以装备小型武器和护甲（由食物材料制成），提升战斗力。高级蚂蚁可以学习特殊技能，如冲锋、喷射毒液、建造临时工事等。

游戏采用波次推进模式，每波敌人的数量和强度递增。在波次间隙，玩家有时间补充兵力和加固防御。

## 核心循环

收集食物 → 孵化蚂蚁 → 建造防御 → 抵御敌人波次 → 升级能力 → 迎接更强敌人

## 核心机制

- 工蚁多任务系统：每只工蚁可以执行搬运、建造、战斗等多种任务，玩家需要合理分配工蚁的工作优先级。这种'有限劳动力管理'是策略深度的核心。
- 食物即货币：食物既是收集目标也是建造资源，还是敌人的攻击目标。这种'资源即战场'的设计让每一次食物搬运都带有风险决策。
- 波次间歇策略：波次之间的准备时间是关键的策略窗口——是补充兵力还是加固防御？是升级蚁后还是孵化特种蚂蚁？每次选择都影响下一波的战斗结果。

## 为什么好玩

蚂蚁视角的微观世界非常有趣——原本不起眼的食物残渣在蚂蚁眼中是巨大的宝藏。指挥一群小蚂蚁对抗各种昆虫的史诗感与微观尺度形成有趣的反差。

## 粘性来源

波次递进带来的'下一波我能守住吗'的紧张感 + 蚂蚁数量和种类的增长带来的成就感。每波胜利后都能立即投入下一波，形成紧凑的游戏节奏。

## Meta 系统

蚁后升级和蚂蚁种类解锁是主要成长系统。通关后解锁更高难度的野餐场景和更多蚂蚁种类。

## 实现难度

中。最大技术难点在于大量单位（蚂蚁和敌人）同时在场时的AI寻路和碰撞检测性能优化。
