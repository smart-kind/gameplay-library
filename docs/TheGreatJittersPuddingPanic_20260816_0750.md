# The Great Jitters: Pudding Panic（The Great Jitters: Pudding Panic）

- **类型**: 休闲 / 动作 / 平台跳跃
- **平台**: Mobile (iOS)
- **开发商**: Retro Dreamer
- **首次发布**: 2013
- **一句话描述**: 帮助可爱的布丁角色在各种关卡中向上攀爬、躲避障碍的动作休闲游戏

## 玩法规则

游戏画面中，玩家控制一个可爱的布丁角色（Jitter），它需要在垂直方向的多层平台之间移动。场景中有各种平台、障碍物和收集品散布在各层。

玩家通过触屏点击或滑动来控制布丁的移动方向。布丁具有弹跳特性，落在平台上会自然弹起。玩家需要把握弹跳时机，让布丁准确落在目标平台上。

游戏的目标是帮助布丁尽可能高地向上攀爬，同时收集途中的物品。场景中可能存在危险障碍物（尖刺、移动陷阱等），触碰即失败。某些版本中还有特殊道具，如弹簧板、传送门等，增加关卡变化。

当布丁掉落屏幕底部或触碰障碍物时，游戏结束。玩家获得基于攀爬高度和收集品数量的分数。

## 核心循环

操控布丁弹跳攀爬 → 收集物品 → 躲避障碍 → 达到更高高度或失败重来

## 核心机制

- **弹性弹跳**：布丁的弹跳特性是核心机制，落在不同材质平台上的弹跳高度不同，玩家需要利用这一点规划路线
- **时机操控**：玩家不直接控制移动方向，而是通过点击时机来影响布丁的弹跳角度和方向
- **渐进关卡设计**：随着高度增加，平台间距变大、障碍物增多、移动平台出现，难度自然递增

## 为什么好玩

布丁角色的可爱形象和物理弹跳的不确定性让游戏充满乐趣。每次弹跳都带有轻微的随机性，但玩家通过精准时机可以影响结果，这种"可控的不可预测性"是休闲游戏的精髓。

## 粘性来源

"再试一次"的冲动非常强烈——每次失败都让人觉得"就差一点点"。收集品和高度分数驱动持续挑战，布丁的可爱形象也增加了情感连接。

## Meta 系统

无

## 实现难度

低 — 2D平台弹跳+简单物理模拟，最大技术难点是弹跳物理的调校，使其既有趣又公平
