## Gameplay Rules

The app provides access to multiple casual games within a single interface. Players browse and select from available games.

Each game has independent mechanics and controls. Games cover various casual genres including arcade, puzzle, and reaction-based challenges.

Games are designed for short play sessions with simple controls and quick restart options.

## Core Loop

Select game -> Play -> Return to menu

## Core Mechanics

- Multi-game interface aggregating casual games.
- Independent scoring per game.
- Simple tap and swipe controls across all games.
