# Slay the Spire

- **类型**: Roguelike / 卡牌构筑 / 地牢探索
- **平台**: Mobile (iOS+Android) / PC / Switch / PS4 / Xbox
- **开发商**: MegaCrit (Balor Games 移动端移植)
- **首次发布**: 2017 (PC Early Access), 2019 (正式版)
- **一句话描述**: 在随机生成的地牢中战斗、收集卡牌、构建专属牌组，攀登不断变化的尖塔

## 玩法规则

游戏采用回合制卡牌战斗。玩家拥有一个牌组（通常 10-20 张牌），每回合从牌组中随机抽取若干张手牌。每张牌代表一个行动（攻击、防御、技能、状态等），打出牌需要消耗"能量点"（通常每回合 3 点）。

玩家面对敌人时，敌人头上会显示其意图（如下回合攻击8点、防御5点、施加中毒等）。玩家根据敌人意图决定出牌策略——是进攻还是防御？

战斗胜利后，玩家可以从随机出现的卡牌中选择一张加入牌组，或选择移除一张牌、获得药水/遗物。遗物是永久生效的被动道具（如"每回合开始时获得1点能量"、"每打出10张牌造成5点伤害"）。

游戏流程是爬塔模式：多层地图节点，玩家选择路线（战斗、精英战、商店、宝箱、休息点）。每层末尾有一个 Boss。到达塔顶并击败最终 Boss 即通关。使用一个角色通关后，解锁新角色和更高难度（进阶模式）。

## 核心循环

选择路线节点 → 进入战斗 → 回合制出牌 → 战胜获得奖励 → 选择新卡/遗物 → 继续攀登 → 挑战Boss

## 核心机制

- **牌组构筑（Deck Building）**：与传统卡牌游戏使用固定牌组不同，玩家在爬塔过程中从随机池中选择卡牌加入牌组。每局牌组完全不同，围绕核心卡牌和遗物构建协同体系。
- **遗物协同系统**：遗物提供被动加成，某些遗物与特定卡牌或流派产生强力配合（如"每次打出力量牌获得2点力量"的遗物配合力量卡组）。寻找和利用这些协同是游戏深度的核心。
- **敌人意图可见**：不同于大多数卡牌游戏隐藏敌人意图，Slay the Spire 显示敌人下一步行动。这让战斗变成信息充分的策略决策——已知信息，如何最优出牌？
- **能量管理**：每回合有限能量（默认3点），卡牌消耗1-3点不等。在有限资源下最大化每回合效率是基本技巧。

## 为什么好玩

将"随机性"从缺点变成了乐趣——每局都是全新的牌组、全新的路线、全新的敌人组合。发现一套卡牌和遗物之间完美协同的"啊哈时刻"，是游戏中最核心的快感来源。而4个角色各有完全不同的玩法风格，重复游玩也不会单调。

## 粘性来源

- **角色多样性**：4个角色（铁甲战士、静默猎手、故障机器人、观者）玩法截然不同，每个都需要不同的学习曲线
- **进阶难度系统**：通关后解锁 20 级进阶难度，逐步增加挑战（如敌人更强、初始牌组更差、商店更贵等）
- **Build 探索**：不同卡牌组合创造无限可能的玩法流派
- **每日挑战**：固定种子的每日挑战，玩家竞争排行榜

## Meta 系统

- **角色解锁**：使用初始角色通关后解锁新角色
- **卡牌图鉴**：解锁所有卡牌后开放图鉴浏览
- **进阶难度**：20级递进难度系统，每级增加一项负面条件
- **统计记录**：详细记录每局的路线选择、卡牌使用频率等数据

## 实现难度

中-高。核心卡牌战斗逻辑本身不难，但难点在于：(1) 数百张卡牌之间的交互逻辑和效果判定——每张卡都可能改变战斗规则，需要高度模块化的效果系统；(2) 遗物系统同样有数百种独立效果，且存在遗物之间的连锁触发；(3) AI 敌人意图系统需要管理多种行为模式；(4) 数值平衡是最大挑战，确保所有 Build 都有竞争力。
